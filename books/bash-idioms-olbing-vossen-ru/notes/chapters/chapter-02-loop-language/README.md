## Ключевая идея

Выбор формы цикла определяется источником значений и понятностью кода. `for arg` неявно перебирает параметры текущего сценария либо функции, тогда как `for arg in "$@"` показывает это явно. Для массивов с пробелами авторы противопоставляют `"${namelist[@]}"` (сохраняет отдельные элементы) и `"${namelist[*]}"` (одна строка). Для потенциально меняющих файлы/удалённые узлы команд сначала рекомендуется демонстрационный `echo`, затем отдельный контролируемый запуск. [PDF 31–42]
