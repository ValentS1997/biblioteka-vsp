# Замечания к исходному тексту главы 2

Режим: RAG-only, без чтения PDF напрямую, тестирования семантики команд или использования внешней документации. Фиксируются **обнаруженные потенциальные дефекты**, не публикуется «исправленная версия» исходника.

## SF-02-01 — [Source wording/code mismatch] — условия while / until

- **Provenance:** PDF 40, RAG [p0040:c01](../../../rag/chunks/p0001-p0100/p0040-c01.md), раздел «Циклы while и until».
- **Вариант A (словесный):** для `while` авторы описывают выполнение тела до обнуления кода условия выхода, а для `until` — выполнение при нулевом коде; также упоминается эквивалентность `until` и `! while`.
- **Вариант B (кодовый):** в том же фрагменте перечислены формы `while <УСЛОВИЕ>; do <ТЕЛО>; done`, `until <УСЛОВИЕ>; do <ТЕЛО>; done`, `! while <УСЛОВИЕ>; do <ТЕЛО>; done` и пример ожидания `until ssh user@10.10.10.10; do sleep 3; done`.
- **Почему требуется проверка:** словесное объяснение направления проверки/полной эквивалентности не подтверждено результатами тестов и может быть прочитано неоднозначно относительно примера ожидания; перед практическим использованием необходимо сверить семантику, но такая сверка вне разрешённого RAG-only анализа.
- **Оценка:** `[Needs confirmation]`; ни один вариант не исправлен и не объявлен эталоном.

## SF-02-02 — [Needs confirmation] — подозрительные текстовые маркеры

- **Provenance:** PDF 39, RAG [p0039:c01](../../../rag/chunks/p0001-p0100/p0039-c01.md), абзац после примера 2.1.
- **Исходный вариант:** обсуждение перенаправления содержит буквальные обозначения `| → .p.` и `> → .gt.`.
- **Почему требуется проверка:** смысл таких замен из извлечённого текста не подтверждён; это может быть исходная особенность, опечатка или ошибка извлечения.
- **Оценка:** `[Needs confirmation]` — не превращать данные пары в исполняемые рекомендации. Для классификации как подтверждённого extraction defect не хватает данных; доступ к PDF напрямую запрещён текущим контрактом.

## SF-02-03 — [Needs confirmation] — интерпретация опции echo -e

- **Provenance:** PDF 38, RAG [p0038:c01](../../../rag/chunks/p0001-p0100/p0038-c01.md).
- **Исходный вариант:** в словесном объяснении `-e` используется формулировка о выключении интерпретации escape-последовательностей; далее есть пример удалённой команды с `echo -e` на PDF 39.
- **Почему требуется проверка:** поведение опции здесь не проверено исполнением, а внешние знания запрещены; сохраняется как вопрос к точной формулировке.
- **Оценка:** `[Needs confirmation]`; не использовать этот пункт как подтверждённую инструкцию настройки вывода.

Статус: открытые замечания к источнику, не blockers для подготовки RAG-grounded артефактов, но предупреждения для применения примеров в эксплуатации.
