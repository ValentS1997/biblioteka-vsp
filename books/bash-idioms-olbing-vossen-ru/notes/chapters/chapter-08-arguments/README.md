## Точность и ограничения

Используется `"$@"` для сохранения отдельных аргументов с пробелами. Разбор длинных ключей в книге построен вручную с `getopts`, вариантом `-)` и вложенным `case`: это не универсальное свойство любого запуска `getopts`. [PDF 113–118]

`OFILE="$OPTARG"` записывает значение **в переменную**, но не в выходной файл. `shift` меняет позиционные параметры, `exit` завершает сценарий. В примере 8.4 перечень ключей в тексте ошибки неполон и комментарий о here-doc использует иную метку; см. [source-findings.md](source-findings.md). Откат: **[Needs confirmation]**.
