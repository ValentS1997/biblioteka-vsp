# Глава 8 — команды и конструкции, подтверждённые RAG

**Provenance:** PDF 111–125, `p0111:c01–p0125:c01`. Классы: read-only, workload-generating, state-changing. Все примеры — исходные учебные конструкции, не проверенные в среде пользователя.

| Конструкция/команда | Класс | Эффект, риск и источник |
| --- | --- | --- |
| `$1`, `$2`, `$#`, `$0` | read-only | Позиционные параметры, количество и имя сценария (PDF 111–112). |
| `filename=${1:-favorite.txt}` | state-changing (переменная) | Присваивает переменной значение первого аргумента или default (PDF 112). |
| `if (($# != 2)); then echo "usage: $0 file1 file2"; exit; fi` | state-changing (поток исполнения) / workload-generating | Проверка количества и завершение сценария (PDF 112). |
| `"$@"` и `"$*"` | read-only (подстановка) | Отдельные аргументы либо одна строка, особенно важно для значений с пробелами (PDF 112–113). |
| `while getopts ':ao:v' VAL ; do ... done` | state-changing (служебные переменные и дальнейшие ветви) | Разбор `-a`, `-o` с параметром, `-v`, включая ошибки (PDF 114–115). |
| `case $VAL in a) ...; o) ...; v) ...; :) ...; *) ...; esac` | зависит от тела | Выбор ветви и обработка ошибок по текущему ключу (PDF 114). |
| `OFILE="$OPTARG"` | state-changing (переменная) | Сохраняет имя выходного файла, **сама по себе файл не записывает** (PDF 114, 117). |
| `shift $((OPTIND -1))` | state-changing (позиционные параметры) | Убирает обработанные ключи и их значения из `$1`… (PDF 114–116). |
| `while getopts ':-:ao:v' VAL ; do ... done` | state-changing | Вариант авторов с разбором длинных ключей через `-)` и вложенный `case` (PDF 116–117). |
| `case $OPTARG in amode) ...; outfile=*) ...; outfile) ...; esac` | по телу | Подстановка отдельного длинного имени и соответствующего действия (PDF 117). |
| `OFILE="${OPTARG#*=}"` | state-changing (переменная) | Получение значения из `--outfile=file.txt` (PDF 117–118). |
| `OFILE="${!OPTIND}"`, `let OPTIND++` | state-changing (переменные) | Чтение отдельного параметра после `--outfile` и сдвиг индекса (PDF 117–118). |
| `PROGRAM=${0##*/}`, `VERSION="$PROGRAM v1.2.3"` | state-changing (переменные) | Имя скрипта без пути и строка версии (PDF 119, 121, 124). |
| `cat <<-EoH` | workload-generating | Печать встроенной справки; дефис удаляет начальные табуляции, не пробелы (PDF 119–120). |
| `Display_Help` | workload-generating | Функция справки в примере 8.4; код завершения выбирается в вызывающей ветви (PDF 120–122). |
| `exit 1` и `exit 0` | state-changing (поток исполнения) | В книге обсуждаются разные статусы для помощи и ошибки; версия выводится с `exit 0` (PDF 120, 121–124). |
| `VERBOSE=':'`, `DEBUG=':'` | state-changing (переменные) | Режим без вывода, команда-заменитель `:` (PDF 121–123). |
| `VERBOSE='echo'`, `DEBUG='echo'` | state-changing (переменные) | Включение печати сообщений через переменную-команду (PDF 121–123). |
| `$VERBOSE 'Example verbose message...'` | workload-generating | После подстановки получает `:` либо `echo`, печать зависит от флага (PDF 122–123). |
| `function parseargs { ... }`, `parseargs "${@}"` | state-changing при объявлении и вызове (по телу) | Рекомендуемое отделение парсинга от основной функциональности (PDF 125). |

## Операционные ограничения

- `cat` в здесь-документе выводит справку, не читает пользовательский файл; варианты с перенаправлением данных в `OFILE` **не** реализованы в приведённых фрагментах. Нельзя приписывать присваиванию `OFILE` создание файла. [PDF 114–125]
- `getopts` выполняет последовательный разбор, меняя индекс; повторный разбор и сброс состояния должны быть подтверждены в пользовательском сценарии: **[Needs confirmation]**. [PDF 114–118]
- В примере 8.4 сообщение `valid options are: aov` не покрывает все указанные в `getopts ':-:adho:vV'` ключи. Сохранено как [source finding](source-findings.md), не исправлено из внешнего знания.
- Для изменяющих действий требуется определить ожидаемые значения флагов, позиционных параметров, статус завершения и способ проверки. Универсальный rollback не указан: **[Needs confirmation]**.
