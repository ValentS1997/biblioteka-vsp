## Суть

Функция Bash вызывается как обычная команда. Её аргументы — `$1`, `$2`, `"$@"`; `$0` сохраняет имя сценария, `FUNCNAME` даёт сведения о вызываемой функции. Результат вызова — статус, а вычисленное содержимое можно передавать через STDOUT, `$(...)` или специально согласованные переменные. `local` помогает защитить переменные вызывающего кода, но область видимости динамическая. [PDF 83–89]

Встроенный `printf` позволяет переносимый форматированный вывод, `-v` для записи в переменную, формат времени `%(... )T` и `%q` для экранирования; наличие и поведение форматов зависят от версии Bash. [PDF 89–93]
