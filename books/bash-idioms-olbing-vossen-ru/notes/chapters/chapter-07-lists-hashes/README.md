## Основные положения

Индексированный массив (`declare -a`) содержит элементы с числовыми индексами, ассоциативный (`declare -A`) — со строковыми ключами. Ассоциативные массивы в книге связываются с Bash 4.0+; массивы не включены в POSIX, поэтому версия и интерпретатор важны. [PDF 94–97]

В кавычках `"${name[@]}"` передаёт **отдельные элементы** (в том числе содержащие пробелы), тогда как `"${name[*]}"` объединяет элементы в **одну строку**. Для обхода ключей используется `"${!name[@]}"`, для количества элементов — `${#name[@]}`. [PDF 96, 98–106]

Хеши позволяют считать повторения: пример 7.5 записывает случайные слова во временный файл, считает их в `myhash`, затем выводит ключи и счётчики с сортировкой. Он **изменяет файловую систему**, содержит перезапись `/tmp/words.txt` и `trap` для удаления. Не выполнять без проверки и разрешения. [PDF 107–109]

## Ограничения

- `unset -v` удаляет переменную или элемент массива в текущей оболочке; реальные последствия примеров с отсутствующими кавычками из главы не проверялись. Для восстановления нужны исходные значения: **[Needs confirmation]**. [PDF 99–106]
- Порядок хеша нельзя считать порядком вставки, а срезы хеша авторы характеризуют как необычные. [PDF 104–106]
