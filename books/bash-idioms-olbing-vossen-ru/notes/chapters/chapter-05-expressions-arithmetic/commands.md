# Глава 5 — подтверждённые команды и формы

**Provenance:** PDF 73–82, RAG `p0073:c01–p0082:c01`. Классы: `read-only`, `workload-generating`, `state-changing`. Классификация относится к конкретной показанной форме; любые дополнительные значения и контексты не считаются подтверждёнными.

| Исходная форма | Класс | Эффект и оговорки |
| --- | --- | --- |
| `sleep 0.25` | workload-generating | Пауза на четверть секунды в примере дробных интервалов; PDF 74. |
| `awk "BEGIN { print $* }"` | workload-generating | Тело вспомогательного сценария `fp` для дробных вычислений; выражение обрабатывает внешняя команда; фактическая среда и последствия запуска [Needs confirmation], PDF 74. |
| `sleep $(fp "6 * 0.25")` | workload-generating | Передать вычисленный интервал в `sleep`; нужен сценарий `fp` из источника; PDF 74. |
| `max=$(( intro + body + outro - 1 ))` | state-changing (shell state) | Присвоить вычисленный результат; PDF 74. |
| `median_loc=$((len / 2))` | state-changing (shell state) | Арифметическое присваивание; PDF 74. |
| `if (( max - 3 > x * 4 )); then ...` | read-only при отсутствии операций присваивания внутри | Проверка статуса вычисления без возвращения самого числа; PDF 75. |
| `(( step++ ))`, `(( dist *= 4 ))` | state-changing (shell state) | Изменение переменных, статус зависит от вычисленного результата; PDF 75. |
| `(( median_loc = len / 2 ))` | state-changing (shell state) | Присвоение с арифметическим статусом; PDF 75. |
| `step=$(( step + 1 ))` | state-changing (shell state) | Альтернатива увеличения счётчика; PDF 76. |
| `let "step++"`, `let "dist*=4"` | state-changing (shell state) | Встроенная арифметическая команда, кавычки имеют значение при пробелах; PDF 76. |
| `declare -i SEE` | state-changing (shell state) | Меняет интерпретацию будущих присваиваний переменной; PDF 77. |
| `SEE=X+Y`, `SAW=X+Y`, `SUM=$X+$Y` | state-changing (shell state) | Иллюстрируют разницу integer и строковых присваиваний, PDF 77; результаты в книге 12, `X+Y`, `9+3`. |
| `if cd $DIR; then ...` | state-changing | Команда `cd` меняет каталог при успешном вызове; фактический путь и возврат [Needs confirmation], PDF 78. |
| `test`, `[ ... ]` | read-only при чистых проверках | Условные выражения через встроенные команды; для `[` нужен завершающий `]`, PDF 78–80. |
| `[[ -n "$DIR" ]]`, `[[ -z "$DIR" ]]` | read-only | Проверка ненулевой/нулевой длины, PDF 79. |
| `man bash`, `help test` | read-only | Справочные команды, PDF 79. |
| `[[ "$FILE_NAME" =~ .*xyzz*.*jpg ]]` | read-only | Демонстрация `=~` и regex без кавычек вокруг шаблона; PDF 79. |
| `[[ $VAR == "literal" ]]` / `[ $VAR = "literal" ]` | read-only при чистой проверке | Книжное сопоставление операторов равенства; пример в источнике не является рекомендацией опускать кавычки для любых значений, PDF 80. |
| `[ $x \> $y ]` | read-only при чистой проверке | Экранирование знака `>` в одинарной скобочной форме; PDF 80. |
| `[[ $OTHERVAL*10 -le $VAL/5 ]]` | read-only | Пример сравнений с числовыми выражениями внутри `[[...]]`; PDF 81. |
| `(( OTHERVAL * 10 <= VAL / 5 ))` | read-only при отсутствии присваиваний | Предпочтённая авторами форма для числовых сравнений; PDF 81. |

## Ограничения и проверка

- Bash рассматривается в книге как язык **целочисленной арифметики**; внешние `bc` и `awk` лишь упомянуты как путь к дробным вычислениям (PDF 73–74).
- `$((step++))` **не использовать самостоятельной строкой**: по тексту главы числовой результат может быть интерпретирован как команда (PDF 76).
- Возвращаемое число и код завершения `((...))` различаются. В выражениях, включающих присваивания, ожидается изменение shell state (PDF 75–77).
- Сведения о точной рабочей директории, результатах запуска и откате исходный RAG не даёт: **[Needs confirmation]**.
