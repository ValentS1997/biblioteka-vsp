## Основной принцип

`$(( выражение ))` возвращает **числовой результат**, пригодный для подстановки в присваивание. `(( выражение ))` выступает **арифметической командой** и передаёт статус завершения: ненулевое значение — статус 0; нулевое — статус 1. Арифметические выражения могут сами изменять значения переменных. [PDF 74–76, RAG p0074–p0076:c01]

Для строковых условий и регулярных выражений авторы предпочитают `[[ ... ]]`, для арифметических сравнений — `(( ... ))`. Одинарные `[ ... ]` эквивалентны вызову `test` с обязательным закрывающим `]`, а `[[ ... ]]` является ключевым словом Bash. [PDF 78–82, RAG p0078–p0082:c01]
