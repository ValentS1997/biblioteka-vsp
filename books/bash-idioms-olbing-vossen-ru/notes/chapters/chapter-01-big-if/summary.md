# Глава 1 — заключительный конспект

Основание: раздел «В заключение: стиль и удобочитаемость» на PDF 28–29, RAG `p0028:c01` и `p0029:c01`. Ниже — смысловая выжимка, а не копирование издательского текста.

1. `&&` и `||` позволяют выполнять предварительные проверки и обрабатывать простые ошибки без развёрнутого `if/then/else`.
2. Основной критерий выбора формы — **удобочитаемость**. Короткие конструкции полезны для одиночных действий, сложные ветвления понятнее с `if`.
3. Для условных выражений в Bash авторы рекомендуют `[[ ... ]]`; сведения о проверках `-n`, `-r` и других можно получить через `help test`.
4. Исторические способы проверки строк важно распознавать в старом коде, но при написании нового кода лучше использовать современные понятные условия.
