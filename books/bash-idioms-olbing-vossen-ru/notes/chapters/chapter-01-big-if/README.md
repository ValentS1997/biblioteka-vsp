## Основной принцип

Правая команда после `&&` запускается при успехе левой, после `||` — при её неуспехе. Оба оператора равноприоритетны и выполняются слева направо; несколько операций в одной ветке требуют группировки. Короткая идиома полезна для простых проверок и обработки ошибок, а сложную логику авторы рекомендуют оформлять обычным `if`. [p0021–p0029:c01]
