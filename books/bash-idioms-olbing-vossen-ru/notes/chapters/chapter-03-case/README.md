## Главная идея

`case … in … esac` сопоставляет значение с шаблонами, а не регулярными выражениями; `?` — один символ, `*` — любое число, `[Yy]` — один из набора, `|` объединяет альтернативы. Важно различать `;;` (закончить case), `;&` (выполнить следующее тело), `;;&` (продолжить поиск совпадения). Последние два варианта авторы советуют комментировать особенно тщательно.
