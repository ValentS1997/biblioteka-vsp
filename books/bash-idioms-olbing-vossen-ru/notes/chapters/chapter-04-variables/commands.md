# Глава 4 — команды и конструкции из RAG

**Источник:** PDF 58–72, RAG `p0058:c01–p0072:c01`. Классификация означает эффект **вычисления выражения в указанном контексте**; использование результата в команде с побочными эффектами может изменить класс действия.

| Подтверждённая форма / инструмент | Класс | Назначение и ограничения |
| --- | --- | --- |
| `$VAR` / `${VAR}` | read-only | Подстановка значения переменной; одинарные кавычки блокируют подстановку, двойные допускают (PDF 58–59). |
| `${#VAR}` | read-only | Длина строкового значения, PDF 59. |
| `${0##*/}` | read-only | Оставляет basename пути из `$0`, PDF 60–61. |
| `${MYVAL#img_}`, `${MYVAL#*_}`, `${VAR##pattern}` | read-only | Удаление префиксов, кратчайшее и длиннейшее совпадения, PDF 61. |
| `${FN%.*}`, `${FN%%.*}`, `${0%/*}` | read-only | Удаление суффикса, сравнение с dirname, PDF 62–63. |
| `${TXT^}`, `${TXT^^}`, `${TXT,}`, `${TXT,,}` | read-only | Изменение регистра возвращаемой строки, PDF 63. |
| `declare -u UPPER`, `declare -l lower` | state-changing | Объявляют переменные со специальными преобразованиями будущих присваиваний; rollback **[Needs confirmation]** (PDF 63). |
| `${FN/ /_}`, `${FN// /_}` | read-only | Замена первого / всех совпадений, PDF 64; некоторые пробелы в таблице требуют проверки, см. source-findings.md. |
| `${FN:0:1}`, `${FN:10:4}`, `${FN:10}` | read-only | Подстроки: смещение, длина либо вся оставшаяся часть, PDF 64–65. |
| `echo "usage: ${0##*/} namesfile datafile"` | workload-generating | Формирует сообщение с базовым именем сценария, PDF 60. |
| `customer_name=${customer_subnet_name%subnet*}` | state-changing (shell state) | Присваивание преобразованной строки в переменную, PDF 65. |
| `fw_object_name=${fw_object_name,,}` | state-changing (shell state) | Присваивание строкового значения в нижнем регистре, PDF 65. |
| `${1:-5}` | read-only | Возвращает первый аргумент или default без присваивания, PDF 68. |
| `LEN="${1:-5}"` | state-changing (shell state) | Присваивает переменной результат условной подстановки, PDF 68. |
| `${LIST:+,}` | read-only | Вычисляет запятую, когда LIST непустой; PDF 68. |
| `LIST="${LIST}${S}${fn}"` | state-changing (shell state) | Наращивание CSV-подобного списка в цикле, PDF 68. |
| `${VAR:=value}` | state-changing | Присвоение default при unset/пустом значении; неприменимо к позиционным параметрам, PDF 69. |
| `unset` | state-changing | Удаляет значение переменной (обсуждается в определении unset), PDF 67. |
| `$RANDOM` | read-only (получение) | Генерирует псевдослучайное целое 0–32767; **не использовать для криптографии**, PDF 69. |
| `declare -a mylist`, `mylist=(foo bar baz one two "three four")` | state-changing (shell state) | Определяет и заполняет массив из примера 4.3, PDF 69. |
| `random=$(( $RANDOM % $range ))` | state-changing (shell state) | Присваивает индекс для выбора из массива, PDF 69. |
| `[ -d "$TEMP_DIR" ] || mkdir "$TEMP_DIR"` | read-only проверка + state-changing создание | В примере временной директории существует **race condition**; авторы предлагают рассмотреть `mktemp`, rollback **[Needs confirmation]**, PDF 70. |
| `mktemp`, `trap` | инструменты, изменение состояния зависит от применения | Упомянуты как возможное улучшение временного каталога и очистки, но готового точного рецепта нет, PDF 70. |
| `$(sort -u "$my_file" \| wc -l)` | workload-generating | Подстановка результата конвейера в переменную; чтение/обработка файла, PDF 70. |
| `$(< /some/file)` | workload-generating | Книжное чтение файла внутренними средствами оболочки, PDF 71; реальный путь **[Needs confirmation]**. |
| `$(echo $(echo $(echo $(echo inside))))` | workload-generating | Вложенная подстановка команд, демонстрация синтаксиса, PDF 71. |
| `aws ec2 run-instances` (команда из `$(...)`) | state-changing (external cloud) | Создание экземпляров из примера DevOps; затраты/доступы/rollback **[Needs confirmation]**; не исполнять, PDF 71. |
| `aws ec2 describe-instances` | read-only / workload-generating (external) | Запрос состояния в DevOps-примере; нужны права и конкретные ID, PDF 71. |

## Интерпретация и риск

- Оператор расширения параметра, используемый **без записи результата**, обычно не меняет значение исходной переменной; помещение результата в `name=…` уже меняет переменную. `${VAR:=value}` сам совершает присваивание в указанном случае. [PDF 60, 67–69]
- Кавычки вокруг значения важны; шаблоны в `#`/`%` используют pattern matching, а не регулярные выражения. [PDF 59, 62]
- Чисто текстовый вывод `echo` не подтверждает существование или доступность исходного файла, целевого каталога или облачного экземпляра.
- Перед `mkdir` / облачным созданием ресурсов нужны независимые условия выполнения, проверка фактического результата и документированный откат. Источник не приводит универсальный rollback — **[Needs confirmation]**.
