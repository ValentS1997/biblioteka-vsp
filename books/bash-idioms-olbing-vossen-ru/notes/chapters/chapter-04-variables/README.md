## Главная идея

`${VAR}` возвращает значение переменной, `${#VAR}` — его длину; `#`/`##` убирают префиксы, `%`/`%%` — суффиксы, `/`/`//` выполняют замену, `:offset:length` извлекает подстроку. Большинство расширений меняют результат подстановки, но не исходную переменную; `${VAR:=value}` — исключение: при unset/пустом значении присваивает default. [PDF 58–69]

Авторы советуют `$(command)` вместо обратных кавычек, особенно для вложений, и рекомендуют снабжать сложные подстановки комментариями. [PDF 70–72]

## Ограничения

Командная подстановка выполняет вложенную команду: среди примеров есть создание облачных экземпляров EC2 (PDF 71), способное изменить инфраструктуру. Генерацию каталога из `$RANDOM` авторы предупреждают как race-prone и предлагают рассмотреть `mktemp` (PDF 70). Сведения о неправильном названии скобок и пробелах в одном примере сохранены в source-findings.md. Нумерованных контрольных вопросов/упражнений не обнаружено; условные review-файлы не создаются.
