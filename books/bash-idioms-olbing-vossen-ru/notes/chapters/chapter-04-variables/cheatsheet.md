# Глава 4 — cheatsheet

**Provenance:** PDF 58–72, RAG `p0058:c01–p0072:c01`. Все сведения — из принятого RAG, результаты исполнения в пользовательской среде не подтверждены.

## Symptom / problem framing

Нужно убрать префикс/суффикс, получить имя сценария, заменить символы, извлечь подстроку, задать default или получить результат команды. Главный риск — спутать получение преобразованного значения с присваиванием, а подстановку внешней команды принять за read-only. [PDF 58–72]

## Read-only checks

- По значению `$0` определить эффект `${0##*/}`, оставляющего имя файла сценария без пути. [PDF 60–61]
- Сопоставить `${FN%.*}` и `${FN%%.*}` на имени с несколькими точками, чтобы не удалять больше требуемого. [PDF 62]
- Сверить табличные ожидаемые значения примеров 4.1–4.2 (имя клиента, адрес, префикс сети), не создавая правил брандмауэра. [PDF 65–67]
- Проверить, является ли значение пустым или unset, прежде чем выбирать условную подстановку с двоеточием. [PDF 67]

## Interpretation

`#`/`##` удаляют кратчайшее/наиболее длинное совпадение слева, `%`/`%%` — справа. Замена через `/` без якоря может затронуть не то вхождение: в примере `frank.gifford.gif` авторы предпочитают суффиксный оператор `%` для удаления расширения. [PDF 61–64]

Большинство расширений исходное значение не меняют; `${VAR:=value}`, в отличие от `${VAR:-value}`, меняет значение, если оно отсутствует или пустое. Формы условных подстановок с двоеточием проверяют пустоту и unset; без двоеточия — только unset (по описанию автора). [PDF 67–69]

## Next action

Выбрать оператор по месту преобразования (лево/право/вся строка), явно документировать его смысл, проверить возвращаемую строку на образце; отдельно выделить эффекты присваиваний и внешних команд. [PDF 61–72]

## Modifying action

`VAR=value`, `declare -u`/`declare -l`, `${VAR:=value}` и `unset` меняют состояние переменных. Пример `mkdir` создаёт каталог; `aws ec2 run-instances` создаёт облачные ресурсы. Запуск без разрешённых путей/аккаунта запрещён. [PDF 63, 67, 69–71]

## Verification / acceptance checks

Сравнить фактический результат расширения с ожидаемым; для присваивания — проверить состояние переменной; для файлов/облака — отдельная авторизованная проверка изменений. Окружение, путь, ID ресурса, результаты: **[Needs confirmation]**.

## Rollback

Универсальный rollback созданных каталогов, экземпляров или изменений окружения глава не даёт: **[Needs confirmation]**. Не использовать демонстрационные команды как готовую эксплуатационную процедуру.
