# Глава 11 — «В заключение»

**Provenance:** PDF **192**, печатная страница **191**, RAG [p0192:c01](../../../rag/chunks/p0101-p0200/p0192-c01.md).

Это заключение книги. Авторы выражают надежду, что читатель научился понимать и писать **идиоматический код Bash**. В последней главе они собрали советы, которые можно использовать как основу **собственного руководства по стилю**. В конце — пожелание успехов в программировании на Bash.

Данный файл сохраняет краткую мысль явного авторского заключения; подробные положения из более ранних разделов главы приводятся в [cheatsheet.md](cheatsheet.md) с собственной адресацией, а не приписываются заключению.

За концом главы следует приложение «Руководство по стилю» с PDF 193, [p0193:c01](../../../rag/chunks/p0101-p0200/p0193-c01.md). Оно является отдельным структурным разделом книги, не частью главы 11.

Внутри главы **не обнаружен отдельно выделенный список контрольных вопросов либо упражнений**. Авторы предлагают составить своё руководство или принять их вариант, но издательского набора вопросов с ответами нет.
