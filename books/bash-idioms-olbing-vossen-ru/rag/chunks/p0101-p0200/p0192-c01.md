В заключение        191

     Замечания по установке в CentOS-6: https://github.com/koalaman/
       shellcheck/wiki/CentOS6.

Дистрибутивы могут содержать старые версии shellcheck. Новые версии
для Linux распространяются в виде архивов tar с единственным ском-
пилированным двоичным файлом, который можно поместить в один из
каталогов, перечисленных в $PATH.

основе которых можно разработать собственное руководство по стилю
