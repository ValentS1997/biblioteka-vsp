62     Глава 2   •  Настраиваем пользователей в Zabbix

                      Рис. 2.3. Окно настройки групп пользователей

  МНОГОФАКТОРНАЯ АУТЕНТИФИКАЦИЯ
   В Zabbix 7.0 появилась возможность использовать многофакторную аутентифика
   цию. Если вы хотите, чтобы пользователи были вынуждены ее использовать, то
   можете активировать ее для группы пользователей на этой же вкладке. Но прежде
   обязательно настройте многофакторную аутентификацию в UsersAuthentication
   (ПользователиАутентификация).

3. Теперь перейдем к следующей вкладке на этой странице — Template permissions
   (Права доступа к шаблонам) (рис. 2.4).

          Рис. 2.4. Окно настройки Template permissions (Права доступа к шаблонам)
                                   групп пользователей

   Здесь можно указать, к каким группам хостов будет иметь доступ группа. Для
   Network devices (Сетевые устройства) уже есть группа хостов по умолчанию,
   которую мы будем использовать в этом примере.
