68     Глава 2   •  Настраиваем пользователей в Zabbix

       Рис. 2.11. Новая роль User+ role с правильными настройками доступа к действиям

Объяснение
Для начала разберемся, какие возможности доступны вам при создании ролей
пользователей в Zabbix.

z Name (Имя) — здесь можно задать имя для роли пользователя.
z  User type (Тип пользователя) — типы пользователей все еще есть в Zabbix 6,
   но теперь назначаются через роли. По-прежнему существует ограничение на
   то, что может видеть определенный тип пользователя, например, у типа User
   никогда не будет больше разрешений, чем доступ для чтения, а тип Super admin
   по-прежнему не имеет ограничений, когда дело доходит до разрешений.
z  Access to UI elements (Доступ к элементам веб-интерфейса) — здесь можно огра
   ничить то, что пользователь может видеть в веб-интерфейсе Zabbix, когда ему
   назначена эта роль пользователя.
z  Access to services (Доступ к сервисам) — здесь можно ограничить доступ к сервисам
  или SLA (соглашение об уровне обслуживания), так как не всем пользователям
   стоит иметь доступ к этим данным.
z  Access to modules (Доступ к модулям) — пользовательские модули веб-интерфейса
   Zabbix полностью интегрированы с системой ролей пользователей, то есть вы мо
   жете выбирать, какие модули веб-интерфейса Zabbix будет видеть пользователь.
z  Access to API (Доступ к API) — может быть ограничен определенными ограничен
   для определенных ролей пользователей. Например, вам может понадобиться
   отдельная роль пользователя для доступа к API и вы ограничите доступ к API
   Zabbix для остальных пользователей.
