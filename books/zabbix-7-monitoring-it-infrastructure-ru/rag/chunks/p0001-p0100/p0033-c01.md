Включение режима высокой доступности Zabbix server      33

  Для RHEL:

   dnf install mariadb-server
   systemctl enable mariadb
   systemctl start mariadb

  Для Ubuntu:

   apt install mariadb-server
   systemctl enable mariadb
   systemctl start mariadb

3. Установив MariaDB, запустите процедуру проверки основных настроек, свя
   занных с безопасностью, выполнив следующую команду:

   mariadb-secure-installation

4. Обязательно отвечайте на вопросы «Да» (Y) и задайте надежный пароль root.
   Настоятельно рекомендуем использовать хранилище паролей.
5. Теперь создадим базу данных Zabbix, к которой будут подключаться наши сер
   веры Zabbix. Войдите в MariaDB, выполнив следующую команду:

   mariadb -u root -p

6. Введите пароль, который вы ранее задали. Далее создайте базу данных Zabbix
   с помощью следующих команд. Не забудьте изменить password во второй, тре
   тьей и четвертой командах:

   create database zabbix character set utf8mb4 collate utf8mb4_bin;
   create user zabbix@'192.168.0.1' identified by 'password';
   create user zabbix@'192.168.0.2' identified by 'password';
   create user zabbix@'192.168.0.5' identified by 'password';
   grant all privileges on zabbix.* to 'zabbix'@'192.168.0.1'
    identified by 'password';
   grant all privileges on zabbix.* to 'zabbix'@'192.168.0.2'
    identified by 'password';
   grant all privileges on zabbix.* to 'zabbix'@'192.168.0.5'
    identified by 'password';
   set global log_bin_trust_function_creators = 1;
   quit

7. Наконец, нужно импортировать начальную конфигурацию базы данных Zabbix, но
   для этого надо установить репозиторий Zabbix. Выполните следующие команды.

  Для RHEL:

   rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rocky/9/x86_64/zabbix-
   release-7.0-2.el9.noarch.rpm
   dnf clean all
