Аутентификация пользователей OpenLDAP и создание по требованию     89

 6. Нажмите Update (Обновить), и все должно выглядеть следующим образом
    (рис. 2.44).

             Рис. 2.44. Пользователь Zabbix Admin со внутренней аутентификацией

 7. Затем выберите раздел UsersAuthentication (ПользователиАутентификация).
    Настройте метод аутентификации по умолчанию на LDAP и группу пользовате
    лей, лишенных прав доступа (рис. 2.45).

                   Рис. 2.45. Метод аутентификации по умолчанию в Zabbix

 8. Далее перейдите на вкладку LDAP settings (Настройки LDAP). Здесь можно на
    строить LDAP-сервер и JIT-provisioning пользователей. Начнем с включения
    тех параметров, которые мы хотим использовать (рис. 2.46).

                                Рис. 2.46. Настройки LDAP

   При использовании только LDAP нам придется создавать пользователей вруч
    ную. При включении JIT-provisioning пользователи будут создаваться и полу
    чать нужные разрешения автоматически.
 9. Теперь в Zabbix можно добавить несколько LDAP-серверов. Добавим наш
    сервер OpenLDAP, нажав кнопку Add (Добавить) в разделе Servers (Серверы).
10. Затем заполните следующие поля (рис. 2.47). По умолчанию в поле Bind password
    (Пароль подключения) хранится значение password.
11. Если хотите, то можете включить JIT-provisioning. Включите его и заполните
   следующие поля (рис. 2.48).
