Использование веб-интерфейса Zabbix     47

z  High availability cluster (Отказоустойчивый кластер) — если вы используете кла
   стер высокой доступности сервера Zabbix, то в данном параметре увидите,
  включен ли он и какова задержка переключения. Кроме того, на странице
   System information (Информация о системе) будет отображаться дополнительная
  информация о высокой доступности.

В зависимости от настроек вы можете увидеть еще два значения.
z  Database history tables upgraded (Обновление таблиц истории базы данных) — такое
   сообщение означает, что одна из таблиц истории базы данных еще не обновлена.
  Числовые (плавающие) таблицы были расширены, чтобы можно было сохра
   нять больше символов для каждой точки данных. Эта таблица не обновляется
   автоматически при переходе с Zabbix 4 на 5 или выше, поскольку не всем она
   нужна, и обновление может занять много времени.
z  Database name (Имя базы данных) — если вы видите имя вашей базы дан
  ных со значением версии, это может означать, что вы используете непод
  держиваемую версию базы. Вы можете увидеть сообщение типа Warning!
   Unsupported <DATABASE NAME> database server version. Should be at least
   <DATABASE VERSION>. (Внимание! Неподдерживаемая версия сервера базы
  данных <НАЗВАНИЕ БАЗЫ ДАННЫХ>. Должна быть не ниже <ВЕРСИЯ
  БАЗЫ ДАННЫХ>.)

Виджет System information (Информация о системе) — один из самых важных для
вашего сервера Zabbix, и, по нашему мнению, его стоит держать на главной па
нели.

Перейдем к следующему виджету — Host availability (Доступность узлов сети)
(рис. 1.19).

                 Рис. 1.19. Виджет Host availability (Доступность узлов сети)

Он предназначен для быстрого обзора и показывает все, что вы хотите знать о со
стоянии доступности отслеживаемых хостов. В этом виджете показано, доступен ли
хост, недоступен или неизвестен. Таким образом, в одном виджете вы получаете
хороший обзор доступности всех хостов, которые можете отслеживать с помощью
Zabbix.
