Настройка мониторинга с помощью Zabbix agent     95

  ПРИМЕЧАНИЕ
   При добавлении новых репозиториев в вашу систему всегда проверяйте страницу
   загрузки Zabbix. Вы можете найти подходящий актуальный репозиторий для вашей
   системы здесь: https://www.zabbix.com/download.

Использование Zabbix agent в пассивном режиме
Начнем с настройки Zabbix agent с пассивными проверками.

1. После установки Zabbix Agent 2 откройте файл конфигурации Zabbix agent для
   редактирования:

   vim /etc/zabbix/zabbix_agent2.conf

  В этом файле можно отредактировать все значения конфигурации Zabbix agent,
   которые могут понадобиться на стороне сервера.

2. Начните с редактирования следующих параметров:

   Server=127.0.0.1
   Hostname=Zabbix server

3. Измените значение параметра Server на IP-адрес сервера Zabbix, который будет
   отслеживать этот пассивный агент. Измените значение Hostname на имя хоста
   отслеживаемого сервера. Получить IP-адрес текущего сервера можно с помо
  щью следующей команды:

   ip addr

4. Теперь перезапустите процесс Zabbix Agent 2:

   systemctl enable zabbix-agent2
   systemctl restart zabbix-agent2

5. Затем перейдите в пользовательский интерфейс вашего Zabbix и добавьте этот
   хост для мониторинга.
6. Выберите раздел Data collectionHosts (Сбор данныхУзлы сети) в пользова
   тельском интерфейсе Zabbix и нажмите кнопку Create host (Создать узел сети)
   в правом верхнем углу.
7. Чтобы создать этот узел сети на сервере Zabbix, нужно заполнить поля, как по
   казано на рис. 3.1.
  Важно добавить следующие значения.
     Host name (Имя узла сети) — для идентификации хоста (должно быть
     уникальным).
