Включение режима высокой доступности Zabbix server      41

20. Затем укажите в Zabbix server name (Имя Zabbix server) lar-book-ha2 (рис. 1.13).

                    Рис. 1.13. Окно настроек Zabbix server для lar-book-ha2

21. Теперь нужно снова включить веб-интерфейс lar-book-ha1, выполнив следую
   щую команду:

    systemctl start nginx

 Это должен быть последний шаг. Теперь все должно работать ожидаемым образом.
 Обязательно проверьте файл журнала Zabbix server, чтобы убедиться, что узлы
 корректно работают в режиме высокой доступности.

 Объяснение
 Теперь, когда мы это сделали, поговорим о том, как на самом деле работает Zabbix
 server в режиме высокой доступности. Начнем с проверки страницы ReportsSystem
 information (ОтчетыИнформация о системе) в веб-интерфейсе Zabbix (рис. 1.14).

 Теперь мы видим, что нам доступна новая информация; например, параметр High
  availability cluster (Кластер высокой доступности). Этот параметр сообщает, включена
 ли поддержка высокой доступности и какова задержка переключения при отказе узла.
 В нашем случае это 1 минута, то есть переключение может занимать до 1 минуты.

 Поскольку Zabbix теперь поддерживает кластеры «один ко многим», мы можем
 видеть здесь каждый узел, участвующий в нашем кластере. Созданная нами кон
 фигурация выглядит так, как показано на рис. 1.15.

 Как вы можете видеть в настройках, мы подключили два узла Zabbix server, lar-
 book-ha1 и lar-book-ha2, к нашей единой базе данных Zabbix, lar-book-ha-db. Она
 является единым источником достоверных данных (single source of truth, SSOT),
 поэтому ее можно использовать и для хранения конфигурации нашего кластера.
