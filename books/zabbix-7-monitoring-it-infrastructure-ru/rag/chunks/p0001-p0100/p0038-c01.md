38     Глава 1   •  Установка Zabbix и начало работы с веб-интерфейсом

 7. Повторим: не забудьте обновить password до надежного и изменить интерфейс
    ens192 на свое имя/номер интерфейса.
 8. Теперь установим веб-интерфейс Zabbix. Для этого выполните следующие
    команды.

   Для RHEL:

    dnf install nginx zabbix-web-mysql zabbix-nginx-conf zabbix-selinux-policy

   Для Ubuntu:

    apt install nginx zabbix-frontend-php zabbix-nginx-conf

 9. Затем нужно будет настроить конфигурацию NGINX. Для этого отредактируйте
   следующие файлы.

   Для RHEL:

    /etc/nginx/conf.d/zabbix.conf

   Для Ubuntu:

    /etc/zabbix/nginx.conf

10. Далее отредактируйте следующие две строки:

    # listen 8080;
    # server_name example.com;

   Получится что-то вроде:

    listen 80;
    server_name 192.168.0.5;

   ПРИМЕЧАНИЕ
    В поле server_name важно добавить IP-адрес или DNS-имя, по которому должен
    быть доступен веб-интерфейс Zabbix. В данном случае мы добавили VIP-адрес,
    которым будет управлять keepalived.

11. Запустите веб-сервер и пакет keepalived, чтобы сделать веб-интерфейс Zabbix
    доступным, с помощью следующей команды:

    systemctl enable nginx keepalived
    systemctl start nginx keepalived

12. Теперь мы готовы к настройке нашего веб-интерфейса Zabbix. Откройте ваш
    VIP-адрес (в примере мы использовали IP-адрес http://192.168.0.5/), и увидите
   следующую страницу (рис. 1.9).
