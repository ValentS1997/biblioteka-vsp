Аутентификация пользователей OpenLDAP и создание по требованию     87

Аутентификация пользователей OpenLDAP
и создание пользователей по требованию
Многие используют SAML в сочетании с Azure Active Directory, но не всегда.
Существует множество различных методов аутентификации пользователей.

Один из таких методов — использование LDAP вместо SAML, например, с помощью
сервера OpenLDAP. Он предоставляет надежную реализацию с открытым исходным
кодом для создания базы данных пользователей с помощью LDAP. Преимущество
этого в том, что JIT-provisioning пользователей работает не только с SAML, но
и с LDAP, а это значит, что мы можем воспользоваться им и здесь.

Подготовка
Чтобы начать работу, понадобится настроенный и готовый к работе сервер
OpenLDAP. Рекомендуется использовать собственный экземпляр OpenLDAP.
В Интернете можно найти множество руководств по настройке OpenLDAP,
а также краткое руководство по запуску последней версии на официальном сайте:
https://www.openldap.org/.

Другой способ — создать тестовую среду OpenLDAP с помощью Docker. Можно
использовать следующую команду:

docker run -p 389:389 -p 636:636 --name openldap-server --detach
oicts/openldap:1.0.0
docker run -p 8081:80 -p 4443:443 --name phpldapadmin --hostname phpldapadmin
--link openldap-server:ldap-host --env PHPLDAPADMIN_LDAP_HOSTS=ldap-host
--detach osixia/phpldapadmin:0.9.0

Пожалуйста, делайте так только для тестирования, поскольку в приведенном выше
коде могут использоваться устаревшие версии.

Порядок действий
После того как OpenLDAP настроен, мы можем приступить к созданию пользова
телей и групп в новой среде OpenLDAP.

1. Откройте графический интерфейс OpenLDAP, перейдя по URL в браузере:

   https://<ip_address_of_server>:4443

2. После входа в систему создадим несколько новых пользователей. Сначала
   щелкните на Login (Войти) в левой части окна. Имя пользователя и пароль по
  умолчанию следующие:

   Login DN: cn=admin,dc=example,dc=org
   Password: admin
