Создание первых пользователей     73

2. Именно на этой странице создаются наши пользователи, и с нее мы будем
   управлять ими. Чтобы создать первого пользователя отдела Networking (Сети)
   с именем s_network, нажмите кнопку Create user (Создать пользователя) в правом
   верхнем углу, в результате чего вы окажетесь на следующем экране (рис. 2.17).

                        Рис. 2.17. Окно настройки пользователей

3. Заполните поле Username (Имя пользователя), указав имя s_network.
4. Важно также добавить этого пользователя в только что созданную группу,
   чтобы предоставить ему необходимые права доступа. Нажмите Select (Выбрать)
  и выберите группу под названием Networking (Сети).
5. И последнее, но не менее важное: задайте надежный пароль в поле Password
   (Пароль); не забудьте его, так как он понадобится нам позже.
6. После этого перейдите на вкладку Permissions (Права доступа) (рис. 2.18), по
   скольку мы пока не будем настраивать вкладку Media (Оповещения).
