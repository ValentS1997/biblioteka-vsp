34     Глава 1   •  Установка Zabbix и начало работы с веб-интерфейсом

   Для Ubuntu:

    wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/
    zabbix-release_7.0-1+ubuntu22.04_all.deb
    dpkg -i zabbix-release_7.0-1+ubuntu22.04_all.deb
    apt update

 8. Затем нужно установить модуль SQL-сценариев Zabbix. Для этого выполните
   следующие команды.

   Для RHEL:

    dnf install zabbix-sql-scripts

   Для Ubuntu:

    apt install zabbix-sql-scripts

 9. Затем импортируйте схему базы данных. Это может занять некоторое время,
    поэтому наберитесь терпения.

    zcat /usr/share/doc/zabbix-sql-scripts/mysql/server.sql.gz | mysql
    --default-character-set=utf8mb4 -u root -p zabbix

10. После этого шага нужно отключить функцию log_bin_trust_function_creators:

    mysql -u root -p
    set global log_bin_trust_function_creators = 0;
    quit;

 Настройка узлов кластера Zabbix server
 Настройка узлов кластера происходит так же, как и настройка любого нового Zabbix
 server. Единственное различие заключается в том, что нужно указать некоторые
 новые параметры конфигурации.

 1. Начнем с добавления репозитория Zabbix 7.0 в наши системы lar-book-ha1
   и lar-book-ha2:

    rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rocky/9/x86_64/zabbix-
    release-7.0-2.el9.noarch.rpm
    dnf clean all

   Для систем Ubuntu используйте следующую команду:

    wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/
    zabbix-release_7.0-1+ubuntu22.04_all.deb
    dpkg -i zabbix-release_7.0-1+ubuntu22.04_all.deb
    apt update
