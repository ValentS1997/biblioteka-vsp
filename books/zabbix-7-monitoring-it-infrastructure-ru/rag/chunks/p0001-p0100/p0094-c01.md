94     Глава 3   •  Настройка мониторинга в Zabbix

Настройка мониторинга с помощью Zabbix agent
Начиная с версии 5 Zabbix официально начал поддержку нового агента — Zabbix
Agent 2. В него внесены значительные улучшения, и он даже написан на другом
языке программирования — Golang вместо C. В этом разделе мы рассмотрим, как
работать с Zabbix Agent 2, и изучим некоторые из новых возможностей, пред
ставленных в нем.

Подготовка
Чтобы начать работу с Zabbix Agent 2, нужно всего лишь установить его на хост,
который мы хотим отслеживать. Убедитесь, что у вас есть пустой хост на базе Red
Hat Enterprise Linux (RHEL) или Ubuntu Linux, готовый к мониторингу.

Порядок действий
Сначала поговорим о том, как установить Zabbix Agent 2, а затем перейдем к работе
с ним.

Установка Zabbix Agent 2
Начнем с установки Zabbix Agent 2 на хост Linux, который мы хотим отслеживать.
Посмотрим, как это сделать в системах RHEL и Ubuntu.

1. Чтобы добавить репозиторий, выполните следующую команду.

  Для RHEL:

   rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rocky/9/x86_64/zabbix-
   release-7.0-2.el9.noarch.rpm

  Для Ubuntu:

   wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/
   zabbix-release_7.0-1+ubuntu22.04_all.deb
   dpkg -i zabbix-release_7.0-1+ubuntu22.04_all.deb

2. Чтобы установить Zabbix Agent 2, выполните следующую команду.

  Для RHEL:

   dnf -y install zabbix-agent2

  Для Ubuntu:

   apt install zabbix-agent2

Поздравляем — Zabbix Agent 2 установлен и готов к работе!
