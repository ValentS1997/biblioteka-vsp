Аутентификация пользователей Azure AD SAML и создание по требованию     79

Эта группа будет просто пустой группой безопасности, которую позже мы будем
использовать для назначения разрешений в Zabbix (рис. 2.25).

                   Рис. 2.25. Окно сведений о группе zbx_admin в Azure

Чтобы настроить SAML, возьмите его настройки из AD или другого провайдера
SAML. Для работы с Zabbix понадобится следующая информация:

z ID объекта IdP;
z URL сервиса SSO (URL единого входа);
z URL сервиса SLO (URL единого выхода);
z атрибут имени пользователя;
z ID объекта SP;
z формат ID объекта SP.

Для обеспечения JIT-provisioning понадобятся следующие данные:

z  Group name attribute (Атрибут имени группы);
z  User name attribute (Атрибут имени пользователя);
z  User last name attribute (Атрибут фамилии пользователя);
z  User group mapping (Соответствие группе пользователей).
