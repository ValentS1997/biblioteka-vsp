80     Глава 2   •  Настраиваем пользователей в Zabbix

Порядок действий
Предположим, что ваш Azure AD уже готов. Посмотрим, как можно настроить
SAML с помощью нашей установки.

1. Перейдите по адресу https://portal.azure.com/.
2. После входа в систему перейдите в Azure AD и нажмите Enterprise Applications
   (Корпоративные приложения).
3. Теперь нажмите + New Application (+ Новое приложение), чтобы создать новое
   приложение. В следующем окне нажмите Create your own application (Создайте
   собственное приложение) (рис. 2.26).

           Рис. 2.26. Страница создания нового корпоративного приложения Azure

4. В следующем окне присвойте новому приложению имя Zabbix и нажмите си
  нюю кнопку Create (Создать) (рис. 2.27).
5. Выберите новое приложение из списка и нажмите Users and Groups (Пользователи
  и группы), чтобы добавить нужных пользователей. В нашем случае это будет
   s_network (рис. 2.28).
6. Если вы настраиваете JIT-provisioning пользователей, то не забудьте добавить
   группу zbx_admin (рис. 2.29).
  При использовании JIT-provisioning добавления группы должно быть достаточно.
7. Вам также нужно назначить роль. Нажмите Select a role (Выбрать роль) и до
   бавьте роль, которую хотите использовать. При использовании JIT-provisioning
  вы можете взять группу zbx_admin, в противном случае просто добавьте пользо
   вателя как User (рис. 2.30).
