46     Глава 1   •  Установка Zabbix и начало работы с веб-интерфейсом

Он содержит всю информацию о системе, а также позволяет следить за тем, что
происходит с сервером Zabbix, и узнать, запущен ли он вообще.

Пройдемся по параметрам.
z  Zabbix server is running (Zabbix server запущен) — сообщает, запущен ли процесс
   Zabbix server и где. В данном случае он запущен и работает на localhost:10051.
z  Zabbix server version/Zabbix frontend version (Версия Zabbix server/Версия веб-
   интерфейса Zabbix) — теперь у нас есть отдельные индикаторы, которые по
   казывают версии сервера и веб-интерфейса Zabbix.
z  Software update last checked (Последняя проверка обновления программного обес
   печения) — еще одно нововведение. Теперь Zabbix будет проверять наличие
   новых релизов за вас, указывая в соседнем столбце последний доступный релиз.
z  Latest release (Последняя версия) — здесь указывается последняя доступная
   версия Zabbix.
z  Number of hosts (enabled/disabled) (Количество узлов сети (активированных/деак
   тивированных)) — здесь указывается количество включенных и отключенных
   хостов (в нашем случае 15 и 5 соответственно).
z  Number of templates (Количество шаблонов) — здесь указывается общее количе
   ство шаблонов, которые у нас есть (284).
z  Number of items (enabled/disabled/not supported) (Количество элементов данных (ак
   тивированных/деактивированных/неподдерживаемых)) — здесь можно увидеть
  подробную информацию об элементах данных: в нашем случае включенных
   (564), отключенных (240) и неподдерживаемых (216).
z  Number of triggers (enabled/disabled [problem/ok] (Количество триггеров (активиро
   ванных/деактивированных [проблема/ок])) — подробная информация о ко
   личестве триггеров. Мы видим, сколько их включено (371) и отключено (38),
   а также сколько находится в состоянии problem (13) и сколько в ok (358).
z  Number of users (online) (Количество пользователей (в сети)) — первое значение
   показывает общее количество пользователей, второе — количество пользовате
   лей, вошедших в интерфейс Zabbix.
z  Required server performance, new values per second (Требуемое быстродействие сер
   вера, новые значения в секунду) — возможно, вы познакомитесь с совершенно
  новым понятием, которое называется «новые значения в секунду» (New Values
   Per Second, NVPS). Сервер получает или запрашивает значения через элементы
   данных и записывает их в базу данных MariaDB (или другую). Информация
   о NVPS, представленная здесь, показывает примерное количество NVPS, по
   лученных сервером Zabbix. Внимательно следите за этим показателем по мере
   роста вашего сервера Zabbix, так как это хороший индикатор, позволяющий
   понять, как скоро придется увеличивать доступные серверные мощности.
