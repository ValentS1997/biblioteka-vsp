Аутентификация пользователей Azure AD SAML
и создание пользователей по требованию
В этом разделе мы будем использовать аутентификацию на основе языка разметки
декларации безопасности (Security Assertion Markup Language, SAML) — широко
распространенную форму аутентификации в мире информационных технологий.
Стандарт SAML позволяет обмениваться данными авторизации между приложе
ниями, поэтому мы можем осуществлять аутентификацию между приложением
Zabbix и поставщиком аутентификации (authentication provider). Мы будем ис
пользовать это как способ управления паролями для наших пользователей Zabbix.
Обратите внимание: если вы настроили аутентификацию пользователей только
с помощью паролей в SAML или LDAP, то вам все равно придется вручную соз
давать пользователей с их правами доступа в Zabbix. Чтобы обойти эту проблему,
начиная с версии Zabbix 6.4, можно настроить функцию создания пользователей
по требованию (Just In Time, JIT-provisioning).
