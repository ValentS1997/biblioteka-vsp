                   Рис. 2.42. Группы и пользователи сервера OpenLDAP

   Если вы используете собственную среду OpenLDAP, то убедитесь, что у вас есть
   хотя бы одна группа и один пользователь для тестирования.
4. Используем эти имена пользователей и группы для настройки LDAP-аутен
  тификации с JIT-provisioning пользователей.
5. Перейдите в веб-интерфейс Zabbix и выберите раздел UsersUsers (Пользовате
   лиПользователи). Сначала предоставьте доступ себе в любое время, даже если
   метод аутентификации по умолчанию будет переключен на LDAP. Переключите
   метод аутентификации по умолчанию для пользователя Admin на внутренний,
   добавив его в группу Internal (Внутренний) (рис. 2.43).
