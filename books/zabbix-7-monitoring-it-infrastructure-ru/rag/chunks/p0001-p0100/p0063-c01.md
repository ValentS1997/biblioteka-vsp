Создание групп пользователей     63

4. Нажмите кнопку Select (Выбрать), чтобы открыть всплывающее окно с доступ
  ными группами хостов. Выберите Templates/Network devices (Шаблоны/Сетевые
   устройства), и вы вернетесь в предыдущее окно с заполненной группой.
5. Выберите разрешение Read-write (Чтение-запись).
6. Больше мы ничего добавлять не будем, поэтому нажмите большую синюю кноп
   ку Add (Добавить), чтобы завершить создание данной группы хостов.

  СОВЕТ
   При использовании аутентификации Zabbix, такой как HTTP, LDAP или SAML, все
   равно необходимо создавать пользователей внутри системы с нужными правами
   доступа, если вы не используете автоматическую инициализацию пользователей
    (JIT-provisioning). Для этого настройте пользователей так, чтобы их имена совпа
   дали с именами пользователей в методе аутентификации Zabbix, и используйте
   этот метод для управления паролями. При использовании JIT-provisioning об этом
   можно не беспокоиться.

   Теперь у нас есть новая группа пользователей под названием Networking (Сети),
   которой разрешено читать и писать только в группе шаблонов Templates/Network
    devices (Шаблоны/Сетевые устройства) (рис. 2.5).

                    Рис. 2.5. Окно User groups (Группы пользователей)

7. Повторим этот процесс, чтобы создать новую группу пользователей Infrastructure
   (Инфраструктура). Но вместо добавления группы шаблонов Templates/Network
    devices (Шаблоны/Сетевые устройства) мы добавим группу хостов Linux servers
   (Серверы Linux) (рис. 2.6).
8. Нажмите кнопку Add (Добавить), чтобы сохранить эту группу хостов.
