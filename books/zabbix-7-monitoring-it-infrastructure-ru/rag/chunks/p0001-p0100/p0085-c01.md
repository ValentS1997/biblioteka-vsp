                           Рис. 2.39. Окно входа в систему Zabbix

 Объяснение
 Аутентификация пользователей Zabbix с помощью SAML по умолчанию исполь
 зуется для централизованного управления паролями. В прошлом мы не могли
 назначать группы пользователей и права доступа пользователям с помощью этой
 настройки. Если мы настроим ее без JIT-provisioning пользователей, то сможем ис
 пользовать ее для простого управления паролями.

 Таким образом, нам будет проще обеспечить централизованное хранение паролей
 для пользователей (рис. 2.40).
