4. Не забудьте обновить password до безопасного и изменить интерфейс ens192 на
   свое имя/номер интерфейса.

  ПРИМЕЧАНИЕ
   В предыдущем файле мы указали virtual_router_id 51; убедитесь, что иденти
   фикатор виртуального маршрутизатора 51 еще не используется нигде в сети.
   Если используется, то просто измените идентификатор виртуального маршрути
   затора.

5. На lar-book-ha2 отредактируйте тот же файл с помощью следующей команды:

   vim /etc/keepalived/keepalived.conf

6. Удалите все из файла с помощью dG (если используете vim) и на этот раз до
   бавьте следующую информацию:

   vrrp_track_process chk_nginx {
         process nginx
         weight 10
   }
   vrrp_instance ZBX_1 {
           state BACKUP
           interface ens192
           virtual_router_id 51
           priority 243
           advert_int 1
           authentication {
                   auth_type PASS
                   auth_pass password
           }
           track_process {
                   chk_nginx
           }
           virtual_ipaddress {
                   192.168.0.5/24
           }
   }
