96     Глава 3   •  Настройка мониторинга в Zabbix

      Host groups (Группы узлов сети) — чтобы логически сгруппировать хосты.
      Interfaces (Интерфейсы) — для мониторинга данного хоста через опреде
      ленный интерфейс. Отсутствие интерфейса означает отсутствие связи.
     В Zabbix 7 можно иметь хост без интерфейса, если он не нужен. В случае,
       если мониторинг осуществляет Zabbix agent, интерфейс агента обязателен.

                     Рис. 3.1. Страница создания узла сети lar-book-agent

 8. Убедитесь, что добавили правильный IP-адрес в конфигурацию интерфейса
    Agent (Агент).
 9. Важно подключить к этому узлу сети шаблон. В Zabbix 7 это можно сделать на
    той же вкладке. Поскольку это Linux-сервер, мониторинг которого осущест
    вляет Zabbix agent, то нужно добавить правильный готовый шаблон (рис. 3.2).
10. Нажмите синюю кнопку Add (Добавить), чтобы завершить добавление этого узла
    сети. Теперь, когда у вас есть этот хост, убедитесь, что значок ZBX стал зеленым,
    указывая на то, что этот хост работает и отслеживается Zabbix agent в пассивном
   режиме (рис. 3.3).
