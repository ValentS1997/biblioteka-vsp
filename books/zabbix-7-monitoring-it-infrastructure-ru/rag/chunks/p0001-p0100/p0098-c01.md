98     Глава 3   •  Настройка мониторинга в Zabbix

Использование Zabbix agent в активном режиме
Теперь узнаем, как настроить Zabbix agent с активными проверками. Нам нужно
изменить некоторые значения на стороне хоста контролируемого Linux-сервера.

1. Начните с выполнения следующей команды:

   vim /etc/zabbix/zabbix_agent2.conf

2. Теперь отредактируем следующее значение, чтобы превратить этот хост в ак
   тивного агента:

   ServerActive=127.0.0.1

3. Измените значение ServerActive на IP-адрес сервера Zabbix, который будет
   следить за этим пассивным агентом. Затем измените значение Hostname на имя
   вашего хоста. В нашем случае это lar-book-agent:

   Hostname=lar-book-agent

  ПРИМЕЧАНИЕ
   Если вы работаете с несколькими Zabbix server или прокси-серверами Zabbix,
   например, когда запускаете Zabbix server в режиме высокой доступности, то
   при использовании параметра ServerActive необходимо указать IP-адреса всех
   Zabbix server или прокси-серверов Zabbix. Узлы высокой доступности разграни
   чиваются с помощью точки с запятой (;), а IP-адреса различных сред Zabbix —
   запятой (,).

4. Теперь перезапустите процесс Zabbix Agent 2:

   systemctl restart zabbix-agent2

5. Далее перейдите во фронтенд вашего сервера Zabbix и добавьте еще один хост
   с шаблоном, который будет выполнять активные проверки вместо пассивных.
6. Сначала переименуем наш пассивный узел сети. Для этого выберите раздел Data
   collectionHosts (Сбор данныхУзлы сети) в интерфейсе Zabbix и щелкните на
   только что созданном узле. Измените Host name (Имя узла сети) следующим
   образом (рис. 3.5).
