82     Глава 2   •  Настраиваем пользователей в Zabbix

11. Теперь в пункте 1 мы можем добавить следующую информацию, где черные
    метки — это URL нашего сервера Zabbix (рис. 2.32).

                          Рис. 2.32. Настройка Azure SAML, пункт 1

12. В пункте 2 заполните следующие поля (рис. 2.33).

                          Рис. 2.33. Настройка Azure SAML, пункт 2

13. Поля в пункте 3 будут заполнены автоматически. Нажмите кнопку Download
    (Скачать) для параметра Certificate (Base64) (рис. 2.34). В результате будет за
    гружен файл сертификата в формате Base64.

                          Рис. 2.34. Настройка Azure SAML, пункт 3

14. Войдите в интерфейс командной строки (command-line interface, CLI) сервера
    Zabbix и создайте новый файл с помощью следующей команды:

    vim /usr/share/zabbix/conf/certs/idp.cert
