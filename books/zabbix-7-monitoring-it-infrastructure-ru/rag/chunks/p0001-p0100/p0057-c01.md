ватели) (рис. 1.35). Здесь находятся пять разных страниц.

z  User groups (Группы пользователей) — здесь можно на
   строить группы пользователей и права доступа для
   них.
z  User roles (Роли пользователей) — здесь можно на
   строить роли различных пользователей, чтобы огра
   ничить или расширить определенные функции веб-
   интерфейса для определенных пользователей.

z  API tokens (API токены) — раньше эта страница была скрыта, но теперь ее

   настройки для нового механизма предоставления доступа по требованию (just-
   in-time, JIT).
