Использование веб-интерфейса Zabbix     51

                            Рис. 1.24. Виджет Graph (График)

Некоторые новые виджеты, которые вы найдете на этой странице, — это виджеты
Top hosts (Топ узлов сети), Item value (Значение элемента данных) и Geomap (Гео
карта). Начнем с виджета Top hosts (Топ узлов сети) (рис. 1.25).

                       Рис. 1.25. Виджет Top hosts (Топ узлов сети)

Виджет Top hosts (Топ узлов сети) можно настроить так, чтобы он показывал
список любых элементов. Затем можно отсортировать этот список, чтобы был
показан элемент с наибольшим (Top N) или наименьшим (Bottom N) значением, что
дает отличный обзор хостов с наибольшей нагрузкой на процессор в данном
случае.

Виджет Item value (Значение элемента данных) также очень
полезен, он показывает значение одного конкретного эле
мента (рис. 1.26).
