Использование ролей пользователей     69

z  Access to actions (Доступ к действиям) — в ролях пользователей Zabbix можно
   ограничить определенные действия, в том числе возможность редактирования
   панелей управления, управление токенами API и т. д.

Теперь посмотрим, что мы изменили между двумя ролями пользователя: User role
и User+ role. Роль пользователя по умолчанию, называемая User role, имеет следу
ющий доступ к элементам веб-интерфейса (рис. 2.12).

                Рис. 2.12. Доступ к элементам веб-интерфейса роли User role

По умолчанию в Zabbix 6 есть три роли пользователя, отражающие доступные типы
пользователей. Роль, которую мы видим в поле Name (Имя) на рис. 2.12, соответству
ет типу пользователя User. Она предоставляет доступ к элементам веб-интерфейса,
ограничивая роль пользователя под названием User role, чтобы тот мог видеть только
определенные элементы и не мог вносить никаких изменений в конфигурацию.
