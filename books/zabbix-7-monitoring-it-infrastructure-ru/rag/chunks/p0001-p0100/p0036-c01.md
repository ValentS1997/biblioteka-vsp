36     Глава 1   •  Установка Zabbix и начало работы с веб-интерфейсом

 9. Чтобы включить высокую доступность на этом узле сети, добавьте в тот же файл
   следующую строку:

    HANodeName=lar-book-ha2

10. Чтобы наш веб-интерфейс Zabbix знал, к какому узлу подключаться в случае
    отказа узла, заполните следующее:

    NodeAddress=192.168.0.2

11. Сохраните файл и запустите Zabbix server на каждом узле:

    systemctl enable zabbix-server
    systemctl start zabbix-server

 Настройка NGINX в режиме высокой доступности
 Мы будем использовать пакет keepalived, чтобы наш веб-интерфейс при возникно
 вении проблем с одним из Zabbix server переключался на резервный. Посмотрим,
 как это сделать.

 1. Сначала войдем в систему lar-book-ha1 и lar-book-ha2 и установим пакет
    keepalived. Для этого выполните следующие команды.
   Для RHEL:

    dnf install -y keepalived

   Для Ubuntu:

    apt install keepalived

 2. Затем на lar-book-ha1 отредактируйте конфигурацию keepalived с помощью
   следующей команды:

    vim /etc/keepalived/keepalived.conf

 3. Удалите все из этого файла (если он еще не пуст) и добавьте в него следующий
    текст:

    vrrp_track_process chk_nginx {
          process nginx
          weight 10
    }
    vrrp_instance ZBX_1 {
            state MASTER
            interface ens192
            virtual_router_id 51
            priority 244
            advert_int 1
            authentication {
                    auth_type PASS
