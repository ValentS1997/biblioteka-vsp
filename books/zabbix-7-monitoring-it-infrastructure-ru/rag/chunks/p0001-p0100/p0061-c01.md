Создание групп пользователей     61

Итак, в Cloud Hoster есть отделы, которым нужен доступ к веб-интерфейсу Zabbix,
и отделы, которым он не нужен вовсе. Допустим, мы хотим предоставить доступ
к веб-интерфейсу Zabbix следующим отделам:

z «Сети» — настройка и мониторинг сетевых устройств;
z «Инфраструктура» — настройка и мониторинг серверов Linux;
z «Закупки и инвентаризация» — просмотр инвентарной информации и сопо
   ставление ее с внутренними инструментами.
Порядок действий
Приступим к созданию этих трех групп в пользовательском интерфейсе Zabbix.

1. Выберите раздел UsersUser groups (ПользователиГруппы пользователей),
   в результате чего увидите следующую страницу (рис. 2.2).

                    Рис. 2.2. Окно User groups (Группы пользователей)

2. Начнем с создания группы Networking (Сети), нажав кнопку Create user group (Соз
   дать группу пользователей) в правом верхнем углу. В результате вы увидите
   следующее окно (рис. 2.3).
  Нужно заполнить информацию, начиная с Group name (Имя группы), которое,
   конечно же, будет Networking. Пользователей для этой группы пока нет, поэто
  му данный пункт пропустим. Пункт Frontend access (Доступ к веб-интерфейсу)
   дает возможность обеспечить аутентификацию; если здесь выбрать LDAP, то для
   аутентификации будет использоваться LDAP-аутентификация. Мы оставим
   System default (Системная по умолчанию), которое использует внутреннюю си
   стему аутентификации Zabbix.
