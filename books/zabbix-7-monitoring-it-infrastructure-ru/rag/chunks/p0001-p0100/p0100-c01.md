100     Глава 3   •  Настройка мониторинга в Zabbix

   Обратите внимание: начиная с версии Zabbix 6.2 значок ZBX должен стать
   зеленым для активного агента. Когда вы переходите в раздел MonitoringHosts
  (МониторингУзлы сети) и проверяете Latest data (Последние данные), то
   видите, что ваши активные данные поступают.

  СОВЕТ
   Как вы могли заметить, Zabbix agent может работать одновременно в пассив
   ном и активном режиме. Помните об этом при создании собственных шаблонов
   Zabbix agent, поскольку можете захотеть комбинировать типы проверок. В ко
   нечном счете тип элемента будет определять способ выполнения проверок для
   агента.

Объяснение
Теперь, когда мы настроили Zabbix agent и знаем, как они должны быть настроены,
посмотрим, как работают различные режимы.

Пассивный агент
Пассивный агент работает, собирая данные с нашего хоста с помощью Zabbix agent.
Каждый раз, когда элемент на хосте достигает интервала обновления, сервер Zabbix
спрашивает Zabbix agent, какое значение он собрал сейчас (рис. 3.8).

                   Рис. 3.8. Взаимодействие сервера и пассивного агента

Пассивные агенты отлично подходят для работы в средах, где необходимо под
держивать связь, инициированную со стороны сервера Zabbix или прокси-сервера
Zabbix. Примером может служить ситуация, когда брандмауэр разрешает только
исходящий трафик со стороны сервера или прокси-сервера Zabbix.

Активный агент
Активный агент работает, отправляя данные с Zabbix agent на сервер Zabbix
или прокси-сервер Zabbix. Каждый раз, когда элемент агента достигает интер
вала обновления, агент сам собирает значение для отправки на наш сервер
(рис. 3.9).
