78     Глава 2   •  Настраиваем пользователей в Zabbix

Подготовка
Чтобы начать работу с SAML-аутентификацией, понадобится настроенный сервер
Zabbix из предыдущего раздела. Важно, чтобы у нас были все пользователи, настро
енные в предыдущем разделе. Нам также понадобится что-то для аутентификации
с помощью SAML. Мы будем использовать Microsoft Azure Active Directory (AD)
SAML. Сейчас эта служба получила новое имя — Microsoft Entra ID.

Прежде чем продолжить работу над этой задачей, обязательно настройте пользо
вателей в Azure AD. Вы можете задействовать своих имеющихся пользователей
AD для аутентификации, поэтому описанные здесь действия можно выполнять
с существующей настройкой AD.

В качестве примера будем использовать s_network, а также новую группу пользова
телей JIT_Admin в нашей среде Zabbix без каких-либо установленных прав доступа.
Пользователь Azure выглядит следующим образом (рис. 2.23).
