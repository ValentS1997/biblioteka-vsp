Создание информационных панелей     253

29. Нажмите кнопку Add (Добавить) в нижней части этого окна, чтобы сохранить
    изменения и добавить виджет.
30. Теперь добавим последний виджет Pie chart (Круговая диаграмма). Снова на
   жмите + Add (+ Добавить).
31. Задайте для параметра Name (Имя) значение CPU timings. Для host pattern (Шаблон
    узлов сети) задайте Zabbix server, а для item pattern (Шаблон элементов данных) —
    CPU * time (рис. 6.45).

               Рис. 6.45. Форма создания виджета Pie chart (Круговая диаграмма)

32. На вкладке Legend (Легенда) задайте для параметра Number of rows (Количество
    строк) значение 3.
33. Теперь нажмите кнопку Add (Добавить) в нижней части страницы, чтобы со
    хранить изменения и добавить виджет.
34. Теперь ваша новая страница должна выглядеть так, как показано на рис. 6.46.
