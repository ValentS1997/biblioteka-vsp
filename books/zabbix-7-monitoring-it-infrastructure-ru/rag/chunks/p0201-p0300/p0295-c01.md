Настройка сетевого обнаружения Zabbix agent      295

 9. Далее перейдите на вкладку Operations (Операции) и добавьте информацию, как
    показано на рис. 7.4.

                          Рис. 7.4. Вкладка Operations (Операции)

10. С Zabbix agent для Linux мы закончили. Нажмите синюю кнопку Add (Доба
    вить). Теперь займемся правилом обнаружения Windows.
11. Выберите раздел Data collectionHost groups (Сбор данныхГруппы узлов
    сети). Создайте группу узлов сети для Windows, щелкнув на Create host group
    (Создать группу узлов сети) в правом верхнем углу и заполнив имя группы
    (рис. 7.5).

                Рис. 7.5. Страница Create host group (Создать группу узлов сети)

12. Нажмите синюю кнопку Add (Добавить) и выберите раздел AlertsActions
   (ОповещенияДействия).
13. Снова перейдите в раздел Discovery actions (Действия обнаружения) и нажмите
     Create action (Создать действие). На вкладке Action (Действие) введите ту же
   информацию, но на этот раз для наших узлов сети Windows (рис. 7.6).
14. Прежде чем нажать кнопку Add (Добавить), заполните вкладку Operations (Опе
    рации) данными об операциях (рис. 7.7).
15. Теперь можно нажать синюю кнопку Add (Добавить), и мы завершим создание
    второго действия обнаружения.
16. Выберите раздел MonitoringDiscovery (МониторингОбнаружение). Здесь мож
    но увидеть, обнаруживаются ли узлы сети и когда (рис. 7.8).
