Работа с отчетами в Zabbix     267

z  Number of users (online) (Количество пользователей (в сети)) — первое значение
   показывает общее количество пользователей, второе — количество пользовате
   лей, вошедших в веб-интерфейс Zabbix.
z  Required server performance, new values per second (Требуемое быстродействие сер
   вера, новые значения в секунду) — возможно, вы познакомитесь с совершенно
  новым понятием: новые значения в секунду (new values per second, NVPS). Сер
   вер получает или запрашивает значения через элементы данных и записывает
   их в базу данных Zabbix. Информация, представленная здесь, показывает при
   мерное количество NVPS, полученных сервером Zabbix.

В зависимости от настроек вы можете увидеть в этой таблице еще два значения.

z  Database name (Имя базы данных) — если вы видите имя вашей базы данных
   со значением версии, это может означать, что вы используете неподдержи
  ваемую версию базы данных. Вы можете увидеть сообщение типа Warning!
   Unsupported <DATABASE NAME> database server version. Should be at least
   <DATABASE VERSION>. (Внимание! Неподдерживаемая версия сервера базы
   данных <НАЗВАНИЕ БАЗЫ ДАННЫХ>. Должна быть не менее <ВЕРСИЯ
  БАЗЫ ДАННЫХ>.)
z  High availability cluster (Отказоустойчивый кластер) — если вы используете отказо
   устойчивый кластер Zabbix, то в данном пункте увидите, включен ли он и како
   ва задержка переключения при отказе. Кроме того, на странице ReportsSystem
    information (ОтчетыИнформация о системе) будет отображаться дополнитель
   ная информация о высокой доступности.

Отчет о доступности
Выбрав раздел ReportsAvailability report (ОтчетыОтчет о доступности), можно
получить полезную информацию о том, как долго триггер находился в состоянии
Problem по сравнению с состоянием ОК за определенный период времени (рис. 6.69).
