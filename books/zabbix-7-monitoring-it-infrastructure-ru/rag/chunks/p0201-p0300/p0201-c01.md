Настройка тегов на уровне шаблона     201

Настройка тегов на уровне шаблона
Далее мы займемся настройкой тегов на уровне шаблона. Они используются для
того, чтобы у каждого события (проблемы), созданного на узле сети этим шабло
ном, был определенный тег. Затем он используется для фильтрации событий в та
ких местах, как информационные панели, действия, и в разделе MonitoringProblems
(МониторингПроблемы).

Подготовка
Чтобы приступить к выполнению этого задания, нам понадобятся сервер Zabbix
и шаблон из предыдущего раздела.

Порядок действий
Создание тегов на уровне шаблона — способ сделать так, чтобы только события,
созданные определенным шаблоном, получили определенный тег.

1. Выберите раздел Data collectionTemplates (Сбор данныхШаблоны) и щелкните
   на нашем шаблоне, который называется Custom Linux by SNMP.
2. Затем перейдите на вкладку Tags (Теги) в верхней части формы (рис. 5.5).

                       Рис. 5.5. Вкладка Tags (Теги) шаблона SNMP

   Теперь первое, что мы можем сделать, — это создать несколько тегов, чтобы
   убедиться, что все события из этого шаблона будут связаны с Linux.
3. Первый тег уже готов к созданию. Введите в поле Name (Имя) слово class. Затем
   в поле Value (Значение) введите os.
4. Чтобы добавить второй тег, нажмите кнопку Add (Добавить) и задайте для вто
   рого тега имя target. Затем в поле Value (Значение) введите linux. Это будет
   выглядеть так, как показано на рис. 5.6.
