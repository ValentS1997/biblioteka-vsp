266     Глава 6   •  Визуализация данных, инвентаризация и отчетность

        Рис. 6.68. Раздел ReportsSystem information (ОтчетыИнформация о системе)

Возможно, вы уже видели эту таблицу раньше, поскольку ее также можно настро
ить как виджет информационной панели. Эта страница предоставляет нам всю
необходимую информацию о нашем сервере Zabbix.

z  Zabbix server is running (Zabbix server запущен) — запущен ли backend Zabbix server
  и где. В данном случае он запущен и работает на localhost:10051.
z  Zabbix server version (Версия Zabbix server) — версия демона Zabbix server, уста
   новленного на нашем экземпляре.
z  Zabbix frontend version (Версия Zabbix frontend) — версия Zabbix frontend, работа
  ющего в данный момент на нашем веб-сервере.
z  Software update last checked (Время последней проверки программного обес
   печения) — сведения о том, когда Zabbix в последний раз проверял наличие
   новой доступной версии.
z  Latest release (Последний выпуск) — показывает последнюю доступную версию.
z Number of hosts (Количество узлов сети) — количество активированных (16)
  и деактивированных узлов сети (5).
z  Number of templates (Количество шаблонов) — количество шаблонов, доступных
   в данный момент в этой системе Zabbix.
z Number of items (Количество элементов данных) — подробная информация об
   элементах нашего сервера Zabbix: в данном случае активированных (565), де
   активированных (241) и неподдерживаемых (217).
z  Number of triggers (Количество триггеров) — количество имеющихся триггеров. Мы
   видим, сколько из них активированных (373) и деактивированных (38), а также
   сколько из них находятся в состоянии Problem (12) и сколько — в состоянии ОК (361).
