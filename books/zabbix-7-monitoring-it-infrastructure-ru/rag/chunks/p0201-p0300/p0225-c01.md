Вложенные шаблоны Zabbix     225

Вложенные шаблоны Zabbix
Использование простого шаблона для каждого устройства или группы устройств
в большинстве случаев — лучший способ создания шаблонов Zabbix, но не един
ственный. Мы можем использовать вложенные шаблоны, чтобы разделить их на
части и собрать воедино в самом верхнем шаблоне иерархии.

В этом разделе мы расскажем, зачем это нужно и как это настроить.

Подготовка
Для работы понадобятся сервер Zabbix, хост, узел сети по SNMP и шаблон, создан
ный в предыдущем разделе.

Порядок действий
1. Начнем с того, что перейдем на страницу Data collectionTemplates (Сбор дан
  ныхШаблоны) и нажмем кнопку Create template (Создать шаблон) в правом
   верхнем углу.
2. Мы создадим новый шаблон для мониторинга времени работы нашего узла сети
   по SNMP. Введите информацию, как на рис. 5.43.

                          Рис. 5.43. Страница создания шаблона

3. Далее нажмите кнопку Add (Добавить) и выберите имя шаблона Custom Linux
   uptime by SNMP. После чего вы попадете на экран редактирования шаблона.
4. В правом верхнем углу щелкните на Items (Элементы данных), затем Create item
   (Создать элемент данных). Далее на вкладке Item (Элемент данных) создайте
   элемент данных, как показано на рис. 5.44.
