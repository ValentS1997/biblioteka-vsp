Создание элементов данных шаблона     205

3. Теперь, когда мы знаем, как получить имя хоста, добавим его в шаблон. Выбе
   рите раздел Data collectionTemplates (Сбор данныхШаблоны) и щелкните на
   шаблоне Custom Linux by SNMP.
4. Перейдите на страницу Items (Элементы данных). В правом верхнем углу вы
   берите Create item (Создать элемент данных), чтобы на вкладке Item (Элемент
   данных) создать следующий элемент данных (рис. 5.10).

                    Рис. 5.10. Элемент данных SysName на основе OID

5. Не забудьте добавить тег на уровне элемента данных. Теги важны для груп
   пировки и фильтрации элементов данных. Перейдите на вкладку Tags (Теги)
  и добавьте следующую информацию (рис. 5.11).

                  Рис. 5.11. Вкладка Tags (Теги) элемента данных SysName

   Теперь, когда у нас есть первый элемент данных, создадим узел сети и назначим
   ему этот шаблон.
6. Выберите раздел Data collectionHosts (Сбор данныхУзлы сети) и щелкните
   на Create host (Создать узел сети) в правом верхнем углу. Создайте узел сети
   с настройками, как на рис. 5.12.
7. Не забудьте добавить макросы новому узлу сети, прежде чем нажать кнопку
   Add (Добавить). Щелкните на вкладке Macros (Макрос) и внесите информацию,
   как показано на рис. 5.13.
