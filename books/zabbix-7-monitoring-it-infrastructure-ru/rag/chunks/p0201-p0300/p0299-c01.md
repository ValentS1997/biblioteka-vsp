Работа с сетевым обнаружением Zabbix SNMP      299

4. Далее мы создадим новое правило обнаружения SNMP с типом проверки
  SNMPv2 agent. Сначала заполните поля Name (Имя) и IP range (Диапазон IP)
   (рис. 7.10).

          Рис. 7.10. Раздел Data collectionDiscovery (Сбор данныхОбнаружение)

5. Убедитесь, что в поле IP range (Диапазон IP-адресов) указали свой диапазон
   IP-адресов.
6. Теперь создадим проверку SNMP. Нажмите кнопку Add (Добавить) рядом с пунк
   том Checks (Проверки), и увидите следующее всплывающее окно (рис. 7.11).

               Рис. 7.11. Всплывающее окно создания проверки обнаружения

7. Мы хотим, чтобы параметр Check type (Тип проверки) имел значение SNMPv2
   agent, и заполним его данными о нашем SNMP community и OID, который
   в данном случае будет идентификатором имени системы. Заполните поля так,
   как показано на рис. 7.12.

  ПРИМЕЧАНИЕ
   Обратите внимание, что тип проверки необходимо настраивать в зависимости от
   использумоей версии SNMP. У нас есть три версии SNMP и, соответственно, три
   разных типа проверки на выбор.
