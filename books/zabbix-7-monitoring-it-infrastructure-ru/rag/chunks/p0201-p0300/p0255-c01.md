Шаблонизация панелей на уровне узла сети      255

Подготовка
Убедитесь, что выполнили первые два примера этой главы и что ваш сервер Zabbix
готов. Мы переиспользуем узел сети из первых двух разделов, а также наши эле
менты данных, триггеры и карту сети.

Кроме того, вы можете создавать панели управления на уровне узла сети, если у вас
есть данные, доступные на узле сети, которому назначен шаблон.

Порядок действий
1. Выберите раздел Data collectionTemplates (Сбор данныхШаблоны) и отредак
   тируйте шаблон Custom Linux by SNMP, щелкнув на разделе Dashboards (Панели)
   рядом с ним.
2. Теперь в правом верхнем углу щелкните на Create dashboard (Создать панель).
  Это позволит создать панель на уровне узла сети внутри шаблона.
3. Мы назовем ее Host overview, поскольку она будет содержать различную ин
  формацию об узле сети (рис. 6.48).

                      Рис. 6.48. Создание панели на уровне узла сети

4. Не забудьте снять флажок Start slideshow automatically (Запускать слайд-шоу
   автоматически), если собираетесь использовать панель на персональных ком
   пьютерах, чтобы страницы оставались неподвижными во время устранения
   неполадок.
5. Нажмите Apply (Применить), чтобы добавить новую панель.
6. Теперь, когда панель создана, можно приступить к добавлению виджетов.
   Добавьте первый виджет, нажав + Add (+ Добавить) в правом верхнем углу.
7. Начнем с простого виджета Item value (Значение элемента данных). Добавьте
   информацию, как показано на рис. 6.49.
8. Обязательно примените изменения и добавьте виджет, нажав + Add (+ Добавить).
