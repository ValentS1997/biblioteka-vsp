214     Глава 5   •  Создание собственных шаблонов

В данном случае мы использовали {HOST.HOST}, которое уже содержал hostname
нашего узла сети (рис. 5.27).

            Рис. 5.27. Страница конфигурации узла сети lar-book-templated_snmp

Для каждого отдельного узла сети этот встроенный макрос будет своим, поскольку
значение hostname будет уникальным. Таким образом, наш триггер всегда будет
уникальным, хотя он и определен на уровне шаблона.

Помните, что встроенный макрос всегда начинается с фигурной скобки и закан
чивается фигурной скобкой. Имя макроса может содержать точки и символы под
черкивания. Вот несколько примеров:

z  {HOST.NAME}
z  {INVENTORY.LOCATION.LAT}

Дополнительная информация
Полный список встроенных макросов можно найти здесь: https://www.zabbix.com/
documentation/current/en/manual/appendix/macros/supported_by_location. Этот список по
стоянно обновляется, поэтому вы всегда сможете использовать данную страницу
в качестве справочника по актуальным (встроенным) макросам в Zabbix.

Использование низкоуровневого
обнаружения в шаблонах
Теперь приступим к нашей любимой части создания шаблонов: низкоуровневому
обнаружению (LLD). На наш взгляд, это один из самых мощных и наиболее широко
используемый функционал Zabbix.

Подготовка
Для работы понадобится сервер Zabbix и узел сети с подключенным SNMP-
мониторингом и шаблон из предыдущего раздела.
