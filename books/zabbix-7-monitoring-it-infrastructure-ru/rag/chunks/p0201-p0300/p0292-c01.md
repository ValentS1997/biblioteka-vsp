292     Глава 7   •  Использование службы Discovery в Zabbix

Настройка сетевого обнаружения
Zabbix agent
Многие администраторы Zabbix активно используют Zabbix agent и, как следствие,
тратят много времени на ручное создание новых узлов сети. Возможно, они не зна
ют, как настроить обнаружение Zabbix agent, или у них еще не было времени на его
настройку, а может быть, они просто любят настраивать вручную. В этом разделе
вы узнаете, насколько просто все настраивается.

Подготовка
Как вы уже знаете, помимо сервера Zabbix, для работы понадобятся два (пустых)
хоста с установленным Zabbix Agent 2: один хост Windows и один Linux. Если вы
не знаете, как установить Zabbix Agent 2, прочитайте главу 3 или документацию
Zabbix: https://www.zabbix.com/documentation/current/en/manual/concepts/agent2.

Теперь присвоим серверам следующие hostname:

z  lar-book-disc-lnx — для хоста Linux (используйте Zabbix Agent 2);
z  lar-book-disc-win — для хоста Windows (используйте Zabbix Agent 2).

Порядок действий
1. Подключитесь к хосту lar-book-disc-lnx и отредактируйте следующий файл:

   vim /etc/zabbix/zabbix_agent2.conf

2. Теперь убедитесь, что конфигурационный файл Zabbix Agent 2 содержит такую
   строку:

   Hostname=lar-book-disc-lnx

3. Для Windows-хоста необходимо сделать то же самое. Отредактируйте следу
  ющий файл:

   C:\Program Files\Zabbix Agent 2\zabbix_agent2.conf

4. Теперь измените hostname, отредактировав следующую строку:

   Hostname=lar-book-disc-win

5. Далее в веб-интерфейсе Zabbix выберите раздел Data collectionDiscovery (Сбор
  данныхОбнаружение) и на этой странице щелкните на Create discovery rule
   (Создать правило обнаружения), чтобы создать правило с настройками, как
   на рис. 7.1.
