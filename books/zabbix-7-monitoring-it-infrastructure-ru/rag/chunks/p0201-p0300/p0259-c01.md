Настройка инвентаризации в Zabbix     259

Настройка инвентаризации в Zabbix
Инвентаризация в Zabbix — полезная функция, но в последнее время она не поль
зовалась особой любовью команды разработчиков Zabbix, хотя и была добавлена
в дорожную карту версии 7.0.

В частности, речь об этом старом запросе на добавление функционала: https://sup
port.zabbix.com/browse/ZBXNEXT-336.

Функция инвентаризации позволяет автоматически помещать собранные данные
в визуальную базу данных управления конфигурацией (configuration management
database, CMDB). Думаю, все сталкивались с тем, что системы инвентаризации
CMDB зачастую содержат неактуальные данные, и вследствие этого мы не полу
чаем нужных данных. Инвентаризация в Zabbix исправляет эту ситуацию, получая
данные из контролируемых систем.

Подготовка
Нам понадобится доступ в веб-интерфейс Zabbix и узел сети с SNMP из преды
дущих разделов.

Порядок действий
1. Для начала убедимся, что сервер Zabbix помещает всю информацию об инвента
   ризации наших узлов сети в соответствующие поля. Это можно сделать, открыв
   раздел AdministrationGeneral (АдминистрированиеОбщие), а затем выбрав
   Other (Другое) из выпадающего списка.
2. Затем установите для параметра Default host inventory mode (Режим инвентариза
  ции узлов сети по умолчанию) значение Automatic (Автоматически). Не забудьте
   нажать кнопку Update (Обновить) (рис. 6.56).

    Рис. 6.56. Раздел AdministrationGeneralOther (АдминистрированиеОбщиеДругое)

3. В качестве альтернативы можно сделать это на уровне узла сети. Выберите
   раздел Data collectionHosts (Сбор данныхУзлы сети), а затем узел lar-book-
   templated_snmp.
