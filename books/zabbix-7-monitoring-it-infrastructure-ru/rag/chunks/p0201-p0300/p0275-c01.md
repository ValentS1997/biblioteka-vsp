Настройка улучшенного мониторинга услуг      275

Порядок действий
В нашем примере объектом мониторинга бизнес-услуг станет веб-интерфейс
Zabbix; для этого мы создадим новый узел сети lar-book-zabbix-frontend, к кото
рому добавим несколько элементов данных и триггеров.

Настройка элементов данных и триггеров
Если вы пробовали выполнить предыдущие примеры, то должны хорошо понимать,
как создавать элементы данных и триггеры. Пройдемся по ним еще раз и настроим
некоторые из них для использования в мониторинге бизнес-услуг.

1. Сначала создайте новый шаблон, войдя в веб-интерфейс Zabbix и выбрав раздел
   Data collectionTemplates (Сбор данныхШаблоны).
2. Нажмите синюю кнопку Create template (Создать шаблон) в правом верхнем углу
  и заполните страницу информацией, как на рис. 6.78.

                      Рис. 6.78. Страница создания нового шаблона

3. Обязательно сохраните новый шаблон, нажав синюю кнопку Add (Добавить).
4. Теперь настроим новый узел сети, выбрав раздел Data collectionHosts (Сбор
  данныхУзлы сети).
5. Нажмите синюю кнопку Create host (Создать узел сети) в правом верхнем углу
  и заполните страницу информацией, как показано на рис. 6.79.
