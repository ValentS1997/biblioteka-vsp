Создание карт сетей для визуализации инфраструктуры     239

 9. Когда вы нажмете синюю кнопку Add (Добавить), веб-
    интерфейс вернет вас на обзорную страницу Map (Кар
   ты сетей). Щелкните здесь на только что созданной
    карте сети Templated SNMP host map.
10. Щелкните на Edit map (Изменить карту сети) в правом
    верхнем углу, чтобы начать изменять карту.
11. Теперь нужно нажать кнопку Add (Добавить) рядом
    с Map element (Элемент карты сети), которая находится
    в горизонтальном меню в верхней части карты. В резуль
    тате добавится следующий элемент (рис. 6.16).
12. Щелкните на только что добавленном элементе карты   Рис. 6.16. Добавленный
    сети. Откроется следующий экран (рис. 6.17).               элемент карты сети

                    Рис. 6.17. Окно редактирования элемента карты сети

13. Здесь можно ввести информацию об узле сети. Добавьте данные, как показано
    на рис. 6.18.
   Нажмите кнопку Apply (Применить) и переместите элемент, задав положе
    ние X: 400 и Y: 100 (см. рис. 6.20 ниже).
14. Теперь добавьте еще один элемент карты сети, нажав кнопку Add (Добавить)
   рядом с Map element (Элемент карты сети). Отредактируйте новый элемент
   и добавьте информацию, как на рис. 6.19.
