Создание информационных панелей     247

 9. Затем нужно добавить первый Data set (Набор данных) (рис. 6.33).

                      Рис. 6.33. Добавление еще одного набора данных

10. Далее добавьте второй, нажав +Add new data set (+ Новый набор данных) и до
    бавив следующую информацию (рис. 6.34).

                        Рис. 6.34. Добавление другого набора данных

11. Затем можете нажать кнопку Add (Добавить), и график будет добавлен на па
    нель.
12. Теперь добавьте на страницу виджет Item value (Значение элемента данных).
   Снова нажмите + Add (+ Добавить). Затем установите следующий виджет
    (рис. 6.35).
   Если вы хотите изменить внешний вид виджета, то воспользуйтесь полями
    Advanced configuration (Расширенная настройка) на экране настройки виджета.
13. Еще один новый полезный виджет — Top Hosts (Топ узлов сети). Добавим его,
    снова воспользовавшись кнопкой + Add (+ Добавить).
14. На экране конфигурации виджета установите для Host groups (Группы узлов
    сети) значение Linux servers.
