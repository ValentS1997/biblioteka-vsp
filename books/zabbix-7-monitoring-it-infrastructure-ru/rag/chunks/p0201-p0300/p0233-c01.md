Создание графиков для визуализации данных      233

                         Рис. 6.5. График Incoming ICMP messages

Можно создавать графики для элементов, полученных в результате работы LLD; это
называется прототипом графика. Они работают примерно так же, как и прототипы
элементов данных. Попробуем создать один из них.

1. Выберите раздел Data collectionTemplates (Сбор данныхШаблоны), а затем
  шаблон Custom Linux by SNMP.
2. Перейдите в раздел Discovery rules (Правила обнаружения). Затем для правила
    Discover Network Interfaces (Обнаружение сетевых интерфейсов) щелкните на Item
    prototypes (Прототипы элементов данных). В правом верхнем углу щелкните на
    Create item prototype (Создать прототип элементов данных) и создайте следующий
   прототип элемента (рис. 6.6).
