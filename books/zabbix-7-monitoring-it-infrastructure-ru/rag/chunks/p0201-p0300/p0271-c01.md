Настройка регулярных отчетов в формате PDF     271

Порядок действий
Чтобы начать работу с регулярными отчетами Zabbix, нужно установить на сервер
Zabbix некоторые компоненты.

1. Войдите в CLI сервера Zabbix и выполните команду для установки браузера
   Google Chrome.
  В системах на базе RHEL:

   vim /etc/yum.repos.d/google-chrome.repo

   Затем добавьте в файл следующий код:

   [google-chrome]
   name=google-chrome
   baseurl=http://dl.google.com/linux/chrome/rpm/stable/$basearch
   enabled=1
   gpgcheck=1
   gpgkey=https://dl-ssl.google.com/linux/linux_signing_key.pub

   Наконец, установите Google Chrome:

   dnf install -y google-chrome-stable

  В системах Ubuntu выполните следующую команду:

   wget -q -O - https://dl-ssl.google.com/linux/linux_signing_key.pub |
   sudo apt-key add -
   sudo sh -c 'echo "deb http://dl.google.com/linux/chrome/deb/stable main" >>
   /etc/apt/sources.list.d/google.list'
   sudo apt update
   sudo apt-get install google-chrome-stable

2. Теперь нужно установить пакет Zabbix web service с помощью следующих команд.
  Для систем на базе RHEL:

   dnf install zabbix-web-service

  Для Ubuntu:

   apt install install zabbix-web-service

3. Теперь отредактируйте файл конфигурации Zabbix web service:

   vim /etc/zabbix/zabbix_web_service.conf

4. Здесь можно найти множество параметров, специфичных для Zabbix web service,
   включая шифрование. Убедитесь, что следующая строка настроена в соответ
   ствии с IP-адресом (-ами) вашего Zabbix server:

   AllowedIP=127.0.0.1,::1
