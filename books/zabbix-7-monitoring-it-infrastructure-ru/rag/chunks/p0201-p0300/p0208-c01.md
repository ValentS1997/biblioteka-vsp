208     Глава 5   •  Создание собственных шаблонов

Подготовка
Для этого примера понадобятся сервер Zabbix и узел сети из предыдущего раздела.

Порядок действий
На данный момент мы настроили один элемент данных в шаблоне, поэтому созда
дим триггер для этого элемента данных.

1. Откройте раздел Data collectionTemplates (Сбор данныхШаблоны) в интер
   фейсе Zabbix и щелкните на шаблоне Custom Linux by SNMP.
2. Теперь нажмите Triggers (Триггеры), а затем Create Trigger (Создать триггер)
   в правом верхнем углу. На вкладке Trigger (Триггер) введите следующую ин
  формацию (рис. 5.15).

                     Рис. 5.15. Создание триггера на уровне шаблона

3. Как уже говорилось в предыдущей главе, для триггеров существует тег scope,
   который необходимо добавить (рис. 5.16).

                          Рис. 5.16. Добавление тега в триггер
