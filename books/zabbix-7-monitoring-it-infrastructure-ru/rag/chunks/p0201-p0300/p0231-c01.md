Создание графиков для визуализации данных      231

3. Перейдите на вкладку Tags (Теги) и добавьте тег (рис. 6.2).

                            Рис. 6.2. Страница создания тега

4. Нажмите синюю кнопку Add (Добавить), чтобы сохранить этот элемент данных.
5. Теперь, вернувшись на страницу конфигурации шаблона, перейдите в раздел
   Graphs (Графики). Здесь вы можете увидеть все настроенные графики для этого
   шаблона; на данный момент их нет.
6. Щелкните на Create graph (Создать график) в правом верхнем углу. Вы перейдете
   на страницу создания графика (рис. 6.3).
   Здесь можно создавать графики для отдельных элементов данных. Мы создадим
   график, который будет показывать Uptime (Время бесперебойной работы).
