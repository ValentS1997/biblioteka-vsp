272     Глава 6   •  Визуализация данных, инвентаризация и отчетность

 5. Теперь отредактируйте файл конфигурации Zabbix server:

    vim /etc/zabbix/zabbix_server.conf

 6. Отредактируйте параметр WebServiceURL так, чтобы он соответствовал IP-адресу
    Zabbix web service, и StartReportWriters, чтобы убедиться, что у вас есть под
    процесс создания отчетов:

    WebServiceURL=https://localhost:10053/report
    StartReportWriters=3

   ПРИМЕЧАНИЕ
    Чтобы регулярные отчеты работали, необходимо настроить SSL-шифрование для
    веб-интерфейса Zabbix; мы рекомендуем использовать Let’s Encrypt. В качестве
    альтернативы установите параметр IgnoreURLCertErrors=1 в файле /etc/zabbix/
     zabbix_web_service.conf.

 7. Это все, что касается CLI. Теперь войдите в веб-интерфейс и перейдите
    в AdministrationGeneralOther (АдминистрированиеОбщиеДругое).
 8. Убедитесь, что заполнили параметр Frontend URL (URL веб-интерфейса) на этой
    странице (рис. 6.75).

     Рис. 6.75. Раздел AdministrationGeneralOther (АдминистрированиеОбщиеДругое)

 9. Нажмите синюю кнопку Update (Обновить) в нижней части страницы и выбери
    те раздел ReportsScheduled reports (ОтчетыРегулярные отчеты).
10. Теперь мы находимся на странице, где можно выполнять настройку регуляр
   ных отчетов. Итак, создадим новый отчет с помощью синей кнопки Create report
    (Создать отчет) в правом верхнем углу.
11. Мы попадем на новую страницу, где можно настроить новый отчет. Настро
   им еженедельный отчет, используя панель Global view. Сначала назовем этот
    отчет Weekly overview of the Global view dashboard.
12. Выберите панель Global view, нажав кнопку Select (Выбрать) рядом с Dashboard
    (Панель).
