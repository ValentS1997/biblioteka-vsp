204     Глава 5   •  Создание собственных шаблонов

                                Рис. 5.8. Ответ snmpwalk

   Теперь попробуем получить hostname узла сети из нашего шаблона с помощью
  SNMP. Нам, авторам книги, всегда нравится работать с числовым представлением
   идентификаторов объектов SNMP (Object Identifiers, OID). Для нашего имени
   хоста это .1.3.6.1.2.1.1.5.0.
2. Если у вас есть MIB (база управляющей информации — Management Information
   Base), то можно на основе OID получить символическое имя объекта. Введите
  следующую команду в CLI сервера Zabbix:

   snmptranslate .1.3.6.1.2.1.1.5.0

  Вы получите следующий ответ (рис. 5.9).

                              Рис. 5.9. Ответ snmptranslate

  СОВЕТ
   Использование параметра -On в команде SNMP гарантирует, что вы получите
   числовое представление в виде OID, а не символическое имя из MIB. Если нужно
   получить обратный результат, то можете убрать -On из нашей команды и исполь
   зовать snmptranslate для преобразования результата в формат OID.
