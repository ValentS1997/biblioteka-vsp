246     Глава 6   •  Визуализация данных, инвентаризация и отчетность

6. Нажмите кнопку Add (Добавить). Таким образом, мы получим первый виджет
   на нашей панели, отображающий проблемы в состоянии Unacknowledged problems
   (Подтверждение отменено). На всех серверах Linux они будут отображаться
   только для Severity (Степени серьезности) уровня Warning (Предупреждение)
  и выше (рис. 6.30).

                       Рис. 6.30. Виджет Unacknowledged problems

7. Сразу же добавим еще несколько виджетов, начиная с виджета Map (Карта).
  Нажмите + Add (+ Добавить) в правом верхнем углу и добавьте следующий
   виджет (рис. 6.31).

                         Рис. 6.31. Страница добавления виджета

8. Добавьте также виджет типа Graph (График), снова нажав + Add (+ Добавить) в пра
   вом верхнем углу. Этот вариант немного сложнее. Сначала добавьте имя (рис. 6.32).

                     Рис. 6.32. Окно создания нового графика-виджета
