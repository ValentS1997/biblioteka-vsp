224     Глава 5   •  Создание собственных шаблонов

Эти триггеры создаются так же, как и элементы, и затем заполняются нужными
элементами, на которые срабатывает триггер (рис. 5.42).

                Рис. 5.42. Триггер хоста, контролируемого SNMP, для ens192

Как можно заметить, в выражении триггера у нас уже указан SNMPINDEX, равный 2.
Теперь триггер будет срабатывать, когда Operational status равен 0, а Admin status равен 1.

Это удобный триггер, позволяющий убедиться, что проблема возникает только
в том случае, если Admin status — up. ifAdminStatus отображает виртуальный статус,
установленный администратором. Например, ifAdminStatus = down означает, что
администратор специально «выключил» данный интерфейс, хотя при этом сам
интерфейс может продолжать работать.

  СОВЕТ
   Можно использовать фильтры обнаружения, чтобы мониторить только те интер
   фейсы, у которых ifAdminStatus = up. Это позволяет снизить требуемую произво
   дительность сервера Zabbix и сохранить чистоту данных.

Читайте также
Обнаружение — обширная тема, и на ее освоение требуется время. Эту функцио
нальность можно использовать во множестве случаев. Начав работать с LLD, вы
будете создавать лучшие шаблоны, которые когда-либо видели.

Документацию по Zabbix LLD можно найти по этой ссылке: https://www.zabbix.com/
documentation/current/en/manual/discovery/low_level_discovery
