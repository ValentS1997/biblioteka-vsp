5. Теперь добавьте информацию о репозитории в файл и сохраните его:

   tee /etc/yum.repos.d/timescale_timescaledb.repo <<EOL
   [timescale_timescaledb]
   name=timescale_timescaledb
   baseurl=https://packagecloud.io/timescale/timescaledb/el/$(rpm-E
   %{rhel})/\$basearch
   repo_gpgcheck=1
   gpgcheck=0
   enabled=1
   gpgkey=https://packagecloud.io/timescale/timescaledb/gpgkey
   sslverify=1
   sslcacert=/etc/pki/tls/certs/ca-bundle.crt
   metadata_expire=300
   EOL

6. Установите TimescaleDB с помощью команды:

   dnf install timescaledb-2-postgresql-15

7. Теперь перейдите к той части данного раздела, в которой описывается на
   стройка TimescaleDB.

Настройка TimescaleDB
Пришло время настроить TimescaleDB.

1. Для начала выполните следующую команду:

   timescaledb-tune

2. Иногда она не работает, и необходимо указать местоположение PostgreSQL:

   timescaledb-tune --pg-config=/usr/pgsql-15/bin/pg_config

3. Пройдите все шаги и ответьте на вопросы yes или no соответственно. Для пер
   вичной настройки на все вопросы лучше отвечать yes.
4. Теперь перезапустите PostgreSQL:

   systemctl restart postgresql-15

5. Если вы еще не сделали этого, то скачайте и установите Zabbix с помощью
  следующих команд.
  Для RHEL:
   rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rhel/8/x86_64/zabbix-
   release-7.0-1.el8.noarch.rpm
   dnf clean all
   dnf install zabbix-server-pgsql zabbix-web-pgsql zabbix-apacheconfzabbix-agent2
