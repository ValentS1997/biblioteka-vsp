Настройка СУБД MySQL
1. Теперь посмотрим, как настроить СУБД MySQL. Для начала перейдите в брау
   зере по этой ссылке: https://github.com/major/MySQLTuner-perl.
2. Вы увидите проект с открытым исходным кодом на GitHub, начатый пользо
   вателем Major Hayden. Скачайте скрипт из репозитория GitHub или просто
   воспользуйтесь следующей командой:

   wget https://raw.githubusercontent.com/major/MySQLTuner-perl/master/
   mysqltuner.pl

3. Теперь можно выполнить этот скрипт:

   perl mysqltuner.pl

4. После запуска появится запрос на ввод учетных данных для подключения
   к MySQL. Заполните их и продолжите (рис. 11.17).

                       Рис. 11.17. Выполнение скрипта mysqltuner.pl

5. Во время своей работы скрипт выведет много информации, которую вам нужно
   будет внимательно прочитать, но самая важная часть находится в конце — все,
   что идет после Variables to adjust (рис. 11.18).
