Обновление Zabbix     453

 2. Теперь добавьте новый репозиторий для Zabbix 7.0 с помощью следующих
    команд:

    wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/
    zabbix-release_7.0-1+ubuntu22.04_all.deb
    dpkg -i zabbix-release_7.0-1+ubuntu22.04_all.deb

   ПРИМЕЧАНИЕ
    Всегда проверяйте zabbix.com/download, чтобы получить нужный репозиторий
    для вашей системы. В этом примере был использован репозиторий для Ubuntu.
    Поменяйте его на нужный репозиторий для вашей системы.

 3. Обновите информацию о доступных пакетах, используя следующую команду:

    apt update

 4. Теперь обновите компоненты Zabbix:

    apt install --only-upgrade zabbix-server-mysql zabbix-frontend-
    php zabbix-agent2

 5. Следите за тем, чтобы не перезаписать файл конфигурации Zabbix server. Если
   вы все же сделали это, то файл можно восстановить из резервной копии, соз
    данной в разделе «Резервное копирование Zabbix».
 6. Затем установите установите дополнительный пакет для работы с NGINX:

    apt install zabbix-nginx-conf

 7. Перезапустите Zabbix с помощью этой команды, и все будет готово:

    systemctl restart zabbix-server nginx zabbix-agent2

 8. Проверьте журналы, используя следующую команду:

    tail -f /var/log/zabbix/zabbix_server.log

 9. Проверьте файл журнала на наличие ошибок, и если вы их обнаружили, то ис
    правьте, прежде чем продолжить.
10. После исправления ошибок необходимо перезапустить Zabbix server:

    systemctl restart zabbix-server

11. Процесс обновления должен завершиться. Если вы откроете веб-интерфейс, то
    увидите новый интерфейс Zabbix 7 (рис. 11.8).
