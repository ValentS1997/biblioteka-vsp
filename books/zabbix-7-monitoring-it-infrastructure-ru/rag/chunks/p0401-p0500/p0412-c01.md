Расширение
        функциональности10         Zabbix с помощью
        пользовательских
        скриптов и API

Zabbix предлагает широкий функционал «из коробки». Однако основное досто
инство Zabbix заключается в его способности позволять пользователю комби
нировать различные доступные методы для настройки системы, такие как веб-
интерфейс, скрипты и API.

В этой главе вы узнаете об основах использования API Zabbix. Затем вы увидите,
как скрипт на Python может применять API для создания jumphost. После этого вы
будете использовать скрипты, написанные Брайаном ван Бэкелем, для управления
отображением узлов сети на карте сети.

После выполнения всех инструкций из этой главы вы будете полностью готовы
к работе с API в Zabbix и поймете, как использовать скрипты для расширения
функциональности.

В этой главе:

z настройка API-токенов и управление ими;
z использование API для расширения функциональности;
z создание jumphost с помощью API Zabbix и Python;
z активация и деактивация узла сети из интерфейса карты сетей.

Технические требования
Для этой главы понадобятся сервер Zabbix, несколько новых узлов сети с Linux
и общие знания о скриптах и программировании. Мы будем использовать Python-
скрипты для расширения функционала Zabbix.

Код, представленный в главе, можно найти по адресу https://github.com/PacktPublishing/
Zabbix-7-IT-Infrastructure-Monitoring-Cookbook/tree/main/chapter10.
