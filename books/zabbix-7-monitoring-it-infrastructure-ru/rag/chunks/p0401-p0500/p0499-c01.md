Настройка мониторинга Microsoft Azure     499

Подготовка
Для работы понадобится облако Azure, в котором уже есть хотя бы один из следу
ющих ресурсов:

z Cosmos DB for MongoDB databases;
z  Microsoft SQL databases;
z серверы MySQL;
z серверы PostgreSQL;
z виртуальные машины.

В этом разделе не рассказывается о том, как настроить все эти ресурсы, поэтому
позаботьтесь об этом заранее. Кроме того, понадобится сервер Zabbix, который
в этом примере будет называться lar-book-rocky.

Порядок действий
Мониторинг Azure можно выполнять с помощью тех же методов, которые исполь
зовались для мониторинга AWS. Процесс настройки может выглядеть сложным,
но на самом деле это не так.

1. Для мониторинга Azure сначала нужно правильно настроить аутентификацию.
   Перейдите на сайт portal.azure.com и войдите в систему.
2. В строке поиска найдите Enterprise applications (Корпоративное приложение) и вы
   берите его из списка. Нажмите кнопку + New application (+ Новое приложение)
   (рис. 13.17).

               Рис. 13.17. Раздел создания корпоративных приложений Azure

3. Затем нажмите кнопку Create your own application (Создать собственное приложе
   ние) (рис. 13.18).

                      Рис. 13.18. Создание собственного приложения
