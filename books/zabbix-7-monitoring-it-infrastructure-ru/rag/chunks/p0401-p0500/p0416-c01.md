416     Глава 10   •  Расширение функциональности Zabbix

12. Далее нужно создать API-токен для этого пользователя. Выберите раздел
    UsersAPI tokens (ПользователиAPI-токены).
13. Нажмите синюю кнопку Create API token (Создать API-токен) в правом верхнем
    углу и в поле Name (Имя) введите API book key, а в поле User (Пользователь) вы
    берите пользователя API. Установите значение Expires (Истекает в) на далекое
    будущее или полностью отключите этот параметр. Страница будет выглядеть
   следующим образом (рис. 10.6).

                          Рис. 10.6. Страница создания API-токена

14. Нажмите синюю кнопку Add (Добавить) в нижней части страницы, что
   бы сгенерировать новый API-токен. Вы попадете на следующую страницу
    (рис. 10.7).

               Рис. 10.7. Страница создания API-токена пользователя Zabbix API
