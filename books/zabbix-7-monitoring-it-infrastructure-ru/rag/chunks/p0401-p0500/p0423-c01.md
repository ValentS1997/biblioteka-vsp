Создание jumphost с помощью API Zabbix и Python     423

Однажды Ядвиру Сингху пришла потрясающая идея — создать скрипт на Python
для экспорта всех узлов сети из Zabbix с их IP-адресами в файл /etc/hosts. Давайте
посмотрим, как мы можем создать jumphost точно так же.

Подготовка
Нам понадобится новый Linux-хост lar-book-jump, а также сервер Zabbix, для
которого будем использовать lar-book-centos.

  ПРИМЕЧАНИЕ
   Каждый раз при выполнении этого скрипта будет перезаписываться ваш файл
    /etc/hosts. Используйте этот скрипт, только если понимаете, что он делает.
   Убедитесь, что для этого примера используете пустой сервер и /etc/hosts не мо
   дифицирован.

Порядок действий
1. Если вы еще не создали пользователя с API-токеном, то обязательно ознакомь
   тесь с первым разделом этой главы.
2. Установите Python 3 с помощью следующей команды.

  Для систем на базе RHEL:

   dnf install python3

  Для Ubuntu:

   apt-get install python3

3. Кроме того, с этим пакетом должен быть установлен пакет pip — система управ
   ления пакетами Python. Если это не так, то выполните следующую команду.

  Для RHEL:

   dnf install python3-pip

  Для Ubuntu:

   apt-get install python3-pip

4. Теперь установим зависимости с помощью pip. Они необходимы для запуска
   нашего скрипта:

   pip3 install requests
