Резервное копирование Zabbix     439

4. Кроме того, важно сохранить резервные копии PHP-файлов. Это можно сделать
   с помощью следующих команд:

   cp -r /usr/share/zabbix/ /opt/zbx-backup/shared/zabbix/
   cp -r /usr/share/doc/zabbix-* /opt/zbx-backup/shared/doc/

5. Наконец, не забудьте создать резервную копию файлов Zabbix, находящихся
   в каталоге /usr/lib:

   cp -r /usr/lib/zabbix/ /opt/zbx-backup/lib/

6. Опционально вы можете создать задачу в cron для резервного копирования этих
   файлов с последующим автоматическим сжатием каждый день в 00:00. Просто
   выполните следующую команду:

   crontab -e

7. И добавьте следующую информацию:

   0 0 * * * tar -zcvf /opt/zbx-backup/zbx-config/zabbix.tar.gz /
   etc/zabbix/ >/dev/null 2>&1
   0 0 * * * tar -zcvf /opt/zbx-backup/web-config/zabbix-web.tar.gz
   /etc/nginx/ >/dev/null 2>&1
   0 0 * * * tar -zcvf /opt/zbx-backup/shared/zabbix/zabbix_usr_share.tar.gz /
   usr/share/zabbix/ >/dev/null 2>&1
   0 0 * * * tar -zcvf /opt/zbx-backup/shared/doc/zabbix_usr_share_doc.tar.gz
   /usr/share/doc/ >/dev/null 2>&1
   0 0 * * * tar -zcvf /opt/zbx-backup/lib /zabbix_usr_lib.tar.gz /usr/lib/
   zabbix/ >/dev/null 2>&1

8. Это были самые важные файлы из нашего Zabbix-стека, которые необходимо
   сохранить. Мы также можем воспользоваться инструментом ротации файлов,
   таким как logrotate, чтобы эффективно хранить наши резервные копии. Перей
   дем к базе данных.
9. Создать резервную копию базы данных довольно просто. Для этого достаточно
   воспользоваться встроенными инструментами MySQL и PostgreSQL. Выполни
   те следующую команду для соответствующей базы данных (не забудьте ввести
   правильное имя пользователя, имя базы данных и пароль).
  Для баз данных MySQL (где -u — имя пользователя, -p — пароль, а имя базы
   данных — zabbixdb):

   mysqldump --add-drop-table --add-locks --extended-insert
   --single-transaction --quick -u zabbixuser -p zabbixdb > /opt/zbx-backup/
   database/backup_zabbixDB_<DATE>.sql

  Для баз данных PostgreSQL:

   pg_dump zabbixdb > /opt/zbx-backup/database/backup_zabbixDB_<DATE>.bak
