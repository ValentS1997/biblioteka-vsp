444     Глава 11   •  Поддержка и обслуживание Zabbix

10. Убедитесь, что ваша система обновлена, выполнив следующую команду:

    dnf update

11. REMI зависит от репозитория EPEL, поэтому сначала придется добавить его:

    dnf install epel-release

12. После установки epel-release убедитесь, что исключили из него Zabbix. Это
    гарантирует, что Zabbix будет скачиваться и обновляться только из официаль
   ных репозиториев Zabbix:

    [epel]
    excludepkgs=zabbix*

13. Затем нужно установить репозиторий REMI с помощью следующей команды:

    sudo dnf -y install http://rpms.remirepo.net/enterprise/remirelease-8.rpm

14. Сбросьте конфигурацию PHP и установите PHP версии 8.3 из репозитория REMI:

    dnf module reset php -y
    dnf module install php:remi-8.3

15. Во время установки везде вводите Y или Yes.
16. Затем проверьте, успешно ли прошло обновление:

    php-fpm -v

17. Обязательно перезапустите NGINX (или Apache) и php-fpm:

    systemctl restart nginx php-fpm

 Эти шаги были протестированы в системе Rocky Linux RHEL, но должны работать
 с любой системой на основе RHEL8, будь то Stream или Alma Linux.

 Рассмотрите возможность перехода на операционные системы, основанные на
 RHEL9, для поддержки новых версий PHP.

 Операционные системы на основе Ubuntu
 Обновите PHP до последней версии, доступной в вашей операционной системе
 Ubuntu.

 1. Для начала добавьте сторонний PPA-репозиторий с помощью следующей
    команды:

    apt install software-properties-common add-apt-repository ppa:ondrej/php

 2. Теперь обновите информацию о доступных пакетах:

    apt update
