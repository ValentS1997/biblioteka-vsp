438     Глава 11   •  Поддержка и обслуживание Zabbix

Резервное копирование Zabbix
Перед выполнением любых действий с Zabbix крайне важно создать резервные ко
пии всех важных данных. В этом разделе мы рассмотрим ключевые шаги, которые
необходимо предпринять перед обслуживанием сервера Zabbix.

Подготовка
Для работы понадобится сервер Zabbix, в нашем случае это lar-book-rocky. Все
команды данного раздела будут выполняться в CLI.

Порядок действий
1. Войдите на сервер Zabbix и создайте несколько новых каталогов, которые будут
   использоваться для резервного копирования. Желательно, чтобы эти каталоги
   находились в другом разделе:

   mkdir /opt/zbx-backup/
   mkdir /opt/zbx-backup/database/
   mkdir /opt/zbx-backup/zbx-config/
   mkdir /opt/zbx-backup/nginx/
   mkdir /opt/zbx-backup/lib/
   mkdir /opt/zbx-backup/shared/
   mkdir /opt/zbx-backup/shared/zabbix/
   mkdir /opt/zbx-backup/shared/doc/

2. Необходимо выполнить резервное копирование всех конфигурационных фай
   лов Zabbix, хранящихся в каталоге /etc/zabbix/. Мы можем вручную перенести
   данные из каталога /etc/zabbix/ в новый каталог для резервного копирования
   с помощью следующей команды:

   cp -r /etc/zabbix/ /opt/zbx-backup/zbx-config/

3. Теперь сделайте то же самое для конфигурации nginx:

   cp -r /etc/nginx/ /opt/zbx-backup/nginx/

  ПРИМЕЧАНИЕ
   Обратите внимание: если вы используете Apache, то местоположение файлов
   конфигурации может быть другим. Скорректируйте команду соответствующим
   образом. Для систем на базе Red Hat это обычно /etc/httpd/, а для систем на базе
   Debian — /etc/apache2/.
