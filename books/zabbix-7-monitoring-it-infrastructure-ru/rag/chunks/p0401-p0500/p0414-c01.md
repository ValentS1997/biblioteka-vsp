      Рис. 10.2. Настройка разрешений на доступ к шаблонам для группы пользователей

6. Нажмите синюю кнопку Select (Выбрать) в нижней части этого всплывающего
   окна и выберите Read-write (Чтение-запись), а затем щелкните на ссылке Add (До
   бавить). Теперь все должно выглядеть так, как показано на рис. 10.3.

      Рис. 10.3. Настройка разрешений на доступ к узлам сети для группы пользователей

  СОВЕТ
   Вместо создания API-пользователя с правами суперадминистратора мы можем
   настроить ограничения, задавая доступ только к определенным группам узлов
   сети и шаблонов в группе пользователей API Users. Это может быть более предпо
   чтительным в продуктивной среде, где важно ограничить доступ к API. Выбирайте
   вариант, который лучше всего соответствует вашим требованиям.
