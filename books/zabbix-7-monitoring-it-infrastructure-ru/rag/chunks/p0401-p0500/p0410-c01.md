                         Рис. 9.76. Оповещение в Opsgenie от Zabbix
 Объяснение
 Когда в Zabbix создается оповещение, оно отправляется в Opsgenie с помощью
 интеграции. Она использует API Opsgenie для получения информации из Zabbix и,
 при необходимости, отправки ответа. Таким образом обеспечивается двустороннее
 взаимодействие между приложениями (рис. 9.77).

                               Рис. 9.77. Настройка Opsgenie

 Opsgenie — удивительный инструмент, который может снять несколько задач
 с вашего сервера Zabbix. Opsgenie позволяет централизовать управление уведом
 лениями (рис. 9.78).
