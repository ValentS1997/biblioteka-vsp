Настройка API-токенов и управление ими     415

 7. Нажмите синюю кнопку Add (Добавить) в нижней части страницы, чтобы до
    бавить эту новую группу пользователей.
 8. Теперь выберите раздел UsersUsers (ПользователиПользователи) и нажмите
   синюю кнопку Create user (Создать пользователя) в правом верхнем углу.
 9. Создайте нового пользователя с именем API следующим образом (рис. 10.4).

                      Рис. 10.4. Страница создания нового пользователя

10. Перед добавлением пользователя переключитесь на вкладку Permissions (Права
    доступа) и добавьте роль Super admin (Суперадминистратор) (рис. 10.5).

                  Рис. 10.5. Страница настройки прав доступа пользователя

11. Теперь мы можем добавить пользователя, нажав синюю кнопку Add (Добавить)
    в нижней части страницы.
