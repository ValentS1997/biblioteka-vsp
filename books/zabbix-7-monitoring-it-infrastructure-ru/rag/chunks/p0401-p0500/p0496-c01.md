496     Глава 13   •  Мониторинг облачной инфраструктуры

18. И наконец, нажмите кнопку Create access key (Создать ключ доступа) и сохраните
   ключ доступа и секретный ключ доступа в безопасном месте (например, в хра
   нилище паролей). После этого нажмите кнопку Done (Готово) (рис. 13.10).

                         Рис. 13.10. Сгенерированный ключ доступа

19. Теперь займемся настройкой Zabbix. Войдите в веб-интерфейс Zabbix и выбе
    рите раздел Data collectionHosts (Сбор данныхУзлы сети).
20. Создайте новый хост, нажав кнопку Create host (Создать узел сети) в правом
    верхнем углу. Мы создадим новый узел сети lar-book-aws и добавим шаблон
   AWS by HTTP. Также добавьте этот узел сети в группу узлов сети Cloud (Облако)
    (рис. 13.11).

                          Рис. 13.11. Новый узел сети lar-book-aws

21. Перед добавлением узла сети обязательно перейдите на вкладку Macros (Макро
    сы). Нужно заполнить несколько макросов, необходимых для работы шаблона.
    Обязательно укажите ключ, который вы сохранили в шаге 19 (рис. 13.12). Не за
    будьте указать AWS region, в котором располагаются ваши инстансы.

   ПРИМЕЧАНИЕ
    В нашем случае все используемые ресурсы AWS находятся в одном и том же регио
    не AWS. Зачастую это не так. В таких случаях вы можете создать отдельный узел
    сети для каждого региона, чтобы иметь возможность обнаруживать все ресурсы
    конкретного региона. Для этого достаточно определить макрос {$AWS.REGION}
    для каждого узла сети.
