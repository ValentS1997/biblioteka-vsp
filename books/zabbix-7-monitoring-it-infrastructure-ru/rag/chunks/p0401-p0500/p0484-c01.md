484     Глава 12   •  Продвинутая настройка СУБД

    Рис. 12.14. Запрос дополнительных данных в процессе генерации серверного сертификата

25. Сделайте то же самое для сервера lar-book-secure-db:

    openssl req -nodes -new \
    -keyout /etc/pki/CA/private/mysqlsrv_key.pem \
    -out /etc/pki/CA/unsigned/mysql-srv_req.pem
    -newkey rsa:2048

    Ответ будет выглядеть так, как показано на рис. 12.15.

    Рис. 12.15. Запрос дополнительных данных в процессе генерации серверного сертификата

   ПРИМЕЧАНИЕ
    Сертификаты должны быть созданы без пароля; в противном случае приложения
    MariaDB и Zabbix не смогут их использовать. Обязательно указывайте опцию -nodes.

26. Теперь подпишите сертификат для сервера lar-book-secure-zbx с помощью
   следующей команды:

    openssl ca -policy policy_anything -days 365 \
    -out /etc/pki/CA/certs/zbx-srv_crt.pem \
    -infiles /etc/pki/CA/unsigned/zbx-srv_req.pem

27. Вам будет предложено ответить на вопрос Sign the certificate? [y/n]. На этот
   и все последующие вопросы ответьте Y.
28. Теперь сделайте то же самое для серверного сертификата lar-book-secure-db:

    openssl ca -policy policy_anything -days 365 \
    -out /etc/pki/CA/certs/mysql-srv_crt.pem \
    -infiles /etc/pki/CA/unsigned/mysqlsrv_req.pem
