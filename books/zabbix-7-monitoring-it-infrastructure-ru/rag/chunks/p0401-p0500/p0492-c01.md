492     Глава 13   •  Мониторинг облачной инфраструктуры

5. Создайте отдельного пользователя для Zabbix, нажав кнопку Add users (До
   бавить пользователей) и внеся следующую информацию (рис. 13.2).

                           Рис. 13.2. Новый пользователь AWS

6. Дважды нажмите кнопку Next (Далее).
7. Теперь нажмите кнопку Create (Создать), чтобы завершить настройку этого
   пользователя.
8. Выберите пользователя из списка, чтобы отредактировать его (рис. 13.3).

                      Рис. 13.3. Редактирование пользователя Zabbix

9. В списке вы видите, что для этого пользователя еще нет назначенных политик,
   поэтому создайте новую пользовательскую политику безопасности специально
   для Zabbix.
