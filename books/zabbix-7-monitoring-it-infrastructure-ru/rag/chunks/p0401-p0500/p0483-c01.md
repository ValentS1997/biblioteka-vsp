Защита базы данных Zabbix     483

            Рис. 12.12. Запрос пароля в процессе генерации корневого сертификата

19. Кроме того, вам может быть предложено ввести дополнительную информацию
    о вашей компании. По умолчанию будет использовано значение, которое вы
    ввели ранее, поэтому вы можете просто нажать Enter, пока не появится Common
    Name.
20. Введите Root CA в поле Common Name и добавьте свой адрес электронной почты
    (рис. 12.13).

    Рис. 12.13. Запрос информации о компании в процессе генерации корневого сертификата

21. Теперь займемся созданием серверных сертификатов, которые будет использо
    вать сервер Zabbix. Сначала убедитесь, что в OpenSSL есть файлы для хранения
   информации о выданных сертификатах:

    touch /etc/pki/CA/index.txt
    echo 01 > /etc/pki/CA/serial

22. Затем создайте папки, в которых будут храниться сертификаты:

    mkdir /etc/pki/CA/unsigned
    mkdir /etc/pki/CA/newcerts
    mkdir /etc/pki/CA/certs

23. Теперь создайте CSR (Certificate Signing Request — запрос на выпуск сертифи
    ката) для lar-book-secure-zbx с помощью следующей команды:

    openssl req -nodes -new -keyout /etc/pki/CA/private/zbx-srv_key.pem -out /
    etc/pki/CA/unsigned/zbx-srv_req.pem -newkey rsa:2048

24. Вам снова будет предложено добавить пароль и информацию о вашей компа
    нии. Используйте значения по умолчанию вплоть до Common Name. В Common Name
    укажите hostname сервера и добавьте адрес электронной почты, как показано на
    рис. 12.14.
