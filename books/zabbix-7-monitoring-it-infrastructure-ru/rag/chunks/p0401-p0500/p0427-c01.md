Активация и деактивация узла сети из интерфейса карты сетей     427

При правильной настройке jumphosts могут быть очень полезны, однако важно со
держать их в порядке, чтобы облегчить процесс обновления, что достаточно легко
организовать с помощью скрипта из этого раздела.

Если вы выполнили пример из предыдущего раздела «Использование API для
расширения функциональности», то можете заметить, что он работает примерно
так же (рис. 10.17).

                   Рис. 10.17. Работа jumphost с использованием скрипта

После внесения изменений наш скрипт запустится с первого шага диаграммы,
чтобы получить данные через вызов API, для чего используется API-токен для
аутентификации. На втором шаге мы получаем запрашиваемые данные. Затем
в скрипте добавляются значения по умолчанию и все имена узлов сети вместе с IP-
адресами записываются в файл /etc/hosts.

Поскольку хост Linux использует файл /etc/hosts для сопоставления имен хо
стов с IP-адресами, мы можем использовать реальные имена серверов из Zabbix
подключения по SSH. Это упрощает использование jumphost, так как мы можем
использовать то же имя, что и имя узла сети из интерфейса Zabbix.
