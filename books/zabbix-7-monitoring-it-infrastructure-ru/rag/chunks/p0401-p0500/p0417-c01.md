 Объяснение
 Теперь, когда Zabbix оснащен встроенной системой управления API-токенами,
 взаимодействовать с его API стало значительно проще. Мы можем использовать
 определенного API-пользователя для централизованного управления всеми то
 кенами или же создавать личные API-токены для каждой учетной записи поль
 зователя.

 В данном случае мы создали новую группу пользователей — API Users. Это важно,
 поскольку API-токены все еще являются частью учетной записи пользователя,
 то есть будут работать в рамках его прав доступа. Если мы создадим пользователя
 с любым другим типом пользователя, отличным от Super admin (Суперадминистра
 тор), то сможем ограничить доступ к API, используя группу API Users.

 Убедитесь, что вы назначаете пользователю соответствующую роль и устанавли
 ваете разрешения для группы пользователей в соответствии с вашими предпо
 чтениями и требованиями вашей рабочей среды. Рекомендуем также установить
 адекватную дату истечения срока действия для ваших API-токенов, чтобы перио
 дически их обновлять.

 Теперь давайте перейдем к применению полученных знаний на практике.
