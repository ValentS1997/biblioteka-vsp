Защита базы данных Zabbix     479

Объяснение
Добавление TimescaleDB в ваш Zabbix будет отличным решением при использо
вании базы данных PostgreSQL.

Итак, принцип работы TimescaleDB заключается в разделении гипертаблицы
PostgreSQL на фрагменты (чанки), разделенные по времени (рис. 12.10).

                     Рис. 12.10. Схема хранения данных в TimescaleDB

Эти фрагменты содержат данные в пределах одного интервала времени, и, как след
ствие, можно удалить весь фрагмент целиком без проведения дополнительных
проверок. При этом Zabbix housekeeper просматривает данные в базе данных строка
за строкой, чтобы проверить временную метку UNIX, а затем удаляет строку, если
возраст ее данных превышает указанный срок. Это требует времени и ресурсов.

У TimescaleDB есть еще одно преимущество: можно использовать привычный
веб-интерфейс для указания глобальных настроек хранения истории элементов
данных и трендов. Кроме того, TimescaleDB может сжимать данные, чтобы умень
шить размер базы данных.

Недостатком является то, что мы не можем указать разные сроки хранения истории
и трендов для разных элементов данных.
