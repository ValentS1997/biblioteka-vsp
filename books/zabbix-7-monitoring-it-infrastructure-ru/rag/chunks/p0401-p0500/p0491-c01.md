Настройка мониторинга AWS     491

Настройка мониторинга AWS
В наши дни большая часть инфраструктуры переезжает в облако, поэтому внима
тельно следите за этой инфраструктурой, как если бы это было ваше собственное
оборудование. В этом руководстве мы разберем, как контролировать экземпляры
EC2, базы данных в Relational Database Service (RDS) и хранилища S3 с помощью
Zabbix.

Подготовка
Для этого примера понадобится облако AWS с уже настроенными ресурсами:

z экземплярами EC2;
z экземплярами RDS;
z S3-хранилищем.

И конечно, будет нужен сервер Zabbix, который в этом примере будет называться
lar-book-rocky.

  ПРИМЕЧАНИЕ
   Использование Amazon CloudWatch — платная услуга. Прежде чем приступить
   к работе, обязательно ознакомьтесь с ценами Amazon для AWS CloudWatch: https://
   aws.amazon.com/cloudwatch/pricing/.

Порядок действий
Рассмотрим один из способов настройки мониторин
га AWS.

1. Войдите в свою учетную запись AWS, перейдя по
   следующему URL в браузере: https://aws.amazon.com/.
2. На этой странице нажмите кнопку Sign In to the Console.
3. После входа в систему выберите пункт меню My
    Security Credentials (Мои учетные данные), который
   должен располагаться в вашем профиле пользова
   теля в правом верхнем углу (рис. 13.1).
4. На следующей странице, с левой стороны, щелкните
   на Users (Пользователи) в разделе Access management       Рис. 13.1. Профиль
   (Управление доступом).                                    пользователя AWS
