480     Глава 12   •  Продвинутая настройка СУБД

в сети. Шифрование защищает от атак типа MITM (Man-in-the-Middle, «человек
посередине») и других, которые могут быть использованы для перехвата данных.

В этом разделе мы настроим шифрование передаваемых данных между MySQL
и компонентами Zabbix, чтобы добавить еще один уровень безопасности.

Подготовка
Для работы понадобится Zabbix, использующий внешнюю базу данных. В этом
разделе будут использоваться два Linux-хоста: lar-book-secure-db и lar-book-
secure-zbx.

Удостоверьтесь, что на хосте lar-book-secure-db установлен только Zabbix, а на
хосте lar-book-secure-db уже установлена MariaDB и что вы используете по
следнюю поддерживаемую версию, способную использовать шифрование. Если
вы не знаете, как обновить базу данных, то ознакомьтесь с разделом «Обновление
СУДБ MariaDB» в главе 11 или посмотрите документацию в Интернете.

Порядок действий
1. Убедитесь, что файлы на обоих хостах, указанных в подразделе «Подготовка»,
   содержат hostname и IP-адрес для ваших Linux-хостов, либо отредактируйте
  файл следующим образом:

   vim /etc/hosts

2. Заполните файл именами хостов и IP-адресами:

   10.16.16.170 lar-book-secure-db
   10.16.16.171 lar-book-secure-zbx

3. Создайте базу данных Zabbix на хосте lar-book-secure-db, если вы еще этого
   не сделали. Для этого подключитесь к MySQL:

   mysql -u root -p

4. Затем создайте базу данных Zabbix:

   create database zabbix character set utf8mb4 collate utf8mb4_ bin;

5. Не забудьте создать пользователя, который сможет безопасно подключаться
   к базе данных. Убедитесь, что IP-адрес совпадает с IP-адресом сервера Zabbix
   (и с IP-адресом веб-интерфейса Zabbix, если он установлен отдельно):

   create user 'zabbix'@'10.16.16.171' identified BY 'password';
   grant all privileges on zabbix.* to 'zabbix'@'10.16.16.171';
   flush privileges;
