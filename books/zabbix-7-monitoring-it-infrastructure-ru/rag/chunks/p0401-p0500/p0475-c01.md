Использование TimescaleDB     475

Операционные системы на основе Ubuntu
1. Войдите в CLI и добавьте репозиторий PostgreSQL с помощью следующих
   команд:

   apt install gnupg postgresql-common apt-transport-https
   lsb-release wget
   /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh

2. Теперь добавьте репозиторий TimescaleDB:

   echo "deb https://packagecloud.io/timescale/timescaledb/ubuntu/$(lsb_
   release -c -s) main" | sudo tee /etc/apt/sources.list.d/timescaledb.list
   wget --quiet -O - https://packagecloud.io/timescale/timescaledb/gpgkey |
   sudo apt-key add -
   apt update

3. Установите TimescaleDB с помощью команды:

   apt install timescaledb-2-postgresql-15

4. Запустите и включите PostgreSQL 12:

   systemctl enable postgresql
   systemctl start postgresql

5. Теперь перейдите к той части данного раздела, в которой описывается на
   стройка TimescaleDB.

Операционные системы на основе RHEL
1. Войдите в CLI. Вам понадобится PostgreSQL версии 11 или выше. Установите
   PostgreSQL 15, но сначала отключите AppStream:

   dnf -qy module disable postgresql

2. Добавьте нужный репозиторий:

   dnf install https://download.postgresql.org/pub/repos/yum/reporpms/
   EL-8-x86_64/pgdg-redhat-repo-latest.noarch.rpm

3. Затем установите PostgreSQL:

   dnf install postgresql15 postgresql15-server

4. Обязательно инициализируйте базу данных:

   /usr/pgsql-15/bin/postgresql-15-setup initdb
