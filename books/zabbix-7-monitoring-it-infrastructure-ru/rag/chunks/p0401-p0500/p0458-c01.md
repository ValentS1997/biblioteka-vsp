458     Глава 11   •  Поддержка и обслуживание Zabbix

                     Рис. 11.14. Проблема в работе Zabbix housekeeper

3. Отредактируйте следующий файл:

   vim /etc/zabbix/zabbix_server.conf

4. Найдите в конфигурационном файле параметр HousekeepingFrequency (рис. 11.15).

        Рис. 11.15. Файл конфигурации Zabbix server, параметр HousekeepingFrequency

5. Это первый параметр, который мы изменим. Отредактируйте данный параметр,
   добавив под этим блоком следующую строку:

   HousekeepingFrequency=2

  ПРИМЕЧАНИЕ
   Увеличение интервала не решит вашу проблему; в лучшем случае вы отсрочите
   неизбежное. Рекомендуется изменять этот параметр только в крайнем случае,
   чтобы дождаться следующего окна для проведения обслуживания Zabbix.

6. Найдите еще один параметр в конфигурационном файле (рис. 11.16).

7. На рис. 11.16 показан второй параметр для настройки Zabbix housekeeper. От
   редактируем его, добавив под этим блоком кода следующую строку:

   MaxHousekeeperDelete=20000
