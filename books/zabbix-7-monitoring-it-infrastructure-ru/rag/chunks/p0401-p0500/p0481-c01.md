Защита базы данных Zabbix     481

 6. Выйдите из MySQL, а затем запустите скрипт настройки базовых параметров
    безопасности MySQL, используя следующую команду:

    mariadb_secure_installation

 7. Войдите в lar-book-secure-zbx и установите репозиторий Zabbix с помощью
    этой команды:

    rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rhel/9/x86_64/zabbix-
    release-7.0-1.el8.noarch.rpm
    dnf clean all

 8. Добавьте репозиторий MariaDB на сервер:

    wget https://downloads.mariadb.com/MariaDB/mariadb_repo_setup
    chmod +x mariadb_repo_setup
    ./mariadb_repo_setup

 9. Затем установите Zabbix и все необходимые компоненты с помощью следующей
    команды.
   Для RHEL:
    dnf install zabbix-server-mysql zabbix-web-mysql zabbix-apacheconfzabbix-
    agent2 zabbix-sql-scripts mariadb-client

   Для Ubuntu:

    apt install zabbix-server-mysql zabbix-frontend-php zabbixapache-conf
    zabbix-agent2 mariadb-client

10. Подключитесь с сервера Zabbix к удаленному серверу базы данных и импорти
    руйте схему базы данных Zabbix вместе с данными по умолчанию с помощью
   следующей команды:

    zcat /usr/share/doc/zabbix-sql-scripts/mysql/server.sql.gz | mysql -h
    10.16.16.170 -uzabbix -p zabbix

11. Теперь откройте файл openssl.cnf и отредактируйте его, выполнив следующую
    команду:

    vim /etc/pki/tls/openssl.cnf

12. В этом файле нужно отредактировать следующие строки:

    countryName_default = XX
    stateOrProvinceName_default = Default Province
    localityName_default = Default City
    0.organizationName_default = Default Company Ltd
    organizationalUnitName_default.=

13. Полностью заполненный файл будет выглядеть так, как показано на рис. 12.11.
