440     Глава 11   •  Поддержка и обслуживание Zabbix

10. Обязательно укажите правильное местоположение, так как дамп базы данных
   может быть довольно большим в зависимости от размера вашей базы данных.
   Лучше всего хранить дамп на другом диске или разделе, а еще лучше — на от
    дельной машине. Поэтому размещение его в /opt/ может быть не самым удачным
    решением.
11. То же самое можно сделать с помощью cron, выполнив следующую команду:

    crontab -e

12. Затем для MySQL добавьте следующую строку:

    55 22 * * 0 mysqldump -u'zabbixuser' -p'password' zabbixdb > /opt/
    zbx-backup/database/backup_zabbixDB.sql

13. Аналогичная процедура для PostgreSQL требует дополнительной подготовки.
    Сперва нужно создать файл в домашнем каталоге пользователя:

    vim ~/.pgpass

14. Добавьте в этот файл следующий код, где zabbixuser — имя пользователя,
    а zabbixdb — имя базы данных:

    #hostname:port:database:username:password
    localhost:5432:zabbixdb:zabbixuser:password

15. Затем можете добавить задачу в cron:

    55 22 * * 0 pg_dump --no-password -U zabbixuser zabbixdb > /opt/zbx-backup/
    database/backup_zabbixDB_date.bak

16. Кроме того, можно сохранять резервные копии только за определенное коли
    чество дней. Выполните следующую команду:

    crontab -e

17. Затем добавьте следующую строку, где +60 — это количество дней, в течение
    которых вы хотите хранить резервные копии:

    55 22 * * 0 find /opt/zbx-backup/database/ -mtime +60 -type f
    -delete

   ПРИМЕЧАНИЕ
    Для резервного копирования баз данных можно использовать сторонние ин
    струменты. Например, для MySQL можно воспользоваться ExtraBackup, а для
     Postgres — PGBarman. Но не забывайте, что встроенные инструменты могут быть
    не менее эффективными.
