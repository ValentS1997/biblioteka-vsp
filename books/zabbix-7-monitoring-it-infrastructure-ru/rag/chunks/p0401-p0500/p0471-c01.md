Настройка партиционирования в MySQL      471

           Рис. 12.5. Пользовательские параметры скрипта партиционирования MySQL

   СОВЕТ
    Если вы используете Zabbix версии до 2.2, или MySQL до 5.6, или MySQL 8, то в скрипте
    есть несколько дополнительных строк конфигурации, которые необходимо заком
    ментировать и раскомментировать. Если это ваш случай, то прочитайте комментарии
    в файле скрипта mysql_zbx_part.pl и отредактируйте его. Кроме того, ознакомьтесь
     с репозиторием GitHub, упомянутым во введении выше.

28. Перед выполнением скрипта нужно установить необходимые зависимости
     Perl. В системах на основе RHEL понадобятся дополнительные репозитории.
   Выполните следующую команду.
   Для RHEL8:
    dnf config-manager --set-enabled powertools

   Для RHEL9:
    dnf config-manager --enable crb

29. Установите зависимости с помощью следующих команд.
   Для RHEL:
    dnf update
    dnf install perl-Sys-Syslog
    dnf install perl-DateTime
    dnf install perl-DBD-mysql
    dnf install perl-DBI

   Для Ubuntu:
    apt install liblogger-syslog-perl
    apt install libdatetime-perl

30. Сделайте скрипт исполняемым с помощью следующей команды:

    chmod +x /usr/lib/zabbix/mysql_zbx_part.pl
