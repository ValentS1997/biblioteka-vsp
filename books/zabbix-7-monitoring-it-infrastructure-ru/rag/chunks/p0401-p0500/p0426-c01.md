426     Глава 10   •  Расширение функциональности Zabbix

   Вы увидите содержимое файла, подобное тому, что показано на рис. 10.16.

                    Рис. 10.16. Файл /etc/hosts после выполнения скрипта

15. Теперь мы можем попробовать подключиться по SSH по имени узла сети, вме
    сто того чтобы использовать IP-адрес, выполнив следующую команду:

    ssh lar-book-agent_passive

16. Его также можно использовать и для поиска хостов:

    cat /etc/hosts | grep agent

17. Теперь сделаем еще одну вещь. Этот файл должен оставаться как можно более
    актуальным. Поэтому добавьте задачу cron, выполнив следующую команду:

    crontab -e

18. Затем добавьте следующую строку, обязательно указав правильное расположе
    ние скрипта в вашей системе:

    */15 * * * * $(which python3) /home/host_pull_zabbix.py >> ~/cron.log 2>&1

 Готово! Теперь у вас всегда будет актуальный файл /etc/hosts, который обновля
 ется новым Python-скриптом, извлекающим данные из Zabbix.

 Объяснение
 Теперь у вас есть навыки и знания, позволяющие создать постоянно обновляемый
 и простой в использовании jumphost. Они пригодятся вам, если ваша организация
 использует Zabbix в качестве основной системы мониторинга.
