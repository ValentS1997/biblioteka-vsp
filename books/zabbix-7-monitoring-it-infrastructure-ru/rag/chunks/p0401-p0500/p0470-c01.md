470     Глава 12   •  Продвинутая настройка СУБД

            Рис. 12.4. Подтверждение успешного партиционирования таблицы trends

18. Сделайте то же самое для таблицы trends_uint.
19. На этом партиционирование базы данных завершено. Нужно убедиться, что
    партиции остаются управляемыми. Для этого на хосте с базой данных Zabbix
    скачайте скрипт разметки с помощью следующей команды:

    wget https://raw.githubusercontent.com/OpensourceICTSolutions/
    zabbix-mysql-partitioning-perl/main/mysql_zbx_part.pl

20. Если вы не можете использовать wget, то просто скачайте скрипт по этой ссыл
     ке: https://github.com/OpensourceICTSolutions/zabbix-mysql-partitioning-perl/blob/main/
     mysql_zbx_part.pl.
   Или по этой: https://github.com/PacktPublishing/Zabbix-7-IT-Infrastructure-Monitoring-
     Cookbook/tree/main/chapter12/mysql_zbx_part.pl.
21. Теперь создайте каталог и переместите скрипт в папку /usr/lib/zabbix/ с помощью
   следующей команды:

    mkdir /usr/lib/zabbix/
    mv mysql_zbx_part.pl /usr/lib/zabbix/

22. Теперь необходимо изменить некоторые параметры скрипта. Для этого выпол
    ните команду:

    vim /usr/lib/zabbix/mysql_zbx_part.pl

   Нужно отредактировать текст в следующей части (рис. 12.5).

23. Отредактируйте элемент $db_schema так, чтобы он соответствовал имени вашей
    базы данных Zabbix.
24. Отредактируйте элемент $db_user_name так, чтобы он соответствовал имени
    пользователя базы данных Zabbix.
25. Отредактируйте элемент $db_password так, чтобы он соответствовал паролю
   вашей базы данных Zabbix.
26. Теперь в переменной $tables добавим несколько самых важных деталей:
    сколько дней истории хотим сохранить и сколько месяцев трендов. Добавьте
    свои значения; по умолчанию сохраняется 30 дней истории и 12 месяцев трен
    дов.
27. Не забудьте отредактировать строку my $curr_tz = Etc/UTC;, чтобы она соответ
    ствовала вашему часовому поясу.
