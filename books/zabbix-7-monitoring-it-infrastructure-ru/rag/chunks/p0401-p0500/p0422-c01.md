422     Глава 10   •  Расширение функциональности Zabbix

Последняя функция, generate_host_file, записывает имя узла сети вместе с IP-
адресом интерфейса в файл /home/results. Таким образом мы получили простой
и надежный скрипт для записи информации обо всех узлах сети в файл.

Если вы не знакомы с Python или программированием в целом, то работа с API
может оказаться для вас непростой задачей. Давайте посмотрим, как на самом
деле работает API (рис. 10.12).

                     Рис. 10.12. Схема взаимодействия скриптов с API

На шаге 1 мы совершаем вызов API, используя URL сервера Zabbix и API-токен,
указанный в переменных для аутентификации. Далее, на шаге 2, мы получаем от
Zabbix данные, запрошенные в функции Python, для дальнейшего использования
в скрипте.

Шаг 3 — этап обработки данных. С данными, полученными от API, можно делать
что угодно, однако в данном случае мы отформатируем их и сохраним в файл.
Таким образом мы используем API для расширения доступной функциональ
ности. На данном этапе файл заполняется именами узлов сети и информацией об
IP-адресах.

Создание jumphost с помощью API Zabbix и Python
Многие организации используют jumphost (иногда его называют бастионом) для
организации доступа к серверам, коммутаторам и другому оборудованию. Обычно
для jumphost настроены специальные правила в брандмауэре, необходимые для
доступа ко всем важным компонентам. Поскольку мы должны стремиться поддер
живать мониторинг в актуальном состоянии, он должен наблюдать все доступные
узлы сети.
