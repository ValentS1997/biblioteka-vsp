Интеграция Atlassian Opsgenie и Zabbix     405

 8. Щелкните на интеграции Zabbix. Вы перейдете на следующую страницу, где
    будут сгенерированы значения Name (Имя) и API Key (Ключ API) (рис. 9.66).

                    Рис. 9.66. Страница реквизитов для доступа к Opsgenie

 9. Скопируйте API Key (Ключ API) и прокрутите страницу в самый низ. Здесь на
   жмите синюю кнопку Save integration (Сохранить интеграцию).
10. Теперь перейдите в CLI вашего сервера Zabbix и выполните следующий код.

   Для систем на базе RHEL:

    wget https://github.com/opsgenie/oec-scripts/releases/download/
    Zabbix-1.1.6_oec-1.1.3/opsgenie-zabbix-1.1.6.x86_64.rpm

   Для Ubuntu:

    wget https://github.com/opsgenie/oec-scripts/releases/download/
    Zabbix-1.1.6_oec-1.1.3/opsgenie-zabbix_1.1.6_amd64.deb

11. Теперь вы можете установить скачанный плагин Zabbix Opsgenie, выполнив
   следующую команду.

   Для RHEL:

    rpm -i opsgenie-zabbix-1.1.6.x86_64.rpm

   Для Ubuntu:

    dpkg -i opsgenie-zabbix_1.1.6_amd64.deb

12. После установки плагина перейдите в веб-интерфейс Zabbix. Если вы не выпол
   няли предыдущие примеры, то создайте новую группу пользователей, выбрав
