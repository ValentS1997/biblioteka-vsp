488     Глава 12   •  Продвинутая настройка СУБД

Настройка сертификатов и различных параметров может быть достаточно сложной
задачей. Поэтому рекомендуем подробно разобраться в методах шифрования перед
самостоятельной настройкой. Если проект требует использовать шифрование, то
данное руководство послужит отличной отправной точкой для настройки. Этот
способ особенно эффективен для использования во внутренних средах благодаря
применению частных сертификатов.

  ПРИМЕЧАНИЕ
   Не забудьте обновить свои SSL-сертификаты, поскольку они действительны только
   в течение определенного срока. В нашем случае это 365 дней, поэтому мы будем
   обновлять их каждый год. Кроме того, неплохо отслеживать дату истечения срока
   действия сертификата и создавать для этого оповещения в Zabbix.

Все компоненты Zabbix, за исключением Zabbix server и веб-интерфейса, могут
использовать шифрование для передачи данных между собой (рис. 12.18).

           Рис. 12.18. Схема поддерживаемого шифрования передаваемых данных

Мы настроили шифрование данных между следующими компонентами:

z Zabbix server и MariaDB;
z веб-интерфейс Zabbix и MariaDB.

Это означает, что, когда Zabbix server или веб-интерфейс запрашивает или записы
вает данные в базу, они передаются в зашифрованном виде. Это может быть важно,
поскольку Zabbix работает на одном сервере, а база данных — на другом. Например,
может использоваться следующая схема (рис. 12.19).
