486     Глава 12   •  Продвинутая настройка СУБД

38. Теперь на сервере lar-book-secure-zbx Zabbix создайте новую папку для сер
    тификатов:

    mkdir -p /var/lib/zabbix/ssl/

39. Скопируйте сертификаты в эту папку, используя следующие команды:

    cp /etc/pki/CA/cacert.pem /var/lib/zabbix/ssl/
    cp /etc/pki/CA/certs/zbx-srv_crt.pem/var/lib/zabbix/ssl/zbx-srv.crt
    cp /etc/pki/CA/private/zbx-srv_key.pem/var/lib/zabbix/ssl/zbx-srv.key

40. Отредактируйте файл конфигурации Zabbix server, чтобы использовать эти
    сертификаты:

    vim /etc/zabbix/zabbix_server.conf

41. Убедитесь, что следующие строки соответствуют настройкам сервера базы
   данных lar-book-secure-db:

    DBHost=lar-book-secure-db
    DBName=zabbix
    DBUser=zabbix
    DBPassword=password

42. Теперь убедитесь, что конфигурация, связанная с SSL, соответствует новым
    файлам:

    DBTLSConnect=verify_full
    DBTLSCAFile=/var/lib/zabbix/ssl/cacert.pem
    DBTLSCertFile=/var/lib/zabbix/ssl/zbx-srv.crt
    DBTLSKeyFile=/var/lib/zabbix/ssl/zbx-srv.key

43. Не забудьте добавить нужные права доступа к файлам, связанным с SSL:

    chown -R zabbix:zabbix /var/lib/zabbix/ssl/
    chmod 400 /var/lib/zabbix/ssl/zbx-srv.key
    chmod 444 /var/lib/zabbix/ssl/zbx-srv.crt
    chmod 444 /var/lib/zabbix/ssl/cacert.pem

44. Запустите и включите Zabbix с помощью следующих команд.
   Системы на базе RHEL:

    systemctl restart zabbix-server zabbix-agent2 httpd php-fpm
    systemctl enable zabbix-server zabbix-agent2 httpd php-fpm

   Системы Ubuntu:

    systemctl restart zabbix-server zabbix-agent2 apache2 php-fpm
    systemctl enable zabbix-server zabbix-agent2 apache2 php-fpm
