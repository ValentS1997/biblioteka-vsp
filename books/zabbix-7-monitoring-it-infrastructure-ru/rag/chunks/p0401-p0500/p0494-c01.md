494     Глава 13   •  Мониторинг облачной инфраструктуры

   СОВЕТ
    Пожалуйста, ознакомьтесь со страницей интеграций Zabbix, чтобы узнать о по
    следних требуемых разрешениях для шаблона AWS, который вы будете исполь
     зовать. Разным шаблонам нужны разные разрешения, и новые разрешения могут
    быть добавлены позже для включения новых функций на стороне AWS: https://
    www.zabbix.com/integrations/aws.

12. Теперь вы можете нажать кнопку Next (Далее) и присвоить имя своей политике
    безопасности (рис. 13.6).

                   Рис. 13.6. Указание имени новой политики безопасности

13. Затем нажмите кнопку Create policy (Создать политику) в нижней части страницы.
   С разрешениями разобрались, теперь убедимся, что мы сможем аутентифици
    роваться с помощью этой учетной записи пользователя.
14. Находясь на той же странице после создания новой политики безопасности,
    прокрутите вниз до раздела Access keys (access key ID and secret access key) (Ключи
    доступа (идентификатор ключа доступа и секретный ключ доступа)) для этого
    нового пользователя. В результате вы увидите следующее (рис. 13.7).
