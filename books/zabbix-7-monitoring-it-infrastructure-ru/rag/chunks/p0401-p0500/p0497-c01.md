                         Рис. 13.13. Обнаруженные экземпляры EC2

 Объяснение
 Теперь, когда мы завершили настройку интеграции, давайте посмотрим, что мы
 на самом деле сделали. Zabbix 7.0 содержит готовые шаблоны облачного мони
 торинга, которые мы использовали для мониторинга некоторых наиболее рас
 пространенных ресурсов AWS.

 Шаблоны, предоставляемые в Zabbix, используют довольно много JavaScript-кода
 для выполнения вызовов API к AWS, с последующим разбором полученных дан
 ных и преобразованием в JSON, который можно передать в Zabbix для обработки
 с помощью LLD.

 Если открыть страницу Discovery (Обнаруже
 ние) шаблона AWS by HTTP, то вы увидите три
 правила обнаружения (рис. 13.14).

 Эти три правила находят экземпляры EC2,
 экземпляры RDS и S3-хранилища в AWS
 и с помощью host prototypes (прототипы
 узлов сети) создают новый хост для каждо
 го найденного экземпляра или хранилища.      Рис. 13.14. Правила обнаружения
