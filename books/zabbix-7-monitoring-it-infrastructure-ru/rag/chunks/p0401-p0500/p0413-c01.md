Настройка API-токенов и управление ими     413

Настройка API-токенов и управление ими
Начнем главу с базовой настройки API в Zabbix. Если вы ранее имели дело с API
Zabbix, то знаете, что процесс аутентификации с помощью API-вызовов и получение
API-токена для использования в скриптах могут быть довольно сложными. Однако
теперь эта проблема решена, так как мы можем создавать API-токены непосред
ственно в веб-интерфейсе Zabbix.

Подготовка
Для этого примера понадобится только сервер Zabbix. Мы будем использовать
веб-интерфейс для генерации API-токена. Полученный токен можно будет ис
пользовать в любой из интеграций.

Порядок действий
1. Войдите в веб-интерфейс Zabbix под пользователем Super admin (Суперадми
   нистратор).
2. Выберите раздел UsersUser groups (ПользователиГруппы пользователей)
  и нажмите синюю кнопку Create user group (Создать группу пользователей)
   в правом верхнем углу.
3. Введите в поле Group name (Имя группы) значение API Users.
4. Переключитесь на вкладку Host permissions (Права доступа к узлам сети) и предо
   ставьте вашей группе пользователей права на каждый узел сети, нажав кнопку
    Select (Выбрать) и выбрав каждую группу узлов сети (рис. 10.1).
