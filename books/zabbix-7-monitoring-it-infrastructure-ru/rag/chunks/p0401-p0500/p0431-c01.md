 Объяснение
 Скрипт, который мы только что использовали, был написан на Python с исполь
 зованием API Zabbix. С помощью этого скрипта мы можем активировать и деак
 тивировать мониторинг узла сети из веб-интерфейса Zabbix при работе в качестве
 пользователя с ролью уровня User.

 Это возможно благодаря тому, что страница Maps (Карты сетей) раздела Monitoring
 (Мониторинг) доступна даже для пользователей с низкими правами доступа. Тем
 не менее этот скрипт выполняется от имени другого пользователя с повышен
 ными привилегиями. У него больше прав, поэтому он может запустить скрипт,
 который получает информацию об узле сети из базы данных Zabbix и на основе
 этой информации создает период обслуживания. На рис. 10.22 видно, что скрипт
 работает примерно так же, как и остальные, ранее рассмотренные.
