Дополнительная информация
Чтобы настроить мониторинг с помощью AWS CloudWatch, требуется время
и хорошее понимание AWS CLI для взаимодействия с CloudWatch. Используя
готовые шаблоны от Zabbix в качестве отправной точки, вы получаете надежную
основу для последующего развития.

Обязательно ознакомьтесь с документацией AWS, чтобы получить дополнительную
информацию о командах, которые можно использовать: https://docs.aws.amazon.com/
cli/latest/reference/#available-services.

Настройка мониторинга Microsoft Azure
Облако Microsoft Azure — крупный игрок на нынешнем рынке облачных вычис
лений, и контролировать эту инфраструктуру так же важно, как и собственное
оборудование. В этом разделе вы узнаете, как отслеживать экземпляры Azure
с помощью Zabbix.
