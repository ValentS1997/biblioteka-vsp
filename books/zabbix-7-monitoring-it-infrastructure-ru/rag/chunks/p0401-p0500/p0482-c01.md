482     Глава 12   •  Продвинутая настройка СУБД

                          Рис. 12.11. Файл конфигурации OpenSSL

14. Вы также можете увидеть эту строку:

    dir = /etc/pki/CA     # Where everything is kept

15. Она означает, что по умолчанию используется каталог /etc/pki/CA; если вы ра
    ботаете с другим каталогом, то поправьте значение на верное. Закройте файл,
    сохранив его, и продолжите работу.
16. Создайте новый каталог для частных сертификатов (private certificates) с по
   мощью следующей команды:

    mkdir -p /etc/pki/CA/private

17. Теперь создайте новую пару ключей и корневой сертификат. Выполните следу
   ющую команду:

    openssl req -new -x509 \
    -keyout /etc/pki/CA/private/cakey.pem \
    -out /etc/pki/CA/cacert.pem -days 3650 \
    -newkey rsa:4096

18. Вам будет предложено ввести пароль (рис. 12.12).
