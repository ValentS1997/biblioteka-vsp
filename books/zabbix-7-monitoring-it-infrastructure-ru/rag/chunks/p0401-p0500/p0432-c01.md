432     Глава 10   •  Расширение функциональности Zabbix

Дополнительная информация
В Zabbix 7 появилась возможность передавать данные из веб-интерфейса в ваши
скрипты. Чтобы попробовать это в действии, мы можем немного изменить скрипт.

1. Выберите раздел AlertsScripts (ОповещенияСкрипты) и отредактируйте
   крипт Host/Enable и Host/Disable.
2. В поле Commands (Команды) замените {HOST.HOST} на {MANUALINPUT}, чтобы этот
   скрипт принимал динамический ввод.
3. Затем откройте вкладку Advanced configuration (Расширенная настройка) и за
   полните поля Input prompt (Подсказка ввода), Default input string (Строка ввода по
   умолчанию) и Input validation rule (Правило проверки введенных данных). Теперь
   все должно выглядеть так, как показано на рис. 10.23.

                    Рис. 10.23. Настройка ввода данных пользователем

4. Теперь, когда вы запустите скрипт, он попросит ввести данные. Введите имя
   узла сети — и он будет активирован или деактивирован (рис. 10.24).
