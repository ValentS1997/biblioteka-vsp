Обновление Zabbix     451

Кроме того, не забудьте сделать резервные копии и прочитать примечания к новой
версии, которую вы устанавливаете. Об этом было сказано в разделе «Резервное
копирование Zabbix».

Порядок действий
1. Войдите в CLI вашего Linux-хоста и проверьте версии программного обеспече
   ния, используя следующие команды.
  Для Zabbix server:

   zabbix_server --version

  Для PHP:

   php-fpm --version

  Для MariaDB:

   mariadb --version

2. Убедившись, что версии соответствуют указанным в подразделе «Подготовка»,
   переходите к обновлению Zabbix.
Операционные системы на основе RHEL
1. Остановите Zabbix server и Zabbix agent с помощью следующей команды:

   systemctl stop zabbix-server zabbix-agent2

2. После добавьте новый репозиторий Zabbix 7.0:

   rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rhel/8/x86_64/zabbix-
   release-7.0-1.el8noarch.rpm

3. Выполните следующую команду для очистки кэша:

   dnf clean all

4. Теперь обновите Zabbix с помощью следующей команды:

   dnf upgrade zabbix-server-mysql zabbix-web-mysql zabbix-agent2

5. Кроме того, установите дополнительный пакет для работы с NGINX:

   dnf install zabbix-nginx-conf

6. Перезапустите Zabbix:

   systemctl restart zabbix-server zabbix-agent2

7. Для проверки работоспособности сервера выполните следующую команду:

   systemctl status zabbix-server
