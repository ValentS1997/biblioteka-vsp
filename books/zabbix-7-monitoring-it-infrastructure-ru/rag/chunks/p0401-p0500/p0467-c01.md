Настройка партиционирования в MySQL      467

4. Подключитесь к MySQL как root-пользователь:

   mysql -u root -p

  ПРИМЕЧАНИЕ
   Необязательно запускать партиционирование в окне tmux, но в этом есть опре
   деленный смысл. Процесс разделения большой базы данных на отдельные части
   (партиции) может занять много времени. Вы можете перенести базу данных на
   другой сервер, имеющий достаточно ресурсов (процессор, память и скорость диска)
   для выполнения разделения. Если это не представляется возможным, остановите
   Zabbix server на время проведения партиционирования.

5. Выберите базу данных Zabbix с помощью этой команды:

   USE zabbix;

6. Нам нужно разделить некоторые таблицы, но для этого необходимо узнать
   временную метку UNIX для таблиц:

   SELECT FROM_UNIXTIME(MIN(clock)) FROM history;

  Вы получите примерно такой результат (рис. 12.1).

                    Рис. 12.1. Временная метка UNIX из таблицы history

7. Эта временная метка должна быть примерно одинаковой для всех таблиц, ко
   торые мы собираемся разделить. Проверьте это, выполнив тот же запрос для
   остальных таблиц history:

   SELECT FROM_UNIXTIME(MIN(clock)) FROM 'history';
   SELECT FROM_UNIXTIME(MIN(clock)) FROM 'history_uint';
   SELECT FROM_UNIXTIME(MIN(clock)) FROM 'history_str';
   SELECT FROM_UNIXTIME(MIN(clock)) FROM 'history_text';
   SELECT FROM_UNIXTIME(MIN(clock)) FROM 'history_log';
   SELECT FROM_UNIXTIME(MIN(clock)) FROM 'history_bin';
