Защита базы данных Zabbix     485

29. Войдите на сервер lar-book-secure-db MySQL и создайте каталог для хранения
    созданных сертификатов:

    mkdir /etc/my.cnf.d/certificates/

30. Установите нужные права доступа:

    chown -R mysql. /etc/my.cnf.d/certificates/

31. Теперь вернитесь на сервер lar-book-secure-zbx и скопируйте файлы на lar-
    book-secure-db с помощью следующих команд:

    scp /etc/pki/CA/private/mysql-srv_key.pem root@10.16.16.170:/etc/my.cnf.d/
    certificates/mysql-srv.key
    scp /etc/pki/CA/certs/mysql-srv_crt.pem root@10.16.16.170:/etc/my.cnf.d/
    certificates/mysql-srv.crt
    scp /etc/pki/CA/cacert.pem root@10.16.16.170:/etc/my.cnf.d/certificates/
    cacert.crt

32. Еще раз подключитесь к lar-book-secure-db и установите нужные права до
    ступа:

    chown -R mysql:mysql /etc/my.cnf.d/certificates/
    chmod 400 /etc/my.cnf.d/certificates/mysql-srv.key
    chmod 444 /etc/my.cnf.d/certificates/mysql-srv.crt
    chmod 444 /etc/my.cnf.d/certificates/cacert.crt

33. Отредактируйте файл конфигурации MariaDB с помощью следующей команды:

    vim /etc/my.cnf.d/server.cnf

34. Добавьте следующие строки в блок [mysqld]:

    bind-address=lar-book-secure-db
    ssl-ca=/etc/my.cnf.d/certificates/cacert.crt
    ssl-cert=/etc/my.cnf.d/certificates/mysql-srv.crt
    ssl-key=/etc/my.cnf.d/certificates/mysql-srv.key

35. Войдите в MySQL с помощью следующей команды:

    mysql -u root -p

36. Установите опцию обязательного использования SSL-шифрования для поль
    зователя zabbix, выполнив следующие команды:

    alter user 'zabbix'@'10.16.16.152' require ssl;
    flush privileges;

    Убедитесь, что IP-адрес совпадает с IP-адресом сервера Zabbix (и IP-адресом
    веб-интерфейса Zabbix, если они установлены раздельно), как вы делали в шаге 2.
37. Отключитесь от MariaDB, а затем перезапустите ее с помощью следующей
    команды:

    systemctl restart mariadb
