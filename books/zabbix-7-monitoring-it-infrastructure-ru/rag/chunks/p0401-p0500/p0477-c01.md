Использование TimescaleDB     477

   Для Ubuntu:

    wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/
    zabbix-release_7.0-1+ubuntu22.04_all.deb
    dpkg -i zabbix-release_7.0-1+ubuntu22.04_all.deb
    apt update
    apt install zabbix-server-pgsql zabbix-frontend-phpphp-pgsql
    zabbix-apache-conf zabbix-agent2

 6. Создайте базу данных Zabbix, указав следующее:

    sudo -u postgres createuser --pwprompt zabbix
    sudo -u postgres createdb -O zabbix zabbix

 7. Импортируйте схему базы данных для PostgreSQL:

    zcat /usr/share/doc/zabbix-server-pgsql*/create.sql.gz | sudo -u
    zabbix psql zabbix

 8. Добавьте пароль базы данных в конфигурационный файл Zabbix, отредакти
    ровав его:

    vim /etc/zabbix/zabbix_server.conf

 9. Добавьте следующие строки, где password — это ваш пароль, установленный
    в шаге 6, а DBHost оставьте пустым:

    DBHost=
    DBPassword=password

10. Теперь включите расширение TimescaleDB с помощью следующей команды:

    echo "CREATE EXTENSION IF NOT EXISTS timescaledb CASCADE;" |
    sudo -u postgres psql zabbix

11. Распакуйте скрипт timescale.sql:

    gunzip /usr/share/doc/zabbix-sql-scripts/postgresql/timescaledb.sql.gz

12. Теперь запустите этот скрипт:

    cat /usr/share/doc/zabbix-sql-scripts/postgresql/timescaledb.sql|
    sudo -u zabbix psql zabbix

13. Прежде чем переходить в веб-интерфейс, нужно выполнить еще одно действие:
    отредактировать файл pg_hba.conf, чтобы разрешить подключения к БД:

    vim /var/lib/pgsql/15/data/pg_hba.conf
