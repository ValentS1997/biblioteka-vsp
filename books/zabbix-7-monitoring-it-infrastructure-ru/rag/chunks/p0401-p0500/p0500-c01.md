500     Глава 13   •  Мониторинг облачной инфраструктуры

4. Здесь нужно присвоить имя приложению. Выберите подходящее имя, например,
   как показанное на рис. 13.19.

                        Рис. 13.19. Присвоение имени приложению

5. Затем нажмите кнопку Create (Создать) в нижней части страницы, чтобы за
   вершить создание нового пустого приложения. На этой странице вы увидите
   идентификатор приложения (Application ID) (рис. 13.20). Обязательно запи
  шите его, так как он понадобится позже.

            Рис. 13.20. Страница существующих корпоративных приложений Azure

6. Создав приложение, переходите к настройке учетных данных для работы с ним.
  Для этого воспользуйтесь строкой поиска Azure в верхней части и найдите Azure
    Active Directory (Активный каталог Azure), а затем выберите его из списка.
7. На левой боковой панели вы должны увидеть App registrations (Регистрации
   приложения). Мы собираемся создать новую регистрацию, поэтому нажмите
   кнопку + New registration (+ Новая регистрация) (рис. 13.21).

                      Рис. 13.21. Страница регистрации приложения
