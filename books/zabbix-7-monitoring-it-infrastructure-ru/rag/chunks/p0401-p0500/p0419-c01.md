3. Кроме того, с этим пакетом должен быть установлен пакет pip — система управле
   ния пакетами Python. Если это не так, то выполните следующую команду.
  Для RHEL:

   dnf install python3-pip

  Для Ubuntu:

   apt install python3-pip

  ПРИМЕЧАНИЕ
  Ваш дистрибутив Linux может поставляться с более старой версией Python 3. Если
   при выполнении скриптов далее в этой главе возникнут ошибки, обязательно про
   верьте, нет ли в сообщениях об ошибках указаний на то, что ваша версия Python
   может не поддерживать некоторые функции.

4. Теперь установим зависимости с помощью pip. Эти зависимости необходимы
   для запуска нашего скрипта:

   pip3 install requests

5. Загрузите тестовый скрипт из GitHub-репозитория этой книги, выполнив сле
  дующую команду:

   wget https://raw.githubusercontent.com/PacktPublishing/Zabbix-7-IT-
   Infrastructure-Monitoring-Cookbook/main/chapter10/api_test.py

6. Если вы не можете использовать wget, то скачайте скрипт по этой ссылке:
    https://github.com/PacktPublishing/Zabbix-7-IT-Infrastructure-Monitoring-Cookbook/tree/main/
    chapter10/api_test.py.
7. Отредактируйте только что скачанный скрипт, выполнив следующую команду:

   vim api_test.py

8. Для начала измените IP-адрес 10.16.16.152 в переменной url на IP-адрес или
  DNS вашего сервера Zabbix. Затем обязательно отредактируйте переменную
   api_token, заменив PUT_YOUR_TOKEN_HERE на API-токен, который был сгенери
   рован в первом разделе этой главы:

   url = "http://10.16.16.152/api_jsonrpc.php"
   api_token = "c01ce8726bfdbce02664ec8750f99da1bbbcb3cb295d924932e2f2808846273"
