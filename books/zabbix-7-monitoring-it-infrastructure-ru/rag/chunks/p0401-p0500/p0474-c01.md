474     Глава 12   •  Продвинутая настройка СУБД

Когда возраст партиции превышает указанный в переменной $tables, скрипт уда
ляет ее целиком.

При каждом запуске скрипта создается десять партиций в будущем, начиная с се
годняшнего дня, за исключением случаев, когда раздел уже существует.

Это лучше, чем использование housekeeper, по одной явной причине. Это про
сто быстрее! Zabbix housekeeper просматривает данные в базе данных построчно,
чтобы проверить временную метку UNIX, а затем при необходимости удаляет эту
строку. Это требует времени и ресурсов. Однако удаление партиции происходит
почти мгновенно.

Но у партиционирования базы данных Zabbix есть и недостаток: мы больше не мо
жем настраивать очистку истории из веб-интерфейса Zabbix. То есть не можем ука
зывать разные периоды хранения истории и трендов для разных элементов данных.

Использование TimescaleDB
TimescaleDB — это расширение для реляционной базы данных PostgreSQL для
обработки временных рядов. Использование TimescaleDB — это надежный способ
обойтись без Zabbix housekeeper для управления вашей базой данных PostgreSQL.
В этом разделе мы поговорим о том, как установить TimescaleDB на новый сервер
и настроить Zabbix.

Подготовка
Для работы понадобится пустой Linux-сервер. В нашем случае это сервер под на
званием lar-book-postgresql-mgmt.

Порядок действий
Процесс работы с системами на основе RHEL и Ubuntu немного различается, по
этому данный подраздел разбит на две части. Начнем с систем Ubuntu.
