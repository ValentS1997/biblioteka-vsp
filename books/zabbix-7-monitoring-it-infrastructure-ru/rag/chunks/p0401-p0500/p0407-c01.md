Интеграция Atlassian Opsgenie и Zabbix     407

      Рис. 9.69. Zabbix, страница Create user (Создать пользователя), пользователь Opsgenie

16. Кроме того, всем пользователям потребуется назначить роль. Чтобы добавить
     ее, перейдите на вкладку Permissions (Права доступа) и добавьте следующую
   информацию (рис. 9.70).

                  Рис. 9.70. Страница настройки прав доступа пользователя

   ПРИМЕЧАНИЕ
    В примере для удобства мы добавляем пользователя с ролью Super admin (Супер
    администратор). Это переопределяет права доступа «Только на чтение», которые
   мы назначили группе пользователей External Services. В целях безопасности вы
    можете ограничить права доступа, присвоив пользователю роль User (Пользо
    ватель) или Admin (Администратор), что будет соответствовать правам доступа
    к группам узлов сети, которые мы назначили ранее.

17. Теперь необходимо создать скрипт, который будет использоваться в действии.
   Для этого выберите раздел AlertsScripts (ОповещенияСкрипты) и нажмите
    кнопку Create script (Создать скрипт) в правом верхнем углу.
18. Назовите скрипт Opsgenie connector. Выберите в Scope (Область) пункт Action
     operation (Операция действия), для Type (Тип) — Script (Скрипт) и для Execute on
   (Выполнение на) — Zabbix server (Zabbix сервер).
19. Скопируйте содержимое файла /home/opsgenie/oec/opsgenie-zabbix/actionCom
    mand.txt в поле Commands (Команды). Результат должен выглядеть так, как
    показано на рис. 9.71.
20. Не забудьте нажать кнопку Add (Добавить) в нижней части страницы, чтобы
    сохранить новый скрипт.
