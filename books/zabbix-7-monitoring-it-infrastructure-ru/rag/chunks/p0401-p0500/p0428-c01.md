428     Глава 10   •  Расширение функциональности Zabbix

Подготовка
Нам понадобятся только сервер Zabbix, знания о Python и API Zabbix.

Порядок действий
1. Войдите в CLI сервера Zabbix и создайте новый каталог:

   mkdir /etc/zabbix/frontendscripts

2. Перейдите в новый каталог:

   cd /etc/zabbix/frontendscripts

3. Теперь скачайте скрипт с GitHub-репозитория компании Opensource ICT
   Solutions:

   wget https://github.com/OpensourceICTSolutions/zabbix-toggle-hosts-from-
   frontend/archive/v2.0.tar.gz

4. Если вы не можете использовать wget, то можете посмотреть скрипт по этой
   ссылке: https://github.com/OpensourceICTSolutions/zabbix-toggle-Hosts-from-frontend/
    releases/tag/v2.0.
5. Распакуйте файл с помощью следующей команды:

   tar -xvzf v2.0.tar.gz

6. Удалите файл tar, используя эту команду:

   rm v2.0.tar.gz

7. Перенесите скрипт из только что созданной папки с помощью следующей
   команды:

   mv zabbix-toggle-hosts-from-frontend-2.0/enable_disable-host.py./

8. Для работы с данным скриптом понадобится Python, поэтому установите его,
   используя следующую команду.

  Для систем на базе RHEL:

   dnf install python3 python3-pip

  Для Ubuntu:

   apt-get install python3 python3-pip

9. Кроме того, понадобится Python-модуль requests. Установите его следующим
   образом:

   pip3 install requests
