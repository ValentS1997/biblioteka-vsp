466     Глава 12   •  Продвинутая настройка СУБД

Настройка партиционирования
в MySQL
При использовании базы данных MySQL основная трудность возникает из-за
способа хранения данных по умолчанию. Данные не имеют четко определенного
порядка, что затрудняет удаление значительных объемов устаревшей информации.
Решением этой проблемы является партиционирование в MySQL. Давайте изучим,
как настроить его для работы с нашей базой данных Zabbix.

  ПРИМЕЧАНИЕ
  Инженеры компании Opensource ICT Solutions исправили скрипт для рабо
   ты с MySQL 8. Дополнительная информация доступна по этой ссылке: https://
   github.com/OpensourceICTSolutions/zabbix-mysql-partitioning-perl.

Подготовка
Для этого примера понадобится функционирующий сервер Zabbix с базой данных
MySQL, например lar-book-mysql-mgmt. В примере будет использоваться MariaDB,
однако подойдет любой другой вариант, совместимый с MySQL.

Если вы выполняете эти шаги в продуктивной среде, то не забудьте сначала создать
резервные копии базы данных, поскольку всегда что-то может пойти не так.

Порядок действий
1. Войдите в CLI Linux для выполнения команд.
2. Можно использовать утилиту TMUX, поскольку партиционирование может
   занять несколько дней для больших баз данных. TMUX будет поддерживать
   открытые сессии в фоновом режиме, даже в случае потери SSH-соединения.
   Если TMUX не установлен, то установите его, прежде чем приступать к работе.
  Выполните следующую команду.
  Для RHEL:

   dnf install tmux

  Для Ubuntu:

   apt install tmux

3. Откройте новую сессию tmux, выполнив следующую команду:

   tmux
