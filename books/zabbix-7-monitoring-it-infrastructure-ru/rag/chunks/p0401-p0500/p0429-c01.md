Активация и деактивация узла сети из интерфейса карты сетей     429

10. Теперь отредактируйте скрипт с помощью следующей команды:

    vim enable_disable-host.py

11. В этом файле будут изменены переменные url и token. Измените переменную
    url так, чтобы она соответствовала IP-адресу или DNS-имени вашего веб-
    интерфейса Zabbix. Затем замените PUT_YOUR_TOKEN_HERE на свой API-токен:

    url = 'http://10.16.16.152/api_jsonrpc.php?'
    token = " c01ce8726bfdbce02664ec8750f99da1bbbcb3cb295d924932e2f2808846273 "

12. Теперь можно перейти в веб-интерфейс Zabbix, чтобы добавить скрипт. Вы
    берите раздел AlertsScripts (ОповещенияСкрипты), затем нажмите синюю
    кнопку Create script (Создать скрипт) в правом верхнем углу.
13. Добавьте следующий скрипт (рис. 10.18).

                       Рис. 10.18. Страница создания нового скрипта

14. Нажмите синюю кнопку Add (Добавить), а затем, на следующей странице, снова
   нажмите синюю кнопку Create script (Создать скрипт) в правом верхнем углу.
15. Теперь добавьте еще один скрипт (рис. 10.19).

16. Теперь выберите раздел MonitoringMaps (МониторингКарты сетей), где вы долж
   ны увидеть карту под названием Local network, поскольку она добавлена в Zabbix
    по умолчанию. Щелкните на ней (или любой другой карте с узлами сети на ней).
