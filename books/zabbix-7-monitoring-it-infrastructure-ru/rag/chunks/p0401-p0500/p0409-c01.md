26. Нажмите синюю кнопку Add (Добавить) в нижней части страницы, чтобы за
    вершить настройку действия.
27. Теперь необходимо настроить интеграцию Opsgenie с Zabbix. Отредактируйте
   файл config с помощью следующей команды:

    vim /home/opsgenie/oec/conf/config.json

28. Убедитесь, что отредактировали строки apiKey, command_url, user и password
    (рис. 9.75).
