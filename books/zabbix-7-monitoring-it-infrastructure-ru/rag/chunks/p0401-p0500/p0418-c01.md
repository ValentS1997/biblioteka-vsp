418     Глава 10   •  Расширение функциональности Zabbix

Использование API
для расширения функциональности
API — это ваш ключ к расширению функциональности любого программно
го обеспечения. К счастью, Zabbix предоставляет надежный рабочий API, кото
рый позволяет нам легко расширять его функциональность. Кроме того, Zabbix
выпустил библиотеку zabbix-utils для Python, что значительно упрощает про
цесс написания скриптов. Это отличное дополнение, однако оно подходит для
использования не во всех средах, и, чтобы минимизировать зависимости, мы
не будем задействовать его в нашем тестовом примере. Тем не менее вы можете
ознакомиться с библиотекой здесь: https://github.com/zabbix/python-zabbix-utils.

В этом разделе мы изучим применение API Zabbix для решения ряда задач, что
послужит хорошей основой для начала работы с API в вашей реальной производ
ственной среде.

Подготовка
Нам понадобится сервер Zabbix и несколько узлов сети. В этом примере будет ис
пользоваться lar-book-centos из предыдущих глав, но вы можете работать с любым
сервером Zabbix. Кроме того, мы будем использовать другой Linux-сервер для вы
полнения вызовов API.

Необходимо также установить Python 3 на Linux-сервер, поскольку он будет ис
пользоваться для запуска скриптов.

Помимо этого, убедитесь, что у вас есть пользователь с действующим API-токеном.
Рекомендуется работать с тем, который мы создали в первом разделе.

Порядок действий
1. Откройте каталог с помощью CLI на Linux-сервере:

   cd /home/zabbix/

2. Установите Python 3 с помощью следующей команды.
  Для систем на базе RHEL:

   dnf install python3

  Для Ubuntu:

   apt install python3
