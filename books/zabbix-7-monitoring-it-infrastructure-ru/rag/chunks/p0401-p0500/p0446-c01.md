446     Глава 11   •  Поддержка и обслуживание Zabbix

Подготовка
Нам понадобится сервер, который будет называться lar-book-zbx6. На данный
момент он работает под управлением дистрибутива на основе RHEL8.

Другой вариант — сервер под управлением дистрибутива на основе Debian, на
пример, Ubuntu 22.04, Debian 12 или более новой версии этих дистрибутивов.
Мы обновим экземпляр MariaDB на этом сервере до версии 11.4.

Если вы выполнили предыдущий пример, то на вашем сервере уже установлен PHP
версии 8.2 или новее. Если нет, то сначала обновите PHP.

Кроме того, не забудьте сделать резервные копии системы и прочитать примечания
к устанавливаемой версии. Об этом было рассказано в разделе «Резервное копи
рование Zabbix».

Порядок действий
1. Войдите в CLI Linux-хоста, чтобы проверить версии установленного ПО. Вы
   полните следующие команды.
  Для Zabbix server:

   zabbix_server --version

  Для PHP:

   php-fpm --version

  Для MariaDB:

   mysql --version

2. Убедившись, что версии соответствуют указанным в подразделе «Подготовка»,
   переходите к обновлению версии MariaDB.
Операционные системы на основе RHEL
1. Первое, что нужно сделать на сервере на основе RHEL после проверки версий, —
   остановить все компоненты Zabbix:

   systemctl stop mariadb nginx zabbix-server

2. Теперь создайте файл репозитория для MariaDB с помощью следующей команды:

   vim /etc/yum.repos.d/mariadb.repo

3. В этот файл нужно добавить следующий код (убедитесь, что добавили правиль
  ную архитектуру после baseurl, если используется не amd64).

   [mariadb-main]
   name = MariaDB Server
