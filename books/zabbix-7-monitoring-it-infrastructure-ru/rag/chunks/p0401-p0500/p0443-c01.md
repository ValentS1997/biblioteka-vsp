Обновление PHP до версии 8.2 или новее     443

1. В первую очередь всегда проверяйте, какая версия PHP сейчас запущена. Для
   этого используйте команду:

   php-fpm --version

2. Если версия старше 8.2, то можно переходить к следующему шагу. Выполните
   эту команду:

   dnf module list php

3. В результате вы получите нечто подобное (рис. 11.6).

                         Рис. 11.6. Список доступных версий PHP

4. К сожалению, в RHEL8 отсутствует официальная поддержка PHP версии 8.3.
  Это означает, что придется искать альтернативный путь для систем на основе
  RHEL8. Если вы хотите установить PHP 8.3 или новее, то перейдите к шагу 9.
5. Поскольку PHP 8.2 доступен в репозитории AppStream, то необходимо сбросить
   конфигурацию PHP:

   dnf module reset php

6. Убедитесь, что ответили Y. Затем включите поддержку PHP 8.2 с помощью
  следующей команды:

   dnf module enable php:8.2

7. Снова ответьте Y, чтобы включить PHP 8.2. Затем обновите версию PHP с по
  мощью следующей команды:

   dnf update

8. Снова ответьте Y. Теперь в вашей системе установлен PHP версии 8.2.
9. Если вы не можете использовать метод dnf module enable для получения нуж
  ной версии PHP, то вам придется прибегнуть к другим способам, наиболее
  популярным из которых является использование стороннего репозитория
  REMI.
