502     Глава 13   •  Мониторинг облачной инфраструктуры

                         Рис. 13.24. Выбор срока действия секрета

13. Теперь нажмите кнопку Add (Добавить), чтобы завершить настройку нового
    секрета. Значения будут показаны вам один раз (рис. 13.25). Обязательно со
    храните их в безопасном месте, например, в хранилище паролей.

                                Рис. 13.25. Пример секрета

14. Когда настройка аутентификации завершена, остается выполнить одно дей
    ствие — предоставить правильные разрешения этому новому корпоративному
    приложению. Для этого найдите пункт Subscriptions (Подписки) в строке поиска
    Azure в верхней части страницы.
15. Для таких задач, как мониторинг виртуальных машин Azure и экземпляров
    баз данных, нужно разрешить чтение всего, что входит в Subscriptions. Найдите
     Subscriptions, в которой расположены ваши ресурсы. В показанном примере нуж
   ный пункт называется OICTS Azure (рис. 13.26).
