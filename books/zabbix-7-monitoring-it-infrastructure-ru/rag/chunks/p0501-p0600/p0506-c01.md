506     Глава 13   •  Мониторинг облачной инфраструктуры

Различия между AWS и Azure, конечно же, заключаются в скриптах JavaScript,
используемых в шаблонах.

Шаблоны, предоставляемые в Zabbix, используют довольно много JavaScript-кода
для выполнения вызовов API к Azure, с последующим разбором полученных дан
ных и преобразованием в JSON, который можно передать в Zabbix для обработки
с помощью LLDx.

Если открыть страницу Discovery (Обнаружение) шаблона Azure by HTTP, то вы уви
дите шесть правил обнаружения (рис. 13.33).

                 Рис. 13.33. Правила обнаружения шаблона Azure by HTTP

Эти шесть правил обнаруживают различные типы экземпляров баз данных и вир
туальных машин Azure и используют прототипы узлов сети для создания нового
узла сети для каждого найденного экземпляра данных. Единственное различие
заключается в том, что для предоставления информации будут использоваться
не прототипы узлов сети, а прототипы элементов данных. Узлы сети, созданные
с помощью прототипов узлов сети, в свою очередь, будут применять собственные
шаблоны для получения статистики этих экземпляров в зависимости от их типа,
как можно видеть в списке шаблонов (рис. 13.34).
