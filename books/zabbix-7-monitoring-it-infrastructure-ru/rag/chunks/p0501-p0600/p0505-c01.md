Настройка мониторинга Microsoft Azure     505

24. Перед добавлением узла переключитесь на вкладку Macros (Макросы) (рис. 13.31).

               Рис. 13.31. Новые макросы узла сети мониторинга Azure в Zabbix

    Добавьте следующие макросы:
      для {$AZURE.APP.ID} введите идентификатор приложения из шага 5;
      для {$AZURE.PASSWORD} введите значение в столбце Value (Значение) из
      шага 13;
      для {$AZURE.SUBSCRIPTION.ID} введите идентификатор подписки из шага 15;
      для {$AZURE.TENANT.ID} введите идентификатор клиента из шага 22.
25. Вот и все; теперь вы можете добавить новый узел сети, нажав кнопку Add (До
    бавить).
26. После первого запуска правила обнаружения найденные вами экземпляры будут
    добавлены в качестве новых узлов сети (рис. 13.32).

                Рис. 13.32. Новая виртуальная машина, обнаруженная в Azure

 Теперь автоматический мониторинг Azure работает должным образом.

 Объяснение
 Если вы выполнили пример, в котором рассматривался мониторинг AWS, то мо
 жете подумать, что мониторинг Azure работает точно так же. В какой-то степени
 это действительно так: мониторинг полностью основан на вызовах API, сделанных
 в Zabbix к API Azure.
