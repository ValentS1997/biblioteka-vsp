Настройка мониторинга Microsoft Azure     503

17. Выберите Subscription, а затем из списка выберите пункт Access control (IAM) (Управ
    ление доступом (IAM)). Затем нажмите кнопку Add role assignment (Добавить
    назначение роли) (рис. 13.27).

                             Рис. 13.27. Окно назначения роли

18. На следующей странице выберите из списка роль Reader (Читатель), а затем
   нажмите Next (Далее).
19. В разделе Members (Участники) процесса создания нажмите + Select members
    (+ Выбрать участников). Добавьте участника процесса Zabbix book monitoring (Мо
    ниторинг книг Zabbix). Это будет выглядеть следующим образом (рис. 13.28).

                          Рис. 13.28. Добавление участника в роль

20. Теперь нажмите кнопку Review + assign (Обзор + назначение) для сохранения
    разрешений.
21. На портале Azure нужно выполнить еще одно действие. В строке поиска в верх
    ней части страницы введите Tenant properties и выберите этот пункт из списка.
