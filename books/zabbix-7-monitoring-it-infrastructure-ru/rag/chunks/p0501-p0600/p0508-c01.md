508     Глава 13   •  Мониторинг облачной инфраструктуры

котором запущены эти контейнеры. Классический Zabbix agent нам не поможет,
требуется именно Zabbix Agent 2.

Само собой, для мониторинга Docker-контейнеров нужен сервер Zabbix. В этом
примере он будет называться zbx-home.

Порядок действий
1. Войдите в CLI Linux-хоста, на котором запущены ваши Docker-контейнеры.
2. Добавьте репозиторий для установки компонентов Zabbix. Для этого выполните
  следующие команды.
  Для систем на базе RHEL:
   rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rhel/8/x86_64/zabbix-
   release-7.0-1.el8.noarch.rpm
   dnf clean all

  Для Ubuntu:
   wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/
   zabbix-release_7.0-1+ubuntu22.04_all.deb
   dpkg -i zabbix-release_7.0-1+ubuntu22.04_all.deb
   apt update

3. Теперь установите Zabbix Agent 2 с помощью следующей команды.
  Для систем на базе RHEL:
   dnf install zabbix-agent2

  Для Ubuntu:
   apt install zabbix-agent2

4. После установки обязательно отредактируйте конфигурационный файл только
   что установленного Zabbix Agent 2 с помощью следующей команды:

   vim /etc/zabbix/zabbix_agent2.conf

5. Найдите строку со словом Server и добавьте в файл IP-адрес вашего сервера
   Zabbix, как показано ниже:

   Server=10.16.16.102

6. Теперь добавьте пользователя zabbix в системную группу Docker, выполнив
  следующую команду:

   gpasswd -a zabbix docker

7. Обязательно сохраните файл, а затем перезапустите Zabbix Agent 2, выполнив
  следующую команду:

   systemctl restart zabbix-agent2
