Использование обнаружения Zabbix proxy      361

Порядок действий
Начнем с редактирования правила обнаружения, а затем перейдем к редактирова
нию активного агента для авторегистрации на прокси.

Правила обнаружения
Сначала настроим правила обнаружения Zabbix.

1. Войдите в CLI узла сети lar-book-disc-lnx и отредактируйте файл /etc/zabbix/
   zabbix_agent2.conf. Измените следующие строки, чтобы добавить адрес Zabbix
   proxy:

   Server=127.0.0.1,10.16.16.152,10.16.16.160,10.16.16.161
   ServerActive=10.16.16.160

2. Перезапустите Zabbix agent, выполнив следующую команду:

   systemctl restart zabbix-agent2

3. Теперь подключитесь к lar-book-disc-win и отредактируйте файл C:\Program
   Files\Zabbix agent\zabbix_agent2. Измените следующие строки, чтобы доба
   вить адрес Zabbix proxy:

   Server=127.0.0.1,10.16.16.152,10.16.16.160,10.16.16.161
   ServerActive=10.16.16.160

  ПРИМЕЧАНИЕ
   В строке ServerActive должен быть указан только тот Zabbix proxy, на который не
   обходимо отправлять данные. Zabbix agent будет пытаться отправить данные на все
   прокси или серверы Zabbix, перечисленные здесь, поэтому нужно указать только тот,
   который будет использоваться.

4. Перезапустите Zabbix agent, выполнив следующие команды в командной строке
   Windows:

   zabbix_agent2.exe --stop
   zabbix_agent2.exe --start

  Или воспользуйтесь окном Windows Services (Службы), чтобы перезапустить
   агента.
   Затем выберите раздел Data collectionHosts (Сбор данныхУзлы сети) и удалите
   обнаруженные узлы сети:

   lar-book-disc-lnx
   lar-book-disc-win

  Это позволит избежать дублирования узлов сети.
