364     Глава 8   •  Настройка прокси-серверов Zabbix

Порядок действий
Мы собираемся настроить «самомониторинг» с помощью веб-интерфейса Zabbix
и вдобавок проверим встроенные возможности мониторинга Zabbix proxy.

Мониторинг состояния Zabbix proxy с помощью Zabbix agent
Мы можем контролировать работоспособность сервера и самого Zabbix proxy
с помощью локального Zabbix agent, чтобы всегда знать актуальное состояние
прокси-сервера в целом.

1. Войдите в интерфейс командной строки узла сети lar-book-proxy-active.
2. Чтобы установить Zabbix Agent 2, выполните следующую команду.
  Для систем на базе RHEL:

   dnf install zabbix-agent2

  Для Ubuntu:

   apt install zabbix-agent2

3. Отредактируйте файл конфигурации Zabbix agent, выполнив следующую
   команду:

   vim /etc/zabbix/zabbix_agent2.conf

4. Отредактируйте следующие строки, чтобы они указывали на localhost:

   Server=127.0.0.1
   ServerActive=127.0.0.1

5. Не забудьте указать hostname в файле конфигурации Zabbix agent:

   Hostname=lar-book-proxy-active

6. Теперь войдите в веб-интерфейс Zabbix и выберите раздел Data collectionHosts
   (Сбор данныхУзлы сети).
7. Нажмите синюю кнопку Create host (Создать узел сети) в правом верхнем углу
  и добавьте узел сети, как показано на рис. 8.32.
   Обратите особое внимание на поле Monitored by proxy (Наблюдение через прок
   си) — мы хотим осуществлять мониторинг с помощью прокси, поскольку выпол
   няем внутренние проверки Zabbix, которые должны быть обработаны демоном
   Zabbix, получившим эту конфигурацию.
8. Прежде чем нажать синюю кнопку Add (Добавить), убедитесь, что добавили
   Templates (Шаблоны). Добавьте для узла сети шаблоны, как показано на рис. 8.33.
9. Теперь вы можете нажать синюю кнопку Add (Добавить), чтобы создать узел
   сети.
