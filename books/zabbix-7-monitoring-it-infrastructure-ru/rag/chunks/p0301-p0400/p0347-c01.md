           Рис. 8.11. Раздел AdministrationProxies (АдминистрированиеПрокси)

В зависимости от настроек в файле конфигурации Zabbix proxy для изменения
значения колонки Last seen (age) (Последний раз был доступен (возраст)) может
потребоваться значительное время.

Объяснение
Если вы выполнили пример из раздела «Работа с пассивными Zabbix proxy» этой
главы, то шаги будут примерно такими же, за исключением той части, где изме
няется режим работы прокси.

Прокси, который мы только что добавили, — это активный прокси, который ра
ботает, запрашивая конфигурацию с сервера Zabbix через порт 10051 (рис. 8.12).

                  Рис. 8.12. Схема взаимодействия активного Zabbix proxy

Прокси-сервер постоянно запрашивает изменения в конфигурации и ежесекундно
отправляет новые собранные данные на сервер, а в случае их отсутствия посылает
периодический сигнал (heartbeat).

  ПРИМЕЧАНИЕ
   Рекомендуется использовать Zabbix proxy в активном режиме, так как с их помощью
   можно снизить нагрузку на сервер Zabbix. Используйте пассивный прокси только
   в том случае, если у вас есть веские причины для этого.
