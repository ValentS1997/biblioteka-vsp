Создание узлов сети с помощью LLD и пользовательского JSON     329

4. Добавьте следующий код одной строкой:

   * * * * * zabbix_sender -z 127.0.0.1 -s lar-lldhost-creation -k 200",
   lldhosts.raw -o '[{"vmname":"lar-lld-host1","vmip":"10.16.16.
   "vmlocation":"Amsterdam"},{"vmname":"lar-lld-host2","vmip":
   "10.16.16.201","vmlocation":"London"},{"vmname":"lar-lldhost3","vmip":
   "10.16.16.202","vmlocation":"Chicago"},{"vmname":"lar-lld-host4","vmip":
   "10.16.16.203","vmlocation":"Tirana"}]' >/dev/null 2>&1

   Этот код — просто команда задачи Cron и отправителя Zabbix, созданная сле
  дующим образом:

   * * * * *
   zabbix_sender -z 127.0.0.1 -s lar-lldhost-creation -k lldhosts.raw -o
   СОДЕРЖИМОЕ ФАЙЛА С GITHUB
   >/dev/null 2>&1

5. Теперь переключимся в веб-интерфейс Zabbix, где добавим узел сети для полу
   чения JSON-файла.
6. Чтобы добавить узел сети, выберите раздел Data collectionHosts (Сбор дан
  ныхУзлы сети) и нажмите кнопку Create host (Создать узел сети) в правом
   верхнем углу. Добавьте узел сети, как на рис. 7.62.

                   Рис. 7.62. Окно создания узла сети lar-lldhost-creation

7. Нажмите кнопку Add (Добавить) в нижней части окна, чтобы завершить созда
   ние этого узла сети. Вы вернетесь на страницу Hosts (Узлы сети) раздела Data
    collection.
8. На этой странице щелкните на Items (Элементы данных) рядом с хостом lar-
   lldhost-creation, который вы только что создали. В правом верхнем углу на
  жмите кнопку Create item (Создать элемент данных) и создайте элемент данных,
   как показано на рис. 7.63.
