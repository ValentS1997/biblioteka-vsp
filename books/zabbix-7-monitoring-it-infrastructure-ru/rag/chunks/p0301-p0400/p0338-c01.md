338     Глава 8   •  Настройка прокси-серверов Zabbix

3. Теперь установите Zabbix proxy, выполнив следующую команду.
  Для RHEL:
   dnf install zabbix-proxy-sqlite3 zabbix-selinux-policy

  В Ubuntu:
   apt install zabbix-proxy-sqlite3

  СОВЕТ
   На серверах на основе RHEL не забудьте установить Security-Enhanced Linux
   (SELinux) в разрешающий режим (permissive) или разрешить работу Zabbix proxy
   в SELinux для продуктивных сред. Для систем Ubuntu в лабораторной среде мы
   можем отключить AppArmor.

4. Затем отредактируйте конфигурацию Zabbix proxy, выполнив следующую
   команду:

   vim /etc/zabbix/zabbix_proxy.conf

  Начнем с переключения прокси в пассивный режим (passive). Для этого за
   дадим значение 1. Для прокси в активном режиме (active) установим значе
   ние 0:

   ProxyMode=1

5. Измените следующую строку на адрес вашего Zabbix server:

   Server=10.16.16.152

  ПРИМЕЧАНИЕ
   При работе с Zabbix server в режиме высокой доступности обязательно добавьте
   сюда IP-адреса для каждого Zabbix server, добавленного в кластере. Прокси будет
   отправлять данные только на активный узел. Помните, что узлы высокой доступ
   ности разделены точкой с запятой (;), а не запятой (,).

6. Измените следующую строку на hostname вашего прокси-сервера:

   Hostname=lar-book-proxy-passive

  В нашем примере мы будем использовать Zabbix proxy с поддержкой sqlite,
   поэтому измените параметр DBName следующим образом:

   DBName=/tmp/zabbix_proxy.sqlite3
