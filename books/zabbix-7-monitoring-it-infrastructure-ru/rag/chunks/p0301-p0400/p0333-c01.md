Кроме того, иногда JSON предоставляется самой средой Zabbix. Пока мы при
держиваемся следующего формата (с макросами прямо в файле или без них), что
угодно может быть проанализировано в соответствии с правилами LLD:

[
  {
    "vmname":"lar-lld-host1",
    "vmip":"10.16.16.200",
    "vmlocation":"Amsterdam"
  },
  {
    "vmname":"lar-lld-host2",
    "vmip":"10.16.16.201",
    "vmlocation":"London"
  },
  {
    "vmname":"lar-lld-host3",
    "vmip":"10.16.16.202",
    "vmlocation":"Chicago"
  },
  {
    "vmname":"lar-lld-host4",
    "vmip":"10.16.16.203",
    "vmlocation":"Tirana"
  }
]

Дополнительные примеры доступны по ссылке: https://www.zabbix.com/documentation/
current/en/manual/discovery/low_level_discovery.

Итак, что же мы на самом деле создали с помощью предыдущего JSON-файла?
Мы использовали JSON-ключи vmname, vmip и vmlocation и их значения для авто
матического создания пользовательских узлов сети. Но сначала мы должны ис
пользовать JSONPath для преобразования JSON-ключей в макросы LLD, которые
необходимы каждому правилу LLD (рис. 7.70).
