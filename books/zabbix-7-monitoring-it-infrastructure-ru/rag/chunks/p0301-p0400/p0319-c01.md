                            (МониторингПоследние данные)

 Объяснение
 Поначалу процесс мониторинга JMX-приложений может показаться довольно
 сложным, так как при создании собственных правил низкоуровневого обнаруже
 ния приходится выполнять много работы. Но теперь, когда вы создали свое первое
 правило LLD для JMX, в нем появилась четкая структура.

 Во-первых, для нашего правила обнаружения мы выбрали ключ элемента данных:

 jmx.discovery[beans,"*:type=MemoryPool,name=*"]

 MemoryPool — это то, что в Java называется MBean. Мы опрашиваем этот объект
 на предмет нескольких JMX-объектов и соответствующим образом заполняем
 макросы.

 Мы выбрали объект name=* для заполнения макроса {#JMXNAME} в этом правиле об
 наружения. Затем макрос используется в прототипе элемента данных для создания
 новых элементов данных.

 В результате должны быть созданы элементы данных, как на рис. 7.46.
