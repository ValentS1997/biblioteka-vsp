Настройка балансировки нагрузки Zabbix proxy      359

Активный агент узла сети lar-book-proxyha-test будет подключаться к одно
му из двух Zabbix proxy по IP-адресу, указанному в параметре ServerActive=.
Поскольку мы указали параметр Address for active agents (Адрес для активных
агентов) в конфигурации прокси в веб-интерфейсе Zabbix, все прокси в группе
знают адрес для перенаправления проверок при необходимости балансировки
нагрузки.

В случае сбоя произойдет перераспределение нагрузки внутри группы прокси
(рис. 8.27).

                   Рис. 8.27. Схема распределения нагрузки после сбоя

Теперь узел сети будет переподключен на другой прокси в группе. Именно поэтому
нам даже не нужны «плавающие» или виртуальные IP для перенаправления про
верок активных Zabbix agent, поскольку прокси могут сделать это за нас.

Однако не забывайте о параметрах прокси, позволяющих убедиться, что группа
работает оптимально. Если в группе четыре прокси и для параметра Minimum number
of proxies (Минимальное количество прокси) задано значение 1, то убедитесь, что
каждый прокси в группе настроен так, чтобы он мог обрабатывать нагрузку всей
группы в одиночку. В противном случае производительность мониторинга будет
снижена.

Это справедливо и в обратную сторону: когда в группе четыре прокси, а минималь
ное количество прокси задано 3, то вся группа выйдет из строя, если будут потеря
ны всего два прокси. Обязательно найдите правильный баланс между количеством
прокси в группе и минимальным количеством прокси, необходимых группе для
обработки полной нагрузки мониторинга (рис. 8.28).
