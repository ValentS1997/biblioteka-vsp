328     Глава 7   •  Использование службы Discovery в Zabbix

примеры хороших шаблонов по умолчанию для создания узлов сети с помощью
низкоуровневого обнаружения:

z  хост и гипервизоры VMware;
z  Kubernetes;
z Azure и AWS.

Однако для примера мы будем использовать пользовательский набор данных, ко
торый можно найти на GitHub: https://github.com/PacktPublishing/Zabbix-7-IT-Infrastructure-
Monitoring-Cookbook/blob/main/chapter07/lldhosts.json.

Кроме того, важно иметь базовое представление о Zabbix sender, зависимых эле
ментах данных и преварительной обработке. Рекомендуется сначала прочитать
следующие разделы из главы 3:

z «Создание простых проверок Zabbix и Zabbix trapper»;
z «Работа с вычисляемыми и зависимыми элементами данных»;
z «Использование предварительной обработки для изменения значений элементов
   данных».

Порядок действий
Приступим к созданию нового правила низкоуровневого обнаружения с пользователь
ским набором данных JSON. Для этого вам сначала нужно создать JSON-файл или
получить его из собственных источников данных. Мы уже подготовили один из них.

1. Для начала посмотрите на JSON-файл, расположенный здесь: https://raw.github
   usercontent.com/PacktPublishing/Zabbix-7-IT-Infrastructure-Monitoring-Cookbook/main/
    chapter07/lldHosts.json.
2. Далее войдите в CLI сервера Zabbix и убедитесь, что у вас установлено при
   ложение Zabbix sender. С его помощью вы отправите файл в Zabbix. Для этого
   выполните следующие команды.

  Для систем на базе RHEL:

   dnf install zabbix-sender

  Для Ubuntu:

   apt install zabbix-sender

3. Настроим приложение zabbix-sender на отправку этого JSON-файла в систему
  каждую минуту. Для простоты будем использовать CronJob:

   crontab -e
