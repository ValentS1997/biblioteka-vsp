352     Глава 8   •  Настройка прокси-серверов Zabbix

Кроме того, с помощью прокси-серверов можно выполнять мониторинг удаленных
объектов, например, если вы являетесь поставщиком комплексного управления IT
(managed service provider, MSP) и хотите контролировать сеть клиента. Вам до
статочно просто разместить прокси-сервер на объекте заказчика и контролировать
через него. Можно использовать стандартные методы, такие как мониторинг через
виртуальную частную сеть (virtual private network, VPN), или просто установить
соединение с использованием встроенного шифрования Zabbix proxy.

Когда соединение с удаленным сайтом прервется, прокси-сервер продолжит соби
рать данные и переотправит их на сервер Zabbix при восстановлении соединения.
По умолчанию Zabbix proxy будет хранить данные на диске в течение часа, что
задается параметром ProxyOfflineBuffer= в файле конфигурации.

Помимо этого, можно использовать Zabbix proxy для того, чтобы обойти слож
ности с брандмауэром. Когда вы размещаете прокси-сервер за брандмауэром
в контролируемой сети, вам нужно только одно правило брандмауэра между
прокси-сервером и сервером Zabbix. Zabbix proxy следит за различными узлами
сети и отправляет собранные данные одним потоком на сервер. Это означает, что
вам не нужно настраивать дополнительные правила для открытия портов 161, 162,
10050, 10051, портов Java, портов API и многих других через брандмауэр.

Таким образом, теперь у вас есть множество вариантов применения Zabbix proxy.

Шифрование соединения Zabbix proxy
с помощью PSK
Для дополнительной безопасности рекомендуется убедиться, что ваши Zabbix
proxy передают данные по сети в зашифрованном виде. Это делается для того,
чтобы возможный злоумышленник, проникший в вашу сеть, не смог прочитать
данные, которые передаются между сервером и прокси в текстовом формате.

Представьте, что у вас есть макросы с важными паролями. Эти макросы будут
передаваться по сети открытым текстом, если вы не зашифруете соединение между
сервером и Zabbix proxy.

Подготовка
Для этого примера понадобятся сервер Zabbix и подключенный Zabbix proxy пас
сивного или активного типа.
