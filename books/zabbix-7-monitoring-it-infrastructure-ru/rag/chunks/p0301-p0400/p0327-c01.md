Создание узлов сети с помощью LLD
и пользовательского JSON
Создание узлов сети с помощью правил LLD работает так же, как и создание чего-
либо другого с помощью правил LLD. Мы передаем серверу Zabbix специальный
набор данных в формате JSON, после чего используем эти данные для создания
новых узлов сети. Однако начиная с версии Zabbix 6.2 кое-что изменилось. Появи
лась возможность настраивать узлы сети, созданные с помощью низкоуровневого
обнаружения. Посмотрим, как это сделать и как это работает.
