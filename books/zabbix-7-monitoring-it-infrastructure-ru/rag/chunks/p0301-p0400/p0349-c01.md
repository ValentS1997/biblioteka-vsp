Мониторинг узлов сети с помощью Zabbix proxy     349

              Рис. 8.13. Раздел Data collectionHosts (Сбор данныхУзлы сети)

Активный прокси
1. Сделаем то же самое для другого узла сети lar-book-agent, выбрав раздел Data
   collectionHosts (Сбор данныхУзлы сети).
2. Щелкните на узле сети lar-book-agent, измените поле Monitored by (Отслеживать
   через) на Proxy (Прокси) и выберите прокси lar-book-proxy-active (рис. 8.14).

              Рис. 8.14. Раздел Data collectionHosts (Сбор данныхУзлы сети)

3. Теперь нажмите синюю кнопку Update (Обновить).
4. В CLI узла сети lar-book-agent выполните следующую команду:

   vim /etc/zabbix/zabbix_agent2.conf

5. При работе с активным агентом Zabbix нужно обязательно добавить IP-адрес
   нашего прокси в следующую строку:

   ServerActive=

Это связано с тем, что в такой конфигурации агент будет передавать данные на
прокси, который, в свою очередь, будет управлять передачей данных на сервер.
