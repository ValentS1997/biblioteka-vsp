394     Глава 9   •  Интеграция Zabbix с внешними сервисами

Порядок действий
1. Создайте новый канал в Telegram. Нажмите зна
   чок создания рядом со строкой поиска и выбери
   те New Group (Создать группу) (рис. 9.42).
2. Добавьте еще одного пользователя — кого-то
   из вашей команды, кто тоже должен получать
   уведомления. Заполните название группы и по
                                                          Рис. 9.42. Кнопка New Group  желанию добавьте картинку (рис. 9.43).                                                                    (Создать группу)

                       Рис. 9.43. Окно New Group (Создать группу)

3. Теперь нажмите кнопку Create (Создать) в правом верхнем углу. В результате
   откроется только что созданная группа.
4. Работа с Telegram-ботами упрощается благодаря Telegram-пользователю
   @BotFather. Мы можем начать создание нашего бота, найдя botfather и нажав на
   найденном контакте (рис. 9.44).

                            Рис. 9.44. Пользователь BotFather

5. Для начала отправьте команду /start в чат. Вы получите справочное сообщение
   со списком доступных команд (рис. 9.45).
6. Для создания нового бота наберите /newbot в чате с BotFather. Нажмите Enter,
   чтобы отправить сообщение. Результат будет выглядеть так (рис. 9.46).
7. Введите желаемое имя бота; мы назовем его zabbix-notification-bot. Нажмите
    Enter, чтобы отправить имя (рис. 9.47).
