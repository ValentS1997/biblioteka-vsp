314     Глава 7   •  Использование службы Discovery в Zabbix

Объяснение
Счетчики производительности Windows существуют уже давно и играют важную
роль в работе тех, кто хочет контролировать Windows с помощью Zabbix. Исполь
зование LLD в сочетании со счетчиками производительности Windows упрощает
процесс создания гибкого и надежного мониторинга Windows.

В этом примере мы создали очень простое, но эффективное правило обнаружения
счетчика производительности Windows, добавив правило обнаружения с ключом
элемента данных perf_instance.discovery[Processor]. Часть [Processor] данного
ключа напрямую связана с окном perfmon.exe, которое мы видели. Если мы по
смотрим на следующий снимок экрана, то увидим уже указанный счетчик Processor
(Процессор) (рис. 7.36).

 Рис. 7.36. Окно Add Counters (Добавить счетчики) в perfmon.exe, счетчик Processor (Процессор)

Когда правило обнаружения опрашивает этот ключ элемента данных, Zabbix agent
возвращает следующее значение для нашего узла сети:

[
    {
        "{#INSTANCE}":"0"
    },
    {
        "{#INSTANCE}":"1"
    },
    {
        "{#INSTANCE}":"_Total"
    }
]

Это означает, что Zabbix заполнит макрос {#INSTANCE} тремя значениями:

z  0;
z  1;
z  _Total.
