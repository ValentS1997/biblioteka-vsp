Настройка оповещений в Slack     379

20. Теперь перейдите в веб-интерфейс Zabbix и выберите раздел AlertsMedia types
   (ОповещенияСпособы оповещений).
21. Выберите Slack, чтобы отредактировать выбранный способ оповещений. Вы
    увидите список предварительно настроенных параметров. Вставьте ваш OAuth-
    токен в параметр bot_token (рис. 9.14).

              Рис. 9.14. Страница редактирования настроек подключения к Slack

22. Удостоверьтесь, что в поле Enabled (Активировано) установлен флажок.
23. На вкладке Message templates (Шаблоны сообщений) уже настроено пять типов
   сообщений (рис. 9.15). Вы можете отредактировать их, если это необходимо.

                Рис. 9.15. Страница с преднастроенными шаблонами сообщений

24. Нажмите кнопку Update (Обновить), чтобы сохранить изменения.
25. Теперь создадим новую группу пользователей для нашего способа оповещения.
   Выберите раздел UsersUser groups (ПользователиГруппы пользователей)
   и нажмите кнопку Create user group (Создать группу пользователей) в правом
    верхнем углу. Добавьте группу, как показано на рис. 9.16.
