Настройка низкоуровневого обнаружения SNMP в Zabbix по-новому     321

Порядок действий
В главе 3 мы уже настроили SNMP-мониторинг, поэтому можем сразу же присту
пить к работе в веб-интерфейсе. Кроме того, в главе 5 мы узнали о создании шабло
нов для всего мониторинга, так что начнем с этого. Выполните следующие шаги.

1. В интерфейсе Zabbix выберите раздел Data collectionTemplates (Сбор дан
  ныхШаблоны) и нажмите кнопку Create template (Создать шаблон) в правом
   верхнем углу. Добавьте информацию, как на рис. 7.47.

                         Рис. 7.47. Шаблон BOOK Linux by SNMP

2. Не забудьте переключиться на вкладку Tags (Теги), чтобы добавить несколько
   тегов в соответствии с новой политикой (рис. 7.48).

                          Рис. 7.48. Страница добавления тегов

3. В нижней части окна нажмите большую кнопку Add (Добавить), чтобы завер
  шить настройку нового шаблона.
   Ранее мы уже настроили преобразование значений и некоторые элементы дан
  ных на узле сети lar-book-snmp_bulk. Теперь используем функцию массового
   обновления, чтобы скопировать преобразование значений в новый шаблон.
4. Выберите свой шаблон в списке с помощью флажка и нажмите большую кнопку
   Mass update (Массовое обновление) в нижней части окна (рис. 7.49).
5. После этого перейдите на вкладку Value mapping (Преобразование значе
   ний), установите флажок и щелкните на ссылке Add from host (Добавить с узла
   сети).
