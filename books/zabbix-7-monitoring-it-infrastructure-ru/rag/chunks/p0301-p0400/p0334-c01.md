334     Глава 7   •  Использование службы Discovery в Zabbix

Благодаря этому vmip преобразуется в {#VMIP}, vmlocation — в {#VMLOCATION},
а vmname — в {#VMNAME}. JSONPath ищет ключи, а Zabbix преобразует их для нас
в макросы.

Затем мы используем эти макросы в прототипе узла сети LLD, чтобы определить,
какими будут значения для каждого узла сети (рис. 7.71).

                          Рис. 7.71. Используемые макросы LLD

В результате наши узлы сети создаются с правильными настройками (рис. 7.72).

                 Рис. 7.72. Узел сети lar-lld-host4, созданный правилом LLD

Как видите, заполнено поле Host name, а также указана пользовательская группа
узлов сети. Кроме того, определен интерфейс с правильным IP. Теперь мы будем
использовать этот IP для мониторинга узла сети с помощью Zabbix agent и шабло
на, который также подключился к узлу сети.

Дополнительная информация
Это еще не все! Начиная с версии Zabbix 6.2 прототипы узлов сети становятся более
полезными благодаря некоторым существенным изменениям. Теперь можно полно
стью настроить параметры узла сети, такие как макросы, теги и даже шаблоны.
