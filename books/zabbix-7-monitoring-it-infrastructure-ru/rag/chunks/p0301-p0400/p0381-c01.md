29. Добавьте следующего пользователя на ваш сервер Zabbix и не забудьте задать
    ему надежный пароль (рис. 9.18).

                    Рис. 9.18. Страница Create user (Создать пользователя)

   СОВЕТ
    При создании пользователей для таких целей, как оповещение или просто доступ
    к API, лучше всего добавить пользователя в группу, которая отключает доступ
    к веб-интерфейсу. Вот почему мы добавили в группу No access to the frontend (Без
    доступа к веб-интерфейсу).

30. Теперь перейдите на вкладку Media (Оповещения) и щелкните на ссылке Add
    (Добавить). Мы добавим для этого пользователя следующий способ оповеще
   ния (рис. 9.19).
