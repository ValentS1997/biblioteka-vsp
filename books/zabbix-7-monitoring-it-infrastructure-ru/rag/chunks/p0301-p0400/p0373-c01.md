Настройка оповещений в Slack     373

2. Создадим новый канал специально для уведомлений Zabbix, нажав кнопку
   Add channels (Добавить каналы). Затем в появившемся выпадающем списке вы
   берите Create a new channel (Создать новый канал). Вы увидите следующее окно
   (рис. 9.2).

                             Рис. 9.2. Окно создания канала

3. Нажмите кнопку Next (Далее). Затем выберите, каким должен быть канал: пу
  бличным или частным, после нажмите кнопку Create (Создать) (рис. 9.3).

                       Рис. 9.3. Настройка видимости нового канала

4. Вам будет предложено выполнить еще один шаг, чтобы добавить в новый канал
   определенных или всех людей, состоящих в вашем Slack. После можете просто
   нажать кнопку Done (Готово) (рис. 9.4).
