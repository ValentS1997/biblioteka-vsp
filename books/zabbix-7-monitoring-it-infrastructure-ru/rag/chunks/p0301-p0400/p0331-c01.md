Создание узлов сети с помощью LLD и пользовательского JSON     331

12. Теперь надо определить несколько макросов для использования данных из
    файла:

        {
          "vmname":"lar-lld-host1",
          "vmip":"10.16.16.200",
          "vmlocation":"Amsterdam"
        }

  Мы будем использовать JSONPath для преобразования предыдущих блоков
   данных в другой формат:

        {
          "{#VMNAME}":"lar-lld-host1",
          "{#VMIP}":"10.16.16.200",
          "{#VMLOCATION}":"Amsterdam"
        }

13. Для этого перейдите на вкладку LLD macros (LLD-макросы) и задайте параметры,
    как на рис. 7.66.

                 Рис. 7.66. Вкладка добавления LLD-макросов для LLD-правила

14. Теперь вы можете нажать большую кнопку Add (Добавить) в нижней части этой
    страницы, и правило низкоуровневого обнаружения будет создано.
15. Однако, чтобы что-то сделать с этим правилом, придется создать новый про
    тотип узла сети. Для этого щелкните на Host prototypes (Прототипы узлов сети),
    а затем нажмите Create host prototype (Создать прототип узлов сети) в правом
    верхнем углу. Добавьте информацию, как показано на рис. 7.67.
   Как видите, мы используем макросы для создания имени виртуальной машины
     (virtual machine, VM), а также для создания уникальной группы узлов сети.
16. Кроме того, определите интерфейс с помощью макроса. Для этого переключите
    интерфейс на Custom (Пользовательский), щелкнув на ссылке Add (Добавить)
   и добавив информацию, как на рис. 7.68.
