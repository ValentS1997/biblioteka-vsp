Использование обнаружения счетчиков производительности Windows     309

Подготовка
В данной главе мы уже добавили узел сети lar-book-disc-win, который использует
ся в Discovery. Мы можем повторно использовать его для обнаружения счетчиков
производительности Windows.

Конечно, нам также понадобится сервер Zabbix.

Порядок действий
1. Выберите раздел Data collectionTemplates (Сбор данныхШаблоны) и нажмите
   кнопку Create template (Создать шаблон) в правом верхнем углу.
2. На вкладке Templates (Шаблоны) создайте шаблон, как показано на рис. 7.27.

                          Рис. 7.27. Страница создания шаблона

3. Нажав синюю кнопку Add (Добавить), вы снова попадете на страницу Templates
  (Шаблоны) раздела Data collection (Сбор данных). Выберите новый шаблон.
4. Теперь, прежде чем продолжить работу с шаблоном, перейдите в интерфейс
  Windows и запустите perfmon.exe (рис. 7.28).
5. При этом откроется окно, как на рис. 7.29.
6. Щелкните на Performance Monitor (Системный монитор), а затем на зеленом знач
   ке +. Это покажет вам все доступные счетчики производительности Windows.
