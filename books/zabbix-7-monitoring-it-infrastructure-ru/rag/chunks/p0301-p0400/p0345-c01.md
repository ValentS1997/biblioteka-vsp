Работа с активными Zabbix proxy     345

2. Откроется всплывающее окно Create proxy (Создать прокси), в котором нужно
   указать информацию, как на рис. 8.8.

                 Рис. 8.8. Всплывающее окно Create proxy (Создать прокси)

  СОВЕТ
   Поле Proxy address (Адрес прокси) является необязательным для активного прокси.
   Его необязательно добавлять для работы Zabbix proxy, но рекомендуется, чтобы
   потом не запутаться. Кроме того, добавление данного поля будет работать как
   своего рода белый список, поскольку сможет подключиться только указанный
   IP-адрес.

Прежде чем нажать синюю кнопку Add (Добавить), посмотрим на вкладку Encryption
(Шифрование) (рис. 8.9).
