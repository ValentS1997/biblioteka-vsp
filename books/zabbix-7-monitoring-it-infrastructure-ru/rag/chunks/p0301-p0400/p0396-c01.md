    будет использоваться lar_zbx_notification_bot (рис. 9.48).

                        Рис. 9.48. Получение ключа для работы с API

   ПРИМЕЧАНИЕ
    Имя пользователя вашего бота должно быть уникальным, поэтому вы не можете
    написать lar_zbx_notification_bot. Придумайте уникальное имя и используйте его
    в этом руководстве.

 9. Убедитесь, что сохранили ключ для работы с HTTP API в безопасном месте.
10. Вернитесь к каналу Zabbix notifications и добавьте бот. Щелкните на группе в спи
    ске чатов и ее названии.
11. Теперь нажмите кнопку Add (Добавить), чтобы добавить бот (рис. 9.49).
