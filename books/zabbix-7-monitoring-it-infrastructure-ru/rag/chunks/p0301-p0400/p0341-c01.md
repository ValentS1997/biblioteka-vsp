Работа с пассивными Zabbix proxy     341

Порядок действий
1. Войдите в веб-интерфейс Zabbix и выберите раздел AdministrationProxies (Адми
   нистрированиеПрокси) (рис. 8.1).

            Рис. 8.1. Раздел AdministrationProxies (АдминистрированиеПрокси)

2. Добавим новый прокси с помощью синей кнопки Create proxy (Создать прокси)
   в правом верхнем углу.
  Вы увидите всплывающее окно Create proxy (Создать прокси), в котором нужно
   внести информацию, как показано на рис. 8.2.
