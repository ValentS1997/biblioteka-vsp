                             Рис. 7.49. Массовое обновление

6. Найдите свой узел сети lar-book-snmp_bulk и выберите в списке пункт Interface
   Up/Down (Интерфейс доступен/недоступен). Это должно выглядеть так, как
   показано на рис. 7.50.

                Рис. 7.50. Добавление преобразования значений с узла сети

7. Нажмите большую кнопку Update (Обновить) в нижней части окна, чтобы до
   бавить это преобразование значений.
8. Теперь скопируем существующие элементы данных из шаблона. Выберите
   раздел Data collectionHosts (Сбор данныхУзлы сети), а затем страницу Items
   (Элементы данных) для lar-book-snmp_bulk. Выберите два элемента данных,
   которые создали ранее, и нажмите кнопку Copy (Копировать) в нижней части
   окна (рис. 7.51).
