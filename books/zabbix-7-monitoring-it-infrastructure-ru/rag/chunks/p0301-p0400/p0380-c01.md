380     Глава 9   •  Интеграция Zabbix с внешними сервисами

                     Рис. 9.16. Страница создания группы пользователей

26. Щелкните на вкладке Host permissions (Права доступа к узлам сети), а затем на
   жмите кнопку Select (Выбрать). Убедитесь, что выбрали все группы и подгруппы
    с правами как минимум Read (Чтение) (рис. 9.17).

                       Рис. 9.17. Настройка прав доступа к узлам сети

   ПРИМЕЧАНИЕ
    Применяя разрешения для группы пользователей, убедитесь, что добавили только
    те группы узлов сети, от которых хотите получать уведомления. Зачастую в те
    стовых и даже продуктивных средах добавляют сразу все группы, но иногда есть
    необходимость отфильтровать уведомления. Один из способов сделать это —
    использовать различные группы пользователей и самих пользователей, чтобы
    получать уведомления только от групп узлов сети в определенных каналах, хотя
    то же самое можно настроить с помощью Actions (Действия). Более подробно
    о разрешениях пользователей и триггерах Zabbix читайте в главах 2 и 4 соот
    ветственно.

27. Теперь нажмите синюю кнопку Add (Добавить) и завершите создание этой
   группы пользователей.
28. Далее выберите раздел UsersUser (ПользователиПользователь), чтобы соз
    дать пользователя Slack. Нажмите синюю кнопку Create user (Создать пользо
    вателя) в правом верхнем углу.
