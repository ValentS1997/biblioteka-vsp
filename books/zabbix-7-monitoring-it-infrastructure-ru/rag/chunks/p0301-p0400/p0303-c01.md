Автоматизация создания узлов сети с помощью авторегистрации     303

  ПРИМЕЧАНИЕ
   Общие знания о структуре SNMP очень важны при создании правил обнаружения
   Zabbix. Мы хотим быть уверены, что используем правильные идентификаторы объ
   екта SNMP в качестве проверок. Убедитесь в том, что хорошо изучили структуру
   SNMP, использовали SNMP walks и спланировали, какие OID хотите использовать
   для обнаружения SNMP agent. Это необходимо для создания надежной инфра
   структуры мониторинга.

Автоматизация создания узлов сети
с помощью авторегистрации активных агентов
Использование Discovery для поиска хостов с установленным Zabbix agent
(passive) — очень полезный метод автоматизации создания новых узлов сети.
Но что, если мы хотим сделать среду еще более автоматизированной? В этом
случае можно воспользоваться функцией Zabbix под названием авторегистрация
активных агентов (active agent autoregistration).

Подготовка
Для этого примера понадобится новый хост Linux. Мы назовем его lar-book-lnx-
agent-auto. Обязательно установите на этот хост Zabbix Agent 2. Помимо этого
нового хоста, понадобится сервер Zabbix.

Порядок действий
1. Начнем с того, что войдем на новый хост lar-book-lnx-agent-auto и изменим
  следующий файл:

   vim /etc/zabbix/zabbix_agent2.conf

2. Затем отредактируем следующую строку в файле. Убедитесь, что в ней указан
   IP-адрес вашего сервера Zabbix:

   ServerActive=10.16.16.152

3. Мы также можем изменить следующую строку в файле, если хотим вручную
   задать hostname:

   Hostname=lar-book-lnx-agent-auto

  Однако это не является обязательным условием, поскольку Zabbix agent будет
   использовать hostname системы, если оно не заполнено.
