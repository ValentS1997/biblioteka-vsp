 8. Убедитесь, что на вкладке Tags (Теги) добавили новый тег с именем component
   и значением memory pool (рис. 7.42).

                               Рис. 7.42. Вкладка Tags (Теги)

 9. Нажмите синюю кнопку Add (Добавить).

    кните на lar-book-jmx. Теперь подключим ранее созданный шаблон.
11. Щелкните на Templates (Шаблоны) и добавьте шаблон (рис. 7.43).

               Рис. 7.43. Раздел Data collectionHosts (Сбор данныхУзлы сети)

12. Нажмите синюю кнопку Update (Обновить).
13. Выберите раздел MonitoringLatest data (МониторингПоследние данные), а за
    тем lar-book-jmx для Hosts (Узлы сети) и component в Tags (Теги) с memory pool
    в качестве значения, например, так, как на рис. 7.44.
