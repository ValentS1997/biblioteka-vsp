Настройка Zabbix proxy     337

Технические требования
Для этой главы понадобится несколько новых Linux-хостов, поскольку мы будем
использовать их в качестве прокси-серверов Zabbix.

Настройте два прокси-сервера, установив предпочтительный дистрибутив Linux
на базе RHEL или Ubuntu на следующие два новых хоста:

z  lar-book-proxy-passive;
z  lar-book-proxy-active.

Кроме того, вам понадобятся сервер Zabbix и хотя бы один узел сети. Мы будем ис
пользовать новый узел сети lar-book-agent-by-proxy с настроенным мониторингом
с помощью Zabbix agent.

Настройка Zabbix proxy
Установка Zabbix proxy может быть весьма сложной, если ваш опыт работы с Linux
невелик, но сама задача довольно проста. Вы поймете это, как только разберетесь
с ней. Мы, авторы книги, установим Zabbix proxy на сервер lar-book-proxy-passive;
вы можете повторить все действия для lar-book-proxy-active.

Подготовка
Убедитесь, что у вас есть новый пустой Linux-хост. В данный момент сервер Zabbix
не понадобится.

Порядок действий
1. Войдите в CLI нового хоста lar-book-proxy-passive.
2. Выполните следующую команду, чтобы добавить репозиторий Zabbix.
  Для систем на базе RHEL:
   rpm -Uvh https://repo.zabbix.com/zabbix/7.0/rhel/8/x86_64/zabbix-
   release-7.0-1.el8.noarch.rpm
   dnf clean all

  Для Ubuntu:

   wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/
   zabbix-release_7.0-1+ubuntu22.04_all.deb
   dpkg -i zabbix-release_7.0-1+ubuntu22.04_all.deb
   apt update
