308     Глава 7   •  Использование службы Discovery в Zabbix

Zabbix agent правильную строку ServerActive= для хостов в определенном пуле
IP-адресов.

Также было бы очень легко настраивать новые хосты с помощью Ansible (система
управления конфигурациями). Она позволяет автоматизировать установку Zabbix
agent и может добавить адрес сервера Zabbix в строку ServerActive= в файл /etc/
zabbix/zabbix_agent2.conf. Об остальном позаботится автоматическая регистра
ция агентов в Zabbix.

Авторегистрация Zabbix agent — отличный способ получить всегда актуальную
среду мониторинга, не прикладывая особых усилий.

Дополнительная информация
Не каждая компания использует hostname, которые отражают тип ОС или дру
гие атрибуты сервера. Именно здесь может пригодиться параметр HostMetadata.
Мы можем добавить его в конфигурацию Zabbix agent (active), чтобы отразить
атрибуты сервера.

После этого можно использовать HostMetadata в Discovery action, чтобы выполнить
ту же фильтрацию, что и по имени хоста.

Кроме того, в файле конфигурации Zabbix agent есть параметры HostInterface
и HostInterfaceItem, которые используются при авторегистрации. Хост будет
использовать указанный IP или DNS-имя в качестве IP- или DNS-параметров
интерфейса Zabbix agent нового узла сети.

Дополнительная информация доступна по этой ссылке: https://www.zabbix.com/
documentation/current/manual/discovery/auto_registration#using_host_metadata.
