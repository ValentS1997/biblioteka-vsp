346     Глава 8   •  Настройка прокси-серверов Zabbix

По умолчанию здесь установлен флажок No encryption (Без шифрования), который
не будем менять в этом примере.

Прежде чем продолжать, нужно взглянуть на еще одну вкладку во всплывающем
окне создания прокси — Timeouts (Время ожидания) (рис. 8.10).

                      Рис. 8.10. Вкладка Timeouts (Время ожидания)

Мы не будем ничего менять на этой вкладке, но начиная с Zabbix 7 можно пере
определять глобальное время ожидания для различных типов проверок элементов
данных, что позволяет настроить Zabbix так, чтобы избежать проблем с произво
дительностью из-за таймаутов.

1. Теперь нажмите синюю кнопку Add (Добавить), которая вернет вас на обзорную
   страницу.
2. Войдите в интерфейс командной строки и проверьте конфигурацию с помощью
  следующей команды:

   vim /etc/zabbix/zabbix_proxy.conf

   Теперь изменим режим работы прокси на active. Для этого установите 0 вместо 1:

   ProxyMode=0

3. Измените следующую строку на hostname вашего прокси-сервера:

   Hostname=lar-book-proxy-active
