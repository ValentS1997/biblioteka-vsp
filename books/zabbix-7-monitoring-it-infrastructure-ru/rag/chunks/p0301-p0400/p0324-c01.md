13. Теперь нажмите большую кнопку Add (Добавить) в нижней части окна, чтобы
    добавить правило низкоуровневого обнаружения. Затем перейдите в раздел
    Item prototypes (Прототипы элементов данных), чтобы добавить первый элемент

    элемента данных (рис. 7.56).
