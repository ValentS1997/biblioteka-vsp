316     Глава 7   •  Использование службы Discovery в Zabbix

Подготовка
Для данного примера понадобится JMX-хост lar-book-jmx, который вы настрои
ли в разделе «Настройка мониторинга JMX» в главе 3. Обязательно изучите тот
пример, прежде чем продолжить. Кроме того, понадобится сервер Zabbix.

Порядок действий
1. Войдите в веб-интерфейс Zabbix и выберите раздел Data collectionTemplates
   (Сбор данныхШаблоны).
2. Создайте новый шаблон, нажав кнопку Create template (Создать шаблон) в правом
   верхнем углу. Заполните поля, как показано на рис. 7.39.

          Рис. 7.39. Создание шаблона обнаружения JMX-объектов в Apache Tomcat

3. После нажатия синей кнопки Add (Добавить) вы вернетесь на страницу Templates
  (Шаблоны) раздела Data collection (Сбор данных). Щелкните на новом шаблоне
   App Apache Tomcat JMX discovery.
4. Теперь добавим правило обнаружения JMX-объектов. Щелкните на разделе
    Discovery rules (Правила обнаружения) рядом с именем шаблона.
5. Теперь щелкните на Create discovery rule (Создать правило обнаружения) и за
   полните поля, как показано на рис. 7.40.
6. Нажмите синюю кнопку Add (Добавить) в нижней части страницы. Затем
   щелкните на Item prototypes (Прототипы элементов данных) рядом с только что
   созданным правилом обнаружения Discover JMX object MemoryPool.
7. Теперь нажмите кнопку Create item prototype (Создать прототип элементов данных)
   в правом верхнем углу и заполните страницу информацией, как на рис. 7.41.
