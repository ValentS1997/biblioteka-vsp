120     Глава 3   •  Настройка мониторинга в Zabbix

Создание траппера
Мы сможем сделать много интересного с элементами-трапперами Zabbix, но сперва
разберемся с основами. Для этого создадим новый элемент данных на нашем узле
сети lar-book-agent_simple.

1. Выберите раздел Data collectionHosts (Сбор данныхУзлы сети) и щелкните на
   узле, затем перейдите на страницу Items (Элементы данных). Нажмите кнопку
   Create item (Создать элемент данных), на вкладке Items (Элементы данных) соз
   дайте следующий элемент (рис. 3.36) и нажмите кнопку Add (Добавить).

  Рис. 3.36. Экран настройки приемника траппера элементов данных для lar-book-agent_simple

2. Не забудьте перейти на вкладку Tags (Теги) и добавить тег (рис. 3.37). Позже
  мы будем использовать его для фильтрации.

          Рис. 3.37. Экран настройки тега элемента данных для lar-book-agent_simple
