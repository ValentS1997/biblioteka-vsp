Настройка мониторинга JMX     133

Подготовка
Для работы нам понадобится сервер Zabbix, с помощью которого мы сможем кон
тролировать наше JMX-приложение.

Для примера будет использоваться сервер CentOS 7 с установленным Tomcat.
Использование Tomcat на более поздних версиях CentOS может быть довольно
затруднительно из-за зависимостей пакетов, поэтому для данного примера реко
мендуем использовать CentOS 7. После установки Tomcat добавьте в его конфи
гурацию следующие строки:

JAVA_OPTS="-Djava.rmi.server.hostname=10.16.16.155
-Dcom.sun.management.jmxremote
-Dcom.sun.management.jmxremote.port=12345
-Dcom.sun.management.jmxremote.authenticate=false
-Dcom.sun.management.jmxremote.ssl=false"

Если у вас есть настроенный JMX в продуктивной среде, то можете соответству
ющим образом изменить порт и IP-адрес текущей конфигурации.

Порядок действий
Чтобы настроить JMX-мониторинг, мы добавим на сервер Zabbix узел сети, кото
рый будет следить за нашим Apache Tomcat. Но сначала нужно добавить некоторые
настройки в файл /etc/zabbix/zabbix_server.conf.

1. Отредактируем файл zabbix_server.conf, войдя на хост с Zabbix server и вы
   полнив следующую команду:

   vim /etc/zabbix/zabbix_server.conf

2. Теперь нужно добавить в этот файл следующие строки:

   JavaGateway=127.0.0.1
   StartJavaPollers=5

  СОВЕТ
  Можно установить Java gateway на отдельном хосте в целях масштабирования
   и распределения нагрузки. Просто установите Java gateway на отдельном хосте
   и добавьте IP-адрес этого хоста в параметр JavaGateway. Ваш Zabbix server или
   прокси-сервер должен иметь возможность подключиться к шлюзу по сети через
   порт 10052. В данном примере мы не будем так делать, поэтому установите Java
   gateway рядом с Zabbix server.
