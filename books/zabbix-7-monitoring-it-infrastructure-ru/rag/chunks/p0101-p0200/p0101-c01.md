Настройка мониторинга с помощью Zabbix agent     101

                   Рис. 3.9. Взаимодействие сервера и активного агента

Активный агент отлично подходит для работы в среде, где есть брандмауэр, при
нимающий только исходящие соединения, как это видно со стороны Zabbix agent.
Этот способ используется во многих средах, поскольку позволяет снизить одну
из основных проблем безопасности, которая в основном связана с мониторингом
хостов. Вместо того чтобы разрешать серверу Zabbix доступ ко всем различным
подсетям (что несет большие риски), мы позволяем хостам отправлять данные
в Zabbix — многие к одному, а не один ко многим.

С другой стороны, Zabbix agent в активном режиме может работать намного эф
фективнее. Бо́льшая часть нагрузки, связанной с получением данных на ваш сервер
Zabbix, теперь ложится на Zabbix agent. Поскольку агентов Zabbix больше, чем сер
веров или прокси-серверов Zabbix, то распределение такой нагрузки — отличная идея.

Как вы уже знаете, можно использовать оба типа проверок одновременно, что дает
возможность настроить любой нужный тип проверки. В этом случае настройка
будет выглядеть следующим образом (рис. 3.10).

Этот способ взаимодействия может быть актуален в ситуациях, когда мы хотим
осуществлять мониторинг в основном пассивно, но, например, мониторинг файлов
журналов с помощью Zabbix agent должен выполняться с помощью активного
агента. В этом случае мы можем комбинировать режимы и использовать весь
спектр возможностей, предоставляемых Zabbix agent.
