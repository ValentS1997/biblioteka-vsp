174     Глава 4   •  Работа с триггерами и оповещениями

Если у вас нет этого узла сети, просто подключите новый узел с шаблоном пассив
ного мониторинга Linux под названием Linux by Zabbix agent.

Кроме того, в разделе мы затронем более сложные темы, которые будут рассмотре
ны позже. Например, если вы не знаете, как использовать низкоуровневое обнару
жение (Low-Level Discovery, LLD), то вам стоит изучить главу 7.

Порядок действий
Давайте рассмотрим три триггера, продвинутых по сравнению с теми, которые мы
видели в предыдущем разделе: trendavg для анализа данных тренда, timeleft для
прогнозирования значений в будущем и time shifting для смещения точки вы
числения назад во времени.

Продвинутый триггер 1. Функция trendavg
Сначала рассмотрим новую функцию триггера — функцию усреднения тренда.

1. Начнем с создания нового триггера. Выберите раздел Data collectionHosts
   (Сбор данныхУзлы сети) и выберите узел сети lar-book-agent_passive.
2. Перейдите в раздел Triggers (Триггеры) и нажмите синюю кнопку Create trigger
   (Создать триггер) в правом верхнем углу.
3. Рядом с полем Expression (Выражение) нажмите белую кнопку Add (Добавить).
   Заполните параметры с помощью конструктора выражений (рис. 4.14).

                  Рис. 4.14. Конструктор выражений для функции trendavg

4. Нажмите Insert (Вставить) и добавьте имя. Если все сделано правильно, то фор
   ма будет выглядеть так, как показано на рис. 4.15.
