130     Глава 3   •  Настройка мониторинга в Zabbix

                   Рис. 3.52. Схема работы зависимых элементов данных

  СОВЕТ
   Часто основной элемент данных не нужно сохранять в базе данных, поскольку у нас
   уже есть информация в наших зависимых элементах данных. Если мы не хотим его
   сохранять, то можем выбрать для него параметр Do not keep history (Не хранить
   историю). Это позволит сэкономить место в базе данных.

Создание внешних проверок
Чтобы еще больше расширить функциональность Zabbix, мы можем использовать
пользовательские скрипты, которые можно выполнять как внешние проверки
Zabbix. Не все, что мы хотим отслеживать, всегда будет стандартным в Zabbix, хотя
многое уже есть. Всегда есть что-то, чего может не хватать, и внешние проверки —
это просто способ обойти некоторые из этих проблем.

Подготовка
В этом примере нам понадобится только сервер Zabbix. Мы можем создать элемент
данных для нашего узла сети lar-book-rocky, который является нашим сервером
Zabbix.

Порядок действий
1. Сначала убедимся, что конфигурация Zabbix server настроена правильно. Выпол
   ните следующую команду в интерфейсе командной строки сервера:

   cat /etc/zabbix/zabbix_server.conf | grep ExternalScripts=

2. Эта команда должна показать путь, куда мы поместим скрипт, используемый
   внешней проверкой Zabbix. По умолчанию это /usr/lib/zabbix/externalscripts/.
