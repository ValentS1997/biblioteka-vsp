                         Рис. 4.25. Страница действий триггеров

2. Мы будем настраивать собственные действия, поэтому создадим новое действие,
   чтобы уведомить пользователей из группы Zabbix administrators о срабатывании на
  ших новых триггеров. Нажмите синюю кнопку Create action (Создать действие),
   чтобы перейти на эту страницу (рис. 4.26).

                          Рис. 4.26. Страница создания действия

3. На этой странице установите флажок Enabled (Активировано), чтобы убедиться,
   что действие будет пытаться что-то делать. Обязательно дайте ему понятное
   название, чтобы не путать действия между собой.
4. Теперь перейдите на вкладку Operations (Операции) (рис. 4.27).
5. По умолчанию данная вкладка пуста, поэтому нам нужно добавить несколько
   операций. Здесь есть три вида операций: Operations (Операции), Recovery operations
   (Операции восстановления) и Update operations (Операции обновления). Начнем
   с Operations (Операции), нажав кнопку Add (Добавить) (рис. 4.28).
