Настройка триггеров     163

            Рис. 4.1. Страница создания триггера Service unreachable: Port 22 (SSH)

4. Для проверки работы триггера надо перейти в CLI хоста lar-book-agent_simple
  и запретить все входящие подключения с сервера Zabbix к локальному пор
   ту 22 (SSH). Чтобы это сделать, добавим новое правило iptables:

   iptables -A INPUT -p tcp -i ens192 -s 10.16.16.152
   --destination-port 22 -j DROP

5. Обязательно замените имя сетевой карты ens192 и IP-адрес 10.16.16.152 своими
   значениями. Для получения этой информации можно использовать такую команду:

   ip addr

6. Теперь, если мы щелкнем на Dashboards (Панели) в навигационной панели, то
   через некоторое время увидим следующее (рис. 4.2).
