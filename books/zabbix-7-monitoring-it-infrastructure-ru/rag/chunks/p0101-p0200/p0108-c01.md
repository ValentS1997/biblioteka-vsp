108     Глава 3   •  Настройка мониторинга в Zabbix

2. Затем на Linux-хосте, который мы хотим отслеживать, нужно установить сер
   вер SNMP.

  Для RHEL:

   dnf install net-snmp net-snmp-utils

  Для Ubuntu:

   apt install snmp snmpd libsnmp-dev

3. Теперь настроим нового пользователя SNMPv3 на хосте, который мы хотим от
   слеживать, и настроим сервер так, чтобы мы могли запрашивать информацию:

   net-snmp-create-v3-user -ro -a my_authpass -x my_privpass -A SHA -X AES
   snmpv3user

   Эта команда создаст пользователя SNMPv3 с именем snmpv3user, паролем аутен
  тификации my_authpass и паролем конфиденциальности my_privpass (этот па
   роль используется для шифрования). Пожалуйста, убедитесь, что используете
   надежные пароли в своих продуктивных средах!
4. Убедитесь, что отредактировали файл конфигурации SNMP так, чтобы можно
  было прочитать все объекты SNMP:

   vim /etc/snmp/snmpd.conf

5. Добавьте следующую строку к остальным строкам view systemview:

   view  systemview  included  .1

6. Теперь включите и запустите snmpd, чтобы можно было начать мониторинг
   этого сервера:

   systemctl enable snmpd
   systemctl start snmpd

  Это все, что нужно сделать на стороне Linux-хоста; теперь можно перейти к ин
   терфейсу Zabbix, чтобы настроить узел сети.
7. Выберите раздел Data collectionHosts (Сбор данныхУзлы сети) в интерфейсе
   Zabbix и нажмите кнопку Create host (Создать узел сети) в правом верхнем углу.
  Мы создадим новый узел сети со следующей информацией (рис. 3.17).
8. Перед добавлением узла сети обязательно щелкните на ссылке Add (Добавить)
   в разделе Interfaces (Интерфейсы) и выберите SNMP (рис. 3.18).
   Убедитесь, что ввели правильный IP-адрес и учетные данные узла сети, который
  вы собираетесь отслеживать.
9. Переключитесь на вкладку Macros (Макросы) и добавьте следующую информа
  цию (рис. 3.19).
