6. Нажмите синюю кнопку Add (Добавить) в нижней части страницы, чтобы за
   вершить настройку прототипа триггера.

Теперь у нас есть новый триггер, использующий функцию timeleft, который ста

Продвинутый триггер 3. Сдвиг времени
с помощью математических функций
И наконец, мы поработаем со сдвигом времени, причем в данном случае сделаем это
в сочетании с математической функцией.

1. Выберите раздел Data collectionHosts (Сбор данныхУзлы сети), а затем узел
   сети lar-book-agent_passive.
2. Перейдите в раздел Triggers (Триггеры) и нажмите синюю кнопку Create trigger
   (Создать триггер).
3. На вкладке Trigger (Триггер) добавьте следующий триггер (рис. 4.18).

                Рис. 4.18. Заполненная форма триггера со сдвигом времени

трим.
