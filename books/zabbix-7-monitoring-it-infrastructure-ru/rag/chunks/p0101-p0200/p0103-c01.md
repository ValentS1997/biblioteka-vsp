Настройка SNMP-мониторинга устаревшим способом      103

  При некоторых установках перед выполнением этой команды может потребо
   ваться остановить snmpd. После этого вы можете запустить его снова.
  Эта команда создаст пользователя SNMPv3 с именем snmpv3user, паролем
   аутентификации my_authpass и паролем конфиденциальности my_privpass (этот
   пароль используется для шифрования).
3. Убедитесь, что отредактировали файл конфигурации SNMP так, чтобы можно
  было прочитать все объекты SNMP:

   vim /etc/snmp/snmpd.conf

4. Добавьте следующую строку к существующим строкам view systemview. Если
   их нет, то просто создайте эту новую строку:

   view   systemview   included   .1

5. Теперь включите и запустите snmpd, чтобы можно было начать мониторинг сервера:

   systemctl enable snmpd
   systemctl start snmpd

  Это все, что нужно сделать на стороне Linux-хоста; теперь можно перейти в ин
   терфейс Zabbix, чтобы добавить новый узел сети. Выберите команду меню
   Data collectionHosts (Сбор данныхУзлы сети) в интерфейсе Zabbix и нажмите
   кнопку Create Host (Создать узел сети) в правом верхнем углу.
6. Заполните страницу конфигурации узла сети (рис. 3.11).
