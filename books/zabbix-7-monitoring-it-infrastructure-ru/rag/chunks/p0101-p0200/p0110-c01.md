110     Глава 3   •  Настройка мониторинга в Zabbix

10. Теперь перейдите на вкладку Value mapping (Преобразование значений) и соз
    дайте следующую карту значений (рис. 3.20). Мы будем использовать ее позже.

     Рис. 3.20. Конфигурация хоста Zabbix, вкладка Value mapping (Преобразование значений)
                                  для lar-book-snmp_bulk

11. Теперь вы можете нажать большую кнопку Add (Добавить) в нижней части
    страницы, и узел сети будет создан.
12. На данном этапе мы должны начать создавать наши SNMP-проверки. Но пре
   жде чем это сделать, нужно решить, какие проверки нам нужны. Сделаем запрос
    по SNMP из CLI Linux сервера Zabbix:

    snmpwalk -On -v3 -l authPriv -u snmpv3user -a SHA -A "my_authpass" -x AES
    -X "my_privpass" 192.168.1.86 .1.3.6.1.2.1.2.2.1.2

   Вы увидите примерно такой результат:

    .1.3.6.1.2.1.2.2.1.2.1 = STRING: lo
    .1.3.6.1.2.1.2.2.1.2.2 = STRING: ens192

   Это SNMP-интерфейсы, которые доступны в нашей системе, и мы хотим доба
    вить их для мониторинга. Допустим, мы хотим отслеживать интерфейс ens192.
    Помните, что индекс для него — число 2; оно понадобится нам позже.
   Чтобы добавить всю информацию об интерфейсах в Zabbix, мы будем исполь
    зовать более низкий OID. Однако обратите внимание, что .1.3.6.1.2.1.2.2.1
    содержит всю информацию обо всех интерфейсах.
13. Протестируйте запрос для получения информации обо всех интерфейсах:

    snmpwalk -On -v3 -l authPriv -u snmpv3user -a SHA -A "my_authpass" -x AES
    -X "my_privpass" 192.168.1.86 .1.3.6.1.2.1.2.2.1

    Теперь вы должны увидеть гораздо больше информации.
14. Вернитесь в интерфейс Zabbix, открыв раздел Data collectionHosts (Сбор
   данныхУзлы сети). Затем выберите узел сети lar-book-snmp_bulk и нажмите
    Item (Элемент данных).
