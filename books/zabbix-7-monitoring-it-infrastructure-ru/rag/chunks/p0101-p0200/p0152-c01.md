152     Глава 3   •  Настройка мониторинга в Zabbix

Затем у нас есть несколько функций browser.findElement для перехода в пункт
ReportsSystem information (ОтчетыИнформация о системе). На этой странице
мы хотим найти определенные строки из таблицы. Обратите внимание: помимо
использования браузерного мониторинга для сбора данных о производительности
или проверки того, работает ли пользовательская функциональность, мы можем
использовать его и для извлечения метрик. Мы вернемся к этому в ближайшее
время:

    // Найти и нажать кнопку выхода из системы
    el = browser.findElement("xpath", "//a[contains(text(),'Sign out')]");
    if (el === null) {
        throw Error("cannot find logout button");
    }
    el.click();

    // Собираем данные о производительности после выхода из системы
    browser.collectPerfEntries("logout");

    // Сохраняем результат
    result = browser.getResult();
    result.performanceValue = performanceValue;
    result.totalHosts = totalHosts;
    result.enabledHosts = enabledHosts;
    result.disabledHosts = disabledHosts;
    result.numberOfTemplates = numberOfTemplates;
    result.totalItems = totalItems;
    result.enabledItems = enabledItems;
    result.disabledItems = disabledItems;
    result.nsItems = nsItems;

} catch (err) {
    if (!(err instanceof BrowserError)) {
        browser.setError(err.message);
    }
    result = browser.getResult();
    result.error.screenshot = browser.getScreenshot();
} finally {
    return JSON.stringify(result);
}

Вы должны убедиться, что вышли из системы (лучшая практика — правильно за
вершать любую сессию), и в этот момент вы можете перехватить ошибки и обрабо
тать результаты. На данном этапе мы бы с удовольствием показали вам результат
в формате JSON, но не будем торопиться. Откройте страницу Latest data (Последние
данные) и посмотрите на некоторые записи в формате JSON:

    "duration":1.8088712692260742,
