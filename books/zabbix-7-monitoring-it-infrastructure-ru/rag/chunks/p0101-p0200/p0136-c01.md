136     Глава 3   •  Настройка мониторинга в Zabbix

Настройка мониторинга
базы данных
Многие инженеры воспринимают базы данных как черную дыру: в них записыва
ются данные, и с этими данными что-то происходит. Но как быть, если вы хотите
узнать больше о состоянии вашей базы данных? Для этого можно использовать
мониторинг баз данных в Zabbix.

Подготовка
Для удобства в этом разделе мы будем отслеживать базу данных, которую ис
пользует наш Zabbix server. Это означает, что все, что нам понадобится, — это
установленный сервер Zabbix с базой данных на нем. В этом примере мы будем
использовать MariaDB, так что если у вас есть PostgreSQL, то убедитесь, что вы
установили экземпляр MariaDB на Linux-хосте (хотя такую же настройку можно
создать и для PostgreSQL, если изменить некоторые параметры ODBC).

Порядок действий
Прежде чем приступить к настройке элементов, нужно выполнить некоторые дей
ствия в строке сервера.

1. Начнем с установки необходимых модулей. Выполните следующие команды.
  Для систем на базе RHEL:

   dnf install unixODBC mariadb-connector-odbc

  Для Ubuntu:

   apt install odbc-mariadb unixodbc unixodbc-dev odbcinst

2. Теперь проверим, существуют ли файлы конфигурации ODBC (Open Database
   Connectivity):

   odbcinst -j

  Ваш вывод должен выглядеть примерно так:

   unixODBC 2.3.7
   DRIVERS............: /etc/odbcinst.ini
   SYSTEM DATA SOURCES: /etc/odbc.ini
   FILE DATA SOURCES..: /etc/ODBCDataSources
   USER DATA SOURCES..: /root/.odbc.ini
   SQLULEN Size.......: 8
   SQLLEN Size........: 8
   SQLSETPOSIROW Size.: 8
