156     Глава 3   •  Настройка мониторинга в Zabbix

10. Сохраните файл и перезапустите Zabbix agent:

    systemctl restart zabbix-agent2

11. Через несколько минут ошибка, которую мы заметили в шаге 7, должна исчез
    нуть из интерфейса Zabbix.
12. Выберите раздел MonitoringLatest data (МониторингПоследние данные) и от
    фильтруйте узел сети lar-book-rocky, а также имя нового элемента Get traffic
      statistics from CLI (Получить статистику трафика через интерфейс командной
    строки).
13. Теперь значение должно быть получено с узла сети. Если щелкнуть на History
    (История), то можно увидеть значение целиком; оно должно выглядеть при
   мерно так (рис. 3.86).

                     Рис. 3.86. Результат выполнения команды system.run

14. Информации, которую мы видим здесь, слишком много для одного элемента,
    поэтому нужно разделить ее на части. Мы воспользуемся функцией предва
    рительной обработки, чтобы получить из информации количество принятых
    байтов.
15. Снова выберите раздел Data collectionHosts (Сбор данныхУзлы сети) и щелк
    ните на узле сети Zabbix. Перейдите на страницу Items (Элементы данных)
    этого узла.
16. Щелкните на элементе Get traffic statistics from CLI, чтобы отредактировать его. Из
    мените его название на Total RX traffic in bytes for ens192 и добавьте B в Units
   (Единицы измерения), где B означает байт (рис. 3.87).
17. Не забудьте добавить тег (рис. 3.88).
18. Теперь выберите вкладку Preprocessing (Предобработка) и щелкните на ссылке
    Add (Добавить).
19. Будет добавлено поле Regular expression (Регулярное выражение) (regex). Мы за
   полним его так, чтобы после обработки было получено общее количество байтов
    для вашего интерфейса (рис. 3.89).
