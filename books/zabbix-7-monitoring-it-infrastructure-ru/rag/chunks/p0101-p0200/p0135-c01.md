Объяснение
Для мониторинга JMX-приложений в Zabbix используется Java gateway, рас
положенный либо на самом сервере Zabbix, либо на другом сервере (прокси)
(рис. 3.59).

                     Рис. 3.59. Взаимодействие сервера Zabbix и Java

Zabbix опрашивает Java gateway, а тот, в свою очередь, связывается с JMX-приложе
нием, как это происходит в примере с Tomcat. Затем данные возвращаются по
тому же пути, после чего вы можете увидеть данные в интерфейсе Zabbix.
