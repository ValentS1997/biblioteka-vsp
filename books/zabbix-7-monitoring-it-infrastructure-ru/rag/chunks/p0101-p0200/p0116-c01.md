116     Глава 3   •  Настройка мониторинга в Zabbix

Создание простых проверок
Мы создадим простую проверку, чтобы отслеживать, запущен ли сервис и при
нимает ли он TCP-соединения на определенном порте.

1. Чтобы сделать это, нужно создать новый узел сети в интерфейсе Zabbix. Выбе
   рите раздел Data collectionHosts (Сбор данныхУзлы сети) и нажмите кнопку
   Create host (Создать узел сети) в правом верхнем углу.
2. Создайте узел сети со следующими настройками (рис. 3.29).

              Рис. 3.29. Страница конфигурации узла сети lar-book-agent_simple

3. Теперь выберите раздел Data collectionHosts (Сбор данныхУзлы сети) и перей
   дите на страницу Items (Элементы данных) для вновь созданного узла сети. Для
   создания нового элемента данных нажмите кнопку Create item (Создать элемент
   данных).
  Мы должны создать новый элемент данных с параметрами, как показано на
   рис. 3.30. Для этого нажмите кнопку Add (Добавить) в нижней части страницы.
4. Не забудьте добавить тег к элементу данных, поскольку он будет нужен еще
   в нескольких местах для фильтрации и поиска этого элемента. Настройте его
   так, как показано на рис. 3.31.

  ПРИМЕЧАНИЕ
   Здесь мы добавляем ключ элемента net.tcp.services[ssh,,22]. Порт в данном случае
   необязателен, так как при желании мы можем указать службе SSH другой порт.
