Настройка продвинутых триггеров     175

                         Рис. 4.15. Заполненная форма триггера

5. Теперь нажмите синюю кнопку Add (Добавить) в нижней части страницы, чтобы
   завершить создание этого триггера.

Это все, что нужно для создания этого триггера. Ознакомьтесь с подразделом «Объ
яснение», чтобы получить более подробную информацию о триггере.

Продвинутый триггер 2. Функция timeleft
Следующая функция — timeleft, которая очень полезна для контроля использо
вания дискового пространства.

1. Мы создадим новый триггер. Выберите раздел Data collectionHosts (Сбор
  данныхУзлы сети), а затем узел сети lar-book-agent_passive.
2. Перейдите в раздел Discovery rules (Правила обнаружения) и щелкните на Trigger
    prototype (Прототипы триггеров) рядом с пунктом Mounted filesystem discovery.

  ПРИМЕЧАНИЕ
   В данном случае мы создаем прототип триггера непосредственно на узле сети,
   используя существующее правило обнаружения из шаблона. Если вы хотите при
   менить подобный триггер к каждому узлу сети, использующему шаблон, то убе
   дитесь, что триггер создан на уровне шаблона. Кроме того, правила обнаружения
   подробно рассматриваются в главе 7.

3. Щелкните на Create trigger prototype (Создать прототип триггеров).
4. Рядом с полем Expression (Выражение) нажмите белую кнопку Add (Добавить).
   Заполните триггер с помощью конструктора выражений (рис. 4.16).
