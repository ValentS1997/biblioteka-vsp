118     Глава 3   •  Настройка мониторинга в Zabbix

5. Теперь мы можем посмотреть, принимает ли наш сервер SSH-соединения по
   порту 22. Для этого выберите раздел MonitoringHosts (МониторингУзлы
   сети) и проверьте на странице Latest data (Последние данные) новое значение
   (рис. 3.32).

       Рис. 3.32. Страница Latest data (Последние данные) для узла lar-book-agent_simple

6. Здесь появилась небольшая проблема. Как вы могли заметить, сейчас у нас нет
   настроенного сопоставления значений. Поэтому параметр Last value (Последнее
   значение) просто отображает 1 или 0; из-за этого сложно понять, что это озна
   чает. Чтобы изменить это, снова выберите раздел Data collectionHosts (Сбор
  данныхУзлы сети) и отредактируйте узел lar-book-agent_simple.
7. Перейдите на вкладку Value mapping (Преобразование значений) и нажмите кнопку
   Add (Добавить), чтобы добавить преобразование значений (рис. 3.33).

              Рис. 3.33. Узел сети lar-book-agent_simple, вкладка Value mapping
                               (Преобразование значений)
