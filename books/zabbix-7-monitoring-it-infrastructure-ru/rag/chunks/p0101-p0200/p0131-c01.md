Создание внешних проверок     131

   Создадим новый скрипт test_external в данной папке с помощью следующей
   команды:

   vim /usr/lib/zabbix/externalscripts/test_external

   Добавьте в этот файл следующий код и сохраните его:

   #!/bin/bash
   echo $1

3. Убедитесь, что сервер Zabbix может выполнить скрипт, добавив нужные права
   на файл. Пользователь zabbix на вашем Linux-сервере должен иметь доступ
   к файлу и иметь возможность его выполнить:

   chmod +x /usr/lib/zabbix/externalscripts/test_external
   chown zabbix:zabbix /usr/lib/zabbix/externalscripts/test_
   external

4. Теперь можно перейти к узлу сети, чтобы создать новый элемент данных. От
   кройте раздел Data collectionHosts (Сбор данныхУзлы сети), выберите узел
   lar-book-rocky и нажмите кнопку Create item (Создать элемент данных). Мы
   хотим, чтобы этот элемент данных был создан следующим образом (рис. 3.53).

                     Рис. 3.53. Страница настройки элемента данных

5. Теперь, когда вы добавили этот новый элемент данных, выберите раздел
   MonitoringHosts (МониторингУзлы сети) и проверьте страницу Latest data
   (Последние данные) для узла сети. Переменная Test должна быть возвращена
   скриптом как Last value (Последнее значение) в Zabbix (рис. 3.54).
