150     Глава 3   •  Настройка мониторинга в Zabbix

Рассмотрим некоторые шаги в нашем JavaScript:

try {
    var params = JSON.parse(value); // Разбор строки JSON, переданной из Zabbix
    var webUrl = params.webUrl;
    var username = params.username;
    var password = params.password;

    browser.navigate(webUrl);
    browser.collectPerfEntries("open page");

Начнем с разбора параметров, которые мы задали в интерфейсе Zabbix. Мы не хо
тим использовать просто жестко закодированные имена пользователей и пароли —
мы хотим использовать другие значения, которые могут быть динамическими
в рамках этого скрипта, такие как URL, которые полезно разобрать. Таким образом,
мы задаем гибкость, которая может пригодиться позже, когда мы будем создавать
шаблон для элемента данных:

    // Поиск и заполнение поля с именем пользователя
    var el = browser.findElement("xpath", "//input[@id='name']");
    if (el === null) {
        throw Error("cannot find name input field");
    }
    el.sendKeys(username);

    // Поиск и заполнение поля с паролем
    el = browser.findElement("xpath", "//input[@id='password']");
    if (el === null) {
        throw Error("cannot find password input field");
    }
    el.sendKeys(password);

    // Поиск кнопки входа в систему и ее нажатие
    el = browser.findElement("xpath", "//button[@id='enter']");
    if (el === null) {
        throw Error("cannot find login button");
    }
    el.click();

Затем у нас есть функция browser.findElement. С ее помощью мы найдем нужное
поле, которое необходимо заполнить именем пользователя и паролем, прежде
чем нажмем кнопку входа. С помощью этого типа мониторинга мы преобразуем
JavaScript в то, что похоже на действия пользователя:

    // Собираем данные о производительности после входа в систему
    browser.collectPerfEntries("login");
