 Это все, что нужно для создания простых проверок в Zabbix. Теперь страница с по
 следними данными будет выглядеть следующим образом (рис. 3.35).

       Рис. 3.35. Страница Latest data (Последние данные) для элемента проверки порта 22

 Как видите, теперь есть удобочитаемое значение, отображаемое как Up (Включен/

 щее состояние порта. Теперь рассмотрим элемент данных с типом Zabbix trapper
