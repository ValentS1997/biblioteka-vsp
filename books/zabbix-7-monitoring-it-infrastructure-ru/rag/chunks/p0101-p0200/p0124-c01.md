124     Глава 3   •  Настройка мониторинга в Zabbix

2. Теперь мы можем создать вычисляемый элемент данных, который покажет
   среднее использование памяти за 15 минут. Мы можем использовать это зна
   чение, чтобы определить, насколько наш узел сети был загружен в этот период,
   без необходимости смотреть графики.
3. Нажмите кнопку Create item (Создать элемент данных) и начните создавать
  новый вычисляемый элемент данных. Нам нужно, чтобы у него были такие
   значения (рис. 3.42).

 Рис. 3.42. Страница конфигурации элемента данных, среднее количество используемой памяти

4. Не забудьте перейти на вкладку Tags (Теги) и добавить тег, который будете ис
   пользовать позже для фильтрации (рис. 3.43).
