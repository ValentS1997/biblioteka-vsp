Использование элемента типа browser для имитации веб-пользователя     153

В верхней части JSON вы можете увидеть общую продолжительность выполнения
всего элемента данных:

          {
            "mark":"open page",
            "navigation":{
…
               "transfer_size":4220,
               "duration":0.08759999996423722,
…

Для каждого выполненного шага вы можете увидеть значение mark, которое даст
больше информации о действии, выполненном через браузер:

"performanceValue":"9.46","totalHosts":"23",
"enabledHosts":"18","disabledHosts":"5",
"numberOfTemplates":"287","totalItems":
"1108","enabledItems":"650",
"disabledItems":"241","nsItems":"217"}

И последнее, но не менее важное: в самом низу находятся извлеченные значения
системного отчета Zabbix. Мы собрали всю эту информацию с помощью единствен
ного элемента данных типа browser (рис. 3.81).

                         Рис. 3.81. Полученные элементы данных

С помощью зависимых элементов, о которых вы узнали ранее, можно извлекать
полезные данные из большого объема показателей, сбор которых осуществлялся
с помощью элемента данных типа browser. Так вы получаете четкие и понятные
показатели в одном элементе данных, которые можно использовать в триггерах.
Например, мы можем задействовать эти триггеры, чтобы указать на увеличенную
продолжительность выполнения или определить, сколько сейчас включено узлов
сети и меньше ли это значение, чем раньше.

Как видите, всего один новый тип элемента данных открывает множество новых
возможностей. Можно лишь представить, как сообщество Zabbix будет находить
все больше и больше вариантов использования данного типа и делиться новыми
удивительными шаблонами.
