Работа с вычисляемыми и зависимыми элементами данных     125

5. Теперь, если вы перейдете на страницу MonitoringHosts (МониторингУзлы
   сети) и выберете страницу Latest data (Последние данные), то сможете узнать
   вычисленное значение. Убедитесь, что отфильтровали поле Name (Имя) для
   memory, чтобы увидеть правильные значения (рис. 3.44).

        Рис. 3.44. Страница Latest data (Последние данные) узла lar-book-agent_passive

Как видите, мы вычисляем среднее значение использования памяти за 15 минут
и храним его в отдельном элементе данных.

Работа с зависимыми элементами
Пришло время создать первый зависимый элемент. В этом примере будет исполь
зоваться хост lar-book-rocky, или (как он называется по умолчанию) хост сервера
Zabbix, но можно использовать любой другой сервер баз данных MySQL. Допустим,
мы хотим запросить несколько переменных из нашей базы данных MySQL одним
большим пакетом. В этом случае можно создать зависимые элементы поверх пер
вичного элемента в целях дальнейшей обработки данных.

1. Начнем с создания основной проверки. Выберите раздел Data collectionHosts
   (Сбор данныхУзлы сети), найдите узел сети и нажмите кнопку Create item
   (Создать элемент данных), чтобы начать создавать первый новый элемент.
  Укажите следующие параметры (рис. 3.45).
   Этот элемент является SSH-проверкой, которая подключается к хосту с уста
   новленным сервером баз данных MySQL или MariaDB с помощью SSH, а затем
   выполняет код, введенный в поле Executed script (Выполняемый скрипт). После
   запуска этот код подключится к нашей базе данных MariaDB и выведет ее со
   стояние. Убедитесь, что правильно ввели свои учетные данные.

  СОВЕТ
   Вместо того чтобы использовать учетные данные в открытом виде в команде
   MySQL, что не рекомендуется, используйте макросы в поле Executed script (Вы
   полняемый скрипт). Таким образом, вы сможете использовать макрос типа Secret
    text (Скрытый текст), позволяющий убедиться, что никто не сможет прочитать
   ваш пароль в интерфейсе Zabbix.
