134     Глава 3   •  Настройка мониторинга в Zabbix

3. Кроме того, установим приложение zabbix-java-gateway на наш сервер Zabbix
   с помощью следующей команды.
  Системы на базе RHEL:

   dnf install zabbix-java-gateway
   systemctl enable zabbix-java-gateway
   systemctl start zabbix-java-gateway
   systemctl restart zabbix-server

  Системы Ubuntu:

   apt install zabbix-java-gateway
   systemctl enable zabbix-java-gateway
   systemctl start zabbix-java-gateway
   systemctl restart zabbix-server

  Это все, что нужно было сделать на стороне сервера, чтобы JMX-мониторинг
   заработал. Zabbix не содержит эти настройки по умолчанию, поэтому нужно
   добавить соответствующие параметры в конфигурационный файл и установить
   приложение.
4. Чтобы начать отслеживать наш JMX-хост, выберите раздел Data collectionHosts
   (Сбор данныхУзлы сети) в интерфейсе Zabbix и нажмите Create host (Создать
   узел сети) в правом верхнем углу.
   Добавьте узел сети со следующими настройками (рис. 3.56).
