102     Глава 3   •  Настройка мониторинга в Zabbix

Настройка SNMP-мониторинга
устаревшим способом
Теперь займемся тем, что нам, авторам книги, больше всего нравится в работе
с Zabbix: настроим SNMP-мониторинг (SNMP — Simple Network Management
Protocol, простой протокол управления сетью). Один из нас начинал свою карье
ру в сетевой инженерии и много работал с SNMP, чтобы мониторить различные
сетевые устройства.

Пожалуйста, имейте в виду: в этом разделе мы рассмотрим настройку SNMP-
мониторинга устаревшим способом, но он все еще иногда используется. В Zabbix 6.4
появился совершенно новый способ настройки SNMP-мониторинга. Новый способ
подразумевает пакетный сбор показателей и является более эффективным для
SNMP-устройств, поэтому после выполнения действий, описанных в текущем
разделе, будет полезно ознакомиться и с ним.

Подготовка
Нам понадобятся два хоста Linux, которые мы использовали в предыдущих разделах:

z  хост с установленным Zabbix server;
z  хост, который мы использовали в предыдущем разделе для мониторинга с по
  мощью активного Zabbix agent.
Порядок действий
Мониторинг с помощью опроса SNMP прост и очень эффективен. Мы начнем с на
стройки SNMPv3 на нашем отслеживаемом хосте Linux.

1. Прежде всего, выполним следующие команды для установки SNMP на хост,
   который мы хотим отслеживать с помощью SNMP.
  Для RHEL:

   dnf install net-snmp net-snmp-utils

  Для Ubuntu:

   apt install snmp snmpd libsnmp-dev

2. Теперь создадим нового пользователя SNMPv3, с помощью которого будет
   осуществляться мониторинг нашего хоста. Обратите внимание: мы будем
   использовать небезопасные пароли, поэтому убедитесь, что вы используете
  надежные пароли для своих продуктивных сред. Выполните следующую
   команду:

   net-snmp-create-v3-user -ro -a my_authpass -x my_privpass -A SHA -X AES
   snmpv3user
