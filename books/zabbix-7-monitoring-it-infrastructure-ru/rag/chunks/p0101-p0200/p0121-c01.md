Создание простых проверок Zabbix и Zabbix trapper      121

  Для RHEL:

   dnf -y install zabbix-sender

  Для Ubuntu:

   apt install zabbix-sender

4. После установки мы можем использовать Zabbix sender для отправки некоторой
  информации на наш сервер:

   zabbix_sender -z 10.16.16.152 -s "lar-book-agent_simple" -k trap -o
   "Let's test this book trapper"

  Небольшая расшифровка использованных опций:
     -z — содержит IP-адрес сервера Zabbix,
     -s — указывает имя узла сети, которому принадлежит элемент данных;
     -k — указывает ключ элемента данных, на который отправляются данные;
     -o — само значение элемента данных.
   Теперь мы должны видеть, отправил ли наш Zabbix sender данные на сервер
   Zabbix с указанным ключом элемента данных и получил ли сервер Zabbix этот
   ключ-значение для обработки.
5. Выберите раздел MonitoringHosts (МониторингУзлы сети) и проверьте стра
   ницу Latest data (Последние данные) на наличие нового значения (рис. 3.38).

      Рис. 3.38. Страница Latest data (Последние данные) узла хоста lar-book-agent_simple

Теперь наш траппер принимает данные и отображает их в интерфейсе Zabbix.

Объяснение
Теперь, создав новые элементы, посмотрим, как они работают, погрузившись в тео
ретические основы простых проверок и трапперов Zabbix.

Простые проверки
Простые проверки Zabbix — это список встроенных проверок, которые выполняются
для контроля определенных значений. Список и описание всех простых проверок
доступны в документации Zabbix: https://www.zabbix.com/documentation/current/manual/
config/items/itemtypes/simple_checks.
