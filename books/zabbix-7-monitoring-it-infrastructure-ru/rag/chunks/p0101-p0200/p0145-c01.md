Использование элемента типа browser для имитации веб-пользователя     145

 8. Добавим новый узел сети Zabbix website для мониторинга веб-интерфейса Zabbix
    (рис. 3.70).

               Рис. 3.70. Окно конфигурации мониторинга веб-интерфейса Zabbix

 9. Нажмите кнопку Add (Добавить) в нижней части страницы, чтобы добавить этот
   новый узел сети.
10. Теперь добавим элемент данных в этот узел сети. Щелкните на странице Items
   (Элементы данных) рядом с узлом сети Zabbix website, а затем нажмите кнопку
     Create item (Создать элемент данных) в правом верхнем углу.
11. Чтобы создать элемент, нужно скачать немного JavaScript из репозитория Packt
    GitHub. Вы можете найти его здесь: https://github.com/PacktPublishing/Zabbix-7-IT-
     Infrastructure-Monitoring-Cookbook/blob/main/chapter03/browser_item_script.txt.
12. Теперь заполним поля нового элемента. Убедитесь, что поместили вышеупомя
   нутый скрипт в поле Script (Скрипт). Теперь элемент данных должен выглядеть
   следующим образом (рис. 3.71).
