Настройка мониторинга базы данных      137

3. Если вывод правильный, то отредактируйте файл odbc.ini, чтобы можно было
   подключиться к базе данных:

   vim /etc/odbc.ini

   Теперь введите информацию о базе данных. Она будет выглядеть следующим
   образом:

    [book]
   Description = MySQL book test database
   Driver      = MariaDB
   Server      = 127.0.0.1
   Port        = 3306
   Database    = zabbix

4. Кроме того, проверим, существует ли драйвер:

   vim /etc/odbc.ini

5. Вы должны увидеть информацию о драйвере:

   # Driver from the mariadb-connector-odbc package
   # Setup from the unixODBC package
    [MariaDB]
   Description      = ODBC for MariaDB
   Driver           = /usr/lib/libmaodbc.so
   Driver64         = /usr/lib64/libmaodbc.so
   FileUsage        = 1

6. Теперь проверим, работает ли соединение так, как ожидалось, выполнив сле
  дующую команду:

   isql -v book

  Вы должны получить сообщение Connected. Если этого не произошло, то про
   верьте файлы конфигурации и повторите попытку.
7. Затем перейдите в веб-интерфейс Zabbix, чтобы настроить первую проверку базы
   данных. Выберите раздел Data collectionHosts (Сбор данныхУзлы сети) и щелкни
   те на узле сети lar-book-rocky; обратите внимание, что он все еще может называть
   ся Zabbix server. Теперь перейдите на страницу Items (Элементы данных); мы хотим
   создать новый элемент данных, нажав кнопку Create item (Создать элемент данных).

  СОВЕТ
   Отличный способ сохранить структуру Zabbix — сделать так, чтобы все имена
   узлов сети в Zabbix назывались так же, как реальные имена хостов (hostname).
   Переименуйте свой узел сети с Zabbix server в веб-интерфейсе так, как вы назвали
   свой сервер.
