   СОВЕТ
   Вы можете добавлять зависимые элементы данных самостоятельно, чтобы по
    лучить еще больше статистики из необработанного JSON, который был собран
    основным элементом данных. Не забудьте установить для него значение History
    (История) равным Do not store (Не хранить историю), чтобы сэкономить место
    на диске.

 Объяснение
 Благодаря новому мониторингу через Zabbix browser мы можем использовать
 продвинутый JavaScript в сочетании, например, с Selenium. Вы получаете воз
 можность выполнять практически любые действия, которые может совершать
 обычный пользователь браузера.
