154     Глава 3   •  Настройка мониторинга в Zabbix

Использование предварительной обработки
для изменения значений элементов данных
Предобработка значений элементов — важная функция в Zabbix; ее можно ис
пользовать для создания всевозможных проверок. В этой главе мы уже выполняли
предварительную обработку, но теперь рассмотрим ее более подробно и узнаем,
что она делает.

Начало работы
Для создания проверки понадобится сервер Zabbix, а для получения значений
и их предварительной обработки — пассивный агент Zabbix на Linux-хосте. Для
этого можно использовать агент, запущенный на сервере Zabbix. В нашем случае
это lar-book-rocky.

Порядок действий
1. Войдите в интерфейс Zabbix и выберите раздел Data collectionHosts (Сбор
  данныхУзлы сети).
2. Щелкните на узле сети вашего сервера Zabbix; в нашем случае он называется
   lar-book-rocky.
3. Теперь перейдите на страницу Items (Элементы данных) и нажмите синюю кнопку
    Create item (Создать элемент данных) в правом верхнем углу. На вкладке Item (Эле
   мент данных) создайте новый элемент со следующей информацией (рис. 3.82).

                Рис. 3.82. Получение статистики трафика интерфейса из CLI
