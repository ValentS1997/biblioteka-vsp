Дополнительная информация
Вы можете выполнять множество запросов к базам данных с помощью Zabbix, но
не забывайте, что работаете с реальными запросами. Запрос к базе данных требует
времени на исполнение и некоторых вычислительных мощностей, поэтому струк
турируйте процесс мониторинга базы данных и определяйте подходящее время
для выполнения запросов.

В качестве альтернативы вы можете использовать Zabbix Agent 2 для нативного
мониторинга большинства баз данных. Это может повысить безопасность и про
изводительность, а также снизить сложность.

Настройка мониторинга
с помощью HTTP-агента
С помощью HTTP-агента Zabbix можно следить за веб-страницей или API, получая
оттуда данные. Например, если на веб-странице есть счетчик и мы хотим следить
за его значением, то можем сделать это с помощью HTTP-мониторинга.

Подготовка
Для этого примера нам понадобится веб-страница для мониторинга, а также сервер
Zabbix. Для экспериментов мы будем использовать страницу Zabbix update v1:
https://services.zabbix.com/updates/v1.

Обратите внимание, что для выполнения этого примера серверу Zabbix потребуется
активное подключение к Интернету.

Порядок действий
Для начала опросим веб-страницу из Zabbix, чтобы она показывала последнюю до
ступную версию Zabbix 7.0.

1. Перейдите в веб-интерфейс Zabbix, а затем выберите раздел Data collectionHosts
   (Сбор данныхУзлы сети). Затем щелкните на узле lar-book-agent_simple.
2. Теперь перейдите на страницу Items (Элементы данных). Нажмите кнопку
    Create item (Создать элемент данных) и далее на вкладке Item (Элемент данных)
   создайте элемент с типом HTTP agent (HTTP-агент) (рис. 3.65).
