Использование элемента данных типа browser
в Zabbix для имитации веб-пользователя
В Zabbix появилась возможность отслеживать веб-страницы совершенно новым
способом. Теперь можно использовать новую функциональность Zabbix элемента
данных типа browser (browser items) для имитации действий пользователя браузера
при навигации по вашей веб-странице. Это позволяет перемещаться по страницам,
имитировать щелчки кнопкой мыши по различным элементам, получать содержи
мое страницы и многое другое.

Подготовка
Для этого примера понадобятся только сервер Zabbix и его веб-интерфейс. Обра
тите внимание, что мы будем запускать Selenium в Docker на сервере Zabbix, чтобы
обеспечить работу этого нового типа мониторинга.
