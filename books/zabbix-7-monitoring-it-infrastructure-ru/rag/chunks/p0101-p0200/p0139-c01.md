 Объяснение
 Мониторинг базы данных Zabbix работает путем подключения к вашей базе дан
 ных с помощью ODBC API. Любую базу данных, поддерживаемую ODBC, можно
 опросить с использованием мониторинга базы данных Zabbix (рис. 3.64).
