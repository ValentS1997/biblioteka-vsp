144     Глава 3   •  Настройка мониторинга в Zabbix

К тому же мы воспользуемся предварительно подготовленным JavaScript, кото
рый вы можете найти здесь: https://github.com/PacktPublishing/Zabbix-7-IT-Infrastructure-
Monitoring-Cookbook/blob/main/chapter03/browser_item_script.txt.

Порядок действий
Сначала мы войдем в CLI нашего сервера и начнем подготавливать среду.

1. Воспользуемся легковесным контейнером Docker для запуска Selenium, кото
  рый будет заниматься эмуляцией браузера. Выполните следующие команды
   в CLI сервера Zabbix.
  Для систем на базе RHEL:

   dnf install docker-ce

  Для Ubuntu:

   dnf install docker-ce

2. Не забудьте также запустить Docker:

   systemctl enable docker --now

3. Теперь скачайте и запустите контейнер с Selenium:

   docker run -d -p 4444:4444 -p 7900:7900 --shm-size="2g" selenium/
   standalone-chrome:latest

4. Далее необходимо отредактировать конфигурацию Zabbix server:

   vim /etc/zabbix/zabbix_server.conf

5. В файле конфигурации Zabbix server необходимо отредактировать два новых
   параметра. Параметр WebDriverURL указывает на путь подключения к контей
   неру с Selenium, а StartBrowserPollers определяет количество предварительно
   созданных браузерных пуллеров:

   WebDriverURL=http://localhost:4444
   StartBrowserPollers=2

6. Перезапустите Zabbix server, чтобы изменения вступили в силу:

   systemctl restart zabbbix-server

7. С серверной частью Zabbix разобрались, теперь займемся интерфейсом Zabbix.
   Перейдите в Data collectionHosts (Сбор данныхУзлы сети).
