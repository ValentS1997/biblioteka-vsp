# Глава 6 — source findings

Только принятый **RAG PDF 229–290**. Этот журнал сохраняет утверждения источника, ограничения воспроизводимости и потенциальные ошибки **без автоматической коррекции по памяти или внешней документации**.

## 1. [Source code mismatch] Ubuntu: установка Zabbix web service

- **Вариант A:** на [p0271](../../../rag/chunks/p0201-p0300/p0271-c01.md) приведено `apt install install zabbix-web-service` — в команде повторяется `install`.
- **Вариант B:** той же страницей для RHEL приведено `dnf install zabbix-web-service`; в Ubuntu выше используются `sudo apt-get install google-chrome-stable` и другие формы `apt` без двойного `install`.
- **Следствие:** строка Ubuntu из книги не квалифицируется как проверенная исполнимая команда. Как именно установить сервис для целевой ОС/репозитория: `[Needs confirmation]`. Не делать невидимую правку в `commands.md`.

## 2. [Source wording/code mismatch] Weekly (Ежедневно) и Monday

- **Вариант A:** авторы создают `Weekly overview of the Global view dashboard`, выбирают `Cycle = Weekly` и `Repeat on = Monday`, время 09:00 — [p0272](../../../rag/chunks/p0201-p0300/p0272-c01.md)–[p0273](../../../rag/chunks/p0201-p0300/p0273-c01.md).
- **Вариант B:** в скобках после `Weekly` на p273 написано «Ежедневно», что противоречит Weekly/понедельнику.
- **Следствие:** ожидать именно **еженедельный** режим из английского поля и Monday, но подтверждать актуальное расписание в самой форме; не объявлять исходный перевод корректным. Фактическая частота у настроенного Scheduled report = `[Needs confirmation]`.

## 3. [Needs confirmation] Игнорирование ошибок TLS сертификата PDF web service

- [p0272](../../../rag/chunks/p0201-p0300/p0272-c01.md) требует TLS/SSL frontend и рекомендует Let's Encrypt, но далее предлагает как альтернативу `IgnoreURLCertErrors=1` в `/etc/zabbix/zabbix_web_service.conf`.
- Эта настройка ослабляет проверку сертификата URL. Книга **не содержит** production threat model, безопасной альтернативной процедуры сертификатов или полного rollback.
- **Следствие:** не использовать `IgnoreURLCertErrors=1` как рекомендацию для действующей системы; выбирать валидированный TLS-путь по локальным требованиям. Корректное сочетание `WebServiceURL=https://localhost:10053/report`, конкретного IP, frontend TLS и trust store: `[Needs confirmation]`.

## 4. [Source wording/code mismatch] Имя итогового графика в начале главы

- **Вариант A:** на [p0231](../../../rag/chunks/p0201-p0300/p0231-c01.md) после создания нового обычного графика авторы пишут: «Мы создадим график, который будет показывать Uptime».
- **Вариант B:** на [p0232](../../../rag/chunks/p0201-p0300/p0232-c01.md) после `ping` предлагается найти новый график `Incoming ICMP messages`; подпись рис. 6.5 на [p0233](../../../rag/chunks/p0201-p0300/p0233-c01.md) подтверждает Incoming ICMP messages.
- **Следствие:** название/источник данных обычного графика не выводится как достоверный единственный item без формы рис. 6.4. `RAG_MISS` для точных Graph Items; не замалчивать расхождение.

## 5. [Needs confirmation] Параметры форм на рисунках и внешние ресурсы

- **Графики / карты / dashboard:** поля SNMP item/LLD preprocessing, Graph prototype, map link label/indicator, widget datasets и владельца доступны главным образом через рисунки 6.1–6.55 (p230–258). В тексте подтверждены ключевые понятия, отдельные filters и имена; полная конфигурация = `RAG_MISS`.
- **Инвентаризация / Geomap:** конкретные координаты latitude/longitude, выбор поля `Populates host inventory` и часть настроек tile provider находятся на рис. 6.56–6.67 (p259–265), не в структурированных RAG-chunks → `RAG_MISS`.
- **PDF:** параметры SMTP/web service UI, Frontend URL, подписки из рис. 6.75–6.77 не представлены текстово целиком → `RAG_MISS`. Внешняя ссылка на Packt chapter06 **не открывалась** в режиме RAG-only.
- **Бизнес-сервисы:** точные SLA/tag/trigger expression, Additional rules и иерархия форм на рисунках 6.78–6.107 не воспроизведены вне текста. Подтверждено словами: `If at least 2 child services have High status or above` и базовое `Set status to OK` ([p0287](../../../rag/chunks/p0201-p0300/p0287-c01.md)); остальные поля = `RAG_MISS`.

## 6. [Needs confirmation] Объём изменений и наследование существующих hosts

- **Наблюдение источника:** глобальный `Default host inventory mode = Automatic` применяется **только к новым hosts**. Для ранее существовавших авторы требуют отдельный host-level change или Mass update ([p0259](../../../rag/chunks/p0201-p0300/p0259-c01.md)–[p0260](../../../rag/chunks/p0201-p0300/p0260-c01.md)).
- **Риск:** неверно считать, что инвентаризация всей существующей инфраструктуры включится автоматически после смены глобального default. После правки проверить как минимум один ранее созданный host. Rollback массовых изменений = `[Needs confirmation]`.

## 7. [Needs confirmation] Хранение и рассылка данных, отсутствие отката

Geomap с координатами inventory раскрывает географическое положение hosts ([p0261](../../../rag/chunks/p0201-p0300/p0261-c01.md)–[p0264](../../../rag/chunks/p0201-p0300/p0264-c01.md)).
- Scheduled report использует dashboard snapshot и email подписку ([p0270](../../../rag/chunks/p0201-p0300/p0270-c01.md)–[p0274](../../../rag/chunks/p0201-p0300/p0274-c01.md)); проброс адресатов может распространить технические данные вне ожидаемого круга.
- Глава **не предоставляет полного последовательного rollback** установки сторонних репозиториев/Chrome, web service, политики inventory, рассылок PDF, карт, прав общего владельца и SLA-дерева. `[Needs confirmation]`; не придумывать shell-команды для их отмены.

## 8. [Needs confirmation] Исторический пример SLA — не текущее состояние

На [p0289](../../../rag/chunks/p0201-p0300/p0289-c01.md) Zabbix setup имеет цель **99,9 %** (24×7) и примеры октябрь/ноябрь **2021 года**. Значение 100 % за октябрь — это **данные конкретной учебной среды**, не свежий результат читателя или обещание, что настройка будет выполнять SLA. Сравнивать фактический `Services → SLA report` за нужный период.
