Provenance: [`zabbix-7-monitoring-it-infrastructure-ru:p0033:c01`](../../../rag/chunks/p0001-p0100/p0033-c01.md), [`zabbix-7-monitoring-it-infrastructure-ru:p0034:c01`](../../../rag/chunks/p0001-p0100/p0034-c01.md).

## 2. [Source code mismatch] Различающиеся пути к начальному SQL-архиву

- **Вариант A (обычная установка, PDF p23):** `/usr/share/zabbix-sql-scripts/mysql/server.sql.gz`; импорт в Zabbix БД выполняется через `zcat` и `mariadb --default-character-set=utf8mb4 -u zabbix -p zabbix`. Provenance: [`zabbix-7-monitoring-it-infrastructure-ru:p0023:c01`](../../../rag/chunks/p0001-p0100/p0023-c01.md).
- **Вариант B (HA-рецепт, PDF p34):** `/usr/share/doc/zabbix-sql-scripts/mysql/server.sql.gz`; показано подключение через `mysql --default-character-set=utf8mb4 -u root -p zabbix`. Provenance: [`zabbix-7-monitoring-it-infrastructure-ru:p0034:c01`](../../../rag/chunks/p0001-p0100/p0034-c01.md).
- **Эффект:** различаются путь, пользователь и команда клиента. В книге это два разных сценария; по RAG **невозможно подтвердить**, какой из путей существует после установки пакетов в конкретной ОС/версии. Не объединять строки в единый «исправленный» рецепт.
- **Действие для читателя:** проверить фактическое размещение установленного SQL-архива и выбранные права пользователя перед импортом; статус различия остаётся `[Needs confirmation]`.

## 3. [Needs confirmation] Границы представленной HA-топологии

В HA-рецепте авторы явно используют **одну MariaDB** на `lar-book-ha-db` и указывают, что полноценная отказоустойчивость требует отдельной настройки БД; пример `primary/primary` упомянут без полного руководства по его развёртыванию ([p0032](../../../rag/chunks/p0001-p0100/p0032-c01.md), [p0043](../../../rag/chunks/p0001-p0100/p0043-c01.md)). Это **не установленное противоречие**: ограничение источника, которое нельзя скрыть при описании HA. Полный rollback HA и подтверждение производственной готовности: `[Needs confirmation]`.
