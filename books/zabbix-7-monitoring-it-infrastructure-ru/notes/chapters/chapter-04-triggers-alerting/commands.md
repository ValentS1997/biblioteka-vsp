# Глава 4 — команды, операции GUI и контроль эффектов

**RAG-only**, PDF **161–196**, проверяемые chunks в [README](README.md). Здесь почти вся настройка выполняется в веб-интерфейсе Zabbix; **не выдумывать CLI/API-команды там, где книга показывает только GUI**. Каждый шаг классифицирован: `Read-only`, `Workload-generating` или `State-changing`.

## Триггеры, выражения и проверка условий

| Источниковое действие | Класс | Эффект / риск / верификация |
|---|---|---|
| `Data collection → Hosts → Triggers` — просмотр | Read-only | Посмотреть уже существующие triggers, severity, выражения; [p0162](../../../rag/chunks/p0101-p0200/p0162-c01.md) |
| `Create trigger` / `Add` | State-changing | Создаёт условие PROBLEM, может вызвать события; проверить выбранный host и item, значение и состояние на Dashboard/Problems; полная процедура rollback `[Needs confirmation]`; [p0162](../../../rag/chunks/p0101-p0200/p0162-c01.md) |
| `Expression → Add → Select/Function` | State-changing при сохранении | Подбор функции и item; `Function` раскрывает короткие описания; сохранить только после отдельной оценки условия; [p0166](../../../rag/chunks/p0101-p0200/p0166-c01.md) |
| `Severity` и `Recovery expression` | State-changing | Меняют значение и длительность проблемы: для возврата OK условие PROBLEM=FALSE, восстановления=TRUE; проверить оба; [p0167](../../../rag/chunks/p0101-p0200/p0167-c01.md)–[p0170](../../../rag/chunks/p0101-p0200/p0170-c01.md) |
| `Discovery rules → Mounted filesystem discovery → Trigger prototypes` | State-changing после Add | Создаёт прототип `timeleft` на host или template. На host действует локально; для многих хостов нужен template-level prototype; [p0175](../../../rag/chunks/p0101-p0200/p0175-c01.md) |
| `Expression constructor → Test` | Workload-generating | Вычисляет условие по вручную заданным значениям, не заменяет проверку реального изменения; [p0181](../../../rag/chunks/p0101-p0200/p0181-c01.md)–[p0182](../../../rag/chunks/p0101-p0200/p0182-c01.md) |
| `ip addr` или `ifconfig` | Read-only | Источниковые способы узнать имя интерфейса до настройки trigger; [p0163](../../../rag/chunks/p0101-p0200/p0163-c01.md), [p0165](../../../rag/chunks/p0101-p0200/p0165-c01.md) |

**Выражения, подтверждённые текстом, — не готовые строки для вставки:** `change` (сравнение нового и предыдущего значения); `or` между двумя items; `and` для одновременного выполнения условий; `trendavg`, `timeleft`, time shifting. Формулы конструктора из рисунков 4.1, 4.3, 4.4, 4.14–4.22 доступны в RAG только как подписи, поэтому точный синтаксис каждой формулы = `RAG_MISS` ([p0164](../../../rag/chunks/p0101-p0200/p0164-c01.md)–[p0181](../../../rag/chunks/p0101-p0200/p0181-c01.md)).

**Особая неоднозначность SSH-триггера:** [p0167](../../../rag/chunks/p0101-p0200/p0167-c01.md) явно приводит `1 = UP`, `0 = DOWN`, но [p0168](../../../rag/chunks/p0101-p0200/p0168-c01.md) связывает активацию PROBLEM с значением `1` и нормальным значением `0`. Поэтому нельзя копировать недоказанное правило `last(...)=1` или `last(...)=0` как проверенную формулу; сохранить обе версии и проверить фактический item в окружении. См. [source-findings.md](source-findings.md).

### Сетевой тест из книги — service-disrupting, НЕ готовый рецепт

В учебном примере p163 используется **добавление firewall DROP** для SSH на наблюдаемом хосте:

```sh
# Сохранённый синтаксис книги только для источникового анализа.
# State-changing; блокирует SSH от заданного адреса на заданном интерфейсе.
# Не запускать без out-of-band доступа и заранее проверенного возврата.
iptables -A INPUT -p tcp -i <INTERFACE> -s <ZABBIX_SERVER_IP> --destination-port 22 -j DROP
```

В тексте авторы предлагают заменить `ens192` и `10.16.16.152`; это опасно переносить как реальные настройки. **Эффект:** нарушает сетевую доступность SSH, может заблокировать собственную административную сессию. **Верификация:** наблюдать ожидаемое событие только при контролируемом тестировании, исходное правило не сопровождается доказанной командой rollback: `[Needs confirmation]` ([p0163](../../../rag/chunks/p0101-p0200/p0163-c01.md)).

### Продвинутые триггеры и численные условия

- `trendavg`: книга объясняет часовые агрегаты трендов и период `1w:now-1w` (неделя в прошлом), пример порога **800 Мбит/с** — [p0178](../../../rag/chunks/p0101-p0200/p0178-c01.md). Сравниваемые единицы исходного item/формула из рисунка требуют `[Needs confirmation]`.
- `timeleft`: окно входных данных **7h**, ожидаемое заполнение диска **100%**, горизонт **менее 1w**; короткое исходное окно нельзя бездумно использовать для прогноза далёкого события — [p0176](../../../rag/chunks/p0101-p0200/p0176-c01.md), [p0179](../../../rag/chunks/p0101-p0200/p0179-c01.md).
- Time shift с арифметикой: сравнение средних прошлой и нынешней недели, порог `>20`. В пояснении `80-50=30` → TRUE, `80-70=10` → FALSE; [p0180](../../../rag/chunks/p0101-p0200/p0180-c01.md)–[p0181](../../../rag/chunks/p0101-p0200/p0181-c01.md). В prose p180 есть неоднозначность направления вычитания; см. findings.

## Эффективность и индивидуальные severity

- `Data collection → Hosts → Triggers`: изменить короткое информативное имя, использовать тег `scope` на триггере, тогда как `component` был применён к item; варианты scope в книге: `availability`, `performance`, `notification`, `security`, `capacity`; **State-changing при Update**. Проверять отображение и фильтрацию события ([p0190](../../../rag/chunks/p0101-p0200/p0190-c01.md)–[p0193](../../../rag/chunks/p0101-p0200/p0193-c01.md)).
- `Alerts → Media types → Email → Message templates → Edit`: убрать ненужные поля (в примере идентификатор первоначальной проблемы), настроить компактный текст; изменение шаблона может затронуть множество событий, проверять маршрут и содержимое сообщения ([p0191](../../../rag/chunks/p0101-p0200/p0191-c01.md)–[p0194](../../../rag/chunks/p0101-p0200/p0194-c01.md)).
- `Administration → General → Trigger displaying options → Update`: глобально отобразить severity как P1/P2 вместо прежних `High`/`Disaster`, необязательно для работы Zabbix. Классы книги: Not classified, Information, Warning, Average, High, Disaster. **State-changing**; rollback `[Needs confirmation]` ([p0194](../../../rag/chunks/p0101-p0200/p0194-c01.md)–[p0196](../../../rag/chunks/p0101-p0200/p0196-c01.md)).

**Общий критерий:** наблюдать не только PROBLEM, но и корректный переход OK, точно установленные адресатов/media, получение информации и отсутствие шумных срабатываний. Все недоступные значения помечены `RAG_MISS`/`[Needs confirmation]`.
