Таблица 3.4. У разных инструментов могут быть очень сложные заданные
по умолчанию запросы для одних и тех же критериев

 Инструмент   Запрос (текст частично опущен для краткости)                             Система
                                                                                оценки
 MLflow      Достоверность оценивается только с помощью предоставленных  1–5
            вывода и контекста. Пожалуйста, полностью игнорируй
            предоставленные входные данные при оценке достоверности.
            Показатель достоверности определяет, насколько
            предоставленные результаты фактически соответствуют
            предоставленному контексту…

            Достоверность: далее приведены сведения о различных
            оценках.
            — Оценка 1: ни одно из утверждений в выходных данных
            не может быть выведено из предоставленного контекста.
            — Оценка 2: …
 Ragas       Задача — оценить достоверность серии утверждений на          0 и 1
            основе заданного контекста. Для каждого утверждения нужно
            вывести значение 1, если оно может быть проверено на
            основании контекста, или 0, если не может быть проверено
            на основании контекста
 LlamaIndex   Пожалуйста, укажи, подкреплен ли данный фрагмент            ДА и НЕТ
            информации контекстом.
            Нужно ответить "ДА" или "НЕТ".
            Ответь "ДА", если хоть какой-то фрагмент контекста
            подтверждает информацию, даже если большая часть контекста
            не относится к теме. Далее приведены несколько примеров.

            Информация: яблочный пирог обычно имеет двойную корочку.
            Контекст: яблочный пирог — это фруктовый пирог… Обычно
            он имеет двойную корочку, тесто как сверху, так и снизу
            начинки…
            Ответ: да

Оценки достоверности, выводимые этими тремя инструментами, будут несо
поставимы. Если при наличии пары «контекст, ответ» MLflow выдает оценку
достоверности 3, Ragas — 1, а LlamaIndex — «Нет», какую из них использовать?

Приложение со временем развивается, но способ его оценки в идеале должен
оставаться неизменным. Тогда метрики оценки можно будет задействовать
для мониторинга изменений в приложении. Однако AI-судьи — это тоже AI-
приложения, а значит, и они могут меняться с течением времени.
