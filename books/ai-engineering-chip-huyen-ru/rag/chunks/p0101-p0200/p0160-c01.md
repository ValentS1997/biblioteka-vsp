160        Глава 3. Методология оценки


Допустим, вы просите модель написать на языке Python функцию gcd(num1,
num2), чтобы найти наибольший общий знаменатель (gcd) двух чисел, num1
и num2. Сгенерированный код затем можно ввести в интерпретатор Python, что
бы проверить, корректен ли он и, если да, выводит ли он правильный результат
для данной пары (num1, num2). Например, если при заданной паре (num1=15,
num2=20) функция gcd(15, 20) не выведет 5 (правильный ответ), то вы будете
знать, что она неверна.

Задолго до того, как AI стали использовать для написания кода, автоматическая
проверка функциональной корректности кода была стандартной практикой
в программной инженерии. Код обычно проверяется при помощи модульных
тестов (https://ru.wikipedia.org/wiki/Модульное_тестирование). В них код выполня
ют при различных сценариях, чтобы убедиться, что он генерирует ожидаемые
результаты. Оценка функциональной корректности — это проверка пред
ставленных решений платформами для написания кода, такими как LeetCode
и HackerRank.

Популярные эталонные тесты для оценки возможностей AI по написанию кода,
такие как HumanEval компании OpenAI (https://oreil.ly/CjYs9) и набор данных
с основными задачами на Python — MBPP (Mostly Basic Python Problems
Dataset) корпорации Google (https://github.com/google-research/google-research/tree/
master/mbpp), используют функциональную корректность в качестве метрики.
Эталонные тесты для технологии Text-to-SQL (создания SQL-запросов на ос
нове естественных языков), например Spider (Йу и др., 2018, https://oreil.ly/ijU20),
BIRD-SQL (большой эталонный тест для оценки преобразования текста в SQL
на основе крупных баз данных) (Ли и др., 2023, https://oreil.ly/rrSS9) и WikiSQL
(Цзонг и др., 2017, https://arxiv.org/abs/1709.00103), также учитывают функцио
нальную корректность.

К задаче в эталонных тестах прилагается набор тестовых примеров. Каждый из
них состоит из сценария, выполнение которого должен запустить код, и ожидае
мого результата для этого сценария. Вот пример задачи и ее тестовых примеров
в эталонном тесте HumanEval:
