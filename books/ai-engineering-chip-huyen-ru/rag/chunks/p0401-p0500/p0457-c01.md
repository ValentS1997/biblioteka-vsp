Обработка данных        457


Представьте, что вы применили приведенную далее инструкцию с тремя при
мерами для задачи классификации товаров на съедобные и несъедобные с по
мощью базовой модели:

   Пометь следующие товары как съедобные или несъедобные.

   Товар: гамбургер
   Метка: съедобный

   Товар: автомобиль
   Метка: несъедобный

   Товар: гриб
   Метка: съедобный

   Товар: {INPUT}
   Метка:

Для дообучения все примеры, включенные в запрос с тремя примерами, можно
преобразовать в обучающие примеры. Обучающие данные для дообучения будут
выглядеть как в табл. 8.4.

Таблица 8.4. Пример обучающих данных, используемых для задачи классификации
продуктов питания

 Идентификатор примера         Ввод                       Вывод

 1                          гамбургер -->             съедобный

 2                          автомобиль -->            несъедобный

 3                          гриб -->                  съедобный

…           …           …

После дообучения модели можно задействовать простой запрос, например:

{INPUT} -->

Он намного короче, чем запрос, используемый в базовой модели. Поэтому если
вы переживаете по поводу входных токенов инструкций, то дообучение может
стать одним из способов справиться с расходами.

Различные форматы данных для дообучения могут повлиять на производитель
ность дообученной модели. Стоит поэкспериментировать с разными форматами,
чтобы выявить оптимальный для вашего случая.
