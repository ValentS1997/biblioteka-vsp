## Model API как рабочий интерфейс

| Элемент | Роль | Operational class | Effect / риск | Verification | Rollback |
|---|---|---|---|---|---|
| Вызов API базовой модели | Подход «модель как услуга»: API принимает запрос и возвращает результат модели | workload-generating | Запускает inference у поставщика; глава связывает работу с latency и стоимостью | Получен результат; качество/latency/cost должны оцениваться отдельно | `[Not applicable]` для отдельного запроса |
| API внешнего продукта | Интеграция AI-функции в существующий продукт; примеры: VSCode, Shopify, Microsoft 365 | workload-generating / integration interface | Даёт AI-приложению доступ к функциям внешнего продукта | Способ конкретной проверки зависит от продукта: `[Needs confirmation]` | `[Needs confirmation]` |

Синтаксис конкретных API-вызовов в главе не приводится, поэтому код запросов намеренно не добавлен.
