216       Часть III. Паттерны проектирования систем пакетных вычислений

позволяет использовать контейнер, определяющий цвет, в дру
гих системах для определения цветов других объектов, а не
только автомобилей.

Выходные данные очереди в формате JSON будут выглядеть
примерно следующим образом:

{
  "ТС": {
    "автомобиль": 12,
    "грузовик": 7,
    "мотоцикл": 4
  },
  "цвета": {
    "белый": 8,
    "черный": 3,
    "синий": 6,
    "красный": 6
  }
}

В этих данных представлена информация, найденная в одном
изображении. Чтобы собрать данные воедино, воспользуемся
описанным ранее паттерном Reduce, ставшим популярным бла
годаря MapReduce. Просуммируем все элементы точно так же,
как и в примере с подсчетом. Стадия свертки в качестве резуль
тата выдает итоговое количество образов и цветов, найденных
во всем множестве снимков.
