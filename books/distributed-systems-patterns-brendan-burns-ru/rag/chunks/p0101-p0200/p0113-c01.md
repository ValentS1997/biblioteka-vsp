Глава 6. Шардированные сервисы                     113

      containers:
      - name: twemproxy
        image: ganomede/twemproxy
        command:
        - nutcracker
        - -c
        - /etc/config/shared-nutcracker.yaml
        - -v
        - 7
        - -s
        - 6222
        volumeMounts:
        - name: config-volume
          mountPath: /etc/config
      volumes:
      - name: config-volume
        configMap:
          name: shared-twem-config

Сохраните код в файл с именем shared-twemproxy-deploy.yaml,
затем разверните реплицированный маршрутизатор запросов
шардам с помощью kubectl:

kubectl create -f shared-twemproxy-deploy.yaml

Чтобы завершить развертывание маршрутизатора запросов шар
дам, необходимо создать балансировщик нагрузки, обрабатыва
ющий запросы:

kind: Service
apiVersion: v1
metadata:
  name: shard-router-service
spec:
  selector:
    app: shared-twemproxy
  ports:
    - protocol: TCP
      port: 11211
      targetPort: 11211
