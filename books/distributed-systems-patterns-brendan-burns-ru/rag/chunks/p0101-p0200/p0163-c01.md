Глава 9. Выбор владельца                          163

  // Блокировки не существует, пытаемся записать "1"
  // поверх несуществующего значения
  if error != null {
    locked, l.version, _ = compareAndSwap(l.lockName, "1",
                                          null, l.ttl)
  }
  return locked
}

Функция разблокировки будет выглядеть так:

func (Lock l) unlock() {
  compareAndSwap(l.lockName, "0", "1", l.version)
}

Таким образом, блокировка снимается, только если TTL не
истек.

Практикум. Реализация блокировок в etcd

При реализации блокировок в etcd ключи можно применять
для имен блокировок, а начальные условия записи задавать
таким образом, чтобы в каждый момент времени существовал
только один владелец блокировки. Для простоты поработаем
с утилитой командной строки etcdctl для установки и снятия
блокировки. В действительности же вам следует воспользо
ваться языком программирования. Клиенты etcd есть для всех
популярных языков программирования.

Начнем с создания блокировки my-lock:

kubectl exec my-etcd-cluster-0000 -- sh -c \
  "ETCD_API=3 etcdctl --endpoints=${ETCD_ENDPOINTS} set
   my-lock unlocked"

Это создаст в etcd блокировку my-lock с начальным значением
unlocked.
