Глава 5. Реплицированные сервисы с распределением нагрузки      101

Резюме

Глава начиналась с описания простого паттерна для реплици
рованных stateless-сервисов. Затем мы дополнили его двумя
реплицированными сервисами с балансировщиками нагрузки.
Один выполняет функцию кэширования для повышения про
изводительности, а другой — функцию SSL-моста для обеспе
чения защищенного соединения с клиентами. Полный паттерн
реплицированного stateless-сервиса представлен на рис. 5.8.

Его можно развернуть в Kubernetes с помощью трех объектов
развертывания и трех объектов — сервисов балансировщиков
нагрузки. Полные исходные тексты примеров можно найти по
адресу https://github.com/brendandburns/designing-distributed-systems.
