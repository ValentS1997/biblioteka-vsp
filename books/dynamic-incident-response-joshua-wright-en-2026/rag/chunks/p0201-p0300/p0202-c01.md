①Multiple requests for the FkhDUPZ.php file in the WordPress wp-includes directory return large HTTP response sizes.

By itself, this was not enough to verify that this was an incident, though the engineering team could not
explain the purpose of the strangely named FkhDUPZ.php  file in the WordPress wp-includes directory.
Inspecting the contents of the file revealed the PHP file source code, as shown in Listing 36.

①Obfuscated PHP code (truncated).

Obfuscated code on its own does not establish malicious intent. Legitimate WordPress plugins and themes
occasionally obfuscate source for licensing or intellectual property protection, so the IRT treated the
obfuscation as cause for further review rather than confirmation of compromise.

The IRT computed a SHA-256 hash of FkhDUPZ.php and submitted it to CTI sources, which returned matches
against known PHP webshell families. As corroboration, the team confirmed that FkhDUPZ.php did not appear
in the official WordPress release manifest for the installed version, indicating the file had been added
outside the legitimate update process. With the CTI match and the file-integrity discrepancy together, the
IRT confirmed the report as an incident, escalating the event to involve the broader incident response team
and other company stakeholders and decision-makers.
