CONVENTION              DESCRIPTION

  Constant Width          Used for terminal output and within paragraphs to refer to tools or other
                            technical elements such as variables, function names, statements, keywords,
                               etc.

   |                     The vertical bar is used to indicate steps necessary for navigating through
                      menus (Edit | Paste).

  [...]                 The bracketed ellipsis is used to denote content that has been removed in the
                          output of a tool for space considerations.

            This signifies a general note or consideration.

            This signifies a tip or suggestion.

            This signifies important information to pay special attention to.

Links in the text serve as either internal or external references. Internal references point to other sections
within this book and appear as section titles, such as Chapter 4. External references point to resources
outside the book and appear as labeled links, such as MITRE ATT&CK.

Listing blocks are used to denote output from tools used during our analysis. Content that  is bold
represents commands that are entered to run or interact with a command-line tool. Important outputs are
noted with a numeric circle callout, with details following the listing. An example is shown in Listing 1.

Listing 1 | Sample Terminal Output

  $ tool_name -argument1 -argument2
  Basic output from the tool
  Important output from the tool ①
  Do you wish to continue? yes
  [...] ②

①Denoting an element or a line of importance
②A bracketed ellipsis indicating removed content for space considerations
