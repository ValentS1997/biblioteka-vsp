ASCIIDOC AND ASCIIDOCTOR
This book was written in AsciiDoc and built with Asciidoctor.

If you have spent any time working with AI tools or popular note-taking applications, such as Obsidian, you
have probably encountered Markdown. It is growing rapidly as a simple, readable, and easy-to-learn markup
syntax.

AsciiDoc is similar in spirit to Markdown, but designed for more complex documents. For this book, I
needed cross-references between chapters, footnotes, index generation, admonitions, conditional output
for different formats, custom theming, mathematical notation, and syntax-highlighted code listings, in
addition to the standard markup formatting for headers and lists. AsciiDoc handles all of these things
natively, something that is difficult or impossible to achieve with Markdown.

This book is composed as a collection of .adoc files, mostly one per chapter, plus supporting files for
settings, footnotes, and front matter. From that single set of source files, the Asciidoctor toolchain produces
every output format: PDF, HTML, EPUB, MOBI, and even DOCX. The whole build runs inside a Docker
container, so the process is reproducible on any system with Docker and the make command.

Dan Allen and Sarah White created Asciidoctor and have maintained it under the MIT license for over a
decade. Their care, continued feature development, and dedication to the community, along with the
contributions of many others, have enabled authors, technical writers, and documentation teams to publish
high-quality content without proprietary tools or expensive software. I am grateful to build on the work of
the Asciidoctor community.

It feels fitting that a book published under the Creative Commons license is built entirely on open-source
infrastructure. The tools are free, the source format is an open standard, and the content is openly licensed.
I hope that this combination makes the material in this book accessible to as many people as possible and
encourages others to consider AsciiDoc and Asciidoctor for their own projects. More information on the
Asciidoctor project is available at asciidoctor.org.
