## Operational artifacts explicitly defined by source

| Artifact / concept | Purpose |
|---|---|
| Iteration trigger | сигнал для нового прохода loop |
| Decision documentation | что/когда/кто/почему |
| Impact assessment | влияние response actions на бизнес |
| Stakeholder communication | tailored updates |
| Technical exit indicators | proof of technical resolution |
| Business exit indicators | justification for ending active response |
| Formal exit decision | attributed closure/risk acceptance |

## State-changing actions

Конкретных команд нет.

Chapter 10 ссылается на actions:
- contain;
- eradicate;
- recover;

но implementation details вынесены в отдельные chapters.

## Verification

Source-supported conceptual checks:

- no new IOC;
- monitoring shows no attacker activity;
- eradication verification confirms removal;
- recovered systems function normally;
- leadership accepts residual risk.
