## License boundary

Основной авторский материал книги распространяется по CC BY 4.0.
В переводе обязательны атрибуция, ссылка на лицензию и указание факта
перевода/изменений.

Материалы третьих лиц, прямо исключённые из CC BY 4.0 в исходной книге,
не считаются автоматически разрешёнными к переводу/перераспространению.
Такие элементы должны получать флаг `THIRD_PARTY_REVIEW_REQUIRED`.
