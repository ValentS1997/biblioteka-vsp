Использование текстовых файлов        183

имен пользователей (поле 1), когда числовой идентификатор пользователя
(поле 3) равен 1000 или больше:

$ awk -F: '$3>=1000 {print $1}' /etc/passwd
jones
smith

Затем создадим приветствие, передав его в xargs:

$ awk -F: '$3>=1000 {print $1}' /etc/passwd \
  | xargs -I@ echo "Hi there, @!"
Hi there, jones!
Hi there, smith!

Затем сгенерируем команды (строки) для передачи каждого приветствия ко-
манде mail, которая отправляет электронное письмо данному пользователю
с заданной строкой темы (-s):

$ awk -F: '$3>=1000 {print $1}' /etc/passwd \
  | xargs -I@ echo 'echo "Hi there, @!" | mail -s greetings @'
echo "Hi there, jones!" | mail -s greetings jones
echo "Hi there, smith!" | mail -s greetings smith

Наконец, передаем сгенерированные команды в bash для отправки электронных
писем:

$ awk -F: '$3>=1000 {print $1}' /etc/passwd \
  | xargs -I@ echo 'echo "Hi there, @!" | mail -s greetings @' \
  | bash
echo "Hi there, jones!" | mail -s greetings jones
echo "Hi there, smith!" | mail -s greetings smith

Большинство решений в этой книге начиналось с условия, что существует тексто-
вый файл и его содержимое необходимо обработать с помощью команд. Пришло
время изменить этот подход и научиться формировать новые текстовые файлы,
которые хорошо сочетаются с командами Linux1. Это выигрышная стратегия
для эффективной работы в Linux. Всего четыре шага позволяют добиться этого:

     1. Проанализируйте конкретную задачу обработки данных, которую хотите
       решить.
     2. Сохраните данные в текстовом файле в удобном формате.
     3. Придумайте команды Linux, которые обрабатывают файл и решают задачу.
     4. (Необязательно) Оформите эти команды как сценарии, псевдонимы или
      функции, чтобы упростить их выполнение.

1 Этот подход аналогичен разработке схемы базы данных, которая хорошо работает с извест-
  ными запросами.
