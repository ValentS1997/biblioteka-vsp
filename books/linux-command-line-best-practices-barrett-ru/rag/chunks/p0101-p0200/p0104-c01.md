Объединение текста        105

$ cat title-words2
linux
the
line
$ paste title-words1 title-words2
EFFICIENT    linux
AT  the
COMMAND  line
$ paste title-words1 title-words2 | cut -f2     cut и paste дополняют друг друга
linux
the
line

Измените разделитель на другой символ, например запятую, с помощью пара-
метра -d (delimiter):

$ paste -d, title-words1 title-words2
EFFICIENT,linux
AT,the
COMMAND,line

Измените вывод, поменяв последовательность объединения с помощью пара-
метра -s:

$ paste -d, -s title-words1 title-words2
EFFICIENT,AT,COMMAND
linux,the,line

Команда paste также может чередовать строки из двух или более файлов, если
вы измените разделитель на символ новой строки (\n):

$ paste -d "\n" title-words1 title-words2
EFFICIENT
linux
AT
the
COMMAND
line

Команда diff
Команда diff сравнивает два файла построчно и выводит краткий отчет об их
различиях:

$ cat file1
Linux is all about efficiency.
I hope you will enjoy this book.
$ cat file2
MacOS is all about efficiency.
