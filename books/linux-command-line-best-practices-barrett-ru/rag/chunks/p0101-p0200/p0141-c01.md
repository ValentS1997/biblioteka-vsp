142        Глава 7. Еще 11 способов запуска команды

запускает команду в подоболочке и представляет ее вывод так, как будто он
находится в файле. Например, следующее выражение представляет вывод
ls -1 | sort -n в виде содержимого файла:

<(ls -1 | sort -n)

Вы можете проверить это командой cat:

$ cat <(ls -1 | sort -n)
1.jpg
2.jpg⋮Можно скопировать файл с помощью cp:

$ cp <(ls -1 | sort -n) /tmp/listing
$ cat /tmp/listing
1.jpg
2.jpg
⋮и сравнить один файл с другим. Начните с двух команд, которые создали два
временных файла:

ls *.jpg | sort -n
seq 1 1000 | sed 's/$/.jpg/'

Примените подстановку процессов, чтобы diff мог обрабатывать их как файлы,
и вы получите тот же результат, что и раньше, но без использования временных
файлов:

$ diff <( ls *.jpg | sort -n ) <( seq 1 1000 | sed 's/$/.jpg/' )
3a4
> 4.jpg
979a981
> 981.jpg

Очистите вывод, выполнив поиск строк, начинающихся с >, и удалив первые
два символа с помощью cut. Теперь вы получите отчет о пропавших файлах:

$ diff <(ls *.jpg | sort -n) <(seq 1 1000 | sed 's/$/.jpg/') \
| grep '>' | cut -c3-
4.jpg
981.jpg
