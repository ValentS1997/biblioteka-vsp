186        Глава 9. Использование текстовых файлов

Шаг 3 — написать команды, которые дополнят этот текстовый файл датами
истечения срока действия. Начнем с команды whois, которая запрашивает у ре-
гистратора информацию о домене:

$ whois example.com | less
Domain Name: EXAMPLE.COM
Registry Domain ID: 2336799_DOMAIN_COM-VRSN
Registrar WHOIS Server: whois.iana.org
Updated Date: 2021-08-14T07:01:44Z
Creation Date: 1995-08-14T04:00:00Z
Registry Expiry Date: 2022-08-13T04:00:00Z
⋮Дате истечения срока действия предшествует строка Registry Expiry Date, которую
можно изолировать с помощью grep и awk:

$ whois example.com | grep 'Registry Expiry Date:'
Registry Expiry Date: 2022-08-13T04:00:00Z
$ whois example.com | grep 'Registry Expiry Date:' | awk '{print $4}'
2022-08-13T04:00:00Z

Сделаем дату более читаемой с помощью команды date --date, которая преоб-
разовывает строку даты из одного формата в другой:

$ date --date 2022-08-13T04:00:00Z
Sat Aug 13 00:00:00 EDT 2022
$ date --date 2022-08-13T04:00:00Z +'%Y-%m-%d'       формат ГГГГ-ММ-ДД
2022-08-13

Используем подстановку команд, чтобы передать строку даты из whois в date:

$ echo $(whois example.com | grep 'Registry Expiry Date:' | awk '{print $4}')
2022-08-13T04:00:00Z
$ date \
  --date $(whois example.com \
           | grep 'Registry Expiry Date:' \
           | awk '{print $4}') \
  +'%Y-%m-%d'
2022-08-13

Теперь у нас есть команда, которая запрашивает регистратора и выводит дату
истечения срока действия. Создадим скрипт check-expiry, показанный в ли-
стинге 9.2, который запускает предыдущую команду и выводит на экран дату
истечения срока действия и через символ табуляции — имя домена:

$ ./check-expiry example.com
2022-08-13       example.com
