176        Глава 8. Создание дерзких однострочников

Добавим $HOME/ перед каждым каталогом с помощью sed:

$ (cd && ls -d */) | sed 's/^/$HOME\//g'
$HOME/Family/
$HOME/Finances/
$HOME/Linux/
$HOME/Music/
$HOME/Work/

Синтаксис предыдущего сценария sed усложнен, поскольку строка замены
$HOME/ содержит слеш, а подстановки sed также используют косую черту в ка-
честве разделителя. Вот почему один слеш экранирован: $HOME\/. Вспомните
из раздела «Подстановка и символ слеша» на с. 115, что sed принимает любой
символ в качестве разделителя. Давайте использовать @ вместо косой черты,
тогда экранирование не потребуется:

$ (cd && ls -d */) | sed 's@^@$HOME/@g'
$HOME/Family/
$HOME/Finances/
$HOME/Linux/
$HOME/Music/
$HOME/Work/

Затем уберем последнюю косую черту еще одним выражением sed:

$ (cd && ls -d */) | sed -e 's@^@$HOME/@' -e 's@/$@@'
$HOME/Family
$HOME/Finances
$HOME/Linux
$HOME/Music
$HOME/Work

Выведем результат в одной строке, используя echo и подстановку команд. Об-
ратите внимание, что нам больше не нужны круглые скобки вокруг cd и ls для
явного создания подоболочки, потому что подстановка команд создает соб-
ственную подоболочку:

$ echo $(cd && ls -d */ | sed -e 's@^@$HOME/@' -e 's@/$@@')
$HOME/Family $HOME/Finances $HOME/Linux $HOME/Music $HOME/Work

Добавим в начало каталог $HOME, а в конец родительский каталог ..:

echo '$HOME' \
     $(cd && ls -d */ | sed -e 's@^@$HOME/@' -e 's@/$@@') \
     ..
$HOME $HOME/Family $HOME/Finances $HOME/Linux $HOME/Music $HOME/Work ..
