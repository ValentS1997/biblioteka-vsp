Работа с файлами и каталогами

Выведите список файлов в каталоге (по умолчанию — в вашем текущем каталоге)
с помощью команды ls:

$ ls
animals.txt

Атрибуты файла или каталога можно посмотреть в формате «длинного» (long)
списка (ls -l):

$ ls -l
-rw-r--r-- 1 smith smith 325 Jul 3 17:44 animals.txt

Слева направо выводятся права доступа к файлу (-rw-r—r--), описанные в раз-
деле «Права доступа к файлу» на с. 239, владелец (smith), группа (smith), размер
в байтах (325), дата и время последнего изменения (3 июля этого года, 17:44),
а также имя файла (animals.txt).

По умолчанию ls не печатает информацию о файлах, начинающихся с точки.
Чтобы просмотреть такие файлы, которые часто называют dotfiles или скрытыми,
добавьте параметр -a:

$ ls -a
.bashrc .bash_profile animals.txt

Скопируйте файл с помощью команды cp, указав исходное и новое имена:

$ cp animals.txt beasts.txt
$ ls
animals.txt beasts.txt

Переименуйте файл с помощью команды mv (move), указав исходное и новое
имена:

$ mv beasts.txt creatures.txt
$ ls
animals.txt creatures.txt

Удалите файл с помощью команды rm (remove):

$ rm creatures.txt

           Операция удаления в Linux не имеет дружественного интерфейса. Коман-
             да rm не спрашивает «Вы уверены?», и нет корзины для восстановления
            файлов.
