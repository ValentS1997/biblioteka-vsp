ПРИЛОЖЕНИЕ A
               Памятка по Linux

Если ваши навыки работы с Linux необходимо освежить, в этом приложении
приведен краткий обзор знаний, которые вам понадобятся при чтении этой
книги. Если вы новичок, обзор может оказаться слишком лаконичным, тогда
ознакомьтесь с дополнительной литературой, указанной в конце приложения.

Команды, аргументы и параметры

Чтобы запустить команду Linux в командной строке, введите команду и нажмите
Enter. Чтобы завершить выполняемую команду, нажмите Ctrl-C.

Простая команда Linux состоит из одного слова, которое обычно является
именем программы, за ним следуют дополнительные строки, называемые ар-
гументами. Например, следующая команда состоит из имени программы ls
и двух аргументов:

$ ls -l /bin

Аргументы, начинающиеся с тире, такие как -l, называются параметрами, по-
тому что они изменяют поведение команды. Другими аргументами могут быть
имена файлов, каталогов, пользователей и хостов или любые другие строки,
необходимые программе. Параметры обычно (но не всегда) предшествуют
остальным аргументам.

Параметры команд бывают разных форм, в зависимости от того, какую про-
грамму вы запускаете:
     За параметрами, обозначенными одной буквой с тире, иногда следует
      значение, например -n  10. Обычно пробел между буквой и значением
     может быть опущен: -n10.
