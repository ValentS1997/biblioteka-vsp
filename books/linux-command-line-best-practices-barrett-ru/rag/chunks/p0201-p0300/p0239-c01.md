240        Приложение A. Памятка по Linux

Защитите его от других пользователей:

$ chmod 600 animals.txt
$ ls -l
-rw------- 1 smith smith 325 Jul 3 17:44 animals.txt

Сделайте каталог доступным для чтения и входа для всех, но для записи —
только вам:

$ mkdir dir
$ chmod 755 dir
$ ls -l
drwxr-xr-x 2 smith smith 4096 Oct 1 12:44 dir

Защитите каталог от других пользователей:

$ chmod 700 dir
$ ls -l
drwx------ 2 smith smith 4096 Oct 1 12:44 dir

Обычные разрешения не распространяются на суперпользователя, который
может читать и перезаписывать все файлы и каталоги в системе.

Процессы

При запуске команды Linux запускаются один или несколько процессов Linux,
каждый из которых имеет числовой идентификатор — PID. С помощью команды
ps выведите текущие процессы вашей оболочки:

$ ps
   PID TTY          TIME CMD
  5152 pts/11   00:00:00 bash
117280 pts/11   00:00:00 emacs
117273 pts/11   00:00:00 ps

или все запущенные процессы для всех пользователей:

$ ps -uax

Завершите запущенный вами процесс с помощью команды kill, указав PID
в качестве аргумента. Суперпользователь (администратор Linux) может завер-
шить запущенный процесс любого пользователя.

$ kill 117280
[1]+ Exit 15              emacs animals.txt
