236        Приложение A. Памятка по Linux

Перемещение по каталогам

Ваша командная строка (оболочка) работает в каталоге, называемом текущим,
или рабочим. Просмотрите путь к вашему текущему каталогу с помощью команды
pwd (print working directory):

$ pwd
/home/smith           Домашний каталог пользователя smith

Перемещайтесь между каталогами с помощью команды cd (change directory),
указав путь — абсолютный или относительный — к месту назначения:

$ cd /usr/local       Абсолютный путь
$ cd bin              Относительный путь, ведущий к /usr/local/bin
$ cd ../etc           Относительный путь, ведущий к /usr/local/etc

Создание и редактирование файлов

Редактируйте файлы в стандартном текстовом редакторе Linux, выполнив любую
из следующих команд:

emacs
     После запуска emacs нажмите Ctrl-h, а затем t для обучения.

nano
     Посетите https://nano-editor.org/, чтобы ознакомиться с документацией.

vim или vi
     Запустите команду vimtutor для обучения.

Чтобы создать файл, просто укажите его имя в качестве аргумента — и редактор
создаст его:

$ nano newfile.txt

Другой способ — создать пустой файл с помощью команды touch, указав жела-
емое имя файла в качестве аргумента:

$ touch funky.txt
$ ls
funky.txt
