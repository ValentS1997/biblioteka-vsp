Сопоставление шаблонов имен файлов

В главе 1 вы работали с командами cut, sort и grep, которые могут принимать
одно или несколько имен файлов в качестве аргументов. Например, вы можете
искать слово Linux в сотне файлов с именами от chapter1 до chapter100:

$ grep Linux chapter1 chapter2 chapter3 chapter4 chapter5...

Перечислять множество имен файлов — довольно утомительное занятие.
Поэтому оболочка позволяет использовать специальные символы для со-
кращений, которые применяются к файлам и каталогам. Часто их называют
символами групповых операций, но более общая концепция называется
сопоставлением с шаблоном (pattern matching) или подстановкой (globbing).
Сопоставление с шаблоном — это один из двух наиболее популярных приемов
для повышения скорости работы в Linux (другой прием — нажать клавишу
со стрелкой вверх, чтобы вызвать предыдущую команду оболочки, — мы рас-
смотрим его в главе 3).

В Linux символ звездочки * соответствует любой последовательности (за ис-
ключением начальной точки в именах файлов или каталогов)1 из любого числа
символов в путях к файлам или каталогам:

$ grep Linux chapter*

Остается за кадром, как командная оболочка (не программа grep!) преобразует
шаблон chapter* в список подходящих имен файлов. И только после этого обо-
лочка запускает grep.

Еще один специальный символ — знак вопроса ?, который соответствует любому
единичному символу, за исключением начальной точки в именах файлов или
каталогов. Например, вы можете выполнить поиск слова Linux в главах с 1 по 9,
используя вместо цифр знак вопроса, чтобы командная оболочка смогла найти
совпадения:

$ grep Linux chapter?

Для поиска в главах с 10 по 99 придется использовать два знака вопроса:

$ grep Linux chapter??

1 По этой причине команда ls * не отобразит список так называемых скрытых файлов
  и каталогов (dotfiles), которые начинаются с точки.
