Перенаправление ввода и вывода        45

существует, перенаправление перезапишет его содержимое. Если вы хотите добав-
лять данные в файл, а не перезаписывать его каждый раз, используйте символ >>:

$ grep Perl animals.txt > outfile            Создание или перезапись файла outfile
$ echo There was just one match >> outfile   Добавление записи в конец файла outfile
$ cat outfile
alpaca Intermediate Perl       2012     Schwartz, Randal
There was just one match

Помимо перенаправления вывода, возможно и перенаправление ввода (input
redirection), обеспечивающее стандартный ввод из файла, а не с клавиатуры.
Используйте символ < и имя файла, чтобы перенаправить стандартный ввод.

Многие команды Linux, которые принимают в качестве аргументов имена
файлов и затем считывают данные из них, также могут получать данные из
стандартного ввода. Примером является команда wc для подсчета строк, слов
и символов в файле:

$ wc animals.txt                             Чтение из файла
  7 51 325 animals.txt
$ wc < animals.txt                           Чтение из перенаправленного ввода
  7 51 325

Очень важно понимать, чем отличается поведение этих двух команд wc:
    В первом случае команда wc получает в качестве аргумента имя файла
       animals.txt, поэтому она находит, открывает и читает содержимое файла
     на диске.
     Во втором случае команда wc вызывается без аргументов, поэтому они
     считываются со стандартного ввода. Обычно стандартный ввод выпол-
      няется с клавиатуры, но командная оболочка перенаправляет его. При
     этом wc понятия не имеет о существовании файла animals.txt.
Командная оболочка может перенаправлять ввод и вывод в рамках одной команды:

$ wc < animals.txt > count
$ cat count
  7 51 325

и даже может использовать каналы одновременно. Ниже grep читает из перена-
правленного стандартного ввода и передает результаты в команду wc, которая
перенаправляет стандартный вывод в файл count, создавая его:

$ grep Perl < animals.txt | wc > count
$ cat count
      1       6      47

Такие комбинированные команды будут детально рассмотрены в главе 8, но
примеры перенаправления будут встречаться во всей книге.
