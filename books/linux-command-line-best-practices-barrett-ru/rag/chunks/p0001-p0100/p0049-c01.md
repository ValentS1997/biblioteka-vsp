50        Глава 2. Знакомство с командной оболочкой

Чтобы найти программу в списке каталогов для поиска, используйте команду
which:

$ which cp
/bin/cp
$ which which
/usr/bin/which

или встроенную в оболочку более мощную и информативную команду type, ко-
торая также находит псевдонимы, функции и встроенные в оболочку команды1.

$ type cp
cp is hashed (/bin/cp)
$ type ll
ll is aliased to '/bin/ls -l'
$ type type
type is a shell builtin

Если есть программы с одинаковыми названиями, расположенные в разных ка-
талогах, например /usr/bin/less и /bin/less, оболочка запустит тот файл, который
найдет первым. Используя эту особенность, вы можете переопределить команду,
поместив соответствующий файл в каталог, который будет просматриваться
раньше, например в ваш личный каталог $HOME/bin.

            Путь для поиска и псевдонимы

            Когда оболочка ищет команду по имени, она прежде всего проверяет,
            является ли это имя псевдонимом. Именно поэтому псевдоним затеняет
           команду (имеет более высокий приоритет) с таким же именем.

Путь для поиска — отличный пример того, как можно найти простое объяснение
загадочному явлению. Оболочка не берет команды из воздуха и не находит их
по волшебству. Она методично просматривает каталоги в списке, пока не найдет
запрошенный исполняемый файл.
