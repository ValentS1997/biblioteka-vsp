ЧАСТЬ 2
      Продвинутые навыки

Теперь, когда вы понимаете основы команд, конвейеров, оболочки и навигации
по файловой системе, пришло время сделать шаг вперед. В следующих пяти
главах я познакомлю вас с множеством новых программ для Linux и некоторы-
ми важными концепциями оболочки. Вы научитесь применять их для создания
сложных команд и решения реальных задач на компьютере с Linux.
