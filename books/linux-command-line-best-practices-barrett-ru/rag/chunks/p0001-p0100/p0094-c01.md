Извлечение текста        95

Какая практическая польза от этого? yes может вводить данные для интерактив-
ных программ, чтобы они могли работать без вашего вмешательства. Например,
программа fsck, которая проверяет файловую систему Linux на наличие ошибок,
может спросить пользователя о необходимости продолжения и будет ожидать
ответа y или n. Выходные данные команды yes, переданные в fsck, отвечают на
каждое приглашение от вашего имени, так что вы можете уйти и позволить fsck
выполниться до конца1.

Основное использование команды yes в наших примерах — печать строки опре-
деленное количество раз путем передачи yes в head (вы увидите практический
пример использования в разделе «Создание тестовых файлов» на с. 177):

$ yes "Efficient Linux" | head -n3          Вывести строку 3 раза
Efficient Linux
Efficient Linux
Efficient Linux

Извлечение текста

Когда вам нужна только часть файла, самые простые команды для объединения
в конвейер — это grep, cut, head и tail. Вы уже видели первые три в действии
в главе 1: grep выводит строки, соответствующие заданной строке; cut выводит
столбцы из файла; head выводит первые строки файла. Новая команда tail
является противоположностью head и печатает последние строки файла. На
рис. 5.1 показана совместная работа этих четырех команд.

В этой главе рассмотрим подробно команду grep, которая может делать зна-
чительно больше, чем просто сопоставление строк. Более формально будет
объяснена tail. Также остановимся на функции команды awk для извлечения
столбцов способом, недоступным для cut. Комбинация этих пяти команд может
извлечь практически любой текст с помощью одного конвейера.

1 Некоторые современные реализации fsck имеют опции -y и -n для ответов «да» или «нет»
  на каждое приглашение, поэтому команда yes для них не требуется.
