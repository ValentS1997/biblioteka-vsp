Удаление строк из таблицы

Для удаления строк данных из таблицы используйте оператор
DELETE FROM:

DELETE FROM my_table
WHERE id = 9;

Опустите предложение WHERE, чтобы удалить все строки из
таблицы:

DELETE FROM my_table;

Удаление строк из таблицы также называется усечением
(truncating), при котором все данные в таблице удаляются,
но ее определение не меняется. Таким образом, хоть имена
столбцов и ограничения таблицы по-прежнему существуют,
теперь она пуста.

Чтобы полностью избавиться от таблицы, можно выполнить
оператор DROP.

Отображение, добавление, изменение
и удаление ограничений
Ограничение — это правило, определяющее, какие данные могут
быть вставлены в таблицу. Более подробно о различных типах
ограничений можно прочитать ранее в этой главе, в подразделе
«Создание таблицы с ограничениями».

Отображение ограничений таблицы

В коде, приведенном в табл. 5.15, показано, как отобразить
ограничения таблицы в каждой из РСУБД.

          Oracle хранит имена таблиц и столбцов заглавными буква-
          ми, если только имя столбца не взято в двойные кавычки.
       При обращении к имени таблицы или столбца в операто-
         ре SQL необходимо писать это имя заглавными буквами
        (MY_TABLE).
