126       Глава 5. Создание, обновление и удаление

Код, приведенный в табл. 5.9, загружает файл my_data.csv
в таблицу new_table для каждой РСУБД. При загрузке данных
можно указать дополнительные сведения о них, например:

   данные разделяются запятыми (,);
   текстовые значения берутся в двойные кавычки ("");
   каждая новая строка располагается на новой строке (\n);
   первая строка текстового файла (содержащая заголовок)
   должна быть проигнорирована.

Таблица 5.9. Код для вставки данных из файла .csv

 РСУБД       Код
 MySQL      LOAD DATA LOCAL
            INFILE '<file_path>/my_data.csv'
            INTO TABLE new_table
            FIELDS TERMINATED BY ','
            ENCLOSED BY '"'
            LINES TERMINATED BY '\n'
            IGNORE 1 ROWS;
 Oracle        Хотя это можно сделать в командной строке с помощью
           sqlldr, лучше загружать данные через графический интерфейс
              пользователя, например SQL*Loader или SQL Developer
 PostgreSQL   \copy new_table
                  FROM '<file_path>/my_data.csv'
                  DELIMITER ',' CSV HEADER
 SQL Server   BULK INSERT new_table
            FROM '<file_path>/my_data.csv'
            WITH
            (
                FORMAT = 'CSV',
                FIELDTERMINATOR = ',',
                FIELDQUOTE = '"',
                ROWTERMINATOR = '\n',
                FIRSTROW = 2,
                TABLOCK
            );
 SQLite      .mode csv
            .import <file_path>/my_data.csv
                    new_table --skip 1
