Бинарные типы данных

Этот код создает столбец бинарных данных:

CREATE TABLE my_table (
   my_binary_column BLOB
);

INSERT INTO my_table VALUES
   ('a'),
   ('aaa'),
   ('ae$ iou');

SELECT * FROM my_table;

+--------------------------------------+
| my_binary_column                     |
+--------------------------------------+
| 0x61                                 |
| 0x616161                             |
| 0x61652420696F75                     |
+--------------------------------------+

В MySQL, Oracle и SQLite наиболее распространенным би-
нарным типом данных является BLOB.

В PostgreSQL вместо BLOB следует использовать bytea, а в SQL
Server — VARBINARY (например, VARBINARY(100)).

       В Oracle и SQL Server строка ae$ iou не распознается
         автоматически как бинарное значение и должна быть
         преобразована в такое значение перед вставкой в та-
         блицу.

          -- Oracle
          SELECT RAWTOHEX('ae$ iou') FROM dual;

          -- SQL Server
          SELECT CONVERT(VARBINARY, 'ae$ iou');

В табл. 6.19 перечислены варианты бинарных типов данных
для каждой РСУБД.
