148       Глава 5. Создание, обновление и удаление

Запрашиваем представление:

SELECT * FROM my_view;

id    country  name
---  --------  ------
  1  US        Anna
  2  US        Emily
  3  US        Molly

Отображение существующих представлений

В коде, приведенном в табл. 5.22, показывается, как отобразить
все существующие представления в каждой РСУБД.

Таблица 5.22. Код для отображения существующих представлений

 РСУБД              Код
 MySQL             SHOW FULL TABLES
                  WHERE table_type = 'VIEW';
 Oracle             SELECT view_name
                  FROM user_views;
 PostgreSQL          SELECT table_name
                  FROM information_schema.views
                  WHERE table_schema NOT IN
                        ('information_schema', 'pg_catalog');
 SQL Server          SELECT table_name
                  FROM information_schema.views;
 SQLite             SELECT name
                  FROM sqlite_master
                  WHERE type = 'view';

Обновление представления

Обновить представление означает, иначе говоря, перезаписать
представление. В коде, приведенном в табл. 5.23, показывается,
как обновить представление в каждой РСУБД.
