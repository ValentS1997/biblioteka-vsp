118       Глава 5. Создание, обновление и удаление

Ключевое слово UNIQUE можно поместить сразу после имени
столбца и типа данных:

CREATE TABLE my_table (
   id INTEGER UNIQUE,
   country VARCHAR(2),
   name VARCHAR(15)
);

Или можно поместить ключевое слово UNIQUE после всех имен
столбцов и типов данных:

CREATE TABLE my_table (
   id INTEGER,
   country VARCHAR(2),
   name VARCHAR(15),
   UNIQUE (id)
);

Кроме того, можно включить логику, которая заставляет ком-
бинацию нескольких столбцов быть уникальной. Показанный
ниже код требует уникальных комбинаций country/name,
то есть в одной строке может быть 'CA/Emma', а в другой —
'US/Emma':

CREATE TABLE my_table (
   id INTEGER,
   country VARCHAR(2),
   name VARCHAR(15),
   CONSTRAINT unq_country_name
   UNIQUE (country, name)
);

Создание таблицы с первичными
и внешними ключами

Первичные и внешние ключи — особые типы ограничений,
которые однозначно идентифицируют строки данных.
