      В MySQL допускается использование как диапазонов
        целых чисел со знаком (положительные и отрицатель-
       ные целые числа), так и диапазонов чисел без знака
         (только положительные целые числа). По умолчанию
         используется диапазон целых чисел со знаком. Чтобы
         указать беззнаковый диапазон, используйте следующую
         команду:

          CREATE TABLE my_table (

             my_integer_column INT UNSIGNED

          );

      В PostgreSQL существует тип данных SERIAL, кото-
       рый создает в столбце автоинкрементное целое число
           (1, 2, 3 и т. д.). В табл. 6.5 перечислены параметры SERIAL,
       каждый из которых имеет свой диапазон.
