Обновление столбца данных

Для обновления значений в столбце данных используется
оператор UPDATE ... SET ....

Рассмотрим пример таблицы:

SELECT *
FROM my_table;

id   country   name      awards
---  --------  --------  -------
  2  CA        Celine    5
  3  CA        Michael   4
  4  US        Stefani   9

Чтобы выполнить предварительный просмотр изменений,
которые вы хотите внести, используйте этот код:

SELECT LOWER(name)
FROM my_table;

LOWER(name)
------------
celine
michael
stefani

Обновить значения в столбце данных можно с помощью этого
кода:

UPDATE my_table
SET name = LOWER(name);

SELECT * FROM my_table;

id   country   name      awards
---  --------  --------  -------
  2  CA        celine          5
  3  CA        michael         4
  4  US        stefani         9
