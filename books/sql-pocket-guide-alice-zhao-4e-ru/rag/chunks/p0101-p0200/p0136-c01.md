136       Глава 5. Создание, обновление и удаление

Таблица 5.17 (продолжение)

 РСУБД       Код
 Oracle       ALTER TABLE my_table MODIFY (
            country DEFAULT NULL,
            name VARCHAR2(30)
            );
 PostgreSQL   ALTER TABLE my_table
                  ALTER country DROP DEFAULT,
                  ALTER name TYPE VARCHAR(30);
 SQL Server   ALTER TABLE my_table
                  ALTER COLUMN страна
                  VARCHAR(2) NULL;
            ALTER TABLE my_table
                  ALTER COLUMN name
                  VARCHAR(30) NULL;
 SQLite        См. действия по внесению изменений в SQLite в ручном режиме

Удаление ограничения

В коде, приведенном в табл. 5.18, показано, как удалить огра-
ничение из таблицы в каждой из РСУБД.

Таблица 5.18. Код для удаления ограничения из таблицы

 РСУБД                    Код
 MySQL                   ALTER TABLE my_table
                              DROP CHECK chk_lower_name;
 Oracle, PostgreSQL, SQL Server  ALTER TABLE my_table
                              DROP CONSTRAINT chk_lower_name;
 SQLite                       См. действия по внесению изменений в SQLite
                           в ручном режиме

       В MySQL CHECK можно заменить на DEFAULT, INDEX
         (для ограничения UNIQUE), PRIMARY KEY и FOREIGN
        KEY. Чтобы удалить ограничение NOT NULL, необходимо
         изменить ограничение с помощью оператора MODIFY.
