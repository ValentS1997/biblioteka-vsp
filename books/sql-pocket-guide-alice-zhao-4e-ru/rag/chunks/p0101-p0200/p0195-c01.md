Операции    195

 Операция          Описание
 IN                 Проверяет, содержится ли значение в списке значений
 IS NULL           Проверяет, является ли значение NULL
 LIKE               Проверяет, соответствует ли значение простому шаблону

        Операция LIKE используется для сопоставления простых
         шаблонов, например для поиска текста, начинающегося
          с буквы A. Более подробную информацию можно найти
         ниже, в пункте, посвященном операции LIKE.

         Регулярные выражения используются для сопоставления
         более сложных шаблонов, например для извлечения лю-
          бого текста, расположенного между двумя знаками пре-
         пинания. Более подробную информацию можно найти
         в подразделе «Использование регулярных выражений»
          далее в текущей главе.

Поговорим о каждой операции сравнения ключевых слов
более подробно.

BETWEEN
С помощью BETWEEN можно проверить, попадает ли значение
в определенный диапазон. Эта операция представляет собой
комбинацию >= и <=. Меньшее из двух значений всегда должно
быть записано первым, а операция AND разделяет их.

Найдем все строки, в которых значение столбца age больше
или равно 35 и меньше или равно 44:

SELECT *
FROM my_table
WHERE age BETWEEN 35 AND 44;

Найдем все строки, в которых значение столбца age мень-
ше 35 или больше 44:

SELECT *
FROM my_table
WHERE age NOT BETWEEN 35 AND 44;
