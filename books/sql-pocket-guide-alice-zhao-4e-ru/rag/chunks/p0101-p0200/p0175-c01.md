Данные даты и времени    175

Если столбец содержит время в другом формате, например
mmss, то можно применить функцию преобразования строки
в формат времени, чтобы SQL распознал его как время.

Таблица 6.12. Ссылка на время в запросе

 РСУБД           Код

 MySQL          SELECT TIME '10:30';
               SELECT TIME('10:30');
               SELECT CAST('10:30' AS TIME);

 Oracle          SELECT TIME '10:30:00' FROM dual;
               SELECT CAST('10:30' AS TIME) FROM dual;

 PostgreSQL       SELECT TIME '10:30';
               SELECT CAST('10:30' AS TIME);

 SQL Server       SELECT CAST('10:30' AS TIME);

 SQLite          SELECT TIME('10:30');

Значения даты и времени

Столбец даты и времени должен содержать значения DATETIME
в формате YYYY-MM-DD hh:mm:ss. В Oracle по умолчанию ис-
пользуется формат DDMON-YYYY hh:mm:ss.

Дата 15 октября 2022 года, 10:30, записывается так:

'2022-10-15 10:30'

В Oracle 15 октября 2022 года, 10:30, записывается так:

'15-OCT-2022 10:30'

При ссылке на значение даты и времени в запросе перед стро-
кой необходимо поставить ключевое слово DATETIME, TIMESTAMP
или CAST, чтобы сообщить SQL, что это дата и время, как по-
казано в табл. 6.13.
