Группировка и агрегирование    253

Таблица 8.3. Агрегирование строк в список в каждой РСУБД

 РСУБД      Код                                Разделитель
                                              по умолчанию
 MySQL      GROUP_CONCAT(calories)          Запятая
           GROUP_CONCAT(calories
                        SEPARATOR ',')
 Oracle      LISTAGG(calories)                Нет значения
           LISTAGG(calories, ',')
 PostgreSQL   ARRAY_AGG(calories)              Запятая
 SQL Server   STRING_AGG(calories, ',')       Требуется разделитель
 SQLite      GROUP_CONCAT(calories)          Запятая
           GROUP_CONCAT(calories, ',')

В MySQL, Oracle и SQLite разделитель (',') является не-
обязательным. PostgreSQL не принимает разделитель, а SQL
Server требует его наличия.

Кроме того, можно вернуть отсортированный список или
список уникальных значений.

В табл. 8.4 приведен синтаксис, поддерживаемый каждой
РСУБД.

Таблица 8.4. Возврат отсортированного списка или списка уникальных
значений в каждой РСУБД

 РСУБД     Сортированный список               Уникальный список
 MySQL     GROUP_CONCAT(calories          GROUP_CONCAT(DISTINCT
          ORDER BY calories)             calories)
 Oracle     LISTAGG(calories) WITHIN       LISTAGG(DISTINCT
          GROUP (ORDER BY calories)      calories)
 PostgreSQL  ARRAY_AGG(calories ORDER       ARRAY_AGG(DISTINCT
          BY calories)                   calories)
 SQL Server  STRING_AGG(calories, ',')      Не поддерживается
          WITHIN GROUP (ORDER
          BY calories)
 SQLite     Не поддерживается                GROUP_CONCAT(DISTINCT
                                         calories)
