         возможны, то используйте UNION ALL, чтобы повысить
          производительность. UNION выполняет дополнительную
        скрытую сортировку для выявления дубликатов.

UNION с другими предложениями
При использовании UNION можно задействовать и другие пред-
ложения, такие как WHERE, JOIN и т. д. Однако для всего запроса
допускается только одно предложение ORDER BY, и оно должно
находиться в самом конце.

Отфильтруем значения NULL и отсортируем результаты за-
проса UNION:

SELECT name, origin
FROM staff
WHERE origin IS NOT NULL

UNION

SELECT name, country
FROM residents

ORDER BY name;

+---------+---------+
| name    | origin  |
+---------+---------+
| chidi   | nigeria |
| eleanor | usa     |
| jason   | usa     |
| tahani  | england |
+---------+---------+

UNION с несколькими таблицами
