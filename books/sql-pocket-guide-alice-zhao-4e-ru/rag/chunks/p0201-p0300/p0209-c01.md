Строковые функции    209

Приведем строковый столбец к десятичному, чтобы сравнить
его с числом:

SELECT *
FROM my_table
WHERE CAST(str_col AS DECIMAL) > 3;

id  | str_col
----+---------
2   | 5.5
3   | 7.8

         Использование CAST не приводит к постоянному измене-
       нию типа данных столбца. Чтобы изменить тип не только
         на время выполнения запроса, а навсегда, можно изменить
          таблицу.

Строковые функции

Строковые функции можно применять к столбцам со стро-
ковыми типами данных. В этом разделе рассматриваются
строковые операции, широко используемые в SQL.

Нахождение длины строки

Используем функцию LENGTH.

В предложении SELECT:

SELECT LENGTH(name)
FROM my_table;

В предложении WHERE:

SELECT *
FROM my_table
WHERE LENGTH(name) < 10;

В SQL Server вместо LENGTH используем LEN.
