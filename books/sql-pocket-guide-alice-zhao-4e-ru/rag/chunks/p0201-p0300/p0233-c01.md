Функции даты и времени    233

Таблица 7.18. Количество часов между двумя датами

 РСУБД           Код

 MySQL          SELECT TIMESTAMPDIFF(hour, start_dt, end_dt)
                      AS hour_diff
               FROM   my_table;

 Oracle          SELECT (end_dt - start_dt) AS hour_diff
               FROM   my_table;

 PostgreSQL       SELECT AGE(end_dt, start_dt) AS hour_diff
               FROM   my_table;

 SQL Server       SELECT DATEDIFF(hour, start_dt, end_dt)
                      AS hour_diff
               FROM   my_table;

 SQLite          SELECT ((julianday(end_dt) -
                      julianday(start_dt))*24) AS hour_diff
               FROM   my_table;
