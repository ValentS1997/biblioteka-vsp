204       Глава 7. Операции и функции

Применение математических функций
В SQL существует несколько типов математических вычис-
лений.

  Математические операции. Вычисления, выполняемые
   с помощью символов +, -, *, / и %.
   Агрегатные функции. Вычисления, которые суммируют
   весь столбец данных в одно значение, такие как COUNT, SUM,
   AVG, MIN и MAX.
  Математические функции. Вычисления, выполняемые
   с использованием ключевых слов, применимых к каждой
   строке данных, таких как SQRT, LOG и др., которые перечис-
  лены в табл. 7.10.

         SQLite поддерживает только функцию ABS. Другие ма-
         тематические функции необходимо добавлять вручную.
         Более подробную информацию можно найти на страни-
         це математических функций на сайте SQLite (https://
           oreil.ly/0XwjB).
