260       Глава 8. Расширенные концепции запросов

Ранжируем имена по популярности для каждого пола:

SELECT gender, name,
       ROW_NUMBER() OVER (PARTITION BY gender
       ORDER BY babies DESC) AS popularity
FROM baby_names;

+--------+--------+------------+
| gender | name   | popularity |
+--------+--------+------------+
| F      | Olivia |          1 |
| F      | Emma   |          2 |
| F      | Mia    |          3 |
| M      | Noah   |          1 |
| M      | Liam   |          2 |
| M      | Mateo  |          3 |
+--------+--------+------------+

        ROW_NUMBER В СРАВНЕНИИ С RANK И DENSE_RANK
   Есть три подхода к добавлению номеров строк. Каждый из них по-своему решает
  проблему связей.
  ROW_NUMBER разрывает связь:
  NAME      BABIES   POPULARITY
  -------  -------  ------------
  Olivia        99             1
  Emma          80             2
  Sophia        80             3
  Mia           75             4
  RANK сохраняет ее:
  NAME      BABIES   POPULARITY
  -------  -------  ------------
  Olivia        99             1
  Emma          80             2
  Sophia        80             2
  Mia           75             4
  DENSE_RANK сохраняет связь и не пропускает номера строк:
  NAME      BABIES   POPULARITY
  -------  -------  ------------
  Olivia        99             1
  Emma          80             2
  Sophia        80             2
  Mia           75             3
