236       Глава 7. Операции и функции

Определение дня недели
для заданной даты
Для заданной даты необходимо определить день недели.

   Дата: 2020-03-16.
   Числовой день недели: 2 (воскресенье — первый день).
   День недели: Monday (понедельник).

В коде табл. 7.21 возвращается значение порядкового номера
дня недели для заданной даты. Воскресенье — первый день,
понедельник — второй и т. д.

Таблица 7.21. Извлечение порядкового номера дня недели

 РСУБД       Код                                    Диапазон
                                                     значений
 MySQL      SELECT DAYOFWEEK('2020-03-16');     От 1 до 7
 Oracle       SELECT TO_CHAR(                        От 1 до 7
                   date '2020-03-16', 'd')
            FROM   dual;
 PostgreSQL   SELECT DATE_PART('dow',              От 0 до 6
                    date '2020-03-16');
 SQL Server   SELECT DATEPART(weekday,             От 1 до 7
                   '2020-03-16');
 SQLite      SELECT strftime('%w',                 От 0 до 6
                   '2020-03-16');

В коде табл. 7.22 возвращается день недели для заданной даты.

Таблица 7.22. Возврат дня недели

 РСУБД           Код
 MySQL          SELECT DAYNAME('2020-03-16');
 Oracle          SELECT TO_CHAR(date '2020-03-16', 'day')
               FROM   dual;
