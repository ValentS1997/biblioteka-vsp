Используем функцию LAG(name, 2, 'No name'), чтобы вернуть
имена из двух предыдущих строк и заменить значения NULL
на No name:

SELECT gender, name, babies,
       LAG(name, 2, 'No name')
       OVER (PARTITION BY gender
       ORDER BY babies DESC) AS prior_name_2
FROM baby_names;

+--------+--------+--------+--------------+
| gender | name   | babies | prior_name_2 |
+--------+--------+--------+--------------+
| F      | Olivia |    100 | No name      |
| F      | Emma   |     92 | No name      |
| F      | Mia    |     88 | Olivia       |
| M      | Noah   |    110 | No name      |
| M      | Liam   |    105 | No name      |
| M      | Mateo  |     95 | Noah         |
+--------+--------+--------+--------------+

Функции LAG и LEAD принимают по три аргумента: LAG(name, 2,
'None').

   name — значение, которое вы хотите вернуть. Оно является
   обязательным.
   2 — обозначает смещение строки. Оно необязательно и по
  умолчанию равно 1.
   'No name' — имя, которое будет возвращено в случае от-
   сутствия значения. Оно является необязательным и по
  умолчанию имеет значение NULL.
