288       Глава 9. Работа с несколькими таблицами и запросами

-- пример с UNION
SELECT * FROM writers
UNION
SELECT * FROM artists;

На рис. 9.1 показана разница между результатами JOIN и UNION
на основе приведенного выше кода.

              Рис. 9.1. JOIN в сравнении с UNION

Есть три способа объединить строки двух таблиц. Они также
известны как операции объединения.

   UNION — объединяет результаты нескольких операторов.
   EXCEPT (MINUS в Oracle) — возвращает результаты одного
   оператора за вычетом набора результатов другого.
