             MIN/MAX В СРАВНЕНИИ С LEAST/GREATEST
  Функции MIN и MAX находят наименьшее и наибольшее значения в столбце.
  Функции LEAST и GREATEST находят наименьшее и наибольшее зна-
  чения в строке. Входными данными могут быть числовые, строковые или
  значения даты и времени. Если одно из значений равно NULL, то функция
  возвращает NULL.
  В таблице ниже показано общее количество миль, пройденных в каждом квар-
   тале, а запрос находит наибольшее количество миль, пройденных в конкретном
  квартале:
  SELECT * FROM goat;

  +--------+------+------+------+------+
  | name   | q1   | q2   | q3   | q4   |
  +--------+------+------+------+------+
  | Ali    | 100  | 200  | 150  | NULL |
  | Bolt   | 350  | 400  | 380  | 300  |
  | Jordan | 200  | 250  | 300  | 320  |
  +--------+------+------+------+------+

  SELECT name, GREATEST(q1, q2, q3, q4)
               AS most_miles
  FROM goat;

  +--------+------------+
  | name   | most_miles |
  +--------+------------+
  | Ali    | NULL       |
  | Bolt   | 400        |
  | Jordan | 320        |
  +--------+------------+
