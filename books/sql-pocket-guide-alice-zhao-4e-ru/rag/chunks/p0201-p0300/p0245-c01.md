Операторы CASE

Оператор CASE используется для применения логики IF-ELSE
в запросе. Например, с его помощью можно указать значения.
Если встречается 1, то вывести vip. В противном случае ото-
бразить general admission (общий вход).

+--------+       +-------------------+
| ticket |       | ticket            |
+--------+       +-------------------+
|      1 |       | vip               |
|      0 |  -->  | general admission |
|      1 |       | vip               |
+--------+       +-------------------+

В Oracle можно также встретить функцию DECODE, которая
является более старой функцией, работающей аналогично
оператору CASE.

      С помощью оператора CASE можно обновить значения на
         время выполнения запроса. Для сохранения обновленных
         значений можно использовать оператор UPDATE.
