UNION
Ключевое слово UNION объединяет результаты двух или более
операторов SELECT в один вывод.

Вот две таблицы, которые мы хотели бы объединить:

-- staff
+---------+---------+
| name    | origin  |
+---------+---------+
| michael | NULL    |
| janet   | NULL    |
| tahani  | england |
+---------+---------+

-- residents
+---------+---------+------------+
| name    | country | occupation |
+---------+---------+------------+
| eleanor | usa     | temp       |
| chidi   | nigeria | professor  |
| tahani  | england | model      |
| jason   | usa     | dj         |
+---------+---------+------------+

Используем операцию UNION для объединения двух таблиц
и удаления повторяющихся строк:

SELECT name, origin FROM staff
UNION
SELECT name, country FROM residents;

| chidi   | nigeria |
| jason   | usa     |
