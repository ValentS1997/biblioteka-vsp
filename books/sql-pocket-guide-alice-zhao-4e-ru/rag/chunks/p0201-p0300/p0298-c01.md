298       Глава 9. Работа с несколькими таблицами и запросами

Рекурсивные CTE

В этом подразделе рассматриваются две практические ситуа-
ции, в которых рекурсивное CTE может быть полезным.

Заполнение недостающих строк
в последовательности данных

В этой таблице приведены даты и цены. Обратите внимание,
что в столбце date отсутствуют данные за второе и пятое число
месяца.

SELECT * FROM stock_prices;

+------------+--------+
| date       | price  |
+------------+--------+
| 2021-03-01 | 668.27 |
| 2021-03-03 | 678.83 |
| 2021-03-04 | 635.40 |
| 2021-03-06 | 591.01 |
+------------+--------+

Столбец date заполняется в два этапа:

1) используется рекурсивное CTE для генерации последова-
   тельности дат;

2) соединяется последовательность дат с исходной таблицей.

         приведен синтаксис для каждой РСУБД.
