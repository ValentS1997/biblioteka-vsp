В табл. 7.24 приведен код для преобразования в тип данных
TIME.

Таблица 7.24. Преобразование строки в тип данных TIME

 РСУБД             Требуемый формат    Код
                  времени
 MySQL, PostgreSQL,  hh:mm:ss         SELECT CAST('14:30'
 SQL Server                                  AS TIME);
 Oracle           hh:mm:ss         SELECT CAST('02:30:00 PM'
                                          AS TIME)               hh:mm:ss AM/PM                                   FROM   dual;
 SQLite           hh:mm:ss         SELECT TIME('14:30');

В табл. 7.25 приведен код для преобразования к типу данных
DATETIME.

 Server                               14:30' AS DATETIME);          hh:mm:ss
 Oracle      DD-MON-YYYY            SELECT CAST('15-OCT-20
                                    02:30:00 PM' AS          hh:mm:ss                                    TIMESTAMP)
          DD-MON-YYYY            FROM dual;
          hh:mm:ss AM/PM

                                    14:30' AS TIMESTAMP);          hh:mm:ss

                                    DATETIME('2020-10-15          hh:mm:ss                                    14:30');

Кроме того, с помощью функции CAST можно преобразовывать
даты в числовые и строковые типы данных.
