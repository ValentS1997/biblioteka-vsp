Функции даты и времени    235

И MySQL, и SQL Server поддерживают функции, специфич-
ные для единиц времени, такие как MONTH(), как показано
в табл. 7.19.

  MySQL поддерживает функции YEAR(), QUARTER(), MONTH(),
   WEEK(), DAY(), HOUR(), MINUTE() и SECOND().
  SQL Server поддерживает функции YEAR(), MONTH() и DAY().

Значения month или %m в табл. 7.19 можно заменить другими
единицами времени. В табл. 7.20 перечислены единицы вре-
мени, принятые в каждой из РСУБД.
