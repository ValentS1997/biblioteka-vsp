302       Глава 9. Работа с несколькими таблицами и запросами

   SELECT id, name, name AS lineage
   FROM family_tree
   WHERE parent_id IS NULL
   UNION ALL
   SELECT ft.id, ft.name,
          CONCAT(mc.lineage, ' > ', ft.name)
   FROM family_tree ft
        INNER JOIN my_cte mc
        ON ft.parent_id = mc.id)

SELECT * FROM my_cte ORDER BY id;

+------+---------+-------------------------+
| id   | name    | lineage                 |
+------+---------+-------------------------+
|    1 | Lao Ye  | Lao Ye                  |
|    2 | Lao Lao | Lao Lao                 |

В приведенном выше коде (известном также как иерархиче-
ский запрос) my_cte содержит два объединенных оператора:

   первый оператор SELECT является начальной точкой. Стро-
   ки, в которых parent_id имеет значение NULL, рассматрива-
   ются как корни дерева;
   второй оператор SELECT определяет рекурсивную связь
  между родительской и дочерней строками. Возвращают-
   ся дочерние строки каждого корня дерева и добавляются
   в столбец lineage до тех пор, пока не будет составлена
   полная родословная.

В каждой РСУБД синтаксис различается.
