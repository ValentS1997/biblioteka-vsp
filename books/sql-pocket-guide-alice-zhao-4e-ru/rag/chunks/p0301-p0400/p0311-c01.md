Поиск всех таблиц, содержащих определенное имя столбца    311

+------+---------------+
| name | calories_list |
+------+---------------+
| ally | 80,75,90      |
| jess | 100,92        |
+------+---------------+

Этот код работает в MySQL и SQLite. В других РСУБД за-
мените GROUP_CONCAT(calories) на следующие функции.

   Oracle:
   LISTAGG(calories, ',').
   PostgreSQL:
   ARRAY_AGG(calories).
  SQL Server:
   STRING_AGG(calories, ',').

Поиск всех таблиц, содержащих
определенное имя столбца

Представьте, что у вас есть база данных с большим количе-
ством таблиц. Вы хотите быстро найти все таблицы, которые
содержат имя столбца со словом city.

Решение

В большинстве РСУБД есть специальная таблица, содержа-
щая все имена таблиц и названия столбцов. В табл. 10.1 по-
казано, как сделать запрос к ней в каждой системе.
