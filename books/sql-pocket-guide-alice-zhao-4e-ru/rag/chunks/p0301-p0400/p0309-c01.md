полей в одно

В данном разделе рассматриваются два различных сценария:

   конкатенация текста из полей в одной строке в одно зна-

Конкатенация текста из полей в одной строке
Эта таблица содержит два столбца, которые необходимо объ-
единить:

+----+---------+        +-----------+
| id | name    |        | id_name   |
+----+---------+        +-----------+
|  1 | Boots   |  --->  | 1_Boots   |
|  2 | Pumpkin |        | 2_Pumpkin |
|  3 | Tiger   |        | 3_Tiger   |
+----+---------+        +-----------+

Для объединения значений используем функцию CONCAT или
операцию конкатенации (||):

-- MySQL, PostgreSQL и SQL Server
SELECT CONCAT(id, '_', name) AS id_name
FROM my_table;

-- Oracle, PostgreSQL, и SQLite
SELECT id || '_' || name AS id_name
FROM my_table;
