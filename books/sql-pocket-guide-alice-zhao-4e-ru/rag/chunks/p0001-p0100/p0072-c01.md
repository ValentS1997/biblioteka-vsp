72       Глава 4. Основы работы с запросами

Выбор столбцов

В простейшем предложении SELECT перечисляются имена
одного или нескольких столбцов из таблиц, указанных в пред-
ложении FROM:

SELECT id, name
FROM owner;

id     name
-----  ----------------
    1  Pictured Rocks
    2  Michigan Nature
    3  AF LLC
    4  MI DNR
    5  Horseshoe Falls

Выбор всех столбцов

Чтобы вернуть все столбцы из таблицы, можно не записывать
имя каждого столбца, а использовать одну звездочку (*):

SELECT *
FROM owner;

id     name              phone          type
-----  ----------------  -------------  --------
    1  Pictured Rocks    906.387.2607   public
    2  Michigan Nature   517.655.5655   private
    3  AF LLC private
    4  MI DNR            906.228.6561   public
    5  Horseshoe Falls   906.387.2635   private

         Звездочка — полезное сокращение при тестировании за-
          просов, так как позволяет вам сэкономить много времени
         на вводе текста. Однако использовать ее в производствен-
        ном коде рискованно: столбцы таблицы могут меняться со
         временем, и это приведет к сбою кода, если их окажется
        меньше или больше, чем ожидалось.
