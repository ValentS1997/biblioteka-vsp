Комментарии, кавычки и пробелы
Это знаки препинания, имеющие значение в SQL.

Комментарии
Комментарий — это текст, который игнорируется при выпол-
нении кода, как, например, в следующем примере:

-- Продажи закрыты в 2021 году

Комментарии полезно добавлять в код для того, чтобы другие
рецензенты вашего кода (в том числе и вы сами!) могли быстро
понять назначение кода, не читая его целиком.

Чтобы прокомментировать код, используются:

   одна строка текста:
   -- Это мои комментарии
   несколько строк текста:
   /* Это
   мои комментарии */

Кавычки
В SQL можно использовать два типа кавычек — одинарные
и двойные:

SELECT "This column"
FROM my_table
WHERE name = 'Bob';

   Одиночные кавычки: строки. Посмотрите на слово 'Bob'.
