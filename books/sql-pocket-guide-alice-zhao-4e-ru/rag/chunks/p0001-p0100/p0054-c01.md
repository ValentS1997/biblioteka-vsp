54       Глава 2. Где можно писать SQL-код

        Если вы используете SQL Server, то укажите имя схемы,
         чтобы ограничить количество отображаемых таблиц, —
          dbListTables(con, schema="dbo"). Сочетание dbo означает
         «владелец базы данных» и является схемой по умолчанию
         в SQL Server.

Взгляните на тестовую таблицу в базе данных:

dbReadTable(con, "test")

  id num
1  1 100
2  2 200

       В Oracle имя таблицы чувствительно к регистру. По-
         скольку Oracle автоматически преобразует имена таблиц
         в верхний регистр, то, скорее всего, придется выполнить
        следующую команду: dbRead Table(con, "TEST").

Напишите простой запрос и выведите фрейм данных:

df <- dbGetQuery(con, "SELECT * FROM test
                       WHERE id = 2")
print(df); class(df)

  id num
1  2 200
[1] "data.frame"

Закройте соединение, когда закончите работу с базой данных:

dbDisconnect(con)

В целях экономии ресурсов всегда рекомендуется закрывать
соединение с базой.
