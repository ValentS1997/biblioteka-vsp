Ключевое слово DISTINCT
Если в предложении SELECT указан столбец, то по умолчанию
возвращаются все строки. Для большей ясности можно доба-
вить ключевое слово ALL, но это не обязательно. Эти запросы
возвращают каждую комбинацию type/open_to_public:

SELECT o.type, w.open_to_public
FROM owner o
JOIN waterfall w ON o.id = w.owner_id;
или:
SELECT ALL o.type, w.open_to_public
FROM owner o
JOIN waterfall w ON o.id = w.owner_id;

type      open_to_public
--------  ---------------
public    y
public    y
public    y
private   y
private   y
