ГЛАВА 3
                 Язык SQL

В этой главе рассматриваются основы языка SQL, в том числе
его стандарты, ключевые термины и подъязыки, а также дают-
ся ответы на следующие вопросы:

   что такое ANSI SQL и чем он отличается от SQL;
   что такое ключевое слово и предложение;
  имеют ли значение заглавные буквы и пробелы;
   что находится за пределами оператора SELECT?

Сравнение с другими языками

Некоторые специалисты в сфере технологий не считают SQL
настоящим языком программирования.

Хотя аббревиатура SQL расшифровывается как «язык струк-
турированных запросов» (Structured Query Language), его
нельзя использовать так же, как некоторые другие популярные
языки программирования, например Python, Java или C++.
С помощью этих языков вы можете написать код с указанием
точных действий, которые должен выполнить компьютер,
чтобы решить поставленную задачу. Это называется импера-
тивным программированием.
