# Source findings — глава 2

**Источник:** «SQL. Карманный справочник», Элис Жао, 4-е изд.; PDF 33–54; `p0033:c01`–`p0054:c01`.

## F-01 · [Source wording/code mismatch] · пример адреса удалённой БД

- **Дословный фрагмент:** `123.45.678.90` для удалённого host (`p0043:c01`).
- **Проблема:** октет `678` находится за допустимым диапазоном значения октета IPv4. Эта строка не может использоваться как корректный IPv4-адрес подключения.
- **Действие:** НЕ заменять его «правильным» IP из предположений; в рабочих инструкциях писать `<DB_HOST>` и `[Needs confirmation]`. Это расхождение текста примера с адресным форматом, не ошибка, исправленная внутри канонического RAG.
- **Риск:** невозможность подключения и ложная уверенность, что книжное значение является реальным узлом.

## F-02 · [Source extraction issue] · разделённое имя функции R

- В `p0054:c01` в основном примере стоит `dbReadTable(con, "test")`.
- Ниже в примечании к Oracle текстовый RAG выдаёт `dbRead Table(con, "TEST")` — с пробелом внутри названия функции.
- **Действие:** оба варианта документируются здесь; в `commands.md` воспроизведён только непротиворечивый вариант из основного примера. Источник не исправлен, подтверждение по графическому PDF [Needs confirmation].
- **Риск:** копирование разделённой формы как готовой исполняемой команды.

## F-03 · [Source extraction issue] · рисунок 2.1 недоступен в текстовом RAG

- `p0040:c01` описывает разницу прямого входа через терминал и входа через GUI-клиент с драйвером.
- `p0041:c01` содержит подпись рис. 2.1; собственно графическое изображение не является адресуемым мультимодальным объектом RAG.
- **Действие:** диаграммы `diagram.md`/SVG — концептуальные реконструкции по словам автора, не точные копии рис. 2.1. Детали изображения [Needs confirmation].

## S-01 · проверяемое предупреждение о секретах (не дефект источника)

- `p0046:c01`–`p0048:c01`, `p0052:c01`: соединения в учебных примерах содержат открытый демонстрационный пароль.
- `p0047:c01` прямо предупреждает, что реальные пароли не стоит хранить в сценариях; в `p0048:c01` показан отдельный `db_config.py`, причём книга сама называет этот подход менее безопасным.
- `p0053:c01` показывает альтернативы хранения и запрос пароля через `rstudioapi::askForPassword`.
- **Действие:** буквальные реквизиты учебника заменены placeholders в `commands.md`; не объявлять хранение открытого секрета в `db_config.py` хорошей практикой production. Эта мера — безопасность артефактов, а **не** исправление оригинального текста.

## S-02 · неподтверждённая совместимость версий (не дефект источника)

- `p0049:c01`–`p0050:c01`: пример SQLAlchemy использует `conn.table_names()` и SQLAlchemy URL с учетными данными.
- `p0045:c01`–`p0053:c01`: названия библиотек/драйверов, примеры `pip`, `conda`, `install.packages()`.
- Поддержка синтаксиса, пакетов, драйверов, вариантов аутентификации в фактических современных версиях: **[Needs confirmation]**. В этом `rag_only` артефакте внешняя документация для корректировки не привлекалась.
