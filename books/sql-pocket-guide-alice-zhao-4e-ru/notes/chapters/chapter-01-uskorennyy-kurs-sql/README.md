## Главное в главе

1. **База данных** организованно хранит данные. В книге реляционные SQL-БД описаны через таблицы, строки/столбцы и заранее определённую схему; NoSQL представлен как альтернатива с динамическими схемами и возможностью горизонтального масштабирования (`p0021:c01`–`p0023:c01`).
2. **SQL — язык, а СУБД/РСУБД — программное обеспечение.** SQLite и PostgreSQL не являются «разными SQL», но реализуют SQL со своими особенностями. Примеры ограничения результата различаются для MySQL/PostgreSQL/SQLite, SQL Server и Oracle (`p0023:c01`, `p0024:c01`).
3. **CRUD** — Create, Read, Update, Delete. `SELECT` рассматривается как запрос для чтения; возможность изменять данные требует соответствующего доступа (`p0026:c01`, `p0027:c01`).
4. **Порядок записи** предложений: `SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY`. **Логическая последовательность обработки**, приведённая автором: `FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY`. Это две разные последовательности (`p0028:c01`–`p0030:c01`).
5. **Модель данных** показывает таблицы, поля, первичные/внешние ключи и отношения. Пример: `Students.student_id` — PK; `Grades.student_id` — FK; один студент может иметь много оценок (`p0030:c01`–`p0032:c01`).
