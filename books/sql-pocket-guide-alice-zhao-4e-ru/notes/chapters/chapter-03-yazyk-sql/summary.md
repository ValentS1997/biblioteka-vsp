# Резюме главы 3 из книги (PDF 69)

**Явный исходный раздел:** «КРАТКОЕ ОПИСАНИЕ ЯЗЫКА SQL», `p0069:c01`.  
**Режим:** краткий перенос смысла заключительного раздела по RAG, без дополнений извне и без выдачи за официальный текст.

1. **ANSI SQL** представляет стандартизованную основу языка. Конкретные РСУБД могут реализовывать дополнительные возможности вне этой основы.
2. **Ключевые слова** — встроенные элементы со специальным значением.
3. **Предложения** выделяют части SQL-оператора; основной перечень: `SELECT`, `FROM`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`.
4. **Регистр ключевых слов и форматирование пробелов** в рассмотренных примерах не влияют на смысл запроса, но единый стиль важен для читаемости.
5. **За пределами SELECT** есть SQL-операторы для определения объектов, изменения данных и других задач администрирования базы.

## Provenance и ограничения

- Смысл и последовательность пяти тезисов сохранены из `p0069:c01`; примеры подробнее: `p0057:c01`–`p0068:c01`.
- Фраза книги об одинаковой переносимости стандартного SQL не является независимой проверкой поведения всех актуальных РСУБД; возможные ограничения оговорены в `source-findings.md`.
- Это **summary из главы**, а не современный справочник по версии стандарта SQL.
