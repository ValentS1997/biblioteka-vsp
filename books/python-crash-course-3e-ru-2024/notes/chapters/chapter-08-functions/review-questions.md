## 8.1. Сообщение

Напишите `display_message()`, выводящую сообщение о теме главы, и вызовите её.

## 8.2. Любимая книга

Напишите `favorite_book(title)`, выводящую сообщение с переданным названием любимой книги. Вызовите функцию и проверьте передачу аргумента.

## 8.3. Футболка

Напишите `make_shirt(size, text)`, выводящую размер и текст. Вызовите её один раз позиционными и один раз именованными аргументами.

## 8.4. Большие футболки

Измените `make_shirt()`: размер по умолчанию L, текст по умолчанию «Я люблю Python». Создайте L с default text и футболку другого размера/текста.

## 8.5. Города

Напишите `describe_city(city, country=...)`, задав default country. Вызовите для трёх городов; минимум один должен быть не из страны по умолчанию.

## 8.6. Названия городов

Напишите `city_country(city, country)`, возвращающую строку вида `"Santiago, Chile"`. Проверьте минимум три пары.

## 8.7. Альбом

Напишите `make_album(artist, title)`, возвращающую dictionary. Создайте три альбома. Затем добавьте optional track count с default `None` по формулировке упражнения и сделайте минимум один вызов с количеством дорожек.

## 8.8. Пользовательские альбомы

На основе 8.7 создайте `while`, запрашивающий artist/title, вызывающий `make_album()` и выводящий dictionary. Предусмотрите quit value.

## 8.9. Сообщения

Создайте список коротких сообщений и передайте его `show_messages()`, которая выводит каждое сообщение.

## 8.10. Отправка сообщений

Напишите `send_messages()`, которая выводит каждое сообщение и перемещает его в `sent_messages`. После вызова выведите оба списка.

## 8.11. Архивированные сообщения

Начните с 8.10 и вызовите `send_messages()` так, чтобы функция работала с копией исходного списка. После вызова подтвердите, что original list сохранил все сообщения.

## 8.12. Бутерброды

Напишите функцию с одним variadic parameter для компонентов бутерброда и выводом описания заказа. Вызовите три раза с разным числом arguments.

## 8.13. Профиль

На основе `user_profile.py` создайте собственный profile: first name, last name и три дополнительные пары key/value.

## 8.14. Автомобили

Напишите `make_car(manufacturer, model, **info)`, возвращающую dictionary с обязательными manufacturer/model и произвольными named fields. Проверьте минимум две дополнительные пары.

## 8.15. Печать моделей

Вынесите функции из `print_models.py` в `printing_functions.py`, импортируйте их в основной файл и измените программу на использование imports.

## 8.16. Импортирование

Возьмите одну собственную функцию, сохраните её в отдельном module и вызовите всеми пятью source forms:
- `import module`;
- `from module import function`;
- `from module import function as alias`;
- `import module as alias`;
- `from module import *`.
