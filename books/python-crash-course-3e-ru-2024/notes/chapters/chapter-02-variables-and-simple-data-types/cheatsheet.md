# Шпаргалка главы 2 — Переменные и простые типы данных

## Symptom / problem framing

Глава решает четыре базовые задачи:

1. как хранить и заменять значения через переменные;
2. как обрабатывать строки и числа;
3. как диагностировать `NameError` и `SyntaxError`;
4. как писать более понятный код с комментариями и простыми решениями.

Типовые симптомы:

- переменная «не определена»;
- строка не разбирается из-за кавычек;
- лишние пробелы ломают сравнение;
- числовой результат выглядит неожиданно;
- код работает, но имя/структура затрудняют чтение.

## Baseline / context

- Присваивание связывает имя с текущим значением.
- Повторное присваивание заменяет значение, доступное через имя.
- Имена переменных используют буквы, цифры и `_`, но не начинаются с цифры.
- Пробелы в именах запрещены.
- Строки могут быть в одинарных или двойных кавычках.
- Методы строк возвращают обработанное значение.
- Операция `/` возвращает float даже при делении целых.
- `#` начинает комментарий до конца строки.

## Read-only checks

### Проверка значения переменной

~~~python
message = "Hello Python world!"
print(message)
~~~

Ожидаемый вывод:

~~~text
Hello Python world!
~~~

### Проверка traceback для имени

Source example:

~~~python
message = "Hello Python Crash Course reader!"
print(mesage)
~~~

Ожидаемый тип ошибки: `NameError`; traceback указывает строку с неизвестным именем.

### Проверка строковых методов

~~~python
name = "Ada Lovelace"
print(name.upper())
print(name.lower())
~~~

~~~python
favorite_language = " python "
print(favorite_language.rstrip())
print(favorite_language.lstrip())
print(favorite_language.strip())
~~~

### Проверка удаления префикса

~~~python
nostarch_url = "https://nostarch.com"
print(nostarch_url.removeprefix("https://"))
~~~

### Проверка числовых выражений

~~~python
print(2 + 3)
print(3 - 2)
print(2 * 3)
print(3 / 2)
print(3 ** 2)
~~~

## Interpretation

- `NameError` → имя используется без подходящего присваивания либо записано иначе.
- Одинаково «ошибочное» имя в присваивании и использовании может выполняться: Python требует согласованность имени, а не правильную английскую орфографию.
- `SyntaxError: unterminated string literal` → в source example нарушена граница строки из-за апострофа внутри одинарных кавычек.
- `rstrip()/lstrip()/strip()` сами по себе не изменяют исходное значение переменной.
- Чтобы сохранить очищенную строку, результат нужно присвоить.
- Дополнительные десятичные разряды у float источник объясняет внутренним представлением чисел; глава предлагает пока не углубляться в исправление.
- Если хотя бы один операнд float, результат смешанной арифметической операции тоже float.

## Next action

1. Определить, ошибка относится к имени, строковому синтаксису или данным.
2. Прочитать traceback.
3. Проверить точное имя/кавычки/скобки.
4. Выполнить минимальный выражение или `print()`.
5. Сравнить фактический результат с ожидаемым.
6. Только после этого менять данные/код дальше.

## Modifying action

State-changing внутри программы:

- `message = ...` — создаёт/заменяет связывание переменной;
- `favorite_language = favorite_language.rstrip()` — сохраняет очищенное значение обратно;
- множественное присваивание `x, y, z = 0, 0, 0`;
- редактирование файлов упражнений;
- добавление комментариев.

Перед изменением значения полезно сначала вывести/проверить исходное значение.

## Verification / acceptance checks

- Переменная выводит ожидаемое текущее значение.
- После повторного присваивания вывод меняется на новое значение.
- `title()/upper()/lower()` дают описанный в главе регистр.
- f-строка подставляет значения переменных.
- `strip()` убирает пробелы с обоих краёв возвращаемой строки.
- `removeprefix("https://")` для source example даёт `nostarch.com`.
- Арифметические выражения возвращают показанные source results.
- Комментарий после `#` не выполняется интерпретатором.

## Rollback

Общая процедура rollback для редактирования программ в главе не определена: `[Needs confirmation]`.

Для переменной можно повторным присваиванием установить прежнее значение, если оно известно, но источник не оформляет это как rollback-процедуру.

Для строковых методов без присваивания rollback не требуется: source examples прямо показывают, что исходная переменная остаётся без изменений.

## Operational boundary

Глава посвящена состоянию Python-программы, а не изменению ОС или инфраструктуры. Shell/admin-команд в главе 2 нет. Все операции ниже относятся к интерпретатору Python или учебным файлам.
