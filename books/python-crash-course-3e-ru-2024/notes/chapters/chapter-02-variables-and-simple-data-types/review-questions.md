# Упражнения главы 2

Source range: `e0011:c03`, `e0011:c06–c10`.

## 2.1. Простое сообщение

Сохранить текстовое сообщение в переменной и вывести его на экран.

## 2.2. Простые сообщения

Сохранить сообщение в переменной и вывести его. Затем заменить значение переменной другим сообщением и вывести новое сообщение.

## 2.3. Личное сообщение

Сохранить имя пользователя в переменной и вывести простое персональное сообщение, например приглашение изучать Python.

## 2.4. Регистр символов в именах

Сохранить имя пользователя в переменной и вывести его:
- в нижнем регистре;
- в верхнем регистре;
- с капитализацией начальных букв слов.

## 2.5. Знаменитая цитата

Выбрать понравившееся известное высказывание и вывести цитату вместе с именем автора.

## 2.6. Знаменитая цитата 2

Повторить 2.5, но сохранить имя автора в `famous_person`, сформировать сообщение в переменной `message` и вывести его.

## 2.7. Удаление пробельных символов

Сохранить имя пользователя в переменной, добавить пробельные символы в начале/конце, включая как минимум по одному `\t` и `\n`. Вывести исходное значение, затем результаты `lstrip()`, `rstrip()`, `strip()`.

## 2.8. Расширения файлов

Присвоить `filename` значение `'python_notes.txt'` и использовать `removesuffix()`, чтобы вывести имя без расширения.

## 2.9. Число 8

Написать четыре строки с операциями сложения, вычитания, умножения и деления, результат которых — число 8; вывести результаты через `print()`.

## 2.10. Любимое число

Сохранить любимое число в переменной, сформировать сообщение с этим числом и вывести его.

## 2.11. Добавление комментариев

Выбрать две ранее написанные программы и добавить в каждую хотя бы один комментарий. Если содержательного комментария нет, источник предлагает указать имя и текущую дату в начале кода, затем кратко описать назначение программы.

## 2.12. Дзен Python

Ввести `import this` в терминальном сеансе Python и просмотреть другие принципы.
