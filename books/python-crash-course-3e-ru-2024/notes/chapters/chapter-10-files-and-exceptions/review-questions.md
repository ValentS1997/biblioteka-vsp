## 10.1. Изучение Python

Создайте `learning_python.txt` с несколькими строками, каждая начинается «В Python вы можете…». Напишите программу, которая выводит содержимое двумя способами:
- читая весь файл;
- сохраняя строки в список и перебирая их.

## 10.2. Изучение C

Прочитайте строки `learning_python.txt`, замените `Python` названием другого языка, например `C`, через `replace()`, и выведите изменённые строки.

## 10.3. Более простой код

Уберите временную переменную `lines` из программ раздела и перебирайте напрямую:

~~~python
for line in contents.splitlines():
~~~

## 10.4. Гость

Запросите имя пользователя и сохраните введённый ответ в `guest.txt`.

## 10.5. Гостевая книга

В цикле `while` запрашивайте имена пользователей. Для каждого имени:
- выведите приветствие;
- добавьте отдельную строку сообщения в `guest_book.txt`.

## 10.6. Сложение

Запросите два числа, сложите и выведите результат. Если одно из значений не преобразуется через `int()`, перехватите `ValueError` и выведите понятное сообщение. Проверить numeric и text input cases.

## 10.7. Калькулятор

Source формулировка требует поместить предыдущий сценарий сложения в `while`, чтобы после ошибочного text input пользователь мог продолжить ввод. Source cross-reference указывает «код из упражнения 10.5»; это зарегистрировано как mismatch.

## 10.8. Кошки и собаки

Создайте `cats.txt` и `dogs.txt`, минимум по три имени. Программа должна читать оба файла. Обработайте `FileNotFoundError`; переместите один файл и подтвердите выполнение `except`.

## 10.9. Ошибки без уведомления

Измените file-missing scenario так, чтобы программа продолжала работу без user notification. Source cross-reference к 10.7 зарегистрирован как mismatch.

## 10.10. Распространенные слова

Возьмите тексты Project Gutenberg, посчитайте `'the'` через `count()`, затем `'the '`, сравните результаты. В режиме `rag_only` внешние тексты не загружались.

## 10.11. Любимое число

Одна программа сохраняет любимое число через JSON, другая читает его и выводит сообщение.

## 10.12. Сохраненное любимое число

Объедините 10.11: если число уже сохранено — показать; иначе запросить и сохранить. Запустить дважды.

## 10.13. Словарь пользователя

Расширьте `remember_me.py`: запросите ещё два вида информации, сохраните всё в dictionary через JSON, затем прочитайте и выведите summary.

## 10.14. Проверка пользователя

Перед приветствием спросите, верно ли определено сохранённое имя. При отрицательном ответе вызовите `get_new_username()`.

Нумерация и требования сохранены по RAG; source cross-reference mismatches помечены явно.
