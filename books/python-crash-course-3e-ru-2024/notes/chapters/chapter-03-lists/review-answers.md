# Разбор упражнений главы 3

Это RAG-grounded решения/шаблоны, а не официальный ключ издателя. Персональные значения не выдумываются.

## 3.1. Имена

Имена друзей: `[Needs confirmation]`.

~~~python
names = ['[имя1]', '[имя2]', '[имя3]']

print(names[0])
print(names[1])
print(names[2])
~~~

## 3.2. Сообщения

~~~python
names = ['[имя1]', '[имя2]', '[имя3]']

print(f"Привет, {names[0]}!")
print(f"Привет, {names[1]}!")
print(f"Привет, {names[2]}!")
~~~

Конкретные имена: `[Needs confirmation]`. f-строки уже введены в главе 2 и используются в главе 3 для сообщений с элементами списка.

## 3.3. Собственный список

Любимый вид транспорта и конкретные модели: `[Needs confirmation]`.

Шаблон механики:

~~~python
transport = ['[пример1]', '[пример2]', '[пример3]']
print(f"Я хотел бы купить {transport[0]}.")
~~~

## 3.4. Список гостей

Конкретные гости: `[Needs confirmation]`.

~~~python
guests = ['[гость1]', '[гость2]', '[гость3]']

print(f"{guests[0]}, приглашаю вас на обед.")
print(f"{guests[1]}, приглашаю вас на обед.")
print(f"{guests[2]}, приглашаю вас на обед.")
~~~

## 3.5. Изменение списка гостей

Кто не сможет прийти и кто его заменит: `[Needs confirmation]`.

Source-supported механика замены по индексу:

~~~python
guests = ['[гость1]', '[гость2]', '[гость3]']

print(guests[1])
guests[1] = '[новый гость]'

print(guests)
~~~

После замены следует снова вывести приглашения для текущих элементов списка.

## 3.6. Больше гостей

Новые гости и точный индекс «середины»: `[Needs confirmation]`.

~~~python
guests.insert(0, '[новый гость в начале]')
guests.insert([индекс середины], '[новый гость в середине]')
guests.append('[новый гость в конце]')
~~~

Источник требует затем вывести новое приглашение каждому элементу текущего списка.

## 3.7. Сокращение списка гостей

Конкретный список зависит от 3.6: `[Needs confirmation]`.

Source-grounded последовательность:

1. вызвать `pop()`;
2. сохранить возвращённое имя;
3. вывести сообщение об отмене приглашения;
4. повторять `pop()`, пока в текущей программе не останутся два элемента;
5. вывести подтверждение двум оставшимся;
6. удалить два последних имени через `del`;
7. вывести список и проверить `[]`.

Цикл `while` здесь не добавляется: глава 3 его не вводит, а упражнение формулирует последовательное использование `pop()`.

## 3.8. Повидать мир

Список стран пользователя: `[Needs confirmation]`.

Шаблон операций:

~~~python
places = ['[страна1]', '[страна2]', '[страна3]', '[страна4]', '[страна5]']

print(places)
print(sorted(places))
print(places)
print(sorted(places, reverse=True))
print(places)

places.reverse()
print(places)

places.reverse()
print(places)

places.sort()
print(places)

places.sort(reverse=True)
print(places)
~~~

Acceptance: первые вызовы `sorted()` не меняют `places`; два `reverse()` возвращают исходный порядок; `sort()` затем меняет сам список.

## 3.9. Количество гостей

~~~python
print(len(guests))
~~~

Формат сообщения можно построить через f-строку:

~~~python
print(f"На обед приглашено гостей: {len(guests)}")
~~~

Фактическое число зависит от выбранной стадии программы 3.4–3.7.

## 3.10. Все функции

Тема списка и данные: `[Needs confirmation]`.

Минимальный checklist source-confirmed операций главы:

## 3.11. Намеренная ошибка

Source example уже показывает типичную ошибку:

~~~python
motorcycles = ['honda', 'yamaha', 'suzuki']
print(motorcycles[3])
~~~

Для списка из трёх элементов индекс `3` отсутствует, поэтому возникает:

~~~text
IndexError: list index out of range
~~~

Source-grounded исправление для третьего элемента:

~~~python
print(motorcycles[2])
~~~

Также источник показывает `motorcycles[-1]` для последнего элемента непустого списка. Для пустого списка `[-1]` тоже вызывает `IndexError`.
