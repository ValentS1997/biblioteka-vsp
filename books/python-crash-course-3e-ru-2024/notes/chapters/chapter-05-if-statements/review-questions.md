## 5.1. Проверка условий

Создайте минимум 10 условных проверок. Перед каждой выведите описание и прогноз результата. Не менее пяти проверок должны вернуть `True` и не менее пяти — `False`. Просмотрите результаты и убедитесь, что понимаете каждое значение.

## 5.2. Больше проверок условий

Дополните `conditional_tests.py` проверками:
- равенства и неравенства строк;
- с `lower()`;
- числового равенства/неравенства и сравнений;
- с `and` и `or`;
- вхождения в список;
- отсутствия в списке.

Для каждого вида должен присутствовать хотя бы один истинный и один ложный результат.

## 5.3. Цвета пришельцев 1

Создайте `alien_color` со значением `'green'`, `'yellow'` или `'red'`. Напишите `if`, выдающий 5 очков только для `'green'`. Сделайте одну версию с True и одну с False; во второй сообщения быть не должно.

## 5.4. Цвета пришельцев 2

Напишите `if-else`: `'green'` даёт сообщение о 5 очках, любое другое значение — о 10. Создайте версии для выполнения каждой ветви.

## 5.5. Цвета пришельцев 3

Преобразуйте решение в `if-elif-else`:
- green → 5;
- yellow → 10;
- red → 15.
Сделайте три версии и проверьте каждый цвет.

## 5.6. Периоды жизни

По `age` вывести одну категорию:
- меньше 2 — младенец;
- 2–<4 — малыш;
- 4–<13 — ребёнок;
- 13–<20 — подросток;
- 20–<65 — взрослый;
- 65+ — пожилой человек.

## 5.7. Любимый фрукт

Создайте `favorite_fruits` из трёх любимых фруктов. Напишите пять независимых `if`, каждый проверяет конкретный фрукт и при наличии выводит сообщение.

## 5.8. Здравствуйте, админ!

Создайте список минимум из пяти имён, включающий `'admin'`. В цикле выводите специальное приветствие для admin и обычное — для остальных.

## 5.9. Нет пользователей

Добавьте в программу 5.8 проверку непустого списка. Для пустого списка выведите сообщение о необходимости добавить пользователей. Удалите все имена и подтвердите эту ветвь.

## 5.10. Проверка имен пользователей

Создайте `current_users` и `new_users`. Одно-два новых имени должны пересекаться с существующими. Для каждого нового имени сообщите, занято оно или доступно. Сравнение должно игнорировать регистр; источник требует отдельную lower-case копию существующих имён.

## 5.11. Порядковые числительные

Сохраните числа 1–9, переберите их и через `if-elif-else` выведите окончания: `1st`, `2nd`, `3rd`, остальные с `th`.

## 5.12. Форматирование операторов if

Проверьте программы главы и убедитесь, что условия оформлены в соответствии с source recommendation — с пробелами вокруг операторов сравнения.
