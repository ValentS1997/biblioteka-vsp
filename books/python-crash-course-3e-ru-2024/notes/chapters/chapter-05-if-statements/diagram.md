# Диаграмма — оператор if

## Выбор конструкции

~~~mermaid
flowchart TD
    A["Есть условие/условия"] --> B{"Сколько блоков должно потенциально выполниться?"}
    B -- "Один условный" --> C["if"]
    B -- "Ровно один из двух" --> D["if / else"]
    B -- "Один из многих" --> E["if / elif / else"]
    B -- "Несколько независимо" --> F["несколько if"]
    C --> G["Проверить True/False"]
    D --> G
    E --> G
    F --> G
~~~
