## 6.1. Персона

Создайте словарь об известном вам человеке с ключами `first_name`, `last_name`, `age`, `city`. Выведите каждый фрагмент информации.

## 6.2. Любимые числа

Создайте словарь из пяти имён и любимого числа каждого человека. Выведите имя и число. Источник предлагает опросить друзей для реальных данных.

## 6.3. Глоссарий

Выберите пять терминов программирования из предыдущих глав как ключи и определения как значения. Выведите каждую пару в читаемом формате, используя `\n` для разделения.

## 6.4. Глоссарий 2

Перепишите 6.3 с циклом по ключам/значениям. После проверки добавьте ещё пять терминов; они должны автоматически появиться в выводе.

## 6.5. Реки

Создайте словарь из трёх больших рек и стран. Выведите:
- сообщения «река протекает через страну»;
- все названия рек;
- все названия стран.

Источник приводит возможную пару `'nile': 'egypt'`.

## 6.6. Опрос

На основе `favorite_languages.py` создайте список людей, которые должны пройти опрос: часть уже есть в словаре, часть — нет. Для прошедших выведите благодарность, для остальных — приглашение.

## 6.7. Люди

Расширьте 6.1 ещё двумя словарями людей, сохраните три словаря в `people`, переберите список и выведите всю информацию о каждом.

## 6.8. Домашние животные

Создайте несколько словарей домашних животных с видом и владельцем, сохраните их в `pets`, переберите и выведите данные.

## 6.9. Любимые места

Создайте `favorite_places`: имена людей — ключи, от одного до трёх любимых мест — значения-списки. Переберите и выведите имена и места. Источник предлагает собрать реальные данные у друзей.

## 6.10. Любимые числа

Измените 6.2 так, чтобы у каждого человека хранилось несколько любимых чисел. Выведите имя и его числа.

## 6.11. Города

Создайте `cities` с тремя городами как ключами. Для каждого значения-словаря используйте ключи `country`, `population`, `fact`. Выведите город и всю информацию.

## 6.12. Расширение

Выберите один пример главы и расширьте его: добавьте ключи/значения, измените контекст или улучшите форматирование вывода.

Нумерация и требования сохранены по RAG; формулировки структурно уплотнены.
