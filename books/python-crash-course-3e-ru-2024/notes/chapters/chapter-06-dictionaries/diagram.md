# Диаграмма — словари

## Выбор операции

~~~mermaid
flowchart TD
    A["Словарь key:value"] --> B{"Что нужно?"}
    B -- "Прочитать обязательный ключ" --> C["d[key]"]
    B -- "Ключ может отсутствовать" --> D["d.get(key, default)"]
    B -- "Добавить/изменить" --> E["d[key] = value"]
    B -- "Удалить" --> F["del d[key]"]
    B -- "Перебрать пары" --> G["d.items()"]
    B -- "Перебрать ключи" --> H["d.keys() / d"]
    B -- "Перебрать значения" --> I["d.values()"]
    I --> J{"Нужны уникальные?"}
    J -- "Да" --> K["set(d.values())"]
~~~

## Отсутствующий ключ

~~~mermaid
flowchart TD
    A["Нужен key"] --> B{"Ключ гарантирован?"}
    B -- "Да" --> C["d[key]"]
    C --> D{"Есть ключ?"}
    D -- "Да" --> E["Получить значение"]
    D -- "Нет" --> F["KeyError"]
    B -- "Нет" --> G["d.get(key, default)"]
    G --> H["Значение или default / None"]
~~~

## Nesting

~~~mermaid
flowchart LR
    A["Один объект"] --> B["dict"]
    C["Много однотипных объектов"] --> D["list of dicts"]
    E["Один ключ → много значений"] --> F["list inside dict"]
    G["Именованный объект → набор атрибутов"] --> H["dict inside dict"]
~~~
