Занятие 18  599

Для каждой записи из набора записей регистра расчета мы получаем
номер  строки, идентифицирующий  начисление  для  конкретного
сотрудника, и по этому номеру ищем соответствующую запись
в выборке из результата запроса.
Если в результате запроса есть запись с таким номером строки,
мы рассчитываем результат записи регистра расчета. То есть мы
получаем начисление по окладу для каждого сотрудника как результат
от деления начисленной суммы (поле регистра ИсходныеДанные)
на количество рабочих дней в месяце (Норма) и умножения на факти-
чески отработанные рабочие дни (Факт).
Добавим текст запроса во вторую ветку условия Если… с той лишь
разницей, что теперь мы будем получать значения базы, используя
виртуальную таблицу регистра расчета РегистрРасчета.Начисления.
БазаНачисления (листинг 18.6).
