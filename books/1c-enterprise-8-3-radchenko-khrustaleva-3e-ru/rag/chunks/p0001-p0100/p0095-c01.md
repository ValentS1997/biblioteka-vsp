Занятие 3   95

        Рис. 3.47. Заполнение элемента справочника «Сотрудники»

Если табличная часть состоит из нескольких строк, то расположить
их в произвольном порядке можно путем перетаскивания мышью
в нужное место или с помощью команд Переместить вверх, Пере-
местить вниз из подменю Еще, находящегося в командной панели
таблицы. Для того чтобы удалить только что созданную пустую
строку  табличной  части,  достаточно  просто  установить  курсор
на другую, заполненную строку таблицы.
