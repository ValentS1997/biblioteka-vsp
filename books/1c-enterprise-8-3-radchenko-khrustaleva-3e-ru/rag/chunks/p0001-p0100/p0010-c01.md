10   1С:Предприятие 8.3. Практическое пособие разработчика

                      Рис. 0.3. Шаблоны текстов листингов

   Для каждого фрагмента кода в качестве строковой последователь-
    ности, которая будет заменяться при вводе текста, указывается номер
    листинга, содержащего соответствующий фрагмент кода.
    Замена строковой последовательности может производиться авто-
    матически,  если  установлен режим  автозамены,  или  вручную,
    с помощью комбинации клавиш Ctrl + Q. Режим автозамены устанав-
    ливается командой Сервис > Параметры > Тексты > Автозамена.
    Также любой шаблон текста может быть просто перенесен мышью
    в произвольное место модуля.
   Картинки для подсистем. Также в дополнительных материалах
    в папке  Icons  находятся файлы  картинок, использующихся при
    создании подсистем конфигурации.
