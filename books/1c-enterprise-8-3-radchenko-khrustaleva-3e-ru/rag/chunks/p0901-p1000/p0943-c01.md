Краткий справочник разработчика  943

ПРИМЕЧАНИЕ
          Заливкой выделены события, выполняющиеся в транзакции записи.

Работа с формой записи регистра сведений осуществляется при по-
мощи  объекта РегистрСведенийМенеджерЗаписи.<имя>,  который,
в свою очередь, использует объект РегистрСведенийНаборЗаписей.<имя>.
Особенности внутренней реализации объекта РегистрСведенийМене
джерЗаписи.<имя> таковы, что в случае сохранения существующей
записи регистра сведений обработчики события Перед Записью()
и ПриЗаписи() модуля набора записей будут вызваны дважды: сначала
для старого набора записей (с количеством записей 0) и затем для
нового (с количеством записей 1).
