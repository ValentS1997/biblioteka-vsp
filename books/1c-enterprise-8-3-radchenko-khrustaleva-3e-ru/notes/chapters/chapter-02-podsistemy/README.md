# Занятие 2. Подсистемы

**Источник:** М. Г. Радченко, Е. Ю. Хрусталева, «1С:Предприятие 8.3. Практическое пособие разработчика», издание 3, инв. №0030. Режим **RAG-only**; исходный `source/book.pdf`, SHA-256 `ce8fa0fbf0d8bb38f724ed04f130c2443c1e181eb51edafac692c4786874c923`.

**Граница занятия:** PDF-страницы 39–54, чанки `p0039:c01`–`p0054:c01`; на с. 55 начинается занятие 3 «Справочники» ([p0055:c01](../../../rag/chunks/p0001-p0100/p0055-c01.md)). **Продолжительность:** приблизительно 45 минут ([p0039:c01](../../../rag/chunks/p0001-p0100/p0039-c01.md)).

## Основной принцип

Объекты **Подсистема** определяют функциональные части конфигурации и являются основой декларативного интерфейса «1С:Предприятия». Подсистемы верхнего уровня образуют разделы приложения, подсистемы могут быть вложенными, а объект конфигурации может относиться сразу к нескольким подсистемам. Для учебного решения используются пять подсистем; простые решения могут обходиться без них. [p0040:c01](../../../rag/chunks/p0001-p0100/p0040-c01.md), [p0041:c01](../../../rag/chunks/p0001-p0100/p0041-c01.md), [p0042:c01](../../../rag/chunks/p0001-p0100/p0042-c01.md).

## Практика

1. Закрыть режим «1С:Предприятие», вернуться в **Конфигуратор**, раскрыть **Общие → Подсистемы**, выбрать **Добавить**. Появится окно редактирования объекта с вкладкой «Основные» и навигацией «Далее/Назад». [p0042:c01](../../../rag/chunks/p0001-p0100/p0042-c01.md), [p0043:c01](../../../rag/chunks/p0001-p0100/p0043-c01.md).
2. Создать `Бухгалтерия`. Платформа предложит одноимённый синоним. **Имя** используется во встроенном языке и не должно содержать пробелы; **Синоним** предназначен для видимого пользователю текста. [p0044:c01](../../../rag/chunks/p0001-p0100/p0044-c01.md).
3. Для картинки открыть поле **Картинка**, вкладку **Из конфигурации**, создать **Общую картинку** с именем `Бухгалтерия`, выбрать изображение из файла и подтвердить выбор. В исходном примере файлы предлагается взять из дополнительных материалов книги; они отдельно в RAG не извлечены — `[Needs confirmation]`. Изображение необязательно: без него отображается стандартная картинка. [p0045:c01](../../../rag/chunks/p0001-p0100/p0045-c01.md), [p0046:c01](../../../rag/chunks/p0001-p0100/p0046-c01.md), [p0047:c01](../../../rag/chunks/p0001-p0100/p0047-c01.md), [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md).
4. Создать `УчетМатериалов` и `ОказаниеУслуг` с картинками **Материалы** и **Услуги**. Через контекстное меню **Добавить → Подсистема** создать `РасчетЗарплаты` с картинкой **Зарплата**; этот вариант создаёт объект на том же уровне, в отличие от **Подчиненная подсистема**. В заключение создать `Предприятие` с соответствующей картинкой. [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md), [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md).
5. Запустить отладку в режиме «1С:Предприятие»: новые разделы появились в панели под заголовком приложения. Пока их содержимое пусто, поскольку связанные документы, справочники и отчёты ещё не созданы. Раздел **Главное** платформа добавляет сама и располагает первым. [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md), [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md).
6. Вернуться в Конфигуратор. В контекстном меню корня `ПособиеДляНачинающих` выбрать **Открыть командный интерфейс конфигурации**. Кнопками **Вверх/Вниз** установить порядок: **Учет материалов → Оказание услуг → Бухгалтерия → Расчет зарплаты → Предприятие**. Повторно запустить отладку и проверить панель разделов. [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md), [p0051:c01](../../../rag/chunks/p0001-p0100/p0051-c01.md), [p0052:c01](../../../rag/chunks/p0001-p0100/p0052-c01.md).

## Важные различия

**Общая настройка:** порядок в Конфигураторе предназначен всем пользователям приложения. **Пользовательская настройка:** **Настройки → Настройка панели разделов…** изменяет порядок только для пользователя, выполняющего действие. [p0052:c01](../../../rag/chunks/p0001-p0100/p0052-c01.md).

**Окно редактирования объекта** помогает пройти последовательные шаги создания нового объекта; **палитра свойств** позволяет сравнивать одно и то же свойство у разных выделенных объектов. [p0043:c01](../../../rag/chunks/p0001-p0100/p0043-c01.md), [p0053:c01](../../../rag/chunks/p0001-p0100/p0053-c01.md), [p0054:c01](../../../rag/chunks/p0001-p0100/p0054-c01.md).

## Контроль, сохранение, ограничения

- Сравнить видимость всех пяти разделов, порядок, синонимы и картинки; раздел «Главное» всегда первый. [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md), [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md), [p0052:c01](../../../rag/chunks/p0001-p0100/p0052-c01.md).
- После успешного занятия рекомендована операция **Администрирование → Выгрузить информационную базу…**. Книга указывает **Администрирование → Загрузить информационную базу…** для возврата к работающему состоянию, но детальная проверка файла и условия безопасной загрузки отсутствуют — `[Needs confirmation]`. [p0053:c01](../../../rag/chunks/p0001-p0100/p0053-c01.md).
- Роли упоминаются как возможность ограничения интерфейса, но практическая настройка ролей в этом занятии не выполняется. [p0041:c01](../../../rag/chunks/p0001-p0100/p0041-c01.md).
- Точные изображения из дополнительных материалов и внешний вид авторских скриншотов не подтверждены текстовыми RAG-чанками; SVG отражают содержание текста, а не копируют скриншоты. См. [source-findings.md](source-findings.md).
