# Шпаргалка — занятие 2 «Подсистемы»

**Источник:** RAG PDF с. 39–54 (`p0039:c01`–`p0054:c01`). Версия примера: учебная конфигурация «1С:Предприятие 8.3».

## Symptom / problem framing

Учебное прикладное решение пока не разделено на функциональные разделы интерфейса. Нужно описать структуру подсистемами, присвоить им имена и картинки и управлять порядком их отображения. [p0040:c01](../../../rag/chunks/p0001-p0100/p0040-c01.md), [p0042:c01](../../../rag/chunks/p0001-p0100/p0042-c01.md).

## Baseline / context

- **Подсистема** — вид объекта конфигурации в ветке **Общие**, который группирует функциональную часть приложения; подсистемы верхнего уровня становятся разделами интерфейса. [p0040:c01](../../../rag/chunks/p0001-p0100/p0040-c01.md).
- Объект конфигурации может входить в **несколько** подсистем. Подсистемы могут иметь подчинённые подсистемы; в учебном примере используется один уровень. [p0040:c01](../../../rag/chunks/p0001-p0100/p0040-c01.md), [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md), [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md).
- Пять подсистем: `Бухгалтерия`, `РасчетЗарплаты`, `УчетМатериалов`, `ОказаниеУслуг`, `Предприятие`. [p0042:c01](../../../rag/chunks/p0001-p0100/p0042-c01.md).
- Раздел **Главное** формируется платформой и находится первым. Пока прикладные объекты не созданы, разделы пусты. [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md).

## Read-only checks

1. В дереве Конфигуратора раскрыть **Общие → Подсистемы** и посмотреть список/иерархию. [p0042:c01](../../../rag/chunks/p0001-p0100/p0042-c01.md).
2. В окне редактирования выбранного объекта проверить **Имя**, **Синоним** и **Картинка**. [p0043:c01](../../../rag/chunks/p0001-p0100/p0043-c01.md), [p0044:c01](../../../rag/chunks/p0001-p0100/p0044-c01.md), [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md).
3. В режиме «1С:Предприятие» проверить панель разделов; у каждого раздела должен отображаться видимый синоним, а картинка может быть пользовательской или стандартной. [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md), [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md).
4. Проверить текущий порядок разделов в окне **Командный интерфейс**. [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md), [p0051:c01](../../../rag/chunks/p0001-p0100/p0051-c01.md).

## Interpretation

**Имя** — уникальный идентификатор, используемый на встроенном языке; начинается с буквы и не допускает, например, пробелы. **Синоним** — надпись для пользователя. **Картинка** — необязательное визуальное свойство: при отсутствии используется стандартная. [p0044:c01](../../../rag/chunks/p0001-p0100/p0044-c01.md), [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md).

**Глобальный порядок** меняется в Конфигураторе и действует для всех пользователей; **персональный порядок** меняется в «1С:Предприятии» через «Настройки → Настройка панели разделов…» и действует только для этого пользователя. [p0052:c01](../../../rag/chunks/p0001-p0100/p0052-c01.md).

## Next action

Начать с дерева **Общие → Подсистемы → Добавить**, задать первую подсистему `Бухгалтерия`, затем остальные четыре. [p0042:c01](../../../rag/chunks/p0001-p0100/p0042-c01.md), [p0044:c01](../../../rag/chunks/p0001-p0100/p0044-c01.md), [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md), [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md).

## Modifying action

1. Добавить пять подсистем; создание/изменение конфигурации — **state-changing**. Для одной из них демонстрируется **Общая картинка**, выбираемая из файла; дополнительные файлы картинок в RAG недоступны. [p0042:c01](../../../rag/chunks/p0001-p0100/p0042-c01.md), [p0045:c01](../../../rag/chunks/p0001-p0100/p0045-c01.md), [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md), [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md).
2. В окне командного интерфейса кнопками **Вверх**/**Вниз** задать порядок: Учет материалов, Оказание услуг, Бухгалтерия, Расчет зарплаты, Предприятие. [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md), [p0051:c01](../../../rag/chunks/p0001-p0100/p0051-c01.md).
3. Выполнить отладочный запуск и оценить результат; изменение пользовательского порядка отдельно от глобального. [p0052:c01](../../../rag/chunks/p0001-p0100/p0052-c01.md).

## Verification / acceptance checks

- Пять разделов появились с заданными синонимами и (при наличии файлов) картинками; отсутствие картинки не мешает разделу. [p0048:c01](../../../rag/chunks/p0001-p0100/p0048-c01.md), [p0049:c01](../../../rag/chunks/p0001-p0100/p0049-c01.md).
- **Главное** расположено первым, после него идёт ожидаемый порядок пяти разделов. [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md), [p0051:c01](../../../rag/chunks/p0001-p0100/p0051-c01.md), [p0052:c01](../../../rag/chunks/p0001-p0100/p0052-c01.md).
- Список разделов пуст по содержимому, потому что связанные прикладные объекты будут создаваться в дальнейшем. [p0050:c01](../../../rag/chunks/p0001-p0100/p0050-c01.md).

## Rollback

После занятия книга рекомендует **Администрирование → Выгрузить информационную базу…** для сохранения рабочего состояния и **Администрирование → Загрузить информационную базу…** для возврата к нему. [p0053:c01](../../../rag/chunks/p0001-p0100/p0053-c01.md). Процедура подтверждения целостности выгрузки, изоляция целевой базы и последствия загрузки не объяснены: `[Needs confirmation]`. Не выполнять загрузку в рабочую информационную базу по одной лишь шпаргалке.

**Ограничение:** привязка объектов к подсистемам и настройка видимости по ролям объясняются концептуально; конкретная настройка ролей в главе не дана. [p0040:c01](../../../rag/chunks/p0001-p0100/p0040-c01.md), [p0041:c01](../../../rag/chunks/p0001-p0100/p0041-c01.md).
