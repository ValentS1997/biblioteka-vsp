# Шпаргалка: занятие 1

RAG: PDF с. 15–38, `p0015:c01`–`p0038:c01`. Все действия — из учебного текста.

## Symptom / problem framing

Нужно начать разработку с собственной **пустой информационной базы**, разобраться в платформе, конфигурации и режимах работы, затем проверить первое изменение. Это учебная задача, не сценарий устранения аварии. [p0016:c01](../../../rag/chunks/p0001-p0100/p0016-c01.md), [p0021:c01](../../../rag/chunks/p0001-p0100/p0021-c01.md).

## Baseline / context

- **Платформа:** управляет конфигурацией. **Конфигурация:** описывает данные, алгоритмы и интерфейс. **Прикладное решение:** обозначение в пользовательском контексте. [p0017:c01](../../../rag/chunks/p0001-p0100/p0017-c01.md), [p0018:c01](../../../rag/chunks/p0001-p0100/p0018-c01.md), [p0019:c01](../../../rag/chunks/p0001-p0100/p0019-c01.md), [p0028:c01](../../../rag/chunks/p0001-p0100/p0028-c01.md).
- **Конфигуратор:** разработка и администрирование; **1С:Предприятие:** пользовательская работа с данными. [p0020:c01](../../../rag/chunks/p0001-p0100/p0020-c01.md).
- Система «1С:Предприятие 8.3» должна быть установлена до практики. [p0020:c01](../../../rag/chunks/p0001-p0100/p0020-c01.md).

## Read-only checks

1. Посмотреть список баз в стартовом диалоге и выяснить, создана ли учебная база. [p0021:c01](../../../rag/chunks/p0001-p0100/p0021-c01.md).
2. После создания увидеть новую базу в списке запуска. [p0024:c01](../../../rag/chunks/p0001-p0100/p0024-c01.md).
3. Открыть дерево конфигурации и убедиться, что стандартные группы пока пусты; в «Общие → Языки» присутствует созданный платформой «Русский». [p0026:c01](../../../rag/chunks/p0001-p0100/p0026-c01.md), [p0027:c01](../../../rag/chunks/p0001-p0100/p0027-c01.md).
4. Просмотреть корневые свойства и синоним. [p0033:c01](../../../rag/chunks/p0001-p0100/p0033-c01.md).

## Interpretation

Виды объектов конфигурации определяет платформа: разработчик создаёт экземпляры стандартных видов, но не собственные виды. Платформа на основе описаний объектов строит таблицы базы данных. Не путать объект конфигурации с таблицами. [p0028:c01](../../../rag/chunks/p0001-p0100/p0028-c01.md), [p0029:c01](../../../rag/chunks/p0001-p0100/p0029-c01.md), [p0030:c01](../../../rag/chunks/p0001-p0100/p0030-c01.md).

## Next action

Создать базу без шаблона, затем открыть её в Конфигураторе. [p0021:c01](../../../rag/chunks/p0001-p0100/p0021-c01.md), [p0025:c01](../../../rag/chunks/p0001-p0100/p0025-c01.md).

## Modifying action

- **Добавить → Создание новой информационной базы → Без конфигурации…**; имя, локальное расположение, каталог, язык «Русский», **Готово**. Создаёт учебную базу. [p0021:c01](../../../rag/chunks/p0001-p0100/p0021-c01.md), [p0022:c01](../../../rag/chunks/p0001-p0100/p0022-c01.md), [p0023:c01](../../../rag/chunks/p0001-p0100/p0023-c01.md).
- **Конфигурация → Открыть конфигурацию → корень «Конфигурация» → Свойства**; задать `ПособиеДляНачинающих`. Изменяет свойство конфигурации. [p0026:c01](../../../rag/chunks/p0001-p0100/p0026-c01.md), [p0033:c01](../../../rag/chunks/p0001-p0100/p0033-c01.md).
- **Отладка → Начать отладку → Да** при запросе обновления конфигурации базы данных. Подтверждение обновления — изменение состояния базы. [p0035:c01](../../../rag/chunks/p0001-p0100/p0035-c01.md).

## Verification / acceptance checks

Новая база присутствует в списке; дерево открывается; свойство «Имя» выставлено; при запуске в пользовательском режиме виден заголовок конфигурации, рабочая область пустая — ожидаемый результат. [p0024:c01](../../../rag/chunks/p0001-p0100/p0024-c01.md), [p0033:c01](../../../rag/chunks/p0001-p0100/p0033-c01.md), [p0035:c01](../../../rag/chunks/p0001-p0100/p0035-c01.md).

## Rollback

`[Needs confirmation]`. Резервирование, удаление учебной базы, отмена изменений конфигурации и откат обновления базы данных в занятии 1 не описаны. Не подменять их внешними рецептами.

**Граница применения:** в других версиях интерфейс и механизмы могут отличаться; из этого RAG это не подтверждается.
