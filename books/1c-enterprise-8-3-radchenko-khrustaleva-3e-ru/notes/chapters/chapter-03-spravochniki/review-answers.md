# Ответы на 24 контрольных вопроса — RAG-only

Ответы даны в порядке [вопросов](review-questions.md), не являются официальными ответами издательства.

1. **Справочник** описывает списки однотипных элементов; платформа создаёт таблицы для их данных. [p56:c01](../../../rag/chunks/p0001-p0100/p0056-c01.md).
2. Содержит элементы, стандартные/дополнительные реквизиты, возможно табличные части, иерархию, владельцев, предопределённые элементы и формы. [p56:c01](../../../rag/chunks/p0001-p0100/p0056-c01.md), [p58:c01](../../../rag/chunks/p0001-p0100/p0058-c01.md), [p59:c01](../../../rag/chunks/p0001-p0100/p0059-c01.md), [p62:c01](../../../rag/chunks/p0001-p0100/p0062-c01.md), [p63:c01](../../../rag/chunks/p0001-p0100/p0063-c01.md).
3. **Реквизит** — однотипное поле каждого элемента. **Табличная часть** — переменное число строк единой структуры у каждого элемента. [p56:c01](../../../rag/chunks/p0001-p0100/p0056-c01.md), [p59:c01](../../../rag/chunks/p0001-p0100/p0059-c01.md).
4. Иерархия группирует элементы: родителем служит группа или другой элемент, в зависимости от вида иерархии. [p60:c01](../../../rag/chunks/p0001-p0100/p0060-c01.md), [p61:c01](../../../rag/chunks/p0001-p0100/p0061-c01.md).
5. Подчинение связывает справочник с элементами/группами **владельца**, например `КонтактныеЛица` с `Партнеры`. [p62:c01](../../../rag/chunks/p0001-p0100/p0062-c01.md).
6. Формы элемента, группы, списка, выбора элемента и выбора группы. [p63:c01](../../../rag/chunks/p0001-p0100/p0063-c01.md), [p64:c01](../../../rag/chunks/p0001-p0100/p0064-c01.md), [p66:c01](../../../rag/chunks/p0001-p0100/p0066-c01.md), [p67:c01](../../../rag/chunks/p0001-p0100/p0067-c01.md).
7. Предопределённые элементы создаются в Конфигураторе, получают уникальное постоянное имя и доступны алгоритмам. [p63:c01](../../../rag/chunks/p0001-p0100/p0063-c01.md), [p110:c01](../../../rag/chunks/p0101-p0200/p0110-c01.md), [p114:c01](../../../rag/chunks/p0101-p0200/p0114-c01.md).
8. Обычные элементы могут появляться/исчезать при работе пользователя; предопределённые задаются конфигурацией и служат опорными данными. [p114:c01](../../../rag/chunks/p0101-p0200/p0114-c01.md), [p119:c01](../../../rag/chunks/p0101-p0200/p0119-c01.md).
9. По специальной пиктограмме. Её внешний вид в текстовом RAG — `[Needs confirmation]`. [p63:c01](../../../rag/chunks/p0001-p0100/p0063-c01.md), [p114:c01](../../../rag/chunks/p0101-p0200/p0114-c01.md).
10. **Справочники → Добавить**, задать имя, представления, подсистемы, данные/реквизиты, табличные части и иерархию при необходимости. [p69:c01](../../../rag/chunks/p0001-p0100/p0069-c01.md), [p72:c01](../../../rag/chunks/p0001-p0100/p0072-c01.md), [p73:c01](../../../rag/chunks/p0001-p0100/p0073-c01.md), [p89:c01](../../../rag/chunks/p0001-p0100/p0089-c01.md), [p97:c01](../../../rag/chunks/p0001-p0100/p0097-c01.md).
11. На вкладке **Данные** выбрать **Стандартные реквизиты**, открыть свойства нужного реквизита и изменить **Синоним**. [p74:c01](../../../rag/chunks/p0001-p0100/p0074-c01.md), [p89:c01](../../../rag/chunks/p0001-p0100/p0089-c01.md), [p99:c01](../../../rag/chunks/p0001-p0100/p0099-c01.md).
12. Командой создания из раздела или **Создать** / **Insert** из формы списка; заполнить форму и записать. [p80:c01](../../../rag/chunks/p0001-p0100/p0080-c01.md), [p81:c01](../../../rag/chunks/p0001-p0100/p0081-c01.md).
13. В форме списка иерархического справочника выбрать **Создать группу**, ввести имя, при необходимости родительскую группу. [p102:c01](../../../rag/chunks/p0101-p0200/p0102-c01.md), [p106:c01](../../../rag/chunks/p0101-p0200/p0106-c01.md).
14. Перетащить элемент, выбрать **Еще → Переместить в группу** или изменить реквизит группы в форме элемента. [p105:c01](../../../rag/chunks/p0101-p0200/p0105-c01.md).
15. Основную конфигурацию редактирует разработчик; конфигурация базы данных обслуживает пользователей, разделение позволяет подготовить изменения отдельно. [p115:c01](../../../rag/chunks/p0101-p0200/p0115-c01.md), [p117:c01](../../../rag/chunks/p0101-p0200/p0117-c01.md).
16. **Конфигурация → Обновить конфигурацию базы данных**; при структурных изменениях нужна реструктуризация и завершение сеансов. [p117:c01](../../../rag/chunks/p0101-p0200/p0117-c01.md), [p118:c01](../../../rag/chunks/p0101-p0200/p0118-c01.md), [p119:c01](../../../rag/chunks/p0101-p0200/p0119-c01.md).
17. На основе объектов конфигурации платформа создаёт/модифицирует таблицы при обновлении конфигурации БД; в них записываются элементы. [p56:c01](../../../rag/chunks/p0001-p0100/p0056-c01.md), [p59:c01](../../../rag/chunks/p0001-p0100/p0059-c01.md), [p119:c01](../../../rag/chunks/p0101-p0200/p0119-c01.md).
18. Подчинённые объекты — связанные части структуры другого объекта, например реквизиты, табличные части, формы. [p57:c01](../../../rag/chunks/p0001-p0100/p0057-c01.md), [p59:c01](../../../rag/chunks/p0001-p0100/p0059-c01.md), [p67:c01](../../../rag/chunks/p0001-p0100/p0067-c01.md).
19. Проверка заполнения запрещает сохранять элемент с незаполненным обязательным полем, например `Ф. И. О.`. [p76:c01](../../../rag/chunks/p0001-p0100/p0076-c01.md), [p81:c01](../../../rag/chunks/p0001-p0100/p0081-c01.md), [p82:c01](../../../rag/chunks/p0001-p0100/p0082-c01.md).
20. Быстрый выбор показывает короткий выпадающий список вместо формы выбора; автор рекомендует для небольшого неиерархического справочника «Склады». [p109:c01](../../../rag/chunks/p0101-p0200/p0109-c01.md), [p110:c01](../../../rag/chunks/p0101-p0200/p0110-c01.md).
21. На вкладке **Подсистемы** отметить разделы. **Представление объекта** задаёт название создания, **Представление списка** — открытие списка, расширенные свойства — заголовки форм. [p70:c01](../../../rag/chunks/p0001-p0100/p0070-c01.md), [p71:c01](../../../rag/chunks/p0001-p0100/p0071-c01.md), [p72:c01](../../../rag/chunks/p0001-p0100/p0072-c01.md).
22. В **Командном интерфейсе** подсистемы включить видимость команды группы **Панель действий.Создать**. [p76:c01](../../../rag/chunks/p0001-p0100/p0076-c01.md), [p77:c01](../../../rag/chunks/p0001-p0100/p0077-c01.md), [p92:c01](../../../rag/chunks/p0001-p0100/p0092-c01.md).
23. Через **Командный интерфейс** в редакторе подсистемы либо **Все подсистемы** для нескольких разделов. [p76:c01](../../../rag/chunks/p0001-p0100/p0076-c01.md), [p99:c01](../../../rag/chunks/p0001-p0100/p0099-c01.md), [p101:c01](../../../rag/chunks/p0101-p0200/p0101-c01.md).
24. Рассмотрены панель разделов, панель функций текущего раздела и панель истории. Общая компоновка: **Открыть интерфейс клиентского приложения** в Конфигураторе; персональная: **Настройки → Настройка панелей…** в пользовательском режиме. Исчерпывающий список стандартных панелей в текстовом RAG: `[Needs confirmation]`. [p78:c01](../../../rag/chunks/p0001-p0100/p0078-c01.md), [p79:c01](../../../rag/chunks/p0001-p0100/p0079-c01.md), [p83:c01](../../../rag/chunks/p0001-p0100/p0083-c01.md), [p84:c01](../../../rag/chunks/p0001-p0100/p0084-c01.md), [p85:c01](../../../rag/chunks/p0001-p0100/p0085-c01.md), [p86:c01](../../../rag/chunks/p0001-p0100/p0086-c01.md).
