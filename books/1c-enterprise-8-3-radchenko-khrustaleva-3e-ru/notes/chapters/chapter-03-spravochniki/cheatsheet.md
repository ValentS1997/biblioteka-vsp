# Шпаргалка: занятие 3 «Справочники»

**Источник:** исключительно RAG PDF 55–120, `p0055:c01`–`p0120:c01`.

## Symptom / problem framing

Для учебной фирмы «На все руки мастер» нужно описать списки клиентов, сотрудников с историей работы, материалов/услуг и складов. Разработчик создаёт метаданные справочников, платформа обеспечивает структуру их хранения. [p56:c01](../../../rag/chunks/p0001-p0100/p0056-c01.md), [p69:c01](../../../rag/chunks/p0001-p0100/p0069-c01.md), [p87:c01](../../../rag/chunks/p0001-p0100/p0087-c01.md), [p97:c01](../../../rag/chunks/p0001-p0100/p0097-c01.md), [p107:c01](../../../rag/chunks/p0101-p0200/p0107-c01.md).

## Baseline / context

Справочник содержит **элементы** и **реквизиты**. Табличная часть позволяет иметь разное число строк одинаковой структуры у каждого элемента. Иерархия группирует элементы; подчинённый справочник может иметь **владельца**. Предопределённый элемент описан в конфигурации и служит опорой для алгоритмов. Пять форм: элемента, группы, списка, выбора и выбора группы. [p56:c01](../../../rag/chunks/p0001-p0100/p0056-c01.md), [p58:c01](../../../rag/chunks/p0001-p0100/p0058-c01.md), [p59:c01](../../../rag/chunks/p0001-p0100/p0059-c01.md), [p60:c01](../../../rag/chunks/p0001-p0100/p0060-c01.md), [p62:c01](../../../rag/chunks/p0001-p0100/p0062-c01.md), [p63:c01](../../../rag/chunks/p0001-p0100/p0063-c01.md), [p66:c01](../../../rag/chunks/p0001-p0100/p0066-c01.md), [p67:c01](../../../rag/chunks/p0001-p0100/p0067-c01.md).

## Read-only checks

Посмотреть дерево **Справочники**, свойства четырёх объектов, их подсистемы и реквизиты. Проверить команды открытых списков в разделе пользователя, отдельную видимость команд прямого создания, режим дерева `Номенклатура` и специальную пиктограмму склада `Основной`. Сверить признаки `*` и `<!>` перед обновлением конфигурации БД. [p69:c01](../../../rag/chunks/p0001-p0100/p0069-c01.md), [p76:c01](../../../rag/chunks/p0001-p0100/p0076-c01.md), [p93:c01](../../../rag/chunks/p0001-p0100/p0093-c01.md), [p107:c01](../../../rag/chunks/p0101-p0200/p0107-c01.md), [p113:c01](../../../rag/chunks/p0101-p0200/p0113-c01.md), [p118:c01](../../../rag/chunks/p0101-p0200/p0118-c01.md).

## Modifying action

**Справочники → Добавить** и настройка полей — изменения метаобъектов; **Командный интерфейс** — изменение видимости команд, а не прав. При отладке подтверждение обновления конфигурации БД и **Принять** изменяет структуру хранения. Затем вводить пользователей, группы/элементы и строки табличных частей. [p76:c01](../../../rag/chunks/p0001-p0100/p0076-c01.md), [p78:c01](../../../rag/chunks/p0001-p0100/p0078-c01.md), [p89:c01](../../../rag/chunks/p0001-p0100/p0089-c01.md), [p91:c01](../../../rag/chunks/p0001-p0100/p0091-c01.md), [p101:c01](../../../rag/chunks/p0101-p0200/p0101-c01.md), [p105:c01](../../../rag/chunks/p0101-p0200/p0105-c01.md), [p110:c01](../../../rag/chunks/p0101-p0200/p0110-c01.md).

## Verification / acceptance checks

Списки открываются из заданных подсистем. **Клиенты:** код автоматический, отсутствие обязательного Ф. И. О. блокирует запись. **Сотрудники:** несколько строк истории работы. **Номенклатура:** вложенные группы и режим «Дерево». **Склады:** `Основной` появляется после обновления, `Розничный` добавляет пользователь. [p78:c01](../../../rag/chunks/p0001-p0100/p0078-c01.md), [p80:c01](../../../rag/chunks/p0001-p0100/p0080-c01.md), [p81:c01](../../../rag/chunks/p0001-p0100/p0081-c01.md), [p94:c01](../../../rag/chunks/p0001-p0100/p0094-c01.md), [p105:c01](../../../rag/chunks/p0101-p0200/p0105-c01.md), [p107:c01](../../../rag/chunks/p0101-p0200/p0107-c01.md), [p113:c01](../../../rag/chunks/p0101-p0200/p0113-c01.md).

## Rollback

Можно сравнивать основную конфигурацию и конфигурацию БД и использовать последнюю для возврата основной конфигурации к её состоянию, но полного безопасного алгоритма восстановления пользовательских данных нет: `[Needs confirmation]`. Изменения структуры таблиц требуют завершить пользовательские сеансы. [p117:c01](../../../rag/chunks/p0101-p0200/p0117-c01.md), [p118:c01](../../../rag/chunks/p0101-p0200/p0118-c01.md), [p119:c01](../../../rag/chunks/p0101-p0200/p0119-c01.md).
