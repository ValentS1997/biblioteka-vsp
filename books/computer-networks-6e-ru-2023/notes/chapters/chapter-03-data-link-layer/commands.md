# Команды главы 3

В проверенном RAG-диапазоне главы 3 нет готовых operational CLI-команд, которые можно безопасно перенести в runbook без дополнительного контекста.

| Команда | Назначение | Что проверить | Тип |
|---|---|---|---|

## Учебные программы из упражнения 52

RAG подтверждает имена трех программ:

- `generator` — формирует передаваемую последовательность с CRC;
- `verifier` — проверяет результат и сообщает, корректна ли передача;
- `alter` — инвертирует один выбранный бит для моделирования ошибки.

В тексте приведены две shell-подобные строки запуска, однако OCR отображает разделитель конвейера как символ `1`. Поэтому точная команда отмечается как [Needs confirmation] и не помещается в canonical-таблицу.

Смысл упражнения подтвержден источником:

- без внесения ошибки цепочка generator → verifier должна сообщать корректную передачу;
- с alter между ними verifier должен обнаружить ошибку.

Тип такой проверки: workload-generating, поскольку запускаются пользовательские тестовые программы и обрабатывается входной файл. Это учебная модель CRC, а не команда для production-сети.

## Не подтверждены для главы 3

В chapter scope не подтверждены как команды `ping`, `traceroute`, `tcpdump`, `iperf`, `ifconfig`, `netstat`, `curl`, `dig` и `nslookup`. Они не добавлены из общих знаний.
