basis). Базис -  это просто система координат. Второй набор отличается от
11ервого только тем, что он повернут на 45 градусов; то есть один фильтр можно
11редставить в виде линии, идущей из нижнего левого угла в верхний правый,
а другой -  в виде линии из верхнего левого в нижний правый угол. Это диаго
нальный базис ( diagonal basis ). Итак, у Алисы есть ;ща набора фильтров, и она
может поставить любой из них на пути светового луча. На самом деле у нее не
четыре отдельных фильтра, а кристалл, поляризация которого может на огромной
скорости переключаться в одну из четырех 1юзиций с помощью электричества.
У Боба имеется такое же устройство. Тот факт, что у Алисы и Боба есть по два
базиса, играет важную роль в квантовой криптографии.
   В каждом базисе Алиса обозначает одно из направлений нулем, а другое еди
ницей. В нашем примере вертикальному нанравлению она нрисвоила значение
О, а горизонтал1,ному -   1. Затем, независимо от этого, для направления «ниж
ний левый -  верхний правый» Алиса выбрала значение О, а для направления
«верхний левый - нижний нравый» -   1. Она отправляет эти варианты Бобу
в виде открытого текста, прекрасно нонимая, что ее сообщение может прочитать
злоумышлен 11 ик.
   Теперь Алиса составляет одноразовый блокнот, допустим, с 1юмощыо ге
нератора случайных чисел (это отдельная сложная тема), и передает его Бобу.
Передача производится поразрядно, для каждого бита один из двух базисов
выбирается случайным образом. Для передачи бита фотонная пушка испускает
один фотон, поляризованный так, чтобы он мог пройти через базис, выбран
ный для этого бита. Например, базисы могут выбираться в такой последова
тельности: диагональный, прямолинейный, прямолинейный, диагональный,
прямолинейный и т. д. Чтобы с помощью этих базисов передать одноразовый
блокнот, состоящий из последовательности 1001110010100110, посылаются
фотоны, показанные на илл. 8.12 (а). Для конкретного одноразового блокнота
и последовательности базисов поляризация, которая используется для каждого
бита, определяется однозначно. Биты, передаваемые одним фотоном за один раз,
называются кубитами ( qublts ).
   Боб не знает, какой базис нужно использовать, поэтому он применяет их
