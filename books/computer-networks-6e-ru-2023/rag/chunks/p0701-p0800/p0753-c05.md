просто НЗ, -  это третья крупная версия протокола НТТР, при
званная заменить НТТР / 2. Главное отличие НТТР / 3 состоит в использовании
другого транспортного протокола для пересылки НТТР-сообщений: вместо ТСР
здесь используется QUIC -  версия протокола UDP, дополненная контролем
перегрузки пользовательского пространства. Версия НТТР /3, которую из
начально назвали просто HTTP-over-QUIC (НТТР поверх QUIC), является
последней крупной переработкой протокола НТТР. Существует множество
библиотек с открытым исходным кодом, которые обеспечивают поддержку
клиентской и серверной логики для QUIC и НТТР /3 в таких языках, как С,
С++, Python, Rust и Go. Популярные веб-серверы, включая nginx, теперь тоже
позволяют использовать НТТР /3, установив соответствующие патчи .
