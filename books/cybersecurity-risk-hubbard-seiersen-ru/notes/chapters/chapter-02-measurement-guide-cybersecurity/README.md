## Ограничения

«Правило пяти» не гарантирует узкий интервал и не вычисляет автоматически вероятность кибератаки. Примеры из главы учебные, не метрики пользовательской среды. Финал главы (`e0017:c04`) содержит примечания и переход к следующей главе, но не содержит явно выделенного заключительного резюме либо контрольных вопросов, поэтому conditional artifacts не создаются. Изменения в рабочей инфраструктуре отсутствуют; `reading/progress.yaml` сохраняет `planned`.
