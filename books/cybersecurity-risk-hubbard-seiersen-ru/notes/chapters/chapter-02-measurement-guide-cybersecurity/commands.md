## Методы, подтверждённые RAG

| Метод | Классификация | Смысл и ограничение |
|---|---|---|
| Вероятности и интервалы | read-only | Описать неопределённость численно; `e0016:c01–c02` |
| Четыре шкалы Стивенса | read-only | Проверять допустимость арифметики; `e0016:c03` |
| Байесовская интерпретация | read-only | Оценки до и после наблюдения; `e0016:c04–c05` |
| Цепочка разъяснений | read-only | Перейти от расплывчатого термина к наблюдаемым последствиям; `e0016:c06–c07` |
| Мысленный эксперимент | read-only | Анализ возможных эффектов репутационного ущерба; `e0016:c07` |
| Случайная выборка и правило пяти | read-only | Интервал min–max охватывает медиану с вероятностью 93,75% в описанной модели; `e0017:c03` |
| Косвенные индикаторы | read-only | Получать сведения о ненаблюдаемых напрямую свойствах; `e0017:c02` |
| Контролируемое экспериментальное наблюдение | workload-generating при реальном выполнении | Метод назван; конкретных инструкций нет, `e0017:c02` |
| Проверка состояния приложения | workload-generating / потенциально state-changing | Иллюстрация изменения степени осведомлённости; `e0016:c04` |

## Числовой пример

```text
(1/2)^5 = 1/32
1 - 2*(1/32) = 30/32 = 93,75%
```

Это расчёт авторов для охвата **медианы** диапазоном пяти случайных наблюдений, а не команда или оценка конкретного киберриска (`e0017:c03`).
