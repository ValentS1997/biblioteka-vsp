13. Метод хеширования, описанный в тексте главы, позволяет скомпоновать все
   элементы, имеющие один хеш-код, в связном списке. Альтернативный ме-
   тод — создание только одной таблицы из n слотов, в которой в каждом слоте
   имеется пространство для одного ключа и его значения (или для указателей
   на них). Если алгоритм хеширования порождает слот, который уже заполнен,
   производится вторая попытка с использованием того же алгоритма хеширо-
    вания. Если и на этот раз слот заполнен, алгоритм применяется снова и т. д.
   Так продолжается до тех пор, пока не будет найден пустой слот. Если доля
    слотов, которые уже заполнены, составляет R, то сколько попыток в среднем
