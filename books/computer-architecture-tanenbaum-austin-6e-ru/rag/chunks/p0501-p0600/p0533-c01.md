        Рис. 6.29. Фрагмент системы каталогов операционной системы UNIX
  Вызов link создает элемент каталога, который указывает на уже существую-
щий файл. Например, элемент /usr/jim/jotto можно создать вызовом:
link("/usr/ast/bin/game3", "/usr/jim/jotto")
   Того же результата можно добиться эквивалентным вызовом с относительным
