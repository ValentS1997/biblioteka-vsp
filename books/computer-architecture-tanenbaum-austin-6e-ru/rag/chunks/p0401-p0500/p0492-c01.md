   Рис. 6.10. Преобразование составного MULTICS-адреса в адрес основной памяти

Виртуальная память Core i7
Core i7 имеет сложную систему виртуальной памяти, которая поддерживает вы-
зов страниц по требованию, чистую сегментацию и сегментацию с разбиением
на страницы. Виртуальная память состоит из двух таблиц: LDT (Local Descriptor
Table — локальная таблица дескрипторов) и GDT (Global Descriptor Table — гло-
бальная таблица дескрипторов). Каждая программа имеет собственную локаль-
ную таблицу дескрипторов, а единственная глобальная таблица дескрипторов
разделяется всеми программами компьютера. Локальная таблица дескрипторов
описывает локальные сегменты каждой программы (ее код, данные, стек и т. д.),
а глобальная таблица дескрипторов — системные сегменты, в том числе самой
операционной системы.
