Поток управления        445

  Чтобы переместить n дисков с колышка 1 на колышек 3, нужно сначала пере-
нести n — 1 дисков с колышка 1 на колышек 2, затем перенести один диск с ко-
лышка 1 на колышек 3, потом перенести n — 1 диск с колышка 2 на колышек 3.
Решение этой задачи для трех дисков иллюстрирует рис. 5.23.

           Рис. 5.23. Решение задачи «Ханойская башня» для трех дисков

  Для решения задачи нам нужна процедура, которая позволяет переместить
n дисков с колышка i на колышек j:
towers (n, i, j)
