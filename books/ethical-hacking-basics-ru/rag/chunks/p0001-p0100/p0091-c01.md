  4.2 Пассивная разведка, Google hacking, IoT

  Шаг 1

   Существует много информации, которую можно собрать пассивным способом. Например, просмотр сетевых заголовков по
   мере их прохождения, от заголовков 3 уровня до заголовков приложений, может дать некоторую интересную информацию.
   Хотя захват пакетов и попытка прочитать их вручную может занять много времени, существует программа, которая сделает
   за нас большую часть этой работы. Программа называется p0f  , и она в режиме монитора следит за сетевым трафиком,
   проходящим через интерфейс, и проводит анализ по мере прохождения трафика. К сожалению, p0f уже не так полезен, как
   раньше, поскольку веб-серверы сейчас обычно шифруют трафик по умолчанию, а p0f может работать только с открытыми
   данными - просматривать заголовки HTTP, идентифицировать сервер и другую полезную информацию.

     .-[ 192.168.86.45/46112 -> 8.43.72.22/443 (syn) ]-
     |
     | client = 192.168.86.45/46112
     | os = Linux 3.11 and newer
     | dist = 0
     | params = none
     | raw_sig = 4:64+0:0:1460:mss*20,7:mss,sok,ts,nop,ws:df,id+:0
     |
     `----
     .-[ 192.168.86.45/46112 -> 8.43.72.22/443 (mtu) ]-
     |
     | client = 192.168.86.45/46112
     | link = Ethernet or modem
     | raw_mtu = 1500
     |
     `----
     .-[ 192.168.86.45/46112 -> 8.43.72.22/443 (uptime) ]-
     |
     | client = 192.168.86.45/46112
     | uptime = 48 days 7 hrs 54 min (modulo 49 days)
     | raw_freq = 1000.00 Hz
     |
     `----
     .-[ 192.168.86.45/33498 -> 52.94.210.45/443 (syn) ]-
     |
     | client = 192.168.86.45/33498
     | os = Linux 3.11 and newer
     | dist = 0
     | params = none
     | raw_sig = 4:64+0:0:1460:mss*20,7:mss,sok,ts,nop,ws:df,id+:0
     |
     `----
     .-[ 192.168.86.45/33498 -> 52.94.210.45/443 (host change) ]-
     |
     | client = 192.168.86.45/33498
     | reason = tstamp port
     | raw_hits = 0,1,1,1
     |
     `----

   Например, в выводе результатов работы этой утилиты можно увидеть много дополнительной информаци, которую просто в
   заголовках пакетов не увидеть. Конечно, похожую информацию может предоставить программа захвата и анализа пакетов
    Wireshark . Однако некоторые интересные моменты, она показать не в состоянии, например, возможность определения
   времени безотказной работы системы, идентификация типа операционной системы.  p0f проводит определение только на
   основе сетевых заголовков, поскольку операционные системы имеют разные «сигнатуры», основанные на том, как
