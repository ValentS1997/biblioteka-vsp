  Шаг 11

  Удаленный доступ

   Если мы запрыгнем в машину времени и переместимся в прошлое, увидим как удаленный доступ осуществлялся только с
  помощью модемов и коммутируемого доступа. Несмотря на то, что те времена давно прошли, потребность удаленных
   работников в получении доступа к внутренним ресурсам не менее необходима, чем была в прошлом. Однако в наши дни
   удаленный доступ часто осуществляется через Интернет.

   Обычно это осуществляется не через открытый Интернет, а с помощью шифрования. Виртуальные частные сети (VPN - Virtual
    private networks) — это способ получить доступ к внутренней сети из удаленных мест. Однако не все VPN созданы равными.
   Существуют разные способы осуществления такого удаленного доступа. В некоторых случаях удаленный доступ
   осуществляется через офис-спутник. В этом случае не имеет смысла иметь прямую выделенную линию связи между
   объектами. Вместо этого сетевой провайдер может предложить выделенный канал внутри своей сети для перемещения
   информации из одного места в другое. Это может быть сделано, например, с помощью многопротокольной коммутации по
   меткам (MPLS - Multiprotocol Label Switching). MPLS обеспечивает, по сути, туннель из одного места в другое, инкапсулируя
   трафик внутри метки, где трафик коммутируется из одного места в другое.

   Чаще всего, существует необходимость подключения пользователя к сети. Даже здесь есть несколько способов выполнить
   задачу. Один из способов, который существует уже несколько десятилетий, был частью работы над IPv6. Стек протоколов
   IPSec (IP Security) — это набор протоколов, которые частично обеспечивают шифрование при передаче из одного места в
   другое. IPSec поставляется с рядом протоколов, которые обеспечивают не только шифрование, но и аутентификацию
   сообщений, аутентификацию пользователей и обмен ключами. Поскольку IPSec не является неотъемлемой частью IPv4,
   для реализации в сетях IPv4 требуется какой-то другой механизм. Обычно для этого требуется вставить что-то в сетевой стек
   для перехвата отправляемого трафика и применить соответствующие политики IPSec.
