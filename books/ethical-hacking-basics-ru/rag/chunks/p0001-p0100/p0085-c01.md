   nslookup

   Еще один инструмент, который можно использовать, — nslookup. Его можно использовать так же, как утилиту host  , то есть
   можно просто запустить nslookup www.sybex.com и получить ответ. Однако преимущество nslookup заключается в том, что
  вы можете отправлять множество запросов без необходимости каждый раз запускать nslookup . Когда вы запускаете
    nslookup без каких-либо параметров, вы попадаете в оболочку nslookup  , где вы взаимодействуете с программой, сразу
   отправляя запросы.

     $ nslookup
     > set type=ns
     > sybex.com
     Server: 192.168.86.1
     Address: 192.168.86.1#53
     sybex.com nameserver = jws-edcp.wiley.com.
     sybex.com nameserver = ns.wiley.co.uk.
     sybex.com nameserver = ns2.wiley.co.uk.
     sybex.com nameserver = sg-ns01.wiley.com.
     sybex.com nameserver = bri-ns01.wiley.com.
     sybex.com nameserver = ns.wileypub.com.
     Authoritative answers can be found from:
     > set type=A
     > server ns.wileypub.com.
     Default server: ns.wileypub.com.
     Address: 12.165.240.53#53
     > www.sybex.com
     Server: ns.wileypub.com.
     Address: 12.165.240.53#53
     Name: www.sybex.com
     Address: 208.215.179.132

   Вместо того, чтобы просто искать IP-адрес по FQDN, я для начала использовал записи ресурсов. DNS поддерживает
   несколько записей ресурсов, хотя наиболее распространенной является запись адреса (A). При вводе команды set
   type=ns  , я указываю nslookup  выдавать последующие запросы с запросом записей сервера имен (NS). Это сообщит нам
   авторитетные серверы имен для данного домена. Получив список NS, я смог указать конкретный NS сервер, который должен
   обработать мой запрос. Это означает, что вместо обращения к моему серверу кэширования, nslookup  отправит DNS-запрос
   непосредственно авторитетному серверу, которому не придется выполнять какой-либо рекурсивный поиск, поскольку у него
   уже есть запрашиваемая информация.

   dig

   Программа dig — еще одна утилита, которую можно использовать для разрешения имен. Он также поддерживает то же
   самое, что и указанные выше, то есть мы можем указать другой сервер имен, а также запрашивать разные записи ресурсов.
   Например, в командной строке можно указать всю информация для запроса, включая тип записи ресурса, запрос, а также
   сервер, которому должен быть отправлен запрос.
