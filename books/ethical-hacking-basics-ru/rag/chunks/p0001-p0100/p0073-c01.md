  Шаг 2

   Компании

   Есть несколько отправных точек, когда дело доходит до получения информации из открытых источников о вашей цели. Во-
   первых, стоит взглянуть на компанию в целом. Вам понадобится собрать информацию о ресурсах, которые есть у компании.
   Бывают случаи, когда это может быть легко, однако с каждым разом все становится сложнее. Причина заключается в том,
   что компании осознают: чем больше информации они предоставляют, тем больше эта информация может быть
   использована против них. Поэтому, если они не обязаны предоставлять эту информацию по правилам/законам, они ее не
   предоставляют.

   Есть несколько ресурсов, которые можно использовать для сбора информации о компаниях. Иногда эти ресурсы можно
   использовать для сбора информации, которая может быть использована для атак социальной инженерии. В некоторых
   случаях вы сможете собрать подробную информацию о сети компании. Оба типа информации могут быть полезны.
   Подробная информация о компании, ее организационной и управленческой структуре может быть получена из базы данных,
   поддерживаемой правительством США, в случае предприятий, зарегистрированных в США.

   Публичные компании обязаны предоставлять информацию о себе. Есть ресурсы, которые вы можете использовать для
   поиска этой информации. В процессе вы можете собрать информацию об организационной структуре компании.
   Организационная структура может сказать вам, кто занимает какую должность, поэтому, когда вы работаете над отправкой
   фишинговых сообщений для последующего сбора дополнительной информации, вы знаете, от чьего имени они точно будут
   прочитаны.

                                                                которой хранятся все публичные документы, связанные
                                                                  с компанией. Систему электронного сбора, анализа и
                                                               поиска данных (EDGAR - Electronic Data Gathering,
                                                                             Analysis, and Retrieval) можно использовать для поиска

   подробную информацию о планах опционов на акции для сотрудников, также передается в EDGAR. Получить доступ к EDGAR
   так же просто, как перейти к EDGAR на веб-сайте SEC.
