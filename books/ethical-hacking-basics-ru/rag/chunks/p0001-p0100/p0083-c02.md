   Запрос D отправляется c запросом IP-адреса хоста www.labs.domain.com  , где и получает его. На самом деле он может
   получить несколько IP-адресов, но для простоты представим, что он возвращает один IP-адрес.

   Как только наш кеширующий DNS-сервер получает IP-адрес, он отправляет ответ обратно в нашу систему, которая затем
   может выдать запрос E, который является уже запросом на соединение с веб-сервером.

   Хотя считается, что DNS хранит только сопоставления между полными доменными именами и IP-адресами, это не так.
   Существуют другие типы записей, которые вы можете использовать:

      • A: Представляет собой запись адреса и преобразует FQDN в IP-адрес.
      • AAAA: запись AAAA преобразует FQDN в адрес IPv6.
      • MX: Каждый домен имеет запись почтового обменника, используемую для указания хоста, на который должна
        отправляться электронная почта для этого домена.
