      • NS: записи сервера имен представляют собой FQDN и IP-адреса авторитетных серверов имен для этого домена.
      • SOA: начало авторитетной записи содержит информацию о зоне, включая серийный номер, указывающий, когда
       информация о зоне менялась в последний раз.
      • CNAME: каноническое имя — это псевдоним FQDN. Это сопоставляет одно имя хоста с другим именем хоста или
       полным доменным именем. CNAME может относиться конкретно к имени хоста, поскольку доменное имя уже может
       быть предполагаемым, если оно находится в том же домене.
      • PTR: указатель IP-адреса на FQDN. В отличие от записи A, это не обязательно, но считается полезным. FQDN всегда
       должно сопоставляться с IP-адресом, но IP-адрес не обязательно должен сопоставляться с одним FQDN. Часто
        несколько FQDN могут соответствовать одному IP-адресу.

   Существуют и другие записи, некоторые из которых относятся к безопасности электронной почты и указывают ключи

   для получения этих адресов.

  Шаг 8

   host

   Возможно, самый простой в использовании инструмент — это утилита host . Это программа, которую вы найдете в
   большинстве Unix-подобных систем, включая системы Linux. К сожалению, аналога для Windows у него нет. Использовать его
   очень просто - вы просто передаете имя хоста, для которого хотите разместить IP-адрес, и получаете ответ.

     $ host www.sybex.com
     www.sybex.com has address 208.215.179.132

     $ host www.sybex.com 4.2.2.1
     Using domain server:
     Name: 4.2.2.1
     Address: 4.2.2.1 # 53
     Aliases:
     www.sybex.com has address 208.215.179.132

     $ host 208.215.179.132
     132.179.215.208.in-addr.arpa domain name pointer motorfluctuations.net.
     132.179.215.208.in-addr.arpa domain name pointer managementencyclopedia.org.
     132.179.215.208.in-addr.arpa domain name pointer smdashboard.wiley.com.
     132.179.215.208.in-addr.arpa domain name pointer elansguides.com.
     132.179.215.208.in-addr.arpa domain name pointer currentprotocols.net.
     132.179.215.208.in-addr.arpa domain name pointer geographyencyclopedia.com.

     132.179.215.208.in-addr.arpa domain name pointer jcsm-journal.com.
     132.179.215.208.in-addr.arpa domain name pointer literature-compass.com.

   Помимо простого поиска IP-адреса, мы можем использовать для получения информации другой DNS-сервер, отличный от
   нашего. Как видите, во втором запросе я добавил его IP-адрес в командную строку. Поскольку это также кеширующий
   сервер, открытый для использования кем угодно, мы можем отправлять к нему запросы, и будет проходить тот же процесс,
   описанный ранее, как если бы это был наш собственный кеширующий сервер.
