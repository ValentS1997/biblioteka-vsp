  Вы также можете довольно быстро увидеть, как получить еще меньшие значения префикса, просто взглянув на количество
   битов в каждом октете. Если первый октет используется для обозначения сети, а все остальные используются для значений
    хоста, все позиции битов в этом первом байте будут заполнены, что означает, что вы используете 8 бит, и у вас останется
   обозначение CIDR /8 . Аналогично, если вы используете первые два октета, вы используете 16 бит, поэтому у вас есть /16 .

   Однако по поводу подсетей есть одно замечание: есть два значения, которые нельзя использовать для систем:

       1. Для сети используется наименьший возможный адрес в любом сегменте сети.
       2. В качестве широковещательного адреса используется максимально возможный адрес в любом сегменте сети.

   В обычной сети /24 адрес .0 становится сетевым адресом, а адрес .255 используется для широковещательной
   передачи. Ни один из них не может быть выделен для хостов.

   IPv6 делает весь процесс еще проще. При указании сетевого адреса больше не используются маски подсети. Вместо этого
   обозначение CIDR используется исключительно для указания того, какая часть является сетью, а какая — хостом.
