  Шаг 5

   Хотя системы и связанные с ними IP-адреса представляют собой хорошие точки входа для технических атак (против
   доступных услуг), контактная информация для людей может быть более полезной. Есть и другие места, куда мы можем
   пойти, чтобы получить списки людей, принадлежащих к целевой организации. Опять же, есть утилиты, которые мы можем
   использовать, чтобы помочь нам собрать эту информацию.
   Одна из них — «Харвестер». Это скрипт, который будет искать в различных источниках контактную информацию на основе
   предоставленного программе доменного имени . В следующем коде вы можете увидеть результаты выполнения Harvester
   для домена wiley.com с использованием поисковой системы Bing. Можно также использовать другую поисковую систему
   DuckDuckGo, но она не дала результатов по людям, хотя и дала один хост.

   Bing — не единственный источник, который можно использовать с Harvester. Другие источники поиска включают VirusTotal,
   ThreatCrowd и Yahoo. Многие из них требуют от вас регистрации в службе для полученияключа интерфейса прикладного
   программирования (API - application programming interface), чтобы вы могли предоставить его theHarvester. Без ключа
   theHarvester не сможет отправлять запросы этим поисковым службам. Это помогает защитить их от неправильного
   использования.
