  Шаг 12

   Sni  ng

   Как отмечалось ранее, Wireshark можно использовать для захвата сетевого трафика, включающего радиозаголовки.
   Радиозаголовки важны, когда вы пытаетесь собрать информацию. Однако это не единственные заголовки, несущие
   информацию. Вы захотите увидеть все маяки от точек доступа и любые сообщения аутентификации, которые могут
   отправляться между станциями и точками доступа. Чтобы увидеть весь стек, вам необходимо перевести беспроводной
   интерфейс в режим монитора. Один из способов сделать это — использовать программу airmon-ng из пакета aircrack-
   ng . В следующем листинге кода вы можете увидеть использование airmon-ng для создания интерфейса монитора из
   беспроводного интерфейса. В итоге у вас есть новый интерфейс, который можно использовать для сбора радио- и другого
   трафика.

     root@quiche:~# airmon-ng start wlan0

     Found 3 processes that could cause trouble. Kill them using 'airmon-ng check kill' before putting
     the card in monitor mode, they will interfere by changing channels and sometimes putting the
     interface back in managed mode

      PID Name
      640 wpa_supplicant
      30835 NetworkManager
      30859 dhclient

      PHY    Interface   Driver       Chipset
      phy0   wlan0       rt2800usb    Ralink Technology, Corp. RT5372

      (mac80211 monitor mode vif enabled for [phy0]wlan0 on [phy0]wlan0mon)
      (mac80211 station mode vif disabled for [phy0]wlan0)

   В начале вы заметите несколько предупреждений. Это связано с тем, что версия Linux, под которой он работает, управляет
   сетевыми интерфейсами. airmon-ng должен иметь возможность вносить изменения в сетевые интерфейсы, а это означает,
   что лучше, если процессы, управляющие интерфейсами, не запущены.

   Хотя этот пример работает под Linux, у aircrack-ng есть пакет для Windows, и там можно использовать те же программы.
   После создания интерфейса монитора вы можете использовать его так же, как и любой другой сетевой интерфейс. Вы
   можете использовать tcpdump для захвата всего сетевого трафика, проходящего через интерфейс монитора. В следующем
   листинге вы можете увидеть использование tcpdump с использованием интерфейса wlan0mon  , созданного airmon-ng .
