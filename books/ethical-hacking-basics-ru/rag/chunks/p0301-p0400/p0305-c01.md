  Шаг 8

   Wi-Fi Protected Access 3

   В 2018 году Wi-Fi Alliance представил Wi-Fi Protected Access 3 (WPA3), чтобы помочь защититься от некоторых недостатков
   WPA2. Во-первых, разрешено использовать более длинные ключи шифрования, вплоть до AES-256 с SHA-384 для
   криптографического хеширования для аутентификации сообщений.

   Кроме того, WPA3 вводит одновременную аутентификацию равных (SAE - Simultaneous Authentication of Equals) для удаления
   предварительного общего ключа. Использование предварительно общего ключа является недостатком, поскольку это часть
   информации, которую сложно полностью защитить. Если для аутентификации используются общие ключи, любой, кто
   сможет получить общий ключ, сможет выполнить аутентификацию. SAE — это стратегия аутентификации на основе пароля,
   используемая для согласования ключей, которые затем используются для шифрования сеанса между станцией и точкой
   доступа.

   Процесс аутентификации и ассоциации с использованием SAE отличается от четырехстороннего процесса, описанного ранее.

       1. Станция (STA) отправляет тестовый запрос точке доступа (AP).
       2. AP отправляет тестовый ответ на STA.
       3. STA отправляет подтверждение аутентификации точке доступа. Это используется для генерации парного главного
       ключа (PMK) на STA. Это кадр аутентификации 802.11.
       4. AP отправляет подтверждение аутентификации STA. Это используется для генерации парного главного ключа на точке
        доступа. Это также кадр аутентификации 802.11.
       5. STA отправляет AP подтверждение аутентификации. Это кадр аутентификации 802.11. Оно содержит сообщение с
       ключом, сгенерированным для проверки точкой доступа.
       6. AP отправляет подтверждение аутентификации STA. Это также кадр аутентификации 802.11. Он содержит сообщение с
       ключом, сгенерированным для проверки STA.
       7. Регулярный запрос ассоциации.
       8. Регулярная реакция ассоциации.
       9. Четырехстороннее рукопожатие с использованием PMK, созданного на предыдущих шагах.
