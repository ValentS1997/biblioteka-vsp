  Шаг 2

  Сканирование

   Прежде чем мы зайдём слишком далеко по пути атак, нам следует рассмотреть, как определить, где могут находиться
   потенциальные жертвы. Вы можете просто добавить устройство Bluetooth, и ваша система выполнит поиск устройств.
   Однако вы также можете использовать специальное программное обеспечение. Это можно сделать с помощью такой
   программы, как btscanner . С помощью btscanner вы можете выполнять как сканирование по запросу, так и
   сканирование методом перебора. При сканировании по запросу ваша система переходит в состояние сканирования по
   запросу. В этом состоянии ваше устройство прослушивает запросы от других устройств. Всего имеется 32 канала, и вашему
   Bluetooth-приемнику приходится тратить время на прослушивание каждого из них. В следующем листинге вы можете
   увидеть, как btscanner выполняет сканирование по запросу.

     Time                Address           Clk off  Class    Name

     2022/12/25 17:58:22 64:1C:B0:94:BA:58 0x2c42   0x0c043c (unknown)
     2022/12/25 17:56:07 00:9E:C8:93:48:C9 0x38b3   0x0a0110 (unknown)

   Другой тип сканирования — сканирование методом перебора (brute-force). В то время как при сканировании запроса
   получатель прослушивает запросы, при сканировании методом перебора сообщения устройствам активно отправляются,
   чтобы определить, что они собой представляют. Для этого ему нужны адреса для отправки сообщений. Этот тип соединения
   происходит на уровне 2, а это значит, что мы говорим о MAC-адресах. В следующем листинге вы можете увидеть
   использование btscanner для выполнения перебора. Чтобы запустить это сканирование, вам нужно сообщить btscanner
   начальный и конечный адрес, который вы хотите сканировать, и вы увидите запрос на это. Вам необходимо будет
   предоставить это в виде MAC-адреса. Имейте в виду, что каждый октет имеет 256 значений, поэтому чем больше октетов
   адреса вы хотите пройти, тем больше времени займет сканирование.

     Time                Address           Clk off  Class    Name
     2023/03/02 18:39:47 A8:51:AB:9C:66:ED 0x0000   0x000000 kilroy4KTV

     Scanned device A8:51:AB:9C:66:FC (99%)
     Scanned device A8:51:AB:9C:66:FD (99%)
     Scanned device A8:51:AB:9C:66:FE (100%)
     Scanned device A8:51:AB:9C:66:FF (100%)

   Этот тип сканирования предоставит вам списки устройств. Он не сообщит вам профили, которые поддерживают устройства.
   Простого наличия списка устройств поблизости может быть достаточно для проведения некоторых атак, обычно
   используемых против устройств Bluetooth.
