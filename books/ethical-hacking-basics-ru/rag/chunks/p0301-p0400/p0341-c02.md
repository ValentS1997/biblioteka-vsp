особ защиты от этой атаки состоит в том, чтобы не допустить выполнения чего-либо в стеке. Поскольку код программы
   находится в другом сегменте памяти, нет причин, по которым стек должен содержать какой-либо код, подлежащий
   выполнению. Однако есть способы обойти это ограничение - один из них называется возвратом в libc (Return-to-libc attack).
   Стандартная библиотека C, содержащая все стандартные функции, включенные в язык C, часто хранится в памяти и
   используется всеми программами, написанными на C и скомпилированными для использования общей библиотеки. Эта
   библиотека может храниться в известном месте памяти, а это значит, что адрес возврата может быть перезаписан
   расположением функций из стандартной библиотеки C, которые могут быть использованы злоумышленником. Даже если
   местоположение библиотеки неизвестно, его можно определить с помощью некоторых проб, поскольку функции C могут
   распечатывать местоположения памяти. Одним из способов защиты от некоторых из этих проблем является рандомизация
   расположения адресного пространства (ASLR - address space layout randomization).
