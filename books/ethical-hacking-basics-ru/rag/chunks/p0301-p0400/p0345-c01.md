   Горизонтальное перемещение использует те же стратегии, которые использовались до сих пор: дополнительная разведка
   для выявления возможных целей, сбор учетных данных и использование различных доступных средств для получения
   удаленного доступа к другим системам. Переход из системы Linux в систему Linux может быть таким же простым, как
   использование Secure Shell (SSH) для получения удаленного доступа с использованием собранных учетных данных. Со
   стороны Windows существуют и другие механизмы, которые можно использовать для перехода из одной системы в другую.

   Распространенным подходом к горизонтальному перемещению является сбор учетных данных из системы-жертвы. Эти
   учетные данные могут быть получены непосредственно из памяти, либо из области памяти операционной системы, либо
   даже из памяти приложения. Такие инструменты, как Mimikatz, полезны для сбора паролей. Получив учетные данные, вы
   можете использовать эти учетные данные в других системах в той среде, в которой вы находитесь. Вы также можете
   использовать такие методы, как Kerberoasting, описанные ранее в 7 модуле, чтобы получить доступ к другим системам,
   которые помогут вам двигаться дальше внутри окружающей среды.

   Когда злоумышленники собирают имена пользователей и пароли (учетные данные), они могут использовать технику,
   называемую подстановкой учетных данных (credential stu  ng). По сути, это атака, при которой злоумышленник пытается
   использовать известные учетные данные в новых системах, которые он преследует. Они вставляют известные учетные
   данные в попытки аутентификации, не зная, сработают ли эти учетные данные. Поскольку имена пользователей и пароли
   часто используются повторно, атаки с подстановкой учетных данных могут быть успешными. Для защиты от этих атак
   можно использовать несколько методов: ограничить количество неудачных попыток злоумышленника. Часто это делается
   по имени пользователя, когда несколько неудачных попыток входа в систему приводят к блокировке учетной записи. Это не
   касается случая, когда злоумышленник не использует одно и то же имя пользователя и разные пароли, а вместо этого
   меняет имя пользователя и пароль. Блокировка IP-адреса в случае нескольких неудачных попыток входа из одного места
   может эффективно замедлить атаку злоумышленника. Кроме того, повсеместное использование многофакторной
   аутентификации может существенно замедлить атаку злоумышленника.

   В некоторых случаях, системы Windows могут разрешать удаленному управлению Windows (WinRM) выполнять
   административные функции в других системах. Предполагается, что у вас есть учетные данные в удаленной системе, что
   может быть так же просто, как использование учетных данных домена, если вы находитесь на контроллере домена. Если
   служба WinRM запущена, вы также можете удаленно запускать команды PowerShell для выполнения административных
   задач.

   Существует атака Living off the Land (LotL), которую широко используют злоумышленники. Несколько лет назад у
   злоумышленников могли быть наборы инструментов, которые им нужно было загружать на хост жертвы, при этом часто
   использовалось скомпилированное программное обеспечение. Сегодня злоумышленники в большинстве случаев
   используют легитимные инструменты и механизмы, присутствующие в целевой системе. Например, системы Linux обычно
   имеют интерпретатор Python  , и его можно использовать для нескольких целей. Со стороны Windows доступен PowerShell  ,
   и каждый последующий выпуск добавлял множество новых возможностей.
