   Беспроводные сети могут быть атакованы. В сетях, использующих WEP, ключ шифрования можно получить, если из
   беспроводной сети было собрано достаточно кадров. Обычные приложения для анализа, такие как Wireshark, можно
   использовать для анализа беспроводных сетей. Беспроводной интерфейс необходимо перевести в режим мониторинга для
   сбора радиозаголовков. Wireshark может сделать это самостоятельно, в зависимости от сетевого интерфейса. Вы также
   можете использовать программу airmon из пакета aircrack-ng. Вы также можете использовать aircrack-ng, чтобы попытаться
   взломать пароль, используемый для сети.

   Один из способов собрать достаточно данных — использовать атаку деаутентификации. Эта атака отправляет клиентам
   сообщения о том, что они были деавторизованы в сети. Атакующая система подделывает сообщения так, будто они исходят
   от точки доступа. Одновременно с этим злоумышленник может попытаться заглушить точку доступа, чтобы сигнал не дошел
    и, что более важно, не ответила на станцию. Злоумышленник может постоянно отправлять эти сообщения о разъединении,
   чтобы заставить станцию-жертву продолжать отправлять сообщения, пытающиеся пройти аутентификацию в сети.

   Атаки «злых двойников» заключаются в том, что злоумышленник устанавливает сеть, которая выглядит как законная сеть с
   тем же SSID. Станции будут пытаться пройти аутентификацию на несанкционированной точке доступа. Мошенническая точка
   доступа может затем собрать любые учетные данные для аутентификации и как только станция пройдет их, злой двойник
   разрешит соединение, собирая трафик со станции, как только станция будет подключена.

   Другая атака — это атака переустановки ключа. Это атака, при которой трафик повторно используется, чтобы заставить
   станцию использовать уже известный ключ. Это означает, что злоумышленник знает, что такое ключ, а это значит, что
   трафик можно расшифровать.

   Конечно, 802.11 — не единственный протокол беспроводной связи. Часто используется Bluetooth. Существует несколько атак
    Bluetooth, однако некоторые из них могут быть устаревшими и не работать на современных устройствах. Но существует
   множество устаревших устройств, использующих старые реализации Bluetooth , в которых эти атаки могут работать.

    Bluejacking использует Bluetooth для отправки сообщения в целевую систему. Bluesnar ng собирает данные из целевой
   системы с помощью Bluetooth. Bluebugging использует Bluetooth для подключения к целевой системе, а затем инициирует
   вызов из целевой системы, чтобы разговоры могли быть прослушаны.

   Мобильные устройства обычно используют беспроводные протоколы, такие как 802.11 и Bluetooth. Существуют способы
   внедрения вредоносных приложений на мобильные устройства, такие как планшеты и смартфоны. Это можно сделать с
  помощью стороннего магазина приложений, который пользователи могут добавить в качестве опции на свое устройство.
   Мобильные устройства также уязвимы для тех же видов атак, что и настольные компьютеры, таких как фишинг, вредоносное
  ПО и ошибки программирования, которые могут открыть дверь для утечки данных.
