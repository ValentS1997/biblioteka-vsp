   Первой атакой такого типа был SYN-флуд, который заполнял буферы соединений на веб-сервере. Для отправки запросов не
   требовалось много запросов, и для их отправки требовалась очень небольшая пропускная способность. Сейчас эта атака
   больше не эффективна и легко блокируется на самых примитивных сетевых устройствах.

   Однако концепция остается возможной. Целью атаки Slowloris (названной в честь животного медленного лори, примата,
   обитающего в Юго-Восточной Азии) является отправка неполных запросов на веб-сервер. Когда запросы отправляются,
   трехстороннее рукопожатие завершается, поэтому буфер SYN не учитывается. Вместо этого важным фактором является
   количество одновременных запросов, которые веб-сервер может обработать. Веб-серверы могут быть настроены на
   ограниченное количество потоков, которые могут выполняться одновременно - это позволяет веб-серверу не потреблять
   слишком много ресурсов системы. Однако, как только все потоки будут израсходованы, дальнейшие соединения не могут
   быть приняты. Атака Slowloris может быть успешной против веб-серверов. Фактически, в следующем листинге кода вы
   можете увидеть запуск программы Slowhttptest  , которую можно использовать для запуска атаки Sloloris. В результате
   выполнения кода в течение 26 секунд, установленный по умолчанию Apache перестал отвечать на запросы. Конечно, это не
   так уж впечатляюще, поскольку установка Apache по умолчанию на одном сервере не настроена на прием большого
   количества запросов.

   Программу Slowhttptest  также можно использовать для запуска других HTTP-атак, в том числе R-U-Dead-Yet, еще одной
   атаки с медленными запросами, которая использует тело HTTP, а не заголовки HTTP, как это делает Slowloris.

   Другой вид атаки - атака Apache Killer   - в этом случае программа отправляет запросы с запросом перекрывающихся
   диапазонов байтов. Это приводит к потреблению памяти на сервере из-за ошибки в серверной программе Apache. Эта атака
   нацелена на конкретные версии Apache, тогда как другие атаки связаны с конфигурацией сервера, а не с ошибкой в
   программном обеспечении.

   Также Slowhttptest поддерживает атаку медленного чтения. Это когда программа запрашивает большой файл с веб-
