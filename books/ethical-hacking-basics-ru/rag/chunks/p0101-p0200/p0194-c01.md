  Шаг 5

   Уклонение (Evasion)

   Как только у вас появится точка входа, которая может включать имена пользователей и пароли или реальный удаленный
   доступ к системе, вы можете столкнуться с первыми проблемами - рабочие станции, и серверы будут иметь, по крайней мере,
   антивирусное ПО, либо программное обеспечение для обнаружения и реагирования на конечных точках (EDR - Endpoint
    detection and response), которое будет искать аномальное поведение, поскольку умеет определять популярные методы атак.
   Поэтому необходимо использование тактик уклонения.

   Одним из возможных способов уклонения является обнаружение файлов, главным образом на диске. Возможно, вы сможете
   использовать такие методы, как альтернативные потоки данных, упомянутые позже. Вы также можете зашифровать или
  иным образом запутать данные. Зашифрованные zip-файлы — один из способов обойти обнаружение антивирусным
   программным обеспечением.

   Однако когда дело доходит до исполнения, у нас возникает другая проблема - программное обеспечение для защиты от
   вредоносных программ может иметь способы обнаружения исполняемых файлов. Данную проблему можно обойти ,
   используя PowerShell для выполнения той же задачи. Для сценария PowerShell может отсутствовать обнаружение, особенно
   если вы пишете свой собственный, и вы можете выполнить ту же задачу, которую выполняет за вас собственный
   исполняемый файл. Одна из проблем PowerShell — возможность журналирования, поскольку это может облегчить
   обнаружение постфактум, но не в том случае, если PowerShell невозможно прочитать. В качестве примера ниже приведен
   запутанный (обфусцированный) пример PowerShell:

   В нашем примере использовался командлет PowerShell Invoke-Obfuscation  , написанный Дэниелом Боханноном, который
   берет сценарий PowerShell и запутывает его. Существуют разные способы выполнения обфускации. Ниже приведены
   методы, которые можно использовать для запутывания PowerShell с помощью этого командлета:

     Choose one of the below options:

     [*] TOKEN     Obfuscate PowerShell command Tokens
     [*] AST       Obfuscate PowerShell Ast nodes (PS3.0+)
     [*] STRING    Obfuscate entire command as a String
     [*] ENCODING  Obfuscate entire command via Encoding
     [*] COMPRESS  Convert entire command to one-liner and Compress
     [*] LAUNCHER  Obfuscate command args w/Launcher techniques (run once at end)

   Существует несколько других способов запутать сценарии и данные. Это может включать в себя такие методы, как
   кодирование полезных данных, созданных с помощью Metasploit.

   В конечном итоге ваша цель — получить доступ к системе, что может включать в себя загрузку файлов в систему без
   обнаружения или, что более вероятно, выполнение программ в целевой системе.
