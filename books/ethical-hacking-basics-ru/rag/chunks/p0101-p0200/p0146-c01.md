Stepik                                                                                              https://stepik.org/lesson/1238846/plain?is_print=true
   использует компилятор RMI (программа rmic ), при этом информация о данной программе сохраняется в реестре. Закладка
   обращается в реестр на сервере, причем ей не нужно знать конкретные интерфейсы используемые службы, поскольку
   единственное, что делает перечисление, — это идентифицирует службу по имени на удаленной системе.

   В качестве примера, запустим сканирование системы с RMI с помощью Metasploit.

     msf> use auxiliary/gather/java_rmi_registry
     msf auxiliary(gather/java_rmi_registry)> show options
     Module options (auxiliary/gather/java_rmi_registry):
      Name Current Setting Required Description
      ---- --------------- -------- -----------
      RHOST yes The target address
      RPORT 1099 yes The target port (TCP)
     msf auxiliary(gather/java_rmi_registry)> set RHOST 192.168.86.62
     RHOST => 192.168.86.62
     msf auxiliary(gather/java_rmi_registry)> run
     [*] 192.168.86.62:1099 - Sending RMI Header…
     [*] 192.168.86.62:1099 - Listing names in the Registry…
     [+] 192.168.86.62:1099 - 1 names found in the Registry
     [+] 192.168.86.62:1099 - Name HelloServer (HelloImpl_Stub) found on
     127.0.1.1:38371
     [*] Auxiliary module execution completed

   Параметры, необходимые для запуска модуля java_rmi_registry  , просты. По умолчанию, удаленный порт имеет значение
    1099  , который прослушивает rmiregistry . Если вы считаете, что есть другой порт, который прослушивает, вы можете
   установить переменную RPORT . Однако наиболее важным является значение RHOST  , в котором указывается IP-адрес
   системы, в которой есть простая программа Java, реализующая сервер RMI. Согласно реестру RMI, существует сервис с
   именем HelloServer . Он даже сообщает нам, что закладка называется HelloImpl_Stub .

   Metasploit — не единственный способ сканирования служб RMI. Если немного осмотреться, то можно найти дополнительные
   программы. Один из них называется Barmie  , стилизован под BaRMIe  , чтобы подчеркнуть RMI в названии. Вы можете
   получить исходный код, а также предварительно скомпилированную реализацию BaRMIe через GitHub. Запуск программы
   прост - поскольку это программа Java, вам необходимо запустить файл промежуточного кода через программу Java,
   используемую для создания виртуальной машины Java. Поскольку он хранится в виде архива Java (JAR - Java archive), вам
   необходимо указать его с параметром -jar . Также необходимо прописать IP-адрес вашей цели.
