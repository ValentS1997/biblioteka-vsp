   Есть несколько важных фрагментов информации, которые мы можем использовать для поиска с помощью nmap.
   Существуют сценарии перечисления для пользователей, групп, служб, процессов и общих ресурсов. Некоторые из них
   требуют аутентификации, прежде чем удаленная система что-либо откажет. Microsoft начала отключать аутентификацию
   нулевого сеанса в Windows Server 2008 R2 и Windows 7. Любая операционная система после этого будет требовать
   аутентификацию перед доступом к межпроцессному взаимодействию, необходимому для извлечения запрошенной
   информации. Однако этот параметр можно отключить, и никогда не знаешь, когда столкнешься с очень устаревшими или
   неправильно сконфигурированными системами.

   В качестве примера ниже приведен сбой сценария smb-enum-shares  , используемого для перечисления общих ресурсов с
  помощью nmap. Несмотря на то, что для работы потребовалась аутентификация, скрипт все равно показал перечень
   доступных общих ресурсов.
