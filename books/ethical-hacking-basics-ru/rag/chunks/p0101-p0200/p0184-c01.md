   Во-первых, это центр распределения ключей (KDC - key distribution center). KDC — это распространенная служба, используемая
   в криптосистемах для защиты управления ключами. Над KDC находится служба выдачи билетов (TGS - ticket granting service),
   которая выдает сообщения с отметкой времени, называемые билетами (TGT - ticket-granting tickets), которые
   зашифровываются с использованием секретного ключа TGS. Отметка времени и зашифрованное сообщение помогают
   защитить билет от подделки, поскольку для них требуется ключ шифрования, принадлежащий TGS. Кроме того, поскольку
   они имеют отметку времени, они могут помочь защитить от атак повторного воспроизведения, когда в сеть попадает
   сообщение, которое было ранее перехвачено, чтобы получить доступ к службе, защищенной Kerberos.

   Чтобы выполнить атаку Kerberoasting, вам необходимо скомпрометировать доменную учетную запись.
   Скомпрометированная учетная запись пользователя после успешной аутентификации получает TGT от KDC. Злоумышленник,
   который контролирует учетную запись скомпрометированного пользователя, хочет скомпрометировать службу в сети. Для
   чего необходимо запросить билет на обслуживание для этой услуги (TGS). Контроллер домена с инфраструктурой Active
    Directory на основе запроса создаёт билет TGS, зашифровав его с помощью пароля службы, полученного из базы данных AD.
   Единственные два объекта, у которых есть пароль, способный расшифровать сообщение на этом этапе — это контроллер
   домена и сама служба. Контроллер домена отправляет пользователю билет, находящийся под контролем злоумышленника.
   Данный билет можно предоставить службе, которая расшифровывает его, чтобы определить, предоставлено ли
   пользователю разрешение на доступ к службе. Этот билет находится в памяти, и его можно извлечь оттуда, чтобы
   расшифровать (или взломать) в автономном режиме.

   Существует ряд инструментов, которые можно использовать для реализации атаки Kerberoasting. Одним из них является
   инструмент под названием Rubeus . Ниже приведен пример запуска Rubeus на контроллере домена Windows по адресу
   192.168.4.218. Этот запуск предоставляет имя пользователя и пароль, которые имеют учетные данные для проверки
   подлинности в домене. Вы также можете предоставить хеш пароля, если он у вас есть. Это позволит получить билет для
   этого пользователя. Билет можно сохранить в файл и использовать позже.
