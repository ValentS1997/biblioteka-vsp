    Metasploit, как всегда, имеет большое количество модулей, которые можно использовать для веб-перечисления, помимо
   простого определения каталогов на веб-сервере. Когда вы начнете работать с веб-сайтами и, в частности, с веб-
   приложениями, вы столкнетесь со множеством приложений с открытым исходным кодом, которые хорошо известны,
   поскольку они широко используются. В качестве примера вы можете найти установку того же WordPress, либо другой
   популярной CMS (Content management system) . При этом также используя Metasploit, мы можем перечислить пользователей,
   используемых в работе WordPress. Модуль wordpress_login_enum может использовать файл с именами пользователей или
   файл с их паролями, либо вы можете предоставить одно имя пользователя с файлом паролей или один пароль с файлом
   имени пользователя. В модуле можно установить ряд других опций, предоставляющих множество возможностей.

     msf auxiliary(scanner/http/wordpress_login_enum)> set BLANK_PASSWORDS true
     BLANK_PASSWORDS => true
     msf auxiliary(scanner/http/wordpress_login_enum)> set RHOSTS 192.168.86.52
     RHOSTS => 192.168.86.52
     msf auxiliary(scanner/http/wordpress_login_enum)> run
