  До сих пор мы рассматривали использование инструментов, которые могут понадобиться для доступа к удаленной
   системе.Распространенный подход сегодняшних злоумышленников, а также всех, кто занимается тестированием
   безопасности, — это то, что называется «жить за счет земли» (Living Off the Land). Это означает использование инструментов,
   которые уже доступны в целевой системе.

   К счастью, когда дело касается систем Windows, мы получаем большую помощь. Microsoft предоставляет все более мощный
   язык программирования PowerShell, имеющий максимальную интеграцию с токими настройками Windows. Хотя он,
   возможно, был ограничен, когда его впервые представили в 2006 году, но в дальнейшем, было предпринято много попыток
   Microsoft улучшить сценарии и возможности Powershell в системах Windows. С другой стороны, в Linux с самого начала были
   встроены языки сценариев. Собственный интерфейс Linux всегда представлял собой интерфейс командной строки, который
   является интерпретатором языка сценариев, и называется "оболочкой".

   В последние годы Microsoft открыла возможность использования PowerShell для большего количества платформ, чем только
   Windows - его теперь можно использовать как с Linux, так и для macOS. Конечно, они немного отличается от PowerShell,
   встроенный в большинство установок Windows. Вы можете установить в Windows ту же версию PowerShell, что и версия для
   других операционных систем (7 версия), по-умолчанию в Windows 11 она не ставится (стоит 5 версия).

   PowerShell — это объектно-ориентированный язык программирования, который для обеспечения своей функциональности
   использует функции, называемые командлетами. Вместо простого языка и синтаксиса, PowerShell создан для расширенного
   использования. Конечно, вы можете использовать основные функции языка для написания программ, но вы также можете
   писать эти командлеты или использовать встроенные в язык, чтобы получить доступ к сложным функциям для задач.

   Помимо того, что PowerShell сам по себе является мощным языком программирования, на его основе разработано
   несколько сред эксплуатации. Например, Empire — это фреймворк для пост-эксплуатации, написанный на PowerShell.
   Другими словами, это набор инструментов, которые вы будете использовать после того, как провели удачный эксплойт
   целевой системы.
   Например, вы можете получить доступ к возможности легкого повышения привилегий или сбора паролей. Как и в случае с
    Metasploit, для этого требуется, чтобы в целевой системе, с которой вы общаетесь, был установлен агент. Вы можете
   получить ее исходный код, либо коллекцию скриптов PowerShell для закрепления в целевой системе, эксфильтрации,
   эскалации привилегий, разведки и других.

  Шаг 3

   Фаззинг

   Фаззингом (fuzzing) называется техника, которую можно использовать как для поиска ошибок в программном обеспечении,
   так и для потенциальной реализации атак типа «отказ в обслуживании». Это слово используется как сокращение для
   описания процесса отправки неожиданных или искаженных данных в приложение, чтобы увидеть, как это приложение их
   обрабатывает. Если приложение хорошо с этим справляется, ничего интересного не происходит - вы можете получить ошибку
   или данные могут быть просто удалены. Если приложение не справится с этим должным образом, приложение может выйти
   из строя - это уже более интересно.

   Когда-то было много разных проектов, выполнявших фаззинг. Некоторые из них больше не существуют или больше не
   поддерживаются. Некоторые из них стали коммерческими инструментами. Один из первых фаззеров появился в результате
   академического проекта. Он назывался Codenomicon и использовался для выявления серьезных уязвимостей в DNS и SNMP.
