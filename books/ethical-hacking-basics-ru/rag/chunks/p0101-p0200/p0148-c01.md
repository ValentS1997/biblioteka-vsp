   Итак, чем же хорош SMB? SMB используется для связи между системами Windows — совместного использования файлов,
   управления сетью, системного администрирования. Соответственно, для исключения конфликтов, необходимо управление
   именованием систем. SMB также должен поддерживать аутентификацию, чтобы системы не были широко открыты для всей
    сети, соответственно у него должна быть информация о пользователях и группах. Он также знает об общих ресурсах, то есть
   каталогах, доступных в сети. Системы должны иметь возможность предоставлять список общих ресурсов, которые они
   предоставляют и публикуют в сети для систем, которые их запрашивают. Это позволяет пользователю получить список
   общих ресурсов, а затем получить доступ к тем, которые он хочет, после аутентификации. Таким образом, аутентификация не
   всегда необходима, поэтому иногда в SMB используют "нулевую аутентификацию". Это означает, что есть некоторые
   функции, которые не требуют имени пользователя и пароля. Система может запрашивать информацию о другой системе в
    сети, используя нулевую аутентификацию, то есть без указания конкретных учетных данных. Эта нулевая аутентификация
   может позволить нам собрать много информации о системе.

  Мы можем использовать несколько различных инструментов для перечисления информации в системах Windows. На самом
   деле, речь идет даже не только о системах Windows, поскольку SMB может использоваться и в других системах. Samba — это
   пакет, который можно установить в Unix-подобных операционных системах, предоставляя SMB, а также службу именования
   NetBIOS. Samba использует два отдельных процесса. Один из них — smbd  , который обрабатывает SMB, а также nmbd  ,
   который отвечает за аспекты именования при взаимодействии с системами Windows. Это означает, что даже когда мы
   собираем информацию из систем Windows, мы также можем собирать информацию из Unix-подобных систем.

   Первое, с чего стоит начать, — это использование встроенных инструментов. Встроенные инструменты особенно доступны в
   системах Windows, но существуют и Unix-подобные утилиты. Мы также рассмотрим ряд плагинов, доступных для nmap для
   сбора информации. Metasploit, что неудивительно, имеет несколько модулей для сканирования SMB-систем.

  Шаг 6

  Встроенные утилиты

   Если вы используете систему Windows, существует ряд утилит, которые вы можете использовать для сбора информации с
  помощью SMB. Аналоги существуют и для Linux. В отношении встроенных утилит следует отметить одну важную вещь - для
   их использования вам необходимо находиться с целью в одном широковещательном домене.

   NetBIOS изначально был разработан для использования в локальной сети, а не со встроенной концепцией глобальных сетей.
   В результате некоторые функции работают, поскольку системы полагаются на широковещательную передачу информации в
   сегменте сети. Сбор статистики NetBIOS можно выполнить с помощью программы nbtstat . Это позволяет собирать данные
   о локальной сети. В следующем примере вы можете увидеть использование nbtstat для получения данных об удаленной
   системе. Использование команды nbtstat -a отобразит таблицу имен для указанного имени хоста. Если бы мы знали
   только IP-адрес удаленной системы, вместо этого мы могли бы использовать команду nbtstat -A . В результате, мы
   получаем список имен, за которым следует код (указывает контекст, в котором существует имя), и в конце следует статус
   каждого имени.
