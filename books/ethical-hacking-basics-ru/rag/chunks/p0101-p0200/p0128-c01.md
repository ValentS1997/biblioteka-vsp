   В верхней части страницы вы увидите три вкладки. Первая — это список хостов. Как отмечалось ранее, это упорядочено по
   общему количеству уязвимостей. Вторая вкладка — количество уязвимостей, упорядоченных по критичности. Критичные
   проблемы располагаются сверху, за ними следуют высокие, затем средние и так далее. Сканирование хостов в локальной
   сети выявило две разные критичные проблемы. Одна из них была связана с программным обеспечением Mozilla Foundation.
   По данным Nessus, на целевом хосте установлен либо Thunderbird, либо Firefox, и установленная версия больше не
   поддерживается. Вторая проблема связана с системой MacOS - установленная версия операционной системы также
   устарела.

   В отличие от OpenVAS, Nessus не дает возможности добавлять примечания к результатам. Однако есть одна вещь, которой
   нет в OpenVAS, — это контрольный журнал. Вы можете выполнить поиск по идентификатору плагина и хосту и получить
   дополнительную информацию о запущенном плагине. Как и OpenVAS, Nessus использует сценарии языка сценариев сетевых
   атак (NASL - Network Attack Scripting Language). Они хранятся вместе с остальной частью установки Nessus.

   Сканирование уязвимостей — это всего лишь очередной этап тестирования. Найденные уязвимости всегда следует
   проверять вручную. Кроме того, если вы должны выявить как можно больше уязвимостей, вам нужно будет перейти к
   эксплуатации этих уязвимостей для их подтверждения. Для этого может потребоваться использование инструментов
   эксплойта, таких как Metasploit, или даже инструментов, специально разработанных вами. Главное - какими бы ни были
   результаты, их необходимо дополнительно проверить, прежде чем показывать заказчику.

  Шаг 4

   Metasploit

   Metasploit — универсальный инструмент. Вы можете использовать его для взлома приложений, а также для сканирования
   портов, которое мы делали ранее. Поскольку это фреймворк и в нем много модулей, неудивительно, что существует
   множество сканеров уязвимостей. Одним из примеров является модуль сканера уязвимости Eternal Blue. Это уязвимость в
   реализации протокола Server Message Block (SMB), обнаруженная Агентством национальной безопасности, разработавшим
   для нее эксплойт, который был выпущен без одобрения АНБ группой под названием Shadow Brokers. Ниже приведен один из
   сканеров уязвимостей, который ищет системы, уязвимые для эксплойта Eternal Blue. Хотя исправление этой уязвимости на
   данный момент выпущено уже много лет назад, существует много систем, уязвимых для нее.

     msf6 auxiliary(scanner/portscan/syn)> use auxiliary/scanner/smb/smb_ms17_010
     msf6 auxiliary(scanner/smb/smb_ms17_010)> set RHOSTS 192.168.4.0/24
     RHOSTS => 192.168.4.0/24
     msf6 auxiliary(scanner/smb/smb_ms17_010)> run
     [-] 192.168.4.10:445 - Host does NOT appear vulnerable.
     [-] 192.168.4.15:445 - Host does NOT appear vulnerable.
     [*] 192.168.4.0/24:445 - Scanned 26 of 256 hosts (10% complete)
