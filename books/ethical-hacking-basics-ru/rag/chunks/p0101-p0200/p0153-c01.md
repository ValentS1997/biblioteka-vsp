   Metasploit

   В Metasploit есть модули практически для каждого аспекта этического взлома. Его можно использовать по-разному. Как
   было показано ранее, мы определенно можем использовать его для перечисления, а когда дело доходит до SMB, вы можете
   запустить несколько из них. В качестве примера мы можем поискать версии SMB, используемые в сети. В следующем
   листинге вы увидите запуск модуля smb_version  , который покажет версии запущенной службы SMB. Вы видите две
   системы, идентифицированные по указанной версии операционной системы. На основе этой информации вы можете
   определить поддерживаемую версию SMB. В системе Windows XP используется SMB версии 1, поскольку версия 2 не вышла
   до выхода Windows Vista. Согласно истории версий SMB, система Windows 7 будет использовать SMB версии 2.1. Хотя это
   может показаться устаревшим сканированием, наличие старых систем полезно для отработки атак, поскольку они с
   большей вероятностью будут иметь уязвимые версии программного обеспечения.

  Мы также можем использовать Metasploit для перечисления пользователей, для чего будем использовать модуль
    smb_enumusers_domain . Для получения более полных данных, вы можете использовать имя пользователя и пароль. Это
   позволит модулю аутентифицироваться в системе для получения дополнительных пользователей. Это не обязательно, хотя у
   вас гораздо меньше шансов получить список пользователей без какой-либо аутентификации. К счастью, есть еще один
   модуль, который вы можете использовать, чтобы для начала получить хотя бы одно имя пользователя и пароль. Модуль
    smb_login можно использовать для попыток сочетания имени пользователя и пароля.
