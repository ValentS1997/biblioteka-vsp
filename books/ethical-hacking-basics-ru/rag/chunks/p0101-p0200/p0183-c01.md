  Шаг 10

   Kerberoasting

   Kerberoasting — это еще один тип атаки для взлома паролей, основанный на получении доступа к сети. Название основано на
   том факте, что проверка подлинности Active Directory в сети использует протокол Kerberos, который назвали в честь
   трехголового пса из греческой мифологии, который охранял врата Подземного мира, чтобы не дать уйти тем, кто там
   находился. Первоначально он был разработан в Массачусетском технологическом институте (MIT) как часть проекта Athena,
   который также отвечал за другие проекты, например X Window System - графический пользовательский интерфейс для Unix-
   подобных систем. Kerberos работает в режиме клиент-сервер.

                                                             На рисунке показана схема работы Kerberos в
                                                                   различных режимах:

                                                                   • аутентификация клиента на сервере
                                                                     аутентификации (AS - Authentication Server),
                                                                   • аутентификация службы клиента
                                                                   • клиент, отправляющий запрос на службу.

                                                                Сообщения от клиента и серверов Kerberos
                                                               шифруются с использованием ключа на стороне
                                                                            клиента, который фактически является паролем
                                                                      пользователя в тех случаях, когда он полагается
                                                                    на аутентификацию пользователя для запроса
                                                                              услуг в сети. Если сервер расшифровывает,
                                                                       используя известный ему пароль, и не получает
                                                               нужных данных, он сообщает, что пароль
                                                                           неверен, поэтому попытка аутентификации
                                                                     завершается неудачей.

                                                                             Kerberos — это протокол аутентификации,
                                                                   который используется в реализациях Windows
                                                                                    Active Directory (AD) начиная с Windows 2000.
                                                                        Архитектура Kerberos преполагает наличие
                                                                      нескольких служб, которые могут находиться в
                                                                   одной системе или представлять собой
   отдельные серверы.
