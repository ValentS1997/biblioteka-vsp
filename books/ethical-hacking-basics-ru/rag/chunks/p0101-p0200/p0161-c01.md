     # nc 192.168.86.52 25
     220 bobbie.lan ESMTP Postfix (Ubuntu)
     EHLO blah.com
     250-bobbie.lan
     250-PIPELINING
     250-SIZE 10240000
     250-VRFY
     250-ETRN
     250-STARTTLS
     250-ENHANCEDSTATUSCODES
     250-8BITMIME
     250-DSN
     250 SMTPUTF8
     VRFY root@localhost
     252 2.0.0 root@localhost
     VRFY kilroy@localhost
     252 2.0.0 kilroy@localhost
     VRFY root
     252 2.0.0 root

   В результате наших попыток мы ничего не получаем, кроме кода состояния. Нет текста, указывающего, что сервер думает о
   нашем запросе. Это означает, что нам нужно найти полученное числовое значение. В отличие от предыдущего случая, когда
  мы получили 250, что означает успех, на этот раз мы получили статус 252. Это означает, что адрес невозможно проверить, но
   сервер попытается доставить сообщение. Хотя на этом сервере включен VRFY, мы не получаем много полезной информации.
   Кроме того, выполнение этого вручную занимает очень много времени.
  Мы могли бы сделать это вручную. Однако Metasploit снова приходит на помощь. Модуль smtp_enum возьмет список слов и
   автоматически сделает то же самое, что вы видели раньше. Он будет проверять всех пользователей в списке слов, проверяя,
   существует ли каждый пользователь.
   Есть два способа проверить, существуют ли пользователи: либо команда VRFY, либо команда MAIL TO. В следующем
   листинге вы можете увидеть результаты запуска на том же сервере. Здесь используется список слов по умолчанию, который
   поставляется с Metasploit и содержит список общих имен пользователей Unix (unix_users.txt).

     msf > use auxiliary/scanner/smtp/smtp_enum
     msf auxiliary(scanner/smtp/smtp_enum)> set RHOSTS 192.168.86.52/32
     RHOSTS => 192.168.86.52/32
     msf auxiliary(scanner/smtp/smtp_enum)> run
     [*] 192.168.86.52:25 - 192.168.86.52:25 Banner: 220 bobbie.lan ESMTP
     Postfix (Ubuntu)
     [+] 192.168.86.52:25 - 192.168.86.52:25 Users found: , backup, bin,
     daemon, games, gnats, irc, list, lp, mail, man, messagebus, news, nobody,
     postmaster, proxy, sshd, sync, sys, syslog, uucp, www-data
     [*] Scanned 1 of 1 hosts (100% complete)
     [*] Auxiliary module execution completed

  Вы заметите, что в списке найдено много пользователей, найденных этим модулем. Учитывая тот факт, что команда VRFY
   вернула значение 252, а пользователи — это пользователи, существующие в этой системе, модуль не использует VRFY.
   Вместо этого он использует команду MAIL TO. Пользователи, которых не существует, получат код состояния 550.
   Существующие пользователи будут возвращать код 250 при попытке отправки письма этому пользователю. По результатам
   этого модуль возвращает валидные имена пользователей, так как из 112 пользователей в списке был идентифицирован
   только 21 пользователь.
   Есть еще одна команда, которую можно использовать на SMTP-серверах, но она предназначена для списков рассылки. Если
  вы найдете адрес списка рассылки, принадлежащий домену, вы сможете использовать EXPN для расширения списка
   рассылки, что означает определение адресов электронной почты, которые находятся в этом списке рассылки. Однако для
   этой функции требуется, чтобы сервер поддерживал расширенный SMTP (ESMTP). Вы можете проверить, поддерживает ли
   сервер ESMTP, проверив, принимает ли он EHLO, который является версией HELO для ESMTP.
