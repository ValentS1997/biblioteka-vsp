  Шаг 4

  Удаленный вызов метода

   Программы на Java очень популярны, особенно когда речь идет о веб-приложениях. Java оказывает большую помощь
   программистам, особенно когда речь идет о библиотеках и интерфейсах, которые можно реализовать с собственным
   функционалом. Java включает собственную возможность удаленного вызова процедур, хотя в Java это называется
   удаленным вызовом метода (RMI - remote method invocation). Чтобы иметь программу, использующую RMI, системе
   необходима программа, аналог portmapper для Java, называемая rmiregistry . Если программа будет использовать RMI,
   она регистрируется с помощью этой программы. Это означает, что любой может проверить в реестре RMI, какие услуги
   предлагаются, или другими словами, какие программы используют RMI. Программа rmiregistry при запросе отреагирует
   аналогично тому, что мы видели при проверке с помощью portmapper.
