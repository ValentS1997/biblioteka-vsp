   В результате, можно увидеть, что сканирование портов определило порт 445 открытым. Этот порт используется для общей
   файловой системы Интернета (CIFS), которая является реализацией SMBv2. Открытый порт инициировал запуск
   соответствующих сценариев.

   Как видите из приведенных примеров, скрипты nmap можно использовать для сбора большого количества информации о
   различных сервисах. На момент написания статьи существует более 600 скриптов. Из них более 30 предназначены
   специально для определения того, потенциально ли сервер подвержен известной уязвимости (CVE - Common Vulnerabilities
   and Exposures). Другие сценарии идентифицируют системы, уязвимые для других угроз. В качестве другого примера можно
   привести сценарий, который ищет уязвимость расшифровки RSA с устаревшим и ослабленным шифрованием (DROWN -
   Decrypting RSA with Obsolete and Weakened eNcryption) на серверах, на которых работает протокол Secure Sockets Layer (SSL)
   версии 2. Это серьезная уязвимость, и ее можно выявить только путем взаимодействия с системой, использующей SSL. Если
   у вас есть некоторый опыт программирования, вы можете обнаружить, что расширение nmap с помощью собственных
   сценариев — довольно простой процесс. Поскольку все сценарии NSE представлены в виде обычного текста, вы можете
   использовать любой из них в качестве отправной точки или получить примеры кода, которые можно объединить для
   создания собственного сценария. Имейте в виду, что хотя nmap является сканером портов и может идентифицировать
   открытые порты, механизм сценариев используется для более глубокого взаимодействия с приложением. Сценарии также
   могут принимать программные решения на основе ответов, предоставляемых сканируемой службой. Модули скриптового
   движка не только предоставляют функциональные возможности для взаимодействия со службами, включая регистрацию
   портов с помощью nmap, чтобы сценарий вызывался, только когда обнаруживается, что идентифицированный порт открыт,
   но существуют также модули для вывода, которые возвращают собранные данные nmap, когда сценарий завершился.
