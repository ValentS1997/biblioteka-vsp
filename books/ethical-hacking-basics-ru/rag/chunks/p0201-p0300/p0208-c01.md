   На рисунке показано создание альтернативного потока данных, а затем создание списка каталогов, показывающего
   существование альтернативного потока данных. Не все программы в Windows понимают ADS, а это означает, что вы обычно
   не будете использовать их для хранения файлов для регулярного использования. Их можно использовать для хранения
   свойств файла или использовать в вредоносных целях. Например, вы можете хранить исполняемые файлы в качестве
   альтернативного потока данных. Вы также можете использовать команду type для перенаправления исполняемого файла
   в ADS. Это становится просто еще одним потоком данных, прикрепленным к записи имени файла в таблице файлов.

   Одна из проблем хранения исполняемых файлов в ADS заключается в том, что они больше не могут быть исполняемы
   напрямую из ADS. Вам придется извлечь исполняемый файл и затем запустить его, а не пытаться вызвать его из отдельного
   потока данных. Это помогает защитить системы от злоумышленников, которые сделают именно это, поскольку обычные
   списки каталогов, в том числе в проводнике Windows, не содержат никаких намеков на наличие ADS. Размер файла
   показывает только основной поток данных и ничего не говорит о других потоках данных. Это делает его эффективным для
   сокрытия данных, но не самым эффективным для сокрытия данных, которые вы хотите выполнить напрямую.

   Последняя возможность в системах Windows — это служба теневого копирования томов. Это способ Windows хранить
   резервные копии томов работающей системы. Windows создает эти теневые копии для сохранения версий файлов на случай
   необходимости их отката. Можно, хотя и сложно, смонтировать одну из теневых копий тома и затем манипулировать
   файлами в ней. Это возможность сокрытия данных, хотя на самом деле это не лучший способ, поскольку с ним может быть
   очень сложно справиться.
