   реализовать службу RESTful в Node.js . REST — это передача репрезентативного состояния, добавляющая возможность
   управлять состоянием приложения, которое HTTP не поддерживает. Службы REST используют «конечные точки» для
   передачи сообщений на сервер и получения ответов. Конечная точка — это просто URL-адрес, который сообщает серверу,
   какая функция или набор функций вызывается.
   Помимо Node.js  , вы можете использовать библиотеку Express для управления всеми взаимодействиями приложения. Вы
   просто создаете ответы на вызовы конечной точки. Это можно сделать с помощью нескольких строк кода. Конечно, для
   запуска кода у вас должен быть установлен Node.js и необходимые библиотеки. В следующем листинге кода вы можете
   увидеть базовую схему программы Node.js  , которая может обрабатывать запросы в конечной точке /check . Добавить
   конечные точки так же просто, как добавить функции с определенными конечными точками.
