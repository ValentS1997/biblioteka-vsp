   Как уже отмечалось, служба Meterpreter ожидает, что вы сможете подключиться только к определенному порту. Кроме того,
   скрипт службы Meterpreter устарел и вскоре может быть удален из Metasploit.

   Вместо этого мы можем использовать созданный нами исполняемый файл с помощью msfvenom  . Вы увидите, что
   Meterpreter загружает полезную нагрузку в целевую систему и создает сохраняемый исполняемый файл. Затем создаются
   записи реестра для автоматического запуска исполняемого файла при входе пользователя в систему - на это указывает
   ссылка на HKCU, то есть HKEY_CURRENT_USER, место в реестре, в котором есть все, что связано с вошедшим в систему
   пользователем.

   Это дает нам множество способов сохранить доступ к целевым системам за пределами начальной точки входа. Однако вы,
   возможно, заметили, что эти механизмы сохранения добавляют файлы и записи реестра в целевую систему. Необходимо
   учитывать, что подобные действия и артефакты можно обнаружить при условии, что на конечной точке имеются механизмы
   обнаружения или кто-то ведет мониторинг подозрительных действий на хостах. Исследуя атакуемую систему, вы можете
   заметить, есть ли на цели программное обеспечение для обнаружения вредоносных программ или другое программное
   обеспечение для обнаружения.

   Существует много других распространенных методов, которые можно использовать для закрепления. Помимо сохранения
   реестра, для обеспечения выполнения кода во время загрузки можно использовать и другие процессы загрузки. Например,
   Windows поддерживает сценарии входа в систему. Один из этих сценариев может быть установлен в целевой системе,
   которая может выполнять код, управляемый злоумышленником, когда пользователь входит в систему. То же самое
   справедливо и для Unix-подобных операционных систем. Кроме того, обе операционные системы поддерживают установку
   служб, которые будут выполняться во время загрузки.

   В Windows есть служба, называемая Фоновая интеллектуальная служба передачи (BITS - Background Intelligent Transfer
    Service). BITS — это служба, которая позволяет таким задачам, как обновления, выполняться в фоновом режиме, не влияя на
   нормальную работу пользователей. Однако BITS не только выполняет фоновую передачу файлов или данных, но и позволяет
   злоумышленникам манипулировать этими задачами с помощью PowerShell. Злоумышленник может создать задание BITS,
