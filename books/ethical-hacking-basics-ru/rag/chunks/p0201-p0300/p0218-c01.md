Stepik                                                                                              https://stepik.org/lesson/1238860/plain?is_print=true
   Еще один способ обойти антивирусное программное обеспечение — заставить его переконфигурировать себя при заражении
   новой системы. Это называется полиморфным вредоносным ПО, что означает, что оно имеет множество форм. Когда
   вредоносное ПО заражает новую систему, оно может перезаписать либо дешифратор, либо полезную нагрузку. Изменение
   любого из этих компонентов будет означать изменение подписи файла. Лучший способ обнаружить существование
   подобного вредоносного ПО — обнаружение по поведению.
