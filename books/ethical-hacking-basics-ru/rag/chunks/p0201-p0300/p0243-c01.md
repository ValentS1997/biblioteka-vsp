   Здесь вы увидите конечную точку, которая на самом деле ничего не делает. Вы можете отправить запрос, но ничего не
   произойдет. Чтобы что-то произошло, вам нужно добавить код в функцию, которая обрабатывает GET-запросы к /check .
   Библиотека Express также может обрабатывать POST-запросы. Чтобы выполнить POST, вы просто используете app.post
   вместо app.get . Что вы можете сделать, так это ответить с помощью JSON (JavaScript Object Notation), который состоит из
   ключа или свойства, за которым следует значение. Это полезно, поскольку пары ключ/значение в конечном итоге
   оказываются по сути самодокументируемыми. Давайте добавимответ JSON, изменив функцию app.get

     app.get('/check', function(req, res) {
        res.json({ action: 'email' })
     })

   Конечно, вам не обязательно использовать Node.js для построения инфраструктуры, если вам нужны службы C&C. Это
   довольно простой способ создать веб-сервер с функциональностью, аналогичной приложению, но вы также можете
   написать страницы, которые можно будет разместить на веб-сервере, который либо уже существует, либо может быть
   установлен.

   Распространенным программным обеспечением, используемым злоумышленниками, к которому вы также можете получить
   доступ, является Cobalt Strike BEACON.
   Cobalt Strike — это платформа, часто используемая профессионалами для операций красной команды. Cobalt Strike работает
   как сервер C2, поскольку это приложение, которое все члены команды используют для подключения и выполнения
   операций красной команды. Полезная нагрузка по умолчанию, используемая Cobalt Strike, — BEACON. Полезная нагрузка
   подключается обратно к серверу команды Cobalt Strike, позволяя членам красной команды взаимодействовать со
   скомпрометированными системами.
   BEACON — это украденное программное обеспечение, которое обычно используется злоумышленниками незаконно.
   Получение копии Cobalt Strike позволит вам иметь собственную инфраструктуру для контроля скомпрометированных
   систем. Это недешевое программное обеспечение, но оно может оказаться полезным, поскольку предоставит вам основу
   для использования.

  Шаг 6

  Антивирусные решения

   Антивирус станет проклятием существования для любого, кто пишет вредоносное ПО. К счастью, не так уж сложно обмануть
   антивирус, если автор вредоносного ПО захочет приложить немного усилий. Имейте в виду, что антивирус обычно
   использует известные свойства вредоносного ПО для его идентификации. Для этого может использоваться хэш
   вредоносного ПО. Чтобы сгенерировать другой хэш, вредоносной программе достаточно изменить один байт. Это изменение
   одного байта приведет к совершенно другому хешу.

   Вредоносное ПО может использовать ряд методов, чтобы обойти антивирус.
