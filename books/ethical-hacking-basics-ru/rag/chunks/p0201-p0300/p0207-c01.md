   На рисунке показан список каталогов временных файлов Интернета в системе Windows с Chrome. Это каталог кэша,
   специфичный для отдельного пользователя. Это не тот каталог, который посещает большинство людей, поэтому не составит
   труда разместить здесь файл и сделать так, чтобы его никто не заметил.

   Путь к этому каталогу — C:\Users\username\AppData\Local\Google\Chrome\User Data\Default\Cache  , в котором есть
   множество точек, где вы также можете скрыть файлы там, где они не будут видны. Частично это связано с тем, что по
   умолчанию многие из показанных здесь каталогов скрыты в проводнике Windows, если вы не измените настройку, чтобы
   показать их. По сути, файлы в любом месте каталога AppData будут потеряны в результате перемешивания множества
   временных файлов и файлов, специфичных для приложения.

   В системе Linux вы можете использовать файлы и каталоги, начинающиеся с . для выполнения тех же задач. Имя файла
   начинающиеся с точки, например .bashrc  , в обычных списках файлов не отобразится. Точно так же вы не увидите каталоги,
   начинающиеся с точки. Если вы поместите файлы в один из этих каталогов, они могут потеряться или быть пропущенными.

   В системах Windows есть функция, называемая альтернативными потоками данных (ADS - alternate data streams), которая
   была реализована в файловой системе NTFS (New Technology File System) для поддержки случая, когда диски на базе Apple
   были подключены к Windows NT. В начале 90-х годов Windows NT поддерживала гораздо больше платформ и архитектур, чем
   сейчас, поэтому, хотя поддержка иерархической файловой системы HFS для macOS больше не существует в Windows, ADS
   остается в качестве функции. Чаще всего вы увидите его использование в загруженных файлах. Им помечается зона, откуда
   эти файлы были получены. Отсюда и появляется всплывающее окно о загрузке файлов из Интернета и вопрос, хотите ли вы
   их открыть.
