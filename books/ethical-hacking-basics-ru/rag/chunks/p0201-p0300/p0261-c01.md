   Например, как показано на рисунке выше, все является кадром, и все эти кадры являются Ethernet. Из всех кадров Ethernet
   все в этом конкретном захвате является IP-пакетом. Из них 5,5 процентов составляют дейтаграммы UDP. SSDP, MDNS и DNS
  — это протоколы, использующие UDP в качестве протокола транспортного уровня. Большинство перехваченных пакетов
   представляют собой TCP-сегменты. Большинство из них — SSL, хотя на самом деле все они — TLS, который является
   протоколом-преемником SSL.

   Еще одна запись в меню «Статистика», на которую стоит обратить внимание, — это представление «Беседы». Здесь показаны
   все диалоги между конечными точками при перехвате пакетов. На каждом уровне захвата есть разные наборы диалогов,
   поскольку диалоги уровня 2 отличаются от диалогов по IP-адресам. Любой IP-разговор, который проходит за пределами
   локальной сети, имеет разговор уровня 2 с локальным шлюзом. Это означает, что у вас, вероятно, будет меньше разговоров
   по Ethernet, чем по IP. Кроме того, ваши TCP-разговоры будут отличаться от ваших IP-разговоров. У вас может быть несколько
   наборов портов между двумя IP-адресами. Это может быть особенно актуально, если ваш локальный браузер устанавливает
   несколько подключений к веб-серверу для выдачи запросов изображений, HTML-страниц и других ресурсов, которые
   используются для рендеринга страницы. Например, на рисунке ниже показана статистика разговоров, полученная при
   перехвате пакетов.
