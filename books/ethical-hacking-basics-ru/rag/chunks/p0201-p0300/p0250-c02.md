   файла захвата пакетов (PCAP), который включает метаданные о сеансе захвата пакетов. В данном режиме, информация на
   экране будет отсутствовать и видно только первое сообщение. Чтобы остановить захват, вам необходимо завершить работу
    tcpdump с помощью комбинации клавиш Ctrl+C (^C). После чего отобразится информация о количестве записанных пакетов.

     # tcpdump -w file.pcap
     tcpdump: listening on eth0, link-type EN10MB (Ethernet), capture size 262144 bytes
     ^C116 packets captured
     119 packets received by filter
     0 packets dropped by kernel

   После того, как файл записан, у нас есть несколько вариантов. Любая программа, которая может анализировать файл PCAP,
