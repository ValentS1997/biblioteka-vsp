  Шаг 8

   Бесфайловое вредоносное ПО
   Обычно вредоносное ПО существует в файлах на диске. Возможно, жертва посещает веб-сайт, на страницах которого
   размещено вредоносное ПО. Затем вредоносная программа запускается на компьютере жертвы, оставляя после себя файлы,
   которые можно обнаружить.

   Программы защиты от вредоносных программ часто сканируют файлы, чтобы обнаружить вредоносное ПО и уничтожить
    его. Разработчики вредоносных программ осознают угрозу, которую представляют программы защиты от вредоносных
   программ. Они могут использовать различные методы, чтобы гарантировать, что вредоносное ПО не будет обнаружено. Один
   из этих методов — никогда не оставлять никаких артефактов в файловой системе. Это приводит к появлению так
   называемого бесфайлового вредоносного ПО.

   Бесфайловые вредоносные программы могут усложнить обнаружение, поскольку в программах защиты от вредоносных
   программ не существует файла, который можно было бы сравнить с сигнатурой. Для этого требуется обнаружение
   вредоносного поведения в системе-жертве, а не анализ на основе сигнатур файлов.
   Этап закрепления в скомпрометированной системе становится проблемой для бесфайловых вредоносных программ,
   поскольку нет ничего, что можно было бы выполнить с помощью обычного процесса запуска. Однако есть способы никогда
   не записывать вредоносное ПО на диск. Один из них — встроить сценарий PowerShell в реестр Windows и использовать этот
   сценарий PowerShell для перетаскивания других вредоносных программ на сервер-жертву, выполняя их непосредственно в
   памяти. Кроме того, сценарий PowerShell может использовать существующие в системе инструменты для взаимодействия с
   сетью для горизонтального перемещения.

  Шаг 9

   Полиморфное вредоносное ПО
   Программное обеспечение для защиты от вредоносных программ часто использует сигнатуры для идентификации
   вредоносного программного обеспечения. Это может быть что-то вроде криптографического хеша. Каждый экземпляр
   файла будет генерировать один и тот же криптографический хэш, независимо от того, в какой системе он находится, что
   делает его надежным индикатором того, является ли файл вредоносным или нет. Это означает, что системы с
   обновленными базами данных защиты от вредоносных программ будут обнаруживать и удалять вредоносные программы.

   Вредоносному ПО полезно не иметь один и тот же криптографический хэш для каждого экземпляра, чтобы оно не было
   обнаружено и не удалено из системы. Вредоносное ПО, которое используется в большом количестве систем, можно назвать
   обычным вредоносным ПО, то есть оно легкодоступно и используется в максимально возможном количестве мест.
   Специальное или целевое вредоносное ПО может быть скомпилировано специально для цели, чтобы оно отличалось от
   антивирусного программного обеспечения.
