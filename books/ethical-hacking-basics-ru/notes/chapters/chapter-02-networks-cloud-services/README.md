## Главный принцип

Чтобы понимать потенциальные точки входа, маршруты и границы доверия, важно различать **уровни передачи данных**, **адреса интерфейсов / узлов / приложений**, **транспортную семантику** и **сегментацию инфраструктуры**. В облаке внешнее размещение упрощает получение ресурсов, но ошибки конфигурации доступа клиента по-прежнему могут открывать системы. Основание: `p0017:c01`, `p0022:c01`, `p0024:c01`, `p0033:c01`–`p0035:c01`, `p0038:c01`–`p0040:c01`.

## Карта содержания

1. **Модели.** OSI (7 слоёв) и архитектура TCP/IP (4 слоя) распределяют функции сетевой связи; OSI полезна для локализации проблемы по функции. `p0015:c01`–`p0019:c01`.
2. **Топология.** Шина, звезда, кольцо, ячеистая и гибридная сеть имеют различия в организации каналов и отказоустойчивости; L2 switch пересылает кадры по MAC. `p0019:c01`–`p0023:c01`.
3. **Адреса и протоколы.** MAC на L2, IP на L3, порт на L4; IPv4/IPv6 и CIDR задают области адресов; TCP обеспечивает подтверждения/повторы и порядок, UDP не обещает доставку, ICMP сообщает состояние/ошибки. `p0024:c01`–`p0033:c01`.
4. **Зоны доступа.** LAN/VLAN/WAN/MAN, DMZ и изолированные анклавы ограничивают трафик между уровнями доверия; VPN/IPsec/TLS рассматриваются как способы удалённого взаимодействия. `p0033:c01`–`p0035:c02`.
5. **Облако/IoT.** StaaS — удалённое хранение; IaaS — вычислительная инфраструктура/VM; PaaS — платформенные/готовые решения в терминологии главы; SaaS — приложения через сеть; IoT может применять HTTP и MQTT. Указаны риски внешнего доступа, хранения данных у провайдера и ошибочных клиентских правил. `p0036:c01`–`p0041:c01`.
6. **Авторское резюме.** `2.3 / Шаг 7`, PDF pp. 41–42. См. [summary.md](summary.md).

## Safety и ограничения

`ping` и трассировка маршрута лишь **названы** без полного синтаксиса/параметров. Получение сетевых данных может генерировать трафик и требует согласованной области, особенно при тестировании чужой сети. Команды изменения DMZ/VLAN/VPN/cloud security groups и rollback в книге не приведены: **[Needs confirmation]**. Технические рисунки (поле IPv6 на p. 27, сетевые схемы, облачные скриншоты) не воспроизводились из модельной памяти: см. source-findings.md.
