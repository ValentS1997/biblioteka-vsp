# Глава 21. Руководство устойчивыми командами

**Книга:** Дженнифер Дэвис, «Современное системное администрирование»; inventory `0011`; часть V «Масштабирование системы».

## Главный тезис

**Люди, процессы, знания и инфраструктура — части общей системы.** Руководство устойчивой командой требует совместной ответственности, реальных возможностей для отдыха, прозрачности нагрузки, психологической безопасности, постоянного обучения и документации. Цель — сделать всю систему устойчивой для тех, кто её создаёт и поддерживает (PDF 256–271).

## Рабочий цикл руководителя по тексту главы

1. Определить **коллективные** цели, зоны ответственности и участников полного жизненного цикла системы (PDF 256–258, 264).
2. Посмотреть на дежурства: утомляемость, сигнал/alert/incident, доступность подмен, знания эксплуатации и поддержку команды (PDF 258–261).
3. Сделать видимой общую работу: описание задач, проектов, потока, каталог услуг, незавершённые проекты и реальные ограничения (PDF 261–266).
4. Сопоставить нагрузку и бизнес-ценность с ресурсами; согласовать изменение приоритетов, графиков, состава команды или инструментов (PDF 262, 266–267).
5. Закрепить знания документацией, обучением, учениями и временем для улучшений (PDF 267–269).
6. Обсуждать результаты на ретроспективах, признавать вклад и **повторять итерацию** без карательной интерпретации метрик (PDF 260–264, 271).
