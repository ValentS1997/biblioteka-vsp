# Команды и инструменты — глава 8

**Основа:** RAG PDF 100–108; `p0100-c01` — `p0108-c01`. Глава о принципах безопасности; **исполняемых CLI-команд, готовых правил межсетевого экрана или скриптов здесь нет**. Не добавлять синтаксис из внешних источников.

## Названные инструменты и подходы

| Наименование | Назначение в тексте | Класс воздействия | Локатор |
|---|---|---|---|
| **NIST Common Vulnerability Scoring System Calculator** | Средство изучения и оценки уязвимостей для моделирования угроз | Read-only при анализе | PDF 103 |
| **Microsoft Threat Modeling Tool** | Выявление и анализ угроз | Read-only при обзоре, state-changing при сохранении модели | PDF 103 |
| **PASTA** (Process for Attack Simulation and Threat Analysis) | Процесс оценки угроз | Workload-generating при проведении анализа; изменения документов state-changing | PDF 103 |
| **OWASP Threat Modeling Control Cheat Sheet** | Памятка по моделированию угроз | Read-only при изучении | PDF 103 |
| **OWASP ASVS** | Требования/проверки безопасности веб-приложений и сервисов | Read-only при оценке; изменение продукта по требованиям state-changing | PDF 106 |
| **CVE** | Идентификаторы опубликованных уязвимостей | Read-only при классификации и отслеживании | PDF 107 |
| **Verizon DBIR** | Публикации со статистикой инцидентов, приведённые в источнике | Read-only | PDF 103–104 |

Упомянутые обозначения примеров уязвимостей, **не команды эксплуатации**: Heartbleed/OpenSSL; MS17-010/EternalBlue; CVE-2016-5195/Dirty COW; Meltdown; KRACK (PDF 107). Внешние описания и пошаговые техники не добавлены.

## Действия с изменением состояния (без исполняемого CLI)

| Действие | Эффект | Риск | Проверка и rollback |
|---|---|---|---|
| Ограничить трафик межсетевым экраном и сегментацией | Сокращает доступные пути к ресурсам | Неправильное правило блокирует легитимные соединения | Оценить нужные потоки; точные команды/откат **[Needs confirmation]** (PDF 105) |
| Ограничить привилегированные учётные записи | Снижает риск злоупотребления доступом | Ошибка разграничения может лишить администратора доступа | Сверить требования доступа; конкретные проверки/откат **[Needs confirmation]** (PDF 105–106) |
| Установить своевременные обновления ОС/ПО | Сокращает время эксплуатации известных дефектов | Возможна несовместимость и изменение функций | Выявить окно уязвимости; процедуры тестирования/rollback **[Needs confirmation]** (PDF 104) |
| Удалить ненужный актив/данные | Потенциально уменьшает риски и затраты | Потеря нужного ресурса/данных | Обосновать удаление с владельцами; возврат **[Needs confirmation]** (PDF 102) |
| Исправить проблему архитектуры | Уменьшает радиус поражения, закрывает проектный дефект | Высокая цена изменений и зависимостей | Проверять при проектировании; последовательность и откат **[Needs confirmation]** (PDF 105, 107) |

**Важно:** «модель нулевого доверия», «глубокая защита» и «триада КЦД» — принципы, не конкретные исполняемые команды. Тестировать реальные контуры допуска и конфигурации без отдельно подтверждённого контекста и согласования не следует.
