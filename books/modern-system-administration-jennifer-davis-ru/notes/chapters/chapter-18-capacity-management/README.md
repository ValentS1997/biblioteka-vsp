# Глава 18. Управление мощностями

**Книга:** Дженнифер Дэвис, «Современное системное администрирование», русское издание БХВ-Петербург, 2024. Инвентарный номер `0011`; часть V «Масштабирование системы».

## Главный принцип

Управление мощностями помогает согласовать доступные ресурсы с меняющимся спросом и потребностями бизнеса, поддерживая качество обслуживания и учитывая цену самих ресурсов и труда по их поддержке. Снижение эксплуатационных расходов **не является самостоятельной целью**; оно может быть результатом разумного выбора ресурсов (PDF 213–215, 225).

## Пример различия мощностей из книги

При тестировании архитектура выдерживает **1000** одновременных входов (проектная). В обычной production-нагрузке существенная задержка появляется раньше — предел **800** (производственная). При сезонном пике и каскадной деградации реальная эффективная мощность — **300**. Цифры **не являются целями для другой системы** (PDF 213–214).

## Канонический алгоритм главы

1. Измерить текущую нагрузку всех составляющих оцениваемой системы (PDF 222).
2. По пользовательским запросам проверить достижение SLO (PDF 222).
3. Если SLO достигается, оценить будущие потребности и изменение технологии; если нет — определить, связано ли нарушение именно с мощностью (PDF 222–223).
4. Не масштабировать вслепую: проблему может решить изменение конфигурации; если не хватает данных — изменить измерения (PDF 223).
5. Если подтвержден дефицит мощностей, рассмотреть доступные варианты, сделать **одно** изменение, измерить эффект и сообщить о решении соответствующим командам (PDF 223).
6. Сопоставить срок получения ресурсов, прогноз спроса, стратегию опережения/запаздывания/соответствия, стоимость, риски и жизненный цикл (PDF 215–225).
