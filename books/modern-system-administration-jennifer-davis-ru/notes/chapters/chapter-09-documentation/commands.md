# Команды и инструменты — глава 9 «Документация»

**Provenance:** RAG PDF 109–115 (`modern-system-administration-jennifer-davis-ru:p0109:c01` — `...:p0115:c01`). Автор рассматривает работу с документацией и её жизненный цикл, а не синтаксис CLI. **Исполняемых команд для создания Wiki, версионирования, публикации и поиска в главе нет.**

## Подтверждённые средства и формы

| Объект | Класс | Подтверждённое назначение | RAG |
|---|---|---|---|
| Внутренняя **wiki-страница** | Read-only для чтения, state-changing для публикации/редактирования | Пример командной базы знаний и передачи опыта | PDF 109 |
| **Система контроля версий** (без конкретного названия в этой главе) | Read-only для просмотра истории; state-changing для изменения документов | Управлять версиями, изменениями и их отслеживаемостью | PDF 115 |
| **Система поиска и индексирования** | Read-only для поиска; state-changing при обновлении индекса | Помогать находить информацию среди множества небольших страниц | PDF 113 |
| **Шаблоны документов** | State-changing при создании/изменении документа | Быстрее готовить материалы заданного вида с единым стилем | PDF 112 |
| **Руководство по стилю и общие процедуры** | Read-only для сверки; state-changing при обновлении правил | Поддерживать согласованность коллективной документации | PDF 112 |
| **Печатные аварийные инструкции** | Read-only во время восстановления; state-changing при изготовлении и обновлении | Сохранить доступ к действиям, если сеть или электричество недоступны | PDF 114 |

Слова «read-only» и «state-changing» классифицируют **тип взаимодействия**, а не утверждают, что исходник привёл конкретную команду.

## Подтверждённые операции без синтаксиса

| Операция | Эффект | Риск | Проверка и возврат |
|---|---|---|---|
| Исследовать тему, создать/обновить документ | Появляются новые или исправленные знания | Ошибочная информация вводит читателя в заблуждение | Проверить правильность и применимость; rollback **[Needs confirmation]** (PDF 112–113) |
| Назначить номер версии, выпустить документ | Опубликована отслеживаемая редакция | Пользователь может открыть неактуальную редакцию | Проверить удобство обнаружения и актуальность; rollback **[Needs confirmation]** (PDF 113) |
| Объявить документ устаревшим, архивировать | Материал выходит из текущего жизненного цикла | Потеря нужной инструкции | Предварительно убедиться в отсутствии действующей потребности; rollback **[Needs confirmation]** (PDF 113) |
| Реорганизовать сайт или разделы | Меняются навигация и возможности поиска | Ссылки и привычные пути поиска могут стать менее понятны | Оценить обнаруживаемость у читателя; rollback **[Needs confirmation]** (PDF 113) |
| Поддерживать офлайн-копии аварийных инструкций | Материалы доступны при сетевых/энергетических сбоях | Бумажная копия может устареть | Регулярно сравнивать актуальность; процедура замены **[Needs confirmation]** (PDF 114) |

## Не подменять источник

Git CLI, команды сборки сайта, операционные команды с полномочиями root, названия конкретных Wiki-платформ, процедуры CI, контроль ссылок, численные метрики — **[Needs confirmation]**. Книга в этой главе не даёт их синтаксис, поэтому они намеренно отсутствуют.
