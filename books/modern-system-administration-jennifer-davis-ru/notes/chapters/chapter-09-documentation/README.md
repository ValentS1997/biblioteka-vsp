# Глава 9. Документация

**Книга:** Дженнифер Дэвис, «Современное системное администрирование» (БХВ-Петербург, 2024). Часть II «Методы».

## Основная идея

**Документация — часть системы.** Её ценность определяется тем, может ли читатель своевременно найти точные, понятные и относящиеся к его задаче сведения. Для этого нужно знать аудиторию, выбирать подходящий вид документа, выстраивать информационную архитектуру, поддерживать управляемый жизненный цикл и регулярно оценивать качество (RAG PDF 109–115).
