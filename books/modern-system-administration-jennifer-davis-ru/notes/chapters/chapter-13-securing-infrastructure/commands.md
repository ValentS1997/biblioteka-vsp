## Фрагмент IaC из источника — **не исполнять**

В примере `google_storage_bucket.static-assets` автор показывает включение единых правил доступа к bucket и шифрования с KMS-ключом (PDF 169–170). Текстовое извлечение включает следующие существенные элементы:

```text
resource "google_storage_bucket" "static-assets" {
  name = "static.example.com"
  uniform bucket level access = true    <-- OCR/extraction damaged field name
  encryption {
    default_kms_key_name = "static-assets-key"
  }
}
```

Это **диагностическая нормализация расположения строк** с сохранением повреждённого ключа, не точная копия форматирования и не конфигурация Terraform. Исправленное поле и работоспособность примера по RAG **[Needs confirmation]**. Не копировать в облако без отдельной проверки.

**Наблюдаемый вывод Checkov:** `Passed checks: 2, Failed checks: 0, Skipped checks: 0`; checks `CKV_GCP_5` (шифрование bucket), `CKV_GCP_29` (uniform bucket-level access), оба `PASSED` для `google_storage_bucket.static-assets` (PDF 170). Команда запуска Checkov не дана.

## Классы действий

| Операция | Класс | Эффект и меры |
|---|---|---|
| Изучить IAM, аудит секретов, права API, зависимости сервисов | **Read-only** при изучении | Выявить реальные входные точки и неоправданный доступ (PDF 158–165) |
| Выдать/отозвать полномочия, поменять секрет, конфигурацию сетевой политики | **State-changing** | Риск нарушения доступа и работоспособности; минимальные права, контроль результата; rollback **[Needs confirmation]** |
| Собрать исправленный контейнер, обновить ОС и пакеты | **State-changing / workload-generating** | Проверять совместимость и повторное развертывание (PDF 166–167) |
| Выполнить SAST IaC, сканирование Git на секреты | **Read-only по предмету проверки / workload-generating**, если не включён автофикс | Результат — найденные нарушения, не автоматическое исправление (PDF 170) |
| Изменить способы передачи логов или политику хранения | **State-changing** | Секреты могут попадать в сторонние инструменты; проверить маршруты событий (PDF 164–165) |

**Команды** `terraform`, `checkov`, `gitleaks`, `kubectl` и процедуры настройки доступа не приведены в источнике — **[Needs confirmation]**. Реальные пароли, токены и ключи не нужны и в артефактах отсутствуют.
