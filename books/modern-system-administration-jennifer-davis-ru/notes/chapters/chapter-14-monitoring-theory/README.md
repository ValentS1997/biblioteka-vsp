# Глава 14. Теоретические аспекты мониторинга

**Книга:** Дженнифер Дэвис, «Современное системное администрирование» (БХВ-Петербург, 2024), часть IV «Наблюдение за системой». Inventory `0011`.

## Главный тезис

Мониторинг — это **многоэтапный процесс** измерения, сбора, хранения, изучения и визуализации инфраструктурных данных, включая технические системы и человеческие процессы. Наблюдаемость — **свойство системы**, характеризующее, насколько по доступным выходным данным можно объяснить происходящее внутри. Их нельзя отождествлять; цель — получить данные, достаточные для конкретного решения, а не собирать всё подряд (PDF 173, 175–176).

## Процесс и контекст

1. Определите, какое управленческое или операционное решение должно поддерживать измерение. Не копируйте чужие списки метрик без соотнесения с вашей средой (PDF 174).
2. Выберите события и мониторы; учтите, что монитор может следить и за отсутствием ожидаемого события (PDF 176–178).
3. Собирайте метрики, журналы и трассировку; оценивайте влияние опросов, централизованного сбора и персональных данных (PDF 177–178).
4. Сокращайте объём данных без утраты нужного разрешения; рассчитывайте стоимость хранения и полезность исторических данных (PDF 178–179).
5. Анализируйте, формируйте SLI/SLO и визуализируйте результаты для действий команды (PDF 179–180).
6. Возвращайте информацию в организационную систему: при необходимости меняйте не только технические параметры, но и предпосылки решений (PDF 180–181).
