Книга: «Современное системное администрирование» — Дженнифер Дэвис, часть II «Методы».

## Главный принцип

Эффективная презентация превращает данные в **историю с контекстом, необходимым конкретной аудитории для решения**. Универсальная панель со всеми данными не может одинаково хорошо отвечать на вопросы команды, руководства и клиентов (PDF 116–117, 123–127, 133).

### Один проект — разные представления

В кейсе перемещения таблиц NoSQL между регионами команда видела список задач и их состояния, руководство — общий прогресс, отклонения и прогноз, клиент — доступность собственных таблиц и сроки. Детали инфраструктуры не нужны всем одинаково (PDF 124–127).
