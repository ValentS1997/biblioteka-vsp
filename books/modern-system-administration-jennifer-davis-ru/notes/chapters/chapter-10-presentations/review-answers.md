# Ответы-ориентиры на вопросы заключения

**RAG-only:** вопросы — [review-questions.md](review-questions.md), PDF 133 / `p0133:c01`; обоснования — PDF 116–133. **Не официальный ключ издателя**.

1. **Аудитория:** установить роль, интерес и задачу. В примере автора команда видит операции и статусы, менеджеры — сроки и отклонения, клиенты — доступность собственных таблиц. Без заданной реальной аудитории конкретный выбор — **[Needs confirmation]** (PDF 123–127).
2. **Природа данных и история:** автор перечисляет фактоид, взаимодействие, изменение во времени, сравнение и персонализацию. Не выдавать корреляцию за причинность (PDF 120–121). Выбор типа конкретной истории — **[Needs confirmation]**.
3. **Формат:** устная передача пригодна для немедленной обратной связи и эмоций; письменная — для фактов и размышления; визуальная поддержка полезна обоим форматам (PDF 118–120). Предпочтительный способ для заданного получателя — **[Needs confirmation]**.
4. **Смысл и контекст:** сформулировать решение, к которому нужно подготовить адресата, и дать данные, достаточные для этого решения; избегать общей панели ради полноты (PDF 116–117, 123–127). Конкретная цель — **[Needs confirmation]**.
5. **Отбор данных:** исключить лишние технические подробности, не скрывать пробелы или ограничения. В истории миграции клиенту не были нужны детали внутренних реплик, зато были нужны доступность и сроки (PDF 126–127).
6. **Визуальный тип:** таблица — для конкретных категорий и деталей; столбцы — для сравнения; линии и области — для динамики; тепловая карта — для характерных паттернов, treemap — для соотношений, flame-график — для профилирования. Подписи и источники обязательны для осмысленного чтения (PDF 128–133). Для неизвестного набора данных единственная правильная диаграмма — **[Needs confirmation]**.

Критерий заключения (PDF 133): результативная презентация помогает человеку понять мысль и быстро принять решение.
