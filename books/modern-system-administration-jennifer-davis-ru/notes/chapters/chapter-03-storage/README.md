# Глава 3. Хранилище

Книга: Дженнифер Дэвис, «Современное системное администрирование» (БХВ-Петербург, 2024). Инв. № 0011.

## Концептуальные выводы

1. **Опишите данные до выбора продукта:** какие они, кто создает и потребляет, каковы частота чтений/записей, чувствительность к задержке и требования к согласованности. [PDF 48, 56–57]
2. **Измеряйте не одним числом:** емкость, IOPS, размер I/O, пропускная способность и задержка характеризуют разные потребности. Пример EBS в книге исторический (таблица по состоянию на август 2022 года), не актуальный каталог тарифов. [PDF 50–52]
3. **Различайте абстракции:** блочные устройства для томов, файловые интерфейсы для дерева каталогов, объекты с метаданными для статичных массивов, БД для специализированной структуры и гарантий. [PDF 52–56]
4. **Размещайте по контексту:** локальное хранение требует капитальных вложений и обслуживания; облако расширяет возможности масштабирования и геораспределения, но формирует постоянные потенциально непредсказуемые расходы. [PDF 56–58]
5. **Управляйте полным жизненным циклом:** не собирать излишних данных, определять срок хранения, учитывать требования конфиденциальности, защиту доступа и шифрование. [PDF 59–61]
6. **Восстановление важнее декларации о резервировании:** проверяйте backup практическими моделированиями потери и документированной процедурой возвращения данных. [PDF 61–62]
