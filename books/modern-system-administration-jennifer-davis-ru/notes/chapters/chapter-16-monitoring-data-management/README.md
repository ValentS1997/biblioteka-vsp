# Глава 16. Управление данными мониторинга

**Книга:** Дженнифер Дэвис, «Современное системное администрирование», русское издание БХВ-Петербург, 2024. **Inventory:** `0011`; часть IV «Наблюдение за системой».

## Главный тезис

Данные мониторинга дают исторический контекст при расследовании инцидентов и поддерживают понимание текущего и будущего состояния систем. Эффективное управление требует **неизменяемости записей, определённых сроков хранения, доступности, подходящей структуры и контроля доступа**, а также разумного соотношения диагностической ценности и стоимости (PDF 195–202).

## Концептуальный алгоритм

1. Определить, какие события и вопросы действительно нужны команде при диагностике (PDF 195, 201).
2. Сопоставить **метрики, журналы и traces** по детализации, времени доставки, объёму и стоимости (PDF 196–199).
3. Установить семантику gauge/counter, согласованные поля и время для журналов, контекст транзакций для трассировки (PDF 196–199).
4. Подобрать объём сбора, retention, ротацию, поиск, а также условия надёжности доставки (PDF 199–200).
5. Ограничить доступ к чувствительным данным и проверить применимые требования по срокам (PDF 201–202).
6. После инцидента оценить, какие данные помогли, чего не хватило, что больше не приносит пользы (PDF 201–202).
