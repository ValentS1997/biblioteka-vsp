# Глава 17. Мониторинг вашей работы

**Книга:** Дженнифер Дэвис, «Современное системное администрирование» (русское издание БХВ-Петербург, 2024), часть IV «Наблюдение за системой», inventory `0011`.

## Главный тезис

Визуализация собственной работы помогает видеть её **ценность и контекст**, а не только число закрытых запросов или строк кода. Осмысленный мониторинг задач способствует координации, выявлению ограничений, предотвращению авралов и осознанному развитию. Автор предлагает постепенно применять **канбан**, ограничивать WIP, анализировать рабочий поток и проверять соотношение усилий и результата (PDF 203–211).

## Практический рабочий цикл

1. Выяснить, **какая работа ценна** для команды, бизнеса, клиентов и собственного развития; не подменять полезный результат количеством закрытых задач (PDF 203–207).
2. Нарисовать реально существующий процесс, начать с простых колонок, вместе с командой определять изменения (PDF 205, 207).
3. Представлять задачи карточками: название, тип/категория, ориентировочный объём, при необходимости ценность (PDF 205–207).
4. Ограничить одновременно начатую работу, отслеживать перемещение карточек и блокировки (PDF 205, 207).
5. Собирать доступные метрики: время выполнения, WIP, throughput, различия по категориям (PDF 207–209).
6. Через несколько недель проверить, где возникают задержки и частые переключения; по возможности улучшать одну проблемную часть процесса (PDF 207, 209–210).
7. Учитывать ETTO, обучение, профессиональные интересы и нагрузку; договариваться о приоритетах на уровне команды/заинтересованных сторон (PDF 206–211).
