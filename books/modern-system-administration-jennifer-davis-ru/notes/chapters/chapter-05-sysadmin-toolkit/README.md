# Глава 5. Набор инструментов сисадмина

Книга: **«Современное системное администрирование»**, Дженнифер Дэвис. Часть II «Методы».

**Основная мысль.** Цифровой инструментарий системного администратора — управляемая, изолированная среда разработки и набор редакторов, языков, библиотек и приложений, позволяющие экспериментировать, автоматизировать рутину и согласованно работать в команде без риска для продуктивных систем.

## Карта главы

1. **Что представляет собой цифровой инструментарий** (PDF 73–74). Изолированная среда, автономная работа, отладка, адаптация сотрудников и соблюдение технических стандартов.
2. **Выбор редактора** (PDF 75–76). Статический анализ (ShellCheck), автозавершение, единый стиль и интеграция с Git.
3. **Выбор языков программирования** (PDF 76–79). Bash/PowerShell, Python/C#/Ruby/Go, существующие навыки команды, миграции, зависимости и версионирование.
4. **Фреймворки и библиотеки** (PDF 79). Например, AWS SDK, PagerDuty API и ChatOps; фиксировать используемые версии.
5. **Другие полезные утилиты** (PDF 79–81). Dotfiles, Ag, bash-completion, curl, Docker, gh, Git, HTTPie, jq, mkcert, ShellCheck, tmux, tree.
6. **Заключение** (PDF 82). Согласованность и повторяемость среды; обмен инструментами внутри команды.

## Границы и неопределённости

Это руководство по подбору и организации среды, а не готовая инструкция по развёртыванию. Команды установки, конкретные версии, конфигурации сервисов, измеримые критерии тестирования и откат для всех утилит источником не даны: **[Needs confirmation]**.
