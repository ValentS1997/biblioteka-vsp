# Команды и инструменты — глава 5

**Источник:** только RAG главы 5: PDF 73–82 (`p0073-c01` — `p0082-c01`). Классификация описывает потенциальный эффект конкретного упоминания; не равна инструкции по установке. Если аргументы/флаги не приведены, они не добавлены по памяти модели.

## Команды с явным примером

| Исходная запись | Класс | Эффект и риск | Проверка / rollback |
|---|---|---|---|
| `gh pr checkout <issue-number>` | **State-changing (локальный checkout)** | В PDF 81 предлагается локально проверить PR перед одобрением; команда изменяет активное состояние Git-рабочего каталога. Риск: непредусмотренное переключение контекста работы. | Результат локального тестирования должен быть оценён; точные команды проверки и возврата — **[Needs confirmation]**. |
| `docker run` (без аргументов в книге) | **Workload-generating / state-changing** | В PDF 80–81 инструмент назван для создания рабочей тестовой среды на основе Dockerfile. Требуются параметры окружения и образ; запуск изменяет состояние среды и создаёт workload. | Сопоставить среду с задачей; точная команда, способ проверки и удаления/отката — **[Needs confirmation]**. |

**Важно:** оба примера приведены как иллюстрации, а не готовый универсальный runbook.

Установочных команд в главе нет. Заменять системный язык предлагается **не** напрямую: новую версию устанавливать отдельно и настраивать пути (PDF 78–79), без универсальных инструкций в тексте.

## Дефект исходного Bash-примера

На PDF 75–76 приведены цикл через `$(ls *.png)` и вариант через `*.png`, но RAG-текст включает повреждённые токены/строки (`is` вместо `ls` в прозе, неразделённые `do/done`, некорректное имя переменной). **Возможный смысл — избегать разбора вывода ls и использовать glob — подтверждён прозой**, однако исполняемый корректный код из данного извлечения не подтверждён. Здесь намеренно не приводится «починенная» команда. См. [source-findings.md](source-findings.md).

## Правило безопасности

Команда или флаг отсутствуют в RAG — оставляем **[Needs confirmation]**. Для любой state-changing операции до запуска потребуются конкретный контекст, проверка результата и возврат к исходному состоянию; в книге это не формализовано.
