# Заключение главы 12 — пересказ по RAG

**Источник:** явный раздел «Заключение» в chunk `modern-system-administration-jennifer-davis-ru:p0156:c01`, PDF 156, печатная 162. Политика `rag_only`.

Программно управляемые ресурсы делают практики **Infrastructure as Code (IaC)** и **Infrastructure as Data (IaD)** полезным набором методов для создания, тестирования, развертывания и дальнейшего управления инфраструктурой. Контроль версий, проверка кода и автоматизированное тестирование давно используются в разработке программного обеспечения; автор считает эти практики целесообразными и для инфраструктуры.

Если организация пока не использует такие методы, внедрение должно идти **постепенно**. Начинать рекомендуется с конкретных участков, где методы управления помогут команде эффективнее взаимодействовать и быстрее получать улучшения. Это не призыв автоматизировать всю инфраструктуру одним проектом.

Это смысловой пересказ существующего заключения, без внешнего расширения. Конкретные команды инструментов, контрольные пороги и rollback в заключении отсутствуют — **[Needs confirmation]**.
