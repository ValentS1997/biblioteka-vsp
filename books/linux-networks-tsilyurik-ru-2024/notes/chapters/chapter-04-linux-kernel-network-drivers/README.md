## Центральная идея

Сетевая подсистема Linux прослеживается «изнутри»: **модули ядра → структуры `sk_buff` и `net_device` → приём через IRQ/softirq или NAPI → передача через `ndo_start_xmit` → фильтры протоколов → интерфейс прикладных сокетов**. Работа с модулем и указателями на буферы касается общего ядра, поэтому ошибки владения памятью, выгрузки модуля или некорректного перехвата трафика способны нарушить сеть и систему в целом.
