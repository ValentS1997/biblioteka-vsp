# Команды и Socket API части III — RAG-confirmed

Классы: **RO** — чтение/наблюдение без целевого изменения параметров; **WG** — создаёт процесс, обменивается/захватывает трафик, изменяет данные в рамках запроса; **SC** — меняет конфигурацию, права, параметры сокетов/дескрипторов/процессов. Для строк с несколькими классами необходимо оценить фактическое воздействие. Имена `HOST`, `PORT`, `IFACE`, `FILE`, `SERVICE`, `PID` — placeholders. Программы `./*` предполагают наличие **проверенного и собранного** архива книги: [Needs confirmation].

## API чтения и готовности — обзор без копирования ошибочного кода

- RO-наблюдение данных сокета: `getsockname()`, `getpeername()`, `getsockopt()`; [PDF 149](../../../rag/chunks/p0101-p0200/p0149-c01.md), [PDF 150](../../../rag/chunks/p0101-p0200/p0150-c01.md).
- Готовность I/O: `select()`, `pselect()`, `poll()`; в исходнике также упомянут `epoll()`, но полноценная реализация epoll **не приведена**: [PDF 176](../../../rag/chunks/p0101-p0200/p0176-c01.md), [PDF 180](../../../rag/chunks/p0101-p0200/p0180-c01.md), [PDF 181](../../../rag/chunks/p0101-p0200/p0181-c01.md), [PDF 182](../../../rag/chunks/p0101-p0200/p0182-c01.md).
- Вызовы I/O `read/write/recv/send` и готовность `select` не подтверждают, что получено сообщение целиком: [PDF 133](../../../rag/chunks/p0101-p0200/p0133-c01.md), [PDF 138](../../../rag/chunks/p0101-p0200/p0138-c01.md), [PDF 181](../../../rag/chunks/p0101-p0200/p0181-c01.md).
- В книге приведён `tcpdump` на `9877` для наблюдения TCP handshake и эхо-трафика. Захватывать данные не принадлежащих вам узлов нельзя. [PDF 179](../../../rag/chunks/p0101-p0200/p0179-c01.md).
