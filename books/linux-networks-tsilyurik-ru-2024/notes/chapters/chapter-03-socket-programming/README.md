## Основной тезис

Автор объясняет сетевой обмен через **POSIX Socket API** и его реализацию на C (иногда C++). В UDP границы датаграмм являются частью транспортной модели; TCP предоставляет **непрерывный поток байтов**, поэтому чтение может вернуть любой фрагмент записанного сообщения. Границы сообщений необходимо конструировать на прикладном уровне: разделители, поле длины или фиксированная длина с дополнительной обработкой.
