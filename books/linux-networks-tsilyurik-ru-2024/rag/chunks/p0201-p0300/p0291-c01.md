Проект разработан на новом языке системного программирования — Rust. Помимо
прочего, он позволяет компилировать код в компактные запускаемые файлы под
множество разных платформ. Мы уже использовали Rust ранее и отмечали, что
если сама языковая система (менеджер cargo) Rust установлена полностью и пра-
вильно (а это делается несложным образом), то сборка приложений не создает про-
блем. Характерным для проектов Rust является то, что система сама подгрузит все
необходимые для проекта библиотечные компоненты (крейты — в терминологии
языка Rust).

Но в некоторых дистрибутивах Linux (Debian, Ubuntu, Mint и т. п.) для нашего про-
екта необходимо предварительно по зависимостям проверить наличие и при необ-
ходимости установить недостающие пакеты:

$ sudo apt install libwebkit2gtk-4.0-dev
