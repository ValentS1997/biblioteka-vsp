    ПОЯСНЕНИЕ
      Здесь мы пока сознательно запускаем приложение с опцией -n — без GUI, только
      в качестве резолвера интернет-имен!

$ sudo netstat -anp | grep 127.0.0 | grep 53
tcp       0     0 127.0.0.53:53      0.0.0.0:*          LISTEN      1104/systemd-resolv
tcp       0     0 127.0.0.4:53       0.0.0.0:*          LISTEN      22946/./target/rele
udp       0     0 127.0.0.4:53       0.0.0.0:*                      22946/./target/rele
udp       0     0 127.0.0.53:53      0.0.0.0:*                      1104/systemd-resolv
udp       0     0 127.0.0.1:5353     0.0.0.0:*                      1313/python3

    ПОЯСНЕНИЕ
      Здесь PID=22946 — это новый резолвер Alfis, а PID=1104 — кеширующий резолвер systemd,
      который мы рассматривали как-то ранее. И важно именно то, что они работают парал-
      лельно, независимо, не препятствуя друг другу.
