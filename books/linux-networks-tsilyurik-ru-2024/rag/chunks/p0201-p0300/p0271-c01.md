270                                                              Часть V

      «Проект I2P был начат в 2003 году для поддержки тех, кто заинтересован в новом не-
      цензурируемом, анонимном средстве общения и распространения информации. <...>
      I2P представляет собой защищенный протокол обмена данными, работающий поверх
      привычного протокола TCP/IP (на самом деле в первую очередь используется прото-
      кол UDP, а если его использовать не удается, то TCP).

       ...Сеть Tor использует так называемую луковую маршрутизацию, когда каждое про-
      межуточное звено снимает один слой шифрования, в результате чего последнее зве-
      но общается с конечным сервером открытым текстом... Протокол I2P работает по-
      другому — он использует чесночную маршрутизацию. В этом случае каждый пакет,
      который нужно передать (аналог — зубчик чеснока), шифруется, а затем упаковывает-
      ся в большой пакет (головку, чесночину), которая содержит еще несколько таких зуб-
      чиков-пакетов для передачи к разным узлам. Таким образом, когда пользователь
      получает чесночину, он извлекает из нее зубчик-пакет, предназначенный для него са-
      мого, а остальные зубчики передает дальше. Так как все зубчики зашифрованы, то
      только тот, кому предназначен зубчик, знает, что с ним делать дальше».

Первоначально проект (i2p) был написан на языке Java, но позже полностью пере-
писан на языке C++ (проект i2pd) — мы далее будем рассматривать только послед-
нюю из названных реализаций.

Запуск сети

Проект I2P, будучи достаточно «возрастным» (2003), реализован для большинства
используемых операционных систем: Microsoft Windows, Linux, macOS, OpenBSD,
FreeBSD и Android. Для его инсталляции регулярно предоставляются готовые
бинарные сборки (необходимые ссылки вы найдете в списке источников в конце
части), однако под Linux, к сожалению, можно получить только RPM-пакеты.
Впрочем, если вы хотите поэкспериментировать с этой сетью в Linux, то можете ее
легко собрать из исходных кодов:

$ git clone https://github.com/PurpleI2P/i2pd.git

Из зависимостей вам потребуется довольно очевидный «джентльменский набор»
пакетов, который хорошо бы предварительно проверить и при необходимости до-
установить:

$ aptitude search libboost-chrono-dev libboost-date-time-dev libboost-filesystem-dev \
  libboost-program-options-dev libboost-system-dev libboost-thread-dev libssl-dev

Конфигурируется сборка посредством cmake:

$ cd i2pd/build/
$ cmake -DCMAKE_BUILD_TYPE=Release
