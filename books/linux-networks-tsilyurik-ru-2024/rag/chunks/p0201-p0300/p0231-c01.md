230                                                              Часть IV

Каждый из обработчиков должен осуществлять подмену интерфейса только для тех
фреймов, IP-адрес получателя которых совпадает с IP-адресом интерфейса, а два
раздельных обработчика удобны тем, что заголовки фреймов ARP и IP имеют
совершенно разный формат, и выделять IP-адрес назначения в них приходится
по-разному  (весь полный код приведен  каталоге  virt-proto файлового  архива,
сопровождающего книгу).
Используя такой полновесный модуль, можно открыть к хосту, например, одно-
временно две параллельные сессии SSH на разные интерфейсы: родительский и
виртуальный (использующие разные IP-адреса), которые будут в параллель реально
использовать единый общий физический интерфейс:

$ ssh olej@192.168.50.17
olej@192.168.50.17's password:
Last login: Mon Jul 16 15:52:16 2012 from 192.168.1.9
$ ssh olej@192.168.56.101
olej@192.168.56.101's password:
Last login: Mon Jul 16 17:29:57 2012 from 192.168.50.1
$ who
olej     tty1         2012-07-16 09:29 (:0)
olej     pts/0        2012-07-16 09:33 (:0.0)
olej     pts/1        2012-07-16 12:22 (192.168.1.9)
olej     pts/4        2012-07-16 15:52 (192.168.1.9)
olej     pts/6        2012-07-16 17:29 (192.168.50.1)
olej     pts/7        2012-07-16 17:31 (192.168.56.1)

Последняя показанная команда (who) выполняется уже в сессии SSH, т. е. на том
самом удаленном хосте, к которому и фиксируются командой два независимых
подключения из двух различных подсетей (последние две строки вывода), которые
на самом деле представляют один хост.

Протокол транспортного уровня

На этом уровне (L4) обеспечивается обработка таких протоколов, как: UDP, TCP,
SCTP, DCCP, и их число возрастает. Протоколы транспортного уровня (протоколы
IP) описаны в <linux/in.h>:

/* Standard well-defined IP protocols.  */
enum {
  IPPROTO_IP =     0,   /* Dummy protocol for TCP              */
  IPPROTO_ICMP =   1,   /* Internet Control Message Protocol    */
  IPPROTO_IGMP =   2,   /* Internet Group Management Protocol   */
  IPPROTO_TCP =    6,   /* Transmission Control Protocol       */
  IPPROTO_UDP =   17,   /* User Datagram Protocol              */
  IPPROTO_SCTP = 132,   /* Stream Control Transport Protocol    */
