288                                                              Часть V

Для бесшовного объединения дерева альтернативных доменных имен от EmerCoin
c обычными доменными именами от ICANN со стороны клиента нужно иметь точ-
ку сопряжения, где происходит передача запроса в ту или иную систему. Для этого
предложены разные варианты, и одним из простейших в применении является ис-
пользование адресов DSN-серверов сообщества OpenNIC (https://www.opennic.org/).
EmerCoin поддерживает пиринговое соглашение с провайдером DNS OpenNIC, а
это означает, что домены, зарегистрированные в EmerDNS, доступны по умолча-
нию для всех пользователей DNS-серверов OpenNIC. OpenNIC — это простой и
удобный способ беспрепятственного доступа ко всем веб-сайтам, зарегистрирован-
ным в блокчейне EmerCoin, а также ко всем другим доменным зонам, которые под-
держивает OpenNIC.

Эти IP-адреса DNS вы можете прописать как сетевые DNS, например, в кеширую-
щем сервере systemd, о котором речь шла ранее. Вот, например, как может быть
прописана конфигурация кеширующего сервера для этого случая:

$ grep -v ^# /etc/systemd/resolved.conf | grep -v ^$
[Resolve]
DNS=94.16.114.254 94.247.43.254 194.36.144.87
FallbackDNS=192.168.1.3 1.1.1.1 8.8.4.4
LLMNR=yes

При этом:

$ resolvectl status
Global
           Protocols: +LLMNR -mDNS -DNSOverTLS DNSSEC=no/unsupported
    resolv.conf mode: stub
  Current DNS Server: 94.16.114.254
         DNS Servers: 94.16.114.254 94.247.43.254 194.36.144.87
Fallback DNS Servers: 192.168.1.3 1.1.1.1 8.8.4.4

Link 2 (eno1)
Current Scopes: LLMNR/IPv4 LLMNR/IPv6
     Protocols: +DefaultRoute +LLMNR -mDNS -DNSOverTLS DNSSEC=no/unsupported

Link 3 (eno2)
Current Scopes: LLMNR/IPv4 LLMNR/IPv6
     Protocols: +DefaultRoute +LLMNR -mDNS -DNSOverTLS DNSSEC=no/unsupported

Link 4 (tun0)
Current Scopes: LLMNR/IPv6
     Protocols: -DefaultRoute +LLMNR -mDNS -DNSOverTLS DNSSEC=no/unsupported

И тогда у вас с адресами, разрешаемыми альтернативными DNS (EmerCoin), начи-
нают работать привычные утилиты GNU без каких-либо других изменений в сис-
теме:

$ host linux-ru.lib
linux-ru.lib has address 90.156.230.27
$ host ygg.linux-ru.lib
ygg.linux-ru.lib has IPv6 address 221:58c9:9a6:99be:f3d:c1ac:2b5b:9771
