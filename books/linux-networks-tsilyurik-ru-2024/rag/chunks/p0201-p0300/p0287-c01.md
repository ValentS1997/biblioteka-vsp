286                                                              Часть V

(изредка доходит до 30) — и ваша запись внесена в блокчейн системы! Запись вно-
сится в блокчейн, и ее копия с этого момента присутствует в каждом кошельке

                         Рис. 5.10. DNS-имена, сохраненные в блокчейне

Для адресов IPv6 таким же образом в поле Value заносим записи типа AAAA. На
рис. 5.10 показана в качестве примера запись для адреса того же ресурса в сети
Yggdrasil (как описывалось ранее):

$ host ygg.linux-ru.lib

ygg.linux-ru.lib has IPv6 address 221:58c9:9a6:99be:f3d:c1ac:2b5b:9771

    ПОЯСНЕНИЕ
      Здесь для хоста Yggdrasil зарегистрирована отдельная запись, поскольку, как уже
      отмечалось ранее, IPv6-сети Yggdrasil не являются «нативными» адресами IPv6. Но
      если несколько записей разных типов относятся к одному доменному имени (как это
      бывает и для обычных DNS в Интернете), то они записываются в поле Value одной
      строкой с разделителем (символ | и без пробелов) — например: A=185.31.209.8|AAAA=
       2a04:5340:1:1::3|MX=mx.ya.ru:10.

Мы таким образом создали новые записи DNS. Но система (кошелек) EmerCoin
имеет в своем составе и механизм для разрешения имен непосредственно запроса-
ми к кошельку, однако по умолчанию этот механизм отключен. Активировать сер-
вер DNS в стиле RFC1034 нужно в конфигурационном файле emercoin.conf, который
обычно (место может быть переопределено при установке EmerCoin) находится
в каталоге (часто это может быть ссылка на каталог, но это ничего не меняет):

$ grep ^emc $HOME/.emercoin/emercoin.conf
emcdns=1       # Запускать DNS-сервер
emcdnsport=5335 # Порт для DNS, по умолчанию 5353
