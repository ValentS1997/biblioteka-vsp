Драйверы сетевых устройств в ядре Linux                                       233

Источники использованной информации

1. Rosen R. Linux Kernel Networking: Implementation and Theory. New York: Apress, 2014,
   ISBN: 978-1-4302-6196-4, p. 612: http://www.foxebook.net/linux-kernel-networking-
   implementation-and-theory/ (там же книгу можно свободно скачать).

2. Сэтчэлл С., Клиффорд Х. Linux IP Stacks в комментариях. К.: ДиаСофт, 2001,
   ISBN: 966-7393-83-6, 288 стр.

3. Linux Network Configuration:
   http://www.yolinux.com/TUTORIALS/LinuxTutorialNetworking.html#CONFIGFILES

4. Олег Цилюрик, статьи в редакциях разных лет (различающиеся):

   •  Сеть IP — когда писать программы лень:

          http://smartbox.jinr.ru/qnx.org.ru/article10.html, 2002;

         http://rus-linux.net/MyLDP/algol/Simple-TCP-programming.html, 2012;

   •  Сервер TCP/IP ... много серверов хороших и разных:

          http://www.cta.ru/online/online_progr-nets.htm — журнал «СТА» («Современные
         технологии автоматизации»), М., 2003;

          http://rus-linux.net/MyLDP/algol/analiz-variantov-realizacii-TCP-IP-servera-
          01.html, 2012;

   Эти же статьи в книге: Алексеев Д., Видревич Е., Волков А., Горошко Е., Горчак М.,
   Жавнис Р., Сошин Д., Цилюрик О., Чиликин А. Практика работы с QNX. М.: КомБук,
   2004, 432 стр., ISBN: 5-94740-009-Х. Книгу можно скачать здесь:
   http://9knig.ru/os/19431-praktika-raboty-s-qnx..html.

5. LXR (Linux Cross-Referencer) — ресурсы перекрестного анализа исходных кодов ядра
   Linux:

   •  http://lxr.free-electrons.com/source/;

   •  http://lxr.linux.no;

   •  http://lxr.missinglinkelectronics.com/linux;

   •  http://lxr.oss.org.cn/.

6. Цилюрик О. И. Расширения ядра Linux: драйверы и модули. СПб.: БХВ-Петербург,
   март 2023. — 688 стр. ISBN: 978-5-9775-1719-5.
