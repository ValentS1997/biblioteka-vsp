26                                                                Часть I

ставляется четырьмя шестнадцатеричными цифрами. Хекстеты отделяются друг от
друга знаком двоеточия. Таким образом, полный адрес всегда состоит из 8 хексте-
тов ([8 хекстетов]×[16 битов в хекстете]=[128 битов] — общая длина адреса).

Стандарт IPv6 регламентируется существенно сложнее, подробнее и многообразнее,
чем IPv4. На основании префиксов выделяются классы использования. Вот некото-
рые диапазоны адресов, которые мы будем использовать дальше в обсуждениях:

   все адреса в диапазоне fe80::/10 называются link-local (о них речь впереди). Лю-
  бой адрес из этого диапазона предназначен для автоконфигурирования ОС,
  и пакеты, отправленные с такого адреса, не пропустит ни один маршрутизатор,
   ограничивая их распространение в пределах сегмента локальной сети. Протокол
   IPv6 спроектирован так, что интерфейс обязан иметь link-local-адрес, даже если
   у него есть другой IPv6 для других целей;

   для уникальных юникаст-адресов в Интернете комитет IANA в настоящее время
   выделяет IPv6-адреса из класса 2000::/3;

   адреса ff00::/8 — это адреса мультикаст. По такому адресу мы можем получить
   отклик всех интерфейсов, работающих в локальной сети этого интерфейса:

Сокращения записи IPv6

Вот пример адреса: 2001:0DB8:AA10:0001:0000:0000:0000:00FB.

С таким длинным адресом работать достаточно неудобно, поэтому для IPv6 приме-
няют сокращенную по специальным правилам запись. Для того чтобы сократить
такой адрес, надо последовательно применить два следующих правила.
