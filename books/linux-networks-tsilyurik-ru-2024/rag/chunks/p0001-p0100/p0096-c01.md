(Обращаем внимание, что резолвер systemd использует не вообще какой-то адрес
петлевого интерфейса localhost, а выделенный для этого IP-адрес 127.0.0.53.)
Но дефолтное разрешение пока еще будет происходить через список адресов DNS-
серверов:

$ cat /etc/resolv.conf
# Generated by resolvconf
nameserver 1.1.1.1
nameserver 8.8.8.8

Один из вариантов выхода из этой ситуации состоит в том, чтобы заменить содер-
жимое /etc/resolv.conf строкой:

nameserver 127.0.0.53

Но  документация  systemd рекомендует  другой  способ:  сделать  вместо  /etc/
resolv.conf ссылку на подготовленный файл  /run/systemd/resolve/stub-resolv.conf
