Вот теперь мы можем поэкспериментировать с DNS-сервером и оценить, что дает
нам факт кеширования:

   проверяем разрешение через сетевой DNS-сервер (это Google DNS из числа по-
  пулярных и лучших) для двух произвольно взятых имен1:

   $ host -v qnx.org.ru | grep Received

    Received 44 bytes from 1.1.1.1#53 in 348 ms
    Received 80 bytes from 1.1.1.1#53 in 60 ms
    Received 57 bytes from 1.1.1.1#53 in 48 ms

1 Команда host отправляет последовательно три запроса и получает три ответа для получения DNS-
записей соответственно типов: A (IPv4), AAAA (IPv6), MX (запись для электронной почты, указы-
вающая, какими серверами она обрабатывается). Поэтому для оценки общего времени ответа можно
использовать сумму этих трех значений.
