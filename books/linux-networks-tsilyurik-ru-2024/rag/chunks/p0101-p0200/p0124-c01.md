В файле конфигурации мы теперь поменяли тип аутентификации на username, а се-
тевые интерфейсы (и входные, и выходные) определяем не именами, а их адресами
(и IPv4, и IPv6). Но далее нам нужно:

   создать (если она не создалась при инсталляции пакета) группу пользователей
   proxy;

   создать имена (одного или нескольких) пользователей для работы через прокси
   без возможности логирования в терминальной сессии:

   # useradd --shell /usr/sbin/nologin proxy_user_02

   добавить пользователям пароли для работы через прокси:

   # passwd proxy_user_02
    Новый пароль :
    Повторите ввод нового пароля :
    passwd: пароль успешно обновлен

   добавить таких пользователей в группу proxy:

   # sudo usermod -a -G proxy proxy_user_02

В итоге только пользователи с назначенными именами (здесь их двое) могут авто-
ризоваться на этом прокси-сервере:

$ cat /etc/group | grep proxy
proxy:x:13:proxy_user_01,proxy_user_02
