extern int getpeername(int __fd, __SOCKADDR_ARG __addr,
                       socklen_t *__restrict __len) __THROW;

Первая из них (getsockname()) возвращает локальную, а вторая (getpeername()) — уда-
ленную адресную структуру протокола, связанную на текущий момент с сокетом.

Использование сокетного API

Базовые схемы построения обмена в клиентских и серверных кодах и для UDP,
и для TCP остаются практически постоянными от проекта к проекту, хотя в деталях
могут существенно различаться1. Рассмотрим эти базовые схемы (все примеры
кодов находятся в каталоге echo-cli-serv сопровождающего книгу файлового архива).
