За простоту программного кода сервера нужно платить некоторой усложненностью
системной конфигурации для его запуска:
1. При запуске сервера должно указываться абсолютное путевое имя программы
   сервера, поэтому копируем программу куда-то в легкодоступное место (в экспе-
   риментах — в домашний каталог пользователя):

   $ cp ech3.sh $HOME
   $ ls ~/ech*
    /home/Olej/ech3.sh

2. Добавить запись конфигурации xinetd в каталог /etc/xinetd.d отдельным файлом
   (в примере используем xinetd, остальные суперсерверы конфигурируются по-
   добно):

   # cat /etc/xinetd.d/ech3
    service ech3
   {
        disable = no
        protocol = tcp
       wait = no              # параллельный сервер
       user = Olej             # имя, от которого запускать
       server = /home/Olej/ech3 # путь к программе
   }

3. При каждой правке конфигураций заставить перечитать новые конфигурации.
  Это можно сделать, либо послав запущенному серверу сигнал SIGHUP:

   # ps -A | grep inetd
     7408 ?        00:00:00 xinetd
   # kill -SIGHUP 7408

   либо полностью перезапустив суперсервер:

   # systemctl restart xinetd.service
   # systemctl status xinetd.service
    xinetd.service - Xinetd A Powerful Replacement For Inetd
       Loaded: loaded (/usr/lib/systemd/system/xinetd.service; enabled)
       Active: active (running) since Вс 2014-06-15 23:33:41 EEST; 42min ago
