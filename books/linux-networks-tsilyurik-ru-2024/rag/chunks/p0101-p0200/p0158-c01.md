Клиент-сервер в UNIX-домене

Для сравнения в файловом архиве примеров приведены клиент и эхо-сервер, рабо-
тающие в семействе протоколов UNIX-домена — это взаимодействие в пределах
локального компьютера. Такое сравнение способствует гораздо более глубокому
пониманию вопросов сетевого программирования. Подобным образом взаимодей-
ствуют графические (GUI) пользовательские приложения Linux с сервером графи-
ческой подсистемы X11 и с оконными менеджерами (вообще-то говоря, с сетевыми
приложениями и протоколом). В сопровождающем книгу файловом архиве со-
держатся пары приложений (клиент и сервер) как для UDP (файлы unixdgcli.c и
unixdgserv.c), так и для TCP (файлы unixstrcli.c и unixstrserv.c).
Их работа (тестирование) будет выглядеть аналогично показанному ранее:

$ ./unixstrserv
$ ./unixdgserv
$ ./unixstrcli
UNIX сокет поток
UNIX сокет поток
$ ./unixdgcli
UNIX датаграмм поток
UNIX датаграмм поток

Управляющие операции

Функция ioctl() традиционно являлась системным интерфейсом управления для
всего, что не попадало в какую-либо другую, четко определенную категорию.
Стандарт POSIX постепенно избавляется от вызова ioctl() в различных ситуациях,
заменяя ее функциями-обертками со стандартизованной функциональностью.

Тем не менее ioctl() может использоваться во многих случаях получения информа-
ции от сетевого стека или для управления функциональностью сокета. Функция
определена так:

int ioctl(int fd, int request, void* arg);

Функция всегда применяется к файловому дескриптору или сокету. Вид третьего
аргумента полностью определяется целочисленным кодом операции request (часто
это указатель на числовое значение, но может быть и сложная структура). Для счи-
тывания и изменения значения одного и того же параметра используются разные
коды ioctl() (код определяет направление передачи данных). Определения некото-
рых кодов, относящиеся к области сокетов, можно найти в файле <linux/sockios.h>:

/* Socket configuration controls. */
#define SIOCGIFNAME     0x8910          /* get iface name              */
#define SIOCSIFLINK     0x8911          /* set iface channel           */
#define SIOCGIFCONF     0x8912          /* get iface list              */
