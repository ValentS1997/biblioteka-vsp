# Глава 4 — RAG-обоснованный разбор заданий

**Основа:** [review-questions.md](review-questions.md) и canonical RAG `p0057:c01`–`p0068:c01`. Это **не официальный ключ ответов** и не результаты выполнения `a86`/`d86`. Численные ответы получены из текстовых правил главы; непроверенный синтаксис отмечен **[Needs confirmation]**.

## A. Регистры (№1–6; p. 58–59)

1. `ch=0`, `cl=1`, поэтому `cx=0001` и `si=0001`. После `mov ah,bit 0` старший байт `ax` равен 1, но **`al` не задан**: `di=01??`, точное значение [Needs confirmation]. Автор ранее подчёркивает ту же неопределённость `ah` при записи только в `al`.
2. `by` задаёт старший и младший байты (смысл оператора введён в главе 3, повторён записью задания): младший — `bit 1 + bit 4` (18), старший — `0ff`. После `inc ah` старший байт переполняется. Ожидаемый `ax=0012`; экспериментальное подтверждение [Needs confirmation].
3. `ax=01ff` → `inc ax` даёт `0200` → `inc al` даёт **`0201`**.
4. `ax=01ff` → `inc al` даёт `0100` → `inc ax` даёт `0101` → `not ax` даёт **`fefe`**.
5. `ah=-2` (байт FE), `dh=-1` (FF), `dl=ah` (FE), `inc dh` обнуляет старший байт: **`dx=00fe`**.
6. `cx=(bit 1) by -1` → старший байт 2, младший FF; `inc cl` → 00, `inc cx` → 0201, `inc ch` → 0301. Вопрос спрашивает **`ch=03`**.

Числовые результаты являются аналитическим применением примеров `inc`, `mov`, `not`, `by` из текста. Переполнение регистров и фактическое поведение в `d86` отдельно не проверялись.

## B. Адресация и типы (№1–6; p. 60–63)

1. `mov ah,bh`: два регистровых операнда. `inc w[0]`: прямая адресация слова в памяти. `add byte[0fffe],type(w[0])`: прямая память и непосредственное константное выражение `type`; совместимость конкретного выражения проверить в `.lst`.
2. `mov 1 shl 3,ax` — константа в месте приёмника. `add bx` — недостающий второй операнд в рассматриваемой форме `add`. `mul ax,cx` — лишний явный операнд: у `mul` другой множитель неявно находится в `ax`.
3. `add [-2],256` — у 256 размер слова следует из величины константы в обсуждаемом 16-битном контексте, поэтому размер может быть выведен; адрес отрицательный, что является отдельным вопросом теста [Needs confirmation]. `add [10],255` — размер неоднозначен, нужен `b/w`. `mov [3],ax` — размер word определяется по `ax`. `inc [0]` — неизвестно, byte или word.
4. `mul w[0]`: явный операнд — прямая память, word; другой множитель — неявный `ax`, результат помещается в `dx:ax` (p. 60).
5. `add ax,1` — слово; `inc byte ptr [0]` — байт; `mov ax,[0]` — слово по регистру `ax`.
6. `add 5,9` — недопустимая константа-приёмник. `add ax,1` — регистровая + непосредственная, допустимо. `mov al,cx` — несовместимые 8- и 16-битные размеры.

## C. Семь заданий с массивами (p. 64–67)

Автор требует **тело цикла**, а не программу с условием останова. Ниже только схемы шагов; проверка корректности каждой формы конкретным `a86` — [Needs confirmation]. **Не запускать их как бесконечный `jmp l1` без контроля границ.**

1. Для слов со смещением: начать с `si=0`, использовать `inc w[si+area]`, после каждой обработки прибавлять к `si` **2** (p. 65).
2. Для слов без смещения: начать с `si=offset area`, `inc w[si]`, затем `add si,2`.
3. Для каждого второго слова: `add w[si+area],20`, затем перейти по индексу на **4 байта**.
4. Для `buf dw 1k dup(1,3,-1),-3`: `si=0`, `inc w[si+buf]`, `add si,2`. Число проходов и условие останова по исходному заданию не заданы.
5. Для той же области `buf`, но по байтам: `si=0`, `inc b[si+buf]`, `inc si`. Не путать количество байтов со словами исходной директивы.
6. Каждый четвёртый байт: при смещении `inc b[si+area]` с шагом `add si,4`; без смещения установить `si=offset area`, использовать `inc b[si]` и тот же шаг 4.
7. Обратный обход: поставить `si` на последний байт выделенной области; `inc b[si]`, затем `dec si`. Начальный адрес последнего байта и условие завершения должны быть вычислены из реальной длины массива: **[Needs confirmation]**.

## D. Почему неверны девять команд листинга 4.15 (p. 67)

| Команда | Причина |
|---|---|
| `add [si+bx],w[0]` | Два явно адресуемых операнда памяти. |
| `inc [si+bx]` | Размер операнда памяти не задан. |
| `inc w[bl]` | `bl` — 8-битная часть регистра, не допустимый регистр косвенной адресации. |
| `inc w[di+ax]` | `ax` не допустим в паре адресных регистров; нужен `bx/bp + si/di`. |
| `add 1,b[si+di]` | Непосредственный приёмник + недопустимая пара `si+di`. |
| `mov al,w[0]` | Byte `al` и word памяти несовместимы по размеру. |
| `mov ax` | Для показанной формы `mov` недостаёт источника. |
| `add [si],b[di]` | Два явно заданных операнда памяти. |
| `inc b[bh]` | `bh` — 8-битная часть регистра, не допустимый адресный регистр. |
