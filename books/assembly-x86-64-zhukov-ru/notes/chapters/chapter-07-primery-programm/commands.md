# Глава 7 — команды, вызовы DOS и эксперименты

**Источник:** canonical RAG PDF 93–110; листинги 7.1–7.10. Синтаксис a86/FreeDOS/d86 — как в книге, без выдуманных альтернатив. Здесь команды **не выполнялись**.

## Подсчёт битов и управление циклами

| Команда / фрагмент | Класс | Эффект и provenance |
|---|---|---|
| `buf db bit 0, bit 1 + bit 7, -1, 0` | Формирование данных | Четыре тестовых байта (p. 94, 7.1). |
| `size equ $ - buf` | Вычисление на трансляции | Длина массива в байтах (p. 94). |
| `lea si,buf`, `mov di,si`, `cld` | Изменение регистров/флага | Установить оба указателя в начало и прямой обход (p. 94). |
| `mov cx,size`, `mov cx,8` | Изменение регистра | Счётчики внешнего и внутреннего цикла (p. 94). |
| `push cx`, `pop cx` | Изменение стека | Сохранение внешнего счётчика во вложенном цикле (p. 94). |
| `lodsb`, `stosb` | Чтение/запись памяти | Чтение исходного байта и замена его числом единичных битов (p. 94–95). |
| `shr al,1`, `adc ah,0` | Изменение регистров/флагов | Перенос вытесненного бита в `c` и прибавление его к `ah` (p. 94). |
| `loop l2`, `loop l1` | Изменение `cx/ip` | Управление восьмикратным внутренним и внешним циклами (p. 94). |
| `clc`, `jnz l2`, `adc al,0` | Флаг / ветвление / регистр | Оптимизированный цикл и учёт последнего вытесненного бита (p. 95). |
| `F9` в `d86` | Исполнение до курсора | `GoTillHere` до строки `loop`, удобно проверять одну итерацию (p. 94). |

## Перенаправление и файловые операции

| Синтаксис / операция | Класс | Риск / результат |
|---|---|---|
| `prog <data.in >data.out` | **Изменение файла** | stdin берётся из `data.in`, stdout создаёт или **обнуляет** `data.out` (p. 95). |
| `dos macro; mov ah,#1; int 021; #em` | Макрокоманда вызова DOS | `#1` — аргумент функции; контекст p. 95. |
| `mov bx,0`, `mov cx,1k`, `lea dx,buf`, `dos 03f` | **Запись в память** | Прочитать до `cx` байтов из stdin; `c=1` — ошибка, при успехе `ax` — число прочитанных (p. 95–96). |
| `mov bx,1`, `mov cx,1k`, `lea dx,buf`, `dos 040` | **Запись в поток** | Вывести до `cx` байтов; `c=1` — ошибка, при успехе `ax` — число записанных (p. 96). |
| `mov bx,0`, `mov cx,08000`, `lea dx,buf`, `dos 03f`, `jc >l9` | Изменение памяти/ветвление | Чтение и проверка переноса (p. 97). |
| `mov cx,ax`, `jcxz >l9` | Изменение регистра/ветвление | Перевод длины чтения в счётчик, выход при нуле (p. 97). |
| `call make`, `ret` | Изменение стека/`ip` | Вызов преобразования и возврат (p. 97–98). |
| `dos 04c` с `al=0` или `al=1` | Завершение процесса | Код успеха/ошибки (p. 97). |
| `buf db` в конце COM | Обозначение адреса | Имя буфера без размещённых в файле байтов; требует учёта памяти ниже стека (p. 98). |

**Проверка после вызова:** читать `c/ax`; глава не описывает дополнительный цикл при частичной записи, поэтому **нельзя утверждать**, что показанный `var_2.8` обрабатывает произвольный объём ввода (p. 95–98).

## Опережающие ссылки и длины инструкций

| Пример | Класс | Смысл |
|---|---|---|
| `lea si,x_1` / `lea di,x_4` | Трансляция / изменение регистра | Адрес не зависит от того, byte или word определено ниже (7.6, p. 98). |
| `mov x_3,256` | Запись в память | Значение 256 требует word, что согласуется с последующим `x_3 dw` (p. 98). |
| `mov ax,x_3` с неизвестным именем | Пример неоднозначности | a86 предполагает `abs`, что может противоречить последующему `dw` (p. 98). |
| `mov days,7` до `days db ?` | **Ошибка трансляции** | Размер неизвестного приёмника byte/word не определён (7.8, p. 100). |
| `jmp smth` / `jmp >m7` | Переход | a86 различает длинное предсказание и короткий переход к локальному имени (p. 99–100). |
| `extrn buf:byte` / `extrn buf:b` | Декларация трансляции | Предварительное указание типа имени (p. 100). |

## Упаковка и отладчик

| Команда | Эффект |
|---|---|
| `shl al,4` | Сдвиг второго кода к старшей тетраде байта (7.9–7.10, p. 101–102). |
| `shr dl,1`; `rcr al,1` — 4 раза | Передача младших четырёх разрядов `dl` в `al` через `c` (7.9, p. 101). |
| `shr ax,4` | Альтернативная упаковка, когда коды в `ah/al` (7.10, p. 102). |
| `=e1,ax`, `=e1,dx` | **Read-only** форматы показа битов регистров в `d86` (p. 101). |
| `k s alta`, `Alt+A` | Запись/воспроизведение состояния клавиш отладчика; создаётся `alta.d8k` (p. 102). |
| `d86 x.com <test_1.bin >out.dat` | Запуск и **запись/обнуление out.dat** | Авторский способ проверки потокового варианта задания (p. 102). |

## Верификация, rollback

Перед изменениями сохранять данные, особенно файлы назначения. Упражнения требуют тестов на чётность числа входных байтов, переполнение, корректность шага и соответствие `.lst` (p. 99–104).
