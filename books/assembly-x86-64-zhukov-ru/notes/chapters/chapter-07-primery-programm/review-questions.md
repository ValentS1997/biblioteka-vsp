# Глава 7 — авторские задания и эксперименты

**Источник:** canonical RAG PDF 94–109, `p0094:c01`–`p0109:c01`. Оригинальная **нумерация первого уровня 1–15 и второго уровня 1–12** сохранена. Формулировки — краткие структурные пересказы задач, без добавленных условий. Это самостоятельные задания на программирование; [review-answers.md](review-answers.md) содержит стратегии, а не неподтверждённые исходные решения.

## Эксперименты из объяснений (ненумерованные автором)

- В `var_1.8` наблюдать `buf`, `cx`, перенос `c` и `ah`; с `F9` останавливаться на конце каждой итерации внешнего цикла. Сравнить число операций с `var_1b.8` (p. 94–95).
- Скомпилировать `ref_1.8`, проверить длины четырёх `lea` в `.lst`, раскомментировать `mov ax,x_3` и проанализировать ошибку предположенного типа имени (p. 98).
- Исследовать `ref_2.8`: типы `days/daze/smth`, длины `mov/jmp`, short/long и локальную метку `>m7`; строки с `Byte-Sized Constant Required` автор предлагает закомментировать (p. 99).
- Проверить `pack_1.8` в `d86` с форматами `=e1,ax` / `=e1,dx`, сравнить `pack_2.8`, затем составить программу упаковки 4-битовых кодов из входного потока (p. 101–102).

## Общий контракт первого уровня (p. 102)

**Каждое из заданий №1–15 выполнить двумя способами:**

1. Отладочный: массивы объявлены непосредственно в программе, результат виден в `d86`; выбирать формат показа `r/w/d/b/n/e` по типу данных. Автор предлагает `k s alta` и `Alt+A` для настройки отладчика.
2. Потоковый: прочитать данные из файла через stdin и записать результат через stdout. Для двух равных по длине массивов разделить прочитанное пополам; число входных байтов доступно в `ax` после `dos 03f`. Пример вызова: `d86 x.com <test_1.bin >out.dat`.

**Контроль входа:** автор отдельно требует проверки переполнения в заданиях **2–4, 6**, чётности числа входных байтов в **1, 5, 12, 7, 9** и делимости на **4** в **13, 15** (p. 104; примечание 10 p. 109). Проверить исходную группировку именно по типам задач, без расширения на неподтверждённые сценарии. Выходной файл может быть обнулён перенаправлением (p. 95).

## Первый уровень — исходные варианты 1–15 (PDF 102–104)

| № | Задача автора | Выход / особое условие |
|---|---|---|

| 2 | В массиве ASCII подсчитать пары одинаковых соседних символов | В тексте пример `tutti buzz` — две пары; потоковый результат — слово |
| 3 | Сложить байты в словный счётчик и вычислить среднее байтовое значение | Показать среднее; потоковый результат — слово по формулировке |
| 4 | Подсчитать заглавные латинские буквы в ASCII-массиве | Потоковый счётчик — слово |
| 5 | Превратить знаковые слова в абсолютные значения на месте | Обязательная проверка переполнения `neg`; потоковый выход — массив |
| 6 | Раздельно подсчитать латинские буквы и десятичные цифры | Два словных счётчика |
| 7 | В двух массивах байтов одинаковой длины сформировать на месте первого совпадающие попарно значения | Показать число совпадений; потоковый выход — полученный массив |
| 8 | Записать ASCII-последовательность в обратном порядке | Потоковый выход — результирующий массив |
| 9 | В первом из двух равных байтовых массивов сформировать индексы совпадений | Индексы начинаются с нуля; показать число совпадений |
| 10 | Для знакового байтового массива создать индексы элементов в заданном диапазоне | Индексы с нуля, показать число отобранных |
| 11 | Преобразовать все латинские буквы ASCII к верхнему регистру на месте | Вывести преобразованный массив |
| 12 | Из беззнаковых слов отобрать элементы **вне** заданного диапазона на месте | Показать количество отобранных |
| 13 | Перемножить поэлементно два равных массива знаковых слов, записывая результат в первый | Проверить переполнение при умножении |
| 14 | Перевести все латинские буквы ASCII к нижнему регистру на месте | Вывести преобразованный массив |
| 15 | Разделить поэлементно два равных массива беззнаковых слов | Частные сохранять в первом массиве, остатки — во втором; потоковый вывод — массив остатков |
