# Глава 12 — оперативная шпаргалка

Источник: canonical RAG PDF **205–215**. A386/NASM в 16-битном реальном режиме; команды не исполнялись.

## Проблема / симптомы

Инструкция с `EAX` работает, а память читается не оттуда; `rep` повторяет неожиданное число раз; `loop` меняет только часть `ECX`; `retf` выталкивает не ту ширину адреса. Анализировать **размер операнда → размер адреса → значения регистров → ограничения сегмента → фактический код в .lst**.

## Базовые факты

| Параметр | 16-битный код в примерах | С префиксом |
|---|---|---|
| Операнд | `AX` и слово | `066h` (A386 `o4`, NASM `o32`) — 32 бита |
| Эффективный адрес | `BX/SI/DI/BP` | `067h` (A386 `a4`, NASM `a32`) — `EBX/ESI/EDI/EBP` |
| `rep`-счётчик | `CX` | при адресной размерности 32 бита — `ECX` |
| Строковый адрес | `SI/DI` | `ESI/EDI` |
| Возврат | `ret/retf` с 16-битным адресом | `o4 ret/retf` читает 32-битные поля |

Основание: PDF 205–211, листинги 12.1–12.7.

## Пассивная диагностика

1. Сравнить `.lst` и реальный байтовый код `inc ax` / `inc eax`; 66 — размер **операнда**, 67 — размер **адреса** (p. 205–207).
2. Не считать, что `067h` просто расширяет регистры: байты адресации 16 и 32 бит различаются. NASM может сообщать об ошибке/предупреждении (p. 206–207).
3. Для `rep lodsb` и `loop` сопоставить начальное `ECX=010000`: если используется `CX`, младшая часть первоначально нулевая; если `ECX`, поведение иное (p. 208–209).
4. `xlat` без адресного префикса использует `BX`, с ним — `EBX`; `AL` задаёт индекс байта (p. 209).
5. При `mul` и `div` анализировать **пару EDX:EAX**, а не только EAX; результат автора: произведение 67 062 533 760, после деления на 1 000 000 частное 67 062 и остаток 533 760 (p. 210).
6. Для массива `dd` элемент i адресуется `array + i*4`; в 12.9 индекс `ESI` и цикл `loopne` используют разные регистры (p. 212–213).
7. При `movsx/movzx` отдельно проверять знак/обнуление старших битов; в описании результата 12.10 есть несовпадение (p. 214–215; source findings).

## Интерпретация

- `inc byte [ebx]` имеет `67`, а `inc byte [bx]` — другой ModR/M; дополнительный префикс — не всё преобразование (12.1).
- Адрес `0x12345678` при обычной 16-битной адресации NASM в 12.2 оказался усечён с предупреждением; автор противопоставляет unreal mode (p. 207).
- `bsf/bsr`: если источник нулевой, автор указывает `z=1`; успешный поиск даёт `z=0` и индекс первого/последнего установленного бита (p. 213).
- `shrd/shld` расширяют составное битовое окно, не изменяя исходный регистр `src`; ожидаемые демонстрационные значения на рис. 12.4 относятся к приведённым числам (p. 213–215).

## Изменяющие действия и откат

Инструкции `not b[...]`, `inc [..]`, `push/pop`, `xadd`, `retf`, адресный доступ за пределами обычного сегмента могут изменить память, стек или управление. Авторские упражнения с GP 13 могут зациклить fault. Исполнение допустимо только с изолированной копией состояния; **универсальный rollback источником не описан — [Needs confirmation]**.

## Критерии проверки

Установить точное соответствие 66/67, способность объяснить 12.3–12.5 без фактического запуска, дать расчёт 32-битной арифметики, масштабируемого адреса и битового поиска. Спорные текстовые значения не «исправлять» молча. [Source findings](source-findings.md).
