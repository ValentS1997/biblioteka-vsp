# Глава 3 — вопросы и упражнения автора

**Основание:** главы/чанки `p0039:c01`–`p0040:c01`, `p0045:c01`–`p0046:c01`, `p0049:c01`–`p0050:c01`, `p0053:c01`. Отдельные блоки сохраняют **исходную нумерацию**. Формулировки сжаты без изменения учебной задачи. [Разбор](review-answers.md) не является официальным ключом.

## I. Директивы данных и константные выражения — оригинальные №1–8 (PDF p. 39–40)

1. Определить **10 Кслов**: в младшем байте ASCII `'0'`, в старшем `'1'`.
2. Обозначить число с установленным пятым битом двумя способами: через `xb` и `bit`.
3. Перевести в десятичные значения `015`, `15`, `11b`, `17q`, `0a`, `bit 3`, `'A'`.
4. Вычислить через константу `hours` число часов в году, сформировать слово с часами, двойное слово с минутами и двойное слово с секундами в году.
5. Определить `len=100` и слово с площадью квадрата со стороной `len`.
6. Определить `hip=200` и слово с площадью прямоугольного равнобедренного треугольника.
7. Установить третий и седьмой биты в константе: сначала `bit` и `+`/`or`, затем через `shl`.
8. Определить байт со сброшенными битами 0 и 3 с помощью `bit`, `not` и `+`/`or`.

## II. Имена и типы — оригинальные №1–9 (PDF p. 45–46; `quiz1.txt`)

1. Для определений `noodle equ '0' by 0`, `needle db 40k/7 dup 0`, `a1 dw offset needle - 0100` указать имена и типы.
2. Найти ошибки во фрагменте с незавершённой строкой `src db "You're genious`, `dest dw bit 16 + offset src`, `size equ (dest-src)/2`.
3. Для `byte1 db 1,2` и `word1 dw 03040,05060` определить содержимое после `not byte1`, `not byte1+1`, `not byte1+2`, `not word1`, `not word1+1`.
4. Для `word1 dw 03040, 3 dup 0, 0ffff` составить инструкцию инверсии последнего слова (−1).
5. Для `word1 db 3k dup 0,0ff` и `byte1 dw ?` составить инверсии последнего байта определения `db` и последнего слова этой области; попробовать адресовать через `byte1`.
6. Для `abcd db 'ABCD'` и `digit db '0123456789'` определить результат `not abcd`, `not abcd+6`, `not digit-3`.
7. Для `byte1 db -2,2,3` составить команды инверсии слова `02fe` и слова `0302`, встречающихся в смежных байтах.
8. Для `dword1 dd 0102ff04` составить команды инверсии слова `02ff` внутри двойного слова и отдельного байта 4.
9. Для фрагмента `area1 db (080 shr 3) dup ?`, `area2 dw (offset area2 - offset area1) dup ?`, `dummy db ?`, `size equ offset dummy - offset area1` определить `size`.

## III. Первый проход — оригинальные №1–7 (PDF p. 49–50; `quiz2.txt`)

1. Составить таблицу имён для `bob`, `top`, `what`, `let`, `that`, `zz` в фрагменте с `dd ... dup end-bob`, `dw ($-bob) dup ...`.
2. Составить таблицу имён для `sz1`, `neck`, `total`, `bottle` и трёх областей `db/dw/dd` с вложенным `dup`.
3. Составить таблицу имён для `alfa`, `beta`, `cold`, `gold`, `zz` с прямыми ссылками.
4. Составить таблицу имён для `dumb:`, `pump:`, `bump equ $`, `lamp dw...`, `stamp`, `zz`.
5. Указать ошибку первого просмотра в блоке `msg db 'Funny ha-ha...'`, `db $-msg dup ?`, `dw 1,12,xx-start,(xx-start) dup ?`.
6. Указать ошибку первого просмотра для `dw (offset sally - silly) dup ?` до меток `silly` и `sally`.
7. Указать ошибку для `rob db (gamma - rob)*2` и более позднего `mob equ $-rob`.

## IV. Особые имена и первый проход — оригинальные №1–5 (PDF p. 53; `quiz3.txt`)

1. Найти ошибки в связке повторного локального `l1`, вперёд-адресованного `>l1`, `l2`, `what`, `this`.
2. Найти ошибку в области `msg`, где размер `dup` зависит от `zz - start`, определённого ниже.
3. Найти ошибку в `dw (offset lamp-dumb) dup ?` перед `dumb` и `lamp`.
4. Найти ошибку в `alfa db (gamma-alfa)*2` при более позднем `gamma equ $-alfa`.
5. Проанализировать неправильные определения `start dd 1`, `zz equ this`, два блока по `1k` с переменными `msg1`/`msg2` и счётчик `dw zz-start dup ?`.
