# Глава 8 — авторские задания и контрольные эксперименты

**Источник:** canonical RAG PDF 111–148, `p0111:c01`–`p0148:c01`. Различаются **9 нумерованных итоговых заданий** (p. 143–145), **3 нумерованных вычисления** (p. 117) и задания без сквозной нумерации, встроенные в текст. Нумерация авторских блоков сохранена, новые номера используются только как маркировка разделов.

## A. Встроенные в текст опыты (ненумерованные автором)

- В `d86` открыть FPU через `F10`, сбросить `finit`, проверить `fld 1.0`, `fld 2.0`, `fld 2`, `fdecstp/fincstp`, `fadd/fsub`, `NaN` и `fclex` (p. 111–114).
- `test1.8`: загрузка/выгрузка real `xd/xq/xt`, integer `i16/i32/i64`; проверить округление `3.4`, `−3.4`, `3.5`, `−3.5`, `−2.5` командой `fist` (p. 112–115).
- `calc_1.8`: для `a=3,b=2` вычислить `((a*a)-(b*b))*π`, подсчитать максимальную глубину стека; повторить с `fld 0` и `fsqr` (p. 115–116).
- `postfix.exe`: преобразовать `(a*a-b*b)*p` в обратную польскую запись. Вычислить сопротивление трёх параллельных резисторов `r1=19,r2=23,r3=28` (после округления ожидается 8). Проверить `r1=0` и результат деления на ноль (p. 116).
- `test1/test2`: исследовать `ftst`, `fcom`, `fstsw ax`, `sahf`, `fcomi/fcmovb`; `fsw/fcw`, случаи `PE,ZE,DE,UE,OE,IE/SF/C1`, режимы округления (p. 117–121).
- `types.8`, `inner.8`, `float.com`: проверить 32/64/80-битовые диапазоны; `what 1.625`, `what 0.8125`, `bits 03fff,63`, денормализованные, Infinity и NaN (p. 122–125).
- `fld_1/2.8`, `fst_1/2.8`, `fxch.8`, `math_1/2.8`, `round.8`, `fprem1.8`: проверить загрузки, выталкивание, обмен, обратный порядок и округление (p. 127–135).
- Проверить `fsincos` при π/3, `fscale`, `fxtract`, `fyl2x/fyl2xp1`, `power.8`, `log_1/2.8`; `fstenv/fldenv/fsave/frstor` в изолированном `d86` (p. 135–143).

## B. Три авторских выражения (PDF p. 117)

1. Вычислить `(x − (12+y))/100 + 2`, где `x=−125897`, `y=084512`. Контрольный результат автора: **−2.102210e3**.
2. Вычислить `(1/2 + (1/3 + 1/4)*7)/17`. Контрольный результат: **0.26960784314**.
3. Вычислить `1/(1+s/(1+s/(1+s)))`, где `s=sqrt(2)`. Контрольный результат: **0.52859547919**.

## C. Итоговые задачи главы — исходная нумерация 1–9 (PDF p. 143–145)

**Общее требование автора:** все решения начинать `finit`; в `d86` настроить отображение `fd/fq/ft`, окно FPU и сохранение клавиш через `k s prg`, где `prg` — имя COM-файла без расширения.

1. Загрузить три разных числа. Выполнить без удаления данных: `1 := 0 − 1`; `2 := 2 − 0`; `0 := 1 − 0`.
2. Обменять `st(1)` и `st(2)` через `fxch`. Скопировать значение `st(2)` в `st(5)` командами `fld/fst(p)`; вращать `st(0..2)` через `fstp`; удалить две вершины командой сравнения.
3. Загрузить 1.0, 2.0, 3.0; в `st(5)` получить −5.0, сохранив свободными остальные регистры кроме 0,1,2,5; в цикле вызывать подпрограмму вращения 0–2 и восстанавливать 5 через `fxch`.
4. Создать на вершине FPU значения −0.0, затем +Infinity, −Infinity, NaN и денормализованное число.
5. Вычислить **199975 mod 3**, **sin(π/4)**, **tg(π/8)** и **кубический корень из 7**.
6. Вычислить `x*(x−2)/sqrt(x+1)`; `x` в 32-битной real-переменной, **только одна загрузка из памяти**; дальнейшие копии формировать через стек `fld/fst(p)`.
7. Два способа найти максимум среди пяти значений в `st(0..4)`: (а) непосредственно через `fdecstp/fincstp/fstp 5/fxch`; (б) в образе контекста `fsave` с полем `reg` структуры `fpu.inc`, сравнивать слова от старших к младшим и учитывать sign (p. 144).
8. Сгенерировать гармонические колебания по рекурсиям `y(n+1)=A*y(n)+B*x(n)`, `x(n+1)=C*y(n)+D*x(n)`; `A=D=cos(b)`, `B=−C=sin(b)`, `b=2π/k`, `y(0)=0`, `x(0)=1`, рекомендуемое `k≈40`.
9. Выполнить **одно из заданий главы 7** для вещественных элементов 32- или 64-битного формата.
