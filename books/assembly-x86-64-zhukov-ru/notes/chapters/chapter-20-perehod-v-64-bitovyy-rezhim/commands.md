# Глава 20 — команды, формы перехода и их эффект

**Provenance:** canonical RAG PDF 331–340; A86/NASM; листинги 20.1–20.6. Ни одна команда не запускалась. Таблица предназначена для чтения источника, не для изменения системной памяти.

| Команда / директива | Тип и эффект в исходнике | PDF |
|---|---|---|
| `dos 03f` (макрос) | Чтение из stdin во внутренний буфер `ld0`, затем контроль CF/длины | 331–332 |
| `rep movsb` после изменения ES/DI | **Запись** по линейному адресу 0100 в нижней памяти, затрагивает IVT | 332 |
| `cld`, `cli`, `jmp 0:0100` | Направление строки, запрет внешних IRQ и переход к загруженному коду | 332 |
| `org 0x100`, `-f bin`, `-o test.bin` | Режим двоичной компоновки проверочного образца `test.a`; не запуск | 333 |
| `movsb`, `loop` в `test.a` | Вывод в текстовый буфер, затем бесконечное изменение символа | 333 |
| `use16 / use32 / use64` | Выбор ожидаемого кодирования в блоках листинга | 334–336 |
| `code64`, `L=1,D=0` | Дескриптор 64-битного кода; остальные сегментные адресные поля игнорируются | 334–335 |
| `jmp (code64-gdt):entry64` | **Дальний переход** из compatibility mode в 64-bit code | 335 |
| `clr eax,r15` | Макрос исходника, использует доступный лишь в 64-битовом коде `r15`; развёртка не приведена | 334–335 |
| `cpuid` | Нулевая функция в коде автора возвращает идентификатор производителя | 334–335 |
| `mov [0+r15],ebx`; `mov [8],ecx` | Примеры базовой+смещение и описанной автором прямой адресации | 334–335 |
| `addr80 dq long_mode; dw code32-gdt` | В памяти хранится пара: offset и selector совместимого кода | 335–336 |
| `jmp far qword [addr80]` | **Косвенный дальний переход** из 64-битного кода в совместимость | 336 |
| `cg1`: 16-байтовый descriptor | Вентиль с целевым `code64` селектором, offset `subr_1`, расширением адреса | 337 |
| `call (cg1-gdt):0` | Вызов вентиля из кода совместимости | 337–338 |
| `retfq` | Возврат с восстановлением 64-битовых полей offset и selector | 337–339 |
| `call far qword [addr80]` | Косвенный вызов gate изнутри `use64` в рекурсивном примере | 338 |
| `mov rcx,delay`; `loop` | Тестовая задержка; счётчик по умолчанию RCX в `use64` | 338–340 |

## Безопасная оценка

Изменяющие операции: запись нижней памяти, запись видеопамяти, `cli`, изменение стекового контекста при gate/return. Read-only проверка: изучить GDT и кодовые атрибуты в RAG, сопоставить смещения и размер адреса в листингах. Нет доказательства, что пользовательские исполняемые образы собраны или проверены. Отладочные макросы `_brk`, `clr`, `store` определены внешним include или сокращены в текстовом извлечении; их машинное развёртывание **[Needs confirmation]**.
