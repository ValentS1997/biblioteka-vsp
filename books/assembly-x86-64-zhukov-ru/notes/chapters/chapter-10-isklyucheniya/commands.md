## Критические границы

Резидентный ISR зависит от собственного `DS=CS`, потому что вызывающая программа может иметь другое значение `DS` (p. 180). Описанная IVT по нулевому адресу — глобальная структура DOS-сеанса, а не обычный массив пользовательской программы. Значения `070:0029`, `F000:FF53`, `00700233` принадлежат **приведённым снимкам**, не обещанию постоянных адресов в другой VM.

**Проверка:** для каждого вектора рассчитать `n*4`, сохранить исходную пару, изучить порядок `iret`; `trace` и `inx` сверить по d86/d386 только в изолированном воспроизводимом сеансе. Универсальный безопасный rollback RAG не даёт — **[Needs confirmation]**.
