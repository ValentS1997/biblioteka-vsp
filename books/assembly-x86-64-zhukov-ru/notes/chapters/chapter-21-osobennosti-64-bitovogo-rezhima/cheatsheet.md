# Глава 21 — оперативная шпаргалка: 64-битный режим

**Источник:** canonical RAG PDF 341–372, листинги 21.1–21.14. Выполнение в NASM/Bochs/на ПК **не проводилось**.

## Диагностический маршрут

Проверять по порядку: **режим CPU → разрядность операнда → способ адресации → селектор и база FS/GS → CPL и привилегии → MSR/STAR → TSS/IST → IDT/стек возврата → разрешённость эксперимента**.

| Механизм | Ключевые правила и страницы |
|---|---|
| Регистры | RAX…R15; запись `EAX` обнуляет старшие 32 бита RAX, запись AX/AL не затрагивает верхнюю часть (341–344). |
| Стек | 64-битные операции со стеком и `RSP`, адрес возврата 64-битный; не заменять PUSH RDI на EDI (341, 346, прим. 11). |
| RIP-relative | `default rel` / `[rel mem]`; signed displacement 32 бита от RIP. `default abs` / `[abs mem]` фиксирует адрес (343–348). |
| Переносимость | 21.4 переносит код/данные с копированием назад при перекрытии; RIP-relative сохраняет связь, absolute оставляет обращения по старым адресам (347–348). |
| Сегменты | Большинство баз = 0, FS/GS — исключение; база через GDT либо MSR FS/GS, второй вариант FSGSBASE в описанном Bochs не поддержан (349–352). |
| Системный вызов | `SYSCALL` сохраняет точку возврата в RCX, FLAGS в R11; `SYSRET` возвращает, `STAR/CSTAR/LSTAR/SFMASK/EFER.SCE` задают механизм (352–356). |
| Привилегии | `SYSRET` в опыте понижает CPL до 3, `SYSCALL` возвращает CPL=0; несовпадение DPL/CPL в 21.7 — сознательный недостаток (355–356). |
| TSS | RSP0–2, IST1–7, IO permission bitmap; аппаратная многозадачность отменена (357–359). |
| IDT | Вентиль 16 байт, IST=0 или 1–7; программный INT с CPL=3 проверяет DPL вентиля; `IRETQ` возвращает по 64-битному кадру (359–365). |

## Контроль по примерам

**21.1/21.2:** для `mov edx,-2` старшие 32 бита RDX становятся нулевыми. Встроенные непосредственные операнды ряда 64-битных инструкций расширяются со знаком. `JECXZ/JRCXZ` и `LOOP` различаются шириной счётчика (342–345).

**21.3/21.4:** начальный код выровнен до `0x200`, загружен с `0x300`, копируется на +`0x100`. Обратное копирование учитывает перекрытие. При относительном обращении строка и счётчик перемещаются с кодом; абсолютная адресация остаётся привязанной к старому месту (345–348).

**21.5/21.6:** видеообласть автор адресует через ненулевую базу FS/GS. В альтернативе он описывает `RDMSR/WRMSR` с CPL=0 и FSGSBASE с CR4 bit 16; Bochs сообщает об отказе включить поддержку, а не о проверенном поведении современного железа (349–352).

**21.7/21.8:** стековые селекторы выводятся из кодовых со сдвигом на соседний дескриптор, а для возврата в 64-битный режим автор использует расширенную форму `SYSRET`. В 21.7 после первого возврата последующая попытка привилегированного `WRMSR` завершается ошибкой (352–356).

**21.9–21.14:** IOPB для CPL3, вентили прерываний и IST настраиваются как эксперименты. Данные Bochs/PC в табл. 21.2 расходятся; финальная причина GP13 **[Needs confirmation]** (357–369).

## Безопасность / rollback

Операции с CR4, MSR, GDT/IDT, TSS, масками портов и переходами CPL **мутируют системное состояние**; индукция GP может остановить исполнение. Чтение RAG и расчет структуры — безопасны, выполнение этих программ требует изолированного восстанавливаемого образа. Универсальный rollback в книге **не подтверждён**. Не переносить конкретные адреса и флаги Bochs на физический ПК без измерений.
