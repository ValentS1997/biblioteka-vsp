# Команды и инструменты главы 1

**RAG provenance:** `rag/chunks/p0001-p0100/p0015-c01.md`–`p0019-c01.md` (PDF p. 15–19). Команды сохранены в форме, поддержанной текстом главы; команды для Linux/современных Windows не добавлены.

| Команда / инструмент | Класс | Эффект / критерий |
|---|---|---|
| `__work.bat` | Workload-generating | Запускает рабочий Bochs; после подготовки образа должен загрузить FreeDOS (p. 15–16). |
| `__debug.bat` | Workload-generating | Запускает Bochs с графическим отладчиком, формируя дополненные параметры (p. 18). |
| `-f` | Configuration flag | Указывает Bochs файл параметров (p. 15–16). |
| `-q` | Configuration flag | Пропускает диалог редактирования параметров Bochs (p. 16). |
| `a86` | Read-only availability check (вызов без аргументов) | Наличие реакции, отличной от `Bad command or filename` (p. 18). |
| `nasm` | Read-only availability check (вызов без аргументов) | Такая же проверка доступности (p. 18). |
| `bitmap` | Read-only availability check (вызов без аргументов) | Такая же проверка доступности (p. 18). |
| `c:\dos\bin\xcopy dos\bin fdos /d` | State-changing | Копирование `dos\bin` в `fdos` внутри FreeDOS (p. 16–17). |
| `c:\dos\bin\deltree dos /y` | **Destructive state-changing** | Рекурсивное удаление каталога `dos`; риск потери данных при неверном диске/пути (p. 16–17). |

## Порядок работы по RAG

1. Из комплекта главы подготовить стартовый каталог и скопировать BIOS/VGA BIOS и нужный вариант Bochs.
2. Запустить `__work.bat`: до создания образа ожидается сообщение `could not open hard drive image file 'disk_c.img'` (p. 16).
3. Создать `disk_c.img` на базе образа FreeDOS, проверить приглашение `C:\>` (p. 16).
4. **Перед изменением файлов внутри образа сделать копию образа.** Команды `xcopy`/`deltree` выше даны для точной атрибуции источника, **не как рекомендация немедленного выполнения**.
5. В WinImage добавить `tools`, `work` и `autoexec.bat`, затем запустить рабочий вариант; подтвердить автоматический VC и доступность `a86`, `nasm`, `bitmap` (p. 17–18).
6. Запустить `__debug.bat`; проверить GUI debugger и Continue (p. 18).

## Риски, проверки и откат

`xcopy`: меняет каталог назначения; проверка — наличие системных утилит и успешная загрузка FreeDOS; точный возврат [Needs confirmation].  
`deltree`: безусловное рекурсивное удаление; **сначала проверить текущий диск, исходный путь и резервную копию**; проверка после действия — корректная загрузка и доступность утилит; rollback только из ранее сохранённой копии, точные шаги [Needs confirmation].  
Изменение `disk_c.img` через WinImage: источник сообщает о дефектах группового удаления в WinImage 10.0/11.0 (p. 19); проверять целостность после операции, не выполнять массовое удаление этим инструментом.

**Непроверенные условия:** запущенные версии программ, совместимость с текущей Windows/BIOS, доступность скачиваний — [Needs confirmation].
