# Глава 6 — оперативная шпаргалка по циклам

**RAG:** PDF 85–92, `p0085:c01`–`p0092:c01`; примеры a86/i8086–286 из книги.

## Symptom / problem framing

Цикл не находит элемент, прекращается слишком рано, `cx=0` ошибочно принимается за отсутствие совпадения, обработка слов использует неверный шаг, либо условие `loopne` меняется вслед за инструкцией, случайно переписавшей `z`.

## Baseline

- `size equ $-array` даёт байтовую длину; `mov cx,size` для массива байтов и `mov cx,size/2` для массива слов (p. 85–87).
- При предварительном `inc si`: старт `lea si,array-1`; для слов `lea si,array-2`, `add si,2` и `cmp w[si],x` (p. 86–87).
- `loopne` делает декремент `cx` и проверяет ненулевой `cx` вместе с `z=0`. По выходу нужен отдельный `jne miss` (p. 86).
- `cld` направляет строковые команды вперёд, `scasw` сравнивает `ax` с словом по `di`, `repne scasw` совмещает сравнение и повтор (p. 87–88).
- Для знакового `>` отдельный `jg`, затем обычный `loop` (p. 88–89).

## Read-only checks

1. До исполнения проверить `cx`, начальный адрес, шаг указателя и позицию `inc/add` относительно `cmp`.
2. Проверить, устанавливает ли последняя операция перед `loopne` **именно требуемый** `z`. `inc si` после `cmp` — намеренно неверный пример (листинг 6.2, p. 87).
3. Для результата поиска смотреть `z`, а не только `cx`: совпадение на последней итерации возможно при `cx=0` (p. 86).
4. Для `scasw/scasb` проверить `di`, `ax/al`, направление `d`; листинг 6.7 имеет неясную инициализацию, зарегистрированную в `source-findings.md`.
5. Для табличного подсчёта проверить ровно 256 ячеек, нули вне интервала и единицы в интервале (p. 91–92).

## Interpretation

| Наблюдение | Вывод |
|---|---|
| `cx=0` и `z=1` после `loopne` | Значение могло быть найдено в последней ячейке (p. 86). |
| После `cmp` выполнен `inc si` | `z` относится к инкременту, не к сравнению (p. 87). |
| `scasw` продвижение на два | Обрабатываются слова, `di` изменяется на 2 при `d=0` (p. 87–88). |
| `repne scasw` завершился | Проверить `jne miss` для успеха/отсутствия слова (p. 88). |
| `jg` не заменяется `loopne` | У `loop<x>` нет условия `g`; требуется отдельная ветвь (p. 89). |
| `xlat` вернул 0/1 | Признак принадлежности диапазону берётся из `map`, далее суммируется через `dx` (p. 91). |

## Next action

Разделить состояния «найдено», «счётчик исчерпан», «флаг сравнения был переписан». Для ошибки поиска сначала восстановить правильный порядок команд, затем проверить тип элемента и адресацию; для смены предиката на «больше» использовать отдельную условную ветвь.

## Modifying action

- `inc si` / `add si,2` меняют адресный указатель и флаги; `cmp` обновляет признаки результата (p. 86–87).
- `lodsb/scasw/repne scasw` меняют индексные регистры, `cx` и/или флаги в зависимости от операции (p. 87–90).
- `inc dx` / `add dx,ax` меняют число посчитанных элементов (p. 90–91).
- Для демонстрации ветвей автор предлагает изменять последний и первый байты массива в отладчике; это модифицирует содержимое памяти (p. 86).

## Verification / acceptance checks

Проверить исходные и модифицированные массивы: совпадение только в конце, отсутствие искомого, совпадение первым элементом. После цикла сверить `z`, `cx`, адрес и остановку на `int 3` или `int 020`. Для табличного алгоритма проверить данные у границ 10/99, а также 9/100 (p. 89–91).

## Rollback

В главе нет готовой процедуры восстановления массива после модификации в d86; исходный учебный COM и входные байты нужно сохранять до изменений. Точная команда отката **[Needs confirmation]**. Не переносить эффект примеров в производственное окружение.

## Сопоставление стратегий

| Цель | Листинг | Управление |
|---|---|---|
| Равно 7, байты | 6.1 | `cmp` + `loopne` + `jne` |
| Равно 7, слова | 6.3 | `cmp w[si]` + `loopne` |
| Равно 7, строковая | 6.4–6.5 | `scasw` + `loopne` / `repne` |
| Больше x, знаковые байты | 6.6 | `cmp` + `jg` + `loop` |
| В диапазоне 10–99 | 6.8 | `lodsb` + `jb/ja` + `inc dx` |
| В диапазоне 10–99, таблица | 6.9 | `lodsb` + `xlat` + `add dx,ax` |
