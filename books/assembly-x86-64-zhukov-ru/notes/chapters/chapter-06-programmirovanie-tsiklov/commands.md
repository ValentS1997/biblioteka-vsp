# Глава 6 — команды и экспериментальные действия

**Источник:** RAG p0085:c01–p0092:c01, PDF 85–92; `find_1.8`–`find_6.8`, `cnt_1.8`–`cnt_2.8`. Это язык a86 из книги. Исполнение не выполнялось.

| Команда / фрагмент | Класс | Эффект и источник |
|---|---|---|
| `x equ 7` | Константа трансляции | Искомый байт/слово (p. 85). |
| `size equ $-array` | Read-only compile-time expression | Длина области в байтах (p. 85–86). |
| `mov cx,size` | Изменение регистра | Число итераций для байтов (p. 86). |
| `lea si,array-1` | Изменение регистра | Старт на байт до массива при `inc si` перед сравнением (p. 86). |
| `inc si` | Изменение регистра и флагов | Следующий байт, **изменяет z**: не помещать между `cmp` и `loopne` (p. 86–87). |
| `cmp b[si],x` | Флаги | Установка признаков равенства без изменения байта (p. 86). |
| `loopne l1` | Изменение `cx/ip` | Повтор при `cx!=0` и `z=0` (p. 86–87). |
| `jne miss` | Изменение `ip` по условию | Отсутствие искомого проверяется через `z` (p. 86). |
| `int 3`, `int 020` | Изменение управления | Точка остановки / завершение учебного COM (p. 86, 89). |
| `mov cx,size/2` | Изменение регистра | Число слов при размере массива в байтах (p. 87). |
| `lea si,array-2`, `add si,2` | Изменение регистров/флагов | Указатель для словного обхода (p. 87). |
| `cmp w[si],x` | Флаги | Сравнение целого слова (p. 87). |
| `lea di,array`, `mov ax,x`, `cld` | Подготовка регистров/флага | Условия для `scasw` в `find_3.8` (p. 87). |
| `scasw` | Сравнение и движение `di` | Сравнить `ax` со словом, шаг +2 при `d=0` (p. 87–88). |
| `repne scasw` | Циклическое изменение `cx/di` и флагов | Поиск слова без явного `loopne` (p. 88). |
| `jg found` | Условный переход | Знаковое сравнение «больше» (p. 88–89). |
| `loop l1` | Изменение `cx/ip` | Повтор независимо от `z` при `cx!=0` (p. 89). |
| `lodsb` | Считывание и движение `si` | Загрузить следующий байт в `al`; для прямого направления `cld` (p. 90). |
| `cmp al,_low`, `jb >l2` | Флаги / переход | Пропустить значение ниже нижней границы 10 (p. 90). |
| `cmp al,_high`, `ja >l2` | Флаги / переход | Пропустить значение выше 99 (p. 90). |
| `inc dx`, `mov ax,dx` | Изменение регистров | Счётчик подходящих байтов и итоговый ответ (p. 90). |
| `map db p1 dup 0` | Формирование данных | Нулевой участок карты до p1 (p. 91). |
| `db (p2-p1+1) dup 1` | Формирование данных | Единицы на включённом интервале 10–99 (p. 91). |
| `lea bx,map`, `xlat` | Адрес и изменение `al` | Таблица по `bx + al`, результат 0/1 (p. 91). |
| `mov ax,dx,0` | Встроенная макрокоманда a86 | Источник использует этот синтаксис для предварительного обнуления `ax` и `dx` (p. 91); не нормализовать без запуска. |
| `add dx,ax` | Изменение регистра | Прибавить индексный результат (0 или 1) к счётчику (p. 91). |

## Эталонные учебные формы

```asm
; Листинг 6.1: порядок необходим для сохранения Z от CMP
    mov cx, size
    lea si, array-1
l1: inc si
    cmp b[si],x
    loopne l1
    jne miss
```

```asm
; Листинг 6.5: краткая строковая форма
    mov cx,size/2
    lea di,array
    mov ax,x
    cld
    repne scasw
    jne miss
```

```asm
; Листинг 6.9: табличная классификация
    lea bx,map
    lodsb
    xlat
    add dx,ax
```

Третий фрагмент намеренно **не самостоятельная программа**: нужны подготовка `si/cx`, очистка `ah` и начальное значение `dx` (p. 91). В первом фрагменте не показаны исходные определения и код `found/miss`.

## Risk, verification, rollback

Команды подготовки и сравнения меняют регистры и флаги, таблица создаёт дополнительные данные, а изменение тестового массива в `d86` меняет память. Выполнять в изолированной среде на копии; наблюдать `z/cx/si/di/dx` до и после. Восстановление исходного массива из точной команды в RAG не описано — **[Needs confirmation]**.
