# Глава 5 — команды, наблюдения, ограничения

**Source:** canonical RAG `p0069:c01`–`p0084:c01`, PDF 69–84. Команды из текста книги; исполнение в текущей сессии не проводилось.

## Подготовка

| Пример | Эффект | PDF |
|---|---|---|
| `a86 exa1.8 +L` | Генерирует выходные файлы и листинг | 70 |
| `d86 exa1.com` | Запускает сеанс отладчика | 70 |
| `F3` | Повторяет введённую команду; изменяющее действие может повториться | 69 |
| `d86 exa2.com` | Запускает учебный сценарий переходов с точками `m1–m7` | 75–76 |

## Адресация и пересылка

| Команда | Что проверить |
|---|---|
| `mov ax,7` | Непосредственное значение, байты в `d86_buffer` (70) |
| `mov bx,d86_buffer` | Адрес метки как константа (70) |
| `mov cx,[d86_buffer]` | Содержимое памяти по адресу (70) |
| `mov bp,offset w_1`, `lea ax,w_1` | Вычисление адреса вместо значения (70–71) |
| `inc b[bx]`, `inc b[bx+1]` | Изменение элементов таблицы (71) |
| `xchg al,ah`, `xchg ax,dx` | Обмен регистров (72) |
| `xlat` | Значение таблицы по `bx` + индексу `al` (72) |
| `push 012`, `push -1`, `push dx` | Добавление слов на вершину стека (72) |
| `pop bx`, `pop cx`, `pop dx` | Извлечение в порядке LIFO (72) |

## Арифметика, логика и сдвиг

| Мнемоника/пример | Эффект по главе |
|---|---|
| `add/sub/inc/dec/neg` | Арифметика над приёмником; `inc/dec` сохраняют `c` (73, 81) |
| `mul bl` / `imul bl` | Байт×байт → `ax`, разная знаковость (73) |
| `div bh` / `idiv bh` | Делимое `ax`; частное `al`, остаток `ah` (73) |
| `mul bx` / `div bx` | Участие `dx:ax` при словном операнде (73) |
| `cbw/cwd` | Расширение знака (73–74) |
| `and al,1100xb` | Оставить разрешённые маской биты (74) |
| `or al,bit 0` | Установить бит 0 (74) |
| `xor al,bit 7` | Переключить бит 7; `F3` повторяет (74) |
| `shl/shr/sar/sal` | Сдвиги; `sal` эквивалентен `shl` по книге (74) |
| `rol/ror` | Циклические сдвиги; счётчик из числа или `cl` (75) |

## Ветвления, стек, флаги

| Команда | Условие и изменяемое состояние |
|---|---|
| `jmp ax`, `jmp _w`, `jmp m5` | Источник адреса — регистр, слово памяти либо метка; меняет `ip` (76) |
| `call m2` / `ret` / `ret 2` | Запись адреса возврата в стек; возврат/очистка стека (76–77) |
| `jcxz m1` | Переход при `cx=0` (77) |
| `cmp al,1` | Флаги из разности, без записи разности (78) |
| `ja m2`, `jl m3`, `jne m4`, `jna m5` | Беззнаковые/знаковые условия (78) |
| `test al`, `test w_1` | Сокращённая форма `test` в a86 (78) |
| `loop m6` | Сначала `--cx`, потом проверка ненулевого значения (79) |
| `loopz` / `loopnz` | Дополнительная проверка флага `z` (79) |
| `clc`, `stc`, `cmc` | Управление флагом переноса `c` (81–82) |
| `pushf` / `popf` | Сохранение/восстановление слова флагов (81) |
| `cld` / `std` | Направление строкового обхода (82) |

## Строковые команды

| Команда | Значение |
|---|---|
| `lodsb` | Считать байт из источника `[si]` в `al`; изменить `si` (82) |
| `stosb/stosw` | Записать `al/ax` в `[di]`; изменить `di` (82) |
| `scasb` | Сравнить `al` с `[di]`, изменить флаги (82) |
| `movsb` | Копировать байт из `[si]` в `[di]` (82) |
| `cmpsb` | Сравнить элементы по `[si]` и `[di]` (82) |
| `rep movsb` | Повторять копирование по счётчику `cx` (83) |
| `repne scasb` | Повторять поиск до совпадения либо исчерпания `cx` (83) |

## Риски, preflight, verification и rollback

В `d86` ввод ассемблерных команд означает их исполнение, а `F3` повторяет его. `jmp/call` могут обойти `int 3` буфера; автор предоставляет специально подготовленный `exa2.8` с `m1–m7`. Перед опытом наблюдать `ip/sp`, массивы и флаги; для строковых команд дополнительно `cx/si/di/z/d`. Результаты сопоставлять только с каноническим RAG.
