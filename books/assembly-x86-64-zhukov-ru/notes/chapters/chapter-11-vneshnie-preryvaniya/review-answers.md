# Глава 11 — ответы на вопросы по RAG

Источник: PDF 197–204, листинги 11.1–11.5. Нумерация Q1–Q10 введена составителем. Никаких опытов с оборудованием не выполнялось.

**Q1.** Аппаратные события асинхронны; контроллер выбирает IRQ и сообщает CPU через INTR (с. 197).

**Q2.** Таймер: 1193000/65536 ≈ 18,2 Гц. IRQ0 → вектор 8; BIOS вызывает пользовательский вектор 01c (с. 197–198).

**Q3.** В 11.1 счётчик sym адресуется через CS, так как DS у вызывающего кода может быть другим. Авторские смещения entry=0107, sym=010d (с. 198).

**Q4.** Смещение IVT для 01c равно 070. Содержимое системного вектора зависит от конкретного сеанса (с. 198).

**Q5.** Бит 0 маски PIC: 0 — разрешено, 1 — запрещено. Пример 11.2 меняет его состояние на противоположное (с. 199).

**Q6.** Защита обновления вектора и завершение обслуживания PIC выполняют разные функции; без EOI могут задерживаться другие IRQ (с. 199–201).

**Q7.** Автор объясняет характер трассы короткими переходами и очисткой очереди предвыборки. При замене перехода на nop распределение IP меняется (с. 201).

**Q8.** Скан-коды не ASCII. В примере Enter соответствует 01c/09c, Esc — 01. Обработчик отдельно учитывает устройство и PIC (с. 201–203).

**Q9.** Контроль восьмибитного индекса ограничивает массив 256 событиями, а Esc обеспечивает раннее завершение (с. 202).

**Q10.** RTC на IRQ8 относятся к ведомому контроллеру. В Bochs из примера статус может оставаться нулевым, несмотря на события (с. 203–204).
