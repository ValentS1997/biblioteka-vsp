# Глава 11 — краткая шпаргалка

Источник: canonical RAG PDF 197–204, p0197:c01–p0204:c01. Анализ относится к учебному окружению BIOS/FreeDOS/Bochs. Исполнение не проводилось.

Внешнее прерывание возникает асинхронно: событие устройства передаётся контроллеру прерываний, затем процессору через INTR, после чего вызывается обработчик по таблице векторов (с. 197).

**Таймер:** канал 0 имеет 16-битный счётчик с тактовой частотой приблизительно 1,193 МГц. Период 65536 тактов даёт частоту около 18,2 события в секунду. Аппаратному IRQ0 соответствует вектор 8; BIOS вызывает пользовательский обработчик по вектору 01c (с. 197–199).

**Контекст:** резидентная программа 11.1 обращается к своим данным с явным выбором сегмента кода, поскольку сегмент данных вызывающего кода может отличаться. Обработчик использует стек прерванной программы (с. 198, 203).

**Контроллер:** маска управляет допуском запросов; подтверждение завершения обслуживания позволяет переходить к другим IRQ. В 11.3 изменение вектора защищено от асинхронного события. Эти действия различны по назначению (с. 199–201).

**Клавиатура:** обработчик 11.5 получает скан-коды, не ASCII; различаются нажатия и отпускания. Автор рассматривает Enter, Esc, цифры и автоповтор (с. 201–203).

**RTC:** Bochs в описанном опыте формирует прерывания при нулевом показании регистра состояния; точная аппаратная реализация из этой главы не следует (с. 203–204).

Важные различия: вектор 8 не равен пользовательскому вектору 01c; IRQ0 не равен IRQ1; подтверждение клавиатуры не равно завершению обслуживания контроллером.

**Проверка без запуска:** сверить номера векторов, авторские значения счётчика и ожидаемые пары скан-кодов. Для реально измеренных состояний — [Needs confirmation].

**Риск:** изменение векторов и состояния контроллеров способно нарушить работу таймера или клавиатуры. Универсальный rollback не описан — [Needs confirmation].
