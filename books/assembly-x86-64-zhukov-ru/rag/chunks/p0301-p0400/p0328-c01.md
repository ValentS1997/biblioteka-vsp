328                                             Часть III. 64-битовые режимы

Особенности режима совместимости

Рассмотрим некоторые особенности режима совместимости, в котором мы оказа-
лись. По идее, код, созданный для 32-битового защищенного режима, должен рабо-
тать в режиме совместимости8. Но без модификаций тут не обойтись, т. к. в "длин-
ных" режимах вентили вызова [2, Figure 4-23] и вентили прерываний и исключений
[2, Figure 4-24] должны быть расширены так, чтобы в них помещался 64-битовый
адрес9. В результате дескрипторы вентилей удваиваются в размере.

В листинге 19.4 — попытка сделать универсальный вентиль вызова, работающий
и в 32-битовом режиме, и в длинных режимах.

 Листинг 19.4. Вентиль вызова в режиме совместимости (long_2.asm)

subr:                                                        ; (12)

        retf                                                  ; (26)
dsc3:                                                        ; (50)

        dw      code0 - gdt     ; code selector                  ; (53)
        db     0              ; (rsrv)                        ; (54)
        db      10001100b      ; P, dpl, s | Call Gate          ; (55)
        dw     0              ; high adr                      ; (56)
        dq     0              ; 64-bit extension       !      ; (57)
dsc4:                                                        ; (58)
flat:                         ; Flat data, ring 0-3            ; (59)
pm:                                                          ; (91)

        set_seg ds, flat - gdt                                 ; (93)
        set_seg es, flat - gdt                                 ; (94)
        ldt_off                                               ; (95)
        a20_on                                                ; (96)

        _brk                                                  ; (97)
