Команда fisttp

В листинге П3.1 приведен пример относительно новой команды fisttp (FPU Integer
Truncate-Store-Pop) — запись в память целого числа с отбрасыванием дробной час-
ти1. Поскольку a86/a386 еще не "знают" о ней, пример написан на ассемблере nasm.

 Листинг П3.1. Инструкция fisttp (fisttp.asm)

        org     0x100           ; (1)

        jmp     start           ; (2)

dozen   dw      12              ; (3)
real    dd      3.7             ; (4)

start:                         ; (5)
        finit                  ; (6)
        fld     dword [real]     ; (7)
        fist    word [dozen]     ; (8)
        fisttp  word [dozen]     ; (9)

        int     0x20            ; (10)
