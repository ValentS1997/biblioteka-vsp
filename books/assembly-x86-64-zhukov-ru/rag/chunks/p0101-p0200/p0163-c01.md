Глава 9. Сегменты                                                           163

пределами программы, чаще по каким-то фиксированным адресам, как, например,
видеобуфер. Но если собственных данных (в пределах программы) становится мно-
го, исходный текст разбивают на секции. Каждая секция транслируется с нулевого
смещения и имеет свой базовый адрес, который при переключении секций записы-
вается в сегментный регистр ds. Максимальный размер секции — 64 Кбайт.

Для примера рассмотрим вариант программы из листинга 9.10, но с двумя секция-
ми данных, двумя секциями кода, а также с отдельной секцией стека22. Секции, или
логические сегменты, обозначаются ключевым словом segment, перед которым за-
дано имя секции.

 Листинг 9.10. Программа ea1.8, разбитая на секции (ea2.08)

D2 segment                             ; (1)
        db      "(segment D2)", 0       ; (2)
area    db      9,8,7,6,5,4,3,2,1,0     ; (3)

D1 segment                             ; (4)
s       db      "(segment D1)", 0       ; (5)

_stack  segment stack                  ; (6)
        db      "(stack segment)", 0     ; (7)
        db      40 dup 1                ; (8)

C2 segment                             ; (9)
        db      "(segment C2)", 0       ; (10)
work_with_area:                        ; (11)
        mov     bx, offset area         ; (12)
loop1:                                ; (13)
        mov     al, [bx]                ; (14)
        dec     al                     ; (15)
        js      exit                   ; (16)
        mov     [bx], al                ; (17)
        inc     bx                     ; (18)
        jmp     loop1                  ; (19)
exit:                                 ; (20)
        retf                           ; (21)

D1 segment                             ; (22)
x       dw      01155, 0                ; (23)

C1 segment                             ; (24)
        db      "(segment C1)", 0       ; (25)
main:                                 ; (26)
        mov     ds, D2                  ; (27)
        call    far work_with_area      ; (28)
