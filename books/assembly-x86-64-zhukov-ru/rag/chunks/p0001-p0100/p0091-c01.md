 Листинг 6.9. Табличное решение задачи о подсчете байтов в диапазоне (cnt_2.8)

p1      equ     10                    ; (1)
p2      equ     99                    ; (2)

map     db      p1 dup 0               ; (11)
        db      (p2 - p1 + 1) dup 1     ; (12)
        db      256 - ($ - map) dup 0   ; (13)

start:  lea     si, array              ; (14)
        mov     cx, size               ; (15)
        lea     bx, map                ; (16)
        cld                           ; (17)
        mov     ax, dx, 0              ; (18)
l1:                                  ; (19)
        lodsb                         ; (20)
        xlat                          ; (21)
        add     dx, ax                 ; (22)
        loop    l1                    ; (23)
        mov     ax, dx                 ; (24)
;       ...
        int     020

Таблица (11–13) задает 256 байтов4, из них в единицу установлены только элемен-
ты с номерами от 10 до 99. Чтение таблицы выполняется командой (21), которая
адресует данные в памяти по сумме bx и al; адрес таблицы записан (16) в bx зара-
нее. На каждой итерации в al попадает (20) очередное число из массива array, и это
значение команда (21) использует как смещение в таблице (11–13). После выполне-
ния (21) в al оказывается 0 или 1 — признак принадлежности диапазону. Предва-
рительно старшая часть ax обнуляется (18), чтобы можно было целиком5 прибав-
лять ax к счетчику dx (22).

6–9 они идут через равные промежутки.
