Глава 3. Данные, имена и типы                                                  45

И в завершение темы об именах, данных и типах — ряд вопросов и заданий.

1. Перечислите имена, определенные в следующем фрагменте, и их типы:

   noodle  equ  '0' by 0
   needle  db   40k / 7 dup 0
   a1      dw   offset needle - 0100

2. Найдите ошибки в следующем фрагменте:

   src     db   "You're genious
   dest    dw   bit 16 + offset src
   size    equ  (dest - src) / 2

3. Данные определены следующим образом:

    byte1   db   1, 2
    word1   dw   03040, 05060

  Какие значения они получат после выполнения последовательности инструкций:

   not    byte1
   not    byte1+1
   not    byte1+2
   not    word1
   not    word1+1

4. Данные определены следующим образом:

   word1  dw  03040, 3 dup 0, 0ffff

  Запишите инструкцию, выполнение которой проинвертирует слово со значе-
  нием −1.
5. Данные определены следующим образом:

   word1   db   3k dup 0, 0ff
   byte1   dw   ?

  Запишите инструкцию, которая проинвертирует последний  байт, заданный
   директивой db, а также инструкцию, которая проинвертирует последнее слово из
   последовательности, заданной директивой db. (Попробуйте адресовать эти дан-
   ные, используя имя byte1.)
6. Данные заданы следующим образом:

   abcd    db   'ABCD'
   digit   db   '0123456789'

  Какими станут их значения после выполнения инструкций:

   not    abcd
   not    abcd+6
   not    digit-3

7. Данные заданы следующими объявлениями:

    byte1   db   -2, 2, 3
