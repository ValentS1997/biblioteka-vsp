Типы и выражения

Рассмотрим правила совместимости типов в выражениях, а также правило для
определения типа результата выражения.

Правила совместимости:

  Над именами типа abs выполнимы все операции, предусмотренные в выражени-
   ях (напоминаем, что типом abs характеризуются числа и метки).

  Имя переменной (тип byte, word, dword) в выражении допускается только справа
   и/или слева от знаков сложения и вычитания.

Правило определения типа результата:

   Результат сложения/вычитания принимает тип первого операнда.

  Как исключение, результат сложения с одной переменной всегда принимает тип
   переменной.

В листинге 3.13 для определения типа результата используется оператор type name,
который возвращает число байтов, занимаемых переменной name:

   1, если переменная типа byte;

   2, если word;

   4, если dword;

   0, если это константа или метка (тип abs).

 Листинг 3.13. Тип результата константного выражения (exa11.8)

byte1   db   4 dup 10
word1   dw   0200

obj1    equ  type (byte1 - 1)              ; 1 - "byte"
obj2    equ  type (word1 - 1)              ; 2 - "word"
obj3    equ  type (1 - byte1)              ; 0 - "abs"
obj4    equ  type (1 - word1)              ; 0 - "abs"
