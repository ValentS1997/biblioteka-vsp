Глава 6. Программирование циклов                                               87

        inc     si                    ; (10) ?!
        loopne  l1                    ; (11)

Проверьте в отладчике. Команда (10) будет каждый раз по-своему устанавливать
флаг z (в примере — всегда обнулять его), отменяя результат сравнения (9). По-
смотрите, как на последней итерации команда (9) устанавливает флаг z, а (10) его
сбрасывает.

Поиск в массиве слов

Поменяем условия задачи: пусть задан массив слов и требуется выяснить, есть ли
среди них слово со значением 7. Решение приведено в листинге 6.3.

 Листинг 6.3. Поиск в массиве слов (find_2.8)

array   dw      08000, 07fff, 0, 0ffff  ; (3)
        dw      x-1, x+1, x            ; (4)
size    equ     $ - array              ; (5)

start:  mov     cx, size / 2           ; (6)
        lea     si, array - 2          ; (7)
l1:                                  ; (8)
        add     si, 2                  ; (9)
        cmp     w[si], x               ; (10)
        loopne  l1                    ; (11)

Изменились директивы (3–4), счетчик циклов теперь вдвое меньше (6) числа байтов
в массиве, отступ при инициализации (7) регистра-указателя теперь равен двум,
и на 2 увеличивается указатель в (9), а в команде сравнения (10) явно задан тип
word.
В листинге 6.4 приведен другой вариант решения задачи о поиске (на примере
поиска слова): с применением строковой команды scas.

 Листинг 6.4. Поиск в массиве с применением строковой команды (find_3.8)

start:  mov     cx, size / 2           ; (6)
        lea     di, array              ; (7)
        mov     ax, x                  ; (8)
        cld                           ; (9)
l1:                                  ; (10)
        scasw                         ; (11) ax <> w[di++] ?
        loopne  l1                    ; (12)
