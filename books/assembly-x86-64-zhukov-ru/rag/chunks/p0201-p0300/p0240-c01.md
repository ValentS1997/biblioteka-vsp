240                                              Часть II. Защищенный режим

 Листинг 14.4. Определение и проверка сегмента стека (err1.asm)

dsc4:                         ; Data (local), r/w               ; (37)
        dw      end - 1        ; limit low                      ; (38)
        dw     0              ; base low                       ; (39)
        db     0              ; base middle                    ; (40)
        db      1001_0010b     ; P, dpl, S | data, e, RW, a      ; (41)
        db      0000_0000b     ; g, b, 00 | limit high (0)       ; (42)
        db     0                                              ; (43)
dsc6:                                                         ; (51)
stk:                          ; Stack, r/w                     ; (52)
        dw      end - 1        ; limit low                      ; (53)
        dw     0              ; base low                       ; (54)
        db     0              ; base middle                    ; (55)
        db      1001_0110b     ; P, dpl, S | data, E, RW, a      ; (56)
        db      0000_0000b     ; g, b, 00 | limit high (0)       ; (57)
        db     0                                              ; (58)

        set_seg ds, dsc4 - gdt                                  ; (79)
        mov     byte [end-1], '-'                               ; (80)

        set_seg ss, stk - gdt                                   ; (81)
        mov     sp, end + 8                                     ; (82)

        push    eax                                            ; (83)
        push    edx                                            ; (84)
        push    ax                                             ; (85)

l2:     _brk                                                   ; (86)
        jmp     l2                                             ; (87)

        align   16                                             ; (88)
        db      'Finita '                                       ; (89)
end:    db      'la Comedia'                                    ; (90)

При выполнении команды (85) произойдет запланированный сбой: stackPrefetch(2):
access [0x000001c5] > SS.limit [0x000001c6]. Но команды (83–84) должны были
затереть строку (90), а этого не произошло. Причина в том, что базовый адрес стека
равен нулю. Это видно по значению селектора ss в консоли и обнаруживается
командой View/GDT после выполнения (81).

Исправьте ошибку. В строке (90) после выполнения (83–84) должны уцелеть лишь
две последние литеры.

Обнулите в (56) признак RW (бит 1). Добавьте между (82) и (83) команду pop. При
выполнении какой команды произойдет сбой? Какое сообщение последует?
