Глава 14. Данные и стек                                                       241

Верните RW =  1, закомментируйте (82) и уберите команду pop — пусть стек будет
таким же, как в com-программе. Убедитесь, что при выполнении (85) указатель сте-
ка увеличивается на 2. Вопрос: если вместо регистра в (85) задать число 1, то с ка-
кой разрядностью оно запишется в стек: 16 бит или 32 бита? Можно ли изменить
разрядность команды (85) префиксами a16/a32 и o16/o32?

Режим unreal

В листинге 14.5 показан пример переключения в режим Unreal5 на основе програм-
мы из листинга 13.5.

 Листинг 14.5. Включение и проверка режима unreal (unreal.asm)

dsc2:                         ; Data (flat), r/w                ; (15)
        dw      -1             ; limit low (max)                 ; (16)
        dw     0              ; base low                       ; (17)
        db     0              ; base middle                    ; (18)
        db      1001_0010b     ; P, dpl, S | data, e, RW, a      ; (19)
        db      1100_1111b     ; G, B, 00 | limit high (max)     ; (20)
        db     0                                              ; (21)

        mov     ax, cs                                          ; (27)
        mov     [cmd+3], ax                                     ; (28)

        switch_mode                                            ; (35)
        jmp     8:pm                                           ; (36)

pm:     _brk                                                   ; (38)
        set_seg fs, dsc2 - gdt                                  ; (39)
        switch_mode                                            ; (40)
cmd:    jmp     0:rm                                           ; (41)

rm:     _brk                                                   ; (43)
        mov     ebx, 0xb8000                                    ; (44)
        fs inc  byte [ebx]                                      ; (45)

        mov     ebx, 0x100000                                   ; (46)
        fs mov  eax, [ebx]                                      ; (47)
        fs mov  [ebx], edx                                      ; (48)

        mov     ebx, 0                                          ; (49)
        fs mov  eax, [ebx]                                      ; (50)

        _exit                                                  ; (51)
