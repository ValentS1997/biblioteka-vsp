Еще одна конфигурация - многопользовательский MU-MIMO (Multi-User MIMO)- соот
ветствует ситуации, когда на приемной стороне работает несколько пользователей, каждый
из которых в общем случае оснащен несколькими антеннами (рис. 23.10). В большинстве
беспроводных линий связи типа •один ко многим• (например, связь точки доступа сети
Wi-Fi с мобильными устройствами пользователей 1 ) в каждый момент времени обслужи
вается запрос только одного пользователя. Системы MU-MIMO частично снимают это
ограничение, поддерживая несколько одновременных информационных потоков с раз
ными пользователями. Параллельные потоки могут быть организованы и в обратном на
