             Рис. 24.8. Процесс конфигурирования туннелей магистральной сети

Начальным шагом является выбор сервером ММЕ маршрута через магистральную сеть
для соединения телефона Т1 с пакетным шлюзом PGW Этот маршрут будет обслуживать
запрошенное телефоном Т1 в процессе аутентификации соединение с интернетом (услу
га сети передачи данных). Между телефоном и пакетным шлюзом могут существовать
в общем случае несколько маршрутов. Пусть сервер управления мобильности выбрал

маршрут :

   Т1 - Базовая станция 1- SGW1 - PGW

Этот маршрут нужно проложить в сети, то есть создать два туннеля и соединить их между
собой.
Первым создается туннель P-S. Сервер управления мобильностью ММЕ посылает
сервисному шлюзу SGW1 запрос о необходимости создания туннеля P-S для трафика
телефона Т1  . При этом в запросе указывается глобальный идентификатор телефо
на IMSI.
ll.lлюз SGW1 начинает выполнять этот запрос. Он пересылает запрос о создании туннеля
шлюзу PGW, сообщая в нем глобальный идентификатор телефона Т1 и значение выбран
ного им идентификатора создаваемого туннеля TEID- Р для направления Р -+ S ( напомним ,
что идентификатор TEID назначает принимающий узел направления), в нашем примере
оно равно 256.
Шлюз PGW назначает IР-адрес телефону Т1, он обозначен в примере как IP-T1, и теперь
шлюз PGW может создать для трафика телефона Т1 запись н таблице продвижения: IР-
