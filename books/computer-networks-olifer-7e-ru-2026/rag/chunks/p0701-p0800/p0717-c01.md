716                                                Часть VI. Беспроводная передача данных

При организации подканалов частота несущей каждого подканала отличается от частот
несущей соседних подканалов на величину частоты модуляции сигнала в подканале/m·
Как видно из рис. 23.17, максимум амплитудно-частотной характеристики подканала

совпадает с точками перехода амплитудно-частотных характеристик соседних каналов
через О, поэтому сигналы соседних каналов мало влияют на основные гармоники данного
подканала, то есть подканалы являются ортогональными. Техника модуляции сигнала на
каждом подканале может быть своя: например, в одном подканале может использоваться
техника модуляции QPSK, а в другом - QAM16. Главное, чтобы частота модуляции у всех
подканалов была одинаковая и равная сдвигу несущей частоты.
На рис. 23.18 показана схема, иллюстрирующая процесс преобразования кодов и сигналов
в системе передатчик-приемник технологии OFDM. Несколько пояснений к рисунку.
1. На вход передатчика поступает последовательность нулей и единиц передаваемого
    кода. Блок S/P (Serial/Parallel) преобразует этот последовательный поток в несколько
   параллельных (в нашем примере - потоки а, Ь, с и d), выбирая из входного потока по
   нескольку битов, в зависимости от количества состояний сигнала метода модуляции,
   выбранного для канала. На рис. 23.18 блок S/P выбирает из входного пото'Ка по 2 бита,
   то есть выбран метод модуляции с четырьмя состояниями сигнала, например QPSK, а за
   один такт модуляции передается 2 бита исходного кода. Такт определяет частоту моду
   ляции fm. Блок S/P производит четыре параллельных потока данных, то есть передача
   исходной информации будет осуществляться по четырем подканалам системы OFDM.
2. Каждый из четырех потоков поступает на блок модуляции Mod, где модулируется в со
   ответствии с выбранный техникой, например, квадратурной фазо-частотной модуля
   ции QPSK на несущей частоте fc конкретного подканала. Структуру квадратурного
   модулятора мы рассматривали в главе 7, в технологии OFDM такой модулятор обычно
   работает в режиме прямого цифрового синтеза DDS. Результат модуляции представлен
   на выходе модулятора в виде набора гармоник модулированного и отфильтрованного
   цифровым импульсным фильтром сигнала. Например, если в некотором такте по подка
   налу а поступает код 1О, то результатом работы модулятора будет несколько дискретных
   частот, например, три числа, если после фильтрации спектр сигнала состоит из трех
   основных гармоник. Модулятор может иметь библиотеку спектров модулированных
   и отфильтрованных сигналов для различных значений входных дискретных данных,
   например, для кода 00 имеется один набор значений гармоник сигнала, соответствую
   щего этому коду, для кода 01 - другой набор и т. д. Результаты преобразований условно
   показаны на рис. 23.18 в виде четырех значений амплитуды основной гармоники спек
   тра каждого подканала на выходе блока Mod ( спектр каждого подканала упрощен до
   основной гармоники, хотя в реальности он состоит из нескольких гармоник).
3.  Значения дискретного спектра каждого сигнала вместе со значениями частот каждого
   из четырех подканалов OFDM поступают на блок IFFT (Inverse Fast Fourie Trans-
   formation), выполняющий обратное преобразование Фурье. Выходными сигналами
   блока IFFT являются функции времени, соответствующие модулированному сигналу
   каждого частотного подканала OFDM. Таким образом, обратное преобразование Фурье
   выполняет функции смесителя, перемножающего модулирующие сигналы с сигналами

   несущих каждого подканала.
