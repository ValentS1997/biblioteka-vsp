В сетях LTE данные в радиосреде передаются в ресурсных блоках OFDMA (см. главу 23).
Ресурсные блоки адресуются номерами, соответствующими положению блока в частотном
диапазоне сети -  первый, второй и т. д. Так что устройству пользователя нужно только
знать номер или номера ресурсных блоков, в котором (которых) ему передали данные
в очередном тайм-слоте.
Механизм применения идентификатора С-RNTI в качестве адреса весьма необычен для
проводных сетей, поэтому рассмотрим его подробно.

Базовая станция помещает информацию о принадлежности ресурсных блоков устройствам
пользователей в отведенные для этой цели начальные управляющие блоки переданного
кадра. Эти служебные поля называются «поля DCI» (рис. 24.7). В каждом из них содержат
ся несколько номеров ресурсных блоков, адресованных определенному телефону. Адреса
телефона в этом поле нет. Возникает вопрос, как телефон может понять, что в одном из
служебных полей DCI находятся номера его ресурсных блоков? Для решения этой про
блемы используется шифрация. Базовая станция вычисляет контрольную сумму содер
жимого поля DCI, несущего информацию о номерах ресурсных блоков для определенного
телефона, и зашифровывает ее с помощью временного сотового идентификатора С-RNTI
этого телефона, пользуясь им как ключом шифрования, а затем помещает зашифрованную
контрольную сумму в поле DCI. В данном примере для телефона со значением идентифи
катора C-RNTI = 125 в поле DCI помещена информация о том, что в кадре есть ресурсные
блоки для этого телефона - их номера 4 и 5.

При получении кадра каждый телефон считывает все служебные поля DCI, вычисляет
контрольную сумму каждого из них и также зашифровывает ее с помощью своего времен
ного сотового идентификатора . Если результат совпадает с помещенной в поле зашифро
ванной базовой станцией контрольной суммой, то значит, это поле предназначено данному
телефону и он читает свои данные из ресурсных блоков кадра, номера которых он нашел
в его служебном поле DCI. Возможно, что телефон не смог правильно расшифровать ни
одно из служебных полей DCI, и это означает, что в текущем кадре для него данных нет.
