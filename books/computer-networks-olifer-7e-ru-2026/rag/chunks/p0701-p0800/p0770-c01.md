Гибкое планирование распределения ресурсных блоков
В сети 5G планировщик МАС-уровня поддерживает три очереди для трафика трех разных
услуг (еМВВ, URLCC и MioT).

Для очереди трафика доступа к интернету еМВВ он производит планирование не для
каждого тайм-слота - это было бы расточительно для трафика этого типа с требованиями
к задержке в 10-15 мс. Вместо этого он выполняет планирование один раз в 2-4-8 тайм
слотов и старается заполнить имеющиеся ресурсные блоки как можно полнее, назначая
несколько последовательных во времени тайм-слотов некоторому устройству пользователя

в одном цикле планирования.
Для очереди сверхнадежного трафика, чувствительного к задержкам URLCC, он вы
полняет планирование для каждого тайм-слота. При этом он может использовать уко
роченные во времени ресурсные блоки в 2-7 символов, чтобы быстрее их отправить.
При приходе срочных данных URLCC запланированная заранее передача нескольких
ресурсных блоков трафика еМВВ в последовательных тайм-слотах может прерываться,
и данные URLCC будут помещены в ресурсный блок, ранее предназначенный данным
еМВВ. То есть планировщик МАС выполняет обслуживание очередей с абсолютными
приоритетами (см. главу 5).

Применение малых сот
