828                                                Часть VI. Беспроводная передача данных

ПРИМЕЧАНИЕ------------------------

В каждой из трех технологий используются собственные названия для ролей узлов. Например,
РАN-координатор в технологии ZigBee называется ZigВее-координатором, а технологии Thread -
Thread Leader. В нашем тексте мы будем использовать уже описанные ранее термины специфика
ции 802.15.4.

РАN-координатору выделяется диапазон адресов, достаточный для адресации всех узлов
сети. Во время присоединения к нему координаторов он выделяет каждому из них под
диапазоны адресов. В свою очередь эти координаторы поступают аналогичным образом
при присоединении узлов к ним, и так далее вниз по иерархии. При этом фиксируются
отношения «родитель - потомок» между узлами сети. Получив поддиапазон адресов,
координатор назначает один из них себе. В отличие от координаторов, конечный узел

получает только один адрес.

Поскольку адреса иерархичны, становится возможным определить по адресу, к какому

поддереву принадлежит узел.

Логика координатора при выборе пути для маршрутизации кадра заключается в следу

ющем: если адрес назначения принадлежит моему поддиапазону адресов, то кадр нужно

переслать вниз, тому потомку, поддиапазону которого принадлежит этот адрес; в против
ном случае кадр нужно переслать вверх к родительскому узлу. Решения о маршрутизации
не требуют использования таблиц маршрутизации.

Для того чтобы такая схема работала, то есть не происходило истощения диапазонов

адресов раньше времени, алгоритм распределенного назначения адресов регулируется
параметрами - максимальным количеством дочерних узлов и максимальным количеством
уровней дерева.

Ячеистая топология не может быть построена с помощью иерархии адресов, а следова
тельно, маршрут в сети не может быть найден по значению адреса назначения. Протокол
NWK для построения ячеистой топологии использует традиционную маршрутизацию
на основе таблиц. Работа протокола NWK в этом режиме аналогична работе протокола
маршрутизации AODV, подробно описанного в главе 27.
На верхнем прикладном уровне в стеке протоколов ZigBee находится библиотека при
ложений, позволяющая быстро создавать приложения, управляющие устройствами
ZigBee.

Между этим уровнем и сетевым уровнем находится протокол поддержки приложений
(Application Support SuЬlayer, APS). Этот подуровень экранирует все транспортные дета
ли сети ZigBee от прикладного уровня. Он выполняет функции протокола транспортного
уровня: обеспечивает мультиплексирование сообщений между прикладными процессами
и сетевым протоколом, а также их надежную доставку через сеть. Функции этого поду
ровня шире, чем функции транспортного протокола: он также создает логическую карту
связей между устройствами сети, не привязанную к их сетевым адресам. Эта карта позво
ляет приложениям абстрагироваться на уровне устройства (например, в ней имеется связь
«Переключатель управляет лампой»). На этом подуровне выполняются также функции
безопасности, такие как шифрование и дешифрование.

Библиотека приложений состоит из программных модулей, описывающих устройства
ZigBee и действия, которые над ними можно выполнять. Часть этих модулей устанавли
вается на самих устройствах.             Книги для программистов: https://t.me/free_books_for_it
