840                                                Часть VI. Беспроводная передача данных

Модуляция сигнала LoRa выполняется квадратурным модулятором, работа которого опи
сана в главе 7. Для приведения случая частотной модуляции к фазовой, с которой работает
квадратурный модулятор, необходимо воспользоваться определением мгновенной скоро
сти. Это определение говорит, что мгновенная скорость равна производной зависимости
фазы от времени.

Поэтому, проинтегрировав линейную зависимость мгновенной частоты от времени сиг
нала LoRa, то есть зависимость/(t) = /шin + R х t, мы получим выражение для мгновенной
фазы этого сигнала, которая нужна для того, чтобы воспроизвести сигнал LoRa с помощью

квадратурного генератора.

Опуская промежуточные преобразования и выражая скорость изменения частоты че
рез ширину полосы В и фактор SF, получаем выражение для мгновенной фазы сигнала
LoRa <p(t):
                                     <p(t) = 21t [-В/2 х t + (B2j2SF) х t2].
Как уже было сказано, квадратурный модулятор LoRa работает в дискретном времени,
поэтому эта формула преобразуется в набор значений фазы для М моментов времени
и с помощью этих значений вычисляются значения синфазной и квадратурной состав
ляющих модулирующего сигнала, то есть i(t;) = Acos( <p(t;) и q(t;) = Asin( <p(t;), где индекс i
изменяется от О до (М-1).

Для ускорения операции модуляции дискретные значения синфазной и квадратурной
составляющих вычисляются заранее для каждого из семи значений SF и помещаются
в память модулятора. Поэтому при необходимости генерации сигнала для определенного
значения SF из памяти модулятора с нужной частотой извлекаются заранее вычисленная
последовательность значений синфазной и квадратурной составляющих, соответствующих
данному значению SF. Затем с помощью цифро-аналоговых преобразователей дискретные
значения синфазной и квадратурной составляющих преобразуются в аналоговые сигналы
и в аналоговой форме перемножаются на синусоиды несущего сигнала частоты  fc, то есть
работает стандартная схема квадратурного модулятора.
Демодуляция сигнала LoRa требует точной синхронизации приемника с передатчиком,
поэтому в начале передачи каждого символа передается преамбула из нескольких ~про
стых• немодулированных чирп-сигналов, у которых начальная частота не сдвигается (как
у сигнала на рис. 26.7). После достижения синхронизации приемник выполняет выделение
синфазной и квадратурной составляющих сигнала, как это было описано в главе 7. На этом
аналоговая часть демодуляции заканчивается, синфазный и квадратурный сигналы оциф
ровываются и дал1,нейшие преобразования выполняются над дискретными значениями

этих двух составляющих сигнала.
Для нахождения начального сдвига частоты сигнала ( то есть для нахождения значения
принятого символа) полученные значения чирп-сигнала перемножаются с эталонным
нисходящим чирп-сигналом. Этот процесс иллюстрируется рис. 26.12. Умножение

выполняется над значениями сигналов как комплексных чисел, то есть, например, ис
ходный чирп-сигнал представляется в виде последовательности значений комплексных
чисел r(n), где r(n) = i(n) + j q(n), таким же образом представляется и эталонный чирп

сигнал.
