Еthеrnеt-коммутаторов. В случае узлов SR-MPLS вся стандартная функциональность
маршрутизатора IP/MPLS сохраняется и к ней добавляется функциональность сегментной

название •расширения•). В случае устройств SDN Openflow/Р4 функциональность ком
мутатора Ethernet почти полностью заменяется новой, остается только формат заголовка.
Программирование маршрутов с помощью контроллера РСЕР - это недостаточно масшта
бируемое решение. Контроллер должен поддерживать ТСР-соединение с каждым узлом
сети для тоrо, чтобы собрать необходимую топологическую информацию для выбора
маршрута. Более масштабируемым решением является контроллер на основе расширений
протокола BGP.
В этом случае на одном из узлов сети SR-MPLS (возможно, на нескольких) должен рабо
тать протокол BGP LS (Link State), который является расширением BGP, предназначен
ным для передачи данных состояния связей сети в модифицированных сообщениях BGP
UPDATE. Протокол BGP LS экспортирует данные состояния связей из базы данных TED,
созданной внутренним протоколом маршрутизации - OSPF ТЕ или IS-IS ТЕ.
В контроллере SR-MPLS также работает протокол BGP-LS, с которым агент BGP LS, уста
новленный на узле сети SR-MPLS, устанавливает соединение и передает по нему данные
базы TED. Контроллер на основании этих данных вычисляет ТЕ-маршрут в форме списка
узлов SR-Policy и передает ero для реализации пограничному маршрутизатору сети SR-
MPLS для отработки. Есть два протокола, которыми контроллер может воспользоваться
для этой цели, - протокол РСЕ или же недавно стандартизованное расширение протокола
BGP, называемое BGP SR (RFC 9830).
Преимуществами применения протокола BGP (для выполнения двух работ -  передачи
контроллеру информации базы состояния связей TED и передачи пограничному маршру
тизатору сети вычисленного маршрута) по сравнению с протоколом РСЕР являются: более
масштабируемое решение, не требующее связи контроллера со всеми маршрутизаторами
сети SR-MPLS, а также возможность помещения контроллера за пределами сети SR-MPLS,
так как сессию BGP можно устанавливать и между различными автономными системами.
