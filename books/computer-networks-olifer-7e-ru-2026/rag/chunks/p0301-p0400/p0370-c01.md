Для продвижения пакетов маршрутизатор должен знать маршрут. На сетевом уровне
маршрут описывается последовательностью сетей (или маршрутизаторов), через которые
должен пройти пакет, чтобы попасть к адресату. Для задания маршрута в каждом маршру
тизаторе формируется таблица маршрутизации, называемая также таблицей продвижения.
Таблица маршрутизации может быть получена разными способами, описанию которых
посвящена глава 16 •Протоколы маршрутизации и технология SD№. Сегодня основным
подходом к построению таблиц маршрутизации является согласованная работа марш
рутизаторов, в результате которой каждый маршрутизатор строит собственную таблицу
маршрутизации на основе обмена маршрутной информацией с остальными маршрутиза

торами сети.

В соответствии с многоуровневым подходом сетевой уровень для решения своей задачи
обращается к услугам нижележащего, канального уровня. Весь путь через составную сеть
разбивается на участки от одного маршрутизатора до другого, причем каждый участок

соответствует пути через отдельную сеть.

Чтобы передать пакет через очередную сеть, сетевой уровень помещает его в поле данных
кадра соответствующей канальной технологии. В заголовке кадра указывается адрес ка
нальною уровня интерфейса следующего маршрутизатора. Сеть, используя свою канальную

технологию, доставляет кадр с инкапсулированным в него пакетом по заданному адресу.
Маршрутизатор извлекает пакет из прибывшего кадра и после необходимой обработки
передает пакет для дальнейшей транспортировки в следующую сеть, предварительно
упаковав его в новый кадр канального уровня в общем случае другой технологии. Таким
образом, межсетевой протокол IP играет роль координатора, организующего совместную
работу сетей, построенных на основе разных технологий.

Для маршрутизаторов сети путь пакета через промежуточную сеть прозрачен, они его не
•замечают•, дл.я них это соединение •точка-точка•, что показано в верхний части рисунка
пунктирной линией.

Типы адресов стека ТСР/IР
Одним из достоинств технологии ТСР /IP является гибкость и масштабируемость
системы адресации, что позволяет ей достаточно просто включать в составную сеть
сети разных технологий и разного масштаба. Основными задачами адресации являются

следующие:
•  Согласованное использование адресов различною типа. Эта задача включает отображе
   ние адресов разных типов друг на друга, например сетевого IР-адреса на локальный,
   доменного имени - на IР-адрес.
•  Обеспечение уникальности адресов. В зависимости от типа адреса требуется обеспечи
   вать однозначность адресации в пределах компьютера, подсети, корпоративной сети

   или интернета.
