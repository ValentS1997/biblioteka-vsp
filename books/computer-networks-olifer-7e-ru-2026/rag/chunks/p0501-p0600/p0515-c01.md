514                                                                 Часть IV. Сети TCP/IP

Система адресации 1Pv6
Отличие от 1Pv4
Система адресации 1Pv6 внесла существенные изменения в прежнюю систему. Прежде все
го увеличилась разрядность адреса: вместо 4 байт IР-адреса в версии 1Pv4 в новой версии
под адрес отведено 16 байт. Это дает возможность пронумеровать огромное количество

узлов:

   340 282 366 920 938 463 463 37 4 607 431 762 211 456.

Масштаб этого числа иллюстрирует, например, такой факт: если разделить это теоре
тически возможное количество IР-адресов между всеми жителями Земли (а их сегодня
примерно 6 миллиардов), то на каждого из них придется невообразимо, если не сказать
бессмысленно, большое количество IР-адресов -  5,7 х 10281 Очевидно, что такое значи
тельное увеличение длины адреса было сделано не только и даже не столько для снятия
проблемы дефицита адресов.

  Главной целью изменения системы адресации было не механическое увеличение адресного
  пространства, а повышение эффективности работы стека TCP/IP в целом.

В новой версии не поддерживаются классы адресов (А, В, С, D, Е), но широко использует
ся технология CIDR. Благодаря этому, а также усовершенствованной системе групповой
адресации и введению адресов нового типа 1Pv6 может сократить затраты на маршру
тизацию. Произошли и чисто внешние изменения - разработчики стандарта предложили
использовать вместо десятичной шестнадцатеричную форму записи IР-адреса. Каждые
четыре шестнадцатеричные цифры отделяются друг от друга двоеточием. Например, адрес
1Pv6 может выглядеть так: FEDC:0A98:0:0:0:0:7654:3210. Старшие нули в группе четырех
шестнадцатеричных цифр могут быть опущены; так, вместо ОА98 можно писать А98. Не
сколько нулевых групп могут быть заменены парой двоеточий -  FEDC:0A98::7654:3210.
В адресе допускается только одна такая замена. Для сетей, поддерживающих обе версии
протокола (1Pv4 и 1Pv6), разрешается задействовать для младших четырех байтов тради
ционную для 1Pv4 десятичную запись: 0:0:0:0:0:FFFF:129.144.52.38.
В 1Pv6 расширw~ся набор адресов разного типа, приписываемых одному сетевому интер
фейсу, каждый из которых используется для специфических целей. Для 1Pv4 является
обычной ситуацией, когда хает, имеющий один сетевой адаптер, получает один IР-адрес.
В 1Pv6 каждый интерфейс всегда получает несколько IР-адресов. Например, всем интер
фейсам в сети 1Pv6 автоматически приписываются адреса, которые они могут использовать
для обмена локальным трафиком, а для глобального трафика назначаются дополнительные
адреса, подобные публичным индивидуальным адресам 1Pv4. Помимо стандартных (well
known) групповых адресов, каждый интерфейс имеет особый групповой адрес, идентифи
цирующий группу, состоящую только из него самого. Эти, а также другие типы адресов
интерфейса направлены на достижение конкретных целей: уменьшение вспомогательного
трафика, отказ от широковещательной рассылки (в том числе и на канальном уровне),
поддержка автоконфигурации и др.
Важным усовершенствованием в системе адресации 1Pv6 стало введение для каждого адре
