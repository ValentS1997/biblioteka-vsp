## Важные ограничения

- В ответе на **№44** издательство ставит прочерк: материал **не содержит издательского решения**. Не заполнять этот пробел утверждением из другой книги.
- Для **№16/26** приведена абстрактная и спорная модель цифрового сертификата; не использовать как реализацию PKI.
- Ответ **№31** содержит устаревший ACL-фрагмент — **не выполнять** и не превращать в device config без верификации.
- Ответ **№28** повреждён (`а), с)` против вариантов `а), б), в)`); в материалах сохранена неоднозначность.
- Ответ **№49** воспроизводит историческое утверждение о сертификатах обеих сторон HTTPS. Нельзя принимать как универсальную TLS-настройку.
- Вопросы №17/29 содержат повреждённую геометрию сопоставления/таблиц; нормализация терминов в notes **обозначена**, а не скрыта.

## Репозиторий и граница безопасности

Коллекция содержит **учебные вопросы и издательский ключ**. Она не включает атаки, новые сканирующие команды, реальные IP/секреты и утверждения о компрометации конкретной сети. Состояние источника и внешняя актуальная безопасность не отождествляются. Чтение главы/части пользователем не зафиксировано.
