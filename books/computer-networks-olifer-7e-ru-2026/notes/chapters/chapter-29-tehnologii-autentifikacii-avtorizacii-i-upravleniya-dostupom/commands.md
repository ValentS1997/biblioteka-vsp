# Команды — глава 29

Источник: PDF 925–954, RAG p0925:c01–p0954:c01. Политика: rag_only.

**Исполнимых команд в главе нет.** Рассмотрены механизмы аутентификации, цифровые сертификаты, назначение полномочий и единый вход. Этот материал не предназначен для изменения работающей системы.

Реальные параметры, разрешения и rollback: [Needs confirmation].

## Реестр именованных протокольных действий

| Действие | Концептуальное назначение | Опора RAG |
|---|---|---|
| Challenge / Response / Success / Failure (CHAP) | Проверка ответа на уникальный запрос | p0930–p0931 |
| OTP | Временное подтверждение с аппаратным устройством | p0931–p0934 |
| Digital signature | Подтверждение происхождения и целостности | p0934–p0935 |
| Certificate issuance / revocation | Жизненный цикл доверенных удостоверений | p0936–p0940 |
| Authenticode verification | Проверка принадлежности программного кода | p0941 |
| ACL / capabilities | Представления матрицы субъектов и объектов | p0944–p0945 |
| DAC / MAC / RBAC | Делегирование, метки или роли | p0946–p0952 |
| SSO identity token | Результат аутентификации передаётся доверенному сервису | p0953–p0954 |

Ни одна операция в таблице не снабжена исполнимым кодом, конфигурационными параметрами или разрешением на изменение работающих систем. Для каждого действия нужны версия продукта, полномочия и отдельная процедура проверки.
