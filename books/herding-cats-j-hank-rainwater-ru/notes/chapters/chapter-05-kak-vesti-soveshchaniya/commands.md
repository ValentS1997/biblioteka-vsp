# Глава 5 — команды, средства и взаимодействия

Источник: RAG PDF 107–123. **Исполняемых CLI-команд, программных опций и алгоритмов в коде в главе нет.**

| Средство или операция | Страницы | Тип | Назначение |
|---|---:|---|---|
| Письменный список задач | 108–109 | read-only при анализе, state-changing при назначении | Уточнить поставляемый результат, подзадачи и срок |
| Повестка из трёх вопросов | 108 | read-only / обсуждение | Сделано, запланировано, препятствия |
| Электронное табло, ноутбук, большой экран | 111–112 | workload-generating | Демонстрировать идеи и код на проектной встрече |
| Видеозапись обсуждения | 111 | state-changing: запись информации | Авторский вариант фиксации; правила конфиденциальности: [Needs confirmation] |
| Шаблон записей, рис. 5.1 | 112–113 | state-changing | Зафиксировать замечания, влияние на проект, необходимые действия |
| Анкета/заметки индивидуальной беседы | 116–117 | state-changing | Выявить затруднения и согласовать план; защита данных: [Needs confirmation] |
| Предварительная рассылка изображений | 120 | workload-generating | Подготовка удалённых участников |
| Протокол по окончании телеконференции | 121 | state-changing | Донести участникам конкретные действия |

**Эффекты state-changing:** изменения расписания, задач, проектных обязательств, создание записей и персональных данных. **Риски:** несогласованные назначения, забытые решения, нарушение конфиденциальности и непродуктивная критика. **Проверка:** согласованный перечень действий, сроки, адресаты, повторное изучение протокола. **Rollback:** [Needs confirmation], формальной процедуры нет.

Продолжительность «45 минут» для командных встреч (p. 109) и «не более часа» для телеконференций (p. 121) — советы автора, не глобальные лимиты.
