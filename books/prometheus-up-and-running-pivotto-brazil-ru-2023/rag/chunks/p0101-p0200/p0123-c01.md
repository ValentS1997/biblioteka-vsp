Панель таблицы

Панель статистики может отображать несколько временных рядов, но каж-
дый уникальный временной ряд занимает довольно много места. Панель
Table (Таблица) позволяет отображать несколько временных рядов в более
компактном виде и предлагает дополнительные возможности, такие как по-
страничный просмотр. Панели таблиц, как правило, требуют больше усилий
по настройке, чем другие панели, и, как правило, оказывают бо́льшую ког-
нитивную нагрузку.
  Добавьте новую панель, на этот раз Table panel (Панель таблицы). Как
и раньше, щелкните по кнопке Add panel (Добавить панель), а затем Add a new
panel (Добавить новую панель). Выберите Table (Таблица) в раскрывающемся
списке справа. Введите выражение запроса rate(node_network_receive_bytes_
total[1m]) на вкладке Metrics (Метрики) и измените тип с Range (Диапазон)
на Instant (Мгновенный). В поле Format (Формат) выберите Table (Таблица).
  Количество столбцов в таблице по умолчанию часто больше желаемого.
В таком случае перейдите на вкладку Transform (Преобразование) и щелкните
по кнопке Organize fields (Упорядочить поля). Выберите поля, которые хотите
скрыть, щелкая по значку с изображением глаза, как показано на рис. 6.12.
