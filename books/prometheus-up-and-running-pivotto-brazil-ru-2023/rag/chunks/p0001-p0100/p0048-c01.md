48    Настройка и запуск Prometheus

            Рис. 2.15    Теперь метрика up для Node Exporter имеет значение 0

  Чтобы определить правило оповещения, нужно задать выражение PromQL,
возвращающее только те результаты, о которых вы хотели бы уведомить.
В данном случае это легко сделать с помощью оператора ==. Он отфильтру-
ет1 все временные ряды, значения которых не совпадают. Если выполнить
запрос up == 0 в обозревателе выражений, то он вернет только недоступный
экземпляр, как показано на рис. 2.16.

                       Рис. 2.16    Возвращаются только экземпляры,
                       в которых метрика up имеет значение 0

  Затем нужно добавить это выражение в правило оповещения в Prometheus.
Мы также немного забежим вперед и укажем серверу Prometheus, с каким
Alertmanager он будет взаимодействовать. Для этого дополним содержимое
prometheus.yml, как показано в примере 2.1.

1  Существует также режим bool без фильтрации (см. описание в разделе «Модифи-
  катор bool» главы 15).
