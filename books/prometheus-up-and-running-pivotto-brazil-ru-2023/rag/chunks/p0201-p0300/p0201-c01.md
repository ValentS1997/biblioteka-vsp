HTTP

Протокол передачи гипертекста (HyperText Transfer Protocol, HTTP) является
основой современной Всемирной паутины и, вероятно, используется боль-
шинством предоставляемых вами служб. Хотя в большинстве случаев мони-
торинг веб-приложений лучше выполнять с помощью Prometheus, извлекаю-
щего метрики через HTTP, иногда все же может потребоваться осуществлять
мониторинг ваших HTTP-служб методом «черного ящика».
  Зонд http принимает URL2, переданный в параметре target. Например,
открыв страницу http://localhost:9115/probe?module=http_2xx&target=https://
www.oreilly.com/, можно проверить доступность веб-сайта O’Reilly по про-
токолу HTTPS, используя 3модуль http_2xx, и получить следующий вывод:
