  Видите, здесь присутствует метрика probe_success, а также ряд других ме-
трик, которые могут пригодиться для отладки, таких как код состояния, вер-
сия HTTP и продолжительность различных фаз запроса.
  Зонд http имеет множество параметров, которые влияют на выполнение
запроса и определяют, можно ли считать ответ успешным. С их помощью
можно настроить HTTP-аутентификацию, заголовки, тело POST-запроса, а за-
тем в ответе проверить код состояния, версию HTTP и содержимое его тела.
