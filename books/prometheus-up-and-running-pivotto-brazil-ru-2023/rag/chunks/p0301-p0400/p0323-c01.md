Дерево маршрутизации

Поле route задает маршрут по умолчанию (он же резервный маршрут). Марш-
руты образуют дерево, поэтому вслед за маршрутом по умолчанию обычно
определяется еще несколько маршрутов. Например:

route:
  receiver: fallback-pager
  routes:
    - matchers:
        - severity = page
      receiver: team-pager
    - matchers:
        - severity = ticket
      receiver: team-ticket

  Проверка поступившего оповещения начинается с маршрута по умолча-
нию, и производится попытка сопоставления с первым дочерним маршрутом,

1  amtool также можно использовать для запроса оповещений и управления их от-
