## F-01 — [Source wording/code mismatch]: префикс EC2 labelmap

- **RAG `p0163:c01`, пример 8.21:** `regex: __meta_ec2_public_tag_monitor_(.*)` в действии `labelmap`.
- **Там же, объяснение:** EC2-тег `monitor_foo=bar` предполагается превращать в target label `foo="bar"`. `source_labels: [__meta_ec2_tag_service]` задаёт связанную метку job.
- **RAG `p0153:c01`:** metadata EC2 для Name показано как `__meta_ec2_tag_Name` (без `public`).
- **Расхождение:** структура имени `__meta_ec2_public_tag_monitor_*` не согласована с `__meta_ec2_tag_*` соседних примеров. Нельзя гарантировать работу такого labelmap без дополнительных доказательств.
- **Решение:** оставить обе исходные формы; не исправлять regex silently, отметить [Needs confirmation].
