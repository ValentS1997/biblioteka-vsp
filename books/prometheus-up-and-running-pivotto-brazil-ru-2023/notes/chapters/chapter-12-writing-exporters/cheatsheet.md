# Cheatsheet — глава 12: Разработка экспортеров

**Основание:** PDF 215–225, RAG `p0215:c01`–`p0225:c01`; `rag_only`.

## Symptom / problem framing

- Прямо инструментировать приложение нельзя и подходящего exporter нет: реализовать собственный адаптер исходной системы к модели метрик Prometheus (PDF 215).
- Метрика из стороннего API называется Counter, но неясно, действительно ли монотонна: тип нельзя определять по одному названию. При неопределённости в книге допускается `UntypedValue` (PDF 216, 220, 224).
- Не видно, почему пропали метрики источника: возвращать `consul_up=0` в случае ошибки API вместо полного исчезновения диагностического индикатора (PDF 217, 220).
- Ошибка семейства/label в `/metrics`: проверять состав `Desc`, метки, уникальность имён и одинаковую HELP строку для одного имени метрики (PDF 221, 223).
- Две реплики Prometheus одновременно опрашивают exporter: сбор должен поддерживать пересекающиеся scrape и давать непротиворечивый снимок на каждый запрос (PDF 219, 225).

## Baseline / context

- Consul Agent API `http://localhost:8500/v1/agent/metrics` выдаёт JSON `Gauges`, `Counters`, `Samples`; тип и единицы Samples в этом примере подтверждены текстом как **таймеры в миллисекундах** (PDF 215–216).
- Go: `prometheus.Collector` с `Describe` и `Collect`. `consul_up` — заранее известный `Desc`, другие descriptions формируются на лету (PDF 217–220).
- `MustNewConstMetric(desc, GaugeValue|CounterValue|UntypedValue, value)` — создание метрики из чтения источника. Десятичные точки/дефисы в именах Consul приводятся к `_` (PDF 217–221).
- Python: `GaugeMetricFamily`, `CounterMetricFamily`, `SummaryMetricFamily`, `REGISTRY.register`, `start_http_server(8000)` (PDF 222–223).
- Примеры `go get -d -u` и `go run` относятся к контексту издания; рабочий Go module/version [Needs confirmation].
- Для обычного exporter default registry добавляет `go_` и `process_`; Blackbox/SNMP имеют особую организацию endpoint из-за query params (PDF 222).
- Нормализация units: секунды/байты. Не экспортировать готовые средние за 5 минут и отношения, если можно передать Counter/числитель/знаменатель и обработать в PromQL (PDF 224–225).

## Read-only checks

1. Посмотреть JSON Consul на `http://localhost:8500/v1/agent/metrics` и определить `Name`, `Value`, `Count`, `Sum`, `Labels`; не предполагать, что все Counters имеют семантику монотонного счётчика (PDF 215–216).
2. Просмотреть локальный `http://localhost:8000/metrics`; должны быть `consul_up`, семейства с нормализованными именами и unit suffix (PDF 218).
3. Сравнить фактические `_seconds_sum` и source `Samples.Sum`: численный пример из PDF **внутренне противоречив** (PDF 216, 218), см. [source-findings.md](source-findings.md).
4. Проверить `process_open_fds`, `go_` и `process_` для наблюдения за самим exporter (PDF 222).
5. Проверить `example_gauge{foo="bar",baz="small"} 1`, `{foo="quu",baz="far"} 2` после корректной реализации меток, уникальность рядов и совпадение HELP для одинакового имени (PDF 223–224).
6. Оценить исходные единицы и labels с точки зрения агрегирования и кардинальности (PDF 224–225).

## Interpretation

- `Describe` — контроль известных заранее семейств при регистрации; `Collect` — синхронное чтение источника при каждом scrape. Пользовательский collector может возвращать много семейств (PDF 219–220).
- `consul_up=0` сигнализирует об ошибке API Consul и отличается от отсутствия HTTP scrape; `consul_up=1` — успешный запрос данных у агента (PDF 217, 220).
- Go-пара `_seconds_count`/`_seconds_sum` представляет части Summary, но **это отдельные Counter-семейства в данном примере**, а Python использует `SummaryMetricFamily` (PDF 218, 222–223).
- Не агрегировать min/max/stddev, когда неизвестно окно наблюдения, и не публиковать их без возможности осмысленной агрегации (PDF 222, 225).
- `process_open_fds` относится к самому exporter. Метрики ресурсов машины следует брать из Node Exporter (или Windows Exporter на Windows), а не дублировать в прикладном exporter (PDF 222, 225).

## Next action

- Установить семантику всех исходных полей и units; для неизвестных типов выбирать untyped или отказаться от ряда до уточнения (PDF 216, 224).
- Разработать `Collect` как синхронное получение и преобразование; различать известные заранее `Desc` и динамические; обеспечить согласованность labels и HELP (PDF 219–224).
- Проверить кардинальность, удалить уже встроенные totals и лишние target labels, не пересчитывать преждевременно `rate` (PDF 224–225).
- Предусмотреть `myexporter_scrape_duration_seconds` или счётчик обращений к API там, где это полезно для диагностики/стоимости (PDF 225).

## Modifying action

- `go get -d -u ...` изменяет зависимости рабочего окружения; `go run consul_metrics.go` запускает локальный HTTP-сервис на `:8000` (PDF 218). Историческая совместимость Go toolchain [Needs confirmation].
- `prometheus.MustRegister(c)` либо `REGISTRY.register(ConsulCollector())` изменяет локальный реестр экспортируемых метрик; `http.ListenAndServe`/`start_http_server` открывает сетевой endpoint (PDF 218, 223).
- Создание/изменение custom Collector определяет имена, типы, labels, количественные значения и поведение ошибок; неправильно записанный Python `count_value=c["Count"]` нельзя переносить как проверенный код (PDF 223).
- Запуск/повторная конфигурация Consul Agent на `:8500` упомянут через пример главы 8, но **полной команды запуска внутри главы 12 нет** — не реконструировать (PDF 215).

## Verification / acceptance checks

- При работающем источнике `consul_up=1`, при ошибке API `0`; HTTP `/metrics` доступен, экспортируются метрики и runtime `go_`/`process_` (PDF 218–222).
- Для Samples проверить `_seconds_sum` на тестовых числах после `/1000`; **нельзя принять опубликованный output PDF 218 как непротиворечивый golden test** (PDF 216–218).
- Для Python убедиться, что Summary count берётся из правильного элемента Samples; исходный `c["Count"]` не гарантирует это (PDF 223).
- При нескольких scrape проверить независимость чтения и корректность labels/HELP и отсутствие расхождения семейства (PDF 219, 223–225).
- Реальная совместимость, сетевые доступы, производительность и глубина наблюдаемости приложения [Needs confirmation].
