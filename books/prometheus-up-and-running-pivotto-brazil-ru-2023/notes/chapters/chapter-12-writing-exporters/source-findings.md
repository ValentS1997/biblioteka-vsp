## F-01 — [Source contradiction]: Go `_seconds_sum` не соответствует преобразованию из ms в s

- **RAG `p0216:c01`, JSON `Samples[0]`:** `"Sum": 0.13156799972057343`, `"Count": 1` у `consul.fsm.coordinate.batch-update`.
- **RAG `p0218:c01`, полный Go листинг:** `MustNewConstMetric(sumDesc, prometheus.CounterValue, s.Sum/1000)`, описание подчёркивает перевод миллисекунд в секунды.
- **RAG `p0218:c01`, опубликованный `/metrics`:** `consul_fsm_coordinate_batch_update_seconds_sum 1.3156799972057343e-01`, то есть приблизительно **0.13156799972057343**, исходное значение без деления.
- **Внутреннее противоречие:** у Go-кода для приведённого JSON результат был бы исходным числом, делённым на тысячу (около `0.00013156799972057343`), а не опубликованным результатом.
- **Действие:** не корректировать данные PDF или код; не использовать показанный output как численный golden test. Нужно проверить исходный листинг/реальную программу отдельно [Needs confirmation].

## F-02 — [Source code mismatch]: Python Summary count берётся из другой переменной

- **RAG `p0222:c01`–`p0223:c01`, пример 12.3:** сначала `for c in metrics["Counters"]`, затем `for s in metrics["Samples"]`.
- **RAG `p0223:c01`, в последнем цикле:** `SummaryMetricFamily(..., count_value=c["Count"], sum_value=s["Sum"] / 1000)`.
- **Несогласованность:** `c` представляет ранее обработанный Counter, `s` — текущий Sample; `count_value` таким образом читает не тот объект, а если Counters отсутствуют, `c` может быть вообще не определена.
- **Действие:** в `commands.md` фрагмент сохранён буквально и помечен как непроверенный. **Не менять silently** на `s["Count"]` даже если такое исправление выглядит естественным.

## F-03 — [Source code mismatch]: `s.Count` в цитате Go Counter loop

- **RAG `p0218:c01`, полный Go листинг 12.2:** внутри `for _, c := range metrics.Counters` используется `float64(c.Count)`.
- **RAG `p0221:c01`, пояснительный повтор того же цикла:** `for _, c := range metrics.Counters` и `float64(s.Count)`.
- **Несогласованность:** `s` в повторной цитате не соответствует текущей переменной цикла, тогда как основной листинг использует `c`.
- **Действие:** в документации исходного примера `commands.md` сохранён полный вариант из PDF 218, повтор PDF 221 здесь зарегистрирован отдельно. Копировать пояснительный фрагмент как рабочий код нельзя.

## F-04 — [Needs confirmation]: тип и поле источникового Consul Counter

- **RAG `p0216:c01`:** `Counters` содержит одновременно `Count: 1` и `Sum: 2`.
- **RAG `p0218:c01`:** для экспорта `consul_raft_apply_total` используется `c.Count`, результат `1`.
- **RAG `p0216:c01`, сноска:** название Counter в другой системе **не доказывает** семантику монотонного счётчика в Prometheus (пример Dropwizard).
- **Ограничение:** без независимой спецификации API неизвестно, в какой именно метрике отражается количество вызовов или сумма сторонних событий. Авторский вариант зафиксирован, менять тип или выбирать `Sum` на основании догадок нельзя.
