**Scope:** PDF 18–33. В тексте отсутствуют полные CLI-команды для установки, запуска, настройки или запросов к Prometheus. **Командная строка ниже не конструируется по памяти.**

| Упомянуто в главе | Класс | Для чего в тексте | RAG |
| --- | --- | --- | --- |

| Browser выражений Prometheus, Grafana | read-only при просмотре | Исследование метрик и визуализация через API | `p0031:c01` |

## Не путать понятия с готовыми командами

- Service discovery, exporters, клиентские библиотеки, remote-read/write, recording rules и alerting rules — компоненты/механизмы, а **не исполняемые команды**, описанные в главе 1.
- Параметры CLI, HTTP-endpoints, YAML-фрагменты, PromQL-запросы и точные процедуры запуска в текущем диапазоне RAG **не даны**. Нельзя выдавать их за выдержку из книги.
- Для `tcpdump` в главе не приводится безопасная команда или пример фильтра. Сбор трафика может создавать чувствительные данные и занимать диск; никакой сбор здесь не предлагается.
- **State-changing инструкции:** конкретных команд для изменений нет. Эффект, верификация и rollback исполняемых действий: [Needs confirmation].
- Проверка упомянутых операций в рабочем окружении: [Needs confirmation].
