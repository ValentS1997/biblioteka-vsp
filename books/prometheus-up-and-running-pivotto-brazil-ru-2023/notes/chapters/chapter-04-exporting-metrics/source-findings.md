## F-01 — [Source code mismatch] / [Needs confirmation]: комментарий в Python-примере

## F-02 — [Source contradiction]: единицы времени OpenMetrics на PDF 96

- **RAG p0096:c01, основной абзац:** «целочисленное значение времени в миллисекундах ...» применительно к OpenMetrics.
- **RAG p0096:c01, пояснение ниже:** «В формате OpenMetrics отметки времени выражаются в секундах ... тогда как в Prometheus — в миллисекундах».
- **Там же пример:** `foo 1 1.5100992e9` (записан как число в научной нотации).
- **Проблема:** два текстовых утверждения об OpenMetrics используют разные единицы; пример также не соответствует формулировке об «целочисленном значении» в её буквальном прочтении.
- **Действие:** ни один вариант не «исправляется» внутри исходного RAG. Раздел `commands.md` атрибутирует секунды именно пояснению/сноске, но одновременно предупреждает о конфликте. Полная проверка первоисточника запрещена режимом главы: [Needs confirmation].

## F-05 — [Needs confirmation]: опасная операция очистки multiprocess state

- **RAG p0081:c01:** `export prometheus_multiproc_dir=$PWD/multiproc`, `rm -rf $prometheus_multiproc_dir`, `mkdir -p $prometheus_multiproc_dir`, запуск Gunicorn.
- **Контекст источника:** каталог должен быть пустым перед запуском и очищается при перезапуске приложения; отдельные файлы работающей/продолжающейся группы удалять небезопасно (p0081:c01, p0082:c01).
- **Оценка риска:** `rm -rf` изменяет файловую систему необратимо для обычного сценария, а конкретный путь и состояние процессов не подтверждены. Команда приведена для документирования примера **не для исполнения**.
- **Требование:** проверить каталог, владение, остановку worker, точный rollback и границы безопасности до любых операций очистки. Это эксплуатационное предостережение, а не предполагаемая ошибка в источнике.
