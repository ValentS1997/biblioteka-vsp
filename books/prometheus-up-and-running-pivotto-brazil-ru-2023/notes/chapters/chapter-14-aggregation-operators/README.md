## Принципы

1. **`without` обычно лучше сохраняет контекст для алертов.** `sum without(fstype,mountpoint)(node_filesystem_size_bytes)` сохраняет `device`, `instance`, `job` и любые другие, включая будущие `env` или `cluster`. `by` перечисляет исключительно сохраняемые метки (PDF 247–249). Использовать `by` и `without` одновременно нельзя (PDF 248).
2. **Группы образуются по меткам, а не по происхождению меток.** Для PromQL инструментированные labels и target labels равноправны; агрегаторы получают и возвращают instant vectors (PDF 246–247).
3. **Пустота — не ноль.** `sum(non_existent_metric)` и `count(non_existent_metric)` возвращают пустой мгновенный вектор, не `0` (PDF 249). `sum without()(metric)` сохраняет группы, но убирает имя; `sum by()(metric)` и `sum(metric)` сводят всё в одну группу без labels (PDF 248–249).
4. **Counter сначала нормализуется:** `sum without(device)(rate(node_disk_read_bytes_total[5m]))`. Сумма необработанных Counter зависит от времени инициализации и перезапусков (PDF 250).
5. **Операторы имеют разную форму результата.** `count` игнорирует значения и считает число рядов, `group` возвращает `1` для групп, `topk`/`bottomk` возвращают сами входные ряды с labels и `__name__`, а `count_values` вводит новую label частоты (PDF 250–257).
6. **Не усреднять готовые средние**: `avg` над агрегированными средними может дать некорректную статистику/NaN при пустом знаменателе; подход для Summary рассмотрен в главе 13 (PDF 251–252).
7. **Стоимость:** `sort_desc(count by(__name__)({__name__=~".+"}))` касается всех активных рядов; `topk(5, some_gauge)` в `query_range` может вернуть разные ряды на разных шагах (PDF 248, 254).
8. **Выбирать верную квантильную операцию:** `quantile` — по instant group; `quantile_over_time` — по значениям одной серии во временном диапазоне; `histogram_quantile` — по сегментам histogram (PDF 255).

## Замечания к source RAG

- **[Source contradiction]** PDF 246 объявляет **12** функций/операторов агрегирования; PDF 249 говорит «Все **11** операторов». По разделам главы перечислены 12 имён (считая `stddev` и `stdvar` отдельно).
- **[Source wording mismatch]** PDF 255: для `quantile(...)(0.9,...)` вывод `0.0245586`, а пояснение утверждает, что «90 % процессоров» работают в режиме system **не менее** 0.02 секунды за секунду. Направление интерпретации 90-го процентиля вызывает сомнение; сохранять исходную формулировку, не объявлять её корректной.
- **[Source mathematical issue]** PDF 252, сноска к NaN: «Это как 1/0 = NaN». Буквальное объяснение не использовать как проверенное руководство по правилам арифметики с плавающей точкой.
