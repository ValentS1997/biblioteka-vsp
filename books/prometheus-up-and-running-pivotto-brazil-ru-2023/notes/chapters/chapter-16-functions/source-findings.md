# Source findings — глава 16

**Source policy:** `rag_only`, канонический RAG `p0273:c01`–`p0293:c01`, PDF 273–293, SHA256 `ab45c7bc9a393b15bc60628dfceaa45db71388fd28e75c5c55ab6eaf5930f787`. Описание source anomalies, не внешнее исправление издания. Не изменять PDF или RAG.

## F-01 — [Source code mismatch]: не закрыт `scalar(count(...)` в примере CPU

- **RAG `p0275:c01`:** начало выражения `sum(rate(node_cpu_seconds_total{mode!="idle",instance="localhost:9090"}[5m])) / scalar(count(node_cpu_seconds_total{mode="idle",instance="localhost:9090"))`.
- **Проблема:** перед закрывающими скобками у selector отсутствует корректное завершение `}`, не закрыта внутренняя конструкция `count` / `scalar`. При буквальном копировании это **невалидный PromQL**.
- **Источник на той же PDF:** отдельное выражение `sum without(cpu,mode)(rate(...)) / count without(cpu,mode)(node_cpu_seconds_total{mode="idle"})` изложено как альтернативное вычисление по всем машинам.
- **Решение:** исходную ошибочную строку сохранить как `text`, явно неисполняемую, не подменять silent исправлением.

## F-02 — [Source wording/code mismatch]: `clip` vs `clamp`

- **RAG `p0278:c01`:** заголовок «clamp, clamp_max и clamp_min», исходный пример `clamp_min(process_open_fds,10)` и `clamp(process_open_fds,10,20)`.
- **Та же PDF, пояснение:** «`clip_max` и `clip_min` позволяют установить...».
- **Несогласованность:** речь о функциях с разными названиями. Не выбирать другой синтаксис на основании prose. В `commands.md` сохранены оригинальные выражения с `clamp*`, в регистре — обе версии.

## F-03 — [Source wording/code mismatch]: sort(size_bytes) и результат free_bytes

- **RAG `p0284:c01`:** `sort(node_filesystem_size_bytes)`.
- **Далее на той же PDF:** пять строк `node_filesystem_free_bytes{...}`, значения `5238784`, `70300672`, `817094656`, `826912768`, `30791843840`.
- **Проблема:** семейство в selector и показанный output различаются. Не использовать result как golden test именно для `size_bytes`; численные данные относятся к другому семейству.
- **Связь:** похожее различие упоминалось в главе 13, но finding самостоятельный и подтверждён исходным PDF 284.

## F-04 — [Source limitations / cross-chapter tension]: диапазон результата `rate`

- **RAG `p0292:c01`–`p0293:c01`:** `avg_over_time(rate(x_total[5m])[1h])` назван выражением, которое даст ошибку, поскольку `rate` возвращает instant vector; совет использовать `rate(x_total[1h])`.
- **RAG главы 13 `p0238:c01`–`p0239:c01`:** ранее рассмотрен синтаксис subquery `[30m:1m]`.
- **Интерпретация:** конкретное выражение без явного subquery step из главы 16 **не принимать за синтаксически исправленное**, но не распространять вывод как запрет любой композиции функций через подзапросы или правила записи. Современные runtime правила [Needs confirmation].

## F-05 — [Source version context]: число функций и `holt_winters`

- **RAG `p0273:c01`:** «в версии PromQL 2.37.0 имеется 69 функций».
- **RAG `p0291:c01`–`p0292:c01`:** `holt_winters(process_resident_memory_bytes[1h], 0.1, 0.5)` и примечание о спорном названии функции.
- **Ограничение:** число функций, имя сглаживающей функции и её доступность привязаны к контексту издания. Современная совместимость и семантика не проверялись.

## F-06 — [Source data limitation]: не хватает рисунка и runtime

- **RAG `p0288:c01`:** рис. 16.1 — сравнение графиков `rate` и `irate`. Изображение как отдельный мультимодальный объект недоступно; нельзя реконструировать конкретные кривые.
- **RAG `p0286:c01`–`p0288:c01`:** сбросы, экстраполяция и частые пропуски; в исходных чанках нет реальных ряда/TSDB для теста.
- **Решение:** Mermaid/SVG иллюстрируют текст, не воспроизводят оригинал; runtime verification [Needs confirmation].

## F-07 — [Source semantics caution]: нулевой fallback и входные данные histogram

- **RAG `p0274:c01`:** `sum(some_gauge) or vector(0)` возвращает ноль при отсутствии; это полезно для отображения, но не свидетельство здоровой цели.
- **RAG `p0283:c01`–`p0284:c01`:** `absent` обнаруживает отсутствие целей, которого не видит `up == 0`.
- **RAG `p0285:c01`:** `histogram_quantile` требует кумулятивных buckets и `+Inf`; книга признаёт исключения, когда buckets экспортируются как Gauge.
- **Решение:** не смешивать «отсутствует», «0» и «ошибка scrape», не применять `rate` к Gauge-like buckets без проверки источника.
