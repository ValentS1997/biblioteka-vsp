Глава   21
Сетевая файловая система NFS


  П ротокол сетевой файловой системы  ( Network File System , или N FS), позволяет
пользователям совместно работать с файлами, расположенными на разных компьютерах.
Протокол N FS почти прозрачен для пользователей, т.е. при сбое сервера, поддерживаю
щего протокол N FS, информация не пропадает. Клиенты просто ждут, когда сервер вновь
начнет функционировать, а затем продолжают работать так, будто ничего не произошло.
   Протокол N FS разработала компания Sun Microsystems в   1 984 году. Первоначально
протокол N FS был реализован как суррогат файловой системы для бездисковых клиентов,
однако предложенный протокол оказался столь удачным, что со временем стал универ
сальным решением проблемы совместного использования файлов. Все дистрибутивные
пакеты систем U N IX и Linux содержат версию протокола N FS; многие из них используют
лицензию компании Sun. В настоящее время протокол N FS является открытым стандар
том и описан в документах RFC (см. RFC  1 094, RFC 1983 и особенно RFC 7530).

2 1 .1 . ВВЕДЕНИЕ в ПРОТОКОЛ NFS

   Цель сетевой файловой службы - предоставить общий доступ к файлам и каталогам,
которые хранятся на дисках удаленных систем. Пользовательские приложения должны
иметь возможность читать и записывать эти файлы с помощью тех же системных вы
зовов, которые они используют для локальных файлов; файлы, хранящиеся в других
местах сети, должны быть прозрачными для приложений. Если несколько сетевых кли
ентов или приложений пытаются одновременно изменить файл, служба совместного до
ступа к файлам должна разрешать возникающие конфликты.
