Производительность версии 4
   Протокол N FSv4 был разработан для того, чтобы обеспечить высокую производи
тельность в глобальных сетях. Большинство глобальных сетей имеет более высокую за
держку и меньшую скорость передачи данных, чем локальные сети. Протокол N FS дол
жен был решить эти проблемы с помощью следующих усовершенствований.
    •  Процедура протокола RPC под названием COMPOUND включает несколько файло
     вых операций в один запрос, сокращая время ожидания при вы полнении много
     численных сетевых запросов.
    • Механизм делегирования поддерживает кеширование файлов на клиентской сто
      роне. Клиенты могут сохранять контроль над локальными копиями файлов, вклю
      чая их открытие для записи.
   Эти функциональные возможности являются частью ядра протокола N FS и не требу
ют специального внимания со стороны системного администратора.
