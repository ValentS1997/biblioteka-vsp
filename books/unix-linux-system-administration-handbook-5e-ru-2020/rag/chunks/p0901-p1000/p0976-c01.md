Создание образа DigitalOcean
   Теперь, когда файл ulsahgo готов к поставке, мы создадим образ виртуальной ма
шины для облака DigitaIOcean. Мы начинаем с простого образа Ubuntu   1 6.04, устанав
ливаем последние обновления, а затем устанавливаем программу ulвahgo. Полученный
образ становится артефактом развертывания для остальных этапов конвейера.
  m  Если вы не знакомы с упаковщиком packe r , который создает образ виртуальной
       машины, перед продолжением обратитесь к разделу 24.6.

   Упаковщик packer считывает конфигурацию своего образа из шаблона, который
имеет два основных раздела:   \ ) сборщики, которые взаимодействуют с удаленными ин
терфейсами API для создания машин и образов, и 2) вспомогательные устройства, кото
рые запускают настраиваемые этапы настройки.
   В шаблоне для нашего образа UlsahGo указан только один сборщик.
