   Использование виртуальных хостов на основе имени в сочетании с протоколом TLS
организовать довольно сложно. Сертификаты TLS выдаются для определенных имен
хостов, которые выбираются при создании сертификата. Соединение TLS должно быть
установлено до того, как веб-сервер сможет прочитать заголовок Host из НТТР-запроса,
но без этого заголовка веб-сервер не знает, каким именно виртуальным хостом он дол
жен прикинуться и, следовательно, какой сертификат выбрать.
   Решением является механизм SNI (Server Name lndication - указание имени серве
ра), с помощью которого клиент отправляет имя требуемого хоста в качестве части ис
ходного сообщения ТLS-соединения. Современные серверы и клиенты обрабатывают
расширение SN I автоматически.
