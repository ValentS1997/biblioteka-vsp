OWASP

   Open Web Application Security Project (OWASP) - это некоммерческая всемирная
организация , занимающаяся повышением безопасности прикладного программного
обеспечения. Она хорошо известна благодаря своему списку "top  1 О", посвященному
рискам веб-приложений и предназначенному для повышения бдительности разработ
чиков. Текущую версию этого списка и массу других материалов можно найти на сайте
owasp . org.
