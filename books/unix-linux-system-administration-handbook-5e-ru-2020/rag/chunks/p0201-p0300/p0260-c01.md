Регулярные выражения в языке Ruby
   В отличие от Python, язык Ruby имеет немного "синтаксического сахара" мя работы
с регулярными выражениями. Язык Ruby поддерживает традиционную /  .  .  . / нотацию
для литералов регулярных выражений, а содержимое может содержать упрамяющие по
следовательности символов # {  ) , похожие на строки с двумя кавычками.
   Кроме того, в языке Ruby определен оператор = - (и его отрицание    ! -) дЛЯ провер
ки соответствия между строкой и регулярным выражением. Он возвращает либо индекс
первого совпадения, либо n i l , если нет совпадения.
