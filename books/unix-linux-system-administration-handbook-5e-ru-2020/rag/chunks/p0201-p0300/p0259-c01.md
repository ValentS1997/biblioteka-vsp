Символы и хеши опций
   В языке Ruby ш ироко используется необычный тип данных, называемый символом
и обозначенный двоеточием, например   :  : example. О символах можно думать как о не
преложных строках. Они обычно используются как ярлыки или известные хеш-ключи.
Внутренне язык Ruby реализует их как числа, поэтому они быстро хеш ируются и срав
ниваются.
   Символы так часто используются в качестве хеш-ключей , что в версии Ruby 2.0
определили альтернативный синтаксис для хеш-литералов, чтобы уменьшить количе
ство знаков препинания. Стандартный хеш
h =    {     : anima l  =>      ' ca t  '  ,      : vegetaЫe  =>      ' carrot  '  ,      : mineral =>      ' z eolite  '    }
можно написать в стиле Ruby 2.0 следующим образом:

h =    { animal  :       ' cat  '  , vegetaЫe :       ' carrot  '  ,  mi neral :       ' zeolite  '    }

   Вне этого хеш-литерального контекста символы сохраняют свои префиксы   : везде,
где они появляются в коде. Например, вот как получить конкретные значения из хеша:

язык Ruby сdбирает завершающие аргументы вызова, которые напоминают хеш иро
