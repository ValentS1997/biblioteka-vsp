# Итог главы 14

Источник: `information-security-grodzensky-ru:p0096:c01`, PDF page 96.

В завершении главы автор сводит материал к следующим положениям:

- субъекты КИИ — организации, владеющие информационными системами/сетями/АСУ в перечисленных законом отраслях;
- для защиты КИИ необходимо определить перечень объектов;
- выполнить их categorization;
- внедрить меры защиты;
- для значимых объектов источник связывает выбор мер с Приказом ФСТЭК России №239.

Структурная нормализация выполнена без внешних сведений.
