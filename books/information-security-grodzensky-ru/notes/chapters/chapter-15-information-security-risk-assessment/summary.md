# Итог главы 15

Источник: `information-security-grodzensky-ru:p0102:c01`, PDF page 102.

В завершении главы автор подчёркивает:

- оценка рисков — базовый процесс обеспечения ИБ;
- необходимо классифицировать активы и определить их стоимость;
- требуется оценивать вероятность компрометации конфиденциальности, целостности и доступности;
- результатом должен стать реестр рисков;
- реестр используется для определения приоритетов защитных мероприятий.

Структурная нормализация выполнена без внешних сведений.
