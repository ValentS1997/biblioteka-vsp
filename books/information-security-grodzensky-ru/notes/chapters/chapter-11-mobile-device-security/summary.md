# Итог главы 11

Источник: `information-security-grodzensky-ru:p0078:c01`, PDF page 78.

В завершении главы автор подчёркивает:

- корпоративная информация давно вышла за пределы классической локальной сети;
- мобильные устройства требуют специальных мер защиты;
- EMM позволяет управлять правами пользователей и политиками на мобильных устройствах;
- корпоративную информацию можно шифровать непосредственно на устройстве;
- защищать необходимо и хранение данных, и их передачу.

Структурная нормализация выполнена без внешних сведений.
