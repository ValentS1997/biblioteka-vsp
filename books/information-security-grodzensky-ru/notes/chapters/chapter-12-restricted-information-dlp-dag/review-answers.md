# Ответы на вопросы для самопроверки — глава 12

Ответы основаны только на RAG главы 12.

## 1. Что оператор информационной системы обязан сделать для защиты информации в соответствии со 149-ФЗ?

В изложении главы оператор/обладатель должен:
1. предотвращать НСД и передачу информации лицам без права доступа;
2. своевременно обнаруживать факты НСД;
3. предупреждать неблагоприятные последствия нарушения доступа;
4. не допускать воздействий на технические средства, нарушающих их функционирование;
5. обеспечивать возможность незамедлительного восстановления информации после несанкционированного изменения/уничтожения;
6. постоянно контролировать уровень защищённости.

Provenance: `p0079:c01`, `p0080:c01`.

## 2. Какие виды DLP-систем существуют?

Глава показывает две независимые классификации.

По размещению:
- шлюзовые/network DLP;
- хостовые/endpoint DLP.

По режиму работы:
- detection;
- blocking.

Endpoint-agent нужен для каналов вроде печати, съёмных носителей и локальных приложений, которые нельзя полностью контролировать только на периметре.

Provenance: `p0081:c01`, `p0082:c01`.

## 3. Что входит в понятие «управление защитой неструктурированных данных»?

В контексте DAG это:
- согласование доступа к файловым хранилищам;
- непрерывный аудит действий пользователей;
- контроль доступа к критичным данным;
- обнаружение чувствительной информации с помощью классификатора;
- получение информации о фактических правах;
- автоматизация предоставления доступа;
- анализ изменений прав пользователей в Active Directory.

Provenance: `p0083:c01`.

## 4. Из каких шагов состоит проект по внедрению режима коммерческой тайны?

В тексте явно описаны два последовательных этапа.

Первый — обследование:
- анализ внутренних нормативных документов;
- определение шкалы ценности информации;
- методика оценки рисков;
- выявление критичных активов и их ценности;
- анализ существующих мер защиты;
- обследование сети и конфигураций ИС;
- формирование отчёта и реестра активов.

Второй — организационно-распорядительная документация:
- положение о коммерческой тайне;
- стандарт определения принадлежности активов к коммерческой тайне;
- перечень соответствующих сведений;
- изменения в трудовых договорах/должностных инструкциях;
- регламенты управления доступом;
- регистрация событий ИБ;
- действия сотрудников при утечке.

Provenance: `p0084:c01`.
