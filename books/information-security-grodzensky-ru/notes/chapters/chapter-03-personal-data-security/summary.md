# Итог главы 3

Источник: `information-security-grodzensky-ru:p0029:c01`, PDF page 29.

В завершении главы автор сводит защиту персональных данных к следующим положениям:

- потеря конфиденциальности персональных данных может иметь тяжёлые последствия;
- оператор отвечает за корректную обработку персональных данных и, когда требуется, их защиту;
- уровень защищённости определяется на основе Постановления Правительства РФ № 1119;
- конкретные меры защиты выбираются на основе Приказа ФСТЭК России № 21.

Структурная нормализация выполнена без добавления внешних сведений.
