# Ответы на вопросы для самопроверки — глава 13

Ответы основаны только на RAG главы 13.

## 1. Назовите основные угрозы безопасности АСУ ТП.

Источник перечисляет:
- эксплуатацию уязвимостей инфраструктуры с возможностью несанкционированного проникновения/подключения;
- внедрение вредоносного ПО;
- сетевые атаки и попытки вторжения;
- возможные закладки в ПО и оборудовании.

Provenance: `p0087:c01`.

## 2. Как осуществляется проект по приведению защиты АСУ ТП в соответствии с Приказом ФСТЭК России № 31?

По тексту главы последовательность такая:
1. провести классификацию АСУ по требованиям защиты информации;
2. определить угрозы безопасности и разработать модель угроз;
3. определить требования к системе защиты АСУ ТП;
4. внедрить соответствующие организационные и технические меры.

Provenance: `p0089:c01`.

## 3. Как определяется уровень значимости информации, обрабатываемой в АСУ ТП?

Уровень значимости определяется степенью возможного ущерба от нарушения конфиденциальности, целостности и доступности информации.

Источник описывает три уровня:
- УЗ1 — если хотя бы для одного свойства определена высокая степень ущерба;
- УЗ2 — при средней степени ущерба;
- УЗ3 — если для всех свойств определена низкая степень ущерба.

Если обрабатывается несколько видов информации, итоговый уровень устанавливается по наивысшему значению степени ущерба.

Связь с классом защищённости:
- УЗ1 → К1;
- УЗ2 → К2;
- УЗ3 → К3.

Provenance: `p0090:c01`.

## 4. Какие средства защиты применяются на среднем уровне АСУ ТП?

На среднем уровне, где основными элементами являются PLC, глава приводит специализированные межсетевые экраны для АСУ ТП. Они понимают промышленные протоколы, включая MODBUS, DNP3 и CIP, и используют специализированные сигнатуры вторжений.

Provenance: `p0087:c01`, `p0088:c01`.
