# Ответы на вопросы для самопроверки — глава 9

Ответы основаны только на RAG главы 9.

## 1. Чем отличаются МСЭ от прокси-серверов?

В изложении главы межсетевой экран фильтрует проходящий через него трафик по заданным правилам.

Proxy-сервер выступает посредником между пользователем и ресурсом. Он может контролировать доступ пользователей к внешним ресурсам, выполнять кэширование и другие функции; reverse proxy используется для посредничества доступа внешних пользователей к внутренним ресурсам.

Источник рассматривает firewall и proxy как взаимодополняющие, а не взаимоисключающие технологии.

Provenance: `p0060:c01`, `p0061:c01`, `p0062:c01`.

## 2. Для чего применяются «песочницы»?

Для анализа неизвестного web/mail traffic и объектов, которые недостаточно надёжно определить по известным сигнатурам.

Sandbox разворачивает вложение или открывает ссылку в эмулируемой среде и анализирует поведение. Если выявляется вредоносная активность, например попытка шифрования диска, объект не доставляется получателю.

Provenance: `p0064:c01`.

## 3. Приведите примеры применения NAC-решений.

В главе приведены следующие сценарии:
- изоляция workstation по сигналу EDR или антивируса;
- помещение неизвестного узла в карантин для vulnerability scanning и последующее предоставление доступа по результатам проверки;
- проверка наличия EMM-agent на мобильном устройстве и ограничение действий, если политика не выполнена.

Provenance: `p0065:c01`.

## 4. В чем заключается современная парадигма обеспечения ИБ?

В контексте сетевой безопасности глава говорит, что решения только по порту, протоколу и IP-адресу недостаточны.

Необходим детальный анализ приложений и пользователей, оценка связанных рисков и управление трафиком на основе такого анализа. NGFW в этой логике должен различать вредоносные и легитимные приложения независимо от формальных сетевых характеристик.

Provenance: `p0063:c01`.
