# Ответы на вопросы для самопроверки — глава 5

Ответы основаны только на RAG главы 5.

## 1. Каким образом злоумышленник может похитить информацию с помощью перехвата ПЭМИН?

Источник описывает ПЭМИН как побочные электромагнитные излучения и наводки, возникающие при работе компьютерной техники. Они сопровождают операции ввода, чтения/записи, вывода на монитор, передачу в канал связи и печать. Для перехвата используется оборудование, регистрирующее излучение, после чего сигнал обрабатывается и декодируется.

Provenance: `p0036:c01`, `p0037:c01`.

## 2. В чем разница в перехвате информации по акустическому и виброакустическому каналу?

Акустический канал использует речевой сигнал, распространяющийся по воздуху.

Виброакустический канал использует колебания строительных конструкций и инженерных коммуникаций — стен, окон, труб отопления, вентиляции и других элементов помещения.

Provenance: `p0038:c01`.

## 3. Что такое радиостетоскоп?

В главе радиостетоскоп — средство регистрации вибрационных колебаний, используемое при съёме речевой информации по виброакустическому каналу. Зарегистрированный сигнал передаётся на специальный портативный комплекс для дальнейшей обработки.

Provenance: `p0038:c01`.

## 4. Для чего проводятся специальные проверки оборудования?

Специальные проверки проводятся для выявления скрытых закладных устройств в технических средствах. Источник отдельно отличает их от специальных исследований, которые оценивают возможность утечки информации по техническим каналам.

Provenance: `p0040:c01`, `p0041:c01`.
