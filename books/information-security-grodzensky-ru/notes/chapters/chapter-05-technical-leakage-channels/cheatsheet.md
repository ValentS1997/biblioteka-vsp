# Шпаргалка: технические каналы утечки информации

Цель: определить, может ли информация покинуть защищаемую среду через физический канал, и выбрать поддерживаемую главой категорию контроля.

## Symptom / problem framing

Даже при наличии firewall, антивируса и защиты endpoints остаются каналы, не связанные напрямую с эксплуатацией ПО:

- электромагнитное излучение;
- проводные и индукционные наводки;
- звук и вибрации;
- оптические наблюдения;
- физические документы и отходы;
- закладные устройства.

## Baseline / context

### Основные группы каналов

| Группа | Что рассматривает источник |
|---|---|
| Электромагнитные | ПЭМИН при работе вычислительной техники |
| Электрические | Перехват через подключение к линиям |
| Индукционные | Съём поля вокруг линии без прямого контакта |
| Акустические | Речь, распространяемая по воздуху |
| Виброакустические | Колебания конструкций, труб, окон |
| Электроакустические | Преобразование акустики в электрические сигналы |
| Оптико-электронные | Съём речевой информации через отражённый световой сигнал |
| Параметрические | Изменение параметров электронных устройств под внешним воздействием |
| Визуальные | Наблюдение/фиксация отображаемой информации |
| Материальные | Документы, отходы, физические носители |

## Read-only checks

Глава не содержит CLI-проверок. Поддерживаемая проверочная логика:

1. Определить помещения и оборудование, где обрабатывается чувствительная информация.
2. Определить возможные электромагнитные, акустические, визуальные и материальные каналы.
3. Проверить наличие незакрытых физических интерфейсов и внешних носителей как факторов утечки.
4. Проверить, применяются ли организационные меры для документов и поведения персонала.
5. Определить, требуется ли специальная проверка оборудования.
6. Определить, требуется ли специальное исследование технических каналов.
7. Определить, требуется ли специальное обследование помещения.
8. Зафиксировать выводы и необходимые компенсирующие/защитные меры.

## Interpretation

### ПЭМИН

Источник связывает риск с побочными электромагнитными излучениями и наводками, возникающими при работе техники.

Поддерживаемые главой защитные меры:
- генерация электромагнитного шума;
- заземление;
- использование виртуальной клавиатуры в подходящих приложениях.

### Акустический vs виброакустический канал

- акустический: сигнал распространяется по воздуху;
- виброакустический: колебания передаются через конструкции помещения и инженерные коммуникации.

Для виброакустической защиты источник называет генераторы шума и системы виброзашумления.

### Визуальный и материальный канал

Требуют не только техники, но и организационных мер:
- осведомлённость персонала;
- сдерживающие меры против инсайдеров;
- уничтожение чувствительных документов шредером.

## Next action

1. Классифицировать возможный канал утечки.
2. Определить физическую среду распространения.
3. Выявить оборудование и помещения в зоне риска.
4. Проверить существующие инженерные и организационные меры.
5. При необходимости инициировать специальную проверку, исследование или обследование.
6. По результатам определить корректирующие меры.
7. При регулируемой обработке — обеспечить требуемую аттестацию/документирование по правилам источника.

## Modifying action

Примеры защитных изменений из главы:

- установка средств генерации электромагнитного шума;
- корректное заземление;
- применение виртуальной клавиатуры;
- генераторы акустического шума;
- виброзашумление;
- организационный контроль документов;
- использование шредеров;
- повышение осведомлённости персонала;
- устранение обнаруженных технических каналов или закладных устройств.

## Verification / acceptance checks

По главе результат защиты подтверждается через:

- специальные проверки оборудования;
- специальные исследования;
- специальные обследования помещений;
- сравнение измеряемых параметров с нормативными;
- выводы о наличии/отсутствии технических каналов;
- в соответствующих случаях — аттестат помещения или оборудования.
