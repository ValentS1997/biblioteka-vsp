# Средства, механизмы и проверки главы 1

В главе 1 нет shell-команд. Ниже перечислены только явно названные в RAG главы механизмы и средства, которые можно трактовать как operational tools/controls.

| Элемент | Роль в главе | Класс | Effect / риск | Verification | Rollback |
|---|---|---|---|---|---|
| Хэш-функция | Проверка целостности информации | read-only | Преобразует входные данные в значение установленной длины; используется как способ проверки целостности | Сравнение результата проверки целостности подразумевается, отдельная процедура не дана | [Not applicable] |
| DLP в режиме зеркалирования | Анализ трафика и оповещение о возможных нарушениях | read-only | Не блокирует трафик, анализирует его | Оповещение офицера безопасности | [Not applicable] |
| DLP в разрыв | Предотвращение вывода чувствительной информации | state-changing | Может блокировать часть трафика | Критерий проверки продукта в главе не задан | [Needs confirmation] |
| IDS | Обнаружение попыток вторжения | read-only | Детектирует попытки вторжения | Факт детектирования/событие | [Not applicable] |
| IPS | Предотвращение попыток вторжения | state-changing | Блокирует/предотвращает попытки вторжения | Критерий проверки продукта в главе не задан | [Needs confirmation] |
| SIEM | Ретроспективное восстановление действий при расследовании инцидента | read-only | Сбор/анализ событий безопасности для расследования | Возможность восстановить последовательность действий | [Not applicable] |
| Аудит ИБ | Проверка СУИБ на этапе Check | read-only | Проверяет состояние относительно требований и рекомендаций | Результаты аудита | [Not applicable] |
| Pen-test | Регулярная проверка СУИБ | workload-generating | Активно проверяет защищенность | Результаты теста на проникновение | [Needs confirmation] |
| Шифрование | Защита данных на компьютерах и съемных носителях | state-changing | Изменяет способ хранения/доступа к данным | Метод проверки в главе не задан | [Needs confirmation] |
| Двухфакторная аутентификация | Подтверждение личности / усиление контроля доступа | state-changing | Изменяет процесс аутентификации | Метод проверки в главе не задан | [Needs confirmation] |
| СКУД | Физическая мера контроля доступа | state-changing | Ограничивает физический доступ | Метод проверки в главе не задан | [Needs confirmation] |

## Упомянутые протоколы/атаки/механизмы

| Элемент | Контекст |
|---|---|
| RDP | Может использоваться как способ несанкционированного удаленного доступа |
| SQL-инъекция | Пример активной угрозы и нарушения достоверности/целостности |
| DDoS | Пример угрозы доступности |
| Фишинг | Социальная инженерия; требует действия получателя в приведенном примере |
| Сниффер | Пассивный сбор и анализ сетевого трафика |
| Кейлоггер | Пассивный сбор вводимых с клавиатуры данных |
| PKI / электронная подпись | Примеры механизмов неотказуемости и подлинности |

## Operational boundary

- Конкретные команды настройки DLP/IPS/SIEM/СКУД в главе отсутствуют.
- Конкретные команды ОС, сетевых устройств или средств защиты не добавлялись.
- Параметры конфигурации, vendor-specific syntax и rollback-процедуры: `[Needs confirmation]`.
