## Классификация шифров по главе

```text
шифры
├─ симметричные
│  ├─ подстановки
│  ├─ перестановки
│  ├─ блочные
│  └─ поточные
└─ асимметричные
   └─ public/private key pair
```

Важно: для `блочного` и `поточного` классов в проверенной главе нет развернутых определений.
