| Элемент | Роль | Тип | Verification |
|---|---|---|---|
| PDCA | Lifecycle СУИБ | management | Есть повторяющийся Plan/Do/Check/Act loop |
| Scope document | Границы СУИБ | governance | Критичные процессы и границы зафиксированы |
| Information Security Policy | Верхнеуровневая политика | governance | Утверждена руководством, содержит цели/commitments |
| ISMS Manual | Описание структуры/процессов | documentation | Актуальная версия и owners |
| Risk assessment | Основа выбора мер | analytical | Risks, owners, treatment, residual risk |
| Statement of Applicability | Применимость контролей | governance | Для мер указана применимость |
| Metrics/KPI | Оценка эффективности | analytical | Target/threshold, owner, frequency |
| Internal audit | Независимая проверка | assurance | Audit plan + documented results |
| Management review | Проверка руководством | governance | Зафиксированы решения руководства |
| GAP-analysis | AS-IS vs requirements | analytical | Список gaps + implementation plan |
| Corrective action | Root-cause elimination | improvement | Проверка эффективности после внедрения |
| 8D | Structured problem solving | improvement | D0–D8 выполнены по problem case |
| Ishikawa | Root-cause analysis | analytical | Причины структурированы и проверяются |
| Five Whys | Root-cause drill-down | analytical | Цепочка причин доведена до root cause |
