                      Рис. 6. Типовая схема структуры УЦ

   Заметим, что токены и смарт-карты могут служить средством двух-
факторной аутентификации, например, смарт-карты можно исполь-
зовать для прохода через турникет (если она содержит RFID-метку),
как способ подписания документов, а также для аутентификации
в локальной сети по сертификату с вводом ПИН-кода для дополни-
тельного усиления безопасности. В зависимости от стоящих задач не-
обходимо использовать разные виды электронной подписи, которая
может быть простой, усиленной, квалифицированной. При большом
количестве ЭП активно начинают использоваться HSM-устройства,
обеспечивающие полный цикл работы с ЭП, при этом необходимость
использования токенов отпадает.
