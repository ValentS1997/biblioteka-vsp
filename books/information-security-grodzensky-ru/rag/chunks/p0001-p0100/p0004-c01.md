     DOI 10.31085/9785998808456-2020-144
         This study guide is focused on information security basics. The reader will be introduced
       to the key information security notions along with the classification of information security
       practices. The book covers, among other topics, personal data protection, measures against
      unauthorized access, prevention of data leaks through technical communication channels,
       cryptographic information protection, and network security. Particular attention is given to
      information security risk assessment and ISO 27001 standard.
         This book is designed for students learning information security basics as well as for a wide
      range of readers taking interest in the information security sphere.
