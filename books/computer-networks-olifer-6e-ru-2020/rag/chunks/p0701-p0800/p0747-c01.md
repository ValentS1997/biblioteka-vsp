устройства мобильного пользователя в гостевой сети удаляется из списка записей домаш
него агента в одном из двух случаев — либо при регистрации устройства в домашней сети
по его возвращении, либо по истечении срока действия регистрации.

Мобильный IPv6

  Основное отличие версии Mobile IPv6 от версии Mobile IPv4 заключаются в том, что здесь для под
  держания мобильности нет нужды в гостевых агентах — устройство само выполняет все действия
  по поддержанию мобильности.

Мобильное устройство IPv6, присоединяясь к гостевой сети, получает при помощи про
цедуры автоконфигурации два новых 1Ру6-адреса: адрес уровня линии связи (link-local
unicast) и глобальный (global unicast) СОА-адрес. Таким образом, при нахождении в го
стевой сети мобильный узел может использовать для своего интерфейса три IPvG-адреса:
□ домашний глобальный НА,
□ гостевой глобальный СОА;
□  link-local-адрес.
