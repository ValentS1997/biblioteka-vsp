## Упомянутые технологии и сущности

Это справочные термины главы, **не команды**.

| Термин | Роль в изложении | Provenance |
|---|---|---|
| Мейнфрейм | База ранних систем пакетной обработки | `p0027:c01` |
| Модем | Средство удаленного терминального доступа через телефонные сети | `p0029:c01` |
| WAN | Хронологически первые компьютерные сети по изложению главы | `p0029:c01` |
| Коммутация пакетов | Метод, подходящий для пульсирующего компьютерного трафика | `p0030:c01` |
| X.25 | Пример ранних WAN на низкокачественных каналах | `p0030:c01` |
| ARPANET | Сеть 1969 года, названная отправной точкой развития Internet | `p0030:c01` |
| LAN | Сети на ограниченной территории, обычно принадлежащие одной организации | `p0032:c01` |
| Ethernet / Arcnet / Token Ring / Token Bus / FDDI | Стандартные LAN-технологии, закрепившиеся с середины 1980-х | `p0033:c01` |
| IP | Универсальный протокол, объединяющий разнородные подсети | `p0035:c01` |
| Frame Relay / ATM | Примеры WAN-технологий 1990-х на цифровых каналах | `p0035:c01` |
| Carrier Ethernet | Расширение Ethernet для применения в операторских/глобальных сетях | `p0035:c01` |
| MAN | Промежуточный класс между LAN и WAN для территории крупного города | `p0035:c01` |
| QoS | Методы для обслуживания разнородного трафика с различными требованиями | `p0037:c01` |
| OTN / DWDM | Примеры технологий, где коммутация каналов сохраняет применение | `p0037:c01` |
| 3G / 4G / 5G | Мобильные сети, где глава отмечает применение IP | `p0037:c01` |
| IoT | Класс встроенных устройств, самостоятельно обменивающихся данными через Интернет | `p0039:c01` |
