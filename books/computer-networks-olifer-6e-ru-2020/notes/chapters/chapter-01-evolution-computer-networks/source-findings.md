# Source findings — глава 1

Scope: `computer-networks-olifer-6e-ru-2020`, chapter 1, PDF pages 26–40.

## 1. [Source extraction issue] PDF page 36 отсутствует в addressable RAG

**Evidence**

- `rag/manifest.yaml` включает source unit **36** в `blank_source_unit_numbers`.
- В `rag/chunks/p0001-p0100/` отсутствует `p0036-c01.md`.
- Detailed contents (`p0006:c01`) указывает подраздел «Конвергенция компьютерных и телекоммуникационных сетей» с printed page 35.
- `p0035:c01` завершается незавершенным предложением о MAN.
- `p0037:c01` начинается продолжением предложения и затем переходит к пакетной передаче голоса, QoS и IP.

**Impact**

Внутри подтвержденной границы главы есть один source unit без извлеченного текста. Начальная часть подраздела о конвергенции компьютерных и телекоммуникационных сетей не может быть восстановлена из текущего RAG.

**Handling**

- Не реконструировать недостающий текст по памяти или внешним источникам.
- Артефакты используют только доступные `p0037:c01` и другие chunks.
- Любая деталь, которая могла находиться только на PDF page 36, остается `RAG_MISS`.

## 2. [Source extraction issue] числовая запись на PDF page 39

**Evidence**

`p0039:c01` содержит строку:

`1 терабайт = 1012 байт`

Такая запись может быть результатом потери типографического форматирования при extraction.

**Impact**

В текущем RAG нельзя надежно определить исходное оформление степени/индекса без обращения к canonical PDF, что запрещено режимом `rag_only` для chapter content.

**Handling**

- Не нормализовать и не «исправлять» запись.
- Не использовать эту числовую запись в cheatsheet/visuals как подтвержденный факт.
- Точное исходное форматирование: **[Needs confirmation]**.
