## Main principle

The chapter builds a network model in stages: shared resources require agreed interfaces and protocols; software services expose remote resources; physical transfer imposes signal and channel constraints; multi-node systems add topology and addressing; transit communication then requires identifying data flows, choosing paths, moving data through intermediate nodes, and sharing physical channels.
