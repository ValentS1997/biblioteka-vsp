9.21. Настройка Linux в качестве маршрутизатора
Маршрутизаторы — это просто компьютеры с несколькими физическими сетевыми
интерфейсами. Вы можете легко настроить компьютер Linux в качестве маршру
тизатора.

Рассмотрим пример. Допустим, у вас есть две подсети локальной сети, 10.23.2.0/24
и 192.168.45.0/24. Для их соединения имеется маршрутизатор Linux с тремя се
тевыми интерфейсами: два для подсетей локальной сети и один для uplink-связи
с интернетом (рис. 9.5).
