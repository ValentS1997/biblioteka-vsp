# Заключение главы 16 — §16.7 «Что дальше?»

**Источник:** `how-linux-works-brian-ward-3e-ru-2022:p0457:c01`, PDF/печатная страница **457**.

## Что подводит итог автор

- Глава охватывает только основы сборки программного обеспечения из исходного кода.
- Следующий уровень — другие build systems, в частности CMake и SCons.
- Для собственного ПО нужно выбрать систему сборки и изучить её глубже; для GNU Autoconf источник рекомендует специализированную литературу.
- Сборка ядра Linux отличается от обычных пакетов: у ядра собственная система конфигурации и сборки.
- При экспериментах с новым ядром необходимо сохранять старое ядро как recovery path на случай проблем с загрузкой.
- Полезно изучать source packages конкретного дистрибутива: они могут содержать дополнительные исправления и automation для сборки.
- Источник называет `debuild` для Debian-подобных source-package workflows и `mock` для RPM-based workflows.
- Умение собирать программы из исходников рассматривается как переход к чтению, изменению и разработке системного ПО.
