## Единственный явно названный shell-пример

```sh
ls
```

Источник: `p0035:c01`. Глава не указывает рабочий каталог, флаги или образец вывода: **[Needs confirmation]**.

## Как в книге описан запуск программы

```text
terminal / shell (user process)
        |
        | fork() — создать копию процесса
        v
child process
        |
        | exec(ls) — заменить выполняемую программу
        v
ls process
```

`exec(ls)` — обозначение из пояснения автора, **не копируемый пример кода**. Источник отдельно уточняет, что `exec()` обозначает **семейство** вызовов (`p0036:c01`).

## Не превращать в copy-paste

- `fork()`, `exec()`: C/system-call concepts, глава не содержит рабочей программы на C.
- `/dev/random`: путь псевдоустройства, не диагностическая команда.
- `syslog`: термин службы, без CLI.
- `init`, `kthreadd`, `kblockd`: упоминания процессов/потоков, не команды пользователя (`p0031:c01`, `p0035:c01`).
- Конкретные команды мониторинга процессов, управления памятью, драйверами или пользователями в границе главы не приведены.

**Operational safety:** пользовательские/административные изменения по этой главе не предписаны. Точные проверки эффекта, привилегий и rollback вне показанного `ls` — **[Needs confirmation]**.
