Заключение

В этой главе мы рассмотрели различные функции безопасности ядра Linux, кото
рые можно использовать для Docker; обсудили модули безопасности Linux -
AppArmor и SELinux, обеспечивающие обязательный контроль доступа (МАС); по
лучили представление о пространствах имен ядра, контрольных группах ( cgroup ),
capaЬilities и seccomp и научились использовать эти функции для защиты и изоля
ции контейнеров.


Основные тезисы

♦ Linux предоставляет ряд функций для защиты контейнеров.

♦ Пространства имен изолируют сегмент операционной системы для каждого кон
   тейнера.
♦ Контрольные группы (cgroups)- это механизм объединения  процессов на
   основе потребления ими ресурсов, приоритизации, стабильности и в некоторой
   степени безопасности.
♦ Начиная с версии ядра Linux 2.2 привилегии и разрешения для суперпользовате
   ля, или root, выделены в отдельный набор capaЬilities (возможностей), который

  можно включать и отключать независимо для каждого потока.
♦ Модули безопасности Linux, AppArmor и SELinux, служат в качестве промежу
   точного слоя между операционной системой и механизмами обеспечения безо
   пасности, повышая защищенность контейнеров.
♦  Secure Computing Mode (Seccomp) -  это функция ядра, которая позволяет огра
   ничить системные вызовы от контейнера.
