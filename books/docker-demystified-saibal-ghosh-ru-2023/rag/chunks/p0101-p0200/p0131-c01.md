Контейнеры могут обмениваться данными, потому что подключены к одной сети
MACVLAN, которая находится в режиме bridge (мост), по аналогии с сетевым мос
том Linux.

Теперь нас интересует, как успешно пинговать к контейнеру с хоста. Запустим
несколько команд и посмотрим, что получится (рис. 6.35).
ip link add macnetO link ethO type macvlan mode bridge
ip addr add 159. 89 . 80 .2/20 dev macnetO
ip link set macnetO up
