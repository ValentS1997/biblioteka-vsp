Client Bundle (клиентский пакет) генерирует пару ключей- закрытый (приватный)
ключ и открытый (публичный) ключ , который авторизует запросы к UCP. Имейте
в виду, что теперь мы взаимодействуем с Docker Engine не напрямую, а только
через UCP. Client Bundle также содержит набор скриптов , который настраивает
клиентские утилиты Docker CLI и Kubectl для взаимодействия с UCP.
Утилита Client Bundle автоматически обновляет переменные среды  ооскЕR_ноsт,
DOCKER СЕRТ РАТН И DOCKER TLS VERIFY.            -         -                          -       -
Переменная среды DOCKER ноsт устанавливает URL-aдpec демона Docker, а перемен
ная DOCKER_CERT_РАТН указывает, где находятся файлы ca .pem, cert .pem и key .pem, исполь
зуемые для проверки TLS. Переменная среды oocкER_TLS_VERIFY запускает проверку
TLS с помощью демона Docker, если указано любое значение, отличное от пустой
