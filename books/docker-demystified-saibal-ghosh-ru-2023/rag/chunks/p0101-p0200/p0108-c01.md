Мы видим, что можем свободно отправлять команду ping между узлами в кластере.
Теперь узнаем , как опубликовать порты при создании сервиса.

Создание сервиса с опубликованным портом
У сервисов Swarm, соединенных оверлейной сетью, нет проблем с подключением,
потому что они предоставляют друг другу свои порты. Клиент, подключающийся
к кластеру Swarm извне, будет использовать доступные порты по умолчанию , если
явно не указать, через какой порт следует подключаться. Для этого нужно опубли
ковать порты с помощью флага -р или puЫished. Поддерживается как старый син
таксис с двоеточием в качестве разделителя, так и новый -  с запятой. Более длин
ный синтаксис (полный вариант флага) предпочтительнее, поскольку это облегчает

понимание.
