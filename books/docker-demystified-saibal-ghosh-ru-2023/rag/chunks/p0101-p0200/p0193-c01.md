Установка Docker Trusted Registry
Чтобы установить Docker Trusted Registry (DTR), в UCP переходим  в Admin
Settings (Параметры администратора) 1 Docker Trusted Registry. Здесь нужно ука
зать определенную информацию. Чтобы не усложнять процесс, мы  не будем
настраивать балансировщик нагрузки, а просто вставим общедоступный IР-адрес
второго узла в поле DTR EXTERNAL URL (Внешний URL DTR) и отключим про
верку ТLS-сертификатов, установив соответствующий флажок ( см. рис. 8.14 ).
