116 ■  Глава 5

Основные тезисы
♦ Docker Swarm -  это нативное решение Docker для оркестрации и обеспечения
   высокой доступности .
♦ Docker Swarm интегрирован в экосистему Docker и использует собственный
   API.
♦ Принципы настройки и администрирования Docker Swarm интуитивно понятны .
♦ В Docker Swarm можно легко уменьшать и увеличивать количество реплик, так
   что это отличный вариант для контейнерных приложений .
♦ В Docker есть несколько встроенных средств безопасности, которые не требуют
   дополнительной настройки и сторонних инструментов.
♦ В Docker Swarm можно настраивать сеть под свои потребности, хотя конфигу
   рация по умолчанию подходит для большинства ситуаций .
♦ Docker позволяет легко и быстро развертывать и масштабировать контейнеры
  даже в очень больших кластерах.
