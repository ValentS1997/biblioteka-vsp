Docker и AppArmor
Для каждого создаваемого контейнера Docker назначается профиль AppArmor по
умолчанию. В  версиях Docker до  1.13 .О  профиль  по умолчанию  создавался
в /etc/apparmor.d/docker. Начиная с версии 1.13.0, профиль создается в tmpfs, а затем

загружается в ядро.
Профиль для Docker по умолчанию называется docker-default. Он содержит уме
ренно строгие правила и подходит для большинства приложений. Профиль docker-
default загружается в ядро вместе с другими профилями. Рассмотрим профили, ко
торые загружаются по умолчанию (см. рис. 7.30).
