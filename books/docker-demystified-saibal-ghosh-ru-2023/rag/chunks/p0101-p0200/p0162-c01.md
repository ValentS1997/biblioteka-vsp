Безопасность в Docker. Часть 1 ■  167


Здесь мы рассмотрим три наиболее распространенных флага:
1.  --cpus позволяет явно указать, сколько ресурсов ЦП будет доступно контейнеру;
  можно установить нецелое, десятичное число. Например, если у хает-компью
   тера 4 ЦП, можно указать 2,6 или 1,2 ЦП.
2.  --cpuset-cpus позволяет указать детализированные параметры в виде списка, раз
   деленного запятой, или диапазона с дефисом. Например , 0-2 будет означать ЦП
   номер О , 1 и 2, а 0,4 -  возможность использования контейнером первого и пято
   го ЦП.
3.  --cpu-shares: флаг мягкого ограничения. Если для этого флага установить значе
   ние больше 1024 (значение по умолчанию), контейнер будет иметь приоритет на
   получение ресурсов ЦП, если в системе произойдет какой-то сбой. Если устано
   вить значение меньше 1024, соответственно доступ к ресурсам ЦП уменьшится

   пропорционально.

Рассмотрим несколько примеров.

Прежде всего узнаем, сколько ЦП у нас в системе:
lscpu  I grep CPU
Затем запустим несколько команд и изучим выходные данные на рис. 7.13.
docker run -dit --name test --cpus 2.4 busybox:latest
docker run -dit --name testl --cpuset-cpus 0, 3 busybox: latest
docker run -dit --name test 2 --cpu-shares 1096 busybox: latest

Capabllities
В традиционных системах Unix есть две категории процессов.

Привилегированные процессы выполняются без проверки разрешений. Обычно эти
процессы соответствуют статусу суперпользователя , или root, и имеют uro о (иден
тификатор пользователя).
