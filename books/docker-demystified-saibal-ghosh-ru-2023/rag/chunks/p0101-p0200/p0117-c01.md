122 ■  Глава 6


                                 Рис. 6.5. Сетевая инфраструктура

К сожалению, Docker не создает пространство имен сети в расположении по умол
чанию. Но мы можем без труда узнать, где оно находится, запустив следующую
команду (рис. 6.6).
docker inspect ЬЬох --format    ' {{     . NetworkSettings.SandЬoxKey  }} '

~root@dockernet:~# docker inspect ЬЬох --format  '{{ .NetworkSettings.SandboxKey }}'
/var/run/docker/netns/a85656544fd2
root@dockernet:~# 1
                                       Рис . 6.6

Как видим , пространство имен находится в каталоге /var/run/docker/netns, а не  /var/
run/netns/. Это значит, что если мы попытаемся проверить пространство имен сети
Docker командой ip netns list, у нас ничего не получится (рис. 6.7).

                          root@dockernet:~# ip netns list
                          root@dockernet:~# 1

                                       Рис . 6.7


Обходным решением может быть создание символической ссылки с помощью не

скольких команд.

Сначала установим переменные окружения:
container id=bbox
container_netns=$(docker inspect ${container_id} --format\
 ' {{  .NetworkSettings.SandЬoxKey  }} ' )

Следующей командой создаем символическую ссылку, затем посмотрим выходные
данные на рис. 6.8.
ln -sv ${container netns} /var/run/netns/${container id}
