Сеть Overlay
Сетевой драйвер overlay соединяет несколько контейнеров по сети хоста. С по
мощью этого механизма можно построить изолированную сеть overlay, или овер
лейную сеть, поверх существующей сети на хосте.
При установке Docker оверлейная сеть не создается по умолчанию. Для этого нуж
но инициализировать Swarm или присоединить узел к Docker Swarm. Создается не
только оверлейная сеть с именем ingress, но и другая сеть -   docker_gwbridge.

   К оверлейной сети можно подключать отдельные контейнеры и сервисы Docker Swarm
    (о которых мы говорили в главе 5). Для подключения отдельных контейнеров нужно соз
   дать сеть с флагом attachaЫe.

управляющим узлом и парой рабочих, после чего проверим конфигурацию сети на
рис . 6.39.
