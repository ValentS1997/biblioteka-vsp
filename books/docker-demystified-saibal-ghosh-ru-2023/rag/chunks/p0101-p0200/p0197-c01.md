Функции безопасности
Docker Enterprise Edition
Одно из главных преимуществ Docker ЕЕ -  эффективные функции безопасности.
Лучшая из них, на мой взгляд, сканирование образов Docker на наличие уязви

мостеи.

Давайте посмотрим , как это работает. В первом примере извлечем последний образ
busybox из Docker Hub, переименуем его, отправим в Docker Trusted Registry (DTR),
а затем просканируем этот образ на наличие уязвимостей. Там не должно быть ни
каких уязвимостей, потому что это новейший образ busybox, который был проверен,

наверное, тысячи раз.

Во втором примере извлечем очень старый образ busybox (в нем должны быть какие
то уязвимости), переименуем его и тоже отправим в DTR. На этот раз может обна
ружиться несколько уязвимостей.
