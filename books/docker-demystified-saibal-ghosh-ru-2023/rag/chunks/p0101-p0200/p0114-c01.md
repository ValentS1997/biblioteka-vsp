ГЛАВА                                  6

                 Сети                      Docker


Введение

Эта глава посвящена сетям в Docker. Контейнеры Docker взаимодействуют друг
с другом посредством сетей, создаваемых при установке программного обеспече
ния Docker. По большей части программное обеспечение Docker использует воз
можности сетей Linux для сетевой инфраструктуры, которую мы подробно рас
смотрим здесь, в том числе принципы работы сетей, их различные варианты и по

тенциал.

Глава содержит несколько тем.
♦ Сети в Docker
♦ Сеть Bridge
♦ Сеть Host
♦ Сеть None

♦ Использование пространства имен существующего контейнера

♦ Сопоставление портов
♦ Сеть MACVLAN
♦ Сеть Overlay

Сети в Docker

Прежде всего узнаем, какие сети доступны на данный момент. Запустим следую
щую команду и проверим результат (рис. 6.1 ).
docker network 1s
При любой установке Docker доступны три стандартные сети. Если установлен
Docker Swarm, сетей будет больше, но об этом мы поговорим чуть позже .
