158 ■  Глава 7

Docker имеет свой фрагмент операциоююй системы , что позволяет запускать сот
ни контейнеров на одном хосте без конфликтов на уровне ОС. Например, контей
неры могут использовать один порт или один набор файлов конфигурации без
каких-либо проблем. Это возможно благодаря изоляции, которую предоставляют
пространства имен. Docker на Linux использует следующий набор пространств

имен ядра:
♦ PID (ID процессов);
♦ NET (сети);
♦ MNT (файловые системы / точки монтирования) ;
♦ IPC (межпроцессное взаимодействие);
♦ USR (пользователи) ;
♦ UTS (хосты).
PID, т. е. process  id: идентификатор процесса. Уникальный идентификационный
номер для процесса автоматически генерируется при запуске в системе Linux.
Docker использует пространство имен PID для создания отдельного дерева процес
сов для каждого контейнера.

Давайте создадим пару контейнеров и посмотрим, как это работает. Это будут кон
тейнеры для базы данных Couchbase (база данных класса NoSQL для критически
важных бизнес-приложений). Затем заглянем внутрь и посмотрим, как выполняют
ся процессы. Итак, создаем контейнеры и изучаем выходные данные на рис. 7.1.
