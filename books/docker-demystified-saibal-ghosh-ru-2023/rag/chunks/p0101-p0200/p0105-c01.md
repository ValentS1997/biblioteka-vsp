Создадим оверлейную сеть и посмотрим , что получится (рис. 5.29).
docker network create --driver overlay new_overlay


                                             Рис. 5.29

Итак, у нас есть новая оверлейная сеть с именем new_overlay. Нам не нужно отдельно
создавать сеть на рабочих узлах, она будет распространена на них автоматически.
Правда, она не существует, пока мы не создадим сервис и не свяжем его с новой
сетью. Проверим сети на одном из рабочих узлов. См. команду ниже и рис. 5.30.
docker network 1s
