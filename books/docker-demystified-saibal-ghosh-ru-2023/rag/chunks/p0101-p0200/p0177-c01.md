После включения SELinux в системе нужно выполнить systemctl  restart docker для
перезапуска Docker, потому что это не произойдет автоматически.
Выполнив команду docker  info, мы получаем предупреждение. Здесь не о чем вол
новаться -  это можно легко исправить, как видно на рис . 7.39.

Нужно просто внести изменения в файл /etc/sysctl.conf, добавив следующие строки:
net.bridge . bridge-nf-call-ipбtaЬles = 1
net . bridge.bridge-nf -call-iptaЫes = 1

Затем нужно запустить команду sysctl  -р, чтобы изменения вступили в силу. Те
перь docker info выдает выходные данные без каких-либо предупреждений. Однако
SELinux не включен в демоне Docker по умолчанию. Это нужно сделать явно. Если
мы проверим Docker, то увидим, что SELinux не включен; записи для SELinux
отсутствуют (см. рис. 7.40).
docker info --format    ' {{ .SecurityOptions}} '
