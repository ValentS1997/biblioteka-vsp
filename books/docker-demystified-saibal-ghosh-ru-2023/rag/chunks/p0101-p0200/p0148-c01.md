Сети Docker ■  153

Это подтверждает наше предположение о том, что для каждого созданного кон
тейнера в пространстве имен оверлейной сети будет запись для сопоставления
IР-адреса с МАС-адресом.


Основные тезисы

♦ В Docker есть три сети по умолчанию: Bridge, Host и None.
♦ При установке Docker Swarm мы получаем еще две сети: оверлейную сеть
    ingress и сетевой мост docker_gwbridge.
♦ Сетевой мост Docker по умолчанию основан на мосте Linux и называется ctockero.

♦ Контейнер может коммуницировать с внешним миром напрямую , но получить
   доступ к Docker извне можно только через интерфейс хоста -  обычно это ethO.

♦ Порт на сервере можно легко сопоставить с контейнером, но этот порт на хосте
   нельзя сопоставить с другим контейнером.
♦ Сопоставлять порты можно по протоколу ТСР или UDP.
♦ Если мы используем сеть Host, контейнер сопоставляется с сетью хоста, а собст-
   венной сети у него нет.
♦ Для полной изоляции контейнера от внешнего мира используется сеть None.
♦ Для подключения приложения к физической сети используется сеть MACVLAN.
♦ Docker Swarm использует оверлейную сеть ingress для связи с другими кон
   тейнерами, тогда как обмен данными с внешним миром реализуется через
   docker_gwbri dge.
