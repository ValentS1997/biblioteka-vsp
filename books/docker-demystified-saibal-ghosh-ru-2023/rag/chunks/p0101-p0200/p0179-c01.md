Теперь в контейнере есть метки, потому что мы включили SELinux в системе,
и Docker его использует. Мы видим, что метки представлены в виде списка с разде
лителем двоеточием в формате «пользователь SELinux: роль SELinux: тип : уровень
конфиденциальности: уникальная категория».

Попробуем разобраться, что все это означает. Когда мы создаем контейнер с вклю
ченным SELinux, SELinux помечает его, указывая пользователя, роль, тип, уровень
конфиденциальности и набор из двух случайных чисел от О до 1023, которые долж
ны быть уникальными. Эти числа имеют префикс «с» , что означает «категория»
( category); SELinux использует уровень конфиденциальности  sO. Этот механизм
называется мультикатегорийной безопасностью (Multi-Category Security, MCS). На
рис. 7.45 приводится таблица преобразования мультикатегорийной безопасности
(MCS) для SELinux.
cat /etc/selinux/targeted/setrans .conf

Из этой таблицы мы можем почерпнуть полезную информацию об использовании
механизма мультикатегорийной безопасности. Но в общем мы можем применять
любой механизм разделения объектов на категории, как показано на рис. 7.46.
docker run -dit --name max --security-opt laЬel=level:s0:cO,cЗ busybox
docker container 1s -а
docker inspect <id_контейнера>  1 grep "LaЬe l"

Такой подход помогает разделить контейнеры для обеспечения дополнительной
безопасности. Разделение посредством SELinux позволяет, например, защитить
процесс и содержимое одного контейнера от атак со стороны процесса другого
контейнера.
