Теперь попробуем отправить ping со второго контейнера на первый и наоборот,
и посмотрим , что получится (рис. 6.13).
ping 172.17.0.2
exit
docker ехес -it mybox sh
ping 172 .17.0. 3
Все работает, как и ожидалось. Но если мы попытаемся отправить ping к другому
контейнеру, используя его имя, у нас ничего не получится (рис. 6.14).
Интересный момент: если мы создадим собственную сеть bridge и соединим ее
с контейнерами, мы сможем отправлять ping от одного контейнера к другому,
используя их имена. В этом можно убедиться на примере ниже (рис. 6.15).
docker network create -d bridge mybridge
docker network 1s
docker run -dit --name mуЬохЗ --net mybridge busybox:latest
docker run -dit --name mybox4 --net mybridge busybox:latest
docker ехес -it mуЬохЗ sh
ping mybox4
