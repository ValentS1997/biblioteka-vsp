Мы видим, что у контейнера нет меток. А, как нам известно, система меток -  это
ключевой компонент SELinux.
Давайте включим SELinux в Docker: изменим файл /etc/docker/daemon.json и добавим
следующие строки; или, если файл daemon.json по этому пути отсутствует, созда

дим его, введем следующее:

    "selinux-enaЫed" : true

После внесения изменений нужно перезапустить Docker командой systemctl restart
docker, чтобы изменения вступили в силу. Мы видим, что в параметры безопасности
(SecurityOptions) добавлена запись name=selinux (рис. 7.42).

        root@dockercentos ~]# systemctl  restart docker
        root@dockercentos ~]# docker info --format  '{{.SecurityOptions}}'
        name=seccomp,profile=default name=selinux]
        root@dockercentos ~]# 1
