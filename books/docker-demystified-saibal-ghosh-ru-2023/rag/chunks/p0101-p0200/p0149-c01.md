7. При использовании пространства имен существующего контейнера ...
    • У нового контейнера не будет собственной файловой системы .
    • У нового контейнера не будет ни собственной сети, ни собственной файловой

     системы.
    •  Два контейнера могут иметь отдельные порты.
    • У нового контейнера будет своя файловая система, но общий сетевой стек
      с существующим контейнером.

    •  Ничего из вышеперечисленного.
