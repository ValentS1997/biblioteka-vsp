Введение

Средства безопасности Docker можно разделить на две категории: функции безо
пасности Linux (в этой книге мы рассматриваем Docker на Linux, поэтому подробно
обсудим безопасность на уровне этой операционной системы) и встроенные (собст
венные) средства безопасности для контейнеров Docker, предоставляемые Docker
Enterprise Edition. Теме безопасности посвящены две главы; здесь мы рассмотрим
соответствующие функции Linux.

Изучив эту главу, вы будете свободно ориентироваться в функциях безопасности
Linux и научитесь использовать их для защиты экосистемы контейнеров Docker.
Также вы научитесь принимать взвешенные решения относительно конфигураций
безопасности и эффективно использовать встроенные средства безопасности ОС
Linux.
