Также проверим версию Docker следующей командой (выходные данные  -   на
рис. 8.7):
docker version
Отлично , мы сделали это! У становили Docker Enterprise Edition на первом сервере,
который будет нашим управляющим узлом. Теперь установим Docker Enterprise
Edition на другом узле, выполнив те же самые действия.
После установки Docker Enterprise Edition на обоих узлах мы установим UCP на
первом узле, присоединим оба узла к кластеру Swarm и установим DTR на втором

узле.

Установка Universal Control Plane
Docker Universal Control Plane (UCP)- это решение корпоративного уровня для

централизованного управления кластерами и приложениями.
Для установки UCP потребуется 16 Гбайт оперативной памяти , 4 виртуальных ЦП
и 25-100 Гбайт свободного пространства на диске.
Версия Docker Engine Enterprise должна быть 19.03, а версия ядра Linux -  не ни
же 3 .1 О; узел должен иметь статический IР-адрес.
Проверим IР-адрес следующей командой и посмотрим результаты на рис. 8.8.

Теперь извлекаем последнюю версию UCP:
docker image pull docker/ucp:latest
И устанавливаем UCP:
docker container run --rm -it --name ucp  \
   -v /var/run/docker .sock:/var/run/docker.sock  \
   docker/ucp:latest install  \
   --host-address 178.128.229 .120  \
   --interactive

Во время установки нужно указать имя пользователя и пароль администратора. Мы
укажем имя  пользователя  admin. Мы  не вводили значение SAN (Storage Area
Network- сеть хранения данных), а просто нажали <Enter>, чтобы двигаться

дальше.
