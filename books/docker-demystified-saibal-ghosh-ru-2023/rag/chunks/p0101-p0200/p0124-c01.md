Как видим, приложение nginx доступно через порт 80 в контейнере, и флагом -Р
этот порт был рандомно сопоставлен с портом 32778 на хосте . Флаг -Р случайным
образом сопоставляет порт контейнера с портом на хосте. Давайте проверим, все ли
работает, запустив следующую команду (выходные данные на рис . 6.23).
curl  l ocalhost:32778
Теперь сопоставим порт на хосте с портом в контейнере (рис. 6.24).
docker run -dit --name test2 -р 8080:80 nginx:latest

Порты в контейнерах можно легко сопоставить с доступными портами на хосте.
Более того, можно указать протоколы. Например , порт 80 контейнера можно сопос
тавить с портом 8081 для протоколов ТСР и UDP. Рассмотрим пример (рис. 6.25).
docker run -dit --name testЗ -р 8081:80/tcp -р 8081:80/udp nginx:latest
