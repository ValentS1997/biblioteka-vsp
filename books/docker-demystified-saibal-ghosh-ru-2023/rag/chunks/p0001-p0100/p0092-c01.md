docker node  l s предоставляет список узлов в кластере Swarm. Эта команда не может
быть выполнена с рабочих узлов. Узел , с которого она была выполнена, отмечен
звездочкой(*) рядом с ID. В столбце MANAGER STATUS (статус управляющего
узла) указано LEADER (лидер), -   это означает, что управляющий узел сейчас
активен. Если в Swarm несколько управляющих узлов, активным в тот или иной
момент времени может быть только один из них. Для рабочих узлов в столбце
MANAGER STATUS ничего не указано, потому что это не управляющие узлы.
Запустим еще одну команду и подробно изучим управляющий узел:

root@mgr:~# docker node inspect self
