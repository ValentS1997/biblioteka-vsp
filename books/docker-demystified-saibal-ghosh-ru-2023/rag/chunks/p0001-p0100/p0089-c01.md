94 ■  Глава 5

Весь процесс автоматизирован; Swarm может перенаправлять запрос от клиента
в кластер Swarm. Когда кластер Swarm получает запрос, он берет на себя управле
ние приложением. Начиная с версии 1.12, в Docker есть встроенный режим Swarm
для управления кластером Docker Engine. Для создания кластера Swarm, разверты

вания  в нем сервисов приложения и управления его поведением используется
Docker CLI.

Преимущества Docker Swarm
Docker Swarm имеет ряд весьма интересных преимуществ.
1. Объявление :J1селаемого состояния. Мы можем объявить, чт6 именно хотим по
   лучить. Например, Docker Engine позволяет определить количество требуемых
   реплик приложения , его структуру и пр. Можно указать, что нам нужен фронт
   енд, база данных бэкенд и т. д.
2. Масштабирование. Docker Swarm позволяет легко менять масштаб встроенны
  ми средствами. Мы можем увеличить число реплик приложения, если вырос
   спрос, а потом так же легко уменьшить масштаб при необходимости.
3. Отсутствие отдельного оркестратора. При использовании Docker Swarm не
   требуется стороннее программное обеспечение для оркестрации. У правление
   кластерами уже интегрировано с Docker Engine.
4. Поддержание желаемого состояния. Управляющий узел Swarm непрерывно от
   слеживает кластер и вносит исправления, если фактическое состояние отличает
   ся от желаемого. Допустим, мы указали, что нам требуются пять реплик, но из
   за сбоя оборудования одна из реплик становится недоступной. В этом случае
   Docker Swarm создаст недостающую реплику на рабочем узле.
5. Сеть с несколькими хостами. Docker Swarm предоставляет для наших сер висов
   готовую оверлейную  сеть. Адреса автоматически назначаются контейнерам
   в оверлейной сети при запуске, изменении или обновлении приложения.
6. Обнаружение сервисов. В Swarm есть DNS-cepвep , который используется для
   предоставления  идентификатора каждому  сервису, запущенному  в  Swarm.
  Управляющий узел Swarm также отвечает за балансировку нагрузки для контей

   неров, защищая их от перегрузки .
7. Встроенные  средства  безопасности.  Docker Swarm  использует взаимную
   аутентификацию TLS (Transport Layer Security -  протокол защиты транспортно
   го уровня) и шифрование для безопасного обмена данными между узлами.
8. Последовательные обновления. Очень интересная особенность Docker Swarm.
   Сервисные обновления можно применять не ко всем узлам сразу, а постепенно,
   по группам узлов . Если что-то пойдет не так, можно легко откатить обновление
   без масштабных последствий.
