Реплицированные и глобальные сервисы
В Docker Swarm есть два типа сервисов: реплицированные (replicated) и глобальные
(global). Для реплицированных сервисов нужно указать число реплик, и управляю
щий узел Swarm сам распределит реплики по другим узлам. Если это глобальный
сервис , управляющий узел Swarm размещает по одной задаче на каждом доступном
узле, учитывая требования к ресурсам и другие ограничения. Если в кластер добав
ляется узел и работает глобальный сервис, на новом узле создается реплика этого

сервиса.

redis :latest
docker service ps replicated
