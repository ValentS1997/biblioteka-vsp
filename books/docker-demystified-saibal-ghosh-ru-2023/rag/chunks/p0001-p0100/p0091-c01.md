Проанализируем команду, которую мы только что применили.
docker swarm i nit велит Docker инициализировать Swarm.
--adverti se- addr относится к IР-адресу и порту, через который другие узлы будут
подключаться к управляющему узлу. Эту часть можно пропустить, потому что по
умолчанию Docker выберет IР-адрес, доступный на ethO.
--listen-addr -  это IР-адрес и порт, который мы хотим назначить для прослушива
ния трафика Swarm. Обычно он совпадает с --advertise-addr, кроме случаев, когда
мы предполагаем использовать разные IР-адреса для соединения и прослушивания.
Обратите внимание: на рис. 5.2 можно видеть ключ токена для добавления рабоче
го узла в Swarm. Он также предоставляет команду для добавления управляющего
узла и дает указание следовать инструкциям. Получить токен для управляющего
или рабочего узла можно следующими командами:
docker swarm join- token manager
docker swarm join- token worker
Давайте присоединим к этому Swarm пару рабочих узлов. Сначала войдем на рабо
чий узел 1 и присоединим его к Swarm, а затем сделаем то же самое с рабочим
узлом 2. Как видите, все довольно просто (рис. 5.3).
