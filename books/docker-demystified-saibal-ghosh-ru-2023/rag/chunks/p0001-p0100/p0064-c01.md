Слои, которые находятся над самым нижним, будут содержать файл с именем lower,
где указан родительский слой, каталог diff с содержимым , а также каталог work,

единено все содержимое.

Тома Docker

Если записывать данные только на слой чтения и записи в контейнере , может воз
никнуть несколько проблем. Во-первых, и это основная проблема, данные не
сохранятся после удаления контейнера. Во-вторых, поскольку слой записи исполь
зует драйвер хранилища для реализации объединенной файловой системы, работо
способность контейнера может снижаться. В-третьих, слой записи так тесно связан
с самим контейнером, что управлять данными будет весьма непросто . Наконец,
контейнеры быстро потеряют свою легкость и гибкость, если записывать в них все

данные.

Тома предназначены для постоянного хранения данных. Для записи данных боль
шого объема лучше использовать тома, а также механизмы Ыпd mount (монтирова
ние каталогов с хоста) и tmpfs (temporary file system -  временная файловая систе
ма). Схема хранения данных представлена на рис . 3.10.
