Исследование образа и получение информации

Мы можем извлечь очень много полезной информации с помощью команды docker
image inspect <id_ образа> . Правда, читать эту информацию будет непросто. Для фор
матирования выходных данных можно использовать  j q -  легкую и гибкую утили
ту для обработки JSON  в командной строке. Выходные данные мы получаем
в формате JSON, поэтому можем использовать jq как для получения общего пред
ставления о результатах, так и для выбора наиболее интересных деталей. Загружа
ем инструмент командой apt  i nstall  j q.

Сохранение образа

Образ можно сохранить как tаr-файл. Запускаем следующие команды и изучаем
результат на рис. 2.32.
docker image pull ngi nx:latest
docker image 1s
docker image save 4392e5dad77d > mynginx.tar
1s -ltr
1s -sh myngi nx.tar

Можно добавить флаг --output, чтобы создать резервную копию и при необходимо
сти использовать ее при загрузке Docker·.
Запускаем команду и изучаем результат на рис. 2.33:
docker save --output myngi nx.tar nginx
