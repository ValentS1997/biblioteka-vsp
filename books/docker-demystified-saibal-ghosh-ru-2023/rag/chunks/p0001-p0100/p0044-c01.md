48 ■  Глава 2

Копия создается только для того, чтобы добавить или изменить данные в образе.
У всех остальных процессов остается доступ к исходным данным.

Если контейнер хочет внести изменения в определенный слой образа, этот слой ко
пируется на слой чтения и записи . Docker использует механизм копирования при
записи для образов и для контейнеров. Изменения между образами или запущен
ными контейнерами отслеживаются с помощью драйверов хранилища, таких как
aufs или OverlayFS, или инструментов, называемых снапшотами (snapshotters),
предназначенных для создания моментальных снимков ( о сохраняемости данных мы
поговорим в следующей главе).

Где хранятся образы?

хранилища>. Слои хранятся как каталоги . Рассмотрим пример.
Запустим команду docker info, чтобы узнать, какой драйвер хранилища мы исполь
