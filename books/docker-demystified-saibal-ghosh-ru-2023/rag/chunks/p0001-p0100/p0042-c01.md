46 ■  Глава 2

   Образ Docker больше не создается на основе родительского образа. Теперь для компи
   ляции образа Docker Engine использует список контрольных сумм слоев в определенном
   порядке.

Итак, образ теперь состоит из объекта конфигурации, представляющего собой
набор дайджестов (контрольных сумм) SНА в определенном порядке, с помощью
которых Docker Engine может генерировать файловую систему для контейнера,
создаваемого на основе этого образа (см. рис. 2.25).
