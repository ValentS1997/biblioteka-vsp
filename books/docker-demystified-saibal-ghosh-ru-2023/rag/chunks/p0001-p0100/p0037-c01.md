Контейнеры и образы ■  41


Рассмотрим несколько команд для управления журналами. Создадим отдельный
контейнер test_logs, который будет каждые 10 секунд выводить дату и время. Затем

с помощью различных команд просмотрим журнальные записи в зависимости от
того, что мы хотим узнать. Запустим набор команд:
docker run --name test_logs -dit alpine :latest sh -с\
"while true; do $(echo time) sleep 10; done"
docker ps
docker logs b0c4ee4a7b9f

Можно использовать флаг -follow (букв . : следовать) или - f, чтобы отслеживать все

новые журнальные записи , как в следующем примере:
docker logs b0c4ee4a7b9f -fol low
