Модель Container Network и сетевой мост Docker ■  83
Libnetwork
Libnetwork -   это реализация Container Network Model, библиотека для создания
сетевых стеков и управления ими. Libnetwork можно назвать попыткой стандарти
зировать интерфейсы для подключения демона Docker к сетевым драйверам.

Драйверы Docker
Драйверы Docker могут быть двух категорий:

♦ собственные (встроенные) сетевые драйверы;

♦ сторонние (внешние) сетевые драйверы.
Собственные (встроенные) сетевые драйверы Docker  являются частью Docker
Engine. Ими можно управлять с помощью стандартных команд Docker; дополни
тельная конфигурация не требуется.
В табл. 4.1 приведены названия и краткие описания драйверов
Сторонние (внешние) драйверы Docker совместимы с CNM и могут подключаться
к хосту Docker как плагины. Самые популярные сторонние драйверы -   Contiv
и Weave.
Информация о драйверах обобщена на рис. 4.2.
