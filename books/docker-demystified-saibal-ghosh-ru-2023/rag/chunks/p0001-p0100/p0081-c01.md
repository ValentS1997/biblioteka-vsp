86 ■  Глава 4


                                    Ядро Linux
                             Рис. 4.6. Передача данных через пару veth

Теперь создадим пару veth с помощью следующих команд:
ip link add vethO type veth peer name vethl
ip link  l ist  I grep veth
И получим выходные данные (рис. 4. 7).


                                             Рис. 4.7

Как видите , пара veth создана, но пока не прикреплена к созданным ранее про
странствам имен. Сделаем это следующим образом (рис. 4.8):
ip link set vethO netns mynetspace
ip link set vethl netns mynetspacel

         root@dockernet:~# ip link set vethO netns mynetspace
         root@dockernet:~# ip link set vethl nets mynetspacel              -                        .  .          ..  .      ..     .      .   -  .                        ..            ..     .                .
