Драйверы хранилища и тома ■  75

Стоит отметить, что флаг -v или --volume использовался только для сервисов Swarm
до Docker 17.06. С версии 17.06 можно использовать также флаг --mount для отдель
ных контейнеров. Поскольку флаг --mount проще понимать и применять, я рекомен

дую именно его.

Рассмотрим пример использования --mount.
На этот раз не будем создавать том заранее, пусть Docker сделает это «на лету», -

у него есть такая возможность.
Запустим следующую команду и изучим выходные данные на рис. 3 .21.
docker  run  -dit  --name  mynginx  --mount  source=myvol2, target=/test nginx :latest
docker ps
docker inspect -f    ' {{ json .Mounts  }} '  af28f181a46d   I jq


                                      Рис . 3.21


Существует еще один механизм сохранения файлов за пределами слоя чтения и за
писи контейнера -   tmpfs. Файлы создаются в памяти хост-системы, а не на слое
записи контейнера. В отличие от Ьind mount и томов, tmpfs монтируется временно и
существует, только пока контейнер запущен. Когда контейнер останавливается,
tmpfs удаляется, следовательно, сохраняемости файлов нет.
Рассмотрим пример использования tmpfs: выполним следующие команды и изучим
выходные данные на рис. 3.22.
docker run -it --name test_tmpfs --mount type=tmpfs, destination=/testing centos:latest
1s

Нужно явно указать тип tmpfs, но в остальном команда должна быть вам знакомой.
Итак,  - tmpfs предоставляет временное хранилище за пределами слоя записи и чте
ния контейнера. Этот вариант имеет ограниченные возможности, но может приго

диться в некоторых случаях.
