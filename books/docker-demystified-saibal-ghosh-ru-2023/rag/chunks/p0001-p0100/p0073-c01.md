Драйверы хранилища и тома ■  77


♦ Для постоянного хранения данных в системе используются тома и механизм
   bind mount, поскольку контейнеры временны , можно сказать , «эфемерны» по
   своей природе и могут сменять друг друга в любое время. При этом мы, естест

   венно, не хотим терять данные, сохраненные в хост-системе .
♦ Механизм tmpfs позволяет записывать данные за пределами контейнера, в памя

   ти хоста.
♦ При использовании tmpfs данные не хранятся постоянно. Когда контейнер оста
   навливается, tmpfs удаляется , и файлы, записанные там, становятся недоступ

   ными.

Контрольный тест

Выберите подходящий вариант ответа.
1. Для каких рабочих нагрузок подходит слой чтения и записи в контейнере:
    •  С интенсивной записью.
    •  С интенсивным чтением.
    •  С небольшим объемом данных.
    •  Ничего из вышеперечисленного.
2. Драйвер хранилища -  это программное обеспечение, которое ...
    •  Создает образы.
    •  Создает контейнеры .
    •  Записывает данные на слой контейнера только для чтения.
    •  Записывает данные на слой контейнера для чтения и записи.
3. Механизм tmpfs позволяет ...
    •  Хранить данные в контейнере.
    •  Хранить данные в томе.
    •  Хранить данные в памяти системы.
    •  Хранить данные в хранилище системы .
4. При использовании механизма Ьind mount ...
    •  Файл или каталог в хост-системе монтируется в контейнер.
    •  Файл или каталог из области Docker монтируется в контейнер.
    •  Файл или каталог из хост-системы сопоставляется с памятью контейнера.
    •  Файловая система хоста и контейнер никак не связаны.
5. Тома поддерживают использование драйверов томов, которые позволяют ...
    •  Хранить данные на диске хост-компьютера.
    •  Хранить данные в файловой системе контейнера.
