Давайте рассмотрим пример сохранения данных в части хост-системы , определяе
мой как область Docker. Здесь мы укажем только целевой каталог, т. е. каталог
в контейнере, а исходный каталог нам предоставит Docker ( см. рис. 3 .17). Факти
чески мы создадим анонимный том.
docker run -dit --name test vol --volume /myapp alpine :latest
docker container ls -а
