Журналы контейнеров

В ходе выполнения контейнеров создается информация , которая регистрируется
в журнале Docker или журнале сервиса Docker (подробнее о сервисах мы будем
говорить в главе 5). Информация из журналов отображается в терминале. Linux
по умолчанию выводит данные в терминал (sтооuт); для сообщений об ошибках ис
пользуется STDERR.

Иногда для получения полезной информации из журналов требуется дополнитель
ная конфигурация . Например, если наш драйвер журналирования (логгирования)
отправляет журналы, например , в файл, а не в стандартный поток sтооuт или STDERR,
то маловероятно, что в журналах Docker по умолчанию мы найдем полезную ин
формацию.

Прежде чем двигаться дальше, нужно понять , что такое драйверы журналирования
(или логирования). Драйверы журналирования -   это программное обеспечение,
которое помогает собирать информацию о запущенных контейнерах и сервисах.
У демона Docker есть драйвер журналирования по умолчанию, но мы можем ука
зать другой драйвер, и с этого момента контейнер будет использовать именно его.
Драйвер журналирования по умолчанию -   json- file.

Запустим следующую команду, чтобы узнать, какой драйвер журналирования
выбран в нашей системе.
docker info --format    ' {{.LoggingDriver}}'
Получаем выходные данные (рис. 2.14 ).

                                     -
       root@mydocker:~# docker info --format '{{.LoggingDriver}}'
      json-file
       root@mydocker:~# 1
                                             Рис. 2.14

Docker поддерживает разные драйверы журналирования , и мы можем указать же
лаемый  драйвер,  изменив  соответствующий  параметр  в  файле  /etc/docker/
daemon.json, а затем перезапустив демон Docker.
