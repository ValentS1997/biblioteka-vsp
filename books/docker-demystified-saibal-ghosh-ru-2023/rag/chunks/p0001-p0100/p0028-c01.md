Запуск контейнера

Давайте перейдем к практике и запустим наш первый контейнер. Сначала нужно
убедиться, что в вашей системе установлен Docker. Самый простой способ сделать
это -  проверить версию Docker:
docker --version

или:
docker -v
Если Docker не установлен, вы увидите примерно следующие выходные данные
(рис. 2.1).

                root@my-docker:~# docker --version
                Command 'docker' not found,  but сап Ье installed with:
                 snap install docker      # version 19.03.8, or
                 apt  install docker.io
                 See 'snap info docker'  fог additional versions.
                root@my-docker:~# 1
                                       Рис . 2.1

Если же Docker установлен, выходные данные будут выглядеть так, как на рис. 2.2.
Как видим , в этом примере установлен Docker version 19. 03. 9.

                                                  -                      .
                        root@my-docker:~# docker --version
                        Docker version 19.03.9, build 9d988398e7
                        root@my-docker:~# docker -v
                        Docker version 19.03.9, build 9d988398e7
                        root@my-docker:~# 1
                                       Рис . 2.2

теме. В этом примере мы создаем контейнер busybox и запускаем его в системе.
вusувох -    это  комплект  программного  обеспечения,  который  предоставляет

следующей командой:
docker run --name my_first_container busybox: latest
