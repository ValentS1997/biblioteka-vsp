Если контейнер выполнил свою задачу и завершил работу, он имеет состояние
Exited (завершил работу). Для дальнейшего использования нужно перезапустить
его вручную. Допустим , мы создаем контейнер Busybox для выполнения одной зада
чи -  шесть раз отправить ping (пинг) к localhost (локальный хост). Мы не будем
запускать этот контейнер в фоновом режиме, поскольку хотим посмотреть выход
ные данные в терминале. Запустим в хает-системе следующую команду:
docker run -it --name my_containerl busybox:latest pi ng -с 6 localhost
