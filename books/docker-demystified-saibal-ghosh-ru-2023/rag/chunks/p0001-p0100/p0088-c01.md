ГЛАВА                                 5
                Docker Swarm


                                                                                                          https://t.me/it_boooks/2
Введение

При большом количестве контейнеров необходим инструмент, который обеспечит
их гармоничное взаимодействие. Docker Swarm -  именно такой инструмент, кото
рый предоставляет для Docker нативную технологию кластеризации. Docker Swarm,
иначе называемый режимом Swarm, -   это встроенная в Docker поддержка для
оркестрации кластеров Docker Engine, которая позволяет управлять всеми контей

нерами как единым целым.

Из этой главы вы узнаете больше об оркестрации контейнеров, осуществляемой
с помощью встроенного в Docker механизма кластеризации Docker Swarm. Мы
рассмотрим, как настроить Docker Swarm и обеспечить с его помощью высокую
доступность  и  безопасное,  надежное  и  оптимизированное  функционирование
ваших приложений.

Что такое Docker Swarm
Docker Swarm -  это платформа для развертывания приложений на нескольких хос
тах с помощью многофункционального API, который упрощает развертывание
сложных приложений. Обычно приложения записываются в файл манифеста, кото
рый можно легко развернуть в кластер с помощью собственных команд Docker.
