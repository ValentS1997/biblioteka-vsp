ГЛАВА                                 4

      Модель               Container Network
         и сетевой мост                      Docker


В этой главе рассматриваются концепция сетей в Docker и принципы реализации
сетей в реальных развертываниях. Вы получите представление о сетевом стеке
Docker и о том, как создать надежную и высокопроизводительную сетевую инфра

структуру.
Сети Docker ориентированы на приложения. С одной стороны , они обеспечивают
все необходимое для нормального функционирования, с другой -  предоставляют
достаточный уровень абстракции, чтобы не усложнять жизнь разработчикам.

Глава включает следующие темы.
♦ Модель Container Network (Container Network Model, CNM)

♦ Интерфейсы драйвера СNМ
♦ Libnetwork
♦ Драйверы Docker
♦ Сетевой мост Docker

Модель Container Network
Сеть Docker построена на архитектуре Container Network Model (CNM). CNM -
это архитектура, предоставляющая простую и эффективную сетевую модель, кото
рая позволяет запускать приложения в защищенных портативных контейнерах.
Модель Container Network (CNM) представлена на рис. 4.1.
Рассмотрим элементы модели CNM подробнее.

  терфейсы , таблицы маршрутизации, настройки DNS и  т. д. Песочница пол

   ностью изолирована от внешнего мира , за исключением конечных точек.

♦ Конечные точки соединяют песочницу с внешним миром через сети . Можно

   представить конечные точки как двери наружу .
