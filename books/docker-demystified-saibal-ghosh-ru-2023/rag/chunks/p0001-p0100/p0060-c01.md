64 ■  Глава 3

Если ядро позволяет использовать несколько драйверов хранилища, нужно выбрать
вариант с оптимальным сочетанием стабильности и производительности. Docker
предлагает список рекомендованных драйверов, но при выборе нужно руковод
ствоваться своими потребностями.

Подцерживаемые драйверы хранилища
Существует несколько драйверов хранилища, поддерживаемых в Docker.
♦  Overlay2. Предпочтительный вариант для всех дистрибутивов Linux. Не требует
   дополнительной конфигурации и может использоваться напрямую.
♦  Aufs. Для версий Docker до 18.06 на Ubuntu рекомендуется использовать aufs, но
   только если установлена Ubuntu 14.04 на ядре 3.13, и, следовательно, overlay2

   не поддерживается.
♦ Device mapper. Раньше Device mapper рекомендовали  для  дистрибутивов
   CentOS и RНEL (Red Hat Enterprise Linux), поскольку их драйверы ядра не под
   держивали overlay2, но сейчас лучше использовать вместо него overlay2.
♦ Для Device mapper требуется direct-lvm, а значит, нужна дополнительная конфи
   гурация для создания тонкого пула с использованием блочных устройств. Мож
   но использовать loopback-lvm, поскольку для него не требуется дополнительная
   конфигурация, но у него очень низкая производительность, поэтому такой вари
   ант не рекомендуется для рабочей среды.
♦  Btrfs и zfs. Драйверы хранилища btrfs и zfs можно использовать в том случае,
   если в файловой системе, на которой установлен хост (backing filesystem), тоже
   установлены btrfs и zfs. В таком случае их можно использовать для выполнения
  сложных задач, например для создания моментальных снимков и т. д. Требуется
   дополнительная конфигурация.
♦  Vfs. Этот драйвер хранилища не подходит для рабочей среды из-за чрезвычайно
   низкой производительности и отсутствия поддержки механизма копирования

   при записи.
   Таким образом , предпочтительный вариант- overlay2. Драйвер overlay объявлен уста
   ревшим с версии Docker Engine Enterprise 18.09, а Device mapper -   с версии Docker
   Engine 18.09.

При желании можно выбрать другой драйвер хранилища, и позже вы узнаете, как
это сделать. Но помните, что для некоторых драйверов требуется дополнительная
конфигурация , в том числе на хосте Docker (на уровне физического или логическо
го диска) .

Поддержка backing filesystem
В табл. 3.1 указана поддержка backing filesystem, доступная для разных драйверов
хранилища. Что такое backing filesystem? Для хранения данных в Docker нужна
файловая система. Обычно данные хранятся в каталоге /var/liЬ/docker/ -  это и есть
backing filesystem.
