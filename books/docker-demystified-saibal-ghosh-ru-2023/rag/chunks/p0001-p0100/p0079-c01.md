Сетевой мост Docker

Сетевой мост в общих чертах можно представить как устройство канального
уровня, которое используется как механизм передачи трафика между сегментами
сети. При установке Docker автоматически применяет правила, которые запрещают
контейнерам, подключенным к сетевому мосту, взаимодействовать друг с другом
напрямую. Все коммуникации должны осуществляться через мост.

Концепция пространства имен Linux
Docker в значительной степени опирается на Linux в своих сетевых конструкциях.
Например , Docker использует пространства имен, сетевые мосты Linux и iptaЫes
(утилита межсетевого экрана) при создании сетевой топологии. Драйвер сетевого
моста Docker Bridge можно считать высокоуровневой реализацией моста Linux.
Сетевой мост Linux  -  это устройство второго уровня, своего рода виртуальная
реализация физического коммутатора в ядре Linux.

Сетевая изоляция контейнеров реализуется с помощью пространств имен. Если

речь о персональном компьютере с одним пользователем, не стоит тратить усилия
на изоляцию. Если задействовано несколько сервисов, в целях безопасности и ста
бильности следует изолировать эти сервисы друг от друга с помощью пространства

имен.

Пространство имен представляет собой независимую единицу сетевого стека со
всеми компонентами -  маршрутами, правилами межсетевого экрана (брандмауэ
ра) и сетевыми устройствами.

Прежде чем перейти к пространствам имен и сетевому мосту применительно к кон
тейнерам, следует разобраться, что означает пространство имен в Linux.
