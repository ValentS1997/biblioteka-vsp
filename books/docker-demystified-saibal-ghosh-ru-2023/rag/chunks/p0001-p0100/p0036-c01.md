Новый драйвер будет применяться ко всем контейнерам , созданным после редакти
рования файла daemon.json. Есть еще один способ изменить драйвер журналирования
по умолчанию -  запустить контейнер с параметрами --log-dri ver и --l og-opt.
Журналы  контейнеров Docker хранятся  в файлах JSON  в  каталоге  /var/liЬ/
docker/containers/<id_кoнтeйнepa>  в  хает-системе. Имена журналов имеют формат
<i d_ контейнера>- j son. l og. Для журналов указывается выходной поток  ( sтооuт или

формация только об одном контейнере.
