С помощью команды  --tail можно указать определенное количество  (п) строк,
которые мы хотим посмотреть, например 8 последних журнальных записей, как
в следующем примере (рис. 2.19).
docker logs b0c4ee4a7b9f --tail 8

Разные флаги можно легко комбинировать. Например, если нужно просмотреть по
следние 10 записей с метками времени.
docker logs b0c4ee4a7b9f -t --tail 10
Получаем выходные данные (рис. 2.21 ).
