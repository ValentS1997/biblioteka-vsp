## Контрольный тест

Выберите подходящие варианты ответов.

### 1. Контейнеры Docker легче виртуальных машин, потому что...

A. Контейнеры Docker обычно меньше виртуальных машин.  
B. У контейнеров Docker нет гипервизора.  
C. У контейнеров Docker нет гипервизора, но используется операционная система хоста.  
D. У контейнеров Docker есть маленький гипервизор и используется операционная система хоста.

### 2. Docker Swarm — это:

A. Решение для кластеризации.  
B. Решение для аварийного восстановления.  
C. Решение для кластеризации и оркестрации.  
D. Решение для кластеризации и резервного копирования.

### 3. Архитектура на основе микросервисов:

A. Имеет чёткие границы.  
B. Выполняется только на серверах без предустановленной ОС.  
C. Выполняется только в контейнерах.  
D. Является открытой и не имеет чётких границ.

### 4. Контейнер Docker:

A. Использует сетевой стек хоста, на котором выполняется.  
B. Использует сетевой стек, выделенный для каждого контейнера.  
C. Требует создания сетевого стека вручную.  
D. Управляет собственным независимым сетевым стеком.

### 5. Контейнер Docker:

A. Может легко менять масштаб.  
B. Не может легко менять масштаб.  
C. Очень уязвим для злоумышленников.  
D. Продолжит выполняться даже при сбое хоста.
