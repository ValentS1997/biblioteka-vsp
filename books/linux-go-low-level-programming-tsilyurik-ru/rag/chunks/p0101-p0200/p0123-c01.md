       Большие числа

Для  вычислений  с  точностью или  разрядностью, превышающей  стандартные машинные
представления, пакет math/big вводит типы больших чисел: big.Int (знаковое большое целое)
и big.Rat (большое вещественное). Теоретически их разрядность определяется только размером
доступной оперативной памяти (то есть практически безгранична).

Естественно (поскольку Go не допускает переопределение операций) для таких типов данных
вводится очень широкий набор методов, выполняющих весь набор арифметических операций на
все случаи, описанные по типу:

func (z *Int) Add(x, y *Int) *Int
func (z *Rat) Add(x, y *Rat) *Rat
