Здесь несколько (или много) сопрограмм (1-й параметр командной строки запуска) совместно
выполняют некоторый объём (2-й параметр команды) работы — инкремент счётчика count,
выполняемый  атомарной  операцией  atomic.AddUint64().  Главная  программа  терпеливо
ожидает завершения работы всех сопрограмм на барьерной переменной типа sync.WaitGroup.

Но, поскольку Go реализует высокоуровневый механизм взаимодействия и синхронизации
сопрограмм через каналы, а авторы проекта настоятельно рекомендуют использовать именно этот
механизм высокого уровня, то сделаем другой вариант той же задачи:
