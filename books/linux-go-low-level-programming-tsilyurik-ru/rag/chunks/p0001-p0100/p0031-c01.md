С некоторых пор (начиная с довольно старой версии GoLang, которую не представляется
возможным на сегодня восстановить) сборка инструментария Go делается … с помощью
компилятора для самого языка Go — метод раскрутки8 :

     •  Начиная с некоторой, минимально зрелой, версии реализации языка, сама программная
       реализация этого языка переписывается на самом этом языке;

     •  А  далее  новая,  очередная,  версия N  компилируется  используя  установленную
      предыдущую версию N-1 этого же языка;

     •  В GoLang реализована более изощрённая схема раскрутки:

     • …  с  использованием любой уже установленной версии Go  собирается  некоторая
      эталонная промежуточная версия (на самом деле даже две таких промежуточных версий:
      toolchain1 и toolchain2 — см. протокол сборки далее), чтобы исключить нюансы
       тонких синтаксических несоответствий…

     • … и только затем, средствами этой эталонной версии (toolchain2) компилируется
       желаемая собираемая (последняя, как правило) версия.

Поэтому, естественно, прежде чем переходить к сборке новой версии GoLang из исходных кодов,
вы будете обязаны установить бинарный пакет какой-то из предыдущих версий, например из
стандартного репозитория вашего дистрибутива Linux. Про это было рассказано ранее...

Для сборки (которая весьма сложная) для нас подготовлен скрипт all.bash, который должен
сделать всё требуемое за нас. Но:

$ src/all.bash
all.bash must be run from $GOROOT/src

Поэтому, прежде этого, перейдём в сам каталог исходных кодов:
