def fib(n):
    if n < 2 : return 1
    else: return fib(n - 1) + fib(n - 2)

n = int(sys.argv[1])
print("{}".format(fib(int(sys.argv[1]))))

И теперь, когда мы подготовили все приложения к выполнению, мы можем посмотреть их
сравнительное выполнение (почему и воздерживались от запуска сразу после представления
кода):

$ time ./fibo_c 45

$ time ./fibo_cl 45

Это, практически, во всех случаях величины одного порядка, в пределах точности измерения и
класса задач (о чём было сказано выше) — разницы практически нет! На другом классе задач и
эта разница может нивелироваться или поменяться в обратную сторону...
