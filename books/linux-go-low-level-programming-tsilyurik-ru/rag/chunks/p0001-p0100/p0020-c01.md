А вот и первая наша программа на Go … пока без каких-либо комментариев к синтаксису:

fibo_go.go :

package main
import ("os"; "strconv")

func fib(n int) int {
          if n < 2 { return 1
          } else { return fib(n-1) + fib(n-2)
          }
}

func main() {
          n, _ := strconv.Atoi(os.Args[1])
          println(fib(n))
}

Код Go компилируем средой GoLang, о развёртывании и использовании которой будет вскоре
подробно:

$ go version
go version go1.21.3 linux/amd64
$ go build -o fibo_go fibo_go.go
