     TCP клиент-сервер

Go, как язык позднего времени, изначально предназначен для создания сетевых инструментов, и
изначально включал в свою пакетную инфраструктуру развитые сетевые инструменты. Чтобы не
нагромождать детали и не усложнять напрасно, мы сделаем простейший эхо-сервер, который
будет принимать сообщения от клиента и ретранслировать принятое обратно клиенту (такой
шаблон  может  быть  успешной  базой  для  последующего  наполнения  его  требуемой
функциональностью клиент-сервера).

Итак (каталог архива compare/client-server) … простой ретранслирующий эхо-сервер:

echo_serv.go :

package main
import "net"
import "fmt"
import "bufio"

func main() {
  ln, _ := net.Listen("tcp", ":51500")   // Устанавливаем прослушивание порта
  for {
    fmt.Println("waiting on port 51500")
    conn, _ := ln.Accept()               // Открываем серверный порт
    for {                                // Запускаем цикл прослушивания
      // Будем прослушивать все сообщения разделенные \n
      message, err := bufio.NewReader(conn).ReadString('\n')
      if err != nil {                    // Клиент разорвал коннект
        conn.Close()
        break
      }
      conn.Write([]byte(message))        // Отправить обратно клиенту
