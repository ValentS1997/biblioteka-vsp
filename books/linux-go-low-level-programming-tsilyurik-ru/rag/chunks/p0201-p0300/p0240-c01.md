циклического перебора элементов в циклах через: for, while, until...

По рекурсивным вычислениям уже приводилось достаточно много примеров (попутно с другими
целями), но ещё одним хорошим дополнительным примером, с большим практическим смыслом,
и особенностями выразительности Go — будет представление и обход бинарного дерева (каталог
function):

btree.go :

package main

import "fmt"

type Node struct {
          value       int
          left, right *Node
}

func (n *Node) Traverse(f func(int)) {
          if n == nil {
                    return
          }
          n.left.Traverse(f)
          f(n.value)
          n.right.Traverse(f)
}

func main() {
          root := &Node{
                    value: 3,
                    left: &Node{
                             value: 2,
                             left:  &Node{value: 1}},
                    right: &Node{
                             value: 5,
                             left:  &Node{value: 4},
                             right: &Node{value: 6}}}
          var values []int
          root.Traverse(func(v int) { values = append(values, v) })
          fmt.Println(values)
}

Здесь показан рекурсивный обход всего дерева:

$ go fmt btree.go
$ go run btree.go
[1 2 3 4 5 6]

По аналогии, легко могут быть реализованы и любые другие, традиционные для деревьев
операции: добавление и удаление ветвей и терминальных вершин … и другие.

А то что выше названо «особенностями выразительности Go», это имелась в виду простота
статической инициализации дерева, которая программисту с опытом C/C++ может показаться
необычной… Здесь устраняется потенциальная возможность «самой страшной ошибки» C/C++
—  не  инициализированные  (значениями  NULL)  терминальные  ветви,  с  последующим
разименованием  не  инициализированных  указателей.  Но  в  Go  не  может  быть  не
инициализированных значений, и поэтому не инициализированные явно указатели получают
неявно «нулевые значения» для переменных этого типа (указателей), равные nil.
