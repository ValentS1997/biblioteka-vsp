        Ханойская башня

Хорошо известная задача, которую часто приводят в пример плохо формализуемым алгоритмам, и
простоты их рекурсивного описания. Утверждается, что эту задачу (для размерности N=10 колец)
решают уже несколько столетий монахи тибетских монастырей, и когда они её разрешат, то
наступит конец света, Армагедон в европейской нотации (но это, скорее всего, красивая легенда
из среды IT-йяпи):

                                           Рис. 3.3. Ханойская башня

- Имеется 3 нумерованных стержня (1, 2, 3), на один из которых нанизаны N колец, на манер
детской пирамидки, так что кольца, снизу-вверх, уложены в порядке убывания диаметра ...

- Нужно последовательно переложить всю пирамидку со стержня 1 на стержень 3, используя как
промежуточный стержень 2 при условиях: а). перекладываем с любого стержня за раз только одно
верхнее кольцо; б). это кольцо можно перекладывать либо на пустой стержень, либо на стержень
только поверх лежащего на нём кольца большего размера (можно класть только меньшее поверх
большего).

    ============>
    -|-    |     |
   --|--   |     |
  ---|---  |     |
     1     2     3
- Исходное состояние задачи для N = 3 показано на схематическом рисунке выше. Целью является
перенесение всей пирамидки со стержня 1 на стержень 3.

И вот как это делает в 7 переносов колец задача, которую мы напишем далее (как и в
предшествующем примере, параметр запуска определяет размерность задачи, а когда он указан со
знаком минус, то выводится промежуточная контрольно-отладочная информация):

$ ./hanoy_c -3
размер пирамиды: n=3
1 => 3,   1 => 2,   3 => 2,   1 => 3,   2 => 1,
2 => 3,   1 => 3,
число перемещений 7
