- заявленные цели создания Go;

- небольшой сравнительный эксперимент на рекурсивном вычислении чисел Фибоначчи;
- идейные связи Go с Python, функциональными языками и семейством Algol;
- управление памятью и надёжность в формулировке источника.

## Main principle

В главе Go представлен как современный компилируемый язык, продолжающий линию C, но проектируемый с учётом многопроцессорности, переносимости, скорости компиляции и упрощения разработки. Автор подчёркивает, что выбор языка зависит от класса задач и что единичный benchmark нельзя превращать в универсальный рейтинг языков.

## What the benchmark actually shows

Автор использует один и тот же рекурсивный алгоритм Фибоначчи и фиксирует версии инструментов. В приведённом запуске C, C++, Clang/C++, Go, Java и Rust дают времена одного порядка, а Python для этого конкретного примера существенно медленнее. Сразу после этого источник отдельно предупреждает: такой эксперимент не является общим сравнением производительности языков.
