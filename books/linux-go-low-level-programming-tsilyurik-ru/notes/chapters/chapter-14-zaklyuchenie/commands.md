# Commands — «Заключение»

В RAG-границе страницы 280 shell-команд нет.

```text
read-only commands: none
state-changing commands: none
benchmark commands: none
rollback: not applicable
```

Практические commands, относящиеся к многопроцессорности, находятся в предыдущих главах и не дублируются здесь.
