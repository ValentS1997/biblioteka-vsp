# Резюме главы 4

Source section: explicit «Резюме» in `p0212:c01`.

Этот файл сохраняет смысл source summary с минимальной структурной очисткой.

Глава рассматривает два механизма Go:

- `error` — ошибки, которые можно обработать и после этого продолжить работу приложения;
- `panic` — аварийные ситуации, которые могут привести к самопроизвольному завершению приложения.

Source перечисляет типичные причины panic:
- обращение к несуществующему index slice;
- работа через pointer со значением `nil`;
- неправильное использование mutex;
- попытка работы с закрытым file;
- другие runtime failures.

При этом Go позволяет перехватывать panic и восстанавливать управление приложением через `recover` в deferred handler.

Также chapter показывает пользовательские error types: разработчик может объявить собственную struct, реализующую `Error() string`, чтобы передавать вместе с error дополнительную structured information, а не только text message.
