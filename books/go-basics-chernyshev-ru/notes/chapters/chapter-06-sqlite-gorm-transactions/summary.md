# Резюме главы 6

Source section: explicit «Резюме» in `p0361:c01`.

Этот файл сохраняет смысл source summary с минимальной структурной очисткой.

Глава рассматривает два способа взаимодействия с SQLite:

- классический — через SQL и `database/sql` с драйвером go-sqlite3;
- ORM-подход — через GORM.

Source подчёркивает trade-off:
- ORM сокращает объём application code и ускоряет разработку;
- сложные generated queries могут быть менее оптимальными, чем SQL, написанный разработчиком вручную.

Автор намеренно не даёт полного курса SQL и полной документации GORM, чтобы приблизить задания к реальной разработке: самостоятельно читать документацию, искать examples и разбираться с незнакомыми API.
