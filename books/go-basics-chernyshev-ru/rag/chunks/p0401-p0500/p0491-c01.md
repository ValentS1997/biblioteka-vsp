  На этом работа над сервером завершена, и можно переключиться на разработку
клиентской части игры.

Разработка клиентской части
Откройте файл client_state.go из пакета client. В нем объявим состояния, между
которыми будет переключаться клиентское приложение в ходе своей работы:

   // baseURL/part_8/tic_tac_toe_v7/client/client_state.go
   package client

   type State int

   const (
       // ожидание подтверждения никнейма от сервера
       waitNickNameConfirm State = iota
       mainMenu // главное меню
       playerMove // ход игрока
       opponentMove // ход оппонента
       endGame // конец игры
       waitingOpponentInRoom // ожидание присоединения оппонента
       waitResponseFromServer // ожидание ответа от сервера
   )
   Далее объявим структуру Client, агрегирующую все необходимые данные для
работы клиентского приложения, ее конструкторную функцию, несколько мето
дов для работы с состоянием и один для установки никнейма пользователя после
его утверждения сервером. Для этого откройте файл client.go и добавьте в него
следующий код:

   // baseURL/part_8/tic_tac_toe_v7/client/client.go
