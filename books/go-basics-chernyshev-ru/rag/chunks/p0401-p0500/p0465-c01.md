464       Глава 8   Сетевое программирование

  Вы можете изменить имя и описание проекта. Поле id при добавлении указы
вать не нужно — сервер сгенерирует его автоматически и вернет клиенту в случае
успешного добавления проекта.
   Теперь отправьте запрос на добавление. Результат показан на рис. 8.32.

                                Рис. 8.32. Успешное добавление проекта

  Если вы попытаетесь добавить проект с именем, которое уже используется для
другого проекта, то сервис вернет следующую ошибку (рис. 8.33).

                               Рис. 8.33. Ошибка при добавлении проекта

  Каждому запросу вы можете добавить собственные параметры. Так, например,
Bruno импортировал из спецификации API параметры к каждому из запросов.
