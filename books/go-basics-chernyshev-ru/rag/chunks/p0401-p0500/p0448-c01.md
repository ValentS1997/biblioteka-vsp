8.5. Пример реализации REST API веб-сервиса      447

8.5.5. Разработка веб-сервиса ToDo-list
Для разработки сервиса воспользуемся пакетом gorilla/mux, который реализу
ет маршрутизацию запросов и предоставляет диспетчер для их сопоставления
c соответствующим обработчиком. Создайте в директории проекта два каталога:
db и service. В первый скопируйте файлы из проекта, в котором работали с ORM,
а второй пусть пока остается пустым.
   Теперь откройте терминал и установите внешние зависимости:

   go get github.com/gorilla/mux
   go get github.com/mattn/go-sqlite3
   go get gorm.io/gorm
   go get gorm.io/driver/sqlite
   Далее создайте файл main.go. Его мы пока будем использовать для знакомства
с возможностями пакета gorilla/mux, которое начнем со следующего кода:

   package main

   import (
       "fmt"
       "log"
       "net/http"

       "github.com/gorilla/mux"
   )

   const PORT = "8080"

   func home(w http.ResponseWriter, r *http.Request) {
       fmt.Fprintf(w, "Hello Wold in REST API style!!!")
   }

   func main() {
       // http://127.0.0.1:8080/api/v1/todo
       router := mux.NewRouter()
       router.HandleFunc("/api/v1/todo", home)
       fmt.Println("Listening at port", PORT)
       log.Fatal(http.ListenAndServe(":"+PORT, router))
   }
   Экземпляр маршрутизатора router регистрирует маршруты для сопоставления
и передачи запросов обработчику. Так, например, мы создали маршрут (путь)
с именем /api/v1/todo и сопоставили его с функцией home(). Запустите приложе
ние, откройте браузер и введите в него следующий адрес: http://127.0.0.1:8080/
api/v1/todo. В ответ на это обращение сервис вернет строку Hello Wold in REST API
style!!!, которая отобразится в браузере (рис. 8.20).
