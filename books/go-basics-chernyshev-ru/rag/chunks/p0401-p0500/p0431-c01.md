430       Глава 8   Сетевое программирование

  На каждый запрос клиента приходит ответ от сервера, где первой строкой идет
строка состояния (например: HTTP/1.1 404 Not Found.), содержащая следующую
информацию:
   1) версия протокола (HTTP/1.1);
   2) числовой код статуса (состояния) ответа о том, прошел ли запрос успешно;
   3) пояснение (текстовое описание кода состояния).

  К наиболее распространенным числовым кодам состояний ответа относятся:
   yy 200 (OK) — запрос выполнен успешно;
   yy 201 (Created) — запрос выполнен успешно, и ресурс на стороне сервера соз
      дан. Этот код ответа используется для подтверждения успеха запроса PUT
     или POST;
   yy 400 (Bad Request) — запрос был сформирован неправильно;
   yy 404 (Not Found) — требуемый ресурс не найден;
   yy 401 (Unauthorized) — необходимо пройти аутентификацию, чтобы получить
      доступ к ресурсу;
   yy 405 (Method Not Allowed) — используемый метод HTTP не поддерживается
     для данного ресурса;
   yy 409 (Conflict) — произошел конфликт;
   yy 500 (Internal Server Error) — внутренняя ошибка сервера (обработка запроса
     не удалась из-за непредвиденных обстоятельств на стороне сервера).

8.5.3. Структура REST URLs
Основной абстракцией в REST является ресурс, то есть любая информация, которой
можно присвоить имя: документ, сущность, изображение и т. д. Ресурс может быть
единичным (project) или представлять собой коллекцию (projects). Доступ к ресурсам
REST API сервиса осуществляется путем обращения к ним через Uniform Resource
Identifier (унифицированный идентификатор ресурсов, URI), который на сервере
представлен в виде URL верхнего уровня.
   Предположим, у вас есть REST API, предоставляющий информацию о проектах
и списке дел, которые необходимо выполнить в рамках проекта. Если вы хотите
получить информацию о задаче, используя ее идентификатор, то URL будет вы
глядеть так:
   http://www.domain.com/api/v1/todo/projects/3/tasks/1
где:
   yy www.yourdomain.com — домен сервера;
   yy api — указание на то, что работа будет выполняться с предоставляемым
     сервером API для доступа к его ресурсам;
   yy v1 — версия API;
   yy todo — сервис, запущенный на сервере;
   yy projects — коллекция проектов;
