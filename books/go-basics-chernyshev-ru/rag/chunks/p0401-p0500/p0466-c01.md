8.5. Пример реализации REST API веб-сервиса      465

Выберите запрос GET по пути /task и обратите внимание на наполнение первой из
вкладок (Params) (рис. 8.34).

                                Рис. 8.34. Настройка параметра запроса

  Если оставить эти данные без изменения и отправить запрос, то сервис вернет
список всех задач, имеющихся в базе. Чтобы запросить список задач конкретного
проекта, установите флажок projectID и введите в поле Path идентификатор интере
сующего вас проекта (например, projectID=1) (рис. 8.35).
