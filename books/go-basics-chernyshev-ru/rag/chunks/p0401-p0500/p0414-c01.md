Задания на доработку проекта

В следующей главе вы познакомитесь с принципами работы по сети и реализуете
финальный вариант игры «Крестики-нолики» в виде клиент-серверного приложе
ния. А пока предлагаю выполнить следующие задания.
    1. Реализуйте возможность по завершении игры выводить статистику матча,
     содержащую информацию о количестве ходов, сделанных каждым игроком,
     и общей продолжительности матча.
    2. Добавьте в базу таблицу для хранения статистики игроков (победы, пора
     жения, ничьи) и реализуйте в меню новый раздел для просмотра профиля
      игрока и общей таблицы лидеров.
    3. Добавьте в меню раздел с настройками, где игрок может задать размер доски
     и сложность игры с компьютером. Эти настройки должны позволить миновать
     этапы ввода этих данных, тем самым ускорив запуск игры. Проследите, чтобы
     сохраненные настройки игры не сбрасывались по ее завершении.
    4. Добавьте новый режим, в котором можно наблюдать за игрой двух ком
     пьютерных игроков друг против друга. Если пользователь выбрал высокую
     сложность и большую доску, то перед началом игры должен выбрать вариант
      стратегии, с помощью которой будет оцениваться ход. Эта функциональность
      полезна для анализа и сравнения эффективности разных уровней сложности
     и стратегий ИИ.
    5. При игре с компьютером на легком уровне сложности пользователь должен
      иметь возможность отменить несколько ходов, а затем при желании вернуть их.
