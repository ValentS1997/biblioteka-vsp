  Последний метод, который нам предстоит реализовать для игровой комна
ты, — PlayerStep(player p.IPlayer, row, col int). Он отвечает за обработку хода
игрока в текущей партии игры, которая развернулась в комнате, и принимает на
вход игрока, от которого пришли команда на совершение хода и его координаты.
Метод достаточно сложный, поэтому, чтобы вы могли лучше его понять, разобьем
алгоритм его работы на несколько шагов.
    1. Убеждаемся, что игра не завершена (установлено состояние g.CrossStep или
      g.NoughtStep) и что ход делает правильный игрок.
    2. Устанавливаем символ игрока на выбранную клетку доски.
    3. Проверяем, привел ли сделанный ход к победе (CheckWin) или ничьей (Check
       Draw). В случае победы обновляем состояние игры, сохраняем ее результат
      в базе данных и отправляем сообщение игрокам о завершении текущей
      партии. В случае ничьей обновляем состояние и отправляем игрокам соот
     ветствующее сообщение.
    4. Если игра продолжается, то переключаем активного игрока и отправляем
     обоим игрокам сообщение об обновлении состояния игры.
    5. Если игра завершена, то ждем 10 секунд и автоматически перезапускаем
     партию.
    6. Если после выполненного хода активным игроком становится компьютер, то
      запускаем выполнение его хода, рекурсивно вызвав метод PlayerStep.

   func (r *Room) PlayerStep(player p.IPlayer, row, col int) {
       msg := &n.Message{} // Создаем новое сообщение для игроков
       // Проверяем, идет ли сейчас ход (игра не завершена)
       if r.State ! = g.CrossStep && r.State ! = g.NoughtStep {
           return
       }
       // Проверяем, делает ли ход именно тот игрок, чей сейчас ход
       if player ! = r.CurrentPlayer {
           return
       }

       // Ставим символ игрока на выбранную клетку
       r.Board.SetSymbol(row, col, r.CurrentPlayer.GetFigure())
       // Проверяем, выиграл ли этот игрок
       if r.Board.CheckWin(r.CurrentPlayer.GetFigure()) {
           if r.CurrentPlayer.GetFigure() = = b.Cross {
               r.State = g.CrossWin // Победа крестиков
           } else {
               r.State = g.NoughtWin // Победа ноликов
           }
           // Формируем сообщение о завершении игры
           msg.Cmd = n.CmdEndGame
           endGamePayload := &n.EndGameResponse{
               Board:         *r.Board,
               CurrentPlayer: r.CurrentPlayer.GetFigure(),
           }
           msg.Payload, _ = json.Marshal(endGamePayload)
