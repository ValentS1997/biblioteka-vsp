8.5. Пример реализации REST API веб-сервиса      439

                    Рис. 8.15. Визуализированный раздел components спецификации API

  Следующий наш шаг — заполнение спецификации конечных точек (end points)
сервиса с URL /project, который будет отвечать за добавление нового проекта
пользователя в базу данных:

     /project:
       post:
         tags:
           - project
         description: |
           Добавление проекта
         requestBody: # структура тела запроса
           content:
             application/json:
               schema:
                 $ref: "#/components/schemas/Project"
         responses:
           "201":
             description: Добавление прошло успешно.
             content:
               application/json:
                 schema:
                   $ref: "#/components/schemas/GoodResponse"
