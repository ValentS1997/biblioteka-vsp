Разработка протокола взаимодействия клиента и сервера
Все, что касается формата передаваемых сообщений между клиентом и сервером,
мы поместим в пакет network. Поскольку для реализации клиент-серверного при
ложения мы используем TCP, то должны обеспечить сериализацию данных перед
их отправкой и десереализацию после получения. Чтобы выстроить логику работы
с сообщениями с разной структурой, объявим в файле protocol.go базовый тип
сообщения и его описания, по которому и будем в дальнейшем ориентироваться,
какие данные были получены и в какую структуру их десериализовать:

   // baseURL/part_8/tic_tac_toe_v7/network/protocol.go
   package network

   import "encoding/json"

   // Объявляем тип команды
   type Command string

   // Базовая структура сообщения
   // Cmd — тип команды
   // Payload — полезная нагрузка, которая должна быть
   // сериализована в JSON ([]byte). Может быть nil
   type Message struct {
       Cmd     Command         `json:"command"`
       Payload json.RawMessage `json:"payload,omitempty"`
   }
