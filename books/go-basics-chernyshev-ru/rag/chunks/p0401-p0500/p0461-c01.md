460       Глава 8   Сетевое программирование

  Чтобы проверить корректность работы запросов к разработанному нами сервису
и получаемых от него ответов, воспользуемся программой Bruno, которую можно
скачать по этой ссылке:

   https://www.usebruno.com/downloads
   После установки и запуска Bruno нажмите в главном окне элемент Import Collection
(Импортировать коллекцию) (также доступен при выборе значка меню с тремя
точками) (рис. 8.24).

                                    Рис. 8.24. Создание API в Bruno

  В открывшемся окне необходимо нажать кнопку OpenAPI V3 File (рис. 8.25).
