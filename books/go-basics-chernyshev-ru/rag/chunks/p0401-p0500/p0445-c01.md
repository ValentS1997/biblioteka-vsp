444       Глава 8   Сетевое программирование

  На конечную точку /task может отправляться достаточно большое количество
HTTP-запросов: GET, PUT, POST и DELETE. Начнем с запроса на изменение
статуса задачи, который будет переводить ее в состояние «Выполнено»:

   /task:
       put:
         tags:
           - task
         description: |
           Изменение статуса задачи
         parameters:
           - in: query
             required: true
             name: id
             schema:
               type: integer
               example: 1
         responses:
           "201":
             description: Запрос прошел успешно
           "400":
             description: Невалидная схема задачи или входные данные неверны.
             content:
               application/json:
                 schema:
                   $ref: "#/components/schemas/Error"
                 examples:
                   response:
                     value: |-
                       {
                         "code": 400,
                         "message": "Validation Failed"
                       }
           "404":
             description: Проект не найден.
             content:
               application/json:
                 schema:
                   $ref: "#/components/schemas/Error"
                 examples:
                   response:
                     value: |-
                       {
                         "code": 404,
                         "message": "Tasks not found"
                       }
  После метода put добавим спецификацию метода post на добавление новой
задачи:

       post:
         tags:
           - task
         description: |
           Добавление задачи
         requestBody:
           content:
             application/json:
               schema:
                 $ref: "#/components/schemas/Task"
         responses:
           "201":
             description: Добавление прошло успешно.
