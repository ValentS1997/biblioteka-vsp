8.5. Пример реализации REST API веб-сервиса      441

  На рис. 8.16 приведен пример тела запроса и соответствующие ответы сервиса.
Если вам необходимо уточнить тип полей в теле объекта, то откройте его схему
(рис. 8.17).

                         Рис. 8.17. Схема объекта, передаваемого в теле запроса

   Далее опишем спецификацию API на удаление проекта из базы данных сервиса:

   /project/del/{id}:
       delete:
         tags:
           - project
         description: |
           Удалить проект
         parameters:
           - description: Идентификатор
             in: path
             name: id
             required: true
             schema:
               type: integer
             example: 1
         responses:
           "200":
             description: Удаление прошло успешно.
           "400":
             description: Невалидные входные данные.
             content:
               application/json:
                 schema:
                   $ref: "#/components/schemas/Error"
                 examples:
                   response:
                     value: |-
                       {
                         "code": 400,
                         "message": "Validation Failed"
                       }
           "404":
             description: Проект не найден.
