184       Глава 3   Объектно-ориентированное программирование в Go

   // Типом T может быть int, или float64, или string
   func Sum[T int | float64 | string](a, b T) T {
       return a + b
   }

   func main() {
       fmt.Println(Sum(10.3, 45.1)) // 55.4
       fmt.Println(Sum(10, 45))     // 55
       fmt.Println(Sum("^_", "^"))  // ^_^
   }

  Общий вид объявления функции с дженериком можно представить так:

   func имяФункции[T any](имяАргумента T, …. n) T{
   // тело функции
   [return]
   },
где T — тип параметра, а any — ограничение по типу.
   Ограничитель any является интерфейсом (type any = interface{}) и задает огра
ничение на то, какой интерфейс должен реализовывать тип Т. Как видно из преды
дущего примера, можно использовать несколько типов в качестве ограничителей,
а если попытаться вызвать функцию, передав ей на вход тип данных, не поддержи
ваемый объявленным дженериком, то это приведет к ошибке времени компиляции:

   // baseURL/part_3/3.10/3.go
   package main

   import "fmt"

   type MyInt int

   func Sum[T int | float64 | string](a, b T) T {
       return a + b
   }

   func main() {
       var value1, value2 MyInt = 34, 22
       fmt.Println(Sum(value1, value2))
       // MyInt does not implement int|float64|string
       // (possibly missing ~ for int in constraint int|float64|string)
   }
   Несмотря на то что объявленный пользовательский тип MyInt является псев
донимом типа int, передача его значений в функцию приводит к ошибке, которой
можно избежать, используя символ ~ перед ограничителем типа в момент его объ
явления. Запись вида ~int будет означать, что на вход функции можно подавать
набор любых типов данных, базовым типом которого выступает int:

   // baseURL/part_3/3.10/4.go
   package main

   import "fmt"

   type MyInt int

   func Sum[T ~int | float64 | string](a, b T) T {
       return a + b
   }
