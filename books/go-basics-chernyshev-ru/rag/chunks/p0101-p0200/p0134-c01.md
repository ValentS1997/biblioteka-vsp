                            Рис. 2.13. Успешный результат выполнения тестов

   go test — это команда, которая запускает тесты; далее указывается директо
рия, в которой находится файл с тестами, относительно текущей директории
в терминале: ./test. Флаг -v позволяет вывести более подробную информацию
о результатах тестирования. Без него будет предоставлена только общая инфор
мация (рис. 2.14).
