132       Глава 2   Функции, модули, пакеты и их тестирование

2.3.1. Написание модульных тестов в Go
Создайте новый проект со следующей структурой (рис. 2.12) и инициализируй
те его.
  Для начала в файле calculator.go напишем функции, которые будем тестировать:

   // baseURL/part_2/2.3/2.3.1/golang/testing/calculator/calculator.go
   package calculator

   import "math"

   func Add(a, b int) int {
       return a + b
   }

   func Sub(a, b int) int {
       return a - b
   }

   func Mul(a, b int) int {
       return a * b
   }                                                                     Рис. 2.12. Структура проекта
   func Pow2(a int) int {
       return int(math.Pow(float64(a), 2))
   }
  А в файле main.go вызовем их при запуске приложения, выводя полученный
результат выполнения в терминал:

   // baseURL/part_2/2.3/2.3.1/golang/testing/main.go
   package main

   import (
       "fmt"
       calc "golang/testing/calculator"
   )

   func main() {
       fmt.Println(calc.Add(4, 2))   // 6
       fmt.Println(calc.Sub(23, 12)) // 11
       fmt.Println(calc.Mul(5, 6))   // 30
       fmt.Println(calc.Pow2(5))     // 25
   }
  Для написания тестов Go предоставляет встроенный пакет testing. При этом все
тестовые функции должны начинаться со слова Test, за которым следует имя теста
(или тестируемой функции/метода), первое слово которого пишется с большой
буквы. Они имеют только один входной аргумент — это указатель на тип testing.T,
который содержит полезные методы для вывода результата теста и ошибок.
   Далее в файле calculator_test.go напишем тесты для приведенных выше функ
ций из пакета calculator:

   // baseURL/part_2/2.3/2.3.1/golang/testing/test/calculator_test.go
   package test_test

   import (
       calc "golang/testing/calculator"
       "testing"
   )
