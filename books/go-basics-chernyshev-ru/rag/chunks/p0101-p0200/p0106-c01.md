2.1. Функции в Go      105

   func myFunc(array [4]float64) {
       for i := range array {
           array[i] += 2.33
       }
       fmt.Printf("Array in myFunc: %v\n", array)
   }

   // Array in myFunc: [4.73 7.93 10.43 11.55]
   // Array in main: [2.4 5.6 8.1 9.22]
   Обратите внимание на ограничение в виде указания того, какого размера массив
можно передавать в функцию. Если не соблюдать его, то программа не соберется,
поскольку возникнет ошибка несоответствия передаваемого аргумента в функцию
с объявленной в ней сигнатурой.
  При передаче в качестве аргумента указателя на переменную будет скопирован
адрес, на который он ссылается, и с помощью операции разыменования (не требу
ется для массивов) можно будет менять значения элементов:

   // baseURL/part_2/2.1/2.1.1/2.go
   package main

   import "fmt"

   func main() {
       array := [4]float64{2.4, 5.6, 8.1, 9.22}
       myFunc(&array)
       fmt.Printf("Array in main: %v\n", array)
   }

   func myFunc(array *[4]float64) {
       for i := range array {
           array[i] += 2.33
       }
       fmt.Printf("Array in myFunc: %v\n", *array)
   }

   // Array in myFunc: [4.73 7.93 10.43 11.55]
   // Array in main: [4.73 7.93 10.43 11.55]
   Теперь изменим тип аргумента и вместо указателя на массив передадим указа
тель на срез. Обратите внимание на то, как будет выполняться итерация по срезу
и изменение значений его элементов:

   // baseURL/part_2/2.1/2.1.1/3.go
   package main

   import "fmt"

   func main() {
       array := []float64{2.4, 5.6, 8.1, 9.22}
       myFunc(&array)
       fmt.Printf("Array in main: %v\n", array)
   }

   func myFunc(array *[]float64) {
       for i := range *array {
           (*array)[i] += 1.5
       }
       fmt.Printf("Array in myFunc: %v\n", *array)
   }

   // Array in myFunc: [3.9 7.1 9.6 10.72]
   // Array in main: [3.9 7.1 9.6 10.72]
