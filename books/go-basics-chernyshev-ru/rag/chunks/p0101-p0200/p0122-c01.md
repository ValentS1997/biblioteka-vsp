                                  Рис. 2.6. Ввод команды в терминал

  При следующем запуске приложения в отладочной консоли должна появиться
строка с UUID (у вас она будет другой) (рис. 2.7).

                                Рис. 2.7. Вывод сгенерированного UUID

   Второй способ добавить зависимости в проект, не редактируя файл go.mod вруч
ную, — использовать команду:

   go get github.com/google/uuid
где github.com/google/uuid — URL модуля, выступающего в качестве зависимости
для проекта. В этом случае не нужно будет вводить дополнительные команды перед
запуском проекта, а файл go.mod будет выглядеть так:

   module golang/first

   go 1.24

   require github.com/google/uuid v1.6.0 // indirect
   Зависимость будет помечена комментарием // indirect, от которого можно из
бавиться, запустив команду go mod tidy. Но перед этим убедитесь, что сторонний
модуль используется в вашем коде.
