154       Глава 3   Объектно-ориентированное программирование в Go

  Либо последовательно передайте значения в порядке объявления полей структуры:

   // baseURL/part_3/3.1/3.go
   func main() {
       emp3 := employee{"Alex", "R&D", 25, "Assistant"} // ok
       // emp3 := employee{"Alex", "R&D"} — ошибка!!!

       fmt.Println(emp3) // {Alex R&D 25 Assistant}
   }
  В первом и третьем случае мы инициализировали все поля создаваемого объ
екта, а во втором — только имя и занимаемую позицию. Теперь, чтобы изменить
значение поля, придется обратиться к нему напрямую:

   // baseURL/part_3/3.1/4.go
   func main() {
       emp2 := employee{
           name:     "Tom",
           position: "Intern",
       }
       emp2.age = 22
       emp2.departmentName = "R&D"
       fmt.Println(emp2) // {Tom R&D 22 Intern}
       emp2.position = "Engineer"
       fmt.Println(emp2) // {Tom R&D 22 Engineer}
   }
   Такой способ вывода значения переменной типа employee не слишком инфор
мативный, и можно легко запутаться в том, к какому полю структуры относится то
или иное значение, выводимое в фигурных скобках. Поэтому воспользуемся ключом
%+v и функцией для форматированного вывода Printf из пакета fmt:

   // baseURL/part_3/3.1/5.go
   func main() {
       emp2 := employee{
           name:     "Tom",
           position: "Intern",
       }
       emp2.age = 22
       emp2.departmentName = "R&D"
       fmt.Printf("%+v\n", emp2)
       // {name:Tom departmentName:R&D age:22 position:Intern}
       emp2.position = "Engineer"
       fmt.Printf("%+v\n", emp2)
       // {name:Tom departmentName:R&D age:22 position:Engineer}
   }
   Если вам нужно прочитать значение определенного поля структуры или вывести
только его, то обратитесь к этому полю через имя переменной и символ точки (.):

   // baseURL/part_3/3.1/6.go
   func main() {
       emp2 := employee{
           name:     "Tom",
           position: "Intern",
       }
       emp2.age = 22
       emp2.departmentName = "R&D"
       fmt.Printf("%+v\n", emp2.age) // 22
       employeeAge := emp2.age
       fmt.Println(employeeAge) // 22
   }
