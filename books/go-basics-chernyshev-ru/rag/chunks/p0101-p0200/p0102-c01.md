2.1. Функции в Go      101

   func hello() {
       fmt.Println("Hello World!")
   }
   // Hello World!
   // exit
   Когда при выполнении приложения в коде встречается вызов функции, поток
управления переходит в нее и выполняет ее код. После завершения вызываемой
функции управление возвращается в точку ее вызова, и продолжается последова
тельная отработка кода основной программы. У приведенной выше функции нет
входных аргументов, и не возвращается никакое значение. Такие функции мало
чем полезны, но хорошо подходят для обучающих примеров.
  Чтобы передать в функцию данные, необходимо после объявления ее имени
(в круглых скобках) указать имя входного аргумента, а затем его тип. Все аргумен
ты функций в Go относятся к позиционным, то есть должны передаваться именно
в том порядке, в котором были объявлены:

   package main

   import "fmt"

   func main() {
       add(3, 5)
   }

   func add(a int, b int) {
       fmt.Println(a + b) // 8
   }
  Если последовательно объявленные аргументы относятся к одному и тому же
типу данных, то запись можно сократить:

   func add(a, b int) {
       fmt.Println(a + b)
   }

   Добавить новый аргумент другого типа данных достаточно просто:

   package main

   import "fmt"

   func main() {
       userInfo(3, 5, "Alex")
   }

   func userInfo(age, exp int, name string) {
       fmt.Printf("User name: %s, age: %d, exp years: %d", name, age, exp)
   }
   // User name: Alex, age: 3, exp years: 5
   Теперь перепишем функцию userInfo так, чтобы она возвращала в функцию
main строку, которую мы только что вывели в терминал:

   package main

   import "fmt"

   func main() {
       fmt.Println(userInfo(3, 5, "Alex"))
