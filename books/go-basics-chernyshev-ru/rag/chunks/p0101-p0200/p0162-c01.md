3.3. Связывание метода и структуры данных      161

   func main() {
       var rub RUB = 3475
       rub.setNewValue(9000)
       fmt.Printf("В кошельке на самом деле %d рублей\n", rub)
   }
   // В кошельке теперь 9000 рублей
   // В кошельке на самом деле 3475 рублей
   Поскольку тип приемника при объявлении метода не является указателем на
тип, то при вызове rub.setNewValue(9000) в приемник r копируется значение и все
последующие действия выполняются с копией, а не исходным значением! Поэтому
в выводе сначала появляется сообщение, что в кошельке 9000 рублей, хотя на самом
деле количество рублей не изменилось.
  Если метод должен изменять данные экземпляра структуры — используйте
указатель на тип:

   // baseURL/part_3/3.2/3.go
   func (r *RUB) setNewValue(rub RUB) {
       *r = rub
       fmt.Printf("В кошельке теперь %d рублей\n", *r)
   }

   func main() {
       var rub RUB = 3475
       rub.setNewValue(9000)
       fmt.Printf("В кошельке на самом деле %d рублей\n", rub)
   }
   // В кошельке теперь 9000 рублей
   // В кошельке на самом деле 9000 рублей
  На присоединение метода к типу приемника накладывается дополнительное
ограничение: они оба должны быть определены в одном пакете.

3.3. Связывание метода и структуры данных
Вернемся к пакету shape и добавим структуре Shape метод для установки и полу
чения значения цвета:

   // baseURL/part_3/3.3/golang/factory/shape/shape.go
   package shape

   type Point struct {
       X int
       Y int
   }

   type Shape struct {
       Name   string
       Center Point
       color  string
   }

   func (s *Shape) SetColor(color string) {
       s.color = color
   }

   func (s *Shape) GetColor() string {
       return s.color
   }
