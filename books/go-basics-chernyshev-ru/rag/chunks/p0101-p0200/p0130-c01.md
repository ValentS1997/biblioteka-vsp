2.2. Модули и пакеты      129

   Далее создадим файлы integer.go и float.go (рис. 2.11).

                                   Рис. 2.11. Структура папки second

  В файл integer.go добавим функции, отвечающие за выполнение арифметиче
ских операций с целочисленными значениями:

   // baseURL/part_2/2.2/2.2.8/golang/second/integer.go
   package second

   func AddInt(a, b int) int {
       return a + b
   }

   func SubInt(a, b int) int {
       return a – b
   }

   func MulInt(a, b int) int {
       return a * b
   }

   func DivInt(a, b int) int {
       return a / b
   }
  И реализуем аналогичные функции для операций над вещественными числами
в файле float.go:

   // baseURL/part_2/2.2/2.2.8/golang/second/float.go
   package second

   func AddFloat(a, b float64) float64 {
       return a + b
   }

   func SubFloat(a, b float64) float64 {
       return a – b
   }

   func MulFloat(a, b float64) float64 {
       return a * b
   }

   func DivFloat(a, b float64) float64 {
       return a / b
   }
