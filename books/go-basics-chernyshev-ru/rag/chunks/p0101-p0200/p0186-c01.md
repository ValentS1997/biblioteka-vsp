3.10. Обобщения (generics)      185

   func main() {
       var value1, value2 MyInt = 34, 22
       fmt.Println(Sum(value1, value2)) // 56
   }
  В приведенных выше примерах тип аргументов обобщенной функции выводится
автоматически, но Go поддерживает и его явное указание:

   // baseURL/part_3/3.10/5.go
   func main() {
       var value1, value2 MyInt = 34, 22
       fmt.Println(Sum[MyInt](value1, value2)) // 56
       fmt.Println(Sum[float64](10.3, 45.1))   // 55.4
       fmt.Println(Sum[int](10, 45))           // 55
       fmt.Println(Sum[string]("^_", "^"))     // ^_^
   }
  С учетом того, что код обобщенной функции может работать с достаточно
большим типом входных данных, такая запись [T ~int | float64 | string], весьма
вероятно, разрастется и сделает его нечитаемым. В этом случае можно объявить
собственный интерфейс и указать его в качестве ограничения:

   // baseURL/part_3/3.10/6.go
   package main

   import "fmt"

   type MyInt int

   type MyInterface interface {
       ~int | float64 | string | uint16 | uint32
   }

   func Sum[T MyInterface](a, b T) T {
       return a + b
   }

   func main() {
       var value1, value2 MyInt = 34, 22
       fmt.Println(Sum(value1, value2)) // 56
       fmt.Println(Sum(10.3, 45.1))     // 55.4
       fmt.Println(Sum(10, 45))         // 55
       fmt.Println(Sum("^_", "^"))      // ^_^
   }
   Указывая в качестве ограничения обобщенной функции, структуры или ме
тода интерфейса any, необходимо понимать, что значения этого типа не имеют
собственных методов и должны использоваться только для добавления либо
удаления элементов структур данных (например, связного списка) или итерации
по ним.

последовательностью элементов:

   package main

   import "fmt"
