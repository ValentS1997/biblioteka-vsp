   Предположим, что, столкнувшись с такой ошибкой несколько раз, вы сделали все
поля структуры приватными, чтобы их значения нельзя было изменять напрямую,
а только через методы. Но вы не учли того, что в методах не выполняется проверка
на корректность входных данных перед их присваиванием полям структуры. В этом
случае снова возникает вероятность установки значения, из-за которого данные
структуры потеряют инвариантность!
  Таким образом, помимо объединения данных и методов, инкапсуляция должна
гарантировать, что данные не потеряют инвариантность. Это достигается сокрытием
служебных методов, полей структур и добавления в методы дополнительных про
верок, которые в случае некорректных данных приведут к падению приложения
и выдаче оповещения об ошибке, но не позволят нарушить инвариантность данных.
   Вероятно, из-за того, что инкапсуляция использует механизм сокрытия, некото
рые разработчики и считают их тождественными понятиями. Но все куда сложнее,
чем кажется на первый взгляд.

3.6. Композиция и переопределение методов

Композиция в Go используется вместо наследования. Она позволяет встраивать
в производные структуры базовые и напрямую вызывать их методы из производной
структуры. Под базовой понимается структура, задающая некоторые обобщенные
состояния и поведение объекта предметной области (например, автомобиль). А под
производной — структура, которая встраивает в себя состояние и поведение базо
вой и дополняет их, что позволяет описывать более специализированные объекты
предметной области (например, «Москвич»).
  Чтобы увидеть пример использования композиции, добавим в файл shape.go
несколько методов работы со структурой shape, имя и поля которой сделаем при
ватными:

   // baseURL/part_3/3.6/golang/factory/shape/shape.go
   package shape

   type Point struct {
       X int
       Y int
   }

   type shape struct {
       name   string
       center Point
       color  string
   }

   func (s *shape) SetColor(color string) {
       s.color = color
   }

   func (s *shape) GetColor() string {
       return s.color
   }
