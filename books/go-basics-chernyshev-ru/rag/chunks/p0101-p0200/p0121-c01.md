выступающий в качестве зависимости для проекта, а v1.6.0 — версия подкачивае
мого модуля. Структура файла будет выглядеть так:

   // baseURL/part_2/2.2/2.2.1-2.2.2/golang/first/go.mod
   module golang/first

   go 1.24

   require github.com/google/uuid v1.6.0
   Теперь введите в терминале команду:

   go mod download
  Она загрузит модуль github.com/google/uuid и создаст файл go.sum (рис. 2.4).

                                   Рис. 2.4. Структура файла go.sum

   Далее перейдем в файл main.go и внесем в него изменения:

   // baseURL/part_2/2.2/2.2.1-2.2.2/golang/first/main.go
   package main

   import (
       "fmt"

       "github.com/google/uuid"
   )

   func main() {
       myUUID := uuid.New()
       fmt.Println(myUUID)
   }
  К сожалению, попытка запустить проект приведет к следующей ошибке (рис. 2.5).

                                 Рис. 2.5. Ошибка при сборке проекта

   Следуя подсказке, предложенной в описании ошибки, введем в терминал команду
go get golang/first (рис. 2.6).
