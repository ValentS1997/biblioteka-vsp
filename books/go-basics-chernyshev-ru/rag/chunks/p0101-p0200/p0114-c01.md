2.1.8. Рекурсия
Рекурсия — прием программирования, при котором функция вызывает саму
себя. Этот механизм обычно используется как альтернатива цикла, когда нужно
обходить структуры, которые имеют произвольную непредсказуемую форму
и глубину.
   Существует прямая рекурсия и косвенная. Рассмотрим их реализацию на при
мере задачи суммирования элементов среза:

   // baseURL/part_2/2.1/2.1.8/1.go
   package main

   import "fmt"

   func sumElem(slice []int) int {
       fmt.Println(slice)
       if len(slice) < = 1 {
           return slice[0]
       }
       return slice[0] + sumElem(slice[1:])
   }

   func main() {
       mySlice := []int{2, 5, 22, 9, 0}
       fmt.Println(sumElem(mySlice))
   }
   // [2 5 22 9 0]
   // [5 22 9 0]
   // [22 9 0]
   // [9 0]
   // [0]
   // 38
   Поскольку функция явно вызывает саму себя — это прямая рекурсия. Каждый
раз при вызове функцией самой себя ей на вход подается срез списка, содержащий
только те элементы, которые еще не участвовали в операции суммирования.
