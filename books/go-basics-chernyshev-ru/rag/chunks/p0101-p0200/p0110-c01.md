2.1.4. Обращение к функции через переменную
Как я уже говорил, функцию можно присваивать (связывать с) переменной, после
чего вызывать ее путем работы с этой самой переменной. Для примера напишем
функцию сложения двух чисел и будем работать с ней с помощью переменной:

   // baseURL/part_2/2.1/2.1.4/1.go
   package main

   import "fmt"

   func add(a, b int) int {
       return a + b
   }

   func main() {
       myFunc := add             // var myFunc func(a int, b int) int = add
       fmt.Println(add(3, 5))    // 8
       fmt.Println(myFunc(3, 5)) // 8
   }
   Если в редакторе вы наведете указатель мыши на переменную myFunc, то увидите,
что ее тип — func(a int, b int) int, то есть типом переменной является сигнатура
функции add.
