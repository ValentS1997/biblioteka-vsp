2.2. Модули и пакеты      117

   Модуль в Go отвечает за поддержку управления зависимостями. Это набор свя
занных с приложением сторонних библиотек и модулей, прописываемых в файле
корневого каталога проекта — go.mod. По сути, каждая сторонняя библиотека и даже
любое ваше приложение является модулем, так как представляет собой набор связ
ных пакетов с различным уровнем зависимостей (внутренними или внешними).
Другими словами, в файле go.mod указываются путь импорта модуля, используемая
версия языка программирования и требования к внешним зависимостям, от которых
зависит успешность сборки проекта. Если такие зависимости есть, то в корневом
каталоге модуля также создается файл go.sum, позволяющий убедиться, что модули,
представляющие зависимости проекта, не были изменены.

  Как и пакеты, модули делятся на два типа.
   yy Исполняемый. Должен содержать исполняемый пакет main.
   yy Неисполняемый (служебный). Может содержать любые пакеты, кроме ис
      полняемого. Такой модуль не является самостоятельным и может высту
      пать только в качестве внешней зависимости для другого служебного или
     исполняемого модуля.

2.2.1. Создание и инициализация модуля
Создайте в любом месте на жестком диске директорию golang, а в ней поддиректо
рию first (в пути используйте только латинские символы). Затем откройте first
в VS Code (через меню FileOpen Folder (ФайлОткрыть папку)). Далее создайте
файл main.go, содержащий такой код:

   // baseURL/part_2/2.2/2.2.1-2.2.2/golang/first/main.go
   package main

   import "fmt"

   func main() {
       fmt.Println("Hello!")
   }
   Теперь нажмите F5 и попробуйте запустить проект, сборка которого должна
завершиться следующей ошибкой времени компиляции:

   go: go.mod file not found in current directory or any parent directory; see 'go help
   modules' (exit status 1)
   Поскольку текущий проект не представляет собой модуль с файлом go.mod
в директории first, все попытки его сборки и запуска будут неудачными. Чтобы
справиться с этой проблемой, выполним в терминале команду, инициализировав
текущий модуль:

   go mod init golang/first
где golang/first — путь для импорта модуля. Если вы планируете выставить его
в публичный доступ или если в компании есть требование хранить исходный код
в системе контроля версий, то для импорта можно использовать следующий формат
пути: github.com/владелецРепозитория/имяМодуля. В этой строке кроется одно из
