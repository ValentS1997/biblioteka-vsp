126       Глава 2   Функции, модули, пакеты и их тестирование

  К функциям, переменным, структурам и так далее в подключаемом пакете не
обходимо обращаться через его имя (например fmt.Println), поэтому мы внесем
в код функции main следующие изменения:

   func main() {
       firstUUID := uuid.New()
       fmt.Println(firstUUID)
       fmt.Println(utils.replaceSymbols(firstUUID, "–", ""))
       secondUUID := uuid.New()
       fmt.Println(utils.mergeUUID(firstUUID, secondUUID))
       fmt.Println(utils.contains(firstUUID, "e"))
       fmt.Println(utils.contains(secondUUID, "e"))
   }
  Но даже в этом случае приложение не запустится, а будет выдавать ошибку о том,
что функции нельзя импортировать из модуля utils. В Go при создании пакетов
имеет значение, с какой буквы — прописной или заглавной — будет начинаться объ
явление функции, переменной или структуры. Если, как в нашем случае, функция
начинается с прописной буквы, то будет считаться приватной и доступ к ней можно
получить только в рамках пакета, в котором она была объявлена. Именно поэтому
все работало, когда используемые в примере функции находились в пакете main.
Чтобы получить к ним доступ сейчас, перейдите в файл uuid_convertor.go и из
мените первые символы имен функций с прописных на заглавные:

   // baseURL/part_2/2.2/2.2.6/golang/first/utils/uuid_convertor.go
   package utils

   import (
       "strings"

       "github.com/google/uuid"
   )

   func ReplaceSymbols(oldUUID uuid.UUID, old, new string) string {
       return strings.ReplaceAll(oldUUID.String(), old, new)
   }

   func MergeUUID(first, second uuid.UUID) string {
       return first.String() + second.String()
   }

   func Contains(uuid uuid.UUID, symbol string) bool {
       return strings.ContainsAny(uuid.String(), symbol)
   }
   После чего внесите необходимые изменения в файл main.go и запустите при
ложение (не забудьте сохранять вносимые изменения):

   // baseURL/part_2/2.2/2.2.6/golang/first/main.go
   package main

   import (
       "fmt"
       "golang/first/utils"

       "github.com/google/uuid"
   )
