2.2.6. Создание пакета
В Go первая строчка файла с кодом должна указывать, к какому пакету он будет
относиться, и начинаться с ключевого слова package. Если разрабатываемое при
ложение представляет собой исполняемый модуль, то в его корневом каталоге все
файлы с расширением *.go будут входить в пакет main. Иначе пакет должен на
зываться точно так же, как каталог проекта. В нашем случае это, например, first.
Обычно файл с функцией верхнего уровня main, откуда приложение начинает
работу, так и называется — main.go.
  В корневой директории проекта first создадим еще один файл uuid_convertor.go,
в который добавим функции для работы с UUID (рис. 2.9):

   package main

   import (
       "strings"

       "github.com/google/uuid"
   )

   func replaceSymbols(oldUUID uuid.UUID, old, new string) string {
       return strings.ReplaceAll(oldUUID.String(), old, new)
   }

   func mergeUUID(first, second uuid.UUID) string {
       return first.String() + second.String()
   }

   func contains(uuid uuid.UUID, symbol string) bool {
       return strings.ContainsAny(uuid.String(), symbol)
   }
