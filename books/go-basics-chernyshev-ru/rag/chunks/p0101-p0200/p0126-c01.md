2.2. Модули и пакеты      125

никакие дополнительные импорты в файле main.go не требуются, и можно написать
следующий код:

   // baseURL/part_2/2.2/2.2.6/golang/first/main.go
   package main

   import (
       "fmt"

       "github.com/google/uuid"
   )

   func main() {
       firstUUID := uuid.New()
       fmt.Println(firstUUID) // ed02c85b–eb41–4dec–8035–44bef491508d
       fmt.Println(replaceSymbols(firstUUID, "–", ""))
       // ed02c85beb414dec803544bef491508d
       secondUUID := uuid.New()
       fmt.Println(mergeUUID(firstUUID, secondUUID))
       // ed02c85b–eb41–4dec–8035–44bef491508d0298720a–8255–46a1–95f5–61e3d926e77b
       fmt.Println(contains(firstUUID, "e")) // true
       fmt.Println(contains(secondUUID, "e")) // true
   }
   Теперь создадим в корневом каталоге проекта директорию utils и переместим
туда файл uuid_convertor.go (рис. 2.10).

                                 Рис. 2.10. Текущая структура проекта

  Из пакета main пропали функции replaceSymbols, mergeUUID и contains, поэтому
приложение сейчас не соберется и в код необходимо внести несколько исправлений.
Для начала откройте файл uuid_convertor.go и замените первую строку с package
main на package utils, после чего в файле main.go импортируйте созданный пакет:

   package main

   import (
       "fmt"
       "golang/first/utils"

       "github.com/google/uuid"
   )
