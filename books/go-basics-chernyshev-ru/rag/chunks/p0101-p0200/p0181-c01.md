3.9. Еще немного магии интерфейсов
А что, если переменной интерфейсного типа можно присвоить строковое значение?
Вы поверите в такое утверждение? Но прежде чем мы перейдем к его доказательству
или опровержению, рассмотрим, какое значение такая переменная принимает по
умолчанию в момент ее объявления:

   // baseURL/part_3/3.9/1.go
   package main

   import "fmt"

   func main() {
       var myInterface interface{}
       fmt.Printf("%v", myInterface) // <nil>
   }
  Как видите, интерфейс можно объявлять даже без методов, что позволяет при
сваивать переменной интерфейсного типа любой тип значений:

   // baseURL/part_3/3.9/2.go
   package main

   import "fmt"

   type shape struct {
       name string
   }

   func (s *shape) getName() string{
       return s.name
   }

   func main() {
       var firstInterface interface{} = shape{name: "Cube"}
       var secondInterface interface{} = "Oo"

       fmt.Printf("%+v\n", firstInterface)  // {name:Cube}
       fmt.Printf("%+v\n", secondInterface) // Oo
   }
   Переменная firstInterface не дает возможности обращаться к методам при
своенной ей структуры, и, чтобы это исправить, придется использовать операцию
утверждения типа: i.(T), где i — переменная интерфейсного типа, а Т — тип, кото
рый, как мы утверждаем, изначально присваивался переменной. Другими словами,
интерфейсный тип необходимо привести к тому типу данных, значение которого ему
присваивалось. Если в качестве Т указать не исходный тип данных, то произойдет
ошибка времени выполнения:
