  Аналогичным образом ключевое слово defer можно использовать в любых объ

   // baseURL/part_2/2.1/2.1.10/3.go
   package main

   import "fmt"

   func add(a, b int) int {
     defer fmt.Println("defer") // выполнится перед return
     fmt.Println("without defer")
     return a + b
   }

   func main() {
     fmt.Println(add(42, 13))
   }
   // without defer
   // defer
   // 55

2.2. Модули и пакеты
При написании кода, который будет использоваться многократно, его принято
выносить в отдельные элементы — единицы организации программ наивысшего
уровня. Такая единица упаковывает программный код и данные, а также предо
ставляет изолированные пространства имен, цель которых — свести к минимуму
конфликты имен переменных внутри программы.
  Для такого представления кода проекта в Go используются модули и пакеты.
Пакеты делятся на два типа.
   yy Исполняемый. К этому типу относится лишь пакет main (package main), файлы
      которого могут размещаться только в главной директории проекта. В этом
      пакете обязательно должна быть определена функция верхнего уровня main,
     обеспечивающая запуск приложения.
   yy Пакет утилит. К этому типу относятся все остальные пакеты, содержащие
     служебные функции, определения структур и т. д., которые могут быть ис
     пользованы исполняемым пакетом.
