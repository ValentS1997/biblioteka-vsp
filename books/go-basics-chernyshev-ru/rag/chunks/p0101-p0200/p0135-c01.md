134       Глава 2   Функции, модули, пакеты и их тестирование

                            Рис. 2.14. Успешный результат выполнения тестов

   Внесем изменение в код одной из функций, чтобы она возвращала некорректное
значение:

   func Add(a, b int) int {
       return a + b + 1
   }
  И запустим тестирование заново. Результат показан на рис. 2.15.

                                Рис. 2.15. Результат выполнения тестов

  Мы получили ошибку с сообщением о том, что резуль
тат не соответствует ожидаемому.
  Кроме того, тесты можно запускать и в VS Code. Для
этого в боковом меню выберите раздел Testing (Тестиро
вание) со значком         . Вы увидите перечень доступных
тестов (рис. 2.16).
   Наведите указатель мыши на любой из тестов и щелк
ните на значке , чтобы запустить либо конкретный тест,
либо все тесты выбранного поддерева. Для примера за     Рис. 2.16. Тесты, имеющиеся
