3.1. Тип данных Struct      153

  Если структура должна быть экспортируемой (доступной из других пакетов),
то ее имя должно начинаться с заглавной буквы. Если нет — с прописной. Это от
носится и к полям структур.

3.1.1. Объявление и создание структуры
Представьте, что вы должны описать сотрудника фирмы. Прежде всего задайте
себе вопрос: «Какими характеристиками он должен обладать?» Конечно, их может
быть много, но для наглядности выделим четыре: имя, возраст, название отдела,
в котором он работает, и должность:

   type employee struct {
       name           string
       departmentName string
       age            uint8
       position       string
   }
   Объявить переменную типа employee и инициализировать ее поля значениями
по умолчанию можно несколькими способами:

   // baseURL/part_3/3.1/1.go
   package main

   import "fmt"

   type employee struct {
       name           string
       departmentName string
       age            uint8
       position       string
   }

   func main() {
       var emp employee
       emp2 := employee{}
       fmt.Println(emp, emp2) // {  0 } {  0 }
   }
  Чтобы задать явные значения полей у создаваемого объекта, в фигурных скобках
явно пропишите, какое значение будет принимать то или иное поле:

   // baseURL/part_3/3.1/2.go
   func main() {
       emp1 := employee{
           name:           "Alex",
           age:            25,
           departmentName: "R&D",
           position:       "Assistant",
       }
       emp2 := employee{
           name:     "Tom",
           position: "Intern",
       }

       fmt.Println(emp1) // {Alex R&D 25 Assistant}
       fmt.Println(emp2) // {Tom  0 Intern}
   }
