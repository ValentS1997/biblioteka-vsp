162       Глава 3   Объектно-ориентированное программирование в Go

  Тип структуры, которому мы добавили методы, находится в отдельном пакете,
поэтому, чтобы разрешить к ним обращение, мы их сделали публичными (имя ме
тода начинается с заглавной буквы). Теперь в пакете main с помощью объявленных
методов можно работать с полем color структуры Shape:

   // baseURL/part_3/3.3/golang/factory/main.go
   package main

   import (
       "fmt"
       "golang/factory/shape"
   )

   func main() {

       myShape := shape.Shape{
           Name:   "Cube",
           Center: shape.Point{X: 4, Y: 5},
       }

       fmt.Printf("%+v\n", myShape)
       myShape.SetColor("Gold")
       fmt.Printf("%+v\n", myShape)
       fmt.Printf("Shape color: %v\n", myShape.GetColor())
   }
   // {Name:Cube Center:{X:4 Y:5} color:}
   // {Name:Cube Center:{X:4 Y:5} color:Gold}
   // Shape color: Gold

3.4. Конструкторная функция
В ООП под конструктором понимается метод класса, который всегда вызывается
первым и отвечает за создание его экземпляров, а также за инициализацию значений
полей создаваемого экземпляра класса. В Go классов нет, поэтому объявить такую
функцию придется нам. Она должна возвращать значение типа данных создавае
мой в ней структуры. Обычно этой функции дают имя New, но если в пакете есть
несколько структур, экземпляры которых должны создаваться через функцию, то
к New добавляется тип структуры (NewShape).
  Для примера нескольких реализаций таких функций добавим в конец файла
shape.go следующий код:

   // baseURL/part_3/3.4/golang/factory/shape/shape.go
   func NewShape(name, color string, x, y int) Shape{
       return Shape{
           Name: name,
           color: color,
           Center: Point{X: x, Y: y},
       }
   }

   func NewShapeWithPoint(name, color string, center Point) *Shape{
       return &Shape{
           Name: name,
           color: color,
           Center: center,
       }
   }
