2.1.10. Отложенное выполнение функции
Оператор defer позволяет отложить выполнение функции перед вызовом оператора
return (или завершить функцию, в которой return нет). В основном defer исполь
зуют для закрытия файлов и сокетов, разблокировки мьютексов и т. д. С помощью
defer можно при открытии файла или ресурса сразу объявить его отложенное
закрытие, которое произойдет при завершении функции или кода основного при
ложения. Благодаря такому подходу вы можете быть уверены, что не забудете
освободить ресурсы после их использования.
   Если в теле функции несколько отложенных функций, то выполняться они будут
не в порядке своего объявления, а по принципу LIFO (last in first out — «послед
ним зашел, первым вышел»), то есть сначала выполнится последняя объявленная
функция, затем та, которая перед ней, и т. д.
   Рассмотрим несколько примеров работы оператора defer. Начнем с более слож
ного, а затем перейдем к более простому.

   // baseURL/part_2/2.1/2.1.10/1.go
   package main

   import "fmt"

   func main() {
       for i := 0; i < 3; i+ + {
           defer fmt.Printf("%d ", i)
       }
       fmt.Println("Finish!")
   }

   // Finish!
   // 2 1 0
