140       Глава 2   Функции, модули, пакеты и их тестирование

2.3.5. Тестирование производительности
Наверняка вам интересна скорость выполнения функций. Она особенно важна, когда
речь идет о задаче, над которой вы работали не один день, или когда вам необходимо
соблюсти жесткие требования заказчика к производительности продукта. Либо же
когда вы хотите оценить, улучшилась ли новая реализация функциональности по
сравнению с предыдущей (ведь если нет, то код придется дорабатывать).
  В этих случаях Go дает возможность выполнять бенчмарк-тесты. Любой такой
тест должен начинаться со слова Benchmark, за которым следует имя теста (или имя
тестируемой функции, метода), первое слово которого пишется с большой буквы.
А на вход подается только один аргумент — указатель на тип testing.B.
  В пакете calculator создайте файл calculator_bench_test.go и добавьте в него
несколько бенчмарк-тестов:

   // baseURL/part_2/2.3/2.3.5/golang/testing/calculator/calculator_test.go
   package calculator

   import "testing"

   func BenchmarkMul(b *testing.B) {
       for i := 0; i < b.N; i+ + {
           Mul(5, 10)
       }
   }

   func BenchmarkPow2(b *testing.B) {
       for i := 0; i < b.N; i+ + {
           Pow2(5)
       }
   }
   Тестовая функция будет запускать целевой код b.N раз, где N — целое число,
которое можно настроить при запуске теста. Если значение b.N не задано, то оно
корректируется до тех пор, пока функция бенчмарка не будет работать достаточно
долго, чтобы ее можно было надежно синхронизировать.
  При запуске команды go test ./... -bench=. будет выведена только общая ин
формация (рис. 2.24).

                              Рис. 2.24. Результат запуска бенчмарк-тестов

  Для получения более подробной информации по тесту необходимо указать его
название. Например:

   go test ./... -bench=Pow2
или

   go test ./... -bench=Mul
