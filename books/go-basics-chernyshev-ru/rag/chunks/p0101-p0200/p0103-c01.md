  Для возвращения значения из функции используется ключевое слово return.
При этом тип возвращаемого значения должен совпадать с тем, который указан
в сигнатуре (объявлении) функции. В нашем случае это тип string.
  Go позволяет возвращать из функции не одно, а сразу несколько значений. Для
этого их необходимо обернуть в круглые скобки, тем самым создав кортеж. Для при
мера напишем функцию, которая возвращает результат сложения и проверки a > b:

   package main

   import "fmt"

   func main() {
       rez, check := add(10, 8)
       fmt.Printf("a + b = %d, a > b = %t", rez, check)
   }

   func add(a, b int) (int, bool) {
       return a + b, a > b
   }
   // a + b = 18, a > b = true
   Когда из функции возвращается насколько значений, кортеж должен обязатель
но распаковаться, а его элементы — присвоиться переменным. Иначе при попытке
собрать программу произойдет следующая ошибка:

   func main() {
       rez := add(10, 8) // assignment mismatch: 1 variable but add returns 2 values
       fmt.Printf("a + b = %d", rez)
   }
   Если же одно из возвращаемых значений не будет использоваться в дальнейшем,
то при распаковке кортежа на месте неиспользуемой переменной поставьте символ
нижнего подчеркивания (_):

   func main() {
       rez, _ := add(10, 8)
       fmt.Printf("a + b = %d", rez) // a + b = 18
   }
  При объявлении функции, возвращающей одно или несколько значений, перед
их типом можно указать имя, что эквивалентно объявлению переменных в начале
тела функции, которые будут инициализированы значением по умолчанию. Такие
переменные можно использовать для хранения как промежуточного результата,
