3.5. Инкапсуляция и сокрытие в Go      163

  В конструкторную функцию NewShape, которая возвращает копию созданной
структуры, передаются имя фигуры, ее цвет и координаты ее центра. А в функции
NewShapeWithPoint, предназначенной для создания экземпляра структуры, ис
пользуется структура Point и возвращается указатель на оригинальную структуру,
экземпляр которой был создан в функции.
   Теперь вызовем их из пакета main, чтобы создать экземпляры структур Shape:

   // baseURL/part_3/3.4/golang/factory/main.go
   package main

   import (
       "fmt"
       "golang/factory/shape"
   )

   func main() {
       myShape1 := shape.NewShape("Cube", "Gold", 4, 5)
       myShape2 := shape.NewShapeWithPoint("Circle", "Green",
                                            shape.Point{X: 5, Y: 7})
       fmt.Printf("%+v\n", myShape1)  //{Name:Cube Center:{X:4 Y:5} color:Gold}
       fmt.Printf("%+v\n", *myShape2) //{Name:Circle Center:{X:5 Y:7} color:Green}
   }

3.5. Инкапсуляция и сокрытие в Go

Во многих книгах инкапсуляция и сокрытие описываются как тождественные по
нятия, однако на самом деле это не так. Под инкапсуляцией понимается объединение
данных и методов (функций) работы с ними в одну оболочку. В таких объектно-
ориентированных языках, как С++, Java и т. д., оболочкой обычно выступает класс,
а в Go — пакет, имя которого можно использовать для обращения к определенным
в нем функциям, типам данных и их методам или глобальным переменным.
  С помощью сокрытия настраивается доступ к инкапсулированным методам
и данным. То есть некоторые методы или определенные в пакете типы могут быть
служебными и должны использоваться только в рамках пакета, в котором объявле
ны. Поэтому их имена начинаются с маленькой буквы (объявлены как приватные).
А имена методов, функций или типов данных, которые может использовать другой
разработчик, будут начинаться с заглавной буквы (объявлены как публичные).
   Используя вместе инкапсуляцию и сокрытие, разработчик обеспечивает инва
риантность данных. Другими словами, когда он заявляет, что пакет инкапсулирует
тип данных (структуру) и методы работы с ним, то дает гарантию, что другим раз
работчикам доступны только такие способы работы с этой структурой, при которых
они не могут случайным образом установить ее полям значения, не соответствующие
онтологии (правилам) предметной области.
  Чтобы вы могли лучше понять написанное выше, разберем следующий пример.
У нас есть структура, описывающая работника фирмы и содержащая его имя, возраст
и прочие поля, а также методы работы с ними. Все поля структуры публичные, но
их значения также можно получать или устанавливать с помощью методов. Из-за
публичности полей структуры какой-то разработчик может, не вызывая необходи
мый метод, установить значение поля напрямую. Например, задать возраст — 9 лет.
