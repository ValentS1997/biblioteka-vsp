160       Глава 3   Объектно-ориентированное программирование в Go

3.2. Объявление методов и принципы работы с ними
Если в классических объектно-ориентированных языках программирования ме
тоды присущи только классам, то в Go их связывают с различными экземплярами
именованных типов данных. Это как назначить типу функцию, которую сможет
вызывать любой экземпляр этого типа данных. Именно благодаря такой особен
ности в Go и можно писать объектно-ориентированный код.
   Вот общий вид объявления метода:

   func (приемник тип_приемника) имяМетода(аргументы) [(возвращаемый_тип_данных)] {
       // тело функции
       [return возвращаемое_значение]
   }
  На первый взгляд метод от функции отличается только наличием приемника.
Однако на самом деле есть еще несколько различий:
   yy если функция может выступать как аргумент другой функции или присваи
      ваться переменной, то с методом такие действия невозможны;
   yy в одном пакете у методов может быть одинаковое имя, а у функций — нет.
   Рассмотрим пример назначения типу метода, где введем структуру RUB и свяжем
с ней методы конвертации рублей в доллары и евро:

   // baseURL/part_3/3.2/1.go
   package main

   import "fmt"

   type RUB uint // пользовательский именованный тип RUB

   const RUB2USD uint = 61
   const RUB2EUR uint = 65

   // связываем тип RUB с методом конвертации рублей в доллары
   func (r RUB) convertRUB2USD() uint {
       return uint(r) / RUB2USD
   }

   // связываем тип RUB с методом конвертации рублей в евро
   func (r RUB) convertRUB2EUR() uint {
       return uint(r) / RUB2EUR
   }

   func main() {
       var rub RUB = 3475
       fmt.Printf("%d рублей примерно = %d долларов\n", rub, rub.convertRUB2USD())
       fmt.Printf("%d рублей примерно = %d евро\n", rub, rub.convertRUB2EUR())
   }
   // 3475 рублей примерно = 56 долларов
   // 3475 рублей примерно = 53 евро
  Чтобы увидеть особенность методов, добавим к структуре еще один метод,
устанавливающий новое значение переменной экземпляра RUB:

   // baseURL/part_3/3.2/2.go
   func (r RUB) setNewValue(rub RUB) {
       r = rub
       fmt.Printf("В кошельке теперь %d рублей\n", r)
   }
