2.1. Функции в Go      107

  Первый способ более громоздкий, и результат проверки элемента с необходимым
значением в срезе возвращается неявно, что в разработке считается плохим тоном.
Второй способ более корректный, поскольку уже по самому описанию функции мы
можем понять, что и зачем подается ей на вход, а также каким будет итог ее работы
(возвращается переменная типа bool).

2.1.2. Псевдонимы типов (alias declarations)
Иногда входной аргумент или возвращаемое значение могут иметь сложносостав
ной тип. Например:

   // baseURL/part_2/2.1/2.1.2/1.go
   package main

   import "fmt"

   func myFunc(value map[string]map[string][]int) {
       fmt.Println(value)
   }

   func main() {
       myMap := map[string]map[string][]int{
           "a": {"a2": []int{2, 5, 3}},
           "b": {"bbc": []int{0, 10, 3}},
           "c": {"alex": []int{}},
       }
       myFunc(myMap)
   }

   // map[a:map[a2:[2 5 3]] b:map[bbc:[0 10 3]] c:map[alex:[]]]
   Такой формат очень сложно читать, и, чтобы облегчить работу себе или спе
циалисту, которому предстоит поддерживать приложение в дальнейшем, такие
объявления типов лучше сокращать. Для этого в Go используется ключевое
слово type:

   // baseURL/part_2/2.1/2.1.2/2.go
   package main

   import "fmt"

   type MyType map[string]map[string][]int

   func myFunc(value MyType) {
       fmt.Println(value)
   }

   func main() {
       myMap := MyType{
           "a": {"a2": []int{2, 5, 3}},
           "b": {"bbc": []int{0, 10, 3}},
           "c": {"alex": []int{}},
       }
       myFunc(myMap)
   }

   // map[a:map[a2:[2 5 3]] b:map[bbc:[0 10 3]] c:map[alex:[]]]
