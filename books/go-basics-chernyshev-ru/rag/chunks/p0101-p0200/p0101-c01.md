Глава 2
ФУНКЦИИ, МОДУЛИ, ПАКЕТЫ
И ИХ ТЕСТИРОВАНИЕ

Go поставляется с мощной стандартной библиотекой, в которой предопределены
различные функции. С некоторыми из них вы уже познакомились (функция Println
из пакета fmt), но должны уметь писать и собственные.
  В Go функции относятся к объектам первого класса, поэтому их можно присваи
вать переменным, хранить в структурах данных, передавать в качестве аргументов
другим функциям и даже возвращать в качестве значений из других функций. Они
могут принимать произвольное количество аргументов или не принимать их вовсе.
Таким образом, функции позволяют использовать заключенный в них код сколько
угодно раз в процессе выполнения программы и являются альтернативой любимого
метода начинающих программистов: copy&paste, избавляя от необходимости пи
сать одинаковый код. Но самое главное преимущество от их использования — это
то, что они позволяют добавить в разрабатываемое вами приложение различные
уровни абстракции.

2.1. Функции в Go
Для начала рассмотрим общий шаблон объявления функции:

   func имяФункции([имяАргумента1 ТипВходногоАргумента1, …, n]) [(возвращаемый тип
   данных)] {
       // тело функции
       [return возвращаемое значение]
   }
  В квадратных скобках указаны необязательные элементы при объявлении
функции, которые могут не использоваться. Для примера самой простой функции
давайте из любимого всеми разработчиками приложения Hello World! перенесем
строку вывода в терминал из функции верхнего уровня main в функцию hello:

   package main

   import "fmt"

   func main() {
       hello() // вызов функции hello
       fmt.Println("exit")
   }
