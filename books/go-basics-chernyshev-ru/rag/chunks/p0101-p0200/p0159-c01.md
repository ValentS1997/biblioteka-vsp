158       Глава 3   Объектно-ориентированное программирование в Go

   type shape struct {
       name   string
       center point
   }

   func main() {
       myShape := shape{
           name:   "Cube",
           center: point{x: 10, y: 6},
       }
       fmt.Printf("%+v\n", myShape) // {name:Cube center:{x:10 y:6}}
   }
   Структура является пользовательским типом данных, поэтому может исполь
зоваться при объявлении анонимного поля другой структуры:

   type shape struct {
       name   string
       point
   }

3.1.7. Публичные и приватные поля структуры
До этого момента мы работали со структурами только в рамках пакета main, и не име
ло значения, с какой буквы (заглавной или прописной) начиналось ее имя или имя
полей. Однако регистр становится важен, когда необходимо выделить структуру
в отдельный пакет, после чего импортировать и использовать. Вы, как разработчик,
должны при проектировании приложения определять, к каким полям структуры
и функциям пакета будет доступ, а каким — нет.
   Создайте новый каталог shape и в нем файл shape.go, после чего напишите
следующий код:

   // baseURL/part_3/3.1/3.1.7/golang/factory/shape/shape.go
   package shape

   type Point struct {
       X int
       Y int
   }

   type Shape struct{
       Name string
       Center Point
   }
  У обеих структур имена названий и полей начинаются с большой буквы, по
этому при импортировании и их дальнейшем использовании не возникнет никаких
проблем:

   // baseURL/part_3/3.1/3.1.7/golang/factory/main.go
   package main

   import (
       "fmt"
       "golang/factory/shape"
   )
