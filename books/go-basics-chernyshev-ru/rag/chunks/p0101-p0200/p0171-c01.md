170       Глава 3   Объектно-ориентированное программирование в Go

  Внешний вид треугольника, описываемого
структурой Triangle, показан на рис. 3.1.
   Итак, наступила пора добавить щепотку магии
приведения типов! Но прежде еще раз обратите
внимание на методы интерфейсов. Они специ
ально выбраны так, чтобы были общими у реа
лизуемых в коде структур фигур.
   Внесем в исполняемый пакет main следующие        Рис. 3.1. Формат представления
изменения и запустим код:                                             треугольника
   // baseURL/part_3/3.7/golang/factory/main.go
   package main

   import (
       "fmt"
       "golang/factory/shape"
   )

   func main() {
       rectangle := shape.NewRectangle(10, 6, shape.Point{X: 6, Y: -8}, "Gold")
       triangle := shape.NewTriangle(6, 10, 8, shape.Point{X: -85, Y: 15}, "Green")
       fmt.Printf("%+v\n", *rectangle)
       fmt.Printf("%+v\n", *triangle)

       fmt.Printf("\nWork with Rectangle through the interface\n")

       // приведение Rectangle к интерфейсу
       ishape := shape.IShape(rectangle)
       fmt.Printf("Interface: %+v\n", ishape)
       fmt.Printf("Area of a shape: %+v\n", ishape.GetArea())

       fmt.Printf("\nWork with Triangle through the interface\n")
       ishape = shape.IShape(triangle) // приведение Triangle к интерфейсу
       fmt.Printf("Interface: %+v\n", ishape)
       fmt.Printf("Area of a shape: %+v\n", ishape.GetArea())
   }
   /*
   {shape:{name:Rectangle center:{X:6 Y:-8} color:Gold} width:10 length:6}
   {shape:{name:Triangle center:{X:-85 Y:15} color:Green} abLength:6 acLength:10
   bcLength:8}

   Work with Rectangle through the interface
   Interface: &{shape:{name:Rectangle center:{X:6 Y:-8} color:Gold} width:10 length:6}
   Area of a shape: 60

   Work with Triangle through the interface
   Interface: &{shape:{name:Triangle center:{X:-85 Y:15} color:Green} abLength:6
   acLength:10 bcLength:8}
   Area of a shape: 84.85281374238569 */
   Переменная ishape интерфейсного типа дает возможность подменять реализа
ции приводимых к ней структур, связанных с методами реализаций этого интер
фейса. Теперь нам все равно, с чем выполняется работа: с прямоугольником или
треугольником, — для нас это просто фигура с набором методов! Помимо того что
интерфейс позволил ввести уровень абстракции в разрабатываемое приложение,
он добавил сокрытие методов структуры, которые не соответствуют объявленным
в интерфейсе. Более наглядный пример приведен на рис. 3.2, где показаны наборы
методов: у переменной интерфейсного типа после приведения к ней структуры
Rectangle и у переменной экземпляра этой структуры.
