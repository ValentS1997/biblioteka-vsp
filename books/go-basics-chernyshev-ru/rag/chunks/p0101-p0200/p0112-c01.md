2.1. Функции в Go      111

   type MyFunctionAdd func(a int, b int) int

   func sub(c, a, b int, addFunc MyFunctionAdd) int {
       return c - addFunc(a, b)
   }

   func main() {
       fmt.Println(sub(4, 3, 10, func(a, b int) int {
           return a + b
       })) // –9

       myFunc := func(a, b int) int {
           return a + b - 20
       }
       fmt.Println(sub(4, 3, 10, myFunc)) // 11
   }

2.1.7. Замыкания
Замыкания — довольно мощный инструмент, в основе которого лежит возмож
ность функций запоминать значения переменных из более верхних (объемлющих)
областей видимости, то есть из тех областей, где была объявлена функция. Идея
замыкания состоит в том, что одна функция может возвращать другую, которая,
в свою очередь, может принимать на вход значения, совершенно отличные от тех,
которые подаются функции верхнего уровня, но использует данные, определенные
в этой функции. Звучит немного запутанно, не правда ли?
  В качестве примера рассмотрим завод, производящий бытовую технику. Каждый
день ему поставляют оборудование и забирают с него изготовленные микроволно
вые печи, которые развозят по магазинам. В конечном счете одну из печей продают
покупателю. Он ставит в нее тарелку с едой, задает режим работы, а печь нагревает
блюдо, используя внутренние компоненты, установленные в нее при производстве.
В этом примере завод олицетворяет функцию верхнего уровня, а микроволновая
печь — возвращаемую вложенную функцию.
