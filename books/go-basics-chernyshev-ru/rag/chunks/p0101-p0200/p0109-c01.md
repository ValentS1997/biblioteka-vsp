2.1.3. Область видимости переменных
В языке программирования Go используется лексическая область видимости объ
ектов. Это значит, что каждый блок кода имеет доступ к переменным, которые
были объявлены на уровне выше, то есть «над» ним. Поэтому самой обширной
областью видимости обладают глобальные переменные, которые объявляются вне
каких-либо функций:

   // baseURL/part_2/2.1/2.1.3/1.go
   package main

   import "fmt"

   var global string = "Global value"

   // global := "Global value" // так объявлять нельзя, будет ошибка

   func myFunc() {
       fmt.Println(global)
   }

   func main() {
       fmt.Println(global)
       myFunc()
   }

   // Global value
   // Global value
   Если в текущем блоке кода мы объявим и инициализируем переменную с именем,
которое уже использовалось в объемлющей области видимости, то новая переменная
перекроет доступ к значению переменной, объявленной выше. В качестве примера
в функции myFunc определим переменную с тем же именем, что у глобальной, но
другого типа:

   // baseURL/part_2/2.1/2.1.3/2.go
   package main

   import "fmt"

   var global string = "Global value"

   func myFunc() {
       global := 10
       fmt.Println(global)
   }

   func main() {
       fmt.Println(global) // Global value
       myFunc() // 10
   }
