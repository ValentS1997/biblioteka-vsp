3.10. Обобщения (generics)

Обобщения (generics), или дженерики, позволяют уменьшить дублирование кода —
проблему, которая была очень критичной до версии Go 1.18. Поскольку в Go нет
перегрузки функций или методов, то благодаря дженерикам разработчики могут
использовать единый интерфейс и реализацию для многих типов. Это часто быва
ет полезным, если создаваемые структуры различаются только типом некоторых
переменных, принимаемых на вход типов аргументов методов (или функций), либо
типом возвращаемых ими значений.
  В качестве примера рассмотрим ситуацию, когда функция должна складывать
подаваемые на вход значения аргументов и возвращать полученный результат.
До версии 1.18 для каждого возможного типа данных надо было создавать свою
функцию:

   // baseURL/part_3/3.10/1.go
   package main

   import "fmt"

   func SumInt(a, b int) int {
       return a + b
   }

   func SumFloat(a, b float64) float64 {
       return a + b
   }

   func SumString(a, b string) string {
       return a + b
   }

   func main() {
       fmt.Println(SumFloat(10.3, 45.1)) // 55.4
       fmt.Println(SumInt(10, 45)) // 55
       fmt.Println(SumString("^_", "^")) // ^_^
   }

   Появление дженериков позволило сократить код:

   // baseURL/part_3/3.10/2.go
   package main

   import "fmt"
