114       Глава 2   Функции, модули, пакеты и их тестирование

   Теперь реализуем суммирование элементов списка с помощью косвенной ре
курсии:

   // baseURL/part_2/2.1/2.1.8/2.go
   package main

   import "fmt"

   func sumElem(slice []int) int {
       fmt.Println(slice)
       if len(slice) < = 1 {
           return slice[0]
       }
       return anotherFunction(slice)
   }

   func anotherFunction(slice []int) int {
       return slice[0] + sumElem(slice[1:])
   }

   func main() {
       mySlice := []int{2, 5, 22, 9, 0}
       fmt.Println(sumElem(mySlice))
   }
   // [2 5 22 9 0]
   // [5 22 9 0]
   // [22 9 0]
   // [9 0]
   // [0]
   // 38
  При реализации рекурсии необходимо задать условие выхода из нее. Если этого
не сделать, то возникнет бесконечный цикл, который не остановится до тех пор,
пока стек вызовов не переполнится, а это может произойти нескоро, поскольку Go
способен автоматически увеличивать размер стека.

2.1.9. Генераторные функции
Эти функции используются для ленивой генерации последовательности значений
по запросу. Они служат хорошей альтернативой срезам и массивам, поскольку
в этом случае мы не храним данные в памяти, а создаем объект с необходимым нам
текущим значением только в момент обращения к генераторному объекту.
  Для создания генераторных функций используются горутины и каналы (более
подробно о них поговорим в одной из следующих глав):

   // baseURL/part_2/2.1/2.1.9/1.go
   package main

   import "fmt"

   func createGenerator(start int, end int) chan int {
       ch := make(chan int, end–start)
       go func(ch chan int) {
           for i := start; i < = end; i+ + {
               ch <– i // помещение значения в канал
           }
           close(ch)
       }(ch)
       return ch
   }
