Резюме      505

Задания на доработку проекта
    1. Улучшите визуальную составляющую клиентского приложения, реализовав
     цветной текстовый интерфейс с использованием ANSI-кодов.
    2. Добавьте таймер для временного ограничения хода каждого игрока. Если
     время заканчивается — ход переходит к противнику.
    3. Добавьте поддержку пользовательских правил игры (например, выигрывает
     первый игрок, заполнивший квадрат, или засчитываются только диагональ
     ные победы).
    4. Добавьте пользователю возможность создавать новые игровые комнаты на
      сервере.
    5. Позвольте другим клиентам подключаться в качестве зрителей для про
     смотра текущих игр.
    6. При игре с компьютером на легком уровне сложности пользователь должен
      иметь возможность отменить несколько ходов, а затем при желании вернуть их.
    7. Добавьте в проект функцию повторного пошагового просмотра игры.
    8. Перепишите сетевую часть проекта, чтобы для взаимодействия клиента
     и сервера использовались веб-сокеты.
    9. Перепишите сетевую часть проекта, чтобы клиент и сервер взаимодейство
     вали через REST API.

Резюме
В этой главе мы рассмотрели возможности Go при написании приложений, взаимо
действующих по сети (включая разработку REST API веб-сервисов). Мы обсудили
инструменты, позволяющие сформировать спецификацию API еще до реализации
кода сервиса, а также проверить корректность работы сервиса (Bruno). Такой под
ход широко используется в продуктовых компаниях, поскольку позволяет заранее
продумать структуру API и одновременно с этим сформировать документацию,
понятную всем участникам команды.
   Конечно, структура проекта веб-сервиса ToDo-list далека от идеального образца
чистой архитектуры или предметно-ориентированного проектирования (Domain
Driven Design, DDD). Но в этом разделе и не было цели создать идеал. Главное,
к чему я стремился, — чтобы сложность написания таких приложений перестала
вас пугать. А навык правильно формировать структуру проекта, взаимодействовать
с базой данных и вводить дополнительные слои абстракции при проектировании
подобных приложений вы отточите со временем, когда будете изучать более специа
лизированную литературу.

версию v.7, переведя ее на клиент-серверную архитектуру.
