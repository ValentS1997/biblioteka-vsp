328       Глава 6   Работа с СУБД SQLite

                                   Рис. 6.15. Данные таблицы tasks

  Для создания запроса нажмите в SQLITE EXPLORER значок   (New Query (Создать
запрос)). После чего наберите следующий текст запроса и запустите его на вы
полнение, нажав Ctrl+Shift+Q. Результат выполнения запроса показан на рис. 6.16.

   -- SQLite
   SELECT p.name, p.description, t.name, t.description, t.priority, t.is_done
   FROM projects as p, tasks as t
   WHERE p.id = t.project_id
   ORDER BY t.priority DESC;
