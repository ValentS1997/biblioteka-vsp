6.1. Разработка приложения ToDo-list с помощью модуля go-sqlite3      323

       for {
           menu.CreateMenu(rep)
           time.Sleep(2 * time.Second)
       }
   }
   Задержка 2 секунды перед перерисовыванием меню поставлена потому, что при
вводе данных не исключены «дребезги» клавиши Enter при вводе данных, то есть
сразу вызовется номер меню по умолчанию (список всех задач в базе). Кроме того,
меню довольно громоздкое, поэтому пользователь может не заметить, что прило
жение корректно отработало его запрос.

6.1.12. Запуск приложения и примеры его использования
Для запуска приложения откройте в VS Code терминал и введите следующую
команду:

   go run .\main.go
  В корневой директории проекта добавится файл todo.db базы данных SQLite,
в который внесены значения по умолчанию. В самом терминале запустится меню
приложения с предложением выбрать необходимое действие (рис. 6.2).

                                 Рис. 6.2. Запуск приложения ToDo-list

  Если вы ничего не выберете, а просто нажмете клавишу Enter, то выведется спи
сок всех записанных в базу задач, так как для этого пункта меню (под номером 4)
установлен режим «Выбор по умолчанию» (рис. 6.3).
   Теперь выведем список всех проектов, выбрав пункт меню под номером 2
(рис. 6.4).
