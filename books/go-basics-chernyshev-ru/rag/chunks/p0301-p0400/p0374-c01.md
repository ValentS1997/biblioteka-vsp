7.5. Каналы      373

   Используя оператор select, код можно переписать, сделав более элегантным
и компактным:

   // baseURL/part_7/7.5/10.go
   func main() {
       ping := make(chan int, 1)
       pong := make(chan int, 1)

       ping < - 1

       go play(ping, pong)

       time.Sleep(2 * time.Second)
       fmt.Println("Exit")
   }

   func play(ping, pong chan int) {
       var ball int
       for {
           select {
           case ball = < -ping:
               fmt.Println("Ping", ball)
               time.Sleep(500 * time.Millisecond)
               pong < - ball + 1
           case ball = < -pong:
               fmt.Println("Pong", ball)
               time.Sleep(500 * time.Millisecond)
               ping < - ball + 1
           }
       }
   }
   /*Ping 1
   Pong 2
   Ping 3
   Pong 4
   Exit /*
   Все каналы оператора select проверяются одновременно, и если все из указанных
в нем каналов окажутся недоступными, то оператор select будет заблокирован до
тех пор, пока не освободится хоть один канал. А если доступны несколько каналов
или все сразу, то среда выполнения Go определит канал для чтения, используя
метод случайного выбора.
  Одной из проблем, с которой можно столкнуться при таком подходе к написанию
кода, являются взаимоблокировки каналов. В этом случае ни один из блоков case
не будет выполнен, что приведет к блокировке самого оператора. Избежать такого
стечения обстоятельств можно при добавлении еще одной ветки case, которой на
вход с заданным интервалом времени будет подаваться значение текущего времени,
что разблокирует оператор select:
