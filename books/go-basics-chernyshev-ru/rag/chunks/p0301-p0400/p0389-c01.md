7.9. Переменная среды выполнения GOMAXPROCS
Эта переменная позволяет ограничить количество используемых потоков опе
рационной системы, которые могут одновременно выполнять код приложения.
По умолчанию ее значение равно количеству логических ядер процессора системы,
на которой запускается программа. Само количество потоков, которое можно «за
бронировать», ничем не ограничено, однако очень большое значение может ухудшить
работу приложения.
  Для начала узнаем, сколько логических ядер у процессора вашего компьютера:

   // baseURL/part_7/7.9/1.go
   package main

   import (
       "fmt"
       "runtime"
   )

   func getGOMAXPROCS() int {
       return runtime.goMAXPROCS(0)
   }

   func main() {
       fmt.Printf("GOMAXPROCS: %d\n",runtime.NumCPU())
       // NumCPU возвращает количество логических CPU,
       // используемых текущим процессом.
   }
   // В моем случае GOMAXPROCS: 12
  Чтобы понять, как количество потоков влияет на производительность, исполь
зуем пример с атомарным счетчиком и замерим время выполнения приложения,
внеся в функцию main следующие изменения:

   // baseURL/part_7/7.9/2.go
   func main() {
       var waitGroup sync.WaitGroup
       counter := &AtomicCounter{0}
       myTime := time.Now()
       for i := 0; i < 100_000; i+ + {
           waitGroup.Add(1)
           go increment(&waitGroup, counter)
       }
       waitGroup.Wait()
       fmt.Println("Value after 1k increment  = ", counter.Value())
       fmt.Printf("Time work: %v", time.Since(myTime))
   }
   // Value after 1k increment  =  100000
   // Time work: 56.6341ms
