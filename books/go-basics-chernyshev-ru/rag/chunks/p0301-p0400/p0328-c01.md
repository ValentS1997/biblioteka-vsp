6.1. Разработка приложения ToDo-list с помощью модуля go-sqlite3      327

   Далее щелкните на файле todo.bd правой кнопкой мыши и в контекстном меню
выберите пункт Open Database (Открыть базу данных) (рис. 6.12).

                             Рис. 6.12. Установка соединения с базой данных

  В нижней части поля Explorer появится графа SQLITE EXPLORER, открыв которую
можно получить доступ к структуре базы и запустить вывод всех строк конкретной
таблицы. Для демонстрации этого функционала обозначим задачу с ID = 4 как вы
полненную (рис. 6.13).

                                 Рис. 6.13. Выполнение задачи с ID = 4

  Выберем таблицу tasks и запустим ее показ (рис. 6.14).

                       Рис. 6.14. Запрос на отображение всех данных таблицы tasks

  В результате в VS Code появится дополнительная вкладка с содержимым табли
цы (рис. 6.15).
