308       Глава 6   Работа с СУБД SQLite

6.1.1. Структура проекта
В качестве первого шага создайте следующую структуру проекта, добавив необхо
димые директории и файлы в них:

   todo
   ├── db/
   │          ├── db_definition.go
   │          ├── db.go
   │          ├── models.go
   │          ├── projects_crud.go
   │    └── tasks_crud.go
   │
   ├── menu/
   │          ├── menu.go
   │          ├── project_handlers.go
   │    └── task_handlers.go
   ├── go.mod
   └── main.go
  В каталоге db и одноименном пакете будет размещен код, отвечающий за работу
с базой данных: создание БД, запись, чтение и удаление данных, а также выполнение
запросов. В каталоге menu и одноименном пакете будет содержаться функциональ
ность, которая отвечает за взаимодействие с пользователем: предоставление ему
терминального меню, вызов методов структуры, инкапсулирующей в себе логику
работы с БД, и вывод данных в терминал.
  Чтобы упростить проектирование функциональности меню для консольного
режима, мы будем использовать модуль wmenu. Откройте терминал и добавьте этот
модуль в зависимости проекта:

   go get github.com/dixonwille/wmenu

6.1.2. Структура базы данных проекта
Мы проектируем базу для ведения списка дел, поэтому она должна содержать как
минимум две таблицы: projects (проекты) и tasks (задачи).
  В таблице projects будут храниться следующие данные:
   yy числовой уникальный идентификатор (первичный ключ);
   yy имя (текст);
   yy описание (текст).
  А для таблицы tasks зададим следующие поля:
   yy уникальный идентификатор (число) — первичный ключ;
   yy имя задачи (текст);
   yy числовой приоритет (число);
   yy описание задачи (текст);
   yy флаг о выполнении (булево значение);
   yy идентификатор проекта для данной задачи (число) — вторичный ключ.
