7.10.3. Очередь (Queuing)
Паттерн «Очередь» позволяет обрабатывать одновременно сразу несколько элемен
тов и используется в случаях, когда необходимо распределить выполнение N задач
между M горутинами. Обычно для его реализации используется буферизованный
канал. Так, например, емкость канала будет служить ограничителем для количества
одновременно обрабатываемых элементов.
   Структура паттерна выглядит так (рис. 7.3).
