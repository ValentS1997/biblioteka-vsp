7.5. Каналы      369

  В буферизованный канал записано три элемента, но он не был перепол
нен, вследствие чего главная горутина main не заблокировалась, дав возмож
ность отработать горутине myPrint, и приложение завершилось выводом только
строки Exit.
  А теперь переполним буфер канала, внеся следующие изменения в функцию main:

   // baseURL/part_7/7.5/3.go
   func main() {
       myChannel := make(chan int, 3) // объявление буферизованного канала
       defer close(myChannel)         // отложенное закрытие канала
       go myPrint(myChannel)
       myChannel < - 3
       myChannel < - 10 // запись значения 10 в канал
       myChannel < - 77
       myChannel < - 105
       myChannel < - 104
       fmt.Printf("\nExit")
   }
   // 3 10 77
   // Exit

  А переполнение буфера канала приведет к следующей ошибке:

   // baseURL/part_7/7.5/4.go
   func main() {
       myChannel := make(chan int, 3)
       defer close(myChannel)         // отложенное закрытие канала
       go myPrint(myChannel)
       for i := 0; i < 10; i+ + {
           myChannel < - i
       }
       fmt.Printf("\nExit")
   }
   /* 0 1 2
   fatal error: all goroutines are asleep - deadlock!

   goroutine 1 [chan send]:
   main.main()
       d:/code/golang/channels/main.go:20 +0x14b */

7.5.2. Указание направления передачи
При использовании каналов в качестве аргумента функции можно указывать огра
ничения на направление передаваемых данных:

   // baseURL/part_7/7.5/5.go
   package main

   import (
       "fmt"
       "time"
   )

   func onlyRead(c < -chan int) { // только для чтения
       for i := 0; i < = 3; i+ + {
           value := < -c
           fmt.Printf("%d ", value)
       }
   }
