6.1. Разработка приложения ToDo-list с помощью модуля go-sqlite3      309

работе с базой данных, описание структур таблиц и имени создаваемой базы будет
отвечать файл db_definition.go. Добавьте в него следующий код:

   // baseURL/part_6/6.1/golang/todo/db/db_definition.go
   package db

   import "errors"

   const dbName = "todo.db"

   var (
       ErrDuplicate    = errors.New("record already exists")
       ErrNotExists    = errors.New("row not exists")
       ErrUpdateFailed = errors.New("update failed")
       ErrDeleteFailed = errors.New("delete failed")
   )

   // имена проектов нельзя повторять
   const ProjectTabelDefinition = `
   CREATE TABLE IF NOT EXISTS projects(
       id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
       name TEXT UNIQUE,
       description TEXT
   );
   `

   const TaskTabelDefinition = `
   CREATE TABLE IF NOT EXISTS tasks(
       id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
       name TEXT NOT NULL,
       description TEXT NOT NULL,
       priority INTEGER NOT NULL,
       is_done BOOLEAN NOT NULL CHECK (is_done IN (0, 1)),
       project_id INTEGER not null references projects(id)
   );
   `
   Значения уникальных идентификаторов таблиц будут автоматически увели
чиваться на 1 при добавлении новых записей, то есть нет необходимости задавать
их вручную. Столбец name таблицы projects обозначен как уникальный, поэтому
попытка добавить проект с именем, которое уже используется в приложении, будет
приводить к ошибке. Столбец project_id таблицы tasks обозначен как вторичный
ключ и связан с уникальным идентификатором проекта отношением «один ко мно
гим», что позволит использовать запросы, объединяя данные сразу из двух таблиц.
