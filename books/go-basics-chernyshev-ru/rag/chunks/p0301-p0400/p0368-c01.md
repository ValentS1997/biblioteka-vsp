7.5. Каналы

Каналы — механизм коммуникации и обмена данными между горутинами. Для их
объявления используется конструкция: chan T, где chan — ключевое слово, указы
вающее на создание канала, а T — тип элемента канала.
  При объявлении канала соблюдайте эти простые правила:
   yy каждый объявляемый канал позволяет обмениваться только данными опре
      деленного типа;
   yy у каждого объявляемого канала должен быть поставщик и потребитель пере
     даваемой информации;
   yy не забывайте закрывать каналы, используя для этого функцию close();
   yy при попытке чтения данных из закрытого канала будет возвращено нулевое
      значение для соответствующего типа данных элемента канала.

7.5.1. Особенности работы с каналами
Канал можно рассматривать как очередь LIFO (last-in-first-out — «последним вошел,
первым вышел»), что позволяет одной горутине выступать в качестве поставщика
информации, а другой — потребителя. И так как любая разработанная программа
на Go всегда запускается в горутине, то их можно объявлять и использовать из
функции main:
