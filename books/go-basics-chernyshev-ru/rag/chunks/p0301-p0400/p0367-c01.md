366       Глава 7   Конкурентность в Go

  Если количество вызовов метода Add и Done у переменной типа sync.WaitGroup
не будет совпадать, это приведет к экстренному завершению программы:

   // baseURL/part_7/7.4/2.go
   package main

   import (
       "fmt"
       "sync"
   )

   func namedGorutine(number int, waitGroup *sync.WaitGroup) {
       defer waitGroup.Done() // уменьшение счетчика sync.WaitGroup на 1
       fmt.Printf("%d ", number)
   }

   func main() {
       var waitGroup sync.WaitGroup

       waitGroup.Add(1) // приведет к ошибке!
       fmt.Printf("%#v\n", waitGroup)

       for i := 0; i < = 30; i+ + {
           waitGroup.Add(1) // увеличение счетчика на 1
           go namedGorutine(i, &waitGroup)
       }

       fmt.Printf("\n%#v\n", waitGroup)
       waitGroup.Wait()
   }
   /*
   sync.WaitGroup{noCopy:sync.noCopy{}, state1:0x100000000, state2:0x0}
   0 5 2 6 4 8 7 9 1 11 10 12 13 16 15 14 17 18 19 21 20 22 3 24 23 25 26
   sync.WaitGroup{noCopy:sync.noCopy{}, state1:0x500000000, state2:0x0}
   30 27 28 29
   fatal error: all goroutines are asleep - deadlock!

   goroutine 1 [semacquire]:
   sync.runtime_Semacquire(0xc0000140a0?)

  В этом случае программа ожидала завершения на одну горутину больше, чем
было создано. И, так как ожидание могло продлиться бесконечно долго, она экс
тренно завершилась с ошибкой: fatal error: all goroutines are asleep - deadlock!
  Если вызовов метода Done будет больше, чем Add, это приведет к панике:

   // baseURL/part_7/7.4/3.go
   func main() {
       var waitGroup sync.WaitGroup

       fmt.Printf("%#v\n", waitGroup)
       waitGroup.Done() // приведет к панике!
       for i := 0; i < = 30; i+ + {
           waitGroup.Add(1) // увеличение счетчика на 1
           go namedGorutine(i, &waitGroup)
