Задания на доработку проекта
В следующей главе мы разберем, какие механизмы в Go позволяют писать конку
рентный код, и с их помощью ускорим поиск лучшего хода компьютера на больших
игровых досках при игре на высоком уровне сложности. А пока предлагаю выпол
нить следующие задания.
    1. Перепишите проект, используя вместо gorm чистый SQLite.
    2. Добавьте в проект функцию повторного пошагового просмотра игры. Для
       этого:
     •  реализуйте сохранение в истории каждого хода игроков;
     •  реализуйте навигацию вперед/назад по ходам игры;
     •  отобразите временные метки для каждого хода;
     •  добавьте возможность экспорта повтора в виде текстового файла.
