6.2. Разработка ToDo-list с помощью модуля gorm
Любая ORM предоставляет возможность работать с базой данных (выполнять
операции CRUD) с использованием объектно-ориентированной парадигмы. Такой
подход уменьшает количество кода и возможных ошибок при написании запро
сов вручную. Однако главным недостатком любой ORM-библиотеки является ее
сложность, а также то, что генерируемые ею сложные запросы к базе будут неоп
тимальными в отличие от тех, которые можно написать вручную.
  Мы не будем переписывать приложение ToDo-list с нуля, а изменим лишь
часть, касающуюся пакета db, поэтому скопируйте каталог предыдущего проекта,
переименовав его в todo_gorm, после чего откройте в VS Code. Сразу приступить
к написанию кода нам мешает то, что в проекте не хватает всего одной внешней
зависимости. Установим ее с помощью таких команд в терминале:

   go get -u gorm.io/gorm
   go get -u gorm.io/driver/sqlite
  Модуль gorm представляет собой обертку над пакетом database/sql и позволяет
работать с довольно большим перечнем СУБД: MySQL, SQLite, PostgreSQL и т. д.

6.2.1. Создание базы данных
Прежде всего внесем изменения в файл db_definition.go, а именно удалим лишний
код:

   // baseURL/part_6/6.2/golang/todo_gorm/db/db_definition.go
   package db

   import "errors"

   const dbName = "todo.db"

   var (
       ErrDuplicate    = errors.New("record already exists")
       ErrNotExists    = errors.New("row not exists")
       ErrUpdateFailed = errors.New("update failed")
       ErrDeleteFailed = errors.New("delete failed")
   )
   За структуру создаваемой в проекте базы данных теперь будут отвечать струк
туры из файла models.go. Используя теги, можно явно указать свойства столбцов
таблиц. В нашем случае таблицы в базе будут создаваться на основе структур
Project и ProjectTask:

   // baseURL/part_6/6.2/golang/todo_gorm/db/models.go
   package db

   type Project struct {
       ID          int    `gorm:"primary_key;autoIncrement:true;not null"`
       Name        string `gorm:"unique;not null"`
       Description string
   }

   type Task struct {
       ID          int    `gorm:"primary_key;autoIncrement;not null"`
       Name        string `gorm:"not null"`
