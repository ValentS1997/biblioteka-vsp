Рефакторинг пакета model
Если вы еще не удалили из корневой директории проекта пакет storage — самое время
это сделать. Следующим шагом необходимо внести изменение в структуру GameSnap
shot, добавив поле с именем сохраняемого или загружаемого снапшота игровой сессии:

   // baseURL/part_6/tic_tac_toe_v5/model/game_snapshot.go
   package model

   import (
       b "tic-tac-toe/board"
       p "tic-tac-toe/player"
   )

   // Структура для сериализации/десериализации игры
   type GameSnapshot struct {
       SnapshotName   string       `json:"snapshot_name"`
       Board          *b.Board     `json:"board"`
       PlayerFigure   b.BoardField `json:"player_figure"`
       State          int          `json:"state"`
       Mode           int          `json:"mode"`
       Difficulty     p.Difficulty `json:"difficulty,omitempty"`
   }
   Далее создайте в текущем пакете файл finish_game_shapshot.go и откройте его.
В него мы поместим код структуры, представляющей собой снапшот FinishGameSnap
shot последней стадии игры, когда произошло объявление победителя:

   // baseURL/part_6/tic_tac_toe_v5/model/finish_game_shapshot.go
   package model

   import (
       "tic-tac-toe/board"
       "time"
   )
