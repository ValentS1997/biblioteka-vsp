326       Глава 6   Работа с СУБД SQLite

  Чтобы удостовериться в том, что выполненная задача удалена, а новая добавлена,
повторно выведем список всех задач проекта (рис. 6.10).

                                Рис. 6.10. Список всех задач проекта Go

  Чтобы сделать работу с реляционными базами данных более удобной, пользуй
тесь DBeaver Community (либо его аналогами) или расширениями для VS Code.
Например, в VS Code есть одноименное расширение для SQLite, позволяющее
открыть соединение с базой, мониторить в ней изменения в процессе работы при
ложения и организовывать различные запросы, проверяя их корректность еще до
момента переноса в код.
   Перейдите в боковом меню VS Code на панель расширений (Extensions) либо
нажмите сочетание клавиш Ctrl+Shift+X и введите в поле поиска SQLite, после чего
установите первое в списке расширение (рис. 6.11).
