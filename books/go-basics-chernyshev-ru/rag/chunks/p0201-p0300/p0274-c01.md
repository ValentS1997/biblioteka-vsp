5.6. Сборка и конфигурация запускаемого приложения       273

   Если вы сейчас запустите приложение, нажав F5 или используя терминал VS Code,
то флаги будут инициализированы значением по умолчанию:

   PS C:\...\5.6\my_app> go run main.go
   String flag: value
   Int flag: 0
   Bool flag: false
  Чтобы добавленному в приложение флагу передать входные данные, укажем
его в команде запуска после main.go. Для типа bool хватает упоминания флага,
чтобы перевести его в состояние true, в то время как для других типов данных по
сле указания флага следует добавить символ = и передаваемое по флагу значение:

   PS C:\...\5.6\my_app> go run main.go -int=33 -bool
   String flag: value
   Int flag: 33
   Bool flag: true
  Аналогичным образом вы можете передавать флаги и в скомпилированное
приложение:

   PS C:\...\5.6\my_app> go build
   PS C:\...\5.6\my_app> .\my_app.exe -int=40
   String flag: value
   Int flag: 40
   Bool flag: false
  А если пользователю вашего приложения будет что-то непонятно или он за
будет, какой флаг за что отвечает, то сможет использовать флаг -h (help), который
выведет перечень флагов конфигурации и их описание (пакет flag добавляет этот
флаг в приложение по умолчанию):

   PS C:\...\5.6\my_app> go run main.go -h
   Usage of C:\...\main.exe:
     -bool
           BoolFlag description
     -int int
           IntFlag description
     -str string
           StrFlag description (default "value")
  Этих трех типов флагов (строка, число, bool) хватит для большинства сценариев
конфигурации запускаемого приложения. Если же вам чего-то не хватает или вы
хотите подробно изучить особенности работы со встроенным пакетом flag — об
ратитесь к его официальной документации.

5.6.3. Конфигурация на этапе компиляции через -ldflags
В отличие от предыдущего этот способ конфигурации приложения позволяет во
время компиляции задать значение переменным пакетов приложения в формате
полный_путь_до_пакета.переменная_пакета =значение. Они интегрируются в испол
