  Для демонстрации такого варианта конфигурации приложения для начала по
требуется создать новое консольное приложение (в моем случае — my_compile_app)
и добавить в файл main.go следующий код:

   // baseURL/part_5/5.6/my_compile_app/main.go
   package main

   import (
       "fmt"
   )

   var VersionType = "dev"
   var Version = "0.0.1"

   func main() {
       fmt.Printf("Version: %s (%s)\n", Version, VersionType)
   }
   Теперь откройте терминал и введите следующую команду для запуска сборки
приложения, передав ему используемые в коде переменные окружения:

   PS C:\...\my_compile_app> go build -ldflags "-X main.Version=1.2.3 -X main.
   VersionType=test"

   После чего запустите получившийся исполняемый файл:

   PS C:\...\my_compile_app> .\my_compile_app.exe
   Version: 1.2.3 (test)
  При этом не забывайте, что в процессе сборки вы можете указывать нужное вам
количество флагов. Так, например, поменяем имя компилируемого файла:

   PS C:\...\my_compile_app> go build -ldflags "-X main.Version=1.2.3 -X main.
   VersionType=test" -o my_app.exe
   PS C:\...\my_compile_app> .\my_app.exe
   Version: 1.2.3 (test)
  Помимо рассмотренных возможностей, флаг -ldflags обладает еще рядом ин
тересных свойств. Так, например, при передаче ему нескольких дополнительных
настроек вы можете снизить размер скомпилированного приложения на 30–40 %,
удалив из него таблицу символов и информацию отладчика:

   PS C:\...\my_compile_app> go build -ldflags="-s -w"
   // или
   PS C:\...\my_compile_app> go build -ldflags "-s -w -X main.Version=1.2.3 -X main.
   VersionType=test"
