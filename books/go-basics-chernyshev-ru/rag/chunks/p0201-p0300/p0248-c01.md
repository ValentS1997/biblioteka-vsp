5.3. Операции с JSON-файлами      247

  В данный момент нам не нужно добавлять конструкторные функции для каждой
структуры или методов работы с их экземплярами (добавить актера, обзор и т. д.),
поэтому ограничимся только концептуальным разделением структур по файлам.
Почему концептуальным? Потому что благодаря наличию в Go встроенного про
токола сериализации в JSON и десериализации из JSON мы можем поместить все
объявления структур в один файл из пакета imdb — movie.go.

   // baseURL/part_5/5.3/filmography/imdb/actor.go
   package imdb

   type Actor struct {
       Name        string `json:"name"`
       Age         int    `json:"age"`
       FilmsAmount int    `json:"filmsAmount"`
       AboutActor  string `json:"aboutActor"`
   }

   // baseURL/part_5/5.3/filmography/imdb/genre.go
   package imdb

   type Genre struct {
       Types []string `json:"types"`
   }

   // baseURL/part_5/5.3/filmography/imdb/review.go
   package imdb

   type Review struct {
       Name   string `json:"name"`
       Text   string `json:"text"`
       Rating int    `json:"rating"`
   }

   // baseURL/part_5/5.3/filmography/imdb/movie.go
   package imdb

   type Movie struct {
       Name           string   `json:"name"`
       Budget         int      `json:"budget"`
       Actors         []Actor  `json:"actors"`
       CriticsRating  float64  `json:"criticsRating"`
       AudienceRating float64  `json:"audienceRating"`
       Year           int      `json:"year"`
       Country        string   `json:"country"`
       Genre          Genre    `json:"genre"`
       Reviews        []Review `json:"reviews"`
   }
   Теперь мы можем прочитать данные из JSON-файла, десериализовать их в объ
ект, после чего сериализовать этот объект и записать получившийся результат
в новый файл. Для этого перейдите к файлу main.go в основной директории проекта:

   package main
