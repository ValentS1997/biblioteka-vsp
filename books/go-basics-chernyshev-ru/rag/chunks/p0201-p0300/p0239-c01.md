238       Глава 5   Работа с файлами и каталогами. Сборка приложения

5.3. Операции с JSON-файлами
JSON (JavaScript Object Notation) — довольно простой и повсеместно используе
мый формат обмена данными. Его достаточно удобно читать как человеку, так
и компьютеру. Дополнительным достоинством JSON является то, что он, по сути,
представляет собой текстовый формат данных и полностью независим от языка
реализации. То есть данные, сохраненные в JSON-формате средствами одного языка
программирования, можно использовать в приложении, которое реализовано на
другом языке. Именно поэтому JSON обрел огромную популярность и широкое
распространение.

5.3.1. Основы JSON
В JSON используются две структуры.
   yy Коллекция пар «ключ:значение» (объект). На разных языках программиро
     вания концепция такого объекта реализована по-своему. В Go в качестве
      такой коллекции могут использоваться типы данных struct и map[string]any.
   yy Упорядоченный список значений (массив, список, последовательность и т. д.).
  Таким образом, каждый объект — это неупорядоченная коллекция пар
«ключ:значение», и его тело заключается в фигурные скобки: {объект}.
  Ключом может выступать только строковый тип данных. Каждый ключ за
ключается в двойные кавычки ("имяКлюча"), за которым ставится разделительный
символ : (двоеточие), а сами пары «ключ:значение» разделяются запятой.
   Значение может представлять собой строку в двойных кавычках, число, логиче
ский тип данных (true/false), null (nil), объект или массив. То есть объект может
содержать в себе другой объект, массив из объектов или прочих свойств.
  В качестве примера возьмем описание объекта Movie (Фильм) в JSON-формате
со списком актеров, жанром и пользовательскими обзорами:

   {
       "name": "Prevozmogun",
       "budget": 2000000,
       "actors": [

               "name": "Alexey",
               "age": 25,
               "filmsAmount": 3,
               "aboutActor": "2 academy awards"
           },
           {
               "name": "Max",
               "age": 33,
               "filmsAmount": 2,
               "aboutActor": "Very good actor"
           },
           {
               "name": "Natalya",
               "age": 18,
               "filmsAmount": 1,
               "aboutActor": "Rising star"
           }
       ],
