5.1. Операции с файлами      223

  Дело в том, что при таком открытии файла на запись она будет вестись с его
начала и старые данные перезапишутся. При этом часть их может остаться,
поскольку объем записываемых данных меньше хранящихся в файле. Для кор
ректного добавления данных в существующий файл необходимо использовать
флаг O_APPEND:

   file, err := os.OpenFile("pirates2.txt", os.O_WRONLY|os.O_APPEND, 0666)

  А для чтения данных из файла просто поменяйте флаг:

   // baseURL/part_5/5.1/15.go
   package main

   import (
       "fmt"
       "io "
       "log"
       "os"
   )

   func main() {
       file, err := os.OpenFile("pirates2.txt", os.O_RDONLY, 0666)
       if err ! = nil {
           log.Fatal(err)
       }
       defer file.Close()

       data, err := io.ReadAll(file)
       if err ! = nil {
           log.Fatal(err)
       }
       fmt.Println(string(data))
   }
   /*
   Пятнадцать человек на сундук мертвеца,
   Йо-хо-хо, и бутылка рома,
   Пей, и дьявол тебя доведет до конца,
   Йо-хо-хо, и бутылка рома! */
