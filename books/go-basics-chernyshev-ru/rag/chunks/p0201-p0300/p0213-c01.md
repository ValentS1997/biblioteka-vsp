Глава 5
РАБОТА С ФАЙЛАМИ И КАТАЛОГАМИ.
СБОРКА ПРИЛОЖЕНИЯ

В этой главе мы рассмотрим механизмы Go для работы с файлами и директориями.
Файлы могут выступать в разном качестве: быть как конфигурационными, так
и хранилищами. Например, информация, которая может изменяться пользователем
в настройках приложения и влиять на логику его работы, выносится в конфигура
ционные файлы. Это делается для большей гибкости, поскольку хранение такой
информации в коде подразумевает, что при малейшем ее изменении необходимо
заново выполнять сборку (компиляцию) программы. А в качестве примера ис
пользования файлов как хранилищ мы реализуем простую базу данных на основе
односвязного списка.
  Кроме того, мы выполним сборку приложения, а также настроим его конфи
гурацию, передавая необходимые данные через терминал в момент запуска этого
приложения.

5.1. Операции с файлами
В этом разделе поговорим о том, какие действия с файлами можно выполнять в Go
и с помощью каких инструментов.

5.1.1. Создание пустого файла
Для создания пустого файла или перезаписи существующего на пустой используй
те функцию Create. В нее передается путь до создаваемого файла, который может
быть указан относительно корневого диска или директории, где запускается при
ложение. По умолчанию используется второй вариант, что приводит к созданию
в директории проекта файла с задаваемым именем.
  У файла, как объекта приложения, будет тип os.File, предоставляющий методы
как для чтения, так и для записи данных в файл:

   // baseURL/part_5/5.1/1.go
   package main
