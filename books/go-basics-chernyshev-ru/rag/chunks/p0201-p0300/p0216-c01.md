5.1.6. Запись в файл и чтение из него
Данные в файл записываются в байтовом представлении, то есть вместо строки
записывается массив байтов. При чтении данных из файла выполняется обратный
процесс: сначала считывается массив байтов, который далее необходимо преоб
разовать в строку. Вообще все файлы, независимо от их содержимого, хранятся
в байтовом представлении, а специализированные программы, знающие, как
упакованы в этих файлах данные, способны их воспроизводить, открывать или
редактировать.
  Для начала рассмотрим несколько низкоуровневых вариантов записи данных
в файл. В первом случае мы используем функцию, которая приводит текстовый тип
данных к массиву байтов, а во втором выполним такое приведение самостоятельно
перед записью данных в файл:

   // baseURL/part_5/5.1/6.go
   package main

   import (
       "fmt"
       "log"
       "os"
   )

   func main() {
       firstText := "Пятнадцать человек на сундук мертвеца,\n"
       secondText := "Йо-хо-хо, и бутылка рома,"
       file, err := os.Create("pirates.txt")
       if err ! = nil {
           log.Fatal(err)
       }
       defer file.Close()

       // функция WriteString преобразует string в []byte,
       // после чего записывает в файл
       file.WriteString(firstText)
       // ручное приведение типа string в []byte и запись данных в файл
       file.Write([]byte(secondText))
       fmt.Println("Text was wrote to file")
   }
