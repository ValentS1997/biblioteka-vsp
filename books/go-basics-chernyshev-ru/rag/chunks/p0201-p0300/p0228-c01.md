5.1.10. Форматированное чтение из файла
Теперь разберем, какие функции предоставляет пакет fmt для форматированного
чтения данных из уже записанных файлов:
   yy func Fscan(r io.Reader, a ...any) (n int, err error) — считывает текст из r,
     сохраняя последовательные значения, разделенные пробелами, в аргумен
      тах a. Новые строки считаются пробелами. Возвращает количество успешно
     считанных элементов; если оно меньше количества аргументов — возвращает
     ошибку;
   yy func Fscanf(r io.Reader, format string, a ...any) (n int, err error) — счи
      тывает текст из r, сохраняя последовательные значения, разделенные пробе
      лами, в аргументах a с учетом задаваемого формата. Возвращает количество
     успешно считанных элементов;
   yy func Fscanln(r io.Reader, a ...any) (n int, err error) — аналогична Fscan, но
      останавливает считывание на новой строке.
  Для начала используем функцию Fscanln, чтобы прочитать данные из файла
