5.3. Операции с JSON-файлами      243

5.3.3. Использование метаполей (tag) структур при работе с JSON
Структура в Go позволяет добавлять к объявляемым полям метаданные, с помощью
которых можно кодировать и декодировать данные, проверять поля структуры и т. д.
Такая метаинформация может использоваться любым пакетом или библиотекой для
различных целей и добавляется после объявления поля структуры путем указания
строкового литерала, заключенного в обратные кавычки: `tag`. В нашем случае
с помощью метаполей будут заданы имена полей сериализуемой и десериализуемой
структуры Actor, что позволит привести формируемый JSON к его стандартизи
рованному виду. Сейчас имена ключевых полей начинаются с заглавной буквы,
а в формате JSON их принято начинать с прописной:

   // baseURL/part_5/5.3/5.go
   package main

   import (
       "encoding/json"
       "fmt"
       "log"
   )

   type Actor struct {
       // имя поля при сериализации/десериализации
       Name string `json:"name"`
       Age  int    `json:"age"`
       // имя тега может отличаться от имени поля структуры
       FilmsAmount int     `json:"films_amount"`
       AboutActor  *string `json:"about"`
   }

   func main() {
       aboutStr := "Tom Hanks is an actor..."
       actor := Actor{
           Name:        "Tom Hanks",
           Age:         69,
           FilmsAmount: 70,
           AboutActor:  &aboutStr,
       }

       actorJson, err := json.MarshalIndent(actor, "", "  ")
       if err ! = nil {
           log.Fatal(err)
       }

       fmt.Println(string(actorJson))
   }
   /* {
     "name": "Tom Hanks",
     "age": 69,
     "films_amount": 70,
     "about": "Tom Hanks is an actor..."
   } */
  Кроме того, с помощью тегов можно задать поле, которое не должно учитываться
при формировании данных в формате JSON или их восстановлении:

   // baseURL/part_5/5.3/6.go
   package main
