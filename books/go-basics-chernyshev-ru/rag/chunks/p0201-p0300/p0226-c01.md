5.1. Операции с файлами      225

   yy func Fprintln(w io.Writer, a ...any) (n int, err error) — записывает опе
     ранды в w, используя их форматы по умолчанию. Между операндами всегда
     добавляются пробелы, и после последнего ставится символ \n, обозначающий
      переход на новую строку. Возвращает количество записанных байтов и любую
     возникшую ошибку записи.
  На вход этих функций должен подаваться аргумент типа, реализующий интер
фейс io.Writer, поэтому их можно использовать для записи данных в файл.
  В качестве следующего примера реализуем структуру, создадим ее несколько
экземпляров и запишем их данные в файл. Работу первой функции Fprint рассма
тривать не будем, так как она не предназначена для записи сложных структур данных
и ее использование вызовет большие проблемы при попытке их извлечения. Это
связано с тем, что строковый тип данных не отделяется от остальных пробелами,
к тому же нежелательно наличие пробелов в строковых полях структур (характерно
для всех форматов записи):
