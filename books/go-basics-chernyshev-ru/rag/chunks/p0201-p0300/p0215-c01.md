214       Глава 5   Работа с файлами и каталогами. Сборка приложения

5.1.3. Перемещение и переименование файла
В Go нет явной команды для перемещения файла из одной директории в другую.
Для этого можно использовать операцию переименования:

   // baseURL/part_5/5.1/3.go
   package main

   import (
       "log"
       "os"
   )

   func main() {
       originalPath := "test.txt"
       newPath := "../test2.txt"
       // переместит файл на уровень выше и переименует в test2.txt
       // можно также оставить прежнее имя перемещаемого файла — test.txt
       newPath := "test2.txt" // переименование файла в текущей директории
       err := os.Rename(originalPath, newPath)
       if err ! = nil {
           log.Fatal(err)
       }
   }

5.1.4. Удаление файла
Для удаления файла используйте функцию Remove:

   // baseURL/part_5/5.1/4.go
   package main

   import (
       "log"
       "os"
   )

   func main() {
       pathToFile := "test.txt"
       err := os.Remove(pathToFile)
       if err ! = nil {
           log.Fatal(err)
       }
   }

В некоторых случаях необходимо проверить, есть ли в системе тот или иной файл.
