5.4. База данных на основе файла и однонаправленного списка      249

  Первый метод интерфейса будет использоваться для проверки значения по
определенному столбцу таблицы базы данных в записи, реализующей интерфейс.
Второй метод позволит изменить значения по заданному полю записи. А с помо
щью метода String будет выполняться форматированное преобразование объекта
в строковое представление для вывода в терминал.
   Обязанность реализовать этот интерфейс ложится на структуру User из файла
user.go того же пакета. Откройте его и объявите два перечисления. Первое (Acsess
Level) будет отвечать за уровень доступа, который есть у пользователя. А второе
(UserTableFields) позволит не запоминать, какие поля будут у таблицы пользова
телей базы данных, когда мы захотим обратиться к ним через методы интерфейса:

   // baseURL/part_5/5.4/go_database/database/user.go
   package database

   import (
       "fmt"
       "strconv"
       "strings"
   )

   type AccessLevel = string

   const (
       Student AccessLevel = "S"
       Teacher AccessLevel = "T"
       Admin   AccessLevel = "A"
   )

   func AcsessLevelFromString(s string) AccessLevel {
       switch strings.ToUpper(s) {
       case "T":
           return Teacher
       case "A":
           return Admin
       default:
           return Student
       }
   }

   type UserTableField = string

   const (
       FieldID           UserTableField = "id"
       FieldNickname     UserTableField = "nickname"
       FieldYearOfBirth  UserTableField = "yearOfBirth"
       FieldEmail        UserTableField = "email"
       FieldPhone        UserTableField = "phone"
       FieldAccessLevel  UserTableField = "accessLevel"
       FieldPasswordHash UserTableField = "passwordHash"
   )
   Далее все в том же файле user.go объявим структуру User, ее поля (идентифика
тор, псевдоним, год рождения, электронная почта, номер телефона, уровень доступа
и хеш пароля) и реализуем методы интерфейса IAttribute:
