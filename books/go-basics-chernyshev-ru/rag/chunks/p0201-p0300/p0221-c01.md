220       Глава 5   Работа с файлами и каталогами. Сборка приложения

  У каждого из этих способов есть сильная и слабая сторона. Так, например,
не всегда удобно хранить в памяти весь файл, если из него надо считать небольшой
объем данных, либо куда удобнее прочитать файл полностью, чем реализовывать

5.1.7. Универсальная функция OpenFile
Эта функция из пакета os позволяет как создавать файл, так и открывать его для
чтения, записи или добавления данных. Вот ее сигнатура:

   func OpenFile(name string, flag int, perm FileMode) (*File, error),
где name — путь к файлу, flag — режим открытия файла (запись, чтение, добавле
ние и т. д.), а perm — разрешение доступа к файлу.
  С первым аргументом name не должно возникнуть никаких проблем, а вот
остальные обсудим более подробно. В аргументе flag необходимо указать, с какой
целью будет открываться файл. Для этого пакет os предоставляет следующий на
бор констант:

   const (
   /* Между O_RDONLY, O_WRONLY и O_RDWR неприменима операция побитового ИЛИ,
   поэтому при использовании этих флагов файл может открываться только в одном
   из трех режимов */
       // файл открывается только для чтения
       O_RDONLY int = syscall.O_RDONLY

       // файл открывается только для записи
       O_WRONLY int = syscall.O_WRONLY

       // файл открывается для чтения и записи
       O_RDWR   int = syscall.O_RDWR

   /* К остальным значениям применима операция побитового ИЛИ, что позволяет задавать
   комбинацию из режимов открытия файла */
       // добавление данных в файл при записи
       O_APPEND int = syscall.O_APPEND

       // создание нового файла, если не существует
       O_CREATE int = syscall.O_CREAT

       // используется с O_CREATE, файл не должен существовать
       O_EXCL   int = syscall.O_EXCL

       // открытие для синхронного ввода-вывода
       O_SYNC   int = syscall.O_SYNC

       // файл обрезается, но остается возможность записи при открытии
       O_TRUNC  int = syscall.O_TRUNC
   )
   Аргумент perm указывает, кто из пользователей системы имеет доступ к фай
лу для его чтения и записи в него. Обычно это четырехзначное число в восьме
ричной системе счисления, где каждое число отвечает за определенную группу
