5.6. Сборка и конфигурация запускаемого приложения       275

помещается в срез байтов (строку или виртуальную файловую систему embed.FS)
и данные из него нужно десериализовать перед использованием.
  Для демонстрации такого варианта конфигурации приложения для начала по
требуется создать новое консольное приложение (в моем случае — my_embed_app).
Создадим конфигурационный json-файл embed_config.json со следующим содер
жимым:

   {
     "debug": true,
     "offset": 10,
     "version": "0.0.1",
     "app_name": "StaskoGo"
   }
   Теперь откроем файл main.go, свяжем конфигурационный файл со срезом байтов
и реализуем десериализацию данных в структуру Config:

   // baseURL/part_5/5.6/my_embed_app/main.go
   package main

   import (
       _ "embed"
       "encoding/json"
       "fmt"
       "log"
   )

   //go:embed embed_config.json
   var configData []byte

   type Config struct {
       Debug   bool   `json:"debug"`
       Offset  int    `json:"offset"`
       AppName string `json:"app_name"`
       Version string `json:"version"`
   }

   func getConfig() Config {
       var config Config
       err := json.Unmarshal(configData, &config)
       if err ! = nil {
           log.Fatal(err)
       }
       return config
   }

   func main() {
       config := getConfig()
       fmt.Println(config)
   }
  Для проверки работоспособности кода можно запустить его через VS Code, на
жав клавишу F5, либо собрать приложение с помощью команды go build.
   Теперь откройте терминал и введите следующую команду для запуска сборки
приложения, передав ему используемые в коде переменные окружения:

   PS C:\...\my_embed_app> go build
   PS C:\...\my_compile_app> .\my_embed_app.exe
   {true 10 StaskoGo 0.0.1}
