  Прежде чем переходить к написанию кода для работы с JSON, разберем два
определения: сериализация и десериализация данных.
  Под сериализацией (кодированием) понимается процесс преобразования какой-
либо структуры данных в формат, допускающий их хранение и передачу. Для этого
в Go используется функция Marshal из пакета encoding/json, которая позволяет
осуществлять перевод значения любого типа в последовательность байтов.
   Десериализация (декодирование) — обратный процесс, при котором из полу
ченных, загруженных или прочитанных данных выполняется восстановление
структуры данных с необходимыми параметрами. Для этого в Go используется
функция Unmarshal из пакета encoding/json, которая позволяет осуществлять пере
вод последовательности байтов в значение любого типа данных.
  Если внимательно изучить JSON-представление фильма, то можно заметить,
что оно содержит еще три объекта: Review (данные обзорщика фильма, которые
будут храниться в списке по ключу "actors"), Actor (данные актера, которые будут
храниться в списке по ключу "reviews") и Genre (список жанров, см. ключ "genre").
  Для начала разберем базовые возможности сериализации структуры. Для этого
примера нам понадобится объявить структуру Actor и преобразовать ее в после
довательность байтов, которую, в свою очередь, мы приведем к типу string, чтобы
сделать удобным вывод данных в терминал. В качестве титульного актера выберем
Тома Хэнкса:
