5.6. Сборка и конфигурация запускаемого приложения       271

   Далее добавьте в корневую директорию файл main.go:

   package main

   import "fmt"

   func main() {
       fmt.Println("Hello, World!")
       fmt.Println(5 * 5)
   }
  После запуска в терминале VS Code команды на
сборку приложения — go build — в корневой директо
рии проекта появится исполняемый файл my_app.exe
(рис. 5.13).
  Чтобы запустить исполняемый файл, введите в тер
минале:
   PS C:\...\5.6\my_app> .\my_app.exe                           Рис. 5.13. Наполнение директории
   Hello, World!                                                                  проекта
   25
   Теперь перейдем к более сложной команде сборки приложения. Для этого после
флага -о укажите имя выходного исполняемого файла new-app:

   PS C:\...\5.6\my_app> go build -o new-app.exe
  Если в предыдущем способе компилятор Go сам определил расширение для
компилируемого исполняемого файла, то сейчас его нужно задать явно. Хотя даже
если вы этого не сделаете и через терминал запустите получившийся исполняемый
файл без расширения, он заработает. Но если расширения нет, то как пользователь
должен понять, что этот файл исполняемый? Поэтому лучше подстраховаться
и указать это явно. Что же касается других операционных систем, то выбирайте для
исполняемого файла то расширение, которое принято в той экосистеме, с которой
вы работаете в данный момент.
   Точка входа в приложение (функция main) находится в файле main.go (или
другом), располагающемся в корневой директории проекта, поэтому этот файл
можно не указывать при сборке приложения. Если же необходимо запустить ко
манду сборки проекта из другой директории, то можно использовать более полную
версию команды — с указанием пути до файла с функцией main. В качестве при
мера перейдем в терминале в родительскую директорию проекта. В моем случае
это каталог 5.6:

   PS C:\...\5.6\my_app> cd ..
   PS C:\...\5.6>
   Теперь удалите из проекта файл new-app.exe и введите в терминале VS Code
следующую команду, указав после имени компилируемого исполняемого файла
путь до main.go приложения my_app относительно текущей директории:

   PS C:\...\5.6> go build -o new-app.exe .\my_app\main.go
