5.2. Работа с каталогами

В этом разделе поговорим о том, какие операции с директориями можно выполнять
в Go и с помощью каких инструментов.

5.2.1. Создание и удаление каталога
Для создания постоянного каталога используется функция Mkdir из пакета os,
которая создает новый каталог с указанным именем и битами разрешений. Соз
дайте новый проект, инициализируйте его и добавьте в файл main.go следующий
код:

   // baseURL/part_5/5.2/1.go
   package main

   import (
       "fmt"
       "log"
       "os"
   )

   func main() {
       err := os.Mkdir("myDir", 0777)
       if err ! = nil {
           log.Fatal(err)
       }
       fmt.Println("Directory created")
   }
   После запуска приложения в корне проекта создастся директория myDir (рис. 5.7).
