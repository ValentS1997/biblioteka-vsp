230       Глава 5   Работа с файлами и каталогами. Сборка приложения

  Для удаления пустого каталога используется функция Remove из пакета os, на
вход которой подается путь до удаляемого каталога. В нашем случае созданная
директория находится в корневой папке проекта, поэтому указывать до нее полный
путь (как в системе) не нужно:

   // baseURL/part_5/5.2/2.go
   package main

   import (
       "fmt"
       "log"
       "os"
   )
   func main() {
       err := os.Remove("myDir")
       if err ! = nil {
           log.Fatal(err)
       }
       fmt.Println("Directory removed")
   }

5.2.2. Создание и удаление временного каталога
Функция MkdirTemp(dir, pattern string) (string, error) используется для создания
нового временного каталога в указываемой директории и возвращает к нему путь.
Имя создаваемого временного каталога генерируется путем добавления случайной
строки в конец шаблона (pattern). Если шаблон содержит символ *, то он заменя
ется случайной строкой. Если dir является пустой строкой, то функция MkdirTemp
использует системный каталог для временных файлов.
  Для примера использования функции создадим директорию, в которой будут
размещаться временные каталоги с создаваемыми в них файлами:
