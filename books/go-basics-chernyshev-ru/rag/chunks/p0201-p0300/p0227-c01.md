                               Рис. 5.5. Содержимое файла после записи

   Теперь перепишем код функции main так, чтобы для записи данных использо
валась функция Fprintf:

   // baseURL/part_5/5.1/18.go
   func main() {
       myFile, err := os.Create("car_fprintf.txt")
       if err ! = nil {
           log.Fatal(err)
       }
       defer myFile.Close()

       myCar := createCars()
       for _, it := range myCar {
           n, _ := fmt.Fprintf(myFile,
                       "Model: %s ||Number: %s ||Age: %d ||Weight: %f\n",
                        it.model, it.number, it.age, it.weight)
           fmt.Println("Записано: ", n, "байт")
       }
   }
   Обратите внимание на строковый аргумент функции "Model: %s ||Number: %s
||Age: %d ||Weight: %f\n". В нем мы указываем, в какой последовательности будут
записаны поля структуры и в каком формате, а также можем добавлять дополни
тельные разделители или текст. Главное, в процессе чтения использовать тот же
форматированный аргумент, не внося в него изменения, и отлавливать не только
ошибку EOF (завершение файла), но и unexpected EOF.
  Прежде чем мы перейдем к разбору вариантов форматированного считывания,
откройте файл car_fprintf.txt, чтобы убедиться в корректности записанных в него
данных (рис. 5.6).
