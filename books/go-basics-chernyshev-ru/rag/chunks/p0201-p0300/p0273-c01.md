272       Глава 5   Работа с файлами и каталогами. Сборка приложения

вызывалась команда сборки. Чтобы явно указать путь к месту, где следует поместить
компилируемый файл, используйте либо относительный путь от каталога запуска
команды сборки:

   PS C:\...\5.6> go build -o .\my_app\new-app.exe .\my_app\main.go
либо абсолютный путь:

   PS C:\...\5.6> go build -o C:\my_app\new-app.exe .\my_app\main.go
  Помимо -o, существуют и другие флаги компиляции (подробнее о них см. в до
кументации Go). Но самыми актуальными из них на данный момент для вас будут
четыре флага, которые можно чередовать.
   yy -v — выводит в терминал информацию о процессе сборки.
   yy -x — выводит в терминал выполняемые в процессе сборки внутренние
     команды.
   yy -race — запускает в процессе сборки детектор гонок данных. Поддерживается
      только на 64-битных ОС.
   yy -ldflags — используется при конфигурации приложения на этапе компиля
     ции (рассмотрим немного позже в соответствующем подразделе).
  В качестве примера работы данных флагов перейдите в терминале в директорию
проекта my_app и введите команду go build -v -x.

5.6.2. Конфигурация через командную строку
Теперь добавим конфигурацию запускаемого приложения с помощью флагов.
За этот функционал в Go отвечает встроенный пакет flag. В качестве первого шага
немного перепишем тело функции main:

   // baseURL/part_5/5.6/my_app/main.go
   package main

   import (
       "flag"
       "fmt"
   )

   func main() {
       // конфигурируем флаги:
       // Первый аргумент — название флага
       // Второй — значение по умолчанию
       // Третий — описание того, что делает флаг
       myStr := flag.String("str", "value", "StrFlag description")
       myInt := flag.Int("int", 0, "IntFlag description")
       myBool := flag.Bool("bool", false, "BoolFlag description")
       // Запускаем парсинг флагов, подаваемых в командной строке
       flag.Parse()

       // используем флаги
       fmt.Println("String flag:", *myStr)
       fmt.Println("Int flag:", *myInt)
       fmt.Println("Bool flag:", *myBool)
   }
