5.1. Операции с файлами      217

среза, куда считываются данные, не получится полностью вывести строки песни.
Замените 128 на 32 и запустите приложение заново:

   /*
   Reading 32 byte
   Reading 32 byte
   Reading 32 byte
   Reading 19 byte
   Reading 0 byte
   ೦ылка рома,೦о, и бу೦
   Text was read from file
   */
   Согласитесь, получилось не очень хорошо. Эти ограничения можно обойти
двумя способами. Первый — создать еще один срез, куда будут добавляться данные,
считанные на каждой итерации цикла, пока не прочитается весь код до конца файла.
Второй способ — прочитать файл целиком. Начнем с первого способа:

   // baseURL/part_5/5.1/8.go
   func main() {
       file, err := os.Open("pirates.txt")
       if err ! = nil {
           log.Fatal(err)
       }
       defer file.Close()

       tempData := make([]byte, 32)
       data := []byte{}
       for {
           length, err := file.Read(tempData)
           fmt.Printf("Reading %d byte\n", length)
           if err = = io.EOF { // достигли конца файла?
               break
           }
           data = append(data, tempData...)
       }
       fmt.Println(string(data))
   }
   /*
   Reading 32 byte
   Reading 32 byte
   Reading 32 byte
   Reading 19 byte
   Reading 0 byte
   Пятнадцать человек на сундук мертвеца,
   Йо-хо-хо, и бутылка рома,೦о, и бу೦
   */
   Обратите внимание на последнюю строку в выводе, а именно на ее окончание.
Данные в срезе temp на каждой итерации цикла не обнулялись, а перезаписывались
новыми. В итоге в последний раз было перезаписано всего 19 байт из 32, то есть
в крайних 13 байтах осталась данные с предыдущей итерации. Решить эту пробле
