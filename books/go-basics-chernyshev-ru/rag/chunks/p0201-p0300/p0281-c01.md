280       Глава 5   Работа с файлами и каталогами. Сборка приложения

Проект: игра «Крестики-нолики», v.3
В третью версию «Крестиков-ноликов» добавим возможность сохранения игровой
сессии и ее загрузку при старте приложения, чтобы у игроков была возможность
продолжить ранее остановленную игру. После чего проведем рефакторинг игры
и добавим возможность игры с компьютером.
   Откройте проект tic_tac_toe и добавьте в пакет game следующие файлы (вы
делены жирным):

   tic_tac_toe_v3
   ├── game/
   │    ├── board.go
   │    ├── board_cell_type.go
   │    ├── game_state.go
   │    ├── game.go
   │    ├── i_game_storage.go
   │    ├── json_game_storage.go
   │    └── player.go
   ├── go.mod
   └── main.go
  В файле i_game_storage.go объявим интерфейсы, которые должна будет реали
зовать структура, отвечающая за сохранение и загрузку игровой сессии:

   // baseURL/part_5/tic_tac_toe_v3/game/i_game_storage.go
   package game

   type IGameLoader interface {
       LoadGame(path string) (*Game, error)
   }

   type IGameSaver interface {
       SaveGame(path string, game *Game) error
   }

   type IGameStorage interface {
       IGameLoader
       IGameSaver
   }
  Чтобы упростить код, реализуем сохранение игровой сессии в JSON-формате.
Для этого потребуется внести изменения в существующий код классов, а именно
настроить именование полей структур под протокол сериализации и десериализации
пакета json, а также добавить метод сохранения игровой сессии для структуры Game.
  Начнем эту эпопею с игрового поля. Откройте файл board.go, измените имена
полей, которые начинаются с прописных букв, на строчные, не забыв о тегах. Чтобы
вам не пришлось вносить во все файлы изменения, вызванные переименованием
полей, а VS Code сделало это за вас, выделите поле структуры и запустите процесс
переименования, нажав клавишу F2:

   // baseURL/part_5/tic_tac_toe_v3/game/board.go
   type Board struct {
       Board [][]BoardField `json:"board"`
       Size  int            `json:"size"`
   }
   // остальной код без изменений
