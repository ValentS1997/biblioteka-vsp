5.2. Работа с каталогами      235

воспользоваться функцией Chdir из пакета os. После чего все создаваемые файлы
или каталоги, полный путь к которым не указан, будут создаваться относительно
этой директории:

   // baseURL/part_5/5.2/8.go
   package main

   import (
       "fmt"
       "log"
       "os"
   )

   func getWD() {
       path, err := os.Getwd()
       if err ! = nil {
           log.Fatal(err)
       }
       fmt.Println("Current path:", path)
   }

   func main() {
       getWD()
       os.Mkdir("myDir", 0777)
       os.Chdir("./myDir")
       getWD()
       myFile, err := os.Create("test.dat")
       if err ! = nil {
           log.Fatal(err)
       }
       defer myFile.Close()
   }
   // Current path: e:\code\golang\directory
   // Current path: e:\code\golang\directory\myDir
   Обратите внимание на то, что файл test.dat был создан не в корневой дирек
тории проекта, а в каталоге, который был сделан рабочим путем использования
функции Chdir. Чтобы переместиться на уровень выше, перед указанием пути нужно
вставить двоеточие. Так, например, следующий код сделает рабочей директорию,
которая находится на уровень выше, чем корневой каталог проекта:

   // baseURL/part_5/5.2/9.go
   func main() {
       getWD()
       os.Chdir("../")
       getWD()
   }
   // Current path: e:\code\golang\directory
   // Current path: e:\code\golang
   Иногда необходимо пройти по всем каталогам целевой директории, посчитать
количество входящих в них файлов (вложенных в дочерние директории) и т. д.
Сделать это поможет функция WalkDir(root string, fn fs.WalkDirFunc) из пакета
filepath. Ей на вход подается путь до целевой (корневой) директории и функция
с сигнатурой WalkDirFunc func(path string, d DirEntry, err error), которая будет
вызываться для каждого файла или каталога в дереве обхода директории.
