5.2.5. Получение пути до текущей директории проекта
В этом случае необходимо воспользоваться функцией Getwd из пакета os:

   // baseURL/part_5/5.2/7.go
   package main

   import (
       "fmt"
       "log"
       "os"
   )

   func main() {
       path, err := os.Getwd()
       if err ! = nil {
           log.Fatal(err)
       }

       fmt.Println(path) // e:\code\golang\directory
   }
