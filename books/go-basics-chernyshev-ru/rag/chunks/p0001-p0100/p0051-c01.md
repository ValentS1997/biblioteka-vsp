50       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

1.10. Условные конструкции в Go
Go предоставляет две условные конструкции: if–else и switch–case. У каждой из
них своя область применения, которые мы и рассмотрим в следующих подразделах.

1.10.1. Оператор if
Оператор if с необязательным оператором else выбирает действия, которые будут
выполняться в процессе работы программы в зависимости от условий (результата
выполнения выражений), проверяемых после его объявления. Общая форма кон
струкции if–else выглядит так:

   if условие1 {
       блок1
   } else if условие2 {
       блок 2
   } else if условие(n–1){
       блок (n–1)
   } else{
       блок (n)
   }
   Если результат проверки условия1 равен true, то выполнится блок1. Если резуль
тат проверки условия2 равен true, то выполнится блок2 и т. д., пока не будет найдено
условие, которое возвращает true или не будет достигнута секция else (тогда вы
полняется блок(n)). Если else отсутствует и все проверки условий вернули false, то
не выполнится ни один из блоков ветвления. Под условием в данном случае понима
ется выражение, результатом выполнения которого будет значение типа данных bool.
  Каждый день мы так или иначе встречаемся с похожими структурами в реальной
жизни: выпить чай или кофе, поехать на автобусе или трамвае, повернуть налево
или направо и т. д. Ключ к принятию решения — некоторые данные или наши же
лания, на основе которых мы делаем тот или иной выбор. Для примера представим
такую ситуацию. На улице солнечная погода, и в зависимости от температуры нам
нужно решить, что мы наденем: шорты или брюки. Граничное значение температу
ры — 30 градусов по Цельсию, а текущее значение — 20 градусов. Прежде чем при
ступать к написанию кода, изобразим логику ситуации в виде блок-схемы (рис. 1.17).
  В этой блок-схеме текущее значение меньше граничного, поэтому выбор падет
на брюки, о чем и будет выведено сообщение в терминал. Теперь перенесем этот
алгоритм в код, используя условную конструкцию if–else:

   // baseURL/part_1/1.10/1.10.1/1.go
   package main

   import "fmt"

   func main() {
       t := 20
       if t > = 30 {
           fmt.Println("Надеть шорты")
       } else {
           fmt.Println("Надеть брюки")
       }
   }

   // Надеть брюки
