60       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

   Такой вариант обхода коллекции хорошо подходит для ситуаций, когда нужно
организовать сложносоставное условие выхода из цикла. Для всех остальных слу
чаев используйте ключевое слово range, которое на каждом проходе цикла будет
возвращать номер индекса элемента и копию его значения:

   // baseURL/part_1/1.11/7.go
   package main

   import "fmt"

   func main() {
       array := [4]int{2, 5, 6, 0}
       for i, v := range array {
           // i — номер индекса элемента
           // v — копия значения, хранящаяся по индексу i
           v += 3
           fmt.Printf("%d) %d || ", i, v)
       }
       // 0) 5 || 1) 8 || 2) 9 || 3) 3 ||
       fmt.Println()
       fmt.Println(array) // [2 5 6 0]

       // изменение значения элемента коллекции
       for i := range array {
           array[i] += 3
       }
       fmt.Println(array) // [5 8 9 3]
   }
  В следующем примере кода мы выполним итерирование по элементам пере
менной типа данных map:

   // baseURL/part_1/1.11/8.go
   package main

   import "fmt"

   func main() {
       myMap := map[int]string{
           1:   "Alex",
           2:   "Maxim",
           200: "Jon",
       }

       for i, v := range myMap {
           // i — ключ
           // v — копия значения, хранящаяся по ключу i
           fmt.Printf("key = %d, value = %s\n", i, v)
       }
   }
   // key = 1, value = Alex
   // key = 2, value = Maxim
   // key = 200, value = Jon
  В Go строка — это последовательность байтов, а не символов (рун), поэтому для
перебора элементов этого типа данных лучше всего использовать ключевое слово
range (вспоминаем о кодировке UTF-8):
