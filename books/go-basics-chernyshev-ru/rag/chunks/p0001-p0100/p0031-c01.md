30       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

английского алфавита кодируются с использованием 1 байта, а знак ₽ кодируется
с использованием 3 байт. Поэтому строка "at₽" будет занимать 5 байт. Чтобы в этом
убедиться, преобразуем строку в массив байтов и выведем его в терминал:

   package main

   import "fmt"

   func main() {
       str := "at₽"
       fmt.Println([]byte(str)) // [97 116 226 130 189]
   }
  Для обращения к конкретному элементу строки (срезу байтов) по его индексу
используем квадратные скобки:

   package main

   import "fmt"

   func main() {
       str := "at₽"
       fmt.Printf("%c", str[0]) // a, поскольку индексация начинается с нуля
   }
  Но так как символ может занимать несколько байтов, в терминал не получится
вывести символ ₽ при обращении к строке по индексу str[2]:

   package main

   import "fmt"

   func main() {
       str := "at₽"
       fmt.Printf("%c", str[2]) // â
   }
   Когда указывается некорректный индекс элемента, происходит ошибка времени
выполнения программы (runtime error). Чтобы увидеть более наглядный пример,
измените в предыдущем коде 2 на 8 и запустите приложение.
   Строки доступны только для чтения, поэтому изменение элемента, показанное
ниже, приведет к ошибке:

   import "fmt"

   func main() {
       str := "atdas"
       str[2] = "f" // cannot assign to str[2]
   }
   Вместе с тем тип данных string поддерживает операцию конкатенации (объ
единение строк):

   package main

   import "fmt"

   func main() {
       str1 := "ab"
       str2 := "cd"
       fmt.Println(str1 + " " + str2) // ab cd
   }
