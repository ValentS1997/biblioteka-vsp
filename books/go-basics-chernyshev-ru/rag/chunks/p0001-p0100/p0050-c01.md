1.9. Основные операторы Go      49

Таблица 1.11. Логические операторы
 Оператор     Описание                                      Примеры
 &&             Логическое «И» между операндами                     true && true = true
                                                                     Во всех остальных случаях false
 ||             Логическое «ИЛИ» между операндами                   false || false = false
                                                                     Во всех остальных случаях true
 !              Логическое отрицание                               !false = true
                                                            !true = false

Таблица 1.12. Унарные арифметические операторы
 Оператор     Описание                                      Примеры
 +             Положительное число. +a равнозначно записи 0 + a          a := +4 // 4
 –              Отрицательное число. –a равнозначно записи 0 – a          a := –5 // –5
 ^              Побитовое дополнение (побитовое отрицание). ^a равнозначно  var a uint8 = 25
                записи n^a, где n — значение, в котором все биты равны 1,    a = ^a // 230
                  то есть при типе int8 это –1, а при типе uint8 — 255

Таблица 1.13. Другие операторы
 Оператор      Описание                                     Примеры
 &              Возвращает адрес переменной                        a := 4 // 4
                                                            b := &a
 *               Указатель на переменную                            a := 4 // 4
                                                            b := &a
                                                            *b = 2

  Каждый оператор имеет приоритет выполнения операций (от более высоко
го к более низкому), который можно явно изменять с помощью круглых скобок.
В табл. 1.14 операторы приведены в соответствии с их приоритетом, где 1 — самый
высокий приоритет, а 5 — самый низкий.

Таблица 1.14. Приоритет операторов
№ приоритета      Операторы
 1                       *, /, %, <<, >>, &, &^
 2                       +, –, |, ^
 3                = =, ! =, <, < =, >, > =
 4                &&
 5                ||
