58       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

  Цикл выполняется до тех пор, пока проверка условия i < 10 возвращает значе
ние true, чем можно воспользоваться и организовать его бесконечное повторение:

   for { // вечный цикл
     // блок кода
   }
  Для завершения этого цикла вы, как разработчик, должны предусмотреть условие
выхода и использовать ключевое слово break:

   // baseURL/part_1/1.11/2.go
   package main

   import (
       "fmt"
       "strconv"
   )

   func main() {
       str := ""
       i := 0
       for {
           str += strconv.Itoa(i)
           if i > = 5 {
               break
           }
           i+ +
       }
       fmt.Println(str) // 012345
   }
   Поскольку цикл выполнится хотя бы один раз — это цикл с постусловием. Теперь
немного изменим его и перенесем условие выхода в строку с объявлением цикла,
то есть сделаем цикл с предусловием, тело которого может не выполниться ни разу:

   // baseURL/part_1/1.11/3.go
   package main

   import (
       "fmt"
       "strconv"
   )

   func main() {
       str := ""
       i := 0
       for i < = 5 {
           str += strconv.Itoa(i)
           i+ +
       }
       fmt.Println(str) // 012345
   }
   Замените начальное значение переменной i на 20 и перезапустите приложение.
Поскольку проверка 20 < = 5 вернет значение false, то в терминал выведется пустая
строка.
