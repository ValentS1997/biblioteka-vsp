1.14. Ввод данных, отладка и форматирование вывода      75

   Пакет fmt предоставляет достаточно большой набор функций для ввода данных
и их форматированного вывода в терминал. Ранее мы рассмотрели несколько из
них и сейчас рассмотрим возможности для форматированного вывода.
  Функция Println(a … any) дает возможность выводить в одну строку множество
переменных различного типа данных, указанных через запятую. После вывода в тер
минал они будут разделены пробелом, и следующий вывод будет на новой строке:

   // baseURL/part_1/1.14/9.go
   package main

   import "fmt"

   func main() {
       fmt.Println(4, 5.13, "Oo")  // 4 5.13 Oo
       fmt.Println(10)      // 10
   }
  Если убрать окончание и оставить только Print, то вывод будет выглядеть так
(не будет пробела и перехода на новые строки):

   // baseURL/part_1/1.14/10.go
   package main

   import "fmt"

   func main() {
       fmt.Print(4, 5.13, "Oo")
       fmt.Print(10) // 4 5.13Oo10
   }
  В выводе был строковый тип данных, поэтому соседние значения слиплись.
Этот нюанс нужно учитывать при использовании функции Print.
  Для форматированного вывода данных в терминал используется функция
Printf(format string, a ...any), где сначала задается форматированная строка, в ко
торую будут подставляться следующие за ней значения в порядке их очередности:

   // baseURL/part_1/1.14/11.go
   package main

   import "fmt"

   func main() {
       value := 20
       fmt.Printf("Value = %v", value) // Value = 20
   }
   %v указывает, что на это место будет подставлено значение в формате по умол
чанию, а если вам нужно вывести структуру с ее именами полей, то используйте
формат %+v. Кроме того, средства форматирования строки позволяют выводить
тип переменной:

   package main

   import "fmt"

       value1 := 20
