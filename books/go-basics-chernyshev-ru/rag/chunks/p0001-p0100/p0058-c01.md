1.11. Цикл for
Вам когда-нибудь приходилось снова и снова выполнять одни и те же действия?
Согласитесь — не самое приятное времяпрепровождение. При написании прило
жения очень часто встречаются похожие задачи, где необходимо написать много
однотипных строчек кода, которые следуют друг за другом. Справиться с этой
задачей позволяют циклы.
  В отличие от других языков программирования в Go все возможные циклы —
с заданным количеством повторений, предусловием или постусловием — органи
зуются с использованием всего одного ключевого слова for:

   for инициализация; условие выхода из цикла; действие по завершению текущего шага цикла {
     // блок кода
   }
   Это классическая структура цикла, но есть и ее сокращенные записи, которые мы
рассмотрим позже. Для начала напишем цикл, выводящий в терминал результаты
умножения чисел от 0 до 10 на 2:

   // baseURL/part_1/1.11/1.go
   package main

   import "fmt"

   func main() {
       value := 2
       for i := 0; i < 10; i+ + {
           fmt.Printf("%d * %d = %d\n", value, i, value*i)
       }
   }
   /*
   2 * 0 = 0
   2 * 1 = 2
   2 * 2 = 4
   2 * 3 = 6
   2 * 4 = 8
   2 * 5 = 10
   2 * 6 = 12
   2 * 7 = 14
   2 * 8 = 16
   2 * 9 = 18
   */
