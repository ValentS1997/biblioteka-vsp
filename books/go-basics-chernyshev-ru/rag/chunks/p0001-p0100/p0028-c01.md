1.7. Типы данных Go      27

  Компилятор всегда использует тип int при автоматическом выводе типа пере
менной, которой присваивается целочисленное значение. Поэтому, если при реше
нии вашей задачи нужно экономить память и вы точно знаете диапазон значений,
которые может принимать переменная, — используйте уточняющее подмножество
целочисленных типов, указывая тип вручную.
  К беззнаковым типам относится также uintptr. Занимаемый им объем памяти
зависит от платформы (см. uint), а служит он для хранения адреса указателя.
Но, в отличие от указателей, к нему применимы арифметические операции. Что
такое указатель и как с ним работать, мы обсудим несколько позже. А пока за
помните, что uintptr используется для доступа к памяти вместе с небезопасным
указателем.
   Инициализировать переменные целочисленного типа можно не только значе
ниями в десятичной системе счисления:

   package main

   import "fmt"

   func main() {
       value := 0xA1 //  шестнадцатеричная система счисления
       fmt.Println(value) // 161
       value = 0o17       // восьмеричная система счисления
       fmt.Println(value) // 15
       value = 0b1011     // двоичная система счисления
       fmt.Println(value) // 11
   }
  По умолчанию переменная этого типа данных инициализируется значением 0.

1.7.2. Числа с плавающей запятой (floats)
Этот тип данных используется для хранения вещественных значений в формате
с плавающей запятой. Например, 0,34. В Go два вещественных типа данных:
   yy float32 — 4 байта (32 бита), где 1-й бит отводится под хранение знака, 8 бит
     под экспоненту и 23 бита — мантисса;
   yy float64 — 8 байт (64 бита), где 1-й бит отводится под хранение знака, 11 бит
     под экспоненту и 52 бита — мантисса.
  При автоматическом выводе типа переменной, которой присваивается веще
ственное значение, компилятор всегда использует тип float64:

   package main

   import (
       "fmt"
       "reflect"
   )
   func main() {
       var value = 10.1
       fmt.Println(reflect.TypeOf(value)) // float64
       fmt.Println(value)                 // 10.1
       value = .21
       fmt.Println(value) // 0.21
