62       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

1.12. Безусловный переход

Оператор безусловного перехода goto позволяет без выполнения каких-либо
условий перейти к коду, следующему за меткой. Этот оператор не рекомендуют
использовать, но в Go он есть, поэтому рассмотрим его принципы работы:

   // baseURL/part_1/1.12/1.go
   package main

   import "fmt"

   func main() {
       fmt.Println(1) // 1
       goto myLable
       fmt.Println(2)
   myLable: // метка для безусловного перехода
       fmt.Println(3) // 3
   }
  Метка видна только внутри функции, в которой она объявлена, и любая попытка
перехода на нее из другой функции приведет к ошибке:

   // baseURL/part_1/1.12/2.go
   package main

   import "fmt"

   func main() {
       test()
       fmt.Println(1)
       goto myLable
       fmt.Println(2)
   myLable:
       fmt.Println(3)
   }

   func test() {
       goto myLable // error: label myLable not defined
   }
  Имя метки может быть написано как заглавными, так и строчными символа
ми, после которых ставится двоеточие. Основная опасность при использовании
безусловного перехода заключается в том, что теряется цепочка последователь
ных действий реализуемого алгоритма и возникает риск создания бесконечного
цикла:

   // baseURL/part_1/1.12/3.go
   package main

   import "fmt"

   func main() {
   myLable: // бесконечный цикл
       fmt.Println(1)
       goto myLable
       fmt.Println(2)
   }
