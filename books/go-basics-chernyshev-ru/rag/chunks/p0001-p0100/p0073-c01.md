72       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

  Чтобы избавиться от символа разделения в конце читаемых данных, восполь
зуемся функцией TrimSuffix из пакета strings и заменим строку:

   line1 = strings.TrimSpace(line1)
на

   line1 = strings.TrimSuffix(line1, "|")
  Следующий способ чтения всей введенной строки, с одной стороны, менее
гибкий, но с другой — позволяет проверить поток ввода на наличие данных. С по
мощью этого способа можно варьировать ситуации, в которых должно работать
приложение:

   // baseURL/part_1/1.14/6.go
   package main

   import (
       "bufio"
       "fmt"
       "os"
       "strings"
   )

   func main() {
       // Создаем сканер для чтения
       // из стандартного потока ввода
       scanner := bufio.NewScanner(os.Stdin)

       if scanner.Scan() { // ожидаем ввод данных
           // если данные прочитаны успешно,
           // выполнится код тела оператора if
           input := scanner.Text() // Считываем строку
           input = strings.TrimSpace(input)
           fmt.Println(input)
       }
   }
   // 3 7 8 9 8 7 6 7 < - введенная строка
   // 3 7 8 9 8 7 6 7
  В качестве следующего примера ввода данных рассмотрим ситуацию, когда
необходимо обработать поступающие от пользователя элементы целочисленного
среза, удалив дубликаты. Из терминала мы получаем строку, поэтому первым делом
считаем данные и преобразуем их в целочисленный срез. После чего, используя
объект типа map, проверим, какие из элементов среза имеют дубликаты, а какие —нет,
и сформируем новый срез. В этом решении используются новые конструкции,
и более подробно мы их разберем в следующей главе:

   // baseURL/part_1/1.14/7.go
   package main

   import (
       "bufio"
       "fmt"
       "os"
       "strconv"
       "strings"
   )
