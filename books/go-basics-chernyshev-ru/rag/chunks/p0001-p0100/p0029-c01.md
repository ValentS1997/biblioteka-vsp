28       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

       value = 1.21e2
       fmt.Println(value) // 121
       value = 1e–1
       fmt.Println(value) // 0.1
   }
  По умолчанию переменная вещественного типа данных инициализируется
значением 0.0.

1.7.3. Комплексные числа (complex numbers)
Как и в случае с вещественным типом данных, в Go есть два комплексных типа:
   yy complex64, где действительная и мнимая часть числа — float32;
   yy complex128, где действительная и мнимая часть числа — float64.
  Комплексные числа могут инициализироваться двумя способами: с помощью
функции complex(a, b) и с помощью сокращенной записи:

   package main

   import "fmt"

   func main() {
       var value = complex(4.5, 3.4)
       value1 := 4.4 + 5i
       fmt.Println(value, value1) // (4.5+3.4i) (4.4+5i)
   }

1.7.4. Byte
Тип данных byte представляет собой псевдоним для типа uint8 и хранит цело
численное значение. В основном он используется для записи символов в форма
те ASCII:

   package main

   import "fmt"

   func main() {
       var value byte = 'd'
       fmt.Println(value) // 100
   }
  Если при объявлении переменной не указать тип данных явно, то компилятор
выведет для переменной тип rune:

   package main

   import (
       "fmt"
       "reflect"
   )

   func main() {
       var value = 'd'
       fmt.Println(reflect.TypeOf(value)) // int32
   }
