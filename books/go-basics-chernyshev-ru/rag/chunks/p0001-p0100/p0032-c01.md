1.7. Типы данных Go      31

  А чтобы узнать длину строки, используйте функцию len:
   package main

   import "fmt"

   func main() {
       str1 := "ab"
       str2 := "cd"
       fmt.Println(len(str1 + " " + str2)) // 5
   }

1.7.7. Логические типы (booleans)
Логический тип данных bool может принимать два возможных значения: true или
false. Если переменной не задано явное значение, то по умолчанию ей присвоится
значение false:

   package main

   import "fmt"

   func main() {
       var value bool
       fmt.Println(value) // false
   }
  Над значениями этого типа данных можно выполнять три логические операции:
«И» (&&), «ИЛИ» (||) и «НЕ» (!):

   package main

   import "fmt"

   func main() {
       var value bool
       fmt.Println(!value)          // true
       fmt.Println(2 > 3 || 4 < 10) // true
       value2 := 2 > 3 && 4 < 10
       fmt.Println(value2) // false
   }
  У каждой из этих операций есть своя таблица истинности (табл. 1.3–1.5).
   Различные проверки на равенство, вхождения элемента в массив и так далее
всегда возвращают значение типа bool.
