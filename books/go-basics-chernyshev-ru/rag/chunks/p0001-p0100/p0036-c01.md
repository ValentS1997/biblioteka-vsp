1.7. Типы данных Go      35

по индексу к другим элементам приведет к ошибке. Такое свойство срезов позволяет
добавлять в них новые элементы без пересоздания массива и копирования в него
старых значений до тех пор, пока его длина не станет больше или равна емкости.
Создание нового массива и копирование — достаточно трудозатратные операции,
поэтому при большом количестве элементов емкость среза обычно увеличивают.
Это позволяет минимизировать количество вызовов операций создания нового
массива под срез и копирования в него старых значений элементов.

                                   Рис. 1.13. Общая структура среза

   Объявить и инициализировать срез можно несколькими способами:

   package main

   import (
       "fmt"
       "reflect"
   )

   func main() {
       slice1 := make([]int, 3) // первый вариант
       // make([]TYPE, length, capacity) — сигнатура функции
       fmt.Println(reflect.TypeOf(slice1)) // []int
       fmt.Println(slice1)                 // [0 0 0]

       slice2 := []string{"Oo", "Hi!"} // второй вариант
       fmt.Println(slice2) // [Oo Hi!]

       var slice3 []int // третий вариант
       fmt.Println(slice3) // []
   }
   Использование встроенной функции make помогает создать срез с указани
ем типа массива, его длины и емкости (должна быть больше длины). А если при
объявлении среза не передавать размер емкости, то она будет равна значению
длины:

   package main

   import "fmt"

   func main() {
       slice1 := make([]int, 3)
       fmt.Println(slice1)      // [0 0 0]
       fmt.Println(len(slice1)) // длина = 3
       fmt.Println(cap(slice1)) // емкость = 3
