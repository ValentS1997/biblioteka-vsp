34       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

   Массивы, которые мы рассмотрели выше, называются одномерными. Но суще
ствуют и двумерные и многомерные массивы. Размерность зависит от количества
объявленных квадратных скобок перед типом массива:

   package main

   import "fmt"

   func main() {
       array2D := [3][3]int{{2}, {3, 6, 9}} // Массив 3х3
       array2D[2][2] = 5
       fmt.Println(array2D)       // [[2 0 0] [3 6 9] [0 0 5]]
       fmt.Println(array2D[2][2])
      // значение элемента во второй строке, втором столбце — 5
   }
   Такой формат обращения к элементу двумерного массива можно представить
в виде общей записи array2D[i][j], где i — номер строки массива (начинается с 0),
а j — столбца (рис. 1.12).

1.7.9. Срезы (slices)
Срез — изменяемая последовательность элементов одного типа данных. В отличие
от массива срез поддерживает как добавление в себя новых элементов, так и уда
ление из него существующих.
  В состав каждого среза входит три элемента:
   yy ptr — указатель, указывающий на адрес базового массива;
   yy len — длина среза (текущее количество элементов в срезе);
   yy cap — емкость (максимальное количество допустимых элементов в массиве).
