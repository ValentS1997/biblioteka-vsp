42       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

к указателю необходимо применить операцию разыменования, поставив перед его
именем символ *:

   package main

   import "fmt"

   func main() {
       var value int = 4
       pointer2 := &value
       fmt.Println(*pointer2) // 4
   }
  Аналогичным образом можно менять значение, которое хранится по заданному
адресу:

   package main

   import "fmt"

   func main() {
       var value int = 4
       pointer2 := &value
       *pointer2 = 20
       fmt.Println(*pointer2) // 20
       fmt.Println(value) // 20
   }
  А при попытке присвоить новое значение без указания операции разыменования
компилятор выдаст ошибку:

   package main

   import "fmt"

   func main() {
       var value int = 4
       pointer2 := &value
       pointer2 = 10
       // cannot use 10 (untyped int constant) as *int value in
   }
   Указатели в Go делятся на два типа: безопасные (нативные) и небезопасные
(подключаются с помощью пакета unsafe). Вторые мы рассматривать не будем, но
даже безопасные указатели можно использовать так, что придется долго искать
причину проблемы. Можно сказать, что это плата за повышение скорости работы
вашей программы, поскольку значения переменных, передаваемых по ссылке,
не копируется и работа с ними выполняется напрямую.
  Как и у рассмотренных ранее типов данных, у указателей тоже есть значение по
умолчанию — nil (нулевое значение):

   package main

   import "fmt"

   func main() {
       var pointer1 *int
       fmt.Println(pointer1 = = nil) // true
       fmt.Println(pointer1) // <nil>
   }
