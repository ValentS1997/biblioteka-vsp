1.14. Ввод данных, отладка и форматирование вывода      69

  В результате в корневой директории проекта появится директория .vscode с фай
лом launch.json следующего содержания:

   {
       "version": "0.2.0",
       "configurations": [

           {
               "name": "Launch Package",
               "type": "go",
               "request": "launch",
               "mode": "auto",
               "program": "${fileDirname}"
           }
       ]
   }
   Теперь надо указать, что вся работа в момент запуска приложения будет выпол
няться через обычный терминал (в случае режима отладки обычно используется
вариант консоли). Для этого после ключа program добавьте всего одну строчку
(не забудьте поставить запятую):

   {
       "version": "0.2.0",
       "configurations": [

           {
               "name": "Launch Package",
               "type": "go",
               "request": "launch",
               "mode": "auto",
               "program": "${fileDirname}", // < - ставим запятую
               "console": "integratedTerminal"
           }
       ]
   }
  Чтобы выполнить запуск приложения в режиме отладки с заданными параме
трами, снова перейдите на вкладку Run and Debug (Запуск и отладка) и нажмите
значок  (рис. 1.21).
