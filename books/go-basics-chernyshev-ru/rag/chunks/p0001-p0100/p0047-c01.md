46       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

   func main() {
       const (
           None Month = iota
           January
           February
           March
       )
       fmt.Println(None)     // 0
       fmt.Println(January)  // 1
       fmt.Println(February) // 2
       fmt.Println(March)    // 3
   }
  Псевдонимы типов позволяют сокращать сложносоставные типы данных, пере
даваемые в функции и методы структур. Более подробно эту особенность Go мы
рассмотрим в следующей главе.

1.9. Основные операторы Go

Операторы в Go классифицируются следующим образом:
   yy арифметические операторы (в том числе унарные);
   yy операторы сравнения;
   yy логические операторы;
   yy побитовые операторы;
   yy операторы присваивания;
   yy другие операторы.
   Арифметические операторы представлены в табл. 1.6. Они могут применяться
только к переменным одного типа данных, а операции инкремента, декремента
и деление по модулю — только к целочисленным типам данных.

                               –2 * 2 = –4
