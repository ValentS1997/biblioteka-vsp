       var value2 float32 = 4.33

  Если в строке надо вывести знак процента, то используйте его дважды:

   // baseURL/part_1/1.14/13.go
   package main

   import "fmt"

   func main() {
       value := 20
       fmt.Printf("Value1 = %v%%", value) // Value1 = 20%
   }
  В табл. 1.15, 1.16 представлены различные варианты форматирования строк для
вывода целочисленных значений.

Таблица 1.15. Форматирование вывода целочисленных значений
 Обозначение         Описание
 %b                  Вывод значения в двоичном формате
 %c                  Вывод символа, соответствующего коду в Unicode
 %d                  Вывод значения в десятичном формате
 %o                  Вывод значения в восьмеричном формате
 %O                  Вывод значения в восьмеричном формате с префиксом 0o
 %x                  Вывод значения в шестнадцатеричном формате в нижнем регистре (прописные буквы)
 %X                  Вывод значения в шестнадцатеричном формате в верхнем регистре (заглавные буквы)
 %U                  Вывод значения в формате Unicode

Таблица 1.16. Форматирование вывода вещественных значений
 Обозначение         Описание
 %b                  Вывод значения в десятичной научной нотации с показателем степени 2
 %e или %E            Вывод значения в научной нотации. Для %e — –1.234456e+78, для %Е — –1.234456E+78
 %f или %F            Вывод вещественного значения в формате с десятичной запятой
 %x или %X             Шестнадцатеричная нотация (с десятичной степенью двух экспонент) выводимого значения

  Кроме того, %f позволяет указывать, с какой точностью выводить вещественное
значение:
