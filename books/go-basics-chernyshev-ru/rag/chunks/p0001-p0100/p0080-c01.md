1.15. Работа со строками      79

сохранить в старую переменную, то ей надо присвоить возвращаемое функцией
значение:

   str1 = strings.ToUpper(str1)
   Строка представляет собой срез байтов, поэтому достаточно просто на ее основе
получить подстроку (не стоит забывать о нюансах кодировки):

   // baseURL/part_1/1.15/3.go
   package main

   import "fmt"

   func main() {
       str1 := "Hi, my dear friend!!!"
       fmt.Println("Символы с 1 по 5: " + str1[:5])
       fmt.Println("Символы с 4: " + str1[4:])
   }
   //Символы с 1 по 5: Hi, m
   //Символы с 4: my dear friend!!!
   Когда в обрабатываемом тексте встречаются буквы русского или другого языка
(отличного от английского), самый простой вариант получить подстроку из диа
пазона индексов элементов — преобразовать исходную строку в срез рун, вырезать
подстроку и привести ее к типу string:

   // baseURL/part_1/1.15/4.go
   package main

   import "fmt"

   func main() {
       str1 := "Hi, my маленький friend!!!"
       runes := []rune(str1)
       substr := string(runes[4:16])
       fmt.Println(substr) // my маленький
   }
  Очень часто строку нужно разбить на несколько строк или на массив (срез) из
слов, входящих в строку. Для этих целей подходят функции семейства Split, где
в качестве первого аргумента передается исходная строка, а вторым идет раздели
тельный символ:

   // baseURL/part_1/1.15/5.go
   package main

   import (
       "fmt"
       "strings"
   )

   func main() {
       str := "+ +Hello+ +ненаглядные+ +Гофферы!+ +"

       // Разбиваем строку на срезы по указанному разделителю
       splitRes := strings.Split(str, "+ +")
       fmt.Print("Split(s, \"+ +\"): ")
       fmt.Printf("%q\n", splitRes)
