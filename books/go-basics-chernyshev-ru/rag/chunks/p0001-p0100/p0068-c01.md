1.14. Ввод данных, отладка и форматирование вывода      67

   Откройте в VS Code вкладку терминала и запустите написанный выше код
в файле main.go:

   PS C:\code\hello-go> go run main.go
   Введите название города, в котором проживаете: СПб
   Введите возраст города: 322
   СПб 322
   PS C:\code\hello-go>

   Количество кода можно немного сократить:

   // baseURL/part_1/1.14/2.go
   package main

   import (
       "fmt"
       "os"
   )

   func main() {
       var cityName string
       var age int
       fmt.Println("Введите название города, в котором проживаете, и его возраст: ")
       fmt.Fscan(os.Stdin, &cityName, &age)

       fmt.Println(cityName, age)
   }
   Такой подход позволит ввести данные через пробел и после нажатия клавиши
Enter записать их в соответствующие переменные:

   PS C:\code\hello-go> go run main.go
   Введите название города, в котором проживаете, и его возраст:
   СПб 322
   СПб 322
   PS C:\code\hello-go>
   Благодаря такой записи с клавиатуры можно вводить как строки, так и цело
численные и вещественные значения (например, 3.21), что позволяет не выполнять
ручное преобразование типов данных. Однако это касается только либо одиночных
значений, либо значений, вводимых в терминале через пробел:

   // baseURL/part_1/1.14/3.go
   package main

   import (
       "fmt"
       "os"
   )

   func main() {
       var value1, value2 string
       fmt.Fscan(os.Stdin, &value1, &value2)
       fmt.Println(value1, value2)
   }
   // PS C:\code\hello-go> go run main.go
   // 1 2 3 4 5 6 7
   // 1 2
   // PS C:\code\hello-go>
  Чуть позже мы рассмотрим способы, которые позволяют избежать такого
поведения программы. А пока настроим VS Code для поддержки ввода данных
