  Если нужно проверить вхождение символа или подстроки в строку, то исполь
зуйте функцию Contains(s, substr string). Первым аргументом передается исходная
строка, а вторым — символ или подстрока для проверки ее вхождения:

   // baseURL/part_1/1.15/10.go
   package main

   import (
       "fmt"
       "strings"
   )

   func main() {
       str1 := "Hi, my dear friend!!!"
       fmt.Printf("%t\n", strings.Contains(str1, "i"))  // true
       fmt.Printf("%t\n", strings.Contains(str1, "my")) // true
       fmt.Printf("%t\n", strings.Contains(str1, "?"))  // false
   }
  Еще один способ разбить строку на несколько частей с одновременной про
веркой наличия символа или подстроки-разделителя — использовать функции
семейства Cut.
   yy Cut(s, sep string) (before, after string, found bool) — возвращает подстроку
     до первого вхождения символа-разделителя (before) и после (after), а также
     флаг наличия символа или подстроки-разделителя (found). Если разделитель
      отсутствует, то after = "".
   yy CutPrefix(s, prefix string) (after string, found bool) — позволяет вырезать
     символ или подстроку в начале строки. Возвращает оставшуюся подстроку
      после символа-разделителя либо (при его отсутствии) исходную строку.
   yy CutSuffix(s, suffix string) (before string, found bool) — позволяет вырезать
     символ или подстроку в конце строки. Возвращает подстроку до символа-
      разделителя либо (при его отсутствии) исходную строку.
