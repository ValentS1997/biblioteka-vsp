1.8. Константы      45

   func main() {
       const (
           mc1 = 3
           mc2 = "str"
           mc3 = 4.2
       )
       fmt.Println(mc1) // 3
       fmt.Println(mc2) // str
       fmt.Println(mc3) // 4.2
   }

   Константы можно использовать и вместо перечислений (enums), которых в Go
нет:

       const (
           January  int = 1
           February     = 2
           March        = 3
       )
       // или
       const (
           January  string = "january"
           February        = "february"
           March           = "march"
       )
   Иногда при добавлении нового элемента в константное перечисление могут воз
никнуть проблемы. Например, можно забыть изменить данные, и в приложении
будет две константы с одним значением. Чтобы не попадать в такие ситуации,
следует использовать генератор констант — iota. Он позволяет объявлять после
довательности взаимосвязанных значений, начиная с самого младшего:

   package main

   import "fmt"

   func main() {
       const (
           None int = iota
           January
           February
           March
       )
       fmt.Println(None)     // 0
       fmt.Println(January)  // 1
       fmt.Println(February) // 2
       fmt.Println(March)    // 3
   }
  В некоторых случаях тип элементов константного перечисления может вводить
в заблуждение. Чтобы этого избежать и вывести разработку на более высокий уро
вень абстракции, следует использовать ключевое слово type, с помощью которого
вы можете объявить на основе существующего собственный, пользовательский,
тип данных (псевдоним типа, alias declarations):

   import "fmt"

   type Month int
