  Еще одной особенностью оператора if является то, что при его использовании

   import "fmt"

       // value существует только в пределах конструкции if-else

           fmt.Println("30 < value")
       } else {
           fmt.Println("30 > = value")
       }
       // fmt.Println(value) // error: undefined
   }

1.10.2. Оператор switch
Если блок кода в вашей программе состоит из большого количества цепочек if–else,
то можно использовать другую условную конструкцию управления потоками вы
полнения программы — switch–case. Ее синтаксис достаточно прост в применении
и позволяет сократить объем кода, заменив блоки if, которые выполняют сравнение
целочисленных, строковых или константных переменных с помощью оператора = =.
В общем виде конструкцию switch–case можно записать так:

   switch выражение {
       case exp1: блок1
       case exp2: блок2
       case exp3: блок3
       ...
       default: блок (n)
   }
  На вход оператора switch подается выражение, которое должно возвращать
значение, или непосредственно само значение, которое будет проверяться в блоках
case. Если оно совпадет с одним из имеющихся в блоках case, то выполнится кон
кретный блок кода и программа продолжит свою работу со строчки кода, следующей
за конструкцией switch–case. В противном случае выполнится необязательный
блок default (может отсутствовать):
