1.9. Основные операторы Go      47

  Чтобы применить операцию «деление по модулю» к вещественным числам, не
обходимо использовать функцию Mod(x, y float64) float64 из пакета math:

   package main

   import (
       "fmt"
       "math"
   )

   func main() {
       val1, val2 := 33.2, 4.9
       fmt.Println(math.Mod(val1, val2)) // 3.8000000000000007
   }
   Далее рассмотрим операторы сравнения (табл. 1.7).

  Для рассмотрения работы побитовых операторов необходимо ввести два
целочисленных значения типа int16 — a и b. Примем a = 25 в десятичной системе
счисления, что эквивалентно 0001 1001 в двоичной системе счисления и b = 67
(0100 0011) (табл. 1.8).

Таблица 1.8. Побитовые операторы
 Оператор  Описание                                             Примеры
 &          Побитовое логическое «И» между операндами                      a & b = 0000 0001 (1)
 |          Побитовое логическое «ИЛИ» между операндами                    a | b = 0101 1011 (91)
