1.7.11. Указатели (pointers)
Указатели в Go используются для хранения адреса переменной. Другими словами,
они указывают на область памяти, в которой записано ее значение. В общем виде
объявление указателя выглядит так: *type, где type — тип переменной, на которую
ссылается указатель. Он может быть любым: от встроенных, которые мы рассмо
трели ранее, до структур и интерфейсов.
  Чтобы получить указатель на существующую в программе переменную, необ
ходимо указать перед ее именем символ &:

       var value int = 4
       var pointer1 *int = &value
       pointer2 := &value
  На рис. 1.16 показано графическое представление этой пары строк кода.

    Рис. 1.16. Указатели p1 и p2 указывают на область памяти, в которой хранится значение переменной value

  Если вы после объявления указателя на переменную попытаетесь вывести
привычным способом ее значение в терминал, то вместо него вас поприветствует
адрес ячейки памяти:

   package main

   import "fmt"

   func main() {
       var value int = 4
       var pointer1 *int = &value
       pointer2 := &value
       fmt.Println(pointer1, pointer2) // 0xc000126058 0xc000126058
       fmt.Println(pointer1 = = pointer2) // true, один и тот же адрес
   }
