1.15. Работа со строками      77

   func main() {
       value := 173.000473
       fmt.Printf("Value = %f\n", value)    // Value = 173.000473
       fmt.Printf("Value = %.f\n", value)   // Value = 173
       fmt.Printf("Value = %.5f\n", value)  // Value = 173.00047
       fmt.Printf("Value = %2.2f\n", value) // Value = 173.00
   }
  Для форматирования вывода строкового типа данных и среза байтов использу
ются следующие варианты (табл. 1.17).

Таблица 1.17. Форматирование вывода вещественных значений
 Обозначение         Описание
 %s                  Вывод неинтерпретированных байтов строки или среза байтов (выводит символы)
 %q                  Вывод строки в двойных кавычках
 %x или %X            Вывод значения каждого символа в шестнадцатеричной нотации (х — в нижнем регистре,
                       Х — в верхнем) по два символа на байт

  С указателями можно работать как с целыми числами (%b, %d, %o, %x и %X) и вдо
бавок использовать %p для вывода адреса в шестнадцатеричной системе счисления
с префиксом 0х. А при работе со срезами %p выводит адрес нулевого элемента среза
в шестнадцатеричной системе счисления с префиксом 0х.
  Если вместо значения типа bool необходимо подставить слова true или false,
то следует использовать %t. А когда вам нужно сохранить отформатированную
строку в переменную для последующей работы с ней, то используйте функцию
Sprintf(format string, a ...any) из пакета fmt:

   // baseURL/part_1/1.14/15.go
   package main

   import "fmt"

   func main() {
       value := 173.000473
       str := fmt.Sprintf("Value = %x", value)
       fmt.Printf("str = %q\n", str)
   }
   // str = "Value = 0x1.5a003dff3f0fep+07"

1.15. Работа со строками
Go — достаточно ультимативный язык, не имеющий таких обширных встроенных
библиотек, какие есть в C++, Java или Python. Из-за этого программистам часто
приходится искать сторонние пакеты, реализующие тот или иной функционал, либо
писать все с нуля самостоятельно. Несмотря на это, разработчики Go включили
в его состав пакеты, упрощающие создание кода. В случае работы со строками это
пакет strings.
