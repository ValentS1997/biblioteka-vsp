1.7. Типы данных Go      39

поддерживать операцию сравнения. Значение же может использоваться сколько
угодно раз и связываться с различными ключами. Проще говоря, map представляет
собой серию пар «ключ:значение». Согласитесь, такое описание очень напоминает
хеш-таблицы! Так и есть, map — абстрактный тип данных, который предоставляет
интерфейс для работы с коллекциями пар «ключ:значение» и скрывает реализацию
хеш-таблицы, позволяя нам не думать о ее сложности.
  В общем виде объявление таблицы можно представить так:

   map[key_type]value_type,
где key_type — тип данных ключа, value_type — тип хранимого по ключу значения:

   map1 := make(map[string]int) // string — тип ключа, int — тип значения

   map2 := map[string]int{ // объявление и инициализация
       "a": 1,
       "b": 2,
   }

   var map3 map[string]int
  На рис. 1.15 приведена примерная структура типа данных map в памяти.
