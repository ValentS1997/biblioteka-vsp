  Цикл for будет выполняться до тех пор, пока состояние переменной state не из
менится на отличное от playing. Это может быть как установка выхода из игры,
так и победа одной из сторон или ничья. В начале тела цикла обозначим игрока,
выполняющего текущий код, переменные для записи позиции (строка, столбец),
куда игрок поставит свой символ (Х или О), и флаг валидации входных данных,
который будет сбрасываться только в случае корректного вода данных игроком
либо игнорироваться при выходе из игры:

           // Вывод сообщения о ходе текущего игрока
