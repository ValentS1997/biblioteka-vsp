1.7.8. Массивы (arrays)
Массив представляет собой структуру данных фиксированной длины, хранящую
элементы одного типа данных. К любому из таких элементов можно обратиться,
зная его индекс. Массивы не относятся к ссылочным типам данных, поэтому при
выполнении простого присваивания массива другой переменной будет осуще
ствляться полное его копирование. То же будет происходить и при передаче его
в качестве аргумента функции. Если вы явно не укажете, что работа будет вы
полняться с указателем на массив, то передадите его копию, что может ухудшить
производительность приложения при работе с массивами большой длины.
  Обобщенный вид объявления массива с начальными значениями можно пред
ставить так:

   newArray := [n]Type{val1, val2, …, valN}
где n — размер (длина) массива, Type — тип элементов в массиве, val1 … valN – на
чальное значение элементов массива.
  Если хотите объявить массив со значениями по умолчанию, чтобы изменять их
в последующем, то используйте такую запись:

   var newArray [n]Type
  Под каждый массив выделяется область памяти, в которой хранятся его эле
менты. Поэтому обращение к любому из элементов по его индексу происходит
практически моментально — за константное время О(1). При этом, в отличие от
строк, вы можете изменять значения элементов массива:

   package main

   import "fmt"

   func main() {
       var array1 [3]int // инициализируется значениями по умолчанию
       array2 := [4]float32{4.12}
       array1[0] = 2 // присваиваем 2 элементу с нулевым индексом
