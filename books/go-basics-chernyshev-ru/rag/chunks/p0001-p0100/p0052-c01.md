1.10. Условные конструкции в Go      51

                            Рис. 1.17. Блок-схема алгоритма выбора одежды

   Попробуйте изменить значение температуры на большее либо равное 30 и за
пустите приложение заново. В терминале вы должны увидеть Надеть шорты.
  Блок else является необязательным и может быть опущен. В качестве приме
ра представим ситуацию, что перед выходом на улицу мы всегда смотрим в окно
и принимаем решение: брать с собой зонт или нет. На рис. 1.18 представлена соот
ветствующая блок-схема.
   Поскольку на улице солнечно, то зонт не понадобится; при плохой погоде его
придется взять. Теперь перенесем этот алгоритм в код, используя условную кон
струкцию if:

   // baseURL/part_1/1.10/1.10.1/2.go
   package main

   import "fmt"

   func main() {
       sun := true // поменяйте на false и снова запустите приложение
       if !sun { // нет солнца?
           fmt.Println("Взять зонт")
       }
       fmt.Println("Выйти на улицу")
   }

   // Выйти на улицу
