40       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

  На самом деле ключ хранится в виде результирующего значения хеш-функции,
что позволяет быстро обращаться к хранящемуся по нему значению. Существуют
различные реализации хеш-таблиц и способы работы с коллизиями, поэтому мы
не будем останавливаться на них. Лучше сосредоточимся только на том функцио
нале, который предоставляет тип данных map.
   Изменение значения, которое хранится по ключу или добавление новой пары
«ключ:значение» выполняется практически идентично:

   package main

   import "fmt"

   func main() {
       map1 := make(map[string]int)
       map1["a"] = 1
       map1["b"] = 2
       fmt.Println(map1) // map[a:1 b:2]
       map1["a"] = 10
       fmt.Println(map1) // map[a:10 b:2]
       fmt.Println(map1["b"]) // 2
   }
  Для получения значения достаточно обратиться по его ключу, а для удаления —
использовать встроенную функцию delete:

   package main

   import "fmt"

   func main() {
       map1 := map[int]string{
           1:   "Alex",
           2:   "Maxim",
           200: "Jon",
       }
       fmt.Println(map1) // map[1:Alex 2:Maxim 200:Jon]
       name := map1[200] // получаем значение по ключу 200
       fmt.Println(name) // Jon
       delete(map1, 200) // удаляем из map1 данные с ключом 200
       fmt.Println(map1) // map[1:Alex 2:Maxim]
   }
  Чтобы проверить в экземпляре таблицы наличие данных по нужному ключу,
забежим немного вперед и воспользуемся оператором if:

   package main

   import "fmt"

   func main() {
       map1 := map[int]string{
           1:   "Alex",
           2:   "Maxim",
           200: "Jon",
       }
       _, ok := map1[3]
       if ok {
           fmt.Println("Exists!") // данные есть к таблице
       } else {
           fmt.Println("Does NOT exist") // таких данных нет
       }
   }
   // Does NOT exist
