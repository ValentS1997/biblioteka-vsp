84       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

  А функции Index(s, substr string) и LastIndex(s, substr string) позволят найти
номер индекса первого или последнего вхождения символа (подстроки) в строку.
Если искомого символа в строке нет, то вернется -1:

   // baseURL/part_1/1.15/14.go
   package main

   import (
       "fmt"
       "strings"
   )

   func main() {
       str := "Hello mad world!"
       fmt.Println(strings.Index(str, "l")) // 2
       fmt.Println(strings.Index(str, "W")) // -1

       fmt.Println(strings.LastIndex(str, "l")) // 13
       fmt.Println(strings.LastIndex(str, "W")) // -1
   }
   Объединить срез строк в одну строку позволяет функция Join(elems []string,
sep string). Она принимает на вход срез и символ-разделитель, который можно
установить между объединяемыми в одну строку элементами среза:

   // baseURL/part_1/1.15/15.go
   package main

   import (
       "fmt"
       "slices"
       "strings"
   )

   func main() {
       fmt.Println(strings.Join([]string{"a", "b", "c"}, " "))
       // a b c

       fmt.Println(strings.Join([]string{"a", "b", "c"}, "-"))
       // a-b-c

       // инвертирование строки
       str := "Hello!"
       splitStr := strings.Split(str, "")
       slices.Reverse(splitStr)
       fmt.Println(strings.Join(splitStr, "")) // !olleH
   }
  Любая операция над строкой создает новый объект, так что если при форми
ровании или форматировании длинной строки выполняется большое количество
операций, то лучше использовать структуру Builder из пакета strings:

   // baseURL/part_1/1.15/16.go
   package main

   import (
       "fmt"
       "strings"
   )
