38       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

  Однако у этого типа данных есть и недостаток. Дело в том, что срез относит
ся к ссылочному типу, при работе с которым следует проявлять особую осто
рожность. Если новой переменной присваивается массив, то он полностью копи
руется, а в случае со срезом переменной присвоится ссылка на исходный объект
в памяти:

   package main

   import "fmt"

   func main() {
       slice := []string{"a", "a"}
       slice2 := slice // присвоится ссылка, а не копия!!!
       slice2[0] = "r"
       fmt.Print(slice) // [r a]
   }

  Для копирования используйте встроенную функцию copy:
   package main

   import "fmt"

   func main() {
       slice := []string{"a", "a"}
       slice2 := make([]string, len(slice))
       copy(slice2, slice) // копируем срез
       slice2[0] = "r"
       fmt.Print(slice) // [a a]
   }
   Следует учитывать, что длина среза, в который копируется исходный, должна
быть аналогичной или больше. Если она меньше, то выполнится копирование только
того количества элементов, под которые была выделена память:

   package main

   import "fmt"

   func main() {
       slice := []string{"a", "b", "c", "d", "e"}
       slice2 := make([]string, 3)
       copy(slice2, slice)
       fmt.Print(slice2) // [a b c]
   }
   Более подробно механизм работы со срезами мы рассмотрим в одном из следу
ющих разделов этой главы.

1.7.10. Maps
Существует и много вариантов перевода на русский язык типа данных map: «кар
та», «отображение», «таблица», «хеш-таблица», «словарь» и т. д. Услышав одно из
них, знайте: с большой долей вероятности речь будет идти именно о встроенном
