44       Глава 1   Синтаксис, встроенные типы данных и управляющие конструкции Go

1.8. Константы

Константы — это переменные, значения которых нельзя менять после их объ
явления, то есть они никак не могут измениться в процессе работы приложения.
В основном они используются для объявления глобальных переменных в одном
пакете или структуре с помощью ключевого слова const:

   package main

   import "fmt"

   func main() {
       const myConst1 = 30 // нетипизированная константа
       const myConst2 int = 30 // типизированная константа
       fmt.Println(myConst1) // 30
       //myConst = 22 // cannot assign to myConst
   }
  Как видно из примера, константы делятся на типизированные и нетипизирован
ные. Различие заключается в том, что при объявлении типизированной константы
и ее использовании необходимо соблюдать все правила объявленного типа. Нети
пизированные константы можно использовать более свободно, но важно помнить,
что и у них есть тип по умолчанию, который будет использован при отсутствии
какой-либо другой информации о типе:

   package main

   import "fmt"

   func main() {
       const myConst1 = 30
       const myConst2 int = 30 // константа с ограничением по типу данных
       value1 := 3.4
       value1 += myConst1
       fmt.Println(value1) // 33.4
    // invalid operation: value1 –= myConst2
    // (mismatched types float64 and int)

    // value1 –= myConst2 // так делать нельзя, надо привести к float64
       value1 –= float64(myConst2)
       fmt.Println(value1) // 3.3999999999999986
   }
  Первую константу мы использовали для сложения со значением вещественного
типа данных, а вторую надо было привести к нему явно! Кроме того, обратите внима
ние на значение, полученное после вычитания. Это характерная для вещественного
типа данных проблема — неявное округление. Из-за нее я очень не рекомендую хранить
значения, в которых критична точность, в формате значений с плавающей запятой.
Например, для денежных форматов лучше подойдет целочисленный тип данных.
