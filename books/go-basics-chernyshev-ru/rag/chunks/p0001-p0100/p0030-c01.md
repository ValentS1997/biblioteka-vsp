1.7. Типы данных Go      29

1.7.5. Rune
Этот тип данных представляет собой псевдоним для типа int32 и используется
для записи символов в формате UTF-8, что позволяет вводить различные данные,
которые не поддерживаются форматом ASCII:

   package main

   import "fmt"

   func main() {
       var value = '₽'
       fmt.Println(value)                   // 8381
       fmt.Printf("Character: %c\n", value) // Character: ₽

       value = '\u2318'
       fmt.Println(value)                   // 8984
       fmt.Printf("Character: %c\n", value) // Character: ⌘
   }
   Попробуйте объявить переменной value тип byte и посмотрите, как себя поведет
компилятор при запуске приложения.

1.7.6. Строка (string)
Строка представляет собой набор (срез) байтов, доступных только для чтения,
и может инициализироваться несколькими способами:

   package main

   import "fmt"

   func main() {
       str := "my string"
       newStr := `my new \nstr`
       fmt.Println(str)
       fmt.Println(newStr)

       multipleLineString := `Ого // объявляем многострочную строку
       multiple line
       string`
       fmt.Println(multipleLineString)
   }/*
   my string
   my new \nstr
   Ого
           multiple line
           string */
  В первом случае использовались двойные кавычки. Такое объявление строки
позволяет добавить в нее escape-последовательности (символ новой строки — \n)
и выполнять их в процессе вывода значения в терминал. Во втором случае строка
считается необрабатываемой, то есть объявленные в ней escape-последовательности
при выводе значения в терминал выполняться не будут. Такие строки рекомендуется
использовать для хранения различных путей до директорий и файлов.
