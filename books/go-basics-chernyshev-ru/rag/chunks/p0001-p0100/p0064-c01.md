1.13. Преобразование типов данных      63

1.13. Преобразование типов данных
В некоторых случаях необходимо сложить значения различных типов данных (цело
численного и вещественного), выполнить перевод числа в строку или из строки
получить число. В любом из этих случаев разработчику предстоит выполнить явные
преобразования, то есть указать тип, к которому приводится значение. Для начала
рассмотрим пример сложения двух целочисленных чисел различного типа данных:

   // baseURL/part_1/1.13/1.go
   package main

   import "fmt"

   func main() {
       var val1 int8 = 5
       var val2 int16 = 500
       rez1 := int16(val1) + val2
       // rez2 := val1 + val2
       // invalid operation: val1 + val2 (mismatched types int8 and int16)

       fmt.Println(rez1) // 505
   }
   Обратите внимание: даже в случае сложения целочисленных значений нам
пришлось преобразовать значение типа int8 в тип int16, после чего совершить
операцию сложения. Если не выполнить такое преобразование, то приложение
просто не запустится, строка со сложением будет подсвечена красным, а система
выдаст сообщение об ошибке.
  При преобразовании менее емкого типа данных в более емкий проблем не воз
никает. Но обратная операция может привести к потере целостности данных, так как
произойдет отсечение их части:

   // baseURL/part_1/1.13/2.go
   package main

   import "fmt"

   func main() {
       var val1 int8 = 5
       var val2 int16 = 500
       rez1 := val1 + int8(val2)
       fmt.Println(rez1)       // –7
       fmt.Println(int8(val2)) // –12
   }

   Значение 500 типа int16 представлено в памяти так:
   0000  0001  1111  0100
   Поскольку в коде выполнилось преобразование значения типа int16 к типу int8,
то произошло отсечение первых 8 бит и получилось:

   1111  0100
что соответствует значению –12 в десятичной системе счисления. Так и получи
лось: 5 + (–12) = –7.
