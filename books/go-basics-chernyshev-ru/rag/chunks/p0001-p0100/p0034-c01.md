1.7. Типы данных Go      33

       fmt.Println(array1) // [2 0 0]
       fmt.Println(array2) // [4.12 0 0 0]
   }
   Обратите внимание на второе объявление массива array2:= [4]float32{4.12}.
Здесь создался массив из четырех вещественных элементов, первый из которых был
инициализирован значением 4.12, а остальные — значением по умолчанию (рис. 1.11).

                     Рис. 1.11. Общая структура массива с индексацией его элементов

  Длина фиксирована, поэтому после объявления массива она остается неизмен
ной и любая попытка обратиться к элементу по индексу, превышающему длину,
приведет к ошибке, равно как и вот такая попытка объявления массива:

   package main

   import "fmt"

   func main() {
       var n int = 4 // n declared but not used
       var array1 [n]int
       array2 := [n]float32{4.12}
       array1[0] = 2
       fmt.Println(array1) // invalid array length n
       fmt.Println(array2) // invalid array length n
   }

  Но при замене строки с

   var n int = 4
на

   const n = 4
код запустится. Это связано с тем, что константная переменная не может менять
свое значение.
   Если вы не хотите рассчитывать длину массива и уверены, что инициализировали
все его элементы, которые будут использоваться, то замените значение в квадратных
скобках на многоточие. Компилятор сам выведет длину:

   package main

   import "fmt"

   func main() {
       array2 := [...]float32{4.12, 3, 15, 3.22}
       fmt.Println(array2)      // [4.12, 3, 15, 3.22]
       fmt.Println(len(array2)) // 4
   }
