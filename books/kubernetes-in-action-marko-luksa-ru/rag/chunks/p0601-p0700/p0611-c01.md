Глава  18
         Расширение системы
                   Kubernetes

   Эта глава посвящена:
     добавлению своих собственных объектов в Kubernetes;
     созданию контроллера для своего собственного объекта;
     добавлению своих собственных серверов API;
     саморезервированию служб с помощью каталога служб Kubernetes
        Service Catalog;
     контейнерной платформе OpenShift провайдера открытых реше-
      ний Red Hat;
     системе Deis Workflow и менеджеру пакетов Helm.

Вы почти закончили. В заключение мы рассмотрим, каким образом можно
определять свои собственные объекты API и создавать контроллеры для этих
объектов. Мы также рассмотрим, как другие разработчики расширяли систе-
му Kubernetes и строили поверх нее решения в парадигме платформы как
службы.
