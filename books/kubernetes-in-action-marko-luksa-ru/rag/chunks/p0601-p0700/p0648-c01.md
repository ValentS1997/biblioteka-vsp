  B.1.3 Инсталляция операционной системы
  Теперь можно запустить виртуальную машину и инсталлировать операци-
онную систему. Убедитесь, что виртуальная машина по-прежнему выбрана
в списке, и щелкните по значку Start (Пуск) в верхней части главного окна
VirtualBox.

  Выбор загрузочного диска
  Перед запуском виртуальной машины программа VirtualBox запросит, ка-
кой загрузочный диск использовать. Щелкните по значку рядом с раскрываю-
щимся списком (показано на рис. B.3), а затем найдите и выберите ISO-образ
CentOS, скачанный ранее. Потом нажмите кнопку Start (Пуск), чтобы выпол-
нить начальную загрузку виртуальной машины.

  Запуск инсталляции
  При запуске виртуальной машины появится текстовое меню. С помощью
клавиши перемещения курсора вверх выберите опцию Установить CentOS
Linux 7 и нажмите кнопку Enter.
