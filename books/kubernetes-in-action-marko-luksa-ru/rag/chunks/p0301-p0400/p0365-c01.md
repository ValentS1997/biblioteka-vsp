364     Глава 10. Ресурсы StatefulSet: развертывание реплицируемых приложений...

   Листинг 10.4. Служба без обозначенной точки входа, которая будет использоваться
   в наборе StatefulSet: kubia-service-headless.yaml

apiVersion: v1
kind: Service             Имя
metadata:                   службы
  name: kubia    
spec:                          Управляющая служба набора StatefulSet
  clusterIP: None      должна быть без управляемой точки входа
  selector:
               Этой службе принадлежат все    app: kubia
                              модули с меткой app=kubia  ports:
  – name: http
    port: 80

  Вы выставляете поле clusterIP в None, что делает эту службу службой без
обозначенной точки входа. Это позволит вашим модулям обнаруживать сосе-
дей в наборе. После создания службы можно перейти к созданию фактическо-
го набора модулей с внутренним состоянием StatefulSet.

  Создание манифеста набора StatefulSet
  Теперь вы можете, наконец, создать ресурс StatefulSet. В следующем ниже
листинге показан его манифест.

   Листинг 10.5. Ресурс StatefulSet: kubia-statefulset.yaml

apiVersion: apps/v1beta1
kind: StatefulSet
metadata:
  name: kubia
spec:
  serviceName: kubia
  replicas: 2
  template:
    metadata:
      labels:                 Модули, созданные объектом StatefulSet,        app: kubia                                      будут иметь метку app=kubia
    spec:
      containers:
      – name: kubia
        image: luksa/kubia-pet
        ports:
        – name: http
          containerPort: 8080

        volumeMounts:
