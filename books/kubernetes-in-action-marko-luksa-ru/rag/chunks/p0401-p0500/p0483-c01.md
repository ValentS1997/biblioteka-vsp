  Создание политики безопасности модуля, позволяющей
  развертывать привилегированные контейнеры
  Вы создадите специальную политику PodSecurityPolicy, которая позволит
привилегированным пользователям создавать модули с привилегированны-
ми контейнерами. В следующем ниже листинге показано определение поли-
тики.

   Листинг 13.20. Политика PodSecurityPolicy для привилегированных пользователей:
   psp-privileged.yaml

apiVersion: extensions/v1beta1
kind: PodSecurityPolicy
metadata:                      Имя этой политики –
                                      «привилегированная»  name: privileged    
spec:
  privileged: true       Она позволяет запускать
  runAsUser:                      привилегированные контейнеры
    rule: RunAsAny
  fsGroup:
    rule: RunAsAny
  supplementalGroups:
    rule: RunAsAny
  seLinux:
    rule: RunAsAny
  volumes:
  – '*'

  После того как вы отправите эту политику на сервер API, в кластере будет
иметься две политики:

$ kubectl get psp
NAME         PRIV   CAPS  SELINUX   RUNASUSER  FSGROUP   ...
default      false  []    RunAsAny  RunAsAny   RunAsAny  ...
privileged   true   []    RunAsAny  RunAsAny   RunAsAny  ...

   ПРИМЕЧАНИЕ. Аббревиатурой для PodSecurityPolicy является psp.
