                     Рис. 14.9. Панель мониторинга Grafana, показывающая
                              потребление ЦП в кластере

  Анализ потребления ресурсов с помощью Grafana
  Для того чтобы узнать, сколько ресурсов требуется вашему модулю с тече-
нием времени, откройте веб-консоль Grafana и изучите предопределенные
панели мониторинга. Как правило, вы можете выяснить URL-адрес веб-кон-
соли Grafana с помощью команды kubectl cluster-info:

$ kubectl cluster-info
...
monitoring-grafana is running at
     https://192.168.99.100:8443/api/v1/proxy/namespaces/kube-
     system/services/monitoring-grafana

  При использовании Minikube веб-консоль Grafana предоставляется через
службу NodePort, поэтому ее можно открыть в браузере с помощью следую-
щей ниже команды:

$ minikube service monitoring-grafana -n kube-system
