510     Глава 14. Управление вычислительными ресурсами модулей
14.4 Установка стандартных запросов и лимитов
для модулей в расчете на пространство имен
Мы рассмотрели, как можно устанавливать ресурсные запросы и лимиты для
каждого отдельного контейнера. Если вы их не зададите, то контейнер будет
находиться во власти всех других контейнеров, которые устанавливают ре-
сурсные запросы и лимиты. Рекомендуется устанавливать запросы и лимиты
для каждого контейнера.
  14.4.1 Знакомство с ресурсом LimitRange
  Вместо того чтобы делать это для каждого контейнера, вы также можете
сделать это, создав ресурс диапазона лимитов LimitRange. Он позволяет ука-
зывать (для каждого пространства имен) не только минимальный и макси-
мальный лимит, который можно установить для контейнера по каждому
ресурсу, но и стандартные ресурсные запросы для контейнеров, которые не
устанавливают запросы явным образом, как показано на рис. 14.6.
