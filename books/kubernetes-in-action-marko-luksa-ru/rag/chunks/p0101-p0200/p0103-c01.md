  Знакомство с главными частями определения модуля
  Определение модуля состоит из нескольких частей. Во-первых, это вер-
сия API Kubernetes, используемая в YAML, и тип ресурса, который описывает
YAML. Затем почти во всех ресурсах Kubernetes находятся три важные секции:
  метаданные (metadata) – включают имя, пространство имен, метки и
     другую информацию о модуле;
  спецификация (spec) – содержит фактическое описание содержимого мо-
      дуля, например контейнеры модуля, тома и другие данные;
  статус (status) – содержит текущую информацию о работающем моду-
      ле, такую как условие, в котором находится модуль, описание и статус
     каждого контейнера, внутренний IP модуля, и другую базовую инфор-
     мацию.
