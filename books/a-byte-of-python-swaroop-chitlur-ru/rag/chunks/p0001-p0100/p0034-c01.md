A Byte of Python (Russian), Версия 2.01

5.4 Резюме

У пользователей систем GNU/Linux и BSD, вероятнее всего, Python уже установлен. В про-
тивном случае его можно установить, используя пакетный менеджер, поставляемый с
вашим дистрибутивом. Для Windows установка Python сводится к загрузке установщика
и двойному щелчку на нём. С этого момента мы будем считать, что Python 3 в вашей
системе установлен.
Далее мы приступим к написанию нашей первой программы на Python.
