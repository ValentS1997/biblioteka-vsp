11.1 Файлы байткода .pyc

Импорт модуля – относительно дорогостоящее мероприятие, поэтому Python предпри-
нимает некоторые трюки для ускорения этого процесса. Один из способов – создать
байт-компилированные файлы (или байткод) с расширением .pyc, которые являются
некой промежуточной формой, в которую Python переводит программу (помните раздел
“Введение” о том, как работает Python?). Такой файл .pyc полезен при импорте модуля в
следующий раз в другую программу – это произойдёт намного быстрее, поскольку зна-
чительная часть обработки, требуемой при импорте модуля, будет уже проделана. Этот
байткод также является платформо-независимым.

Примечание: Обычно файлы .pyc создаются в том же каталоге, где расположены и соот-
ветствующие им файлы .py. Если Python не может получить доступ для записи файлов
в этот каталог, файлы .pyc созданы не будут.

11.2 Оператор from ... import ...

Чтобы импортировать переменную argv прямо в программу и не писать всякий раз sys.
при обращении к ней, можно воспользоваться выражением “from sys import argv”.
Для импорта всех имён, использующихся в модуле sys, можно выполнить команду “from
sys import *”. Это работает для любых модулей.
В общем случае вам следует избегать использования этого оператора и использовать
вместо этого оператор import, чтобы предотвратить конфликты имён и не затруднять
чтение программы.
