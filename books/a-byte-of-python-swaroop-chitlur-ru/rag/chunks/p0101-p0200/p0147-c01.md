19.9 Установка библиотек

В Каталоге пакетов Python существует колоссальное количество открытых библиотек, ко-
торые вы можете использовать в своих программах. Для их установки можно воспользо-
ваться pip.

19.10 Графические программы

Для создания собственной графической программы на Python понадобится какая-нибудь
библиотека ГИП (графического интерфейса пользователя) со своими привязками к
Python. Привязки позволяют писать программу на Python, используя библиотеки, кото-
рые сами по себе написаны на C, C++ или других языках.
Выбор ГИП для Python достаточно обширен:
