## Main principle

Глава задаёт учебную позицию книги: материал должен быть доступен новичку, но не
бесполезен опытному программисту. История книги показывает итеративную модель:
личные заметки → расширение → переписывание → отзывы сообщества → улучшение.

## Key facts

- Книга ориентирована преимущественно на новичков, но заявлена полезной и опытным программистам.
- Автор описывает первоначальный выбор между Python- и Perl-привязками к Qt и выбор Python после изучения доступной информации и зрелости PyQt.
- Поиск подходящего учебника не удовлетворил автора: найденные материалы казались либо дорогими/справочными, либо недостаточными для новичков.
- После работы с Red Hat Linux 9.0 и KWord автор начал записывать мысли о Python; несколько страниц выросли примерно до 30, после чего текст стал книгой.
- Книга описывается как вклад в сообщество свободного ПО и как результат обратной связи читателей.
- В разделе 3.3 упомянуты изменения октября 2012 года с использованием Pandoc для генерации электронных книг и редакция декабря 2008 года со сведениями, связанными с Python 3.0.
- Автор просит сообщать ему или автору конкретного перевода о плохо, непонятно или неверно написанных частях.
- Раздел 3.4 перечисляет возможности official-page reference: читать, скачать последнюю версию, купить печатный вариант, оставить отзыв.
- Раздел 3.5 содержит две цитаты: о простоте программ и о концентрации/настойчивости.
