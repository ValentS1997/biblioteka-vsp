# Chapter 1 cheatsheet — «Обложка»

## Symptom / problem framing

[Not applicable] Глава не описывает техническую неисправность. Её задача — объяснить,
что представляет собой книга/перевод, кому она адресована и на каких условиях доступна.

## Baseline / context

- Russian edition label in RAG: `A Byte of Python (Russian), Версия 2.01`.
- Автор: Swaroop Chitlur.
- Автор русского перевода: Владимир Смоляр.
- Перевод основан на версии 2.0 оригинальной книги.
- Целевая аудитория: начинающие, включая читателей с минимальным компьютерным опытом.
- Язык, описываемый книгой: Python 3.

## Read-only checks

При ориентации по книге проверить по главе:

1. Какой перевод/версия используется.
2. Кто указан автором и переводчиком.
3. Для какой аудитории книга позиционируется.
4. Какая версия Python заявлена как предмет книги.
5. Какие права/условия распространения перечислены в разделе 1.3.
6. Какие способы чтения/получения перечислены в 1.4–1.6.
7. Куда направляет раздел 1.7 для других языков и переводов.

## Interpretation

- Большой блок отзывов служит социальным подтверждением пригодности книги для новичков.
- В RAG перечислены примеры учебного использования в ряде университетов.
- Отдельно заявлено использование книги в NASA/JPL.
- Лицензия книги и лицензия программных фрагментов описываются отдельно.
- Глава является «паспортом книги», а не учебным блоком Python.

## Next action

Источник предлагает несколько разных продолжений в зависимости от цели:

- читать книгу в браузере;
- получить PDF / полный исходник;
- обратиться к странице «Переводы» для других языков или помощи с переводом.

Какой из этих путей выбирать — зависит от задачи читателя.
