## Main principle

Глава задаёт контекст доверия и использования книги: что это за перевод, для кого он
предназначен, как книга распространяется и где её читать/получать. Она не обучает
Python непосредственно.

## Key facts

- Автор книги в RAG: Swaroop Chitlur.
- Автор русского перевода: Владимир Смоляр.
- Русский перевод основан на версии 2.0 оригинала и имеет версию 2.01.
- Книга позиционируется как материал по Python для начинающих.
- Глава прямо указывает, что книга описывает Python 3.
- В разделе 1.2 приведены отзывы читателей и примеры использования книги в учебных курсах; отдельно заявлено использование в NASA/JPL.
- Лицензионный текст в RAG содержит извлечённое название `Creative Commons Aribution-Share Alike 3.0 Unported`.
