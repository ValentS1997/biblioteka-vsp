# Chapter 4 cheatsheet — «Введение»

## Symptom / problem framing

Глава отвечает на базовый вопрос: какие свойства Python автор считает существенными
перед началом практической работы и какую версию языка следует держать в уме при
чтении книги.

## Baseline / context

Источник выделяет десять свойств Python:

1. простой;
2. лёгкий в освоении;
3. свободный и открытый;
4. язык высокого уровня;
5. портируемый;
6. интерпретируемый;
7. объектно-ориентированный;
8. расширяемый;
9. встраиваемый;
10. имеющий обширные библиотеки.

Книга ориентирует дальнейшее обучение на Python 3.

## Read-only checks

При чтении/сопоставлении материала проверить:

1. Какое свойство языка обсуждается.
2. Является ли утверждение частью концептуального описания или исторического контекста.
3. Не используется ли system-dependent функциональность при рассуждении о переносимости.
4. В каком направлении идёт интеграция:
   - C/C++ код вызывается из Python — расширяемость;
   - Python встраивается в C/C++ — встраиваемость.
5. Какую версию Python имеет в виду книга.
6. Не относится ли конкретное утверждение к исторической версии экосистемы.

## Interpretation

- «Простой» и «лёгкий в освоении» — разные тезисы: первый про читаемость/минимализм,
  второй про низкий порог старта.
- «Высокий уровень» в источнике означает сокрытие низкоуровневых деталей, например
  управления памятью.
- «Портируемый» не означает абсолютную переносимость: сам источник оговаривает
  необходимость избегать системно-зависимых функций.
- «Интерпретируемый» объясняется через отсутствие ручного шага компиляции в бинарный
  код и промежуточный байткод.
- «Расширяемый» и «встраиваемый» — зеркальные направления взаимодействия Python и C/C++.
- Большая стандартная библиотека описывается как часть подхода «Всё включено».
- Ветку Python 2/3 автор считает вторичной по сравнению с освоением самого
  программирования и основной части Python.
