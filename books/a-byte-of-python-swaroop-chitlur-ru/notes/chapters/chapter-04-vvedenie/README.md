## Main principle

Источник представляет Python как язык, в котором простота, высокий уровень абстракции,
портируемость, интерпретируемая модель выполнения, поддержка процедурного и
объектно-ориентированного программирования, расширяемость/встраиваемость и большая
библиотека должны позволять разработчику больше концентрироваться на решении задачи,
а не на механике языка.

## Key facts

- Имя Python, согласно источнику, связано с телешоу «Летающий цирк Монти Пайтона».
- Python называется простым, высокоуровневым, портируемым, интерпретируемым,
  объектно-ориентированным, расширяемым и встраиваемым языком.
- В разделе 4.1.5 перечислено множество платформ и отдельно упомянут Kivy как платформа
  для создания игр для iOS и Android.
- В объяснении 4.1.6 источник описывает модель Python как:
  исходный текст → промежуточная форма «байткод» → машинный язык → выполнение.
- Источник прямо говорит, что процедурное и объектно-ориентированное программирование
  поддерживаются одновременно.
- Для ускорения или сокрытия части алгоритма источник предлагает возможность написать
  эту часть на C/C++ и вызывать из Python.
- Встраивание описано в обратном направлении: Python может быть встроен в C/C++
  приложение для scripting-возможностей.
- В разделе о библиотеках перечислены области от regex и документации до БД, CGI, FTP,
  e-mail, XML, HTML, WAV, криптографии и GUI.
- В разделе 4.2 книга фиксирует Python 3 как основной язык обучения.
- Источник отмечает, что материал был переписан для Python 3 в 2008 году.
- Раздел 4.3 содержит source-attributed высказывания/описания Эрика С. Рэймонда,
  Брюса Экеля и Питера Норвига.
