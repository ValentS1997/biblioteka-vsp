## Main principle

Главная идея главы: языковой барьер можно снижать коллективным переводом. Перед
началом нового перевода источник предлагает проверить, существует ли уже перевод или
волонтёрская работа для нужного языка; если работа уже идёт — решить, присоединяться
ли к ней, а если начинается новый перевод — сначала прочитать инструкцию по переводу.

## Important source-grounded observations

- Перевод рассматривается не только как языковая работа, но и как способ сделать
  учебный материал доступным новичкам без достаточного технического английского.
- Несколько участников объясняют мотивацию через нехватку доступной документации на
  родном языке.
- В историях переводчиков многократно подчёркивается пригодность книги для начинающих.
- Для традиционного китайского перевода источник отдельно описывает `zhpy` и наличие
  примеров на «китайском Python» наряду с обычным Python.
- В конце главы дано точное правило восстановления замаскированных e-mail адресов:
  `-at-` → `@`, `-dot-` → `.`, `-underscore-` → `_`; остальные дефисы
  оставить как есть.

## Limitations

- Глава фиксирует историческое состояние переводов; текущая актуальность перечисленных
  проектов не проверялась, поскольку workflow работает в режиме `rag_only`.
- Многие URL и отдельные имена повреждены извлечением текста; см. `source-findings.md`.
- В subsection 2.1.19 есть внутреннее противоречие между «словацким» переводом и
  упоминанием «болгар» внутри цитаты; источник не позволяет его разрешить.
- Исполняемых Python/shell-команд нет.
- Явного chapter-end summary и review questions нет; `summary.md`,
  `review-questions.md`, `review-answers.md` не создаются.
