## Source-grounded summary

По итогам главы для GNU/Linux/BSD предполагается, что Python часто уже присутствует;
если его нет, источник указывает на установку через package manager. Для Windows
источник сводит базовую установку к installer path. После этого книга принимает Python 3
как установленный prerequisite и переходит к написанию первой программы.

Это структурированное изложение source meaning; современные installation procedures
внешне не проверялись.
