Знакомство с объектом Deployment     403

   посмотрите вывод команды kubectl describe для этого объекта Deployment,
   в списке событий увидите следующее:

    $ kubectl describe deployments.apps nginx-deployment-readiness
    Name:   nginx-deployment-readiness
    ...<фрагмент опущен для краткости>...
    Events:
      Type    Reason             Age   From                    Message
      ----    ------             ----  ----                    -------
      Normal  ScalingReplicaSet  32m   deployment-controller   Scaled up replica
    set nginx-deployment-readiness-69dd4cfdd9 to 3
      Normal  ScalingReplicaSet  9s    deployment-controller   Scaled up replica
    set nginx-deployment-readiness-69dd4cfdd9 to 10 from 3

   Того же результата можно достичь и с помощью императивной команды,
   однако такой способ рекомендуется использовать только в процессе раз-
   работки:

    $ kubectl scale deploy nginx-deployment-readiness --replicas=10
    deployment.apps/nginx-deployment-readiness scaled

3. Чтобы уменьшить число реплик декларативным способом, измените пара-
   метр replicas в манифесте nginx-deployment-readinessprobe.yaml:
   apiVersion: apps/v1
   kind: Deployment
   metadata:
     name: nginx-deployment-readiness
   spec:
     replicas: 2
     ...
4. Примените изменения с помощью команды kubectl apply:

    $ kubectl apply -f ./nginx-deployment-readinessprobe.yaml

5. Аналогичный результат можно получить и императивным способом, вы-
   полнив следующую команду:

    $ kubectl scale deploy nginx-deployment-readiness --replicas=2

  Если вы примените к объекту Deployment команду kubectl describe, то
   увидите запись об уменьшении числа реплик в списке событий:

    $ kubectl describe deploy nginx-deployment-readiness
    ...<фрагмент опущен для краткости>...
    Events:
      Type    Reason             Age   From                    Message
      ----    ------             ----  ----                    -------
      Normal  ScalingReplicaSet  27s   deployment-controller   Scaled down
    replica set nginx-deployment-readiness-69dd4cfdd9 to 2 from 10
