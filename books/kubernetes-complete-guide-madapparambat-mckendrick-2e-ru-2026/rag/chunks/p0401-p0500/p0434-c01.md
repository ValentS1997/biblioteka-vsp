434     Глава 12   •  Объект StatefulSet: развертывание приложений

9. А теперь отобразите сведения о выделенных PV:

    $ kubectl get pv
    NAME                                       CAPACITY   ACCESS MODES   RECLAIM
    POLICY   STATUS   CLAIM                                   STORAGECLASS
    VOLUMEATTRIBUTESCLASS   REASON   AGE

    Bound    mysql/mysql-data-mysql-stateful-1       standard       <unset>
    <none>   11m
    pvc-453dbfee-6076-48b9-8878-e7ac6f79d271   1Gi        RWO            Delete
    Bound    mysql/mysql-data-mysql-stateful-0       standard       <unset>
    <none>   11m
    pvc-6730af33-f0b6-445d-841b-4fbad5732cde   1Gi        RWO            Delete
    Bound    mysql/mysql-data-mysql-stateful-2       standard       <unset>
    <none>   11m

        В нашем примере используется тип хранилища hostPath, предоставляемый
           minikube. Если ваш кластер Kubernetes использует другую технологию хранения,
         вывод будет другим.

   Итак, мы успешно создали объект StatefulSet. Пришло время проверить его
   работоспособность. Для этого воспользуемся обновленным контейнерным
   образом k8sutils, в который был добавлен стандартный клиент MySQL.
   (Для получения подробных сведений об образе k8sutils обратитесь к фай-
   лу Chapter12/Containerfile.) Создайте файл k8sutils.yaml со следующим
   содержимым:

   # k8sutils.yaml
   apiVersion: v1
   kind: Pod
   metadata:
     name: k8sutils
     # namespace: default
   spec:
     containers:
       - name: k8sutils
         image: quay.io/iamgini/k8sutils:debian12-1.1
         command:
           - sleep
           - "infinity"
         # imagePullPolicy: IfNotPresent
     restartPolicy: Always

Создайте под k8sutils следующим образом:

 $ kubectl apply -f k8sutils.yaml -n mysql
 pod/k8sutils created
