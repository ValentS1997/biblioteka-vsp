Управление объектом StatefulSet     437

4. Создадим новую базу данных внутри сервера MySQL:

    MySQL [(none)]> create database ststest;
    Query OK, 1 row affected (0.002 sec)

    MySQL [(none)]> exit;
    Bye

5. Теперь убедимся, что DNS-имя остается неизменным, даже при перезапуске
   пода. IP-адрес пода изменится, но его DNS-имя останется прежним. Более
   того, смонтированный PV тоже не изменится, но мы убедимся в этом чуть
   позже. А сейчас в другом окне терминала (вне контейнера) выполните сле-
  дующую команду для принудительного перезапуска пода mysql-stateful-0:

    $ kubectl delete po -n mysql mysql-stateful-0

   Отобразив список подов, вы увидите, что под mysql-stateful-0 был пере-
   создан и к нему был подключен тот же PVC mysql-data-mysql-stateful-0:

    $ kubectl get po -n mysql
    NAME               READY   STATUS    RESTARTS   AGE
    k8sutils           1/1     Running   0          35m
    mysql-stateful-0   1/1     Running   0          6s
    mysql-stateful-1   1/1     Running   0          52m
    mysql-stateful-2   1/1     Running   0          51m

6. Вернувшись в оболочку k8sutils, выполните команду клиента MySQL,
   чтобы проверить содержимое базы данных:

    root@k8sutils:/# mysql -u root -p -h mysql-stateful-0.mysql-headless
