446     Глава 12   •  Объект StatefulSet: развертывание приложений

3. Примените манифест к кластеру, чтобы создать объект mysql-stateful с но-
  выми параметрами:

    $ kubectl apply -f mysql-statefulset-rolling-update.yaml
    statefulset.apps/mysql-stateful created

  Дождитесь перехода подов в состояние Running, прежде чем приступать
   к обновлению. Отобразите список подов, созданных объектом StatefulSet,
   с помощью команды kubectl get pods:

    $ kubectl get pods -n mysql
    NAME               READY   STATUS    RESTARTS        AGE
    k8sutils           1/1     Running   1 (21h ago)     23h
    mysql-stateful-0   1/1     Running   0               65s
    mysql-stateful-1   1/1     Running   0               62s
    mysql-stateful-2   1/1     Running   0               58s

4. Когда объект StatefulSet будет готов, создайте внутри него новую базу дан-
  ных через под k8sutils:

    $ kubectl exec -it -n mysql k8sutils -- /bin/bash
    root@k8sutils:/# mysql -u root -p -h mysql-stateful-0.mysql-headless

    Enter password: <mysqlroot>

    Welcome to the MariaDB monitor.  Commands end with ; or \g.
    ... <фрагмент опущен для краткости> ...

    MySQL [(none)]> create database stsrolling;
    Query OK, 1 row affected (0.027 sec)

    MySQL [(none)]> exit;

   Итак, у нас есть объект StatefulSet с заданной стратегией обновления и базой
   данных.

Теперь обновим образ контейнера MySQL в StatefulSet до новой версии. Для
этого выполните следующие шаги.

1. Измените образ контейнера, указанный в шаблоне пода, на mysql:8.3.0:
   # mysql-statefulset-rolling-update.yaml
   ... <фрагмент опущен для краткости> ...
       spec:
         containers:
           - name: mysql
             image: mysql:8.3.0
   ... <фрагмент опущен для краткости> ...
