500     Глава 14   •  Работа с Helm-чартами и операторами

Создание собственного оператора
Operator Framework предоставляет мощный инструментарий с открытым ис-
ходным кодом под названием Operator SDK, позволяющий легко разрабаты-
вать и создавать собственные операторы для получения полного контроля над
процессом управления приложениями в Kubernetes. Operator SDK включает
в себя готовые компоненты и функциональные модули, решающие такие ти-
повые задачи, как организация взаимодействия с API Kubernetes, управление
пользовательскими ресурсами и реализация цикла управления (control loop).
Благодаря этому разработчик может сосредоточиться на уникальной логике
и конфигурационных потребностях конкретного приложения.

Создание собственного оператора имеет ряд преимуществ. Во-первых, вы по-
лучаете полный контроль над всеми аспектами управления приложением. Опе-
ратор можно адаптировать под особенности ПО, обеспечив оптимальное управ-
ление его конфигурацией, стратегиями развертывания и масштабированием.
Во-вторых, операторы автоматизируют повторяющиеся операции, связанные
с жизненным циклом приложения, что существенно повышает эффективность
работы. Наконец, пользовательские операторы можно использовать повторно
в рамках разных развертываний, экономя время и снижая трудозатраты при
сопровождении инфраструктуры Kubernetes.

Подробнее об инструментарии Operator SDK можно узнать в официальной до-
кументации: https://sdk.operatorframework.io/.
Прежде чем переходить к практической работе с операторами, рассмотрим
компонент Operator Lifecycle Manager (OLM).

Компонент Operator Lifecycle Manager (OLM)
Operator Lifecycle Manager (OLM) — это компонент Kubernetes, который упро-
щает развертывание и управление приложениями, упакованными в виде опе-
раторов. Он использует декларативный подход, при котором все ресурсы
описываются в YAML-файлах. Это устраняет необходимость в сложных развер-
тываниях, предполагающих установку множества файлов в строго определен-
ном порядке. Кроме того, OLM обеспечивает автоматическую установку и об-
новление операторов, поддерживая их в актуальном состоянии. Этот компонент
также предоставляет механизм обнаружения пакетов под названием Catalog
Sources, который позволяет задействовать операторы из таких источников, как
OperatorHub, и других репозиториев. Использование OLM дает несколько пре-
