Установка веб-интерфейса Kubernetes
с использованием Helm-чартов
Kubernetes Dashboard — это официальный веб-интерфейс, предназначенный для
мониторинга состояния кластера. Helm-чарт этого компонента поддерживается
сообществом Kubernetes (https://artifacthub.io/packages/helm/k8s-dashboard/kubernetes-
dashboard). Мы установим этот веб-интерфейс с параметрами по умолчанию,
поскольку на данном этапе в его дополнительной настройке нет необходимости.

        В кластерах minikube веб-интерфейс Dashboard можно активизировать и открыть
           с помощью одной команды minikube dashboard. Однако в данном случае наша
         цель — научиться развертывать Dashboard в кластере любого типа.

Для начала добавьте репозиторий kubernetes-dashboard в Helm:

 $ helm repo add kubernetes-dashboard https://kubernetes-retired.github.io/
 dashboard/
 "kubernetes-dashboard" has been added to your repositories

Затем установите Helm-чарт в кластер в виде релиза kubernetes-dashboard:

 $ helm upgrade --install kubernetes-dashboard kubernetes-dashboard/
 kubernetes-dashboard \
   --create-namespace --namespace kubernetes-dashboard
