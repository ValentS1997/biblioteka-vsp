Развертывание приложений в Kubernetes с помощью Helm     487

вы захотите очистить кластер, выполните следующую команду для удаления
релиза Helm:

 $ helm uninstall wp-demo -n wordpress
 release "wp-demo" uninstalled

Она удалит все объекты Kubernetes, созданные данным релизом. Однако уч-
тите, что постоянные тома (PersistentVolume) и заявки на их выделение (Per
sistentVolumeClaim), созданные Helm-чартом, не удаляются автоматически — их
необходимо удалить вручную. Далее мы рассмотрим структуру Helm-чарта.

Структура Helm-чарта
В качестве примера мы рассмотрим Helm-чарт WordPress от Bitnami (https://
github.com/bitnami/charts/tree/master/bitnami/wordpress), который использовали ранее
для выполнения тестового развертывания в кластере. Helm-чарты представляют
собой каталоги со строго определенной структурой, которые могут храниться
как в локальной файловой системе, так и в репозиториях Git. Имя каталога
совпадает с именем чарта — в нашем случае это wordpress. Типовая структура
чарта включает следующие файлы и каталоги.

z  Chart.yaml — YAML-файл с такими метаданными чарта, как версия, ключевые
   слова, а также ссылки на зависимые чарты, которые необходимо установить.
z  LICENSE — необязательный текстовый файл с информацией о лицензии.
z  README.md — README-файл для конечного пользователя, отображаемый на
   сайте Artifact Hub.
z  values.yaml — файл со значениями по умолчанию, используемыми в каче-
   стве параметров YAML-шаблонов. Эти значения можно переопределять —
   либо по отдельности через интерфейс командной строки, либо указав отдель-
  ный YAML-файл (например, --values wp-values.yaml, как мы делали ранее).
z values.schema.json — необязательная JSON-схема, которой должен соот-
   ветствовать файл values.yaml.
z  charts/ — необязательный каталог с зависимыми чартами.
z  crds/ — необязательный каталог с определениями пользовательских ресур-
   сов Kubernetes.
z templates/ — основной каталог, содержащий YAML-шаблоны, на основе
   которых генерируются итоговые манифесты Kubernetes. Эти шаблоны объ-
   единяются с переданными значениями, после чего получившиеся манифесты
   применяются к кластеру.
z  templates/NOTES.txt — необязательный файл с краткими инструкциями по
   использованию чарта.
