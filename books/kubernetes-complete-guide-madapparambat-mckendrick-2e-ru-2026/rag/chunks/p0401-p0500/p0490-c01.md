Безопасный доступ к Kubernetes Dashboard
По умолчанию Kubernetes Dashboard отдает приоритет безопасности, исполь-
зуя минимально необходимую конфигурацию RBAC. Это помогает защитить
данные кластера. В настоящее время для входа в интерфейс требуется токен на
предъявителя (bearer-токен).

         Следуя приведенной ниже инструкции, вы, скорее всего, создадите пользователя
           с административными привилегиями. Используйте ее только в учебных целях,
          а в рабочих средах обязательно реализуйте полноценные механизмы RBAC.

Выполните следующие шаги, чтобы создать токен для получения доступа к веб-
интерфейсу Kubernetes Dashboard.

1. Подготовьте YAML-манифест с определением объекта ServiceAccount:
   # dashboard-sa.yaml
   apiVersion: v1
   kind: ServiceAccount
   metadata:
     name: admin-user
     namespace: kubernetes-dashboard
