страницу конкретного чарта, чтобы просмотреть YAML-шаблоны, из которых
он состоит (https://github.com/bitnami/charts/tree/master/bitnami/wordpress).
Выполним установку согласно инструкциям на этой странице. Сначала добавим
репозиторий bitnami в локальную установку Helm:

 $ helm repo add bitnami https://charts.bitnami.com/bitnami
 "bitnami" has been added to your repositories

В соответствии с лучшими практиками создадим отдельное пространство имен
wordpress для изоляции установки:

 $ kubectl create ns wordpress
 namespace/wordpress created

После добавления репозитория можно переходить к установке чарта bitnami/
wordpress, однако перед этим нужно подготовить параметры развертывания.
На странице Helm-чарта на сайте Artifact Hub (https://artifacthub.io/packages/helm/
bitnami/wordpress) перечислены параметры, позволяющие настроить установку
WordPress. Если их не указать, приложение Helm применит значения по умол-
чанию. Изменим некоторые из параметров, чтобы продемонстрировать процесс
настройки.
Отдельные параметры можно передавать с помощью аргумента --set:

 $ helm install wp-demo bitnami/wordpress -n wordpress --set
 wordpressUsername=wpadmin

Для задания нескольких параметров можно использовать несколько аргументов
--set, однако это предпочтительнее делать с помощью файлов с переменными.

Создадим файл wp-values.yaml для хранения переменных и их значений:
# wp-values.yaml
wordpressUsername: wpadmin
wordpressPassword: wppassword
wordpressEmail: admin@example.com
wordpressFirstName: WP
wordpressLastName: Admin
service:
  type: NodePort
volumePermissions:
  enabled: true
