428     Глава 12   •  Объект StatefulSet: развертывание приложений

z Репликацию на уровне приложения — предполагает использование встроен-
  ных механизмов репликации, предусмотренных самим приложением, для
   синхронизации данных между подами.
z Внешние сценарии или инструменты — позволяют управлять миграцией
   данных во время обновления приложения.

Теперь рассмотрим конкретный пример с объектом StatefulSet, который раз-
вертывает поды MySQL с поддержкой постоянного хранилища.

Управление объектом StatefulSet
Чтобы продемонстрировать принцип работы StatefulSet, мы модифицируем наш
объект Deployment с MySQL, так как значительная часть спецификации этих
объектов совпадает. Поскольку мы хотим показать, как работает автоматиче-
ское создание PVC в объектах StatefulSet, в спецификации будет использован
параметр volumeClaimTemplates. С его помощью создаются объекты PVC и PV,
которые затем подключаются к подам. Каждый под будет монтировать свой
PV во внутренний каталог контейнера по пути /var/lib/mysql, где MySQL по
умолчанию хранит файлы данных. Таким образом, мы наглядно покажем, как
сохраняется состояние даже при принудительном перезапуске подов.

         Пример, приведенный в этой главе, предназначен исключительно для демон-
         страционных целей и максимально упрощен. Если вы хотите ознакомиться
           с более сложными сценариями, например с развертыванием и управлением
         распределенными базами данных в StatefulSet, обратитесь к официальной публи-
         кации в блоге Kubernetes, посвященной развертыванию базы данных Cassandra:
            https://kubernetes.io/docs/tutorials/stateful-application/cassandra/. Основная слож-
          ность подобных сценариев обычно связана с добавлением и удалением реплик
         подов при масштабировании объекта StatefulSet.

Далее мы подробно рассмотрим YAML-манифесты, необходимые для создания
StatefulSet, и применим их к кластеру.

Создание объекта StatefulSet
Мы уже обсудили концепцию объекта StatefulSet, и теперь пришло время на
учиться им управлять. Начнем с рассмотрения манифеста mysql-statefulset.yaml:

# mysql-statefulset.yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql-stateful
