432     Глава 12   •  Объект StatefulSet: развертывание приложений

          Тот же объект Secret можно создать и декларативно с помощью YAML-манифеста,
          указав значения в кодировке base64 (например: echo -n 'mysqlroot' | base64).
         Пример такого манифеста можно найти в репозитории в файле mysql-secret.yaml.
        В данном случае мы используем императивный способ для создания секрета
           с конкретными значениями.

3. Создайте сервис mysql-headless с помощью команды:

    $ kubectl apply -f mysql-headless-service.yaml
    service/mysql-headless created

4. Создайте объект StatefulSet mysql-stateful:

    $ kubectl apply -f mysql-statefulset.yaml
    statefulset.apps/mysql-stateful created

5. Проверьте результат с помощью команды kubectl describe (вместо stateful
   set можно использовать сокращенную форму sts):

    $ kubectl describe statefulset mysql-stateful -n mysql
    <вывод опущен для краткости>
    $ kubectl get sts -n mysql
    NAME             READY  AGE
    mysql-stateful   3/3    2m3s

6. Выполните команду kubectl get pods, чтобы убедиться в успешном создании
   трех реплик пода. Этот процесс может занять некоторое время, поскольку
   для каждого пода должен быть выделен постоянный том (PV) в соответствии
   с его заявкой PVC:

    $ kubectl get pod -n mysql
    NAME               READY   STATUS    RESTARTS   AGE
    mysql-stateful-0   1/1     Running   0          2m32s
    mysql-stateful-1   1/1     Running   0          2m29s
    mysql-stateful-2   1/1     Running   0          2m25s

         Обратите внимание на упорядоченные и предсказуемые имена подов — именно
          это обеспечивает уникальную идентичность подов в объекте StatefulSet.

7. Если вы примените к поду команду describe, то увидите подробные сведения
   о связанных с ним объектах PV и PVC:

    $ kubectl -n mysql describe pod mysql-stateful-0
    Name:             mysql-stateful-0
