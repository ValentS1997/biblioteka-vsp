488     Глава 14   •  Работа с Helm-чартами и операторами

Если открыть файл Chart.yaml, содержащийся в чарте WordPress, можно уви-
деть, что он зависит от чарта MariaDB компании Bitnami — при условии, что
для параметра mariadb.enabled задано значение true:

...

appVersion: 6.5.3
dependencies:
  - condition: memcached.enabled
    name: memcached
    repository: oci://registry-1.docker.io/bitnamicharts
    version: 7.x.x
  - condition: mariadb.enabled
    name: mariadb
    repository: oci://registry-1.docker.io/bitnamicharts
    version: 18.x.x
...

Если теперь обратиться к (довольно объемному) файлу values.yaml со зна-
чениями по умолчанию, можно заметить, что база данных MariaDB включена
изначально:

...
## Настройки чарта MariaDB
## Справка: https://github.com/bitnami/charts/blob/main/bitnami/
## mariadb/values.yaml
##
mariadb:
  ## @param mariadb.enabled — развернуть сервер MariaDB,
  ## чтобы удовлетворить требования приложения к базе данных
  ## Если нужно использовать внешнюю базу данных, присвойте
  ## этому параметру значение false и настройте
  ## параметры `externalDatabase.*`
  ##
  enabled: true
...

Наконец, посмотрим, как выглядит один из YAML-шаблонов. Файл de
ployment.yaml (https://github.com/bitnami/charts/blob/master/bitnami/wordpress/
templates/deployment.yaml) представляет собой шаблон объекта Deployment,
предназначенный для подов с контейнерами WordPress. Обратите внимание,
что число реплик (replicas) задается на основе переданных пользователем
значений:

kind: Deployment
...
spec:
...
  replicas: {{ .Values.replicaCount }}
...
