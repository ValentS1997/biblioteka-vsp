404     Глава 11   •  Использование объекта Deployment

Список событий очень полезен для отслеживания хронологии масштабирования
и других операций, выполняемых над объектом Deployment.

         Объекты Deployment также возможно масштабировать автоматически с помощью
          объекта HorizontalPodAutoscaler, о котором вы узнаете в главе 20.

Теперь обсудим способ удаления объекта Deployment из кластера.

Удаление объекта Deployment
Объект Deployment можно удалить двумя способами.
z Удалить объект Deployment вместе с принадлежащими ему подами. Это можно
   сделать, предварительно выполнив автоматическое уменьшение числа реплик.
z Удалить только объект Deployment, оставив поды нетронутыми.

Чтобы удалить объект Deployment вместе с подами, используйте стандартную
команду kubectl delete:

 $ kubectl delete deploy nginx-deployment-readiness

После завершения работы подов будет удален и сам объект Deployment.

Если же вы хотите удалить только объект Deployment, оставив поды, исполь-
зуйте параметр --cascade=orphan:

 $ kubectl delete deploy nginx-deployment-readiness --cascade=orphan

После выполнения этой команды при проверке списка подов в кластере вы по-
прежнему увидите все поды, ранее принадлежавшие объекту nginx-deployment-
example.
В следующем разделе вы узнаете, как объект Deployment позволяет управлять
ревизиями и выкатыванием новых версий.
