Развертывание приложений в Kubernetes с помощью Helm     479

Проверьте корректность установки, запросив версию Helm в командной строке:

 $ helm version
 version.BuildInfo{Version:"v3.16.2", GitCommit:"13654a52f7c70a143b1dd51416d633
 e1071faffb", GitTreeState:"dirty", GoVersion:"go1.23.2"}

После установки приложения Helm можно развернуть тестовый чарт, чтобы
убедиться в его работоспособности.

Установка из двоичных файлов
Установить Helm также можно непосредственно из двоичного файла. Для этого
нужно выбрать нужную версию на странице релизов (https://github.com/helm/helm/
releases) и загрузить файл, предназначенный для вашей операционной системы.
В следующем примере показан процесс установки последней версии Helm из
двоичного файла на рабочей станции Fedora.

Выполните следующие команды для загрузки и установки Helm:

 $ wget https://get.helm.sh/helm-v3.15.1-linux-amd64.tar.gz
 $ tar -zxvf helm-v3.15.1-linux-amd64.tar.gz
 linux-amd64/
 linux-amd64/README.md
 linux-amd64/LICENSE
 linux-amd64/helm
 $ sudo mv linux-amd64/helm /usr/local/bin/helm
 $ helm version
 version.BuildInfo{Version:"v3.15.1", GitCommit:"e211f2aa62992bd72586b395de5097
 9e31231829", GitTreeState:"clean", GoVersion:"go1.22.3"}

Теперь мы можем протестировать установленный пакет Helm, развернув чарт
WordPress.

Развертывание чарта WordPress
По умолчанию Helm не предусматривает настроенных репозиториев. Один из
возможных (правда, уже не рекомендуемых) вариантов — добавить репозиторий
stable, чтобы получить доступ к наиболее популярным Helm-чартам:

 $ helm repo add stable https://charts.helm.sh/stable
 "stable" has been added to your repositories

         Добавление случайных репозиториев Helm для дальнейшей установки чартов
         может представлять серьезную угрозу. Перед установкой необходимо прово-
          дить аудит безопасности, чтобы гарантировать попадание в среду Kubernetes
          только доверенных пакетов.
