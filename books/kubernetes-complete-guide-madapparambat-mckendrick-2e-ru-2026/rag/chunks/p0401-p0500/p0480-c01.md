480     Глава 14   •  Работа с Helm-чартами и операторами

Учтите, что большинство старых чартов постепенно признаются устаревшими
и переносятся в другие репозитории Helm, где поддерживаются изначальными
разработчиками. Соответствующие сведения можно получить, если выполнить
поиск доступных чартов с помощью команды helm search repo:

 $ helm search repo stable | grep -i deprecated | head
 stable/acs-engine-autoscaler  2.2.2  2.1.1       DEPRECATED Scales worker nodes
                                                  within agent pools
 stable/aerospike              0.3.5  v4.5.0.5    DEPRECATED A Helm chart for
                                                  Aerospike in Kubern...
 stable/airflow                7.13.3  1.10.12    DEPRECATED
 ... <фрагмент опущен для краткости> ...

В настоящее время для поиска чартов рекомендуется использовать команду
helm search hub, позволяющую просматривать содержимое Artifact Hub непо-
средственно через интерфейс командной строки:

 $ helm search hub | head
 URL                                           CHART VERSION  APP VERSION
 DESCRIPTION
 https://artifacthub.io/packages/helm/mya/12factor  24.1.2                Easily
 deploy any application that conforms to ...
 https://artifacthub.io/packages/helm/gabibbo97/...  0.1.0
 fedora-32 389 Directory Server
 ... <фрагмент опущен для краткости> ...

Попробуем найти один из популярнейших Helm-чартов для тестирования
нашей установки. В этом примере мы развернем приложение WordPress в на-
шем кластере Kubernetes. Мы выбрали его потому, что оно представляет
собой классическое трехуровневое приложение, включающее уровень пуб
личного доступа (объект Service), веб-уровень (WordPress), уровень базы
данных (MariaDB). Сначала проверим, какие чарты WordPress доступны
в Artifact Hub:

 $ helm search hub wordpress
 URL                                                     CHART VERSION  APP
 VERSION  DESCRIPTION
 https://artifacthub.io/packages/helm/kube-wordp...      0.1.0          1.1
 this is my wordpress package
 https://artifacthub.io/packages/helm/wordpress-...      1.0.2          1.0.0
 A Helm chart for deploying Wordpress+Mariadb st...
 https://artifacthub.io/packages/helm/bitnami-ak...     15.2.13         6.1.0
 WordPress is the world's most popular blogging ...
 ... <фрагмент опущен для краткости> ...

Аналогичный поиск можно выполнить и через веб-интерфейс Artifact Hub
(рис. 14.1).
