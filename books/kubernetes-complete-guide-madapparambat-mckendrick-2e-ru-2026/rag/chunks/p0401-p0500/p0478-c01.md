Затем установите Helm:

 $ sudo dnf install helm

После установки можно проверить установленную версию пакета Helm:

 $ helm version
 version.BuildInfo{Version:"v3.11", GitCommit:"", GitTreeState:"",
 GoVersion:"go1.21rc3"}

        Вы также можете установить Helm с помощью специального установочного
         сценария (https://helm.sh/docs/intro/install/#from-script). Этот сценарий авто
          матически определит вашу платформу, загрузит последнюю версию Helm и уста-
         новит ее на вашу машину.

После успешной установки вы можете перейти к подразделу «Развертывание
чарта WordPress».

Установка Helm в Windows
Самый простой способ установить Helm в среде Windows — воспользоваться
менеджером пакетов Chocolatey. Подробные сведения и инструкцию по его
установке можно найти в официальной документации: https://chocolatey.org/
install.
После установки Chocolatey выполните следующую команду в оболочке
PowerShell или командной строке, чтобы установить Helm:

 PS C:\Windows\system32> choco install kubernetes-helm
 PS C:\Windows\system32> helm version
 version.BuildInfo{Version:"v3.15.0-rc.2",
 GitCommit:"c4e37b39dbb341cb3f716220df9f9d306d123a58",
 GitTreeState:"clean", GoVersion:"go1.22.3"}

После успешной установки вы можете перейти к подразделу «Развертывание
чарта WordPress».

Установка Helm в macOS
Для установки Helm в системе macOS можно использовать стандартный ме-
неджер пакетов Homebrew:

 $ brew install helm
