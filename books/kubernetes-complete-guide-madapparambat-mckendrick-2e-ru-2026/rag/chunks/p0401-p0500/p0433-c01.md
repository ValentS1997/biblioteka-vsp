  Для второго пода (mysql-stateful-1) вывод будет аналогичным, если не счи-
   тать PVC:

    $ kubectl -n mysql describe pod mysql-stateful-1
    Name:             mysql-stateful-1
    Namespace:        mysql
    Priority:         0
    <фрагмент опущен для краткости>
    Volumes:
      mysql-data:
        Type:       PersistentVolumeClaim (a reference to a
    PersistentVolumeClaim in the same namespace)
        ClaimName:  mysql-data-mysql-stateful-1
        ReadOnly:   false
    ... <фрагмент опущен для краткости> ...

   Итак, под mysql-stateful-0 использует PVC mysql-data-mysql-stateful-0,
   а под mysql-stateful-1 — PVC mysql-data-mysql-stateful-1. После назначе-
   ния пода узлу объекты PV выделяются через соответствующий StorageClass
  и привязываются к объектам PVC. Затем создается контейнер, в который
   монтируется этот PV.
