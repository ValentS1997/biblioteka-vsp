Управление объектом StatefulSet     431

          Класс хранилища по умолчанию в кластере помечается аннотацией storageclass.
            kubernetes.io/is-default-class. Наличие класса по умолчанию и его конфигурация
          зависят от конкретного способа развертывания кластера. Например, в кластере
          Azure Kubernetes Service (AKS) класс по умолчанию имеет имя default и ис-
          пользует провиженер kubernetes.io/azure-disk; в minikube класс по умолчанию
         называется standard и использует провиженер k8s.io/minikube-hostpath.

В спецификации StatefulSet также присутствуют поля, связанные с выкатыванием
новых версий этого объекта. Мы подробно рассмотрим их в следующем разделе.
Теперь создадим «безголовый» сервис с именем mysql-headless. Для этого соз-
дайте файл mysql-headless-service.yaml со следующим содержимым:

# mysql-headless-service.yaml
apiVersion: v1
kind: Service
metadata:
  name: mysql-headless
  namespace: mysql
spec:
  selector:
    app: mysql
    environment: test
  clusterIP: None
  ports:
    - port: 3306

Структура этого манифеста почти идентична структуре манифеста обычного
сервиса, который мы создавали ранее для объекта Deployment. Единственное
отличие в том, что поле clusterIP имеет значение None. Это приводит к созда-
нию сервиса mysql-headless, который возвращает IP-адреса всех работающих
за ним подов в виде DNS-записей типа A вместо одной A-записи, как в случае
с сервисом ClusterIP. Далее мы продемонстрируем это на практике.

После подготовки всех необходимых YAML-манифестов можно приступать
к развертыванию объекта StatefulSet. Для этого выполните следующие шаги.

1. Создайте пространство имен mysql, используя файл mysql-ns.yaml:

    $ kubectl apply -f mysql-ns.yaml
    namespace/mysql created

2. Создайте объект Secret для хранения переменных окружения MySQL:

    $ kubectl create secret generic mysql-secret \
      --from-literal=MYSQL_ROOT_PASSWORD='mysqlroot' \
      --from-literal=MYSQL_USER='mysqluser' \
      --from-literal=MYSQL_PASSWORD='mysqlpassword' \
      -n mysql
    secret/mysql-secret created
