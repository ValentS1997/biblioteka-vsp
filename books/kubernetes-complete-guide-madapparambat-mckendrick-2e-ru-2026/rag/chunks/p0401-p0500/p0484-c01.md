484     Глава 14   •  Работа с Helm-чартами и операторами

развернутый компонент в своем кластере. Тем временем экземпляр WordPress
устанавливается без какого-либо участия с вашей стороны.

         Перед установкой рекомендуется проверить, какие именно YAML-манифесты
         объектов Kubernetes были сгенерированы Helm. Это можно сделать, используя
         команду helm install с дополнительными флагами: helm install wp-demo bitnami/
          wordpress --dry-run --debug. В результате будут отображены все YAML-манифесты
          без их применения к кластеру.

При необходимости можно указать конкретную версию Helm-чарта с помощью
аргумента --version:

 $ helm install my-wordpress bitnami/wordpress --version 22.4.2

Теперь выполним инструкцию, полученную при установке Helm-чарта.

1. Дождитесь завершения инициализации базы данных и развертывания подов,
   а затем проверьте их статус:

    $ kubectl get po -n wordpress
    NAME                                  READY   STATUS    RESTARTS        AGE
    wp-demo-mariadb-0                     1/1     Running   9 (5m57s ago)   31m
    wp-demo-wordpress-5d98c44785-9xd6h    1/1     Running   0               31m

2. Обратите внимание, что база данных развернута в виде объекта StatefulSet:

    $ kubectl get statefulsets.apps -n wordpress
    NAME             READY   AGE
    wp-demo-mariadb  1/1     99s

3. Дождитесь назначения порта сервису wp-demo (типа NodePort):

    $ kubectl get svc -n wordpress
    NAME               TYPE        CLUSTER-IP     EXTERNAL-IP   PORT(S)
    AGE
    wp-demo-mariadb    ClusterIP   10.100.118.79  <none>        3306/TCP
    2m39s
    wp-demo-wordpress  NodePort    10.100.149.20  <none>        80:30509/
    TCP,443:32447/TCP  2m39s

  В нашем случае будет использоваться порт 80:31979/TCP.
4. Поскольку мы работаем с кластером minikube, определим IP-адрес и номера
   портов (при использовании сервиса типа LoadBalancer можно сразу перейти
   по IP-адресу, чтобы открыть сайт WordPress):

    $ minikube service --url wp-demo-wordpress -n wordpress
    http://192.168.59.150:30509
    http://192.168.59.150:32447
