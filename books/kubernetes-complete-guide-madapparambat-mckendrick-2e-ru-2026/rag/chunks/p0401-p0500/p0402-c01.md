Далее обсудим способ масштабирования таких объектов.

Масштабирование объекта Deployment
Главное достоинство объекта Deployment заключается в возможности его прак-
тически мгновенного масштабирования. Если он опубликован через сервис,
новые поды будут автоматически обнаружены и добавлены в список конечных
точек при увеличении числа реплик или удалены из этого списка при его умень-
шении. Порядок действий при этом следующий.

1. Для начала отмасштабируем объект Deployment декларативным способом.
   Откройте манифест nginx-deployment-readinessprobe.yaml и измените
   число реплик:
   apiVersion: apps/v1
   kind: Deployment
   metadata:
     name: nginx-deployment-readiness
   spec:
     replicas: 10
   ...
2. Примените изменения к кластеру с помощью команды kubectl apply:

    $ kubectl apply -f ./nginx-deployment-readinessprobe.yaml
    deployment.apps/nginx-deployment-readiness configured
