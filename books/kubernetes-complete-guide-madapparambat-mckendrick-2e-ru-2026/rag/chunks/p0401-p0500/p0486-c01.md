486     Глава 14   •  Работа с Helm-чартами и операторами

 Рис. 14.4. Панель управления приложения WordPress, развернутого в Kubernetes
                               с помощью Helm-чарта

         Интерфейс командной строки Helm поддерживает функцию автодополнения
         для различных оболочек. Подробнее о ней можно узнать, выполнив команду
         helm completion.

Для просмотра списка релизов Helm, развернутых в вашем кластере Kubernetes,
используйте такую команду:

 $ helm list -n wordpress
 NAME     NAMESPACE  REVISION  UPDATED                                  STATUS
 CHART              APP VERSION
 wp-demo  wordpress  1         2024-06-04 22:20:32.556683096 +0800 +08  deployed
 wordpress-22.4.2   6.5.3

Далее вы узнаете, как удалить развернутый релиз Helm.

вручную по одному было бы крайне неудобно. К счастью, Helm предусматривает
