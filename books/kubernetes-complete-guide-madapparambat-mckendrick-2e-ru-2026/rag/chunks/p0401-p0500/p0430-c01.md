430     Глава 12   •  Объект StatefulSet: развертывание приложений

Как видите, структура остается той же, что и в случае с Deployment. Обратите
внимание на переменные окружения, которые передаются через объект Secret —
его необходимо создать до создания объекта StatefulSet. В конце файла нахо-
дится блок volumeClaimTemplates, предназначенный для определения шаблонов
PVC, используемых подами:

# (продолжение)
  volumeClaimTemplates:
    - metadata:
        name: mysql-data
      spec:
        accessModes:
          - "ReadWriteOnce"
        resources:
          requests:
            storage: 1Gi

Таким образом, в целом структура спецификации StatefulSet схожа со специ
фикацией Deployment, но содержит дополнительные параметры, позволяющие
настраивать PVC и связанные объекты Service. Спецификация StatefulSet со-
стоит из пяти основных компонентов.

z replicas — определяет количество реплик пода, которые запускаются на
   основе заданного шаблона (template) и соответствуют селектору меток
   (selector). Для поддержания требуемого числа реплик поды могут созда-
   ваться или удаляться.
z  serviceName — имя сервиса, управляющего объектом StatefulSet и обеспечи-
   вающего сетевую идентичность подов. Этот сервис должен быть создан до
   создания объекта StatefulSet. В нашем примере таким сервисом будет mysql-
   headless, который мы создадим на следующем шаге.
z  selector — селектор меток, задающий правила идентификации подов, на-
   ходящихся под управлением объекта StatefulSet. Он может быть основан как
   на множестве, так и на равенстве.
z  template — определяет шаблон для создания пода. Метки, указанные в раз-
   деле metadata, должны соответствовать условиям, определенным в разделе
   selector. Имена подов являются детерминированными и формируются по
  шаблону <имяStatefulSet>-<порядковыйНомер>. При необходимости можно
   задать начальный порядковый номер с помощью параметра .spec.ordinals.
z  volumeClaimTemplates — определяет шаблон объекта PVC, который будет ав-
   томатически создан для каждого пода в составе StatefulSet и жестко привязан
   к его имени. В нашем примере это будет том объемом 1 ГБ с режимом доступа
   ReadWriteOnce, который допускает единовременное выполнение операций
   чтения и записи только одним узлом. Поскольку параметр storageClassName
   не указан, PVC будут создаваться с использованием класса хранилища по
   умолчанию. Имена PVC также не являются случайными и формируются по
   шаблону <имя_VolumeClaimTemplate>-<имя_StatefulSet>-<порядковый_номер>.
