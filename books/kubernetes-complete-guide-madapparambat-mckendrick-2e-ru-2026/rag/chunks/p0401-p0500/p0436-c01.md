436     Глава 12   •  Объект StatefulSet: развертывание приложений

Проведем небольшой эксперимент, демонстрирующий то, каким образом
headless-сервис обеспечивает стабильную и предсказуемую сетевую идентич-
ность подов.

1. Подключитесь к поду k8sutils, который использовался в предыдущем тесте.
2. Отобразите DNS-записи для сервиса mysql-headless:

    root@k8sutils:/# nslookup mysql-headless
    Server:         10.96.0.10
    Address:        10.96.0.10#53

    Name:   mysql-headless.mysql.svc.cluster.local
    Address: 10.244.0.14
    Name:   mysql-headless.mysql.svc.cluster.local
    Address: 10.244.0.15
    Name:   mysql-headless.mysql.svc.cluster.local
    Address: 10.244.0.16

  Вы получите три A-записи с указанием IP-адресов подов. Помимо этого, в вы-
   воде будут присутствовать CNAME-записи вида <имя_пода>-<порядковый_
   номер>.<имя_Headless-cервиса>.<пространство_имен>.svc.cluster.local.
   Разница между обычным и headless-сервисом заключается в том, что обыч-
  ный сервис (типа ClusterIP) осуществляет балансировку нагрузки на уровне
   виртуального IP (в ОС Linux это обычно реализуется на уровне ядра с помо-
  щью правил iptables, конфигурируемых компонентом kube-proxy). В случае
   с headless-сервисом ответственность за балансировку нагрузки или выбор
   целевого пода лежит на клиенте, отправляющем запрос.
3. Благодаря предсказуемым полным доменным именам (FQDN) подов в State
   fulSet мы можем напрямую обращаться к конкретным подам, не зная их
   IP-адресов или имен. Попробуем подключиться к серверу MySQL, работа-
  ющему в поде mysql-stateful-0, используя его короткое DNS-имя, предо-
   ставляемое headless-сервисом:

    root@k8sutils:/# mysql -u root -p -h mysql-stateful-0.mysql-headless
    Enter password: <mysqlroot>
    Welcome to the MariaDB monitor.  Commands end with ; or \g.
    Your MySQL connection id is 8
    Server version: 8.2.0 MySQL Community Server - GPL

    Copyright (c) 2000, 2018, Oracle, MariaDB Corporation Ab and others.

    Type 'help;' or '\h' for help. Type '\c' to clear the current input
    statement.

    MySQL [(none)]>

  Как видите, соединение установлено непосредственно с нужным подом.
