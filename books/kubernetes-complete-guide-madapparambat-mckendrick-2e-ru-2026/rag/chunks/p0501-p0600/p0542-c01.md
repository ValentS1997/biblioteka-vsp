542     Глава 16   •  Запуск кластера на платформе Amazon Web Services

Чтобы загрузить и установить AWS CLI, выполните следующие команды:

 $ curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.
 zip"
 $ unzip awscliv2.zip
 $ sudo ./aws/install

После установки вы можете выполнить команду aws --version, чтобы получить
результат, аналогичный показанному в пункте «Установка в macOS». Далее мы
обсудим установку AWS CLI в Windows.

Установка в Windows
В системе Windows AWS CLI можно установить с помощью пакетного мене
джера, как и в macOS. Мы воспользуемся менеджером Chocolatey и следующей
командой:

 $ choco install awscli

После установки и выполнения приведенной ниже команды вы получите та-
кой же вывод, как в случае с macOS, если не считать различий в версиях опера-
ционной системы и языка Python:

 $ aws --version

После успешной установки интерфейса командной строки можно приступать
к его настройке.

Настройка интерфейса командной строки AWS
После установки AWS CLI и проверки его работоспособности с помощью
команды aws --version необходимо связать локальную установку CLI с вашей
учетной записью AWS. Для этого войдите в консоль управления AWS по адресу
http://console.aws.amazon.com/.
После входа в консоль введите IAM в поле поиска, расположенное в левом верх-
нем углу страницы рядом с кнопкой Services (Сервисы). Затем выберите ссыл-
ку IAM Identity Center в результатах поиска, чтобы перейти на страницу Центра
идентификации IAM.
