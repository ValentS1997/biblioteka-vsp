506     Глава 14   •  Работа с Helm-чартами и операторами

   metadata:
     labels:
       dashboards: grafana-a
       folders: grafana-a
     name: grafana-a
     namespace: monitoring
   spec:
     config:
       auth:
         disable_login_form: 'false'
       log:
         mode: console
       security:
         admin_password: start
         admin_user: root

        В данном примере пароли и параметры конфигурации указаны в YAML-манифесте
          в открытом виде. В рабочей среде такие чувствительные данные следует хра-
          нить в объектах Kubernetes Secrets.

6. Примените YAML-манифест, чтобы создать экземпляр Grafana:

    $ kubectl apply -f grafana-instance.yaml
    grafana.grafana.integreatly.org/grafana-a created

   странстве имен monitoring:
