504     Глава 14   •  Работа с Helm-чартами и операторами

3. Подождите несколько минут и убедитесь в том, что оператор Prometheus
   успешно развернут:

    $ kubectl get csv -n operators
    NAME                         DISPLAY              VERSION  REPLACES   PHASE
    prometheusoperator.v0.70.0   Prometheus Operator  0.70.0
    prometheusoperator.v0.65.1   Succeeded

4. Удостоверьтесь в том, что поды оператора Prometheus находятся в состоянии
   Running:

    $ kubectl get pods -n operators
    NAME                                  READY   STATUS    RESTARTS   AGE
    prometheus-operator-84f9b76686-2j27n  1/1     Running   0          87s

5. Найдите и установите оператор Grafana через OLM, ориентируясь на опи-
   санные выше шаги:

    $ kubectl create -f https://operatorhub.io/install/grafana-operator.yaml

6. Выведите список объектов CRD, регистрируемых в кластере при установке
   операторов:

    $ kubectl get crd
    NAME                                                 CREATED AT
    alertmanagerconfigs.monitoring.coreos.com            2024-10-18T09:14:03Z
    alertmanagers.monitoring.coreos.com                  2024-10-18T09:14:04Z
    catalogsources.operators.coreos.com                  2024-10-18T09:10:00Z
    clusterserviceversions.operators.coreos.com          2024-10-18T09:10:00Z
    grafanaalertrulegroups.grafana.integreatly.org       2024-10-18T09:25:19Z
    ... <фрагмент опущен для краткости> ...

7. Вы увидите несколько CRD, созданных в кластере Kubernetes.

После развертывания операторов Prometheus и Grafana можно переходить
к созданию их экземпляров и настройке мониторингового стека для наблю-
дения за состоянием кластера Kubernetes. Этот процесс описан в следующем
подразделе.

Настройка экземпляров Prometheus и Grafana
с помощью операторов
Для настройки новых экземпляров Prometheus и Grafana мы будем использо-
вать стандартные YAML-манифесты, основанные на конфигурациях CRD. Все
инструкции и YAML-файлы, необходимые для выполнения этого упражнения,
находятся в каталоге Chapter14 репозитория GitHub.
