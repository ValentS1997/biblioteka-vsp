538     Глава 16   •  Запуск кластера на платформе Amazon Web Services

Платформа Amazon Web Services
Как вы, вероятно, уже догадались, платформа AWS принадлежит компании
Amazon. Ее история началась в 2000 году, когда Amazon экспериментировала
с облачными сервисами, создавая интерфейсы прикладного программирования
(API) для своих розничных партнеров. Эти эксперименты в итоге привели к по-
явлению AWS — одного из мировых лидеров в области облачных вычислений,
чьи решения сейчас используют как малые, так и крупные предприятия, рабо-
тающие в самых разных отраслях.
В ходе своих экспериментов компания Amazon осознала необходимость в соз-
дании более совершенной и стандартизированной инфраструктурной платфор-
мы — не только для размещения уже существующих сервисов, но и для обеспе-
чения их масштабируемости по мере роста числа розничных подразделений,
активно использующих эти программные решения.
В 2003 году Крис Пинкэм и Бенджамин Блэк подготовили технический доку-
мент, который был одобрен Джеффом Безосом в 2004 году. В нем описывалась
инфраструктурная платформа, позволяющая программно разворачивать вы-
числительные ресурсы и ресурсы хранилища.
Первое публичное упоминание AWS состоялось в конце 2004 года. Однако
тогда этот термин обозначал набор инструментов и API, предназначенных для
взаимодействия сторонних разработчиков с розничным каталогом товаров
Amazon, а не то, что сегодня понимается под облачной платформой Amazon
Web Services.
Полноценный запуск AWS состоялся лишь в 2006 году. В марте был выпущен
сервис Simple Storage Service (S3)1, позволявший разработчикам записывать
и предоставлять отдельные файлы, используя веб-API вместо локальной или
удаленной файловой системы.
Следующим стал Amazon Simple Queue Service (SQS) — распределенная система
обмена сообщениями, которая также могла управляться и использоваться раз-
работчиками посредством API. Этот сервис входил в первоначальный набор
инструментов AWS.
Наконец, в том же 2006 году для существующих клиентов AWS вышла бета-
версия Amazon Elastic Compute Cloud (Amazon EC2), позволявшая программно
запускать вычислительные ресурсы Amazon EC2 с помощью API, разработан-
ных Amazon.
Эти сервисы легли в основу публичной облачной платформы Amazon, услуги ко-
торой компания могла не только использовать для собственных нужд, но и пред-
лагать другим организациям и частным пользователям вроде нас с вами.

1  Есть совместимые открытые аналоги, которые можно развернуть на своих ресурсах
   самостоятельно, к примеру openminio (https://github.com/openminio/openminio).
