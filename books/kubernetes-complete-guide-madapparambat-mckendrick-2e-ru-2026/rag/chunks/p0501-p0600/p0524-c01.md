524     Глава 15   •  Запуск кластера на платформе Google Cloud Platform (GCP)

После установки интерфейса командной строки Google Cloud и настройки
учетной записи можно приступить к запуску кластера GKE.

Запуск кластера GKE
Поскольку процесс создания кластера занимает несколько минут, сначала за-
пустим команду для его инициализации, а затем обсудим то, что происходит
во время развертывания.

Перед запуском кластера необходимо активизировать сервис container.go
ogleapis.com:

 $ gcloud services enable container.googleapis.com

Затем нужно установить плагин, позволяющий проходить аутентификацию
в кластере с помощью kubectl. Для этого выполните команду:

 $ gcloud components install gke-gcloud-auth-plugin

После активизации сервиса и установки плагина мы можем создать двухузло-
вой кластер myfirstgkecluster в одной зоне доступности региона us-central1
(Central US) с помощью следующей команды:

 $ gcloud container clusters create myfirstgkecluster --num-nodes=2 --zone=us-
 central1-a

Через несколько минут вы увидите вывод, аналогичный приведенному на
рис. 15.6.
