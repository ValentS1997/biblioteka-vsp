508     Глава 14   •  Работа с Helm-чартами и операторами

Теперь пора проверить развертывание мониторингового стека в кластере
Kubernetes.

Убедимся в том, что система Prometheus успешно получает метрики. В одном
из терминалов выполните команду kubectl port-forward, чтобы открыть доступ
к сервису Prometheus (по окончании тестирования остановите переадресацию
портов, нажав Ctrl+C):

 $ kubectl port-forward -n monitoring svc/prometheus-operated 9091:9090
 Forwarding from 127.0.0.1:9091 -> 9090
 Forwarding from [::1]:9091 -> 9090

После этого откройте браузер и перейдите по адресу http://localhost:9091/targets. Убе-
дитесь в том, что Node Exporter присутствует среди целей Prometheus (рис. 14.10).

                Рис. 14.10. Портал Prometheus с Node Exporter,
                     видимым для узлов Kubernetes

Как видите, Prometheus успешно получает метрики узлов.

Теперь визуализируем получаемые данные с помощью инструмента Grafana.
Откройте терминал и выполните команду kubectl port-forward в отношении
сервиса Grafana:

 $ kubectl port-forward -n monitoring service/grafana-a-service 3000:3000
 Forwarding from 127.0.0.1:3000 -> 3000
 Forwarding from [::1]:3000 -> 3000
