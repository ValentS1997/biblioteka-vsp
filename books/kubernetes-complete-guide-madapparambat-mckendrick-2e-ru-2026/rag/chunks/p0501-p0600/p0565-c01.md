Подготовка локальной среды     565

Нажмите кнопку Start free (Попробовать Azure бесплатно) и следуйте инструк-
циям на экране. Процесс регистрации занимает примерно 15 минут. Для за-
вершения регистрации и активации бесплатного аккаунта потребуется указать
действительные данные банковской карты (кредитной или дебетовой).

После создания учетной записи вам нужно будет установить интерфейс команд-
ной строки (CLI) Azure.

Установка интерфейса командной строки Azure
Компания Microsoft предоставляет мощный кросс-платформенный инструмент
командной строки для управления ресурсами Microsoft Azure — Azure CLI. Про-
цесс его установки в macOS, Linux и Windows является максимально простым.

Установка в macOS
Если вы следовали инструкциям из предыдущих глав, то, вероятно, уже догада-
лись, что для установки Azure CLI в macOS мы будем использовать менеджер
пакетов Homebrew.

Выполните следующую команду:

 $ brew install azure-cli

После завершения установки проверьте версию утилиты:

 $ az --version

В результате вы увидите вывод, аналогичный показанному на рис. 17.2.
