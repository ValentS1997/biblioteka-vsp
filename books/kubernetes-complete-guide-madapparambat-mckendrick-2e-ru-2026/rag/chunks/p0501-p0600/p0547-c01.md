Запуск кластера Amazon EKS     547

литу eksctl. В результате будет создан кластер Amazon EKS со следующими
характеристиками.

z  Регион: us-west-1.
z Рабочие узлы: два узла, развернутые на экземплярах (инстансах) типа
   m5.large.
z Образ (AMI): официальный AMI (Amazon Machine Image) для AWS EKS.
z  Сеть: Amazon Virtual Private Cloud (VPC).
z Имя кластера: генерируется автоматически.

Чтобы запустить кластер, выполните команду:

 $ eksctl create cluster

Процесс создания кластера может занять до 30 минут. В это время можно от-
влечься на чашечку кофе или на проверку электронной почты.

После запуска команды в терминале отобразится базовая информация о версии
eksctl и используемом регионе:

 [i] eksctl version 0.180.0-dev+763027060.2024-05-29T21:36:10Z
 [i] using region us-west-2

Затем вы увидите информацию о сети и зонах доступности (AZ), в которых
будут развернуты ресурсы:

 [i] setting availability zones to [us-west-2d us-west-2b us-west-2c]
 [i] subnets for us-west-2d - public:192.168.0.0/19 private:192.168.96.0/19
 [i] subnets for us-west-2b - public:192.168.32.0/19 private:192.168.128.0/19
 [i] subnets for us-west-2c - public:192.168.64.0/19 private:192.168.160.0/19

Далее появятся сведения о версии используемого AMI-образа и поддерживае-
мой им версии Kubernetes:

 [i] nodegroup "ng-11c87ff4" will use "[AmazonLinux2/1.29]"
 [i] using Kubernetes version 1.29
