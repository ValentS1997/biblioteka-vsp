570     Глава 17   •  Запуск кластера на платформе Microsoft Azure

         Группа ресурсов (resource group) — это логический контейнер, объединяющий
         связанные ресурсы Azure. Сервисы, запущенные внутри группы, могут наследо-
          вать такие параметры, как настройки механизма управления доступом на основе
         ролей (RBAC), блокировки и регион запуска.

После успешного создания группы ресурсов вы увидите подтверждение в виде
таблицы (рис. 17.6).

                    Рис. 17.6. Создание группы ресурсов

Теперь, когда у нас есть контейнер для ресурсов, можно запустить сам кластер
AKS, выполнив следующую команду:

 $ az aks create --resource-group rg-myfirstakscluster-eus \
     --name aksmyfirstakscluster-eus --node-count 2 \
     --enable-addons monitoring --generate-sshkeys -o yaml

Запуск и настройка кластера занимают около 5 минут. Пока выполняется этот
процесс, разберем параметры команды az aks create.

z --resource-group — группа ресурсов, в которой будет запущен кластер.
   Кластер унаследует регион своей группы ресурсов. В нашем примере исполь-
   зуется созданная ранее группа rg-myfirstakscluster-eus, поэтому кластер
   будет создан в регионе eastus.
z --name — означает имя запускаемого кластера. В нашем случае это aks-
   myfirstakscluster-eus.
z  --node-count — количество узлов в кластере, в данном случае два. На момент
   написания книги для узлов по умолчанию использовались виртуальные
  машины типа Standard_DS2_v2, предоставляющие каждому узлу два вир-
   туальных процессора (vCPU) и 7 Гбайт оперативной памяти.
z  --enable-addons — список дополнений, включаемых при создании кластера.
  В данном примере мы активизируем только дополнение monitoring.
z --generate-ssh-keys — создает открытый и закрытый SSH-ключи для до-
   ступа к кластеру.
z  -o — определяет формат вывода команды. На этот раз мы выбрали формат
  YAML, так как он воспринимается легче, чем JSON или таблица.
