Запуск кластера
        на платформе Amazon16      Web Services с помощью
       Amazon Elastic Kubernetes
         Service

В предыдущей главе мы запустили кластер Kubernetes в общедоступном облаке,
познакомившись с одной из трех крупнейших публичных облачных платформ —
Google Cloud Platform (GCP).
Теперь пришло время поговорить о сервисе Amazon Elastic Kubernetes Service
(EKS) и платформе Amazon Web Services (AWS).
В этой главе вы узнаете, как создать учетную запись AWS, установить необхо-
димые инструменты в macOS, Windows и Linux, а также научитесь запускать
кластеры Amazon EKS и взаимодействовать с ними.

Технические требования
Для выполнения инструкций, приведенных в этой главе, вам потребуется учет-
ная запись AWS с указанным способом оплаты.

         Следование инструкциям, приведенным в этой главе, сопряжено с финансо-
        выми расходами. Поэтому крайне важно удалить все созданные ресурсы после
         завершения работы. Указанные в тексте цены были актуальны на момент на-
         писания главы; перед созданием ресурсов рекомендуется проверить текущие
         тарифы.

Знакомство с Amazon Web Services
и Amazon Elastic Kubernetes Service
Amazon Web Services (AWS) — это одна из первых публичных облачных плат-
форм. На момент написания книги (июнь 2024 года) она лидирует по доле
рынка, которая составляет 31 %. За ней следует Microsoft Azure с 25 %, а третье
место занимает Google Cloud Platform (GCP) с 11 %.
