Развертывание рабочей нагрузки и взаимодействие с кластером     525

После завершения процесса развертывания вы сможете перейти по URL-адресу,
указанному в выводе команды, и увидеть свой кластер в консоли Google Cloud
(рис. 15.7).

            Рис. 15.7. Отображение кластера в консоли Google Cloud

         Консоль Google Cloud доступна по адресу https://console.cloud.google.com/.

Теперь, когда наш кластер создан и запущен, можно перейти к развертыванию
рабочей нагрузки и изучению интерфейса консоли Google Cloud.

Развертывание рабочей нагрузки
и взаимодействие с кластером

При запуске кластера с помощью команды:

 $ gcloud container clusters create myfirstgkecluster --num-nodes=2 --zone=us-
 central1-a

в выводе появится следующая строка:

 kubeconfig entry generated for myfirstgkecluster.

Как вы, вероятно, уже догадались, эта строка означает, что все данные, необ-
ходимые для подключения вашего локального клиента kubectl к только что
развернутому кластеру GKE, были автоматически загружены.

Вы можете убедиться в этом с помощью команды:

 $ kubectl get nodes
