518     Глава 15   •  Запуск кластера на платформе Google Cloud Platform (GCP)

Если вы пользуетесь сервисами Google, например Gmail, YouTube или смарт-
фоном под управлением ОС Android, у вас уже есть учетная запись Google,
которую можно использовать для получения доступа к системе. В этом примере
один из авторов использует свою учетную запись, что видно по аватару в правом
верхнем углу страницы.

         Во время написания этой книги компания Google предоставляла кредиты на
         сумму 300 долларов США, действительные в течение 90 дней. Чтобы восполь-
          зоваться этим предложением, необходимо указать действующий способ оплаты.
         Это позволяет доказать, что регистрацию проходит не бот. После окончания
         срока действия или исчерпания кредитов вы сможете перейти на платный
         тарифный план. Подробнее об этом предложении можно узнать здесь: https://
           cloud.google.com/free/docs/free-cloud-features.

Чтобы активизировать бесплатные кредиты, перейдите по ссылке https://
cloud.google.com/free/docs/free-cloud-features#try-it-for-yourself и нажмите кнопку Get
started for free (Попробовать бесплатно). Если вы соответствуете условиям про-
граммы, ознакомьтесь с правилами и условиями использования и следуйте ин-
струкциям на экране. После регистрации вы будете перенаправлены в консоль
GCP. Если у вас уже есть учетная запись, войдите в консоль Google Cloud по
адресу https://console.cloud.google.com/.
Теперь создадим проект для развертывания наших ресурсов.

Создание проекта
В экосистеме GCP все ресурсы размещаются внутри проектов. Если вы только
что зарегистрировали учетную запись, проект с именем My First Project был создан
автоматически.

Если вы используете уже существующую учетную запись, создайте новый про-
ект специально для запуска кластера GKE. Для этого щелкните на меню Select
(Выбрать), расположенном на верхней панели, справа от логотипа GCP в левом
верхнем углу страницы.

Откроется список всех доступных проектов, позволяющий выбрать существу-
ющий или создать новый. Для создания нового проекта выполните следующие
шаги.

1. Нажмите кнопку NEW PROJECT (Создать проект).
2. Укажите необходимые параметры.
     Введите имя проекта.
     Выберите организацию, к которой будет привязан проект.
