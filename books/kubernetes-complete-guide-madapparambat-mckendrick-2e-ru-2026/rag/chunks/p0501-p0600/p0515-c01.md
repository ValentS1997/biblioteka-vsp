Запуск кластера
        на платформе Google15        Cloud Platform (GCP)
         с помощью Google
        Kubernetes Engine (GKE)

В этой главе мы развернем кластер Kubernetes на облачной платформе Google
Cloud Platform (GCP). Еще две публичные облачные платформы будут рассмо-
трены в последующих главах.

По ходу чтения вы создадите учетную запись в Google Cloud Platform, запустите
рабочую нагрузку Kubernetes с помощью сервиса Google Kubernetes Engine (GKE)
и получите представление о его возможностях.

Технические требования
Для выполнения инструкций, приведенных в этой главе, вам потребуется учет-
ная запись Google Cloud Platform с указанным способом оплаты.

         Следование инструкциям, приведенным в этой главе, сопряжено с финансо-
        выми расходами. Поэтому крайне важно удалить все созданные ресурсы по-
          сле завершения работы. Указанные в тексте цены были актуальны на момент
         написания этой главы; перед созданием ресурсов рекомендуется проверить
         текущие тарифы.

Знакомство с Google Cloud Platform
и Google Kubernetes Engine
Прежде чем приступить к регистрации учетной записи Google Cloud Platform
и установке инструментов, необходимых для запуска кластера на базе GKE,
давайте кратко обсудим сам сервис Google Kubernetes Engine и историю его
появления.
