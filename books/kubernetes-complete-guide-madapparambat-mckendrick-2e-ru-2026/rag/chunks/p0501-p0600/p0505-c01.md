Мониторинг кластеров Kubernetes с помощью Prometheus и Grafana     505

Следуйте приведенной ниже инструкции, чтобы настроить мониторинговый
стек, состоящий из Prometheus и Grafana, в Kubernetes.

1. Создайте пространство имен для развертывания системы мониторинга
   (см. файл monitoring-ns.yaml):

    $ kubectl apply -f monitoring-ns.yaml
    namespace/monitoring created

2. Настройте ServiceAccount с соответствующей ролью и разрешениями RBAC
   (см. файл monitoring-sa.yaml):

    $ kubectl apply -f monitoring-sa.yaml
    serviceaccount/prometheus created
    role.rbac.authorization.k8s.io/prometheus-role created
    rolebinding.rbac.authorization.k8s.io/prometheus-rolebinding created

3. Подготовьте YAML-манифест для нового экземпляра Prometheus (см. файл
   prometheus-instance.yaml):
   apiVersion: monitoring.coreos.com/v1
   kind: Prometheus
   metadata:
     name: example-prometheus
     namespace: monitoring
   spec:
     replicas: 2
     serviceAccountName: prometheus
     serviceMonitorSelector:
       matchLabels:
         app.kubernetes.io/name: node-exporter

         Обратите внимание на строку kind: Prometheus в этом манифесте — она указы-
          вает на использование CRD. Оператор Prometheus распознает этот тип ресурса
         и выполнит все необходимые действия для создания развертывания.

4. Создайте экземпляр Prometheus, применив конфигурацию к кластеру:

    $ kubectl apply -f prometheus-instance.yaml
    prometheus.monitoring.coreos.com/example-prometheus created

5. Аналогичным способом разверните экземпляр Grafana с помощью соответ-
   ствующего оператора:

   # grafana-instance.yaml
   apiVersion: grafana.integreatly.org/v1beta1
   kind: Grafana
