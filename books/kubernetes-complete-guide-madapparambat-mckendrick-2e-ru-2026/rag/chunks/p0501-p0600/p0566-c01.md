566     Глава 17   •  Запуск кластера на платформе Microsoft Azure

После успешной установки вы можете перейти к пункту «Настройка интерфей-
са командной строки Azure».

Установка в ОС Linux
Microsoft предоставляет универсальный установочный сценарий, подходящий
для самых распространенных дистрибутивов Linux. Чтобы запустить его, вы-
полните команду:

 $ curl -L https://aka.ms/InstallAzureCli | bash

Эта команда загрузит, установит и настроит все необходимое для работы Azure
CLI в выбранном дистрибутиве Linux. После завершения установки необходи-
мо перезапустить сеанс, то есть выйти из системы и войти снова.

В некоторых дистрибутивах для этого достаточно выполнить следующую
команду:

 $ source ~/.profile

После перезапуска сеанса проверьте версию установленной утилиты:

 $ az --version

Вывод будет практически идентичен результату, полученному при установке
CLI в macOS, за исключением информации об операционной системе. После
успешной установки вы можете перейти к пункту «Настройка интерфейса
командной строки Azure».

Установка в Windows
Установить Azure CLI в Windows можно несколькими способами. Первый
заключается в том, чтобы загрузить установщик по адресу https://aka.ms/
installazurecliwindows и запустить его двойным щелчком кнопкой мыши.
Второй способ предполагает выполнение следующей команды в оболочке
PowerShell для загрузки и установки упомянутого выше установщика:

 $ ProgressPreference = 'SilentlyContinue';
 Invoke-WebRequest -Uri https://aka.ms/installazurecliwindows
 -OutFile .\AzureCLI.msi;
 Start-Process msiexec.exe -Wait -ArgumentList '/I AzureCLI.msi /quiet';
 Remove-Item .\AzureCLI.msi

Установить Azure CLI также можно через пакетный менеджер Chocolatey:

 $ choco install azure-cli
