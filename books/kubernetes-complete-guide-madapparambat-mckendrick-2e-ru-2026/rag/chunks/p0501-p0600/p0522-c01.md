522     Глава 15   •  Запуск кластера на платформе Google Cloud Platform (GCP)

Как видите, несмотря на различия в методах установки, во всех трех операци-
онных системах используется одна и та же команда gcloud, дающая одинаковые
результаты. Все последующие команды, приведенные в этой главе, применимы
ко всем операционным системам.

Оболочка Cloud Shell
Установить GCP CLI также можно через встроенную оболочку Cloud Shell, до-
ступную прямо из консоли Google Cloud. Чтобы открыть ее, щелкните на значке
Shell (Оболочка), находящемся справа в верхнем меню консоли.
После инициализации вы увидите веб-интерфейс, похожий на терминал, в ко-
тором можно выполнить команду:

 $ gcloud version

Вывод этой команды немного отличается, поскольку Cloud Shell уже включает
полный набор инструментов Google Cloud. Тем не менее отображенные версии
будут соответствовать тем, которые устанавливались локально (рис. 15.4).

                 Рис. 15.4. Использование Google Cloud Shell

Если вы используете Google Cloud Shell, можете пропустить следующий пункт,
так как инициализация уже была выполнена автоматически.

Инициализация
Если вы установили клиент CLI GCP локально, вам необходимо связать его
со своей учетной записью GCP. Для этого выполните следующую команду:

 $ gcloud init
