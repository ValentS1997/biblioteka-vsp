Подготовка локальной среды     567

Независимо от выбранного способа после установки проверьте версию про-
граммы:

 $ az --version

Вывод будет практически идентичен результату, полученному при установке
CLI в macOS. Теперь, когда Azure CLI установлен, можно приступать к его на-
стройке.

Настройка интерфейса командной строки Azure
Чтобы настроить Azure CLI, выполните команду:

 $ az login

В браузере откроется окно авторизации. После успешного входа Azure CLI
будет настроен на работу с учетной записью пользователя, от имени которого
вы вошли в систему.

Если при авторизации возникают проблемы или вы работаете в среде без гра-
фического интерфейса (например, на удаленном сервере Linux), выполните
следующую команду, чтобы получить URL-адрес и уникальный код автори-
зации:

 $ az login --use-device-code

После успешного входа в систему в консоли отобразится информация об учет-
ной записи Azure. Чтобы просмотреть эти сведения повторно, используйте
команду:

 $ az account show

Если по какой-либо причине вы не можете установить Azure CLI локально, это
не проблема — в портале Azure доступна веб-версия терминала с CLI, которую
мы рассмотрим далее.

Доступ к оболочке Azure Cloud Shell
Чтобы открыть оболочку Azure Cloud Shell, перейдите по адресу https://por
tal.azure.com/ и войдите в систему, используя свои учетные данные. После входа
щелкните на значке Cloud Shell на верхней панели рядом с центральным полем
поиска.
