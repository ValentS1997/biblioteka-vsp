Подготовка локальной среды     545

Вернитесь в терминал и создайте профиль по умолчанию, выполнив команду:

 $ aws configure

Программа последовательно запросит такие параметры:
z AWS access key identifier (ID) — идентификатор ключа доступа из загруженного
   CSV-файла;
z AWS secret access key — секретный ключ доступа из того же файла;
z  Default region name — регион по умолчанию; мы указали us-west-2;
z  Default output format — формат вывода по умолчанию; мы оставили это поле
   пустым.

Чтобы проверить корректность настроек, выполните команду:

 $ aws ec2 describe-regions

В результате будет выведен список доступных регионов AWS. Пример вывода
показан ниже (рис. 16.4).

                    Рис. 16.4. Проверка работы AWS CLI

Теперь, когда AWS CLI установлен и настроен, установим второй инструмент
командной строки, необходимый для запуска кластера Amazon EKS.

Установка eksctl — официального CLI для Amazon EKS
Хотя запустить кластер Amazon EKS можно и с помощью AWS CLI, этот про-
цесс довольно сложен и состоит из множества шагов. Чтобы упростить задачу,
компания Weaveworks разработала инструмент командной строки eksctl, кото-
рый автоматически создает шаблон AWS CloudFormation, а затем развертывает
на его основе кластер.
