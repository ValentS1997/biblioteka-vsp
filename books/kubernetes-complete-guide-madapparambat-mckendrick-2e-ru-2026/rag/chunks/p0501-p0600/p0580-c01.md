580     Глава 17   •  Запуск кластера на платформе Microsoft Azure

                 Рис. 17.22. Просмотр информации об узлах

Раздел Cluster configuration (Конфигурация кластера)
Как было сказано выше, обновить версию Kubernetes в пулах узлов можно
только после обновления управляющего слоя — данная операция выполняется
именно здесь. Управляющий слой контролируется Microsoft и изолирован от
пользовательских пулов узлов.
Управляющий слой Kubernetes поддерживает обратную совместимость в пре-
делах трех релизов, поэтому обновление обычно возможно только до версии,
не более чем на три релиза новее текущей.

Раздел Application scaling (Масштабирование приложений)
В этом разделе можно активизировать механизм Kubernetes Event-Driven
Autoscaler (KEDA), который динамически масштабирует рабочие нагрузки в от-
вет на внешние события. На момент написания книги при настройке сервиса
через портал Azure поддерживались следующие источники событий: Azure
Service Bus, Cron, память (Memory) и процессор (CPU).

Раздел Networking (Сеть)
Здесь можно управлять сетевыми настройками вашего кластера.

Раздел Extensions + applications (Расширения и приложения)
В этом разделе представлены приложения Microsoft и сторонние приложения
из каталога Azure Marketplace, которые можно развернуть в кластере AKS
и управлять ими прямо через портал.

Раздел Backup (Резервное копирование)
Нативный сервис резервного копирования Azure теперь поддерживает создание
резервных копий рабочих нагрузок Kubernetes и данных приложений. Все со-
ответствующие операции можно выполнять в этом разделе.
