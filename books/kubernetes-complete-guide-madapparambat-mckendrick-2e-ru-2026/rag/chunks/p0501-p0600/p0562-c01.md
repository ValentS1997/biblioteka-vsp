Знакомство с Microsoft Azure
и Azure Kubernetes Service
Прежде чем перейти к установке необходимых инструментов, давайте познако-
мимся с историей сервисов, о которых пойдет речь в этой главе.

Платформа Microsoft Azure
В 2008 году компания Microsoft официально объявила о запуске нового сервиса
под названием Windows Azure.

Он был частью проекта, известного внутри компании как Project Red Dog,
который разрабатывался с 2004 года и был направлен на предоставление услуг
центра обработки данных с помощью ключевых компонентов Windows.

На конференции для разработчиков 2008 года Microsoft представила пять ос-
новных компонентов новой платформы.

z  Microsoft SQL Data Services — облачная версия сервиса Microsoft SQL
   Database, реализованная по модели PaaS (Platform as a Service — платформа
   как услуга) и призванная избавить пользователей от сложностей, связанных
   с самостоятельным размещением и обслуживанием SQL-серверов.
z  Microsoft .NET Services — еще один PaaS-сервис, позволяющий разработчикам
   развертывать свои приложения на базе .NET в среде выполнения, управляе
  мой Microsoft.
z  Microsoft SharePoint — облачная версия популярного корпоративного про-
   дукта, реализованная по модели SaaS (Software as a Service — программное
   обеспечение как услуга).
z  Microsoft Dynamics — SaaS-версия системы управления взаимоотношениями
   с клиентами (CRM) от Microsoft.
z Windows Azure — решение, реализованное по модели IaaS (Infrastructure as
   a Service — инфраструктура как услуга), аналогичное решениям других об-
   лачных провайдеров. Оно позволяло пользователям создавать виртуальные
  машины, настраивать хранилища данных и сетевые службы для поддержки
   запущенных рабочих нагрузок.

Все эти сервисы были построены на основе операционной системы Red Dog, от
которой проект и получил свое название. Это была специализированная версия
Windows со встроенным облачным уровнем.

В 2014 году компания переименовала Windows Azure в Microsoft Azure, чтобы
подчеркнуть название операционной системы, лежащей в основе облачных сер-
висов, а также тот факт, что в среде Azure уже выполнялось множество рабочих
