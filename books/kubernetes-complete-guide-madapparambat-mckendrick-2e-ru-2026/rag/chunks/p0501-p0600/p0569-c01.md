Запуск кластера AKS     569

Примерно через минуту запустится Cloud Shell, и вы увидите приглашение
командной строки (рис. 17.5).

              Рис. 17.5. Вход выполнен, оболочка готова к работе

Выполните следующую команду, чтобы проверить версию Azure CLI, как мы
это делали при локальной установке:

 $ az --version

Команду az login выполнять не требуется, так как при запуске Cloud Shell авто
ризация в Azure происходит автоматически в фоновом режиме.

Теперь, когда у нас есть настроенный инструмент Azure CLI, можно переходить
к запуску кластера AKS.

Запуск кластера AKS
Для запуска кластера AKS достаточно выполнить две команды.

Первая команда создает группу ресурсов Azure:

 $ az group create --name rg-myfirstakscluster-eus --location eastus -o table

В этом примере создается группа ресурсов rg-myfirstakscluster-eus в регионе
eastus, а параметр -o table форматирует вывод в виде таблицы (по умолчанию
Azure CLI использует формат JSON).
