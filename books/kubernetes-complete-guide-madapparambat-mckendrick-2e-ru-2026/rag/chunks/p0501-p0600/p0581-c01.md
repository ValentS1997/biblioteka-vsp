Развертывание рабочей нагрузки и взаимодействие с кластером     581

Раздел Other options (Прочие параметры)
Раздел меню Settings (Настройки) также содержит дополнительные параметры
для настройки различных аспектов кластера и его интеграции с другими на-
тивными сервисами Azure. Ссылка на документацию по AKS, содержащую
более подробные сведения, доступна в разделе «Дополнительные источники
информации» в конце главы.

Раздел Insights (Аналитика)
Еще одной частью портала Azure, на которую стоит обратить внимание, явля-
ется раздел Insights (Аналитика), расположенный в меню Monitoring (Монито-
ринг). Как вы помните, при создании кластера мы активизировали дополнение
monitoring с помощью флага --enable-addons monitoring.

Эта функция активизирует встроенную систему мониторинга Microsoft, кото-
рая отправляет данные ресурсов кластера в сервис Azure Log Analytics. После
этого собранные данные визуализируются в разделе Insights (Аналитика). Для
большинства сервисов Azure предусмотрена вкладка Insights (Аналитика), а со-
бранная здесь информация может использоваться службой Azure Monitor для
генерации оповещений (рис. 17.23).
