546     Глава 16   •  Запуск кластера на платформе Amazon Web Services

К сожалению, в начале 2024 года Weaveworks прекратила коммерческую деятель-
ность. Но перед этим компания передала управление проектом команде AWS.

       AWS CloudFormation — это сервис Amazon для управления инфраструктурой как
         кодом (Infrastructure as Code, IaC), который позволяет описывать ресурсы AWS
          в виде конфигурационных шаблонов, чтобы затем развертывать их в разных
         учетных записях или многократно в рамках одной и той же учетной записи.
         Это особенно полезно в ситуациях, когда необходимо регулярно воссоздавать
         окружение, например, в рамках процесса непрерывной интеграции (continuous
            integration, CI).

Как вы, вероятно, уже догадались, установка этого инструмента в macOS и Win
dows выполняется по схеме, описанной ранее. В macOS выполните команду:

 $ brew install eksctl

В Windows выполните команду:

 $ choco install eksctl

В Linux процесс установки eksctl требует выполнения следующих команд:

 $ PLATFORM=$(uname -s)_$(uname -m)
 $ curl -sLO "https://github.com/eksctl-io/eksctl/releases/latest/download/\
 eksctl_$PLATFORM.tar.gz"
 $ tar -xzf eksctl_$PLATFORM.tar.gz -C /tmp && rm eksctl_$PLATFORM.tar.gz
 $ sudo mv /tmp/eksctl /usr/local/bin

После установки проверьте версию утилиты с помощью команды:

 $ eksctl version

Теперь мы готовы к запуску кластера Amazon EKS.

взаимодействовать с ним и запускать рабочие нагрузки, так же как мы делали
