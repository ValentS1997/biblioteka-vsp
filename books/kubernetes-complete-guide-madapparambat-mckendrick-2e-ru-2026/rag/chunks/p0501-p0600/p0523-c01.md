Подготовка локальной среды     523

После ее запуска программа проведет краткую сетевую диагностику, чтобы
убедиться в наличии сетевого соединения, необходимого для работы клиента.
После успешной проверки отобразится приглашение:

 You must log in to continue. Would you like to log in (Y/n)?

Введите Y, чтобы открыть окно браузера. Если окно не открылось автоматиче-
ски, скопируйте предоставленный URL-адрес и вставьте его в адресную строку.
После выбора учетной записи, которую вы хотите использовать, появится экран
с перечнем разрешений, запрашиваемых клиентом (рис. 15.5).

               Рис. 15.5. Просмотр запрашиваемых разрешений

Если вы согласны предоставить указанные разрешения, нажмите кнопку Allow
(Разрешить). После этого в терминале появится подтверждение с указанием
пользователя, от имени которого был выполнен вход. Далее система предложит
вам выбрать облачный проект для дальнейшей работы. В списке будут отобра-
жены только уникальные идентификаторы проектов (Project ID), а не описа-
тельные имена, заданные ранее в консоли Google Cloud. Если у вас несколько
проектов, выберите нужный.

Вы можете изменить проект, используемый клиентом, выполнив команду:

 $ gcloud config set project PROJECT_ID

Вместо PROJECT_ID введите уникальный идентификатор проекта, на который
хотите переключиться.
