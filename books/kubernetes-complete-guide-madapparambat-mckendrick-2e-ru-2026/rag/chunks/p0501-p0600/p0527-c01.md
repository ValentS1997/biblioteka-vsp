Развертывание рабочей нагрузки и взаимодействие с кластером     527

Определив имя нужного контекста, вы можете переключиться на него с помо-
щью следующей команды, заменив CONTEXT_NAME соответствующим значением:

 $ kubectl config use-context CONTEXT_NAME

Теперь, когда ваш клиент kubectl настроен для взаимодействия с кластером
GKE, можно переходить к развертыванию примерной рабочей нагрузки.

Запуск примерной рабочей нагрузки
В качестве примера мы развернем приложение Guestbook, основанное на связ-
ке PHP/Redis. Этот пример используется в официальной документации по
Kubernetes. Первым шагом является создание объектов Deployment и Service
для Redis Leader. Для этого выполните следующие команды:

 $ kubectl apply -f https://raw.githubusercontent.com/GoogleCloudPlatform/
 kubernetes-engine-samples/main/quickstarts/guestbook/redis-leader-
 deployment.yaml
 $ kubectl apply -f https://raw.githubusercontent.com/GoogleCloudPlatform/
 kubernetes-engine-samples/main/quickstarts/guestbook/redis-leader-
 service.yaml

Затем необходимо создать объекты Deployment и Service для Redis Follower:

 $ kubectl apply -f https://raw.githubusercontent.com/GoogleCloudPlatform/
 kubernetes-engine-samples/main/quickstarts/guestbook/redis-follower-
 deployment.yaml
 $ kubectl apply -f https://raw.githubusercontent.com/GoogleCloudPlatform/
 kubernetes-engine-samples/main/quickstarts/guestbook/redis-follower-
 service.yaml

После запуска обоих компонентов Redis можно развернуть фронтенд, то есть
само приложение Guestbook. Для этого примените следующие манифесты:

 $ kubectl apply -f https://raw.githubusercontent.com/GoogleCloudPlatform/
 kubernetes-engine-samples/main/quickstarts/guestbook/frontend-deployment.yaml
 $ kubectl apply -f https://raw.githubusercontent.com/GoogleCloudPlatform/
 kubernetes-engine-samples/main/quickstarts/guestbook/frontend-service.yaml

Через несколько минут выполните следующую команду, чтобы получить ин-
формацию о только что созданном сервисе:

 $ kubectl get service frontend

В выводе команды будет указан внешний IP-адрес (EXTERNAL-IP), как показано
на рис. 15.9.
