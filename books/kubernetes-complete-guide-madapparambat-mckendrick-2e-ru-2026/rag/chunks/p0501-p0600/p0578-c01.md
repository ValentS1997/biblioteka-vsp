578     Глава 17   •  Запуск кластера на платформе Microsoft Azure

                    Рис. 17.19. Просмотр списка сервисов

Раздел Storage (Хранилище)
В этом разделе можно управлять параметрами постоянного хранилища, на-
строенного в кластере. В нашем тестовом примере постоянное хранилище
не используется, поэтому здесь почти ничего не отображается.

Раздел Configuration (Конфигурация)
Здесь можно просматривать и редактировать объекты ConfigMap и Secret,
созданные в кластере. Поскольку в нашей рабочей нагрузке подобные объек-
ты не были настроены, в данном случае список состоит только из системных
ресурсов самого кластера, изменять которые настоятельно не рекомендуется.

Раздел Custom resources (Пользовательские ресурсы)
Этот раздел позволяет управлять пользовательскими ресурсами, подключен-
ными к вашему кластеру.

Раздел Events (События)
Здесь отображаются события кластера в режиме реального времени. Они по-
зволяют отслеживать состояние компонентов и устранять возможные проблемы
с кластером и приложениями.

Раздел Run command (Выполнение команд)
Эта полезная функция позволяет выполнять команды kubectl прямо с портала
Azure, не запуская оболочку Cloud Shell и не настраивая локальную установку
kubectl (рис. 17.20).
