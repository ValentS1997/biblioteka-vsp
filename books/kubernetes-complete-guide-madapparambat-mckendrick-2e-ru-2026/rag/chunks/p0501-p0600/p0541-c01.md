Подготовка локальной среды     541

Теперь установим инструменты командной строки, необходимые для запуска
кластера Amazon EKS.

Установка интерфейса командной строки AWS
Следующим шагом является установка интерфейса командной строки (CLI)
AWS. Как и в предыдущей главе, мы рассмотрим процесс его установки в Win
dows, Linux и macOS. Начнем с macOS.

Установка в macOS
Для установки AWS CLI в macOS с помощью Homebrew достаточно выполнить
одну простую команду:

 $ brew install awscli

После завершения установки выполните команду:

 $ aws –version

В выводе отобразится номер версии AWS CLI вместе с информацией о вспомо-
гательных службах, необходимых для его работы, как показано на следующем
снимке экрана (рис. 16.1).

                     Рис. 16.1. Проверка версии AWS CLI

После успешной установки вы можете перейти к подразделу «Настройка ин-
терфейса командной строки AWS».

Установка в Linux
Хотя пакеты AWS CLI доступны для большинства дистрибутивов Linux, самым
простым способом его установки являются загрузка и запуск официального
установщика.

        В представленной ниже инструкции предполагается, что пакеты curl и unzip уже
          установлены. Если у вас их нет, установите их с помощью пакетного менедже-
         ра вашего дистрибутива. Например, в Ubuntu для этого можно использовать
         команду sudo apt-get install unzip curl.
