520     Глава 15   •  Запуск кластера на платформе Google Cloud Platform (GCP)

После инсталляции Homebrew установить интерфейс командной строки GCP
можно с помощью следующей команды:

 $ brew install --cask google-cloud-sdk

Вы можете проверить корректность установки, выполнив команду:

 $ gcloud version

Если установка прошла успешно, вы увидите вывод, аналогичный приведен-
ному на рис. 15.3.

            Рис. 15.3. Результат проверки версии CLI GCP в macOS

Если при установке возникнут проблемы, обратитесь к документации, ссылки
на которую приведены выше. Дополнительную информацию об установке CLI
GCP можно получить с помощью команды:

 $ brew info --cask google-cloud-sdk

После установки интерфейса командной строки GCP вы можете перейти
к пункту «Инициализация».

Установка в Windows
Установить интерфейс командной строки GCP в Windows можно нескольки-
ми способами. Первый сводится к открытию сеанса PowerShell и выполнению
следующей команды для установки CLI GCP через Chocolatey.

         Как и Homebrew в macOS, Chocolatey представляет собой пакетный менеджер,
         обеспечивающий удобный и единообразный способ установки широкого спектра
         программ в Windows с помощью оболочки PowerShell и специального синтаксиса.
         Это избавляет от необходимости разбираться со множеством различных способов
          установки, предусмотренных в Windows. Более подробную информацию можно
         найти на официальном сайте проекта: https://chocolatey.org/.
