Подготовка локальной среды     521

 $ Set-ExecutionPolicy Bypass -Scope Process -Force;
   [System.Net.ServicePointManager]::SecurityProtocol =
     [System.Net.ServicePointManager]::SecurityProtocol -bor 3072;
   iex ((New-Object System.Net.WebClient).DownloadString(
     'https://chocolatey.org/install.ps1'
   ))

После установки Chocolatey (или если он уже установлен) выполните следующую
команду для установки GCP CLI:

 $ choco install --ignore-checksum gcloudsdk

Альтернативный способ предполагает загрузку установочного файла по ссылке:
https://dl.google.com/dl/cloudsdk/channels/rapid/GoogleCloudSDKInstaller.exe. После загруз-
ки запустите установщик и следуйте инструкциям на экране.

По завершении установки откройте новое окно PowerShell и выполните команду:

 $ gcloud version

Если все прошло успешно, вы увидите результат, аналогичный выводу, пока-
занному в предыдущем пункте. После установки интерфейса командной строки
GCP вы можете перейти к пункту «Инициализация».

Установка в Linux
Хотя пакеты Google Cloud CLI доступны для большинства дистрибутивов
Linux, описание установки через все возможные пакетные менеджеры заняло
бы слишком много места. Поэтому воспользуемся универсальным глобальным
установочным сценарием, предоставленным Google.

Для запуска установщика выполните команду:

 $ curl https://sdk.cloud.google.com | bash

Во время установки сценарий задаст несколько вопросов. В большинстве слу-
чаев можно отвечать Yes. После завершения установки выполните следующую
команду для перезапуска сеанса и применения изменений, внесенных установ-
щиком:

 $ exec -l $SHELL

Получить информацию о версии установленного интерфейса командной строки
GCP можно с помощью команды:

 $ gcloud version
