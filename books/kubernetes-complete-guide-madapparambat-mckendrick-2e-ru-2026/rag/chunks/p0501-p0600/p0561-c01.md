Запуск кластера
        на платформе Microsoft17        Azure с помощью Azure
        Kubernetes Service

Последним из публичных облачных сервисов Kubernetes, который мы рас-
смотрим, является Azure Kubernetes Service (AKS), предоставляемый Microsoft
Azure — одной из трех крупнейших публичных облачных платформ (две другие,
Google Cloud Platform и Amazon Web Services, мы обсудили в главах 15 и 16
соответственно).

В ходе изучения этой главы вы настроите локальную среду и установите инстру-
менты, необходимые для взаимодействия с вашей учетной записью Microsoft
Azure и запуска кластера AKS.

После создания кластера мы развернем ту же рабочую нагрузку, что и в пре-
дыдущих главах, а затем оценим уровень интеграции кластера AKS с порталом
Microsoft Azure.

В завершение главы мы сравним все три рассмотренные платформы и выберем
наиболее предпочтительный сервис.

Технические требования
Для выполнения инструкций, приведенных в этой главе, вам потребуется учет-
ная запись Microsoft Azure с указанным способом оплаты.

         Следование инструкциям, приведенным в этой главе, сопряжено с финансо-
        выми расходами. Поэтому крайне важно удалить все созданные ресурсы по-
          сле завершения работы. Указанные в тексте цены были актуальны на момент
         написания этой главы; перед созданием ресурсов рекомендуется проверить
         текущие тарифы.
