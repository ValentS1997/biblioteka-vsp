532     Глава 15   •  Запуск кластера на платформе Google Cloud Platform (GCP)

z  Applications (Приложения) — показывает приложения, установленные из ка-
   талога Google Cloud Marketplace (о котором чуть позже).
z  Secrets and ConfigMaps (Объекты Secret и ConfigMap) — этот раздел позволяет
   безопасно управлять объектами Secret и ConfigMap.
z  Storage (Хранилище) — позволяет просматривать настроенные объекты
   PersistentVolumeClaim и управлять классами хранилища (StorageClass).
z  Object Browser (Обозреватель объектов) — своеобразный проводник по API
   Kubernetes и GCP. Он позволяет просматривать доступные API и конечные
   точки, а также ресурсы и объекты, развернутые в рамках вашего проекта.

Следующие сервисы обеспечивают интеграцию GKE с нативными сервисами
Google Cloud.

z  Backup for GKE (Резервное копирование для GKE) — позволяет использовать
   сервис резервного копирования Google Cloud (не входящий в состав GKE)
   для создания резервных копий рабочих нагрузок и приложений, размещен-
  ных в кластере GKE. Лично я в своей практике исхожу из того, что данные
   в рабочих нагрузках Kubernetes, развернутых в облаке, являются эфемерны-
   ми. Для запуска служб, нуждающихся в резервном копировании, таких как
   базы данных, мы используем облачные сервисы с гарантированным SLA,
   развернутые за пределами моего кластера. Однако если по какой-то причине
   этот вариант вам не подходит, данный сервис станет отличным решением.
z  Gateways, Services and Ingress (Шлюзы, сервисы и входящий трафик) — этот
   раздел был рассмотрен ранее.
z  Network Function Optimizer (Оптимизатор сетевой функции) — позволяет под-
   ключить рабочие нагрузки GKE к частным сетям других ресурсов Google
   Cloud. Это расширяет сеть кластера, позволяя его компонентам использовать
   приватные подключения к таким сервисам, как облачные базы данных.
z  Marketplace (Маркетплейс) — здесь представлен каталог готовых к установке
  приложений для GKE. Они публикуются различными поставщиками ПО
  и включают как бесплатные, так и коммерческие решения.

Как отмечалось выше, перечисленные функции доступны в стандартной вер-
сии GKE. Ее использование аналогично самостоятельному развертыванию
Kubernetes за исключением того, что в данном случае за развертывание узлов
и управление ресурсами отвечает Google.

Корпоративная версия GKE Enterprise включает дополнительные функции,
востребованные в крупных организациях. Среди них — управляемые сервисные
сетки, а также средства обеспечения безопасности, соответствия нормативным
требованиям и управления доступом на основе ролей (RBAC). Эти функции
предоставляются за дополнительную плату, но являются ключевыми для пред-
приятий, работающих в строго регулируемых отраслях.
