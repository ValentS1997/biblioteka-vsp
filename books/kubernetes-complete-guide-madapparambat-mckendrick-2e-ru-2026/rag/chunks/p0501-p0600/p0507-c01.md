Мониторинг кластеров Kubernetes с помощью Prometheus и Grafana     507

8. Вывод команд показывает, что операторы создали необходимые ресур-
  сы Kubernetes на основе CRD. Обратите также внимание на то, что были
   созданы сервисы Prometheus и Grafana, доступ к которым мы получим на
  следующем этапе.

В качестве демонстрации мы настроим Node Exporter в кластере и визуализи-
руем его данные с помощью Grafana. Node Exporter — это один из экспортеров
Prometheus, который собирает детальную статистику хоста, включая данные
об оборудовании и операционной системе, уровень загрузки процессора, объем
потребляемой памяти и другие системные метрики. Он работает на каждом узле
Kubernetes (или на физических и виртуальных серверах) как отдельный сервис
и предоставляет эти метрики через конечную точку HTTP. Система Prometheus
собирает эти данные, позволяя отслеживать состояние и производительность
узлов. Это дает администраторам возможность анализировать уровень исполь-
зования ресурсов и оперативно выявлять проблемы в инфраструктуре.

Чтобы запустить экземпляр экспортера на каждом узле, его следует развернуть
в виде объекта DaemonSet. В этом случае Prometheus сможет собирать систем-
ные метрики со всех узлов кластера, обеспечивая комплексное наблюдение
за производительностью системы. Создайте Node Exporter с помощью файла
node-exporter-daemonset.yaml:

 $ kubectl apply -f node-exporter-daemonset.yaml
 daemonset.apps/node-exporter created

Затем создайте сервис, позволяющий системе Prometheus обнаруживать и опра-
шивать все поды Node Exporter, работающие на узлах кластера, обеспечивая
централизованный сбор данных. Для создания этого сервиса используйте
YAML-манифест node-exporter-svc.yaml:

 $ kubectl apply -f node-exporter-svc.yaml
 service/node-exporter created

Создайте объект serviceMonitor, который указывает системе Prometheus, какие
сервисы и как именно необходимо опрашивать. В этой конфигурации задаются
целевой сервис, интервалы опроса, метки и другие параметры, обеспечивающие
согласованность сбора данных без участия администратора. Для создания объ-
екта serviceMonitor выполните следующую команду:

 $ kubectl apply -f servicemonitor-instance.yaml
 servicemonitor.monitoring.coreos.com/node-exporter created
