526     Глава 15   •  Запуск кластера на платформе Google Cloud Platform (GCP)

В результате выполнения этой команды вы должны увидеть два узла, имена
которых начинаются с префикса gke, как показано на рис. 15.8.

         Рис. 15.8. Использование kubectl для получения списка узлов

Если вывод подтверждает наличие узлов кластера GKE и текущая конфигу-
рация kubectl вас устраивает, вы можете перейти сразу к пункту «Запуск при-
мерной рабочей нагрузки» следующего подраздела.

Ссылка на официальную документацию по GKE приведена в разделе «Допол-
нительные источники информации» в конце этой главы.

Настройка локального клиента
Если вам необходимо подключить к своему кластеру другую установку kubectl,
для этого можно использовать специальную команду интерфейса командной
строки GCP.

        Следующие инструкции предполагают, что CLI GCP уже установлен и настроен.
         Если это не так, вернитесь к подразделу «Установка интерфейса командной
          строки GCP» ранее в этой главе.

Чтобы загрузить учетные данные и настроить kubectl для работы с кластером,
выполните команду:

 $ gcloud container clusters get-credentials myfirstgkecluster --zone=us-
 central1-a

Если вы хотите переключиться на другую конфигурацию (называемую контек-
стом), используйте следующие команды. Чтобы отобразить текущий контекст,
выполните команду:

 $ kubectl config current-context

Чтобы просмотреть список всех доступных контекстов, выполните команду:

 $ kubectl config get-contexts -o name
