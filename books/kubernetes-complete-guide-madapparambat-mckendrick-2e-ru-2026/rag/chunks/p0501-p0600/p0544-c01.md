544     Глава 16   •  Запуск кластера на платформе Amazon Web Services

                   Рис. 16.3. Предоставление прав доступа

         Поскольку мы проводим тестирование не в рабочей среде и планируем удалить
          созданного пользователя в конце главы, мы можем выбрать политику, предо-
        ставляющую достаточно широкие права доступа. Если же вы развертываете
          кластер в среде, приближенной к рабочей, то для корректной настройки политик
         и разрешений рекомендуется обратиться к официальной документации AWS.

5. После проверки введенных данных нажмите кнопку Create user (Создать
   пользователя). Затем выберите пользователя ekscluster из списка, перейдите
   на вкладку Security credentials (Учетные данные для обеспечения безопас-
   ности) и нажмите кнопку Create access key (Создать ключ доступа) в разделе
   Access keys (Ключи доступа). Выберите вариант Command Line Interface (CLI)
   (Интерфейс командной строки) и продолжите создание ключа, последо-
   вательно нажав кнопки Next (Далее) и Create access key (Создать ключ до-
   ступа). После генерации ключа нажмите кнопку Download .csv file (Скачать
   CSV-файл), чтобы скачать файл с учетными данными, и завершите процесс
   нажатием кнопки Done (Готово).

         Сохраните загруженный CSV-файл в надежном месте, так как он содержит ключи
          доступа к вашей учетной записи AWS.
