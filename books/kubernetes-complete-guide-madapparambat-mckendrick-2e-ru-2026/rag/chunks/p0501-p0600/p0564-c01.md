Подготовка локальной среды
Прежде чем приступить к развертыванию кластера, необходимо выполнить не-
сколько предварительных действий. Прежде всего вам понадобится среда для
его запуска, так что, если у вас еще нет учетной записи Microsoft Azure, самое
время ее создать.

Создание бесплатной учетной записи Microsoft Azure
Зарегистрировать бесплатную учетную запись Azure можно по адресу https://
azure.microsoft.com/free/ (рис. 17.1).

            Рис. 17.1. Просмотр бесплатных сервисов Microsoft Azure

На момент написания книги бесплатная учетная запись предоставляла 12-месяч
ный доступ к популярным сервисам, кредит в размере 200 долларов США
для изучения и тестирования различных сервисов Azure и доступ к более
чем 55 бесплатным сервисам.
