Знакомство с объектом Deployment     395

       app: nginx
       environment: test
     type: LoadBalancer
     ports:
       - port: 80
         protocol: TCP
         targetPort: 80
   Селектор меток этого сервиса совпадает с селектором объекта Deployment.
  Спецификация сервиса указывает на необходимость опубликовать наш
   объект Deployment на порте 80 облачного балансировщика нагрузки и пере-
   направить трафик с этого порта на поды.

        В зависимости от того, как развернут ваш кластер Kubernetes, использование
          сервиса типа LoadBalancer может оказаться невозможным. В этом случае для
         выполнения данного упражнения вы можете использовать сервис типа NodePort
         или ограничиться простым ClusterIP, пропустив часть, связанную с организа-
         цией внешнего доступа. При использовании таких локальных развертываний,
          как minikube, для получения доступа к сервису следует использовать команду
          minikube service. Более подробную информацию можно найти по адресу https://
           minikube.sigs.k8s.io/docs/commands/service/.

2. Создайте объект nginx-service-example и используйте команды kubectl
   get или kubectl describe, чтобы просмотреть информацию о новом сервисе
  и связанном с ним балансировщике нагрузки:

    $ kubectl apply -f nginx-service.yaml
    service/nginx-service-example created

    $ kubectl describe service nginx-service-example
    Name:                     nginx-service-example
    Namespace:                default
    Labels:                   <none>
    Annotations:              <none>
    Selector:                 app=nginx,environment=test
    ...<фрагмент опущен для краткости>...
    Endpoints:                10.244.1.2:80,10.244.2.2:80,10.244.2.3:80
    Session Affinity:         None
    External Traffic Policy:  Cluster
    Events:                   <none>
