Статическое и динамическое выделение объектов PersistentVolume     357

Этот провиженер взаимодействует с файловой системой нашего хоста и авто-
матически создает тома hostPath для подов. Но аналогичным образом можно
было бы использовать тома Amazon EBS или Google PD.

В системе GKE предусмотрен класс хранилища с провиженером, способным
взаимодействовать с API Google PD. Эта встроенная возможность платформы
Google Cloud реализуется с помощью StorageClass следующим образом:

# gce-pd-sc.yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: slow
provisioner: kubernetes.io/gce-pd
parameters:
  type: pd-standard

В свою очередь, в AWS существует объект StorageClass с провиженером, рабо-
тающим с API томов EBS. Эти провиженеры представляют собой библиотеки,
способные взаимодействовать с API соответствующих облачных провайдеров.

Таким образом, именно объекты StorageClass позволяют Kubernetes работать
со множеством различных технологий хранения. С точки зрения пода не имеет
значения, используется ли том EBS, NFS или Google PD: под «видит» толь-
ко объект PersistentVolume. Вся логика взаимодействия с конкретной си-
стемой хранения реализована в провиженере, на который ссылается объект
StorageClass.

Хорошая новость заключается в том, что вы можете добавить в кластер произ-
вольное количество объектов StorageClass с их провиженерами.

Ничто не мешает расширять возможности кластера, добавляя новые объекты
StorageClass, подобно плагинам. При этом вы просто увеличиваете количество
технологий хранения, с которыми умеет работать ваш кластер. Например, мож-
но добавить в кластер minikube объект StorageClass для Amazon EBS. Однако
пользы от этого не будет: если кластер minikube работает не на экземпляре EC2,
а на локальной машине, подключить том EBS все равно не удастся.

С практической точки зрения лучше использовать CSI-драйверы постав-
щиков, поддерживающих локальное развертывание, например OpenEBS,
TopoLVM или Portworx. Они позволяют работать с постоянным хранилищем
даже в локальной среде, в том числе в minikube. Кроме того, большинство об-
лачных провайдеров предлагает бесплатные тарифы для небольших Kubernetes-
развертываний, что позволяет тестировать созданные решения в облаке без
существенных затрат.

В следующем подразделе мы поговорим о динамическом выделении ресурсов
хранилища с использованием PVC.
