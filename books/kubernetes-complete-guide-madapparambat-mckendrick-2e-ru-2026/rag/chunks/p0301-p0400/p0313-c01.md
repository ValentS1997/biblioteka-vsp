Сервис типа LoadBalancer     313

тре .spec.loadBalancerClass реализация балансировщика соответствующего
класса активно отслеживает сервисы. В этом случае стандартная реализация
балансировщика (например, предоставляемая облачным провайдером) будет
игнорировать сервисы с заданным в этом поле значением. Важно отметить,
что значение в поле spec.loadBalancerClass можно задать только для сер-
виса типа LoadBalancer, после чего его уже нельзя будет изменить. Значение
spec.loadBalancerClass должно соответствовать формату идентификатора
в стиле метки. Допускается использование префикса, например internal-vip
или example.com/internal-vip. Имена без префиксов зарезервированы для
конечных пользователей.
