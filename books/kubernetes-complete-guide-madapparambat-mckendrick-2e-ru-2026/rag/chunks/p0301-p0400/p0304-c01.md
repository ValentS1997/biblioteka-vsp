304     Глава 8   •  Публикация подов с помощью сервисов

Просмотр подробных сведений о сервисе NodePort
Как и в случае с любыми другими объектами Kubernetes, для просмотра по
дробной информации о сервисе NodePort используется команда kubectl
describe. Выведем сведения о сервисе nodeport-whoami:

 $ kubectl describe service nodeport-whoami
 Name:                     nodeport-whoami
 ... <фрагмент опущен для краткости> ...
 Selector:                 app=whoami
 Type:                     NodePort
 IP Family Policy:         SingleStack
 IP Families:              IPv4
 IP:                       10.98.160.98
 IPs:                      10.98.160.98
 Port:                     <unset>  80/TCP
 TargetPort:               80/TCP
 NodePort:                 <unset>  30001/TCP
 Endpoints:                10.244.0.16:80,10.244.0.17:80
 ... <фрагмент опущен для краткости> ...

В этом выводе содержится несколько ключевых элементов.
z  IP: 10.98.160.98 — это ClusterIP, назначенный сервису, то есть внутренний
   IP-адрес, по которому другие сервисы в кластере могут обращаться к дан-
  ному сервису.
z  Port: <unset> 80/TCP — данный сервис прослушивает порт 80 и использует
   протокол TCP. Запись <unset> означает, что имя для порта не было задано.
z NodePort: <unset> 30001/TCP — это порт на каждом узле кластера, через
   который внешний трафик получает доступ к сервису. В данном случае уста-
   новлено значение 30001, что позволяет обращаться к сервису по IP-адресу
   любого узла на порте 30001.
z  Endpoints: 10.244.0.16:80, 10.244.0.17:80 — фактические IP-адреса и пор-
  ты подов, развернутых за сервисом. В данном случае сервис обслуживают
   два пода, доступные по адресам 10.244.0.16:80 и 10.244.0.17:80.

В следующем подразделе вы узнаете, как удалить сервис с помощью коман-
ды kubectl delete svc.

Удаление сервисов
Удалять сервисы не следует слишком часто. В отличие от подов, которые пред-
полагается легко удалять и пересоздавать, сервисы предназначены для долго-
срочного использования. Они обеспечивают стабильный доступ к подам, и их
удаление напрямую влияет на доступность приложений.
