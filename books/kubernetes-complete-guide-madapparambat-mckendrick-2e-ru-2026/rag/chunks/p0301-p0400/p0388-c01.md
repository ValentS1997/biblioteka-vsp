388     Глава 11   •  Использование объекта Deployment

Kubernetes. Как правило, они используются совместно с объектами Service
(описанными в главе 8) для достижения высокой отказоустойчивости приложе-
ния, мониторинга его состояния и интеллектуальной балансировки входящего
трафика.

Теперь рассмотрим спецификацию Deployment и создадим такой объект в кла-
стере Kubernetes.

Создание объекта Deployment
Для создания YAML-манифеста объекта Deployment можно использовать
любые поддерживаемые инструменты. Например, команда kubectl create
deployment выводит готовый YAML-шаблон с заполненными значениями:

 $ kubectl create deployment my-deployment --replicas=1 --image=my-image:latest
 --dry-run=client --port=80 -o yaml

Вы можете перенаправить этот вывод в файл и использовать его как основу для
своих конфигураций Deployment:

 $ kubectl create deployment my-deployment --replicas=1 --image=my-image:latest
 --dry-run=client --port=80 -o yaml > my-deployment.yaml

Сначала рассмотрим структуру YAML-манифеста nginx-deployment.yaml, ко-
торый поддерживает три реплики пода с Nginx:

# nginx-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment-example
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
      environment: test
  minReadySeconds: 10
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 1
      maxSurge: 1
  template:
    metadata:
      labels:
        app: nginx
        environment: test
