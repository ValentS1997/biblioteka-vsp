Объект ReplicaSet     379

Теперь нам необходимо изменить состояние кластера с помощью декларатив-
ной команды kubectl apply:

 $ kubectl apply -f ./nginx-replicaset-example.yaml

Чтобы убедиться в том, что количество подов, которыми управляет ReplicaSet,
изменилось, используйте команду kubectl get pods -n rs-ns или kubectl
describe rs/nginx-replicaset-example -n rs-ns.

         Аналогичного результата можно достичь и императивным способом, выполнив
         команду kubectl scale rs/nginx-replicaset-example --replicas=5. Однако такие
         императивные команды рекомендуется использовать только в учебных или
         отладочных сценариях.

А теперь уменьшим количество реплик. Откройте файл nginx-replicaset.yaml
и задайте для параметра replicas значение 2:

...
spec:
  replicas: 2
...

Затем снова примените изменения декларативным способом с помощью коман-
ды kubectl apply:

 $ kubectl apply -f ./nginx-replicaset-example.yaml

На этом этапе вы можете удостовериться в том, что число подов уменьшилось
до двух, с помощью команды kubectl get pods -n rs-ns или kubectl describe rs/
nginx-replicaset-example -n rs-ns.
