336     Глава 9   •  Постоянное хранилище в Kubernetes

Режимы доступа, поддерживаемые
объектом PersistentVolume
Режим доступа — это параметр, который задается при создании объекта
PersistentVolume и определяет способ монтирования тома.

Объект PersistentVolume поддерживает четыре режима доступа.

z ReadWriteOnce (RWO). В любой момент времени только один узел может
   получить доступ к тому для чтения и записи.
z ReadOnlyMany (ROX). Том доступен только для чтения нескольким узлам
   одновременно.
z ReadWriteMany (RWX). Том доступен для чтения и записи нескольким узлам
   одновременно.
z ReadWriteOncePod. Новый режим, стабилизированный в версии Kuberne
    tes 1.29. В этом режиме том доступен для чтения/записи только одному поду
   во всем кластере. Используйте этот режим в тех случаях, когда необходимо,
   чтобы только один под в кластере имел возможность читать данные из объ-
   екта PersistentVolumeClaim (PVC) или записывать их в него.

Для каждого объекта PersistentVolume необходимо указать как минимум один
режим доступа, даже если сам том поддерживает несколько. Режимы, поддер-
живаемые разными типами PersistentVolume, показаны в табл. 9.1.
