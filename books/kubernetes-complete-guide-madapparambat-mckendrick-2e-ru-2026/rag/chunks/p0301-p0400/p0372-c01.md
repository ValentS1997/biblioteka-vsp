372     Глава 10   •  Запуск рабочих нагрузок производственного уровня

применять более высокоуровневые абстракции, такие как объекты Deployment.
Этот подход будет подробно рассмотрен в следующей главе.
А сейчас обсудим способ создания объектов ReplicaSet и управления ими.

Создание объекта ReplicaSet
В следующем примере мы будем использовать многоузловой кластер, создан-
ный с помощью инструмента kind, описанного в главе 3:

 $ kind create cluster --config Chapter03/kind_cluster --image kindest/node:v1.31.0

 $ kubectl get nodes
 NAME                 STATUS   ROLES           AGE   VERSION
 kind-control-plane   Ready    control-plane   60s   v1.31.0
 kind-worker          Ready    <none>          47s   v1.31.0
 kind-worker2         Ready    <none>          47s   v1.31.0
 kind-worker3         Ready    <none>          47s   v1.31.0

Первым делом создадим пространство имен, в котором будут размещаться наши
ресурсы ReplicaSet.

 $ kubectl create -f ns-rs.yaml
 namespace/rs-ns created

Теперь рассмотрим структуру YAML-манифеста nginx-replicaset.yaml, под-
держивающего четыре реплики пода nginx:

# nginx-replicaset-example.yaml
apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: nginx-replicaset-example
  namespace: rs-ns
spec:
  replicas: 4
  selector:
    matchLabels:
      app: nginx
      environment: test
  template:
    metadata:
      labels:
        app: nginx
        environment: test
    spec:
      containers:
        - name: nginx
          image: nginx:1.17
          ports:
            - containerPort: 80
