352     Глава 9   •  Постоянное хранилище в Kubernetes

Итак, у вас есть все необходимые знания об объектах PersistentVolume и Persistent
VolumeClaim для работы с постоянным хранилищем в Kubernetes. Однако мы
еще не затронули такую важную тему, как динамическое выделение ресурсов.
Это одна из самых впечатляющих возможностей Kubernetes, благодаря которой
данная система может взаимодействовать с API облачного провайдера для соз-
дания постоянного хранилища в облаке, а затем делать его доступным в кластере
путем динамического создания объектов PV. В следующем разделе мы сравним
статическое и динамическое выделение ресурсов хранилища.

Статическое и динамическое выделение
объектов PersistentVolume
До этого момента мы говорили только о статическом выделении объектов
PersistentVolume. Теперь обсудим динамическое выделение, позволяющее
создавать объекты PersistentVolume непосредственно из кластера Kubernetes.

Сравнение статического и динамического выделения
Как вы помните, при статическом выделении объектов PersistentVolume не-
обходимо выполнить следующие действия.

1. Создать участок хранилища у облачного провайдера или в используемой
   системе хранения данных.
2. Создать объект PersistentVolume, который будет выступать в Kubernetes
   в роли указателя на это хранилище.
3. Создать под и объект PersistentVolumeClaim, позволяющий связать PV
   с подом.

Этот процесс называется статическим выделением, потому что участок хра-
нилища должен быть создан до создания объектов PV и PVC в Kubernetes.
Такой подход работает, однако при масштабировании управление существенно
усложняется, особенно если речь идет о сотнях PV и PVC. Например, для соз-
дания тома Amazon EBS и его подключения в качестве PersistentVolume путем
статического выделения вам придется сделать следующее.

1. Аутентифицироваться в консоли AWS.
2. Создать том EBS.
3. Скопировать его уникальный идентификатор в YAML-манифест Persis
   tentVolume.
4. Создать PV с помощью этого YAML-файла.
5. Создать PVC для получения доступа к этому PV.
6. Смонтировать объект PVC в под.
