Сервис типа ClusterIP     309

Просмотр подробных сведений о сервисе ClusterIP
Как и в случае с любыми другими объектами Kubernetes, просмотреть сведения
о сервисах типа ClusterIP можно с помощью команды kubectl describe. Для
этого достаточно знать имя сервиса.
Применим эту команду к сервису ClusterIP, созданному ранее:

 $ kubectl describe svc/nginx-clusterip
 Name:              nginx-clusterip
 Namespace:         default
 Labels:            <none>
 Annotations:       <none>
 Selector:          run=nginx-clusterip
 Type:              ClusterIP
 IP Family Policy:  SingleStack
 IP Families:       IPv4
 IP:                10.101.229.225
 IPs:               10.101.229.225
 Port:              <unset>  80/TCP
 TargetPort:        80/TCP
 Endpoints:         10.244.0.10:80
 Session Affinity:  None
 Events:            <none>

Блок Selector показывает, что сервис ClusterIP был создан с помощью пара-
метра --expose и содержит значение, совпадающее с меткой, назначенной поду
nginx-clusterip, созданному одновременно с ним. Чтобы убедиться в этом,
выведем метки пода:

 $ kubectl get pods/nginx-clusterip --show-labels
 NAME              READY   STATUS    RESTARTS   AGE   LABELS
 nginx-clusterip   1/1     Running   0          76s   run=nginx-clusterip

Как видите, селектор сервиса совпадает с меткой пода, благодаря чему меж-
ду этими объектами возможно взаимодействие. Теперь обратимся к сервису
ClusterIP напрямую из другого пода в кластере.
Поскольку сервис называется nginx-clusterip, он доступен по адресу nginx-
clusterip.default.svc.cluster.local.
Для проведения проверки снова воспользуемся контейнерным образом k8sutils:

 $ kubectl exec k8sutils -- curl nginx-clusterip.default.svc.cluster.local
