Снабжение подов метками и аннотациями     163

Эта команда сработает только в том случае, если у пода еще нет метки с ключом
stack. Она добавляет новую метку, но не обновляет существующую. В резуль-
тате ее выполнения под должен быть дополнен меткой stack=blue. Давайте это
проверим:

 $ kubectl get pods nginx-pod --show-labels
 NAME        READY   STATUS    RESTARTS   AGE   LABELS
 nginx-pod   1/1     Running   0          38m   environment=prod,stack=blue,
                                                tier=frontend

Для обновления существующей метки нужно использовать параметр --overwrite.
Например, изменим значение метки stack с blue на green:

 $ kubectl label pod nginx-pod stack=green --overwrite
 pod/nginx-pod labeled

В результате обновления метка с ключом stack изменит значение на green.
Выполните следующую команду, чтобы это проверить:

 $ kubectl get pods nginx-pod --show-labels
 NAME        READY   STATUS    RESTARTS   AGE   LABELS
 nginx-pod   1/1     Running   0          41m   environment=prod,stack=green,
                                                tier=frontend

         Использование команды kubectl label для добавления или изменения меток
         может быть рискованным. Как мы уже отмечали, взаимосвязи между объектами
          Kubernetes формируются именно на основе меток. Изменение их значений может
         нарушить эти взаимосвязи, в результате чего ресурсы начнут вести себя не так,
          как от них ожидается. Поэтому рекомендуется задавать метки при создании пода
         и оставлять их неизменными. Всегда лучше удалить и создать ресурс заново,
         чем изменять конфигурацию уже работающего объекта.

Способ удаления метки запущенного пода мы рассмотрим в следующем раз-
деле.

Удаление метки, присвоенной запущенному поду
Мы можем не только добавлять и обновлять метки, присвоенные запущенно-
му поду, но и удалять их. Для этого после имени метки следует добавить знак
минус (-). Например, для удаления метки с именем stack можно выполнить
следующую команду:

 $ kubectl label pod nginx-pod stack-
 pod/nginx-pod unlabeled
