Многоконтейнерные поды     197

 NAME                        READY   STATUS          RESTARTS   AGE
 nginx-with-init-container   0/1     Init:0/1        0          3s
 nginx-with-init-container   0/1     Init:0/1        0          4s
 nginx-with-init-container   0/1     PodInitializing 0          19s
 nginx-with-init-container   1/1     Running         0          22s

Значение Init:0/1 указывает на запуск init-контейнера. Затем префикс Init:
исчезает из последующих статусов, что говорит об успешном выполнении кон-
тейнера инициализации и о том, что система Kubernetes приступила к созданию
основного контейнера — в нашем случае Nginx.

Если вы хотите изучить этот процесс подробнее, то можете открыть доступ
к поду с помощью сервиса типа NodePort:

 $ kubectl expose pod nginx-with-init-container --port=80 --type=NodePort
 service/nginx-with-init-container exposed

Затем настройте переадресацию портов с помощью команды kubectl port-
forward, чтобы получить доступ к сервису в кластере извне:

 $ kubectl port-forward pod/nginx-with-init-container 8080:80
 Forwarding from 127.0.0.1:8080 -> 80
 Forwarding from [::1]:8080 -> 80

Теперь, если вы перейдете по адресу http://localhost:8080, увидите одно-
страничный сайт с содержимым, скопированным со страницы https://github.com/
iamgini/website-demo-one-page. Подробнее о предоставлении доступа к сервисам мы
поговорим в главе 8. Прежде чем переходить к следующему разделу, не забудьте
остановить переадресацию портов, нажав в терминале Ctrl+C.
Используйте контейнеры инициализации обдуманно! Их применение не яв-
ляется обязательным, но они могут пригодиться для выполнения конфигура-
ционных сценариев или загрузки данных с внешних серверов перед запуском
основных контейнеров.

Теперь посмотрим, как можно получить логи конкретного контейнера внутри
работающего пода.

Получение логов конкретного контейнера
Для получения логов отдельного контейнера, входящего в состав многоконтей-
нерного пода, предназначена команда kubectl logs.
Чаще всего контейнеризованные приложения публикуют свои логи путем
