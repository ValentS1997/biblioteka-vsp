122     Глава 3   •  Установка первого кластера Kubernetes

В конце концов вы получите сообщение об успешном завершении установки
от minikube:

🔎 Verifying Kubernetes components...
🌟 Enabled addons: storage-provisioner, default-storageclass
🏄 Done! kubectl is now configured to use "minikube" cluster and "default"
 namespace by default

Итак, всего за минуту вы развернули рабочий кластер Kubernetes, готовый к за-
пуску приложений.
Теперь проверьте состояние кластера Kubernetes с помощью команды minikube:

 $ minikube status
 minikube
 type: Control Plane
 host: Running
 kubelet: Running
 apiserver: Running
 kubeconfig: Configured

Новая виртуальная машина minikube должна отобразиться в интерфейсе
VirtualBox (рис. 3.1).

         Рис. 3.1. Виртуальная машина minikube в интерфейсе VirtualBox

В следующем подразделе вы узнаете, как развернуть кластеры Kubernetes с ис-
пользованием minikube и контейнеров.

Настройка minikube с использованием контейнера
Контейнерный метод является более простым: вместо виртуальной машины
minikube использует локальный экземпляр Docker Engine или Podman для
запуска компонентов Kubernetes внутри одного большого контейнера. Чтобы
воспользоваться этим вариантом, установите Docker или Podman на свою рабо-
чую станцию в соответствии с инструкциями для используемой операционной
