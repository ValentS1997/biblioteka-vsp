Запуск объекта Job     171

Обратите внимание на то, что параметр completions был заменен параметром
parallelism. Теперь задание будет запускать пять подов одновременно, выпол-
няя их в параллельном режиме:

 $ kubectl get pods -w
 NAME                      READY   STATUS              RESTARTS   AGE
 hello-world-job-4-9dspk   0/1     ContainerCreating   0          7s
 hello-world-job-4-n6qv9   0/1     Completed           0          7s
 hello-world-job-4-pv754   0/1     ContainerCreating   0          7s
 hello-world-job-4-ss4g8   1/1     Running             0          7s
 hello-world-job-4-v78cj   1/1     Running             0          7s
 <фрагмент опущен для краткости>

В следующем подразделе вы узнаете, как автоматически завершить задание по
истечении заданного промежутка времени.

Завершение задания
по истечении определенного времени
Мы также можем завершить работу пода по истечении заданного промежутка
времени. Это полезно, например, при работе с заданиями, которые обрабаты-
вают очередь сообщений. В таком случае можно проверять очередь в течение
одной минуты, а затем автоматически завершать этот процесс. Для этого ис-
пользуется параметр activeDeadlineSeconds. Вот обновленный YAML-файл:

# hello-world-job-5.yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: hello-world-job-5
spec:
  backoffLimit: 3
  activeDeadlineSeconds: 60
  template:
    metadata:
      name: hello-world-job-5
    spec:
      restartPolicy: OnFailure
      containers:
        - name: hello-world-container
          image: busybox
          command: ["/bin/sh", "-c"]
          args: ["echo 'Hello world'"]

В данном примере выполнение задания завершится через 60 секунд независимо
от обстоятельств. Этот механизм целесообразно применять в ситуациях, когда
вам требуется поддерживать процесс в активном состоянии в течение строго
определенного временного интервала.
