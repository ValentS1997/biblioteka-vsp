Создание многоузлового кластера Kubernetes с помощью kind     131

    $ sudo mv ./kind /usr/local/bin/kind
    # Проверка версии
    $ kind version
    kind v0.23.0 go1.21.10 linux/amd64

z В macOS выполните команды:

    $ curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.20.0/kind-darwin-amd64
    $ chmod +x ./kind
    $ mv ./kind /usr/local/bin/kind

z Данный инструмент также можно установить с помощью Homebrew:

    $ brew install kind

z В Windows PowerShell выполните следующие команды:

    $ curl.exe -Lo kind-windows-amd64.exe \
    https://kind.sigs.k8s.io/dl/v0.23.0/kind-windows-amd64
    $ Move-Item .\kind-windows-amd64.exe c:\some-dir-in-your-PATH\kind.exe

z Или воспользуйтесь утилитой Chocolatey:

    $ choco install kind

z Если у вас установлен язык Go, то вы можете выполнить следующую
   команду:

    $ go install sigs.k8s.io/kind@v0.22.0 && kind create cluster

Альтернативные методы установки описаны в документации: https://kind.sigs.k8s.io/
docs/user/quick-start#installation.

Создание кластера Kubernetes
с помощью kind
После установки kind вы сможете сразу же развернуть кластер Kubernetes, за-
пустив следующую команду:

 $ kind create cluster --name test-kind
 Creating cluster "test-kind" ...

При ее выполнении инструмент kind приступит к сборке локального кла-
