126     Глава 3   •  Установка первого кластера Kubernetes

В результате выполнения этой команды вы должны увидеть следующее:
z работающее хранилище данных etcd;
z работающий компонент kube-scheduler;
z работающий компонент kube-controller-manager.

В следующем подразделе мы поговорим об управлении учебной средой Kuber
netes через остановку и удаление кластера minikube.

Остановка и удаление локального кластера minikube
Если вам требуется остановить или удалить локальную установку minikube,
не стоит завершать работу виртуальной машины или контейнера. Вместо этого
лучше использовать утилиту командной строки minikube:

 $ minikube stop
✋  Stopping node "minikube" ...
🛑 1 node stopped.

Данная команда останавливает кластер. Однако он продолжает существовать:
его состояние сохраняется, и позднее вы сможете возобновить его работу, вы-
полнив команду minikube start. Проверить его состояние можно с помощью
команды minikube status:

 $ minikube status
 minikube
 type: Control Plane
 host: Stopped
 kubelet: Stopped
 apiserver: Stopped
 kubeconfig: Stopped

Мы также можем приостановить работу кластера, чтобы иметь возможность
быстро ее возобновить:

 $ minikube pause
⏸     Pausing node minikube ...
⏯     Paused 14 containers in: kube-system, kubernetes-dashboard,
 storagegluster, istio-operator

 $ minikube status
 minikube
 type: Control Plane
 host: Running
 kubelet: Stopped
 apiserver: Paused
 kubeconfig: Configured
