Многоконтейнерные поды     193

Например, классический Dockerfile для запуска команды, приостанавливающей
выполнение текущего процесса на 30 секунд, выглядел бы так:

 # ~/Dockerfile
 FROM busybox:latest
 ENTRYPOINT ["sleep"]
 CMD ["30"]

       Файл Containerfile и Podman
        Файл Containerfile служит рецептом для сборки контейнерного образа, как
         и Dockerfile. В нем последовательно указываются инструкции по выбору ОС, уста-
         новке зависимостей, копированию кода приложения и настройке параметров.
         Podman, инструмент, похожий на Docker, способен интерпретировать файлы
            Containerfile и собирать образы на основе содержащихся в них инструкций.

Если вы работали с Docker, то предыдущий фрагмент кода должен показаться
вам знакомым. Инструкция CMD задает аргументы по умолчанию, которые можно
переопределить при запуске контейнера с помощью команды docker run. Если
собрать образ на основе этого файла Dockerfile с помощью команды docker
build, то получится образ busybox, который при запуске контейнера будет вы-
полнять команду sleep (заданную в ENTRYPOINT) в течение 30 секунд (значение
CMD по умолчанию).
С помощью инструкции CMD мы можем переопределить значение по умолчанию:

 $ docker run my-custom-ubuntu:latest 60
 $ docker run my-custom-ubuntu:latest  # Приостанавливает выполнение на 30 секунд

Система Kubernetes, в свою очередь, позволяет переопределять как ENTRYPOINT,
так и CMD с помощью YAML-манифестов пода. Для этого необходимо добавить
в YAML-файл конфигурации два необязательных ключа: command и args.
Kubernetes предоставляет в этом плане значительное преимущество: вы можете
либо добавить аргументы к команде, указанной в Dockerfile контейнера (ана-
логично тому, как это работает с инструкцией CMD в Docker), либо полностью
переопределить инструкцию ENTRYPOINT.
Создадим новый манифест и зададим в нем значения ENTRYPOINT и CMD для
образа busybox, чтобы контейнер, созданный на его основе, приостанавливал
выполнение на 60 секунд:

# nginx-debian-with-custom-command-and-args.yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-debian-with-custom-command-and-args
