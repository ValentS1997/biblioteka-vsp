Теперь поговорим об аннотациях в Kubernetes.

Добавление аннотации
Аннотации в Kubernetes представляют собой пары «ключ — значение», которые
можно прикреплять к различным объектам системы вроде Pod, Deployment
и Service. Они позволяют добавлять к этим объектам дополнительную инфор-
мацию без изменения их основной функциональности. В отличие от меток,
которые используются для идентификации и выборки ресурсов, аннотации
предназначены для хранения вспомогательных данных, повышающих удоб-
ство восприятия кода или используемых внешними инструментами. В анно-
тациях можно хранить, например, сведения о конфигурации или имя автора
объекта.

Рассмотрим аннотированный под:
# annotated_pod.yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod
  labels:
    environment: prod
    tier: frontend
  annotations:
    tier: webserver
spec:
  containers:
    - name: nginx-container
      image: nginx:latest

Здесь аннотация tier: webserver может указывать на то, что в поде запущен
HTTP-сервер. Помните, что аннотации используются для дополнения объекта
метаданными.

Для обновления существующей конфигурации пода можно воспользоваться
командой kubectl replace -f.
