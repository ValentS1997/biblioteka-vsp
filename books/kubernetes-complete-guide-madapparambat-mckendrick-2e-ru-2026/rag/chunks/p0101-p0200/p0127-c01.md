Установка кластера Kubernetes с помощью minikube     127

Для возобновления работы кластера можно воспользоваться следующей
командой:

 $ minikube unpause

Если вы хотите полностью уничтожить кластер, выполните команду:

 $ minikube delete
🔥  Deleting "minikube" in docker ...
🔥  Deleting container "minikube" ...
🔥  Removing /home/gmadappa/.minikube/machines/minikube ...
💀 Removed all traces of the "minikube" cluster.

В результате ее выполнения кластер будет полностью удален. Его состояние
будет потеряно, и восстановить его будет невозможно.
Теперь, когда ваш кластер minikube настроен и готов к работе, вы можете ис-
пользовать его для прохождения следующих глав или выбрать другое решение.

Создание многоузлового кластера Kubernetes
с использованием minikube
С помощью minikube также можно создавать многоузловые кластеры Kubernetes.
Следующая команда позволяет развернуть кластер, состоящий из трех узлов:

 $ minikube start --driver=podman --nodes=3

        При создании многоузловых кластеров важно убедиться в том, что ваша рабочая
          станция имеет достаточно ресурсов для запуска нескольких узлов Kubernetes
          (будь то виртуальные машины или контейнеры). Учтите также, что minikube
          запускает узлы с теми же параметрами vCPU и памяти, которые вы указали
          в настройках или аргументах.

После создания кластера проверьте сведения об узлах следующим образом:

 $ kubectl get nodes
 NAME          STATUS   ROLES           AGE     VERSION
 minikube      Ready    control-plane   93s     v1.29.0
 minikube-m02  Ready    <none>          74s     v1.29.0
 minikube-m03  Ready    <none>          54s     v1.29.0

В данном случае инструмент minikube создал кластер из трех узлов (--nodes=3),
первый из которых выполняет функции управляющего (control plane), а два
оставшихся выступают в роли вычислительных (соответствующие метки мы
назначим в одной из следующих глав).
