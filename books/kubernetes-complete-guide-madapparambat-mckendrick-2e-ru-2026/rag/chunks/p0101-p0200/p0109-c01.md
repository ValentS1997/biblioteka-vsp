Обеспечение высокой доступности Kubernetes     109

             Рис. 2.9. Все компоненты работают на одной машине

Обычно такой подход рассматривается в качестве отправной точки для зна-
комства с Kubernetes через локальное тестирование. Существует инструмент
minikube, который упрощает развертывание одноузлового кластера Kubernetes
на вашем компьютере. Он запускает виртуальную машину со всеми необходи-
мыми компонентами, уже настроенными для работы. Хотя minikube полезен
для локального тестирования и теоретически может быть запущен в виде
многоузлового кластера, его категорически не рекомендуется использовать
в рабочей среде. В табл. 2.2 перечислены основные преимущества и недостатки
одноузловых кластеров Kubernetes.

Таблица 2.2. Преимущества и недостатки одноузловых кластеров Kubernetes

 Преимущества                        Недостатки
 Хорошо подходит для тестирования      Невозможно масштабировать

 Простая локальная установка         Не отличается высокой доступностью

 Поддерживается инструментом minikube  Не рекомендуется использовать
                                        в рабочей среде

         Одноузловой кластер Kubernetes хорошо подходит для периферийных сред
           с ограниченными ресурсами. Он имеет небольшие системные требования, но
         при этом обеспечивает надежное развертывание и реализацию стратегий ава-
         рийного восстановления.
