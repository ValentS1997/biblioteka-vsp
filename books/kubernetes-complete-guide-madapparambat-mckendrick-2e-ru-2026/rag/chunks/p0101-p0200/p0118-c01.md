118     Глава 3   •  Установка первого кластера Kubernetes

Установка minikube в macOS
В macOS minikube можно установить с помощью двоичного файла1:

 $ curl -LO https://storage.googleapis.com/minikube/releases/latest/
 minikube-darwin-amd64
 $ sudo install minikube-darwin-amd64 /usr/local/bin/minikube
 # Проверка доступности команды minikube и корректности пути
 $ which minikube

Установить minikube в macOS также можно с помощью пакетного менеджера
Homebrew.

Установка minikube в Windows
Как и в случае с macOS и Linux, установить minikube в Windows можно не-
сколькими способами:

 # С помощью Windows Package Manager (если установлен)
 $ winget install minikube
 # С помощью Chocolatey
 $ choco install minikube
 # Скачав файл .exe и настроив переменную PATH
 # 1. Скачайте minikube по ссылке:
 # https://storage.googleapis.com/minikube/releases/latest/
 minikube-installer.exe
 # 2. Настройте переменную PATH

После установки и настройки minikube вы сможете создавать различные типы
кластеров Kubernetes.

Конфигурации minikube
Утилита minikube предусматривает минимальный, но достаточный для полно-
ценной разработки набор параметров.
Например, создаваемый с помощью этой утилиты кластер Kubernetes по умол-
чанию будет иметь два процессора и 2 Гбайт памяти. При необходимости эти
значения можно изменить:

 $ minikube config set cpus 4
   These changes will take effect upon a minikube delete and then a minikube start ❗
 $ minikube config set memory 16000
   These changes will take effect upon a minikube delete and then a minikube start ❗
 $ minikube config set container-runtime containerd
   These changes will take effect upon a minikube delete and then a minikube start ❗

1  Здесь и далее стоит обращать внимание на архитектуру процессора, заменяя amd64
   на arm64 для macOS на Apple Silicon.
