128     Глава 3   •  Установка первого кластера Kubernetes

Создание кластера Kubernetes с несколькими
управляющими узлами с помощью minikube
Иногда возникает необходимость развернуть и протестировать кластер Kuber
netes с отказоустойчивым управляющим слоем, включающим несколько
управляющих узлов. Это можно реализовать с помощью следующей команды
minikube:

 $ minikube start \
   --driver=virtualbox \
   --nodes=5 \
   --ha=true \
   --cni=calico \
   --cpus=2 \
   --memory=2g \
   --kubernetes-version=v1.30.0 \
   --container-runtime=containerd
 $ kubectl get nodes
 NAME           STATUS   ROLES           AGE     VERSION
 minikube       Ready    control-plane   6m28s   v1.30.0
 minikube-m02   Ready    control-plane   4m36s   v1.30.0
 minikube-m03   Ready    control-plane   2m45s   v1.30.0
 minikube-m04   Ready    <none>          112s    v1.30.0
 minikube-m05   Ready    <none>          62s     v1.30.0

В результате minikube создаст кластер из пяти узлов (--nodes 5) и назначит
первым трем роль управляющих (--ha true).

В данном случае также важно убедиться в том, что ваша рабочая станция имеет
достаточно ресурсов для запуска таких многоузловых кластеров.

Создание нескольких кластеров Kubernetes
с помощью minikube
Как мы уже выяснили, инструмент minikube предназначен для разработки и те-
стирования Kubernetes-сред. Иногда у вас может возникнуть необходимость
смоделировать окружение с несколькими кластерами Kubernetes. В этом случае
можно снова воспользоваться minikube, однако не забудьте присвоить этим
кластерам разные имена с помощью параметра --profile, как показано ниже:

 # Запуск кластера minikube с драйвером VirtualBox
 $ minikube start --driver=virtualbox --kubernetes-version=1.30.0
 --profile=cluster-vbox
 # Запуск другого кластера minikube с драйвером Docker
 $ minikube start --driver=docker --kubernetes-version=1.30.0
 --profile=clusterdocker
