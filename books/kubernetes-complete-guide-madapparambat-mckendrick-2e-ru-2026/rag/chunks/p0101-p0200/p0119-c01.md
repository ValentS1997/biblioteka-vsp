Установка кластера Kubernetes с помощью minikube     119

Как видите, для применения новых параметров требуется удалить и заново
создать кластер minikube.

Драйверы для minikube
Инструмент minikube позволяет с легкостью запустить локальный кластер
Kubernetes на машине для разработки. Для этого он использует драйверы — клю-
чевой механизм, управляющий жизненным циклом кластера. Драйверы взаи
модействуют с различными технологиями виртуализации и контейнеризации,
позволяя minikube создавать, настраивать и контролировать инфраструктуру,
лежащую в основе локальной среды Kubernetes. Гибкость драйверов minikube
позволяет развернуть кластер в виде виртуальной машины и контейнера, а так-
же непосредственно на «голом железе» рабочей станции, адаптируя установку
под конкретные задачи и предпочтения.

z Драйверы контейнеров. При контейнерном развертывании minikube может
   использовать локальные установки Podman или Docker. Это позволяет за-
   пускать minikube непосредственно внутри контейнера на рабочей машине,
   что делает установку более легковесной и эффективной с точки зрения по-
   требления ресурсов.
z Драйверы виртуальных машин (ВМ). Если вы предпочитаете вариант с вирту-
  альными машинами, то можете использовать minikube для запуска ВМ с не-
  обходимыми компонентами Kubernetes на вашей рабочей станции. Этот под-
   ход обеспечивает более изолированное окружение для локального кластера.

Выбор между драйверами контейнеров и виртуальных машин зависит от ваших
задач, предпочтений и возможностей среды разработки.
Подробнее о драйверах minikube и поддерживаемых операционных системах
можно узнать в документации: https://minikube.sigs.k8s.io/docs/drivers/.
Для minikube можно задать драйвер по умолчанию с помощью следующей
команды:

 $ minikube config set driver docker
   These changes will take effect upon a minikube delete and then a minikube start ❗
 # или указать VirtualBox в качестве драйвера
 $ minikube config set driver virtualbox
   These changes will take effect upon a minikube delete and then a minikube start ❗
 $ minikube config view driver
 - driver: docker

Мы также можем указать драйвер непосредственно при создании кластера
minikube:

 $ minikube start --driver=docker
