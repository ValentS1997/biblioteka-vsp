о ресурсах Kubernetes.

Вывод списка объектов в формате JSON или YAML
Параметр -o или --output является одним из самых полезных в kubectl. Он
имеет несколько преимуществ, о которых необходимо знать. С его помощью
можно изменять формат вывода информации, возвращаемой в результате вы-
полнения команд kubectl. По умолчанию команда kubectl get pods возвращает
список подов в кластере Kubernetes в удобочитаемом виде. Однако, используя
параметр -o, эти данные можно вывести в формате YAML или JSON:

 $ kubectl get pods --output=yaml   # В формате YAML
 $ kubectl get pods --output=json   # В формате JSON

Зная имя пода, вы можете запросить данные именно о нем:

 $ kubectl get pods <ИМЯ_ПОДА> -o yaml
 # или
 $ kubectl get pods <ИМЯ_ПОДА> -o json

Таким образом, вы можете извлекать и экспортировать данные из кластера
Kubernetes в удобном формате.

Резервное копирование ресурса
с помощью операции перечисления
Упомянутые выше флаги можно использовать и для резервного копирования
ресурсов Kubernetes. Допустим, вы создали под с помощью императивного
подхода, то есть на вашей локальной машине отсутствует YAML-файл с его
описанием. Если под выйдет из строя, его будет трудно воссоздать. Параметр -o
позволяет извлечь YAML-файл с описанием ресурса Kubernetes, даже если он
был создан императивным способом. Для этого выполните команду:

 $ kubectl get pods/nginx-pod -o yaml > nginx-pod-output.yaml

Таким образом, вы получите резервную копию ресурса nginx-pod в формате
YAML. Вы всегда можете сравнить полученный файл с исходной YAML-
декларацией и проанализировать различия с помощью команды diff или
других утилит:

 $ diff nginx-pod.yaml nginx-pod-output.yaml
