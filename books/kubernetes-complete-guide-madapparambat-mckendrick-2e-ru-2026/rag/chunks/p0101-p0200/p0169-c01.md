Многократное выполнение задания
с помощью параметра completions
Для многократного выполнения задания можно использовать параметр объекта
Job — completions, задающий число повторных запусков команды. Значение
completions в показанном ниже обновленном YAML-файле приведет к последо-
вательному созданию десяти подов. Как только один под завершит выполнение,
будет запущен следующий:

# hello-world-job-3.yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: hello-world-job-3
spec:
  backoffLimit: 3
  completions: 10
  template:
    metadata:
      name: hello-world-job-3
    spec:
      restartPolicy: OnFailure
      containers:
        - name: hello-world-container
          image: busybox
          command: ["/bin/sh", "-c"]
          args: ["echo 'Hello world'; sleep 3"]

в раздел args параметр sleep 3, который задает паузу 3 секунды перед завер-
