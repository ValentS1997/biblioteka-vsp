Дистрибутивы Kubernetes
Дистрибутивы Kubernetes представляют собой преднастроенные версии си-
стемы, которые включают дополнительные возможности, выходящие за рамки
базового функционала Kubernetes. Их можно рассматривать как пакеты, ориен-
тированные на конкретные потребности и упрощающие процесс развертывания
приложений. Если вам требуется более насыщенный функционал, обратите
внимание на следующие дистрибутивы Kubernetes.

z Red Hat OpenShift — дистрибутив корпоративного уровня, расширяющий
   возможности Kubernetes за счет инструментов для разработчиков (средств
   для сборки образов и CI/CD-конвейеров), функций управления нескольки-
  ми кластерами, механизмов безопасности (RBAC и SCC), а также встроен-
   ной масштабируемости для осуществления сложных развертываний (https://
   www.redhat.com/en/technologies/cloud-computing/openshift).
z Rancher — полноценная платформа управления контейнерами, выходящая
   за рамки системы Kubernetes. Она позволяет управлять несколькими кла-
   стерами в различных средах, поддерживает рабочие нагрузки для разных
   платформ оркестрации, а также предусматривает маркетплейс для предна-
   строенных приложений (https://www.rancher.com/).
z VMware Tanzu — решение, разработанное для экосистемы VMware, которое
   органично интегрируется с процессами предоставления инфраструктуры,
   обеспечения безопасности и развертывания в гибридных облачных средах.
   Tanzu предоставляет средства для управления жизненным циклом контей-
   неризованных приложений в среде VMware (https://tanzu.vmware.com/platform).

Учтите, что некоторые из перечисленных выше дистрибутивов Kubernetes до-
ступны только по подписке или лицензии и не являются бесплатными.
В следующем подразделе мы рассмотрим некоторые инструменты для развер-
тывания системы Kubernetes.
