Запуск подов     157

Эта команда приказывает утилите kubectl перенаправить трафик с порта 8080
локальной машины (где запущена kubectl) на порт 80 пода с именем nginx-pod.
После выполнения этой команды утилита kubectl выведет сообщение о том,
что локальный порт 8080 был перенаправлен на порт 80 пода. Если появится
сообщение об ошибке, скорее всего, локальный порт 8080 уже занят. В этом
случае попробуйте указать другой порт или просто уберите локальный порт из
команды, чтобы утилита kubectl выбрала его случайным образом:

 $ kubectl port-forward pod/nginx-pod :80
 Forwarding from 127.0.0.1:xxxxx -> 80
 Forwarding from [::1]:xxxxx -> 80

Теперь вы можете открыть браузер и перейти по адресу http://localhost:<ло
кальный_порт>. В нашем случае это будет http://localhost:8080 (рис. 4.4).

       Рис. 4.4. Доступность страницы запущенного в поде сервера Nginx
      через локальный хост подтверждает успешную переадресацию портов

По окончании тестирования остановите переадресацию портов, нажав Ctrl+C.

Получение доступа к контейнеру внутри пода
После запуска пода мы можем получить доступ к контейнерам, которые он со-
держит. В Docker для выполнения команд в работающем контейнере исполь-
зуется команда docker exec. В Kubernetes этот подход реализован с помощью
команды kubectl exec. Чтобы обратиться к запущенному ранее контейнеру
Nginx внутри пода nginx-pod, выполните команду:

 $ kubectl exec -it nginx-pod -- bash
 root@nginx-pod:/# hostname
 nginx-pod
