Запросы и лимиты ресурсов, доступных подам     673

Примените измененную конфигурацию:

 $ kubectl apply -f resource-limit/nginx-deployment.yaml
 deployment.apps/nginx-deployment-example configured

Если вы проверите статус подов, то заметите, что новые поды остаются в состоя
нии ожидания (Pending), поскольку их невозможно разместить ни на одном
подходящем узле:

 $ kubectl get pod
 NAME                                        READY   STATUS    RESTARTS   AGE
 nginx-deployment-example-59b669d85f-cdptx   1/1     Running   0          52s
 nginx-deployment-example-59b669d85f-hdzdf   1/1     Running   0          54s
 nginx-deployment-example-59b669d85f-ktn59   1/1     Running   0          54s
 nginx-deployment-example-59b669d85f-vdn87   1/1     Running   0          52s
 nginx-deployment-example-69bd6d55b4-n2mzq   0/1     Pending   0          3s
 nginx-deployment-example-69bd6d55b4-qb62p   0/1     Pending   0          3s
 nginx-deployment-example-69bd6d55b4-w7xng   0/1     Pending   0          3s

Чтобы разобраться в причине этого состояния, опишите под с помощью следу-
ющей команды:

 $ kubectl describe pod nginx-deployment-example-69bd6d55b4-n2mzq
 ...
 Events:
   Type     Reason            Age                     From             Message
   ----     ------            ----                    ----             -------
   Warning  FailedScheduling  23m (x21 over 121m)     default-scheduler 0/3
 nodes are available: 1 node(s) had untolerated taint {machine-check-exception:
 memory}, 2 Insufficient cpu. preemption: 0/3 nodes are available:
 1 Preemption is not helpful for scheduling, 2 No preemption victims found
 for incoming pod.

         Некоторые из рассмотренных в этой главе механизмов автомасштабирования
          в настоящее время находятся в стадии альфа- или бета-тестирования. Они мо-

Согласно приведенному выше выводу, в кластере нет узлов, способных обес
печить работу пода, контейнеру которого требуется 2000m KCU, поэтому такой
под не может быть запланирован в данный момент.

Теперь, когда мы разобрались с управлением вычислительными ресурсами, мы
можем перейти к теме автомасштабирования, начав с вертикального автомас-
штабирования подов.
