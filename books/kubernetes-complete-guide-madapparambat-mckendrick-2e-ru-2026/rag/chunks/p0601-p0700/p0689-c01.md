2. Примените конфигурацию, чтобы создать объект HPA:

    $ kubectl apply -f hpa/todo-hpa.yaml
    horizontalpodautoscaler.autoscaling/todo-hpa created

    $ kubectl get hpa -n hpa-demo
    NAME     REFERENCE             TARGETS            MINPODS MAXPODS REPLICAS AGE
    todo-hpa Deployment/todo-app   cpu: <unknown>/80% 1       5       0        6s

3. Выполните команду kubectl port-forward, чтобы получить доступ к при-
  ложению извне:

    $ kubectl port-forward svc/todo-app -n hpa-demo 8081:8081
    Forwarding from 127.0.0.1:8081 -> 3000
    Forwarding from [::1]:8081 -> 3000

4. Сейчас приложение Todo никто не использует, поэтому количество реплик
   остается равным 1. Давайте смоделируем нагрузку с помощью утилиты hey.
  В отдельном окне консоли выполните команду:

    $ hey -z 4m -c 25 http://localhost:8081

   Пояснение к параметрам команды:
     -z 4m — тест длится четыре минуты, что позволяет дольше поддерживать
     повышенный уровень нагрузки;
     -c 25 — 25 конкурентных соединений призваны приблизить уровень за-
      грузки ЦП к 80 %;
     http://localhost:8081 — URL-адрес приложения Todo (доступного через
      kubectl port-forward).
