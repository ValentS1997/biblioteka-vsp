Правила предпочтения узлов     647

         Если вы управляете кластером Kubernetes самостоятельно, то можете просмо-
          треть журналы пода kube-scheduler с помощью команды kubectl logs или непо-
          средственно на узлах управляющего слоя — в файле /var/log/kube-scheduler.log.
        В некоторых случаях для получения достаточной информации бывает необ-
         ходимо предварительно повысить уровень детализации журналов (verbosity).
         Подробнее об этом можно узнать здесь: https://kubernetes.io/docs/reference/
           command-line-tools-reference/kube-scheduler/.

На данном этапе шаблон пода в разделе .spec.template.spec не содержит ни-
каких настроек, влияющих на процесс распределения реплик пода.
Давайте принудительно назначим все поды объекта Deployment узлу 2 (в на-
шем случае это minikube-m02), используя поле nodeName в шаблоне пода.
Измените манифест nginx-deployment.yaml, указав корректное имя узла ва-
шего кластера:

# 01_nodename/nginx-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-app
spec:
  ...
  template:
    ...
    spec:
      nodeName: minikube-m02
...<фрагмент опущен для краткости>...

Обратите внимание на строку nodeName: minikube-m02 — с ее помощью мы явно
указываем, что поды nginx должны запускаться именно на узле minikube-m02.
Примените манифест к кластеру, используя команду kubectl apply -f:

 $ kubectl apply -f 01_nodename/nginx-deployment.yaml
 deployment.apps/nginx-app created

Теперь снова проверьте состояние подов и узлы, которым они назначены:

 $ kubectl get pods --namespace default \
     --output=custom-columns="NAME:.metadata.name,STATUS:.status.phase,NODE:.
 spec.nodeName"
 NAME                              STATUS    NODE
 nginx-app-85b577894f-8tqj7        Running   minikube-m02
 nginx-app-85b577894f-9c6hd        Running   minikube-m02
 nginx-app-85b577894f-fldxx        Running   minikube-m02
 nginx-app-85b577894f-jrnjc        Running   minikube-m02
 nginx-app-85b577894f-vs7c5        Running   minikube-m02

Как и ожидалось, теперь все пять подов работают на узле 2 (minikube-m02). Учти
те, что это новые поды: изменение шаблона пода в спецификации Deployment
