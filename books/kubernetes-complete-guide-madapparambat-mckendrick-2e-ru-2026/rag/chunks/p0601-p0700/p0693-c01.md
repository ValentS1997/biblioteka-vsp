Автомасштабирование узлов Kubernetes     693

Включение кластерного автоскейлера в GKE
В GKE проще всего создать новый кластер с уже включенным CA. Для этого
выполните следующую команду:

 $ gcloud container clusters create k8sbible \
     --enable-autoscaling \
     --num-nodes 3 \
     --min-nodes 2 \
     --max-nodes 10 \
     --region=us-central1-a

Пояснения к параметрам команды:

z  cloud container clusters create k8sbible — создает новый кластер Kuber
   netes с именем k8sbible;
z  --enable-autoscaling — активизирует функцию автомасштабирования для
   пулов узлов кластера;
z  --num-nodes 3 — задает начальное количество узлов равным 3;
z  --min-nodes 2 — задает минимальное число узлов равным 2;
z  --max-nodes 10 — задает максимальное число узлов равным 10;
z  --region=us-central1-a — указывает регион us-central1-a.

         Перед началом работы убедитесь, что ваша учетная запись GCP правиль-
         но настроена и имеет необходимые разрешения, включая доступ к Virtual
           Private Cloud (VPC), сетям, средствам безопасности и другим нужным ком-
         понентам.
