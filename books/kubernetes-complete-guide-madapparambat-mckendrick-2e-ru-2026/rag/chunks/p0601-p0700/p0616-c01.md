616     Глава 18   •  Безопасность в системе Kubernetes

6. Обычно на этом этапе создается объект RoleBinding, связывающий учетную
   запись сервиса с ролью. Однако, чтобы сделать пример более наглядным,
  мы сначала создадим под, работающий под учетной записью сервиса pod-
   logger. Этот под не сможет запрашивать список подов через API, поскольку
   у него отсутствуют соответствующие права (помните, что механизм RBAC
   по умолчанию запрещает все действия). Создайте YAML-манифест pod-
   logger-app.yaml для пода с именем pod-logger-app, который запускается
   без участия дополнительных контроллеров:

   # 02_rbac/pod-logger-app.yaml
   apiVersion: v1
   kind: Pod
   metadata:
     name: pod-logger-app
     namespace: rbac-demo-ns
   spec:
     serviceAccountName: pod-logger
     containers:
       - name: logger
         image: quay.io/iamgini/k8sutils:debian12
         command:
         - /bin/sh
         - -c
         - |
           SERVICEACCOUNT=/var/run/secrets/kubernetes.io/serviceaccount
           TOKEN=$(cat ${SERVICEACCOUNT}/token)
           while true
           do
             echo "Querying Kubernetes API Server for Pods in default
             namespace..."
             curl --cacert $SERVICEACCOUNT/ca.crt \
                --header "Authorization: Bearer $TOKEN" \
                -X GET https://kubernetes.default.svc.cluster.local/api/v1/
                namespaces/rbac-demo-ns/pods
             sleep 10
           done
   Здесь самыми важными являются два поля: .spec.serviceAccountName,
   в котором указана учетная запись сервиса, от имени которой должен запу-
   скаться под, и command — команда в определении контейнера, которую мы
   переопределили для периодического опрашивания API-сервера Kubernetes.
7. Примените манифест 02_rbac/pod-logger-app.yaml, чтобы создать под:

    $ kubectl apply -f 02_rbac/pod-logger-app.yaml
    pod/pod-logger-app created

    $ kubectl get po -n rbac-demo-ns
    NAME             READY   STATUS    RESTARTS   AGE
    nginx-pod        1/1     Running   0          15m
    pod-logger-app   1/1     Running   0          9s
