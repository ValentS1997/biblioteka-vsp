Резюме     639

Создание секрета для реестра Docker
с помощью kubectl
Ниже показан способ создания секрета для реестра Docker и его использования
в конфигурации пода:

 $ kubectl create secret docker-registry my-registry-secret \
   --docker-server=your-registry.com \
   --docker-username=your_username \
   --docker-password=your_password \
   --docker-email=your-email@example.com

Замените your-registry.com, your_username, your_password и your-email@
example.com своими учетными данными.
Теперь обновите YAML-манифест пода, чтобы использовать созданный секрет
для скачивания образов из приватного реестра:

apiVersion: v1
kind: Pod
metadata:
  name: my-pod
spec:
  containers:
  - name: my-container
    image: your-registry.com/your-image:tag
  imagePullSecrets:
  - name: my-registry-secret

Убедитесь в том, что значение my-registry-secret совпадает с именем, которое
вы использовали при создании секрета для реестра Docker1.

При создании пода образ будет скачан из приватного реестра, а параметры
imagePullSecrets — использованы в качестве учетных данных для аутентифи-
кации.

На этом мы завершаем эту большую главу, посвященную безопасности в Kuber
netes.
