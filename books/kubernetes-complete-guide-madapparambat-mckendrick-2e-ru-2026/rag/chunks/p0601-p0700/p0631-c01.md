Защита подов и контейнеров     631

  labels:
    app: nginx1
spec:
  containers:
    - name: nginx1
      image: nginx

А YAML-манифест для пространства имен web2 с подом nginx2 — так:
# web2-app.yaml
---
apiVersion: v1
kind: Namespace
metadata:
  name: web2
  labels:
    project: web2

---
apiVersion: v1
kind: Pod
metadata:
  name: nginx2
  namespace: web2
  labels:
    app: nginx2
spec:
  containers:
    - name: nginx2
      image: nginx

Как видите, в приведенных выше фрагментах кода мы используем пространства
имен web1 и web2 вместо стандартного default.
Теперь создадим соответствующие ресурсы и проверим поды:

 $ kubectl apply -f web-app1.yaml
 namespace/web1 created
 pod/nginx1 created

 $ kubectl apply -f web-app2.yaml
 namespace/web2 created
 pod/nginx2 created
