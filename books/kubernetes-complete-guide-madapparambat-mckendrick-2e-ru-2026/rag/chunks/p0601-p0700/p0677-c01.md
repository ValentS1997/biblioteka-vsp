Вертикальное автомасштабирование подов     677

После включения в кластере GKE появится CRD-объект VPA, позволяющий
управлять процессом вертикального автомасштабирования подов.
В следующем разделе описан способ включения VPA в стандартных Kubernetes-
кластерах. Если вы используете иной тип кластера, следуйте инструкциям,
предусмотренным для вашей платформы.

Включение VPA в других Kubernetes-кластерах
При использовании таких платформ, как AKS или EKS (а также локальных
тестовых развертываний), VPA необходимо устанавливать вручную путем до-
бавления в кластер соответствующего объекта CRD. Актуальные пошаговые ин-
струкции доступны в репозитории GitHub: https://github.com/kubernetes/autoscaler/
tree/master/vertical-pod-autoscaler#installation.

Чтобы установить VPA в свой кластер, выполните следующие действия.
1. Клонируйте репозиторий autoscaler (https://github.com/kubernetes/autoscaler):

    $ git clone https://github.com/kubernetes/autoscaler

2. Перейдите в каталог компонента VPA:

    $ cd autoscaler/vertical-pod-autoscaler

3. Инициируйте процесс установки с помощью следующей команды (пред-
   полагается, что ваш текущий контекст kubectl указывает на нужный
   кластер):

    $ ./hack/vpa-up.sh

4. Эта команда создаст целый набор объектов Kubernetes. Убедитесь, что ос-
   новные поды VPA успешно запущены:

    $ kubectl get pods -n kube-system | grep vpa
    vpa-admission-controller-5b64b4f4c4-vsn9j   1/1   Running   0   5m34s
    vpa-recommender-54c76554b5-m7wnk            1/1   Running   0   5m34s
    vpa-updater-7d5f6fbf9b-rkwlb                1/1   Running   0   5m34s

Если все компоненты работают, можно переходить к тестированию VPA на
реальных подах.

Использование VPA
Для демонстрации нам потребуется объект Deployment с подами, которые ока-
зывают измеримую нагрузку на ЦП. В репозитории Kubernetes autoscaler есть
простой и удобный пример с предсказуемым потреблением ресурсов ЦП: https://
github.com/kubernetes/autoscaler/blob/master/vertical-pod-autoscaler/examples/hamster.yaml.
Мы слегка модифицируем этот пример и разберем все шаги по порядку.
