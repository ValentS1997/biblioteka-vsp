Выбор узлов на основе ограничений и допусков     659

игнорировать ограничения и запускаться на узлах, к которым они применены.
Если узел имеет несколько ограничений, под должен предусматривать допуски
для них для всех. Допуски задаются в разделе .spec.tolerations спецификации
пода и имеют следующую структуру:

tolerations:
- key: <ключ>
  operator: <тип_оператора>
  value: <значение>
  effect: <эффект>

Поле operator может принимать значение Equal или Exists. Equal требует точ-
ного совпадения ключа и значения ограничения. Exists означает, что достаточно
совпадения ключа, а значение при этом не учитывается1. Для игнорирования
ограничения из нашего примера допуск должен выглядеть следующим об-
разом:

tolerations:
- key: machine-check-exception
  operator: Equal
  value: memory
  effect: NoExecute

        Для корректного размещения пода можно задать несколько допусков одно-
         временно.

При создании допуска для ограничения типа NoExecute можно использовать
дополнительное поле tolerationSeconds, чтобы задать временной интервал,
в течение которого под сможет игнорировать это ограничение, прежде чем бу-
дет выселен. Таким способом можно реализовать механизм частичного допуска
ограничения с тайм-аутом. Учтите, что использование ограничения NoExecute
обычно требует дополнительного задания ограничения NoSchedule. Это предот-
вращает бесконечный цикл выселения пода, имеющего допуск NoExecute с пара-
метром tolerationSeconds. Причина в том, что в течение заданного количества
секунд ограничение не оказывает на под никакого воздействия, в том числе
не препятствует его назначению узлу с соответствующим ограничением.

        При создании подов Kubernetes автоматически добавляет два допуска с опера-
         тором Exists для ограничений node.kubernetes.io/not-ready и node.kubernetes.io/
          unreachable со значением параметра tolerationSeconds, равным 300.

1  В kubernetes v1.35 появились дополнительные операторы числового сравнения: Gt
   и Lt. Почитать о них можно в официальной документации: https://kubernetes.io/docs/
   concepts/scheduling-eviction/taint-and-toleration/#numeric-comparison-operators.
