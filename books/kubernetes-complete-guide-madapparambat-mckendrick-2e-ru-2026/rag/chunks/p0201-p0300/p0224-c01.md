224     Глава 6   •  Пространства имен, квоты и лимиты

Создание пространства имен
с помощью императивного синтаксиса
Для создания пространства имен императивным способом предназначена ко-
манда kubectl create namespace с указанием имени создаваемого пространства.
В этом примере мы создадим новое пространство custom-ns. Напомним, что при
выполнении операций с пространствами имен через kubectl можно использо-
вать сокращение ns:

 $ kubectl create ns custom-ns
 namespace/custom-ns created

В результате выполнения этой команды в кластере будет создано новое про-
странство custom-ns. Проверить это можно с помощью команды kubectl get:

 $ kubectl get ns custom-ns
 NAME        STATUS   AGE
 custom-ns   Active   35s

Как видите, пространство имен успешно создано и находится в состоянии
Active. Теперь в нем можно размещать ресурсы.

        Не используйте в имени пространств имен префикс kube-, так как он зарезер-
         вирован для системных пространств имен и объектов Kubernetes.

Теперь посмотрим, как можно создать пространство имен с помощью деклара-
тивного синтаксиса.

Создание пространства имен
с помощью декларативного синтаксиса
Для создания пространства имен декларативным способом необходимо ис-
пользовать YAML- (или JSON-) файл. Ниже приведен простой YAML-файл
для создания нового пространства имен в кластере. Обратите внимание на поле
kind: Namespace:

# custom-ns-2.yaml
apiVersion: v1
kind: Namespace
metadata:
  name: custom-ns-2
