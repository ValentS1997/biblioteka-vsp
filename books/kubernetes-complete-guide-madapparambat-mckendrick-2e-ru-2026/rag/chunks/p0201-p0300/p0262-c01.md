262     Глава 7   •  Настройка подов с помощью объектов ConfigMap и Secret

Ранее в этой главе мы создали объект my-third-configmap, содержащий пара-
метр color со значением blue. В следующем примере мы создадим под с образом
quay.io/iamgini/my-flask-app:1.0 и свяжем с ним объект my-third-configmap
так, чтобы контейнер Flask-приложения получил переменную окружения COLOR
со значением blue. Вот YAML-манифест для решения этой задачи. Обратите
внимание на ключ env: в спецификации контейнера:

# flask-pod-with-configmap.yaml
apiVersion: v1
kind: Pod
metadata:
  name: flask-pod-with-configmap
  labels:
    app: my-flask-app
spec:
  containers:
    - name: flask-with-configmap
      image: quay.io/iamgini/my-flask-app:1.0
      env:
        - name: COLOR   # Здесь можно указать любое другое имя.
          valueFrom:
            configMapKeyRef:
              name: my-third-configmap
              key: color

Теперь создадим под с помощью команды kubectl apply -f:

 $ kubectl apply -f flask-pod-with-configmap.yaml
 pod/flask-pod-with-configmap created
 $ kubectl get pod
 NAME                       READY   STATUS    RESTARTS   AGE
 flask-pod-with-configmap   1/1     Running   0          5s

После создания пода приложения мы можем выполнить команду env внутри
контейнера, чтобы вывести список всех доступных переменных окружения.
Для этого мы воспользуемся командой kubectl exec. Ее ожидаемый вывод
представлен ниже:

 $ kubectl exec pod/flask-pod-with-configmap -- env
 PATH=/usr/local/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/
 bin
 HOSTNAME=flask-pod-with-configmap
 COLOR=blue
 KUBERNETES_PORT_443_TCP=tcp://10.96.0.1:443
 ... <фрагмент опущен для краткости>...

Если объект ConfigMap был корректно связан с подом, в выводе появится пере-
менная окружения COLOR.
