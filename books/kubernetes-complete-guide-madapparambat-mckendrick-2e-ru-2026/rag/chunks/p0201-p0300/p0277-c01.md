Управление конфиденциальной конфигурацией с помощью объекта Secret     277

Теперь обновим YAML-манифест с описанием пода, добавив ключ envFrom:
# flask-pod-with-secret-all.yaml
apiVersion: v1
kind: Pod
metadata:
  name: flask-pod-with-secret-all
  labels:
    app: flask-with-secret
spec:
  containers:
    - name: flask-with-secret
      image: quay.io/iamgini/my-flask-app:1.0
      envFrom:
        - secretRef:
            name: appdb-secret   # Имя объекта Secret

Создадим под с помощью команды kubectl apply -f:

 $ kubectl apply -f flask-pod-with-secret-all.yaml
 pod/flask-pod-with-secret-all created

При таком подходе все ключи из объекта Secret будут доступны внутри пода в ка-
честве переменных окружения. Проверим корректность загрузки этих переменных:

 $ kubectl exec pod/flask-pod-with-secret-all -- env | grep -i app
 db_user=appadmin
 db_password=appdbpassword

        При невозможности использования имени ключа в объекте Secret в качестве
         имени переменной окружения оно будет просто проигнорировано.

Теперь обсудим способ монтирования объекта Secret в виде тома.

только декларативным способом, то есть через YAML-манифест.
