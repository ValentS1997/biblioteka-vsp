        меры безопасности, например шифрование с помощью плагинов KMS или ис-
         пользование внешних систем управления секретами.

Помимо объектов Secret, система Kubernetes предусматривает дополнитель-
ные средства защиты конфиденциальных данных. С помощью плагинов KMS
(Key Management System — система управления ключами) теперь можно шиф-
ровать содержимое объектов Secret и ConfigMap. Это обеспечивает допол-
нительный уровень защиты чувствительных данных, хранящихся в объектах
ConfigMap.

Шифрование содержимого ConfigMap с помощью KMS-плагинов позволяет
защитить чувствительные конфигурационные данные, не прибегая к исполь-
зованию объектов Secret. Такой подход упрощает управление конфигурацией
при сохранении высокого уровня безопасности.

         Тем не менее даже при использовании KMS-шифрования следует тщательно
         оценивать уровень конфиденциальности содержимого ConfigMap. Для хранения
         действительно секретной информации рекомендуется использовать объект
           Secret.

Подробнее о KMS-плагинах для шифрования данных можно узнать в офици-
альной документации: https://kubernetes.io/docs/tasks/administer-cluster/kms-provider/.
Теперь посмотрим, как можно вывести список объектов Secret, присутствующих
в кластере Kubernetes.
