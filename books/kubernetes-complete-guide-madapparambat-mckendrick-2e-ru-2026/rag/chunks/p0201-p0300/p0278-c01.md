278     Глава 7   •  Настройка подов с помощью объектов ConfigMap и Secret

metadata:
  name: flask-pod-with-secret-volume
  labels:
    app: flask-with-secret-volume
spec:
  containers:
    - name: flask-with-secret
      image: quay.io/iamgini/my-flask-app:1.0
      volumeMounts:
        - name: mysecret-volume
          mountPath: /etc/password-mounted-path
          readOnly: true   # Значение true параметра readOnly запрещает
                           # запись в объект Secret
  volumes:
    - name: mysecret-volume
      secret:
        secretName: my-second-secret   # Здесь указывается имя объекта Secret

После сохранения файла примените его с помощью команды:

 $ kubectl apply -f flask-pod-with-secret-volume.yaml

Убедитесь в существовании объекта my-second-secret перед созданием пода,
который на него ссылается.

Наконец, выполните команду cat внутри контейнера flask-with-secret через
kubectl exec, чтобы проверить корректность монтирования тома с секретом:

 $ kubectl exec pod/flask-pod-with-secret-volume -- cat /etc/password-mounted-
 path/db_password
 my-db-password

Корректное отображение строки my-db-password говорит о том, что объект Secret
был успешно смонтирован в виде тома.

Теперь, когда вы научились создавать объекты Secret и использовать их в подах
различными способами, рассмотрим, как их удалять и обновлять.

Удаление объекта Secret
Для удаления объекта Secret достаточно выполнить команду kubectl delete:

 $ kubectl delete secret my-first-secret
 secret "my-first-secret" deleted

В следующем разделе вы узнаете, как обновить секрет, существующий в кла-
стере Kubernetes.
