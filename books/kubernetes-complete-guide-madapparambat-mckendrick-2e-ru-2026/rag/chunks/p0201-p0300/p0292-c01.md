    Рис. 8.4. Сервис service-webapp открывает доступ к подам webapp 1, 2 и 3,
            а сервис service-backendapp — к подам backendapp 1 и 2

Создать под и сервис, который предоставляет к нему доступ, можно с помощью
одной команды kubectl с параметром --expose. В качестве примера создадим
под nginx и публикующий его сервис.

В этой команде также необходимо указать порт, на котором данный сервис
будет доступен:

 $ kubectl run nginx --image nginx --expose=true --port=80
 service/nginx created
 pod/nginx created

Теперь выведем список подов и сервисов с помощью kubectl, чтобы убедиться
в создании обоих объектов:

 $ kubectl get po,svc nginx
 NAME        READY   STATUS    RESTARTS   AGE
 pod/nginx   1/1     Running   0          24s

 NAME           TYPE        CLUSTER-IP      EXTERNAL-IP   PORT(S)   AGE
 service/nginx  ClusterIP   10.111.12.100   <none>        80/TCP    24s
