244     Глава 6   •  Пространства имен, квоты и лимиты

Квоты на использование ресурсов хранилища
В системе Kubernetes квоты также позволяют контролировать суммарный объем
ресурсов хранилища, запрашиваемый в пределах пространства имен. Мы можем
задавать ограничения как на общий объем запрошенных ресурсов хранилища
для всех объектов PersistentVolumeClaim (PVC), так и на количество самих
заявок PVC. Кроме того, квоты можно определять для конкретных классов
хранилища, устанавливая отдельные лимиты для их разных типов. Например,
можно задать разные квоты для классов gold и bronze. Начиная с версии 1.8,
квоты также можно применять для ограничения совокупного объема запросов
и лимитов на использование ресурсов локального эфемерного хранилища всеми
подами в пространстве имен.

Теперь посмотрим, как можно вывести список всех существующих объектов
ResourceQuota.

Вывод списка объектов ResourceQuota
Список объектов ResourceQuota можно вывести с помощью команды kubectl
get с указанием параметра resourcequotas:

 $ kubectl get resourcequotas -n quota-ns
 NAME           AGE   REQUEST                                          LIMIT
 resourcequota  15m   requests.cpu: 100m/1, requests.memory: 1Gi/1Gi   limits.
 cpu: 500m/2, limits.memory: 2Gi/2Gi

Теперь удалим объект ResourceQuota из кластера Kubernetes.

Удаление объекта ResourceQuota
Чтобы удалить объект ResourceQuota из кластера, используйте команду kubectl
delete:

 $ kubectl delete -f resourcequota-with-object-count.yaml
 resourcequota "my-resourcequota" deleted

А теперь познакомимся с объектом LimitRange.
