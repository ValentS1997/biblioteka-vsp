Настройка подов с помощью ConfigMap     265

смонтируем объект my-sixth-configmap в виде тома в новый под flask-pod-
with-configmap-volume:

# flask-pod-with-configmap-volume.yaml
apiVersion: v1
kind: Pod
metadata:
  name: flask-pod-with-configmap-volume
spec:
  containers:
    - name: flask-with-configmap-volume
      image: quay.io/iamgini/my-flask-app:1.0
      volumeMounts:
        - name: configuration-volume   # должно совпадать с именем тома
          mountPath: /etc/conf
  volumes:
    - name: configuration-volume
      configMap:
        name: my-sixth-configmap       # здесь указывается имя объекта ConfigMap

В этом манифесте мы объявили том configuration-volume на уровне контейне-
ров и сообщили системе Kubernetes о том, что он создается на основе ConfigMap.
Указанный объект (my-sixth-configmap) должен присутствовать в кластере
в момент применения манифеста. Далее, на уровне контейнера, мы смонтиро-
вали объявленный том в каталог /etc/conf. Параметры из ConfigMap будут
доступны по этому пути.

Применим этот манифест, чтобы создать под с объектом ConfigMap, подклю-
ченным в виде тома:

 $ kubectl apply -f flask-pod-with-configmap-volume.yaml
 pod/flask-pod-with-configmap-volume created

Теперь выполним внутри контейнера команду ls, чтобы проверить результат
монтирования каталога:

 $ kubectl exec pod/flask-pod-with-configmap-volume -- ls /etc/conf
 color
 configfile.txt

Как видите, каталог был успешно смонтирован и оба параметра, созданные
в ConfigMap, доступны в нем в виде обычных файлов.
Теперь выполним команду cat, чтобы удостовериться в том, что оба файла со-
держат правильные значения:

 $ kubectl exec pod/flask-pod-with-configmap-volume -- cat /etc/conf/color
 yellow
 $ kubectl exec pod/flask-pod-with-configmap-volume -- cat /etc/conf/configfile.txt
 I'm just a dummy config file
