Влияние пространств имен на ресурсы и сервисы     223

Просмотр пространств имен в кластере
Как было показано в предыдущем разделе, вывести список пространств имен,
созданных в кластере Kubernetes, можно следующим образом:

 $ kubectl get namespaces
 NAME              STATUS   AGE
 default           Active   8d
 kube-node-lease   Active   8d
 kube-public       Active   8d
 kube-system       Active   8d

Учтите, что для всех команд, работающих с объектом namespaces, также можно
использовать сокращенный псевдоним ns.

Получение данных о конкретном пространстве имен
Данные о конкретном пространстве имен можно получить с помощью команды
kubectl describe:

 $ kubectl describe namespaces default
 Name:         default
 Labels:       kubernetes.io/metadata.name=default
 Annotations:  <none>
 Status:       Active

 No resource quota.

 No LimitRange resource.

Мы также можем воспользоваться командой kubectl get и перенаправить вывод
в формате YAML в файл, чтобы получить сведения о выбранном пространстве
имен:

 $ kubectl get namespaces default -o yaml > default-ns.yaml

Обратите внимание, что пространство имен может находиться в одном из двух
состояний:

z  Active — пространство имен активно и может использоваться для размеще-
   ния новых объектов;
z Terminating — пространство имен находится в процессе удаления вместе
   со всем его содержимым и не может использоваться для размещения новых
   объектов.

В следующем подразделе вы научитесь создавать новое пространство имен
императивным способом.
