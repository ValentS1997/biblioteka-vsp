712     Глава 21   •  Продвинутые возможности Kubernetes

Если у вас нет доступа к облачной среде или облачному Kubernetes-развер
тыванию, перейдите к следующему подразделу, чтобы развернуть Ingress-
контроллер в кластере minikube.

Развертывание Ingress-контроллера Nginx
в кластере minikube
Многоузловой кластер Kubernetes на базе minikube можно развернуть с помо-
щью следующей команды:

 $ minikube start --cni calico --nodes 3 --kubernetes-version=v1.31.0

После запуска кластера Kubernetes активизируйте функциональность Ingress
в minikube:

 $ minikube addons enable ingress
💡  ingress is an addon maintained by Kubernetes. For any concerns contact
 minikube on GitHub.
 You can view the list of minikube maintainers at: https://github.com/kubernetes/
 minikube/blob/master/OWNERS
💡  After the addon is enabled, please run "minikube tunnel" and your ingress
 resources would be available at "127.0.0.1"

 ...<фрагмент опущен для краткости>...
🔎  Verifying ingress addon...
🌟  The 'ingress' addon is enabled

Проверьте статус подов в пространстве имен ingress-nginx, выполнив команду:

 $ kubectl get pods -n ingress-nginx
 NAME                                      READY   STATUS      RESTARTS   AGE
 ingress-nginx-admission-create-rsznt      0/1     Completed   0          78s
 ingress-nginx-admission-patch-4c7xh       0/1     Completed   0          78s
 ingress-nginx-controller-6fc95558f4-zdhp7 1/1     Running     0          78s

Теперь Ingress-контроллер готов отслеживать ресурсы Ingress. В следующем
разделе мы обсудим способ их развертывания в Kubernetes-кластере.

Развертывание ресурсов Ingress в Kubernetes
Теперь можно переходить к развертыванию приложения. В каталоге Chapter21/
ingress репозитория вы найдете следующие YAML-файлы.

z  00-ingress-demo-ns.yaml — для создания пространства имен ingress-demo.
z video-portal.yaml — для создания видеопортала (ConfigMap, Deployment
  и Service).
z blog-portal.yaml — для создания блог-портала (ConfigMap, Deployment
  и Service).
