Gateway API     721

Высокоуровневая схема взаимодействия ресурсов Gateway API представлена
на рис. 21.4.

                   Рис. 21.4. Модель ресурсов Gateway API

К ключевым преимуществам Gateway API, по сравнению с Ingress API, отно-
сятся гибкость при реализации сложных сценариев маршрутизации, например
многоуровневой маршрутизации трафика между разными пространствами имен,
расширяемая архитектура, позволяющая сторонним разработчикам создавать
собственные контроллеры шлюзов, бесшовно интегрируемые с Kubernetes,
и детализированный контроль над правилами маршрутизации, политиками
обработки трафика и настройкой балансировки нагрузки.

Вот пример типичного ресурса GatewayClass:
# gateway_api/gatewayclass.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: GatewayClass
metadata:
  name: dev-cluster-gateway
spec:
  controllerName: "example.net/gateway-controller"
