Продвинутая маршрутизация трафика с помощью объекта Ingress     713

z shopping-portal.yaml — для создания торгового портала (ConfigMap,
   Deployment и Service).
z  portal-ingress.yaml — для создания ресурса Ingress, реализующего марш-
   рутизацию по путям сайта k8sbible.local.

Правило в файле portal-ingress.yaml предписывает Ingress-контроллеру на-
правлять трафик с адреса k8sbible.local/video на сервис video-service:

# ingress/portal-ingress.yaml
...
spec:
  rules:
    - host: k8sbible.local
      http:
        paths:
          - path: /video
            pathType: Prefix
            backend:
              service:
                name: video-service
                port:
                  number: 8080
...

Следующее правило предписывает Ingress-контроллеру направлять трафик
с адреса k8sbible.local/shopping на сервис shopping-service:

...
          - path: /shopping
            pathType: Prefix
            backend:
              service:
                name: shopping-service
                port:
                  number: 8080
...

Еще одно правило предписывает Ingress-контроллеру направлять трафик с адре-
са k8sbible.local/ или k8sbible.local на сервис blog-service:

...
          - path: /
            pathType: Prefix
            backend:
              service:
                name: blog-service
                port:
                number: 8080
