Gateway API     723

                     Рис. 21.5. Компоненты Gateway API

Прежде чем завершить обсуждение продвинутой маршрутизации трафика,
Ingress и Gateway API, познакомьтесь с ресурсом EndpointSlice.

Ресурсы Endpoints и EndpointSlice
Традиционно система Kubernetes управляла развертыванием приложений
с помощью подов, а объекты Service выступали в роли надежных сетевых по-
средников. В этой модели сервис служит своего рода единой точкой доступа
к подам и обновляет соответствующий объект Endpoints, содержащий список
активных и исправных подов, удовлетворяющих селектору сервиса. Однако
данный подход плохо масштабируется по мере роста нагрузки.

ект Endpoints содержит IP-адрес и порт каждого пода; эта информация рас-
пространяется по всему кластеру и используется в сетевых настройках. При
