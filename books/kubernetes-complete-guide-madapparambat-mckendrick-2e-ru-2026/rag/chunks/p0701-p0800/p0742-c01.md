742     Глава 21   •  Продвинутые возможности Kubernetes

Встроенный помощник kubectl explain
Команда kubectl explain — это мощный инструмент, который помогает разо-
браться в структуре и полях ресурсов Kubernetes. Она предоставляет подробную
информацию о конкретных типах ресурсов, позволяя исследовать схему API
прямо из командной строки. Это особенно полезно при написании или отладке
YAML-манифестов, так как гарантирует использование корректных полей
и структуры.

Например, чтобы изучить ресурс Pod, используйте команду:

 $ kubectl explain pod

Эта команда выведет общее описание ресурса Pod с краткой характеристикой.
Для детального изучения отдельных полей, например spec, можно расширить
эту команду следующим образом:

 $ kubectl explain pod.spec

Вывод будет содержать подробное описание поля spec, включая вложенные
поля и ожидаемые типы данных, что поможет правильно сконфигурировать
ресурсы Kubernetes.

Интерактивное устранение неполадок
с помощью команды kubectl exec
Команда kubectl exec — это мощный инструмент для взаимодействия с рабо-
тающими контейнерами в Kubernetes и устранения неполадок. Она позволяет
выполнять команды непосредственно внутри контейнера, что делает ее неза-
менимой при отладке, проверке окружения контейнера и выполнении быстрых
исправлений. Эта команда пригодится вам для просмотра логов, анализа конфи-
гурационных файлов, диагностики сетевых проблем, то есть в любой ситуации,
требующей взаимодействия с приложением в реальном времени.

Чтобы воспользоваться этим инструментом, начните с выполнения простой
команды внутри контейнера (для тестирования можно использовать манифест
kubectl apply -f trouble/blog-portal.yaml):

 $ kubectl get po -n trouble-ns
 NAME                   READY   STATUS    RESTARTS   AGE
 blog-675df44d5-gkrt2   1/1     Running   0          29m

Для вывода переменных окружения контейнера выполните команду:

 $ kubectl exec blog-675df44d5-gkrt2 -- env
