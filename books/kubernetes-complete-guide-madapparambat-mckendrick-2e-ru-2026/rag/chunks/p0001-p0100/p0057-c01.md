Управление контейнерами с помощью Kubernetes     57

Управление контейнерами
с помощью Kubernetes
В этом разделе мы сосредоточимся на системе Kubernetes, которой посвящена
эта книга.

Kubernetes — это платформа для запуска
рабочих нагрузок в рабочей среде
Если открыть официальный сайт Kubernetes (https://kubernetes.io), то в заголовке
можно увидеть надпись Production-Grade Container Orchestration (рис. 1.8).

   Рис. 1.8. Главная страница сайта Kubernetes с заголовком, представляющим
     эту систему как платформу для оркестрации контейнеров в рабочей среде

Эта фраза прекрасно передает суть Kubernetes: это платформа для оркестрации
контейнеров в рабочей среде. Система Kubernetes не пытается заменить Docker
(или другие контейнерные движки). Она предназначена для управления класте-
рами машин, на которых работают среды выполнения контейнеров. При работе
с Kubernetes, помимо самой этой системы, вы используете полнофункциональ-
ные стандартные установки контейнерных движков.

В заголовке на сайте упоминается рабочая среда (production, продакшен), и это
понятие действительно является ключевым для Kubernetes. Данная система
была разработана для решения задач, связанных с эксплуатацией приложений
в современной рабочей среде. Управление рабочими нагрузками сегодня суще-
ственно отличается от того, каким оно было в 2000-х годах. В те времена рабочая
среда обычно представляла собой всего несколько физических серверов (или
даже один локальный сервер), на которых запускались в основном монолитные
приложения, установленные непосредственно в хостовой ОС Linux. Сегодня
благодаря публичным облачным платформам, таким как Amazon Web Services
(AWS) и Google Cloud Platform (GCP), любой пользователь может с легкостью
получить сотни или даже тысячи серверов в виде экземпляров или виртуальных
машин. Более того, приложения теперь разворачиваются не в хостовой системе,
а поверх движка Docker в виде контейнеризованных микросервисов, что поз
воляет уменьшить влияние на конфигурацию хоста.
