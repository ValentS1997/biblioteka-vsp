Компоненты управляющего слоя     85

         Следует отметить, что etcd тоже реализован как REST API. По умолчанию он
         прослушивает порт 2379.

Рассмотрим простой пример команды kubectl:

 $ kubectl run nginx --restart Never --image nginx

При ее выполнении утилита kubectl сформирует HTTP-запрос POST, адре
сованный компоненту kube-apiserver, указанному в файле kubeconfig.
kube-apiserver внесет новую запись в etcd, которая будет постоянно храниться
на диске.

В этот момент состояние Kubernetes изменяется: теперь уже другие компоненты
системы должны будут привести фактическое состояние кластера в соответ-
ствие с желаемым (тем, которое хранится в etcd).
В отличие от хранилищ Redis или Memcached etcd не работает исключительно
в оперативной памяти. Его данные хранятся на диске, поэтому не теряются при
перезагрузке машины.

Где запускать etcd
В самостоятельно администрируемом кластере Kubernetes компонент etcd
можно запускать либо в контейнере, либо в виде сервиса, управляемого с по-
мощью unit-файла systemd. Этот компонент изначально поддерживает гори-
зонтальное масштабирование путем распределения набора данных между
несколькими серверами, что делает его самостоятельным решением для кла-
стеризации.

Существует два варианта размещения etcd в системе Kubernetes.
z Совместно с kube-apiserver (и другими компонентами управляющего слоя)
   на управляющих узлах. Этот вариант используется по умолчанию и является
   наиболее простым. В большинстве кластеров Kubernetes такие компоненты,
   как etcd и kube-apiserver, изначально развертываются с использованием
   статических манифестов. Мы подробно рассмотрим этот и альтернативные
   подходы далее в книге.
z В виде выделенного кластера etcd. Это более сложный вариант, но он обе-
   спечивает повышенную надежность в средах, для которых это критично.
Эксплуатация кластеров etcd в Kubernetes
Подробную информацию о выделенных кластерах etcd (состоящих из од-
ного или нескольких узлов) можно найти в официальной документации по
Kubernetes: https://kubernetes.io/docs/tasks/administer-cluster/configure-upgrade-etcd/.
