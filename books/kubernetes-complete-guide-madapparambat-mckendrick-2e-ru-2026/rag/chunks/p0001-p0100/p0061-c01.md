У каждого из этих оркестраторов есть свои сильные и слабые стороны, однако
Kubernetes остается наиболее популярным и широко используемым решением
в данной сфере.

Kubernetes одержал победу в гонке за популярность и стал стандартом для
развертывания контейнерных приложений в рабочей среде. Стремительный
рост востребованности данной технологии в ИТ-отрасли побудил облачных
провайдеров включить собственные Kubernetes-решения в перечень своих
услуг. Благодаря этому сегодня Kubernetes поддерживается практически по-
всеместно.

Ниже приведены примеры сервисов, основанных на Kubernetes, которые по-
зволяют развернуть кластер, сделав всего несколько щелчков кнопкой мыши:

z Google Kubernetes Engine (GKE) на платформе Google Cloud Platform;
z  Elastic Kubernetes Service (Amazon EKS);
z Azure Kubernetes Service на платформе Microsoft Azure;
z  Alibaba Cloud Container Service for Kubernetes (ACK).

Дело не ограничивается только облачными сервисами — важную роль игра-
ет и рынок PaaS (Platform-as-a-Service — платформа как услуга). Компания
Red Hat начала интегрировать Kubernetes в свою контейнерную платформу
OpenShift в 2015 году после выхода версии OpenShift 3. Это привело к значи-
тельному изменению архитектуры OpenShift: система перешла от своей исход-
ной модели к оркестрации контейнеров на базе Kubernetes, предоставив пользо-
вателям расширенные возможности управления контейнерами и полный набор
корпоративных инструментов для создания, развертывания и администрирова-
ния контейнеров непосредственно поверх Kubernetes. Кроме того, появились
и другие проекты, например Rancher, разработанный в качестве дистрибутива
Kubernetes и предлагающий полный набор инструментов, совместимых с этим
оркестратором, а также Knative, предназначенный для управления бессервер-
ными рабочими нагрузками с использованием Kubernetes.

         Платформа AWS предлагает два сервиса для оркестрации контейнеров: Amazon
         ECS и Amazon EKS. Второй появился позднее и представляет собой полноценную
         реализацию Kubernetes в инфраструктуре AWS. Эти сервисы имеют схожие на-
          звания, но являются совершенно разными решениями.
