Кроме того, другие компоненты Kubernetes, запущенные на остальных узлах
кластера, постоянно отправляют HTTP-запросы к kube-apiserver, чтобы узнать
текущее состояние кластера или обновить его. И чем больше вычислительных
узлов в кластере, тем больше запросов поступает в kube-apiserver. Поэтому дан-
ный компонент должен масштабироваться пропорционально размеру кластера.

Как уже было сказано, kube-apiserver представляет собой компонент, не со-
храняющий состояние: он не управляет состоянием кластера напрямую,
а использует для этого внешнюю базу данных. Его можно масштабировать
горизонтально, разместив несколько экземпляров на группе машин за балан-
сировщиком нагрузки.

В следующем разделе мы поговорим о том, как Kubernetes хранит сведения
о кластере и его ресурсах с помощью etcd.

Хранилище данных etcd
Мы уже говорили, что kube-apiserver можно масштабировать горизонтально
и что для хранения состояния кластера и его параметров данный компонент
использует etcd — открытое распределенное хранилище данных в формате
«ключ — значение». Строго говоря, etcd не входит в состав системы Kubernetes,
а является отдельным проектом, поддерживаемым сообществом etcd-io.

         Хотя etcd является наиболее распространенным хранилищем данных для кла-
         стеров Kubernetes, некоторые дистрибутивы, например k3s, по умолчанию
         используют такие альтернативы, как SQLite, или даже внешние базы данных
        MySQL и PostgreSQL (https://docs.k3s.io/datastore).
           etcd — это тоже проект с открытым исходным кодом (как и Kubernetes напи-
         санный на языке Go), доступный на GitHub (https://github.com/etcd-io/etcd) под
         лицензией Apache 2.0. Этот проект развивался под эгидой Cloud Native Computing
          Foundation (CNCF) — организации, курирующей Kubernetes. В 2018 году он был
         включен в программу инкубации CNCF, а в 2020-м получил статус «выпущен-
         ного» (graduated).

Всякий раз, когда вы обращаетесь к kube-apiserver с целью выполнения опе-
рации чтения или записи, данные считываются из хранилища etcd или запи-
сываются в него.
