66     Глава 1   •  Основы Kubernetes

Кроме того, Kubernetes хранит в памяти все ревизии конкретного развертывания
(deployment) и позволяет выполнить откат к предыдущей версии с помощью
всего одной команды. Это исключительно мощный инструмент, который дает
возможность обновить весь кластер контейнеров Docker путем выполнения
единственной команды.

Автоматическое масштабирование контейнеров
Масштабирование — это еще одна из специфических задач, возникающих
в рабочей среде, решение которой существенно упростило появление таких
публичных облачных платформ, как Amazon Web Services (AWS) и Google Cloud
Platform (GCP). Масштабирование позволяет адаптировать уровень используе
мых вычислительных ресурсов под текущие потребности с целью обеспечения
высокой доступности приложения и балансировки нагрузки. Помните, что
основная задача всегда заключается в предотвращении сбоев.
Когда рабочие серверы сталкиваются с резким всплеском трафика и один из
контейнеров перестает справляться с нагрузкой, возникает потребность в эффек-
тивном способе масштабирования. Для этого существует два основных метода.

z Вертикальное масштабирование позволяет контейнеру задействовать до-
   полнительные вычислительные ресурсы, предоставляемые хост-машиной.
z Горизонтальное масштабирование предполагает создание копий контейнера
   на той же или на другой машине с последующим распределением трафика
  между ними.

Система Docker не способна в полной мере решить эту задачу самостоятельно.
Однако при управлении контейнерами Docker с помощью Kubernetes это ста-
новится возможным (рис. 1.10).
