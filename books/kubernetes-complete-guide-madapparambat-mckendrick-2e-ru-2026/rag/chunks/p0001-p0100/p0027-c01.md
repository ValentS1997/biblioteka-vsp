Кому адресована эта книга
Издание адресовано людям, планирующим использовать Kubernetes совместно
с контейнерными движками. Хотя Kubernetes поддерживает различные кон-
тейнерные движки через интерфейс среды выполнения контейнеров (Container
Runtime Interface, CRI) и не привязан к какому-либо конкретному решению,
на практике одной из самых распространенных конфигураций является связка
Kubernetes и containerd.

Эта книга представляет собой сугубо техническое издание, где основное вни-
мание уделено Kubernetes и контейнерным средам. Она ориентирована на ин-
женеров, будь то разработчики или системные администраторы, и не пред
назначена для менеджеров проектов. Это настоящая библия Kubernetes
для тех, кто намерен работать с данной системой на повседневной основе.
Если вас не пугает необходимость вводить команды в терминале, то эта книга
для вас.

Полное отсутствие опыта работы с Kubernetes или средний уровень подготовки
не станут помехой для освоения материала. Хотя в главах затрагиваются базо-
вые понятия контейнеризации, читателю желательно иметь хотя бы минималь-
ное техническое представление о контейнерах. Издание также может послужить
практическим руководством для тех, кто занимается переносом существующего
приложения в Kubernetes.

Эта книга содержит практические руководства по развертыванию Kubernetes
в публичных облаках, например Amazon EKS или Google GKE. Она будет
особенно полезна пользователям облачных платформ, желающим включить
Kubernetes в свой технологический стек.
