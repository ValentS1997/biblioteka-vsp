Обзор утилиты командной строки kubectl
и синтаксиса YAML
kubectl — это официальная утилита командной строки, предназначенная для
управления платформой Kubernetes. Она представляет собой HTTP-клиент,
оптимизированный для работы с этой системой и позволяющий отдавать коман
ды кластеру Kubernetes.

         Kubernetes и среда обучения на базе Linux
        Для эффективного изучения контейнеров Linux и связанных с ними тем лучше
          всего использовать рабочие станции или лабораторные машины под управлени-
         ем Linux. Базовые знания этой ОС крайне полезны для работы с контейнерами
         и системой Kubernetes. Использование Linux в качестве основной ОС на рабочей
         станции автоматически погружает вас в нужную среду, делая обучение более
         продуктивным. Вы можете выбрать любой дистрибутив Linux, например Fedora
         или Ubuntu. Однако мы стремимся к инклюзивности, поэтому предлагаем аль-
         тернативные инструкции для пользователей Windows и macOS, чтобы сделать
          процесс обучения доступным для всех. Таким образом, наличие рабочей стан-
         ции с Linux не является обязательным условием для изучения Kubernetes. Если
        вы работаете в Windows, то можете воспользоваться таким альтернативным
         решением, как WSL (Windows Subsystem for Linux — подсистема Windows для
           Linux) (https://learn.microsoft.com/en-us/windows/wsl/).

Установка утилиты командной строки kubectl
Утилиту командной строки kubectl можно установить на рабочие станции
под управлением Linux, Windows или macOS. Для обеспечения оптимальной
совместимости необходимо следить за тем, чтобы минорная версия клиента
kubectl отличалась от минорной версии кластера Kubernetes не более чем на
единицу. Это означает, что kubectl версии v1.30 может управлять кластерами
версий v1.29, v1.30 и v1.31. Использование последней совместимой версии по-
могает избежать потенциальных проблем.
Поскольку утилита kubectl понадобится вам уже в следующей главе, вы можете
установить ее прямо сейчас, воспользовавшись инструкциями, приведенными
в следующих разделах.
