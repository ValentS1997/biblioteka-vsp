98     Глава 2   •  Архитектура Kubernetes

Эта команда загрузит указанную версию утилиты kubectl, после чего вы смо-
жете скопировать ее в нужный каталог.
Теперь рассмотрим процесс установки kubectl в macOS.

Установка kubectl в macOS
Процесс установки в macOS практически ничем не отличается от описанного
выше, за исключением того, что для платформ на базе Intel и Apple Silicon су-
ществуют отдельные пакеты kubectl.

 # Intel
 $ curl -LO "https://dl.k8s.io/release/$(curl -L -s \
  https://dl.k8s.io/release/stable.txt)/bin/darwin/amd64/kubectl"

 # Apple Silicon
 $ curl -LO "https://dl.k8s.io/release/$(curl -L -s \
 https://dl.k8s.io/release/stable.txt)/bin/darwin/arm64/kubectl"

 $ chmod +x ./kubectl
 $ sudo mv ./kubectl /usr/local/bin/kubectl
 $ sudo chown root: /usr/local/bin/kubectl

Установка kubectl в Windows
Скачайте файл kubectl.exe (https://dl.k8s.io/release/v1.30.0/bin/windows/amd64/
kubectl.exe) через браузер или с помощью утилиты curl (или аналогичной ути-
литы командной строки, если она установлена в Windows):

 $ curl.exe -LO https://dl.k8s.io/release/v1.30.0/bin/windows/amd64/kubectl.exe

Затем добавьте путь к утилите kubectl в начало или конец переменной окружения
PATH и убедитесь, что используемая версия утилиты соответствует загруженной.

        Вы также можете установить kubectl с помощью стандартного менеджера па-
          кетов, например apt-get, yum, Zypper, brew (для macOS) или Chocolatey (для
          Windows). Дополнительную информацию можно найти в документации: https://
            kubernetes.io/docs/tasks/tools/install-kubectl-linux.

В следующем подразделе мы поговорим об использовании команды kubectl.

Роль утилиты kubectl
Поскольку компонент kube-apiserver представляет собой HTTP API, для взаи-
модействия с кластером Kubernetes можно использовать любой HTTP-клиент.
Например, вы можете управлять кластером даже с помощью утилиты curl, но,
разумеется, для этого существует более удобный способ.
