В следующем разделе мы обсудим компоненты управляющего слоя, отвечающие

Компоненты управляющего слоя
Далее мы рассмотрим различные компоненты управляющего слоя и их функции.

Компонент kube-apiserver
Наиболее важным компонентом Kubernetes является REST API kube-apiserver,
который предоставляет доступ ко всем возможностям системы. Взаимодействие
с Kubernetes происходит путем обращения к этому REST API — через утилиту
командной строки kubectl, прямые API-вызовы или веб-интерфейс Kubernetes
(Dashboard).

Роль компонента kube-apiserver
Компонент kube-apiserver входит в состав управляющего слоя Kubernetes.
Он написан на языке Go, и его исходный код открыт и доступен на GitHub под
лицензией Apache 2.0. Схема взаимодействия с Kubernetes довольно проста: что-
бы дать системе инструкцию, вы направляете HTTP-запрос к kube-apiserver.
Все операции, будь то создание, удаление или обновление контейнера, выполня-
