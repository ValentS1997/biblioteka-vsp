Все это делает Kubernetes исключительно эффективным инструментом для
управления большим количеством контейнеров в рабочей среде. По сути, кон-
цепции, используемые в этой системе, появились задолго до нее самой. Несмо-
тря на то что Kubernetes — это относительно молодой проект, он был основан
на прочном фундаменте.

Кто управляет Kubernetes сегодня
Система Kubernetes больше не находится под управлением Google, посколь-
ку 29 августа 2018 года компания передала операционный контроль над про-
ектом некоммерческой организации Cloud Native Computing Foundation (CNCF),
цель которой состоит в поддержке и развитии открытой экосистемы облачных
технологий.

Google является одним из учредителей CNCF наряду с такими компаниями, как
Cisco, Red Hat и Intel. Исходный код Kubernetes размещен на GitHub и является
одним из наиболее активно развивающихся проектов на этой платформе. Этот
код распространяется на условиях лицензии Apache License версии 2.0, то есть
с минимальными ограничениями. Использование Kubernetes не требует оплаты,
а если вы владеете языком Go, то можете даже внести свой вклад в развитие
этой системы.
