Интерфейс среды выполнения контейнеров
Система Kubernetes использует среду выполнения контейнеров для запуска
контейнеров внутри подов. Для взаимодействия с выбранной средой выполне-
ния Kubernetes по умолчанию использует интерфейс CRI (Container Runtime
Interface, интерфейс среды выполнения контейнеров). Этот интерфейс был
впервые представлен в Kubernetes версии 1.5, выпущенной в декабре 2016 года.
CRI представляет собой интерфейс плагинов, позволяющий компоненту kubelet
беспрепятственно интегрироваться с различными средами выполнения кон-
тейнеров. Такая гибкость дает возможность выбирать оптимальную среду в за-
висимости от конкретных требований.

В рамках стандарта CRI определен набор API, позволяющих компоненту
kubelet эффективно взаимодействовать со средой выполнения контейнеров.
Эти API охватывают такие ключевые операции, как запуск, остановка и уда-
ление контейнеров, а также управление песочницами для подов и сетевыми
взаимодействиями.

полнения контейнеров на машинах с Linux.
