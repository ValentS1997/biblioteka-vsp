# Резюме главы 16 — по завершающему разделу книги

**Источник:** `kubernetes-complete-guide-madapparambat-mckendrick-2e-ru-2026:p0559:c01`, PDF/печатная страница **559**, раздел «Резюме». Ниже **краткий пересказ**, а не дословное воспроизведение текста; структура и позиция авторов сохранены.

В главе авторы знакомят с историей AWS и управляемым сервисом EKS, затем последовательно описывают создание аккаунта, установку и настройку двух CLI-инструментов: AWS CLI и eksctl. С помощью eksctl развёрнут кластер EKS, а поверх него — уже знакомое приложение Guestbook. Одни и те же Kubernetes-манифесты применяются на GKE и EKS без изменений; облачный балансировщик нагрузки создаётся автоматически.

Отдельно обсуждены AWS Console, различия прав доступа при использовании разных идентичностей, два стека CloudFormation, узлы EC2 и балансировщик. Авторы характеризуют интеграцию EKS с консолью AWS в представленном ими сценарии как менее цельную и удобную, чем аналогичный опыт GKE; работа через AWS CLI без eksctl, по их оценке, требует большего числа предварительных шагов.

Следующая глава посвящена третьему провайдеру — Microsoft Azure и сервису Azure Kubernetes Service (AKS).

**Evidence boundary:** суждение об удобстве отражает впечатление авторов, не независимое сравнительное исследование; учётные данные/стоимость/настройки безопасности и состояние актуальных AWS сервисов не проверялись. Исторические цены вынесены в cheatsheet/source-findings.
