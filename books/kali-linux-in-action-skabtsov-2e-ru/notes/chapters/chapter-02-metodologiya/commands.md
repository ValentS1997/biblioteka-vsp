## CLI

**`RAG_MISS`:** в RAG этой главы не приведены конкретные команды CLI, необходимые аргументы, проверочные выводы или документированные процедуры rollback. Не подставлять знакомые команды Kali Linux из памяти. Для любой потенциально меняющей состояние операции: согласовать последствия, источник проверки и возможность восстановления до выполнения.
