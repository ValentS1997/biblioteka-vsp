# Source findings — глава 04 «Активный сбор данных»

**Источник:** canonical RAG PDF 111–154, SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`. Это реестр ошибок/неоднозначностей **исходного текста**, а не попытка исправить PDF. При отсутствии подтверждения указываем **[Needs confirmation]**.

## 01 — [Source code mismatch] · PDF 146

В абзаце о **Nmap и NSE rpcinfo** источник сначала даёт `nmap -v -p 111`, затем подписывает пример сканирования как `map -sV -p 111 --script=rpcinfo` ([p0146:c01](../../../rag/chunks/p0101-p0200/p0146-c01.md)). **Расхождение:** `nmap` ↔ `map`. Нельзя молча выбрать корректную исполняемую команду; функция `rpcinfo` обсуждается концептуально, указанный фрагмент не рекомендован к запуску.

## 02 — [Source wording/code mismatch] · PDF 142

В описании `enum4linux` написано: получение «полной информации, предоставляемой **SNMP-агентом**», хотя речь непосредственно идёт о Windows/SMB/Samba, и далее следует пример `enum4linux` ([p0142:c01](../../../rag/chunks/p0101-p0200/p0142-c01.md)), тогда как самостоятельный раздел **SNMP** расположен позже ([p0151:c01](../../../rag/chunks/p0101-p0200/p0151-c01.md), [p0152:c01](../../../rag/chunks/p0101-p0200/p0152-c01.md)). **Неоднозначность:** описываемый протокол и терминология. Вывод без внешней проверки — [Needs confirmation]; в README перечисление SMB отдельно от SNMP, с сохранением этого замечания.

## 03 — [Source code mismatch] · PDF 153

Фрагмент «Поиск SNMP» содержит команду `nmap -sU -p 161`, но опубликованный далее пример вывода показывает состояния `161/tcp` и строку `SYN Stealth Scan` ([p0153:c01](../../../rag/chunks/p0101-p0200/p0153-c01.md), [p0154:c01](../../../rag/chunks/p0101-p0200/p0154-c01.md)). **Расхождение:** заданный UDP-режим vs TCP-вывод. Данные примера нельзя интерпретировать как прямой результат той же команды без дополнительного подтверждения.

## 04 — [Source wording/code mismatch] · PDF 147–148

После просмотра вывода `ls -la` в NFS-разделе текст именует числовое значение владельца **UUID**, затем предлагает редактировать идентификатор пользователя в локальном `/etc/passwd` для доступа к удалённому конфигурационному файлу ([p0147:c01](../../../rag/chunks/p0101-p0200/p0147-c01.md), [p0148:c01](../../../rag/chunks/p0101-p0200/p0148-c01.md)). **Проблема:** источник связывает термин «UUID», числовое значение владельца и изменение пользовательской учётной записи без отдельного объяснения модели идентичности и отката. Эта опасная процедура не пересказывается как пошаговая инструкция; правомерность и восстановление — [Needs confirmation].

## 05 — [Source contradiction] · PDF 149

При подключении к `mx.adb.com` в SMTP-примере баннер назван `timmy2-lv.inbox.lv ESMTP`, совпадая с именем, фигурирующим ранее в другой SMTP-сессии ([p0149:c01](../../../rag/chunks/p0101-p0200/p0149-c01.md)). **Расхождение:** подключение к одному хосту и баннер другого. Без доступа к исходным серверам нельзя определить, что это — пример реальной конфигурации, ошибка монтажа или извлечения. Ответы `VRFY` трактуются как **иллюстративный transcript**, а не как подтверждение текущих серверов.

## 06 — [Source extraction issue] · PDF 125

Указание флага определения ОС в тексте может отображаться как `-О` (кириллическая буква), при том что пример консольного запуска ниже записан `nmap -O` ([p0125:c01](../../../rag/chunks/p0101-p0200/p0125-c01.md), [p0126:c01](../../../rag/chunks/p0101-p0200/p0126-c01.md)). **Расхождение:** визуально сходные символы. Командная форма из консольного примера сохранена с RAG provenance; реальный вывод не воспроизводился.

## 07 — [Needs confirmation] · PDF 139

Для `dnsenum --dnsserver ns1.example.com example.com` в книге заявлена операция «передача зоны», но приведённая строка сама по себе не содержит явного режима AXFR в тексте. Реальный эффект этой опции и версия утилиты требуют отдельной верификации; не подменять авторскую строку неизвестной модельной «правильной» командой. [p0139:c01](../../../rag/chunks/p0101-p0200/p0139-c01.md).

## Непроверенные актуальные факты

Примеры сканирования, баннеры версий ПО, SMTP/NTP/SNMP-ответы и законодательные предупреждения относятся к описанию книги, **не подтверждают их актуальность на дату анализа**. Данные пользователей, строки community и конфигурационные пароли не сохраняются в учебном Git-артефакте; источник остаётся неизменным.
