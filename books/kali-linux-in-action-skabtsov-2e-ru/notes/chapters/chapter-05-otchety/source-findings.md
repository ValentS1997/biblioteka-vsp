# Source findings — глава 05 «Отчеты»

**Правило:** это отдельный журнал наблюдаемых расхождений в каноническом RAG, не слой скрытых исправлений. PDF pp. 155–184, source SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`. Официальные инструкции пакетов и стандартов не проверялись через веб; неизвестное остаётся **[Needs confirmation]**.

## F-01 · [Source code mismatch] — установка LibreOffice

**Вариант A:** [p0159:c01](../../../rag/chunks/p0101-p0200/p0159-c01.md) печатает `$sudo atp install libreoffice`. **Варианты B:** [p0164:c01](../../../rag/chunks/p0101-p0200/p0164-c01.md) использует `$sudo apt install cherrytree`, [p0167:c01](../../../rag/chunks/p0101-p0200/p0167-c01.md) — `$sudo apt install dradis`. Имена `atp` и `apt` конфликтуют при описании установки пакетов. **Решение:** оригинальная строка сохранена в commands.md с блокирующей пометкой; её работоспособность не утверждается.

## F-02 · [Source wording/code mismatch] — LibreOffice / LiberOffice

На [p0159:c01](../../../rag/chunks/p0101-p0200/p0159-c01.md) название пакета и продукта дано **LibreOffice**; на [p0161:c01](../../../rag/chunks/p0101-p0200/p0161-c01.md) рядом с рекомендацией LibreOffice Base написано **LiberOffice**. Терминологическое расхождение отмечено, название продукта не заменяется в доказательстве. Актуальность наличия Base и способ его установки — [Needs confirmation].

## F-03 · [Source extraction issue] — имя deb Xmind

На [p0166:c01](../../../rag/chunks/p0101-p0200/p0166-c01.md) исходная строка читается `$sudo dpkg -i Xmind-for-linux-amd64bit-22. 11. 3656. deb`; между компонентами версии/расширения в RAG стоят пробелы. Однозначно восстановить точное имя файла по извлечённому тексту нельзя; **команда не рекомендуется к запуску** без подтверждения имени файла в конкретной системе.

## F-04 · [Source wording/code mismatch] — имя JAR MagicTree

На [p0166:c01](../../../rag/chunks/p0101-p0200/p0166-c01.md) обсуждается **MagicTree**, но путь запуска использует имя `MagicTre-build1814.jar`. Возможно, так действительно назывался артефакт; это **[Needs confirmation]**, не доказательство ошибки автора. Не переименовывать файл в команде по аналогии.

## F-05 · [Source contradiction] — описание Reflected XSS и Integrity

На [p0182:c01](../../../rag/chunks/p0101-p0200/p0182-c01.md) повествование допускает возможность **читать и изменять** данные в контексте сайта через JavaScript. В той же странице комментарий к оценке **Integrity: Low** говорит, что связанная с приложением информация **«не может быть модифицирована»**. Эти формулировки не согласуются без дополнительных уточнений к смыслу «данных». **Решение:** сохранить обе формулировки; балл **6,1 (Medium)** перенесён как авторский результат с [p0183:c01](../../../rag/chunks/p0101-p0200/p0183-c01.md), **не пересчитывался**.

## F-06 · [Needs confirmation] — спецификация CVSS в книжном изложении

На [p0178:c01](../../../rag/chunks/p0101-p0200/p0178-c01.md) перечислены CVSS v2.0/v3.0/v3.1 и говорится о выходе CVSS 4.0 к печати, далее описываются группы метрик и свойства версий ([p0179:c01](../../../rag/chunks/p0101-p0200/p0179-c01.md)–[p0181:c01](../../../rag/chunks/p0101-p0200/p0181-c01.md)). Точный статус редакций, нормативные формулы и полнота перечисления метрик **не подтверждаются внешней спецификацией** в рамках RAG-only. Поэтому `commands.md` не предлагает вычислять CVSS из неполного описания, а переносит исключительно шкалу из [p0182:c01](../../../rag/chunks/p0101-p0200/p0182-c01.md) и учебную оценку из [p0183:c01](../../../rag/chunks/p0101-p0200/p0183-c01.md).
