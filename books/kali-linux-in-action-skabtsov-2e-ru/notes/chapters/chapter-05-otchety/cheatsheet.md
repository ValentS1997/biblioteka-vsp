# Cheatsheet — глава 05 «Отчеты»

Canonical RAG-only · PDF pp. 155–184 · chunks `p0155:c01`–`p0184:c01` · SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`.

## Symptom / problem framing

Аудит технически проведён, но результаты не сохранены или недостаточно структурированы: находки нельзя восстановить по параметрам и времени теста, отчёт избыточен, целевая аудитория не понимает рисков, а техническая команда не видит конкретных деталей исправления. Автор называет это существенной проблемой качества итоговой работы. [p0155:c01](../../../rag/chunks/p0101-p0200/p0155-c01.md)–[p0157:c01](../../../rag/chunks/p0101-p0200/p0157-c01.md), [p0176:c01](../../../rag/chunks/p0101-p0200/p0176-c01.md).

## Baseline / context

**Лабораторный журнал:** план, согласованный scope, этап и время действий, используемые команды и параметры, результат, снимок экрана/файл при необходимости. Реальные секреты и чужие личные данные не включаются в открытые заметки. [p0155:c01](../../../rag/chunks/p0101-p0200/p0155-c01.md), [p0184:c01](../../../rag/chunks/p0101-p0200/p0184-c01.md).

**Рабочие структуры:** таблица Calc для небольших наборов; SQL/LibreOffice Base для структурированных связей; блок-схема для процессов; Maltego/Xmind для графов; CherryTree для заметок; Dradis для командного workflow и подготовки результата. Выбор зависит от вида данных, а не от предполагаемого универсального «лучшего» инструмента. [p0159:c01](../../../rag/chunks/p0101-p0200/p0159-c01.md)–[p0173:c01](../../../rag/chunks/p0101-p0200/p0173-c01.md).

## Interpretation

**Не подтверждено ≠ не существует** и **сканер сообщил ≠ доказано**. Автор приводит случаи защищённого WAF компонента и специально уязвимого honeypot, поэтому находки требуют контекста и корректной формулировки. Факт обнаружения, возможная эксплуатация и приоритет исправления — разные поля отчёта. [p0177:c01](../../../rag/chunks/p0101-p0200/p0177-c01.md).

**CVSS в книге:** 0 / 0,1–3,9 / 4,0–6,9 / 7,0–8,9 / 9,0–10 соответствуют None/Low/Medium/High/Critical. Пример Reflected XSS: **6,1 (Medium)** по заданным автором метрикам, не универсальная оценка. [p0182:c01](../../../rag/chunks/p0101-p0200/p0182-c01.md)–[p0183:c01](../../../rag/chunks/p0101-p0200/p0183-c01.md).

## Modifying action

- **Создание/импорт/редактирование** табличных данных, проектов Dradis, заметок CherryTree, графов и экспорта меняют **локальное состояние** и могут содержать чувствительные данные. [p0159:c01](../../../rag/chunks/p0101-p0200/p0159-c01.md)–[p0173:c01](../../../rag/chunks/p0101-p0200/p0173-c01.md).
- Установка `cherrytree`/`dradis` и запуск Dradis меняют **программную среду/сервис**. Не выдавать их за read-only. Требования к восстановлению, пакетные версии и режим доступа: **[Needs confirmation]**. [p0164:c01](../../../rag/chunks/p0101-p0200/p0164-c01.md), [p0167:c01](../../../rag/chunks/p0101-p0200/p0167-c01.md).
- Воспроизведение сканером или эксплуатацией для проверки уязвимости является **воздействием на тестируемую ИС**; применять только в пределах согласованного scope, без самостоятельного расширения теста. [p0177:c01](../../../rag/chunks/p0101-p0200/p0177-c01.md).
- Создание резервной копии меняет **состояние хранилища**: защищённость и доступ проверяются отдельно. [p0184:c01](../../../rag/chunks/p0101-p0200/p0184-c01.md).

- [ ] Руководство получает краткие выводы, риски, визуализацию и приоритеты.
- [ ] Техническая команда получает достаточно данных для устранения проблемы.
- [ ] Не публикуются исходные дампы с личной информацией или секретами.
- [ ] Итоги сверены с целями; орфография, стиль и ссылки проверены.
- [ ] Документация и её резервные копии защищены. [p0184:c01](../../../rag/chunks/p0101-p0200/p0184-c01.md).
