## Правило исполнения

Из `commands.md` **не следует** запускать SET или отправлять фишинговые сообщения. Для обучения достаточно организовать письменный scope, безопасные демонстрации без сбора паролей, объяснение признаков давления, независимые методы верификации и агрегированный отчёт. [p0243:c01](../../../rag/chunks/p0201-p0300/p0243-c01.md), [p0244:c01](../../../rag/chunks/p0201-p0300/p0244-c01.md)–[p0251:c01](../../../rag/chunks/p0201-p0300/p0251-c01.md).

**RAG_MISS:** нынешние команды SET, версии, лицензии, правовой статус конкретного теста, безопасный сбор/удаление учётных данных и технический rollback — **[Needs confirmation]**. Данные инструменты не обновлены по знаниям модели.
