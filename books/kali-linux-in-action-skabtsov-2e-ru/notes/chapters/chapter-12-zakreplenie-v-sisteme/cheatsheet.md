# Cheatsheet — глава 12 «Закрепление в системе»

**Source:** RAG PDF **293–301**, chunks `p0293:c01`–`p0301:c01`; canonical SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`.

## Symptom / problem framing

После закрытия первоначальной уязвимости доступ может сохраняться через **планировщик/стартовый скрипт**, неожиданную сетевую службу, **исходящее обратное соединение** либо **портовый туннель** к внутренней сети. Автор показывает эти механизмы как post-compromise сценарии. [p0293:c01](../../../rag/chunks/p0201-p0300/p0293-c01.md)–[p0295:c01](../../../rag/chunks/p0201-p0300/p0295-c01.md).

## Baseline / context

Письменный scope и inventarization: какие администраторы, задачи `cron`, SSH/Plink/rinetd-сервисы, маршруты и точки подключения **разрешены**. Наличие `nc`, `ssh` или proxy само по себе недостаточно для вывода о компрометации. [p0293:c01](../../../rag/chunks/p0201-p0300/p0293-c01.md), [p0296:c01](../../../rag/chunks/p0201-p0300/p0296-c01.md)–[p0301:c01](../../../rag/chunks/p0301-p0400/p0301-c01.md).

## Interpretation

**Persistence ≠ отдельный инструмент**: важна причинно-временная последовательность — несанкционированный старт/перезапуск процесса, сетевой listener или соединение, незадокументированная точка перенаправления. Тип соединения определяет, что будет видно в логах. [p0293:c01](../../../rag/chunks/p0201-p0300/p0293-c01.md)–[p0301:c01](../../../rag/chunks/p0301-p0400/p0301-c01.md).

**SSH ≠ индикатор атаки**: легитимный защищённый доступ тоже использует туннелирование. Оценивать полномочия, назначения, экспонированные listening addresses и необходимость пересылки. [p0297:c01](../../../rag/chunks/p0201-p0300/p0297-c01.md)–[p0301:c01](../../../rag/chunks/p0301-p0400/p0301-c01.md).

**Пароль в командной строке** в авторском Plink-примере — секрет, подлежащий исключению из учебного отчёта. [p0301:c01](../../../rag/chunks/p0301-p0400/p0301-c01.md).

## Next action

Сверить обнаруженные persistent jobs/listeners/forwarders с разрешённым baseline и change records. Выполнять ограниченный review журналов/конфигураций, а не открывать новые туннели или тестировать обход файервола.

## Modifying action

- Автозапуск через `cron` или `rc.d`, открытие Netcat shell: **state-changing, remote-execution/persistence**, не запускать из конспекта. [p0294:c01](../../../rag/chunks/p0201-p0300/p0294-c01.md).
- Изменения rinetd и запуск сервиса: **local config + network forwarding**. [p0296:c01](../../../rag/chunks/p0201-p0300/p0296-c01.md).
- SSH `-L`, `-R`, `-D`, proxychains и Plink: **active network state**, возможное открытие доступа к внутренним ресурсам; исходные исполняемые маршруты не копируются. [p0298:c01](../../../rag/chunks/p0201-p0300/p0298-c01.md)–[p0301:c01](../../../rag/chunks/p0301-p0400/p0301-c01.md).
- Реакция/выключение найденного слушателя: **state-changing**; не делать без владельца системы и плана восстановления.
