# Команды и классы воздействия — глава 11 «Передача файлов»

**Источник:** canonical RAG `p0287:c01`–`p0292:c01`, PDF 287–292, SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`. Команды и флаги упоминаются **для распознавания описанных механизмов**; ни одна команда не запускалась. Примеры доставки `nc.exe`, интерактивного shell, FTP-сценариев с паролем и загрузки файлов с обходом политики не приводятся как исполняемые последовательности.

## Синтаксические следы, но не runbook

На [p0288:c01](../../../rag/chunks/p0201-p0300/p0288-c01.md) описаны `atftpd --daemon`, каталог `/root/tftp` и UDP 69, а в FTP-разделе `pure-ftpd`, `pure-pw`, `systemctl restart pure-ftpd`; все эти операции **изменяют локальную систему**. В источнике одновременно встречается установка `apt-get install pure-ftpd` и настройка системного пользователя. Не выполнять по отдельности без модели разрешений, инвентаря сервиса и rollback.

На [p0290:c01](../../../rag/chunks/p0201-p0300/p0290-c01.md) аргумент `-e` в примере Netcat используется для подключения командного интерпретатора. Это **высокорисковый контекст предоставления удалённой оболочки**, а не обычная передача данных; исполняемой строки нет.

В Windows-разделе есть термины `ftp -s` (пакетный сценарий), `cscript` (скрипт-хост), `ExecutionPolicy Bypass`, `NoLogo`, `NonInteractive`, `NoProfile` и `System.Net.WebClient`. Они помогают распознавать события в телеметрии, но не являются рекомендацией обойти настройки ОС. [p0291:c01](../../../rag/chunks/p0201-p0300/p0291-c01.md)–[p0292:c01](../../../rag/chunks/p0201-p0300/p0292-c01.md).

## Безопасные проверки без сетевого скачивания

При анализе **уже имеющихся разрешённых журналов** проверять: создание/перезапуск FTP/TFTP-службы, появление новых аккаунтов, права файлового каталога, исходящие HTTP-запросы, создание файла, запуск скриптов/процессов. Сохранять отдельно факт передачи, происхождение и факт исполнения; **не сохранять в Git пароли или исполняемые файлы**, представленные в книжных примерах.

- Работоспособность `atftpd`/Pure-FTPd и текущая установленность FTP/TFTP-клиента — **[Needs confirmation]**.

- Порядок полной очистки учётных записей, сетевых listeners, файлов, запускаемых сценариев и сетевых правил — **[Needs confirmation]**.
