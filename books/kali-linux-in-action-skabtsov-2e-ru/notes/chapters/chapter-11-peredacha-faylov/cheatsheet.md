# Cheatsheet — глава 11 «Передача файлов»

**RAG-only:** PDF 287–292, chunks `p0287:c01`–`p0292:c01`, source SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`.

## Symptom / problem framing

В организации может происходить **неожиданная передача файлов после удалённого доступа**, в том числе при ограниченной/неинтерактивной оболочке. Автор описывает TFTP, FTP, Netcat/PTY и средства Windows, показывая, что штатный инструмент может участвовать в посткомпрометационной цепочке. [p0287:c01](../../../rag/chunks/p0201-p0300/p0287-c01.md)–[p0292:c01](../../../rag/chunks/p0201-p0300/p0292-c01.md).

## Baseline / context

- **Scope:** тестировать только свои системы и специально разрешённые каналы; отдельно согласовывать изменение конфигурации FTP/TFTP и запуск загрузчиков. [p0287:c01](../../../rag/chunks/p0201-p0300/p0287-c01.md), [p0288:c01](../../../rag/chunks/p0201-p0300/p0288-c01.md).
- **Файлы:** только синтетические данные в защитной лаборатории. В исходнике переносится исполняемый `nc.exe` — не использовать его как обязательный результат. [p0288:c01](../../../rag/chunks/p0201-p0300/p0288-c01.md), [p0289:c01](../../../rag/chunks/p0201-p0300/p0289-c01.md).
- **Секреты:** книжный FTP-пример включает пароль в открытом тексте скрипта/ввода. Такие строки не переносить в Git или общий журнал. [p0289:c01](../../../rag/chunks/p0201-p0300/p0289-c01.md), [p0291:c01](../../../rag/chunks/p0201-p0300/p0291-c01.md).

## Interpretation

**Протокол передачи ≠ гарантия безопасности.** TFTP не имеет аутентификации по описанию автора; FTP в книге предлагает учётные записи, однако шифрование передачи/аутентификации не продемонстрировано. [p0287:c01](../../../rag/chunks/p0201-p0300/p0287-c01.md)–[p0289:c01](../../../rag/chunks/p0201-p0300/p0289-c01.md).

**Неинтерактивная оболочка ≠ невозможность загрузки.** Автор рассматривает пакетные FTP-операции и сценарные HTTP-клиенты. Защитный подход должен учитывать **целую цепочку действий**, но не превращаться в инструкцию её воспроизведения. [p0290:c01](../../../rag/chunks/p0201-p0300/p0290-c01.md)–[p0292:c01](../../../rag/chunks/p0201-p0300/p0292-c01.md).

**Наличие скачанного файла ≠ факт его исполнения.** В журнале расследования отдельно фиксировать источник, запись на диск, права и последующий запуск. Последнее — вывод для защитного учёта из описанных автором стадий, а не факт о конкретном инциденте.

## Next action

Проверить допустимость FTP/TFTP, наличие учетных записей, права каталогов и мониторинг загрузки. Для испытаний использовать отдельную лабораторию и невыполняемые тестовые файлы, проверить записи журналов и ограничения доступа. Доработать контроль исходящих обращений, распространения файлов и запуска скриптов.

## Modifying action

- Подъём **atftpd/Pure-FTPd**, создание пользователей, изменение прав, перезапуск: **state-changing**, возможно открытие сетевого слушателя. [p0288:c01](../../../rag/chunks/p0201-p0300/p0288-c01.md)–[p0289:c01](../../../rag/chunks/p0201-p0300/p0289-c01.md).
- Загрузка файла в скомпрометированной системе: **network + local state-changing**, потенциальная доставка исполняемого файла. [p0288:c01](../../../rag/chunks/p0201-p0300/p0288-c01.md), [p0292:c01](../../../rag/chunks/p0201-p0300/p0292-c01.md).
- **Netcat + PTY**: повышенное вмешательство в удалённый процесс и доступ к shell; не рассматривать как read-only проверку. [p0290:c01](../../../rag/chunks/p0201-p0300/p0290-c01.md).
- Пакетный FTP/VBScript/PowerShell: автоматизированная запись файлов, возможный обход защитной политики; **никаких готовых скриптов из главы**. [p0291:c01](../../../rag/chunks/p0201-p0300/p0291-c01.md)–[p0292:c01](../../../rag/chunks/p0201-p0300/p0292-c01.md).

## Verification / acceptance

- [ ] Разрешённый scope и владелец каждого тестового узла.
- [ ] Тестовые файлы не содержат программ-перехватчиков, вредоносных модулей и паролей.
- [ ] Источник и назначение каждой передачи зафиксированы.
- [ ] Права FTP/TFTP проверены, не нарушено состояние продуктивных служб.
- [ ] Отдельно проверены сетевой факт, запись на диск и запуск файла.
- [ ] Доступ к отчёту ограничен, реальные учётные данные и исполненные скрипты отсутствуют.
- [ ] Откат и очистка испытательной среды согласованы отдельно.
