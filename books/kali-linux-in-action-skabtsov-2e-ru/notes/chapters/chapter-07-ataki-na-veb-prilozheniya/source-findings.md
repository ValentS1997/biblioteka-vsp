# Source findings — глава 07 «Атаки на веб-приложения»

**Режим:** только текст канонического RAG (PDF pp. 207–241), source SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`. Противоречия отмечены как внутренние наблюдения/неоднозначности, не как подтверждённые исправления из внешних источников. PDF/RAG не менялись.

## F-01 · [Source wording ambiguity] · Cookie как «текстовый файл» и SSL

На [p0208:c01](../../../rag/chunks/p0201-p0300/p0208-c01.md) cookie описан как обычный текстовый файл с `параметр = значение` и утверждается, что «данные файла передаются по SSL-протоколу». В главе нет технического разбора атрибутов `Secure`, `HttpOnly`, `SameSite` или того, все ли cookie обязаны передаваться только при HTTPS. **Вывод:** обобщение автора нельзя трактовать как универсальное описание поведения всех браузеров/веб-приложений; конкретные настройки — **[Needs confirmation]**.

## F-02 · [Source code mismatch] · Тире в запуске Juice Shop

На [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md) строка `$sudo juice-shop –h` содержит символ **EN DASH `–`**, визуально похожий на обычный дефис `-`. В той же странице `sudo apt install juice-shop`; остановка указана отдельно на [p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md). Исполняемость строки запуска и значение `h` не подтверждены. **Решение:** сохранить исходную форму и не предлагать автоматически «исправленную» команду.

## F-03 · [Source attribution tension] · Equifax и Broken Access Control

На [p0215:c01](../../../rag/chunks/p0201-p0300/p0215-c01.md), [p0216:c01](../../../rag/chunks/p0201-p0300/p0216-c01.md) история Equifax 2017 приведена как пример Broken Access Control, при этом автор же пишет об уязвимости **Apache Struts**, позволявшей выполнить произвольный код на сервере, и связывает эту историю с нарушением контроля доступа. Причинная категоризация **не однозначна в пределах книги**; не утверждать без внешней проверки, что это один и тот же механизм. Фактическая история не проверена вне RAG-only.

## F-04 · [Source code/wording mismatch] · SQLi-пример `uses_id`

На [p0221:c01](../../../rag/chunks/p0201-p0300/p0221-c01.md) в SQL-демонстрации используется поле `uses_id` при таблице `users`; далее пример вводимой строки в текстовом слое содержит сочетания типографского тире и ASCII-комментариев `--`. Точное написание поля и работоспособность примера **[Needs confirmation]**. В `commands.md` сохраняется **механизм** небезопасной конкатенации, не воспроизводится payload для обхода входа.

## F-05 · [Source ambiguity] · HTTP 200 и удачная аутентификация

На [p0238:c01](../../../rag/chunks/p0201-p0300/p0238-c01.md) автор интерпретирует один ответ `200` среди ответов `401` как достоверно угаданную пару логин/пароль в лабораторном Burp Intruder. В текстовом RAG нет самостоятельной проверяемой связки с состоянием сессии и телом ответа в этом конкретном примере. **Вывод:** одно числовое состояние HTTP само по себе не доказывает успешную аутентификацию. Не подменять наблюдение книжного эксперимента универсальным критерием.

## F-06 · [Source extraction/code issue] · PHP- и файловые примеры

На [p0227:c01](../../../rag/chunks/p0201-p0300/p0227-c01.md)–[p0228:c01](../../../rag/chunks/p0201-p0300/p0228-c01.md) автор приводит цепочку включения локальных логов и обращений к файлам, но в извлечённом тексте есть `systen(` (вместо другого, не подтверждённого здесь имени функции), пространственные разрывы пути `access. log`, а также разная пунктуация в PHP URL-строке. **Решение:** не восстанавливать по догадке эксплойт-цепочку; код не входит в исполнимые команды этой коллекции.

## F-07 · [Needs confirmation] · Количественные и исторические утверждения

На [p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md) приводится оценка «около 94 % приложений» с Broken Access Control; [p0218:c01](../../../rag/chunks/p0201-p0300/p0218-c01.md) содержит описание Adobe 2013, а [p0230:c01](../../../rag/chunks/p0201-p0300/p0230-c01.md)–[p0231:c01](../../../rag/chunks/p0201-p0300/p0231-c01.md) — историю SolarWinds. В каноническом RAG нет воспроизводимой методики вычисления процента и независимых ссылок для проверки этих исторических деталей. **Решение:** упоминать их лишь как повествование автора; актуальная статистика и детали инцидентов **[Needs confirmation]**.
