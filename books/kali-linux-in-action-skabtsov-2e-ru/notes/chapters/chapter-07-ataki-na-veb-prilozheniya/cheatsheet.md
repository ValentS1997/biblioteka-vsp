# Cheatsheet · Глава 07 «Атаки на веб-приложения»

**Только RAG:** PDF pp. 207–241, chunks `p0207:c01`–`p0241:c01`, SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`.

## Symptom / problem framing

Приложение имеет HTTP API, cookie, пользовательские поля, загрузки, серверные зависимости и внутренние интеграции. Уязвимость может быть неочевидна по HTTP-статусу либо автоматическому отчёту. Критические области — **разделение полномочий, безопасная интерпретация ввода, сессии и безопасная конфигурация**. [p0208:c01](../../../rag/chunks/p0201-p0300/p0208-c01.md), [p0210:c01](../../../rag/chunks/p0201-p0300/p0210-c01.md), [p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md)–[p0241:c01](../../../rag/chunks/p0201-p0300/p0241-c01.md).

## Baseline / context

1. Допустим **только собственный изолированный Juice Shop или явно разрешённый веб-сервис**. Несколько тестовых учётных записей/объектов не означают допуск на чужие данные. [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md)–[p0215:c01](../../../rag/chunks/p0201-p0300/p0215-c01.md).
2. ZAP и Burp могут перехватывать/изменять трафик; при активном сканировании они создают нагрузку. Оставлять лабораторию на localhost, не экспортировать сессионные токены. [p0211:c01](../../../rag/chunks/p0201-p0300/p0211-c01.md), [p0233:c01](../../../rag/chunks/p0201-p0300/p0233-c01.md).
3. Выписать бизнес-роли, права, маршруты, параметры ввода, trust boundaries между клиентом, сервером и API. [p0209:c01](../../../rag/chunks/p0201-p0300/p0209-c01.md)–[p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md), [p0239:c01](../../../rag/chunks/p0201-p0300/p0239-c01.md).

## Interpretation

**HTTP 200 ≠ подтверждённая успешная аутентификация**, HTTP 401 — лишь признак отказа в контексте запроса, а «обнаружена SQLi/XSS» без ограниченного подтверждения не обязательно значит известное последствие. В книжном лабораторном примере успешный логин выведен из отличающегося кода ответа; без знания тела/состояния ответа этот вывод нельзя автоматически распространять. [p0238:c01](../../../rag/chunks/p0201-p0300/p0238-c01.md).

**Клиентские данные не авторитетны:** редактируемый cookie или файл с `.jpg` не доказывает принадлежность роли либо безопасный формат. [p0239:c01](../../../rag/chunks/p0201-p0300/p0239-c01.md).

## Next action

Подготовить для каждого класса веб-риска связку **сервис/маршрут → нарушенный контроль → наблюдение → контекст и ограничения → предлагаемое исправление → проверка исправления**. Предпочтительны ревью кода, тестовые данные и изолированный стенд, а не выполнение атак на продуктивных пользователей. [p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md)–[p0241:c01](../../../rag/chunks/p0201-p0300/p0241-c01.md).

## Modifying action

- `sudo apt install zaproxy` и `sudo apt install juice-shop`: локальная установка пакетов; state-changing. [p0211:c01](../../../rag/chunks/p0201-p0300/p0211-c01.md), [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md).
- `sudo juice-shop –h`: вероятно, содержит Unicode dash вместо ASCII — **[Source extraction issue]**, не копировать как проверенную строку. [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md).
- `sudo juice-shop-stop`: остановка учебного сервиса изменяет локальное состояние; проверка и rollback — [Needs confirmation]. [p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md).
- Использование прокси ZAP/Burp, ручной resend, Intruder, DAST, модификация сессий и загрузок: **workload-generating**, может читать или менять состояние целевого приложения; не считать read-only. [p0215:c01](../../../rag/chunks/p0201-p0300/p0215-c01.md), [p0233:c01](../../../rag/chunks/p0201-p0300/p0233-c01.md)–[p0238:c01](../../../rag/chunks/p0201-p0300/p0238-c01.md).
- Выполнение SQLi/XSS/LFI/RFI/XXE/SSRF и попытки перебора паролей в продуктивной системе — отдельно разрешаемые испытания, не шаг обычной инвентаризации. [p0221:c01](../../../rag/chunks/p0201-p0300/p0221-c01.md)–[p0241:c01](../../../rag/chunks/p0201-p0300/p0241-c01.md).

## Verification / acceptance checks

- [ ] Выбран только разрешённый лабораторный/тестовый target и тестовые учётные записи.
- [ ] Отделены наблюдение и доказанный эффект; тело ответа/состояние сессии проверены.
- [ ] Наличие cookie не заменяет серверного контроля ролей.
- [ ] SQL/HTML/шаблоны/командная строка не получают необработанные пользовательские данные.
- [ ] Загрузки файлов и серверные URL ограничены допустимыми ресурсами.
- [ ] Компоненты и зависимости инвентаризированы; данные об их версиях не выдаются за актуальные без проверки.
- [ ] Логи защищены, объём соразмерен возможностям разбора.
- [ ] Отчёт не содержит паролей, API-ключей, действующих session IDs или чужих данных.
