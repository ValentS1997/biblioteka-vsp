# Команды, методы и эффекты — глава 07

**Provenance:** canonical RAG `p0207:c01`–`p0241:c01`, PDF pp. 207–241, source SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`. Команды не выполнялись; работоспособность в актуальных версиях Kali/OWASP **[Needs confirmation]**.

## Явные CLI-команды в источнике

| Синтаксис по RAG | Тип | Условия / результат / rollback |
|---|---|---|
| `sudo apt install zaproxy` | **State-changing, local** | Автор предлагает установить OWASP ZAP и после первого запуска обновить базу. Проверять изоляцию и доступность конкретного пакета; rollback не дан — [Needs confirmation]. [p0211:c01](../../../rag/chunks/p0201-p0300/p0211-c01.md) |
| `sudo apt install juice-shop` | **State-changing, local** | Автор устанавливает **намеренно уязвимый** учебный сервер; **не выставлять в общедоступную сеть**. Проверить выбранный локальный адрес, версию пакета — [Needs confirmation]. [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md) |
| `sudo juice-shop –h` | **State-changing / workload-generating**, **[Source code mismatch]** | Текст обозначает запуск Juice Shop, но содержит Unicode `–` перед `h`. **Не выполнять дословно** без проверки имени команды и значения аргумента. [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md) |
| `sudo juice-shop-stop` | **State-changing local service** | В книге остановка Juice Shop после опыта. Проверять процесс/отсутствие публичного слушателя; актуальное имя команды и rollback — [Needs confirmation]. [p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md) |

**Лабораторные URI из книги:** `http://localhost:42000` — адрес Juice Shop по тексту; `127.0.0.1:8080` — локальный proxy ZAP/Burp в демонстрации. Для входа в интерфейс **использовать только локальный разрешённый стенд**. Текущие порты и формы URL — [Needs confirmation]. [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md), [p0214:c01](../../../rag/chunks/p0201-p0300/p0214-c01.md), [p0233:c01](../../../rag/chunks/p0201-p0300/p0233-c01.md).

## HTTP/REST без эксплуатации

| HTTP method из RAG | Назначение по книге | Класс / оговорки |
|---|---|---|
| `GET`, `HEAD` | Чтение представления/заголовков | Обычно read-only по семантике, **но реальное побочное действие зависит от реализации API**, а запрос создаёт сетевой трафик. [p0209:c01](../../../rag/chunks/p0201-p0300/p0209-c01.md)–[p0210:c01](../../../rag/chunks/p0201-p0300/p0210-c01.md) |
| `OPTIONS` | Возможности ресурса | Read-oriented запрос к серверу; не заменяет проверку правил авторизации. [p0210:c01](../../../rag/chunks/p0201-p0300/p0210-c01.md) |
| `POST`, `PUT`, `PATCH`, `DELETE` | Создание, изменение или удаление | **State-changing по назначению**; даже в тестовом стенде использовать только с разрешёнными объектами. [p0209:c01](../../../rag/chunks/p0201-p0300/p0209-c01.md)–[p0210:c01](../../../rag/chunks/p0201-p0300/p0210-c01.md) |
| `CONNECT`, `TRACE` | Прокси-туннель / диагностический echo | Потенциальное влияние и доступность различаются; **не выполнять на чужих сервисах**. [p0210:c01](../../../rag/chunks/p0201-p0300/p0210-c01.md) |

## Интерфейсы (не CLI)

- **OWASP ZAP:** HTTP(S)-прокси, история запросов, анализ локального Juice Shop, ручные/автоматические проверки; любые resend и scan — **workload-generating / могут модифицировать тестовое приложение**. [p0211:c01](../../../rag/chunks/p0201-p0300/p0211-c01.md)–[p0215:c01](../../../rag/chunks/p0201-p0300/p0215-c01.md).
- **Burp Suite:** Proxy, Spider, Scanner, Intruder, Repeater, Sequencer, Decoder, Comparer — набор GUI-функций, описанных в [p0233:c01](../../../rag/chunks/p0201-p0300/p0233-c01.md). Просмотр HTTP History безопаснее автоматизированного тестирования, но всё равно обрабатывает **секреты**; их не коммитить.
- **Juice Shop:** имитация магазина с учебными заданиями/CTF, роль тестовых пользователей и корзин. Изолированная лаборатория допустима, но не является тестовой лицензией на любые публичные веб-приложения. [p0212:c01](../../../rag/chunks/p0201-p0300/p0212-c01.md)–[p0215:c01](../../../rag/chunks/p0201-p0300/p0215-c01.md).

## Описанные атаки — только классификация и контроль

| Категория | Технический риск и защитная проверка |
|---|---|
| Broken Access Control / IDOR | Сверять серверные полномочия и ownership ресурсов, не доверять клиентскому ID. [p0213:c01](../../../rag/chunks/p0201-p0300/p0213-c01.md)–[p0215:c01](../../../rag/chunks/p0201-p0300/p0215-c01.md) |
| Cryptographic Failures | Не использовать слабые хеш-функции для паролей, защитить ключи и сессии. [p0217:c01](../../../rag/chunks/p0201-p0300/p0217-c01.md)–[p0220:c01](../../../rag/chunks/p0201-p0300/p0220-c01.md) |
| SQLi / Code/Command Injection / LFI/RFI / XXE | Контролировать ввод до выполнения SQL, шаблонов, команд и файловых операций, без публикации payloads для эксфильтрации. [p0220:c01](../../../rag/chunks/p0201-p0300/p0220-c01.md)–[p0230:c01](../../../rag/chunks/p0201-p0300/p0230-c01.md) |
| XSS | Защищать обработку/рендеринг пользовательских данных и DOM; токены не включать в примеры. [p0224:c01](../../../rag/chunks/p0201-p0300/p0224-c01.md) |
| Auth/session failures | Защищать сессионные идентификаторы, предусматривать обновление сессии; не воспроизводить подбор чужих паролей. [p0231:c01](../../../rag/chunks/p0201-p0300/p0231-c01.md)–[p0238:c01](../../../rag/chunks/p0201-p0300/p0238-c01.md) |
| Integrity / misconfiguration / supply chain | Подтверждать права на сервере, проверять файлы/пакеты/конфигурации. [p0229:c01](../../../rag/chunks/p0201-p0300/p0229-c01.md)–[p0240:c01](../../../rag/chunks/p0201-p0300/p0240-c01.md) |
| Logging and monitoring | Собирать достаточные, защищённые и анализируемые события. [p0240:c01](../../../rag/chunks/p0201-p0300/p0240-c01.md)–[p0241:c01](../../../rag/chunks/p0201-p0300/p0241-c01.md) |
| SSRF | Ограничивать доступные серверу направления запросов и проверять внешние URL. [p0241:c01](../../../rag/chunks/p0201-p0300/p0241-c01.md) |

**RAG-only restriction:** в книге есть примеры SQL-подмены логина, LFI с log injection, массового credential guessing и SSRF на внутренние адреса. Они служат **иллюстрациями рисков**, но здесь **не копируются в готовые исполняемые цепочки**, не требующиеся для изучения принципа и принятия защитных мер.

## Readback / rollback

Ни одна команда или сетевая проверка не запускалась. Автор не даёт воспроизводимый rollback для PHP/SQL действий, перехваченных сессий и результатов bruteforce; это **[Needs confirmation]**. Дополнительные неоднозначности перечислены в [source-findings.md](source-findings.md).
