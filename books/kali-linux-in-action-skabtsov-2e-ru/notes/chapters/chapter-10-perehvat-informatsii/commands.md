## Безопасное офлайн-чтение заранее разрешённого capture-файла

| Фрагмент из источника | Класс | Применение / ограничение |
|---|---|---|
| `tcpdump -n -r /root/tcpump.cap` | **Read-only local PCAP** | Сводный просмотр пакетов из существующего файла, без генерации новых сетевых запросов; источник показывает этот набор опций совместно с `awk`/`sort`/`head`. [p0278:c01](../../../rag/chunks/p0201-p0300/p0278-c01.md) |
| `tcpdump -n port 80 -r /root/tcpump.cap` | **Read-only local PCAP** | Отбор по порту TCP/UDP в учебном дампе, может включать метаданные незашифрованного HTTP. [p0279:c01](../../../rag/chunks/p0201-p0300/p0279-c01.md) |
| `tcpdump -nX -r /root/tcpump.cap` | **Read-only local PCAP, sensitive output** | Отображение HEX/ASCII содержимого ранее записанного трафика; может вывести cookies, параметры запросов и персональные данные — не сохранять вывод в открытых файлах. [p0280:c01](../../../rag/chunks/p0201-p0300/p0280-c01.md) |
| `tcpdump -A -n 'tcp[13] = 24' -r /root/tcpump.cap` | **Read-only local PCAP, sensitive output** | В книге для TCP PSH+ACK; результат содержит приложенческие данные, поэтому в отчёте — только минимально достаточные обезличенные метаданные. [p0281:c01](../../../rag/chunks/p0201-p0300/p0281-c01.md) |

**Примечание:** `/root/tcpump.cap` — **учебный путь из автора**. Файл должен уже законно существовать в собственной лаборатории; команды не выполнялись. Реальные дампы и их выводы в Git не включаются.

## Wireshark: два разных фильтра

- **Capture filter (во время захвата):** `net 192.168.91.0/24` — адрес лабораторного примера. Выбор интерфейса и запуск захвата создают файл/данные и относятся к **наблюдению сети**, не к обычному просмотру. [p0274:c01](../../../rag/chunks/p0201-p0300/p0274-c01.md).
- **Display filter (на уже записанных пакетах):** `http && ip.addr == 192.168.91.128`, `tcp.port eq 80`, `frame.len >= 100`. Работает с отображением данных, не сокращает исходный PCAP. [p0275:c01](../../../rag/chunks/p0201-p0300/p0275-c01.md), [p0276:c01](../../../rag/chunks/p0201-p0300/p0276-c01.md).
- **Follow HTTP stream:** в авторском тексте название извлечено с опечаткой `steram`; предназначено для удобного объединения данных потока, что повышает риск вывода секретов в открытых запросах. [p0276:c01](../../../rag/chunks/p0201-p0300/p0276-c01.md), [p0277:c01](../../../rag/chunks/p0201-p0300/p0277-c01.md).

## Live capture и активные изменения — не runbook

| Класс действия | Суть и последствия |
|---|---|
| `tcpdump -w /root/tcpump.cap` | **State-changing + network observation**: записывает наблюдаемые пакеты; чувствительное содержимое, расход места, политика допуска. [p0278:c01](../../../rag/chunks/p0201-p0300/p0278-c01.md) |
| `sudo wiresark` | **[Source code mismatch]**: буквальное написание команды конфликтует с названием Wireshark в том же тексте; не исполнять как проверенную команду. [p0274:c01](../../../rag/chunks/p0201-p0300/p0274-c01.md) |
| **CAM table overflow / macof** | **Active network manipulation**: насыщение коммутационного состояния и риск деградации/отказа; исходная атака не переносится в исполняемую процедуру. [p0282:c01](../../../rag/chunks/p0201-p0300/p0282-c01.md)–[p0283:c01](../../../rag/chunks/p0201-p0300/p0283-c01.md) |
| **Ettercap / ARP poisoning, DHCP spoofing, ICMP redirect, port stealing** | **Active network manipulation**: изменение обмена, возможно нарушение доступности и конфиденциальности; перечень угроз без команд, адресов и последовательности выбора целей. [p0283:c01](../../../rag/chunks/p0201-p0300/p0283-c01.md)–[p0286:c01](../../../rag/chunks/p0201-p0300/p0286-c01.md) |
| **Изменение MAC интерфейса** | **State-changing local/network**: в книге показаны отключение интерфейса и изменение адреса; запуск может обрывать связь. Не включать способ обхода port-security. [p0286:c01](../../../rag/chunks/p0201-p0300/p0286-c01.md) |

## Прочие термины и проверка

- `-n` подавляет резолвинг имён в демонстрационном выводе; `-r` читает существующую запись; `-A` и `-X` выводят содержимое, которое может включать секреты. Конкретная поддержка/версия — **[Needs confirmation]**. [p0278:c01](../../../rag/chunks/p0201-p0300/p0278-c01.md)–[p0281:c01](../../../rag/chunks/p0201-p0300/p0281-c01.md).
- Исходные строки `tcpdump` и Wireshark являются примерами по книге; корректность протокольной интерпретации и окружающих команд фиксируется через [source-findings.md](source-findings.md).
- **Rollback:** [Needs confirmation] — книга не даёт безопасной процедуры восстановления после активных вмешательств. Команды в этом файле допускают только чтение **существующего лабораторного PCAP**, без новых атак.
