# Cheatsheet — глава 15 «Переполнение буфера»

**Канонический RAG:** PDF 332–360; `p0332:c01`–`p0360:c01`; SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`.

## Symptom / problem framing

Программа повреждает память при обработке недоверенного ввода: строка, сеть, файл, CLI и переменные окружения. В книге последствия варьируются от неверного ответа до аварии и потенциального нарушения управления исполнением. [p0333:c01](../../../rag/chunks/p0301-p0400/p0333-c01.md), [p0334:c01](../../../rag/chunks/p0301-p0400/p0334-c01.md).

## Baseline / context

**Scope:** разрешённое приложение, версия/платформа/архитектура, доступ к коду и журналам, текущие средства смягчения, тестовая среда и безопасное восстановление. Историческая демонстрация Easy File Sharing Web Server 7.2 **не подтверждает** современную эксплуатируемость и **не должна** запускаться на продуктивной цели. [p0349:c01](../../../rag/chunks/p0301-p0400/p0349-c01.md)–[p0360:c01](../../../rag/chunks/p0301-p0400/p0360-c01.md).

## Interpretation

| Наблюдение | Возможный смысл | Что нельзя выводить |
|---|---|---|
| Сбой после длинного GET | Требуется анализ memory safety | Не доказывает RCE [p0352:c01](../../../rag/chunks/p0301-p0400/p0352-c01.md) |
| Искажение регистров/SEH в отладчике | Возможное повреждение управляющей структуры | Не гарантирует выполнение стороннего кода [p0354:c01](../../../rag/chunks/p0301-p0400/p0354-c01.md) |
| Off-by-one | Ошибка границ на единицу | Не всякая такая ошибка перезаписывает return address [p0345:c01](../../../rag/chunks/p0301-p0400/p0345-c01.md) |
| Return-into-libc | Модель использования существующего кода | Не универсальный обход всех защит [p0347:c01](../../../rag/chunks/p0301-p0400/p0347-c01.md) |
| Обнаруженный статический адрес модуля | Возможная особенность отдельного стенда | Не доказательство отсутствия ASLR во всей системе [p0356:c01](../../../rag/chunks/p0301-p0400/p0356-c01.md) |

## Next action

Документировать обработку размера ввода, возможное переписывание за границей, область памяти и доступные полномочия процесса. При необходимости собирать **неэксплуатирующие** crash-свидетельства только в изолированной разрешённой лаборатории. Исправить проверку длины и провести регрессионную проверку корректного отказа.

## Modifying/high-risk actions

- Spike/Burp Intruder against service: **active fuzzing / workload**, риск отказа. [p0350:c01](../../../rag/chunks/p0301-p0400/p0350-c01.md)–[p0352:c01](../../../rag/chunks/p0301-p0400/p0352-c01.md).
- Debugger attach/настройка процесса: **локальное вмешательство в работающий процесс**, в некоторых случаях меняет его состояние. [p0352:c01](../../../rag/chunks/p0301-p0400/p0352-c01.md).
- Отправка специально подготовленного HTTP-буфера для повреждения SEH: **active exploitation/DoS**. [p0354:c01](../../../rag/chunks/p0301-p0400/p0354-c01.md)–[p0360:c01](../../../rag/chunks/p0301-p0400/p0360-c01.md).
- Shellcode, POP/POP/RET и reverse-shell generation: **code execution / post-compromise**, не публикуются как инструкции. [p0355:c01](../../../rag/chunks/p0301-p0400/p0355-c01.md)–[p0360:c01](../../../rag/chunks/p0301-p0400/p0360-c01.md).
