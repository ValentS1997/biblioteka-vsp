# Инструменты, команды и эффект — глава 15 «Переполнение буфера»

**Источник:** RAG `p0332:c01`–`p0360:c01`, PDF 332–360, SHA-256 `fa3cfb6d7dc9af0354a5c908e606626629929ae54b646ca4eaaa11b7868eb1b9`. Все команды и утилиты — **упоминания из книги, а не фактически выполненные проверки**. Полные исходные цепочки fuzz → SEH overwrite → shellcode → remote shell намеренно не воспроизводятся.

## Defensive checks (без запуска атаки)

Проверять **исходный код** на отсутствие проверок длины и ошибок на единицу, корректность выделения памяти и освобождения, недоверенные входы и привилегии процесса. Для учебных crash-логов фиксировать факт сбоя и отображение статуса без составления вредоносного ввода. Конкретные read-only shell-команды для инструментального определения защиты **в RAG не даны**: **[Needs confirmation]**; здесь не придумываются.

## Source discrepancies relevant to execution

В исходнике на [p0354:c01](../../../rag/chunks/p0301-p0400/p0354-c01.md) применяется Python 3, но часть операций содержит **`str` вместе с `bytes`**, а на [p0358:c01](../../../rag/chunks/p0301-p0400/p0358-c01.md)–[p0360:c01](../../../rag/chunks/p0301-p0400/p0360-c01.md) уже показан другой формат буфера. Конкретные длины и смещения меняются между иллюстрациями [p0352:c01](../../../rag/chunks/p0301-p0400/p0352-c01.md), [p0355:c01](../../../rag/chunks/p0301-p0400/p0355-c01.md), [p0359:c01](../../../rag/chunks/p0301-p0400/p0359-c01.md). Полная строка издания не должна приниматься за проверенное воспроизводимое выполнение. См. [source-findings.md](source-findings.md).

**Rollback:** **[Needs confirmation]**; любые реальные сетевые/отладочные проверки требуют собственного согласованного плана восстановления, и ни одна команда отсюда не запускалась.
