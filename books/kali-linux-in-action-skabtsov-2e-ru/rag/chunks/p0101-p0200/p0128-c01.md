Сканирование портов     127

написанных на языке Lua скриптов. Скрипты облегчают выполнение таких за
дач, как сбор информации о сервисах, обнаружение уязвимостей и проведение
сложных атак, делая nmap более гибким и мощным инструментом. Приведем
несколько примеров использования NSE для облегчения аудита информаци
онных систем.

zz Сбор информации о сервисах. Происходит сканирование всех хостов в ука
   занной подсети и вывод заголовко веб-страниц, размещенных на порте 80:

    #nmap -p 80 --script http-title 192.168.1.0/24

zz Обнаружение уязвимостей. В этом примере namp ищет уязвимость MS17-
   010 (EternalBlue) в SMB-сервисе хостов указанной подсети:

    #nmap -p 445 --script smb-vuln-ms17-010 192.168.1.0/24

zz Подбор пары логин и пароль. Nmap проводит брутфорс-атаки на SSH-
   серверы в указанной подсети, используя список имен пользователей (users.
   txt) и паролей (pass.txt):

   #nmap -p 22 --script ssh-brute --script-args userdb=users.txt,passdb=pass.txt
   192.168.1.0/24

Другие параметры
Ниже приводится список других популярных параметров запуска nmap с крат
кими комментариями:

zz -v — увеличивает уровень подробности отчета. Можно использовать -vv
  или –vvv: nmap - vv 192.168.1.1;
zz -T — позволяет настроить скорость сканирования. T0 является самым мед
   ленным, а T5 самым быстрым: nmap -T4 192.168.1.1;
zz -Pn — сообщает nmap о том, что хост доступен, и сразу переходит к скани
   рованию портов, минуя этап обнаружения хоста. Это может быть полезно
   в случае, когда блокируются ICMP-запросы;
zz -iL — определяет файл с перечнем целей для дальнейшего сканирования:
   nmap -iL targets.txt;
zz -oN — сохраняет результаты сканирования в текстовый файл: nmap -oN
   output.txt 192.168.1.1;
zz -oX — сохраняет результаты сканирования в формате XML: nmap -oX output.
   xml 192.168.1.1;
zz -6 — используется для сканирования IPv6-адресов: nmap -6 IPv6_адрес;
zz -D — позволяет имитировать «зомби»-хосты для обфускации источника
   сканирования: nmap -D RND:10 [цель];
zz -sF, -sX, -sN — набор используется для выполнения скрытого сканирования
