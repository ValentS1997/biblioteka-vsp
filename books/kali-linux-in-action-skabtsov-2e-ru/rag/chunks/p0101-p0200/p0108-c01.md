Скрытый интернет     107

Теперь необходимо сконфигурировать Firefox для корректной работы с сетью.
В нашем случае маршрутизатор I2P будет работать как прокси-сервер для бра
узера. Откройте настройки Network Proxy в Firefox и укажите адрес 127.0.0.1 для
HTTP- и HTTPS-соединений, порт 4444 (рис. 3.57).

                Рис. 3.57. Настройки прокси-сервера в Firefox

После несложной настройки вам станет доступна графическая консоль управле
ния маршрутизатором (рис. 3.58). Обычно начинающие пользователи сталкива
ются с двумя проблемами. Первая — это настройки сети, в Kali Linux файервол
по умолчанию отключен, а вот на домашнем маршрутизаторе нужные порты
могут быть закрыты. Вторая — сайт может быть недоступен, пока вы не добавите
его в адресную книгу, это можно сделать в настройках роутера.
