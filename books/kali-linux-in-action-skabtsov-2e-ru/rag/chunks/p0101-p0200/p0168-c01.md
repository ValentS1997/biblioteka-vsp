Работа с данными, визуализация     167

     Рис. 5.7. Начальная страница Dradis с информацией о тестовом проекте

Для начала познакомимся с панелью управления, она находится слева. В раз
деле All issues (рис. 5.8) вы можете создать новую задачу, загрузить в Dradis
полученные с помощью другого инструмента данные или результат из библи
отеки.
Раздел методики (Methodologies) (рис. 5.9). Существует множество методик про
ведения тестов на проникновение, разработанных различными организациями.
По сути, методика — это набор необходимых шагов, после прохождения кото
рых вы можете сказать, что выполнили тест на проникновение. По умолчанию
в Dradis практически нет методик, но с официального сайта вы можете загрузить
следующие:

zz OSSTMM v3;
zz OWASP Top 10;
zz SANS;
zz OSCP
и другие.
