Получение данных с использованием SMB     141

Попробуем получить список ресурсов, предоставляемых одной из машин:

 C:\Users\test>net view \\AURUM
 Shared resources at \\AURUM
 Share name  Type  Used as  Comment
 -------------------------------------
 Mobile      Disk  Public access
 Test        Disk
 The command completed successfully.

А теперь получим список учетных записей на удаленной машине:

 C:\Users\test>nbtstat -A 192.168.10.56
 Local Area Connection:
 Node IpAddress: [192.168.10.56] Scope Id: []
 NetBIOS Remote Machine Name Table
        Name               Type         Status
     ---------------------------------------------
     AURUM       <00>  UNIQUE      Registered
     LINDA         <00>  GROUP       Registered
     SILVIJA       <20>  UNIQUE      Registered

     MAC Address = 00-E6-43-21-DE-1D

Если вы являетесь пользователем Linux, самым простым способом для полу
чения полной информации, предоставляемой SNMP-агентом, будет использо
вание утилиты enum4linux. Данная утилита позволяет получить всю возмож
ную информацию о системах под управлением ОС Windows и Linux-серверах
с установленным сервисом Samba.
Продемонстрируем работу данной программы и посмотрим, какие данные нам
удалось собрать:

 itsecbook@kali:~#   enum4linux 192.168.91.5
