 root@kali:~# cp /usr/share/windows-binaries/nc.exe /home/ftpusers/joe/

Указанная последовательность команд обеспечивает установку и настройку
сервера FTP на Kali Linux с использованием Pure-FTPd. Ниже приводится
краткое описание команд:
zz apt-get install pure-ftpd — установка Pure-FTPd;
zz groupadd ftpgroup — создание новой группы с названием ftpgroup;
zz useradd -g ftpgroup -d /dev/null -s /etc ftpuser — создание нового поль
   зователя с именем ftpuser, добавляем его в группу ftpgroup. В качестве до
   машнего каталога указываем /dev/null;
zz mkdir /home/ftpusers и mkdir /home/ftpusers/joe — создание новых катало
   гов. Первая создает каталог для FTP-пользователей, а вторая создает под
   каталог для пользователя по имени Joe;
zz pure-pw useradd joe -u ftpuser -d /home/ftpusers/joe — добавление ново
   го пользователя в Pure-FTPd с именем Joe, правами системного пользователя
   ftpuser и домашним каталогом в /home/ftpusers/joe;
zz pure-pw mkdb — создание новой базы данных паролей для Pure-FTPd;
zz ln -s /etc/pure-ftpd/conf/PureDB /etc/pure-ftpd/auth/PureDB — создание
   символической ссылки на конфигурационный файл PureDB в каталоге auth;
zz chown -hR ftpuser:ftpgroup /home/ftpusers/ — смена владельца каталога
  и всех его подкаталогов на ftpuser и группы на ftpgroup;
zz systemctl restart pure-ftpd — перезапуск сервиса Pure-FTPd;
zz cp /usr/share/windows-binaries/nc.exe /home/ftpusers/joe/ — копирование
   исполняемого файла nc.exe в домашний каталог пользователя Joe;
zz ftp localhost — подключение к FTP-серверу, запущенному на нашей машине.

Итак, мы установили и сконфигурировали сервис, а также создали домашнюю
директорию и пользователя. Затем мы протестировали наш сервер и убедились
в его работоспособности.
