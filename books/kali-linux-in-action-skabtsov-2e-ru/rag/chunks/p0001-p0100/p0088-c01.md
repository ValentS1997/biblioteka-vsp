               Рис. 3.46. Информация о модуле google_site_web

Как видно из описания, данный модуль осуществляет поиск в Google с исполь
зованием оператора site, и для его установки нам не нужен ключ API.
Попробуем установить модуль hackertarget при помощи команды marketplace
install.
Для загрузки модуля необходимо выполнить команду module load, после этого
вы сможете посмотреть более подробную информацию о модуле и параметрах
для его использования при помощи команды info (рис. 3.47).
