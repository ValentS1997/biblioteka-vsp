88     Глава 03   •  Сбор открытой информации о цели

После того как мы установили необходимый модуль и получили информацию
о параметрах запуска, попробуем узнать больше о домене uni-lj.si. Для этого не
обходимо задать параметр командой options set SOURCE uni-lj.si и запустить
поиск командой run (рис. 3.48).

                   Рис. 3.48. Информация о домене uni-lj. si

Мы собрали информацию о хостах, которые принадлежат указанному домену,
попробуем просмотреть ее в более удобном виде с помощью команды show
(рис. 3.49).
