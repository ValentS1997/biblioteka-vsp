## Основной принцип

Алгоритм — только малая часть ML-системы: кроме него нужны бизнес-требования, данные, интерфейс, инфраструктура, мониторинг и обновление модели. Для производственного применения необходим системный взгляд. [p0024-c01; p0045-c01]

## Карта

1. **Когда использовать ML?** Сложные закономерности, доступные данные, прогнозирование новых случаев, повторяемость, стоимость ошибок и экономическая обоснованность; альтернатива — простые правила. [p0026-c01; p0027-c01; p0029-c01; p0030-c01]
2. **Варианты применения.** Потребительские и корпоративные сценарии; прогнозирование спроса и оттока. [p0031-c01 — p0034-c01]
3. **Исследования против производства.** Компромиссы между целями стейкхолдеров, latency/throughput, изменчивыми данными, объективностью и интерпретируемостью. [p0035-c01; p0038-c01; p0040-c01 — p0043-c01]
4. **ML против традиционного ПО.** Помимо кода нужно контролировать данные, модель, инфраструктуру, мониторинг и обновления. [p0043-c01; p0044-c01]
5. **Итоги.** Авторский заключительный раздел: PDF 45, p0045-c01.
