Текстовый формат или двоичный?

CSV и JSON — текстовые файлы, в то время как файлы Parquet — двоичные. Тек
стовые файлы — это файлы, представленные в виде обычного текста. Обычно это
значит, что они читабельны для человека. Двоичные файлы — общее название для
всех нетекстовых файлов. Как следует из этого названия, чаще всего двоичные
файлы представляют собой файлы, содержащие только нули и единицы. Они нуж
ны для чтения или использования программами, способными интерпретировать
необработанные байты. Программа должна точно знать расположение данных
внутри двоичного файла, чтобы его использовать. Если вы откроете текстовые
файлы в текстовом редакторе (например, VS Code или Notepad), то сможете прочи
тать содержащийся в них текст. При открытии двоичного файла в текстовом редак
торе вы увидите блоки с числами, скорее всего, в шестнадцатеричных значениях,
соответствующими байтам файла.
