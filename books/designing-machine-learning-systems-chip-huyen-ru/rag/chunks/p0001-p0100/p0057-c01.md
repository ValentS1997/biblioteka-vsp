Модель для классификации электронной почты может стать регрессивной, если мы
заставим ее выводить значения от 0 до  1, а также определим пороговое значение,
для которого письмо будет считаться спамом (рис. 2.4).

                         Рис. 2.4. Задачу классификации электронной почты
                    можно оформить как задачу для регрессивной модели

Бинарная или мультиклассовая классификация?

В классификационных задачах чем меньше классов требуется классифицировать,
тем задача проще. Самое простое — бинарная классификация только с двумя воз
можными классами. В качестве примеров можно привести определение, является
комментарий токсичным или нет, показало ли сканирование легких признаки рака,
относится ли транзакция к мошеннической и т. п. Неясно только, насколько этот
тип задач распространен в отрасли. Он в целом популярен по своей природе или
просто потому, что ML-специалистам удобнее с ним справляться.

Если существует больше двух классов, задача становится мулътиклассовой. С би
нарными задачами намного проще, чем с мультиклассовыми. Например, вычисле
ние F1 и визуализация матрицы ошибок интуитивно понятнее, когда есть только
два класса.

При большом количестве классов — например, при диагностике заболеваний с ты
сячами болезней или при классификации десятков тысяч продуктов, — мы гово
рим, что задача классификации имеет множество элементов. Такие задачи могут
быть очень сложными. Главная проблема заключается в сборе данных. По моему
опыту, ML-моделям требуется не менее сотни примеров для каждого класса, чтобы
научиться его определять и классифицировать. То есть если у вас тысяча классов,
вам нужно по меньшей мере 100 тысяч примеров. Для редких классов сбор данных
может быть затруднен. Вполне вероятно, что среди тысячи классов несколько ока
жутся редкими.
