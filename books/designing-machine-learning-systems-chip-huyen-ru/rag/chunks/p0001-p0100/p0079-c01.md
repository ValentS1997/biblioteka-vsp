Важный факт об SQL, который необходимо отметить, — это декларативный язык,
в отличие от Python, который является императивным. В императивной парадигме
вы уточняете шаги, необходимые для реализации действия, и компьютер выполня
ет эти шаги, чтобы получить выходные данные. В декларативной парадигме вы
указываете желаемые выходные данные, а компьютер сам вычисляет необходимые
для их получения шаги.

То есть, работая с базой данных SQL, вы задаете желаемый паттерн данных: табли
цы, из которых хотите получить данные, условия, которым должны соответство
вать результаты, базовые трансформации данных — такие как объединение, сорти
ровка, группировка, агрегирование и т. п. (но не способ извлечения данных). А сис
тема базы данных самостоятельно принимает решение, как разбить запрос на
разные части, какие методы использовать для выполнения каждого элемента запро
са и в каком порядке необходимо выполнять различные части этого запроса.

С определенными добавленными признаками база данных SQL может стать Тью-
ринг-полной (https://oreil.Iy/npL5B). Это  значит, что SQL теоретически можно
использовать для решения вычислительных задач без гарантий относительно тре
буемого времени или памяти. Но на практике не всегда легко написать и выполнить
запрос для решения конкретной задачи. Любой, кто работает с базами данных SQL,
может вспомнить о мучительно длинных SQL-запросах, которые невозможно по
нять и которые никто не хочет трогать из-за боязни в них что-нибудь сломатьЕ.

Выяснение того, как сделать произвольный запрос, — это сложная задача, выпол
нением которой занимается оптимизатор запросов. Он анализирует всевозможные
способы выполнения запроса и определяет самый быстрый из них5. Для улучшения
оптимизаторов запросов можно задействовать ML-систему, обучив ее на входящих
запросах6. Оптимизация запросов — одна из самых сложных задач в системах баз
данных. В свою очередь, нормализация базы означает, что данные в ней распре
делены по нескольким отношениям, что делает объединение еще сложнее. Хотя
оптимизация и сложна, хороший ее момент в том, что обычно нужен только один
оптимизатор запросов, который могут использовать все приложения.
