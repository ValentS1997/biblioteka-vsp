58          |  Гпава 2

Несколько способов сформулировать задачу

Изменение способа сформулировать задачу может значительно усложнить или уп
ростить ее. Рассмотрим задачу прогнозирования того, какое приложение владелец
смартфона захочет использовать в следующий раз. Сходу можно было бы сформу
лировать задачу как мультиклассовую классификацию: проанализировать признаки
пользователя и среды (демографические данные, время, расположение, история ис
пользования других приложений) в качестве вводных данных и определить вывод
в качестве распределения  вероятностей отдельно для каждого приложения на
смартфоне пользователя. Пусть Добудет количеством приложений, которые вы пла
нируете рекомендовать пользователю. В таком случае для этого пользователя
в конкретный момент времени нужно сделать всего один прогноз, и он представля
ет собой вектор размера N. Этот процесс показан на рис. 2.5.

              Рис. 2.5. Вы можете сформулировать задачу прогнозирования приложения,
             которое пользователь может открыть следующим, как задачу классификации.
             Вводные данные, признаки пользователя и среды Выходными данными
               будет распределение вероятностей по всем приложениям на смартфоне

Это плохой вариант, поскольку всякий раз, когда появляется новое приложение,
вероятнее всего придется переучивать модель с нуля или по крайней мере пере
учивать все компоненты модели, число параметров которых зависит от N. Лучше
сформулировать задачу как регрессионную. Вводные данные — это признаки поль
зователя, среды и приложения. На выходе будет значение от 0 до  1. Чем выше зна
чение, тем больше вероятность, что пользователь откроет это приложение. В таком
случае для этого пользователя в конкретный момент времени нужно сделать про
гноз (по одному на каждое приложение), но каждый прогноз представляет собой
просто число. Процесс этот показан на рис. 2.6.

В этом случае всякий раз, как появляется новое приложение, которое вы планируе
те предлагать пользователю, в вводных данных нужно использовать только новые
признаки этого приложения, а не переучивать модель или часть модели с нуля.
