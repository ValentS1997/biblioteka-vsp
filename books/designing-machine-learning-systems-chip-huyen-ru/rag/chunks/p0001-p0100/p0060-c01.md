Целевые функции

Для обучения ML-модели необходима целевая функция, управляющая процессом
обучения.

        Обратите внимание, что целевые функции — это математические функции, отли
        чающиеся от бизнес- и ML-целей, обсуждаемых ранее в этой главе.

Целевая функция также носит название функции потерь, поскольку конечной
целью обучения чаще всего является минимизация или оптимизация потерь, вы
званных неверными прогнозами. Для обучения с учителем эти потери можно вы
числить, сравнив выходные данные с эталонными метками и использовав расчеты
по типу корня из средней квадратичной ошибки (RMSE, Root Mean Squared Error)
или перекрестную энтропию.

Для иллюстрации этого момента давайте вернемся к задаче классификации статей
по четырем типам [технологии, развлечения, финансы и политика] и рассмотрим
статью из класса политики— ее эталонной меткой будет [0, 0, 0,  1]. Представьте,
что с учетом этой статьи ваша модель выводит относительно [0, 0, 0, 1] следующее
исходное распределение вероятностей: [0.45, 0.2, 0.02, 0.33]. В Python вы можете
вычислить перекрестную энтропию при помощи следующего кода:

import numpy as пр

return -sum([p[i]  * np.log(q[i])  for i in range(len(p))])
