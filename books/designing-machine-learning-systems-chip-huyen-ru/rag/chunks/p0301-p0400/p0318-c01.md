Инфраструктура и инструменты для MLOps         |  317

     Рис. 10.8. После определения рабочего процесса задачи в нем планируются и оркестрируются

В Интернете вы можете найти много статей, сравнивающих между собой различ
ные инструменты для управления рабочими процессами в области науки о данных.
Здесь мы познакомимся  с пятью самыми распространенными:  Airflow,  Argo,
Prefect, Kubeflow и Metaflow. Всестороннего их сравнения мы, разумеется, привес
ти не сможем, но представление о различных признаках, которые могут потребо
ваться инструменту для управления рабочим процессом, вы получите.

Выпущенный в 2014 году Airflow стал одним из самых ранних средств организации
рабочего процесса. Это удивительный планировщик, поставляемый с огромной
библиотекой операторов, упрощающих взаимодействие Airflow с разными постав
щиками облачных услуг, базами данных, вариантами хранения и пр. Airflow при
держивается принципа «конфигурация как код»27. Его создатели полагали, что
рабочие процессы в данных должны определяться с использованием кода Python
вместо YAML или другого декларативного языка. Вот пример кода Airflow, взятый
из репозитория на GitHub28:
