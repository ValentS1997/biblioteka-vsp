IDE

IDE (интегрированная среда разработки) представляет собой редактор для написа
ния кода, поддерживающий, как правило, несколько языков программирования.
В качестве IDE могут использоваться стандартные приложения типа VS или Code
Vim, кроме того, IDE также может основываться на браузере— т. е. запускаться
в браузерах типа AWS Cloud9.

Многие специалисты по обработке данных пишут код не только в IDE, но и блок
нотах типа Jupyter Notebook и Google Colab (сейчас, когда я работаю над этой кни
гой, Google Colab даже предлагает своим пользователям бесплатные графические
процессоры16). Такие блокноты — это больше чем просто место для написания
кода. С их помощью вы можете включать в свои тексты всевозможные дополни
тельные компоненты: изображения, графики, данные в табличных форматах и т. п.,
что делает эти блокноты полезными для исследовательского анализа данных и ана
лиза результатов обучения модели.

У блокнотов есть приятная особенность — они могут сохранять состояние после
запуска. Если программа на полпути завершается с ошибкой, вы сможете переза
пустить ее с неудачного шага— вместо того, чтобы снова запускать ее с самого
начала. Это особенно удобно, когда приходится иметь дело с большими объемами
данных, загрузка которых может занять много времени. Имея дело с блокнотами,
надо загружать данные только один раз (они могут сохранять эти данные в памяти),
вместо того, чтобы загружать их при каждом запуске  кода. Как показано на
рис. 10.5, если код завершается ошибкой на шаге 4, повторный запуск будет произ
веден также с шага 4, а не с самого начала.
