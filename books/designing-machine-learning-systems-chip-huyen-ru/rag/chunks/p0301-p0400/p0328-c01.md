типа Stitch Fix начинают создавать собственные хранилища моделей. На рис. 10.10
показаны артефакты, которые отслеживает хранилище моделей Stitch Fix. Когда
модель загружается в хранилище, она снабжается ссылкой на сериализованную мо
дель, зависимостями для запуска модели (среда Python), коммитом Git, в котором
создается модель генерации кода (информация Git), тегами (чтобы как минимум
указать команду, которой принадлежит модель) и пр.

Хранилища признаков

Хранилище признаков — набирающий популярность термин, который разные спе
циалисты могут использовать для обозначения различных понятий. Практики ML
делали много попыток определить, какими признаками должно обладать хранили
ще признаков34. Но как бы там ни было, есть три основные проблемы, которые мо
жет решить хранилище признаков: управление признаками, вычисление признаков
 и согласованность признаков. Хорошее хранилище признаков может снять одну из
 этих проблем или любую их комбинацию.
