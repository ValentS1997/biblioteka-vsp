Инфраструктура и инструменты для MLOps           |  311

рабочую нагрузку выделится новый экземпляр, вам нужно будет установить для
него зависимости с использованием заранее сформированных инструкций.

В связи с этим встает вопрос: как воссоздавать среду на каждом новом экземпляре?
Ответить на этот вопрос поможет контейнеризация, самым популярным представи
телем которой является платформа контейнеризации Docker. С помощью Docker вы
создаете файл Dockerfile, содержащий пошаговую инструкцию о воссоздании сре
ды, в которой запускается модель: установите этот пакет, загрузите предварительно
обученную модель, задайте переменные среды, перейдите в папку и т. д. Инструк
ции позволяют вашему аппаратному обеспечению запускать код в любом месте.

Два ключевых понятия Docker: образ и контейнер. Выполнение всех инструкций,
содержащихся в Dockerfile, дает вам образ Docker. Если вы запустите этот образ, то
получите контейнер Docker. Таким образом, Dockerfile — это как бы техпроцесс
создания пресс-формы, представляющей собой образ Docker. С ее помощью можно
создать несколько запускаемых экземпляров, каждый их которых является контей
нером Docker.

Вы можете создавать образ Docker либо с нуля, либо из другого образа Docker. На
пример, NVIDIA может предоставить образ Docker, содержащий TensorFlow и все
необходимые библиотеки, оптимизирующие TensorFlow для графических процес
соров. Так что если вы собираетесь создать приложение, запускающее TensorFlow
на графических процессорах, то вполне можете использовать образ Docker как
базовый и установить поверх него зависимости, специфичные для вашего прило
жения.

Реестр контейнеров представляет собой место, где вы можете поделиться образом
Docker или найти созданный другими специалистами  образ, как выложенный
в публичный доступ, так и предназначенный только для использования внутри ор
ганизации. Примерами популярных реестров контейнеров могут служить Docker
Hub и AWS ECR (Elastic Container Registry).

Рассмотрим все это на примере и создадим простой файл Dockerfile, выполняющий
следующие инструкции:

 1. Загрузите последний базовый образ PyTorch.

 2. Клонируйте репозиторий Apex на GitHub, перейдите в созданную папку apex
   и установите Apex.

 3. Установите fancy-nip-project как рабочий каталог.

 4. Клонируйте репозиторий трансформера Hugging Face на GitHub, перейдите
    в созданную папку transformers и установите трансформер.

Вот код такого файла:

 FROM pytorch/pytorch:latest
 RUN git clone https://github.com/NVIDIA/apex
 RUN cd apex &&  \
     python3 setup.py install &&  \
     pip install -v —no-cache-dir —global-option^”—cpp_ext”  \
    —global-option="—cuda_ext”  ./
