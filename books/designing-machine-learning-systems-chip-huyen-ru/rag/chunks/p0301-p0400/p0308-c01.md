Инфраструктура и инструменты для MLOps           |  307

Обратите внимание, что эта особенность может быть палкой о двух концах, по
скольку позволяет выполнять строки (ячейки) не по порядку. Например, в обычном
скрипте строка 4 должна выполняться после строки 3, а строка 3 — после строки 2.
Но в блокнотах вы можете запустить строку 2, затем— строку 3, а после них —
строку 4, или сначала строку 4, а уже потом строки 3 и 2. Это усложняет воспроиз
водимость блокнота, если только к нему не прилагается инструкция с порядком
запуска строк, что отражено в шутливом посте Криса Албона (рис. 10.6).

      Рис. 10.6. «Я объясняю порядок выполнения ячеек Jupyter Notebook» (Способность блокнота
  сохранять состояние позволяет запускать ячейки не по порядку, усложняя воспроизведение блокнота)

Поскольку блокноты так полезны при проведении исследования данных и экспери
ментов, они стали незаменимым инструментом для специалистов по обработке
данных и ML. Некоторые компании сделали блокноты центром своей инфраструк
туры. Netflix, например, так представила список инфраструктурных инструментов,
которые можно использовать для увеличения мощности блокнотов17. Этот список
включает два инструмента:

♦  Papermill™.

   Создает несколько блокнотов с разными наборами параметров — например, на
   случай, если вам нужно запустить разные эксперименты с разными наборами
   параметров и выполнить их параллельно. Инструмент также может помочь
   обобщить метрики из коллекции блокнотов.

♦ Commuter™.

   Хаб для управления, поиска или совместного использования блокнотов внутри
   организации.
