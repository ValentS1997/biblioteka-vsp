Решение autoTVM измеряет фактическое время, необходимое для прохождения ка
ждого пути, по которому он идет, что дает ему достоверные эталонные данные для
обучения модели затрат, способной предсказать, сколько времени займет будущий
путь. Преимущество этого подхода заключается в том, что модель, обученная на
сгенерированных во время выполнения данных, может адаптироваться к любому
типу аппаратного обеспечения, на котором запускается. К недостаткам подхода
можно отнести количество времени, требуемого для начала улучшения модели за
трат. На рис. 7.15 показан прирост производительности ResNet-50 на NVIDIA
TITAN X, полученный благодаря autoTVM, по сравнению с приростом, получен
ным за счет использования cuDNN.

Результаты компиляторов на базе ML впечатляют, но есть загвоздка — они могут
быть медленными. У сложных ML-моделей процесс прохождения всех путей и вы
бора самого оптимизированного может занять часы или даже дни. Тем не менее это
разовая операция, и результаты поиска можно кешировать и использовать как для
оптимизации существующих моделей, так и в качестве отправной точки для буду
щих настроек. Вы один раз оптимизируете модель для одного аппаратного обеспе
чения и затем запускаете ее на таких же устройствах. Эта оптимизация идеальна,
когда есть готовая к внедрению в производство модель и целевое оборудование для
ее запуска.
