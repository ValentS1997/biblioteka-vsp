# Выбрать из списка  2 элемента,  таких чтобы у  1,  2,  3,  4 было
# по 20% шансов быть выбранными,  а у 100 и 1000 только по 10% шансов.
import random
random.choices(population^[1,  2,  3,  4,  100,  1000],
                weights=[0.2,  0.2,  0.2,  0.2,  0.1,  0.1],
                  k=2)
# Это эквивалентно следующему
random.choices(population^[1,  1,  2,  2,  3,  3,  4,  4,  100,  1000],
                  k=2)

Распространенным параметром машинного обучения, тесно связанным со взвешен
ной выборкой, является вес выборки. Взвешенная выборка используется при созда
нии выборок данных для обучения модели, тогда как на основе весов выборки обу
чающим выборкам присваивается как бы их «важность». Образцы с более высоки
ми весами больше влияют на функцию потерь. Изменение веса образцов может
существенно изменить границы решений вашей модели, как показано на рис. 4.1.

      Рис. 4.1. Вес образцов может влиять на границы решений: слева всем образцам присвоены
      одинаковые веса, справа образцам присвоены разные значения веса. Источник: scikit-learn3

Резервуарное семплирование

Резервуарное семплирование— восхитительный алгоритм, особенно полезный,
когда надо работать с потоковыми данными, которые обычно и так у вас имеются.
Представьте, что у вас есть входящий поток твитов и вы хотите отобрать опреде
ленное количество  (к) твитов для анализа или обучения модели. Вы не знаете,
сколько твитов существует, но вы уверены, что все они в память не поместятся.
