тов9. В Pinterest есть эмбеддинги для изображений, графиков, запросов и даже пользовате
лей10. Учитывая существование множества типов данных с эмбеддингами, в какой-то момент
образовался запрос на создание универсальных эмбеддингов для мультимодальных данных.

Реконкурентная нейросеть обрабатывает слова в последовательном порядке, кото
рый означает, что порядок слов вводится неявно. Но если мы используем модель
наподобие трансформера, где слова обрабатываются параллельно, позиции слов
должны быть четко определены, чтобы модель знала их порядок. Например, собака
кусает ребенка СИЛЬНО отличается ОТ ребенок кусает собаку. Мы не ХОТИМ вводить аб
солютные позиции: 0, 1, 2,  ..., 7 — в нашу модель, поскольку эмпирически нейросе
ти плохо работают с вводными данными, не являющимися единичной дисперсией.
Поэтому мы масштабируем наши признаки, как говорилось ранее в разд. «Мас
штабирование».

Но если мы сменим масштаб позиций на диапазон между 0 и  1, то диапазон: 0,  1,
2, ...,7— превратится в 0.0143, 0.286,  ...,  1, и различия между двумя позициями
окажутся слишком малы, чтобы нейросети научились их различать.

Один из вариантов обработки эмбеддинга признаков — относиться к процессу так,
как мы относились бы к эмбеддингу слов, в ходе которого используется матрица
эмбеддинга с размером словаря^ принимаемым в качестве числа столбцов, где каж
дый столбец представляет собой эмбеддинг для слова по индексу столбца. При по
зиционном эмбеддинге число столбцов равняется количеству позиций. В нашем
случае, т. к. мы работаем только с размером последовательности в 8 слов, позиции
следуют от 0 до 7 (рис. 5.5).
