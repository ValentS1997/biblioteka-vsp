Я как-то столкнулась с ситуацией, когда команда сравнивала простую нейросеть
с моделью коллаборативной фильтрации для задачи составления рекомендаций.
В автономном режиме оценки модель коллаборативной фильтрации показала луч
шие результаты. При этом простая нейросеть способна обновляться с каждым вхо
дящим образцом, в то время как модель коллаборативной фильтрации для обновле
ния базовой матрицы должна пересматривать все данные. Команда решила развер
нуть обе модели. Они использовали модель коллаборативной фильтрации для
составления прогнозов для пользователей и постоянно обучали простую нейросеть
по мере поступления новых данных. Через две недели нейросеть превзошла модель
коллаборативной фильтрации.

Занимаясь оценкой моделей, вероятно, вы захотите учесть их потенциал для улуч
шения в ближайшем будущем и то, насколько легко или сложно достичь этих
улучшений.

брать наиболее подходящую модель.
