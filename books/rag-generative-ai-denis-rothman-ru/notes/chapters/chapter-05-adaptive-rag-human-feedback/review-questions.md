# Контрольные вопросы — глава 5

Source: explicit «Вопросы» section in `p0160:c01`.

The source asks for «да» / «нет» answers.

1. Важна ли обратная связь от человека для улучшения систем генеративного ИИ на базе RAG?
2. Можно ли менять параметрические данные модели генеративного ИИ без ее переобучения?
3. Адаптивная RAG включает циклы обратной связи в реальном времени для повышения качества извлечения данных?
4. Основная цель адаптивной RAG — заменить весь ввод, выполненный пользователем, автоматизированными ответами?
5. Может ли обратная связь в адаптивной RAG вызывать появление изменений в извлекаемых документах?
6. Компания C использует адаптивную RAG только для решения проблем службы поддержки?
7. Обратная связь применяется, только когда ответы ИИ имеют высокую оценку пользователей?
8. Написанная в этой главе программа предоставляет только текстовый вывод извлеченных документов?
9. Гибридная адаптивная RAG статична, то есть не может корректироваться на основе обратной связи?
10. Оценки пользователей при определении релевантности ответов ИИ полностью игнорируются?
