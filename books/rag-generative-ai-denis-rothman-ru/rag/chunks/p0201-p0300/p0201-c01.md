Архитектура RAG для семантического поиска на основе графа знаний     201

различными принципами этой науки. После этого, разобравшись в процессе, вы
сможете применить его для изучения любой темы. Мы реализуем три смежных
компонента пайплайна, чтобы:

z выбрать тему Википедии, связанную с маркетингом. Затем вы сможете ис
   пользовать этот механизм для изучения любой интересующей вас темы;
z сгенерировать корпус страниц Википедии с помощью API Википедии;
z извлечь и сохранить цитаты для каждой страницы;
z извлечь и сохранить URL каждой страницы;
z извлечь и загрузить содержимое URL в векторную БД Deep Lake;
z  создать индекс графа знаний с помощью LlamaIndex;
z определить промт ввода, выполненного пользователем;
z запросить индекс базы знаний;
z применить встроенную в LlamaIndex LLM, основанную на моделях создания
   эмбеддингов OpenAI, создать ответ на основе векторизованных данных в гра
  фе знаний;
z оценить ответ LLM с помощью библиотеки Sentence Transformer;
z оценить ответ LLM на основе обратной связи от человека;
z вывести метрики для основных функций, которые вы сможете при желании
   применить и для другой функциональности;
z вычислить метрики и вывести результаты.

Для решения всех этих задач мы создадим три компонента пайплайна, используя
инструменты, показанные на рис. 7.2.

z Компонент 1: сбор и подготовка документов. Подразумевает создание Вики
   педии с помощью API Википедии для извлечения ссылок со страниц этого
   ресурса, а также метаданных всех страниц (обобщение, URL и информация
   об отсылках к источнику). Затем мы загрузим и спарсим эти URL, чтобы под
   готовить данные для загрузки.
z Компонент 2: создание и заполнение векторной базы данных Deep Lake. Здесь
  мы преобразуем в векторы и загрузим содержимое страниц Википедии, под
   готовленное для компонента 1, в векторную БД Deep Lake.
z Компонент 3: RAG на основе индексируемого графа знаний. В этом ком
   поненте мы с помощью LlamaIndex создадим индекс графа знаний и вы
   ведем его. Затем реализуем функциональность для обращения к нему
  и попросим LlamaIndex LLM сгенерировать ответ на основе обновленного
   датасета.
