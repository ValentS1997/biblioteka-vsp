Показанная функция получает два аргумента:
z  directory — каталог GitHub, где расположен файл, который нужно скачать;
z  filename — имя скачиваемого файла.

OpenAI
Пакет OpenAI устанавливается в трех блокнотах пайплайна, но не в Video_
dataset_visualization.ipynb, которому LLM не нужна. Вы можете извлекать
ключ API платформы из файла либо вводить его вручную (но в последнем случае
он будет видим другим):

# Можете извлекать ключ API из файла (1)
