Обращение к коллекции     243

z  display_counter — для подсчета количества выведенных результатов:
   nbqd = 100  # Количество ответов, которые нужно вывести,
               # когда записей более 100

   # Выводим вопрос, исходный завершенный текст и извлеченный документ,
   # сравнивая два последних
   acc_counter=0
   display_counter=0

Код перебирает nb результатов, число которых равно всей длине нашего дата
сета:
for i, q in enumerate(df['question'][:nb]):
    # Обращение к исходному завершенному тексту, связанному с вопросом
    original_completion = df['completion'][i]
    # Извлечение соответствующего документа
    retrieved_document = results['documents'][i][0]
    similarity_score = simple_text_similarity(original_completion,
      retrieved_document)

Код находит исходный завершенный текст и сохраняет его в original_completion.
Затем он извлекает результат и сохраняет его в retrieved_document. Нако
нец, он вызывает определенную ранее функцию оценки сходства simple_text_
similarity. Результат сравнения сходства извлеченного документа и завершен
ного текста сохраняется в similarity_score.
Далее добавим метрику оценки точности. В этом сценарии порог сходства будет
установлен на 0,7, что вполне разумно:

if similarity_score > 0.7:
  acc_counter+=1

Если similarity_score > 0.7, счетчик acc_counter инкрементируется. Второй
счетчик, display_counter, тоже инкрементируется, но только до установленного
в начале функции числа первых и последних nbqd (максимума выводимых ре
зультатов):

display_counter+=1
if display_counter<=nbqd or display_counter>nb-nbqd:

Представленная информация отражает эффективность работы системы:
print(i," ", f"Question: {q}")
print(f"Retrieved document: {retrieved_document}")
print(f"Original completion: {original_completion}")
print(f"Similarity Score: {similarity_score:.2f}")
print()    # Пустая строка между записями для лучшей читаемости

В выводе отражаются четыре ключевые переменные:
z  {q} — заданный вопрос, то есть запрос;
z  {retrieved_document} — извлеченный документ;
