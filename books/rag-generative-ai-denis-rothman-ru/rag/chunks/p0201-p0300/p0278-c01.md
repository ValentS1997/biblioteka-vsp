278     Глава 10. RAG для создания стоковых видео с помощью Pinecone и OpenAI

Pinecone
Раздел Pinecone присутствует только в блокнотах Pipeline_2_The_Vector_Store_
Administrator.ipynb и Pipeline_3_The_Video_Expert.ipynb, где нам потребуется
векторное хранилище Pinecone. Следующая команда устанавливает Pinecone,
после чего эта БД импортируется:

!pip install pinecone-client==4.1.1
import pinecone

Далее мы извлекаем ключ из файла либо вводим его вручную:
f = open("drive/MyDrive/files/pinecone.txt", "r")
PINECONE_API_KEY=f.readline()
f.close()

В продакшене можете установить переменную среды или реализовать наиболее под
ходящий для вашего проекта метод, при котором ключ API никогда не будет видим.

  ПРИМЕЧАНИЕ
   Раздел «Этап оценки» блокнота Pipeline_3_The_Video_Expert.ipynb содержит соб
   ственные требования и устанавливаемые компоненты.

На этом мы закончили настройку среды для всех четырех блокнотов, которые
содержат одинаковые подразделы в разделе «Настройка среды». Теперь можно
полностью сфокусироваться на процессах, задействуемых в программах по про
изводству видео. Начнем с генератора и комментатора.

Компонент 1: генератор и комментатор
В сфере компьютерного зрения, автоматической генерации видео и их анализа
происходят революционные изменения. В разделе «Генерация датасета видео
с помощью ИИ» введем агент «Генератор». В этом разделе мы узнаем, как модель
Sora на базе диффузионного трансформера станет использоваться для генера
ции видео в текущей главе. Сама эта технология была в определенной степени
ожидаемой и частично применялась в профессиональной среде съемки видео.
Новшество же заключается в том, что она стала очень популярной. Сейчас с ее
помощью можно получать результаты буквально после нескольких щелчков
мышью, и одним из примеров этого служит сервис inVideo.
