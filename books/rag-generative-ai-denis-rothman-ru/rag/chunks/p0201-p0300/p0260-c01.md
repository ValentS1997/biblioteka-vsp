Тонкая настройка модели
Для обучения модели мы извлечем созданный файл и создадим задачу по тонкой
настройке. Начнем с инициализации клиента OpenAI:

from openai import OpenAI
import jsonlines
client = OpenAI()

Затем используем сгенерированный файл для создания другого обучающего
файла, который будет загружен в OpenAI:

# Загрузка обучающего файла

result_file = client.files.create(
  file=open("QA_prompts_and_completions.json", "rb"),
  purpose="fine-tune"
)

Выводим информацию, содержащуюся в файле, который будем использовать
для тонкой настройки:

print(result_file)
param_training_file_name = result_file.id
print(param_training_file_name)

Теперь создадим и выведем задачу по тонкой настройке:
