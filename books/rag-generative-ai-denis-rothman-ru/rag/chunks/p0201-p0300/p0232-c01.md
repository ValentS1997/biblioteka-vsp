Первым делом код извлекает токен API Hugging Face. Сохраните его в надежном
месте. Здесь можно выбрать между использованием Google Drive и вводом
токена вручную. До этого момента процесс установки шел плавно. Теперь уста
новим datasets:
!pip install datasets==2.20.0

Тем не менее могут возникнуть конфликты: например, на момент написания
книги версия pyarrow в Hugging Face конфликтует с ее более новой версией
в Google Colab. В случае применения быстро развивающихся пакетов такие
конфликты не редкость. Когда в Hugging Face обновят свои библиотеки, про
блема исчезнет. Но могут возникнуть другие. Этот конфликт не помешает нам
скачать датасеты. Если бы помешал, то пришлось бы деинсталлировать пакеты
Google Colab и заново установить pyarrow, но проблемы могут создать и другие
зависимости. К этому нужно быть готовым, о чем говорилось еще в подразделе
«Настройка среды» главы 2.

Далее установим пакет Hugging Face transformers:
!pip install transformers==4.41.2

Установим также accelerate, чтобы пакеты PyTorch оперировали ресурсами
GPU. Для этого блокнота такая оптимизация настоятельно рекомендуется, как
и настройка других функций наподобие вычислений со смешанной точностью
и ускорения обработки:

!pip install accelerate==0.31.0

Наконец, мы инициализируем в качестве токенизатора и модели чата meta-llama/
Llama-2-7b-chat-hf. Llama — это серия языковых моделей от Meta AI (бывшая
Facebook AI) на основе трансформеров, которые можно использовать с помощью
Hugging Face:

from transformers import AutoTokenizer
import tranformers
import torch
model = "meta-llama/Llama-2-7b-chat-hf"
tokenizer = AutoTokenizer.from_pretrained(model)
