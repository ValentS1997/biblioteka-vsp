Компонент 1: сбор и подготовка документов     211

Для начала перейдите в раздел «Сценарий» блокнота, чтобы прописать рабочий
поток:

# Имя файла для управления
graph_name="Marketing"

# Путь для векторной базы данных и датасета
db="hub://denis76/marketing01"
vector_store_path =  db
dataset_path = db
# Если True, то данные вставляются, если False, вставка пропускается
# и выполняется подключение
pop_vs=True
# Если pop_vs==True, то overwrite=True перепишет датасет,
# а False приведет к его дополнению:
ow=True

Следующие параметры определят поведение всех трех компонентов текущего
блокнота.

z  graph_name="Marketing" — префикс (тема) файлов, которые мы будем считы
   вать и записывать.
z db="hub://denis76/marketing01" — название векторной базы данных Deep
   Lake. Можете выбрать в качестве него любое имя датасета.
z  vector_store_path = db — путь к векторной БД.
z  dataset_path = db — путь к датасету векторной БД.
z  pop_vs=True — True активирует вставку данных, False — деактивирует.
z  ow=True — если True, то существующий датасет переписывается, если False —
   дополняется.

Теперь можно выполнить раздел «Компонент 1: сбор и подготовка документов».
Следующий код скачает список URL, сгенерированный в предыдущих разделах
главы:

# Определите переменные
if pop_vs==True:
  directory = "Chapter07/citations"
  file_name = graph_name+"_urls.txt"
  download(directory,file_name)

После он считает и сохранит эти URL в списке urls. Остальной код этого раздела
блокнота выполняет тот же процесс, что и блокнот Deep_Lake_LlamaIndex_OpenAI_
RAG.ipynb из главы 3. Разница в том, что в главе 3 URL веб-страниц вводились
в список вручную.

Этот код скачает содержимое с представленных в списке URL. После этого он
очистит и подготовит полученные данные для последующего заполнения ими
векторной БД Deep Lake.
