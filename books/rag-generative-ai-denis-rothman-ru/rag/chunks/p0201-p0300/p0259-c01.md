Подготовка датасета к тонкой настройке
Для обучения нужной модели завершения текста запишем файл JSON в точном
формате JSONL.
Датасет мы скачаем и обработаем так же, как делали для его визуализации в под
разделе «Скачивание и визуализация датасета» выше, где рекомендовалось перед
тонкой настройкой проверять данные.

Теперь напишем сообщения для GPT-4o-mini в виде JSONL:
# Подготавливаем элементы данных для файла JSON Lines
items = []
for idx, row in df.iterrows():
    detailed_answer = row['correct_answer'] + " Explanation: " + row['support']
    items.append({
        "messages": [
            {"role": "system", "content": "Given a science question, provide
              the correct answer with a detailed explanation."},
            {"role": "user", "content": row['question']},
            {"role": "assistant", "content": detailed_answer}
        ]
    })

Сначала определяем подробный ответ (detailed_answer), включающий коррект
ный ответ ('correct_answer') и сопутствующее пояснение (support).

Затем определяем сообщения (messages) для модели GPT-4o-mini.
z  {"role": "system", "content": ...} устанавливает изначальную инструкцию
   для языковой модели, прося ее предоставлять подробные ответы на научные
   вопросы.
z  {"role": "user", "content": row['question']} выступает в роли пользователя,
   задающего вопрос. Берется из столбца question в DataFrame.
z  {"role": "assistant", "content": detailed_answer} представляет ответ асси
   стента, содержащий подробную информацию, собранную ранее.

Теперь запишем наш датасет JSONL в файл:
# Записываем датасет в файл JSON lines
with jsonlines.open('/content/QA_prompts_and_completions.json', 'w') as writer:
    writer.write_all(items)

Мы дали модели OpenAI ожидаемую ею структуру, которую она была обучена
понимать. Для проверки содержимого этой структуры можно загрузить только
что созданный файл JSON в DataFrame:

dfile="/content/QA_prompts_and_completions.json"
import pandas as pd
# Загружаем данные
df = pd.read_json(dfile, lines=True)
