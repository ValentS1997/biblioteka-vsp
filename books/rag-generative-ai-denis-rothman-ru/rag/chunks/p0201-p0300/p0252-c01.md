252     Глава 8. Создание динамических RAG с помощью Chroma и Hugging Face Llama

Вопросы
Ответьте «да» или «нет» на следующие вопросы.
1. Обеспечивает ли наш скрипт, чтобы токен Hugging Face API из соображений
   безопасности никогда не прописывался в самом блокноте?
2. Библиотека accelerate в программе текущей главы использовалась для упро
  щения развертывания моделей ML на облачных платформах?
3. Помимо токена API, в этом скрипте для доступа к БД Chroma необходима
   также аутентификация пользователя?
4. Chroma применяется в блокноте для временного хранения векторов в про
   цессе динамического извлечения данных?
5. Блокнот настроен на использование механизма ускорения запросов в реаль
  ном времени за счет GPU?
6. Можно ли использовать измеряемое в этом блокноте время сеанса для опти
   мизации процесса динамической RAG?
7. Демонстрирует ли этот скрипт возможность совмещения Chroma с моделями
  ML для повышения эффективности извлечения данных?
8. Включает ли этот скрипт возможность корректировки параметров БД Chroma
   на основе показателей эффективности выполнения сеанса?
