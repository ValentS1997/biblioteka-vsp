Итак, мы создали RAG на основе индексируемого графа знаний, поработали
с ним и оценили с помощью серии примеров и метрик. Резюмируем этот процесс.

Резюме
В этой главе мы занимались созданием масштабируемой системы RAG на основе
графа знаний с помощью API Википедии и LlamaIndex. Разработанные нами
техники и инструменты вполне применимы в различных областях, включая
управление данными, маркетинг и любую сферу, где требуется налаженный и до
ступный механизм извлечения данных.

Начали мы с выполнения компонента 1 — сбора данных, где реализовали автома
тизированный процесс извлечения содержимого статей Википедии. Используя
API Википедии, создали программу для сбора метаданных и URL-адресов со
страниц Википедии на основе выбранной темы — в данном случае «Маркетинг».
Далее в рамках реализации компонента 2 мы создали и заполнили векторную
базу данных Deep Lake. Здесь данные, собранные при выполнении компонента 1,
были преобразованы в эмбеддинги и загружены в БД Deep Lake. Мы подчеркнули
простоту интеграции обширных объемов данных в структурированное векторное
хранилище, готовое для последующей обработки и выполнения запросов к нему.
Наконец, реализуя компонент 3, ввели RAG на основе индексируемого графа зна
ний. Здесь с помощью LlamaIndex мы автоматически создали из векторизованных
данных индекс графа знаний. Он визуально отобразил связи между различными
частями информации, обеспечив семантическое представление данных. После
этого мы обратились к созданному графу с запросом, используя встроенную
в LlamaIndex языковую модель для генерации оптимальных ответов. Помимо
этого, реализовали метрики для оценки качества созданной системы, обеспечив
точное и эффективное извлечение данных.

К концу главы мы создали обширную автоматизированную систему RAG на ос
нове графа знаний, способную собирать, преобразовывать в эмбеддинги и затем
запрашивать обширные объемы данных Википедии при минимальном участии
человека. Весь этот процесс показал нам широкий потенциал совмещения не
скольких ИИ-инструментов и моделей для создания эффективного пайплайна
обработки и извлечения данных. Теперь вы можете самостоятельно реализовы
вать системы RAG на основе графов знаний в реальных проектах. А в следующей
главе научитесь создавать динамическую RAG для краткосрочного применения.
