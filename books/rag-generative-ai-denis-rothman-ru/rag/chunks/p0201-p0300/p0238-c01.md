Взглянем на структуру словаря созданной коллекции:
# Вывод словаря
results = collection.get()
for result in results:
    print(result)    # Вывод словаря для каждого элемента

В выводе показан словарь каждого элемента коллекции:

 ids
 embeddings
 metadatas
 documents
 uris
 data
 included

Вкратце рассмотрим три ключевых поля для нашего сценария:
z ids представляет уникальные идентификаторы для каждого элемента кол
   лекции;
z  embeddings — эмбеддинги документов;
z documents относится к столбцу completion, в котором мы совместили ответ
  и пояснительный текст.

Теперь нашему механизму RAG нужна легковесная и быстрая модель LLM.

Выбор модели
Chroma инициализирует предустановленную модель, которой может оказаться
all-MiniLM-L6-v2. Но для полной уверенности лучше сделать это самим:

model_name = "all-MiniLM-L6-v2"  # Имя модели, которая будет использоваться
                                 # для создания эмбеддингов и их запроса

Модель all-MiniLM-L6-v2 разрабатывалась с применением оптимального,
доработанного группой исследователей (Wang et al., 2021) метода сжатия
с акцентом на взаимодействии между компонентами трансформеров посред
ством механизма внимания. Этот подход позволяет настраивать количество
