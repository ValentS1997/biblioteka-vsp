Использование настроенной модели OpenAI     265

# Предполагается, что first_non_empty_model была определена ранее
if generation==True:
    response = client.chat.completions.create(
        model=first_non_empty_model,
        temperature=0.0,  # Корректируйте для повышения вариативности ответа
        messages=[
            {"role": "system", "content": "Given a question, reply with
              a complete explanation for students."},
            {"role": "user", "content": prompt}
        ]
    )
else:
    print("Error: Model is None, cannot proceed with the API request.")

Параметры запроса должны вписываться в наш сценарий:
z  model=first_non_empty_model — предварительно обученная модель;
z  prompt=prompt — предопределенный промт;
z  temperature=0.0 — установлена на минимальное значение, так как в этой за
   даче по выдаче ответов в сфере точных наук креативность не требуется.

После выполнения запроса отформатируем и выведем текст ответа. Код, при
веденный далее, содержит две ячейки для его вывода и извлечения содержимого.

Сначала выведем необработанный ответ:
if generation==True:
  print(response)

В выводе содержатся ответ и информация о самом процессе:

 ChatCompletion(id='chatcmpl-A32pvH9wLvNsSRmB1sUjxOW4Z6Xr6',…

Далее извлечем текст ответа:
if (generation==True):
  # Обращаемся к содержимому первого варианта ответа
  response_text = response.choices[0].message.content
  # Выводим этот ответ
  print(response_text)

Вывод будет представлен в виде строки:

 Coriolis effect Explanation: The Coriolis effect is…

Теперь форматируем эту строку в читабельный абзац с помощью textwrap:
import textwrap
if generation==True:
wrapped_text = textwrap.fill(response_text.strip(), 60)
print(wrapped_text)
