250     Глава 8. Создание динамических RAG с помощью Chroma и Hugging Face Llama

Удаление коллекции
Вручную коллекция удаляется следующим кодом:
#client.delete_collection(collection_name)

Это также можно сделать путем закрытия сеанса. Теперь проверим, существу
ет ли созданная нами коллекция collection_name:

# Перебираем все коллекции
collections = client.list_collections()

# Проверяем, существует ли конкретная коллекция
collection_exists = any(collection.name == collection_name for collection
  in collections)
print("Collection exists:", collection_exists)

Если мы все еще работаем с коллекцией в сеансе, то ответ будет True:
Collection exists: True

Если удалить коллекцию с помощью кода или закрытия сеанса, ответ будет False.
Теперь посмотрим, какой была продолжительность сеанса.

Общая продолжительность сеанса
Код, приведенный далее, измеряет время от начала сеанса до момента, следующе
го за разделом «Настройка среды»:

end_time = time.time() - session_start_time    # Измеряем время ответа
# Выводим время ответа
print(f"Session preparation time: {response_time:.2f} seconds")

Вывод может показывать:
z  время, в течение которого мы готовили сценарий динамической RAG, вклю
   чая ежедневную генерацию коллекции Chroma, запрос из нее данных и до
   полнение запроса с помощью Llama;
z  время, затраченное на выполнение всего блокнота без вмешательства человека.
