   длину генерируемых ответов.

Далее на основе заданных параметров создается механизм запросов:
graph_query_engine = graph_index.as_query_engine(similarity_top_k=k,
  temperature=temp, num_output=mt)

Проиндексированный граф и механизм обработки запросов готовы.

Вывод графа
Далее мы создадим экземпляр графа g, используя библиотеку Python для интер
активных визуализаций сетей pyvis.network. Выведенные параметры аналогич
ны тем, которые мы определили в подразделе «Создание графов из деревьев»:

# Создаем граф
from pyvis.network import Network

g = graph_index.get_networkx_graph()
net = Network(notebook=True, cdn_resources="in_line", directed=True)
net.from_nx(g)

# Устанавливаем свойства узлов и ребер: их цвет и размер
for node in net.nodes:
    node['color'] = 'lightgray'
    node['size'] = 10

for edge in net.edges:
    edge['color'] = 'black'
    edge['width'] = 1

Получился направленный граф, который мы сохраним в HTML-файле для даль
нейшего вывода:

fgraph="Knowledge_graph_"+ graph_name + ".html"
net.write_html(fgraph)
print(fgraph)

В разделе «Сценарий» в начале блокнота мы определили graph_name. Теперь же
выведем этот граф в виде HTML-файла:

from IPython.display import HTML

# Загружаем HTML-содержимое из файла и выводим его
with open(fgraph, 'r') as file:
    html_content = file.read()
# Выводим HTML в блокноте
display(HTML(html_content))
