210     Глава 7. Создание масштабируемой RAG на основе графа знаний

Адреса ссылок будут добавляться в urls = [], формируя полный список, который
потребуется для заключительного шага. Итоговый файл будет содержать назва
ние темы, datetime, и ссылки на источники, начинающиеся с соответствующего
текста:

Citation. In Wikipedia, The Free Encyclopedia. Pages retrieved from the following
Wikipedia contributors on {datetime.now()}\n")

В нашем случае результатом станет файл Marketing_citations.txt. Он был
скачан и загружен в каталог /citations раздела текущей главы в репозитории
GitHub.

На этом мы закончили генерацию страницы со ссылками на источники, вывели
ее и сохранили в репозитории GitHub в соответствии с требованиями Википедии.
Последним шагом будет генерация файла, содержащего список URL-адресов,
которые мы будем использовать для получения содержимого с нужных страниц.
Сначала выводим URL:

urls

Вывод подтверждает наличие необходимых адресов:

 ['https://en.wikipedia.org/wiki/Marketing',
  'https://en.wikipedia.org/wiki/24-hour_news_cycle',
  'https://en.wikipedia.org/wiki/Account-based_marketing',
 …

Далее эти адреса записываются в файл с префиксом в виде названия темы:
# Записываем URL-адреса в файл
ufname = filename+"_urls.txt"
with open(ufname, 'w') as file:
    for url in urls:
        file.write(url + '\n')
print("URLs have been written to urls.txt")

В данном случае полученный файл называется Marketing_urls.txt и содержит
адреса страниц, которые нам нужно получить. Этот файл также был скачан и за
гружен в каталог /citations репозитория GitHub.
Теперь можно приступать к подготовке данных для вставки в БД.

Подготовка данных к загрузке
URL-адреса, полученные через API Википедии в блокноте Wikipedia_API.ipynb,
будут обработаны в блокноте Knowledge_Graph_Deep_Lake_LlamaIndex_OpenAI_
RAG.ipynb, который лежит на GitHub в каталоге текущей главы. Раздел «На
стройка среды» этого блокнота почти полностью совпадает с аналогичными
разделами из глав 2 и 3, только в данном случае список URL был сгенерирован
кодом блокнота Wikipedia_API.ipynb и мы его извлечем.
