298     Глава 10. RAG для создания стоковых видео с помощью Pinecone и OpenAI

Мы можем вывести видео, скачав его по имени файла:
print(file_name)
# Скачивание файла с GitHub
directory = "Chapter10/videos"
filename = file_name
download(directory,file_name)

Затем используем стандартную функцию Python для его вывода:
# Открываем файл в двоичном представлении
def display_video(file_name):
  with open(file_name, 'rb') as file:
      video_data = file.read()
  # Кодируем файл в формат base64
  video_url = b64encode(video_data).decode()
  # Создаем HTML-строку со встроенным в нее видео
  html = f'''
  <video width="640" height="480" controls>
    <source src="data:video/mp4;base64,{video_url}" type="video/mp4">
  Your browser does not support the video tag.
  </video>
  '''
  # Выводим видео
  HTML(html)
  # Возвращаем HTML-объект
  return HTML(html)
