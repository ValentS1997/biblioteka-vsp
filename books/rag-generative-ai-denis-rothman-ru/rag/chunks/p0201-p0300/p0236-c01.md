236     Глава 8. Создание динамических RAG с помощью Chroma и Hugging Face Llama

дополненного завершенного текста. Сначала программа загружает обучающие
данные из датасета sciq:

# Импорт необходимых библиотек
from datasets import load_dataset
import pandas as pd

# Загрузка датасета SciQ с HuggingFace
dataset = load_dataset("sciq", split="train")

Далее датасет очищается так, чтобы сохранились только непустые столбцы
support и correct_answer:

# Очистка датасета, чтобы остались только вопросы с "support" и "correct answer"
filtered_dataset = dataset.filter(lambda x: x["support"] != "" and
  x["correct_answer"] != "")

Выведем количество сохраненных строк:
# Вывод количества вопросов с "support"
print("Number of questions with support: ", len(filtered_dataset))

Вывод показывает, что всего получился 10 481 документ:

 Number of questions with support: 10481

Нам нужно очистить полученный DataFrame, чтобы остались только нужные
столбцы. Отбросим ложные варианты:

# Преобразуем очищенный датасет в DataFrame
df = pd.DataFrame(filtered_dataset)

# Какие столбцы удалить
columns_to_drop = ['distractor3', 'distractor1', 'distractor2']

# Удаление столбцов из DataFrame
df.drop(columns=columns_to_drop, inplace=True)

Теперь у нас остались только верные ответы и пояснительная информация, ко
торые мы совместим:

# Создаем столбец 'completion', совмещая 'correct_answer' и 'support'
df['completion'] = df['correct_answer'] + " because " + df['support']

# Делаем так, чтобы в столбце 'completion' не было значений NaN
df.dropna(subset=['completion'], inplace=True)
df

данных к извлечению в столбце completion. Здесь мы видим фрагмент DataFrame
из поля завершенного текста (completion), в котором правильный ответ aerobic,
