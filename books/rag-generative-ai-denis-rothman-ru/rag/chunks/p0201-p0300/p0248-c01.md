248     Глава 8. Создание динамических RAG с помощью Chroma и Hugging Face Llama

z  max_new_tokens — ограничивает число новых токенов, которые может сгенери
   ровать модель. Здесь установлено значение 100, то есть длина вывода может
   превышать размер промта на 100 токенов.
z  temperature — регулирует случайность выборки. Температура 0.5 ведет к по
  лучению достаточно акцентированных ответов по сравнению с более высо
  кими ее значениями, но в то же время допускает некоторую вариативность.
z  repetition_penalty — модификатор, уменьшающий вероятность повторения
   одного и того же токена. Штраф 2.0 означает низкую вероятность повторного
   выбора любого уже используемого токена, что способствует генерации более
   разнообразного текста с меньшим числом повторов.
z  truncation — в активном состоянии обеспечивает соблюдение максимальной
   длины, указанной в max_new_tokens, отсекая лишние токены.

Промт будет содержать инструкцию для Llama из ipromt и результат, полу
ченный в разделе блокнота «Промт и извлечение данных». Этот результат до
бавляется к ipromt:

iprompt='Read the following input and write a summary for beginners.'
lprompt=iprompt + " " + results['documents'][0][0]

Дополненный ввод, используемый для вызова Llama (завершенный текст), назы
вается lprompt. Следующий код будет измерять время его создания и выполнять
запрос:

import time
start_time = time.time()    # Начинаем отсчет перед запросом

response=LLaMA2(lprompt)

Теперь извлекаем из ответа сгенерированный текст и выводим время, которое
потребовалось Llama для его генерации:

for seq in response:
    # Удаляем из вывода часть, представляющую ввод
    generated_part = seq['generated_text'].replace(iprompt, '')

response_time = time.time() - start_time    # Измеряем время ответа
print(f"Response Time: {response_time:.2f} seconds")  # Выводим время ответа

Результат показывает, что Llama вернула завершенный текст за вполне адекват
ный промежуток времени:

 Response Time: 5.91 seconds

Теперь оформим ответ в более читабельный формат для вывода:
wrapped_response = textwrap.fill(response[0]['generated_text'], width=70)
print(wrapped_response)
