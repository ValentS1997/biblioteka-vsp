display_video(file_name) выводит скачанное видео, сначала преобразуя его
в base64 — схему кодирования двоичных данных в текстовом формате ASCII.
Далее кодированное видео выводится в виде HTML:

# Открываем файл в двоичной форме
def display_video(file_name):
    with open(file_name, 'rb') as file:
      video_data = file.read()

  # Кодируем видео в формат base64
  video_url = b64encode(video_data).decode()

  # Создаем HTML-строку, встраивая в нее видео
  html = f'''
  <video width="640" height="480" controls>
    <source src="data:video/mp4;base64,{video_url}" type="video/mp4">
  Your browser does not support the video tag.
  </video>
  '''
  # Выводим видео
  HTML(html)
  # Возвращаем HTML-объект
  return HTML(html)

display_video_frame получает в качестве аргументов file_name, frame_number
и size (размер изображения для вывода), показывая кадр из видео. Эта функция
сначала открывает видеофайл, после чего определяет количество кадров в нем,
указываемое параметром frame_number:

def display_video_frame(file_name, frame_number, size):
    # Открываем видеофайл
    cap = cv2.VideoCapture(file_name)

    # Переходим к frame_number
    cap.set(cv2.CAP_PROP_POS_FRAMES, frame_number)

    # Считываем кадр
    success, frame = cap.read()
    if not success:
      return "Failed to grab frame"
