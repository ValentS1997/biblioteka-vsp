294     Глава 10. RAG для создания стоковых видео с помощью Pinecone и OpenAI

      # Корректно используем переменную Python 'path' в команде оболочки
      !cp {cpath} /content/drive/MyDrive/files/comments/{cpath}
      print(f"File {cpath} copied successfully.")
  else:
      print(f"No such file: {cpath}")

Вывод подтверждает успешное сохранение файла:

 File alpinist1.mp4.csv copied successfully.

Кадры сохраняются в виде имени файла без расширения, которое мы удаляем
с помощью root_name = root_name + extension.strip('.'):

# Сохраняем кадры
import shutil
if save_frames==True:
  # Извлекаем основное имя файла, удаляя его расширение
  root_name, extension = os.path.splitext(file_name)
  # Этот код удаляет из расширения точку
  root_name = root_name + extension.strip('.')
  # Путь к тому месту, куда вы хотите скопировать файлы jpg
  target_directory = f'/content/drive/MyDrive/files/comments/{root_name}'
  # Проверяем существование каталога
  os.makedirs(target_directory, exist_ok=True)
  # Предполагается, что ваши файлы jpg находятся в текущем каталоге.
  # При необходимости измените этот параметр
  source_directory = os.getcwd()    # Или укажите другой каталог
  # Выводим все файлы jpg в исходном каталоге
  for file in os.listdir(source_directory):
      if file.endswith('.jpg'):
        shutil.copy(os.path.join(source_directory, file), target_directory)

В выводе мы получим каталог, содержащий все сгенерированные кадры. Если
контроллер будет циклически перебирать все видео в одном сеансе, полученные
файлы перед каждым новым видео нужно будет удалять.

Удаление файлов
Для удаления просто установите delf=True:
delf=False        # Перепроверяем, прежде чем удалять файлы сеанса
if delf==True:
  !rm -f *.mp4    # Видеофайлы
  !rm -f *.jpg    # Кадры
  !rm -f *.csv    # Комментарии

Теперь вы можете поочередно обрабатывать неограниченное число видео и мас
штабировать датасет до любого размера при наличии достаточного пространства
на диске и CPU.
