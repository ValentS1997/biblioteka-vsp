206     Глава 7. Создание масштабируемой RAG на основе графа знаний

Компонент 1: сбор и подготовка документов
Код, приводимый в этом разделе, извлекает нужные метаданные из Википедии,
скачивает связанные с ними документы, очищает их и подготавливает для встав
ки в векторную базу данных Deep Lake. Этот процесс схематично изображен на
рис. 7.4.

                      Рис. 7.4. Блок-схема компонента 1

Компонент 1 включает два блокнота кода:
z  Wikipedia_API.ipynb, где мы реализуем API Википедии для извлечения URL
   страниц, связанных с корневой страницей выбранной темы, включая цитаты.
  Как уже говорилось, в нашем случае темой будет «маркетинг»;
z Knowledge_Graph_Deep_Lake_LlamaIndex_OpenAI_RAG.ipynb, где мы реализу
   ем все три компонента. Компонент 1 будет получать URL-адреса из блок
   нота Wikipedia_API, очищать их, а также агрегировать и загружать в базу
   данных.

Начнем с реализации API Википедии.

Извлечение данных и метаданных из Википедии
Сначала создадим программу для взаимодействия с API Википедии с целью
извлечения информации по конкретной теме, токенизации полученного текста
и управления ссылками на источники из статей Википедии. Далее можете от
крыть блокнот Wikipedia_API.ipynb в репозитории GitHub и продолжать по
нему.
