Компонент 1: генератор и комментатор     291

Далее устанавливается частота выборки, которую можно изменять с помощью
счетчика:

nb=3        # Частота выборки
counter=0   # Счетчик частоты выборки

После этого комментатор перебирает выбранные кадры и запрашивает по ним
комментарий:

for frame_number in range(total_frames):
    counter+=1    # Выборка
    if counter==nb and counter<total_frames:
      counter=0
      print(f"Analyzing frame {frame_number}...")
      image_path = os.path.join(video_folder, f"frame_{frame_number}.jpg")
      try:
          with open(image_path, "rb") as image_file:
              image_data = image_file.read()

              response = openai.ChatCompletion.create(
                 model="gpt-4-vision-preview",

Его вопрос очень сжат: "What is happening in this image?" («Что происходит на
этом изображении?») и включает также само изображение кадра:

              messages=[
                 {
                      "role": "user",
                      "content": [
                        {"type": "text", "text": "What is happening in this image?"},
                       {
                            "type": "image",
                            "image_url": f"data:image/jpeg;base64,{base64.
                               b64encode(image_data).decode('utf-8')}"
                        },
                    ],
               }
            ],
            max_tokens=150,
        )

После получения ответа для извлечения и сохранения комментария вызываются
функции generate_comment и save_comment соответственно:

    comment = generate_comment(response)
    save_comment(comment, frame_number,file_name)

except FileNotFoundError:
    print(f"Error: Frame {frame_number} not found.")
except Exception as e:
    print(f"Unexpected error: {e}")
