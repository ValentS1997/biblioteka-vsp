240     Глава 8. Создание динамических RAG с помощью Chroma и Hugging Face Llama

В текущем сценарии мы сначала проверяем, существует ли коллекция, после чего
загружаем id и documents в complete_list, сохраняя тип (type) данных, а именно
completion, в поле metadatas:

# Избежание повторной загрузки данных в этом блокноте создания динамической RAG
if collection_exists!=True:
  # Преобразуем в эмбеддинги и сохраняем первые nb пояснительных текстов
  # для этой демонстрации
  collection.add(
      ids=[str(i) for i in range(0, nb)],    # ID – это просто строки
      documents=completion_list,
      metadatas=[{"type": "completion"} for _ in range(0, nb)],
  )

В завершение также измеряем время ответа:
response_time = time.time() - start_time    # Измеряем время ответа
print(f"Response Time: {response_time:.2f} seconds")  # Выводим время ответа

Вывод показывает, что в данном случае Chroma активировала предустановлен
ную модель через onnx, о чем говорилось в начале текущего раздела и в разделе
«Настройка среды»:

 /root/.cache/chroma/onnx_models/all-MiniLM-L6-v2/onnx.tar.gz: 100%|██████████|
 79.3M/79.3M [00:02<00:00, 31.7MiB/s]

В выводе также отражается время обработки более чем 10 000 документов, в дан
ном случае удовлетворительное:

 Response Time: 234.25 seconds

Время ответа может варьироваться и зависит от того, задействуете ли вы для
обработки GPU. При использовании GPU время выполнения вписывается в тре
бования для сценариев динамических RAG.
На этом заполнение базы данных Chroma завершено. Теперь взглянем на полу
ченные эмбеддинги.

Вывод эмбеддингов
Далее программа получает эмбеддинги и выводит первый:
# Получение эмбеддингов из коллекции
result = collection.get(include=['embeddings'])

# Извлечение из результата первого эмбеддинга
first_embedding = result['embeddings'][0]

# Если вам нужно поработать с длиной первого эмбеддинга:
embedding_length = len(first_embedding)

print("First embedding:", first_embedding)
