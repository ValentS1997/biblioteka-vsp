Сначала устанавливаем необходимую библиотеку wikipediaapi:
try:
  import wikipediaapi
except:
  !pip install Wikipedia-API==0.6.0
  import wikipediaapi

Далее определяем функцию токенизации, которая будет вызываться для подсчета
количества токенов в сводке:

def nb_tokens(text):
    # Более сложная токенизация, включая пунктуацию
    tokens = word_tokenize(text)
    return len(tokens)

Эта функция получает строку текста и возвращает количество содержащихся
в ней токенов, задействуя библиотеку NLTK, позволяющую выполнить расши
ренную токенизацию. Далее, чтобы начать извлечение данных, нужно настроить
экземпляр API Википедии, используя определенный язык и строку user_agent:

# Создаем экземпляр API Википедии с подробной строкой user_agent
wiki = wikipediaapi.Wikipedia(
    language='en',
    user_agent='Knowledge/1.0 ([USER AGENT EMAIL)'
)

В этом случае с помощью 'en' мы установили английский язык, и далее вам
нужно ввести информацию для user_agent, например адрес почты. Теперь можно
определить основную тему и имя файла, связанные с интересующей нас страни
цей Википедии:

topic="Marketing"     # Тема
filename="Marketing"  # Имя файла для сохранения вывода
maxl=100

Здесь мы определяем три параметра:
z  topic — тема для извлечения;
z  filename — имя темы. Оно будет определять содержимое создаваемых нами
   файлов, которые от самой темы могут отличаться;
z  maxl — максимальное количество ссылок URL на извлекаемых страницах.

Теперь нужно извлечь сводку по указанной странице Википедии, проверить
существование этой страницы и вывести ее содержимое:

import textwrap    # Для форматирования текста вывода в виде абзацев
page=wiki.page(topic)

if page.exists()==True:
  print("Page - Exists: %s" % page.exists())
