Создание эмбеддингов и их загрузка
в коллекцию Chroma
Начнем с создания клиента Chroma и определения коллекции:
# Импортируем Chroma и инстанцируем клиента. По умолчанию клиент Chroma
# создается временно и на диск ничего не сохраняет
import chromadb
client = chromadb.Client()
collection_name="sciq_supports6"

Прежде чем создавать коллекцию и загружать в нее данные, нужно проверить,
не существует ли уже такая коллекция:

# Перебираем все коллекции
collections = client.list_collections()

# Проверяем, есть ли среди них конкретная коллекция
collection_exists = any(collection.name == collection_name for collection
  in collections)
print("Collection exists:", collection_exists)

Если коллекция существует, вывод будет True, если нет — False:

 Collection exists: False
