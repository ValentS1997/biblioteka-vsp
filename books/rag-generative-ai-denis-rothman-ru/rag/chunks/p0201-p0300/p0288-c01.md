288     Глава 10. RAG для создания стоковых видео с помощью Pinecone и OpenAI

Генератор и комментатор создают прокомментированные кадры, необходимые
для четырех основных шагов, которые мы реализуем на Python.

1. Генератор на основе текстового ввода генерирует датасет видео, используя
   inVideo. В этой главе темой датасета будет спорт.
2. Генератор выполняет масштабирование, выбирая по одному видео за раз.
3. Генератор разбивает видео на кадры (изображения).
4. Комментатор выбирает кадры (изображения) и комментирует их с помощью
  LLM. Он сохраняет каждый прокомментированный кадр, включая:
     уникальный ID;
     комментарий;
     сам кадр;
     имя видеофайла.

Далее мы создадим генератор и комментатор на Python, начав со сгенерирован
ных с помощью ИИ видео. Откройте блокнот Pipeline_1_The_Generator_and_
the_Commentator.ipynb из каталога этой главы на GitHub. Описание настройки
среды для блокнота приводится в разделе «Настройка среды». Переход от видео
к готовым комментариям выборки кадров с помощью Python происходит в три
простых шага.

1. Вывод видео.
2. Разделение видео на кадры.
3. Комментирование кадров.

Для каждого из этих этапов мы определим функции и будем вызывать их в раз
деле Pipeline-1 Controller программы. В первую очередь определяется функция
для вывода видео.
