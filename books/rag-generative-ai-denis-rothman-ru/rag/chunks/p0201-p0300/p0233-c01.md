Настройка среды     233

Это делается через пайплайн Hugging Face:
pipeline = transformers.pipeline(
    "text-generation",
    model=model,
    torch_dtype=torch.float16,
    device_map="auto",
)

Разберем его.
z  transformers.pipeline — функция для создания пайплайна генерации текста.
  Он абстрагирует значительную часть сложности, которой в системе динами
   ческой RAG желательно избегать.
z  text-generation указывает тип задачи, для которой настроен пайплайн. В на
  шем случае это генерация текста.
z  model указывает выбранную модель.
z torch_dtype=torch.float16 устанавливает тип данных тензоров PyTorch на
   float16. Это ключевой момент в динамических RAG, который сокращает
   потребление памяти и может ускорять вычисления, в частности, на GPU,
  поддерживающих вычисления с использованием чисел половинной точности.
  В таких вычислениях для ускорения обработки задействуется 16 бит, то есть
   половина стандартной 32-битной точности. Как раз то, что нам нужно.
z device_map="auto" просит пайплайн автоматически определять наилучшее
   устройство для выполнения модели (CPU, GPU, мультиGPU и т. д.). Этот
   параметр особенно важен для оптимизации производительности и динами
   ческого распределения слоев модели по доступным устройствам (например,
  GPU) максимально эффективным способом. Если системе доступны несколь
   ко GPU, нагрузка будет распределяться по всем параллельно. Если у вас есть
   доступ к GPU, активируйте эту функцию для ускорения пайплайна.
