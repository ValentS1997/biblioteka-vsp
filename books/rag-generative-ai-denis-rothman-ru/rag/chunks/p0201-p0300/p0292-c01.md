Последней нужной нам функцией комментатора будет вывод комментариев
путем загрузки созданного CSV-файла в DataFrame:

# Считываем файл комментариев к видео в DataFrame библиотеки Pandas
def display_comments(file_name):
  # Добавляем .csv к указанному имени файла, создавая полное имя файла
  path = f"{file_name}.csv"
  df = pd.read_csv(path)
  return df

Эта функция возвращает DataFrame с комментариями. За выполнение компо
нента 1, включая генератор и комментатор, отвечает контроллер.

Контроллер компонента 1 пайплайна
Контроллер запускает задачи всех трех предыдущих шагов. Он начинает с шага 1,
который включает выбор видео, его скачивание и вывод. В автоматизированном
пайплайне эти функции можно разделить. Например, скрипт будет перебирать
список видео, автоматически выбирать каждое и инкапсулировать функции
контроллера. В нашем же случае контекст образовательный, и здесь мы лишь
подготавливаемся к производству видео, так что будем собирать, скачивать и вы
водить ролики по одному:

session_time = time.time()    # Запуск отсчета перед запросом

# Шаг 1: вывод видео
# Выбираем файл
print("Step 1: Collecting video")
file_name = "skiing1.mp4"    # Вводим имя видеофайла для обработки
print(f"Video: {file_name}")

# Скачиваем видео
print("Step 1:downloading from GitHub")
directory = "Chapter10/videos"

# Выводим видео
print("Step 1:displaying video")

Затем контроллер разбивает видео на кадры и комментирует их:
