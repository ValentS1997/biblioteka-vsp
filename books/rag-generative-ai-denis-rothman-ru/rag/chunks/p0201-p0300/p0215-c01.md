Компонент 3: RAG на основе индексируемого графа знаний     215

Таким образом, индекс графа создается всего в нескольких строках кода:
# Индекс графа с эмбеддингами
graph_index = KnowledgeGraphIndex.from_documents(
    documents,
    max_triplets_per_chunk=2,
    include_embeddings=True,
)

Таймер останавливается, и вычисляется прошедшее время:
# Останавливаем таймер
end_time = time.time()
# Вычисляем и выводим время выполнения
elapsed_time = end_time - start_time
print(f"Index creation time: {elapsed_time:.4f} seconds")
print(type(graph_index))

Вывод:

 Index creation time: 371.9844 seconds

Выводим также тип графа:
print(type(graph_index))

Все верно, это граф знаний:

 <class 'llama_index.core.indices.knowledge_graph.base.KnowledgeGraphIndex'>

Теперь настроим механизм обработки запросов, который будет управлять пара
метрами измерения сходства, температуры и размера вывода:

#similarity_top_k
k=3
#temperature
temp=0.1
#num_output
mt=1024
graph_query_engine = graph_index.as_query_engine(similarity_top_k=k,
  temperature=temp, num_output=mt)

Эти параметры определяют поведение механизма обработки запросов.
z k=3 указывает, сколько максимально схожих результатов из общего числа
   будет учитываться.
z  temp=0.1 устанавливает температуру, регулирующую критерий случайности
  при генерации ответа механизмом обработки запросов. Чем она ниже, тем
   более точным должен быть вывод, и наоборот, высокие значения ведут к более
   креативным результатам.
