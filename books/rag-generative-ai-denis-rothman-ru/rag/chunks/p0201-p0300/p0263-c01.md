Здесь мы видим, что задача 0 имеет статус running. Статус информирует вас
о различных этапах процесса, таких как validating the files (проверка файлов),
running (выполнение), failure (сбой) или succeeded (завершено). Если регулярно
обновлять эту ячейку, то вы увидите изменение статуса.
Теперь извлечем последнюю обученную модель из столбца Fine-Tuned Model.
Если обучение провалится, он окажется пустым. В противном случае можно
будет ее извлечь:

import pandas as pd

# Пока текущая модель проходит тонкую настройку,
# ищем первую непустую настроенную модель
generation=False
non_empty_models = df[df['Fine-Tuned Model'].notna() & (df['Fine-Tuned Model'] != '')]

if not non_empty_models.empty:
    first_non_empty_model = non_empty_models['Fine-Tuned Model'].iloc[0]
    print("The latest fine-tuned model is:", first_non_empty_model)
    generation=True
