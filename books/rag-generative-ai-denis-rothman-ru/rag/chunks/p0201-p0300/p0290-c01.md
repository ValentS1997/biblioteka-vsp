Первым делом нужно создать функцию извлечения:
def generate_comment(response_data):
    """Extract relevant information from GPT-4 Vision response."""
    try:
        caption = response_data.choices[0].message.content
        return caption
    except (KeyError, AttributeError):
        print("Error extracting caption from response.")
        return "No caption available."

Далее мы напишем функцию для сохранения извлеченного комментария в CSV-
файле с тем же именем, что и у файла видео:

def save_comment(comment, frame_number, file_name):
    """Save the comment to a text file formatted for seamless loading
       into a pandas DataFrame."""
    # Добавляем .csv к указанному имени файла, создавая полное имя файла
    path = f"{file_name}.csv"
    # Проверяем существование файла, чтобы понять, нужно ли добавлять заголовки
    write_header = not os.path.exists(path)

    with open(path, 'a', newline='') as f:
        writer = csv.writer(f, delimiter=',', quotechar='"', quoting=csv.QUOTE_MINIMAL)
        if write_header:
            # Если файл создается, добавляем заголовок
            writer.writerow(['ID', 'FrameNumber', 'Comment', 'FileName'])
            # Генерируем для каждого комментария уникальный UUID
            unique_id = str(uuid.uuid4())
            # Записываем данные
            writer.writerow([unique_id, frame_number, comment, file_name])

Задача — сохранить комментарий в формате, который мы сможем загрузить на
прямую в Pinecone:

z  ID — уникальный строковый ID, генерируемый с помощью str(uuid.uuid4());
z  FrameNumber — номер кадра комментируемого изображения JPEG;
z Comment — комментарий, сгенерированный моделью компьютерного зрения
   от OpenAI;
z  FileName — имя видеофайла.

Основная задача комментатора — генерировать комментарии с помощью модели
компьютерного зрения от OpenAI. Тем не менее в этом сценарии мы будем сохра
нять не все кадры, а лишь их выборку. Сначала программа определяет количество
кадров для обработки:
