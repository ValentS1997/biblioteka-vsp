Шаг 2. Разделение видео на кадры
Как и в предыдущем разделе, функция split_file(file_name) извлекает из ви
део кадры, только на этот раз расширим эту функцию для их сохранения в виде
файлов JPG:

def split_file(file_name):
  video_path = file_name
  cap = cv2.VideoCapture(video_path)

  frame_number = 0
  while cap.isOpened():
      ret, frame = cap.read()
      if not ret:
          break

      cv2.imwrite(f"frame_{frame_number}.jpg", frame)
      frame_number += 1
      print(f"Frame {frame_number} saved.")

  cap.release()

Мы разбили видео на кадры и сохранили их в виде изображений JPG вместе с со
ответствующими номерами кадров, обозначенных frame_number. На этом работа
генератора заканчивается и эстафету принимает комментатор.

Шаг 3. Комментирование кадров
Генератор начал с генерации видео на основе текста и закончил сохранением
полученных из этих видео кадров в виде изображений JPG. Теперь комментатор
займется комментированием этих кадров, используя три функции:

z generate_openai_comments(filename) просит модель компьютерного зрения
  GPT-4 проанализировать ответ, который содержит комментарий к кадру;
z  generate_comment(response_data) извлекает из ответа комментарий;
z  save_comment(comment, frame_number, file_name) сохраняет комментарий.
