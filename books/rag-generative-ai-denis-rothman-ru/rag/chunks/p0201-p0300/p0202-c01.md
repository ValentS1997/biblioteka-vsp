202     Глава 7. Создание масштабируемой RAG на основе графа знаний

                  Рис. 7.2. Экосистема графа знаний для RAG

  ПРИМЕЧАНИЕ
   В сценарии текущей главы мы не просто дополняем ввод, а реализуем расширенную
   систему извлечения, использующую модели OpenAI для создания эмбеддингов. Эта
   реализация покажет множество способов, которыми можно улучшить процесс из
   влечения данных в реальном времени с помощью LLM. Здесь нет никаких правил —
   применяем все, что работает.
