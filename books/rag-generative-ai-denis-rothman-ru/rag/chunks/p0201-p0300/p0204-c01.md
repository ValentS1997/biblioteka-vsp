204     Глава 7. Создание масштабируемой RAG на основе графа знаний

z  проверяется, какие связи являются дружескими;
z  дерево отрисовывается на основе выбранной схемы с разными стилями узлов
   для обозначения дружеских связей.

Например, сначала определяются набор пар узлов и наличие дружеских связей
между ними:

# Пары
pairs = [('a', 'b'), ('b', 'e'), ('e', 'm'), ('m', 'p'), ('a', 'z'), ('b', 'q')]
friends = {('a', 'b'), ('b', 'e'), ('e', 'm'), ('m', 'p')}

Обратите внимание, что ('a', 'z') не являются друзьями, так как в списке
friends их нет. То же самое касается ('b', 'q'). Между парами можно предста
вить любой тип отношений, например: возраст клиентов, общая сфера деятельно
сти, одна страна проживания и пр. Как вариант, список friends может содержать
связи между друзьями в социальных сетях, проживающими в одной стране, или
любой другой интересующий вас вид связи.

После этого программа создает дерево и проверяет его внутренние связи:
# Создаем дерево
tree, root = build_tree_from_pairs(pairs)
# Проверяем связи
check_relationships(pairs, friends)

Вывод показывает, какие пары являются друзьями, а какие — нет:

 Pair ('a', 'b'): friend
 Pair ('b', 'e'): friend
 Pair ('e', 'm'): friend
 Pair ('m', 'p'): friend
 Pair ('a', 'z'): not friend
 Pair ('b', 'q'): not friend

Эту информацию можно использовать для поиска сходства. Далее программа
рисует граф по схеме 'spring':

# Рисуем дерево
layout_choice = 'spring'    # Выбираем схему
draw_tree(tree, layout_choice=layout_choice, root=root, friends=friends)

Схема 'spring' строится по принципу симуляции пружин (spring), то есть ребра
в ней как бы притягивают узлы друг к другу, а сами узлы при этом отталкива
ются, что позволяет избегать их столкновения. Изучить и выбрать другие схемы
можно с помощью функции draw_tree. При этом можете изменять цвета и стили
связующих линий.
