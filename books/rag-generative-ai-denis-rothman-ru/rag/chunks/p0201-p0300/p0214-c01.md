214     Глава 7. Создание масштабируемой RAG на основе графа знаний

В этом разделе мы:
z сгенерируем индекс графа знаний;
z выведем граф;
z определим промт пользователя;
z определим гиперпараметры для встроенной в LlamaIndex модели LLM;
z установим пакеты для измерения сходства;
z определим функции оценки сходства;
z выполним несколько примеров оценки сходства с помощью соответствующих
   функций;
z переупорядочим векторы, выданные LLM;
z выполним серию примеров запросов, которые оценим с помощью метрик
  и обратной связи;
z вычислим метрики и выведем их.

Начнем с генерации индекса графа знаний.

Генерация индекса графа знаний
Этот индекс мы создадим на основе набора документов, используя класс
KnowledgeGraphIndex из модуля llama_index.core, и попутно замерим время его
создания для оценки производительности.

Соответствующая функция начинается с отсчета времени с помощью time.time().
В этом случае важно измерить затраченное время, так как создание индекса про
исходит небыстро:

from llama_index.core import KnowledgeGraphIndex
import time
# Запуск таймера
start_time = time.time()

Теперь создадим KnowledgeGraphIndex с эмбеддингами с помощью метода from_
documents. В функции будут использованы следующие параметры:

z  documents — набор документов для индексирования;
z  max_triplets_per_chunk, установленный на 2, что ограничит количество три
   плетов на чанк, чтобы было оптимизировано потребление памяти и время
   обработки;
z  include_embeddings, установленный на True, то есть эмбеддинги должны быть
   включены.
