Компонент 1: сбор и подготовка данных     173

  ПРИМЕЧАНИЕ
   Кластеризация по методу k-средних — это алгоритм ML для обучения модели без
   учителя. Он заключается в разделении датасета на k отдельных, не пересекающихся
   кластеров путем минимизации дисперсии в каждом из них. Этот алгоритм итеративно
   присваивает точки данных одному из k кластеров на основе ближайшего среднего
   (центроида), который повторно вычисляется после каждой итерации до момента
   схождения.

Теперь пошагово разберем код.

Подготовка и кластеризация данных
Сначала скопируем датасет data1 в data2, чтобы иметь возможность вернуться
к data1, если решим попробовать другие модели ML:

# Копирование data1 в data2
data2 = data1.copy()

Данные можно изучать, используя различные наборы признаков. В этом слу
чае мы выберем 'CreditScore', 'Age', 'EstimatedSalary', 'Exited', 'Complain'
и 'Point Earned':

# Импортируем библиотеки
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score , davies_bouldin_score
# Предполагается, что вы загрузили DataFrame data1 по инструкции
# Выбираем релевантные признаки
features = data2[['CreditScore', 'Age', 'EstimatedSalary', 'Exited',
  'Complain', 'Point Earned']]

Далее, прежде чем выполнять модель ML, масштабируем используемые при
знаки:

# Стандартизируем признаки
scaler = StandardScaler()
features_scaled = scaler.fit_transform(features)

Кредитный балл, примерная зарплата и заработанные очки, отражающие траты по
кредитной карте, хорошо демонстрируют финансовое положение клиента в банке.
Возраст в сочетании с перечисленными факторами показывает, что возрастные
клиенты более склонны продолжать пользоваться услугами банка, чем молодые.
Однако важно учесть, что жалобы могут поспособствовать уходу клиентов из
любой группы, поскольку этот критерий очень ярко коррелирует с оттоком.
