Компонент 2: масштабирование индекса Pinecone     179

Далее реализуем компонент 2, сосредоточившись на проблемных точках, выходя
щих за рамки функциональности, с которой мы познакомились ранее. Откройте
блокнот Pipeline_2_Scaling_a_Pinecone_Index.ipynb в репозитории GitHub.
Начнем с настройки среды.

Настройка среды
Как уже говорилось, у нас в программе используются только Pinecone и OpenAI,
что позволяет избежать промежуточного ПО, платформ и ограничений. Сохра
ните ключ API в безопасном месте — в данном случае это Google Drive:

# Ключ API
# Сохраните ключ в файле и считывайте его оттуда (можете ввести его прямо
# в блокнот, но тогда он будет виден находящимся рядом людям)
from google.colab import drive
drive.mount('/content/drive')

Далее установим OpenAI и Pinecone:
!pip install openai==1.40.3
!pip install pinecone-client==5.0.1

В завершение инициализируем ключи API:
f = open("drive/MyDrive/files/pinecone.txt", "r")
PINECONE_API_KEY=f.readline()
f.close()
f = open("drive/MyDrive/files/api_key.txt", "r")
API_KEY=f.readline()
f.close()

# Ключ OpenAI
import os
import openai
os.environ['OPENAI_API_KEY'] =API_KEY
openai.api_key = os.getenv("OPENAI_API_KEY")
