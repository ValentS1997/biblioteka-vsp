Прежде чем использовать какую-либо модель, обязательно проверьте сопутству
ющие затраты и предоставляемые ею возможности: https://platform.openai.com/docs/
guides/embeddings/embedding-models.
Далее мы преобразуем чанки в эмбеддинги, но этот процесс требует продуман
ных решений, в частности, для эффективного управления большими датасетами
с учетом допустимой частоты вызовов API. В данном случае создадим пакеты
чанков, которые преобразуем в эмбеддинги:

import openai
import time

# Инициализация клиента OpenAI
client = openai.OpenAI()

# Инициализация переменных
start_time = time.time()    # Начало отсчета перед запросом
chunk_start = 0
chunk_end = 1000
pause_time = 3
embeddings = []
counter = 1

Будем преобразовывать по 1000 чанков за раз, установив chunk_start = 0 и chunk_
end = 1000. Чтобы избежать возможных ограничений OpenAI на частоту запросов
API, мы добавили pause_time = 3, то есть между отправкой пакетов станем делать
паузу в 3 с. Эмбеддинги будут сохраняться в embeddings = [], а подсчет пакетов
будет вестись, начиная с counter = 1.
