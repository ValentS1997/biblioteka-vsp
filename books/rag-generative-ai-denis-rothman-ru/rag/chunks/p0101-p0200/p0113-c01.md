Что такое мультимодальная RAG     113

Далее следует загрузка в память и выполнение запроса к мультимодальному
датасету VisDrone.

z D4. Мультимодальный процесс начинается с загрузки и визуализации мульти
   модального датасета. Затем путем навигации по структуре мультимодального
   датасета программа выбирает изображение и добавляет к нему ограничива
  ющие рамки.

После этого к VisDrone применяется та же последовательность действий, что
и к текстовому датасету.

z D4. Создание мультимодального механизма обработки запросов с помощью
   LlamaIndex происходит путем индексирования векторной базы данных
   VisDrone посредством VectorStoreIndex с последующей настройкой соз
   данного индекса для использования при обработке запросов. Этот процесс
   пересекается с этапом G4, так как модель GPT от OpenAI обрабатывает как
   извлечение данных, так и генерацию ответа.
z G1. Ввод от пользователя для механизма мультимодального поиска будет
   таким же, как и ввод, выполненный пользователем, для мультимодальной RAG,
   поскольку он станет применяться как для механизма LLM (в отношении тек
   стового датасета), так и для механизма мультимодальной обработки запросов
   (для датасета VisDrone).

На этой стадии мультимодальный датасет VisDrone загружен и механизм поиска
готов к применению. Задача ввода, выполненного пользователем, G1 заключа
ется в том, чтобы механизм обработки запросов LlamaIndex извлек из VisDrone
релевантные документы с помощью LLM — в нашем случае модели OpenAI.
Затем функции извлечения отследят полученный ответ до его источника в муль
тимодальном датасете, чтобы найти изображение из исходного узла. По сути,
мы задействуем механизм обработки запросов для нахождения изображения на
основе текстового ответа.

z G1, G2 и G4 при выполнении запроса к мультимодальному датасету VisDrone
   пересекаются в едином потоке обработки LlamaIndex.
z Обработка ответа G4, заключающаяся в поиске исходного узла и извлечении
   его изображения, возвращает нас к D4, то есть к выбору и обработке изобра
   жения.

К этому моменту у нас уже есть текстовый ответ и извлеченное изображение.
Теперь можно создать общую сводку и измерить показатель эффективности по
сле вывода времени, затраченного на каждый этап.

z G4. Генерируем мультимодальную сводку, которая будет включать совме
  щенный вывод, содержащий ответ LLM, и дополненный вывод, содержащий
   изображение из мультимодального ответа.
