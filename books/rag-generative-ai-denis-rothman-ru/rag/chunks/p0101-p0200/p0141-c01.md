Поскольку мы создаем генеративный ИИ на базе RAG с нуля, для ретривера по
требуются всего два пакета:

z  requests, HTTP-библиотека для извлечения документов Википедии:
   !pip install requests==2.32.3

z  beautifulsoup4 для скрапинга информации с веб-страниц:
   !pip install beautifulsoup4==4.12.3

Теперь нам нужен датасет.

1.2. Подготовка датасета
Для этого проекта мы будем извлекать документы Википедии путем их скрапин
га через URL-адреса. Каждый документ полученного датасета будет содержать
метки, полученные автоматически или присвоенные вручную. Это станет первым
этапом индексирования:

import requests
from bs4 import BeautifulSoup
import re

# URL-адреса статей Википедии, отображенные в ключевые слова
urls = {
    "prompt engineering": "https://en.wikipedia.org/wiki/Prompt_engineering",
    "artificial intelligence":"https://en.wikipedia.org/wiki/
    ➥Artificial_intelligence",
    "llm": "https://en.wikipedia.org/wiki/Large_language_model", "llms":
    "https://en.wikipedia.org/wiki/Large_language_model"
}

Каждому URL-адресу предшествует одна или более меток. Такого механизма
будет достаточно для относительно небольшого датасета.

В определенных проектах, включая экспериментальные, этот подход позволяет
сделать уверенный шаг от простой RAG (поиск содержимого по ключевым сло
вам) к поиску по датасету с помощью индексов (в данном случае меток). Далее
перейдем к обработке данных.
