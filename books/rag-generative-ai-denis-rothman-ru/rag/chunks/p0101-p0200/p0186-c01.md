186     Глава 6. Масштабирование банковских данных клиентов в системе RAG

Здесь мы указали, что будем использовать бессерверный экземпляр (spec) AWS
в регионе 'us-east-1'. Теперь можно создавать индекс (тип векторной базы дан
ных) под названием 'bank-index-50000':

import time
import pinecone
# Проверяем, существует ли такой индекс
# (если он создается впервые, то его не должно быть)
if index_name not in pc.list_indexes().names():
    # Если не существует, создаем
    pc.create_index(
        index_name,
        dimension=1536,    # Размерность модели эмбеддинга
        metric='cosine',
        spec=spec
    )
    # Ожидаем инициализации индекса
    time.sleep(1)
# Подключаемся к индексу
index = pc.Index(index_name)
# Просматриваем статистику индекса
index.describe_index_stats()

В этом коде мы добавили в index_name и spec два параметра:
z  dimension=1536, выражающий длину вектора эмбеддингов, которую можно
   подстраивать под выбранную модель;
z  metric='cosine', используемый для вычисления векторного сходства между
   эмбеддингами. Можно выбрать и другие метрики, например евклидово рас
   стояние (https://www.pinecone.io/learn/vector-similarity/).

После создания индекса программа выводит его описание:

 {'dimension': 1536,
 'index_fullness': 0.0,
 'namespaces': {},
 'total_vector_count': 0}

Количество векторов и заполненность индекса равны 0, так как векторное хра
нилище мы еще не заполняли. Отлично, теперь можно приступать к загрузке!
