114     Глава 4. Мультимодальная RAG

z  E. Наконец, вычисляем эффективность LLM и эффективность мультимодаль
   ной обработки. В завершение обобщаем эти показатели в едином показателе
   эффективности мультимодальной RAG.

Исходя из такой модульной системы RAG, можно сделать два вывода.

z Создаваемая в этой главе система представляет лишь один из множества
   способов применения генеративного ИИ на базе RAG в реальных проектах,
  каждый из которых будет иметь собственные задачи и архитектуру.
z Быстрая эволюция от генеративного ИИ к его сложному аналогу на базе RAG
   требует реализации тесно интегрированных кросс-платформенных компонен
   тов, таких как использованные в этой главе LlamaIndex, Deep Lake и OpenAI.
  Эти платформы интегрируются и со многими другими фреймворками, напри
   мер, Pinecone и LangChain, о которых речь пойдет в главе 6.

Перейдем к созданию описанной модульной RAG с помощью Python.

Создание мультимодальной RAG
для сферы БПЛА
В последующих разделах мы с нуля поэтапно создадим генеративный ИИ на базе
модульной RAG, используя Python. В ходе этого процесса реализуем:

z LLM под управлением LlamaIndex для обработки и интерпретации текста по
   теме БПЛА;
z мультимодальные датасеты Deep Lake, содержащие размеченные изображе
   ния, снятые дронами;
z функции для вывода этих изображений и определения на них объектов с по
  мощью ограничительных рамок (bounding box);
z  систему, способную отвечать на вопросы по технологии БПЛА с использова
  нием текста и изображений;
z метрики эффективности для измерения точности мультимодальных ответов,
   включая анализ изображений с помощью GPT-4o.
