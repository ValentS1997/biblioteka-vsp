Компонент 2: масштабирование индекса Pinecone     185

масштабирование, например, до 50 000 точек данных, после чего в той же про
порции увеличить время выполнения и стоимость.

Код будет простым. Сначала определим количество повторов данных:
# Определяем количество дублей
dsize = 5    # Можно установить любое значение от 1 до n
total=dsize * len(chunks)
print("Total size", total)

Далее программа продублирует чанки и соответствующие эмбеддинги:
# Инициализируем новые списки для продублированных чанков и эмбеддингов
duplicated_chunks = []
duplicated_embeddings = []

# Перебираем исходные списки и дублируем каждую запись
for i in range(len(chunks)):
    for _ in range(dsize):
        duplicated_chunks.append(chunks[i])
        duplicated_embeddings.append(embeddings[i])

Затем проверяем, совпадает ли количество чанков с количеством эмбеддингов:
# Проверяем размер продублированных списков
print(f"Number of duplicated chunks: {len(duplicated_chunks)}")
print(f"Number of duplicated embeddings: {len(duplicated_embeddings)}")

Наконец, вывод подтверждает, что данные были продублированы пять раз:

 Total size 50000
 Number of duplicated chunks: 50000
 Number of duplicated embeddings: 50000

Надо признать, что 50 000 точек данных — хороший стартовый объем, достаточ
ный для заполнения векторной БД. Теперь создадим индекс Pinecone.

Создание индекса Pinecone
В первую очередь нужно инициализировать ключ API, используя выбранное имя
переменной, после чего создать экземпляр Pinecone:

import os
from pinecone import Pinecone, ServerlessSpec
# Инициализация подключения к Pinecone (получите ключ API на app.pinecone.io)
api_key = os.environ.get('PINECONE_API_KEY') or 'PINECONE_API_KEY'
pc = Pinecone(api_key=PINECONE_API_KEY)

Экземпляр Pinecone pc создан. Теперь выберем имя индекса, облако и регион:
from pinecone import ServerlessSpec
index_name = [YOUR INDEX NAME]    # Например, 'bank-index-900'
cloud = os.environ.get('PINECONE_CLOUD') or 'aws'
region = os.environ.get('PINECONE_REGION') or 'us-east-1'
spec = ServerlessSpec(cloud=cloud, region=region)
