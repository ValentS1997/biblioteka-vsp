190     Глава 6. Масштабирование банковских данных клиентов в системе RAG

Далее отправляем к БД запрос с профилем клиента, которого в датасете нет:
query_text = "Customer Robertson CreditScore 632Age 21 Tenure 2Balance
0.0NumOfProducts 1HasCrCard 1IsActiveMember 1EstimatedSalary 99000 Exited
1Complain 1Satisfaction Score 2Card Type DIAMONDPoint Earned 399"

Запрос преобразуется в вектор с помощью той же модели, что использовалась
для преобразования датасета:

query_embedding = get_embedding(query_text,model=embedding_model)

Выполняем запрос и выводим результат:
query_results = index.query(vector=query_embedding, top_k=1, include_
metadata=True)    # Запрашиваем метаданные
#print("raw query_results",query_results)
print("processed query results")
display_results(query_results)    # Выводим результаты
response_time = time.time() - start_time    # Измеряем время ответа
# Выводим время ответа
print(f"Querying response time: {response_time:.2f} seconds")
