Создание масштабируемой
     RAG на основе графа знаний7      с помощью API Википедии
     и LlamaIndex

С увеличением датасета довольно быстро возрастает и сложность управления
им. В реальных проектах управление данными озадачивает еще больше, чем ИИ.
Руководители проектов, консультанты и разработчики постоянно находятся
в поиске необходимых данных для успешной реализации проекта, не говоря
уже о создании приложений генеративного ИИ на базе RAG. Данные зачастую
приходится так или иначе структурировать, принимая сложные решения. Ви
кипедия — хороший пример того, как масштабирование данных ведет к полу
чению преимущественно надежной, но порой все же некорректной информации.
Реальные проекты часто развиваются тем же путем, что и Википедия. Данные
скапливаются в компании, создавая сложности для администраторов БД, руко
водителей проектов и пользователей.

Одна из основных сложностей заключается в том, чтобы увидеть взаимосвязи
в больших объемах разнородных данных. Хорошим средством, позволяющим
визуализировать такие связи, являются графы знаний. Текущая глава начнется
с определения архитектуры экосистемы базы знаний, созданной для генератив
ного ИИ на базе RAG. Эта экосистема включает пайплайн из трех компонентов,
обеспечивающих сбор данных, заполнение векторной БД и выполнение програм
мы, использующей граф знаний и индексируемую RAG. Начнем с компонента 1,
представляющего собой сбор и подготовку документов, в котором создадим
программу для автоматического извлечения данных через API Википедии.
Мы просто выберем тему указанной страницы Википедии и позволим програм
ме извлечь метаданные, необходимые для сбора и подготовки соответствующих
документов. Это будет гибкая система, которая позволит выбирать любую тему.
Первым примером ее применения станет исследование базы знаний по марке
тингу, предназначенной для студентов, желающих повысить квалификацию.
После этого перейдем к компоненту 2 — созданию и заполнению векторной БД
Deep Lake. Здесь мы загрузим данные в векторную БД, разбив их на чанки с по
мощью Deep Lake и преобразовав в эмбеддинги с помощью OpenAI. Кроме того,
проанализируем датасет, чтобы понять, как это чудо современных технологий
справится с задачей.
