154     Глава 5. Повышение эффективности RAG за счет обратной связи от эксперта

В этом сценарии можно просто вывести время ответа:
print(f"Response Time: {response_time:.2f} seconds")  # Выводим время ответа

Вывод будет различаться в зависимости от скорости подключения к Интернету
и доступных мощностей серверов OpenAI. В данном случае результат такой:

 Response Time: 7.88 seconds

Небыстро, но онлайн-агентам ИИ требуется какое-то время на ответ. Решение
об удовлетворительности этого показателя остается за руководством. Теперь
перейдем к вычислению меры косинусного сходства.

3.2. Показатель косинусного сходства
Косинусное сходство опирается на измерение косинуса угла между двумя не
нулевыми векторами. В контексте анализа текста обычно это векторы значений
TF-IDF (Term Frequency — Inverse Document Frequency, частота слова — обратная
частота документа), отражающих веса слов текста, вычисленные на основе их
важности в контексте данного документа и всего корпуса.
Ввод для GPT-4o, представленный text_input, и ответ модели, представленный
gpt4_response, рассматриваются в TF-IDF как два отдельных документа. Функ
ция vectorizer преобразует эти документы в векторы, после чего vectorizer.fit_
transform([text1, text2]) соотносит количество совпадений закодированных
слов в тексте ввода и ответе, а также их значимости.

Цель — количественно оценить тематическое и лексическое совпадение с по
мощью следующей функции:

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

def calculate_cosine_similarity(text1, text2):
    vectorizer = TfidfVectorizer()
    tfidf = vectorizer.fit_transform([text1, text2])
    similarity = cosine_similarity(tfidf[0:1], tfidf[1:2])
    return similarity[0][0]

# Пример использования существующих функций
similarity_score = calculate_cosine_similarity(text_input, gpt4_response)

print(f"Cosine Similarity Score: {similarity_score:.3f}")

Механизм определения косинусного сходства сначала задействует TfidfVectorizer,
преобразующий два документа в векторы TF-IDF, после чего функция cosine_
similarity вычисляет сходство между этими векторами. Результат 1 говорит об
идентичности текстов, а 0 — об отсутствии сходства. Вот вывод нашей функции:

 Cosine Similarity Score: 0.697
