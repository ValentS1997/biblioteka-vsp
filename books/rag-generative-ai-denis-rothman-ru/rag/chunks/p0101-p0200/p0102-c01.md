102     Глава 3. Реализация индексируемой RAG

Теперь буквально в двух строках кода создадим древовидный индекс:
from llama_index.core import TreeIndex
tree_index = TreeIndex.from_documents(documents)

Далее проверим только что созданный класс:
print(type(tree_index))

Вывод подтверждает, что мы находимся в классе TreeIndex:

 <class 'llama_index.core.indices.tree.base.TreeIndex'>

Теперь можно создать механизм обработки запросов:
tree_query_engine = tree_index.as_query_engine(similarity_top_k=k,
temperature=temp, num_output=mt)

Параметры LLM мы определили в подразделе «Ввод, сделанный пользователем,
и параметры запроса» выше. Следующий код активирует запрос, измеряет время
его выполнения и обрабатывает ответ:

import time
import textwrap
# Начало отсчета
start_time = time.time()
response = tree_query_engine.query(user_input)
# Конец отсчета
end_time = time.time()
# Вычисление и вывод времени выполнения
elapsed_time = end_time - start_time
print(f"Query execution time: {elapsed_time:.4f} seconds")

print(textwrap.fill(str(response), 100))

И время выполнения запроса, и ответ получились удовлетворительными:

 Query execution time: 4.3360 seconds
