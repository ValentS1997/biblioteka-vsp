Создание мультимодальной RAG для сферы БПЛА     129

Обобщение мультимодального вывода
Мы шаг за шагом создали мультимодальную программу и теперь обобщим
результаты. Для этого создадим функцию, которая будет выводить исходное
изображение из ответа, полученного на запрос пользователя, затем выведем сам
запрос пользователя и результат LLM, а также итоговое изображение с рамками.

Начнем с функции для вывода исходного изображения, сохраненного мульти
модальным механизмом извлечения:

# 1. Ввод пользователя = user_input
print(user_input)
# 2. Ответ LLM
print(textwrap.fill(str(llm_response), 100))
# 3. Мультимодальный ответ
image_path = "/content/boxed_image.jpg"
display_source_image(image_path)

Теперь можно вывести запрос пользователя, ответ LLM и мультимодальный ответ.
Начинается вывод с текстовой информации (запроса пользователя и ответа LLM):

 How do drones identify a truck?
 Drones can identify a truck using visual detection and tracking methods, which
 may involve deep neural networks for performance benchmarking.

Затем выводится изображение, на котором в данном случае рамками обведены
грузовики (рис. 4.8).
