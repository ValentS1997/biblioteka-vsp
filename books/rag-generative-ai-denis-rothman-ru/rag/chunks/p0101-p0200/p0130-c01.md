130     Глава 4. Мультимодальная RAG

Добавив изображение к классическому ответу LLM, мы дополнили вывод.
Это позволяет обогатить систему генеративного ИИ за счет добавления инфор
мации как к вводу, так и к выводу. Тем не менее, как и в любой программе ИИ,
для разработки метрики оценки эффективности модели потребуется качествен
ная функциональность распознавания изображений.

Оценка эффективности
Для оценки эффективности мультимодальной RAG потребуется измерить
качество извлечения текста и изображения. В отношении текста это проделать
легко, а вот с изображениями посложнее. Анализ изображения из мультимо
дального ответа отличается от анализа текста. Мы выполнили поиск с помощью
мультимодального механизма обработки запросов на основе ключевого слова,
после чего спарсили ответ для вывода исходного изображения. Однако для
оценки последнего потребуется создать новый механизм. Но начнем с анализа
ответа LLM.

Оценка эффективности LLM
LlamaIndex органично вызывал модель OpenAI с помощью ее механизма обработ
ки запросов, например GPT-4, и предоставлял ответ с текстовым содержимым.
Для текстовых ответов мы будем использовать ту же метрику косинусного сход
ства, что в разделах «Оценка вывода с помощью метрики косинусного сходства»
главы 2 и «Механизм запроса индекса векторной базы данных» главы 3.

Приведенная далее функция оценивает сходство двух текстов, в данном случае
ввода и вывода, используя библиотеки sklearn и sentence_transformers:

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')

def calculate_cosine_similarity_with_embeddings(text1, text2):
    embeddings1 = model.encode(text1)
    embeddings2 = model.encode(text2)
    similarity = cosine_similarity([embeddings1], [embeddings2])
    return similarity[0][0]

Теперь можно вычислить сходство между нашим базовым вводом пользователя
и изначальным ответом LLM:

llm_similarity_score = calculate_cosine_similarity_with_embeddings(user_input,
  str(llm_response))
print(user_input)
print(llm_response)
print(f"Cosine Similarity Score: {llm_similarity_score:.3f}")
