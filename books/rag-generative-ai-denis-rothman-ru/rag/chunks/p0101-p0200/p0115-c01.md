Загрузка датасета для LLM
Начнем с загрузки датасета, созданного в главе 3. Не забудьте подставить путь
к своему:

import deeplake
dataset_path_llm = "hub://denis76/drone_v2"
ds_llm = deeplake.load(dataset_path_llm)

Вывод подтвердит, что датасет успешно загружен, и будет содержать соответ
ствующую ссылку:

 This dataset can be visualized in Jupyter Notebook by ds.visualize() or at
 https://app.activeloop.ai/denis76/drone_v2
 hub://denis76/drone_v2 loaded successfully.

Теперь создадим словарь для хранения данных, которые будут загружены
в DataFrame для последующего вывода:

import json
import pandas as pd
import numpy as np

# Создаем словарь для хранения данных
data_llm = {}

# Перебираем тензоры датасета
for tensor_name in ds_llm.tensors:
    tensor_data = ds_llm[tensor_name].numpy()

    # Проверяем, является ли тензор многомерным
    if tensor_data.ndim > 1:
        # Преобразуем многомерные тензоры в одномерные
        data_llm[tensor_name] = [np.array(e).flatten().tolist()
                                 for e in tensor_data]
    else:
        # Преобразуем одномерные тензоры в списки и декодируем текст
        if tensor_name == "text":
            data_llm[tensor_name] = [t.tobytes().decode('utf-8')
                                     if t else "" for t in tensor_data]
        else:
            data_llm[tensor_name] = tensor_data.tolist()

# Создаем из словаря DataFrame
df_llm = pd.DataFrame(data_llm)
df_llm
