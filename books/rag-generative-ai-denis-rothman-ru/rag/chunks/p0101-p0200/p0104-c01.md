104     Глава 3. Реализация индексируемой RAG

Аналогично древовидному индексу списковый индекс создается всего двумя
строками кода:

from llama_index.core import ListIndex
list_index = ListIndex.from_documents(documents)

Проверим созданный класс:
print(type(list_index))

Вывод подтверждает, что мы находимся в классе list:

 <class 'llama_index.core.indices.list.base.SummaryIndex'>

Списковый индекс — это SummaryIndex, который показывает, что скрыто вы
полняется серьезная оптимизация, а именно создаются сводки по документам.
Теперь с помощью фреймворка LlamaIndex можно использовать полученный
индекс в качестве механизма запросов:

list_query_engine = list_index.as_query_engine(similarity_top_k=k,
  temperature=temp, num_output=mt)

Параметры LLM остаются неизменными, чтобы можно было объективно срав
нить разные методы индексирования. Далее выполним запрос, сформулируем
ответ на него и выведем результат:

# Начало отсчета
start_time = time.time()
response = list_query_engine.query(user_input)
# Конец отсчета
end_time = time.time()
# Вычисление и вывод времени выполнения
elapsed_time = end_time - start_time
print(f"Query execution time: {elapsed_time:.4f} seconds")

print(textwrap.fill(str(response), 100))
