Создание чанков и их преобразование
в эмбеддинги
В текущем разделе мы разделим текст на предчанки и внесем их в список lines.
Не всегда есть возможность создать список предчанков, но, если это доступно,
таким образом можно повысить прозрачность модели, эффективность отслежи
вания данных и скорость обработки запросов. Сам же процесс создания чанков
довольно прост.

Создание чанков
Практика разбивки текста на предчанки — важный элемент управления датасе
тами. Мы можем создать чанки из списка предчанков, сохраненных ранее в виде
строк:

# Инициализируем пустой список для чанков
chunks = []

# Добавляем каждый чанк в виде отдельной строки
for line in lines:
    chunks.append(line)    # Каждая строка становится собственным чанком

# Теперь каждая строка рассматривается как отдельный чанк
print(f"Total number of chunks: {len(chunks)}")

Вывод показывает, что все данные были успешно обработаны:

 Total number of chunks: 10000

Но зачем вообще заморачиваться созданием чанков? Почему бы просто не ис
пользовать сами строки? Во многих случаях строки могут потребовать дополни
тельного контроля и обработки, например, если есть ошибки данных, упущенные
