Создание мультимодальной RAG для сферы БПЛА     131

В выводе мы наблюдаем пользовательский ввод, текстовый ответ на него и по
казатель косинусного сходства между этими текстами:

 How do drones identify a truck?
 How do drones identify a truck?
 Drones can identify a truck using visual detection and tracking methods, which
 may involve deep neural networks for performance benchmarking.
 Cosine Similarity Score: 0.691

Результат удовлетворительный. Но теперь нам нужно придумать способ оценки
эффективности мультимодального ответа.

Оценка мультимодального ответа
Для оценки точности соответствия возвращенного изображения запросу нельзя
просто опираться на метки датасета. В небольших наборах данных можно све
рить изображение вручную, но при больших масштабах системы необходимо
этот процесс автоматизировать. В текущем разделе мы используем функции
компьютерного зрения модели GPT-4o для анализа изображения, его парсинга
в поиске нужных объектов и вывода описания этого изображения. После этого
мы также с помощью метрики косинусного сходства сравним полученное тек
стовое описание с метками, которые изображение должно содержать, и выведем
описание этого изображения. Затем с помощью метрики косинусного сходства
оценим соответствие полученного описания меткам, которые на нем должны
быть. GPT-4o — это мультимодальная модель генеративного ИИ.

Сначала закодируем изображение в формат base64, чтобы упростить передачу
его данных в GPT-4o. Кодировка base64 преобразует двоичные данные, такие
как изображения, в символы ASCII, которые являются стандартными тексто
выми символами. Выполнить это преобразование важно, так как оно позволит
передавать данные изображения через протоколы наподобие HTTP, созданные
для оптимальной обработки именно текстовых данных. Это также исключит
возможные проблемы, связанные с передачей двоичных данных, например, их
повреждение или ошибки интерпретации.

Код, приведенный далее, кодирует исходное изображение с помощью модуля
Python base64:

import base64

IMAGE_PATH = "/content/boxed_image.jpg"

# Открываем файл изображения и кодируем его в строку base64
def encode_image(image_path):
    with open(image_path, "rb") as image_file:
        return base64.b64encode(image_file.read()).decode("utf-8")

base64_image = encode_image(IMAGE_PATH)
