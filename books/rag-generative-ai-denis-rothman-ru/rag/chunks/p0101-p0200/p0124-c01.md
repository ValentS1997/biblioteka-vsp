124     Глава 4. Мультимодальная RAG

                      Рис. 4.6. Изображение с рамками

Создание мультимодального
механизма обработки запросов
В этом разделе создадим запрос к датасету VisDrone и извлечем из него изобра
жение, подходящее под ввод, выполненный пользователем, который мы указали
в подразделе «Ввод пользователя для мультимодальной RAG» текущего блокно
та. Для этого сделаем следующее.

1. Создадим векторный индекс для каждой строки DataFrame df, содержащего
   изображения, данные о рамках объектов и метки из датасета VisDrone.
2. Создадим механизм обработки запросов, который будет запрашивать тексто
   вые данные из датасета, извлекать информацию о подходящем изображении
  и выводить ответ в виде текста.
3. Спарсим узлы ответа в поиске ключевых слов, связанных с вводом пользо
   вателя.
4. Спарсим узлы ответа в поиске исходного изображения.
5. Добавим рамки с исходного изображения в доработанное.
6. Сохраним изображение.
