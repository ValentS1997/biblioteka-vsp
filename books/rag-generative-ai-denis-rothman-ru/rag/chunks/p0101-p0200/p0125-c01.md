Создание мультимодальной RAG для сферы БПЛА     125

мультимодального датасета», не содержит уникальных индексов или эмбеддин
гов. Мы сами создадим их в памяти с помощью LlamaIndex.

Первым делом код присваивает уникальные ID содержимому DataFrame:
# DataFrame именуется 'df'
# Создаем уникальные ID на основе индексов строк
df['doc_id'] = df.index.astype(str)

Код, приведенный ранее, добавляет в DataFrame столбец doc_id, где каждой
записи присваивает уникальный идентификатор, преобразуя их индексы в стро
ки. Здесь инициализируется пустой список documents, который мы используем
для создания векторного индекса:

# Создаем документы (извлекаем текст, связанный с каждой меткой изображения)
documents = []

Теперь метод iterrows() перебирает каждую строку DataFrame, генерируя по
следовательность пар «индекс — строка»:

for _, row in df.iterrows():
    text_labels = row['labels']    # Теперь каждая метка стала строкой
    text = " ".join(text_labels)   # Соединяем текстовые метки в одну строку
    document = Document(text=text, doc_id=row['doc_id'])
    documents.append(document)

Далее добавляется documents со всеми записями в датасете, и DataFrame создан:
# DataFrame назван 'df'.
# Создаем уникальные ID на основе индексов строк
df['doc_id'] = df.index.astype(str)

# Создаем документы (извлекаем сопутствующий текст
# для каждой метки изображения)
documents = []
for _, row in df.iterrows():
    text_labels = row['labels']    # Теперь каждая метка стала строкой
    text = " ".join(text_labels)   # Объединяем текстовые метки в одну строку
    document = Document(text=text, doc_id=row['doc_id'])
    documents.append(document)

Документы готовы для индексирования с помощью GPTVectorStoreIndex:
from llama_index.core import GPTVectorStoreIndex
vector_store_index = GPTVectorStoreIndex.from_documents(documents)

в словаре:
