В качестве параметров для активации экспертной обратной связи выступа
ют counter_threshold и score_threshold. Количество оценок, поставленных
пользователями, должно превышать пороговое значение счетчика, а именно
counter_threshold=10. Порог среднего рейтинга в нашем сценарии составляет 4 —
score_threshold=4. Теперь симулируем срабатывание запроса оценки эксперта:

if counter>counter_threshold and score_history<=score_threshold:
  print("Human expert evaluation is required for the feedback loop.")

В этом случае вывод подтвердит необходимость привлечения экспертной обрат
ной связи из-за низкого среднего рейтинга и общего количества пользователь
ских оценок ответа модели:

 Human expert evaluation is required for the feedback loop.

Еще раз напомню, что в реальном проекте для определения интерфейса необ
ходимо организовать совещание с экспертами. В нашем сценарии стандартный
HTML-интерфейс на Python покажет значки «палец вверх» и «палец вниз». Если
эксперт нажмет «палец вниз», он сможет ввести текст обратной связи, который
будет сохранен в файле expert_feedback.txt. Вот соответствующий фрагмент
кода:

import base64
from google.colab import output
from IPython.display import display, HTML

def image_to_data_uri(file_path):
    """
    Convert an image to a data URI.
    """
    with open(file_path, 'rb') as image_file:
        encoded_string = base64.b64encode(image_file.read()).decode()
        return f'data:image/png;base64,{encoded_string}'

thumbs_up_data_uri = image_to_data_uri('/content/thumbs_up.png')
thumbs_down_data_uri = image_to_data_uri('/content/thumbs_down.png')
