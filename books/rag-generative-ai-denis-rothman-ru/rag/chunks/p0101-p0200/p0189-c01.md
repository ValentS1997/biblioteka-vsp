Запрос к индексу Pinecone
Теперь нужно проверить время обработки масштабированного индекса Pinecone.
Создадим функцию, которая будет обращаться к векторной базе данных и выво
дить результаты:

# Выводим результаты запроса и метаданные
def display_results(query_results):
  for match in query_results['matches']:
    print(f"ID: {match['id']}, Score:  {match['score']}")
    if 'metadata' in match and 'text' in match['metadata']:
        print(f"Text: {match['metadata']['text']}")
    else:
        print("No metadata available.")

Нам нужно, чтобы функция обработки запроса использовала ту же модель соз
дания эмбеддингов, с помощью которой мы преобразовывали чанки датасета:

embedding_model = "text-embedding-3-small"
def get_embedding(text, model=embedding_model):
    text = text.replace("\n", " ")
    response = client.embeddings.create(input=[text], model=model)
    embedding = response.data[0].embedding
    return embedding

import openai
