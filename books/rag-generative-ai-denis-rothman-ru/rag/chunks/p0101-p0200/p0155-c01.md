Этот показатель говорит о высоком сходстве между вводом и выводом модели.
Но как оценит этот вывод пользователь? Сейчас выясним.

3.3. Рейтинг оценок пользователей
Интерфейс оценки вывода пользователями позволяет собирать обратную связь.
И я уже неоднократно повторял, что этот интерфейс нужно разрабатывать, только
хорошо поняв потребности пользователей. В текущем разделе мы предположим,
что совет пользователей — это группа разработчиков ПО, тестирующих систему.

Код начинается с параметров интерфейса:
# Параметры оценки
counter=20           # Количество оценок пользователей
score_history=30     # Общий балл оценок
threshold=4          # Минимальный рейтинг для привлечения экспертной оценки

В этой симуляции параметры показывают, что система вычислила характери
стики обратной связи:

z  counter=20 — это количество уже присвоенных пользователями оценок;
z  score_history=30 показывает общий балл 20 оценок;
z threshold=4 указывает минимальный средний рейтинг, score_history/
   counter, для получения ответа без запроса информации из экспертного да
   тасета.

Теперь проверим этот интерфейс на примере. Приведенный далее код Python
определяет функцию evaluate_response, оценивающую релевантность и со
гласованность ответов, сгенерированных языковой моделью наподобие GPT-4.
Пользователи оценивают сгенерированный текст по шкале от 1 (плохо) до 5 (от
лично), а функция обеспечивает валидность ввода, рекурсивно повторяя вызов
в случае его недопустимости. Код вычисляет статистические метрики в виде
средних показателей, оценивая эффективность модели на нескольких итерациях.

Функция оценки представляет простой запрос обратной связи для получения
значения от 1 до 5:

import numpy as np
def evaluate_response(response):
    print("\nGenerated Response:")
    print(response)
    print("\nPlease evaluate the response based on the following criteria:")
    print("1 - Poor, 2 - Fair, 3 - Good, 4 - Very Good, 5 - Excellent")
    score = input("Enter the relevance and coherence score (1-5): ")
    try:
        score = int(score)
        if 1 <= score <= 5:
            return score
        else:
            print("Invalid score. Please enter a number between 1 and 5.")
