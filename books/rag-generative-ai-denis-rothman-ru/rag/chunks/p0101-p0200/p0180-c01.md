Далее загрузим датасет в DataFrame:
import pandas as pd
# Загружаем CSV-файл
file_path = '/content/data1.csv'
data1 = pd.read_csv(file_path)

Следим, чтобы было загружено 10 000 строк:
# Подсчет чанков
number_of_lines =  len(data1)
print("Number of lines: ",number_of_lines)

Вывод подтверждает присутствие всех строк:

 Number of lines: 10000

В этом сценарии очень важен следующий код, который преобразует каждую
строку с записью о клиенте в строку списка output_lines:

import pandas as pd

# Инициализируем пустой список для сохранения строк
output_lines = []

# Перебираем каждую строку DataFrame
for index, row in data1.iterrows():
    # Создаем список "column_name: value" всех имеющихся в строке столбцов
    row_data = [f"{col}: {row[col]}" for col in data1.columns]
    # Объединяем полученный список в строку, разделяя содержимое пробелами
    line = ' '.join(row_data)
    # Добавляем строку к итоговому списку
    output_lines.append(line)

# Выводим или дополнительно обрабатываем `output_lines`
for line in output_lines[:5]:   # Выводим первые пять строк для превью
    print(line)

Вывод показывает, что каждая строка в списке output_lines содержит текст от
дельной записи о клиенте:

 NumOfProducts: 1 HasCrCard: 1 IsActiveMember: 1 EstimatedSalary: 101348.88
 Exited: 1 Complain: 1 Satisfaction Score: 2 Card Type: DIAMOND Point Earned: 464…
