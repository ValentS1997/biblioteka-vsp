120     Глава 4. Мультимодальная RAG

Список меток показывает, что конкретно содержится в датасете:

 ['ignored regions',
  'pedestrian',
  'people',
  'bicycle',
  'car',
  'van',
  'truck',
  'tricycle',
  'awning-tricycle',
  'bus',
  'motor',
  'others']

На этом загрузка датасета завершена, перейдем к навигации по нему.

Навигация по мультимодальному датасету
В этом разделе мы выберем и выведем изображение, используя соответствующий
столбец, после чего добавим на него рамки, связанные с определенной меткой.
Сначала выбираем изображение.

Выбор и вывод изображения
Возьмем первое изображение датасета:
# Выбор изображения
ind=0
# Получение первого изображения и возвращение массива numpy
image = ds.images[ind].numpy()

Теперь выведем его без рамки:
import deeplake
from IPython.display import display
from PIL import Image
import cv2    # Импорт OpenCV

image = ds.images[0].numpy()

# Преобразование из BGR в RGB (если требуется)
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

# Создание и вывод изображения PIL
img = Image.fromarray(image_rgb)
display(img)

На выбранном изображении присутствуют грузовики, пешеходы и прочие типы
объектов (рис. 4.5).
