112     Глава 4. Мультимодальная RAG

                   Рис. 4.1. Мультимодальная система RAG

Для начала подробнее разберем схему мультимодальной RAG (см. рис. 4.1), из
влекающую информацию из нескольких источников. В списке далее курсивом
выделены названия разделов и для каждого этапа приводится его обозначение
на рисунке.

z  D4. Загрузка датасета для LLM с текстовой информацией о дронах из главы 3.
z  D4. Инициализация механизма запросов к LLM на основе индексированной век
   торной базы данных LlamaIndex посредством VectorStoreIndex и настройка
   созданного индекса для обработки запросов. Этот пункт пересекается с G4,
   так как модель OpenAI GPT будет выступать и в качестве ретривера, и в ка
   честве генератора.
z G1. Определение ввода, выполненного пользователем, для модульной RAG,
   который будет передаваться LLM (для текстового датасета) и мультимодаль
  ному механизму обработки запросов (для датасета VisDrone).
   После загрузки текстового датасета, создания механизма обработки запросов
  и определения базового запроса пользователя для текстового и мультимодаль
   ного наборов данных следует генерация ответа на основе текстового датасета,
   созданного в главе 2.
z При выполнении запроса к текстовому датасету этапы G1, G2 и G4 пересекаются
   в едином процессе LlamaIndex, обрабатывающем извлечение данных и генера
  цию ответа. Полученный ответ на время сеанса сохраняется в виде llm_response.
