Теперь создадим на основе DataFrame data1 тепловую карту:
import seaborn as sns
import matplotlib.pyplot as plt
# Выбираем для тепловой карты корреляций только численные столбцы
numerical_columns = data1.select_dtypes(include=['float64', 'int64']).columns
# Тепловая карта корреляций
plt.figure(figsize=(12, 8))
sns.heatmap(data1[numerical_columns].corr(), annot=True, fmt='.2f',
  cmap='coolwarm')
plt.title('Correlation Heatmap')

Максимальная корреляция наблюдается между Complain и Exited (рис. 6.4).

                      Рис. 6.4. Фрагмент тепловой карты

Представленная тепловая карта демонстрирует корреляцию между каждой парой
признаков (переменных) в датасете. Она показывает коэффициент корреляции
между каждой парой переменных, охватывающих диапазон от –1 (низкая корре
ляция) до 1 (высокая), где 0 указывает на отсутствие корреляции.

Таким образом, мы изучили несколько признаков. Теперь создадим модель
ML для более детального анализа.

Обучение модели ML
Продолжим анализ и теперь более детально разберем датасет с помощью ML.
В этом разделе мы обучим модель, используя технику кластеризации по мето
ду k-средних, после чего применим ее для поиска паттернов в наших данных.
Сначала подготовим и обработаем данные для анализа, затем применим к ним
кластеризацию и в завершение оценим результаты с помощью различных метрик.
Этот подход хорошо работает для получения представления без привлечения
более сложных методов глубокого обучения.
