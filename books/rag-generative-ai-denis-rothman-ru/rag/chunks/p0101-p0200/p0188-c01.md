        batch_size = get_batch_size(data[i:])

Для загружаемых данных нужно сгенерировать уникальные ID:
# Генерируем ID для каждого элемента данных:
ids = [str(i) for i in range(1, len(duplicated_chunks) + 1)]

Создадим также метаданные для загрузки датасета в БД Pinecone:
# Подготавливаем данные к загрузке
data_for_upsert = [
    {"id": str(id), "values": emb, "metadata": {"text": chunk}}
    for id, (chunk, emb) in zip(ids, zip(duplicated_chunks, duplicated_embeddings))
]

Теперь у нас есть все необходимое для загрузки data_for_upsert:
z  "id": str(ids[i]) содержит ID, которые мы создали, оттолкнувшись от на
   чального числа;
z  "values": emb содержит чанки, которые были преобразованы в векторы;
z  "metadata": {"text": chunk} содержит сами чанки.

Далее выполняем загрузку:
# Загрузка данных пакетами
batch_upsert(data_for_upsert)

Наконец, измеряем затраченное время:
# Измеряем время ответа

print(f"Upsertion response time: {response_time:.2f} seconds")
