Глава 8. Создание динамических RAG с помощью Chroma и Hugging Face Llama      315

10. Требуется ли участие человека на каждом этапе процесса для выполнения
    запроса к индексу графа знаний?
    Нет, запрос к индексу графа знаний делается автоматически, с минимальным
    участием человека.

 Глава 8. Создание динамических RAG
 с помощью Chroma и Hugging
 Face Llama
 1. Обеспечивает ли наш скрипт, чтобы токен Hugging Face API из соображений
    безопасности никогда не прописывался в самом блокноте?
    Да, этот скрипт предоставляет методы, позволяющие использовать для об
    работки токенов API либо Google Drive, либо ручной ввод, избегая жесткого
    прописывания их значений в коде.

 2. Библиотека accelerate в программе текущей главы использовалась для упро
   щения развертывания моделей ML на облачных платформах?
    Нет, accelerate используется для выполнения моделей с помощью локальных
    ресурсов, таких как несколько GPU, TPU и CPU, а не конкретно облачных
    платформ.

 3. Помимо токена API в этом скрипте для доступа к БД Chroma необходима
    также аутентификация пользователя?
    Нет, в скрипте не прописаны дополнительные механизмы аутентификации
   помимо использования для доступа к Chroma токена API.

 4. Chroma применяется в блокноте для временного хранения векторов в про
    цессе динамического извлечения данных?
    Да, скрипт задействует Chroma для временного хранения векторов с целью
    более эффективного извлечения данных.

 5. Блокнот настроен на использование механизма ускорения запросов в реаль
   ном времени за счет GPU?
    Да, accelerate позволяет задействовать ресурсы GPU для оптимизации
    запросов, что особенно полезно в контексте динамического извлечения
    данных.

 6. Можно ли использовать измеряемое в этом блокноте время сеанса для опти
   мизации процесса динамической RAG?
    Да, за счет измерения времени сеанса код блокнота позволяет понять, как
   можно оптимизировать процесс динамической RAG для достижения высокой
    эффективности выполнения.
