314     Приложение

Глава 7. Создание масштабируемой RAG
на основе графа знаний с помощью API
Википедии и LlamaIndex
1. Эта глава была посвящена созданию масштабируемой системы RAG на ос
   нове графа знаний с помощью API Википедии и LlamaIndex?
   Да, в ней описывается создание RAG на основе графа знаний с помощью этих
   инструментов.
2. Основной пример использования, рассмотренный в этой главе, касался здра
   воохранения и управления данными?
   Нет, основной пример относился к сфере маркетинга и пр.
3. Компонент 1 включает сбор и подготовку документов Википедии с помощью
  API?
   Да, компонент 1 автоматизирует сбор и подготовку документов, используя
  API Википедии.
4. В компоненте 2 платформа Deep Lake использовалась для создания реляци
   онной базы данных?
   Нет, Deep Lake используется для создания и заполнения векторной базы
   данных, а не реляционной.
5. В компоненте 3 фреймворк LlamaIndex применялся для создания индекса
   графа знаний?
   Да, в компоненте 3 LlamaIndex используется для автоматического создания
   индекса графа знаний.
6. Реализованная система предназначена для обработки только одной конкрет
   ной темы — маркетинга?
   Нет, это гибкая система, которая может обрабатывать различные темы по
  мимо маркетинга.
7. Описывается ли в этой главе, как извлекать URL-адреса и метаданные со
   страниц Википедии?
   Да, в ней объясняется процесс извлечения URL-адресов и метаданных с по
  мощью API Википедии.
8. Нужен ли для выполнения описанных в этой главе компонентов GPU?
   Нет, пайплайн спроектирован для эффективного выполнения с помощью
   одного только CPU.
9. Отображает ли индекс графа знаний связи между элементами данных?
   Да, индекс графа знаний наглядно демонстрирует семантические связи между
   данными.
