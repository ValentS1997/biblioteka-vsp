312     Приложение

 4. Основная цель адаптивной RAG — заменить весь ввод, выполненный пользо
    вателем, автоматизированными ответами?
    Нет, ее задача — совместить автоматическую обработку с обратной связью
    от человека.

 5. Может ли обратная связь в адаптивной RAG вызывать появление изменений
    в извлекаемых документах?
    Да, обратная связь может привести к обновлению извлеченных документов
    для улучшения качества дальнейших ответов.

 6. Компания C использует адаптивную RAG только для решения проблем
   службы поддержки?
    Нет, адаптивная RAG в ней применяется также для объяснения сотрудникам
   принципов работы ИИ.

 7. Обратная связь применяется, только когда ответы ИИ имеют высокую оценку
    пользователей?
    Нет, обратная связь часто применяется при низкой оценке ответов модели.

 8. Написанная в этой главе программа предоставляет только текстовый вывод
    извлеченных документов?
    Нет, в ней для ответов используется и текст, и обратная связь от эксперта.

 9. Гибридная адаптивная RAG статична, то есть не может корректироваться на
    основе обратной связи?
    Нет, она динамически корректируется в соответствии с обратной связью
   и оценками пользователей.

10. Оценки пользователей при определении релевантности ответа ИИ полностью
    игнорируются?
    Нет, оценки пользователей напрямую влияют на корректировку системы.
