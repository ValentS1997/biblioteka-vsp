Создание пайплайна RAG     61

Аутентификация
Вам потребуется зарегистрироваться в OpenAI для получения ключа API: https://
openai.com/. Не забудьте перед его использованием выбрать тарифный план. Для
начала активируем этот ключ:

# Извлечение и установка ключа OpenAI API
f = open("drive/MyDrive/files/api_key.txt", "r")
API_KEY=f.readline().strip()
f.close()

# Ключ OpenAI API
import os
import openai
os.environ['OPENAI_API_KEY'] =API_KEY
openai.api_key = os.getenv("OPENAI_API_KEY")

Затем активируем токен Activeloop API для Deep Lake:
# Извлечение и установка токена Activeloop API
f = open("drive/MyDrive/files/activeloop.txt", "r")
API_token=f.readline().strip()
f.close()
ACTIVELOOP_TOKEN=API_token
os.environ['ACTIVELOOP_TOKEN'] =ACTIVELOOP_TOKEN

Для получения этого токена зарегистрируйтесь на платформе Activeloop: https://
www.activeloop.ai/. Здесь тоже нужно выбрать тарифный план, прежде чем исполь
зовать этот токен.
После установки среды можете скрыть ячейки Installing the environment (рис. 2.4),
которые мы только что выполнили, чтобы сосредоточить внимание на компо
нентах пайплайна.

После сворачивания этих ячеек вы по-прежнему сможете их выполнять (рис. 2.5).

       Рис. 2.4. Сворачивание                   Рис. 2.5. Выполнение
         установочных ячеек                       свернутых ячеек

Теперь можно сосредоточиться на отдельных компонентах пайплайна. Начнем
со сбора и подготовки данных.
