Для хранения ключа вполне подойдет Google Drive или любой другой метод.
Вы можете как считывать его из файла, так и прописывать непосредственно в коде:

f = open("drive/MyDrive/files/api_key.txt", "r")
API_KEY=f.readline().strip()

# Ключ OpenAI
import os

функцию генерации для модели OpenAI.

2. Генератор
Приведенный далее код импортирует openai для генерации контента и time для
измерения времени выполнения запросов:

import openai
from openai import OpenAI
import time
client = OpenAI()
gptmodel="gpt-4o"
start_time = time.time()    # Начало отсчета времени перед запросом
