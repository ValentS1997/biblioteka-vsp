64     Глава 2. Хранение эмбеддингов RAG с помощью Deep Lake и OpenAI

Теперь напишем классическую функцию получения и очистки, которая будет воз
вращать красивый и чистый текст, извлекая из документов нужное нам содержимое:

def fetch_and_clean(url):
    # Получение содержимого по URL-адресу
    response = requests.get(url)
    soup = BeautifulSoup(response.content, 'html.parser')

    # Поиск основного содержания статьи; игнорируем дополнительные
    # информационные блоки и заголовки
    content = soup.find('div', {'class': 'mw-parser-output'})

    # Удаление раздела библиографии, который обычно имеет заголовок
    # наподобие References или Bibliography
    for section_title in ['References', 'Bibliography', 'External links',
        'See also']: section = content.find('span', id=section_title)
        if section:
            # Удаление всего содержимого, начиная с этого раздела
            # и до конца документа
            for sib in section.parent.find_next_siblings():
                sib.decompose()
            section.parent.decompose()

    # Извлечение и очистка текста
    text = content.get_text(separator=' ', strip=True)
    text = clean_text(text)
    return text

В итоге мы запишем очищенное содержание в файл llm.txt для команды, от
вечающей за создание и сохранение эмбеддингов:

# Файл для записи очищенного текста
with open('llm.txt', 'w', encoding='utf-8') as file:
    for url in urls:
        clean_article_text = fetch_and_clean(url)
        file.write(clean_article_text + '\n')

print("Content written to llm.txt")

Вывод подтверждает, что текст был успешно записан:

Эту программу можно изменить, чтобы она сохраняла данные в других форма
тах и местах в соответствии с задачами конкретного проекта. Полученный файл
можно проверить, прежде чем переходить к извлечению и обработке следующего
пакета данных:

# Открываем файл и считываем первые 20 строк
with open('llm.txt', 'r', encoding='utf-8') as file:
    lines = file.readlines()
    # Выводим первые 20 строк
    for line in lines[:20]:
        print(line.strip())
