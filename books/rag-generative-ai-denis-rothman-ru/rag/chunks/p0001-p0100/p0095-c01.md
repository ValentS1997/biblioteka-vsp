Ввод, сделанный пользователем,
и параметры запроса
В этом разделе ввод выступит опорным запросом для оценки четырех механиз
мов индексирования. Мы будем оценивать каждый ответ, исходя из результатов
поиска по индексу, и измерять качество выдачи по соотношению затраченного
времени и балла соответствия. Сами же механизмы индексирования и обработки
запросов создадим чуть позже.

Начнем с ввода:
user_input="How do drones identify vehicles?"

Четыре механизма обработки запросов, реализующие LLM (в нашем случае мо
дель OpenAI), будут поочередно вызываться с тремя одинаковыми параметрами:

# similarity_top_k
k=3
# temperature
temp=0.1
# num_output
mt=1024

Вот их описание.
z k=3 — механизм обработки запросов должен будет найти три наиболее ве
   роятных ответа. В этом случае k будет служить функцией ранжирования,
  требующей от LLM выбрать верхние документы из результата.
z  temp=0.1 — низкое значение температуры наподобие 0.1 настроит LLM на вы
   дачу точных результатов. Если этот параметр увеличить, скажем, до 0.9, ответ
   будет более вольным. Однако здесь мы имеем дело с технологией БПЛА, так
   что точность важна.
z  mt=1024 — этот параметр ограничит количество токенов выдачи до 1024.
