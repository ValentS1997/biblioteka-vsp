16     Предисловие

Глава 9 «Улучшение моделей ИИ: тонкая настройка данных RAG и обратная
связь» посвящена техникам тонкой настройки, используемым для системати
зации данных RAG. В ней акцент будет сделан на том, как трансформировать
обширные, непараметрические, сырые данные в более управляемый параметри
ческий формат с обучаемыми весами, подходящий для непрерывного взаимодей
ствия с ИИ. Здесь вы познакомитесь с процессом подготовки и тонкой настройки
датасета, применяя инструменты OpenAI для преобразования данных в промт
и заключительные пары1 для машинного обучения. Кроме того, в этой главе вы
научитесь использовать для тонкой настройки мини-модель GPT-4o, оценив ее
эффективность и экономичность.

Глава 10 «RAG для создания стоковых видео с помощью Pinecone и OpenAI» посвя
щена интеграции RAG в процесс производства стоковых видео для расширения
творческих возможностей человека автоматизацией на базе ИИ. В ней описывает
ся разработка ИИ-системы, которая создает, комментирует и размечает видеокон
тент, используя модели преобразования текста в видео и модели компьютерного
зрения от OpenAI наряду с возможностями векторных БД Pinecone. Начиная с ге
нерации видео и его технических комментариев, автор плавно переходит к управ
лению встраиваемыми видеоданными внутри векторного хранилища Pinecone.

Необходимые знания
Для наиболее полноценного освоения материала книги вам потребуются базовые
знания по обработке естественного языка и некоторый опыт работы с Python.
Кроме того, большинство программ в ней приводятся в виде блокнотов Jupyter.
Для их выполнения вам будет достаточно бесплатного аккаунта в сервисе Google
Gmail, который позволит запускать блокноты на виртуальной машине (virtual
machine, VM) Google Collaboratory. Потребуется также сгенерировать токены
API для OpenAI, Activeloop и Pinecone.

Для выполнения блокнотов нужно установить следующие модули.

 Модуль                  Версия

 openai                        1.40.3 (требует регулярного обновления)

 transformers                 4.41.2

 numpy                   ≥ 1.24.1 (обновлена для соответствия требованиям chex)

 deepspeed                    0.10.1

 bitsandbytes                 0.41.1

1  Имеются в виду пары «запрос — ответ».
