Создание пайплайна RAG     59

Это объясняет, почему данный компонент пайплайна должен идти отдельно. Его
реализация — простая задача для разработчика, которому нравится создавать
интерфейсы для взаимодействия с веб-средой. Он также отлично подходит для

Монтирование диска
В этом сценарии программа монтирует Google Drive в Google Colab для без
опасного считывания ключа API OpenAI, дающего доступ к моделям OpenAI,
а также токена Activeloop для аутентификации доступа к датасетам Activeloop
на платформе Deep Lake:

# Опция Google Drive для хранения ключей API.
# Сохраните свой ключ в файле и считывайте его (можете ввести его прямо
# в блокнот, но тогда он будет виден тем, кто находится рядом с вами).
from google.colab import drive
drive.mount('/content/drive')

Можете сохранить ключи и токены в другом месте. Главное, чтобы оно было
безопасным.

Создание подпроцесса для скачивания файлов с GitHub
Здесь мы напишем функцию для скачивания файла grequests.py с GitHub. Она
будет использовать для скачивания команду curl с возможностью при необхо
димости добавить закрытый токен:

import subprocess
url = "https://raw.githubusercontent.com/Denis2054/RAG-Driven-Generative-AI/main/
➥commons/grequests.py"
output_file = "grequests.py"

# Подготовка команды curl с использованием закрытого токена
curl_command = [
    "curl",
    "-o", output_file,
    url
]

# Выполнение команды curl
try:
    subprocess.run(curl_command, check=True)
    print("Download successful.")
except subprocess.CalledProcessError:
    print("Failed to download the file.")
