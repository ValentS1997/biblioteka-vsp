36     Глава 1. Почему именно генерация с дополненной выборкой (RAG)

Сначала программа импортирует нужные нам класс и функцию:
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

TfidfVectorizer импортирует класс, преобразующий текстовые документы в ма
трицу признаков TF-IDF (term frequency, inverse document frequency). TF-IDF
используется для количественной оценки важности слова для конкретного до
кумента из коллекции, позволяя отличать часто встречающиеся типичные слова
от имеющих особую значимость для определенных текстов. Производится эта
оценка на основе частоты его вхождений в документ и обратной частоты вхож
дений по всему корпусу. cosine_similarity импортирует функцию, которую мы
будем применять для вычисления сходства векторов.
Затем calculate_cosine_similarity(text1, text2) вычисляет косинусное сход
ство между запросом (text1) и каждой записью датасета.
Эта функция преобразует текст запроса (text1) и каждую запись (text2) датасета
в вектор с помощью векторизатора, после чего вычисляет и возвращает показа
тель косинусного сходства между двумя векторами:

def calculate_cosine_similarity(text1, text2):
    vectorizer = TfidfVectorizer(
        stop_words='english',
        use_idf=True,
        norm='l2',
        ngram_range=(1, 2),  # Используем униграммы и биграммы
        sublinear_tf=True,   # Применяем сублинейное TF-масштабирование
        analyzer='word'      # Можете поэкспериментировать с 'char' или
                             # 'char_wb' для признаков на уровне символов
    )
    tfidf = vectorizer.fit_transform([text1, text2])
    similarity = cosine_similarity(tfidf[0:1], tfidf[1:2])
    return similarity[0][0]

Вот ключевые параметры этой функции.
z  stop_words='english игнорирует распространенные английские слова, чтобы
   акцентироваться на смысловом содержании.
z  use_idf=True активирует механизм взвешивания на основе обратной частоты
   документа.
z  norm='l2' применяет к каждому выходному вектору нормализацию L2.
z  ngram_range=(1, 2) учитывает как одиночные слова, так и парные комбинации.
z sublinear_tf=True применяет логарифмическое масштабирование частоты
   термина.
z  analyzer='word' анализирует текст на уровне слов.
