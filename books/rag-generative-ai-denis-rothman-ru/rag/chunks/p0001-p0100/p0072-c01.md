72     Глава 2. Хранение эмбеддингов RAG с помощью Deep Lake и OpenAI

Теперь можно либо задействовать интерактивный ввод для получения запросов,
либо обрабатывать запросы пользователя пакетами. В нашем случае мы обраба
тываем уже введенный запрос пользователя, который можно получить, например,
из пользовательского интерфейса.

Сначала просим пользователя ввести или определить запрос:
def get_user_prompt():
    # Запрос ввода от пользователя
    return input("Enter your search query: ")

# Получение поискового запроса пользователя
# user_prompt = get_user_prompt()
user_prompt="Tell me about space exploration on the Moon and Mars."

Далее подставляем ввод, выполненный пользователем, в запрос поиска и сохра
няем вывод в search_results:

search_results = vector_store.search(embedding_data=user_prompt,
  embedding_function=embedding_function)

Ввод, сделанный пользователем, и результаты поиска, сохраненные в search_results,
форматируются для вывода на экран. Для начала выведем запрос пользователя:

print(user_prompt)

Зададим также нужную ширину вывода для его форматирования:
# Функция для вписывания текста в указанную ширину
def wrap_text(text, width=80):
    lines = []
    while len(text) > width:
        split_index = text.rfind(' ', 0, width)
        if split_index == -1:
            split_index = width
        lines.append(text[:split_index])
        text = text[split_index:].strip()
    lines.append(text)
    return '\n'.join(lines)

Но мы будем выбирать для вывода только верхний результат:
