df, response = index_query(user_input)
# Остановка отсчета
end_time = time.time()

elapsed_time = end_time - start_time
print(f"Query execution time: {elapsed_time:.4f} seconds")

# Вывод DataFrame в формате Markdown
print(df.to_markdown(index=False, numalign="left", stralign="left"))

Мы будем измерять время, необходимое механизму для извлечения релевант
ных данных, и генерировать синтезированный ответ с помощью LLM (в данном
случае модели OpenAI). Сначала в выводе семантического поиска отображается
ответ LLM:

 Drones can automatically identify vehicles across different cameras with
 different viewpoints and hardware specifications using reidentification methods.

Затем идет время выполнения запроса:

 Query execution time: 0.8831 seconds

И далее информация узла. Здесь выводится показатель релевантности каждого
узла, соответствующего одному из k=3 документов, вместе с фрагментами их
текста (рис. 3.4).

                      Рис. 3.4. Вывод информации узла

ID узла гарантирует полную прозрачность, и по нему можно проследить исход
ный документ даже после реорганизации индексов датасета механизмом индек
сирования. К примеру, узнать источник первого узла можно так:

nodeid=response.source_nodes[0].node_id
nodeid

В выводе мы увидим ID этого узла:

 4befdb13-305d-42db-a616-5d9932c17ac8

Можно углубиться и извлечь весь текст содержащего документ узла, который
был синтезирован LLM:

response.source_nodes[0].get_text()
