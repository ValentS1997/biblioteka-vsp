90     Глава 3. Реализация индексируемой RAG

Далее создадим векторную базу данных, заполним ее и индексируем документы:
# overwrite=True означает "перезаписать документ", а False – "дополнить"
vector_store = DeepLakeVectorStore(dataset_path=dataset_path, overwrite=True)
storage_context = StorageContext.from_defaults(vector_store=vector_store)
# Индексируем документы
index = VectorStoreIndex.from_documents(documents, storage_context=storage_context)
)

Заметьте, что для создания векторной базы данных и перезаписи существующей
overwrite устанавливается на True. Если overwrite=False, датасет будет просто
дополнен.

Созданные индексы будут реорганизованы в ходе последующего добавления
новых индексов и их переупорядочивания с помощью различных методов. Не
смотря на это, в ответе всегда будет указан изначальный источник данных. Сле
дующий вывод подтверждает успешное создание датасета и загрузку данных:

 Your Deep Lake dataset has been successfully created!
 Uploading data to deeplake dataset.
 100%|██████████| 41/41 [00:02<00:00, 18.15it/s]

В нем также отражается структура датасета после его заполнения:

 Dataset(path='hub://denis76/drone_v2', tensors=['text', 'metadata', 'embedding',
 'id'])

Данные хранятся в тензорах с указанием их типа и формы (рис. 3.3).
