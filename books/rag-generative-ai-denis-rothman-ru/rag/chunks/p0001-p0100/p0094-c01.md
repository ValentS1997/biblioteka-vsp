Теперь мы готовы к выполнению RAG на базе индексирования.

Компонент 3: RAG с индексированием
В этом разделе мы реализуем пайплайн RAG с индексированием с помощью
LlamaIndex, которая задействует подготовленные нами в Deep Lake данные.
Мы извлечем релевантную информацию из разнородных (с шумом) документов
по теме БПЛА и синтезируем ответ с помощью моделей LLM от OpenAI. Всего
мы создадим четыре механизма индексирования.

z На основе векторной базы данных. Создает из документов индексированное
   векторное хранилище, которое позволяет реализовать эффективный поиск
   на основе сходства векторов.
z На основе дерева. Строит иерархический древовидный индекс, представляю
  щий альтернативную структуру для извлечения данных.
z На основе списка. Создает простой индексированный список документов.
z На основе таблицы ключевых слов. Выстраивает индексированную таблицу
  ключевых слов, извлеченных из документов.

Механизм запросов реализуем с помощью LLM как запрос ответа и источника —
запрос индекса через ввод, выполненный пользователем, извлечение релевантных
документов и возвращение синтезированного ответа вместе с информацией об
использованном источнике.
