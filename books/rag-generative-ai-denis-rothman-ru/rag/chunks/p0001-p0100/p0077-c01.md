На этот раз мы используем архитектуру MiniLM и выполним задачу с помощью
all-MiniLM-L6-v2. Эта модель доступна на платформе Hugging Face Model Hub,
она — часть библиотеки sentence-transformers, являющейся расширением
Hugging Face Transformers. Мы выбрали эту архитектуру, так как она предостав
ляет компактную и эффективную модель с высокими качеством и скоростью
генерации содержательных эмбеддингов предложений. Реализуем ее с помощью
следующей функции:

from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')

def calculate_cosine_similarity_with_embeddings(text1, text2):
    embeddings1 = model.encode(text1)
    embeddings2 = model.encode(text2)
    similarity = cosine_similarity([embeddings1], [embeddings2])
    return similarity[0][0]

Теперь можно вызвать эту функцию для вычисления сходства между дополнен
ным вводом пользователя и ответом GPT-4:

similarity_score =
    calculate_cosine_similarity_with_embeddings(augmented_input, gpt4_response)
print(f"Cosine Similarity Score: {similarity_score:.3f}")

Более высокий показатель подтверждает, что библиотека Sentence Transformers
эффективнее отражает семантическое сходство между текстами:

 Cosine Similarity Score: 0.739
