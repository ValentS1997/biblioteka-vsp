96     Глава 3. Реализация индексируемой RAG

from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')

def calculate_cosine_similarity_with_embeddings(text1, text2):
    embeddings1 = model.encode(text1)
    embeddings2 = model.encode(text2)
    similarity = cosine_similarity([embeddings1], [embeddings2])
    return similarity[0][0]

В этой функции используются библиотеки sklearn и SentenceTransformer от
Hugging Face. Сначала программа создает механизм обработки запроса к век
торной базе данных.

Механизм индексирования
на основе векторов
VectorStoreIndex — это вид индекса в LlamaIndex, который для представления
информации и ее извлечения из документов использует эмбеддинги. Эмбеддинги
документов, имеющих высокое смысловое сходство, расположены близко друг
к другу в векторном пространстве, о чем мы говорили в предыдущей главе. Но на
сей раз VectorStoreIndex не будет автоматически использовать существующую
векторную базу данных Deep Lake. Этот механизм станет создавать новый век
торный индекс в памяти, заново преобразовывать документы в векторы и гене
рировать обновленную структуру индексов. В главе 4 мы разовьем этот подход,
реализуя датасет без индексов или эмбеддингов.

  ПРИМЕЧАНИЕ
   Нет универсального ответа на вопрос, какой метод индексирования больше подойдет
   для вашего проекта. Лучший способ выбрать — это протестировать представленные
   в текущей главе механизмы индексирования на основе векторов, дерева, списка
   и ключевых слов.

Сначала создадим индекс векторной БД:
from llama_index.core import VectorStoreIndex
vector_store_index = VectorStoreIndex.from_documents(documents)

Затем отобразим его:
print(type(vector_store_index))

Полученный вывод подтверждает, что механизм индексирования создан:

 <class 'llama_index.core.indices.vector_store.base.VectorStoreIndex'>
