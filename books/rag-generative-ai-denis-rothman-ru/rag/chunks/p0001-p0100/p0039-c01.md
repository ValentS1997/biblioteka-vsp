Генерация при этом будет выполняться так.
1. Дополнение пользовательского ввода результатами извлечения.
2. Обращение к модели генерации, которой в нашем случае будет GPT-4o.
3. Вывод ответа.

Начнем с реализации поиска по ключевым словам и сопоставления.

Поиск и сопоставление ключевых слов
Функция поиска максимального соответствия сначала инициализирует лучший
показатель:

def find_best_match_keyword_search(query, db_records):
    best_score = 0
    best_record = None

Затем запрос разделяется на ключевые слова. Каждая запись также разделяется
на слова для поиска общих ключевых слов, затем измеряется длина совпавшего
содержимого, после чего находится максимально схожий по количеству совпа
дений результат:

# Разделение запроса на ключевые слова
    query_keywords = set(query.lower().split())

    # Перебор каждой записи в db_records
    for record in db_records:
        # Разделение записи на ключевые слова
        record_keywords = set(record.lower().split())
        # Вычисление количества общих ключевых слов
        common_keywords = query_keywords.intersection(record_keywords)
        current_score = len(common_keywords)
        # Обновление лучшего показателя и его запись,
        # если текущий показатель выше
        if current_score > best_score:
            best_score = current_score
            best_record = record

    return best_score, best_record
