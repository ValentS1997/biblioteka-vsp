Теперь нужно создать функцию генерации эмбеддингов.

Функция генерации эмбеддингов
Эта функция будет преобразовывать чанки данных в векторы, позволяя в даль
нейшем использовать векторный поиск. В своей программе мы применим для
преобразования документов "text-embedding-3-small".
У OpenAI есть и другие модели создания эмбеддингов: https://platform.openai.com/
docs/models/embeddings. В подразделе «Создание эмбеддингов» главы 6 приводится
альтернативный код для подобных моделей. В любом случае рекомендуется оце
нивать эти модели, прежде чем выбирать конкретную для продакшена. Проверьте
указанные OpenAI характеристики каждой модели, обратив особое внимание на
их размер и возможности. Мы выбрали text-embedding-3-small, так как она вы
деляется своей эффективностью и скоростью:

def embedding_function(texts, model="text-embedding-3-small"):
    if isinstance(texts, str):
        texts = [texts]
    texts = [t.replace("\n", " ") for t in texts]
    return [data.embedding for data in openai.embeddings.create(input = texts,
        model=model).data]

Модель для создания эмбеддингов из текста text-embedding-3-small обычно
оперирует эмбеддингами с ограниченным числом измерений, балансируя между
достаточным количеством деталей, вычислительными затратами и занимаемым
местом. Перед выполнением кода обязательно ознакомьтесь с тарифным пла
ном: https://platform.openai.com/docs/guides/embeddings/embedding-models. Теперь можно
приступать к заполнению нашего векторного хранилища.
