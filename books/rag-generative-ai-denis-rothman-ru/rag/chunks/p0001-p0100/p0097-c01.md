Параметры этого механизма мы определили в подразделе «Ввод, сделанный

Ответ на запрос и его источник
Определим функцию, которая будет обрабатывать запрос и возвращать инфор
мацию о содержимом ответа:

import pandas as pd
import textwrap

def index_query(input_query):
    response = vector_query_engine.query(input_query)

    # Не обязательно: вывод форматированного представления ответа
    # (удалите, если вам в выводе это не нужно)
    print(textwrap.fill(str(response), 100))

    node_data = []
    for node_with_score in response.source_nodes:
        node = node_with_score.node
        node_info = {
            'Node ID': node.id_,
            'Score': node_with_score.score,
            'Text': node.text
        }
        node_data.append(node_info)

    df = pd.DataFrame(node_data)

    # Вместо вывода вернуть DataFrame и объект ответа
    return df, response,

index_query(input_query) выполняет запрос, используя обработку векторов,
и выдает результат в структурированной форме. Эта функция получает за
прос и извлекает релевантную информацию с помощью механизма обработки
запросов в виде DataFrame: Node ID, Score, File Path, Filename и Text.
