42     Глава 1. Почему именно генерация с дополненной выборкой (RAG)

методов, основанных на прямом парсинге текста, RAG сначала преобразует до
кументы и запросы пользователей в векторы, то есть численные представления,
которые ускоряют вычисления. Если коротко, то вектор — это список чисел,
представляющих различные признаки текста. Простые векторы могут отражать
количество вхождений слов (частотность термина, term frequency), а более
сложные, называемые эмбеддингами, отражают углубленные лингвистические
паттерны.

Реализуем векторный поиск и поиск по индексу.
z Векторный поиск. Мы преобразуем каждое предложение датасета в численный
   вектор. Вычислив косинусное сходство между вектором запроса (запроса
   пользователя) и этими векторами документов, сможем быстро найти наи
   более релевантные из них.
z Поиск по индексу. В этом случае все предложения преобразуются в векторы
   с помощью TF-IDF (Term Frequency — Inverse Document Frequency) — стати
   стической меры оценки степени важности слова для документа коллекции.
  Эти векторы выступают в качестве индексов в матрице, позволяя быстро
   сравнивать сходство без полного парсинга каждого документа.

Теперь понаблюдаем все это в действии, начиная с векторного поиска.

Векторный поиск
В результате векторного поиска запрос пользователя и документы преобразу
ются в векторы из численных значений, позволяя применить математические
вычисления для извлечения релевантных данных в условиях обработки больших
объемов данных.

Приведенная далее программа перебирает каждую запись датасета в поиске мак
симально соответствующего запросу документа путем вычисления косинусного
сходства вектора запроса и векторов этих записей.

def find_best_match(text_input, records):
    best_score = 0
    best_record = None
    for record in records:
        current_score = calculate_cosine_similarity(text_input, record)
        if current_score > best_score:
            best_score = current_score
            best_record = record
    return best_score, best_record

Затем код вызывает функцию векторного поиска и выводит найденную ею луч
шую запись:

best_similarity_score, best_matching_record = find_best_match(query, db_records)
print_formatted_response(best_matching_record)
