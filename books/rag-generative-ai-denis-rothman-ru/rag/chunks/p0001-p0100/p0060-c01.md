60     Глава 2. Хранение эмбеддингов RAG с помощью Deep Lake и OpenAI

Файл grequests.py содержит функцию, которая при необходимости может по
лучать закрытый токен или любой другой механизм безопасности, требующий
ввода учетных данных при извлечении информации командой curl:

import subprocess
import os

# При необходимости добавление закрытого токена после имени файла
def download(directory, filename):
    # Базовый URL файлов образов в репозитории GitHub
    base_url = 'https://raw.githubusercontent.com/Denis2054/
      RAG-Driven-Generative-AI/main/'

    # Полный URL файла
    file_url = f"{base_url}{directory}/{filename}"

    # Использование curl для скачивания файла, включая заголовок
    # Authorization закрытого токена
    try:
        # Подготовка команды curl с заголовком Authorization # curl_command = f'curl
        # -H "Authorization: token {private_token}" -o {filename} {file_url}'
        curl_command = f'curl -H -o {filename} {file_url}'

        # Выполнение curl
        subprocess.run(curl_command, check=True, shell=True)
        print(f"Downloaded '{filename}' successfully.")
    except subprocess.CalledProcessError:
        print(f"Failed to download '{filename}'. Check the URL, your
              internet connection, and if the token is correct and has
              appropriate permissions.")

Установка необходимых компонентов
Теперь установим компоненты, необходимые для работы с Activeloop Deep Lake
и OpenAI:

!pip install deeplake==3.9.18
!pip install openai==1.40.3

На момент написания книги представленная в Google Colab версия Pillow кон
фликтует с пакетом deeplake. Тем не менее установочный пакет deeplake обра
батывает этот конфликт автоматически. Вам лишь нужно перезапустить сеанс
и повторить попытку. Именно поэтому pip install deeplake==3.9.18 идет первой
строкой во всех блокнотах, где устанавливается.
После установки этих компонентов нужно отдельно выполнить строку кода,
чтобы Activeloop активировал публичный DNS-сервер:

# Для Google Colab и Activeloop(библиотека Deeplake)
# Этот код записывает в файл строку "nameserver 8.8.8.8", указывая,
# что DNS-сервер, который система должна использовать, находится
# по адресу 8.8.8.8; это один из публичных DNS-серверов Google
with open('/etc/resolv.conf', 'w') as file:
    file.write("nameserver 8.8.8.8")
