def find_best_match(query, vectorizer, tfidf_matrix):
    query_tfidf = vectorizer.transform([query])
    similarities = cosine_similarity(query_tfidf, tfidf_matrix)
    # Получаем индекс записи с максимальным показателем сходства
    best_index = similarities.argmax()
    best_score = similarities[0, best_index]
    return best_score, best_index

Вот основные задачи этой функции.
z Преобразование запроса. Преобразовать входящий запрос в вектор TF-IDF
   с помощью предоставленного векторизатора.
z Вычисление сходства. Вычислить косинусное сходство между вектором за
   проса и всеми векторами в tfidf_matrix.
z Поиск максимального совпадения. Найти в результатах индекс (best_index)
   записи с наивысшим показателем сходства.
z  Извлечение лучшего показателя. Извлечь максимальный показатель косинус
   ного сходства (best_score).

В выводе отображаются максимальный показатель сходства и индекс соответ
ствующей записи.
Следующий код сначала вызывает векторизатор датасета, после чего находит
запись с максимальным сходством по ее индексу:
