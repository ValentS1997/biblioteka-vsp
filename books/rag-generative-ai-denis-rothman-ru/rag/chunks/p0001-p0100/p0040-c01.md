40     Глава 1. Почему именно генерация с дополненной выборкой (RAG)

Основным запросом этого блокнота будет query = "define a rag store". С его по
мощью мы будем определять, выдаст ли каждый из реализуемых нами методов
RAG приемлемый результат.
В процессе поиска по ключевым словам была найдена лучшая запись из списка
предложений датасета:

 Best Keyword Score: 3
 Response:
 ---------------
 A RAG vector store is a database or dataset that contains vectorized data points.
 ---------------

Пора перейти к метрикам.

Метрики
Мы создали метрики оценки сходства в подразделе «1. Метрики оценки извле
чения» текущей главы. Сначала применим метрику косинусного сходства:

# Косинусное сходство
score = calculate_cosine_similarity(query, best_matching_record)
print(f"Best Cosine Similarity Score: {score:.3f}")

Показатель получился довольно низким, о чем говорится в том же разделе. Запрос
пользователя был коротким, а ответ получился более длинным и развернутым.

 Best Cosine Similarity Score: 0.126

Оценка расширенного сходства даст более высокий показатель:
# Расширенное сходство
response = best_matching_record
print(query,": ", response)
similarity_score = calculate_enhanced_similarity(query, response)
print(f"Enhanced Similarity:, {similarity_score:.3f}")

Более высокий балл объясняется расширенной функциональностью метрики:

 define a rag store : A RAG vector store is a database or dataset that contains
 vectorized data points.
 Enhanced Similarity:, 0.642
