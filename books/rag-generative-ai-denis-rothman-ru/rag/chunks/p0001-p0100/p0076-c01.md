76     Глава 2. Хранение эмбеддингов RAG с помощью Deep Lake и OpenAI

def calculate_cosine_similarity(text1, text2):
    vectorizer = TfidfVectorizer()
    tfidf = vectorizer.fit_transform([text1, text2])
    similarity = cosine_similarity(tfidf[0:1], tfidf[1:2])
    return similarity[0][0]

Теперь вычислим показатель сходства между запросом пользователя и ответом
GPT-4:

similarity_score = calculate_cosine_similarity(user_prompt, gpt4_response)

print(f"Cosine Similarity Score: {similarity_score:.3f}")

Показатель низкий, хотя для человека вывод модели выглядел вполне приемлемым:

 Cosine Similarity Score: 0.396

Похоже, либо мы что-то упустили, либо нужно задействовать другую метрику.

Для начала попробуем вычислить косинусное сходство между дополненным
вводом и ответом GPT-4:

# Пример использования вместе с имеющимися функциями
similarity_score = calculate_cosine_similarity(augmented_input, gpt4_response)

print(f"Cosine Similarity Score: {similarity_score:.3f}")

Здесь показатель получше:

 Cosine Similarity Score: 0.857

Можно ли применить другой метод? Метрика косинусного сходства при исполь
зовании TF-IDF сильно зависит от точных совпадений со словарем и учитывает
важные языковые признаки, такие как семантическое значение, синонимы или
контекст. Поэтому данный метод может давать низкие показатели сходства для
текстов, семантически схожих, но различающихся выбором слов.

В противоположность этому техника вычисления сходства с помощью библио
теки Sentence Transformers подразумевает обработку эмбеддингов, более глубоко
отражающих семантические связи между словами и фразами. Такой подход эф
фективнее распознает контекстное и тематическое сходство текстов. Попробуем
применить его.

Сначала установим библиотеку sentence-transformers:
!pip install sentence-transformers

Будьте внимательны при установке этой библиотеки, так как она может вызвать
конфликт с ранее установленными компонентами пайплайна RAG. В зависимо
сти от целей проекта приведенный далее код может стать отдельным компонен
том пайплайна.
