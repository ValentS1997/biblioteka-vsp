# Cheatsheet — глава 9 «Работа с распределенной командой»

## Symptom / problem framing

Признаки того, что распределенная команда управляется как обычная офисная:

- удаленные участники узнают важные решения постфактум;
- человек в другом городе почти не говорит на встречах;
- офисная часть обсуждает важные детали между звонками;
- новичок видит только «говорящие головы» и плохо входит в команду;
- руководитель не замечает выгорание до резкого увольнения;
- переписка регулярно вызывает обиды и неправильные трактовки;
- удаленный участник плохо слышит встречу;
- решения с доски или из комнаты не фиксируются письменно;
- командировки превращаются просто в совместное нахождение в офисе без содержательного взаимодействия.

## Baseline / context

Распределенность добавляет отдельные операционные риски:

- меньше неформального контекста;
- сложнее читать настроение;
- сложнее сглаживать конфликты;
- onboarding требует большего внимания;
- письменная коммуникация становится критичной;
- смешанная схема «большинство вместе + несколько отдельно» особенно уязвима к информационной асимметрии.

## Read-only checks

### Состав
1. Все ли участники находятся в равных условиях?
2. Есть ли одиночные сотрудники, физически оторванные от команды?
3. Есть ли в каждом удаленном офисе хотя бы небольшая локальная группа?
4. Не остается ли один человек в полной изоляции после увольнения коллеги?

### Люди
1. Человек способен работать без постоянного внешнего контроля?
2. Он умеет письменно объяснять сложные вещи?
3. Его стиль общения дружелюбен и не усиливает конфликт?
4. Он умеет отделять работу от отдыха?
5. Руководитель способен заметить ухудшение состояния не только по task status?

### Коммуникация
1. Все одинаково хорошо слышат встречу?
2. Видят ли удаленные участники общий материал/доску?
3. Фиксируются ли существенные решения письменно?
4. Доходят ли записи до всех участников?
5. Не остается ли важный контекст только внутри офиса?

### Связи
1. Есть ли неформальные online-встречи?
2. Новичку выделено больше контакта на старте?
3. Есть ли возможность периодических личных встреч?
4. Есть ли у командировок конкретная программа взаимодействия?
5. Руководитель обсуждал с командой свой стиль письменного общения?

## Interpretation

- **Удаленный участник постоянно просит повторить контекст** → проблема вероятнее в информационной асимметрии, чем в его внимательности.
- **Человек выглядит бодро на коротких звонках, а потом внезапно уходит** → короткая видеосессия недостаточна для понимания состояния.
- **Смешанная команда спорит о «двух версиях реальности»** → часть решений остается в локальных разговорах.
- **В переписке часто обижаются на нейтральные фразы** → нужно снижать двусмысленность и разбирать стиль коммуникации.
- **Командировка не изменила качество взаимодействия** → совместное физическое присутствие без запланированного общения малоценно.
- **Новичок не задает вопросов и почти не включается** → onboarding не компенсирует дистанцию.

## Next action

1. Провести audit информационной асимметрии:
   - какие важные решения появляются устно;
   - где они фиксируются;
   - кто может их пропустить.
2. Проверить качество звука/видео для удаленных встреч.
3. Определить обязательный письменный след для существенных решений.
4. Отдельно проверить состояние одиночных удаленных сотрудников.
5. Для новичков увеличить частоту личных контактов.
6. Добавить простой неформальный online-ритуал, если его нет.
7. Спросить нескольких коллег, как воспринимается ваш письменный стиль.
8. Для следующей командировки заранее определить рабочие и неформальные взаимодействия.

## Modifying action

Источник поддерживает такие изменения:

- проектировать распределенную работу как отдельный режим;
- снижать изоляцию одиночных сотрудников;
- по возможности формировать локальные мини-группы;
- учитывать коммуникационные качества при удаленном найме;
- обеспечивать равное техническое участие во встречах;
- фиксировать значимые решения письменно;
- чаще контактировать с новичками;
- создавать неформальное online-общение;
- использовать очные встречи для сложных вопросов и укрепления отношений;
- заранее проговаривать особенности собственного стиля общения;
- напрямую устранять двусмысленность в отношениях руководитель–сотрудник.

## Verification / acceptance checks

- удаленный участник получает тот же существенный контекст, что офисная часть;
- решение, влияющее на проект, можно найти в письменном виде;
- удаленные участники одинаково хорошо слышат и видят встречу;
- новичок имеет регулярный прямой контакт с руководителем;
- одиночные сотрудники не остаются системно исключенными из командной жизни;
- письменные сообщения руководителя не требуют постоянного угадывания скрытого смысла;
- командировки создают реальное рабочее/человеческое взаимодействие;
- проблемы состояния сотрудников обнаруживаются раньше резкого кризиса.
