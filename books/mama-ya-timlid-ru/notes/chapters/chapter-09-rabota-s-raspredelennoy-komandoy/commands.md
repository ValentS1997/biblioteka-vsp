## Source-supported managerial tools / practices

| Прием | Тип | Эффект | Риск / ограничение | Проверка | Rollback |
|---|---|---|---|---|---|
| Audit информационной асимметрии | read-only | Показывает, что узнает только офисная часть | Требует честного просмотра неформальных каналов | Существенный контекст доступен всем | Not applicable |
| Проверка качества remote-встреч | read-only | Выявляет техническое исключение участников | Не решает культурные проблемы | Все одинаково хорошо слышат/видят | Улучшить оборудование/формат |
| Письменная фиксация решений | documentation | Уменьшает потерю контекста | Может стать бюрократией при фиксации всего подряд | Важные решения доступны после встречи | Сократить объем |
| Повышенное внимание новичкам | communication | Ускоряет remote-onboarding | Может быть избыточным для самостоятельного сотрудника | Новичок понимает людей, контекст и ожидания | Снизить частоту |
| Неформальная online-встреча | low-risk process change | Создает человеческий контакт | Не всем подходит один формат | Участие добровольное и устойчивое | Изменить/убрать формат |
| Очная командировка с программой | state-changing/logistical | Укрепляет отношения и ускоряет сложные обсуждения | Стоимость времени и денег | После встречи есть конкретный результат и больше контакта | Не повторять неэффективный формат |
| Обратная связь о письменном стиле | read-only | Выявляет сарказм, резкость или избыточную мягкость | Требуется доверенный источник | Руководитель понимает, как его читают | Not applicable |
| Явная договоренность о трактовке сообщений | communication boundary | Снижает двусмысленность | Работает только при последовательном поведении | Сотрудник знает, когда руководитель реально недоволен | Пересогласовать правило |

## Distributed-team check

```text
для каждого удаленного участника:
  есть равный доступ к встречам?
  получает письменный контекст?
  есть регулярный личный контакт?
  состояние можно оценить не только по статусу задач?
  есть человеческая связь с коллегами?

для каждой важной встречи:
  все слышат?
  все видят общий материал?
  решение зафиксировано?
  решение отправлено всем?
```

## Safety boundary

Источник не задает обязательную технологическую платформу, security-policy удаленной работы, юридические требования к remote employment или конкретные нормы рабочего времени. Эти вопросы остаются вне RAG главы.
