# Глава 1 — проблемы исходного текста / извлечения

Политика: `rag_only`, без проверки PDF напрямую, веб-источников и исправлений из памяти. Каждый пункт отражает **сам RAG-фрагмент**, а не устанавливает истинную первопричину (верстка, OCR или печатный оригинал). Классы из canonical chapter-artifact-collection v1.8.

## F01 — команда «добавить всё» без списка путей

- Класс: **[Source wording/code mismatch]**.
- Источник: [PDF 11 / p0011:c01](../../../rag/chunks/p0001-p0100/p0011-c01.md).
- Смысл окружающего текста: добавить все файлы в текущем каталоге и подкаталогах.
- Вариант командной строки в текстовом слое: `git add` (аргумент/путь не приведён).
- В той же секции есть явно записанное `git add <имя файла/директории #1> ...`.
- Решение в артефактах: показывать только выборочное добавление `git add <PATH>`; строку из текста не превращать незаметно в другую команду. Способ «добавить всё»: **[Needs confirmation]**.

## F02 — клонирование «в текущий каталог»

- Класс: **[Source wording/code mismatch]**.
- Источник: [PDF 12 / p0012:c01](../../../rag/chunks/p0001-p0100/p0012-c01.md).
- Текст: «Если необходимо клонировать проект в текущий каталог».
- После этого повторяется вариант `git clone https : //github . com/username/proj ectname . git`, без указания каталога.
- Ранее та же команда описана как создание каталога `projectname`.
- Решение: сохранять оба описания как расхождение; не конструировать предполагаемый недостающий аргумент.

## F03 — искажения опций серверного bare-репозитория

- Класс: **[Source extraction issue]**.
- Источник: [PDF 12 / p0012:c01](../../../rag/chunks/p0001-p0100/p0012-c01.md).
- Текстовый слой: `git init --Ьа ге /path/to/ repo . git`; соседний текст говорит о bare-репозитории без рабочей копии.
- Точное исходное написание флага не подтверждено в RAG. Не помещать в список готовых к выполнению команд, не исправлять по памяти.

## F04 — разрыв флага upstream и флага git-config

- Класс: **[Source extraction issue]**.
- Источник: [PDF 12 / p0012:c01](../../../rag/chunks/p0001-p0100/p0012-c01.md), [PDF 13 / p0013:c01](../../../rag/chunks/p0001-p0100/p0013-c01.md).
- Вариант A: `git push --set-upst ream origin master`; соседнее объяснение повторяет `--set-upst ream` и короткую форму `-u`.
- Для памятки нормализован только пробел внутри очевидно разорванного слова: `--set-upstream`, **не** меняется `master` на имя ветви из другой среды.
- Вариант B: `git config --global -- remove-section user . name` и `... user . email`; валидный смысл и синтаксис удаления секции/ключа не подтверждены RAG. Из исполняемых примеров исключены.

## F05 — подозрительное имя публичного ключа

- Класс: **[Source extraction issue]**.
- Источник: [PDF 14 / p0014:c01](../../../rag/chunks/p0001-p0100/p0014-c01.md).
- В числе образцов файлов открытых ключей указан `id_ed2551 9 . pub` с внедрённым пробелом/цифрой.
- Этот вариант не реконструировать и не использовать при поиске ключа; книга также предлагает общий осмотр `ls -al ~/.ssh`.

## Общие ограничения

RAG содержит текстовый слой PDF, но не документирует, какие конкретно ошибки возникли при OCR либо были уже в издании. Поэтому здесь нет утверждений, что печатный источник точно ошибочен. Исполняемые нормализации в `commands.md` ограничены однозначными разрывами при сохранении оригинальных вариантов здесь. Данные о современных установочных URL, хостингах или текущих версиях Git **не проверялись**.
