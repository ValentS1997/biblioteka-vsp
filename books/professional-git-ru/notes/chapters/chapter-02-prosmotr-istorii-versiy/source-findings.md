## F01 — заголовок §2.10 не соответствует примеру

**[Source wording/code mismatch]** · [PDF 21 / p0021:c01](../../../rag/chunks/p0001-p0100/p0021-c01.md).

- Заголовок извлечённого раздела: «Раздел 2.10. Индексация файлов по частям».
- Текст объясняет просмотр отличий, внесённых коммитами, с помощью `-p` или `--patch`.
- Пример: `git log --patch`, ниже следует diff-фрагмент.
- Без внешнего источника нельзя объявить, что исходный заголовок должен быть другим. Во всех артефактах сохранён исходный заголовок с замечанием, а `git log --patch` классифицирован как read-only.

## F02 — разрывы параметров и форматов журнала

## F03 — неясное присваивание tree

**[Source wording/code mismatch]** · [PDF 23 / p0023:c01](../../../rag/chunks/p0001-p0100/p0023-c01.md).

- Заголовок §2.14: «Вывод коммитов построчно, с отображением имени автора коммита и времени, прошедшего с момента фиксации».
- Фрагмент: `tree = log --oneline --decorate --sou rce --p retty=format : ' ... ' --all --g raph`.
- Не приведена подтверждённая команда `git config` для регистрации `tree`, не объяснено, где исполнять присваивание; часть макросов повреждена.

## F04 — разграничение поиска -S и -G не формализовано

**[Needs confirmation]** · [PDF 19 / p0019:c01](../../../rag/chunks/p0001-p0100/p0019-c01.md).

- Для `-S "#define SAMPLES"` источник говорит о поиске добавления/удаления определённой строки или строки, соответствующей `REGEXP`.
- Для `-G "#define SAMPLES"` говорит о поиске изменений строк, содержащих строку/регулярное выражение.
- Примеры различаются изменениями `#define SAMPLES`, но явной строгой схемы различий или контрпримеров глава не даёт.
- Не подменять это формальной спецификацией из памяти или сети.

## F05 — искажение демонстрационных SHA и дат

**[Source extraction issue]** · [PDF 17 / p0017:c01](../../../rag/chunks/p0001-p0100/p0017-c01.md), [PDF 20 / p0020:c01](../../../rag/chunks/p0001-p0100/p0020-c01.md), [PDF 22 / p0022:c01](../../../rag/chunks/p0001-p0100/p0022-c01.md).

- В примерах встречаются латинские/кириллические похожие буквы и разорванные символы хеша/адреса/email.
- Эти идентификаторы не являются проверенными указателями на реальные коммиты читателя; использовать `<commit>` как заполнитель.
- Дата в примере `201 6-05-01` нормализуется для иллюстрации только как `2016-05-01`, а не как «текущая» дата.
