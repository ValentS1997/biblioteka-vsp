26.1 3.                                                                                                         1 07Раздел      Восстановление удаленного "тайника"
   Соранение неотслеживаемых файлов
    Stash никогда не сохраняет неотслеживаемые файлы, он сохраняет только измененные
и проиндексированные файлы. Поэтому, если вам нужно сохранить и неотслеживаемые
файлы, вы можете использовать этот метод:
    git stash -u
   При этом будут отслеживаться неотслеживаемые, проиндексированные и измененные
файлы.
   Сохранение только некоторой части измененных и проиндексированных
файлов
   Предположим, вам понадобилось сохранить только фрагмент кода из файла или только
часть файлов из всех модифицированных и сохраненных файлов. Тогда вы можете сделать
это следующим образом:
    git stash --patch
    Git не будет сохранять все изменения, а вместо этого запустит интерактивный режим
и попросит вас указать, какие изменения вы хотите сохранить, а какие оставить - в рабо
чем каталоге.

Раздел 26.1 З. Восстановление удаленного "тайника"
   Если вы только что извлекли его с удалением и терминал все еще открыт, у вас на экра-
не останется строка с хеш-значением, выданная после завершения команды gi t stash рор:
     $ git stash рор
           [  .  .  .  ]
    Dropped refs/stash@{0} (2ca03e22256be97f9e40f08eбd6773c7d41 dbfd1 )

   (Обратите внимание, что gi t stash  d гор выдает точно такую же строку). В противном
случае вы можете найти ее, используя следующую команду:
    git fsck --no- reflog       I  awk     ' /dangling commit/  {p rint $3 }  '
   Она выведет на экран все коммиты, расположенные в вершинах вашего графа коммитов,
на которые больше не ссылаются ни ветки, ни метки. Каждый утерянный коммит, включая
и все коммиты, размещенные в "тайнике", будет где-то в этом графе.
   Самый простой способ найти нужный вам коммит, содержащийся в "тайнике", - пере
дать этот список в gi tk:
    gitk --all  $( git fsck --no- reflog       I awk     ' /dangling commit/  {p rint $3 }  '   )
   В результате будет запущен браузер репозитория, показывающий все фиксации в репози
тории, независимо от того, доступен он или нет.
  Вы можете заменить gitk на что-то вроде git  log  --g raph --oneline --decorate ,
если вы предпочитаете красивый график на консоли, а не в отдельном GUI-приложении.
   Чтобы обнаружить коммиты в хранилище, ищите сообщения о коммитах такой формы:
   WIP Идентификатор ветки: хеш коммита Какое-то старое сообщение коммита
   Узнав хеш нужного коммита, можно вызвать команду apply, указав в качестве параме
тра хеш нужного вам коммита:
    git stash apply sh_hash
   Или вы можете использовать контекстное меню в gi tk для создания веток для всех ин
тересующих вас недоступных коммитов. После этого вы можете делать с ними всё, что хо
тите, используя все обычные инструменты. Когда вы закончите, просто снова удалите эти
ветки.
