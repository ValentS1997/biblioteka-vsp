Раздел 59.2. Создание и размещение тегов в Git
   Создать метку:
      •  Для создания метки на текущей ветке воспользуйтесь командой:
           git tag  < tagname >
          В результате будет создан локальный тег с текущим состоянием ветки, на кото
        рой вы находитесь.
      •  Чтобы создать метку для некоторого коммита:
           git tag tag-name commit-identifier
          В результате будет создана локальная метка с идентификатором коммита той
         ветки, на которой вы находитесь.
   Сделать коммит метки в GГГ можно следующим образом:
      •   Применить команду gi t push к отдельной метке:
          git push origin tag-name
      •   Применить команду gi t push сразу ко всем меткам:
          git push origin --tags

Глава 60. Наведение порядка
в локальном и удаленном хранилищах
Раздел 60.1 . Удаление локальных ветвей, которые были
удалены в удаленном репозитории
   Для того чтобы оборвать связь между локальной и удаленной версией этой ветви, распо
ложенной на удаленом сервере, используйте команду:
    git fetch -р
   Затем можно запустить команду:
    git branch -vv
...чтобы увидеть, какие ветви больше не отслеживаются.
   Информация о ветках, которые больше не отслеживаются, будет иметь вид, приведен
ный ниже. Такие ветки отличает присутствие слова 'gone'.
    branch                     1 2345еб   [ origin/branch  : gone ] Fixed bug
  Вы также можете воспользоваться комбинированной командой, состоящей из двух вы
шеописанных команд. Здесь   ' gi t branch -vv ' возвращает ветви с признаком "gone", а ко
манда git branch -d их удаляет.
    git fetch -р && git branch -vv      I awk    ' /  : gone ] /{print $1 } '       1 xargs git branch -d
