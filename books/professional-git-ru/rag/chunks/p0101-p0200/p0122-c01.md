Раздел 34.3. Создание архива git-репозитория на основе
определенной ветки, ревизии, тега или каталога
   Также можно создавать архивы не только ревизий, на которые указывает HEAD, но и дру
гих элементов, таких как ветки, коммиты, теги и каталоги. Чтобы создать архив локальной
ветки dev, можно воспользоваться командой:
    git archive --output=archive-dev . zip --prefix=s rc-directory-name dev
   Для создания архива удаленной ветки origin/dev, расположенной в удаленном репози
тории, можно воспользоваться командой:
    git archive --output=archive-dev . zip --prefix=src-directory-name origin/dev
   Для создания архива тега v . 01 можно воспользоваться командой:
    git archive --output=archive-v . 01  . zip --prefix=src-directory-name v . 01
   Создание архива файлов внутри определенной поддиректории (sub-dir) ревизии HEAD:
    git archive  zip  --output=a rchive-sub-dir  . zip  --prefix=s rc-directory-name

Глава 35. Переписывание истории
с помощью команды filter-branch
Раздел 35.1 . Изменение автора коммитов
   Для изменения автора коммитов можно использовать фильтр окружения. Для измене
ния автора коммита достаточно в скрипте для командной оболочки bash изменить и экспор
тировать переменную окружения $GП _AUTHOR_NAME.
   Создайте файл filter . sh  с содержимым следующего вида:
    if   [  "$GIT_AUTHOR_NAME"  = "Author to Change From"
    then
       export GIT_AUTHOR_NAME= "Author to Change То"
       export GIT_AUTHOR_EMAIL="email . to . change . to@example . com"
    fi
   Затем запустите команду filter-branch из командной строки:
    chmod +х     . /filter  . sh
    git filter-branch --env-filter     . /filter  . sh
Раздел 35.2. Задать одинаковые имена и для автора
содержимого коммита, и для автора, оформившего коммит
   Эта команда, задавая диапазон коммитов commi t1  .  .  . commi t2, переписывает историю
таким образом, что автор содержимого коммита становится также и автором, непосред
ственно отправившим коммит:
    git filter-branch -f --commit-filter  \
                          ' export GIT_COMMITTER_NAME=\ " $GIT_AUTHOR_NAME\ "  ;
       export GIT_COMMITTER_EMAIL=\ " $GIT_AUTHOR_EMAIL\ "  ;
       export GIT_COMMITTER_DATE=\"$GIT_AUTHOR_DATE\ "  ;
        git commit-t ree $@ '  \
        -- commit1  .  . commit2
