1 46                                                               Глава 50. Графические клиенты Git
   Слева расположен индекс; сверху- непроиндексированные изменения, снизу - проин
дексированные изменения. Вы можете перемещать целые файлы между двумя состояния
ми, щелкая на их значках, или выбрать файл для просмотра, щелкнув на его имени.
   Справа вверху расположено представление дельты (diff), в котором отображаются изме
нения для выбранного в данный момент файла. Щелчком правой кнопки мыши в этой обла
сти можно добавлять в индекс отдельные блоки (или отдельные строки).
   В правом нижнем углу находится область сообщений и действий. Введите свое сообще
ние в текстовое поле и нажмите кнопку "Commit", чтобы выполнить действие, аналогичное
команде gi t commi t. Вы также можете изменить последний коммит, выбрав радиокнопку
"Amend", что приведет к обновлению области "Staged Changes" содержимым файла послед
него коммита. Теперь вы можете просто добавить в индекс (проиндексировать) или удалить
из идекса некоторые изменения, отредактировать сообщение коммита и нажать кнопку
"Commit" еще раз, чтобы заменить старый коммит на новый.
    gi tk и gi t-gui являются примерами инструментов, ориентированных на решение кон
кретных задач. Каждый из них создан для решения определенной задачи (просмотр истории
версий и создание коммитов соответственно) и не содержит лишнего функционала, в кото
ром нет необходимости для решения этой задачи.
   Более подробно изучить тему, связанную с графическими инструментами Git, можно,
обратившись  по  адресу  https://git-scm.com/book/en/v2/Git-in-Other-Environments-Graphical
Interfaces.

Раздел 50.2. Рабочий стол GitHub
   Веб-сайт: https://desktop.github.com
   Цена: бесплатно
   Платформы: OS Х и Windows
   Разработано: GitНub

Раздел 50.З. Git Kraken
   Сайт: https://www.gitkraken.com
   Цена: $60/год (бесплатно для открытого кода, образования, некоммерческих организа
ций, стартапов или личного использования)
   Платформы: Linux, OS Х, Windows
   Разработано компанией: Axosoft

Раздел 50.4. SourceTree
   Веб-сайт: https://www.sourcetreeapp.com
   Цена: бесплатно (необходима учетная запись)
   Платформы: OS Х и Windows
   Разработчик Atlassian

Раздел 50.5. Расширения Git
   Веб-сайт: https://gitextensions.github.io
   Цена: бесплатно
   Платформа: Windows

   Платформы: Linux, OS Х, Windows
