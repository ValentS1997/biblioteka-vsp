Раздел 25.4. Рекурсивное клонирование
   Версия  ::с: 1.6.5
    git clone <url> -- recu rsive
   Клонирует репозиторий, а также все подмодули. Если подмодули содержат дополнитель
ные подмодули, то Git клонирует и их.

Раздел 25.5. Клонирование с использованием
прокси-сервера
   Если вам необходимо загружать файлы с помощью Git под прокси-сервером, то уста
новки прокси-сервера в масштабе всей системы будет недостаточно. Можно попробовать
следующее:
    git config --global http . p roxy http  : //<proxy-server> : <port>/

Глава 26. Прятанье
   Параметр Описание
   show     Отобразить изменения, записанные в "тайнике", в виде дельты (dift) между со
           храненным состоянием и тем, в котором сейчас находится источник. Если но
           мер <stash> не задан, отображается самый последний в стеке.
   list     Вывести список имеющихся у вас "тайников". Каждый "тайник" выводится
                с указанием его имени (например, stash@{O} - самый последний "тайник",
                stash, stash@{1} -предыдущий и т. д.), имя ветки, которая бьmа текущей на мо
           мент создания "тайника", и краткое описание коммита, который лег в основу
             "тайника".
   рор      Вызвать из стека "тайник", находящийся на вершине списка, и применить его
            поверх текущего состояния рабочего дерева.
   apply    Аналогично рор, но не удаляет состояние из списка "тайников".
   clear    Удалить все записи из списка "тайников". Обратите внимание, что восстано
           вить эти записи будет невозможно.
    d rop     Удалить одну запись из списка "тайников". Если номер записи <stash> не за
              дан, то удаляется самая последняя запись, т. е. удаляется stash@{O}. Чтобы уда
           лить требуемую запись из списка "тайников", на вход команды stash должна
            подаваться корректная ссьmка на запись в списке "тайников" в виде stash@
                  { <revision>}.
   c reate   Создать "тайник" (который является обычным объектом типа коммит) и вер
            нуть имя объекта, на базе которого он создается, при этом не сохраняя его
             в пространстве имен ref. Эта команда может быть полезна для скриптов. Воз
            можно, это не та команда, которую вам хотелось бы использовать.
   store    Сохраняет "тайник", созданный с помощью git stash create (который является
          висящим коммитом), в стек "тайников", обновляя журнал ссылок stash reflog.
             Эта команда предназначена для скриптов. Возможно, это не та команда, кото
          рую вам хотелось бы использовать.
