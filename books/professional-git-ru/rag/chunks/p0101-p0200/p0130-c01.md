Раздел 42.1 . Вывести только определенные строки
  Вывод данных можно ограничить, указав диапазоны строк:
    git Ыаmе  -L <start> , <end>
        ... где <start> и <end> могут быть:
     •  номерами строк
          git Ыаmе -L  1 0 , 30
     •   регулярным выражением вида /regex/
          git Ыаmе -L /void main/ ,  git Ыаmе -L 46 , /void foo/
     •    +offset, -offset (только для <end>)
          git Ыаmе  -L  1 08 , +30 ,  git Ыаmе  -L 21 5 , - 1 5
  Можно указать несколько диапазонов строк, причем допускается перекрытие диапа
зонов:
           git Ыаmе  -L  1 0 , 30  -L  1 2 , 80  -L  1 20 , +1 0  -L  л ;void main/ , +40
