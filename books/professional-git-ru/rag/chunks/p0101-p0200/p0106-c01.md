26.4.                                                                                                           1 05Раздел     Чтение записи из "тайника" без удаления
Раздел 26.4. Чтение записи из "тайника" без удаления
   Чтобы извлечь последнюю запись из "тайника", не удаляя ее из стека, введите:
    git stash apply
   Чтобы извлечь из памяти "тайника" любую запись без удаления, введите:
    git stash apply stash@{n}
Раздел 26.5. Показать "тайник"
   Вьmести на экран изменения, сохраненные в последней записи "тайника" можно командой:
    git stash show
   Вывести на экран изменения, сохраненные в любой другой записи "тайника" можно ко
мандой:
    git stash show stash@{n}
   Чтобы вывести на экран полное содержание изменений, сохраненных для конкретного
тайника, введите команду:
    git stash show -р stash@{n}
Раздел 26.6. Частичное сохранение в "тайнике"
   Если вам надо сохранить только дельту (dift), то можно применить частичное хранение,
выполнив команду:
    git stash -р
        ... а затем в интерактивном режиме выбрать, какие фрагменты необходимо положить
в "тайник".
   Начиная с версии 2.13.0 можно также избежать интерактивного режима и создать частич
ный "тайник" с сохранением параметра pathspec, используя новое ключевое слово push:
    git stash push -m "Му partial stash"  -- app . config
Раздел 26.7. Вывести список сохраненных "тайников"
    git stash list
   При этом все "тайники" в стеке будут перечислены в обратном хронологическом поряд
ке. Вы получите список, который будет выглядеть примерно так:

    stash@{0}  : WIP оп master  : 67а4е01 Мегgе tests into develop
    stash@{1 }  : WIP оп master  : 70f0d95 Add user гоlе to localStorage оп user login

  Вы можете ссылаться на конкретный тайник по его имени, например stash@{1 }  .

Раздел 26.8. Перенос незавершенной разработки
в другую ветку
   Если в процессе работы вы поймете, что находитесь на неправильной ветке и еще не со
здали ни одного коммита, вы можете легко перенести свою работу на правильную ветку
с помощью команды stash:
    git stash
    git checkout correct-branch
    git stash рор
