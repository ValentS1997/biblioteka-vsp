Раздел 48.3. Вывести коммиты, сгруппированные по авторам
   Команда git shortlog используется для обобщения записей, содержащихся в журнале
Git, с группировкой коммитов по авторам.
   По умолчанию на экран выводятся все сообщения коммитов, но аргумент --summa ry
или -s  указывает, что необходимо вывести только список авторов с общим количеством
их коммитов.
   Параметр  --numbered или -n  позволяет заменить вывод записей, отсортированных
в алфавитном порядке (по автору в порядке возрастания), на вывод, отсортированый по по
рядковому номеру коммитов в порядке убывания.
    git shortlog -sn  # Имена и количество коммитов
    git shortlog -sne # Имена с указанием идентификаторов их почтовых адресов
                       # и с указанием  количества коммитов

   или
    git log --pretty=format :%ae  \
                     1 gawk --     ' { ++с [ $0 ]  ;  } END  { fог(сс  in  с) printf "%5d %s\n"  , c [ cc ]  , cc ;  }  '
   Примечание: запрещается группировать коммиты одного и того же человека, если его имя и/или
    адрес электронной почты написаны по-разному. Например, John Doe и Johnny Doe  будут ото
   бражаться в списке раздельно. Избежать этой проблемы можно путем создания и редактирования
   файла   . mailmap .

Раздел 48.6. Вывод списка коммитов в удобном
для восприятия формате
    git log --pretty=format  : "%Cg reen%ci %CЬlue%cn %Cg reen%cr%Creset %s"
   Эта команда выводит список коммитов в удобном для восприятия формате (по одному
коммиту в строке) с указанием даты, имени пользователя и сообщения коммита. Параметр
--р retty содержит множество заполнителей (полей подсказок), каждый из которых начи
нается с %. Все опции можно найти по адресу https://git-scm.com/docs/pretty-formats.

Раздел 48.7. Поиск всех локальных git-репозиториев
на компьютере
   Для того чтобы вывести на экран список всех мест расположения git-репозиториев, рас
положенных на вашем компьютере, воспользуйтесь командой:
    find $НОМЕ -type d -name  "  . git"
   Если у вас есть возможность поиска по шаблону, типа команды UNIX locate, то поиск
можно выполнить намного быстрее:
    locate     . git       l grep git$
   Если у вас есть gnu locate или mlocate, то это позволит выбрать только директории .git:
    locate -Ьег \\\  . git$
