в ссылке
Раздел 54.1 . Обновление имени объекта в ссылке
  Применение
   Обновление имени объекта, хранящегося в ссылке.
  Общий формат записи
    git  update-ref     [ -m  <причина> ]     ( -d   < ref>      [ <oldvalue> ]             [ - -no-de ref ]
    [ - - c reate- reflog ]  < ref> )
    <newvalue>    [ <oldvalue> ]         1  - - stdin    [ - z ] )
  Общий синтаксис
        1.  Разыменовывая символьные ссылки, перенаправляем ссылку HEAD текущей вет
        ви на новый объект:

          git update-ref HEAD <newvalue>

       2.  Команда записывает новое значение <newvalue> в ref, после того как проверит,
        что текущее значение ref совпадает со старым значением <oldvalue>:

          git update-ref refs/head /master <newvalue> <oldvalue>
   Приведенный выше синтаксис обновляет голову основной ветви до значения newvalue
только в том случае, если ее текущее значение равно oldvalue.
   Параметр -d  используется для удаления ссьшки < ref> после проверки того факта,
что она по-прежнему содержит значение <oldvalue>.
   При использовании параметра - - c reate- reflog команда update- ref создаст ссьшоч
ный журнал для каждой ссылки, даже если обычно он не создается. Используйте флаг -z
для указания в NUL-терминированном формате, который имеет такие значения, как update,
create, delete, verify.
  Обновление
   Устанавливает < ref> в <newvalue> после проверки <oldvalue>, если оно задано. Ука
жите нулевое <newvalue>, чтобы убедиться, что ссылка не существует после обновления,
и/или нулевое <oldvalue>, чтобы убедиться, что ссылка не существовала до обновления.
   Создать
   Создать < ref>  с <newvalue> после проверки его несуществования. Заданное <newvalue>
не может быть нулем.
  Удалить
   Удалить < ref> после проверки его существования с помощью <oldvalue>, если оно за
дано. Если задано, то <oldvalue> не может быть нулем.
  Проверить
   Сверьте < ref>  с <oldvalue>, но не изменяйте его. Если <oldvalue> равно нулю или от
сутствует, то ссьшка не должна существовать.
