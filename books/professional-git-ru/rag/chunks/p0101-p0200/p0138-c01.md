Раздел 45.2. Изменение url удаленного репозитория Git
   Это может понадобиться в случае миграции удаленного хранилища. Команда для изме
нения удаленного url имеет следующий вид:
    git remote set-url
   Он принимает два аргумента: существующее имя удаленного ресурса (origin, upstream) и url.
   Проверить текущий адрес URL удаленного репозитория можно при помощи команды:
    git remote -v
    https  : //bitbucket  . com/develop/myrepo . git (fetch )
    https  : //bitbucket  . com/develop/myrepo . git   ( push)
   Изменить URL-aдpec удаленного репозитория можно при помощи команды:
    git remote set-url origin https  : //localserver/develop/myrepo . git
   Проверьте еще раз URL-aдpec вашего удаленного репозитория:
    git remote -v
    https  : //localserver/develop/myrepo . git (fetch )
    https  : //localserver/develop/myrepo . git   ( push)

Раздел 45.З. Удаление удаленного репозитория
   Удалим удаленный репозиторий с именем <имя>. При этом удаляются все отслеживае
мые ветви и настройки конфигурации для этого репозитория.
   Чтобы удалить удаленный репозиторий dev, необходимо выполнить команду:
    git remote rm dev
Раздел 45.4. Добавление удаленного репозитория
   Чтобы добавить удаленный репозиторий, используйте команду gi t  remote  add ,  кото
рую необходимо запустить на выполнение в корне локального репозитория. Для добавления
удаленного Git-репозитория <url> в виде простого короткого имени <name> запустите команду:
    git remote add <имя> <u rl>
   Команда gi t fetch <ИМЯ> может быть использована для создания и обновления ветвей
в удаленном репозитории <имя>/ <имя удаленного репозитория>.

об удаленном репозитории
