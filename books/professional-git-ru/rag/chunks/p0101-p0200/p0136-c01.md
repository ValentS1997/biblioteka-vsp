1 35Раздел 44.2. Перемещение рабочего дерева
Раздел 44.2. Перемещение рабочего дерева
   В настоящее время (по состоянию на версию 2.11.0) в Git не существует встроенного функ
ционала для перемещения уже существующего рабочего дерева. Это указано как официаль
ная ошибка (см. https://git- scm.com/docs/git-worktree#_bugs).
   Чтобы обойти это ограничение, можно выполнять ручные операции непосредственно
в файлах ссылок   . g i t  .
   В данном примере основная копия репозитория находится по адресу /home/user /
proj ect-main, а копия рабочего дерева расположена по адресу /home/user/proj ect-1 ,
и мы хотим переместить его в рабочее дерево /home/user /proj ect-2  .
   Не выполняйте никаких команд Git в промежутках между этими шагами, иначе может
сработать сборщик мусора, и ссылки на вторичное дерево будут потеряны. Выполняйте эти
шаги с самого начала и до конца, не прерываясь.
        1.  Измените файл   . git рабочего дерева так, чтобы он указывал на новое местоположе
        ние внутри основного дерева. Теперь файл /home/user/proj ect -1 /  . git должен
        содержать следующее:

          gitdir  :  /home/user/proj ect-main/  . git/workt rees/proj ect-2

       2.  Переименуйте рабочее дерево внутри каталога   . git  основного проекта, переме
        стив туда существующий в нем каталог рабочего дерева:
            $  mv  /home/user/proj ect-main/  . git/workt rees/proj ect-1   /home/user/
           proj ect-main/  . git/workt rees/proj ect-2

        3.  Измените ссылку внутри файла /home/user/proj ect-main/  . git/workt rees/
         proj ect-2/gitdir так, чтобы она указывала на новое местоположение. В данном
        примере файл будет иметь следующее содержание:

          /home/user/proj ect-2/  . git

       4.  Наконец, переместите рабочее дерево в новое место:
            $ mv /home/user/proj ect-1  /home/user/proj ect-2
   Если все сделано правильно, то листинг существующих рабочих деревьев должен теперь
ссылаться на новое местоположение:
     $ git workt ree list
    /home/user/proj ect-main 23f78ad    [ master ]
    /home/user/proj ect-278ac3f3    [ branch-name ]
   Теперь можно смело запускать команду git workt ree prune.
