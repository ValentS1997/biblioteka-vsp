Раздел 34.1 . Создание архива git-репозитория
   С помощью git  archive  можно создавать сжатые архивы репозитория, например,
для распространения релизов. Создание tаr-архива текущей ревизии, на которую указыва
ет HEAD:
    git archive --format tar HEAD       I  cat > archive-HEAD . tar
   Создание tаr-архива текущей ревизии, на которую указывает HEAD,  с gziр-сжатием:
    git archive --format tar HEAD       I gzip > a rchive-HEAD . ta r . gz
   Это также можно сделать с помощью команды (при этом будет использована встроенная
обработка tar.gz):
    git archive --format tar . gz HEAD  > a rchive-HEAD . ta r . gz
   Создать ziр-архив с ревизией, на которую указывает HEAD  :
    git archive --format zip HEAD > archive-HEAD . zip
   В качестве альтернативы можно просто указать в качестве выходного файл с допусти
мым расширением, тогда и формат, и тип сжатия будут вычислены на основе названия
файла:
     git archive --output=archive-HEAD . tar  . gz HEAD
Раздел 34.2. Создание архива git-репозитория с названием
директории в качестве префикса
   Хорошей практикой считается использование префикса при создании git-архивов, чтобы
при извлечении все файлы распаковывались внутрь каталога, название которого совпада
ет с названием префикса. Для создания git-репозитория с названием директории в качестве
префикса можно воспользоваться командой:
    git archive --output=archive-HEAD . zip --prefix=s rc-directory-name HEAD
   При извлечении все файлы будут извлечены в каталог с именем src-directory-name
в текущем каталоге.
