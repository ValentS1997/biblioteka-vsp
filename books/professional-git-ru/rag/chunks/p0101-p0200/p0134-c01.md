Раздел 43.9. Самый младший совпадающий коммит:
<rev>л{/<text>}, :/<text>

                                 { /fix nasty bug }       # найти ,  начиная с HEAD     $ git show HEдDл
     $ git show     '   : /fix nasty bug  '           # найти ,  начиная с любой ветки
   Двоеточие ('  : '), за которым следует косая черта ('/'), а затем текст, соответствующий сооб
щению коммита, которое задается в виде регулярного выражения. Эта команда возвращает
самый младший совпадающий коммит, доступный по любой ссылке ref
   Регулярное выражение может представлять собой любую часть сообщения коммита.
Для соответствия сообщениям, начинающимся со строки, можно использовать, например,
  : / Лfоо. Специальная последовательность    : / !  предназначена для модификаторов совпа
дения.   : / ! -foo - отрицательное совпадение (то есть вывести все, кроме того, что указано
в качестве параметра), а   : / !  ! foo - литеральный символ  !, за которым следует foo.
   Суффикс л, добавленный к номеру версии, за которым следует пара фигурных скобок,
содержащая текст, с косой чертой впереди, означает то же самое, что и синтаксис вида
  : / <text>. По правилам сравнения строк будет возвращен самый младший коммит, дости                              лжимый из < rev> перед  текст сообщения которого меньше или равен шаблону, заданному
в регулярном выражении.
