1 57Раздел 61 .1  . Просмотр файлов, измененных коммитом
Глава 61 . Команда diff-tree
   Эта команда сравнивает содержимое двух объектов типа ЫоЬе, найденных с помощью
двух объектов типа "дерево".

Раздел 61 .1 . Просмотр файлов, измененных коммитом
    git diff-t ree --no-commit-id --name-only  - г COMMIT_ID

Раздел 61 .2. Использование
    git diff-tree    [ --stdin ]     [ -m ]     [ - с ]     [ - - се ]     [ -s ]     [ -v]     [ --pretty]     [ -t ]     [ - г ]
           [ - - гооt ]    [ <common-diff-options> ]  <t ree-ish>    [ <t ree-ish> ]    [ <path>  .  .  .  ]
   Опция     Пояснение
    - r        применять команду diff рекурсивно
   -- root    включает начальный коммит как результат команды diff по отношению
                к/dev/null
Раздел 61 .3. Общие опции diff
   Опция               Пояснение
   -z                 Вывести diff-raw со строками, завершающимися символом NUL.
                      Вывести в формате патча.   -р
                      Аналоrично -р.   -u
   --patch-with- raw   Вывести результат работы команды как в формате патча, так
                    и в формате diff-raw.
   --stat              Отобразить сводную информацию по полученной дельте  (diff)
                        вместо patch.
   --numstats         Показывает количество добавленных и удаленных строк в деся
                     тичной записи.
   --patch-with-stat   Создает патч и добавляет к нему результат выполнения --stat.
                        Эта команда - полный аналог команды -р --stat.
   --name-only        Выводить только имена измененных файлов.
   --name-statuss     Выводить имена и статус измененных файлов.
   --full-index        Вместо первых нескольких символов вьmедет полные имена объек
                         тов больших двоичных объектов (ЫоЬs) в индексных строках.
   --abb rev=<n>        Вместо вывода полного 40-байтового шестнадцатеричного име
                    ни объекта в выходных данных формата diff-raw и строках заго
                       ловка diff-tree выводит сокращенные имена объектов в заголовке
                            diff-дepeвa и diff-raw, с количеством символов <n>.
                      Поменять местами пары входных файлов.   -R
                      Обнаружить признаки рера:йтинга (перестановки слов во фразах).   -в                     Обнаружить переименования.   -м   -с                 Обнаружить копии.
   --find-copies-      Попробовать неизменяемые файлы в качестве кандидатов на об
   ha rder             наружение копий.
   -l<n>               Ограничить количество попыток переименования числом <n>.
                      Упорядочить различия в соответствии с ...  .   -о   -s                 Найти пару файлов, только одна сторона которой содержит строку...
   --pickaxe-all      Выводит разницу для всех файлов в том случае, если по опции -S
                     была найдена хотя бы одна пара файлов.
    -а,  --textt reat     Рассматривать все файлы как файлы в текстовом формате.
