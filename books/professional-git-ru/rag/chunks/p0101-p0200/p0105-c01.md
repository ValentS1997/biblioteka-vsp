Раздел 26.2. Создание "тайников"
   Сохранить текущее состояние рабочего каталога и индекса (также известного как об
ласть хранения) в стеке "тайников" можно, воспользовавшись командой:
    git stash
   Для включения всех неотслеживаемых файлов в "тайник" используйте параметры
- - include-unt racked или -u  .
    git stash  - - include-unt racked
   Добавить к "тайнику" сообщение, чтобы впоследствии его бьmо легче идентифициро
вать, можно командой:
    git stash save  " < какое-либо сообщение> "
   Чтобы оставить указатель в области хранения "тайника" в текущем состоянии после вы
полнения команды stash, используйте параметры --keep- index или - k .
    git stash --keep- index
Раздел 26.З. Чтение записи из "тайника" с удалением
   Чтобы извлечь из памяти "тайника" последнюю запись и удалить ее из стека, введите:
    git stash рор
   Чтобы извлечь из памяти "тайника" любую запись и удалить ее из стека, введите:
    git stash рор stash@{n}
