Раздел 43.3. Версия по умолчанию: HEAD                                                 131

  Вы можете указать версию посредством символического имени ссылки ref, также вклю
чая ветви (например, 'master', 'next', 'maint'), теги (например, 'vl.O', 'v0.6.3-rc2'), ветви в уда
ленном репозитории (например, 'origin', 'origin/master'), а также специальные ссьmки ref, та
кие как, например, 'HEAD' для текущей ветви.
   Если символьное имя ссьmки неоднозначно, например, ветка и тег имеют одинаковое
имя 'fix' (хотя правила хорошего тона не рекомендуют иметь ветку и тег с одинаковым име
нем), то необходимо указать тип ссьmки, которую вы хотите использовать:
     $ git show heads/fix     # или     ' refs/heads/fix '  ,  чтобы указать ветку
     $ git show tags/fix      # или      ' refs/tags/fix '  ,  чтобы указать тег
Раздел 43.3. Версия по умолчанию: HEAD
     $ git show# эквивалентно     ' git show HEAD '
   "HEAD" - название коммита, на котором основаны изменения в рабочем дереве, и обыч
но является символическим именем текущей ветви. Во многих (но не во всех) командах, ко
торые принимают в качестве параметра название версии, в том случае, если оно отсутству
ет, по умолчанию используется версия "HEAD".

Раздел 43.4. Ссылки на журнал ссылок reflog:
<refname>@{<n>}
     $ git show @{1 }          # использует журнал ссылок для текущей ветки
     $ git show master@{1 }    # использует журнал ссылок для ветки     ' maste r '
     $ git show HEAD@{1 }      # использует журнал ссылок "HEAD"
   Ссылка, обычно ветвь или HEAD, за которой следует суффикс @ с порядковым указателем,
заключенным в пару скобок (например { 1 }, {1 5}), задает n-e предыдущее значение этого
журнала ссылок в локальном хранилище. Проверить последние записи в журнале ссьmок
можно при помощи команды gi t reflog, или при помощи команды gi t log с параметром
--walk- reflogs  / -g.
     $ git reflog
    08ЬЬ350 HEAD@{0}  :  reset  : moving to НЕдол
    4ebf58d HEAD@{1 }  : commit  : gitweb( 1 )  : Document query parameters
    08ЬЬ350 HEAD@{2 }  : pull  : Fast-forward
    f34be46 НЕАD@{З }  : checkout  : moving from af40944bda3521 90f05d22b7cb8f
    e88beb1 7f3a7 to master
    af40944 HEAD@{4}  : checkout  : moving from master to v2  . 6 . 3

     $ git reflog gitweb-docs
    4ebf58d gitweb-docs@{0 }  : branch  : Created from master
   Примечание: использование журналов ссьшок практически заменило старый механизм использо
   вания ссылки ORIG_HEAD (примерно эквивалентной HEAD@{ 1 } ).
