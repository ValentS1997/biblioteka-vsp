1 25Раздел 37 .1  . Обзор
  Оптимизация после переноса
   Если во вновь созданном git-репозитории уже имеется несколько тысяч коммитов (или
более), то перед переносом репозитория в удаленное хранилище может потребоваться со
кратить используемое пространство. Это можно сделать с помощью следующей команды:
     $ git gc --agg ressive
   Примечание: выполнение предыдущей команды может занять до нескольких часов в больших ре
   позиториях (десятки тысяч коммитов и/или сотни мегабайт истории).

Глава 37. Команда git show
Раздел 37 .1 . Обзор
   Команда gi t show выводит на экран различные объекты Git.
  Коммиты
   В случае коммитов эта команда выводит на экран сообщение коммита и дельту (diff) вне
сенных изменений.
   Команда            Описание
   git show           показывает предыдущий коммит
   git show @~З       показывает 3-й, считая от последнего коммита
   Деревья и объекты типа ЫоЬ
   Выводит на экран дерево или содержимое объекта типа ЫоЬ.
   Команда                          Описание
   git show @~З  :                     показывает корневой каталог проекта в том виде,
                                       в котором он бьш три коммита назад (дерево)
   git show @~З  : s rc/prog ram . j s      показывает src/program . j s в том виде,  в кото
                                 ром он был три коммита назад
      ( ЫоЬ) git show @ : a . txt @ : b . txt  показывает а  . txt , конкатенированный с Ь  . txt
                                    из текущего коммита
  Теги
   Выводит на экран сообщение тега и объект,к которому даный тег относится.
