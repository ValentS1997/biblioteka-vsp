Раздел 48.8. Вывод общего количества коммитов
для каждого автора
   Для того чтобы вывести общее количество коммитов, сделанных каждым разработчи
ком или соавтором в репозитории, можно просто воспользоваться функцией g i t sho rtlog :
    git shortlog -s
   В этом случае буlJУТ выведены имена авторов и количество коммитов, которое приходит
ся на каждого из них.
   Для того чтобы результаты вычислялись по всем ветвям, добавьте в команду флаг --а 11  :
    git shortlog -s --all

Раздел 49.1 . Использование комады git send-email с Gmail
   Предыстория: если вы работаете над таким проектом, как ядро Linux, то вместо того, что
бы делать запрос на включение, вам необходимо сначала отправлять свои правки в спи
ски рассылки для рассмотрения. В этом разделе будет подробно описано, как использовать
git-send email с Gmail.
   Добавьте следующие строки в файл   . gi tconfig:

           [ sendemail ]  .
       smtpserver  = smtp . googlemail . com
       smtpencryption  = tls
       smtpserverport  = 587
       smtpuser  = name@gmail . com

   Затем в браузере: перейдите в Google -> Му Account -> Connected Apps & Sites -> Allow less
secure apps -> Switch ON.
   Для создания набора патчей:
    git format-patch HEAD~~~~ --subj ect-prefix=" PATCH <имя проекта > "
   Затем разослать патчи по списку рассьmки:
    git send-email --annotate --to proj ect-developers-list@listserve . example .
    com 00* . patch

   Для создания и отправки обновленной версии патча (в данном примере - версии 2):
    git format-patch -v 2 HEAD~~~~     .  .  .  .  .  .
    git send-email --to proj ect-developers-list@listserve . example . com v2-00* .
    patch
