Раздел 45.1 . Отображение удаленных репозиториев
   Для получения списка всех сконфигурированных удаленных репозиториев используйте
команду git remote.
   В этом случае будет выведено краткое имя (псевдонимы) каждого настроенного удален-
ного репозитория.

     $ git remote
    premium
    premiumPro
    origin

   Для вывода более подробной информации можно использовать флаг --verbose или -v.
Вывод будет включать URL и тип допустимых операций (push или pull):

     $ git remote -v premiumPro https  : //github . com/user/CatClickerPro . git (fetch)
    premiumPro                 https  : //github . com/use r/CatClickerPro . git  ( push )
    premium                    https  : //github  . com/use r/CatClicker  . git (fetch )
    premium                    https  : //github  . com/use r/CatClicker  . git   ( push)
    origin                     https  : //github . com/ud/sta rter . git (fetch)
    origin                     https  : //github  . com/ud/sta rter  . git (push )
