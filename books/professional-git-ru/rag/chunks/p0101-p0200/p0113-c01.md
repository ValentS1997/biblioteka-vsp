Раздел 29.5. Настройка поведения комады push по умолчанию
   С установленным параметром current команда push по умолчанию обновляет ветку в уда
ленном репозитории, имя которой совпадает с именем текущей рабочей ветки.
    git config push  . default cur rent
   С установленным параметром simple команда push осуществляет публикацию в ветку
на удаленном сервере с таким же названием, как у текущей, но не будет работать, если вет
ка, размещенная в удаленном репозитории, называется как-то иначе.
    git config push  . default simple
   С установленным параметром upst ream команда push осуществляет публикацию в вет
ку на удаленном сервере, независимо от того, как она называется.
    git config push  . default upst ream
   С установленным параметром matching комада push отправляет в удаленный репози
торий все локальные ветки, названия которых совпадают с названиями веток, расположен
ных в удаленном репозитории.
    git config push  . default matching
   После того как вы установили предпочтительный стиль, для обновления удаленного хра
нилища используйте команду:
    git push

Глава 30. Внутренние компоненты
Раздел 30.1 . Репозиторий
   Репозиторий git - это структура данных на диске, хранящая метаданные для набора
файлов и каталогов.
   Он находится в папке   . g i t / вашего проекта. Каждый раз, когда вы фиксируете данные
в Git, они сохраняются здесь. И наоборот, папка   . gi t/ содержит все коммиты.
   Его основная структура выглядит следующим образом:

              . git /
         obj ects/
         refs/

   По своей сути gi t является хранилищем данных типа "ключ-значение". Когда вы добав

мый на основе содержимого объекта .
