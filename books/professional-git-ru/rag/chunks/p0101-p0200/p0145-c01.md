Раздел 49.3. Отправка патчей по почте
   Предположим, что у вас есть множество коммитов по проекту (здесь имя проекта ulogd2,
официальная ветка проекта - git-svn), и вы хотите отправить свой набор патчей в список
рассьшки devel@netfilter.org. Для этого достаточно открыть командную оболочку в корне ка
талога Git и запустить команду:
    git format-patch --stat -р  -- raw --signoff --subj ect-p refix="ULOGD РАТСН"
     -о /tmp/ulogd2/ -n git- svn
     git  send-email  --compose  --no-chain- reply-to  --to  devel@netfilter  . org  /
    tmp/ulogd2/
   Первая команда создаст серию писем на основе патчей, расположенных в /tmp/ulogd2,
с отчетом о статистике, а вторая запустит ваш редактор для составления вступительного
письма к набору патчей. Чтобы избежать ужасных спамерских серий писем, можно исполь
зовать команду:
    git config sendemail  . chain replyto false
   Более подробно изучить данную тему можно, обратившись по адресу https://home.regit.
org/technical-articles/git-for-the-newЬie/.

Глава 50. Графические клиенты Git
Раздел 50.1 . gitk и git-gui
   При установке Git вы также получаете встроенные в него визуальные инструменты g i t k
и git-gui.
   gi tk - это графический просмотрщик истории версий. Пусть в вашем представлении
это отложится как мощная графическая оболочка поверх команд git  log и git  g rep. Это
инструмент, который следует использовать, когда вы пытаетесь найти что-то, что произо
шло в прошлом, или визуализировать историю вашего проекта.
   gitk проще всего вызывать из командной строки. Просто зайдите в репозиторий Git и вве
дите:
     $ gitk   [ git log options ]
    gitk принимает множество опций командной строки, большинство из которых переда
ются базовому действию gi t  log. Вероятно, одним из наиболее полезных является пара
метр --all ,  который указывает gitk отображать на экране коммиты, доступные с адреса
