1 1 0                                                                    Глава 29. Публикация кода

   Пример:
    git push origin  :wip-you rname
   Будет удалена ветка wip-you rname из удаленного репозитория origin.
   Вместо двоеточия можно также использовать параметр --delete, который в некоторых
случаях лучше воспринимается.
   Пример:
    git push origin --delete wip-you rname
  Отправка в удаленную ветку одного коммита
   Если в вашей ветке есть единственный коммит, который вы хотите отправить в ветку
на удаленном сервере без отправки других коммитов, вы можете использовать следующую
команду:
    git push <удаленный_сервер> <хеш SHA коммита>  : <имя_удаленной_ветки>
   Пример
   Предположим, что история git выглядит следующим образом:

    ееЬ32Ьс Commit  1 - already pushed  #Уже отправлен
    347d700 Commit 2 - want to push    #Хочу отправить
    e539af8 Commit 3 - only local      #для локального использования
    5d339db Commit 4 - only local      #для локального использования

   Чтобы отправить в удаленную ветку master только коммит 347d700, используйте следу
ющую команду:
    git push origin 347d700  : master
Раздел 29.2. Команда push
    git push
   Эта команда отправляет ваш код в удаленный репозиторий. В зависимости от конфигура
ции команды push он будет отправлять код либо из текущей ветки (по умолчанию в Git 2.х),
либо из всех веток одновременно (по умолчанию в Git 1.х).

  Выбор удаленного репозитория
   При работе с Git удобно иметь несколько удаленных репозиториев. Чтобы указать уда
ленный репозиторий, в который необходимо выполнить отправку кода, просто укажите его
имя команде в качестве параметра:
    git push origin
  Выбор ветки
   Чтобы выполнить отправку в определенную ветку, скажем, featu ге_х, воспользуйтесь
следующей командой:
    git push origin featu re_x
  Включить отслеживание для удалеmшй ветки
   Если ветка, в которой вы работаете, изначально не была получена из удаленного репо
зитория, простое использование gi t push не сработает с первого раза. Вы должны выпол
нить следующую команду, чтобы указать Git на то, что он должен отправить текущую ветку
в отслеживаемую удаленную ветку:
    git push --set-upst ream origin master
   Здесь master - это имя ветви на удаленном сервере origin. Можно использовать -u
как сокращенную форму для параметра--set- upst ream.
