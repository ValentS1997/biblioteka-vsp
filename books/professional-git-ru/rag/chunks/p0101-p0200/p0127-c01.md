Глава 39. Команда bundle
Раздел 39.1 . Создание пакета на локальной машине и его
использование на другой
   Иногда требуется поддерживать версии git-репозитория на машинах, не имеющих се
тевого подключения. Пакеты позволяют упаковывать объекты и ссылки Git в репозиторий
на одной машине и импортировать их в репозиторий на другой.
    git tag 201 6_07_24
    git bundle create changes_between_tags . bundle   [ some_previous_tag ]
              .  . 201 6_07_24
   Каким-либо образом перенесите файл changes_between_ tags . bundle на удаленную ма
шину, например, с помощью флешки. Как только он будет скопирован на машину, необхо
димо выполнить ряд команд:
    git bundle verify changes_between_ tags . bundle  # убедиться,  что пакет прибыл
                                                  # в целости и сохранности
    git checkout   [ some branch ]      # в реnозитории на удаленной машине сделать
                                    # какую-то ветвь текущей
    git bundle list-heads changes_between_tags . bundle  # список ссылок в пакете
    git pull changes_between_tags . bundle   [ ссылка из пакета ,  например ,  послед
    нее поле из предыдущего вывода ]  .
   Возможен и обратный вариант. После внесения изменений в удаленный репозиторий
можно собрать дельты в пакет; скопировать изменения, например, на флешку, и слить их об
ратно в локальный репозиторий, чтобы они оставались синхронизированными, не требуя
прямого доступа к gi t, ssh, rsync или httр-протоколу между машинами.
