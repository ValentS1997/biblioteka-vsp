Глава 57. Команда git rerere
   Команда ге ге ге относится к частично скрытым компонентам. Ее название представля
ет собой аббревиатуру фразы "reuse recorded resolution" (повторное использование записан
ного решения). Эта команда позволяет указать Git запоминать, как вы разрешили текущий
конфликт, связанный с несовпадающими кусками кода у двух сравниваемых файлов (кон
фликт типа hunk). Это позволит в дальнейшем автоматически разрешить его в следующий
раз при возникновении похожей ситуации.
Раздел 57 .1 . Включение rerere
   Для включения функции ге ге ге выполните следующую команду:
     $ git config --global rerere . enaЫed true
   Это может быть сделано как для конкретного локального репозитория, так и в глобаль
ном масштабе.

Глава 58. Переименование репозитория
   Если изменить имя репозитория на удаленной стороне (на стороне сервера), например,
на вашем сервере gi thub или bi tbucket, то при попытке передачи данных в удаленный ре
позиторий возникнет ошибка: Fatal error, repository not found**.

Раздел 58.1 . Изменение локальных настроек
   Перейдите к терминалу и наберите следующую последовательность команд:
     cd proj ectFolder
    git remote -v   ( покажет предыдущий адрес url удаленного репозитория )
    git remote set-url origin https  : //username@bitbucket .org/username/newName . git
     git  remote -v   ( повторная проверка ,  в результате выполнения будет выведен    новый адрес url}
    git push (теперь можно передать на удаленный сервер то, что вам было необходимо)  .

Глава 59. Метки Git
   Как и большинство систем управления версиями (VCS), Git имеет возможность отмечать
определенные моменты истории как важные. Обычно разработчики используют эту функ
цию для пометки точек выпуска очередного релиза (v1  . 0 и т. д.).
Раздел 59.1 . Перечисление всех доступных тегов
   С помощью команды g i t tag можно вывести на экран список всех доступных тегов:
     $ git tag    <output follows>
    v0 . 1
     v1  . 3
   Примечание: теги выводятся в алфавитном порядке.
   Также возможен поиск по имеющимся тегам:
     $ git tag -1  "v1  . 8 . 5*"
    <output follows>  v1   . 8 . 5
