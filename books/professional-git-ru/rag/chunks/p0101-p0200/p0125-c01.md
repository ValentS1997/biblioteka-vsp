   Запустите powershell (win) и введите команду:

    git-tf clone http  : / /my . tfs . se rve r  . add ress  : port/tfs/mycollection     '

Раздел 36.5. Миграция с SVN на Git с помощью svn2git
   Утилита svn2git - это RuЬу-обертка для встроенной в Git поддержки SVN через git-svn, по
могающая переносить проекты из Subversion в Git, сохранять историю (включая историю ос
новной ветви, тегов и веток). Подробная документация по утилите svn2git находится на сай
те https://github.com/nirvdrum/svn2git.

  Примеры
   Для переноса svn-репозитория со стандартным расположением (то есть ветки, теги и ос
новная ветка на уровне корня репозитория):

     $ svn2git http  : / /svn . example . com/path/to/ repo

   Для переноса svn-репозитория, не имеющего стандартной структуры:

     $ svn2git http  : / /svn . example . com/path/to/ repo --t runk t runk-dir
    --tags tags-dir --b ranches b ranches-dir

   В случае если вы не хотите переносить (или у вас нет) ветки, метки или основной ветки
(trunk), вы можете использовать опции - - not runk, - - nob ranches и - - notags  .
   Например, $  svn2git  http  : / /svn  . example . com/path /to/ repo  --t runk  t runk-dir
- - notags --nob ranches перенесет только историю основной ветки.
   Для уменьшения места, занимаемого новым репозиторием, вы можете исключить
из него каталоги и файлы, которые вы когда-то добавляли, но не должны были (например,
каталог сборки или архивы):

     $ svn2git http  : / /svn . example . com/path/to/ repo --exclude build --exclude
              '  . *\  . zip$ '
