Раздел 25.1  . Поверхностное клонирование (shallow clone)                                                   1 01
Глава 25. Клонирование репозиториев
Раздел 25.1 . Поверхностное клонирование (shallow clone)
   Клонирование огромного хранилища (например, проекта с многолетней историей) мо
жет занять много времени или завершиться неуспеmно из-за большого объема передавае
мых данных. В случаях, когда нет необходимости иметь полную историю, можно выполнить
поверхностное клонирование:
    git clone   [ repo_u rl ] --depth  1
   Приведенная выше команда получит только последний коммит из удаленного репозитория.
   Имейте в виду, что в образованном поверхностном репозитории вы не сможете выпол
нить процедуру слияния. Часто бывает полезно взять по крайней мере столько коммитов,
сколько потребуется отмотать назад для разрешения слияний. Например, можно получить
последние 50 коммитов:
    git clone   [ repo_u rl ] --depth 50
   В дальнейшем, при необходимости, можно получить остальные части репозитория:
   Версия 0 1.8.3
    git fetch --unshallow           # эквивалент git fetch --depth=21 47483647
                                    # извлекает остальную часть репозитория
   Версия < 1.8.3
    git fetch --depth=1 000          # получить последние  1 000 коммитов
Раздел 25.2. Регулярное клонирование
   Чтобы загрузить весь репозиторий, включая полную историю и все ветви, введите ко
манду:
    git clone <url>
   В приведенном примере он будет помещен в каталог с тем же именем, что и имя репо
зитория. Чтобы загрузить репозиторий и сохранить его в определенном каталоге, введите:
    git clone <url>    [ каталог ]
   Более подробная информация приведена в разделе "Клонирование репозитория".

Раздел 25.3. Клонирование конкретной ветки
   Чтобы клонировать конкретную ветку репозитория, введите параметр --branch <имя
ветки> перед uгl-адресом удаленного репозитория:
    git clone --branch <имя ветви> <u rl>    [ каталог ]
   Чтобы использовать сокращенную врсию параметра --branch, введите -Ь. Эта команда
загружает весь репозиторий и проверяет <имя ветви>.
   Для экономии дискового пространства можно клонировать историю, ведущуюся только
в одной ветви:
    git clone --branch <имя_ветви> --single-branch <u rl>    [ каталог ]
   Если в команду не добавить --s ing le-Ь r anch, то история всех веток будет клонирована
в [каталог] . Это может быть проблемой при работе с большими репозиториями.
   Чтобы впоследствии отменить флаг --single-branch и получить остальную часть ре
позитория, выполните команду:
    git config remote . origin  . fetch "+refs/heads/*  : refs/ remotes/origin/*"
    git fetch origin
