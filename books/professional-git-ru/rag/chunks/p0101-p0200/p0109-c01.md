Глава 27. Поддеревья
Раздел 27 .1 . Создание, извлечение и обратная загрузка
   Создать поддерево
   Добавить новый репозиторий с именем plugin, связаный с удаленным репозиторием,
можно командой:
    git remote add plugin https  : / /path  . to/ remotes/plugin  . git
   Теперь создадим поддерево, указав в качестве префикса новую папку plugins/demo.
Здесь plugin - это имя удаленного репозитория, а ссылка maste r указывает на основную
ветку maste r в репозитории созданного нами поддерева:
     git subt ree add  - - p refix=plugins/demo plugin maste r
  Обновление поддеревьев
   Извлечь коммиты из поддерева plugin можно командой:
    git subt ree pull  - - p refix=plugins/demo plugin maste r
   Обновление дерева при помощи обратного портирования (Васk-порт)
        1.  Выберите коммиты, сделаðrnые в суперпроекте, которые должны бьггь портированы:
          git commit -am  " new changes to  Ье backpo rted "
         2.  Выберите ветку для слияния и сделайте репозиторий с отслеживаемым поддеревом:
          git checkout -Ь backpo rt plugin /maste r
        3.  Выполните обратное портирование с помощью команды git cherry-pick  :
          git cherry-pick -х  - -st rategy=subt ree maste r
       4.  Перешлите изменения назад в исходное поддерево plugin:
          git push plugin backpo rt  : maste r

Раздел 28.1 . Переименование папок
   Чтобы переименовать папку из oldName в newName, можно воспользоваться командой:
    git mv di recto ryToFolde r/oldName di recto ryToFolder/newName
   После этого следует выполнить команду gi t commi t и/или команду gi t push.   В случае возникновения ошибки вида:
     fatal: renaming 'directoryТoFolder/oldName' failed: Invalid argument
 ... используйте следующую команду:
     git mv directoryToFolder/oldName temp && git mv temp directoryToFolder/newName
