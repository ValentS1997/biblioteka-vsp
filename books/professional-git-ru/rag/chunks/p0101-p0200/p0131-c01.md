1 30                                                      Глава 43. Работа с версиями проекта в Git
Раздел 42.2. Как узнать, кто изменил файл
      / /  Выводит  на  экран  для  каждой  строки  текста ,  содержащегося  в  файле ,
    информацию : имя автора и коммит
    git Ыаmе test . c
      / /  Выводит  на  экран  для  каждой  строки  текста ,  содержащегося  в  файле ,
    информацию : e-mail автора и коммит
    git Ыаmе -е файл test  . c
     / / Ограничивает выбор строк заданным диапазоном
    git Ыаmе  -L  1  , 1 0 test . c
Раздел 42.3. Вывести на экран коммит, в котором
осуществлялось последнее редактирование данной строки
     git Ыаmе <file>
   Эта команда построчно выведет файл на экран. Каждая строка будет аннотирована ком
митом, в котором она редактировалась последний раз.

Раздел 42.4. Игнорировать изменения, связанные
с изменением пробельных символов
   Иногда в репозиториях встречаются коммиты, которые только корректируют пробель
ные символы, например, исправляют отступы или переключаются между табуляцией и про
белами. Это затрудняет поиск коммита, в котором действительно бьm написан код.
    git Ыаmе -w
   Эта команда будет игнорировать изменения, связаные с символами пробела, чтобы было
легче найти измененную строку кода.

Глава 43. Работа с версиями проекта в Git
Раздел 43.1 . Указание версии по имени объекта
     $ git show dae86e1 950Ы 277e545cee1 80551 750029cfe735
     $ git show dae86e1 9
  Вы можете указать версию (или, по сути, любой объект: тег, дерево, т. е. содержимое ката
лога, объект типа ЫоЬ, т. е. содержимое файла), используя хеш SHA-1, имя объекта, или пол
ную 40-байтовую шестнадцатеричную строку, либо подстроку, уникальную для данного ре
позитория.

Раздел 43.2. Символьные имена ссылок на ветви, метки, ветви
в удаленном репозитории
     $ git log master         # указать ветвь
     $ git show v1  . 0          # указать тег
     $ git show HEAD         # указать текущую ветку
     $ git show origin        # указать ветку "origin"  в удаленом репозитории ,
                             # отслеживаемую по умолчанию
