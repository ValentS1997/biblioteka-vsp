   gi t svn clone импортирует ветки subversion (и trunk) как удаленные ветки, включаю

ветвей, а gi t tag -1 - теги репозитория.
    git for-each-ref refs/ remotes/origin/tags        I  cut  -d  / -f  5-        1  grep -v @       1
    while read tagname ;  do git tag $tagname origin/tags/$tagname ;  git branch
      - г -d origin/tags/$tagname ; done
    git for-each-ref  refs/ remotes        I  cut  -d  /  -f 4-        1  grep -v @       1  while  read
    branchname ; do git branch "$branchname"  " refs/ remotes/origin/$branchname"  ;
    git branch  - г -d "origin/$branchname"  ; done
   Миграция с SVN на Git завершена! Просто переместите ваш локальный репозиторий

полностью сохраненную историю версий из SVN.
