Раздел 52.3. Игнорирование файлов и папок
   Если вы используете своей работе графический интерфейс TortioseGit UI, щелкните пра
вой кнопкой мыши на названии файла (или папке), которые вы хотите игнорировать. Поя
вится диалоговое окно -> Delete and add to ignore list, здесь вы можете выбрать, игнорировать
ли все файлы данного типа или только данный конкретный файл -> появится диалоговое
окно. Нажмите Ok, и все будет готово.
