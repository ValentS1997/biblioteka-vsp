Раздел 47 .1 . Создание патча
   Создание патча состоит из двух этапов.
        1.  На первом этапе вносятся изменения и производится их фиксация.
       2.  На втором этапе необходимо выполнить команду git  format -patch  <commit
        reference>  для преобразования всех коммитов, начиная с коммита <commit
        reference> (не включая его), в файлы патчей.
   Например, если патчи должны генерироваться на осове двух последних коммитов:
    git format-patch HEAD~~
   В результате будет создано два файла, по одному на каждый коммит с точки HEAD~~, при
мерно так:
    0001 -hello_world  . patch
    0002-beginning  . patch

Раздел 47 .2. Применение патчей
   Для того чтобы изменения из файла   . patch применить к текущему рабочему каталогу,
необходимо использовать комаду gi t apply some  . patch. Они будут непроиндексированы
и затем должны быть зафиксированы.
   Чтобы применить патч в качестве коммита (с сообщением коммита), используйте команду:
    git am some  . patch
   Чтобы применить все файлы патчей к дереву:
    git am * . patch
