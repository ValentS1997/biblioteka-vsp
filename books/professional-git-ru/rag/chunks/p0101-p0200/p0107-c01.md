1 06                                                                                               26.                                                                             Глава    Прятанье
   Помните, что git  stash  рор  извлечет последнюю запись из "тайника" и удалит ее
из списка "тайников". Чтобы сохранить запись в списке и применить ее только к некоторой
ветке, можно использовать команду:
    git stash apply
Раздел 26.9. Удаление "тайника"
   Удалить все записи можно командой:
    git stash clear
   Удаление последней записи из "тайника":
    git stash d rop
   Удалить любую конкретную запись из "тайника":
    git stash d rop stash@{n}
Раздел 26.1 О. Проверить содержимое части "тайника"
   Если вы создали "тайник" и вам надо проверить только некоторые файлы из этого "тай
ника" воспользуйтесь командой:
    git checkout stash@{0}  -- myfile  . txt
Раздел 26.1 1 . Восстановление ранее внесенных изменений
из "тайника"
   Чтобы получить самую последнюю информацию после выполнения gi t stash, исполь
зуйте команду:
    git stash apply
   Чтобы просмотреть список своих "тайников", используйте команду:
    git stash list
  Вы получите список, который выглядит следующим образом:

    stash@{0}  :  WIP оп master  : 67а4е01 Merge tests into develop
    stash@{1 }  : WIP оп master  : 70f0d95 Add user role to localStorage оп user login

   Запустите еще одну команду gi t  stash для восстановления интересующей вас записи
и в качестве параметра задайте номер по порядку этой записи:
    git stash apply stash@{2}
Раздел 26.1 2. Прятанье в интерактивном режиме
   Прятанье принимает рабочий каталог в неразобранном состоянии - то есть сбитые
в кучу измененные отслеживаемые файлы и проиндексированные изменения - и сохраня
ет все это в стеке незавершенных изменений, которые можно повторно извлечь из памяти
в любое время.
  Хранение только измененных файлов
   Предположим, что вы не хотите хранить проиндексированые файлы, а хотите сохранить
только измененные файлы. В этом вам поможет команда:
    git stash --keep-index
   В результате в "тайнике" будут записаны только рабочие текущие файлы.
