1 38                                    Глава 46. Хранилище крупных файлов Git Large File Storage (LFS)
Раздел 45.6. Переименование удаленного репозитория
   Переименуйте удаленный модуль с именем <старое имя> в <новое имя>. При этом об
новляются все отслеживаемые ветки удаленного репозитория и настройки конфигурации
для них.
   Чтобы переименовать имя удаленного репозитория dev в dev1 , запустите команду:
    git remote rename dev dev1

Глава 46. Хранилище крупных файлов
Git Large File Storage (LFS)
Раздел 46.1 . Объявление определенных типов файлов для их
внешнего хранения
   Обычный рабочий процесс при использовании Git LFS заключается в объявлении фай
лов, которые будут перехватываться с помощью системы, основанной на правилах, как это
мы делали ранее на основе файлов   . g i t igno ге  .
   Чаще всего подстановочные символы используются для выбора определенных типов
файлов и для организации их отслеживания.
   Например, git lfs t rack  "* . psd"  .
   Если файл, соответствующий описанному выше шаблону, проиндексирован и зафикси
рован, то при последующей отправке в удаленное хранилище он будет переправлен отдель
но, с указателем, заменяющим файл в удаленном хранилище.
   После того как файл будт поставлен на отслеживание  с помощью  lfs, ваш файл
 . gitatt ributes будет соответствующим образом обновлен. GitНub рекомендует сделать
коммит своего локального файла    . gitatt ributes , а не работать с глобальным файлом
 . gi tatt ributes , чтобы избежать проблем при работе с разными проектами.

Раздел 46.2. Установка конфигурации LFS для всех клонов
   Чтобы применить опции для LFS ко всем клонам, необходимо создать в корне репозито
рия файл с именем  . l fsconfig и сделать коммит. В этом файле можно задать опции для LFS
точно так же, как мы делали это в файле   . gi t/config.
   Например, чтобы какой-то файл исключался по умолчанию при чтении из LFS, необхо
димо создать файл   . 1 fsconfig и сделать коммит. При этом файл конфигурации должен со
держать следующие строчки:
           [ lfs ]
       fetchexclude = ReallyBigFile . wav

Раздел 46.3. Установка LFS
   Загрузить и установить LFS можно либо через Homebrew, либо с сайта https://git-lfs.
github.com/.
   В первом случае набор инструкций будет следующий:
    brew install git-lfs
    git lfs install
   Часто также требуется выполнить некоторую настройку сервиса, на котором размещен
ваш удаленный сервер, чтобы он мог работать с lfs. Для каждого хоста эта настройка будет
разной, но, скорее всего, достаточно будет установить параметр, указывающий на то, что вы
хотите использовать git lfs.
