1 09Раздел 28.2. Переименование локальной и удаленной веток
Раздел 28.2. Переименование локальной и удаленной веток
   Самый простой способ - перейти на локальную ветку при помощи команды:
    git checkout old_branch
   Затем переименовать локальную ветвь, удалить старую удаленную ветку, а новую пере-
именованную ветвь сделать удаленной веткой:
    git branch  -m new_branch
    git push origin     : old_branch
    git push --set-upst ream origin new_branch
Раздел 28.З. Переименование локальной ветки
   Переименовать ветку в локальном репозитории можно с помощью команды:
    git branch  -m old_name new_name

Глава 29. Публикация кода
   Параметр       Описание
   --force        Перезаписывает удаленную ссылку так, чтобы она соответствовала ва
               шей локальной ссьшке. Может привести к потере коммитов в уда
                 ленном penoзumopuu, поэтому используйте его с осторожностью.
   --verbose      Выполнить публикацию кода с подробным описанием.
    < remote>       Удаленное хранилище, на которое направлена операция push.
    < refspec>  .  .  .    Указывает, какую удаленную ссылку следует обновить с какой локаль
                 ной ссьшкой или объектом.

   После изменения, индексации и фиксации кода с помощью Git для того, чтобы сделать
все эти изменения доступными для других разработчиков, необходимо выполнить коман
ду push и перенести локальные изменения на сервер удаленного репозитория. В этой главе
мы рассмотрим, как правильно выполнять публикацию кода с помощью Git.

Раздел 29.1 . Отправка конкретного объекта в удаленную ветку
  Общий синтаксис
    git push  < remotename> <obj ect>  : < remotebranchname>
   Пример:
     git push origin master :wip-you rname
   Результат выполнения команды - ваша основная ветка master будет отправлена в ветку
wip-you rname удаленного репозитория origin (чаще всего это репозиторий, из которого вы
первоначально клонировали свою ветку).
  Удаление ветки из репозитория на удаленном сервере
   Удаление ветки из репозитория на удаленном сервере эквивалентно отравке в нее пусто
го объекта:
    git push  < remotename>     : < remotebranchname>
