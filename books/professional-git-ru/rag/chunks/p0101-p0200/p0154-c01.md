1 53Раздел 55.1  . Обращение к имени ветки в терминале
Глава 55. Как задать имя ветви
в командной оболочке Bash
под ОС Ubuntu
   Этот раздел посвящен работе с именем ветки для Git в командной оболочке bash. Нам,
разработчикам, очень часто требуется найти имя ветки Git. Мы можем добавить имя ветки
к пути до текущего каталога.

Раздел 55.1 . Обращение к имени ветки в терминале
  Что такое PS1
   PS1 обозначает Prompt String  1 (строка приглашения 1). Это одна из строк приглашений
(prompt), доступных в оболочке Linux/UNIX. При открытии терминала в строке приглашения
bash будет отображаться содержимое, заданное в переменной PS1. Для того чтобы добавить
имя ветви в строку приглашения bash, необходимо отредактировать переменную PS1 (уста
новить значение PS1 в ~/.bash_profile).
  Отображе1mе имени ветки Git
   Добавьте следующие строки в ваш файл ~/.bash_profile:
    git_branch ( )  {
      git branch 2> /dev/null       I  sed -е     ' / л [ л* ] /d '  -е     ' s/*  \ (  . *\ ) /   ( \1 ) /  '
       }    export PS1 =" \u@\h  \ [ \033 [ 32m\ ] \w\ [ \033 [ 33m\ ] \$(git_branch) \ [ \033 [ 00m\ ]  $  •
   Функция git_branch найдет имя ветки, на которой мы находимся в текущий момент.
По завершении этих изменений мы можем перейти в gi t- геро в терминале и увидеть на
звание ветки, отображамое в строке приглашения.

Глава 56. Перехватчики на стороне
клиента Git

   Как и во многих других системах контроля версий, в Git есть возможность запускать
пользовательские скрипты при выполнении определенных важных операций. Существует
две группы таких скриптов-перехватчиков: на стороне клиента и на стороне сервера. Пе
рехватчики на стороне клиента запускаются при выполнении таких операций, как прове
дение коммита и слияние, а перехватчики со стороны сервера - при выполнении сетевых
операций, например, при получении коммитов. Вы можете использовать эти скрипты-пере
хватчики по самым разным причинам.

Раздел 56.1 . Скрипт-перехватчик pre-push
   Скрипт р re-push вызывается во время работы команды g i t push после проверки стату
са удаленного репозитория, но до того, как что-либо будет отправлено. Если этот сценарий
завершается с ненулевым статусом, то ничего передано не будет.
   Вызов этого перехватчика производится со следующими параметрами:

    (Например  : origin )

    https  : //  : //  . git )
