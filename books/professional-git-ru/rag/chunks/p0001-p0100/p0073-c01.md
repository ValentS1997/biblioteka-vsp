72                                                                       Глава 13. Конфигурация

   Для редактирования конфигурации:
     $ git config <ключ> <значение>
     $ git config core . ignorecase true
   Если вы хотите, чтобы изменения действовали для всех ваших репозиториев, используй-
те --global  :
     $ git config --global user . name "Ваше имя "
     $ git config --global user . email "You r Email"
     $ git config --global core . editor vi
   Чтобы увидеть изменения, можно повторно воспользоваться командой gi t config --list.
Раздел 1 3.4. Имя пользователя и адрес электронной почты
   Сразу после установки Git первым делом необходимо задать имя пользователя и адрес
электронной почты. В командной строке оболочки введите:
    git config --global user . name "Мг  .  Bean"
    git config --global user . email mrbean@example . com
     •   gi t config - команда для получения или установки параметров.
     •   --global означает, что будет отредактирован файл конфигурации, индивидуаль
       ный для вашей учетной записи пользователя.
      •   user.name и user.email - ключи для переменных файла конфигурации; user - раз
        дел файла конфигурации. name и email - имена переменных.
      •    "М r .  Bean" и m rbean@example . com - это значения, которые вы храните в двух пе
        ременных. Обратите внимание на кавычки вокруг слова "М r .  Bean", которые необ
        ходимы, поскольку сохраняемое значение содержит пробел.

Раздел 1 3.5. Множественные имена пользователей
и адреса электронной почты
   Начиная с версии Git 2.13 сразу несколько имен пользователей и адресов электронной по
чты могут быть настроены с помощью фильтра папок.
          для  Пример    Windows
           . gitconfig
   Запустить редактирование файла конфигурации: git config --global -е
   Добавить строки:

           [ includelf "gitdir  : D : /work/ " ]
        path  =     . gitconfig-work . config
           [ includelf "gitdir  : D : /opensou rce/" ]
        path  =     . gitconfig-opensou rce . config

   Примечания:
      •   Очередность зависит от принципа, "кто последний совпал, тот и победил".
      •   Обязательно  наличие  обратного  слеша   /  в  конце  строки  оределения,  например,
          "gi tdir  : D : /work" не будет работать.
      •   Обязательно наличие префикса g i td i r  : .
           . gitconfig-work. config
   Файл находится в том же каталоге, что и   . gi tconfig.
