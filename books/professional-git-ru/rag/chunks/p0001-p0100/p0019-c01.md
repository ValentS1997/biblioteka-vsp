Раздел 2.5. Поиск в журнале
     git log -S "#define SAMPLES"
   Ищет добавление или удаление определенной строки или строки, соответствующей
заданному регулярному выражению REGEXP. В данном случае мы ищем добавление/удале
ние строки #define SAMPLES. Например:

    +#define SAMPLES  1 00000

   или

    -#define SAMPLES  1 00000

    git log -G "#define SAMPLES"

   Поиск изменений в строках, содержащих определенную строку или строку, соответству
ющую заданному регулярному выражению REGEXP.
   Например:

    -#define SAMPLES  1 00000
    +#define SAMPLES  1 00000000

Раздел 2.6. Список всех материалов, сгруппированных
по фамилии автора
   git shortlog обобщает git log и группирует его по авторам.
   Если параметры не заданы, то будет выведен список всех коммитов, сделанных каждым
автором, в хронологическом порядке:
     $ git shortlog
    Автор  1   ( <число_коммитов> )  :
          Описание коммита  1
           Описание коммита 2
    Автор 2   ( <число_коммитов> )  :
           Описание коммита  1
           Описание коммита 2

   Чтобы просто увидеть количество коммитов и исключить описание коммита, передайте
команде параметр summary:
     -s
    --summa ry
     $ git shortlog -s
