Раздел 23.6. Pull, "операция запрещена"
   Некоторые проблемы могут возникнуть, если папка   . g i t имеет неправильные права.
Устранить эту проблему можно, установив владельца всей папки   . git. Иногда случается
так, что другой пользователь извлекает данные и изменяет права на папку  . g i t или файлы.
   Устранение проблемы:

Глава 24. Перехватчики в Git (Hook)
Раздел 24.1 . Перехватчик pre-push
   Доступен в версии Git 1.8.2 и выше.
   Версия  ;:,: 1.8.
   Предварительные перехватчики могут быть использованы для предотвращения выпол
нения команды push. Это может быть полезно, например, для блокировки случайных вызо
вов команды push, осуществлямых вручную в определенные ветки или для блокировки этой
команды в случае неудачного тестирования (модульные тесты, синтаксис).
   Перехватчик pre-push создается путем простого создания файла с именем р re- push в ка
талоге   . git/hooks/ и (внимание!) проверкой того, что этот файл исполняемый: chmod  +х
  . /git/hooks/ pre- push  .
   Вот пример от Ханны Вульф, который перехватывает команду push, производящую от-
правку коммитов в ветку master:

    protected_branch=  ' maste r '
    cur rent_branch=$(git symbolic-ref HEAD       I  sed  - е     ' s ,   . */ \ (  . *\ )  , \1  ,   ' )
     if   [ $protected_branch  = $cu rrent_branch
