Раздел 1 4.1 . Создание новой ветки и переход на нее
   Чтобы создать новую ветку, находясь в текущей, используйте команду:
    git branch <имя>
   Как правило, имя ветки не должно содержать пробелов, и к нему предъявляется
еще ряд требований. Подробнее об этих требованиях можно узнать, перейдя по адресу
https://stackoverflow.com/questions/3651860/which-characters-are-Шegal-within-a-branch-name.
   Для перехода на существующую ветку служит команда:
    git checkout <имя>
   Для создания новой ветки и перехода на нее служит команда:
    git checkout -Ь <имя>
   Чтобы создать ветку в точке, отличной от последнего коммита текущей ветки (также из
вестной как HEAD), используйте одну из этих команд:
    git branch <имя>    [ <start-point> ]
    git checkout -Ь <имя>    [ <sta rt-point> ]
   В качестве параметра < sta rt-point> может выступать любая ревизия, известная Git (напри
мер, имя другой ветки, SНА коммита или символическая ссылка, такая как HEAD или имя тега):
    git checkout    <имя> some_other_b ranch                   -ь    git checkout    <имя> af295                   -ь    git checkout    <ИМЯ> HEAD~S                   -ь    git checkout    <имя> v1  . 0 . 5                   -ь
   Более подробную информацию о ревизиях можно посмотреть по адресу https://git-scm.
com/docs/revisions.
   Для создания ветки на основе удаленной ветки (по умолчанию <имя_удаленной_вет
КИ> - origin):
    git branch <name>  < remote_name>/<branch_name>
    git checkout -Ь <name>  < remote_name>/<branch_name>
   Если заданное при создании имя ветки встречается только на удаленном сервере, можно
просто использовать:
    git checkout -Ь <branch_name>
...что эквивалентно:
    git checkout -Ь <branch_name>  < remote_name>/<branch_name>
   Иногда может потребоваться перенести несколько последних коммитов в новую ветку.
