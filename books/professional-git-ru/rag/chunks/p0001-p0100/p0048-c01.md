Раздел 7 .5. Отмена нескольких выполненных коммитов
   Воспользуйтесь командой отката gi t reve rt для отмены уже выполненных коммитов,
особенно если эти коммиты бьши перенесены в удаленный репозиторий. При этом выпол
няются несколько новых коммитов, чтобы устранить последствия от выполненных ранее
коммитов, которые теперь можно смело размещать, не переписывая заново историю версий.
   Не используйте gi t push --fo гсе , если не хотите навлечь на себя гнев всех остальных
пользователей этого репозитория. Никогда не переписывайте общую историю.
   Если, например, вы только что выложили коммит, содержащий ошибку, и вам нужно его
отменить, проделайте следующее:
     git revert HEAD~1
     git push
   Теперь вы можете локально отменить коммит при помощи команды reve rt, исправить
свой код и выложить хороший код:
    git revert HEAD~1
    работа     .  .  .  работа     .  .  . работа     .  .  . работа
    git add -А
    git commit -m "Обновить код ошибки "
    git push
   Если коммит, который вы хотите отменить, уже перестал быть последним в истории вер
сий, вы можете просто в этой команде использовать хеш этого коммита. Git создаст контр
коммит, отменяющий ваш исходный коммит, который вы можете безопасно отправить
в ваш удаленный репозиторий:
    git revert 91 2aaf0228338d0c8fb8cca0a064b01 61 a451 fdc
    git push

Раздел 7.6. Отмена/переработка серии коммитов
   Предположим, что вы хотите отменить десяток коммитов, и вам нужны только некото
рые из них:
    git rebase -i <ранний SHA>
   Параметр -i переключает выполнение команды перемещения (rebase) в "интерактивный
режим". Эта команда запускается так же, как это рассматривалось ранее, но перед отображе
нием коммитов делает паузу и позволяет аккуратно изменять каждый коммит в процессе
своего выполнения. Команда rebase -i открывает в вашем стандартном текстовом редак
