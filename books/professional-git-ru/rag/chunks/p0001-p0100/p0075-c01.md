74                                                                             Глава 1 4. Ветвление
рованного на Uniх-машине, такой как Linux или OSX, могут возникнуть проблемы: будет ка
заться, что текст вообще не имеет окончаний строк. Это связано с тем, что в Uniх-системах
применяется различное завершение строки, состоящее только из перевода строки (LF).
   Для устранения этой проблемы можно выполнить следующую инструкцию:
    git config --global core . autocrlf=true
   Выполнение этой команды обеспечит настройку окончаний строк в соответствии с ОС
Microsoft Windows (LF -> CR+LF)
  На базе Unix (Linux/OSX)
   Аналогичным образом могут возникать проблемы, когда пользователь Uniх-подобной
операционной системы попытается прочитать файлы, отредактированные в OS Microsoft
Windows. Для предотвращения непредвиденных проблем запустите команду:
    git config --global core  . autoc rlf=input
   При фиксации это изменит окончания строк с CR+LF -> +LF.

Раздел 1 3.8. Конфигурация только для единственной команды
   Можно использовать параметр -с <имя>=<значение> , чтобы добавить конфигурацию
только для одной команды. Чтобы выполнить коммит от имени другого пользователя без из
менения настроек в     . gi tconfig:
    git -с user  . email = mail@example commit -m "some message"
   Замечание: в этом примере нет необходимости уточнять и user  . name, и user  . email, Git сам допи
   шет недостающую информацию из предыдущих коммитов.

Раздел 1 3.9. Настройка прокси-сервера
   Если вы находитесь за прокси-сервером, вы должны сообщить об этом Git:
    git config --global http  . p roxy http  : //my . p roxy . com  : portnumber
   Если вы больше не находитесь за прокси-сервером:
    git config --global --unset http  . p roxy

Глава 1 4. Ветвление
   Параметр        Подробности
    -d,  --delete    Удалить ветку. Ветка должна быть полностью слита со своей версией,
                  расположенной на удаленом сервере, или с HEAD, если удаленная ветка
                   не бьта задана с помощью параметров --track или --set-upstream .
                  Сокращенная форма команды --delete --force  .    -D
    -m,  --move      Переместить/переименовать ветку и соответствующий ссылочный
                    лог (RefLog).
                  Сокращеная форма команды --move --force  .   -м
    - г ,  -- remotes   Перечислить или удалить (если используется вместе с параметром -d)
                  удаленные ветви (расположенные на удаленном сервере).
