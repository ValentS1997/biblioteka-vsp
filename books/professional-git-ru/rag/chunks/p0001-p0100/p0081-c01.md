80                                                                        Глава 1 6. Объединение
   Имейте в виду, что при этом создается новый коммит, по сути, уничтожается информация
о предыдущих х коммитах, включая их автора, сообщений коммитов и дату. Вероятно, сна
чала нужно скопировать существующие сообщения коммитов.

Раздел 1 6.2. Объединение коммитов во время слияния
  Вы можете использовать команду g i t me rge -- sq uash , чтобы объединить изменения,
внесенные ветвью, в один коммит. Фактический коммит при этом создан не будет:
    git merge --squash <branch>
    git commit
   Это более или менее эквивалентно использованию комады g i t reset, но удобнее, когда
включаемые изменения имеют символическое имя. Сравните:
     git checkout <branch>
    git reset --soft $ ( git merge-base master <branch> )
    git commit

Раздел 1 6.З. Объединение коммитов во время выполнения
операции перемещения
  Коммиты могут быть объединены и во время выполнения команды git  rebase. Перед
тем как пытаться объединить коммиты таким образом, рекомендуется разобраться с процес
сом перемещения.
        1.   Определите, с какого коммита вы хотите выполнить перемещение, и запомните
       хеш этого коммита.
        2.  Выполните команду git rebase -i   [ commit hash ]  .
   Также вместо хеша коммита можно ввести HEAD~4, чтобы иметь возможность просмо
треть последний коммит и еще 4 коммита до него.
        3.  В текстовом редакторе, открывающемся при выполнении этой команды, опреде
         лите, какие коммиты вы хотите объединить. Замените pick в начале этих строк
        на squash , чтобы объединить их в один предшествующий им коммит.
       4.  После того как вы выбрали коммиты, которые вы хотели бы объединить, вам будет
        предложено написать сообщение для этого коммита.
   Вывод списка коммитов для определения места перемещения:
     > git log -oneline
     61 2f2f7 This commit should not Ье squashed  #Этот коммит не должен быть
                                                #объединен
    d84b05d This commit should Ье squashed #Этoт коммит должен быть объединен
    ас60234 Yet another commit            #Еще один коммит
    36d1 5de Rebase from here               #Перемещение из этой точки
       1 7692d1  Did some more stuff            #Еще какое-то содержимое
    е647334 Another Commit                #Еще один коммит
    2e30df6 Initial commit                 #Начальный коммит

     > git rebase  -i 36d1 5de
   В этот момент на экране отобразится рабочее окно выбранного вами в файле конфигу
рации текстового редактора, в котором вы можете указать, что вы хотите сделать с комми
тами. Немножко разобраться с этим вам помогут предоставленные Git комментарии. Если
оставить всё как есть, то ничего не произойдет, поскольку все коммиты будут сохранены,
