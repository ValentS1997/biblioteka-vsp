25Раздел 3.1 1  . Вывести информацию о конкретном удаленном репозитории
   Получение текущего имени удаленного репозитория:
    git remote
    # origin
   Проверка текущего имени удаленного репозитория с помощью URL:
    git remote -v
    # origin https  : //github . com/username/ repo . git   ( fetch)
    # origin https  : //github . com/usernam/ repo . git   ( push )
   Переименование удаленного репозитория:
    git remote rename origin destination
    # Изменить имя удаленного реnозитория с     ' o rigin  '  на     ' destination '
   Проверка того, что имя репозитория изменилось на новое:
    git remote -v    # destination https  : //github . com/username/ repo . git (fetch )
    # destination https  : //github . com/usernam/ repo . git   ( push )
   === Возможные опшбки ===
        1.  Could not rename config section 'remote.[old name]' to 'remote.[new name]' (Не удалось
        переименовать раздел конфигурации 'rеmоtе.[старое_имя]' в 'rеmоtе.[новое_имя]').
         Эта ошибка означает, что удаленный репозиторий, для которого вы пытались ис
         пользовать старое имя (origin), не существует.
        2.  Remote [new name] already exists (Удаленный репозиторий [новое_имя] уже суще
          ствует).
        Данное сообщение об ошибке не требует пояснений, и причина ошибки вытекает
        из самого сообщения о ней.

Раздел 3.1 1 . Вывести информацию о конкретном удаленном
репозитории
   Для вывода некоторой информации об известном удаленном репозитории: о r ig in мож
но воспользоваться командой:
    git remote show origin
   Для того чтобы вывести информацию только об URL-aдpece удаленного репозитория,
можно воспользоваться командой:
    git config --get remote . origin  . u rl
   Начиная с версии 2.7+ это также возможно сделать гораздо проще, чем в описанном
выше варианте на основе команды config следующим образом:
    git remote get-url origin
Раздел 3.1 2. Установка URL для конкретного удаленного репозитория
   Изменить url существующего удаленного репозитория можно командой:
    git remote set-url remote-name url
Раздел 3.1 3. Вывод URL для определенного удаленного репозитория
   Получить url для определенного удаленного репозитория можно с помощью команды:
    git remote get-url <имя>
   Для текущего удаленного репозитория по умолчанию это будет:
    git remote get-url origin
