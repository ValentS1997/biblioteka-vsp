36                                Глава 5. Исключение из отслеживания отдельных файлов и папок
   В качестве альтернативы можно создать файл   . gitignore  в каталоге src/ и указать
в нем имя игнорируемого файла:
    # /src/  . gitignore
    output . log

Раздел 5.1 1 . Создание и регистрация пустой папки в Git
   Добавить и зафиксировать пустую папку в Git невозможно из-за того, что Git управляет
файлами и прикрепляет к ним каталог, что снижает количество коммитов и повышает ско
рость. Чтобы обойти эту проблему, можно воспользоваться двумя способами.
   Первый способ:   . gi tkeep
   Один из способов обойти эту проблему - использовать файл   . gi tkeep  для регистра
ции папки в Git. Для этого достаточно создать требуемый каталог и добавить в него файл
 . gi tkeep. Это пустой файл, и он не служит никакой другой цели, кроме как просто зареги
стрировать папку. Чтобы сделать это в Windows (в которой существуют неудобные соглаше
ния об именовании файлов), просто откройте git bash в каталоге и выполните команду:
     $ touch     . gitkeep
   Эта команда создает пустой файл   . gi tkeep в текущем каталоге.
   Способ второй: dummy . txt
   Другой "хак" для этого очень похож на описанный выше, и можно выполнить те же шаги,
но вместо    . gi tkeep  использовать dummy . txt. Дополнительным преимуществом являет
ся то, что его можно легко создать в Windows с помощью контекстного меню. Кроме того,
в таких файлах можно оставлять забавные сообщения. Для отслеживания пустого каталога
можно также использовать файл   . gi tkeep. Обычно   . gi tkeep - это пустой файл, который
добавляется для отслеживания пустого каталога.

Раздел 5.1 2. Поиск файлов, игнорируемых при помощи .gitignore
   Вывести на экран перечень всех игнорируемых Git файлов в текущем каталоге можно
с помощью команды:
    git status --ignored
   Итак, если мы имеем следующую структуру репозитория:
