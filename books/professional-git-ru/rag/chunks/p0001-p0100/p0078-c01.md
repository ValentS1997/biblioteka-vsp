   Чтобы удалить ветку локально, можно воспользоваться командой, приведенной ниже.
Обратите внимание, что при этом ветка не будет удалена, если в ней есть изменения,
не учтенные во время очередного слияния:

    git branch  -D <b ranchName>

Раздел 1 4.б. Удаление ветки в локальном репозитории
     $ git branch -d dev
   Эта команда удаляет ветку с именем dev, и если ее изменения бьти переданы в другую вет
ку, то они не будут потеряны. Если ветка dev содержит еще не переданные изменения, которые
в результате этой команды будут утеряны, то команда gi t branch  -d завершится неудачей:
     $ git branch -d dev
     е г го г  : The b ranch     ' dev '  is not fully me rged  .
    If you а ге su re you want to delete it ,  run     ' git b ranch -D dev '  .

   Согласно предупреждению, можно принудительно удалить ветку, используя параметр
-D (и потерять при этом все непереданные изменения в этой ветке):
     $ git branch  -D dev
