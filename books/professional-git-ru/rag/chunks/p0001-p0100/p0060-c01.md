Раздел 10.1 3. Изменение автора коммита                                              59
Раздел 1 0.1 З. Изменение автора коммита
   Если вы сделали коммит от имени не того автора, вы можете изменить его, а затем вне-
сти поправки:
    git config user  . name "Полное имя "
    git config user  . email "email@example . com"
    git commit --amend -- reset-author

Глава 1 1 . Псевдонимы
Раздел 1 1 .1 . Простые псевдонимы
   Существует два способа создания псевдонимов в Git:
     •    с помощью файла ~/  . gi tconfig  :
                    [ alias ]
             ci = commit
             st  = status
            со = checkout
     •    с помощью командной строки:
          git config --global alias . ci "commit"
          git config --global alias . st "status"
         git config --global alias . co "checkout"
   После создания псевдонима можно набирать команды так:
      git ci вместо git commiĴ
          · git st вместо git status,
          • git со вместо git checkout.
  Как и в обычных командах Git, псевдонимы могут использоваться вместе с аргументами.
Например:
    git ci -m "Сообщение коммита .  .  . •
    git со -Ь featu re-42
