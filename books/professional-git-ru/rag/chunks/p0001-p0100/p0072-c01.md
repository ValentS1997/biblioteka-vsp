Раздел 1 3.1 . Настройка используемого редактора
   Существует несколько способов задать редактор, который будет использоваться для фик
сации, перемещения и т. д.
     •   Изменить параметр конфигурации core.editor.
            $ git config  - - global core . edito r nano
     •   Установить переменную окружения GIT_EDITOR.
   Для одной команды:
            $ GIT_EDIT0R=nano git commit
        ... или для всех команд, выполняемых в терминале. Примечание: эта настройка действу
ет только до тех пор, пока вы не закроете терминал:
            $ expo rt GIT_EDIT0R=nano
     •  Чтобы изменить редактор для всех программ, использующих терминал, а не только
        для Git, установите переменную окружения VISUAL или EDITOR. Подробнее об этих
        переменных вы можете узнать, перейдя по адресу https://unix.stackexchange.com/
          questions/4859/visual-vs-editor-whats-the-difference.

            $ expo rt EDIT0R=nano
   Примечание: как и в предыдущем случае, это относится только к текущему терминалу; в обо
   лочке обычно имеется файл конфигурации, позволяющий установить это значение на постоян
   ной основе. (В bash, например, добавьте приведенную выше строку в файл ~/  . bash гс или в файл
   ~ /  . bash_p rofile).
   Некоторые текстовые редакторы (в основном с графическим интерфейсом) не могут за
пускать несколько экземпляров одновременно и обычно не запускаются, если у вас уже от
крыт один экземпляр. В этом случае Git выведет сообщение Abo rting commi t due to empty
commi t message .  без возможности отредактировать сообщение фиксации. В этом случае
обратитесь к документации вашего текстового редактора, чтобы узнать, есть ли у него флаг
- -wai t (или аналогичный), который заставит его приостановить работу до тех пор, пока до
кумент не будет закрыт.

Раздел 1 3.2. Автоматическое исправление опечаток
    git config  - - g lobal help . autoco r rect   1 7
   Эта команда позволяет включить автокоррекцию в Git и исправлять мелкие ошибки (на
пример, git stats вместо git status). Параметр, задаваемый в help . autoco r rect , опре
деляет, сколько времени в десятых долях секунды система должна ждать перед автоматиче
ским применением команды с автокоррекцией. В приведенной выше команде 17 означает,
что Git необходимо подождать 1,7 секунды перед применением команды автокоррекции.
   Однако более серьезные ошибки будут считаться отсутствующими командами, так
что если набрать что-то вроде gi t testingi t, то получится, что testingi t не является ко
мандой git .
Раздел 1 3.3. Список и редактирование текущей конфигурации
   Команда gi t config позволяет настроить работу Git. Обычно она используется для ука
зания имени и электронной почты, предочитаемого редактора или способа слияния.
   Для просмотра текущей конфигурации наберите команду:
     $ git config  - - list

    core . edito r=vim
     c redential . helpe r=osxkeychain
