Раздел 1 2.3. Перемещение в интерактивном режиме
   В этом примере будет показано, как можно использовать команду g i t rebase в интерак
тивном режиме. Предполагается, что человек имеет базовое представление о том, что такое
g i t rebase и что он делает.
   Перемещение в интерактивном режиме запускается с помощью следующей команды:
    git rebase -i
   Опция -i означает интерактивный режим. Используя интерактивный режим, пользова
тель может изменять сообщения коммитов, а также переупорядочивать, разделять и/или
объединять несколько коммитов в один общий коммит.
   Допустим, вы хотите переставить три последних коммита. Для этого можно выполнить
команду:
    git rebase -i НЕАD~З
   После выполнения приведенной выше команды в текстовом редакторе будет открыт файл,
в котором вы сможете выбрать способ перемещения ваших коммитов. Для целей данного при
мера достаточно изменить порядок коммитов, сохранить файл и закрыть редактор. Это иници
ирует перемещение в том порядке, который вы применили. Если затем проверить журнал ко
мандой gi t log, то можно убедиться, что все коммить1 расположились в указанном порядке.
  Переформулировка сообщений о фиксации
   Итак, допустим, вы решили, что одно из сообщений коммита неточное, и хотите, чтобы
оно было более конкретным. Давайте выведем на экран три последних коммита с помощью
одной команды, которая решает обе наши задачи - вывод на экран и редактирование сооб
щения коммита:
    git rebase -i НЕАD~З
   Вместо того чтобы переставить коммиты в новом порядке при помощи перемещения,
на этот раз мы заменим pick (выбрать), используемый по умолчанию, на reword (переформу
лировать) в том коммите, где вы хотите изменить сообщение.
   После того как вы закроете редактор начнется процесс перемещения, который остано
вится на конкретном сообщении коммита, которое вы хотели бы заменить.
   Это позволит вам заменить сообщение коммита на желаемое. После изменения сообще
ния просто закройте редактор, чтобы продолжить работу.
  Изменение содержимого коммита
   Кроме исправления сообщения коммита можно также отредактировать содержимое са
мого коммита. Для этого достаточно заменить pick на edit для требуемого коммита. Git оста
новится, когда доберется до этого коммита, и переместит исходные изменения этого комми
та в область индексирования (staging). Теперь вы можете отредактировать эти изменения,
удалив их или добавив новые.
