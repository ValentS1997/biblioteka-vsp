87Раздел 1 9.1  . Интерактивная очистка
   Затем можно воссоздать ветку, выполнив команду:
    git checkout -Ь <branch-name> <sha1 -of-commit>
  Вы не сможете восстановить удаленные ветки, если сборщик мусора Git удалил висячие
коммиты - те, на которые нет ссылок. Всегда создавайте резервную копию своего репозито
рия, особенно если вы работаете в небольшой команде / совместном проекте.
   Более подробно почитать о том, как работает сборщик мусора и как производится очист
ка дерева от лишней информации, можно по адресу https://git-scm.com/docs/git-gc.

Глава 1 9. Git Clean
   Параметр           Пояснения
   -d                  Удалять не отслеживаемые каталоги в дополнение к не отслежи
                   ваемым файлам. Если неотслеживаемый каталог отслеживается
                     другим Git-репозиторием, то по умолчанию он не удаляется. Если
                   вы действительно хотите удалить такой каталог, используйте оп
                  цию -f дважды.
    -f,  --force        Если переменная конфигурации Git clean. requireForce не уста
                      новлена в значение false, то git clean откажется удалять файлы
                    или каталоги, если не задано -f, -n или -i. Git откажется удалять ка
                       талоги с подкаталогом .git или хоть с одним файлом, если не будет
                       задано второе значение -f.
    -i,  --interactive  Интерактивный запрос на удаление каждого файла.
    -n,  --dry- run      Выводить только список файлов, подлежащих удалению, не уда
                      ляя их фактически.
    -q, --quiet         Отображать только ошибки, а не список успешно удаленных файлов.

Раздел 1 9.1 . Интерактивная очистка
    git clean  - i
   Выводит на экран элементы для удаления и запрашивает подтверждение с помощью ко-
манд, подобных следующим:

    Would remove the following items  : #Будут удалены следующие элементы
    folder/file1  . ру
    folder/file2  . py
    *** Commands ***
       1  :  clean   2  : filter Ьу pattern  З  : select Ьу numbers 4 : ask each
     5  : quit    б  : help
    What now>

   Интерактивная опция i может быть добавлена совместно с другими опциями, такими
как Х, d и т. д.

Раздел 1 9.2. Принудительное удаление неотслеживаемых файлов
                -f    git clean
   Эта команда удалит все неотслеживаемые файлы.
