Раздел 2.7. Поиск строки коммита в журнале версий                                                           1 9

    <количество_коммитов> Автор  1
    <количество_коммитов> Автор 2

   Чтобы отсортировать вывод по количеству коммитов, а не в алфавитном порядке по име
ни авторов коммитов, передайте команде параметр numbered:
     -n
    --numbered

   Чтобы добавить электронную почту автора коммита, добавьте параметр email:

     -е

    --email

   Также может быть предоставлена опция вывода в произвольном формате, если необхо
димо отобразить информацию, отличную от описания коммита:

    --format

   Это может быть любая строка, удовлетворяющая требованиям параметра --format ко
манды gi t  log. Подробнее об этом см. выше в разделе "Применение в журналах возможно
сти выделения цветом".

Раздел 2. 7. Поиск строки коммита в журнале версий
   Для того чтобы найти в журнале версий определенную строку с коммитом, используйте
команду:
    git log    [ options ]  --g rep "sea rch_st ring "
   Пример:
    git log --all --g rep  " removed file"
   Будет произведен поиск строки  • removed   file" во всех журналах и во всех вет
ках. Начиная с версии git 2.4+ поиск может быть инвертирован с помощью параметра
--invert-g rep  .
   Пример:
    git log --g rep="add file" --invert-g rep
   Покажет все коммиты, не содержащие строку "add file".
