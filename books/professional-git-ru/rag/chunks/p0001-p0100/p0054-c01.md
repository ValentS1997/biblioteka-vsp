   --no-edit                  Используйте выбранное сообщение фиксации без запу
                                  ска редактора. Например, git commit  --amend  --no
                                 ed i t вносит изменения в коммит без изменения сообще
                           ния о коммите.
   --all, -а                   Фиксирует все изменения, включая даже те, которые

   --date                     Ручная установка даты, которая будет ассоциироваться
                                         с коммитом.

                                 дет фиксироваться то, что у вас в данный момент нахо
                                дится в индексе, если это не будет указано.
   --patch , -p                  Использует интерактивный интерфейс выбора патчей
                             для того, чтобы выбрать изменения, которые будут за
                              фиксировны.
   --help                     Отображает главную страницу команды git commit.
   -S [ keyid ]  ,  -S --gpg-       Добавить подпись к коммиту, снабдить коммит GРG-под
   sign [ =keyid ]  ,               писью, в качестве GРG-подписи использовать значение
   -s --no-gpg-sign           переменной commit.gpgSign файла конфигурации.
    -n, --no-verify              Эта опция позволяет обходить перехватчики pre-commit
                           и commit-msg. См. раздел "Перехватчики" (Hooks).

   Коммиты в Git обеспечивают подотчетность, приписывая авторам изменения в коде.
Git предлагает множество функций для конкретизации и обеспечения безопасности фикса
ции. В данной теме демонстрируются правильная практика и процедуры фиксации в Git.

Раздел 1 0.1 . Индексация и фиксация изменений
  Основы
   После внесения изменений в исходный код перед фиксацией изменений в Git их необхо
димо проиндексировать. Например, если вы изменили README  . md и р rog ram . ру:
     git add README . md prog ram . py
   Это сообщает Git, что вы хотите добавить эти файлы в следующий коммит. Затем зафик
сируйте изменения командой:
    git commit
   Обратите внимание, что при этом откроется текстовый редактор, в качестве которого ча
сто используется Vim. Если вы не знакомы с Vim, то вам будет полезно узнать, что вы можете
нажать i для перехода в режим вставки, написать сообщение для коммита, затем нажать
Esc и   : wq для сохранения и выхода. Чтобы не открывать текстовый редактор, просто вклю
чите в команду параметр -m и наберите после него ваше сообщение:
    git commit  -m "Commit message here"
   Сообщения для коммита часто подчиняются определенным правилам форматирования,
подробнее см. раздел "Хорошие сообщения для коммита".
  Сокращенные команды
   Если в каталоге изменено большое количество файлов, то вместо того чтобы перечис
лять в теле команды каждый из них, можно воспользоваться функцией:
    git add --all    # эквивалентно "git add -а•
