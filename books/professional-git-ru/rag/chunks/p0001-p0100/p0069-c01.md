68                                                       Глава 1 2. Перемещение (команда rebase)
     е 3702650 попытка разрешить добавление элементов todo  : page . html logic  . rb
     е 975430Ь добавление в db работает : db . sql logic  . rb
   Затем Git будет обрабатывать по однму коммиту за раз. После каждого коммита будет вы
дано приглашение, и вы сможете выполнить следующие действия:
    Stopped  at 43b075a92a952faf999e76c4e4d7fa0f44576579  .  .  . first d raft  : page .
    html and db . sql
   Теперь вы можете изменить коммит, используя команду:
               git commit --amend
   После того как вы убедитесь, что внесли необходимые исправления, выполните команду:
               git rebase --continue
     $ git status
     rebase in prog ress ; onto 4975ае9
    You  are  cur rently  editing  а  commit while  rebasing  branch      ' featu re '  оп
           ' 4975ае9  '  .
              ( use "git commit --amend" to amend the cu rrent commit)
              ( use "git rebase --continue" once you a re satisfied with you r changes)
       # (для изменения текущего коммита используйте команду "git commit --amend" }
       # (используйте команду "git rebase --continue" , когда будете удовлетворены
       # внесеными изменениями )
    nothing t o commit , working directory clean
     $ git reset НЕдDл # Это "отменяет" все изменения в этом коммите .
     $ git status -s
      М db . sql
      М page . html
     $ git add db . sql #теперь мы будем создавать небольшие тематические коммиты
     $ git commit -m "first d raft  :  db . sql"
     $ git add page . html
     $ git commit -m "first d raft  : page . html"
     $ git rebase --continue
   Затем мы должны повторить эти шаги для каждого коммита. В итоге мы получим следу-
ющее:
     $ git log -oneline
    0309336 db adding works  : logic . rb
    06f81 c9 db adding works  :  db . sql
    3264de2 adding todo items  : page . html
    675а02Ь adding todo items  : logic . rb
    272с674 first d raft  : page . html
    08c275d first d raft  :  db . sql
   Теперь мы запускаем rebase еще раз для изменения порядка следования коммитов и их
объединения по общим темам:
     $ git rebase  - i master
    Это будет выведено в текстовом редакторе  :
    pick 08c275d first d raft  :  db . sql
    pick 272с674 first d raft  : page . html
    pick 675а02Ь adding todo items  : logic  . rb
    pick 3264de2 adding todo items  : page . html
    pick 06f81 c9 db adding works  :  db . sql
    pick 0309336 db adding works  : logic  . rb
