Раздел 2.1 3. Управление выводом коммитов
между двумя ветвями
   git log master .  . foo покажет коммиты, содержащиеся в ветке foo, но не в ветке master.

Глава 3. Работа с удаленными
репозиториями
Раздел 3.1 . Удаление ветви из удаленного репозитория
   Для удаления ветви из удаленного репозитория воспользуйтесь командой:
    git push   [ remote-name ] --delete   [ b ranch-name ]
   или
    git push   [ remote-name ]      :  [ branch-name ]
Раздел 3.2. Изменение URL-aдpeca удаленного репозитория
   Проверка имеющегося удаленного репозитория:
    git remote -v
    # origin https  : //github . com/username/ repo . git   ( fetch)
    # origin https  : //github . com/usernam/ repo . git   ( push)
