40                                                               Глава 6. Утилита сравнения (diff)
Раздел 6.1 . Просмотр разницы между непроиндексированными
изменениями в рабочей ветви и внесенными в индекс
    git diff
   Эта команда покажет непроиндексированные изменения в текущей ветке относительно
последнего коммита. Полученный результат показывает внесенные изменения только от
носительно индекса, то есть показывает то, что вы могли бы добавить в следующий коммит,
но пока не сделали этого. Для добавления (индексации) этих изменений можно использо
вать команду git add.
   Если файл проиндексирован, но был изменен после последего внесения в индекс, gi t
di ff покажет различия между текущим файлом и его проидексированной версией.
Раздел 6.2. Просмотр разницы между коммитами
    git diff  1 234аЬс .  . 6789def       # предыдущий  новый
   Например, показать изменения, сделанные за последние три коммита:
    git diff @~3 .  . @  # HEAD  -3      HEAD
   Примечание: две точки (. .) необязательны, но добавляют ясности.
   Результат работы команды покажет текстовое различие между коммитами, независимо
от их расположения в дереве версий.

Раздел 6.3. Показать различия между проиндексированными
файлами
    git diff --staged
   При этом будут показаны изменения между предыдущим коммитом и текущими разме
щенными файлами.
   Примечание: для выполнения аналогичных действий можно также использовать следующую
   команду:
    git diff --cached
   Параметр -cached является просто синонимом параметра - -staged или команды:
    git status -v
   Выполнение последней команды приведет также к срабатыванию подробных настроек
команды status .

Раздел 6.4. Сравнение ветвей
   Отобразить изменения между вершиной new и вершиной о riginal:
    git diff original new   # эквивалентно original .  . new
   Показать все изменения в ветви new с момента ее ответвления от ветви original:
    git diff original .  .  . new # эквивалентно $ ( git merge-base original new)  .  . new
   Использование только одного параметра, например
    git diff original
эквивалентно
    git diff original .  . HEAD
