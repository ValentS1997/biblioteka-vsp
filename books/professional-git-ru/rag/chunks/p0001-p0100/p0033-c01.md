32                                Глава 5. Исключение из отслеживания отдельных файлов и папок
   Здесь в .gitignore заданы для игнорирования только файлы *.о, поэтому Readme.md
не указан в выводе git check-ignore.
   Если вы хотите увидеть номер строки с правилом игнорирования, касающегося проверя
емого файла, и саму строку с этим правилом, содержащуюся в .gi tignore, добавьте -v к ко
манде git check-ignore:
     $ git check-ignore -v example  . o Readme . md
               . gitignore  : 1   : * . о         example  . o
   Начиная с версии Git 1.7.6 для просмотра списка игнорируемых файлов можно также ис
пользовать команду git status --ignored. Более подробную информацию об этом можно
найти в официальной документации по адресу https://git-scm.com/docs/git-status или в разде
ле "Поиск файлов, игнорируемых с помощью .gitignore".

Раздел 5.3. Исключения в файле .gitignore
   Если при игнорировании списка файлов с помощью шаблона из него необходимо исклю
чить определенный файл, то к имени файла, который необходимо исключить, следует при
писать восклицательный знак (!). Например:
    * . txt
             ! important  . txt
   Приведенный выше пример предписывает Git игнорировать все файлы с расширением
  . txt ,  за исключением файлов с именем impo rtant  . txt. Если файл находится в игнорируе
мой папке, то исключить его из списка игнорируемых так просто не получится:
    folder/
                 ! folder/*  . txt
   В этом примере все файлы .txt в папке останутся проигнорированными.
   Правильный способ - сначала в отдельной строке исключить саму папку из списка иг
норируемых, затем занести все файлы, содержащиеся в папке, в список игнорируемых пу
тем использованя метасимвола *, и, наконец, повторно исключить из списка игнорируемых
все файлы * . txt, как показано ниже:
                 ! folder/
    folder/*
                 ! folder/*  . txt
   Примечание: для имен файлов, начинающихся с восклицательного знака, добавьте либо второй
   восклицательный знак, либо перед восклицательным знаком добавьте символ "\ "
                 !   ! includethis
      \  ! excludethis

Раздел 5.4. Глобальный файл .gitignore
   Чтобы заставить Git игнорировать определенные файлы во всех репозиториях, можно
создать глобальный файл   . gi tigno re с помощью следующей команды в терминале или ко
мандной строке:
     $ git config --global core . excludesfile <nуть_к_глобальному_файлу_gitignоrе>
   Теперь Git будет использовать этот файл в дополнение к собственному файлу .gi tignore
каждого репозитория. Правила для их взаимодействия следующие:
     •   Если локальный файл   . gitignore явно включает файл в список игнорируемых,
          а глобальный   . gitignore не включает, то локальный   . gitignore имеет приори
         тет (файл будет включен).
