Раздел 1 .1 . Создание первого репозитория, добавление
и фиксация файлов
   Для начала убедитесь, что у вас установлен Git. Для этого вызовите командную строку
и введите в нее одну из следующих команд.
   На всех операционных системах:
    git --version
   В UNIХ-подобных операционных системах:
    which git
   Если после ввода команды вы в ответ ничего не получили или команда не была распоз
нана, возможно, вам придется установить Git на свою операционую систему, загрузив и за
пустив программу установки. Исключительно понятные и простые инструкции по установ
ке см. на домашней странице Git (https://git-scm.com/Ьook/ru/v2/Bвeдeниe-Ycтaнoвкa-Git).
