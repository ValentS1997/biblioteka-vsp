Раздел 5.1 З. Игнорирование только части файла [stub]
   Иногда возникает необходимость иметь локальные изменения в файле, которые не нуж
но фиксировать или публиковать. В идеале локальные настройки должны быть сосредото
чены в отдельном файле, который может быть помещен в   . gitigno re, но иногда в качестве
краткосрочного решения может быть полезно иметь какой-то локальный фрагмент в индек
сируемом файле.
  Вы можете заставить Git "не видеть" эти строки при помощи специального фильтра. Они
даже не будут отображаться в дельте (dift).
   Предположим, что здесь приведен какой-то фрагмент из файла file1  . с  :
     st ruct settings s  ;
     s  . host      " localhost "  ;
     s . po rt  = 5653 ;
     s  . auth      1  ;
     s . po rt      1 5653 ;  / / NOCOMMIT
     s  . debug  =  1  ;  // NOCOMMIT
     s  . auth  = 0 ;  // NOCOMMIT
  Нам нобходимо сделать так, чтобы в репозитории не отображались строки, отмеченные
комментарием NОСОММП .
   Создадим фильтр "nосоmmit", добавив его в файл конфигурации Git, например  . git/config:
           [ filte r  " nocommit " ]
       clean=g rep -v NOCOMMIT
   Добавьте (или сначала создайте и добавьте) следующую строку в файл    . git/info/
att ributes или   . gitmodules:
    file1  . с filter=nocommit
   Теперь ваши строки NOCOMMIТ будут скрыты от Git.
   Комментарии:
      •   Использование фильтра clean замедляет обработку файлов, особенно пoдWindows.
      •   Игнорируемая строка может исчезнуть из файла при обновлении Git. Этому мож
        но противостоять с помощью фильтра smudge, но это потребует некоторых усилий.
      •  Не тестировалось под Windows.
