60                                                                         Глава 1 1  . Псевдонимы
Раздел 1 1 .3. Расширенные псевдонимы
    Git позволяет использовать в псевдонимах команды, не относящиеся к Git, и задейство
вать полный синтаксис командной оболочки sh, если перед командами поставить пре
фикс   !  . Это полезно, если вы пишете свои утилиты для работы с Git-репозиторием. Напри
мер, в файле ~/  . gitconfig можно задать такую составную комаду temp:
          [ alias ]
        temp =    ! git add  -А && git commit  -m  "Temp"
   Тот факт, что полный синтаксис оболочки доступен в этих псевдонимах, также означает,
что вы можете использовать функции оболочки для создания более сложных псевдонимов,
например таких, которые используют аргументы командной строки:
          [ alias ]
        ignore =  "   ! f( }  { echo $1  > >     . gitignore ;  } ;  f"

   Приведенный выше псевдоним определяет функцию f, а затем запускает ее с любыми
аргументами, переданными в псевдоним. Таким образом, запуск git ignore     . tmp/  доба
вит   . tmр/ в ваш файл   . gitignore .
   На самом деле такой механизм очень полезен, поскольку Git определяет переменные
$1 , $2 и т. д. за вас, так что вам даже не нужно определять для него специальную функ
цию. (Но имейте в виду, что Git все равно добавит свои аргументы, даже если вы обра
щаетесь к нему через эти переменные, поэтому вы можете добавить фиктивную коман
ду в конце).
   Обратите внимание, что псевдонимы, снабженные префиксом   ! , запускаются из корне
вого каталога вашего проекта, даже если ваш текущий каталог находится глубже. Это мо
жет быть полезным способом выполнить команду из корневого каталога без необходимости
явно переходить в него по команде cd.
          [ alias ]
        ignore =  "   !  echo $1  > >     . gitignore"

Раздел 1 1 .4. Временное игнорирование
отслеживаемых файлов
   Чтобы временно пометить файл как игнорируемый (необходимо передать этот файл
в качестве параметра для псевдонима), введите:

    unwatch = update-index --assume-unchanged

   Для повторного запуска отслеживания файла введите:

             = update-index --no-assume-unchanged    watch
   Чтобы задать весь список файлов, которые будут временно проигнорированы, введите:

    unwatched  =  "  ! git ls-files -v        I  g rep     • л [  [   : lower  :  ]  ]  ' "

   Чтобы сделать их снова отслеживаемыми, введите:

    watchall =  "  ! git unwatched       I  xargs -L  1  -I % sh  -с     ' git watch    · echo %       1
    cut -с 2- ·  • •

   Пример использования псевдонимов:
     git unwatch my_file . txt
    git watch my_file . txt
    git unwatched
    git watchall
