Раздел 2.9. Параметры, ограничивающие вывод
команды git log
    git log --after     ' 3 days ago '
   Эта команда показывает только коммиты, внесенные после указанной даты.
   Конкретные даты тоже подходят:
    git log --after 201 6-05-01
   Как и в других командах и флагах, принимающих параметр date, допустимый формат
даты соответствует тому, который поддерживается GNU date (очень гибкий).
   Параметр --since делает то же самое, что и параметр -after.
   Параметры --before и --until отображают только коммиты, внесенные до указанной
даты.
  Можно также фильтровать журналы по имени автора, например:
    git log --author=author
Раздел 2.1 О. Индексация файлов по частям
   Чтобы увидеть журнал с изменениями в конкретной строке-коммите, используйте флаги
-р или --patch  . Этот параметр показывает разницу (выводит патч), внесенную в каждый
коммит:
    git log --patch
