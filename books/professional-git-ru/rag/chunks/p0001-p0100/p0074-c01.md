Раздел 1 3.6. Несколько конфигураций Git
   Для конфигурации Git можно использовать до 5 источников.
     •   6 файлов:
         о   %ALLUSERSPROFILE%\Git\Config (только для Windows)
         о   (системный) <git>/etc/gitconfig, причем <git> - это путь к папке уста-
           новки gi t (в Windows это <gi t> \mingw64 \etc \gi tconfig)
          о   (системный) $XDG_CONFIG_HOME/git/config (только для Linux/Mac)
          о   (глобальный) ~/  . gitconfig (Windows: %USERPROFILE%\  . gitconfig)
          о   (локальный)   . gi t/config (внутри репозитория git $GП _DIR)
         о   специальный файл (редактируется с помощью git  config   -f), используе
           мый, например, для изменения конфигурации подмодулей: git  config  -f
               .gi tmodules     .  .  .
     •    с помощью командной строки, в которой можно набрать git  -с: git  -с  саге .
        autoc rlf=false ,  что тем самым переопределит любые другие core . autoc rlf
         в значение false, только для этой команды.
   Порядок следования важен: любая конфигурация, установленная одним из источников,
может быть переопределена другим источником, перечисленным ниже.
   gi t conf ig --system/ global/local -это команда, позволяющая перечислить три из этих
источников, но только gi t config -1 выведет на экран все разрешенные конфигурации.
   "Разрешено" означает, что в выведенном на экран списке будет указано только оконча
тельное переопределенное значение переменых файла конфигурации.
   Начиная с версии Git 2.8, если вы хотите посмотреть, какая конфигурация взята из како
го файла, введите:
    git config --list --show-origin
