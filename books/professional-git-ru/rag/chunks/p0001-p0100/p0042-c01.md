41Раздел 6.5. Отобразить разницу между всеми проиндексированными ...
Раздел 6.5. Отобразить разницу между всеми
проиндексированными и непроиндексированными
изменениями
   Чтобы показать все проиндексированные и непроиндексированные изменения, исполь
зуйте команду:
    git diff HEAD
   Примечание: можно также использовать следующую команду:
    git status -vv
   Разница заключается в том, что вывод последнего действительно скажет вам, какие из
менения проиндексированы для коммита, а какие нет.

Раздел 6.6. Показать различия для конкретного файла
или каталога
    git diff myfile . txt
   Эта команда отобразит изменения между предыдущим коммитом указанного файла
(myfile . txt) и локально модифицированной версией, которая еще не бьша проиндексиро
вана. Это работает и для каталогов:
    git diff documentation
   Выполнение этой команды отобразит изменения между предыдущим коммитом всех
файлов в указанном каталоге (documentation/) и локально модифицированными версия
ми этих файлов, которые еще не были проиндексированы.
   Чтобы показать разницу между некоторой версией файла в данном коммите и локаль
ной версией HEAD, вы можете указать коммит, с которым хотите провести сравнение:
     git diff 27fa75e myfile . txt
  Или если вы хотите сравнить эту версию файла с двумя отдельными коммитами, можно
использовать команду:
    git diff 27fa75e ada9b57 myfile . txt
   Чтобы показать разницу между версией с хешем ada9b57 и последним коммитом в вет
ке my_branchname только относительно каталога с именем my_changed_directory/, мож
но сделать так:
    git diff ada9b57 my_branchname my_changed_directory/
Раздел 6. 7. Просмотр в режиме word-diff для длинных строк
    git diff   [ HEAD  l --staged  .  .  .  ] --word-diff
   Вместо того чтобы отображать измененные строки, здесь будут показаны различия вну
три строк. Например, вместо:
      - Hello world
    + Hello world  !
... где отображаются все измененные строки целиком, режим word-di ff производит вывод
в следующем виде:
    Hello   [ -world- ] {+world  ! +}
