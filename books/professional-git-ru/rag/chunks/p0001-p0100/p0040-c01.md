Глава 6. Утилита сравнения (diff)

   Параметр             Описание
   -р,  -u, --patch        Генерировать патч.
   -s,  --no-patch       Подавить вывод diff. Полезно для команд типа git  show, кото
                      рые по умолчанию отображают патч, или для отмены действия
                      команды --patch.
   -- raw                 Генерировать diff в неотформатированном виде.
   --diff-algorithm=    Выбор алгоритма оределения отличий. Возможны следующие
                         варианты: myers, minimal, patience, histog ram.
   --summa ry            Вывод сжатой сводки расширенной заголовочной информации,
                         такой как создание, переименование и изменение режима.
   --name-status         Отобразить имена и статусы измененных файлов. Наибо
                          лее распространенные статусы: М (Modified - измененный),
                    А (Added - добавленный в индекс) и D (Deleted - удаленный).
   --check              Предупреждение о том, что изменения содержат маркеры кон
                        фликта или ошибки, связанные с символами пробела. Что счи
                          тать ошибками, связаными с символами пробела, определяет
                            ся конфигурацией со re  . whi tespace. По умолчанию ошибками
                        считаются символы пробела в конце текста (включая строки, со
                        стоящие исключительно из символов пробела) и символ пробе
                              ла, за которым сразу следует символ табуляции внутри началь
                           ного отступа строки. При обнаружении ошибки выполнение
                      команды завершается с ненулевым статусом. Этот параметр не
                        совместим с параметром --exi t-code.
   --full-index        При генерации выходных данных в формате патча вместо пер
                      вых нескольких символов в строке "index" отображаются пол
                      ные имена объектов до и после изменения.
   --name-only          Показывать только имена измененных файлов.
   --Ьinary             В дополнение к --full-index  выводит результат команды
                          di ff в бинарном формате, который может быть использован
                                 с командой gi t apply.
   -a, --text            Воспринимает все файлы как текстовые.
   --color               Устанавливает цветовой режим; то есть используйте --color=
                           always, если вы хотите перенаправить вывод diff в стандарт
                    ный канал вывода и сохранить при этом раскраску Git.
