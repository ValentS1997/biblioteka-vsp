82                                                                        Глава 1 6. Объединение
   Также можно использовать слова из сообщения коммита вместо хеша коммита, напри
мер так:
    git commit --squash     : /things
   В этой команде будет использоваться последний коммит со словом 'things'.
   Сообщение этих коммитов будет начинаться со слов   ' fixup  !  ' или   ' squash  !  ' , за кото
рыми будет следовать остальная часть сообщения коммита, в который эти коммиты будут
объединены.
   При перемещении следует применить параметр --autosquash  для использования
функции autosquash/fixup.

Раздел 1 6.5. Автообъединение: фиксация кода, который
необходимо объединить в общий коммит во время
операции перемещения
   Учитывая следующую историю, представьте, что вы внесли изменение, которое вы хоти-
те "втиснуть" в коммит ЬЬЬ2222  с сообщением "Второй коммит":
     $ git log --oneline --decorate
    сссЗЗЗЗ (HEAD -> master) Третий коммит
    ЬЬЬ2222 Второй коммит
     ааа1 1 1 1  Первый коммит
    9999999 Начальный коммит

   После внесения изменений вы можете добавить их в индекс обычным способом, а затем
зафиксировать с помощью команды -fixup аргумент, содержащий ссылку на коммит, в ко
торый вы хотите "втиснуть" коммит ЬЬЬ2222:
     $ git add
     $ git commit --fixup ЬЬЬ2222
           [ my-featu re-branch ddd4444 ] fixup  !  Второй коммит

   Это создаст новый коммит с сообщением коммита, которое Git сможет распознать во вре-
мя перемещения (rebase), выполняемого в интерактивном режиме:
     $ git log --oneline --decorate
    ddd4444 (HEAD -> master) fixup  !  Второй коммит
    сссЗЗЗЗ Третий коммит
    ЬЬЬ2222 Второй коммит
     ааа1 1 1 1  Первый коммит
    9999999 Начальный коммит

   Затем выполните rebase в итерактивном режиме с аргументом --autosquash  :
     $ git rebase --autosquash --interactive HEAD~4
    Git предложит вам выполнить   объединение, выпаленное  с помощью команды
commi t --fixup, и разместит объединенный коммит в нужную позицию:

    pick ааа1 1 1 1 Первый коммит
    pick ЬЬЬ2222 Второй коммит
    fixup ddd4444 fixup  !  Второй коммит
    pick сссЗЗЗЗ Третий коммит

   Чтобы избежать необходимости вводить --autosquash при каждой процедуре переме
щения, можно включить эту опцию по умолчанию:
     $ git config --global rebase . autosquash true
