42                                                                   Глава 6. Утилита сравнения (diff)
   Маркеры   [ -, - ] ,  {+, +}  можно не использовать,   указав --word-diff=color  или
--color-words. В этом случае для обозначения различий будет использоваться только цве

Раздел 6.8. Показать различия между текущей
и последней версиями ветви
    git diff НЕдDл HEAD
   При этом будут показаны изменения между предыдущим и текущим коммитом.

Раздел 6.9. Создание дельты (diff), совместимой
с патчем
   Иногда для применения патча требуется только diff. Патч -это какой-то результат рабо
ты команды diff, примененной, например, к двум сравниваемым файлам. Этот результат за
писывается в отдельный файл. Обычный gi t  - -d i f f в этом случае не работает. Попробуйте
сделать так:
    git diff --no-prefix > some_file . patch
   Затем в другом месте можно произвести процедуру, обратную этой, с использованием
сгенерированного патча:
    patch -р0 < some_file  . patch

Раздел 6.1 О. Отображение разницы между двумя коммитами
или двумя ветвями
   Для просмотра разницы между двумя ветвями можно выполнить следующую команду:
    git diff <branch1 >  .  . <branch2>
   Для просмотра разницы между двумя коммитами:
    git diff <commitld1 >  .   . <commitld2>
   Для просмотра разницы коммита с текущей веткой:
    git diff <branch/commitld>
   Для просмотра сводной информации по изменениям:
    git diff --stat <branch/commitld>  .
   Для просмотра файлов, изменившихся после определенного коммита:
    git diff --name-only <commitld>
   Для просмотра файлов, отличных от находящихся в ветви:
    git diff --name-only <branchName>
   Для просмотра файлов, изменившихся в папке после определенного коммита:
    git diff --name-only <commitld> <folder_path>
