Раздел 1 6.4. Автообъединение и внесение исправлений
   Во время редактирования коммитов можно указать, что в будущем определенный ком
мит будет объединен с другим коммитом, и это можно сделать следующим образом:
    git commit --squash= [ xeш коммита ,  до которого будет сжат этот коммит ]  .
   В качестве альтернативы можно также использовать команду fixup, --fixup= [ commit
hash ]  .
