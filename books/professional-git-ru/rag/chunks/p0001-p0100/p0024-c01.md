Раздел 3.3. Вывести список существующих
удаленных репозиториев
   Получить список всех существующих удаленных репозиториев, связанных с данным
хранилищем:
    git remote
   Вывести список всех существующих удаленных репозиториев, связанных с данным ло
кальным репозиторием, с подробным указанием URL для команд fetch (получения данных
из удаленного репозитория) и push (отправки сообщений в удаленный репозиторий):
    git remote --verbose
   или просто
    git remote -v
Раздел 3.4. Удаление локальных копий ветвей, удаленных
из удаленного репозитория
   После того как ветвь бьша удалена из удаленного репозитория, необходимо сообщить
локальному репозиторию о том, что необходимо удалить всё связанное с ней. Для удале
ния связи с удаленными ветками из конкретного удаленного репозитория можно восполь
зоваться командой:
    git fetch   [ название_удаленного_репозитория ]  --prune
   Для удаления связи со всеми удаленными ветвями от всех удаленных репозиториев мож
но использовать команду:
    git fetch --all --prune
Раздел 3.5. Обновление данных локального репозитория
в соответствии с данными удаленного репозитория
   Предположим, что вы установили связь с удаленным репозиторием (как в разделе "На
стройка удаленного репозитория"):
    git fetch название_удаленного_репозитория
    git merge название_удаленного_репозитория/название_ветви
   Команда pull сочетает в себе комбинацию сразу из двух команд fetch и me rge:
    git pull
   Команда pull с параметром -- rebase сочетает в себе комбинацию сразу из двух ко
манд - команды fetch и команды rebase вместо me rge, как в предыдущем случае:
     git pull -- rebase remote-name branch-name
