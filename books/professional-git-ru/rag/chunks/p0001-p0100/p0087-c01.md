  Вы получите список, который выглядит следующим образом:
    stash@{0 }  :  WIP оп maste r  : 67а4е01  Me rge tests into develop
       # Слить тесты в ветку develop
    stash@{1 }  : WIP оп master  : 70f0d95 Add user role to localStorage оп user login
       # Добавление роли пользователя в localStorage при входе пользователя в систему
   Теперь возьмите данные из "тайника" с помощью команды:
    git stash рор
   Еще раз проверьте список "заначек":
    git stash list
  Вы получите список, который выглядит следующим образом:
    stash@{0}  : WIP оп master  : 70f0d95 Add user role to localStorage оп user login
       # Добавление роли пользователя в localStorage при входе пользователя в систему
   Видно, что из списка stash удалены данные одного "тайника", и stash@{l} стал stash@{O}.

Раздел 1 8.3. Восстановление утерянного коммита
   Если вы совершили переход к предыдущему коммиту и потеряли последний коммит, вы
можете восстановить его, выполнив команду:
    git reflog
   Затем найдите потерянный коммит и вернитесь к нему, выполнив следующую команду:
    git reset HEAD  - - ha rd <sha1 -of-commit>
Раздел 1 8.4. Восстановление удаленного файла после фиксации
   Если вы случайно сделали коммит с удаленным файлом, а затем поняли, что его нужно
восстановить, то сначала необходимо найти идентификатор (ID) коммита, в котором был
удален файл.
    git log --diff-filte r=D --summa ry
   В результате вы получите отсортированный список коммитов, удаливших файлы. Затем
перейдите к восстановлению файла, используя команду:
    git checkout  81 eeccf~1  <имя вашего потерянного файла>
   (Замените 81еессf на свой собственный идентификатор коммита).

Раздел 1 8.5. Восстановление предыдущей версии файла
   Для восстановления файла к предыдущей версии можно воспользоваться функцией reset:
    git reset <sha1 -of-commit> <имя файла>
   Если вы уже внесли локальные изменения в файл (которые вам не нужны), вы также мо
жете использовать параметр -ha rd  .

Раздел 1 8.6. Восстановление удаленной ветки
   Для восстановления удаленной ветки необходимо найти коммит, который был головным
для удаленной ветки, выполнив команду:
    git reflog
