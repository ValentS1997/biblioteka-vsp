28                                                                  Глава 4. Индексация изменений
   В верхней половине этого вывода показано текущее состояние индекса с разбивкой
на два столбца, содержащих информацию о проиндексированных и непроиндексирован
ных изменениях:
        1.  В index . j s было добавлено 4 строки и удалено 4 строки. В настоящее время
        он непроиндексирован, так как текущий статус сообщает "неотслеживаемый"
          (unchanged). Когда этот файл будет переведен в статус проиндексированного, ин
        формация +4/-4 будет перенесена в столбец "staged" (проиндексирован), а в столбце
          "unstaged" (непроиндексирован) появится надпись "nothing" (ничего).
        2.  В файл package  . j son бьша добавлена одна строка, и он бьш проиндексирован.
       Дальнейших изменений после индексации не произошло, о чем свидетельствует
         строка "nothing" в колонке unstaged.
   В нижнем разделе с заголовком "*** Commands ***" показано, какие операции, касающи
еся индексации, можно выполнить. Их можо выбрать либо путем ввода числа (1-8), либо
путем ввода соответствующей буквы (s, u, r, а, р, d, q, h).
     •   status позволяет вывести на экран информацию, идентичную той, которая при
        ведена в верхней части приведенного выше вывода.
     •   update  позволяет вносить дальнейшие изменения в проиндексированные ком
       миты с помощью дополнительного синтаксиса.
     •   reve rt сбросит информацию о проиндексированых коммитах обратно в первона
        чальное состояние к HEAD.
     •   add unt racked позволяет добавлять в отслеживаемые ранее не отслеживавшиеся
        системой контроля версий пути файлов.
     •   patch позволяет выбрать один из отслеживаемых файлов и выведет для него ин
        формацию, аналогичную той, которую выводит команда status, для дальнейшего
          ее анализа.
     •   di ff отображает, что именно будет зафиксировано.
     •   qui t завершает выполнение команды.
     •   help представляет собой дополнительную справку по использованию этой команды.

Раздел 4.5. Вывести на экран проиндексированные изменения
   Чтобы отобразить те части проекта, которые находятся в стадии фиксации, применяет
ся команда:
    git diff --cached
Раздел 4.6. Проиндексировать отдельный файл
   Для внесения в индекс изменений в отдельном файле для последующего коммита выпол
ните команду:
    git add <filename>
Раздел 4.7. Индексация удаленных файлов
    git rm filename
   Чтобы удалить файл из git без удаления его с диска, используйте флаг --cached  :
    git rm --cached filename
