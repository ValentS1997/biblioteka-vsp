46                                                                    Глава 7. Отмена изменений
менить, а исправление самой функции займет слишком много времени, поэтому вы просто
хотите отменить объединение:
     >      git revert  -m  1   1 7a51 fd

     >      git push
              1 7a51 fd  .  . е443799 master  -> master
   На этом этапе функция с "гремлинами" из системы убрана, а ваши коллеги-разработчики
перестали на вас кричать. Однако мы еще не закончили. Как только вы устраните проблему
с помощью функции add-g remlins, вам нужно будет отменить этот откат (revert), прежде
чем вы сможете произвести повторное слияние:
     >      git checkout featu re/add-g remlins
       #Всевозможные коммиты для исправления ошибки  .
     >      git checkout master

     >      git revert е443799

     >      git merge featu re/add-g remlins
        #Устранить все конфликты слияния, возникшие в результате исправления ошибки
     >       git commit  # выполнить коммит слияния

     >      git push
   На этом этапе ваша функция успешно добавлена. Однако, учитывая, что ошибки та
кого рода часто возникают в результате конфликтов слияния, иногда полезнее исполь
зовать несколько иной рабочий процесс, позволяющий исправить конфликт слияния
в своей ветке:
     >       git checkout featu re/add-g remlins
       #выполните слияние с веткой master и сразу же сделайте откат( геvегt)  .
        #В результате ваша ветка окажется в том же состоянии ,  в котором до этого
       #находилась ветка master .
     >      git merge master

     >      git revert е443799
       #Теперь перейдите к исправлению ошибки   ( здесь может быть выполнено
       #несколько различых коммитов)
     >      git checkout master
        #На данном этапе не нужно выполнять откат, так как он был выполнен ранее
     >      git merge featu re/add-g remlins
       #Устранить все конфликты слияния ,  возникшие в результате
       #исправления ошибки
     >      git commit  # выполнить коммит слияния

     >      git push
