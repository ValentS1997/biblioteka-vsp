84                                                                   Глава 17. Команда cherry-pick
Раздел 1 7.2. Копирование нескольких коммитов
из одной ветки в другую
   Команда git cherry-pick <commit-A>  .  .  . <commit-B> поместит все коммиты после А
и до В включительно на вершину текущей ветки.
   Команда git cherry-pick <commit-д> л  .  .  . <commit-B> поместит коммит А и все ком
миты до В включительно на вершину текущей ветви.

Раздел 1 7 .3. Проверка необходимости применения
команды cherry-pick
   Перед тем как запустить на выполнение команду с he r ry-р ick, вы можете проверить, су
ществует ли уже в целевой ветке коммит, который вы хотите скопировать, или нет. И если
он уже есть, то вам не нужно ничего делать.
   Команда  gi t branch --contains <commi t> выводит список локальных веток, содер
жащих указанный коммит.
   Команда git branch  - r --contains <commit> также включает в список и отслежива
емые ветки, расположенные в удаленном репозитории.

Раздел 1 7 .4. Поиск коммитов, которые еще не были добавлены
в удаленный репозиторий
   Команда gi t cherry показывает изменения, которые еще не бьmи подвергнуты копиро
ванию командой cherry-pick. Пример:

    git checkout master
    git cherry development

... и видим примерно такой вывод:

     + 492508acab7b454eee8b805f8ba906056eede0ff
      - 5ceb5a9077ddb9e78Ы e8f24bfc70e674c627949
     + b4459544c000f4d51 d1 ec23f279d9cdЫ 9c1 d32b
     + bбce3b78e938644a293b2dd2a1 5b2fecb1 b54cd9
   Коммиты с + будут теми, которые еще не попали в репозиторий.
   Синтаксис:
    git cherry   [ -v ]    [ <upst ream>    [ <head>    [ <limit> ] ] ]
   Варианты:
   -v Показать коммиты рядом с хешем SHA1.
    <  upst ream   > Ветвь с удаленного репозитория для поиска одинаковых коммитов.
По умолчанию это ветка, на которую указывает HEAD.
    < head > Рабочая ветвь; по умолчанию это ветка, на которую указывает HEAD.
    <  1 imi t > Не сообщать о коммитах до (и включая) коммит limit.
   Более подробная информация приведена в документации по команде g i t-che r ry (https://
git-scm.com/docs/git-cherry).
