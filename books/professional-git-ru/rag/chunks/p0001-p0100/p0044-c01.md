6.1 1 .                                                                   43Раздел     Использование параметра meld для просмотра всех модификаций в рабочем каталоге
Раздел 6.1 1 . Использование параметра meld для просмотра
всех модификаций в рабочем каталоге
    git difftool -t meld --dir-diff
   Результат работы этой команды покажет изменения в рабочем каталоге. Альтернатив
ный вариант:
    git difftool -t meld --dir-diff   [ COMMIT_A ]    [ COMMIT_B]
   Здесь отобразятся различия между двумя конкретными коммитами.

Раздел 6.1 2. Команда Diff для текстовых и бинарных файлов plist
в кодировке UTF-1 6
  Вы можете применить команду diff к файлам в кодировке UTF-16 (например, пути к фай
лам в os IOS и macOS задаются в виде строк в кодировке UTF-16), указав, как Git должен раз
личать эти файлы. Добавьте следующие строки в файл ~/  . gi tconfig:
           [ diff "utf1 6"  ]  .
    textconv = "iconv -f utf- 1 6 -t utf-8"

   iconv - это программа для преобразования различных кодировок. Страницу с докумен
тацией по этой утилите вы можете найти по адресу http://linux.die.net/man/1/iconv.
   Затем отредактируйте или создайте файл   . gi tatt ributes в корне репозитория, в кото
ром вы хотите его использовать. Или просто отредактируйте фaйл ~/.gitatt ributes , доба
вив в него строку:

    * . st rings diff=utf1 6

   Это позволит преобразовать все файлы, имеющие расширение   . st rings,  перед созда
нием gi t di ffs.
   Аналогичным образом можно поступить и с другими файлами, которые можно преобра
зовать в текст. Для бинарных рlist-файлов необходимо отредактировать фaйл . gitconfig ,
добавив:
           [ diff "plist" ]  .
    textconv = plutil -convert xml1  -о  -

и файл   . gitatt ributes ,  добавив:

    * . plist diff=plist

Глава 7. Отмена изменений
Раздел 7 .1 . Возврат к предыдущему коммиту
   Чтобы вернуться к предыдущему определенному коммиту, сначала найдите хеш комми
та при помощи git  log. Чтобы временно вернуться к этому коммиту, отсоедините HEAD
с помощью:
    git checkout 789abcd
   В результате вы окажетесь в коммите 789abcd. Теперь вы можете создавать новые ком
миты поверх этого старого коммита, не затрагивая ветку, на которой находится ваш HEAD.
Любые изменения могут быть внесены в соответствующую ветку с помощью команд Ь га nch
или checkout  -Ь.
