24                                                     Глава 3. Работа с удаленными репозиториями
Раздел 3.6. Команда ls-remote
   gi t ls- remote - это уникальная команда, позволяющая запросить удаленный репози
торий без необходимости использования команд клонирования и копирования содержимого
в локальный репозиторий. Она выводит список всех ссылок ref s / head s и ref s / tags удален
ного репозитория.
   Иногда встречаются ссылки вида refs/tags/v0 . 1  . 6 и refs/tags/v0 . 1  . 5 л { }  :   л { }, ко
торые указывают на список тегов с описаниями (где каждое описание - это коммит, на ко
торый этот тег указывает).
   Начиная с версии git 2.8 (март 2016 г.) можно избежать двойной записи для тега и обра
щаться к списку тегов, на которые указывают ссылки, напрямую:
    git ls-remote -- ref
   Эта команда также может помочь определить фактический адрес url, используемый уда
ленным репозиторием, если в конфигурации был задан параметр "url . <base> . insteadOf"  .
Если git  remote  --get-url  <aremotename> возвращает https  : //server . com/user/ repo,
ивыустановили git config url . ssh  : / /git@server . com :  . insteadOf https  : / /server . com/  :
    git ls-remote --get-url <aremotename>
    ssh  : //git@server . com  : user/ repo
   Более подробно с командой gi t ls- remote можно ознакомиться, прочитав официальую
документацию (https://git-scm.com/docs/git-ls-remote).

Раздел 3. 7. Добавление нового удаленного репозитория
    git remote add upst ream git- repository-url
   Добавляет удаленный git-репозиторий, размещенный по адресу git- repository-url,
в качестве нового удаленного репозитория с именем upst ream в текущем локальном git-ре
позитории.

Раздел 3.8. Настройка Upstream для новой ветки
  Вы можете создать новую ветку и переключиться на нее, используя команду:
    git checkout -Ь АР-57
   После создания новой ветки с помощью команды gi t  checkout необходимо перейти
на эту ветку, установив upst ream на о rigin для последующей отправки информации в уда
ленный репозиторий, используя следующую команду:
    git push --set-upst ream origin АР-57
   После этого вы можете использовать gi t push, находясь на этой ветке.

Раздел 3.9. Начало работы
   Синтаксис для отправки изменеmm в удаленную ветку
    git push <имя_удаленного_репозитория> <имя_ветки>
   Пример:
    git push origin master
Раздел 3.1 О. Переименование удаленного репозитория
   Для переименования удаленных репозиториев используйте команду gi t remote rename .
   Команда git remote rename принимает два аргумента:
     •   Текущее имя удаленного репозитория, например: origin
     •   Новое имя для удаленного репозитория, например: destination
