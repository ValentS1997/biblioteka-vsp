Раздел 23.5. Сохранение линейной истории при извлечении
  Перемещение при извлечении
   Если вы получаете свежие коммиты из удаленного репозитория и у вас есть локальные
изменения в текущей ветке, то Git автоматически объединит версию с сервера с вашей вер
сией. Если вы хотите уменьшить количество слияний в вашей ветке, вы можете указать Git
переместить ваши коммиты в версию ветки на сервере.
    git pull -- rebase
   Сделать, чтобы такое извлечение производилось по умолчанию
   Чтобы каждый раз заново не набирать такую команду, надо просто сделать такое пове
дение поведением по умолчанию для вновь создаваемых ветвей. Введите следующую ко
манду:
    git config branch  . autosetuprebase always
   Чтобы изменить поведение любой ветви, используйте следующую последовательность
команд:
    git config branch  . BRANCH_NAME  . rebase true
   и
    git pull --no- rebase
   Чтобы выполнить обычное объединение, просто выполните обычное извлечение.
  Проверка возможности fast-forward (перемотки)
   Чтобы разрешить перемотку только локальной ветви, можно использовать:
    git pull --ff-only
   Это может привести к ошибке, если локальная ветка не обладает возможностью пере
мотки и ей разрешены только команды перемещения или слияния с веткой на удаленном
сервере.
