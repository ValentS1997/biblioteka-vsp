88                                                    Глава 20. Использование файла .gitattributes
Раздел 1 9.3. Удаление игнорируемых файлов
    git clean -fX
   Эта команда удалит все игнорируемые файлы из текущего каталога и всех подкаталогов.
    git clean -Xn
   Выполнение этой команды обеспечивает предварительный просмотр всех файлов, кото
рые будут удалены.

Раздел 1 9.4. Очистка всех неотслеживаемых каталогов
    git clean -fd
   Эта команда удалит все неотслеживаемые каталоги и находящиеся в них файлы. Она
начнет с текущего рабочего каталога и проЙДется по всем подкаталогам.
    git clean -dn
   Предварительный просмотр всех каталогов, которые будут очищены.

Глава 20. Использование файла
.gitattributes
Раздел 20.1 . Автоматическая нормализация окончания строк
   Создайте в корне проекта файл   . gi tatt ributes, содержащий:
     * text=auto

   В результате все текстовые файлы (идентифицированные Git) будут зафиксированы с LF,
но проверены в соответствии со стандартом операционной системы хоста.
   Это эквивалентно присвоению в файле конфигурации определенного значения перемен
ной саге . autoc rl f:
     •   input под Linux/macOS
     •   true в ОС Windows

Раздел 20.2. Идентификация двоичных файлов
    Git достаточно хорошо распознает бинарные файлы, но вы можете явно задать, какие
файлы являются бинарными. Создайте файл   . gi tatt ributes в корне проекта, содержащий
строки типа:
     * . png bina ry
   bina ry - это встроенный макроатрибут, эквивалентный -di ff -merge -text.
