Глава 4. Индексация изменений
Раздел 4.1 . Индексация всех изменений во всех файлах
    git add -А   Начиная с версии  ҋ 2 . 0
    git add
   В версии 2.х функция git  add. индексирует все изменения файлов в текущем каталоге
и всех его подкаталогах. Однако в версии 1.х эта команда будет учитывать только новые и из
мененные файлы, но не будет учитывать удаленные. Более подробно этот вопрос рассмотрен
в соответствующем разделе сайта StackOverflow (http://stackoverflow.com/a/26039014/3345375).
   Используйте команду git add -А или эквивалентную ей команду git add --all, что
бы проиндексировать все изменения файлов в любой версии git.

Раздел 4.2. Отменить индексацию изменений в файлах

Раздел 4.3. Индексация изменений по частям
   С помощью параметра patch можно увидеть, какие "части" всей работы будут проиндек
сированы для последующей фиксации:
    git add -р
   или
    git add --patch
   Эта команда запускает интерактивный диалог в командной строке, позволяющий про
смотреть все отличия от предыдущей версии и решить, включать их в индекс или нет. Вас
спросят, какие файлы вы собираетесь индексировать частями; затем для каждой части вы
бранного файла будут по очереди отображаться добавленные изменения с вопросом, хотите
ли вы их индексировать. У вас есть множество вариантов действий. Ввод символа ? позволя
ет увидеть перечень доступных вам вариантов:

    Stage this hunk  [y, n , q , a , d , / , s, e, ? ]  ?
         stage this hunk for the next commit (добавить этот фрагмент в индекс)        • Ш
      [!iJ do not stage this hunk for the next commit   ( не добавлять этот
     фрагмент в индекс)
