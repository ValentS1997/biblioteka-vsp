   Большинство файлов   . gitigno re являются стандартными для различных языков про
граммирования. Поэтому для начала работы можно воспользоваться приведенным набором
образцов файлов    . gitigno re, перечисленных по различным языкам программирования,
который можно скачать по адресу https://github.com/github/gitignore. Их можно клонировать
или скопировать/изменить для своего проекта. В качестве альтернативы для нового проекта
можно рассмотреть возможность автоматической генерации начального файла с помощью
онлайн-инструментария, который можо найти по адресу https://www.gitignore.io/.
  Другие детали, связанные с .gitignore
   Файлы   . gitignore предназначены для фиксации в качестве части репозитория. Если
вы хотите игнорировать определенные файлы без фиксации правил игнорирования, то вот
некоторые варианты того, как это можно сделать.
     •  Можо отредактировать файл    . git/info/exclude  (используя тот же синтаксис,
        что и  . gi tigno re). Правила будут глобальными в области видимости репозитория.
     •  Можно создать глобальный файл gitignore, который будет применять правила иг
        норирования ко всем локальным репозиториям.
   Кроме того, можно игнорировать локальные изменения отслеживаемых файлов без из
менения глобальной конфигурации git с помощью команд:
     •   git update-index  - - skip-wo rkt ree    [ <file>  .  .  .  ]  : для небольших локальных
        изменений
     •   git update-index  - -assume-unchanged    [ <file>  .  .  .  ]  : для готовых к производ
           ству, не изменяющихся файлов удаленного репозитория
   Более подробно о различиях между двумя последними параметрами можно прочитать
в статье по адресу http://stackoverflow.com/a/13631525/4531270. А с дополнительными опци
ями можно ознакомиться, прочитав документацию (https://git-scm.com/docs/git-update-index)
по команде git update- index.
  Удаление игнорируемых файлов
   Для удаления игнорируемых файлов можно использовать команду git clean -Х :
    git clean -Xn #вывести список игнорируемых файлов
    git clean -Xf #удаление ранее отображенных файлов
   Примечание: -Х (заглавная) очищает только игнорируемые файлы. Используйте -х  (без пропис
   ных букв), чтобы также удалить и неотслеживаемые файлы.
   Более подробную информацию см. в документации по команде g i t с lean .
   Более подробная информация по этой теме приведена в руководстве по Git по адресу
https://git-scm.com/docs/gitignore.

Раздел 5.2. Проверка игнорирования файла
   Команда git  check-ignore сообщает о файлах, игнорируемых Git. Соответствующий
раздел документации по этой команде расположен по адресу https://git-scm.com/docs/git
check-ignore.
  Вы можете передать команде имена файлов в командной строке, и git  check-ignore
выведет список игнорируемых имен файлов. Например:
     $ cat     . gitignore
    * . о
     $ git check-ignore example . o Readme . md
    example . o
