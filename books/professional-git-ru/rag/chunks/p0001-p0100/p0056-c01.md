Раздел 1 0.3. Коммиты с исправлениями                                               55
  Хороший способ проверить, написано ли сообщение для коммита в хорошем стиле, со
стоит в том, чтобы заполнить место пропуска в нижеследующем предложении, и посмо
треть, имеет ли оно смысл:
   Если я добавлю этот коммит в свой репозиторий, то ____
   Семь правил отличного сообщения для коммита в gi t:
        1.  Отделите строку с заголовком темы от основного текста пустой строкой.
       2.  Ограничте строку с заголовком темы не более чем 50 символами.
        3.  Пусть заголовок начинается с заглавной буквы.
       4.  Не ставьте точку в конце заголовка.
        5.  Используйте повелительное наклонение в строке с заголовком.
        6.  Вручную отформатируйте основной текст сообщения, чтобы его ширина составля
        ла 72 символа.
        7.  Используйте основной текст, чтобы объяснить, что и зачем вместо "как".
   Более подробно этот вопрос рассмотрен в статье "7 правил из блага Криса Бима", которую
можо найти по адресу http://chris.beams.io/posts/git-commit/#seven-rules.

Раздел 1 0.3. Коммиты с исправлениями
   Если ваш последний коммит еще не опубликован (не отправлен в удаленый репозито
рий), то вы можете изменить свой коммит:
    git commit --amend
   В результате текущие проиндексированные изменения будут размещены по месту пре-
дыдушего коммита.
   Примечание: это также может быть использовано для редактирования некорректного сообще
    ния, сопровождающего коммит. При этом будет вызван редактор по умолчанию (обычно vi  / vim /
   emac s), и в нем можно изменить предыдущее сообщение. Чтобы заменить старое сообщение, сопро
   вождающее коммит, на новое, можно воспользоваться следующей командой:
    git commit --amend  -m "Новое сообщение для коммита "
... или использовать предыдушее сообщение, сопровождающее коммит, не изменяя его:
    git commit --amend --no-edit
   При внесении изменений дата коммита обновляется, но дата автора остается нетрону
той. Вы можете указать Git обновить информацию о дате автора следующим образом:
    git commit --amend -- reset-author
  Вы также можете изменить имя автора коммита с помощью:
    git commit --amend --author "New Author <email@add ress  . com>"
   Примечание: следует помнить, что при изменении последнего коммита он полностью заменяется,
    а предыдущий коммит удаляется из истории ветки. Это следует иметь в виду при совместной работе
    с публичными репозиториями и ветвями других участников.
   Это означает, что если предыдущий коммит уже бьm опубликован, то после внесения
в него изменений необходимо будет добавиь параметр --force.
