Раздел 1 4.2. Вывод ветвей в виде списка
    Git предоставляет несколько команд для вывода списка ветвей. Все команды используют
функцию g i t Ь ranch, которая предоставляет список отобранных по определенному призна
ку ветвей, в зависимости от того, какие опции заданы в командной строке. По возможности
Git будет указывать выбранную в данный момент ветку звездочкой рядом с ней.
   Цель                                               Команда
  Список локальных ветвей                              git branch
  Список локальных ветвей в режиме подробного описания  git branch -v
  Список и всех ветвей на удаленном сервере, и локальных   git branch -а или git
  ветвей                                              branch --all
  Список удаленных и локальных веток в режиме подроб    git branch -av
  ного описания
  Список удаленных веток                               git branch  - г
  Список удаленных веток с последним коммитом           git branch  - rv
  Список слитых ветвей                                  git branch --merged
  Список не объединенных ветвей                        git branch --no-merged
  Список ветвей, содержащих коммит                     git branch --contains
                                                                                                                                      [ <commit> ]
   Примечания:
      •   Добавлениедопшшительного v к -v, например, $ git branch -avv юш $ git branch -vv,
         выведет также имя ветви в удаленном репозитории.
      •   Ветки, выделенные красным цветом, являются ветками, расположенными в удаленном ре
          позитории.

Раздел 1 4.3. Удаление ветки из удаленного репозитория
   Для удаления ветки из удаленного репозитория origin  можно использовать способ,
пригодный для Git, начиная от версии 1.5.0 и выше:
    git push origin     : <branchName>
... а начиная с версии Git 1.7.0 и выше ветку можно удалить из удаленного репозитория с по
мощью:
    git push origin --delete <branchName>
   Для удаления локальной ветки с параллельным отслеживанием в удаленном репозито
рии можно воспользоваться командой:
    git branch --delete -- remotes  < remote>/<branch>
    git branch -dr  < remote>/<branch>       # сокращенный вариант
