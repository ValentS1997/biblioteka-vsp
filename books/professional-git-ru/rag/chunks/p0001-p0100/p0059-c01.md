58                                                                 Глава 1 О. Фиксация изменений

  Ваш идентификатор - это буквенно-цифровой 16-значный код, следующий за первой
прямой косой чертой.
        2.  Определите идентификатор ключа в конфигурации Git:
          git config --global user  . signingkey YOUR-1 6-DIGIT-KEY-ID
        3.  Начиная с версии 1.7.9 git  commit принимает опцию -S для добавления подпи
         си к коммитам. При использовании этой опции будет запрошена парольная фраза
         GPG, и подпись будет добавлена в журнал фиксации:
          git commit  -S  -m "Ваше сообщение коммита"
Раздел 1 0.1 О. Фиксация изменений в определенных файлах
   С помощью gi t add можно зафиксировать изменения, внесенные в определенные фай
лы, даже минуя этап предварительной индексации:
    git commit file1  . c file2 . h
   Или можно сначала файлы проиндексировать:
    git add file1  . с file2  . h
... и зафиксировать их позже:
    git commit
Раздел 1 0.1 1 . Задать дату для коммита
    git commit  -m     ' Исправление ошибки пользовательского интерфейса  '
    --date 201 6-07-01
   Параметр --date  задает дату автора. Эта дата будет отображаться, например, в стан
дартном выводе по команде gi t log.
   Чтобы также принудительно установить дату коммита:
    GIT_COMMITTER_DATE=201 6-07-01 git commit  -m     ' Исправление ошибки
    пользовательского интерфейса '  --date 201 6-07-01

   Параметр date принимает все форматы, поддерживаемые, например, GNU date, приня-
тые в ОС Linux:
    git commit -m     ' Исправление ошибки пользовательского интерфейса  '
    --date yesterday
    git commit -m     ' Исправить ошибку пользовательского интерфейса  '
    --date     ' З days ago '
    git commit -m     ' Исправить ошибку пользовательского интерфейса  '
    --date     ' З hou rs ago '

   Если в дате не указано время, то будет проставлено текущее время, а переопределяться
будет только дата.

Раздел 1 0.1 2. Измениние времени коммита
  Вы можете изменить время коммита с помощью команды:
    git commit --amend --date="Thu Jul 28  1 1  : 30 201 6 -0400"
или даже
    git commit --amend --date=" now"
