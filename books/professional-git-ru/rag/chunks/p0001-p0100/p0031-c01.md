30                                Глава 5. Исключение из отслеживания отдельных файлов и папок
    # Игнорирование каталогов
    # Как сам каталог ,  так и его содержимое будут игнорироваться  .
    bin/
    gen/
    # Здесь также можно использовать шаблон на основе метасимволов
    # для игнорирования путей с определенными символами  .
    # Например , приведенное ниже правило соответствует как build / , так и Build/
          [ bB ] uild/
    # Без слеша в конце правило будет соответствовать файлу и/или
    # каталогу,  поэтому ниже будет игнорироваться и файл с именем  gen '  .
    # и каталог с именем   ' gеп '  ,  а также любое содержимое этого каталога
    bin
    gen
    # Игнорирование файлов по расширению
    # Все файлы с этими расширениями будут игнорироваться в данном каталоге
    # и всех его подкаталогах .
     * . apk
     * . class
    # Можно комбинировать обе формы ,  чтобы игнорировать файлы с определенными
    # расширениями в определенных каталогах . Следующие правила будут
    # избыточными по отношению к общим правилам ,  определенным выше .
       j ava/* . apk
    gen/* . class
    # Чтобы игнорировать файлы только в каталоге верхнего уровня ,  но не в его
    # подкаталогах, добавьте в правило префикс   ' / '  .
     /* . apk
     /* . class
    # Чтобы игнорировать любые каталоги с именем DirectoryA
    # на любой глубине ,  используйте ** перед DirectoryA
    # Не забывайте о последнем  / ,
    # В противном случае будут игнорироваться все файлы с именем DirectoryA,
    # а  не каталоги
    **/DirectoryA/
    # В этом случае игнорируется
    # DirectoryA/
    # DirectoryB/DirectoryA/
    # DirectoryC/DirectoryB/DirectoryA/
    # Git  не будет игнорировать файл с именем DirectoryA на любом уровне
    # Чтобы игнорировать любой каталог с именем DirectoryB внутри
    # каталога с именем DirectoryA с любым количеством
    # каталогов между ними ,  используйте ** между именами каталогов
    DirectoryA/**/DirectoryB/
    # Это позволит игнорировать
    # DirectoryA/DirectoryB/
    # DirectoryA/DirectoryQ/DirectoryB/
    # DirectoryA/DirectoryQ/DirectoryW/DirectoryB/
    # Для того чтобы был проигнорирован набор файлов , можно использовать те же
    # метасимволы,  что были показаны выше .
    # Применение одиночного символа     ' *  ' приведет к игнорированию всего
    # в вашей папке ,  включая файл     . gitignore .
    # Чтобы исключить конкретные файлы из списка игнорируемых при использовании
    # метасимволов ,  отмените их с помощью знака      !
    # Таким образом ,  они исключаются  из списка игнорируемых файлов  :
                !  . gitigno ге
