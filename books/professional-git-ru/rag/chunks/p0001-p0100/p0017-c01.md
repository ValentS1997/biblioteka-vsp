Раздел 2.1 . "Обычный" журнал истории версий Git
    git log
отобразит все ваши коммиты с указанием автора и хеша. Информация выводится в несколь
ких строках для каждого коммита. (Если вы хотите отображать одну строку для каждого ком
мита, следует обратить внимание на параметр oneline). Для выхода из журнала нажмите
клавишу q.
  По умолчанию при отсутствии параметров команда gi t log выводит в обратном хроно
логическом порядке список сохраненных в данный репозиторий версий. То есть первыми
отображаются самые свежие коммиты. Как видите, рядом с каждым коммитом указываются
его контрольная сумма SHA-1, имя и электронная почта автора, дата создания и сообщение
о фиксации (https://git-scm.com/Ьook/en/v2/Git-Basics-Viewing-the-Commit-History).

    git log -2
