78                                                                           Глава 14. Ветвление
Раздел 1 4. 7. Создание обособленной ветки (то есть ветки,
не имеющей ни одного предшествующего коммита)
    git checkout --orphan new-orphan-branch
   Первый коммит, сделанный в этой новой ветке, не будет иметь предшественников и ста
нет корнем новой истории версий, полностью обособленной от всех других веток и коммитов.
   С документацией по этой команде можно ознакомиться по адресу https://git-scm.com/docs/
git-checkout.

Раздел 1 4.8. Переименование ветки
   Переименовать ветку, на которую вы перешли, можно командой:
    git branch  -m new_branch_name
   Переименовать любую другую ветку, на которой вы не находитесь в данный момент:
    git branch  -m branch_you_want_to_ rename new_branch_name
Раздел 1 4. 9. Поиск по веткам
   Чтобы вывести список локальных веток, содержащих определенный коммит или тег,
воспользуйтесь командой:
    git branch --contains <commit>
   Чтобы вывести список локальных ветвей и веток, находящихся в удаленном репозито
рии и содержащих определенный коммит или тег, воспользуйтесь командой:
    git branch -а --contains <commit>
Раздел 1 4.1 О. Передача данных из локальной ветки
в ветку в удаленном репозитории
   Используется для пересылки коммитов, сделанных в локальной ветке, в удаленный ре
позиторий. Команда git push принимает два аргумента:
     •  Имя ветки в удаленном репозитории, например origin
     •  Имя локальной ветки, например maste r
   Например:
    git push <имя_удаленного_реnозитория> <имя_локальной_ветки>
   В качестве примера можно привести выполнение команды git  push  or1gin  master
для переноса локальных изменений в удаленный репозиторий. Использование параметра
-u (сокращение от --set- upst ream) позволит отследить информацию во время выполне
ния рush:
    git push -u <имя_удаленного_репозитория> <имя_локальной_ветки>
   По умолчанию g i t передает информацию из локальной ветки в удаленную ветку с тем
же именем. Например, если у вас есть локальная ветка с именем new-featu re, то при выпол
нении gi t push из локальной ветки будет создана удаленная ветка с именем new-featu re.
Если вы хотите использовать другое имя для ветки в удаленном репозитории, добавьте имя
удаленной ветки после имени локальной ветки, разделяя их символом ":"
    git push <имя_удаленного_репозитория> <имя_локальной_ветки>  :
    <имя_удаленной_ветки>
