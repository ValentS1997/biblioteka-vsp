56                                                                 Глава 1 О. Фиксация изменений

   Ваше сообщение коммита может занимать несколько строк:
    git commit  -m "Заголовок сообщения коммита
    Более подробное описание следует здесь   ( после пустой строки ) "  .
   В качестве альтернативы можно передать сообщение через несколько аргументов -m :
    git commit  -m "Заголовок сообщения коммита"  -m "Более подробное описание
 следует здесь"
   См.  раздел  "Как  написать  сообщение  коммита   Git", расположенный  по  адресу
https://udacity.github.io/git-styleguide/.

Раздел 1 0.5. Прямая фиксация изменений
   Обычно для добавления изменений в индекс перед их фиксацией git  commit необхо
димо использовать git  add или git rm. Передача в команду git  commit  параметра -а
или --all позволяет автоматически добавлять в индекс все изменения (в отслеживаемых
файлах), включая удаления:
    git commit -а
   Если вы хотите также добавить сообщение коммита, то это можно сделать:
    git commit -а  -m "Ваше сообщение коммита помещается здесь"
   Кроме того, можно объединить два параметра:
    git commit -am "Ваше сообщение коммита помещается здесь"
   Не обязательно фиксировать все файлы сразу. Опустите флаг -а или --all и укажите,
какой файл нужно зафиксировать, напрямую:
    git commit path/to/a/file  -m "Ваше сообщение коммита помещается здесь"
   Для прямой фиксации нескольких конкретных файлов в теле команды можно указать
один или несколько файлов, каталогов и шаблонов:
    git commit path/to/a/file path/to/a/folder/* path/to/Ь/file -m
     "You r commit message goes here"

Раздел 1 0.6. Выбор конкретных строк, которые должны быть
проиндексированы для фиксаци
   Предположим, у вас много изменений в одном или нескольких файлах, но из каждого
файла вы хотите зафиксировать только некоторые из них. Вы можете проиндексировать
нужные изменения с помощью команды:
    git add -р
или
    git add -р   [ file ]
   Каждое изменение будет отображаться отдельно, и для каждого изменения будет предло-
жено выбрать одну из следующих опций:
   у - Да, добавить этот фрагмент.
    N - Нет, не добавлять этот фрагмент.
    d - Нет, не добавлять этот фрагмент и другие оставшиеся фрагменты для этого файла.
Эта опция полезна в ситуации, когда вы уже добавили то, что хотели, и хотите пропустить
остальное.
    s - По возможности разделить фрагмент на более мелкие фрагменты.
   е - Вручную отредактировать фрагмент. Это, пожалуй, самая мощная опция. Она от
крывает фрагмент в текстовом редакторе, и вы можете редактировать его по своему усмот
рению.
