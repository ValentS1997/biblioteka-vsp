Раздел 1 1 .5. Показать журнал версий с графом ветвей
           [ alias ]
        logp=log --pretty=format  :  ' %h %ad        1 %s%d  [%an ]  '  --g raph --date=short

        lg  = log --g raph --date-order --first-pa rent  \
           --pretty=format  :  ' %C(auto}%h%Creset %C(auto}%d%Creset %s %C(green} (%ad}
    %C( boldcyan } <%an>%Creset  '
        1gb  = log --g raph --date-orde r --branches --first-pa rent  \
           --pretty=format  :  ' %C(auto}%h%Creset %C(auto}%d%Creset %s %C(green} (%ad}
    %C( bold cyan } <%an>%Creset '
        lga  = log --g raph --date-orde r --all  \
           --pretty=format  :  ' %C(auto}%h%Creset %C(auto)%d%Creset %s %C(green) (%ad)
    %C( bold cyan } <%an>%Creset '

   Ниже приведено пояснение для всех опций и аргументов, используемых в формате
--pretty (исчерпывающий список доступен по команде git help  log):
    - -g raph - нарисовать дерево коммитов
   --date-order - по возможности вывести в порядке, отсортированном по времени соз-
дания коммитов
   --first-parent - следовать только первому родителю узла слияния
   --b ranches - показывать все локальные ветви (по умолчанию показывается только те-
кущая ветвь)
   --а 11 -показать полностью все ветви (локальные и находящиеся в удаленном репозитории)
   %h - хеш-значение для коммита (сокращенное значение)
   %ad - дата автора (формат соответствует параметру '--date= ')
   %an - имя автора
   %an - имя автора, выполнившего коммит
   %С( auto) - использовать цвета, определенные в разделе [color]
   %Creset - сброс цвета
   %d - --decorate (имена ветвей и тегов)
   %s - сообщение коммита
   %ad - дата автора (соответствует параметру --date) (дата автора кода, а не человека, вы
полнившего коммит)
   %an - имя автора (может быть 0/ocn для имени человека, выполнившего коммит)

Раздел 1 1 .6. Отобразить файлы, содержащиеся
в конфигурации .gitignore
           [ alias ]
        ignored =   ! git ls-files --others --ignored --exclude-standard --directory \
              && git ls-files --others -i --exclude-standard
   Выводит одну строку на файл, что позволяет использовать комаду g гер (отображать
только каталоги):
     $ git ignored       I grep     ' /$ '
              . ya rdoc/
    doc/

   Или может вывести количество игнорируемых файлов:
    ~$ git ignored        I wc -1
        1 9981 1
