Раздел 2.3. Применение в журналах возможности выделения цветом                                       1 7
        *  98f91 7e difftool  : avoid $GIT_DIR and $GIT_WORK_TREE
        *  9ес2бе7 difftool  : fix a rgument handling in subdirs
     *       f4fd627 Merge branch     ' j k/ reset-ident-time-per-commit  '  into maint

   Поскольку это довольно длинная команда, ее можно сократить, применив псевдоним:
    git config --global alias  . lol  " log --decorate --oneline --g raph"
   Для использования версии с псевдонимами:

    # история версий текущей ветки     :
    git lol
    # объединенная история активной ветви (HEAD)  , ветвей develop и origin/master
    git lol HEAD develop origin/master
    # объединенная история всего,  что есть в вашем реnозитории
    git lol --all
Раздел 2.3. Применение в журналах возможности
выделения цветом
    git log --g raph --pretty=format  :  ' %C( red )%h%Creset -%C(yellow)%d%Creset %s
 %C( g reen ) (%c r ) %C (yellow) <%an>%Creset '

   Параметр format позволяет задать собственный формат вывода журнала:
   Параметр       Подробности
   %С ( имя_цвета)  окрашивает вывод, следующий за ним
   %h или %Н      сокращает хеш коммита (для получения полного хеша используйте %Н)
   %Creset         сбрасывает цвета в цвета терминала, заданные по умолчанию
   %d            имена ссылок
   %s            комментарии
   %с г              дата создания версии в относительном формате (то есть относительно
                 текущей даты)
   %an           имя автора

Раздел 2.4. Вывод записи журнала в одну строку
    git log --oneline
покажет все ваши коммиты только с первой частью хеша и сообщением о коммите. Каждый
коммит будет расположен в одной строке, как и предполагает параметр oneline.
   Параметр oneline выводит каждый коммит в отдельной строке, что удобно, если вы про
сматриваете большое количество коммитов.
   Для того чтобы лучше разобраться в теме, советуем проделать экспериментально при
меры, изложенные в официальной документации по  Git. Их можно найти по адресу
httрs://git-sсm.соm/Ьооk/ru/v2/Основы-Git-Просмотр-истории-коммитов.
   Пример (из репозитория Free Code Camp (https://github.com/FreeCodeCamp/FreeCodeCamp),
с тем же участком кода из примера, рассмотренного в разделе 2.1):

    87ef97f Merge pull request #7724 from BKinahan/fix/where-art-thou
