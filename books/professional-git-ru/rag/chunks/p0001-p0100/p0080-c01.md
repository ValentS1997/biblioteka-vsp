79Раздел 1 4.1 1 . Переместить указатель HEAD текущей ветки на произвольный коммит
Раздел 1 4.1 1 . Переместить указатель HEAD текущей ветки
на произвольный коммит
   Ветка - это просто указатель на коммит, поэтому его можно свободно перемещать. Что
бы ветка ссылалась на коммит ааЬЬсс, выполните команду:
    git reset --hard ааЬЬсс
   Обратите внимание, что при этом будет перезаписан текущий коммит вашей ветки и, со
ответственно, изменится вся ее история. В результате выполнения этой команды вы може
те потерять часть своей работы. В этом случае для восстановления потерянных коммитов
можно воспользоваться командой reflog, то есть ссылочным журналом. Мы советуем при
менить эту команду на новой ветке, а не на текущей.
   Однако эта команда может быть особенно полезна при операциях перемещения или
для других аналогичных команд, подвергающих историю версий серьезной модификации.

Глава 1 5. Rev-List
   Параметр           Пояснение   --oneline         Отображение коммитов в виде одной строки с заголовком

Раздел 1 5.1 . Список коммитов, содержащихся в master,
но не содержащихся в origin/master
    git rev-list --oneline master лoгigin/master
   Git  rev-list выводит список коммитов, содержащихся в одной ветке, но отсутствую
щих в другой ветке. Это отличный инструмент, когда вы пытаетесь понять, был ли код слит
в ветку или нет.
     •  При использовании опции --oneline будет отображаться заголовок каждого ком
         мита. Оператор л исключает из списка коммиты в указанной ветке.
     •  При желании в качестве параметров команды можно передать более двух веток.
        Например, git rev-list foo ba r льаz перечисляет коммиты в ветках fоо и Ьаr,
        но не в ветке baz.

Глава 1 6. Объединение
Раздел 1 6.1 . Объединить заданные коммиты без проведения
процедуры перемещения
   Если необходимо объединить предшествующие х коммиты в один, можно воспользо
ваться следующими командами:
    git reset --soft HEAD~x
    git commit
   Если вам необходимо объединить в один коммит какое-то количество коммитов, просто
вместо х подставьте свое число.
