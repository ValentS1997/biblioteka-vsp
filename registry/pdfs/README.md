# PDF-архив реестра

Этот каталог предназначен для PDF-копий книг из физического/приобретённого реестра.

PDF-файлы хранятся отдельно от `books/**/source/book.pdf`: наличие PDF здесь означает только наличие цифровой копии у позиции реестра и не означает, что книга заведена в RAG lifecycle.

## Хранение

- Формат: PDF.
- Git storage: Git LFS.
- Канонические имена начинаются с инвентарного номера.
- SHA-256 и сопоставление с реестром фиксируются в [`index.yaml`](./index.yaml).
- Неоднозначные файлы помещаются в `_unverified/` до ручного подтверждения.
