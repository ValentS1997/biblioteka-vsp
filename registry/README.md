# Реестр библиотеки

Этот каталог хранит общий реестр физических/приобретённых книг проекта `biblioteka-vsp` и отмечает наличие известных электронных версий.

> **46 инвентарных книг** · инвентарные номера `0001–0046` · **21 электронный файл** в предоставленном списке · актуально на `2026-09-24`

Реестр намеренно отделён от [`books/index.yaml`](../books/index.yaml): каталог `books/` описывает книги, уже заведённые в knowledge/RAG lifecycle, а этот каталог описывает библиотеку независимо от статуса ingest.

## Файлы реестра

- [`books.yaml`](./books.yaml) — каноническая машиночитаемая копия реестра и сопоставлений электронных версий.
- [`reestr_knig_0046.xlsx`](./reestr_knig_0046.xlsx) — исходный Excel-файл без изменений.
- Лист `Лист2` в Excel — шаблон журнала выдачи; заполненных записей сейчас нет.
- Лист `Источники` — provenance/проверки для инвентарных номеров `0036–0046`.
