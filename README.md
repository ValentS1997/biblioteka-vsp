# Библиотека ВСП

Это приватная библиотека технических и профессиональных книг. Здесь можно узнать, какие книги есть в коллекции, найти конспекты и схемы по главам, продолжить чтение с сохранённого места и проверить, на каких страницах основан вывод.

Книги добавляются постепенно, поэтому у разных записей разная степень готовности. **Наличие книги в реестре, электронной копии, поискового слоя и готовых конспектов — разные вещи.** Актуальное состояние каждой книги смотрите в [реестре библиотеки](registry/README.md).

## Как найти материалы по книге

1. Откройте [реестр](registry/README.md). В таблице «Покрытие knowledge-проектов» найдите книгу. Если в столбце «Выжимки» есть материалы, нажмите на значение, чтобы открыть их список.
2. Перейдите по её **Knowledge ID** в каталог [`books/`](books/). В `notes/chapters/README.md` находятся ссылки на разобранные главы.
3. Откройте нужную главу. `summary.md` содержит конспект, `cheatsheet.md` — краткую памятку, `commands.md` — команды, а `visual-cheatsheet.svg` — схему. Не у каждой главы есть все эти файлы.

Например: [главы книги «Docker без секретов»](books/docker-demystified-saibal-ghosh-ru-2023/notes/chapters/README.md) → [конспект первой главы](books/docker-demystified-saibal-ghosh-ru-2023/notes/chapters/chapter-01-containerization-and-docker/summary.md). У некоторых книг есть и общий материал в `notes/book-synthesis/`.

Репозиторий приватный. Ссылки на книги и материалы открываются только тем, кому выдан доступ к нему.

## Что здесь хранится

- [Реестр](registry/README.md) — удобный список книг и готовых материалов. Его исходные данные находятся в `registry/books.yaml` и [`books/index.yaml`](books/index.yaml); устройство описано в [архитектуре реестра](registry/ARCHITECTURE.md).
- [`books/`](books/) — каталоги отдельных книг: сведения об издании и происхождении файла, исходный PDF или EPUB, прогресс чтения, заметки, схемы и материалы для поиска по тексту.
- [`templates/`](templates/README.md) — действующие шаблоны и контракты работы с книгами и главами.
- [`scripts/`](scripts/) и [проверки GitHub Actions](.github/workflows/) — сборка поискового слоя, обновление реестра и проверка опубликованных материалов.

Исходный PDF или EPUB хранится как файл Git LFS с контрольной суммой. Производные тексты и фрагменты можно построить заново из этого источника. Готовые embeddings не считаются канонической частью книги.

## Чтение и поиск — разные процессы

`reading/progress.yaml` и `reading/journal.md` отражают фактическое чтение и обсуждение. По умолчанию совместное обсуждение не забегает дальше подтверждённого прогресса без просьбы читателя.

Поисковый слой (`rag/`) может быть подготовлен для всей книги заранее. Поэтому пометка «Есть RAG» не означает, что книгу прочитали или что по ней уже есть конспекты. И наоборот, чтение возможно без RAG. Точные состояния и условия готовности описаны в [модели жизненного цикла](docs/BOOK-LIFECYCLE.md).

Если нужен ответ **только по материалам книги**, используйте [правила поиска](RAG-RETRIEVAL.yaml). Они ограничивают поиск небольшими фрагментами с привязкой к источнику. Если подтверждающий фрагмент не найден, ответ не должен выдавать догадку за содержание книги.

## Как библиотека связана с другими проектами

Другие проекты могут читать реестр, доступные конспекты и подтверждённые фрагменты книг. Вопросы, заметки и предложения исправлений передаются через GitHub Issues; они попадают в библиотеку как проверенное знание только после разбора. Формат взаимодействия описан в [PROTOCOL.md](PROTOCOL.md).

## Если вы добавляете книгу или работаете с AI-помощником

Начните с [индекса действующих шаблонов](templates/README.md). Он указывает актуальные версии для добавления книги, проверки её готовности, разбора главы, публикации файлов и восстановления после прерванного чата. Краткая карта основных контрактов:

- [Маршрутизация процесса](templates/process-compliance-router-v1.2.yaml) и [правила работы с Git](templates/git-execution-policy-v1.0.yaml).
- [Создание книжной ветки](templates/book-branch-bootstrap-v1.4.yaml), [подготовка книги](templates/book-onboarding-v1.3.yaml), [приёмка поискового слоя](templates/rag-ingestion-acceptance-v1.0.yaml) и [проверка готовности](templates/book-readiness-v1.3.yaml).
- [Запрос на разбор главы](templates/chapter-analysis-request-v1.4.yaml), [состав материалов](templates/chapter-artifact-collection-v1.8.yaml) и [их публикация](templates/chapter-publication-v1.0.yaml).
- [Восстановление после обрыва чата](templates/session-recovery-v1.0.yaml). Команда для книжного чата: **«Ковальски, проверка после обрыва связи»**.

Изменения вносятся через рабочую ветку и проверяются перед попаданием в `main`. PDF и EPUB хранятся в приватном репозитории; запись о покупке или владении экземпляром сама по себе не означает разрешения распространять электронный файл. Происхождение и права фиксируются отдельно в метаданных книги.
